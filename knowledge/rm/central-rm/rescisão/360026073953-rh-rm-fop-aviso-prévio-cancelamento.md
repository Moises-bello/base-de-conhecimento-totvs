Dúvida**Como realizar o cancelamento de aviso prévio?  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar o **cancelamento do** **Aviso Prévio** realize os seguintes passos:  
  
1. Acesse o menu **Rescisão | Cancelar Aviso Prévio****![](https://centraldeatendimento.totvs.com/hc/article_attachments/23511154275223)**2. Será apresentada a tela com os campos para preenchimento, conforme abaixo;  
  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/23511204626583)****Filtro Período do Aviso**A Data Inicial e Data Final é um Filtro, portanto informe uma data inicio e fim, o produto irá buscar entre as datas, funcionários com Aviso Prévio cadastrado.  
  
**Data do Cancelamento**Preencha com a data que está sendo cancelado o aviso prévio.  
  
**Seleção de Funcionários**Preencha com a chapa do funcionário que deseja cancelar o aviso prévio.   
  
**Motivo do cancelamento**Selecione o motivo pelo qual está cancelando o aviso prévio.   
  
**Atenção** Ao realizar o cancelamento,  funcionário terá sua situação retornada para A - Ativo.
