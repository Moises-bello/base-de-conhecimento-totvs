**Dúvida**O que devo encaminhar para suporte quando o sistema gerar *error Log*?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) – Gestão de Pessoal  – Todas as versões  
  
**Solução**Para uma análise mais assertiva do problema, envie o arquivo *erro.log* conforme orientações abaixo:  
  
**1.** Entrar no servidor, pasta ***System*** e apagar o arquivo ***ERROR.LOG***  
**2.** Gerar novamente o erro no sistema  
**3.** Voltar para a pasta *system* e *ZIPAR* o novo arquivo *ERROR.LOG*  
**4.** Salve no bloco de notas com o número do chamado  
**5.** Envie este arquivo através do portal do cliente /Ticket  
**6.** Envie também o Extrato de Versão:   
[Como gerar extrato de versão quando a porta multiprotocolo está desabilitada](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4410028522135-RH-Linha-Protheus-GPE-Como-gerar-Extrato-de-Vers%C3%A3o-quando-a-porta-MultiProtocolo-est%C3%A1-desabilitada)  
[Como gerar Extrato de Versão quando a porta MultiProtocolo está habilitada](https://centraldeatendimento.totvs.com/hc/pt-br/articles/25085490130071-RH-Linha-Protheus-GPE-Como-gerar-Extrato-de-Vers%C3%A3o-quando-a-porta-MultiProtocolo-est%C3%A1-habilitada)
