**Dúvida**Por que o cálculo de rescisão apresenta o ID 1695-Insalubridade Aviso Prévio?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**

O ID 1695-Insalubridade aviso prévio se trata da insalubridade referente a verba indenizatória aviso prévio, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1695.**
