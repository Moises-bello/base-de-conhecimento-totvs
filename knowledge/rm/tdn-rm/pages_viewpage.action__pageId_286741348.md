# LOG DE MATRÍCULA NA DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Matricular aluno nas disciplinas |
| **Situação/Requisito:** | Na versão 12.1.14, o Log do final do processo “Matricular aluno nas disciplinas” mesmo com vários itens não atendidos para matrícula, no caso o usuário que possui perfil para sobrescrevê-los, consegue realizar a matrícula e o Log do final de processo aparece. Porém, na versão 12.1.17 não está aparecendo o log. |
| **Solução/Implementação:** | Correção para que ao matricular um aluno em uma disciplina, caso exista alguma pendência e o usuário possua perfil para sobrescrevê-las, apareça o log ao final do processo com as pendências que foram sobrescritas. |
