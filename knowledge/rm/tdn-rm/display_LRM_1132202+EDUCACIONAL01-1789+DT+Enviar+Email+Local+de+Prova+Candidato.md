# ENVIAR E-MAILS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Enviar e-mails* |
| **Situação/Requisito:** | *Foi identificado que ao enviar um e-mail no processo seletivo do tipo "Local de prova do candidato" o sistema não filtra por situação da inscrição nem status da opção, sendo assim, ao enviar e-mails de locais de prova o sistema envia até mesmo para candidatos que já foram desclassificados.* |
| **Solução/Implementação:** | *Foi feito um ajuste para este tipo e-mail para que o envio de e-mails seja feito somente para candidatos com inscrições ativas e que não estejam com nenhum tipo de ausência ou desclassificação no processo seletivo ou nas etapas.* |
