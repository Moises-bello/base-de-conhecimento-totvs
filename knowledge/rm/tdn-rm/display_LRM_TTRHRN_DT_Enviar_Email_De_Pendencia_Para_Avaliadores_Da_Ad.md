# ENVIAR EMAIL DE PENDÊNCIA PARA AVALIADORES DA AD

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Enviar Email de Pendência para Avaliadores da AD* |
| **Situação/Requisito:** | *O processo "Enviar e-mail de pendência para os avaliadores da A.D." não está sendo executado corretamente.* *Ele pede ao usuário para selecionar os itens pendentes e envia para o avaliador os e-mails de todas as avaliações. Independente da situação. O processo deverá selecionar os itens pendentes que estão na visão e encaminhar um e-mail listando esses itens.* |
| **Solução/Implementação:** | *Ajuste no processo "Enviar e-mail de pendência para os avaliadores da A.D.". Nos e-mails enviados pelo processo, só são listadas as avaliações pendentes para o avaliador correspondente. Além disso, o processo não pode ser executado se forem selecionadas avaliações não pendentes.* |
