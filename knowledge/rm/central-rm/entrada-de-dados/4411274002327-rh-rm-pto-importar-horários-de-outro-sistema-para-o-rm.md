![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16503303055511) Tempo aproximado para leitura: **00****:01:00 min****Dúvida**Como importar horário de outro sistema para o RM?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - Todas as versões  
  
**Solução**Para realizar a importação de horários de outro sistema para o RM, realize os seguintes passos:

1. Acesse o módulo Folha de Pagamento o menu **Configurações | Importações | Importação de Dados da Folha de Pagamento.**

2. A janela do assistente será aberta, avance e marque o campo **Horários** e no ícone localizar arquivos identifique o arquivo do horário em .txt a ser importado.  
  
![importa_horario.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29044980600599)  
  
3. Avance e execute.

**Saiba Mais**  
Para criar o arquivo .txt e importar o horário de outro sistema, verifique as opções de layouts do link a seguir [Importação de Horário](https://tdn.totvs.com/pages/viewpage.action?pageId=415707918)
