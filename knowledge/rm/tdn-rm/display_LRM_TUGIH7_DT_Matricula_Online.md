# VALIDAÇÃO REQUISITOS NA MATRÍCULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Matrícula Online* |
| **Situação/Requisito:** | *Durante o processo de matrícula online, caso o aluno avançasse no processo utilizando as abas a validação dos requisitos das disciplinas selecionadas não era realizado no client, desta forma o bloqueio só ocorria no Server da aplicação.* |
| **Solução/Implementação:** | *Ajuste no processo de matrícula online para que a validação dos requisitos da disciplina seja realizada no client quando o aluno avançar no processo, seja via botão ou selecionando diretamente as abas disponíveis.* |
