**Dúvida**

Como visualizar os Custos do Projeto no Browser?  
  
**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGAPMS -  Todas as versões.

**Solução :**

O controle de custos do sistema de projetos oferece a ferramenta completa para planejar e monitorar todos os custos envolvidos na execução do projeto, possibilitando o planejamento e monitoração em vários níveis de detalhamento no projeto.

• Se Árvore, à direita da tela podemos verificar os dados cadastrais do projeto à esquerda, e a direita é apresentada a estrutura do projeto.

• Se Planilha, a estrutura do orçamento é apresentada linha a linha da planilha.

Configuração :

1. F12 Browser > Projeto >Parâmetro = "**Planilha**";

2. Posicione no projeto, e acione Outras Ações **→** Alt. Estrutura **→** Selecione Edt / Tarefa **→** Outras Ações **→ Configurar** **Colunas** ;

Permite configurar as colunas que se deseja visualizar, por **planilha**, no projeto.

3. Selecione os campos desejados e clique no botão **Adicionar**;
