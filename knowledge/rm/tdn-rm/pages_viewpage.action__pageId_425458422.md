**Motivo Atividade/Inatividade**   
O Motivo Atividade/Inatividade permite registrar as razões que podem ocorrer para deixar o atendente inativo ou ativo para exercer suas atividades.  O cadastro é composto pelo código (gerado automaticamente pelo sistema), descrição além das flags:  
Aparece como Ativo no posto de trabalho.  
Define motivo como padrão.  
Caso a opção "Define motivo como padrão" seja definida para um motivo e já exista outro motivo  como padrão, ao tentar gravar o registro uma mensagem de alerta é apresentada solicitando confirmação, em caso positivo o motivo padrão é alterado e em negativa a operação é cancelada.
