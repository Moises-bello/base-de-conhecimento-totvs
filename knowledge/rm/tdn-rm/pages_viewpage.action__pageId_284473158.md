# Baixa com meio de pagamento cheque não compensa extratos das parcelas.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixa de Lançamento |
| **Situação/Requisito:** | Ao realizar a baixa com meio de pagamento cartão de crédito com mais de uma parcela, o sistema compensa o extrato da primeira baixa e não compensa os restantes. |
| **Solução/Implementação:** | Agora o sistema faz a compensação de todos os extratos de caixa, se for parametrizado para compensar. |
