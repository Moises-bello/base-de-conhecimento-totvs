Através deste assistente é possível a importação de fotos para as publicações cadastradas.

Para realizar a importação de uma determinada foto para uma publicação, o nome do arquivo desta imagem deve ser o mesmo referente ao código da publicação. Por exemplo, se deseja importar a foto para um livro de código igual a "2", é necessário que o nome do arquivo a ser importado seja "2.jpg" ou "2.jpeg".

Se desejar substituir foto de uma publicação existente, habilite o parâmetro "Substituir Foto Existente" na etapa do processo de selecionar fotos.
