## **02. VISÃO GERAL**

Ativar oparâmetro **'Ativar Integração com Swile'** e preencher os campos  **Id. Work Group**, **Usuário**, **Senha** e **URL Base.** Veja um exemplo de utilização em**[Integração Benefício com Swile](https://tdn.totvs.com/pages/viewpage.action?pageId=737546308)**.

## **03.** **Tela Integração API Swile**

**a. Principais Campos e Parâmetros**

|  |  |
| --- | --- |
| **Campo** | **Descrição** |
| Ativar Integração com Swile | Marcar para ativar a Integração com Swile e disponibilizar os campos para parametrização |
| Id Work Group | Informar o id do grupo de trabalho informado pela Swile |
| Usuário | Informar o 'usuário' cadastrado para a integração com o Portal da Swile |
| Senha | Infromar a 'senha' cadastrado para a integração com o Portal da Swile |
| URL Base | Informar a URL Base informado pela Swile |

Atenção

Os dados da integração são fornecidas pelo parceiro Swile, para seus clientes
