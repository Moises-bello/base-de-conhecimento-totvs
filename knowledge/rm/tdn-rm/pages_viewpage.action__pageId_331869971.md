# Geração de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Geração de lançamento |
| **Situação/Requisito:** | O processo de geração de lançamento (Financeiro / Contábil opção Financeiro) depois de informar qual o ano letivo, a parcela inicial e parcela final na tela seguinte onde selecionamos utilizamos a opção de selecionar sentença SQL, porém o sistema está mostrando todas as consultas SQL e deveria mostrar apenas consultas do Educacional. |
| **Solução/Implementação:** | Ajuste para que o filtro do lookup retorne apensa consultas SQL cadastradas para o Educacional, pois em determinado cliente ele filtrava todas as consultas e sistema demorava. |
