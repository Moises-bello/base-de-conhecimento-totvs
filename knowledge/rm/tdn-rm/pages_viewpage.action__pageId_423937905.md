Esse processo é utilizado para efetivar os dados informados no apontamento via Código de Barras por Atividade.   
 Para finalizar uma atividade deve ser marcada a opção "Termina?".  
****Importante**:**Para se finalizar o apontamento de uma atividade através da Conciliação de Apontamento por Atividade deve-se obrigatoriamente marcar a opção "Termina". Caso essa opção esteja desmarcada, a atividade ficará com status "Parcialmente Concluída".
