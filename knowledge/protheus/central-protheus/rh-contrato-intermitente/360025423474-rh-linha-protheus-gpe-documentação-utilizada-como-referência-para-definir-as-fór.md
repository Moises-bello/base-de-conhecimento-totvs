**Dúvida**Qual documentação foi utilizada como referência para definir as fórmulas de cálculo (DSR, 13º, férias, etc) para os funcionários com contrato intermitente tendo como embasamento a legislação da Reforma Trabalhista?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**A Reforma Trabalhista, no que se refere ao contrato intermitente, foi analisada pela Consultoria Jurídica da TOTVS. Utilizando este parecer, foram desenvolvidas as fórmulas de cálculo para funcionários que se encaixam nesta forma de contrato.
