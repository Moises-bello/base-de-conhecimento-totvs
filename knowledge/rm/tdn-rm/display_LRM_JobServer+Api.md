Através desta Api é possível monitorar a disponibilidade e realizar operações de Start/Stop de um conjunto de JobServers. Para acessa-la é necessário conhecer o **IP** e **Porta** http/https de um servidor de aplicação do ambiente que se deseja monitorar. Onde o endereço base desta Api é: http://host:port/RMSJobServerApi
