# Extrato de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | Extrato de Caixa |
| **Situação/Requisito:** | No módulo de caixa se tentar baixar um lançamento com cheque emitido na visão, o sistema emite mensagem confusa.  A mensagem exibida é: Lançamento (XXXXX) com cheque emitido para realizar o pagamento, deve-se fazer pela tela de visão de lançamentos. |
| **Solução/Implementação:** | *Melhoria na mensagem, passando a exibir a seguinte mensagem:*  O lançamento xxxx possui cheque emitido através da Visão Geral de Lançamentos, sendo assim toda e qualquer operação referente a esse lançamento deverá ser realizada na Visão Geral de Lançamentos. |
