## **01. VISÃO GERAL**

Processo a ser executado para transferência de dados da produção para o histórico da produção. Nesse   processo poderá ser feita a transição entre as tabelas PPRODUCAOAGRARIA x PHSTPRODUCAOAGRARIA ou PHSTPRODUCAOAGRARIA x PPRODUCAOAGRARIA respeitando a parametrização e o período selecionado.

## **02. EXEMPLO DE UTILIZAÇÃO**

Transferência da produção da folha agrária para o histórico de produção agrária referente aos dias 01/05/2021 a 05/05/2021.

Realizada com sucesso

## **03. TELA: **Transferência entre Produção x Histórico****

****Principais Campos e Parâmetros****

| Campo | Descrição |
| --- | --- |
| Quebra de Seção | Selecione a quebra |
| Seleção de funcionários | Selecione os funcionários |
| Data para transferência | Selecione o período para processamento da transferência |
| Da Produção para o Histórico | Selecione para transferir registros da tabela PPRODUCAOAGRARIA para a tabela PHSTPRODUCAOAGRARIA |
| Do Histórico para a Produção | Selecione para transferir registros da tabela PHSTPRODUCAOAGRARIA para a tabela PPRODUCAOAGRARIA |
| Forma de exibição do log | Simples / Detalhado |
| Registros Repetidos | Selecione todos os registros que serão atualizados no momento da execução do processo |

## **04. TABELAS UTILIZADAS**

* PPRODUCAOAGRARIA
* PHSTPRODUCAOAGRARIA
