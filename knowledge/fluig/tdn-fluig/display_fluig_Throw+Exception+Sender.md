Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**. 

A finalidade desse componente é permitir ao usuário lançar uma exceção num diagrama.

| Campo | Descrição |
| --- | --- |
| Name | Inserir uma identificação para a configuração do componente. |
| Description | Informar a mensagem de erro a ser apresentada. É possível criar uma mensagem dinâmica, inserindo valores da mensagem por meio de um ${xpath}. Exemplo: Usuário do tipo: ${/User/type} não encontrado. |
