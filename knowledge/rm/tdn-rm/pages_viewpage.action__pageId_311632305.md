# Objetivo:

---

       O objetivo deste documento é trazer uma visão de como funciona a tela de Cadastro de Conexões.

# Introdução:

---

       Será estabelecida uma conexão entre o relatório e o [Provedor de Dados](http://tdn.totvs.com/x/lyGTEg). Essa conexão será utilizada ao adicionar uma [Fonte de Dados](http://tdn.totvs.com/x/uCGTEg), onde deve-se informar de qual conexão os dados para o relatório serão buscados.

# Como criar:

---

       Para criar uma nova conexão, basta clicar em "+ Novo" e informar os campos abaixo:

***Nome:***Informe o nome da conexão, deve ser um nome único e é por ele que a Conexão será identificada.

***Provedor de dados:***Informe em qual [Provedor de Dados](http://tdn.totvs.com/x/lyGTEg) será estabelecida a conexão.
