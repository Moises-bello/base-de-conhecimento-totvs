**Dúvida**Para que serve o parâmetro **MV\_AGRO021**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O parâmetro **Informar o Código do Produto que será utilizado no pedido de compra para comissão -  MV\_AGRO021** é do tipo caractere e está localizado na rotina de **Comissão Calculada - OGC110**. Permite informar o **código do produto** que será utilizado para gerar os pedidos de compra para pagamento das comissões. Caso não exista, será um impeditivo para geração dos pedidos de compra para comissão.
