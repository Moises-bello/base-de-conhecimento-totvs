# GERAÇÃO DE MOVIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de Movimentos em regime de competência |
| **Situação/Requisito:** | Ao gerar movimento em regime de competência, o sistema criava um movimento para cada competência mensal e em caso de existir mais de um serviço, o sistema criava um item de movimento para cada serviço. Este comportamento foi identificado não conformidade com a legislação, que exige que seja criado um movimento para cada serviço. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimento em regime de competência, permitindo ao sistema, gerar um movimento para cada serviço existente no contrato, que seja passível ser utilizado na geração de movimentos. |
