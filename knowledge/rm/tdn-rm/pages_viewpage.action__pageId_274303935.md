# Geração de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Geração de lançamento |
| **Situação/Requisito:** | Ao gerar o movimento (regime de caixa) o sistema apresenta uma mensagem de não conformidade informando que o movimento já foi remetido a prefeitura para boletos que ainda não tiveram movimentos gerados. |
| **Solução/Implementação:** | Melhoria na geração de lançamento para que não sejam geradas informações na tabela TMOVLAN quando já existir movimento (regime de caixa) gerado para o contrato utilizando o recurso de cálculo do valor líquido do movimento por fórmula. |
