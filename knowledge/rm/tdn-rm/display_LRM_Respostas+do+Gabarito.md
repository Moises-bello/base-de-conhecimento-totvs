Para cada questão do gabarito deve ser cadastrada uma resposta correspondente.

**Para efetuar o cadastro das repostas é necessário preencher os campos:**

* Tipo de prova
* Nº Questão
* Resposta

Cada gabarito pode ter até 5 provas: provas A, B, C, D e E. Estes tipos de provas são internos do sistema e não podem ser editados/incluídos/excluídos. Para cada tipo de prova, o usuário deverá informar o número da questão e a resposta correta.   
 **Exemplo:** Prova A, Questão 1, resposta A Prova A, Questão 2, resposta D Prova B, Questão 1, resposta C   
 Só é possível ter uma resposta para cada TipoProva/Questão. Caso seja necessário indicar que determinada questão foi anulada, ou seja, seu ponto será atribuído a todos os alunos, informe \* (asterisco) como resposta.  
 **Exemplo:** Prova C, Questão 3, resposta A Prova C, Questão 4, resposta \*
