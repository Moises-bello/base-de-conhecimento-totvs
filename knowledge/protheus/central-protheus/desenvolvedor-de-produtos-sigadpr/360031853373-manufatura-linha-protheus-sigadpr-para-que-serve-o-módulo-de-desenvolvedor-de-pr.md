**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)** Tempo aproximado para leitura: **00:01:30 min****Dúvida**Para que serve o módulo de **SIGADRP - Desenvolvedor de Produtos**?  
  
 **Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Desenvolvedor de Produto (SIGADPR) - A partir da versão 11.8  
  
**Solução**O módulo **Desenvolvedor de Produtos** permite gerenciar a criação de novos produtos que futuramente são fabricados e comercializados pela empresa.  
  
É um ambiente de desenvolvimento que possui funções semelhantes ao módulo **SIGAPCP - Planejamento e Controle da Produção**. Porém, utiliza uma base de dados à parte, não afetando ou poluindo a base original, onde estão cadastradas todas as informações de engenharia do produto.  
  
As principais funcionalidades desse módulo são:

* Desenvolver novas versões de um produto, controlando-as de forma separada;
* Armazenar e consultar o histórico das versões desenvolvidas;
* Avaliar a melhor versão de um produto desenvolvido antes da liberação do item para a engenharia;
* Gerar ordens de produção para protótipos;
* Efetuar reservas de materiais para as ordens de produção para protótipos;
* Avaliar o custo de fabricação de cada versão desenvolvida;
* Controlar a aprovação da versão desenvolvida de um produto, tornando o produto aprovado um item normal da engenharia.
