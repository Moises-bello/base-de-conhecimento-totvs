Dúvida**Estou utilizando o comando FOR XML *PATH(''), TYPE* em um BeginSQL e está apresentando erro, existe uma forma de executar o comando?  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**A sintaxe SQL *for XML PATH(''), TYPE* não é suportada pelo Protheus, será necessário adequar a query de outra forma
