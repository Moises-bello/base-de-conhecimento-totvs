**Dúvida**Como é gerado a quantidade de meses de banco de horas na manutenção RAIS?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal –  Todas as versões  
  
**Solução**A quantidade de meses de banco de horas na Manutenção RAIS é apresentado a partir de uma nova verba incluída no módulo SIGAPON - Ponto Eletrônico, apenas para representar a quantidade de meses.   
  
Possuímos documentação da versão 11 mostrando este processo, veja o link abaixo:  
<http://tdn.totvs.com/display/PROT/RAIS+-+GPE008RAIS_Fechamento_do_Banco_de_Horas_para_RAIS>  
  
Na ausência do módulo SIGAPON - Ponto Eletrônico, essa verba que mostra a quantidade de meses de banco de horas deve ser incluída via manutenção de acumulado. Abaixo, instruções para essa inclusão:  
<https://centraldeatendimento.totvs.com/hc/pt-br/articles/360019957332>
