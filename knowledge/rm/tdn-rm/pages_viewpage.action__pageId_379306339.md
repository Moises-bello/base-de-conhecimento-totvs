# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Gestão Financeira. |
| **Função:** | Baixa |
| **Situação/Requisito:** | Após baixar parcialmente um lançamento que contém rateio por departamento, cada item de baixa tem seu rateio com o valor baixado, e ao realizar a alteração na contabilização de um dos itens de baixa inserindo novas partidas manualmente, o rateio de departamento do outro item de baixa está sendo excluído pelo sistema. |
| **Solução/Implementação:** | Foi realizado o ajuste na exclusão do Rateio por departamento quando existir mais de um item de baixa por lançamento. |
