![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30943243744535) Tempo aproximado para leitura: **00h02 min****Dúvida**Mensagem: PG020FINALIZED - Não é possível excluir a cotação "**XXXXXX**", pois ela está finalizada, no NFC

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30943927727127)

**Ambiente**

Protheus – Compras – A partir da versão 12

**Solução**

Não é possível excluir uma cotação que já foi finalizada.

Para isso, será necessário primeiro excluir o pedido que foi gerado a partir dessa cotação e, somente após essa exclusão, você conseguirá excluir a cotação normalmente. Antes de excluir o Pedido de Compra, certifique-se de que o parâmetro MV\_PCEXCOT = 2. Para maiores informações, verifique documentação abaixo.
