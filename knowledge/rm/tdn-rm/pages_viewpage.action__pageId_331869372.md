# Alteração do Sped Fiscal para 2018 - Alterações na NF-e

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Alteração do Sped Fiscal para 2018 - Alterações na NF-e |
| **Situação/Requisito:** | Será necessário a criação de dois campos para considerar as duas novas opções de Natureza de Exportação que foram criadas para as alterações do SPED Fiscal:  5 - UnicaDireta (Declaração Única de Exportação Direta) e  6 - UnicaIndireta (Declaração Única de Exportação Indireta) |
| **Solução/Implementação:** | Foram inseridas duas novas opções de Natureza de Exportação para a NF-e, criadas para as alterações do SPED Fiscal para 2018, são elas:  5 - UnicaDireta (Declaração Única de Exportação Direta) e  6 - UnicaIndireta (Declaração Única de Exportação Indireta) |
