# ASSUNTO DO E-MAIL NO AGENDAMENTO/ENVIO DE MENSAGENS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Agendamento/envio de mensagens |
| **Situação/Requisito:** | Ao tentarmos enviar um e-mail em 'Atividades Acadêmicas > Central de Comunicações > Agendamento/Envio de Mensagens' selecionando o tipo ''Texto Livre'', não é possível colocarmos um Assunto no e-mail enviado. Com isso, todos emails criados saem como (Sem Assunto), porém, não existe campo para preenchimento. |
| **Solução/Implementação:** | Foi incluído o campo ASSUNTO no "Agendamento/envio de mensagens" do Educacional. |
