# CAMPOS OBRIGATÓRIOS NO CADASTRO DA RESCISÃO E FUNCIONÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Campos obrigatórios* |
| **Situação/Requisito:** | Após informar alguns campos obrigatórios na tela de rescisão, ao tentar cadastrar ou alterar o cadastro de algum funcionario, é apresentado mensagem que os campos que estão como obrigatórios na tela de rescisão tambémm são obrigatórios na tela de funcionário. |
| **Solução/Implementação:** | Permitir cadastrar/alterar o funcionário, não obrigando o preenchimento dos campos obrigatórios que existe na tela de rescisão. |
| **Chamados relacionados:** | TUCIYC |
