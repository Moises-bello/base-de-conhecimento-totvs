PainelVisão Geral

Na etapa "Dados do Convênio" será possível cadastrar, remover e selecionar o convênio desejado para utilização do agendamento.

Cadastrar Convênio

Logar no Portal do Paciente, abrir a página de "Agenda", concluir a etapa "Dados" e clicar no botão "Próximo".

Ao entrar na etapa "Convênio", o sistema irá carregar automaticamente os convênios já utilizados pelo usuário no Portal do Paciente em agendamentos anteriores.

Caso seja necessário, o usuário poderá cadastrar um novo convênio e/ou remover um convênio pré-existente.

Se o convênio desejado não for apresentado ao abir a etapa, o usuário deve clicar no botão "Adicionar convênio". Este processo abrirá uma nova

tela para que o usuário informe os dados do convênio para cadastro. Após informar os dados mínimos para cadastro (Convênio e Plano) e clicar no botão "Adicionar",

o sistema irá persistir os dados no perfil do usuário logado e irá recarregar a lista de convênios disponíveis.

Se o usuário desejar remover da lista de convênios, um convênio não mais utilizado, é necessário clicar no botão "Lixeira" disponibilizado juntamente com os dados do convênio.

Este processo removerá o convênio do perfil do usuário logado e irá recarregar a lista de convênios disponíveis.

Se todos os dados convênio estiverem corretos, selecionar o convênio desejado para o agendamento e clicar no botão "Próximo".

Remover Convênio

## **REMOVER CONVÊNIO**

01. Ao abrir a etapa "Qual é o convênio", o sistema irá carregar uma lista de convênios vinculados ao perfil do usuário logado.

02. Clicar no botão "Lixeira", localizado juntamente aos dados do convênio, para remover um novo convênio vinculado ao perfil.

03. O sistem irá questionar se o usuário realmente deseja remover o convênio. Confirmando o processo, o sistema irá remover o convênio do perfil do usuário.

04. O convênio removido não será mais apresentado na lista de convênios vinculados ao perfil do usuário logado.

Selecionar Convênio

## **SELECIONAR CONVÊNIO**

01. Ao abrir a etapa "Qual é o convênio", o sistema irá carregar uma lista de convênios vinculados ao perfil do usuário logado.

02. Após selecionar o convênio desejado, o botão "Próximo" ficar habilitado para seguir com o processo de agendamento.

03. Ao clicar no botão "Próximo", o sistema irá validar as informações do convênio selecionado e, o processo será interrompido e o usuário

notificado caso a algum dado esteja incorreto.

04. A etapa "Dados do Procedimento" é carregada.
