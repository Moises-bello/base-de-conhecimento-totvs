**Frontend**

No *frontend*, está sendo usado estas linguagens e recursos:

* [Angular JS v1.7](https://code.angularjs.org/1.7.9/docs/guide)
* CSS
* HTML
* [NodeJS](https://nodejs.org/pt-br/download/releases/)
* SASS

**Backend**

* [PHP 7.3](https://www.php.net/)
* [Micro Framework Slim v2](https://www.slimframework.com/docs/v2/)
* [RedBean ORM v3.5 (Legado)](https://redbeanphp.com/manual3_0/)
* [Eloquent ORM v5](https://laravel.com/docs/5.8/eloquent)
* [Codeception Tests](https://codeception.com/)

**Outros**

* API padrão *RESTful*(JSON)
* SPA (*Single Page Application*)
* [Gerenciador de dependências Yarn (frontend)](https://classic.yarnpkg.com/lang/en/)
* [Gerenciador de dependências Composer (backend)](https://getcomposer.org/)
