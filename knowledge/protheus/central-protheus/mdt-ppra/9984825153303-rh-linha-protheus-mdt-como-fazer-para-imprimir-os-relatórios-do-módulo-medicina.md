![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19994265228183) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como fazer para imprimir os relatórios do módulo Medicina e Segurança do Trabalho em PDF?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho – Todas as versões  
  
**Solução**Abaixo segue exemplos de formas que podem ser feito a impressão.**Impressão do relatório em PDF quando o modelo de relatório é Word:**1. Selecionar a opção Word:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984060920215)  
  
2. Informar os dados referente aos parâmetros de impressão:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984130214551)  
  
3. No Word, selecionar as opções Arquivo/Imprimir e no local da Impressora, selecionar a opção PDF:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984311642903)  
  
**Impressão do relatório em PDF quando o modelo de relatório é Padrão/Gráfico:**1. Selecionar a opção Padrão ou Gráfico:

![mceclip10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984819449751)  
  
2. Na tela de **Parâmetros**, selecionar no **Tipo Impressão** a opção **Via Spool**:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984376961303)  
  
3. Nesse momento é solicitado para que seja salvo o arquivo PDF:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984431726615)

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984425162647)  
  
**Impressão do relatório em PDF quando não há seleção de tipos de relatórios:**1. Na tela de **Parâmetros**, selecionar no **Tipo Impressão** a opção **Via Spool**:

![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984478730135)  
  
2. Nesse momento é solicitado para que seja salvo o arquivo PDF:

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984534392983)

![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9984732589975)  
  
**Importante:** É necessário instalar uma extensão PDF para utilizar este recurso.
