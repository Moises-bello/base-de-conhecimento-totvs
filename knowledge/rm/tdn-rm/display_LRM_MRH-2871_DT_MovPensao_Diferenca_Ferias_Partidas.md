# MOVIMENTAÇÃO DE PENSÃO NA DIFERENÇA DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projeto* |

| **Situação/Requisito:** | *No cálculo da diferença de férias partidas, quando o aumento salarial é somente no segundo mês, o valor da diferença de pensão alimentícia de férias está sendo gravado com o valor integral na movimentação do dependente.* |
| **Solução/Implementação:** | *Ajuste na gravação da movimentação de pensão do dependente para proporcionalizar o valor de diferença de pensão alimentícia pelos dias de férias do segundo mês.* |
