## **01. VISÃO GERAL**

Este processo consiste em agrupar todos os repasses, créditos, débitos e descontos relacionados a um prestador.

### ***Somente os registros com o código igual a -1 é que são passíveis de gerar a folha. Os demais registro, são as folhas já geradas para o prestador selecionado.***

## **02. EXEMPLO DE UTILIZAÇÃO**

Para gerar a folha de pagamento, iremos até **Faturamento> Gestão de Repasse> Folha de Pagamento de Prestadores**selecionaremos o prestador desejado, informando um período e liberando um repasse para pagamento. Na tela **Liberado para Pagamento> Processos> Gera Folha de pagamento.**

Informe a data de referência

Filtre  o período de pagamento para exibição na aba de pagamento dos itens registros que farão parte da folha
