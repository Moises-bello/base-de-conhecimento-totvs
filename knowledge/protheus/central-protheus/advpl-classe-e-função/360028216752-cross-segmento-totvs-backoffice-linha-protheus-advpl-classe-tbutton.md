**Dúvida**Existe algum método / propriedade na Classe TButton() para modificar a cor do botão?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - AdvPL - Todas as versões  
  
**Solução**Método existe somente para alterar a cor do texto do botão SetColor() ex. oTButton1:SetColor(CLR\_BLUE), mas via CSS consegue alterar a cor do botão
