![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16666111287959) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**O que verificar quando não é calculado salário família para funcionário de férias?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Acesse **Atualizações -> Definições Cálculo -> Tipos de ausência**, verifique como consta a configuração do campo **Pg Sal Fam** do tipo de ausência 001 - Férias:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414179151383)

A configuração deste campo que irá definir como será pago salário família para funcionário de férias.
