**Dúvida**

O que devo encaminhar para suporte quando o sistema gerar error Log ?  
  
**Ambiente**  
Cross Segmento - Backoffice Linha Protheus – Ativo fixo  – Todas as versões  
  
  
**Solução**

Para uma analise mais detalha do problema envie do erro.log conforme orientações abaixo:

- Entrar no servidor, pasta System e apagar o arquivo ERROR.LOG

- Gerar novamente o erro no sistema

- Voltar para a pasta system e ZIPAR o arquivo ERROR.LOG

- Salve o mesmo com o nome/número do chamado

- Salve no Bloco de notas

- Envie este arquivo através do portal do cliente /Ticket

- Dessa forma possível analisar o erro apresentado
