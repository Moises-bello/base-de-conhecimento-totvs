# TTPSRO\_DT\_Cotacao\_Online\_Botao\_Fechar

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Construção e projetos.* |
| **Módulo:** | *Gestão de estoque compras e faturamento.* |
| **Função:** | *Botão fechar da tela principal de cotação online.* |
| **Situação/Requisito:** | *Botão "Fechar" da tela principal de cotação online não estava realizando nenhuma ação em alguns navegadores.* |
| **Solução/Implementação:** | *Botão de fechar padrão foi substituído por um customizado, assim caso o navegador possua alguma política de segurança que impede que janelas abertas pelo usuário sejam fechadas de outra forma que não pelo próprio botão "X" do navegador, o botão fechar executa um logout do sistema.* |
