# Lançamento de segunda moeda na baixa com perda financeira

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa com perda financeira |
| **Situação/Requisito:** | Na baixa com perda financeira não considerava a moeda da baixa quando a conta/caixa não é informada |
| **Solução/Implementação:** | Otimizado o processo de baixa com perda financeira na geração do item de baixa considerar a moeda da baixa conforme a regra:   * Considerar a moeda do lançamento se a conta/caixa não for informada. Se a conta/caixa for informada será a moeda da mesma |
