Application Server - 20.3.2.12

# Correções

Alto consumo de CPU em conexões RPC utilizando versão debug do Application Server

Incidente: Aumento no consumo de CPU em conexões RPC quando do uso da versão debug do Application Server Linux.

Correção:  Alteração no processo de desconexão RPC para evitar aumento no consumo de CPU no Application Server Linux usando build DEBUG.

  

Referente ao chamado: DTAPPSRV-8085
