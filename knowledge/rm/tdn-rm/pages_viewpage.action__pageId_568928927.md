## **02. SITUAÇÃO/REQUISITO**

Possibilitar que a cópia de cadastros entre coligadas seja realizada com origem de uma base de Cloud.

## **03. SOLUÇÃO**

Foi disponibilizado a opção de realizar a cópia entre coligadas a partir de uma base de origem Cloud.

Os cadastros contemplados com esta implementação são:

* Cópia de Parâmetros;
* Cópia de Tributo;
* Cópia de Exercício Fiscal;
* Cópia de Códigos de Ajuste;
* Cópia de Regras de IPI;
* Cópia de Regras de ICMS;
* Cópia de Naturezas;
* Cópia de INSS/PJ.
