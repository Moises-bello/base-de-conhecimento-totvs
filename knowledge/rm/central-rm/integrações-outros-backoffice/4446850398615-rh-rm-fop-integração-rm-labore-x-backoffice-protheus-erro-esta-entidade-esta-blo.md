![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:24 min****Ocorrência**Ao realizar um cadastro de um novo funcionário no sistema RM é apresentado a mensagem de erro Mensagem retornada pelo 'App: [Protheus] - [RM] : Esta entidade esta bloqueada.CTT .  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões**Causa**  
Esse incidente ocorre quando ao tentar cadastrar um novo funcionário no sistema RM é apresentado a mensagem de erro " **Entidade está bloqueada.CTT** "

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4446788482967/mceclip0.png)  
  
**Solução**Verifique se o centro de custo que está sendo enviado pelo Funcionário está marcado como **Bloqueado** no sistema Protheus.  
  
![](https://totvssuporte.zendesk.com/attachments/token/0FTS5PS7pTpp9SkRkkI2B9rxg/?name=inline-1872361285.png)

Após acessar o Cadastro de Centro de Custo e alterar para não bloqueado, salve e realize o cadastro no RM novamente.
