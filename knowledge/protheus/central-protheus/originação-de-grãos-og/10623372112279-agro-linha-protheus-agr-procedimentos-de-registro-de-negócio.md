**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20625731486743)** Tempo aproximado para leitura:**00:00:45 min****Dúvida**Quais são os Procedimentos para Registros de Negócios das commodities agrícolas.  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos para incluir um novo negócio:

**1.** Selecione **Incluir** na tela principal;

**2.** Verifique, o Sistema apresenta a tela para facilitar a inclusão;

**3.** Preencha os dados solicitados;

**4.** Selecione *Ok* para utilizar a inclusão facilitada ou cancela para descartar;

**5.** Preencha os dados conforme orientação do *help* de campo;

**6.** Veja os principais campos no tópico **Principais Campos;**

**7.** Confira os dados e confirme a inclusão;

**8.** Veja os dois *status* ficarão como pendentes e na **cor vermelha**.

Para confirmar um novo negócio:

Será necessário receber **Aprovação do** **Cliente** e **Aprovação do Negócio** e assim gerar contrato com *status* previsto e a situação do negócio mudar para aprovado **cor verde**.
