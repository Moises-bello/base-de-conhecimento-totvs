# Objetivo:

---

       O objetivo deste documento apresentar a geração do evento S-2416 – Alteração do Cadastro de Benefícios – Entes Públicos.

Mais informações sobre esse evento acesse: 

---

13-1Edição do benefícioEdição do benefício

Acesse o menu RH | Folha de Pagamento | Administração de Pessoal | Funcionários | Anexos | Folha de Pagamento | Dados do Benefício

Este cadastro só será habilitado caso funcionário esteja com o campo  "Beneficiário Entes Públicos" marcado ou tipo de funcionário seja W-Beneficiário.

Clique em editar e edite os dados do benefício.

Após Salvar os dados será gerado o gatilho com evento S-2416.

3-2SuspensãoSuspensão

Para o cadastro de suspensão do benefício, acesse o menu RH | Folha de Pagamento | Administração de Pessoal | Funcionários | Anexos | Folha de Pagamento | Dados do Benefício

Este cadastro só será habilitado caso funcionário esteja com o campo  "Beneficiário Entes Públicos" marcado ou tipo de funcionário seja W-Beneficiário.

Clique em editar e edite os dados do benefício.

Marque o campo "Supensão do benefício", sistema abrirá uma nova tela para cadastro dos dados da suspensão.

Após Salvar os dados será gerado o gatilho com evento S-2416, com os dados da suspensão.

3-3Retorno da suspensãoRetorno da suspensão

Para o cadastro de suspensão do benefício, acesse o menu RH | Folha de Pagamento | Administração de Pessoal | Funcionários | Anexos | Folha de Pagamento | Dados do Benefício

Este cadastro só será habilitado caso funcionário esteja com o campo  "Beneficiário Entes Públicos" marcado ou tipo de funcionário seja W-Beneficiário.

Clique em editar e edite os dados do benefício.

Desmarque o campo "Supensão do benefício", sistema abrirá uma nova tela para cadastro dos dados do retorno da suspensão.

Após Salvar os dados será gerado o gatilho com evento S-2416, com os dados do retorno da suspensão.
