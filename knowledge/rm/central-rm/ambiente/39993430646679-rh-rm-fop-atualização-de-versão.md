**Dúvida**  
Como realizar a atualização de versão?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**

**Clientes Cloud**  
Para atualizar versões em ambiente em cloud, siga os seguintes passos:  
  
1 - Para clientes que possuem ambientes em Cloud, é necessário abrir um ticket para a equipe de Cloud realizar o processo de atualização de versão, pois esse ticket foi criado de maneira incorreta para a equipe de Folha de Pagamento.

2 - A segunda alternativa seria o próprio cliente fazer a atualização por meio do TCLOUD, conforme as orientações abaixo;  
[CLOUD - RM - Atualizar release RM via TCLOUD](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4417778065431-CLOUD-RM-Atualizar-release-RM-via-TCLOUD)  
  
**Instalação local**  
  
1 - Para instalação local, é possível baixar a versão e o patch por meio do Portal de download.  
[Portal de download](https://suporte.totvs.com/portal/p/10098/customer-portal-dashboard/services/downloads)

2 - Após realizar o download siga as instruções conforme a documentação abaixo;  
[Framework - Linha RM - Frame - Como realizar atualização de patches da Biblioteca](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360004983291-Framework-Linha-RM-Frame-Como-realizar-atualiza%C3%A7%C3%A3o-de-patches-da-Biblioteca)

3 - Para atualizações de relese segue as orientações;  
[Framework - Linha RM - Frame - Como atualizar o release da biblioteca RM](https://centraldeatendimento.totvs.com/hc/pt-br/articles/115016056328-Framework-Linha-RM-Frame-Como-atualizar-o-release-da-biblioteca-RM)  
  
4 - Caso seja uma versão específica que não esteja mais disponível na Central de Downloads, será necessário solicitar o envio dessa versão realizando a abertura de um ticket para a equipe de (folha de pagamento RM rotinas ou RM Framework).
