No anexo Locais de Instalação são cadastrados todos os locais de instalação do cliente/fornecedor onde são instalados os objetos de manutenção cadastrados no sistema TOTVS Manutenção.   
É possível verificar onde um objeto de manutenção está instalado acessando o cadastro de objetos de manutenção no sistema TOTVS Manutenção.
