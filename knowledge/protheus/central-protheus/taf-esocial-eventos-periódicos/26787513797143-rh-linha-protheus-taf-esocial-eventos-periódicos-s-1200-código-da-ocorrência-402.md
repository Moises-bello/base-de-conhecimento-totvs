![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26787497030423) Tempo aproximado para leitura: **00:01:30 min****Ocorrência**No módulo do TAF, ao tentar realizar a transmissão do evento S-1200 (Folha de Pagamento) é apresentada a seguinte rejeição:  
  
**Sequência: 000001 - Tipo: Erro - Código da Ocorrência: 402**  
 **Descrição: 'IDxxx' is already used as an ID.**  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF - Todas as versões.  
  
**Causa**Essa inconsistência ocorre, pois o ID apresentado já está sendo usado.  
  
**Solução**Para solucionar essa ocorrência, realize os seguintes passos:  
**1.** Realize a exclusão do evento com rejeição no TAF;  
  
**2.** Integre novamente o evento a partir de seu ERP para que seja gerado um novo ID;  
  
**3.** Tente transmitir novamente e verifique se o erro é solucionado.
