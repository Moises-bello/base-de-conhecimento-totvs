**Dúvida**Como corrigir Help AVG0000164 ?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360086690174/mceclip0.png)  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
**Solução**Verifique o cadastro da despesa a mesma não pode ser base de Imposto e base de ICMS.  
Help("",1,"AVG0000164"  "Despesa não pode ser Base de I.C.M.S. quando já é Base de Impostos"
