Como definir quais os tipos de abono que serão apresentados na rotina de abono no Meu RH?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - MEU RH - todas as versões  
  
**Solução**1. Caso não possua o campo citado na **tabela SP6**, seguir o passo a passo do artigo abaixo para criação do campo: **[Como definir os tipos de abono no MEU RH](https://tdn.totvs.com/display/NPR/DRHMEURH-193+DT+Solicitar+abono+com+anexo)**  
  
2. Acessar no módulo **SIGAPON** o menu **> Atualizações > Cadastro do ponto > Motivos Abono/Justificativa.**  
No abono, preencher com "**SIM**" ou "**NÃO**" no campo **Perm. Meu RH** para definir se esse tipo de abono será ou não apresentando no portal.  
![kSIe9j29GW.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4414501887511)  
  
Para o App Meu RH utilizar este tipo de Abono cadastrado, o campo Pré-Abona, obrigatoriamente, precisará estar como SIM.  
  
3. Na rotina de abono no **MEU RH**, será apresentado somente os tipos de abono que foram definidos como "**SIM**" no cadastro de motivo de abono no **SIGAPON**.  
![cjXpw22jnG.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4414502035735)
