**Exclusão de Ocorrências Canceladas**   
As ocorrências que são canceladas, ou seja, que estão com o status como Cancelado, podem ser excluídas da base de dados. De acordo com a seleção realizada através do filtro, o sistema exclui as ocorrências canceladas da base de dados. As ocorrências não são mais exibidas na Visão de Atendimentos e não são mais visualizadas no sistema após a exclusão.   
Essa tela permite que as ocorrências canceladas sejam selecionadas através do filtro e excluídas da base de dados.   
Os campos abaixo servem como critérios para que o sistema realize o filtro para a seleção das ocorrências canceladas. Os dados selecionados nos campos podem ser filtrados individualmente ou em conjunto.  
Veja a descrição dos campos presentes nesta tela e o procedimento correto para preenchê-los:  
Coligada  
Selecione nesse campo o nome da coligada onde a(s) ocorrência(s) se encontra.   
Localidade  
Selecione nesse campo o nome da localidade onde a(s) ocorrência(s) se encontra.  
Filtrar pelo código da ocorrência  
Selecione essa opção caso deseja esolher a ocorrência que vai ser excluída pelo código da mesma. Basta selecionar a opção e digitar no campo abaixo o número da ocorrência em questão.   
Selecionando essa opção o sistema desabilita os campos abaixo.   
Optando por essa forma de filtro a eclusão deve ser feita apenas de uma ocorrência de cada vez. O campo não permite que seja digitado mais de um código de atendimento.   
Produto  
Selecione nesse campo o nome do produto cadastrado na ocorrência cancelada que vai ser excluída da base.   
Classificação  
Selecione nesse campo a classificação da ocorrência cancelada que vai ser excluída da base.   
Período de data de abertura  
Para que as ocorrências sejam selecionadas pela data de abertura, selecione a data inicial e/ou final de abertura do atendimento cancelado que deseja excluir.   
Clicando no botão OK, o sistema executa a rotina que exclui da base a(s) ocorrência(s) selecionada através do filtro e exibe uma tela com mensagem informando se a exclusão foi realizada com sucesso ou se o filtro não retornou nenhum registro (ocorrência) para a exclusão.  
**Atenção**  
Se nenhum dos campos presentes nesta tela for preenchido, todas as ocorrências com status cancelado serão excluídas após a confirmação de exclusão.
