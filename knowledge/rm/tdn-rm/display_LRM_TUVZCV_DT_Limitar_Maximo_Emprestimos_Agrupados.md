# MOVIMENTAÇÕES - LIMITE DE EMPRÉSTIMOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Bibliotecária* |
| **Função:** | *Moimentações - Limite de empréstimos* |
| **Situação/Requisito:** | *O parâmetro que define o limite de empréstimos não está claro, na tela de parâmetros do sistema (Movimentações -> Empréstimos 2/2), o parâmetro "Ao limitar o nº máximo de empréstimos por tipo de usuário, não considerar separadamente os empréstimos de consulta interna e externa" não está de acordo com sua real funcionalidade.* |
| **Solução/Implementação:** | *Sendo assim foi feito o ajuste no texto do parâmetro para que fique claro qual seu real objetivo, que é considerar o total de exemplares que um tipo de usuário poderá tomar emprestado como um todo, sem distinção entre exemplares normais, de circulação interna e de circulação externa, utilizando para tal o campo "nº máximo de empréstimos normais".* |
