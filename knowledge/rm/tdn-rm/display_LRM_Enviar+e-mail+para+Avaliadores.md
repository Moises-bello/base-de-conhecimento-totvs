**Enviar e-mail para Avaliadores**

Utilize essa opção para enviar e-mail para os Avaliadores com o(s) link(s) de execução das avaliações de desempenho.

**Observação**

Quando executar a avaliação pelo link enviado por email, lembrar de verificar, antes de executar este processo, qual a URL de acesso ao Portal RM está cadastrada no menu Opções| Parâmetros| Globais.
