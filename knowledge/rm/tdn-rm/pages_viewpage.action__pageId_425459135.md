Os parâmetros do sistema, são responsáveis por configurar e determinar como algumas das funcionalidades e processos do sistema ira com se comportar. Estas configurações podem influenciar tanto em nível de interface quanto em regras de negócio. Através da configuração de um parâmetro, por exemplo, uma tela pode ter alguns campos ocultos ou até mesmo o fluxo de uma regra de negócio direcionada para ser executada de outra forma.

Os Parâmetros estão divididos em categorias:  
    
  
O objetivo destes parâmetros é definir as características do funcionamento da secretária   
acadêmica da instituição. São exemplos de tipos de parâmetros: Período Letivo, Notas e Faltas,   
Relatórios, Alocação de sala...   
   
  
Estes parâmetros são necessários para o funcionamento correto dos processos de Tesouraria   
do sistema. O objetivo desta etapa é definir o comportamento do sistema em relação aos assuntos   
financeiros.

[Matrícula](http://tdn.totvs.com/pages/viewpage.action?pageId=425459701)O objetivo destes parâmetros é definir como o sistema ira se comportar durante o processo de   
matrículas. Engloba parâmetros que definem o comportamento durante o processo de matrícula,   
sugestões de disciplinas e formulas visuais.

Os parâmetros de portal definem o comportamento das funcionalidades e processo executados   
no RM Portal: Matrícula, relatórios, financeiro, dados do aluno, plano de aula, ocorrência...   
   
  
Nesta sessão são encontrados os parâmetros que definem como o sistema ira se comportar quando   
integrado com outros produtos: Folha de Pagamento, Ponto, Financeiro, CRM, Biblios, Protheus,   
Fiscal e Scientia.   
   
  
Nesta etapa são parametrizados os dados para utilização do módulo de Estágio.   
   
[TCC](http://tdn.totvs.com/x/u3OQGg)  
Nesta etapa são parametrizados os dados para utilização do módulo de TCC.

[Agenda Infantil](https://tdn.totvs.com/x/N8ukOQ)
