# TRANSFERÊNCIA INTERNA ENTRE FILIAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Transferência interna* |
| **Situação/Requisito:** | Ao realizar a transferência interna de um aluno, as matrículas nas disciplinas não estão sendo realizadas. |
| **Solução/Implementação:** | Foi realizado um acerto no processo de transferência para que as validações de matrículas não interfiram quando há uma transferência de uma disciplinas em curso.  Ao realizar a transferência de uma disciplina em curso, o sistema barra a matrícula na disciplina por acusar que o aluno já estava com a mesma em curso. |
