# Novo padrão de nomenclatura para Avaliação Institucional

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | TOTVS Educacional. |
| **Módulo:** | Gestão Educacional. |
| **Função:** | Avaliação Institucional. |
| **Situação/Requisito:** | Ao criar uma avaliação institucional no processo da turma disciplina o nome da avaliação recebia apenas "Provas". |
| **Solução/Implementação:** | A prova da Avaliação Institucional teve seu padrão de nome alterado.  Agora ao criar uma prova a nomenclatura é: Provas | Turma: [Nome da Turma] - Disciplina: [Nome da Disciplina] | [Descrição da Avaliação]. |
