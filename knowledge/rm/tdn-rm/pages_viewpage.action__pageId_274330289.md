# Módulo de Caixa - Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Módulo de Caixa - Baixa |
| **Situação/Requisito:** | Ao incluir a forma de pagamento, voltar a aba anterior e avançar novamente, o sistema está permitindo incluir novamente a forma de pagamento. E também ao marcar a flag "Contabilizar Posteriormente" o sistema não exibe a aba de contabilização. Porém ao retornar a aba, desmarcar a flag informada e avançar para a próxima etapa, o sistema continua não exibindo a aba de contabilização |
| **Solução/Implementação:** | Otimização no processo de baixa via sessão de caixa. A partir de agora o sistema irá se comportar da mesma forma que a baixa manual. Ao retornar a aba anterior a da forma de pagamento e avançar novamente, o sistema irá limpar a forma de pagamento para ser incluída novamente. E também a aba de contabilização irá funcionar de acordo com a flag "Contabilizar Posteriormente". |
