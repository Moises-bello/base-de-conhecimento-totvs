**Dúvida**Como gerar o custo realizado do processo de importação?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**Para gerar o custo realizado do processo de importação realize o procedimento no módulo *Easy Import Control* :

1. Selecione o menu Atualizações\Desembaraço\Receb. Importação:

![mceclip0.png](https://totvssuporte.zendesk.com/hc/article_attachments/360052150053/mceclip0.png)

2. Posicione sobre o processo e selecione Outras Ações\Custo Realiz:

![mceclip1.png](https://totvssuporte.zendesk.com/hc/article_attachments/360052150073/mceclip1.png)

3. Selecione a opção Itens:

![mceclip2.png](https://totvssuporte.zendesk.com/hc/article_attachments/360051251314/mceclip2.png)

4. Selecione a opção Grava:

![mceclip3.png](https://totvssuporte.zendesk.com/hc/article_attachments/360051251334/mceclip3.png)

5. Neste momento o custo realizado será gravado:

![mceclip4.png](https://totvssuporte.zendesk.com/hc/article_attachments/360052150213/mceclip4.png)
