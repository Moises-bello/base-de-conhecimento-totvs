Correção - Deslocamento dos textos dos campos em formulários de telas 4GL

|  |  |
| --- | --- |
| Situação | SmartClient exibindo telas 4GL (Logix) sendo executado no Windows com escala de tela maior que 100% |
| Ocorrência | Deslocamento dos labels dos campos dos formulários 4GL, fazendo com que os textos fiquem totalmente ou parcialmente sob os inputs dos campos. |
| Correção | Correção no tratamento dos labels dos formulários 4GL. |
| Informações adicionais | * Referente à ocorrência: DTCLIENT01-3153 * Disponível em builds iguais ou superiores a 20.3.0.3 |
