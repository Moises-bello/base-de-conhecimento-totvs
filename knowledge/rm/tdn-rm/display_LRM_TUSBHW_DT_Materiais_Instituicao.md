# MATERIAIS DA INSTITUIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Materiais da Instituição* |
| **Situação/Requisito:** | *Ao publicar um arquivo institucional (funcionário), é feito a associação da turma. Porém, ao acessar com o login do aluno, o mesmo tem acesso a todos os documentos institucionais, mesmo os que não pertencem a turma que está vinculado.* |
| **Solução/Implementação:** | *Ajuste na visualização de materiais da instituição para alunos/responsáveis e professores. Sendo que alunos/responsáveis verão materiais que não estão associados à nenhuma turma/disciplina e os que estão associados às turmas/disciplinas que o aluno estiver matriculado. Bem como os professores verão apenas materiais que não estão associados à nenhuma turma/disciplina e os que estão associados às turmas/disciplinas que o professor estiver associado.* |
