# BAIXA DE LANÇAMENTOS COM CHEQUE EMITIDO/RECEBIDO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa de Lançamentos com Cheque emitido/recebido |
| **Situação/Requisito:** | Ao tentar baixar um lançamento (sem cheque emitido) o mesmo contabiliza da forma correta considerando o valor baixado, porém ao realizar a emissão do cheque para o mesmo lançamento e tentar realizar a baixa, o sistema está considerando o Valor Original do lançamento na sua contabilização. |
| **Solução/Implementação:** | Otimização no processo de baixa de lançamentos com cheque emitido/recebido para executar corretamente a função de formula VALOR. |
