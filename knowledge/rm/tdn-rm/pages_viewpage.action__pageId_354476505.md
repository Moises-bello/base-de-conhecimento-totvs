# Nova tag para mensagem boleto próximo ao vencimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cadastro de mensagens de objetivo "Boleto próximo ao vencimento" |
| **Situação/Requisito:** | Ao acessar o cadastro de mensagens para objetivo "Boleto próximo ao vencimento", não está sendo possível definir uma tag para o nome do responsável do aluno. |
| **Solução/Implementação:** | Foi realizado um ajuste no TOTVS Gestão Educacional no cadastro de mensagem, de maneira a disponibilizar uma nova tag de nome do destinatário ([NOMEDESTINATARIO]) no objetivo "Boleto próximo ao vencimento", para possibilitar ao usuário direcionar a mensagem para os responsáveis do aluno. |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | N/A |
| **Requisito:** | N/A |
