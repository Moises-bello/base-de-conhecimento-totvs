![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30564823509911) Tempo aproximado para leitura: **00:00:01 min** **Dúvida**Como gerar o Gráfico de Absenteísmo?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 12.  
  
**Solução**Para gerar o  gráfico de absenteísmo, siga os passos abaixo: 

1. Acesse no Automação de Ponto o menu **Relatórios |** **Gráfico de Absenteísmo**.   
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30564848983831)
2. Ao abrir o assistente para geração do relatório, faça a seleção desejada:  
   1- Grupo de funcionários (Caso não faça nenhuma seleção será para todos os funcionário ou seções conforme o agrupamento selecionado);  
   2- Opções de consideração pra ser apresentada no relatório;  
   3- Agrupamento;   
   4 - Informe o período desejado;  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30564823511191)  
     
   Observação:  
   Para visualizar o gráfico de Absenteísmo, o parâmetro Considera Atrasos e/ou Considera Faltas deve estar habilitado.
3. Após realizar todo a ajustes, para gerar o gráfico clique em executar.
