**Relatório Espelho de Ponto Eletrônico**

Conforme portaria 1510/2009, o relatório do espelho deverá ser gerado para o controle dos horários registrados e os tratamentos efetuados sobre os dados originais. A utilização desse relatório dependerá de um modelo criado pela TOTVS, no qual ficará disponível no momento da instalação do aplicativo RM Chronus. Basta acessar o Gerador.NET e realizar a importação do arquivo "Relatório Espelho de Ponto Eletrônico".

**Observação**

Caso o arquivo não fique disponível após a instalação do RM Chronus, solicite-o junto ao TOTVS. O layout foi definido pelo MTE através da Portaria 1510/2009 e pode ser consultado em: [www.mte.gov.br](http://www.mte.gov.br/)  
Para gerar o relatório é necessário preencher os campos abaixo:

**Grupo de Funcionários**

**Quebra de seção -** Este campo deve ser utilizado para selecionar o grupo de funcionários pela seção que está cadastrado. Podendo informar o código da seção, ou até mesmo o código de quebra da seção.

**Seleção de funcionários -** Ao clicar no botão de Seleção de funcionários o sistema abrirá uma janela com os campos onde você poderá selecionar um funcionário digitando sua chapa ou localizando seu nome, ou também fazer a seleção de funcionários pela situação, tipo de funcionário e recebimento e até mesmo criar um filtro para seleção.

**Perfil de Parâmetros -** Este campo permite guardar a configuração ao gerar o relatório. Ao acessar novamente este relatório, basta selecionar o perfil criado para o sistema trazer os parâmetros salvos.

**Salvar perfil ao concluir -** Este parâmetro é utilizado para incluir um novo perfil de parâmetros. Informe um nome de um novo perfil, marque o parâmetro "salvar perfil ao concluir" e ao clicar no botão "OK" para efetuar o lançamento o sistema gravará o novo perfil de parâmetros.

**Informe o período** **Período -** Informe o período que será gerado o relatório, este deve ser menor ou igual ao período atual.

**Data início -** Informe a data início de geração do relatório, esta deve estar dentro do período selecionado.

**Data fim -** Informe a data fim de geração do relatório, esta deve estar dentro do período selecionado.

**Nome do Arquivo -** Informe o nome que será gravado o arquivo.

**Salvar o(s) arquivo(s) na pasta -** Informe o diretório onde será salvo o arquivo.

**Selecione o relatório a ser gerado -** Informe o relatório do espelho de ponto eletrônico para geração.
