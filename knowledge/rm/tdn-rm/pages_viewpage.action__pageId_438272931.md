# EDIÇÃO DOS ITENS DO PEDIDO DE MATERIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Edição dos Itens de Pedido de Material. |
| **Situação/Requisito:** | Deverá ser criado a pagina de edição dos itens de Pedido de Material.  Ter como referencia o protótipos criados. |
| **Solução/Implementação:** | Foi desenvolvido a edição dos itens de pedido de material de forma responsiva para os dispositivos: mobile, tablet e desktop.  A edição possui:   * Lista com as tarefas associadas ao item (insumo) * Filtro para buscar por tarefa (código e nome) * Informações da quantidade pedida e necessária para a tarefa selecionada por item e totalizada * Formulário para edição de um item. |
