# Inclusão de Boleto Registrado Online

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção & Projetos* |
| **Módulo:** | **TOTVS Gestão Financeira** |
| **Requisito/S****tory/Issue:** | *FINANCEIRO01-32* |

## Descrição

Esta implementação tem como objetivo de ter a possibilidade no serviço de inclusão de boleto e registrá-lo online.

## Procedimento para Configuração

No processo de inclusão de boleto, na página Dados do Boleto, ao selecionar o tipo "Cobrança" será exibido o parâmetro "Registrar Online o boleto", se marcado o boleto será registrado online junto ao banco. O boleto será incluído independente se o processo do registro online for realizado com sucesso.

**Atenção**: Para realizar o registro online do boleto o convênio do(s) lançamento(s) ou o convênio selecionado para inclusão do boleto na tela deverá estar com o parâmetro "Permite registro de boleto online" marcado.
