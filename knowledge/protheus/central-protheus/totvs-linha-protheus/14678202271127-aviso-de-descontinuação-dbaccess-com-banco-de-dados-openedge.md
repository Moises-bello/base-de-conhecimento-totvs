Os produtos TOTVS estão em constante evolução para transpor desafios e acompanhar cada etapa da jornada digital da sua empresa.

Por este motivo, comunicamos que a utilização do **DBAccess com banco de dados OpenEdge** será descontinuada em **31/10/2023.**

|  |
| --- |
| ***Importante:*** *outros produtos já divulgaram a descontinuação da utilização do Banco de Dados OpenEdge no* [*Portal do Cliente*](https://centraldeatendimento.totvs.com/hc/pt-br/articles/8495424197655-Descontinua%C3%A7%C3%A3o-Gest%C3%A3o-de-Frete-Embarcador-SIGAGFE-com-Banco-de-Dados-OpenEdge) *e, nestes casos, estes seguirão as datas de descontinuação previamente comunicadas.* |

A seguir, esclarecemos as possíveis dúvidas sobre a transição do OpenEdge para um novo banco de dados: 

**O que vai acontecer com os meus dados?**

Todos os clientes que ainda utilizam  **DBAccess** **com o banco de dados OpenEdge**, devem realizar a conversão de sua base de dados para outro banco de dados homologado pela TOTVS para a Linha Protheus, entre eles: PostgreSQL (código aberto e gratuito), Oracle ou SQL Server.

[Clique aqui](https://tdn.totvs.com/display/tec/DBAccess+-+Banco+de+dados) e conheça a documentação oficial dos bancos de dados homologados e suas respectivas versões. 

**O que vai acontecer se eu não migrar para um banco de dados homologado até a data da descontinuação?**

Se você não realizar a migração para um banco de dados homologado, a partir da data da descontinuação, a TOTVS não prestará mais suporte técnico para eventuais situações que estejam relacionadas ao banco de dados OpenEdge.

**O que vai acontecer após a data da descontinuação?**

Conforme nossa Política de Ciclo de Vida de Software, a partir da data de descontinuação, a TOTVS não irá evoluir, prestar suporte ou realizar manutenção no DBAccess para o banco de dados OpenEdge.

**Existe algum conversor para realizar a migração de dados?**

Preparamos uma documentação para te ajudar nesta transição. [Acesse aqui](https://tdn.totvs.com/display/tec/DBTools) e conheça todos os detalhes. 

De acordo com a documentação do DBTools, a migração para o novo banco de dados pode ser realizada por sua equipe especializada. Caso não  possua equipe especializada em sua empresa, a TOTVS pode fornecer este serviço sob demanda. Para isto, acione seu Executivo de Soluções e Negócios, que irá providenciar a elaboração de orçamento, via TOTVS Infra Services (TIS)

 

**Preciso fazer a validação do novo banco de dados em meu ambiente?**

Para assegurar sucesso na adoção do novo banco de dados, recomendamos que seja realizada a validação da aderência e definição de configurações específicas e novas parametrizações, seguidas de um ciclo de homologação antes de alterar o banco de dados do ambiente de produção.

 

Estamos à disposição para esclarecer qualquer dúvida. Basta entrar em contato com o seu ESN (Executivo de Soluções e Negócios)!
