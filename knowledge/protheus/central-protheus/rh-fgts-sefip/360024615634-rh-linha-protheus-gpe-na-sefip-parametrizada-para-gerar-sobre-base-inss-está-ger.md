**Dúvida**Na SEFIP, parametrizada para gerar sobre base INSS está gerando a base FGTS para licença maternidade  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para as situações em que o funcionário está afastado por licença maternidade e alguns outros tipos de afastamento é utilizado a base FGTS na SEFIP mesmo que esteja parametrizado para a base INSS.
