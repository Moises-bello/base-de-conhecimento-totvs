*![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21076673562391) Tempo aproximado para leitura: **00:02:00 min*****Dúvida**Gostaria de saber o caminho no sistema para alteração de câmbio a pagar gerados no SIGAEIC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**

Execute os procedimentos abaixo:

1. Acesse o módulo SIGAEIC em Atualizações\ Financeiro \ Controle Cambio.

![](https://totvssuporte.zendesk.com/attachments/token/8C8q9iDImcPNV8SQbR5WcLFvh/?name=inline-216241873.png)​

2. Posicione sobre  tipo do o processo  **Desembaraço, Adiant. P.O. ou Adiant. Fornec.,** selecione ![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028536652).

3. Posicione na linha do câmbio a ser alterada, selecione **Outras Ações** e **Alteração**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028536712)

4. Após selecionar Alteração, será aberta a tela do câmbio, para que sejam feitas as alterações, feito os ajustes salvar.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028535311)
