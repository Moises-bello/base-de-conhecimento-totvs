**Informamos que possui dados pessoais contidos nesta entidade.**

**Para mais informações sobre a LGPD e as soluções oferecidas pela TOTVS consulte nossa página neste link ([https://tdn.totvs.com/pages/releaseview.action?pageId=514427789](https://tdn.totvs.com/pages/releaseview.action?pageId=514427789 "Follow link")).**

Esse cadastro tem a finalidade de registrar os parceiros de negócios da empresa, armazenando informações deste relacionamento, como percentuais de Comissão e Repasse, Endereço de Pagamento, Site, E-mail e Tabelas para a Integração Financeira. Além das informações cadastrais acima, o sistema disponibiliza o cadastro de Default Contábeis, para que a contabilização de Movimentos possa ocorrer a partir destes default e, desta forma, todo o processo contábil possa ocorrer de acordo com as informações do Representante. O sistema ainda permite que o cadastro seja configurado com o parâmetro 'Fatura Cliente Direto', que pode ser filtrado no momento de imprimir um documento de Nota Fiscal, o qual retorna os dados do Cliente/Fornecedor do Movimento ou os dados do Representante relacionado a este Movimento.
