| **Sintoma** | **No menu Sindicato "Pasta de Médias", o que significa "Número mínimo de meses para habitualidade?** |
| Solução | Número mínimo de meses, que os eventos que entrarão para o cálculo das médias, deverão constar na ficha financeira do funcionário para ser considerado pelo Sistema para o cálculo da média. Essa habitualidade será verificada dentro do período (número de meses para análise). |
