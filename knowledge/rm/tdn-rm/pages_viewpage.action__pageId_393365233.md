# AUTOR DA ÚLTIMA MODIFICAÇÃO NO REGISTRO DE MATRÍCULA EM DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Matrícula em disciplina |
| **Situação/Requisito:** | Ao alterar uma informação na tela de matrícula em disciplinas e clicar em salvar, o sistema não altera o autor da última modificação no registro. Apenas a data de alteração é modificada. |
| **Solução/Implementação:** | A tela de matrícula em disciplinas foi alterada para mostrar corretamente o usuário que é o autor da última modificação no registro. |
