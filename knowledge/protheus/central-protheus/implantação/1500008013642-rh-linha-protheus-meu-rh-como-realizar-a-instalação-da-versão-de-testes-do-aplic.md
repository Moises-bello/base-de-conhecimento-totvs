**Dúvida**  
Como funciona a versão de testes do aplicativo Meu RH?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - MEU RH - Todas as versões   
  
**Solução**  
**Importante:** Os programas de testes para os sistemas operacionais Android e iOS são limitados por número de usuários participantes, ou seja, a versão BETA deve ser instalada somente para o Administrador/Usuário chave para testes na nova versão, a disponibilização para todos os usuários deve ocorrer somente quando sair a versão oficial.  
  
**Usuários dispositivos Android:**  
  
1.Para receber as atualizações, é necessário participar do programa beta da *PlayStore*. Para realizar este procedimento basta entrar na *PlayStore*, pesquisar pelo aplicativo Meu RH e clicar na opção para ingressar no programa beta:  
![WhatsApp-Video-2021-03-12-at-101.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500011644162)  
  
**Importante:** O processo para ingressar no programa beta pode levar algum tempo, caso não exista nenhuma atualização espere por algumas horas.   
  
2. Caso ainda não tenha o aplicativo instalado, basta realizar a instalação:

![](https://lh6.googleusercontent.com/5LnVK1bTRIqVTv8DNtbFDWCYotJwDuIxE13DJZ8mq_08yKpdfLOTqcjKyFuW4Q2DXAajHO7ogPavmFWwMU0C3K2u3asgCC7KKqNgtaaRA88FLbXIlrKYLjx31rLGpTh5oeABXrB6)  
  
3. Depois de estar no programa beta, uma atualização ficará disponível para o aplicativo Meu RH. Assim que estiver disponível a atualização, basta atualizar o app que a nova versão já estará disponível no seu celular:

![](https://lh6.googleusercontent.com/Pf3nHIPlhWrn2iRIkzu1Z9RJFLM0cdnWlPTQt7xRSpoW5eTkyLQ9edcXoYPS08NeaefDAe8xIUh6ZlTGm7OZE12Rau4ZVVsYS1JkH1iSvA0dawkXErZtTFmksOsqkvEjljeeZGeX)

**Usuários dispositivos IOS:**  
  
4. Para receber as atualizações, é necessário instalar o aplicativo *TestFlight*. Para isso, abra a *App Store,* pesquise por “*TestFlight*” e faça a instalação:  
![RPReplay-Final1615557025.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500011646362)  
  
5. **Após o app estar instalado, acesse o link abaixo pelo celular:**

<https://testflight.apple.com/join/ob3XSjm3>  
  
6. Depois, basta acessar o aplicativo *TestFlight* e instalar a nova versão:  
![Captura_de_Tela_2021-03-12___s__11.40.44.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/1500011646502)
