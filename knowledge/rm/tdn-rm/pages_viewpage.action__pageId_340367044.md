# Formatação de mensagem no eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Leitura de mensagem no TOTVS eduCONNECT |
| **Situação/Requisito:** | Ao cadastrar uma mensagem no TOTVS Gestão Educacional para o eduCONNECT com quebra de linha (enter), a mensagem não estava sendo formatada com as quebras de linhas devidamente ao abrir a mensagem no eduCONNECT. |
| **Solução/Implementação:** | Foi realizado um ajuste no TOTVS Gestão Educacional, de maneira que o sistema possa converter a quebra de linha da mensagem em um formato que o TOTVS eduCONNECT possa exibir a mensagem corretamente. |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | N/A |
| **Requisito:** | N/A |

divs

Aperfeiçoado o envio de mensagens aos pais do aluno quando este estiver matriculado em dois ou mais cursos.
