# Painel de classificação de risco sem plantão, permite alterações na tela de triagem

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de Classificação de Risco |
| **Situação:** | Na classificação de risco, mesmo sem plantão cadastrado, era possível alterar os dados na triagem quando o médico não estava cadastrado. |
| **Solução:** | Foi desenvolvido rotina para bloquear o sistema quando o médico não está cadastrado no plantão. |
