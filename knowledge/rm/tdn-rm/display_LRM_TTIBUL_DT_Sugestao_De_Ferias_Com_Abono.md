# SUGESTÃO DE FÉRIAS (PORTAL)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias (Portal)* |
| **Situação/Requisito:** | Ao aprovar férias via portal com dias de abono, o sistema validava os dados das férias com base nos parâmetros do grupo de acesso do gestor, e não do funcionário quem marcou as férias. |
| **Solução/Implementação:** | Foi alterado para que os parâmetros fossem validados de acordo com o grupo de acesso do funcionário que marcou as férias |
| **Chamados relacionados:** | TTIBUL |
| **Versões/Release:** | *12.1.8* |
