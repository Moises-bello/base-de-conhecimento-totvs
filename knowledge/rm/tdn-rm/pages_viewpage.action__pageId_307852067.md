# CADASTRO DE ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Educacional |
| **Função:** | Cadastro de aluno - campo Filiação |
| **Situação/Requisito:** | No cadastro do aluno, o campo Filiação não habilitava os botões “Adicionar” e “Remover”, quando estava marcado na permissão de acesso, o item “Outras permissões | Outros módulos | Pessoas | Filiação”. Somente ocorria se o usuário tinha somente acesso de leitura ao cadastro de aluno. |
| **Solução/Implementação:** | Otimizado o controle de permissão de acesso ao campo “Filiação” do cadastro de Aluno. As permissões de acesso aos botões “Adicionar” e “Remover” Filiação é configurada no perfil do usuário, item “Outras permissões | Outros módulos | Pessoas | Filiação”. |
