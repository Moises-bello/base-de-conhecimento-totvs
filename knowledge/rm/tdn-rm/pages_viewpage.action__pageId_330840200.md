# Sinais Vitais Horário Atual

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário Eletrônico do Paciente - Sinais Vitais |
| **Situação/Requisito:** | Ao realizar uma inclusão de sinais vitais e com a tela em aberto clicar em novo o sistema estava preenchendo a data com o horário no formato "00:00" e não buscando a hora atual como quando a tela é aberta. |
| **Solução/Implementação:** | Alterado o sistema para buscar o horário da data atual ao clicar no botão novo dos sinais vitais. |
