# IRRF FÉRIAS NÃO DEDUZ INSS DO TERCEIRO MÊS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *IRRF* |
| **Situação/Requisito:** | No cálculo de férias que abrange um período com dias em 3 meses diferentes, como 31/01/2017 a 01/03/2017 por exemplo, o INSS é calculado separado para cada uma das 3 competências.  Entretanto no cálculo do IRRF está deduzindo somente os descontos de INSS do primeiro e segundo mês, desconsiderando o valor do terceiro mês. |
| **Solução/Implementação:** | Ajuste no cálculo do IRRF Férias para deduzir também o desconto de INSS do terceiro mês das férias. |
