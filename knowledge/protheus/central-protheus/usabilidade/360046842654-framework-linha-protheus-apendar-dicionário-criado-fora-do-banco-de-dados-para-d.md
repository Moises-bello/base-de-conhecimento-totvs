**Dúvida**  
É possível apendar um dicionário criado fora do banco de dados (SX3XXX.dtc) para dentro de um ambiente com dicionário no banco de dados?  
  
**Ambiente**  
Protheus - Dicionário - A partir da versão 12  
  
**Solução**  
Não é possível **apendar**um **dicionário** criado fora do **banco de dados** (SX3XXX.dtc) para dentro de um ambiente com **dicionário** no **banco de dados**, pois as duas estruturas são diferentes.
