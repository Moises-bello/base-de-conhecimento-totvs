**Dúvida**O que analisar quando no cálculo do dissídio retroativo, o sistema não gera valores de bases nem de encargos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**

Primeiramente **verifique se toda parametrização necessária foi realizada**, para isso consulte o manual de dissídio retroativo através do *link* abaixo:  
<https://centraldeatendimento.totvs.com/hc/pt-br/articles/360034578653-MP-GPE-Manual-do-diss%C3%ADdio-retroativo->   
  
A rotina de dissidio passou por uma série de atualizações para corrigir os últimos problemas de conhecimento de Suporte Técnico.   
<https://suporte.totvs.com/portal/p/10098/download#all/all/all/search/rh_expedicao>   
  
Por este motivo, **sempre mantenha o ambiente devidamente atualizado.**

Após analisar o manual e aplicar as devidas atualizações, **verifique os itens abaixo**:

- O Encargo provém de uma base, se ele não está sendo apresentado, possivelmente a base é inexistente ou menor do que esperado;  
- Conferir se o cálculo da época foi feito de forma correta;  
- Se as verbas de encargo estão devidamente amarradas.
