**Atenção:**

Alguns módulos do sistema obrigatoriamente necessitam de seguir uma ordem na cópia de registro entre suas coligadas. O roteiro abaixo deverá ser seguido, quando o usuário utilizar a opção "Copiar todos os Registros".

Abaixo segue os caminhos dos módulos que são possíveis realizar  copia entre coligadas:

# **COMO FAZER :**

Será necessário criar um filtro que busque todos os registros, exceto aqueles que estão cadastrados na coligada 0, isto porque a coligada 0 é global, portanto um registro que está cadastrado para a mesma, está cadastrado para todas as demais.

Veja exemplo de filtro abaixo:

Selecionar  o registro  desejado, acessar  Processos |  Copiar valor fixo entre coligadas

No exemplo foi selecionado apenas um registro, entretanto é possível que seja selecionado mais de um.

Selecionar a coligada destino desejada, e clicar em executar

No exemplo foi selecionado apenas uma coligada, entretanto é possível que seja selecionado mais de uma.

**OBS: É possível substituir os registros no destino se eles já existirem.**

Execução concluída com sucesso.
