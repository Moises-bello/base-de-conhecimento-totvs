Para acessar os Relacionamentos de Característica, ao cadastrar ou editar um Empreendimento, clique em Anexo e depois em Característica.  
 Nesta opção de menu serão relacionadas as Características ao Empreendimento;

Através do cadastro é possível controlar:

**Identificação - Relacionamento de Características**  
 Ao cadastrar ou editar uma Características, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* Empreendimento: Neste campo estará o Empreendimento que receberá a Característica. Este campo está desabilitado para edição;
* Tipo de Característica: Informe o Tipo de característica que o Empreendimento receberá. O sistema apresentará uma lista de opções de Tipos de Características já previamente cadastradas no sistema RM SGI no menu Cadastro | Característica de Apartamento | Tipo de Características;
* Índice de Característica: Informe o Índice de característica que o Empreendimento receberá. O sistema apresentará uma lista de opções de Índices de Características já previamente cadastradas no sistema RM SGI no menu Cadastro | Característica de Apartamento | Tipo de Características, no anexo Índice de Característica.
