**Dúvida**  
Como cadastrar um novo código de retenção para a regra financeira?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - A partir da versão 12.1.2210  
  
**Solução**  
No **Configurador de Tributos**, acesse o menu **Base de Dados > Base de Dados**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/35462461077399)

Em seguida, selecione **Tabela Genérica**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/35462466342679)

Localize a **Chave 37 – Código de Retenção Impostos de Renda,** clique em editar, em seguida clique em **Itens**. Serão exibidas as retenções cadastradas no padrão.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/35462466343831)

No último item da lista, pressione a **seta para baixo** no teclado para habilitar um novo campo em branco.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/35462461079191)

Seguindo o mesmo padrão dos demais registros, cadastre o novo código de retenção conforme o exemplo:

* **Chave:** Novo código de retenção
* **Descrição:** Descrição do código de retenção
* **Desc Spanish:** Utilizar a mesma descrição anterior.
* **Desc English:** Utilizar a mesma descrição anterior.
