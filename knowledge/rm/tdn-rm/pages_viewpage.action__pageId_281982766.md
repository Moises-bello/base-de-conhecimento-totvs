# São Exibidos Itens Repetidos na Pesquisa de Emissão de Etiquetas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Etiquetas de Código de Barra |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu: **Estoque/Etiquetas de Código de Barra**, abrir o formulário, selecionar um local de estoque, clicar no botão pesquisa, irá exibir o formulário "Pesquisa de Itens de Estoque". Ao pesquisar um item é possível verificar que o item era exibido duplicado. |
| **Solução:** | Ajuste realizado no formulário para que a pesquisa não exiba itens duplicados. |
