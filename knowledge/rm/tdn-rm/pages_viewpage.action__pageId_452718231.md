Evento Base de Cálculo e do tipo valor, com as mesmas incidências do evento com código de cálculo 49 - IRRF 13º Salário.  
 Este código de cálculo é utilizado no cálculo da pensão alimentícia de 13º quando o funcionário utilizar múltiplos vínculos.  
    
 O sistema faz o cálculo do IRRF 13º somente com a base do funcionário corrente, da mesma forma que o código de cálculo 49 quando não se utiliza múltiplos vínculos.
