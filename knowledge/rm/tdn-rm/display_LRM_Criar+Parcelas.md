Este assistente é utilizado para facilitar ao usuário a criação de parcelas para o contrato do aluno na instituição.   
O assistente possibilita a seleção de um ou mais serviços, permitindo ainda que os valores iniciais dos mesmos sejam alterados.

Após a seleção do(s) serviço(s) o usuário deve informar os dados referentes às parcelas a serem geradas para o(s) plano(s) de pagamento:  
- Número de parcelas;   
- Número de cotas;   
- Parcela Inicial;   
- Cota Inicial;   
- Tipo de parcela;   
- Data de competência;   
- Desconto;   
- Tipo de desconto;   
- Dia de vencimento (fixo ou útil) ;   
- Data de vencimento inicial.   
  
**Manter informações para todos os serviços selecionados:** Essa opção permite que os dados informados para o primeiro serviço sejam propagados para todos os outros serviços selecionados anteriormente, evitando uma nova digitação dos dados por parte do usuário.

**Observação**:   
Não é possível incluir parcelas em contratos do tipo "Acordo" e em contratos "Cancelados", por isso, os contratos desses tipos não serão exibidos na aba "Contratos Selecionados" do processo de criação de parcelas.

**IMPORTANTE:**

Hoje temos um parâmetro, conforme abaixo, para definir se o vencimento será em **dia útil** ou **dia fixo**. Suponha que no campo **Data de vencimento inicial** eu informe a data de vencimento da parcela como **10/02/2025**. Ao marcar o parâmetro **dia Fixo**, estou informando ao sistema que meu desejo é gerar a parcela com vencimento no **dia 10 do mês de Fevereiro de 2025**. Se eu marcar o parâmetro **Dia Útil**, o sistema altera o comportamento do campo e gera o vencimento para o **Décimo dia útil do mês de Fevereiro de 2025**.
