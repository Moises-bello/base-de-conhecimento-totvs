**Dúvida**A função DlgToExcel para exportar informações para o Excel não está funcionando.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL– A partir da versão 12.1.17  
  
**Solução**O problema ocorre, pois o office não está homologado, a função [DLGTOEXCEL](http://tdn.totvs.com/pages/releaseview.action?pageId=39682606) é descontinuada o que temos a função [FWMsExcelEx](http://tdn.totvs.com/display/framework/FWMsExcelEx)

verifique o artigo para validar a integração com o Excel.
