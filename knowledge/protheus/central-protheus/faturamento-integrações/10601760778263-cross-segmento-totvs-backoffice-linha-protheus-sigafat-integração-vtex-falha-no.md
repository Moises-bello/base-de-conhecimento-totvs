**Dúvida**Ao enviar dados do Protheus para o VTEX, o Protheus indica " Falha no Envio "  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões  
  
**Solução**A comunicação do Protheus com o VTEX é realizada pelo Connector e existem duas possibilidades na falha de envio :  
  
1) O cliente não utilizar o Connector (erro mais habitual para quem está implantando);

2) As rotas do Adapter EAI estarem incorretas.  
  
Neste segundo caso é necessário que o suporte do software de destino indique qual a rota que deve ser cadastrada no Protheus
