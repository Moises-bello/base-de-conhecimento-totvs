# Folha Analítica por Dissídio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projeto. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | Tratamento dos eventos de base de códigos de calculo 114, 115 e 116 na calculo de BASE de INSS na Folha Analítica por Dissídio. |
| **Situação/Requisito:** | A folha analítica por dissídio não deverá considerar o estorno de INSS nas competências de cálculo  do dissídio para os eventos de código de cálculo:    114 - ESTORNO BASE INSS DISSÍDIO RET. FOLHA;    115 - ESTORNO BASE INSS DISSÍDIO RET. 13º;    116 - ESTORNO BASE INSS DISSÍDIO RET. FÉRIAS.    Estes eventos devem ser considerados, para estorno de INSS apenas na competência e período de pagamento.  . |
| **Solução/Implementação:** | A folha analítica por dissídio passa a não considerar o estorno de INSS nas competências de cálculo  do dissídio para os eventos de código de cálculo:    114 - ESTORNO BASE INSS DISSÍDIO RET. FOLHA;    115 - ESTORNO BASE INSS DISSÍDIO RET. 13º;    116 - ESTORNO BASE INSS DISSÍDIO RET. FÉRIAS.    Considerando-os, para estorno de INSS, apenas na competência e período de pagamento.  . |
