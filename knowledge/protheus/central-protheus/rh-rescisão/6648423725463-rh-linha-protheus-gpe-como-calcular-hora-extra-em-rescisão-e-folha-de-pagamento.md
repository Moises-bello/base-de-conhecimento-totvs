![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25666856600215) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como calcular hora extra em rescisão considerando salário base mais periculosidade sobre salário id 0036?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para calculo de hora extra considerando salário base mais periculosidade sobre salário id 0036, a verba de periculosidade id 0036 deve estar com Sim para Incorpora Salário e a verba hora extra como campo Base Cálculo com Salário Incorporado. Deste modo o sistema considera como base para cálculo da verba hora extra a soma do salário base mais o adicional periculosidade.  
  
Verba periculosidade id 0036 campo **Incorpora Salário** com **SIM**:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30712588999959)

Verba hora extra campo **Base Cálculo** com **2-Salário Incorporado**:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30712594060055)
