**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26823241128087)**Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que arquivo seguro desemprego não carrega número de telefone (celular) mesmo tendo informação em cadastro?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Pelo layout do arquivo seguro desemprego, só consta um campo para número de telefone sendo este número não descrito como número de celular. Para o número de telefone ser carregado para o arquivo seguro desemprego, devem ser preenchidos em cadastro de funcionário os campos DDD Telefone e Telefone.
