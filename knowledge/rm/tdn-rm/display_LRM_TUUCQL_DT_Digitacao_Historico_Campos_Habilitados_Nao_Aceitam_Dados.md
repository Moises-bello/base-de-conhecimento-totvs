# DIGITAÇÃO DE HISTÓRICO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Digitação de histórico* |
| **Situação/Requisito:** | *Na tela de "Digitação de histórico", os campos para seleção dos dados do histórico estão habilitados porém só aceitam dados após clicar no botão "novo". Nas versões 11.82 estes campos ficam desabilitados e somente após clicar em "novo" que são habilitados, aceitando assim a entrada de dados.* |
| **Solução/Implementação:** | *Foi feito o ajuste na tela para que os campos fiquem desabilitados e só habilitem após clicar no botão "novo", igual na 11.82e da forma que melhora o entendimento e usabiltidade da tela* |
