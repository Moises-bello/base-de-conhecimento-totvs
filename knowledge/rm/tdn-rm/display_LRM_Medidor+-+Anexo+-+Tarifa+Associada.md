O cadastro de tarifa permite o usuário informar o valor que será cobrado pelo fornecimento de determinado insumo, por exemplo água e luz. Este preço deve ser estabelecido pelo condomínio conforme gestão interna. Neste cadastro será informado um valor unitário da unidade de medida configurada no medidor e sem a possibilidade de indicação de valores variados por faixa de consumo.

**Figura 1 - Tela de cadastro da Tarifa no Medidor**

**Aba Identificação:** 

* **Medidor:** Exibe qual medidor a tarifa está sendo associada. Este campo é preenchido automaticamente pelo sistema;
* **Cód. Tarifa:**Neste campo é possível selecionar uma tarifa a ser associada ao Medidor.
* **Data inicial:** data no formato (mês/ano) a partir da qual a tarifa deve ser utilizada no cálculo do fechamento do medidor. Este campo é preenchido de acordo com a Data Inicial da tarifa no qual está sendo associada;
* **Data final:** data final no formato (mês/ano) que a tarifa deve ser utilizada no cálculo do fechamento do medidor. Este campo é preenchido de acordo com a Data Final da tarifa no qual está sendo associada;
* **Valor:** Exibe o valor da tarifa que está sendo associada. Este campo é preenchido conforme o valor da tarifa;
* **Fórmula**: Exibe a fórmula que foi definida no cadastro de tarifa para calcular o valor da tarifa.

**Observação:** O sistema não permite incluir tarifas com as datas em interseção para o mesmo medidor.
