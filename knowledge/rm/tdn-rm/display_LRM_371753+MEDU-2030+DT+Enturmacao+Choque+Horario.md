# ENTURMAÇÃO COM CHOQUE DE HORÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Enturmação.* |
| **Situação/Requisito:** | *Ao realizar a enturmação, selecionando várias turmas/disciplinas para o aluno, caso uma delas tivesse choque de horário, não era realizada a enturmação para nenhuma das turmas/disciplinas selecionadas.* |
| **Solução/Implementação:** | *Alteração no comportamento do sistemas para que no caso de existir choque de horário, para alguma das disciplinas selecionadas, apenas as disciplinas que tiverem essa exceção não terão a enturmação realizada e serão exibidas em um log. Todas as outras turmas/disciplinas que não tiverem exceções terão a enturmação realizada.* |
