# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | TOTVS Educacional. |
| **Módulo:** | Educacional. |
| **Função:** | Parametrização TOTVS Fast Analytics Educacional. |
| **Situação/Requisito:** | Clientes tem como prática utilizar o mesmo status para indicar alunos ativos e alunos formados no Ensino Básico (ex.: status de aprovado). O que diferencia os indicadores é a série parametrizado como última séria do Ensino Básico da instituição de ensino. |
| **Solução/Implementação:** | Retirado a trava que bloqueava a utilização do mesmo status na parametrização de alunos ativos e formandos do Ensino Básico. Foi alterado também a consulta de extração da fato aluno para considerar a última séria parametrizada do ensino básico para definir se o aluno é ativo ou formado. |
