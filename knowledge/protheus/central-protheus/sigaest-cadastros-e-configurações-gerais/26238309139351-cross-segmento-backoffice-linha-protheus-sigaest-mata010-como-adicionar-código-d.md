![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26238316288663) Tempo aproximado para leitura: **00:02:13 min** **Dúvida**Como adicionar Códigos de Serviços no campo B1\_CODISS sem que ocorra o help: Cod. Serv. ISS?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238309112087)  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
  
**Solução**A consulta genérica (Lupa) deste campo, consulta a **Tabela 60**. Então, caso tenha a necessidade de criar novos códigos de serviços para posteriormente inserir no Cadastro do Produto, basta:

1 - Acessar ao Configurador (SIGACFG)

2 - Acessar ao caminho: Base de Dados -> Dicionário -> Base de Dados

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238316293399)

3 - Acessando a opção de Tabelas Genericas, clique na Lupa e pesquisa por **60**:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238309118231)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238316301847)

4 - Posicione em um registro qualquer desta tabela e clique no ícone da caneta vermelha para edição (penúltimo da direita para esquerda) para adicionar uma nova chave (código ISS)

5 - Clique em "Itens"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238316305047)

6 - Seta para baixo para adicionar um novo registro

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238309127191)

7 - Ao retornar ao campo do Cadastro de Produto, ele permitirá inserir o código criado sem dar o help.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26238309128599)
