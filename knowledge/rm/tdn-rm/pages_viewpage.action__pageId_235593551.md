|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Gerar lançamento* |
| **Situação/Requisito:** | *Ao regerar um lançamento, após incluir uma bolsa de crédito, o Número de Documento da Partida Contábil não condizia com o Número de Documento do Lançamento Financeiro.* |
| **Solução/Implementação:** | Alterado processo de geração de lançamento,ao regerar um lançamento, após incluir uma bolsa de crédito, o Número de Documento da Partida Contábil deverá ser igual ao Número de Documento do Lançamento Financeiro na contabilização de Inclusão, conforme parametrizado. |
