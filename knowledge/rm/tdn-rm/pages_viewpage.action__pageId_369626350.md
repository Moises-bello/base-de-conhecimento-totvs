# PROCESSO SELETIVO TERCEIRIZADO - MATRICULAR CANDIDATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Processo seletivo terceirizado - matricular candidato |
| **Situação/Requisito:** | Ao matricular o candidato do processo seletivo terceirizado, o sistema estava gravando nacionalidade default do responsável financeiro como estrangeira, para os candidatos que não tinha esta informação preenchida. |
| **Solução/Implementação:** | No processo seletivo terceirizado, ao Matricular Candidato, o sistema irá gravar a nacionalidade do responsável financeiro do aluno como default Brasileira, caso não seja informado nos dados do candidato. |
