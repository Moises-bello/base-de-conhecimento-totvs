![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20638947752343) Tempo aproximado para leitura:**00:02:00 min** **Dúvida**Qual o parâmetro define se será possível salvar e restaurar as informações alteradas das adições no Recebimento de Importação?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) Easy Import Control - Todas as versões  
  
**Solução**   
O parâmetro que define se será possível restaurar as informações alteradas nas adições é o **MV\_UTILEIB.**
