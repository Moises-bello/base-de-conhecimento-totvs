**Dúvida**

Sequencia da geração do código base através do documento de entrada  
  
**Ambiente**

Cross Segmento - Backoffice Linha Protheus – Ativo Fixo –  Todas as versões  
  
**Solução**

MV\_CBASEAF

Próximo código base do Ativo Imobilizado a ser incluído automaticamente pelo documento de entrada.

Sistema incrementa informação para o campo N1\_CBASE, de acordo com informações do conteúdo do parâmetro MV\_CBASEAF, ou seja, se o conteúdo do parâmetro estiver = "NFE000000M", representa que a próxima inclusão de Ativo o campo de Código de Bem receberá este conteúdo.
