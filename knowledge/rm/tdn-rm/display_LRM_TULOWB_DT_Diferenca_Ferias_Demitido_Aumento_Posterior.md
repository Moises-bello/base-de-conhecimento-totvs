# DIFERENÇA DE FÉRIAS DE DEMITIDO CONSIDERA AUMENTO SALARIAL POSTERIOR AO PERIODO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Diferença de Férias* |
| **Situação/Requisito:** | *Quando é calculada diferença de férias para funcionário demitido, está sendo considerado aumento salarial ocorrido após o final do periodo de férias.* |
| **Solução/Implementação:** | *Ajuste na diferença de férias para tratar o caso de funcionário demitido, e não considerar aumentos salariais ocorridos após o final do periodo de férias.* |
