Dúvida**Como o sistema irá trabalhar e\ou atualizar os Incoterm 2020?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 12.1.017.  
  
**Solução**Conforme levantamento com a equipe de produtos sobre as regras do Incoterm para o ano de 2020, ainda não temos nenhuma informação oficial do governo. Geralmente lançam o comunicado oficial na virada do ano, com previsões, pois os países precisam assinar o acordo. Mesmo acontecendo as atualizações as alterações são de menor impacto levando em consideração que se houver uma incoterm nova temos a opção de cadastra-la no sistema.   
Quando ocorrer esta atualização é possível que a Trade encaminhe uma carga com as incoterms mais recentes ou até mesmo um patch para esta atualização. Sendo assim, atualmente não temos novas atualizações referente aos incoterms 2020.
