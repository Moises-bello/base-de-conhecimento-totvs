# Processo Encerrar Vigência do Simples Nacional

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Processo "Encerrar Vigência do Simples Nacional" |
| **Situação/Requisito:** | Criar processo para permitir ao cliente inserir Data Fim da Vigência em várias alíquotas do simples nacional. |
| **Solução/Implementação:** | * Criado processo para permitir ao cliente inserir a "Data Fim da Vigência" em várias alíquotas do simples nacional.   Processo disponível em "TOTVS Gestão Fiscal - Obrigações Principais\Simples Nacional\Alíquota do Simples\Processos"   Tela de processo * Ao selecionar as alíquotas desejadas e executar o processo "Encerrar Vigência Alíquota Simples Nacional" sistema irá atualizar o campo "Data Fml da Vigência" de todas alíquotas selecionadas que tenham data de início de vigência anterior a data definida na tela do processo. * Por padrão a tela do processo virá com o valor padrão 31/12/2017. |
