# Objetivo

Esse documento tem o objetivo de demonstrar o procedimento que deve ser executado para realizar a associação de arquivos com extensão .rel ao aplicativo RM\_Rel\_Viewer, responsável pela visualização de relatórios Delphi do RM.

# Procedimentos

* Baixe o arquivo RMRelViewer.zip disponível no link
* Extraia os arquivos para o diretório de instalação do SmartClient, que por padrão é **C:\totvs\RM.NET**
* Será criada uma pasta conforme print abaixo

* Em seguida, acessa esta pasta e clique 2 vezes sobre o arquivo TESTE.REL

* Na janela que surgir para definição de aplicativo padrão para abertura de arquivo com extensão .rel, clique em **Alterar**, e em seguida selecione o executável **RM\_REL\_VIEWER.exe**, conforme prin abaixo:

* Para validar se a associação foi executada corretamente clique 2 vezes com o botão esquerdo do mouse no arquivo TESTE.REL. Será aberto uma janela com o relatório, conforme abaixo:

* Se esta janela for apresentada basta executar normalmente os relatórios Delphi do RM, através do SmartClient. Caso ocorra alguma inconsistência entre em contato com a equipe de atendimento do RM.
