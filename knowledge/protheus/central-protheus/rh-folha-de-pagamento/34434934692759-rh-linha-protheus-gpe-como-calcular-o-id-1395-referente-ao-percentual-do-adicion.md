**Dúvida**  
Como calcular o id 1395 referente ao percentual do adicional SANAI na folha de pagamento?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**  
1. Acesse o cadastro de verbas e verifique se o Id de cálculo está devidamente cadastrado com o percentual definido:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/34434934667799)

2. Acesse Atualizações/ Definições de cálculo/ Manutenção tabelas - Tabela S038 Outras entidades. O campo % Adic. Senai deve estar preenchido:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/34434930392855)

3. Ao calcular a folha de pagamento, sistema apresenta a verba de id 1395:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/34434930393367)

4. Desmembramento do cálculo:

(118,00\*20%) + 5,27% = 24,84.  
   
Os 5,27% é o percentual definido na verba conforme primeiro print.
