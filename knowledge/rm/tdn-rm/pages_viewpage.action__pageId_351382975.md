# TCC

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | TCC. |
| **Situação/Requisito:** | Ao enviar o documento final do TCC, caso parametrizado, um e-mail de confirmação é enviado para os usuários associados ao TCC. No portal do aluno havia uma inconsistência que impedia a geração e envio da notificação. |
| **Solução/Implementação:** | Ajuste no processo de envio do arquivo final, disponível para o aluno matriculado na disciplina de TCC, para que ao realizar o envio do arquivo uma notificação seja emitida para os usuários associados ao TCC(conforme parametrização). |
