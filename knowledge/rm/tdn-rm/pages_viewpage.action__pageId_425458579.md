Este assistente é para facilitar o cadastro dos horários da turma disciplina, os mesmos que também podem ser cadastrados pelo anexo de Horário da Turma/Disciplina  
 Nova implementação no processo de geração de horário modular por recorrência, com base nos seguintes parâmetros:

**Gerar horário por recorrência:** ao marcar este parâmetro, o sistema irá permitir gerar horário por recorrência (semanal ou mensal) usando um intervalo de recorrência.   
 Para isto escolha o tipo de recorrência (semanal ou mensal) e informe o intervalo desejado. Ou seja caso o tipo de recorrência seja semanal com ocorrência 2, o sistema irá gerar o horário marcado a cada duas semanas, semana sim, semana não. Este mesmo comportamento para a recorrência mensal com intervalo em mês.  
 A geração de horário por recorrência, permite ainda a verificação de feriados informados no período letivo, caso algum horário gerado possa cair em um feriado. Para isto marque o seguinte parâmetro:

**Gerar data posterior ao período informado, caso seja um feriado/recesso:** o sistema irá gerar aulas em datas posteriores ao período informado para o horário, caso ocorra de uma data coincidir com feriado/recesso.
