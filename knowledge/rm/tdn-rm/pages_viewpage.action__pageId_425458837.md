**Textos Padrões para Textos de Acompanhamento**

---

O texto padrão é uma informação pré-definida que pode ser utilizada como modelo ou referência para o texto Acompanhamento dos atendimentos (Solicitação, Discussão e Solução). Eles podem ser utilizados para auxiliar na inserção de informações (preenchimento de campos, por exemplo, pode ocorrer necessidade de informar várias vezes em momentos distintos a mesma informação) ou até mesmo por determinação da empresa que visa a padronização /organização dos dados que são inseridos no andamento do atendimento facilitando a consulta e a auditoria.   
    
 Na manipulação do atendimento (avanço de etapa, repasse de atendimentos, execução de processos em geral) o texto padrão pode ser utilizado para tornar mais fácil o entendimento. Para efetuar o cadastro de um texto padrão basta acessar a área de apoio dos atendimentos ou diretamente do tipo de atendimento (através de um anexo) e informar a descrição, o texto e o tipo de disponibilidade. A disponibilidade que pode ser classificada em:

Atendente: Somente o atendente responsável pelo cadastro possui o privilégio de visualizar o texto padrão.

Hierarquia: Para todos os atendentes pertencentes a hierarquia selecionada.

Geral: Para todos os atendentes cadastrados no sistema.

Tipo de Atendimento: Para os atendentes que possuam permissão no tipo de atendimento selecionado.

Para  utilizar os textos padrões realize os passos.:   
    
 **Inserção do Texto Padrão:**  
    
 Acesse a aba de Acompanhamento na parte que deseja inserir a informação (Solicitação, Discussão, Solução);  
 Clique com o botão direito do mouse  e escolha a opção Inserir Texto de Acompanhamento;  
 Os textos padrões relacionados ao tipo de atendimento informado na identificação serão listados;  
 Clique no texto padrão desejado;  
 A informação do texto padrão será registrada na aba, mas a alteração deve ser salva no atendimento para gravação dos dados.  
    
 Ou  
    
 **Pesquisa do Texto Padrão:**  
    
 Acesse a aba de Acompanhamento na parte que deseja inserir a informação ( Solicitação, Discussão, Solução);  
 Clique com o botão direito do mouse  e escolha a opção Pesquisar Texto Acompanhamento;  
    
 A partir desse momento é possível:  
    
 Digitar parte do texto padrão e pesquisar ou Marcar para mostrar todos os textos padrões.  
 Clicando no botão Adicionar, o texto é registrado na aba.  
    
 **Observação.:**  
    
 Os textos padrões serão listados de acordo com as permissões liberados e as regras de validação.

 Vale ressaltar que para manipular os textos padrões com segurança, o sistema respeita as regras:  
    
 **Atendente:**  
    
 Somente o atendente que cadastrou o texto padrão poderá visualizá-lo.  
    
 **Hierarquia:**  
    
 O campo Hierarquia é apresentado para seleção somente quando a disponibilidade igual a Hierarquia é marcada.  
    
 Este nível  é permitido somente para os atendentes que possuam o modo de hierarquia  igual a chefia e/ou seção e para os atendentes caso a permissão no perfil esteja marcada, caso contrário ele ficará desabilitado.  
    
 Para os usuários que selecionarem o nível 'Hierarquia' e ele for chefe de uma hierarquia, o lookup apresentará somente a(s) hierarquia(s) cujo atendente é chefe , caso contrario será mostrado todas as hierarquias do sistema.  
    
 **Geral:**  
    
 É permitido quando o usuário associado ao atendente logado for um usuário supervisor ou caso a permissão no perfil esteja marcada.  
    
 **Tipo de Atendimento:**  
    
 O campo Tipo de Atendimento é apresentado para seleção somente quando a disponibilidade igual a Tipo de Atendimento é marcado.  
    
 Este nível é permitido somente para atendentes que possuam  permissão liberada no perfil.
