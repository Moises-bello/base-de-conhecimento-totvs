# DIRF/INFORME DE RENDIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *DIRF/Informe de Rendimentos* |
| **Situação/Requisito:** | *Quando o funcionário tem rendimentos recebidos no exterior e nos eventos estão marcados que incidem em IR de 13º salário ou IR de férias, os valores não são somados nos rendimentos pagos. Os valores só são somados se tiverem marcados que incidiram em IR de folha e/ou parâmetro ‘Informe Rendimentos’ está marcado.* |
| **Solução/Implementação:** | *Ajustado geração da DIRF para considerar também eventos que incidem em IR *de 13º salário ou IR de férias.** |
| **Chamados relacionados:** | *TTYHKU* |
| **Versões/Release:** | *12.1.9,12.1.10* |
