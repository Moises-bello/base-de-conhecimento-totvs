## **02. SITUAÇÃO/REQUISITO**

Revitalizar as funções de fórmulas dos providers ImbProvider, ImbProviderGeracaoPlano,  ImbProviderParcela, ImbProviderReajuste e ImbProviderVenda  para a máquina de cálculo, desta forma, melhorando em usabilidade, performance e padrão de código.

Para realizar o teste devemos habilitar o novo reajuste "*update xparams set valor = 1 where nome like '%HABILITARREAJUSTEREVITALIZADO%'* "   Criar o contexto de SQL conforme cada grupo de variáveis de fórmulas e trocar o provider na base para o novo provider antes de iniciar os testes das fórmulas.

> *UPDATE GTIPOFORMULA*
>
> *SET NOMECLASSES = 'ImbVendaProvider;ImbProviderApuracao;ImbProviderAlgContratoLocacao;ImbProviderAlgEventoFinanceiro;ImbProviderCondominio',*
>
> *ARQUIVOS = 'RM.Imb.Venda.Calc.Formula.dll;RM.Imb.Formula.dll;RM.Imb.Formula.dll;RM.Imb.Formula.dll;RM.Imb.Formula.dll'*
>
> *WHERE CODSISTEMA = 'X'*
>
> *AND CODTIPO = 1*
