# Como Registrar Agravos e Doenças de Notificação Compulsória?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como Registrar Agravos e Doenças de Notificação Compulsória existentes na Instituição? |
| **Passo a passo:** | A funcionalidade possibilita o registro dos agravos e doenças de notificação compulsória existentes na instituição. É possível registrar os detalhes de cada uma das notificações, bem como a impressão de relatórios dos dados já registrados. A lista de doenças que devem ser notificadas às autoridades sanitárias, já se encontra disponível no sistema, para seleção e registro.    **Importante:**A notificação via RM, visa o registro das notificações para a instituição, todavia, para efetivar a notificação perante as autoridades sanitárias, esta deve ser realizada também via SINAN.    **Registro de Doenças e Agravos:** Registrando a Notificação   1. No TOTVS Gestão Hospitalar acesse **Atendimento/Registro de Notificação de doenças e agravos**. 2. Clique em **Pesquisar** para selecionar o paciente. 3. Será exibida a tela de pesquisa. 4. Selecione o Paciente, é possível realizar a busca por inúmeros filtros. 5. Clique em **OK**. 6. Selecione o Agravo, como, por exemplo, Dengue. Para a seleção será exibida a tela com a lista de agravos e doenças. 7. O Tipo de Notificação (Compulsória ou Imediata) é atualizado automaticamente de acordo com a doença ou agravo, conforme determinações do Ministério da Saúde. 8. Caso a notificação esteja associada a um surto, informe a **data dos primeiros sintomas do primeiro caso** e o **número de casos ou expostos.** 9. Informe a Data da Notificação. 10. Selecione o Status (Emitida ou não Emitida). 11. Clique em **OK**.  Emitindo a Notificação  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Registro de Notificação de doenças e agravos.** 2. Será exibida a tela para realização de filtros. 3. É possível selecionar um agravo específico ainda não emitido, ou então todos os registros ainda não emitidos para sinalizá-los como notificados simultaneamente. 4. Na tela de registro de notificações de doenças e agravos, selecione as notificações que deseja sinalizar como já notificada para as autoridades sanitárias competentes. 5. Na opção **Processos**, selecione a opção **Marcar como agravo notificado**. 6. Será exibida a tela de confirmação de notificação de agravo.  Relatório de Notificação  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Relatório de Notificação**. 2. Após marcar o item como agravo notificado, o relatório com as notificações já encaminhadas será carregado automaticamente. 3. Será apresentada uma notificação por página com todas as informações a respeito das notificações e pacientes. 4. É possível salvar o relatório e também encaminhá-lo via e-mail. 5. Você pode acessar o relatório também pela opção processos/relatório de notificação. |
