# REQUISIÇÃO DE TRANSFERÊNCIA COM ALTERAÇÃO DE DADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Requisição de Transferência com Alteração de Dados |
| **Situação/Requisito:** | Após cadastrar uma “Requisição de Transferência com Alteração de Dados” e fazer a transferência do funcionário através da rescisão, marcando o parâmetro “altera a chapa do funcionário demitido”, a chapa demitida e ativa ficam com o mesmo código de seção.  A chapa demitida deverá manter a seção antiga e a chapa Ativa com a seção nova do funcionário. |
| **Solução/Implementação:** | Ajustado para quando o parâmentro AlteraChapaDemitido for marcado, colocar a seção antiga no funcionário antigo. |
