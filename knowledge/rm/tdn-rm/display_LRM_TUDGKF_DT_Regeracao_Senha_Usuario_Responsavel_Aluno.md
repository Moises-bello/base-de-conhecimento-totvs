# REGERAÇÃO DE SENHA PARA USUÁRIO RESPONSÁVEL DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Regeração de Senha Para Usuário Responsável do Aluno* |
| **Situação/Requisito:** | *Ao processar a rotina de criação de usuários para os responsáveis do aluno não está sendo possível alterar a senha dos usuários existentes, na opção segurança de senha utilizamos flag Regerar senha para usuários já existentes avançamos o processo ele é executado com sucesso porém ao logar no portal ocorre o erro de que usuário ou senha inválidos o sistema não altera a senha do usuário para a nova senha solicitada.* |
| **Solução/Implementação:** | *Ajuste no processo de Geração de Usuário quando marcado o parâmetro para Regerar senha do usuário, para que seja regerado a senha para os usuários responsáveis pelo aluno.* |
