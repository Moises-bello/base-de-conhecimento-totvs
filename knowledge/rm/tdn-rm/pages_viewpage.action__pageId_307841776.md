# Gerador de Saídas - Remessa de Débito Automático

|  |  |
| --- | --- |
| **Linha de Produto:** | . |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Remessa de Débito Automático. |
| **Situação/Requisito:** | Após gerar a remessa de débito automático alguns campos como por exemplo a conta corrente não está sendo gerada corretamente. |
| **Solução/Implementação:** | Foi preciso retirar os campos do layout deixando a opção "Nenhuma" e após informar os campos no contexto novamente. Depois de informar os campos no contexto os respectivos campos forma vinculados no layout novamente. Com isto, a remessa foi gerada e os campos apresentados corretamente. |
