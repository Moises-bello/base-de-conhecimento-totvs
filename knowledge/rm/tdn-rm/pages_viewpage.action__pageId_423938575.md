Este parâmetro está disponível no RM Officina.exe em Opções | Parâmetros | Sistema | Lançamento(s) de Indicador de Uso.

**Atualização**

Na inserção de indicador de uso por Atualização você digita o valor apenas para atualizar o indicador de uso, substituindo o valor anterior pelo novo digitado. Veja o exemplo abaixo do comportamento do parâmetro.  
 Exemplo

|  |  |
| --- | --- |
| **Valor Anterior** | 1000 KM |
| **Novo Valor Digitado** | 1500 KM |
| **Resultado Final** | 1500 KM |

**Incremento**

Na inserção de indicador de uso por Incremento você digita o quanto o indicador de uso deverá ser atualizado, e irá incrementar o valor anterior. Veja o exemplo abaixo do comportamento do parâmetro.  
 Exemplo

|  |  |
| --- | --- |
| **Valor Anterior** | 1000 KM |
| **Novo Valor Digitado** | 500 KM |
| **Resultado Final** | 1500 KM |
