**Ocorrência**  
No módulo **Viagens**, as aprovações para liberação de **Solicitação**, **Adiantamento** já aparecem aprovadas.   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões  
  
**Causa**   
Esse processo ocorre devido a uma configuração que se faz necessária no assistente de configuração Rotina **FINA691**.  
  
**Solução**  
Para solucionar essa ocorrência, realize os seguintes passos:  
1. Abra a Rotina **FINA691**  
2. Avançar direta para Tela **Cadastros Gerais**.  
3. Clique no Botão **Configurar Aprovações**  
4. Se quiser que o sistema exija aprovação nos passos que são apresentados, então deve-se marcar a opção como no exemplo da tela abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027022631/mceclip0.png)
