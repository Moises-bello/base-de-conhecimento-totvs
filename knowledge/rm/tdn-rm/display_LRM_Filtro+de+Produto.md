O Anexo **Filtro Produto** será habilitado para os processos **F****ECP (Fundo de Combate a Pobreza)**e **FCI (Ficha de Conteúdo de Importação)**

Para o processo **FECP e FCI**, o Cadastro de Produto conterá os seguintes campos:

**Identificação:**

* Código do Produto
* Descrição

Validações

Não deve ser permitido cadastrar produtos duplicados para um mesmo subgrupo.
