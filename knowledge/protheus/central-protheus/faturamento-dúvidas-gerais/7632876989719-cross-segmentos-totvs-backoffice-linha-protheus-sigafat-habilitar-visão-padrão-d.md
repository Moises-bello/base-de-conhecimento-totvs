![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20479550677911) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como habilitar a visão padrão do Dashboard?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Faturamento (SIGAFAT) - Protheus 12.1.033;  
  
**Solução**

Tivemos um Webinar sobre o tema, não deixe de assistir: [Webinar | MP - SIGAFAT - Novo Dashboard de Faturamento](https://youtu.be/elTDggvJFmI?si=35h5tnIy3gIxUDUM) (**Confira o índice na descrição do vídeo**).

Para solucionar essa dúvida, realize os seguintes passos:  
1. Acessar o sistema **"Dashboard"** com um usuário Administrador ou com permissão de Administrador;  
2. Com o usuário Administrador, a opção **"Visão"** será apresentada na lateral da tela;

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7632429864343)  
3. Realizar a inclusão da Visão que deseja;

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7632506005783)

Observação; Os Cads, Gráficos são padrão, somente para visualização do funcionamento, para informações especificas teria que customizar o API do Dashboard;

[Gerenciar Cards e Gráficos Customizados](https://tdn.totvs.com/pages/releaseview.action?pageId=668652759)

4. Após realizar a inclusão das visões, o sistema vai apresentar na tela Home o campo Visão, para selecionar a que deseja;

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7632852855959)
