# Parametrizador

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Gestão Financeira. |
| **Função:** | Parametrizador |
| **Situação/Requisito:** | Adicionar parâmetro interno "Proporcionalizar valor baixado dos lançamentos faturados pelo valor líquido" ao formulário de parametrização do financeiro. |
| **Solução/Implementação:** | Removido parâmetro interno e criado parâmetro "Proporcionalizar valor baixado dos lançamentos faturados pelo valor líquido" no formulário de parametrização financeiro.  Parâmetro desmarcado: a proporção é feita utilizando o valor baixado do vencimento de fatura.  Parâmetro marcado: a proporção é feita utilizando o valor líquido do lançamento faturado. |
| **Conversores e Parâmetros:** | Parâmetro : Proporcionalizar valor baixado dos lançamentos faturados pelo valor líquido |
