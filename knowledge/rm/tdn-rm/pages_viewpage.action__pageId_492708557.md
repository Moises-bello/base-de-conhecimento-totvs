# MONITOR DE OBRAS - Detalhes Mão de Obra

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Monitor de Obras - Detalhes Mão de Obra |
| **Situação/Requisito:** | Detalhes de Mão de Obra do Monitor de Obras no Portal do TOP. |
| **Solução/Implementação:** | Foi desenvolvido a página de Detalhes de Mão de Obra no Portal TOP.   * **Status Geral**   + **Funcionários Trabalhando**: Todos os membros da equipe que estão trabalhando.   + **Funcionários Ociosos**: Os Funcionários que estão presentes mas com improdutividade.   + **Total de Funcionários**: Funcionários Presentes + Funcionários Ociosos.   + **Horas Apontadas:**Total  de horas apontadas.   + **Horas Trabalhadas:**Total de horas apontadas.   + **Horas Improdutivas:**Total de horas improdutivas. * **Mão de obra - Status dos Funcionários**:   + **No Painel de Status de Funcionários serão exibidos os dados agrupado por Função:**     - **Trabalhando:**       * Quantidade de Funcionários Trabalhando em uma determinada função;     - **Ociosos:**       * Quantidade de Funcionários Ociosos em uma determinada função;     - **Adicionais:**       * Quantidade de Funcionário Adicionais Trabalhando em uma determinada função;     - **Motivo de improdutividade:**        * Motivos de Improdutividade, caso haja funcionário ocioso, ordenado por criticidade.   + **Agrupamentos por criticidade:**     - **Crítico:**        * Acima de 40% dos Funcionários ociosos ou 1 Motivo de Improdutividade crítico;     - **Atenção:**       * No intervalo de 21% a 39% dos Funcionários ociosos;     - **Em Operação:**        * Até 20% dos Funcionários ociosos;     - **Não Iniciado:**       * Funções que não foram iniciadas; * **Localização dos Funcionários**   + Localização geográfica dos Apontamentos realizados pelos funcionários. |
