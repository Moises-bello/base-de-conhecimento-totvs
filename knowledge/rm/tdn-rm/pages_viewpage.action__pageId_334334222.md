| **Ocorrência:** | Restrição de acesso de usuários  a filiais no TAF. |
| **Ambiente:** | Acesso de usuários |
| **Passo a passo:** | **Configuração de acesso de usuários TAF.**    Caso deseje que o usuário tenha acesso a uma ou mais filiais específicas realize a parametrização abaixo:  1- Acesse o TAF e clique no menu Miscelânea > Usuários.      2 - Selecione e edite o usuário que deseja parametrizar o acesso as filiais;    3 - Acesse a aba Restrições de acesso e depois a aba ambiente e verifique se o usuário possui permissão para o SIGATAF conforme imagem abaixo:    4 - Ainda dentro do cadastro do usuário clique na aba Restrições de Acesso em seguida na aba Filiais e selecione quais filiais o usuário terá acesso.    **Atenção:** Verifique no final da tela se o parâmetro “Todas as Empresas” Está marcado e caso esteja é necessário desmarca-lo para que as restrições sejam efetivas.  Após realizar as parametrizações acima acesse o TAF com o usuário em questão e verifique se o usuário possui acesso somente as seções. |
