# Processo Agendamento/envio de mensagens

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Processo Agendamento/envio de mensagens |
| **Situação/Requisito:** | Ao acessar o processo de Agendamento/envio de mensagens, selecionar uma mensagem pré-configurada e alterar o texto, ao avançar no processo e voltar, a funcionalidade estava alterando o texto para a mensagem inicial perdendo o texto alterado pelo usuário. |
| **Solução/Implementação:** | Foi realizado uma otimização no processo, de maneira que a funcionalidade não altere o texto do usuário ao avançar ou retornar na aba do processo. |
