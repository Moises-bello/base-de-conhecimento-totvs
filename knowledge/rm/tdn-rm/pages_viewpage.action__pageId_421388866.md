O cálculo automático do dígito verificador tem como objetivo facilitar o tratamento para o débito automático, sem necessidade do cadastro manual dos dados para cada cliente fornecedor que optar por esta forma de pagamento. Conforme manual de retorno de débito automático do CNAB 150 da Febraban, foi implementado o processo de ajuste na base para calcular o dígito verificador do débito automático.

**Processo para calcular Dígito Verificador de débito automático do cliente/fornecedor**

Após executar o processo, os clientes fornecedores existentes e os novos cadastrados, terão o dígito verificador calculado automaticamente.

**Obs**:

A tabela de Cli/For (FCFO), é a principal envolvida no Processo para Calcular o dígito verificador de débito automático.
