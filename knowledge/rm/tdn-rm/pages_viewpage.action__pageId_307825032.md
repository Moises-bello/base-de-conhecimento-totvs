# Lançamento incorreto no xml

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento para Convênios |
| **Situação:** | Quanto uma taxa tem sua unidade em minutos, o sistema está lançando como gasoterapia mesmo que ela não esteja configurada na faixa de codificação de gasoterapia. |
| **Solução:** | Ajuste realizado para que o sistema faça a geração do arquivo xml de faturamento, levando em consideração a faixa de codificação da despesa. |
