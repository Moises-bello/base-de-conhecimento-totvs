**Dúvida**É possível que verba de 1\3 férias Id 0077 incida somente para o INSS segurado (empregado), desconsiderando para o INSS empresa?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoas - Todas as versões  
  
**Solução**Não. Toda verba contendo **Sim** para INSS será considerada para a **base INSS**, desta maneira o valor fará parte para cálculo do INSS segurado (desconto funcionário) e INSS empresa.
