# Validação para Incluir Linha na Planilha

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Criar nova Linha em Planilha de Atividades |
| **Situação/Requisito:** | Ao utilizar a opção INCLUIR LINHA o sistema criar uma nova etapa com o código da anterior e altera o código da anterior. Entretanto o sistema não muda as tarefas filhas, fazendo com que elas agora sejam filhas da nova etapa, não acompanhando a etapa pai. |
| **Solução/Implementação:** | Criação de validação para a opção de Incluir Linha na Planilha, esta validação será exibido quando a planilha se encontra com tarefas/etapas não exibidas devido ao filtro utilizado |
