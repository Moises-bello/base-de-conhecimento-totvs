# Como utilizar o Autotexto para Laudo de Exames

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.8x e 12.1.x |
| **Ocorrência:** | O que é e para que serve o Autotexto para Laudos de Exames |
| **Passo a passo:** | O Autotexto para Laudo de Exames, tem a finalidade de ser uma substituição automática da digitação do código Mneumônico do exame.  **1º Passo)** Configurar o código Mneumônico.  Acesse o menu Cadastros / Unidade Diagnóstico / Autotexto para Laudos de Imagem  Clique no botão “Incluir”  Digite o código Mneumônico desejado e escreva o texto que será carregado ao citá-lo.    **2º Passo)** Digitação de Laudos  Acesse o menu Unidades Diagnóstico / Controle de Pedido de Exames  Selecione um exame, cujo código Mneumônico seja o que você realizou a substituição.  Espere carregar o laudo.  No status “Em Digitação”, coloque o mouse onde gostarias que o texto aparecesse  Digite o código Mneumônico onde na imagem está destacada em vermelho e clique no botão destacado em preto.    **3º Passo)** Veja o resultado |
