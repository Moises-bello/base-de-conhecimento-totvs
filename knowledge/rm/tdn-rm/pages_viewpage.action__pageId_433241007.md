# Processo de Associação Ajuste SPED x Natureza de Operação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Associação Natureza de Operação x Código Ajuste Fiscal |
| **Situação/Requisito:** | Criação da Associação da Natureza de Operação com o Cadastro de Ajuste do Sped Fiscal. |
| **Solução/Implementação:** | Foi implementado um Cadastro para Associação de Códigos de Ajuste às Naturezas de Operação.  Foi implementado também um Processo para que esta associação possa ser feita.  **Permissão:**  A permissão a esta associação esta vinculada a mesma permissão do Cadastro de Ajuste Sped Fiscal.  Está associação (Processo/Inclusão Manual) está disponível na visão do Cadastro de Natureza de Operação.  **Cadastro de Associação**    Neste cadastro o usuário poderá associar vários Códigos de Ajuste a uma determinada Natureza de Operação.  **Regras:**  Apenas Naturezas Analíticas porem ser associadas.  Não poderá associar o mesmo Código de Ajuste na mesma Natureza de Operação.  **Processo de Associação**    Processo criado para facilitar a associação, podendo o usuário associar ou desassociar vários Códigos de Ajuste a várias Naturezas de Operação ao mesmo tempo.  Para a associação as regras para vinculação serão as mesmas da Inclusão manual. |
