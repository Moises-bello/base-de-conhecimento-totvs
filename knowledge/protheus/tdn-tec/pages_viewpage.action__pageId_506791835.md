A página mp.htm está sendo carregada normalmente quando configurada a opção BrowserEnabled.

|  |  |
| --- | --- |
| Situação | A página mp.htm não é carregada. |
| Ocorrência | Ao iniciar o ERP com a opção BrowserEnabled a página mp.htm não é carregada. |
| Correção | Foi corrigido o carregamento da página. |
| Informações adicionais | * Referente à ocorrência: MTEC-2836 * Disponível em builds superiores a 17.3.0.10 |
