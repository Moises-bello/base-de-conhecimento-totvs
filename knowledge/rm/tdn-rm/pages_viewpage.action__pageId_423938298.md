Através deste Processo é possível aplicar um Grupo de Clientes/Fornecedores aos Produtos marcados.

**Incluir/Excluir:** Neste campo é marcado se a operação será para Incluir ou Excluir o Grupo de Cliente/Fornecedor dos Produtos selecionados.

**Grupo de Cliente/Fornecedor:** Neste campo seleciona-se o Grupo de Cliente/Fornecedor para o Produto, no qual estão incluídos os Cli/For's a serem adicionados aos Produtos selecionados.
