![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24789535415831) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Qual data é preenchida no campo emissão do ASO?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as Versões  
  
**Solução**Na rotina Atestado ASO (MDTA200 ), menu *Atualizações - Atendimento Médico - Atestado ASO*, tem o campo Data Emissão (TMY\_DTEMIS).

![](https://centraldeatendimento.totvs.com/hc/article_attachments/12888843648791)  
  
Por padrão, o campo fica em branco e assume a data base do sistema quando o ASO é impresso, conforme leiaute do eSocial.

![](https://totvssuporte.zendesk.com/attachments/token/7ZTnDfp4OsRHHMM9DAESd1PW1/?name=image.png)  
  
**Observação**: O campo Data Emissão fica habilitado para preenchimento manual ao incluir o ASO, porém, sugerimos que deixe em branco para o sistema considerar a data base do sistema e respeitar a regra do leiaute do eSocial.  
  
Caso tenha duvidas referente aos campos do ASO segue documentação:
