# 1 - Síntese

Foram desenvolvidos scripts para padronizar os valores default dos campos complementares da matrícula no período letivo.

* Categoria: 5 – Comunidade
* EBEP?: 0 – Não
* Vira Vida?: 0 – Não
* Tempo Integral?: 0 – Não
* Gratuidade: 0 – Não
* Código do Financiamento (SCAE): 1 – Pago

Figura 1 – Cadastro de campos complementares da matrícula no período letivo

# 2 - Processo para execução dos scripts

Os scripts devem ser executados diretamente no banco de dados SGE utilizando o usuário ‘rm’ para conexão com a base. O regional deve executar o script referente ao seu SGDB (Oracle ou SQL Server).
