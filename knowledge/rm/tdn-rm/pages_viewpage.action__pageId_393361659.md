# Gerar SPED Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Contábil. |
| **Função:** | Gerar SPED Contábil. |
| **Situação/Requisito:** | Ao gerar o SPED Contábil sem informar um plano de contas consolidado, alguns registros referentes ao Bloco K estão sendo gerados indevidamente. Esse tipo de registro só deve ser gerado quando o plano de contas consolidado for informado no momento de geração do SPED. |
| **Solução/Implementação:** | Manutenção efetuada na geração dos registros referentes ao bloco K relacionados ao não preenchimento do plano de contas consolidado na geração do SPED. Neste caso nenhum registro referente ao bloco K deverá ser informado. |
