# Descrição

---

Tipos de planilhas suportados pela API. Ao salvar uma planilha o usuário poderá fazer a conversão para qualquer um dos tipos desse enumerador.

|  |  |
| --- | --- |

| Excel8 | Formato de arquivo do MS Excel (97, 2000, 2002, XP e 2003). (.xls) |
| OpenXML | Formato de arquivo do MS Excel 2007 (Open XML). (.xlsx) |
| OpenXMLWithMacro | Formato de arquivo do MS Excel 2007 com macro habilitada (Open XML). (.xlsxm) |
