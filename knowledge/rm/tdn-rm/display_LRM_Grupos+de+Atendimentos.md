**Grupos de Atendimentos**

Trata-se de um agrupador dos tipos de atendimentos:  
   
  
   
   
Para facilitar a abertura e o gerenciamento dos atendimentos está disponível no sistema os grupos de atendimentos, que agregam de maneira macro assuntos que podem ser relevantes para a empresa. Por sua vez, os grupos de atendimentos podem ser segmentados por tipos de atendimentos que visam dividir o assunto ampliado em partes menores para resolução dos mesmos além de classificá-los e determinar o fluxo de trabalho (Workflow) que o atendimento percorrerá no sistema.  
   
Os grupos são montados de acordo com suas características ou paridades que auxiliam na busca de informações de forma eficaz e ágil. Este cadastro é de suma importância para relacionar os atendimentos, mas de interface simples no cadastramento:

* Basta informar o nome do grupo (obrigatório) e uma breve descrição (optativo) para que o registro seja salvo com sucesso. O código é gerado automaticamente pelo sistema.
