# Login no eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Login eduCONNECT |
| **Situação/Requisito:** | O login no eduCONNECT era bloqueado dependendo de qual contexto o usuário setasse no Corpore.NET, ou seja, poderia haver situações onde o usuário que estivesse definido com um contexto cujo perfil naquela coligada não permitisse acesso ao eduCONNECT, e daí era retornada uma mensagem de erro de permissão. |
| **Solução/Implementação:** | Aperfeiçoamento da verificação da segurança de acesso ao Educamobile, de forma que é verificada apenas a permissão em algum perfil do usuário para que este tenha acesso. |
