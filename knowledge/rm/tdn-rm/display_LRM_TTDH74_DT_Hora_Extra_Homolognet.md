# HOMOLOGNET

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Homolognet* |
| **Situação/Requisito:** | Funcionário possui dois eventos de horas extra, 100% e 50% utilizando a mesma rubrica, ao gerar arquivo Homolognet para o mesmo o sistema não está considerando o evento de hora extra 100% |
| **Solução/Implementação:** | Otimizado homolognet, de forma que as rubricas de hora extra sejam repetidas a cada ocorrência, possibilitando que sejam levadas para o arquivo mais de uma ocorrência de hora extra. |
