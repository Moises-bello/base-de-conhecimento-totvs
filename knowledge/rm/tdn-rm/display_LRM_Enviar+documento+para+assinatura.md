Enviar documento do aluno para assinatura com o **TOTVS Assinatura Eletrônica**.

false

Essa funcionalidade está disponível a partir do patch: 12.1.2402.

Para acessar o processo de integração é necessário que **RM** esteja devidamente parametrizado. **Para saber mais acesse** [Integração com TOTVS Assinatura Eletrônica](https://tdn.totvs.com/x/yCOOIQ).

Para conhecer o **TOTVS Assinatura Eletrônica** [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=605018639).

### 1.0 - Configuração Integração com o TAE e configuração do documento

A instituição de ensino pode configurar os documentos para que sejam integrados ao **TOTVS Assinatura Eletrônica**. Saiba mais em [Documento](https://tdn.totvs.com/display/LRM/Documento).

### 2.0 - Monitor de documento - Visualizar a relação de documentos que foram integrados ao TOTVS Assinatura Eletrônica

### 3.0 - Permissão de acesso ao Processo de envio de documento para assinatura

### 4.0 - Processo de envio de documento para assinatura

Ao executar este processo, o documento selecionado será enviado para o **TOTVS Assinatura Eletrônica**, com o(s) destinatário(s) de assinatura previamente definido(s) no cadastro do documento.

Filtros enviados para o relatório

Cada relatório deve possuir os campos obrigatórios para a correta emissão. Os filtros são aplicados automaticamente pelo sistema.

**Parâmetros obrigatórios**: CODCOLIGADA, RA

### 5.0 - Assinatura do documento

Os destinatários devem acessar seu e-mail e utilizar o token e o link para realizar a assinatura, conforme as orientações enviadas por e-mail. **Para saber mais, acesse** [TOTVS Assinatura Eletrônica](https://tdn.totvs.com/x/fvccJ) na opção de **Funcionalidades | Fluxo do Usuário | Assinando um Documento |  Eletronicamente (Com com autenticação por envio de código por e-mail)**
