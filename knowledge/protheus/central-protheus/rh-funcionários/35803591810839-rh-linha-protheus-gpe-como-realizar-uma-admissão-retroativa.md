**Dúvida**  
É possível realizar uma admissão retroativa no Protheus?

**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões 

**Solução**  
A admissão retroativa é permitida no módulo 07 (GPE) do sistema. O cadastro do colaborador é realizado normalmente, da mesma forma que para uma admissão com data atual, sendo que a única diferença é a definição de uma data de admissão retroativa.

Contudo, é obrigatório enviar essa admissão retroativa ao eSocial. Para mais detalhes, consulte a documentação abaixo.
