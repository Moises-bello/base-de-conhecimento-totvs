# Alteração do Item de Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Alteração do Item de Baixa |
| **Situação/Requisito:** | Ao alterar as informações do Item de Baixa relacionadas a rateio Centro de Custo e/ou Departamento a tela não avisa que as mesmas podem ter sido utilizadas na contabilização como é feito hoje na visão de edição do Lançamento. |
| **Solução/Implementação:** | Melhoria na validação para que ao abrir as telas de rateio Centro de Custo e/ou Departamento o sistema avise que essa informações podem ter sido utilizadas na contabilização e sugerir a regerar no momento de salvar o Item de Baixa |
| **Conversores e Parâmetros:** | N/A |
| **Chamados relacionados:** | N/A |
| **Requisito (ISSUE):** | FINTRF000217 |
