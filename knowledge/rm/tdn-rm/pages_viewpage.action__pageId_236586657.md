# Visualizar autor do período cadastrado

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Agenda | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER e ORACLE |
| **Tabelas Utilizadas:** | SZPERIODOESP |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Foram implementadas colunas, para visualização do o autor que criou o período (**Usuário Inclusão**) e a data de criação (**Data**).

## Procedimento para Utilização

1. Acesse a **Agenda de atendimentos** e selecione uma agenda disponível.
2. Clique em **Opções** e acesse a aba **Períodos Especiais**.
3. Insira um período e ao voltar para a tela de Períodos Especiais, clique em **Salvar**.
4. As informações serão exibidas juntamente com o as novas colunas "**Usuário Inclusão**" e "**Data**".
