# GERAÇÃO DE USUÁRIO PARA PROFESSOR UTILIZANDO A CHAPA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de Usuário para Professor Utilizando a Chapa* |
| **Situação/Requisito:** | *A geração automática de usuários de professor está ativada e o modo de geração de usuários está definido por chapa. Porém, ao tentar cadastrar novo professor, o sistema gera a seguinte mensagem de erro: "Usuário não criado. O professor não possui chapa para geração do código".* |
| **Solução/Implementação:** | *Ajuste no cadastro de professor para que quando inserir um novo professor utilizando um funcionário ativo no sistema que seja inserido também ele no cadastro da filial do professor, ou seja, será inserido a chapa do funcionário no cadastro de filial dele. Com isso, será possível neste momento a geração automática do usuário utilizando a chapa.* |
