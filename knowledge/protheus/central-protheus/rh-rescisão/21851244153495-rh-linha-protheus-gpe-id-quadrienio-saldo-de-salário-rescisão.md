![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21851244137239) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Existe ID especifico de quadriênio saldo de salário rescisão?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Não existe ID especifico de quadriênio saldo de salário rescisão. O quadriênio saldo de salário se trata do adicional mês assim pelo padrão em rescisão será calculado no id 0004.
