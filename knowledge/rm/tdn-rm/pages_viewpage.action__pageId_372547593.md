# CADASTRO DE TURMA/DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cadastrar Turmas/Disciplinas |
| **Situação/Requisito:** | Foi verificado que ao selecionar duas turmas com a mesma grade e curso para rodar o processo de Cadastrar Turmas/Disciplinas, o sistema estava gravando as disciplinas das duas matrizes para ambas as turmas. Isso acontecia porque o sistema não estava verificando a habilitação na hora de gravar. |
| **Solução/Implementação:** | O processo de Cadastrar Turmas/Disciplinas foi alterado para verificar a habilitação na hora de gravar as disciplinas. |
