![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: 00**:10:00min****Ocorrência**Importação MILE não funciona para Produto x Fornecedor.  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Compras - A partir da release 12.1.27.  
  
**Causa**Ao analisar o processo o sistema não trata mais a rotina do MILE para produto x fornecedor, pois foi descontinuada e alterada para a MATA061 gerando assim algumas limitações na rotina.  
  
**Solução**Como solução, possuímos o tratamento via rotina automática, onde a mesma permite a inclusão/alteração/exclusão em massa dos cadastros de produto x fornecedor.

**Observação:** Para realizar a opção de alteração e/ou exclusão é necessário que deixe posicionado no registro a ser alterado ou excluído.
