Como realizar o bloqueio da opção de editar batidas manuais?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - MEU RH - todas as versões  
  
**Solução**  
1. Para realizar o bloqueio da opção de editar batidas manuais, deve ser realizado através da rotina **TCFA006**, rotina de permissões no módulo 18 (**SIGATCF**). Acesse o menu **> Atualizações > Configurações > Usuários > Permissões.**![j7obevYYmH.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4422437357719)  
  
Caso não tenha a rotina configurada no menu, seguir o passo a passo do link abaixo para criação:  
  
[Configuração de permissão de acesso as funcionalidades e menu do MEU RH](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360033892693-RH-Linha-Protheus-MEU-RH-Configura%C3%A7%C3%A3o-de-permiss%C3%A3o-de-acesso-as-funcionalidades-e-menu-do-MEU-RH?source=search)  
  
2. Selecione o usuário genérico e altere a permissão "**Editar Batidas Informadas**" para "**Não**" caso deseje bloquear a opção para o trabalhador.  
  
**OBS:** Este usuário genérico é vinculado no cadastro do participante, ou seja, é importante verificar qual usuário esta sendo alterado para surtir efeito quando o trabalhador acessar o MEU RH.  
  
![KCzirz9LN1.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4422438037911)  
  
3. Ao realizar o acesso no espelho de ponto e tentar editar a batida, não será apresentada a opção de "Editar batidas".
