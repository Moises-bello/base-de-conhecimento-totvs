Com intuito de facilitar a customização das imagens que serão exibidas no novo portal do processo seletivo, foi criado o cadastro de Banner, onde será vinculado as imagens por processo seletivo, ou seja, cada processo seletivo pode ter sua lista de banners.

##### Configuração do Banner a ser exibido no Portal

**1-** Acessar o cadastro de Banner para realizar a configuração a ser exibido no portal:

 **TOTVS Processo Seletivo| Cadastros| Processo seletivo| Anexos| Banner**

**Parâmetro Ativo:** Este parâmetro determina que o banner está ativo ou não, através deste parâmetro que o usuário determina se o Banner será apresentado no portal;

**Imagem:** O campo imagem tem como objetivo determinar qual a imagem será exibida no portal;

**Titulo:** O Título que aparecerá sob a imagem a ser ser configurada;

**Link:** Caso deseja redirecionar o Candidato para outra página, informar o link neste campo;

**Data Inicial :** A data inicial determina a data em que o Banner será apresentado no portal. A data inicial é preenchida automaticamente de acordo com a data corrente, mas é possível informar uma data anterior ou posterior a data atual;

**Data Final:** A data final determina o dia em que o Banner será apresentado no portal;

**Ordem:** O campo ordem tem como objetivo definir a ordem de apresentação do mural.
