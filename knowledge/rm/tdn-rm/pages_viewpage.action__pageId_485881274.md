**Menu**: Relatórios | Contratos | Contratos

Permite a execução de relatórios relacionados a contratos que possuem o tipo Contratos (10015).

**Relatórios Disponíveis**

Informações Técnicas

Os parâmetros abaixo são utilizados no relatório e podem ser utilizados na confecção de outros.

| **Parâmetro** | **Descrição** | **Tipo** |
| --- | --- | --- |
| CODCOLIGADA | Código da Coligada | inteiro |
| CODPRJ | Código do Projeto | string |
| NUMCONTRATO | Número do Contrato | string |
| PERMEDINI | Período Inicial | string |
| PERMEDFIM | Período Final | string |
