# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de lançamentos |
| **Situação/Requisito:** | Ao gerar um lançamento financeiro que aproveita valores da conta corrente e exista uma fórmula cadastrada em algum valor opcional do financeiro que dependa de algum valor do lançamento que está sendo gerado, o cálculo do valor líquido, feito pelo aproveitamento da conta corrente, pode não ser concluído com sucesso, gerando falha ao gerar o lançamento. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de lançamentos, permitindo ao sistema, aproveitar valores em conta corrente quando existir uma fórmula cadastrada em algum valor opcional do TOTVS Gestão financeira que dependa dos valore do lançamento que está sendo gerado. |
