![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32588132503191) Tempo aproximado para leitura: **00:01:20 min****Dúvida**Quais são as licenças que o **Protheus** **TMS** utiliza?  
  
**Ambiente**TOTVS Logística - TOTVS TMS (Linha Protheus) - Gestão de Transportes (TMS) - Todas as versões  
  
**Cenário**Ao acessar as rotinas do **módulo 43 - Protheus TMS**, temos a mensagem de **Excedeu número de licenças.**Essa mensagem ocorre quando o cliente não possui licenças necessárias para utilizar o módulo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/32589023856791)

**Solução**Para acessar o **módulo 43 - Protheus TMS** é necessário possuir uma das licenças a seguir, **ID Licença**: **4171, 3999, 4016, 4017, 4032, 4046, 4047, 4000 ou 4099.**  
  
Para validar, acesse o Gestão de Licenças no Portal do cliente e verifique os IDs de licenças citados, ou então, verifique no monitor do *License Server* se existe uma das licenças citadas disponível para uso.  
  
Caso tenha alguma dúvida, quanto as licenças disponíveis para uso, entre em contato com seu gerente de Contas para tratar a questão de necessidade de acesso versus licenças contratadas.  
  
Após validar as licenças com seu gerente de Contas, e possua uma das licenças listadas para o TMS e ainda assim ocorrer o erro, entre em contato com suporte do Protheus Framework.
