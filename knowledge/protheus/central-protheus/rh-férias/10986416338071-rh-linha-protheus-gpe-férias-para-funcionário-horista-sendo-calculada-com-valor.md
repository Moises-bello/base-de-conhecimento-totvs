![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32036560303383) Tempo aproximado para leitura: **00:01:00 min** **Ocorrência**Férias para funcionário horista sendo calculada com o valor errado.  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - Todas as versões  
  
**Causa**  
Funcionário com o campo Jornada Variável preenchido com SIM indevidamente.  
  
**Solução**O funcionário horista com Jornada Variável é aquele cuja quantidade de horas trabalhadas no mês sofre variações de acordo com a necessidade de suas atribuições, portanto, se o seu funcionário horista **sempre cumpre a mesma carga horária** de acordo com os meses (horário fixo), faça o ajuste abaixo:  
Na rotina **Funcionários**, pelo caminho **Atualizações >Funcionários >Funcionários**, para o funcionário em questão, altere o campo **Jor. Variável** para **Não** na aba **Funcionais**:
