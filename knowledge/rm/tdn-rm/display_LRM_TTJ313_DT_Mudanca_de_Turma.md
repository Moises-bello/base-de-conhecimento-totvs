# Mudança de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Mudança de turma* |
| **Situação/Requisito:** | *Após ajustes anteriores, caso a data de matrícula da disciplina na turma de origem não estivesse preenchida, a disciplina na turma de destino também não teria a data de matrícula informada.* |
| **Solução/Implementação:** | *Ajustes no processo de mudança de turma. No contexto de ensino básico, ao executar o processo, será exibido um novo passo, solicitando ao usuário que informe qual a data deverá ser assumida pela disciplina na turma de destino.*  *As opções são:*   * *Data de matrícula da disciplina na turma de origem.* * *Data de matrícula do período letivo.* * *Data de execução do processo.*   *Caso não seja possível utilizar a data selecionada o processo assumirá a próxima opção disponível.* |
