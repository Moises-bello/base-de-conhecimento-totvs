# Cadastro de Conta Contábil/Gerencial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro de Conta Contábil/Gerencial |
| **Situação/Requisito:** | Ao criar nova conta contábil o sistema procura as lacunas de código reduzido para inserir a informação. De acordo com o cliente o reduzido seguia a sequência de códigos e a partir das novas versões não mais efetua a operação desta forma o que gera desorganização no plano de contas. |
| **Solução/Implementação:** | Melhoria no processo de cadastro de Código Reduzido de Contas Contábil/Gerencial para que o usuário tenha a opção parametrizável de gerar o código sequencialmente preenchendo ou não as lacunas que ficam após a exclusão de alguma conta. |
