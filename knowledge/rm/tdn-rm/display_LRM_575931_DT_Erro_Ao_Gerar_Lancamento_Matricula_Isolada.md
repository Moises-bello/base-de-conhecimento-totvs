# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de lançamentos financeiros* |
| **Situação/Requisito:** | *Ao verificar se o aluno possui currículo individual, o sistema espera que as parcelas do contrato do aluno estejam associadas a uma matriz curricular, o que causa erro caso o aluno possua uma matrícula isolada, pois o contrato não está associado a uma matriz aplicada.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de lançamentos, permitindo ao sistema, gerar lançamentos para parcelas de contratos sem vínculo com uma matriz aplicada.* |
