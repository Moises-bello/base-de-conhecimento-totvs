**Resumo do Projeto**

---

O Resumo de Projeto auxilia o usuário a visualizar as informações relativas a valores do projeto. Para acessar o Resumo de projeto basta acessar Menu Projeto | Resumo do Projeto ou em anexos da Planilha de Atividade ou Planilha de Serviços.    
 O resumo do projeto se divide em:

* **Gestão de Risco:**
  + Custo Medidas Riscos Ameaça;
  + Custo Medidas Riscos Oportunidade;
  + VME Riscos Ameaça;
  + VME Riscos Oportunidade;
  + VME Projeto com Riscos;
  + Valor do Projeto no Pior Caso;
  + Projeto no Melhor Caso;
* **Cenários:**
  + Valor da planilha;
  + Valor da planilha (sem BDI);
  + Total indireto;
  + Valor do BDI;
  + Avanço físico;
  + Valor da receita do projeto;
  + Último cálculo da curva S;
  + Último cálculo da curva ABC;
* **Projeto:**
  + Identificador do Projeto;
  + BDI;
  + Data Ultimo Cálculo;
  + Nome (descrição do Projeto);

As informações somente aparecerão para Cenários recém-calculados. Para uma melhor visualização agrupe pelo campo Entidade, que identifica as informações de cada planilha.  
 Para que o Resumo do Projeto fique habilitado é necessário que o usuário esteja conectado a um Projeto.   
 É necessária permissão de acesso para visualizar o Resumo do Projeto. Para conceder ou retirar a permissão acesse em Cadastros Gerais | Segurança| Perfis e na aba Acesso a Menus | Projetos | Básico | Resumo do Projeto, conceder ou retirar a permissão da funcionalidade.
