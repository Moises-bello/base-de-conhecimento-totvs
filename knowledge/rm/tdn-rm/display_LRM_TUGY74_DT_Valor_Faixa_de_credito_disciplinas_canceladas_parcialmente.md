# CONSIDERAR VALOR DA FAIXA DE CRÉDITO QUANDO AS DISCIPLINAS SÃO CANCELADAS PARCIALMENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | **Geração de Lançamentos** |
| **Situação/Requisito:** | Sistema não estava considerando os valores da faixa de crédito quando se tinha uma disciplina cancelada parcialmente utilizando o parâmetro da situação de matrícula de abater os valores das  disciplinas para parcelas com vencimento igual ou posterior à data de alteração de matrícula |
| **Solução/Implementação:** | Ajuste para considerar o valor da faixa de crédito nas disciplinas canceladas parcialmente. Sistema estava considerando o valor informado na matriz curricular |
