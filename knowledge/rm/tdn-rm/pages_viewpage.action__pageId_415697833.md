# MATRÍCULA DE DISCIPLINAS EM LOTE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Educacional |
| **Função:** | Matrícula de Disciplinas em Lote |
| **Situação/Requisito:** | Ao matricular os alunos nas disciplinas através da opção "Matrícula de Disciplinas em lote", a Turma do aluno no Período Letivo (SMATRICPL) estava sendo alterada para a turma da primeira Turma/Disciplina selecionada. |
| **Solução/Implementação:** | Realizado ajuste no processo de "Matrícula de Disciplinas em lote" para manter a turma no período letivo, no contexto do Ensino Superior, mesmo com matrículas em disciplinas com turmas diferentes. |
