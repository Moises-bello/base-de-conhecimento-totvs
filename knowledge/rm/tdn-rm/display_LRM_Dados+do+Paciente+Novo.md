PaineçVisão Geral

## **VISÃO GERAL**

Na etapa "Dados do Paciente" será possível declarar que o agendamento será para o usuário logado no Portal do Paciente ou para outra pessoa. Se o agendamento for para o usuário logado, o sistema irá carregar automaticamente os dados do mesmo no formulário. Sendo o cadastro para outra pessoal, o usuário será responsável por informar todos os dados necessários.

**Importante**:

Entendemos que o agendamento para outra pessoa será de um dependente do usuário o qual está logado no Portal do Paciente, sendo de total responsabilidade do usuário ter posse de dados pessoais e sensíveis da outra pessoa.

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Logar no Portal do Paciente e abrir a página de "Agendar". Se o agendamento for para o usuário logado, apenas marcar o aceite de termos de serviço e política de privacidade. Para os casos de agendamento para outra pessoa, o usuário deverá preencher o formulário com as informações necessárias, atendendo os requisitos mínimos, como:

* Todos os itens obrigatórios devem ser preenchidos (os itens obrigatórios são marcados com um \*);
* Atender os critérios de validação de CPF, Telefone, e E-mail;
* Concordar com os Termos de Serviço;
* Concordar com a Política de Privacidade.
Para Mim

## **PARA MIM**

01. Ao abrir a página de "Agendar", o sistema irá apresentar a etapa "Para quem deseja agendar" e, por padrão carregará os dados do usuário logado, não sendo permitido a edição de nenhuma informação.

02. Após concordar com os termos de serviço e política de privacidade, o botão "Próximo" ficará habilitado para seguir com o processo de agendamento.

03. A etapa "Dados do Convênio" é carregada.

Para outra Pessoa

## **PARA OUTRA PESSOA**

01. Ao clicar no botão "Para outra pessoa", o formulário será limpo, cabendo ao usuário preencher corretamente com todas as informações necessárias a qual o agendamento está sendo realizado.

02. Após preencher os dados e concordar com os termos de serviço e política de privacidade, o botão "Próximo" ficará habilitado para seguir com o processo.

03. O sistema irá validar os dados informados e, caso não seja possível encontrar um paciente cadastrado, o processo será interrompido e o usuário notificado. Se o usuário clicar em "Não", o processo ficará parado na etapa atual. Se o usuário clicar em "Sim", o sistema irá efetuar o cadastro do paciente e seguirá para a etapa seguinte.

04. A etapa "Dados do Convênio" é carregada.
