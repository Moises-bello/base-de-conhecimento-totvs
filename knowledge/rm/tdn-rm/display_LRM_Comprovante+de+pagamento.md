Comprovante com informações de pagamentos de **Cartão de crédito** e **PIX.**

Este comprovante poderá ser visualizado ou compartilhado.

Poderá ser acessado através da tela de extrato financeiro ou da tela de pagamento com sucesso quando um título é pago com cartão de crédito.

## 

Visualização

Os dados de pagamentos via cartão de crédito ou PIX serão visualizados caso o pagamento tenha sido confirmado ou concluído.

## **TABELAS UTILIZADAS**

* FCARTEIRADIGITAL - Tabela de carteira digital
* GENDERECO - Contém os dados de endereço do cartão
* FINTEGRACAOCARTAO - Tabela com dados de transação
* FBOLETO - Tabela com dados do boleto

Dados do cartão não serão armazenados na base de dados para maior segurança dos usuários.IMPORTANTE!
