**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)** Tempo aproximado para leitura: **00:01:40 min****Dúvida**Algumas rotinas do TOTVS Folha de Pagamento demandam a verificação e às vezes alteração da extensão dos arquivos gerados pelo módulo. No entanto, nem todos os usuários têm sua máquina configurada para demonstrar a extensão dos arquivos. Como se faz a alteração das extensões?  
 **Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Na caixa de pesquisas do Windows, realize a busca pelo Painel de Controle:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018510521/mceclip0.png)  
  
2. No campo "Exibir por:" selecione a opção Categoria e acesse o menu Aparência e Personalização:  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018221082/mceclip1.png)  
  
3. Acesse Opções do Explorador de Arquivos e, nesta tela, acesse Modo de Exibição, desmarcando a flag **Ocultar as extensões dos tipos de arquivo****conhecidos**:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018510661/mceclip2.png)  
  
4. Após aplicar a alteração, os arquivos agora demonstrarão sua extensão ao fim de seu nome, podendo renomear e alterar para a extensão desejada:  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018221302/mceclip3.png)  
  
5. Uma situação bastante comum é realizar a alteração do Arquivo em formato .TXT para .CSV, essa alteração muda o formato do arquivo para importação junto ao Empregador Web para Usuários que geram o arquivo através do Layout do B.E.M pelo RM.  
  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018221362/mceclip4.png)
