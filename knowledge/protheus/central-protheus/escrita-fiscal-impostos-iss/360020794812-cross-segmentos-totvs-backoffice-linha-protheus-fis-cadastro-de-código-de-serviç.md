**Dúvida**Quais os procedimentos para cadastrar códigos de serviço do ISS na rotina MATA943 (Cadastro de Código de Serviço do ISS).  
  
**Ambiente**  
Protheus – Livros Fiscais – A partir da versão 11.80  
  
  
**Solução**Está disponível a opção para Cadastro de Código de Serviço do ISS (MATA943), para que sejam utilizados códigos com nove caracteres.
