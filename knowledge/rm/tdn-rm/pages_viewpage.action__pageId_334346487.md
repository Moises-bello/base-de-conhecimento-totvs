# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Solicitação de Atendimento |
| **Situação/Requisito:** | Geração de lançamento a partir do processo de solicitação de atendimento via executável (Educacional | Atividades Acadêmicas | CRM | Solicitações) está gerando valores diferentes se comparado a execução do processo via portais. |
| **Solução/Implementação:** | Quando o parâmetro "Substituir todos os valores atuais pelos do modelo do tipo de atendimento" (definido no cadastro do tipo de atendimento utilizado na solicitação) estiver desmarcado o valor do lançamento gerado pelo processo será o valor definido no anexo de local de entrega somado ao valor definido para o serviço, caso contrário, será apenas o valor do local de entrega. |
