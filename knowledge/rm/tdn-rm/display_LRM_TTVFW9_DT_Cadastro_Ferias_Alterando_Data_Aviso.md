# CADASTRO DE FÉRIAS ESTÁ ALTERANDO A DATA DO AVISO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Férias* |
| **Situação/Requisito:** | *Foram lançadas férias coletivas informando uma data de aviso menos de 30 dias antes da data de inicio das férias.*  *Ao acessar o cadastro de férias, quando clica no botão Salvar, sem efetuar nenhuma alteração, a data de aviso é alterada para 30 dias antes da data de inicio.* |
| **Solução/Implementação:** | *Quando não ocorre nenhuma alteração no cadastro das férias, o sistema não pode efetuar modificações nos dados informados pelo usuário.*  *Ajuste na tela de cadastro das férias para somente preencher novamente a data de aviso quando houver alteração na data de início das férias.* |
| **Chamados   relacionados:** | *TTVFW9, TU2661* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
