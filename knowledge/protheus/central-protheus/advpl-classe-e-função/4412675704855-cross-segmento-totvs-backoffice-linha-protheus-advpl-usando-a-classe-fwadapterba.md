![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Usando a classe **FWAdapterBaseV2** é possível retornar uma lista de itens com subitens?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – Todas versões  
  
**Solução**Usando a classe **FWAdapterBaseV2** não é possível criar essa hierarquia desejada com subitens.  
Porém, por padrão você pode utilizar o **MVC** para criar seu serviço **Rest**.
