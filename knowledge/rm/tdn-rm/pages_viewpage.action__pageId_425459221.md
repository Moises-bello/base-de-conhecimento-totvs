O processo consiste em associar um perfil de usuário à alunos do TOTVS Educacional ou Classis Ensino Básico e Superior cadastrados no TOTVS Gestão Bibliotecária por meio do processo de importação de usuários.

 **O assistente está disposto em 4 etapas:**

* "Seleção do tipo de usuário";
* "Seleção de usuários";
* "Selecionar perfis";
* "Selecionar filiais/unidades de acesso dos usuários";

Importante: os alunos já devem estar cadastrados no TOTVS Gestão Bibliotecária. Os seguintes dados devem ser informados para a associação dos perfis:

* Qual perfil o aluno estará associado.
* Filiais/unidades que o aluno terá acesso.

A execução do processo consiste nas seguintes atualizações:

* Verificar se o usuário já tem um usuário Corpore RM associado. Caso não tenha, deve inserir as permissões e logo após associar os perfis conforme configurado no assistente.
* Durante a associação dos perfis, deve-se verificar antes de inserir o perfil configurado para o usuário se o perfil selecionado no assistente já está associado ao usuário. Caso não esteja, deve-se inserir o perfil configurado para o aluno.
* Configurar as permissões de acesso às unidades/filiais do TOTVS Gestão Bibliotecária para o usuário importado.

**O acesso a este processo é feito através do menu "Utilitários | Assistente Para Inclusão de Perfis Para Usuários (Alunos)".**

**Atenção:** para maiores informações a respeito de perfis de usuário Corpore acesse o help de Serviços Globais.
