# Habilitação Histórico Alterações

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | BackOffice |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Habilitação Histórico Alterações |
| **Situação/Requisito:** | Ao tentar realizar o processo de 'Habilitação Histórico Alterações' na aba de Utilitários, o sistema apresenta a seguinte mensagem de erro: "Incorrect syntax near the keyword 'WHERE'." |
| **Solução/Implementação:** | Otimização no processo de "Habilitação Histórico Alterações". A alteração foi para aplicar somente uma clausula WHERE na consulta do filtro. |
