# Verificação de Base de Dados sem que seja validado campos complementares

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | **TOTVS Folha de Pagamento** |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | *Folha mensal* | *Validação* | |
| **Versão/Release:** | *12.1.4* |

## Descrição

No processo de Validação, o flag “Desconsidera campos complementares” tem como objetivo desconsiderar os campos complementares no momento de sua execução.

## Procedimento para Utilização

Para que o usuário tenha acesso ao flag é preciso seguir o seguinte caminho. Acesse **Folha de Pagamento / Folha Mensal / Validações / Validação de Base de Dados.**

Durante o processo de “Verificação de base de dados”, irá aparecer a tela abaixo com o novo flag “Desconsidera campos complementares”.
