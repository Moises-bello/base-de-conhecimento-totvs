![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18520580434583) Tempo aproximado para leitura: **02:00 min** **Dúvida**É possível alterar o diretório de envio do arquivo para o despachante referente ao Embarque (rotina EICEI100)?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Dentro do Produto Padrão não é possível alterar o diretório referente a gravação dos arquivos de envio ao despachante, pois o mesmo é definido em fonte.
