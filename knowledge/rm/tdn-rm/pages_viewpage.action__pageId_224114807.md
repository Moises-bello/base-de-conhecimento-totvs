Integração Bancária - Remessa de Pagamento

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Integração Bancária - Remessa de Pagamento |
| **Situação/Requisito:** | Ao tentar realizar a baixa de um lançamento gerado pelo repasse o sistema apresenta a  mensagem: A baixa do lançamento de repasse X não pode ser feita. Baixa do lançamento ainda não está liberada. Porém o sistema está permitindo incluir este lançamento em borderô, consequentemente gerar a remessa. |
| **Solução/Implementação:** | Otimização no processo de inclusão do borderô ao lançamento. Agora o sistema não permite a inclusão/vinculo de um  lançamento gerado pelo repasse ao um borderô para consequentemente não poder gerar a remessa. |
