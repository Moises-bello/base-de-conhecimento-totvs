**Ocorrência**Como efetuar o cálculo de insalubridade utilizando, salário do cadastro + verbas com SIM para insalubridade como base de cálculo?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**Na versão 12 existem quatro formas diferentes de efetuar o cálculo de insalubridade.  
  
Salário Base  
Salário Mínimo  
Salário base + verbas  
Salário mínimo + verbas

**1**º Passo:

Cadastro de Sindicatos em **Atualizações > Cadastros > Sindicatos  (GPEA340)**;  
  
![Capturar.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/360016211332)

**2**º Passo:

Cadastro do Funcionários em **Atualizações > Funcionários > Funcionários (GPEA010)**;  
  
![Capturar.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/360016258571)

**3**º Conferência do cálculo  
  
![Capturar.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/360016211352)

**SALÁRIO BASE + HORA EXTRA 50% + DSR HORA EXTRA \* 20% = VALOR INSALUBRIDADE**

**R$3.600,00 + R$ 245,46 + R$37,76 = R$3883,22 \* 20% = R$776,64**

Na ultima coluna ele demonstra a base de calculo da verba. Podemos identificar que ele buscou a informação do salário base + VERBAS calculadas para o funcionário.  
  
Observação: **Para que as outras verbas como horas extras e faltas sejam consideradas para o calculo de insalubridade é necessário que no cadastro das mesmas o campo INSALUBRIDADE esteja com SIM.**
