**Dúvida**Por que o cálculo de rescisão apresenta o ID 1700-Insalubridade Médias Férias Aviso?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**O ID 1700-Insalubridade Médias Férias Aviso se trata da insalubridade referente a verba indenizatória Médias Férias Aviso, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1700.**
