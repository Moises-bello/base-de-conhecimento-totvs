# TROCA DE CHAPA NO CADASTRO DE PROFESSOR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Troca de chapa de um professor* |
| **Situação/Requisito:** | *O botão para a realização de troca de chapa de um professor somente era habilitado caso o mesmo tivesse duas ou mais chapas ativas.*  *No caso de um retorno a instituição com uma nova chapa, o sistema não permitia a sua troca.* |
| **Solução/Implementação:** | *A verificação para habilitação do botão de troca de chapa foi alterada para validar se há uma ou mais chapas ativas para o professor.*  *Dessa forma, será possível atualizar a chapa do professor quando um regresso com uma nova chapa.* |
