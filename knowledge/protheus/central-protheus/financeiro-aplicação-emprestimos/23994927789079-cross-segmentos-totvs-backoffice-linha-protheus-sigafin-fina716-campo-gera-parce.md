![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23994927777815) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como incluir um empréstimo quando o campo **Gera Parcela** está bloqueado para alteração?  
  
**Ambiente**Cross Segmentos - TOTVS Backoffice Protheus - Contas a Pagar - A partir da versão 11.  
  
**Solução**O campo "**Gera Parcela**" só liberado para incluir quando o tipo de operação for "**EMP**" ou "**TEM**" se for outro tipo de operação não será possível gerar parcela.
