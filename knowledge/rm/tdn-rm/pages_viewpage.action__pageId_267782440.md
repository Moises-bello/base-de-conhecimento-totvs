# Lançamento - Cancelamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento - Cancelamento |
| **Situação/Requisito:** | Ao cancelar três lançamentos financeiros gerados via Totvs Educacional e que estão vinculados ao mesmo Boleto,  o sistema conclui a operação, mas mantém o Nosso Número de apenas um dos lançamentos preenchido. |
| **Solução/Implementação:** | Otimização no processo de cancelamento de lançamentos vinculados ao mesmo boleto. Agora o sistema realiza o  processo corretamente conforme fosse executado por apenas um lançamento. |
