**Notas de Avaliação**

---

Observação: Para que a coluna \[Disponível para os Alunos?\] esteja visível no portal para o Professor/Coordenador, o perfil: "Liberar visualização da avaliação" deverá estar associado ao(s) usuário(s) do(s) mesmo(s). Caso esse perfil não esteja associado, esta coluna não estará disponível para visualização e o parâmetro: "Permitir a visualização das notas das avaliações e faltas somente após a liberação do professor" disponível em: Totvs Educacional | Configuração | Parâmetros | Secretaria | Notas/Faltas estiver habilitado.
 
Para auxiliar no processo de digitação das notas, é possível utilizar vários filtros para seleção dos alunos. Na digitação das notas, também é possível adicionar um comentário independente para cada aluno.
 
Detalhes como Situação do Aluno na turma/disciplina, nota da Etapa, data da Avaliação poderão ser facilmente visualizadas nesta página.
 
No campo Somatório, o professor pode inserir o valor total da soma de todas as notas dos alunos, desta forma é possível validar se as notas foram cadastradas corretamente e garantir que não houve erro de digitação.]]>

* Digitação de notas para avaliações do tipo numérico:
  + Número da nota menor que zero
  + Informar nota para uma etapa que não tenha pontos definidos
  + Informar nota maior que a nota máxima da etapa.
* Digitação de notas para avaliações do tipo conceitual:
  + Informar um conceito que não esteja previamente cadastrado no grupo de conceitos da etapa.

Após a digitação das notas dos Alunos, é possível realizar a liberação de visualização das notas para os   
alunos. Esta liberação não influencia no período de digitação, desta forma caso o professor libere a visualização para os alunos as notas poderão ser alteradas normalmente, desde que obedeça o período de digitação.  
   
**Observação:**   
   
Ao liberar a visualização de uma etapa o sistema liberará automaticamente a visualização de todas as avaliações relacionadas a esta etapa.
