# Logs Agendas de Atendimento e Cirurgias

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotinas:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Atendimento > Agenda > Agenda de Atendimentos >[Selecionar Agenda] > Log de Agendamento | Logs da Agenda de Atendimentos | | Atendimento > Agenda > Agenda de Cirurgias > Processos > Log da Agenda de Cirurgias | Log da Agenda de Cirurgias | |
| **Requisito****:** | DSAUGHASSIST-262 |
| **Descrição:** | Adequação das listagens dos logs das agendas de Atendimento e Cirurgia para o padrão RM de padrão e filtros. |

## Procedimento para Utilização

### Agenda de Atendimento

1. Acesse **Atendimento > Agenda > Agenda de Atendimentos;**

2. Selecione uma agenda e clique no botão **Log de Agendamento;**

3. Selecione ou crie um filtro;

4. Tela será exibida conforme imagem abaixo.

### Agenda de Cirurgias

1. Acesse**Atendimento > Agenda > Agenda de Cirurgias**

2. Acesse **Processos > Log da Agenda de Cirurgias** 

3. Selecione ou crie um filtro

4. A listagem dos filtros será exibida conforme imagem abaixo
