# Tratar caracteres especiais na integração com GUPY

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | RH |
| **Módulo:** | Gestão de Pessoas |
| **Função:** | Integração Gupy |
| **Situação/Requisito:** | Criação de parâmetro para a integração com a Gupy. Ao marca-lo qualquer campo enviado do candidato que possua acentos, cê-cedilha ou caracteres especiais da língua portuguesa serão alterados para que esses caracteres sejam trocados por outros sem acentos. Exemplo á -> a, ç -> c. |
| **Solução/Implementação:** | Criado o parâmetro **Remove acentuação e caracteres especiais das informações provindas da integração**que é liberado para marcação quando o parâmetro da integração da Gupy é marcado **(Processo seletivo integrado com o sistema GUPY),** este parâmetro fará com que qualquer letra com acento ou carácter especial  seja substituído por outro sem o acento. |
