O WebAgent do Protheus não é homologado para uso em navegadores via Metaframes, RDPs ou Web enablers como Citrix, Windows Remote Desktop, Go Global e VMWare Horizon, nem para sistemas operacionais ChromeOS, iOS, iPadOS e Android. A arquitetura do WebApp permite operação sem essas ferramentas. Para mais informações, consulte a documentação técnica oficial.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37472298344087) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
È possivel utilizar o protheus para dispositivos Tablets, mobile, Android e IOS Afins com WebAgent   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**

O WebAgent **não é homologado**para navegadores utilizados a partir de Metaframes, RDPs ou Web enablers, como:

* Citrix;
* Windows Remote Desktop;
* Go Global;
* VMWare Horizon.

Devido à simplificação na montagem do ambiente com o  WebApp, nossa arquitetura **não depende** das ferramentas acima para operação dos ERPs Protheus/Logix.

O WebAgent **não é homologado**para sistemas operacionais :

* ChromeOS/ChromeOS Flex
* iOS
* iPadOs
* Android

Duvidas: Segue documentação oficial disponibilizado nosso time de tecnologia: [Documentação técnica](https://tdn.totvs.com/display/tec/2.+WebApp+-+WebAgent#id-2.WebAppWebAgent-Sistemas)
