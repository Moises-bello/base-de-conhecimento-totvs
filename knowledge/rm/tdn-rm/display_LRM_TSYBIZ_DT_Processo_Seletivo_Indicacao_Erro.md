| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Processo Seletivo* |
| **Função:** | *Inscrição em área ofertada com indicação pelo portal do processo seletivo* |
| **Situação/Requisito:** | *Quando o processo seletivo utiliza indicações e é informada uma indicação inválida, o sistema permite prosseguir ao salvar a inscrição porém retorna um erro não tratado.* |
| **Solução/Implementação:** | *Foi feito um ajuste para que antes que ocorra o processo de salvar a inscrição o sistema validade as indicações, se estiverem inválidas o sistema limpas as indicações e prossegue corretamente com a conclusão da inscrição.* |
