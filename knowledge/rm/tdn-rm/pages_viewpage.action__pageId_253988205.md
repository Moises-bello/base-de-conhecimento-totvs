# Cheques - Emissão de Cheques (sem baixar)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Cheques - Emissão de Cheques (sem baixar) |
| **Situação/Requisito:** | Ao emitir um cheque a receber e em seguida um a pagar com o mesmo número do cheque a receber, o sistema não  permite tal inclusão. |
| **Solução/Implementação:** | Otimização no processo de emissão de cheque. Agora o sistema verifica a repetição do número dos cheques apenas  em Saque Cheque (Emissão de Cheque - A pagar). |
