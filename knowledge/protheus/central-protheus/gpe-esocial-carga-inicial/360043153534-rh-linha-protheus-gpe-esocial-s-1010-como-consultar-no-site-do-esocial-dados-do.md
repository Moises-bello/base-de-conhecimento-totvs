Dúvida**Como consultar no site do eSocial dados do evento **S-1010** (Tabelas de Rubricas)? **Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões **Solução**Esse evento está localizado no menu **Empregador** após fazer *login* no [Portal eSocial](https://www.gov.br/esocial/pt-br). Para consultar os dados do **S-1010**, o empregador deverá informar o código da rubrica (verba) para buscar seus dados.

Caminho: *Empregador > Tabelas > Rubricas**![](https://centraldeatendimento.totvs.com/hc/article_attachments/28159292184471)*O empregador deverá informar o código da rubrica (verba), e clicar na rubrica apresentada:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059222753)  
  
Será apresentada a seguinte tela onde é possível ver as datas de inicio da validade e a incidência que está correspondente a vigência da validade :  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360058310874)  
 **Importante**

* Para conhecer o manual completo de navegação no site do eSocial acesse:   
  [Manual do usuário para os módulos WEB GERAL e SST](https://www.gov.br/esocial/pt-br/empresas/manual-web-geral)
* Não recomendamos **inclusão / alteração** manual no site do **eSocial** devido a prejudicar a integridade entre os dados do sistema e governo gerando erros futuro.
