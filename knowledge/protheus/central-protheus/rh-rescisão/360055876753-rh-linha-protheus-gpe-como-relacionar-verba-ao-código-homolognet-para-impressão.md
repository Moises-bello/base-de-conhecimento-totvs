**Dúvida**Como relacionar verba ao código homolognet para que ela seja impressa no TRCT?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**Para relacionar verbas ao código Homolognet para impressão no TRCT, no cadastro da verba, preencha o campo V. Homolognet de acordo com o código (rubrica) que deseja que seja impresso no TRCT:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360093233613/mceclip0.png)

O sistema busca essa informação da Tabela S020 da rotina Manutenção Tabelas, onde é possível incluir mais códigos caso necessidade.
