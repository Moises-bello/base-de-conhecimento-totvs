# Lançamentos Financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Geração Movimento Regime Caixa |
| **Situação/Requisito:** | Com as evoluções para possibilidade de emissão de boletos registrado o TOTVS Gestão Financeira permite que um lançamento proveniente do educacional tenha seu boleto cancelado ou excluído diretamente no módulo financeiro.  Com isso realizamos um mapeamento para avaliar impactos:   * A geração de movimento regime de caixa estava permitindo gerar movimento para um boleto com status igual a cancelado. |
| **Solução/Implementação:** | Ao gerar o movimento para regime de caixa se o boleto estiver com status igual a cancelado o sistema apresentará uma mensagem de não conformidade para o boleto em questão. |
