**Dúvida**  
Qual rotina **ajusta** o conteúdo dos campos "**Sld. Ped. Lib" ( A1\_SALPEDL ) e "Sl.Pd.Bl.Cre" (A1\_SALPEDB)**?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - A partir da versão 11.80

**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

**1.** Acesse o módulo Estoque->Miscelânea-> Rotina Refaz Empenho também conhecida como Refaz Acumulados (MATA215) e execute clicando no botão OK ;

**2.** Esse processo deve ser feito em **MODO EXCLUSIVO**.
