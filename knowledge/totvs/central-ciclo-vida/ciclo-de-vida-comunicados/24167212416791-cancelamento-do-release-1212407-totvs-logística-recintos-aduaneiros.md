Cliente,

Estamos trabalhando constantemente para oferecer a melhor experiência em nossos produtos e focados no sucesso do seu negócio.

Temos novidades sobre a expedição dos releases do TOTVS Logística Recintos Aduaneiros previstos para 2024.

O **release 12.1.2407**, que estava **previsto para julho/24** foi cancelado. 

O principal motivo para esta alteração é a nova **atualização da API Recintos** que entrará em vigor em Outubro/2024 e será **obrigatória** para todos os clientes.

Desta forma, a **atualização da API Recintos** estará disponível em *patches* antes de seu vigor, [previsto para final de outubro/2024](https://www.gov.br/siscomex/pt-br/noticias/noticias-siscomex-sistemas/comunicados/sistemas-no-2024-004), e consolidada no release 12.1.2411, simplificando o processo de atualização em seu ambiente.  

Confira abaixo como ficou o planejamento para expedição dos nossos releases para o ano de 2024:

![](https://lh7-us.googleusercontent.com/docsz/AD_4nXcmzRLd8TY-0MthpSRT193JEFXkZBKemLm6Qj-6Rl8a0V7s7s2lee78II-w41HsglT724uf5jt-p3xIv81mfduB5ZVIUGHY-9z2z2ieQPWnYzbKJcbpzqkC7myxyOyRvfdB8sDArBwp4y-5NAT0eHjm12yyDhHZmcNonubM?key=S4sO-iwaho5mpxI5zDmRdQ)

Mas não se preocupe. Todas as melhorias que estavam previstas para o release 12.1.2407 **serão liberadas no release 12.1.2411**.

Acompanhe o ciclo de vida dos nossos produtos no [**Portal Ciclo de Vida**](https://suporte.totvs.com/portal/p/10098/ciclodevida)**.**

 

Um abraço.

Equipe TOTVS
