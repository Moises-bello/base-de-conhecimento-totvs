# DEMONSTRAR QTDE DE FALTAS NO LOG DE CÁLCULO DO RECIBO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cálculo de Férias* |
| **Situação/Requisito:** | *No cálculo das férias do funcionário, o log de cálculo não demonstra a quantidade de dias de faltas, dificultando a conferência do cálculo e a apresentação dos mesmos para a fiscalização trabalhista.* |
| **Solução/Implementação:** | *Tratar no cálculo do recibo de férias para informar no log de cálculo a quantidade de faltas ocorridas durante o periodo aquisitivo, que podem ocasionar em uma possível perda de dias no saldo de direito.* |
| **Chamados   relacionados:** | *TUANKP* |
| **Versões/Release:** | *12.1.11* |
