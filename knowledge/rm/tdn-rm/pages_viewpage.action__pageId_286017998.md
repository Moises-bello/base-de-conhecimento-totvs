# IMPRESSÃO RAIS P/ CONFERÊNCIA TXT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | RAIS |
| **Situação/Requisito:** | Ao gerar a RAIS para conferência em TXT e tentar efetuar a impressão, o conteúdo que era exibido normalmente em uma página no bloco de notas é impresso em duas páginas perdendo a formatação. |
| **Solução/Implementação:** | Foram realizados ajustes no relatório 'FOPREL0013 - Rais para conferência\_12\_1\_10' adequando o espaçamento entre os campos e realizando abreviações para que o conteúdo possa ser formatado adequadamente em apenas uma página.    Entretanto, é importante ressaltar que a correta impressão do relatório gerado não depende exclusivamente do relatório em si, mas também das configurações do editor de texto utilizado. Para que o conteúdo do relatório possa ser impresso com a formatação adequada em apenas uma página, é recomendado configurar a fonte do editor de textos para 8pts, conforme pode ser visto a seguir no exemplo do Bloco de Notas (notepad) do Windows:  1 - Acesse o menu 'Formatar' -> 'Fonte':    2 - Na janela aberta, configure a fonte para 8pts e, em seguida, clique em OK:    3 - Após concluir o procedimento, o conteúdo do relatório na área de edição do Bloco de Notas deverá ser atualizado segundo as configurações selecionadas. |
