**Dúvida**  
Onde localizar a URL e Token para Integração com a Feedz  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal  
  
**Solução**  
Para a integração com a Feedz possuímos dois parâmetros:  
  
**MV\_APIFEE1 -** Informar a URL base do ambiente de integração com a Feedz  
**MV\_APIFEE2 -** Informar o Token de autenticação para integração com a Feedz  
  
**URL:**  
Ambiente Produção: <https://integrations.feedz.com.br/protheus-feedz-etl/>  
Ambiente Homologação: <https://integrations.feedz.dev/protheus-feedz-etl/>  
  
**Token:**  
O Token deve ser gerado por um usuário Administrador da empresa na Feedz. A chave é obtida em: **Configurações > Integrações > Chave Integração** (API 2.0).  
Caso o campo esteja vazio, clique em '**Gerar Token'.**   
  
Para mais informações sobre o Token e URL entre em contato com o seu Customer Sucess Feedz.
