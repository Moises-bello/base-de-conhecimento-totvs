**Dúvida**Devo criar uma nova série para o MDFE?

**Ambiente**Cross Segmentos - Backoffice Protheus - Todas as versões

**Solução**É necessário criar uma nova série para o MDFE diferente da série da NFE.

Esta nova série **NÃO** é para informar no parâmetro MV\_ESPECIE.

Segundo o Manual de Orientação do Contribuinte da SEFAZ, a série do MDFE deve ser numérica de 1 a 3 dígitos. Caso utilize uma série com letras o sistema converte para 0.
