Function GetScreenRes() doesn't available in JOB. in file  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Causa**Essa função só pode ser utilizada nos programas executados através do TOTVS | SmartClient  
  
**Solução**Não é possível utilizar essa função via JOB.
