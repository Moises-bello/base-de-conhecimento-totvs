# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Localidade |
| **Ambiente:** |  |
| **Passo a passo:** | Neste cadastro, você poderá incluir as localizações relacionadas aos patrimônios. Trata-se das localizações físicas em que se encontram os patrimônios, podendo ser diferentes das localizações como Filial ou Departamento.    **Regras na Inclusão de Localizações:** O campo [Centro de Custo](https://tdn.totvs.com/display/LRM/Centros+de+Custos) será mostrado apenas se o parâmetro “Vincular localização com centro de custo” estiver marcado. O campo [Responsável](https://tdn.totvs.com/pages/viewpage.action?pageId=444616202) será apresentado somente se o parâmetro “Vincular localização com responsável” estiver marcado. O campo Ativo só poderá ser desmarcado se não existirem patrimônios na localização.  Parâmetros disponíveis no menu Ambiente | Parâmetros | Gestão de Patrimônio | Cadastro de Bens | Etapa ‘Localizações’.      **Vincular Localização com Centro de Custo** Através deste parâmetro será possível fazer a vinculação de uma localização com um centro de custo diretamente no cadastro de localizações. Assim toda vez que uma localização de um bem for inserida, o Centro de Custo vinculado a esta localização será incluído automaticamente com a mesma data da localização incluída.  **Vincular Localização com Responsável** Através deste parâmetro será possível fazer a vinculação de uma localização com um responsável diretamente no cadastro de localização. Assim toda vez que uma localização de um bem for inserida, o Responsável vinculado a esta localização será incluído automaticamente no cadastro de bens através da pasta Dados Complementares.  **Campos Complementares de Localização** Nesta etapa serão visualizados os [campos complementares](https://tdn.totvs.com/pages/viewpage.action?pageId=423938336) existentes e ativos que foram cadastrados no Menu Cadastro | Campos Complementares | Localizações, para que você faça aqui o preenchimento de cada campo complementar como queira. Estas informações não são obrigatórias, mas podem auxiliar na informação de dados não disponíveis no cadastro de Localizações.  **Procedimento** Acesse o **menu Cadastros | Localizações** | Incluir | Preencha os dados como Código, Descrição e outros | Salvar. |
