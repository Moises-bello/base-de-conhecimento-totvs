Processo responsável pela alteração da relação (Pai e Filhos) entre os projetos cadastrados.  
 Lembrando que somente é permitida a alteração da hierarquia para projetos que não tenham filhos e para projetos com status diferente de "Revisado".  
    
  A opção "Hierarquia de projetos" encontra-se na visão de projetos, Anexos.   
 Quando selecionamos um projeto que não esta vinculado a nenhum projeto e realizamos a alteração da hierarquia o projeto passa a ser subprojeto de outro projeto. O processo é realizado da seguinte forma, seleciona-se um projeto e clique em alterar hierarquia, escolha o projeto para o qual terá sua hierarquia alterada e clique em executar.  
 O projeto selecionado inicialmente estará abaixo do projeto que foi selecionado através da opção alterar hierarquia.  
 Ex. O projeto A é selecionado, a opção "Alterar Hierarquia de Projeto" é acionada. O projeto B é selecionado e o processo é executado.  
 Neste momento se visualizarmos a visão de projetos o projeto B estará acima do projeto A, o projeto A estará representado como filho do projeto B.
