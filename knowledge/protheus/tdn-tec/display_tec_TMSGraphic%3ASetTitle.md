SetTitle

Define a posição do título no gráfico.

## Parâmetros

| Nome | Tipo | Descrição | Obrigatório |
| --- | --- | --- | --- |
| cTitle | Caracter | Indica o primeiro titulo do gráfico. |  |
| cTitle2 | Caracter | Indica o segundo título do gráfico. |  |
| nColor | Numérico | Indica a cor do título. | x |
| nAlign | Numérico | Indica o alinhamento do titulo no gráfico, sendo:  1 = A\_LEFTJUST 2 = A\_RIGHTJUS 3 = A\_CENTER | x |
| lFoot | Lógico | Indica se, verdadeiro (.T.), terá titulo no rodapé. Caso contrário, falso (.F.). |  |
