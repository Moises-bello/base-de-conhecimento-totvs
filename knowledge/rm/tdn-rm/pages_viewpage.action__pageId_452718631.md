Este módulo permite cadastrar os tipos referente a acordo de trabalho para o cálculo da diferença salarial e possui os seguintes campos: Data vencimento pagto acordo, Data do efeito, tipo do acordo e Descrição.  
    
 Nessa rotina é possível copiar as informações entre as coligadas, através de Processos | Copiar registro entre coligadas. No processo também há a opção de substituir os registros já existentes nas coligadas de destino.  
    
 **Atenção:**  
 Este campo é utilizado para o eSocial leiaute S-1200 - Remuneração do Trabalhador.
