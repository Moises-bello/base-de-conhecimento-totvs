![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28692255197975) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como alterar um campo de uma aba para outra no Cadastro de Clientes (CRMA980)?  
  
**Ambiente**Cross Segmentos - BackOffice Protheus - SIGAFAT - Todas as versões  
  
**Solução**

É possível alterar a pasta que é apresentado um campo dentro do cadastro de clientes através do **SIGACFG** (Configurador).

*Exemplo:*

* No **SIGACFG**, acesse a tabela de Clientes (**SA1**):

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28692261635095)

* Selecione a opção **pastas** e o botão **mover campos** (setas verdes no cabeçalho):

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28692261636247)

* Selecione o**campo**, a **pasta de origem** e a **pasta destino**:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28692255203479)

* Após alteração clique em **Salvar:**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/28692261637399)**

* Clique em Salvar a alteração no disquete para **Atualizar base de dados.**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/28692261638551)**
