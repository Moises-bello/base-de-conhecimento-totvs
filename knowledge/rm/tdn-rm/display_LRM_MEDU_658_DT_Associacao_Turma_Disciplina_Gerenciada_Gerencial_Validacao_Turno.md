# ASSOCIAÇÃO DE TURMA/DISCIPLINA GERENCIADA À GERENCIAL - VALIDAÇÃO DE TURNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Associação de Turma/Disciplina Gerenciada à Gerencial - Validação de Turno* |
| **Situação/Requisito:** | *De acordo com a documentação existente o sistema deveria bloquear a associação de turmas/disciplinas gerenciada à gerencial com turnos diferentes, fato que não está ocorrendo.* |
| **Solução/Implementação:** | *Ajuste na associação de turmas/disciplinas gerenciadas à gerencial, para que seja bloqueado quando forem de turnos diferentes. Além disso, será bloqueado a alteração do turno da turma/disciplina gerenciada, bem como na turma/disciplina gerencial quando a mesma possuir turmas/disciplinas gerenciadas.*  *O mesmo vale para associação entre filiais/níveis de ensino diferente, onde deverá ser respeitado a relação de cadastro de turnos entre filiais, ou seja, somente será possível associar turma/disciplina gerenciada à gerencial que possuírem turnos que tem relação de cadastros.* |
