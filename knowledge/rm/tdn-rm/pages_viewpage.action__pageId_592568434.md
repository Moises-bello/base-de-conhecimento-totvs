A partir da versão 12.1.31, a tela de Elaboração de Contas na nova MDI foi liberada com algumas funcionalidades do escopo de Clínicas, sendo elas:

* Encerramento da Parcial
* Imprimir Conta (RM Reports Novo)
* Imprimir Guias (RM Reports Novo)
* Criar parciais
* Cancelar parcial
* Alterar data inicio da parcial
* Pendências da parcial
* Anexos da Parcial
* Resumo
* Grupos de Gastos (vide quadro detalhado abaixo)

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **Funcionalidades dos Grupos de Gasto:** | **Honorários** | **Taxas** | **SADT** | **Gastos Particulares** |
| Estornar lançamento | OK | OK | OK | OK |
| Valores corretos (AMB e CBHPM) | OK |  | OK | N/A |
| Todos os campos (visuais) para preenchimento | OK | OK | OK | OK |
| Localização Rápida | N/A | N/A | N/A | N/A |
| Reverter Estorno | OK | OK | OK | Delphi não tem |
| Dentro e Fora da Conta | OK | OK | OK | N/A |
| Prestador TISS | OK | N/A | OK | N/A |
| Vincular/Desvincular Guia (honorário/sadt) | OK | OK | OK | N/A |
| Permissões dos Grupos (permissão de acesso para cada aba) | OK | OK | OK | OK |

Dica

Para mais informações, acessar nosso documentação da [Elaboração de Contas](https://tdn.totvs.com/pages/viewpage.action?pageId=557322371)
