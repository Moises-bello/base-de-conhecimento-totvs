# Lançamento - Inclusão / Alteração

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento - Inclusão / Alteração |
| **Situação/Requisito:** | Ao realizar qualquer alteração em um lançamento já gravado, clicar em cancelar e na tela de confirmação que é exibida clicar em Não, o campo referente ao Cliente/Fornecedor (FLAN.COFCFO) fica invisível na aba Identificação do Lançamento. |
| **Solução/Implementação:** | Otimização no processo de inclusão de lançamentos. Agora o sistema não deixar o campo Cliente/Fornecedor invisível na aba de Identificação do Lançamento após clicar em não no cancelar na tela de confirmação de alteração. |
