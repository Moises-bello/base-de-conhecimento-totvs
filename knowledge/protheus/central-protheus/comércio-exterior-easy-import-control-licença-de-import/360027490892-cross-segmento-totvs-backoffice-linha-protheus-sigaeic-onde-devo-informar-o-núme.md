**Dúvida**Onde informar o numero do ato concessório no SIGAEIC quando não integramos com o módulo SIGAEDC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**1. O item que será utilizado para um processo Drawback deve estar cadastrado no Purchase Order como Anuente, na Purchase Order (EICPO400):

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027417231/mceclip0.png)

2. Para processos Drawback (1 - Anuente), deve ser feita a inclusão da P.L.I., onde será informado o **número do ato concessório**, no campo **W4\_ATO\_CON**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027417491/mceclip2.png)

3. Preencha todos os dados obrigatório e grave a P.L.I.
