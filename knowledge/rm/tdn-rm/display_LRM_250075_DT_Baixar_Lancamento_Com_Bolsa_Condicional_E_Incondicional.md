# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de movimento por competência* |
| **Situação/Requisito:** | *A rotina responsável por carregar os parâmetros do Educacional, no momento de descobrir o nível de ensino, não distinguia o resultado por coligada. Assim, o sistema tentava carregar os valores opcionais de bolsa de um contexto inexistente, causando erro no momento da realização da baixa.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de baixa de lançamentos financeiros, permitindo ao sistema, carregar corretamente os valores opcionais de bolsa, com base no lançamento financeiro que está sendo baixado.* |
