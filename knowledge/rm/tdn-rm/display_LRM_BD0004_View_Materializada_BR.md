| **Passo a passo:** | Views materializadas são utilizadas para fazer cálculos, armazenamentos de dados e dar agilidade em troca de informações entre um banco de dados ou entre tabelas.  Sugerimos a criação de Materialized View de algumas tabelas e views, do catálogo do Oracle, para alguns casos em clientes onde a leitura, pelo provider da Oracle, às tabelas e views de catálogo torna-se extremamente lenta. Após a criação dessas views, é de extrema importância realizar a criação e acompanhamento por um DBA e atualização das mesmas periodicamente, por exemplo a cada 7 dias. Este processo de atualização é de inteira responsabilidade do cliente.  Visando facilitar o entendimento, abaixo segue o link para download dos exemplos das views      **Atenção!**   É de extrema importância realizar o backup antes das rotinas de manutenção!  Inicialmente conceda permissão ao usuário RM para criação das views materializadas através do comando a seguir, logado com o usuários SYS.  ***GRANT CREATE MATERIALIZED VIEW TO RM*.** |
