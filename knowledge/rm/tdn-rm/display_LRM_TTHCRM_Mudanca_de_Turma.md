# Mudança de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Mudança de turma* |
| **Situação/Requisito:** | *Ao efetuar uma mudança de turma, caso a disciplina da turma de origem não possua data de matrícula é lançada uma exceção tratada informando do problema e não é possível dar prosseguimento no processo.* |
| **Solução/Implementação:** | *Ajustes para que, ao efetuar uma mudança de turma, caso a turma de destino possua disciplinas na qual o aluno não se encontra matrícula na turma de origem, seja exibido mais um passo no processo, informando a situação e questionando o usuário se ele deseja dar prosseguimento.* |
