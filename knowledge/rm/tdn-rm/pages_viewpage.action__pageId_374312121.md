# Visão da movimentação de estoque com problema na descrição do local de estoque destino

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Movimentação de Estoque |
| **Situação/Requisito:** | A visão da movimentação de estoque traz a informação do almoxarifado 01 vinculado a filial 25. No entanto ao editar o registro, a informação correta é do almoxarifado 01 vinculado a filial 28. |
| **Solução/Implementação:** | Realizado a ajuste na consulta que retorna o nome do local de estoque destino com a filial correta |
