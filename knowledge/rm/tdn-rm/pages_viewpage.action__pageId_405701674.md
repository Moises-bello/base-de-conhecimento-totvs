|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Turma/Disciplina do professor |
| **Situação/Requisito:** | Quando é informado o valor 1 no campo "Aulas por semana", o sistema mantém o valor sem casas decimais. Mas quando informado qualquer valor maior que 1, o sistema exibe o campo preenchido com 4 casas decimais. |
| **Solução/Implementação:** | Foi incluída uma máscara no campo de aulas por semana do professor na turma/disciplina para que sempre apareça 4 casas decimais. |
