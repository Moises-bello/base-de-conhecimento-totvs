# Dígito verificador

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Relatórios fixos |
| **Situação/Requisito:** | A opção ‘Usa dígito verificador’, da tela de parâmetros do módulo contábil, foi marcada. No cadastro das Contas Contábeis o dígito é apresentado para a conta e para o reduzido, porém ao realizar o processo de emissão do relatório Balancete os dígitos não são apresentados, mesmo após aumentar o tamanho do campo de Conta. |
| **Solução/Implementação:** | Após marcar a opção ‘Usa dígito verificador’, existente na tela de parâmetros do módulo contábil, as contas contábeis e gerencias exibem o dígito em todos os relatórios fixos do sistema. Vale ressaltar que apenas as contas analíticas exibem o dígito verificador, para manter o mesmo comportamento dos relatórios Delphi. |
