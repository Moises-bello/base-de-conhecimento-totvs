# DEFINIR SUBSTITUTO CHEFE/SUPERVISOR PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Definir Substituto Portal* |
| **Situação/Requisito:** | Ao acessar a tela de definir substituto de chefe/supervisor pelo portal, a lookup de substituto era exibida em branco ou apenas com os funcionários da seção selecionada, por padrão. Mesmo podendo serem alterados os filtros, isso causava confusão no usuário, que acreditava não haver mais opções à selecionar. |
| **Solução/Implementação:** | *Foi alterada para a lookup exibir todos os funcionários por padrão, caso nenhuma equipe/seção esteja selecionada no momento de abertura do lookup* |
| **Chamados relacionados:** | TTQTQD |
