# MATRÍCULA EM DISCIPLINA COM CO-REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Matricular aluno nas disciplinas |
| **Situação/Requisito:** | O aluno está realizando a matrícula em uma disciplina, que é de outra grade, mas que é equivalente a uma disciplina da grade onde está matriculado. Essa disciplina possui um co-requisito, nas duas grades, o aluno já está matriculado em uma disciplina de co-requisito e ao realizar a matrícula na outra disciplina, o sistema/portal, informa erro dizendo que a matricula não pode continuar, pois existe o co-requisito. |
| **Solução/Implementação:** | O sistema foi alterado para verificar se o aluno está cursando uma disciplina equivalente ao co-requisito da disciplina em que ele está sendo matriculado. |
