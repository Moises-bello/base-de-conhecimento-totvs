![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19366426723991) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como fazer o cadastro de Departamentos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Arquitetura Organizacional – Todas as versões  
  
**Solução**Neste cadastro devem ser relacionados os **departamentos** da empresa que são utilizados na montagem da estrutura dos **cargos**, **visões e hierarquias dos portais MEU RH e GCH.**  
  
Exemplo:

|  |  |
| --- | --- |
| Departamento | Descrição |
| 001 | Financeiro |
| 002 | Compras |
| 003 | Recursos Humanos |
| 004 | Programação |
| 005 | Vendas |

**Acesse Atualizações > Cadastros > Departamentos > Incluir**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/19366462442903)**

**Preencha os dados conforme help dos campos e salve**
