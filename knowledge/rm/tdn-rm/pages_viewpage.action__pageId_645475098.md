Para acessar configuração de proteção de Dados, deve-se:

* Clicar na aba Segurança/ Configurar Proteção de Dados

Deve-se inserir a tabela com proteção de dados na qual deseja-se realizar a auditoria.

Obs: Enumerado os passos para cadastro da tabela.

Nesse exemplo a tabela selecionado a tabela **PFUNC**

**O campo "Pessoal" deve ser selecionado conforme abaixo:**

A partir da versão **12.1.32** o usuário poderá escolher se irá auditar as tabelas da LGPD conforme tela abaixo:

* Por default o campo vem marcado no configurador do TOTVS Audit;
* Quando desmarcado o flag abaixo todas as tabelas que tem campos pessoas deixam de ser auditadas, sendo assim, caso o usuário tenha interesse em audita-la deve realizar a marcação e executar o configurador novamente.
