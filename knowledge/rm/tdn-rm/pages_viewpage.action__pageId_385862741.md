# Tag do código do período letivo na contabilização inclusão e de baixa do lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Tag na contabilização de inclusão e de baixa de lançamento |
| **Situação/Requisito:** | Na contabilização de inclusão e de baixa do lançamento gerado por acordo a partir de outro lançamento do TOTVS Gestão Educacional a tag [PRL.C] - código do período letivo não era substituída corretamente. |
| **Solução/Implementação:** | Otimização na substituição da tag [PRL.C] - código do período letivo na contabilização de inclusão e de baixa do lançamento independe se no contrato do aluno tem bolsa. |
