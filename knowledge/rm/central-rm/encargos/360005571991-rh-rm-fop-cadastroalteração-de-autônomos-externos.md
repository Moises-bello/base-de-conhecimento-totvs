**Dúvida**Como faço para inserir novos cadastros ou realizar alterações em cadastros existentes na rotina de Autônomos Externos?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**O cadastro de Autônomos Externos foi desenvolvido para receber dados dos autônomos registrados em outros sistemas, como no BackOffice de outras linhas de produto, por exemplo.  
  
A inserção de dados poderá ser realizada através do Web Service FopPagAutonomosExtData ou via importação de dados (menu Configurações | Importação Dados Folha de Pagamento). Já edição dos registros poderá ser realizada somente através do Web Service ou diretamente no banco de dados.  
  
**Importante**  
Em alguns casos é obrigatório o cadastro do autônomo como funcionário no módulo Folha de Pagamento, para envio ao E-social, para acessar a documentação completa [clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360004013531-RH-RM-FOP-eSocial-Necessidade-de-cadastro-dos-aut%C3%B4nomos-no-TOTVS-Folha-de-Pagamento?source=search).
