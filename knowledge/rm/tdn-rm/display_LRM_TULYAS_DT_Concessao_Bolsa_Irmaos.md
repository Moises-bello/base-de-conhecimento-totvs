# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Matrícula on-line* |
| **Situação/Requisito:** | Identificamos que a descrição de alguns parâmetros na tela estava fazendo com que os usuários interpretassem de forma incorreta o funcionamento do processo. Dessa forma, iremos alterar a descrição de alguns parâmetros que está como "Desconto" para "Bolsa" com o objetivo de facilitar o entendimento dos parâmetros disponíveis na tela de execução do processo de concessão de bolsas para irmãos. |
| **Solução/Implementação:** | Nessa tela, o texto do grupo "Desconto" foi alteado para "Bolsa".  No grupo "Tipo de desconto" caso seja marcado "Percentual" a tela seguinte exibirá o texto "Percentual de desconto" como label do campo para informar o desconto e como título da coluna correspondente na grade.  O texto "Dar desconto" foi alterado para "Conceder bolsa".  Os parâmetros do grupo "Bolsa" tiveram o texto alterado de: "Sempre cadastrar desconto" para "Sempre cadastrar bolsa" "Não cadastrar desconto se o aluno já possuir outro desconto" para "Não cadastrar bolsa se o aluno já possuir outra bolsa" "Não cadastrar desconto se algum irmão já possuir outro desconto" para "Não cadastrar bolsa se algum irmão já possuir outra bolsa" "Não cadastrar desconto se o aluno já possuir outro desconto" para "Não cadastrar bolsa se o aluno já possuir outra bolsa"    No grupo "Tipo de desconto" caso seja marcado "Percentual" a tela seguinte exibirá essa descrição. |
