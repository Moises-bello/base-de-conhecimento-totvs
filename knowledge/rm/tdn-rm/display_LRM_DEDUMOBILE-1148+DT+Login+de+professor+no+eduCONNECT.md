# Login de usuário professor/coordenador no eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Login |
| **Situação/Requisito:** | Ao acessar o eduCONNECT via login de usuário professor/coordenador, o sistema estava exibindo a mensagem de "erro interno do servidor", para usuários que possuíam uma imagem de foto de alta resolução no cadastro. |
| **Solução/Implementação:** | Foi realizado um ajuste no serviço de login do TOTVS Educa Mobile, de maneira a realizar um tratamento na imagem dos usuários professores/coordenadores com imagem em alta resolução para possibilitar o login normalmente no TOTVS eduCONNECT. |
