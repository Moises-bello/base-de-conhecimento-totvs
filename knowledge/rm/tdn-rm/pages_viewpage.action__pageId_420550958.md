# CONTEXTO NÃO DEVE SER TROCADO AO CARREGAR PERFIL DE PARÂMETROS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Recursos Humanos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Férias Coletivas Globais |
| **Situação/Requisito:** | Ao abrir o assistente de execução do processo de Férias Coletivas Globias e carregar um perfil de parâmetros, o usuário do contexto da action estava sendo trocado para o usuário que criou o perfil de parâmetros. |
| **Solução/Implementação:** | Foi realizado ajuste para não alterar o usuário do contexto da action ao carregar um perfil de parâmetros do processo de Férias Coletivas Globais. |
