## Como fazer para localizar o arquivo ctsrvr.cfg

Para localizar o arquivo de configuração (ctsrvr.cfg) do c-tree Server, é necessário realizar o seguinte procedimento:

1. Acesse a pasta de instalação do **c-tree**.
2. Localize o arquivo **ctsrvr.cfg**.
