A barra de ferramentas possuiu os botões para adicionar ou remover Registros, Arquivos e Contextos no Layout. Além de outras ações como Executar, Gerar a documentação e gerar o código fonte do Layout para validação.

![](/download/attachments/319787260/barra_de_ferramentas.png?version=1&modificationDate=1512921805000&api=v2)

1Novo

Utilize essa opção para criar um novo Layout, todas as alteração não salvas no Layout serão perdidas.

2Salvar

Utilize esta opção para salvar o conteúdo do Layout.

3Salvar para Arquivo

Utilize esta opção para salvar o conteúdo do Layout para um arquivo em disco.

4Abrir de Arquivo

Utilize esta opção para carregar o conteúdo do Layout a partir de um arquivo do disco.

5Adicionar Contexto

Utilize esta opção para adicionar um novo contexto de dados no Layout. Esta opção só é habilitada se estiver na visão de contextos na árvore de Layout. Para mais informações consulte a [Configuração do Contexto](/display/LRM/Manual+-+Contextos).

6Remover Contexto

Utilize esta opção para remover o contexto selecionado na árvore de Layouts. Esta opção só é habilitada se estiver na visão de contextos na árvore de Layouts e se houver um contexto selecionado.

7Adicionar Arquivo

Utilize esta opção para adicionar um arquivo no Layout. Esta opção só é habilitada se estiver na visão de Layout na árvore de Layouts. Para mais informações consulte a [Configuração do Arquivo](/pages/viewpage.action?pageId=319787269).

8Adicionar Registro

Utilize esta opção para adicionar um registro no Layout. O registro será adicionado como registro filho do registro selecionado. Esta opção só é habilitada se estiver na visão de Layout na árvore de Layout. Para mais informações consulte a [Configuração do Registro](/pages/viewpage.action?pageId=319787271).

9Remover

Utilize esta opção para remover um arquivo ou registro do Layout. Esta opção só é habilitada se estiver na visão de Layout na árvore de Layout.

10Mover para Cima

Utilize esta opção para mover o registro selecionado para cima caso ele não seja o primeiro registro da hierarquia. A ordem dos registros define a ordem em que os dados serão gerados no arquivo final. Esta opção só é habilitada se estiver na visão de Layout na árvore de Layout.

11Mover para Baixo

Utilize esta opção para mover o registro seleciona para baixo caso ele não seja o último registro da hierarquida. Esta opção só é habilitada se estiver na visão de Layout na árvore de Layout.

12Executar

Utilize esta opção para montar a linha de comando e executar o Layout em edição. Esta opção não está disponível dentro do RM, neste caso a execução só é permitida pelo processo de Executar Layout na visão de Layouts do gerador. Para mais informações consulte [Executar](/display/LRM/Manual+-+Executar).

13Gerar Documentação

Utilize esta opção para gerar o arquivo de ajuda contendo todas as informações pertinentes do Layout. O arquivo de ajuda pode ser distribuido para que terceiros possam utilizar como base para geração do arquivo ou para conferência da estrutura do Layout. Para mais informações consulte [Gerar Documentação](/pages/viewpage.action?pageId=319787262).

14Gerar Classe

Utilize esta opção para gerar e compilar a classe de execução do Layout, ela é usada para fins de diagnóstico de erros e problemas na geração. Para mais informações consulte [Gerar Classe](/display/LRM/Manual+-+Gerar+Classe).
