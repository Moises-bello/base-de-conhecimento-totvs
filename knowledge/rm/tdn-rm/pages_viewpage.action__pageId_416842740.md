# Lançamentos financeiros no EducaMobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS EducaMobile |
| **Função:** | Lançamentos financeiros |
| **Situação/Requisito:** | Os lançamentos financeiros do Educa Mobile eram exibidos de forma não agrupada, uma vez que a habilitação do Aluno não fosse a mesma para as disciplinas. |
| **Solução/Implementação:** | Aperfeiçoamento na apresentação dos dados financeiros no Educa Mobile, análogo ao funcionamento do Portal Educacional, onde lançamentos financeiros com o mesma habilitação serão agrupados, com o objetivo de gera-los em um único boleto. |
