A partir da Release 12.1.2302, essa visão é **multicoligada**, ou seja, é possível visualizar tarefas de coligadas distintas e consequentemente executar os processos.

Através deste módulo é possível visualizar e gerenciar as **Tarefas** solicitadas por outros aplicativos. Para obter um entendimento maior sobre Tarefas, os tipos disponíveis e como cada uma atua no sistema clique aqui.

Na visão principal, anterior à esta tela, é possível visualizar o cadastro geral de todas as Tarefas solicitadas nos módulos externos ao da contabilidade, assim como o status de cada uma.

Ao editar uma solicitação de Tarefa ficarão visíveis para consulta todos os dados referentes à solicitação.

Para auxiliar na análise, antes de executar ou cancelar uma solicitação de Tarefa, além de serem mostradas as informações de origem, será possível, através dos respectivos *links* disponíveis nesta tela, acessar e *Visualizar* a contabilização e os próprios dados de origem facilitando assim a análise para o gerenciamento.

Somente os usuários com *permissão*, ou seja, aqueles que foram incluídos dentro do Tipo de Tarefa, é que poderão executar ou cancelar a solicitação de uma Tarefa.

Para executar ou cancelar uma Tarefa, selecione-a e utilize os processos *Executar Tarefa* ou *Cancelar Tarefa*.

* Cancelar Tarefa
