**Requisitos de Acesso**

---

O cadastro dos Requisitos de Acesso tem como objetivo demonstrar o desenvolvimento necessário para a viabilização da avaliação de determinada competência. Competência esta que apenas será oficializada ao passar por um processo de avaliação de desempenho, quando o (s) avaliador (es) poderá (m) validar, ou não, a aquisição desta competência.

Os requisitos de acesso serão utilizados no cadastro das competências, onde o usuário deverá definir os requisitos necessários para viabilizar o acesso a tal competência, e também serão vinculados no cadastro de pessoas, onde o usuário definirá quais os requisitos de acesso as pessoas possuem.

A correta vinculação destas informações será necessária para o LNT e para o Radar de Competências.

**Requisitos Agregados**

O conceito de Requisitos Agregados está baseado na relação de requisitos vinculados ao atual. Os requisitos agregados compõem o requisito atual de forma que quando um requisito é adquirido os requisitos agregados também serão adquiridos. Em todos os processos que uma pessoa possa adquirir um requisito de acesso, como a carga de requisitos, inclusão manual ou certificações deverão serem atualizados os requisitos agregados.

**Observação:**

- Uma ou várias competências podem ser vinculadas a um mesmo requisito de acesso;

- Uma competência não pode ser vinculada mais de uma vez a um mesmo requisito de acesso;

- Uma ou mais pessoas podem possuir vínculos com um mesmo requisito de acesso;

- Uma pessoa não pode possuir mais de um vínculo com o mesmo requisito de acesso;

- Para ilustrar quais tipos que compõem o requisito (Cursos Acadêmicos, Cursos, Grau de Instrução, Idioma e certificação) será exibida uma imagem representando o tipo na tela de visão.

Ao marcar a flag "Disponível no portal", o requisito ficará visível no portal no caminho: Recursos Humanos / Painel de aprendizagem.

**Competências que possuem o requisito**

Esta pasta destina-se ao cadastramento, consulta e / ou alteração das vinculações de competências aos requisitos. Ao vincular uma competência a um requisito, o usuário definirá quais são as competências que exigem da pessoa o desenvolvimento do requisito em questão, para que ela possa ter a competência registrada no seu cadastro.

Pelo LNT (que futuramente se transformará em MND – mapeamento de necessidade de desenvolvimento) será possível verificar quais são os requisitos de acesso que uma determinada pessoa possui e cruzar estas informações com os requisitos de acesso necessários para a competência exigida para exercer a função desempenhada pela pessoa em questão. Com bases nestas informações será possível identificar, para cada pessoa, quais são os requisitos que precisam ser desenvolvidos / melhorados por ela.
