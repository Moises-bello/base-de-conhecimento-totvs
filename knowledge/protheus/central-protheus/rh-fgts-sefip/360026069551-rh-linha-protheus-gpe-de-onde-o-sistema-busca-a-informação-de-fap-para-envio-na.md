Dúvida**De onde o sistema busca a informação de FAP para envio na SEFIP ?

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
  
**Solução**

Conforme documentação abaixo a informação deve ser digitada diretamente no sistema da SEFIP, visto que o campo FAP não existe no layout de integração.
