# Baixa - Inclusão do Extrato

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa - Inclusão do Extrato |
| **Situação/Requisito:** | Ao realizar a baixa de dois lançamentos escolhendo a opção de cheque como forma de pagamento e inserir  informações na aba dados adicionais do cheque, tais informações não são levadas para o extrato de caixa na aba  Dados do Cheque. Ocorre somente quando é selecionado mais de um lançamento, se baixar somente um, tais  informações são levadas para o extrato. |
| **Solução/Implementação:** | Otimização no processo de baixa de cheque com mais de um lançamento e extrato agrupado. Agora o sistema  preenche corretamente os campos Código Banco, Código da Agência e Conta Corrente. |
