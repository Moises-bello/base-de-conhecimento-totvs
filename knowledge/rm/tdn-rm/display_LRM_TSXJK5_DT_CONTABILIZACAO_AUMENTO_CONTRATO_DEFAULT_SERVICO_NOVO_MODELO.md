# CONTABILIZAÇÃO POR COMPETÊNCIA NOVO MODELO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Contabilização do aumento de contrato.* |
| **Situação/Requisito:** | *O sistema, para o novo modelo de contabilização, não está suportando a contabilização do aumento ou redução no valor contrato para quando o default de contas contábeis é obtido através do serviço. O sistema não está preenchendo os itens de serviço dos eventos, o que faz com que a contabilização por serviço nãO seja executada.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de contabilização por competência para o novo modelo de modo a permitir que os eventos contábeis de aumento ou redução do valor do contrato, possam buscar as contas contábeis do default de serviço.* |
