**Dúvida**Ao tentar usar uma determinada função, o sistema retorna o seguinte erro:*InterFunctionCall: cannot find function*

```
InterFunctionCall: cannot find function <function> in AppMap
```

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Essa ocorrência é apresentada em tempo de execução quando realizada a chamada de uma função que não foi compilada ou que foi removida do repositório de objetos.
