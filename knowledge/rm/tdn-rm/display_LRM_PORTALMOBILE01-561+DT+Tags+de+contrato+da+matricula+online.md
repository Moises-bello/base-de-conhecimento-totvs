|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |

| **Função:** | Tags do contrato financeiro na matrícula online |
| **Situação/Requisito:** | Ao cadastrar a mesma TAG no texto do contrato financeiro nos parâmetros da matrícula online, o sistema realizava a substituição apenas da primeira ocorrência da TAG. |
| **Solução/Implementação:** | Foi realizado ajuste para que o sistema possa substituir todas as ocorrências de TAGs no texto do contrato financeiro na matrícula online. |
