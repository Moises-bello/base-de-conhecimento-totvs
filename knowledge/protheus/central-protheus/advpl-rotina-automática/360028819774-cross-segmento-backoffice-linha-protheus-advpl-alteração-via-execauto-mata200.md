Dúvida**Alteração de estruturas não está sendo feita corretamente quando utilizado o ExecAuto do programa MATA200 (Estruturas).  
  
**Ambiente**Protheus – ADVPL – A partir da versão 12.1.017  
  
**Solução**Foram realizados ajustes no cadastro de estruturas (MATA200), para que a execução automática seja realizada corretamente para a alteração de estruturas.   
Quando for utilizada a operação de Alteração de Estruturas, os componentes que não forem informados no array de componentes deverão ser excluídos da estrutura, sendo que a exclusão do componente deverá funcionar da mesma maneira que ocorre quando o programa é executado pelo menu do sistema.
