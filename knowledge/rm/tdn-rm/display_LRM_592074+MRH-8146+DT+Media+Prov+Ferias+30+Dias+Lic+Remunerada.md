# MEDIA NA PROVISÃO DE FÉRIAS COM 30 DIAS DE LICENÇA REMUNERADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Provisão de Férias* |
| **Situação/Requisito:** | No cálculo de média da provisão de férias está considerando a perda do período aquisitivo com 30 dias de licença remunerada.  O correto é considerar a perda com mais de 30 dias de licença, ou seja, à partir de 31 dias de afastamento tipo R. |
| **Solução/Implementação:** | Ajuste no cálculo de média da provisão de férias para considerar a perda do período aquisitivo somente quando o funcionário ficar 31 dias ou mais com afastamento tipo R - Licença Remunerada. |
| **Tickets relacionados:** | MRH-8146 |
