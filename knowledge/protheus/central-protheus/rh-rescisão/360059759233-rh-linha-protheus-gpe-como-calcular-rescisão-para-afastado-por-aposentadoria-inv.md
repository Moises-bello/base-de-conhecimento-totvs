**Dúvida**Como calcular rescisão para afastado por aposentadoria invalidez?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Para cálculo da rescisão é necessário informar a data fim do afastamento aposentadoria por invalidez, desta maneira o cadastro do funcionário passa de situação Afastado para Normal e o sistema permite calcular a rescisão com data de desligamento a partir do dia seguinte do retorno:
