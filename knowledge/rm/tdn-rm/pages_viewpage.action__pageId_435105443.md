Neste cadastro/edição são inseridos os Valores de Integrações para cada componente, sendo que estes valores são inseridos na aba Valores de Integração do lançamento financeiro.   
 Os Valores de Integração equivalem aos Valores Opcionais que eram utilizados pelos Componentes do TOTVS Incorporação em versões anteriores

**Identificação**

Neste cadastro temos os seguintes campos:

Campo: Id do Valor de Integração  
 Descrição: Descrição do Valor de Integração.  
 Ação:

* Nada: Não realiza nenhuma ação no lançamento financeiro.
* Acrescenta - Acrescenta o valor no lançamento financeiro.
* Desconta - Desconta o valor do lançamento financeiro.

**Observação: O campo ação poderá ser trocado a qualquer momento para os valores de Integração do TIN. Independente se o valor de integração estiver sendo usado ou não.**

Ordem: Qual será a ordem do Valor de Integração.  
 Fórmula: Formula usada para o Valor de Integração.
