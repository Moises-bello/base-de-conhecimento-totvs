# ALTERAÇÃO GLOBAL DE TOMADORES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Alteração Global de tomadores* |
| **Situação/Requisito:** | Ao tentar alterar a quantidade de Dias para “31” na rotina “Alteração Global de Tomadores”, o sistema não permite avançar apresentando a mensagem “Total de dias a distribuir está superior a 30”. Porém, na visão Delphi utilizando a versão 11.82, o sistema permite que seja informado 31 dias e realiza a alteração em todos os tomadores informados no Filtro. |
| **Solução/Implementação:** | Permitir alterar a quantidade de dias para 31 na rotina de Alteração Global de Tomadores”. |
