# Matricular aluno em disciplina

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matricular aluno em disciplina* |
| **Situação/Requisito:** | *Ao realizar a matricula do aluno, mesmo a disciplina com pré-requisito de carga horária mínima definido o sistema está permitindo a matricula. No caso o sistema tinha que bloquear informando que o aluno não cumpriu a carga horária mínima exigida para poder matricular na disciplina com situação de matricula igual a pre-matriculado(Parâmetro de disciplina em curso não marcado).* |
| **Solução/Implementação:** | *Foi alterado o processo de matricula em disciplinas para que o sistema valide pre-requisito independente do status de matricula estar ou não como disciplina em curso(Parâmetro da situação de matricula) dessa forma ao executar uma matricula em disciplina o sistema valida os pre-requisitos de carga horaria, número mínimo de disciplinas cursadas, número mínimo de credito e disciplina.* |
