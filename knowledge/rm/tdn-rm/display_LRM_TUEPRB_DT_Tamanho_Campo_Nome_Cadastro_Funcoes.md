# ALTERAR O TAMANHO DO CAMPO NOME NO CADASTRO DE FUNÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Alterar o tamanho do campo Nome na tela de cadastro de funções.* |
| **Situação/Requisito:** | Ao cadastrar uma função no RM Labore, o campo Nome (PFUNCAO.NOME) não me permite informar um nome com mais de 40 caracteres. Nesse campo é informado o mesmo nome da função registrada no CBO disponibilizado pela tabela do MTE e vários CBOs possuem nome maior que 40 caracteres, o cliente por exemplo, possui algumas funções que chegam a 60 caracteres. |
| **Solução/Implementação:** | *Alterado o tamanho do campo Nome na tela de cadastro de função permitindo inserir até 100 caracteres, de acordo com a orientação do e-Social.* |
| **Chamados relacionados:** | TTAO67, TUEPRB |
