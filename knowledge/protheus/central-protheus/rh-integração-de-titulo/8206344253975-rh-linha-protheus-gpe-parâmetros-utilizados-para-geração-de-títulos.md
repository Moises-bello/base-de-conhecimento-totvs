**Dúvida**Parâmetros utilizados para geração de títulos.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**Os parâmetros que envolvem a geração de títulos:

**MV\_BTITADT** - Configura Integ. Título para Adiantamento. 0=Não Trata;1=Tratamento com Mensagem;2=Tratamento Com Bloqueio.   
**MV\_BTITFER** - Configura Integ. Título para Férias. 0=Não Trata; 1=Tratamento com Mensagem;2=Tratamento Com Bloqueio.   
**MV\_BTITFOL** - Configura Integ. Título para Folha. 0=Não Trata ;1=Tratamento com Mensagem;2=Tratamento Com Bloqueio.   
**MV\_BTITRES** - Configura Integ. Título para Rescisão. 0=Não Trata ;1=Tratamento com Mensagem;2=Tratamento Com Bloqueio.   
**MV\_CADFORA** - Cadastra Fornecedor Automaticamente Através da Rotina de Geração de Títulos (GPEM650)? .T. = Cadastra Automaticamente; .F. = Não Cadastra  
**MV\_CHAVDUP** - Chave para consistência de duplicidade "1" - Chave sem data de vencimento; "2" - Chave com data de vencimento;   
**MV\_CONDUPL** - Consiste Duplicidade? .T. - Consiste / .F. - Não Consiste vencimento | "3" - Consiste com data de vencimento  
**MV\_RATITM** - Define se realizará rateio por Item Contábil na integração de títulos.
