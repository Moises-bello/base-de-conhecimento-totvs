**Excluir Avaliação de Desempenho por Competências**

Por este processo é possível excluir as respostas de uma avaliação.

**Observação**

O sistema deve excluir a avaliação se:

- a data atual estiver entre a data de abertura e data limite de execução;

- se o processo de "Finalizar avaliação de desempenho" não tiver sido executado.
