Nesta opção, serão exibidos os tipos de componentes, onde estes serão associados a um componente para que posteriormente seja possível criar uma modalidade de venda.

Esta é uma tabela fixa do sistema, o usuário não tem permissão para incluir, alterar ou excluir dados.

Para entender o tipo de componente, devemos primeiramente explicar o que é um componente. Como o próprio nome diz, componente é o que compõe uma modalidade de pagamento ou modalidade de venda, ou seja, como será o financiamento de uma subunidade.

Ex. Podemos vender uma apartamento, nas seguintes condições, Entrada, 36 Parcelas Mensais, 2 Parcelas Semestrais, 1 Parcela de Chaves, sendo que as parcelas serão corrigidas pelo IGPM + juros de 1 % juros após a entrega do empreendimento. Portanto, chamamos de componente, a Entrada, as Parcelas Mensais, as Parcelas Semestrais, a Correção Monetária, os Juros, etc.

Contudo, componentes com as mesmas características são de um mesmo e único tipo de componente, no caso, Parcelas Mensais, Parcelas Semestrais são do tipo de componente "Principal", pois elas tem o mesmo comportamento no plano de financiamento, o que muda é só a periodicidade e o número de parcelas financiadas. Já o componente "Correção Monetária" é do tipo "Correção Monetária" e "Juros após entrega" é do tipo "Juros Fixo".
