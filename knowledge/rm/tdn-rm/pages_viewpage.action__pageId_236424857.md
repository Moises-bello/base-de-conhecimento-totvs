# Data de Entrada na Elaboração de APACs

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Faturamento | Elaboração de APACs | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server e Oracle |
| **Tabelas Utilizadas:** | SZPARCIALATEND |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Realizada alteração para que seja exibido o campo "Data de Entrada" na tela de visão da Elaboração de APACs, relativo a data de início de atendimento do paciente.

## Procedimento para Utilização

1. Acesse o **TOTVS Gestão Hospitalar**.
2. Acesse o menu **Faturamento/ Faturamento SUS /Elaboração de APACs**.
3. Verifique o campo "**Data Entrada**" na visão da tela.
