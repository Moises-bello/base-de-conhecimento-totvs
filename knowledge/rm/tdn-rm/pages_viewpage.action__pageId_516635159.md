## **02. SITUAÇÃO/REQUISITO**

O usuário do TOTVS educacional necessita ativar a importação dos dados de mensagens do Azure para a base RM

## **03. SOLUÇÃO**

Criando a nova funcionalidade para que seja possível importar os dados das mensagens de notificação do Azure para a base RM através do novo módulo disponível em: **TOTVS Gestão Educacional | Atividades Acadêmicas | Central de Comunicações | eduCONNECT | Importação de Mensagens de Notificação.**
