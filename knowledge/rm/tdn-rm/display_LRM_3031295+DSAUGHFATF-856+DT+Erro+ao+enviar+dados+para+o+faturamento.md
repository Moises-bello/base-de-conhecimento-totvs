# Erro ao enviar dados para o faturamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Informações Cirúrgicas |
| **Situação:** | Ao realizar o processo de envio de dados para o faturamento, o sistema informa que o campo SEQPARCIAL não pode ser do tipo nulo. |
| **Solução:** | Ajuste realizado para que os campos que são de preenchimento obrigatório sejam preenchidos no lançamento dos dados para o faturamento. |
