---

* [Desenvolvimento sobre a plataforma](http://tdn.totvs.com/x/PYSbC): Permite visualizar os tópicos referentes ao desenvolvimento sobre a plataforma.

* [hAPI](http://tdn.totvs.com/x/8uAlE): Permite verificar os métodos disponíveis. Acesse o link para conferir.

* [docAPI](http://tdn.totvs.com/x/x_MlE): Variável que permite acesso a funções relacionadas a documentos, podendo ser utilizada nos eventos. Acesse o link da documentação para visualizar os métodos disponíveis.

* [Mecanismo de atribuição](http://tdn.totvs.com/x/d_0lE): Permite que o usuário os utilize para criar uma lista de possíveis usuários para uma atividade. Acesse o link para ter acesso a todos os detalhes.

* [Mensagens de log para processos](http://tdn.totvs.com/x/u5QKDg): Guia que permite auxiliar na ativação e compreensão do conjunto de mensagens de log que podem trazer informações sobre solicitações de processo. Acesse o link para conferir a documentação.

* [Parâmetros](http://tdn.totvs.com/x/BuYlE): Permite conferir os tipos de parâmetros utilizados no desenvolvimento do processo sob a plataforma. Acesse o link para conferir mas informações.

* [Tratamento de exceções](http://tdn.totvs.com/x/MO0lE): Permite acessar os modelos de tratamentos de exceções para cada um dos eventos citados. Acesse o link e confira os modelos para utilização.

* [Eventos de processos](http://tdn.totvs.com/x/htAlE): Permite visualizar todos os eventos e exemplos de implementação de cada um deles*.* Acesse o link da documentação e confira as informações de todos os eventos.

* [Eventos finais de processo](http://tdn.totvs.com/x/RoSNBw): Permite visualizar a descrição dos tipos de eventos finais de um processo. Acesse o link da documentação e veja as informações referente a cada um deles.

* [Eventos de notificação](http://tdn.totvs.com/x/_5X5Cw): Guia que permite visualizar a configuração do *widget* específico e um evento de notificação. Acesse a documentação e confira os detalhes passo a passo.

* [Acompanhamento de eventos](http://tdn.totvs.com/x/ZvwlE): Permite acompanhar a execução de eventos pelo componente loading. Acesse a documentação através do link e confira os exemplos de utilização deste componente.
