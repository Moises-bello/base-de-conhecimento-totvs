**Dúvida**

É possível incluir campos customizados em um grupo de campos?  
  
**Ambiente**

Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**

O grupo de campos existe para garantir que as tabelas em si, tenham o mesmo tamanho de campo, por exemplo, o código do produto, imagina que você quer alterar na SB1, ai vai ter que alterar na SB2, SC6, SD2, SD1, SC7, etc… para não ter que alterar uma a uma das tabelas, é só alterar no Grupo de Campos.

Este recurso foi criado para facilitar e para garantir a integridade das informações salvas no Protheus, visando que o campos que possuam a mesma informação em tabelas diferentes tenham o mesmo tamanho.

Prezando a garantia da integridade dos dados hoje não é permitido incluir campos customizados em um grupo de campos já existente e nem criar um grupo de campos novo.
