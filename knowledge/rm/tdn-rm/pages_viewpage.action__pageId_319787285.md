A opções do registro incluem propriedades avançadas do gerador de saídas. Estas propriedades normalmente não devem ser alteradas pois são de uso interno da TOTVS e para utiliza-las é necessário um estudo caso a caso.

![](/download/attachments/319787285/opcoes_do_registro.png?version=1&modificationDate=1512921870000&api=v2)

1Gravar arquivo parcial em disco

Esta opção avançada permite a geração parcial de arquivos em disco, só deve ser habilitada após um estudo de caso do Layout pois pode causar efeitos colaterais indesejáveis.

2Gravar arquivo parcial dos registros filhos

Esta opção avançada permite a geração parcial de arquivos em disco, só deve ser habilitada após um estudo de caso do Layout pois pode causar efeitos colaterais indesejáveis.

3Gerar somente se possuir registro filho

Utilize esta opção para gerar o registro selecionado somente se ele possuir registros filhos, caso não possua nenhuma informação será gravada no arquivo de saída.

4Id do Registro

Este Id é utilizado para a integração do Gerador de Saídas RM com o projeto TAF.
