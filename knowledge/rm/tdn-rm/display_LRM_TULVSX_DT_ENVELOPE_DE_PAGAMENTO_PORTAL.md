|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |

| **Função:** | *Envelope de Pagamento (Portal)* |
| **Situação/Requisito:** | *Ao tentar acessar o envelope de pagamento do portal utilizando uma conexão segura (https) o usuário é redirecionado para o protocolo comum (http), causando erros de timeout ou de exibição do relatório.* |
| **Solução/Implementação:** | *Foi corrigido o redirecionamento para levar em conta corretamente o protocolo utilizado pelo cliente.* |
