**Utiliza módulo de condomínio:** Marque essa opção se deseja utilizar o módulo de condomínio. Para maiores informações sobre esse módulo, [consulte nossa documentação](https://tdn.totvs.com/pages/viewpage.action?pageId=438279824).

**Nomes para o empreendimento, unidade e subunidade:** Preencha aqui nestes campos os nomes que irá utilizar para as entidades listadas. Essa modificação irá abranger todos os menus onde essas entidades interagem, tanto no módulo de Condomínio, quanto no [M](https://tdn.totvs.com/pages/viewpage.action?pageId=641464976)[ódulo de Shopping.](https://tdn.totvs.com/pages/viewpage.action?pageId=641464976)

Importante: É imprescindível que, ao alterar os padrões de nomes das entidades, que seja reiniciado o sistema assim como o rm host. Isso deve ser realizado para que qualquer cache que envolva parâmetros seja refeito e com isso as modificações sejam aplicadas corretamente.
