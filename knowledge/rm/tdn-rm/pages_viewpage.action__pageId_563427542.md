## **01. VISÃO GERAL**

Após Emitir o exame corretamente o próximo status e o Entregar Exame - Status F

Ao clicar em Salvar e exibido a seguinte tela.

Com as devidas validações:  
Data Entrega maior que data atual o sistema emite um alerta não permitindo que seja salvo o responsável para buscar o laudo.  
Data Entrega menor que data do status de Liberação o sistema emite um alerta não permitindo que seja salvo o responsável para buscar o laudo.  
Hora Entrega: não pode ser em branco.  
Quando clicado em "Próprio Cliente" o sistema preenche automaticamente o campo "Nome responsável pela busca:"  
Quando clicado em "Outros" é habilitado um contador de caracteres para preenchimento manual. (O campo aceita um limite máximo de 50 caracteres)

Ao clicar em Salvar o exame atualiza para o Status F (Entrega Laudo)

Ao clicar em Cancelar o sistema aborta o processo.
