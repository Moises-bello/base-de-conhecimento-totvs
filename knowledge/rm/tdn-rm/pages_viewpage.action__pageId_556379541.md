Requisitos mínimos para utilização da funcionalidade:

* Sistema Operacional: Windows 8, 8.1, 10 ou Server 2012;
* Framework 4.7.2; (até a versão 12.1.33)
* Framework 4.8; (a partir da versão 12.1.34)
* [Microsoft Visual C++ 2013 Redistributable](https://download.microsoft.com/download/2/E/6/2E61CFA4-993B-4DD4-91DA-3737CD5CD6E3/vcredist_x64.exe)
* Microsoft Visual C++ 2015-2019 Redistributable

Sistemas operacionais **não** suportados pelas funcionalidades:

* Windows 7 e Server 2008;

**Observação:**

Caso o modelo 3D não esteja sendo exibido:

* Verifique se a biblioteca "**Microsoft Visual Studio C++ 2013**" está instalado na máquina cliente. (x64 para o sistema operacional de 64 bits ou x86 para o sistema operacional de 32 bits)
* Faça o download do cliente do componente xBIM: <https://docs.xbim.net/downloads/xbimxplorer.html> e instale na máquina. Após a instalação, abra o arquivo IFC e verifique se ocorreu algum erro log no menu: View → Developer windows → Information Log

* Caso a tela da visualização 3D esteja com problemas de escala: Altere as seguintes configurações em: 
  + Configurações de exibição -> Configurações de escala avançadas

**Window 10**

**Windows 11**

Colocar a escala como 100%

* **Observação:** Caso as fontes fiquem ilegíveis por causa do tamanho pequeno, recomendamos reduzir o tamanho da tela.
