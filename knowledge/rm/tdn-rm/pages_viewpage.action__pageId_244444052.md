# CÁLCULO SALÁRIO FAMÍLIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Salário Família* |
| **Situação/Requisito:** | Cálculo do salário família não considera como base somatório de proventos das atividades em caso de múltiplo vínculo pois não identifica o múltiplo vinculo.   E, de acordo como Ministério do Trabalho “Considera-se remuneração mensal o valor total do respectivo salário-de-contribuição, caso o cidadão exerça mais de uma atividade”. |
| **Solução/Implementação:** | *Ajustado regra quando deve ou não carregar os dados do múltiplo vínculo para o cálculo do salário família.* |
