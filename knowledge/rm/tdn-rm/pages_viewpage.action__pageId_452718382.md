**Pasta Identificação - Requisição Geral**

Na pasta Identificação os seguintes dados devem ser informados:

**Número -** Gerado automaticamente e com valor único.

**Status -** Será apresentado logo após a abertura da requisição como  "Pendente". Este campo será alterado a medida que a requisição for avançando no fluxo de aprovações assumindo os valores parametrizados para cada etapa.

Para verificar a parametrização acesse: Configurações | Tipos de Requisições. Os status que poderão ser definidos pelo fluxo de aprovação são "Em Andamento", "Aprovado" e "Reprovado".

Os status "Suspenso" e "Cancelado" serão definidos conforme a utilização do processo "Suspender requisição " e "Cancelar Requisição" respectivamente. O status "Concluído" será determinado quando o usuário acessar Processos | Concluir Requisição.

**Os status das requisições são representados pelas cores:**

Aprovada – cor verde

Cancelada – cor preta

Concluída – cor roxa

Em Andamento – cor amarela

Pendente – cor laranja

Reprovada – cor vermelha

Suspensa – cor azul

**Aprovador Atual -** Este campo não é editável e apresentará o nome do aprovador atual da requisição, ou seja, o responsável atual pela requisição, conforme definição do fluxo de aprovações.

**Data de conclusão -** Irá apresentar a data em que a requisição foi concluída.

**Finalidade -** Deverá ser informada a finalidade da nova requisição. Os novos tipos de requisição cadastrados em Configurações | Tipos de Requisição estarão disponíveis para escolha.

**Requisitante -** O Gestor de RH pode definir como requisitante qualquer funcionário de qualquer coligada. Caso a requisição seja aberta pelo Totvs RM Portal o requisitante será o usuário logado.

**Previsão -** Deverá ser informada uma data prevista para finalizar a requisição geral.

**Justificativa -** Ao solicitar uma requisição deverá ser informada uma justificativa para tal solicitação. Este campo poderá ser alterado enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado.
