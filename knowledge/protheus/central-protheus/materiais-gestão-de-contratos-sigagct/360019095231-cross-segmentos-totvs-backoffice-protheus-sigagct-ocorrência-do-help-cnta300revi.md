**Dúvida**

Ocorrência do Help CNTA300REVIND ao revisar um contrato

**Ambiente**Microsiga Protheus – Gestão de Contratos – A partir da versão 12  
  
**Solução**

Ao revisar um contrato, o sistema apresenta help CNTA300REVIND impedindo o processo. Como solucionar esta mensagem?

Este help é apresentado quando a revisão for realizada com tipo Reajuste ou revisão de Índice.

Para que não seja apresentada esta mensagem é necessário que o campo 'Reajuste S/N" (CN9\_FLGREJ - 1=Sim; 2=Nao) esteja igual a 1, para que o contrato esteja hábil para realização de Revisão Reajuste ou Índice.
