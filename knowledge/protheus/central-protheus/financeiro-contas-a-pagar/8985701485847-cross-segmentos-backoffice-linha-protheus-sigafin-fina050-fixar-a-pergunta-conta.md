![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00** **Dúvida**  
Como fixar a pergunta do menu F12 do browser na rotina FINA050 para que os usuários não alterem?  
  
**Ambiente**Cross Segmento - Backoffice Linha Protheus - Financeiro - FINA050 - Todas as versões  
  
**Solução**

Para solucionar essa dúvida, realize os seguintes passos:

No **Configurador(SIGACFG)** -> **Dicionário** -> **Base de Dados**  -> **Perguntas**.

Em pesquisar (botão lupa ) acesse a Pergunta (**FIN050**), item 4 deixando a opção  
**Pré Seleção (Combo)** = 1  (sim);   
  ![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8985485249175/mceclip2.png)

 Acesse o módulo de **Financeiro (06)**  -> **Atualização** -> **contas a pagar** -> **contas a pagar**

 Aperte na tela **F12** para a visualização do menu;

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8981710429463/mceclip0.png)
