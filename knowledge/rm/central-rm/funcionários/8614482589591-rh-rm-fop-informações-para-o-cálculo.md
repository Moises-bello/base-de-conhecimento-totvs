**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura:**00:00:40 min** **Dúvida**Quais informações importantes sobre cálculo no módulo folha de pagamento?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**As informações para o cálculo da folha de pagamento são muito importantes para o departamento pessoal, pois são dados que serão transformados mensalmente em valores para o empregado.

Como o orientação referente a informações para o cálculo da folha de pagamento é demasiado extenso, foi disponibilizado um manual completo no TDN para servir de base de consulta e para tirar as dúvidas referente a alguns pontos sobre estas informações. **Acesse o link: [Informações para o cálculo](https://tdn.totvs.com.br/pages/releaseview.action?pageId=452719181)**
