# Ajuste no preenchimento da justificativa de prescrição

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário Eletrônico do Paciente |
| **Situação:** | Ao preencher a justificativa de antibióticos o sistema apresentava uma mensagem e não era exibida a tela de justificativa. |
| **Solução:** | Realizado ajuste para que o sistema permita registro de justificativa de prescrição. |
