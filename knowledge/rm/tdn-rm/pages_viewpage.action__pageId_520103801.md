# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO PATRIMONIAL |
| **Versões:** | 12.1.23 |
| **Ocorrência:** | Integrar Aquisição Pendente |
| **Ambiente:** |  |
| **Passo a passo:** | Na [Integração de Compra](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.integraAquisicaoCompra.aspx) ao optar por gerar/informar o código e número do patrimônio manualmente, as opções abaixo deverão ser desmarcada no processo de Integração de Aquisição:      Apos desmarcar as opções acima o processo de integração é concluído normalmente, porém, ao final será apresentada a seguinte mensagem: “Os patrimônios gerados a partir dos produtos pertencentes à nota xxx deverão ter seus códigos e números preenchidos. Este procedimento deverá ser realizado através do processo de integração de aquisições pendentes”.    As integrações pendentes são apresentadas no menu **Utilitários | Integrar Aquisições Pendentes**. A aquisição deverá ser editada, inserir as informações que ficaram pendentes para o cadastro de patrimônio (código do patrimônio e número do patrimônio), salvar e posteriormente realizar sua integração através de **Processos | Integração de aquisições pendentes**. |
| **Observações:** | **Exclusão de Patrimônio originado do Gestão de Compras:**  Ao realizar exclusão de patrimônio originado do Gestão de Compras, o sistema irá automaticamente excluir todos registros vinculados aquela nota. |
