# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento |
| **Função:** | Cadastro de Natureza de Inversa. |
| **Situação/Requisito:** | 1ª inconsistência: O nome da janela está como "Monitor de Arquivos Totvs Colaboração"  2ª inconsistência: Ao clicar em salvar os registros dos campos "Natureza Origem" e "Natureza Inversa" desaparecem.  3ª inconsistência: O campo de código da natureza está setado para buscar pelo ID, e não pelo código da natureza (exemplo "1.101.01")  4ª inconsistência: As colunas "ID Natureza Origem" e "ID Natureza Inversa" estão com os nomes "IDNATORIGEM" e "IDNATINVERSA". |
| **Solução/Implementação:** | 1ª inconsistência: Nome da Janela corrigido para "Natureza Inversa para Totvs Colaboração."  2ª inconsistência: Melhoria para que os campos "Natureza Origem" e "Natureza Inversa" não amis desapareçam.  3ª inconsistência: Melhoria para que o campo exiba o Código da Natureza e não o ID>  4ª inconsistência: As colunas são internas e não devem ser exibidas. Melhoria para não exibição das colunas. |
