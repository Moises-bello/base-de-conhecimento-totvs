# INTEGRAÇÃO LABORE X AVERBAÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Integração Labore x Averbações* |
| **Situação/Requisito:** | *A integração do Labore com Averbações limita os cadastros de empréstimos que chegam ao sistema com um código de exatamente 9 caracteres, sendo que pelo RM sempre foi possível cadastrar até 20 caracteres.* |
| **Solução/Implementação:** | *Aumentar o limite de caracteres do código do empréstimo para ficar igual ao limite do sistema* |
