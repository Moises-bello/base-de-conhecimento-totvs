# Configuração de Horários no Formato Americano

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Saúde. |
| **Módulo:** | TOTVS Gestão Hospitalar. |
| **Função:** | Agenda . |
| **Situação:** | Casos a data do sistema estivesse configurado para o formato americano, o sistema não convertia o formato para o Inglês, através do caminho do sistema Agenda/Configurações/Eventos/Novo. |
| **Solução:** | Realizada a alteração no sistema para que sempre exiba o formato Inglês. |
