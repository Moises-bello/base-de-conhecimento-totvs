# GERAÇÃO DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo. |
| **Função:** | Geração de movimento |
| **Situação/Requisito:** | Ao gerar movimento, através do processo seletivo, ocorria duplicidade caso o lançamento financeiro tivesse dois boletos, sendo um deles cancelado. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimento, através de um processo seletivo, de forma que, sejam gerados movimentos apenas para boletos em aberto, evitando assim, que movimentos sejam gerados em duplicidade caso um lançamento financeiro possua boletos cancelados associados a ele. |
