| **Ocorrência:** | Versão do Layout |
| **Ambiente:** |  |
| **Passo a passo:** | **Alteração de Versão do Layout**    A cada novo layout disponibilizado pela Receita é necessário alterar a versão do arquivo(layout) do SPED Fiscal, pois esta informação é consistida pelo PVA.  Para a rotina do SPED FISCAL, não há no Gestão Fiscal um layout/ arquivo (Gerador de Saídas) para ser importado como em outras rotinas. Exemplo: EFD Contribuições, NFTS(SP), DIEF(PA) e SEF II(PE).  Na própria tela de geração da rotina, há o campo 'Versão', nele contém o valor do layout atual. Este valor é *default*do sistema.        Caso não seja apresentada a versão atual, atualize seu ambiente.  Esse campo é editável e poderá digitar manualmente o código da versão atual. |
