# MATRICULAR ALUNO INADIMPLENTE NA DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | *****Totvs Educacional***** |
| **Função:** | Matrícula do Aluno |
| **Situação/Requisito:** | O sistema está parametrizado para bloquear a matrícula para alunos inadimplentes, porém o usuário possui permissão especial para essa matrícula. Ao realizar a matrícula o sistema não inclui a disciplina para o aluno. |
| **Solução/Implementação:** | Alteração no sistema para permitir a matrícula em uma disciplina quando está parametrizado para bloquear a matrícula para alunos inadimplentes e o usuário possui permissão especial para essa matrícula. |
