Este assistente irá auxiliá-lo na cópia de registro(s) entre as coligada(s) do sistema.  
 Para utilizar o assistente clique no botão Avançar.  
    
 **Parâmetros da cópia**

Na janela de Parâmetros da cópia o sistema lista todas as coligadas disponíveis na base de dados para se fazer à cópia de registro. Selecione a coligada ou as coligadas que deseja fazer a cópia e clique no botão Avançar.  
    
 **Observação**

A coligada não ficará disponível caso o usuário não tenha permissão de incluir Rateios de Eventos na coligada destino.  
    
 **Substitui registros no destino se eles já existirem**

Marque esta opção quando já existir o Rateio de Evento na coligada de destino e deseja alterar seus dados pelos dados do Rateio de Evento da coligada de origem. Caso contrário o sistema manterá os dados do Rateio de Evento na coligada de destino.  
    
 **Concluindo o Assistente de Cópia de Registros entre Coligadas**

Para fazer a cópia do Rateio de Evento entre as coligadas clique no botão 'Concluir'.
