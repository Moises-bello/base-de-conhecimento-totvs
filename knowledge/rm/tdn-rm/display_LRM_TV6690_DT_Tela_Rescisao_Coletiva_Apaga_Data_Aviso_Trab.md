# TELA DA RESCISÃO COLETIVA ESTÁ APAGANDO A DATA DO AVISO TRABALHADO AO AVANÇAR PARA PRÓXIMA PASTA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Coletiva* |
| **Situação/Requisito:** | *Na tela da Rescisão Coletiva, quando não tem aviso prévio indenizado e é informada a Data do Aviso Trabalhado, ao avançar para a próxima pasta e informar a Data da Demissão, a Data do Aviso Trabalhado é deletada na tela anterior.*  *Com isto, a informação não é gravada para o funcionário demitido, e gera inconsistência de informação no relatório do TRCT.* |
| **Solução/Implementação:** | *Ajuste na tela da Rescisão Coletiva para nunca apagar a Data do Aviso Trabalhado informada pelo usuário..* |
| **Chamados   relacionados:** | *TV6690, TVAQXL* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
