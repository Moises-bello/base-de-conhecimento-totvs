Comandos de Componentes Visuais

Os comandos dos componentes visuais do AdvPL permitem a utilização de muitas das classes da interface visual do AdvPL através de instruções mais simples de serem codificadas e compreendidas. No momento que o código fonte AdvPL é compilado, as chamadas escritas em código como comandos são traduzidas para as chamadas dos métodos e/ou construtores das respectivas classes de interface. Isso é muito útil para codificar e entender o código escrito, pois a sintaxe via comandos utiliza palavras-chave para a passagem de parâmetros, tornando o código mais intuitivo e favorecendo a legibilidade do código e manutenção.
