# Melhoria no Processo de Associação de Lançamentos Fiscais

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Processo de Associação de Lançamentos Fiscais |
| **Situação/Requisito:** | Criar uma nova action do Processo para que seja possível executar o processo através do Utilitários  sem ser pela grid de Lançamentos.  Isso tornou-se necessário por causa do volume de dados dos clientes. Além disso,  permitir que o Processo seja agendado por Job. |
| **Solução/Implementação:** | Processo de Associação Lançamentos de Saída criado no Menu Utilitários (Com Filtro de Lançamentos Fiscais).  Obs.: A Permissão para acesso ao Processo e a mesma do Processo que se encontra na visão de Lançamentos de Saída. |
