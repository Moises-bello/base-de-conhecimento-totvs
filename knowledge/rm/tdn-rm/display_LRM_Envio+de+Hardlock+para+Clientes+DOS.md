FAQ: **Envio de Hardlock para Clientes DOS**

|  |  |
| --- | --- |
| Produto: | Unspecified |
| Ambiente: | Unspecified |
| Versão: | 10.80, 11.XX |

Solução

|  |
| --- |
| **Produto:** *FRAMEWORK***Versão:** *10.80* |
|  |
| **Assunto:***Envio de Hardlock para clientes DOS.* |
|  |
| Alguns clientes que possuem produtos da linha DOS estão recebendo o Hardlock. Isso tem causado algumas duvidas, tais como:  O cliente que usa os aplicativos da Linha DOS vai ser obrigado a usar servidor de licenças com Hardlock ?  **Resp:** NÃO, o licenciamento da linha DOS não mudou. Ele continua sendo efetuado apenas pelo Arquivo aponta. |
| Então porque os clientes DOS estão recebendo Hardlock?  **Resp:** Na nova forma de comercialização TOTVS, o cliente pode usufruir de todos os aplicativos da marca. Ele poderá instalar e testar algumas de nossas soluções para Windows , como por exemplo o CorporeRM.  OBS: Ter a licença para o aplicativo não isenta o cliente de passar por um processo de implantação para adequar o sistema a sua realidade. O suporte não implanta via telefone. |
