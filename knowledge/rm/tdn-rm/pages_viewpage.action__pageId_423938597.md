Esta funcionalidade só está disponível para as bases já migradas para o Novo Modelo do BackOffice.

Dentro do sistema de Gestão Contábil é necessário dar permissão aos usuários que ficarão responsáveis pela execução e cancelamento das Tarefas que forem solicitadas em módulo externo ao da contabilidade.

Esta permissão é feita dentro do próprio cadastro do Tipo de Tarefa. Para isto, edite-o e inclua os usuários que passarão a ser os responsáveis pelo gerenciamento deste Tipo de Tarefa.

**Importante**: Somente os usuários associados ao Tipo de Tarefa tem permissão para executar ou cancelar as solicitações agendadas.

Sobre o recebimento de Email:

* Os usuários responsáveis pela execução recebem notificações via e-mail quando uma nova tarefa é solicitada, entretanto, o usuário pode optar por não receber essas notificações, para isso basta desmarcar a caixa de seleção "Receber Email de Solicitações".
* O usuário solicitante recebe e-mail de confirmação quando a tarefa é executada ou cancelada, independente do parâmetro.

* **Atenção:** Para que as notificações sejam enviadas corretamente, o endereço de e-mail nos cadastros dos usuários deve estar preenchido e as informações para envio de e-mails dentro dos Parâmetros Globais devem estar cadastradas.
