**Dúvida**

Em qual situação o campo C7\_APROV é gravado, após aprovar o pedido de compras?

**Ambiente**

Protheus – Compras – A partir da versão 12

**Solução**

Referente a gravação o campo **C7\_APROV** com o código do Grupo de Aprovação, esta gravação é feita somente quando o tipo de alçada do Pedido estiver configurada como "**Alçada Padrão**" (Não sendo gravado o campo com a alçada por Entidades Contábeis).

[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Como configurar o Controle de Alçadas Padrão?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360006822671-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Como-configurar-o-Controle-de-Al%C3%A7adas-Padr%C3%A3o-)

No padrão este campo possui no seu Dicionário de Dados a Propriedade de "Visualizar", e é preenchido automaticamente pelo sistema no uso da alçada padrão como reportado acima, não sendo um campo para ser preenchido manualmente.
