# BAIXA DE CRÉDITOS/DEVOLUÇÕES VINCULADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Processo de Baixar Créditos/Devoluções Vinculados |
| **Situação/Requisito:** | Ao vincular um lançamento de nota fiscal com um crédito e realizar a baixa através do processo de "Baixar Créditos/Devoluções Vinculadas",  o processo calcula as retenções incorretamente, após a baixa. |
| **Solução/Implementação:** | Ajuste feito no processo de "Baixar Créditos/Devoluções Vinculados" para calcular corretamente as retenções após a baixa, quando é baixado  totalmente o lançamento de nota fiscal. |
