# Incluir Borderô para lançamentos de Distrato do Totvs Incorporação.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Inclusão de Borderô de Pagamento |
| **Situação/Requisito:** | Ao incluir lançamentos em um borderô de pagamento o sistema está chamando o serviço do SGI para atualizar as parcelas de distrato do contrato. |
| **Solução/Implementação:** | Realizada a validação no serviço de baixa não gerando atualização e reajuste ao inserir um item de baixa relacionado a borderô de pagamentos. |
