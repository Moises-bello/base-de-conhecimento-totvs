Existe algum campo que posso consultar os orçamentos gerados do PMS através da oportunidade.   
  
**Ambiente**  
Cross Segmentos - Backoffice Protheus - SIGAPMS - A partir da versão 12.  
  
**Solução**

Na Proposta Comercial é possível criar um orçamento através do Gestão de Projetos e amarrar com a Proposta.

Quando ocorre esta amarração o sistema preenche o campo **ADZ\_PMS**, **ADZ\_PMSVER** .

Na criação do orçamento o sistema cria um ID de forma automática na descrição (**AF1\_DESCRI**).   
**Este ID só é criado nesta integração.**
