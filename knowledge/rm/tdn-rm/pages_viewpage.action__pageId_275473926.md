# Bolsa Retroativa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Bolsa Retroativa |
| **Situação/Requisito:** | O sistema está permitindo alterar as informações de valores da bolsa no processo de bolsa retroativa mesmo a bolsa estando parametrizada para não permitir alteração. |
| **Solução/Implementação:** | Ajuste no processo de bolsa retroativa para que o sistema não permita que as informações dos valores da bolsa sejam alteradas quando a bolsa estiver parametrizada para não permitir a alteração. |
