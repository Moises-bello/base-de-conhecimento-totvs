Quando a propriedade "Detalhe contagem quando a fonte de dados está vazio" for 0 e o Subdetalhe do relatório não tiver dados a serem exibidos, as ligações de dados presentes no cabeçalho de página não serão exibidos.

EX:

No RM, o relatório não é exibido o Detalhe, porém, os dados de cabeçalho e rodapé são informados normalmente:

Após a conversão do relatório para o Smart View o mesmo não é exibido corretamente cabeçalho e rodapé de página.
