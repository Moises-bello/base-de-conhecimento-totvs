# Importação de Salário composto

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Importação de Dados do RM Labore |
| **Situação/Requisito:** | Na importação de dados do RM Labore, o sistema permite que seja importado Salário Composto com valor 0 para o campo NROSALARIO. Via sistema isso não é permitido, é apresentado um erro informando que o Número do Salário é obrigatório ser maior que 0. |
| **Solução/Implementação:** | Foi alterado para não permitir a importação de salários compostos com o NRPSALARIO de valor "0". |
