# Objetivo:

---

Fornecer à área de segmentos uma API para manipulação de planilhas eletrônicas.

# Descrição

---

      API é a abreviação do termo em inglês *Application Program Interface*. Uma API é um conjunto de rotinas e padrões estabelecidos por um software para a utilização das suas funcionalidades por aplicativos que não pretendem envolver-se em detalhes da implementação do software, mas apenas usar seus serviços.

     A API da Planilha RM está disponibilizada no assembly *RM.Glb.PlanilhaNet.Core.dll*. Dentro da arquitetura da Linha RM, esse assembly está disponível tanto no *Client Side* quanto no *Server Side*.

# Utilização

---

  Para utilizar a API, basta adicionar uma referência ao assembly *RM.Glb.PlanilhaNet.Core.dll*. Os detalhes sobre a utilização da API e sua documentação podem ser acessadas .

      Juntamente com a API foram desenvolvidos novos formulários para que o usuário possa fazer a manipulação das planilhas visualmente. Esses formulários foram disponibilizados no assembly *RM.Glb.PlanilhaNet.Windows.dll*. Eles são totalmente novos e oferecem suporte à Gráficos e as melhorias feitas nas Visões de Dados (Consultas SQL).

      Para habilitar a utilização o usuário deverá desativar a opção "Utilizar planilhas Excel" presente no cadastro de parâmetros globais. Quando essa opção está habilitada, o usuário poderá fazer uso da Planilha .Net, que é baseada no MS Excel, e da Planilha RM (Antiga). Caso contrário, os novos formulários serão utilizados. A nova API pode ser utilizada para criação/edição de planilhas que não serão salvas no banco de dados independente da opção escolhida.
