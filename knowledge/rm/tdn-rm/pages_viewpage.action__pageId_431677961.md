| **Passo a passo:** | **Introdução**    A Conversão RM IMOB/RM Bonum é o processo responsável pela conversão de todos os dados existentes no sistema RM IMOB para o sistema RM Bonum.    **Desenvolvimento/Procedimento**    Citaremos os passos para realização da conversão do RM IMOB para o RM Bonum para um sistema que não seja Multifirma. O RM IMOB também possui o conceito de Multifirma que citaremos posterioremente.    **1.****Para realizar o processo no RM Bonum deve-se acessar o menu Utilitários/Conversões/Base DOS p/Windows.**    · Antes de iniciar a conversão é muito importante que todo o **roteiro de conversão** seja lido. Para acessar o roteiro de conversão acesse o menu **Ajuda/Conteúdo** , dentro do **help** na aba **“Conteúdo”** acesse o item **“Roteiros de Operação”**. Ao clicar na opção de **“Pasta de Roteiros”** serão apresentados os roteiros disponíveis, entre eles o **Roteiro de Conversão RM IMOB/RM Bonum.**    · Leia todo o roteiro, pois o mesmo possui orientações importantes que devem ser feitas no **RM IMOB** antes da conversão.  OBS: Caso seja necessário utilizar o programa **CONSISTE** favor entrar em contato com equipe de suporte técnico para que o programa seja disponibilizado.    · Após leitura de todo o roteiro verifique também o **help**das informações da tela de conversão, após editar a tela de conversão clique no botão **“Ajuda”** para verificar as informações disponíveis sobre cada campo.    · Após realizar estes procedimentos para conhecimento do processo de conversão, inicie a conversão clicando no botão **“Converter”**    · Após clicar no botão **“Converter”** deve ser informado o local onde se encontra o diretório da firma que será convertida.  **Ex: Vamos supor que vamos converter a empresa “Exemplo”, então devemos informar o seguinte caminho, C:\RMIMOB\EXEMPLO.**    · Após informar o caminho do diretório será apresentada a seguinte mensagem:  “Caso já existam dados Cadastrados no RM Bonum, esses serão perdidos. Prosseguir a conversão?”    · Clicando em **Sim** será iniciada a conversão. Caso ocorra algum erro será apresentado um **log de conversão** que deverá ser analisado pela equipe de suporte técnico. Estes são os passos para realização de uma conversão de dados do **RM IMOB** para **RM Bonum** para sistemas que não sejam **Multifirmas.**    Citaremos agora os passos para realização da conversão do **RM IMOB Multifirma** para o **RM Bonum**. Um sistema **Multifirma**significa que é permitido que sejam cadastradas várias **firmas** dentro do **RM IMOB**.    Ex: Vamos supor que um escritório de contabilidade vai realizar o controle de imobilizado de várias empresas. Então o escritório de contabilidade adquire o RM IMOB Multifirma. Assim todas as empresas clientes do escritório serão cadastradas no sistema como firmas. Para cada firma será criado um diretório de dados dentro do diretório do RM IMOB.    **2.****Para realizar o processo de conversão no RM Bonum para um sistema RM IMOB Multifirma deve-se acessar o menu, Utilitários/Conversões/Conversão de Coligada DOS Windows**    · Antes de iniciar a conversão é muito importante que todo o roteiro de conversão seja lido. Para acessar o roteiro de conversão acesse o menu **Ajuda/Conteúdo** , dentro do **help** na **aba “Conteúdo”** acesse o item **“Roteiros de Operação”.** Ao clicar na opção de **“Pasta de Roteiros”** serão apresentados os roteiros disponíveis, entre eles o **Roteiro de Conversão RM IMOB/RM Bonum.**    · Leia todo o roteiro, pois o mesmo possui orientações importantes que devem ser feitas no **RM IMOB** antes da conversão.  OBS: Caso seja necessário utilizar o programa **CONSISTE** favor entrar em contato com equipe de suporte técnica para que o programa seja disponibilizado.    · Após leitura de todo o roteiro verifique também o **help**das informações da tela de **conversão**. Após editar a tela de **conversão**clique no botão **“Ajuda”** para verificar as informações disponíveis sobre cada campo.    · Após realizar estes procedimentos para conhecimento do processo de conversão, na tela de conversão, clique no botão “**Seleciona FIRMASAT”.**Após selecione o arquivo **FIRMASAT.DAT** que fica dentro do diretório do **RMIMOB**. Este arquivo contém o cadastro das firmas a serem convertidas**.**      · Em seguida entre com os dados de cada uma das firmas que serão convertidas. Informe um **CNPJ**válido, do contrário sua conversão será **cancelada**. Três dos campos visualizados são de preenchimento obrigatórios **(CNPJ, Nome Fantasia e Razão Social)**, os demais ficam a sua escolha. Repita este passo para cada uma das firmas a serem convertidas. Note que no campo **Nome Fantasia** o sistema trará o nome da **firma** informado no **RMImob**. Este campo pode ser **alterado**. Clique no botão **Próximo**até que o botão **CONCLUIR** apareça.    · O sistema abrirá uma nova tela onde todas as novas coligadas ficarão visíveis. Você poderá escolher novamente qual ou quais filiais deseja converter. Caso desista de converter alguma, posicione o cursor sobre ela, clique com o botão direito e escolha a opção **"Não Inclui".**    · Para as coligadas que devem ser convertidas clique no ícone **“Converte Coligada DOS”**. As coligadas que foram convertidas para o RM Bonum aparecerão **riscadas** e no campo **AÇÃO** aparecerá escrito **"Não Inclui"**, pois estas já foram incluídas e não poderão ser incluídas novamente.    Cada uma das firmas convertidas será uma nova coligada no seu sistema, e o **CNPJ** será o da **Filial selecionada.** Caso ocorram erros na conversão, favor entrar em contato com o suporte técnico para análise da situação.    **Informações Adicionais**  Após a conversão é muito importante que sejam feitas a conferências dos dados e relatórios para certificar que os dados estão ok. |
