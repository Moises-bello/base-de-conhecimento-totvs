# Associação de Action

---

   Uma vez criado o cubo, vamos vincular a action da tela dos movimentos lançados no sistema para que através do cubo, possamos acessar a tela do sistema via action para conferências ou quaisquer alterações no mesmo.

* Acesse o menu indicado para que possamos efetuar o vinculo da Action da tela de movimento ao nosso cubo :

* Será exibida a janela abaixo na qual devemos efetuar a ação que devemos executar na tarefa relacionada ao cubo:

* Clique em **Adicionar**, para localizarmos a Action da tela de movimentos:

* Depois em localizar, digite a palavra **MOVIMENTO**, para que seja listadas as Actions no sistema para você:

* Feito a seleção da Action iremos definir as ações no qual definimos as chaves para execução:

Clique em **OK**.

* Feito o processo, acesse o cubo, Clique com o botão direito do mouse sobre algum Movimento listado no cubo e clique em **MOVIMENTO**:

* Feito isso, verá que a tela do Movimento selecionado será aberta via Action do RMNucleus na visão do seu cubo.
