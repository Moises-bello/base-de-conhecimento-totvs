# TRANSFERÊNCIA DE OBJETO DE MANUTENÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Manutenção. |
| **Função:** | Transferência entre Locais. |
| **Situação/Requisito:** | Ao realizar a Transferência entre Locais para um objeto de manutenção estão sendo apresentados as localizações inativas. |
| **Solução/Implementação:** | Ao realizar a Transferência de Objeto de Manutenção, seja para Coligadas, Filiais ou Locais, no campo Localização Destino poderão ser selecionados somente os registros com situação ativo. |
