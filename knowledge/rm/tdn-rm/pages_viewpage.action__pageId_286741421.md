# PROJETOS DE PESQUISA E EXTENSÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Projetos de Inovação, Pesquisa e Extensão* |
| **Situação/Requisito:** | *Na criação de uma proposta de um projeto de pesquisa/extensão está sendo permitido o cadastro de bolsas e a vinculação dessas informações com participantes e planos de trabalho.* |
| **Solução/Implementação:** | *Após a informação de um edital externo, todos os campos relacionados a bolsas foram removidas dos cadastros de projetos.*  *As informações relacionadas a:*   * *Equipe* * *Plano de trabalho* * *Bolsas de pesquisa e pagamento* * *Receitas e despesas*   *não são destinadas a um edital externo e não serão disponibilizadas para o usuário, no cadastro de uma proposta para um projeto.* |
