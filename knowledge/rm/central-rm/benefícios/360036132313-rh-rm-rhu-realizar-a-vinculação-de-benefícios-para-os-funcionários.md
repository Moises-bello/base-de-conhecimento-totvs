Dúvida**Como realizar a vinculação de benefícios para os funcionários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - Todas as versões   
  
**Solução**Para realizar a vinculação de benefícios para os funcionários, siga os passos abaixo:

1. Acesse o menu **Valorização** >> **Processos** >> **Vinculação de Beneficio**:  
     
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/28411400854167)
2. Ao abrir o assistente, clique em avançar, selecione a opção '**Funcionário**' e faça o filtro para que liste os funcionários desejados:  
     
   ![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047292673)
3. Será apresentada uma interface onde serão exibidos os benefícios diretos e indiretos, os funcionários e seus dependentes.   
     
   Clique no botão incluir, selecione o beneficio o qual deseja vincular e informe a data da vinculação e clique no botão '**Ok**':  
     
   ![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047293413)  
     
   ![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046431574)
4. Após inserir o benefício, clique em '**Avançar**' e execute o processo:  
     
   ![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046432674)  
     
   ![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046432694)
5. Caso deseje realizar a vinculação para mais de um funcionário no mesmo processo, clique no botão '**Copiar**', faça a seleção dos funcionários para os quais irá ocorrer a vinculação dos benefícios, selecione-os, insira o tipo de origem de vinculação e ação para a vinculação dos benefícios:  
     
   ![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047293873)
6. Posteriormente, será exibida uma mensagem de confirmação, clique em '**Sim**'.   
   Avance e execute o processo:  
     
   ![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046432194)  
     
   ![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047294793)  
     
   ![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047294893)
7. Para realizar a vinculação para os dependentes funcionários, clique sobre o sinal '**+**' na frente do nome do funcionário para que liste os dependentes cadastrados.   
     
   Selecione o dependente desejado e clique em novo. A inclusão do beneficio dos dependentes, tanto individual quanto global, irá seguir conforme os mesmos passos para vincular o benefícios para os funcionários:  
     
   ![mceclip11.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047295353)  
     
   ![mceclip12.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047295833)
8. Para conferir se os benefícios foram vinculados acesse a guia **Acompanhamento** >> menu **Funcionários**, selecione o funcionário desejado e acesse a opção **Anexos** >> **Benefícios** >> **Benefícios Vinculados ao Funcionário**:  
     
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/28411400854807)
9. Para conferir os dos dependentes acesse a guia **Acompanhamento** >> menu **Funcionários**, selecione o funcionário desejado e acesse a opção **Anexos** >> **Folha de Pagamento** >> **Dependentes**.   
     
   Edite o dependente e acesse a opção **Anexos** >> **Benefícios** >> **Benefícios Vinculados aos Dependentes**:  
     
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/28411416986135)  
     
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/28411400856087)
