![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30087375406359) Tempo aproximado para leitura: **00:01:05 min** **Dúvida**O que é que indica o **Parâmetro MV\_AGRO049**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O Parâmetro MV\_AGRO049 - Indica status do Lote de Sementes em nota fiscal de devolução.

|  |  |
| --- | --- |
| **Linha de Produto:** | Microsiga Protheus |
| **Segmento:** | Agroindústria |
| **Módulo:** | SIGAAGR |
| **Rotina:** | O parâmetro é do tipo lógico e está localizado na rotina AGRUTIL.  Definir. indica que nas notas fiscais de devolução de lote de sementes o Lote de Sementes terá seu status como  "Não Aprovado" e será gravado histórico referente à alteração. |
| **Parâmetro(s):** | MV\_AGRO049 |
| **País:** | Todos |
| **Banco de Dados:** | Todos Homologados pela Totvs. |
| **Sistemas Operacionais:** | Todos Homologados pela Totvs. |
