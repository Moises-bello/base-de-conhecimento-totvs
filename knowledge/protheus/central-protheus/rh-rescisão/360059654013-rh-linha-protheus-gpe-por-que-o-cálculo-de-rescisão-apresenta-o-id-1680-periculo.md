**Dúvida**Por que o cálculo de rescisão apresenta o ID 1680-Periculosidade Férias Indenizadas?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**O ID 1680 (periculosidade férias indenizadas) se trata da periculosidade referente a verba indenizatória férias vencidas, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1680.**
