# CRIAR PARCELAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Educacional |
| **Função:** | Assistentes Criar Parcelas |
| **Situação/Requisito:** | Ao executar o processo "Financeiro/contábil | Assistentes | Criar Parcelas", quando não for informado o campo "Parcela Inicial", o sistema não estava gerando a quantidade de parcelas solicitadas. |
| **Solução/Implementação:** | Otimizado processo "Financeiro/contábil | Assistentes | Criar Parcelas", quando não for informado o campo "Parcela Inicial" o sistema irá verificar qual a última parcela existente no contrato do aluno e inserir a quantidade de parcelas solicitada a partir desta numeração. |
