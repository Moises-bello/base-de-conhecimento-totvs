# Fechamento de período

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Fechamento de período |
| **Situação/Requisito:** | O processo de fechamento de período não está gravando o valor de impairment na tabela ISALDOCALCULOPATRIMONIOMOEDA. Este comportamento está incorreto, pois impede que a reversão de impairment seja realizada após o fechamento. |
| **Solução/Implementação:** | O fechamento de período foi alterado para que o valor do impairment seja gravado na tabela ISALDOCALCULOPATRIMONIOMOEDA, possibilitando que a reversão de impairment seja realizada após o fechamento. |
