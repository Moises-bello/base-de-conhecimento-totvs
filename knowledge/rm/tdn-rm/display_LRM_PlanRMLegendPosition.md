# Descrição

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Bottom | Define que a legenda ficará na parte inferior. |
| Corner | Define que a legenda ficará no canto. |
| Top | Define que a legenda ficará no topo. |
| Right | Define que a legenda ficará à direita. |
| Left | Define que a legenda ficará à esquerda. |
| Custom | Define que a posição da legenda será definida manualmente ou será móvel. |
