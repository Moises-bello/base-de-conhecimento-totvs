**Agente Complementar**   
A Opção de Agente Complementar permite o usuário realizar a associação de Clientes pré cadastrados no sistema à venda.   
   
O Sistema permite que o usuário:

* Cadastre compradores por grupo no mesmo Contrato. Ao cadastrar as condições de venda/aluguel o usuário poderá selecionar um comprador para cada grupo. Ao selecionar um comprador para o respectivo grupo as parcelas geradas para o financeiro posteriormente serão geradas para o comprador informado no grupo.
* Gere Lançamentos Financeiros. Ao gerar lançamentos para o financeiro o sistema permite o seguinte: Se o usuário informar apenas o comprador na venda, todas as parcelas geradas para o financeiro serão criadas para este comprador. Agora se ele informar o comprador na venda e no grupo, será considerado o comprador informado no nível do grupo.
* Efetue um Aditivo de Agente Complementar. O Sistema permite, que após a venda estiver efetivada, e com o Contrato gerado, o usuário efetue um aditivo de troca de Agente Complementar, alterando o Agente Complementar da venda.  
     
  Outra forma de incluir um Agente Complementar no Contrato é através da opção Anexos | Agente Complementar. Com está opção é possível especificar o percentual do cliente no contrato, porém não possibilita gerar parcelas do cliente para o Fluxus.  
     
  Para incluir, excluir ou alterar um Agente Complementar, utilize os seguintes ícones:
* **Incluir**: Inclui um novo Agente Complementar na Venda/Aluguel
* **Editar**: Altera dados de um Agente Complementar da Venda/Aluguel
* **Excluir**: Exclui um Agente Complementar da Venda/Aluguel  
     
  Campos a serem preenchidos na inclusão de Agentes Complementares:
* **Cód. Agente Compl**.: Código que o sistema traz automaticamente para identificar o Agente Complementar.
* **Núm Venda/Aluguel**: Informa o número da venda. Campo preenchido automaticamente.
* **Data de Inclusão**: Data de Inclusão do Agente Complementar.
* **Data de Exclusão**: Data de Exclusão do Agente Complementar.
* **Cód. Tipo Agente Compl**.: Informe o tipo de agente. Na lista de opções serão apresentados todos os tipos cadastrados através do Menu Cadastro | Tabelas Adicionais | Tipo Agente Complementar;
* **Participação (%)**: Informa o percentual que esse agente complementar irá ter na participação da venda.
* **Cód. Cliente**: Informe o código do cliente que será o agente complementar. Na lista de opções serão apresentados todos os clientes e cônjuges cadastrados no sistema através do Menu Cadastro | Clientes;
* **Situação Ativa**: Informa se o agente está ativo ou não.
