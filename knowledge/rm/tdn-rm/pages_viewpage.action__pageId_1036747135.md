# 1. Sobre

De acordo com o **artigo 4º da Resolução ANTT nº 6024/2023** e a **Portaria ANTT nº 17/2024**, tornou-se obrigatório declarar no MDF-e os valores referentes aos pedágios pagos nos trechos de transporte.

# 2. Versões para atualização

A solução está disponível a partir dos patches:

Data: 

Biblioteca RM

* 12.1.2502.272
* 12.1.2506.233
* 12.1.2510.161

# 3. Principais Alterações

Foi disponibilizado no movimento o cadastro: Vale Pedágio, possibilitando informar um ou mais registros. Preenchendo o cadastro será gerado o grupo valePed no xml do MDF-e.

A aba Vale Pedágio será apresentada em: CTRC | CT-e sempre que o código de modelo do documento for 58.
