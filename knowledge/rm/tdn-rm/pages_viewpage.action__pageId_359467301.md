# CUSTO UNITÁRIO NA FICHA FÍSICA FINANCEIRA EM MOVIMENTAÇÕES DE DEVOLUÇÃO AO UTILIZAR O PARÂMETRO "UTILIZAR DEVOLUÇÕES COMO ESTORNO NA FICHA"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Utilizar devoluções como estorno na ficha. |
| **Situação/Requisito:** | Ao marcar o parâmetro para **Utilizar devoluções como estorno na ficha**, o Custo Unitário do movimento está sendo apresentado com o valor do Custo Unitário da última entrada realizada quando a movimentação é uma devolução lançada como estorno. |
| **Solução/Implementação:** | Realizado o ajuste para o sistema considerar sempre o Custo Unitário do movimento relacionado, caso esteja marcado o parâmetro para **Buscar custo no movimento relacionado**.  Se o parâmetro de buscar custo no movimento relacionado não estiver marcado no tipo de movimento em questão, deverá considerar o Custo Médio da última entrada realizada. |
| **Conversores e Parâmetros:** | Ambiente | Parâmetros | Gestão de Estoque, Compras e Faturamento | Acessar a Parametrização do Tipo de Movimento | Etapa Estoque - Custo | **Utilizar devoluções como estorno na ficha**. |

| **Requisito:** | MATESTCNTFTOF01-1987. |
