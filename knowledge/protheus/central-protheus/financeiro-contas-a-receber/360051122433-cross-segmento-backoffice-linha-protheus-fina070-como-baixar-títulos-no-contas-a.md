**Dúvida**  
Como baixar com data menor a emissão do título?  
  
**Ambiente**  
Microsiga Protheus – Financeiro – A partir da versão 11.80  
  
**Solução**  
Para que o sistema permita a baixa de um título no Contas a Receber com data inferior à data de emissão, é necessário alterar o parâmetro **MV\_ANTCRED** para **T**.  
Caso o parâmetro esteja configurado como **F**, o sistema exibirá a mensagem de ajuda **DATAERR**.
