![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que rescisão complementar por dissídio não apresenta diferença de Base FGTS rescisão ID 0293 e FGTS rescisão ID 0119?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para rescisão complementar por dissídio, a diferença de Base FGTS rescisão é calculada no ID 0337 e diferença FGTS rescisão no ID 0339. Para isso, devem existir uma verba relacionada ao ID 0337 e outra relacionada no ID 0339.
