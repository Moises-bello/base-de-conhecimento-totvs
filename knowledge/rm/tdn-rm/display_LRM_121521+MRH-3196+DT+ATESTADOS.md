| **Situação/Requisito/Story/Issue:** | Sistema está validando período ativo do CHRONUS durante atualizações realizadas no cadastro de atestado de funcionários que nunca utilizaram cartão de ponto. |
| **Solução/Implementação:** | No processo de cadastro de atestados, foi inserida uma verificação para o respectivo funcionário em relação a utilização do cartão de ponto. É verificado se, caso o funcionário não utilize cartão de ponto na data de início do afastamento, é permitido o cadastro de atestados fora do período ativo. Caso contrário, é feita a validação do Chronus. |
