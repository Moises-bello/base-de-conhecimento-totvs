**Dúvida**Quais são os Mnemônicos que tem impacto nos cálculos de Provisão de Férias e 13º Salário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução:**

**P\_REGPARCI -** Configuração de Férias por Regime Parcial.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360051400313-MP-GPE-Como-parametrizar-o-mnem%C3%B4nico-P-REGPARCI-F%C3%A9rias-por-regime-de-tempo-parcial).  
  
**P\_ADISMED** - Cálculo dos adicionais sobre as médias.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360016550212-MP-GPE-C%C3%A1lculo-de-adicionais-sobre-m%C3%A9dias). **P\_FDESFOL** - Ano e Mês de Início e Fim da Desoneração da Folha de Pagamento.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020939331-MP-GPE-Como-parametrizar-o-fim-da-desonera%C3%A7%C3%A3o).  
  
**P\_LPROVEST** - Cálculo de Provisão de 13º Salário para Estagiários.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360035732714-MP-GPE-Como-Calcular-Provis%C3%A3o-de-13%C2%BA-Sal%C3%A1rio-para-Estagi%C3%A1rios).  
  
**P\_MEDDIREN** - Mnemônico de Reestruturação de Médias, em substituição ao Parâmetro MV\_MEDDIRE, que define a regra de divisão das médias.  
Para mais informações sobre este mnemônico [Clique Aqui](https://tdn.totvs.com/pages/releaseview.action?pageId=515701094).   
  
**P\_PROVAVP -** Provisão de Férias e 13º Salário sobre a projeção do Aviso Indenizado.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360027855571-MP-GPE-Como-Provisionar-F%C3%A9rias-e-13%C2%BA-Sal%C3%A1rio-Sobre-o-Aviso-Pr%C3%A9vio-no-m%C3%AAs-da-demiss%C3%A3o).  
  
**P\_DEDMAT -** Define quais verbas de Maternidade serão desprezadas para formação da base dos INSS Patronal.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360060446574-RH-Linha-Protheus-GPE-Contribui%C3%A7%C3%A3o-previdenci%C3%A1ria-patronal-sobre-o-sal%C3%A1rio-maternidade-NT-20-2020-).  
  
**P\_ENCEMP -**  Define quais encargos patronais serão calculados utilizando a composição de base indicada no mnemônico P\_DEDMAT.  
Para mais informações sobre este mnemônico [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360060446574-RH-Linha-Protheus-GPE-Contribui%C3%A7%C3%A3o-previdenci%C3%A1ria-patronal-sobre-o-sal%C3%A1rio-maternidade-NT-20-2020-).  
  
**P\_RECDES -** Define quais valores serão abatidos na composição das bases de cálculo para a Contribuição Previdenciária sobre a Folha de Pagamento (CPP) quando é aplicada Desoneração.  
 Para mais informações sobre este mnemônico: [Clique Aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020161392).
