# Ajuste na Tela de Cadastro de Leitos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastros |
| **Situação:** | O sistema exibia leitos vinculados à unidades de atendimento que o usuário não tinha acesso na tela de cadastro de leitos. |
| **Solução:** | Realizado ajuste na tela de cadastro de leitos para exibir somente leitos vinculados às unidades de atendimento que o perfil do usuário está vinculado. |
