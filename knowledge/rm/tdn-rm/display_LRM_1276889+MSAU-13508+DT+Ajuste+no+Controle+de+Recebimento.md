# Ajuste no Formulário de Controle de Recebimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Recebimento |
| **Situação:** | Em Controle de Recebimento ao clicar na sub aba Faturamento pesquisar pelo convênio e unidade de faturamento da remessa gerada, o campo Glosa digitada diferia da exibida no formulário de Registro de Glosas. |
| **Solução:** | Realizada alteração no Controle de Recebimento, para que ao exibir os dados de uma remessa que possui cobranças de pacote de produto, o sistema calcule os valores de forma adequada. |
