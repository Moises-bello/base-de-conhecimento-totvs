**Ocorrência**  
Ao realizar o cadastro de uma consulta demissional para um funcionário é apresentada a seguinte mensagem de erro:  
  
**Não é possível salvar o registro porque já existe uma consulta demissional para este funcionário.**  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Segurança e Saúde Ocupacional – Todas as Versões  
  
**Causa**  
Este incidente ocorre quando o funcionário já possui uma consulta demissional cadastra. Por padrão do sistema é possível cadastrar somente uma consulta Demissional e uma consulta Admissional para o funcionário.   
  
**Solução**  
Para solucionar essa ocorrência, acesse a consulta demissional cadastrada anteriormente para o funcionário, limpe o campo **Funcionário** e em seguida clique em salvar, conforme o exemplo a seguir:
