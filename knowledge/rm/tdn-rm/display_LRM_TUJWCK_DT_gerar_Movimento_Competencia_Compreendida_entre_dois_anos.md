# GERAR MOVIMENTO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Gerar movimento por competência* |
| **Situação/Requisito:** | *No processo de geração de movimento por competência, o sistema não está gravando o mês 01/2016 quando a competência compreende dois anos, por exemplo de 08/2015 a 03/2017.* |
| **Solução/Implementação:** | Otimização no processo de gerar movimento por competência:  Permitir executar o processo quando a competência do movimento compreende mais de 1 ano, por exemplo de 08/2015 a 03/2017.  Ao solicitar alteração do movimento, caso escolha para alterar o último mês existente, o sistema emitia incorretamente a mensagem "Não foi possível gerar movimento para a competência indicada, pois existe movimento posterior gerado para o contrato." |
