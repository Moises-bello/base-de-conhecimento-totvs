![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22322721465239) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Quais informações cadastrais do funcionário, são possíveis alterar via Meu RH?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Meu RH - Todas as versões  
  
**Solução**Os funcionários conseguirão acessar o Meu RH e alterar os dados:

-Telefones  
-Apelido  
-Endereço  
-Carteira de Motorista  
-Passaporte  
  
Para alterar estes dados, após logar no Meu RH, basta acessar o Perfil conforme print abaixo:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4418020979095)

E clicar em Editar informações:  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4418009449367)  
  
Após o funcionário salvar os dados, eles irão para o DP aprovar ou já serão alterados automaticamente no RM, vai depender de como foi parametrizado em Folha de Pagamento / Configurações / Parametrizador / RM Portal / Edite o Quiosque / Alterações Cadastrais:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4418018396311)  
  
**Importante**Para o DP aprovar os dados alterados, basta acessar a rotina abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28150780419095)

[Caso queira liberar ou bloquear essa funcionalidade, basta conferir a nossa documentação clicando aqui.](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024560374-RH-RM-Meu-RH-Como-bloquear-altera%C3%A7%C3%B5es-no-perfil-do-colaborador-no-Meu-RH)
