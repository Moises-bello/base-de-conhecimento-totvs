# Objetivo:

---

O objetivo deste documento é trazer informações necessárias para a criação do conceito que viabiliza a importação de dados da tabela PESOCIALEVENTOS (Fila de Eventos).

Segue abaixo lista dos campos que devem ser preenchidos na tabela PESOCIALEVENTOS conforme o tipo do Evento:

| Evento | Campo |
| --- | --- |
| **S-1000** | ID, CODCOLIGADA, DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1000', STATUS='10',  GRUPO='1', RECIBO, MENSAGEM(xml) |
| **S-1005 (Sem Tomador de serviço)** | ID, CODCOLIGADA, CODLOTACAO(código da seção), DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1005', STATUS='10', GRUPO='2', RECIBO, MENSAGEM(xml) |
| **S-1005 (Com Tomador de serviço)** | ID, CODCOLIGADA, CODCOLTOMADOR, CODTOMADOR, IDCEI, DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1005', STATUS='10', RECIBO, GRUPO='2', MENSAGEM(xml) |
| **S-1010** | ID, CODCOLIGADA, CODRUBRICA(código do evento), DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1010', STATUS='10', RECIBO, GRUPO='2', MENSAGEM(xml) |
| **S-1020 (Sem Tomador de serviço)** | ID, CODCOLIGADA, CODLOTACAO(código da seção), DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1020', STATUS='10', RECIBO, GRUPO='2', MENSAGEM(xml) |
| **S-1020 (Com Tomador de serviço)** | ID, CODCOLIGADA, CODLOTACAOTRIBUTARIA, DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1020', STATUS='10', RECIBO, GRUPO='2', MENSAGEM(xml) |

| **S-1050** | ID, CODCOLIGADA, TIPOHORARIO, CODHORARIO, INDICEHOR, IDJORNADA, DATAEVENTO, DATEGERACAO, DATAENVIO, TIPOEVENTO='S-1050', STATUS='10', RECIBO, GRUPO='2', MENSAGEM(xml) |
