# Ajuste em Formulário Duplicando Leitos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Leitos |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu **Cadastro/Registro e Controle/Leitos**, abrir o formulário, era possível verificar que os leitos estavam duplicados. |
| **Solução:** | Ajuste realizado no formulário para que sejam exibidos todos os leitos cadastrados sem duplicação desta informação. |
