Por esta opção, são cadastradas as Vigências dos Eventos Tributários para utilização do sistema. Nesse cadastro se define o período de utilização de uma determinada regra de cálculo para dos impostos IRPJ, CSLL, RET e OUTROS. Somente para impostos deste tipo será possível o cadastro de Vigências de Eventos Tributários.

***Observação*:**Ao encerrar o Período de Apuração o sistema precisa identificar qual a regra deve ser utilizada para o cálculo do imposto. Não pode existir mais de uma regra para o mesmo Período de Apuração. Não é permitido alterar o Evento Tributário associado à vigência, se existe Período de Apuração Encerrado dentro do intervalo de datas da vigência.
