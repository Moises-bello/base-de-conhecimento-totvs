# Transferir Itens da Elaboração de Contas para a Conta de Itens Grátis

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Elaboração de Contas | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER e ORACLE |
| **Tabelas Utilizadas:** | SZATENDHONORARIOS, SZATENDDIARIAS, SZATENDTAXASERV, SZATENDSADT, SZATENDITEMGRATIS |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Implementação possibilita a  transferência de honorários, diárias, taxas e serviços e SADT para itens grátis.

## Procedimento para Utilização

1. Acesse a **Elaboração de Contas** de um paciente.
2. Lance honorários, diárias, taxas e serviços e diagnose e terapias para o paciente.
3. Em cada aba, para cada tipo lançado, clique com o botão direito na grade de itens lançados.
4. Selecione a opção **"Transfere item selecionado p/ conta de Itens Grátis**".
5. Verifique na nova tela se os itens correspondem com os selecionados para transferir.
6. Clique em "**Transferir p/ Itens Grátis**" para completar a operação.
7. Verifique que os itens saíram da aba original e passaram a ser apresentados na aba de itens grátis.
