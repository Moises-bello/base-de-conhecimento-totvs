# ENDEREÇO PROFISSIONAL (EDUPESSOAACTION) - ANEXO CADASTRO DE PESSOA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Endereço Profissional (EduPessoaAction) - Anexo Cadastro de Pessoa* |
| **Situação/Requisito:** | *Ao criar um anexo com a action End. Profissional (EduPessoaAction) na tela de cadastro de Pessoa, o anexo abre normalmente porém é apresentado erro ao salvar registro. Isso com o anexo marcado como ativo e obrigatório.* |
| **Solução/Implementação:** | *Ajuste no cadastro de endereço profissional (EduPessoaAction) quando se coloca esta action como ativa e obrigatória no cadastro de pessoa, para que seja possível inserir um novo registro de pessoa levando os campos de profissão e ocupação de forma correta para a tabela de pessoa.*  *Observação: é possível configurar esta extended action no cadastro de pessoas até a versão 12.1.21, a partir da 12.1.22 não é mais possível fazer isso, porque a EduPessoaAction é uma extended action, o sistema de forma incorreta possibilitou esta configuração. Para mais informações sobre preferências de anexo acesse: <http://tdn.totvs.com/x/brAQG>* |
