Correção - TCheckBox indevidamente marcado por padrão

|  |  |
| --- | --- |
| Situação | Em algumas telas de cadastro, foi observado que o componente TCheckBox era apresentado marcado por padrão, independente do valor correspondente do banco de dados. |
| Ocorrência | Componente TCheckBox apresenta marcação indevida no carregamento de determinadas telas de cadastro. |
| Correção | O componente TCheckBox recebeu um ajuste para tratar corretamente o valor a ser apresentado. |
| Informações adicionais | * Referente à ocorrência: DTCLIENT01-5135 * Disponível em builds iguais ou superiores a 20.3.2.9 |
