Ao imprimir um relatório por exemplo Posição de Estoque (MATR260) não está mostrando todos os números das casas decimais, como fazer para que mostre?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**

Ao imprimir o relatório com o valor onde o sistema apenas está mostrando apenas duas casas decimais igual o exemplo do relatório:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26198187820055)

Nesse caso favor colocar o preencher o número de casas decimais da base de dados no parametro MV\_CENT para que ao fazer a impressão do relatório mostrando o valor de todas as casas decimais.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26198187821463)
