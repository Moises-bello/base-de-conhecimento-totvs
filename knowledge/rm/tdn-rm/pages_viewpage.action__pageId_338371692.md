# CÓPIA DE PLANOS DE PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Cópia de planos de pagamentos* |
| **Situação/Requisito:** | *Na rotina de cópia de planos de pagamentos, em casos onde existam mais de 1 cota e/ou mais de um serviço por parcela, as competências das parcelas são geradas de forma a não respeitar a parcela.* |
| **Solução/Implementação:** | *Foi ajustado o processo de cópia de planos de pagamentos para que nos casos citados (presença de mais de uma cota ou serviço por parcela) a geração das competências respeite a parcela.* |
