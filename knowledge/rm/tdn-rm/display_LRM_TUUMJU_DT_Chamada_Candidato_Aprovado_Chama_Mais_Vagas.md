# CHAMADA DE CANDIDATOS APROVADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Chamada de candidatos aprovados.* |
| **Situação/Requisito:** | *Foi identificado que a chamada de candidatos aprovados estava inconsistente com o número de vagas das áreas ofertadas, chamando mais candidatos que vagas.* |
| **Solução/Implementação:** | *Foi identificado que a falha ocorria no momento da chamada dos candidatos, que não estava validando corretamente o número de vagas da área ofertada pelo número de vagas chamadas para cada candidato, assim, o processo sempre chamava todos os candidatos, foi feito o ajuste nesta validação e o número de vagas na chamada passou a ser respeitado, chamando somente a quantidade de candidatos pela quantidade de vagas livres da área ofertada.* |
