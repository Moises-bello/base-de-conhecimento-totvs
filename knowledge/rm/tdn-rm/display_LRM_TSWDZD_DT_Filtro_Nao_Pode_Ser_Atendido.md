# Alteração Global de Tomadores

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Alteração global de tomadores* |
| **Situação/Requisito:** | Ao executar alteração global de tomadores, o sistema não considerava filtro passado na seleção de funcionários, e o processo não encontrava os funcionários a serem alterados |
| **Solução/Implementação:** | Otimizada rotina de alteração global de tomadores quando é feita seleção de funcionários utilizando filtro com parâmetros. |
