 **Dúvida**Quais os **PEs - Pontos de Entrada** disponíveis para o **Banco de Conhecimento**?  
   
 **Ambiente**Microsiga Protheus – Banco de Conhecimento – Versão 12  
  
**Solução**Os **PEs** disponíveis são:

* [FT340VLD - Validar inclusão/alteração/exclusão](http://tdn.totvs.com/pages/releaseview.action?pageId=6784460)
* [MTVLDACE - Valida acesso à rotina de conhecimento](http://tdn.totvs.com/pages/viewpage.action?pageId=6085698)
* [MTCONHEC - Validar se o botão Banco de Conhecimento estará ativo ou não.](http://tdn.totvs.com/display/public/PROT/MTCONHEC)
* [MSDOCVIS - Bloqueia manipulação de dados](http://tdn.totvs.com/pages/releaseview.action?pageId=6087680)
* [MSDOCVLD - Validar tipo de objeto do banco de conhecimento](http://tdn.totvs.com/display/public/PROT/MSDOCVLD+-+Validar+tipo+de+objeto+do+banco+de+conhecimento)
* [MTGRVVLD - Validar inclusão do banco de conhecimento](http://tdn.totvs.com/pages/releaseview.action?pageId=6784474)
* [FT340TAM - Para limitar o tamanho do arquivo](http://tdn.totvs.com/display/public/PROT/FT340TAM+-+Controlar+tamanho+do+arquivo)
