![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:54 min****Dúvida**Quais os requisitos mínimos para uso do Meu RH?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) – Meu RH – Todas as versões  
  
**Solução**Para acesso via aplicativo Meu RH:

1. Android 9.0 ou superior
2. iOS 13.0 ou superior
3. Não ter *root/jailbreak* habilitado no dispositivo
4. Acesso à internet
5. Acesso externo ao servidor estar liberado (para acesso via 3G/4G)
6. É altamente recomendado que seja implementado o protocolo ***SSL*** (*Secure Socket Layer*) para garantir que os dados dos colaboradores trafegados fiquem menos vulneráveis. Consulte a área de TI da sua empresa e/ou empresas certificadoras.

   * O *SSL* consegue fazer o uso de criptografia e garante o sigilo das informações que são depositadas pelo usuário dentro dos serviços oferecidos pela web. A consequência disso, é uma maior segurança durante a navegação.
   * Sem o uso do protocolo *SSL* algumas funcionalidades do aplicativo que utilizam geolocalização para funcionamento se tornam inoperantes

Para acesso via desktop os navegadores homologados são:

1. Google Chrome (sugerimos a ultima versão disponível)
2. Mozilla Firefox (sugerimos a ultima versão disponível)

**Importante**

É altamente recomendado utilizar o protocolo ***SSL*** no aplicativo Meu RH devido as exigências da *LGPD*. Favor já se programarem para a implantação do Meu RH considerando este protocolo *SSL*.
