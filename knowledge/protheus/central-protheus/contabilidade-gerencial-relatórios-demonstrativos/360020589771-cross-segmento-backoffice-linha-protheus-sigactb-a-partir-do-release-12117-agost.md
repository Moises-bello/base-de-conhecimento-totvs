**Dúvida**  
Relatórios em formato R3 descontinuado?  
  
  
  
**Ambiente**Cross Segmento - Backoffice Linha Protheus - Contabilidade Gerencial – A partir da versão

12.1.17  
  
  
**Solução**Os relatórios criados a partir deste release serão suportados no formato Release 4 (personalizado).

* O formato Release 3 (não personalizado) não receberá melhorias ou manutenções a partir deste release.
* O parâmetro **MV\_TREPORT**não terá mais efeito.

Ao utilizar um relatório no formato personalizável é possível:

* Impressão nos formatos Excel, PDF, HTML
* Tipo de papel e orientação de impressão
* Adicionar novas colunas
* Remover colunas não utilizadas
* Adicionar Totalizadores
* Ajuste de margem
* Ajuste no tamanho de fontes de colunas
