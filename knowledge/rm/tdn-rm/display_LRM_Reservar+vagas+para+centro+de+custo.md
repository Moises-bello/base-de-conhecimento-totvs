**Reservar vagas para centro de custo**

O processo Reservar vagas para centro de custo permite a reserva de várias vagas para os centros de custo. As reservas das vagas podem ser consultadas no anexo de Turmas.

**Observação**

Vagas disponíveis = Vagas disponíveis na turma – Participantes inscritos – Vagas definidas para outros centros de custo
