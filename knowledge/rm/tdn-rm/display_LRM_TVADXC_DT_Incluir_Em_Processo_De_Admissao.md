# INSERIR EM PROCESSO DE ADMISSÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Incluir em Processo de Admissão* |
| **Situação/Requisito:** | *Ao conter uma demissão proveniente de uma requisição e a mesma gerar uma outra de substituição no qual o requisitante é de uma coligada diferente do funcionário desligado e do que irá substituir, ao incluir candidato no processo de admissão e informar a  requisição de substituição são carregadas indevidamente as filiais da coligada do requisitante. Sendo que deveria ser carregada filiais do desligado e substituto conforme a requisição.* |
| **Solução/Implementação:** | *Ajuste no processo "Incluir Candidato no Processo de Admissão". Ao selecionar uma requisição, são carregados os dados referentes à coligada da requisição.* |
