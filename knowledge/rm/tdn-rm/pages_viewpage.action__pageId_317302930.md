# Ao editar a contabilização do extrato o sistema não carrega evento contábil default.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeiro |
| **Função:** | Contabilização de Extrato de Caixa |
| **Situação/Requisito:** | Ao editar um extrato não contábil e modificá-lo para contábil e abrir a contabilização o sistema não carrega os dados contábeis defaults. |
| **Solução/Implementação:** | Agora o sistema carrega a contabilização do extrato de caixa de acordo com a tabela default para evento. |
