Dúvida**Existe alguma forma de executarmos a rotina FINA100 via ExecAuto informando os dados para rateio de centro de custos, conforme é realizado manualmente?  
  
**Ambiente**Protheus – ADVPL – A partir da versão 12.   
  
**Solução**

A rotina não esta preparada para que seja informado o rateio via execauto, do mesmo modo que a rotina se comporta manualmente.

Caso entenda como importante esta implementação pode ser solicitada através da central colaborativa para votação e análise para ser desenvolvida nos próximos releases.
