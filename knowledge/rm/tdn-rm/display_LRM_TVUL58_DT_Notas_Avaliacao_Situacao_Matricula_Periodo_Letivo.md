# NOTAS DE AVALIAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Notas de avaliação* |
| **Situação/Requisito:** | *Na tela de "Digitação de notas de avaliações por aluno (Matrícula e avaliação | Mais | Digitação por aluno | Notas de avaliação)", a opção da situação de matrícula está carregando todas as situações, independente se não está que é uma situação de período letivo.* |
| **Solução/Implementação:** | *Foi identificado que a lista não utiliza nenhum filtro, sendo assim, ao carregar é listada todas as situações de matrícula, foi feito o ajuste na lista de situações para que nesta tela, ao carregar as situações de matrículas, o sistema filtre somente as que tem a opção de período letivo marcado, foi feito também um ajuste na descrição do campo para facilite o entendimento que a situação de matrícula está relacionada ao período letivo.* |
