Esta tela apresenta a **lista de Coligadas que possuem empreendimentos já cadastrados para elas** no sistema, exibindo informações básicas como **Código da Coligada (COD)** e **Descrição**.

Aqui, o usuário deve **selecionar as coligadas** que deseja configurar utilizando o botão de seleção (quadrado à esquerda).

* **Coluna de Seleção (Checkbox):** Permite selecionar uma ou mais coligadas para aplicar as mesmas configurações simultaneamente.
* **COD:** Exibe o código único que identifica cada coligada no sistema RM.
* **Descrição:** Mostra o nome completo da coligada para facilitar sua identificação.
