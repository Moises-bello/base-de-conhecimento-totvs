# Envio da NF-e - Nota Fiscal Eletrônica

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Envio da Nfe |
| **Situação/Requisito:** | De acordo com o Manual de Orientação ao Contribuinte v.6.0, quando tal motivo de  desoneração 8 (Venda a Órgão Púlico ) é utilizado, as tags <xNEmp> <xPed> e <xCont> devem ser gravadas no grupo informações da compra (tag <compra>) . |
| **Solução/Implementação:** | Devem ser preenchidos os campos complementares do movimento XPED, XNEMP e associar um contrato no item do movimento para que seja preenchida a tag XCONT. |
| **Requisito:** | FIS000071 |
