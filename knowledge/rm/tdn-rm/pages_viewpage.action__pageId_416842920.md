# Interpretação do campo de código de usuário no painel de mensagens

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | RM |
| **Função:** | Painel de mensagens |
| **Situação/Requisito:** | O painel de mensagens no RM possui um campo de código de usuário, no detalhamento da mensagem individual. Este campo coexiste com o campo de data da leitura da mensagem, foi interpretado como "o usuário que efetuou a leitura da mensagem", entretanto este campo refere-se ao usuário de destinatário da mensagem. |
| **Solução/Implementação:** | Alterado o label que expicitava o nome do destinatário de uma mensagem do eduCONNECT, por gerar divergências sobre a interpretação do campo. |
