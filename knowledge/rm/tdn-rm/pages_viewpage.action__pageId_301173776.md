| **Ocorrência:** | Apuração dos tributos PIS Importação e COFINS importação |
| **Ambiente:** |  |
| **Passo a passo:** | O PIS e a COFINS incidem também na importação de produtos estrangeiros ou serviços do exterior. Para o sistema trata-se de outros tributos com fato geradores, base de cálculo e contribuintes diferentes dos anteriores.  O sistema irá consistir a "Sigla" do tributo informado.  Para o PIS importação deve ser cadastrada a sigla: PISIMPORT  Para o COFINS Importação deve ser cadastrada a sigla: COFINSIMPO  Para cadastrar o tributo acessar o Menu Cadastro - Tributo.  Em Tipo tributo informa Pis Importação ou Cofins Importação.        Na aba > outras dados > preencha as informação conforme desejado pela empresa.        Esses tributos devem ser inseridos na pasta "Outros Tributos" do lançamento fiscal. Devem ser vinculados aos Lançamentos de Entrada do tipo importação.        Na geração automática da guia o sistema consiste a data do Desembaraço Aduaneiro, que deve estar preenchida com a mesma data em que está gerando a guia.        Após encerrar o período de apuração o sistema não calcula o saldo devedor, isto porque o tributo é pago ao se registrar cada nota fiscal de importação. O saldo devedor será a soma das guias DARF's pagas. As Guias geradas consideram os rateios de Centro de Custo e Departamento. |
