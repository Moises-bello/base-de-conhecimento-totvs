![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30086997324055) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como enviar o titulo RA para o bloco F500/F525?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Financeiro - Todas as versões  
**Solução**O parâmetro **MV\_ENVRA**, que define se os títulos a receber do tipo RA devem ser enviados para composição dos blocos **F500/F525**.

O parâmetro é do tipo caractere, tendo as opções:

1 = Envia  
2 = Não envia
