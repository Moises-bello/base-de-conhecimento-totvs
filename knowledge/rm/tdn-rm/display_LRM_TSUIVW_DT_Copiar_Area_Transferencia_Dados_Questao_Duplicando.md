# ADICIONAR QUESTÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Avaliação e Pesquisa* |
| **Função:** | *Adicionar Questão* |
| **Situação/Requisito:** | *Ao cadastrar uma questão e utilizar a opção "Colar área de trabalho" duas vezes ou mais o sistema gera várias alternativas, porém ao tentar subir ou descer a ordem da alternativa ele ordena errado, pulando as alternativas.* |
| **Solução/Implementação:** | *Foi identificado que o sistema estava copiando os dados incorretamente, ao utilizar o botão para copiar da área de transferência, o correto é limpar os dados atuais e manter somente os novos dados, assim, ao utilizar o botão, a questão será limpa e os novos dados inseridos, após esta alteração a ordenação de questões não apresenta mais problemas.* |
