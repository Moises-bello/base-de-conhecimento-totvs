## O que é?

AAPI na ferramenta de Automação de Testes é uma interface que permite interação programática com o sistema, possibilitando automação e integração com outras ferramentas, sem a necessidade de utilizar a interface gráfica no navegador. Com a API, é possível realizar diversas operações, como incluir registros ou executar agendamentos, de maneira mais eficiente e personalizada.

## Para que serve?

A API do TOTVS Automação de Testes acelera o desenvolvimento de automações de teste. Você não precisa criar todas as soluções do zero, pois pode utilizar os recursos prontos da API para funções padrão. Além disso, a API facilita a integração com diferentes sistemas e serviços, melhora a eficiência dos testes e permite adaptá-los às necessidades específicas do seu projeto.

## Informações Endpoint

Clique para Expandir

Um endpoint é uma URL que permite o acesso a uma funcionalidade específica de uma API, definindo o ponto de entrada para que sistemas ou aplicativos se comuniquem, seja para obter, enviar ou modificar dados. Em outras palavras, é a "porta" por onde as requisições HTTP são feitas para interagir com os serviços de uma API.

O endpoint a ser utilizado é: `http://SEUHOST:6060/graphql`.
