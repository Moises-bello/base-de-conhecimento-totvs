**Dúvida**Ao transmitir a nota para um processo de conta e ordem o sistema apresenta a rejeição 331, como podemos resolver ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões.  
  
**Solução**Este problema ocorre por não ter um CNPJ vinculado ao importador do processo.

1. Acesse o cadastro de importadores no módulo SIGAEIC

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360084174933/mceclip0.png)

2. Selecione o importador do processo que está apresentando a rejeição

3. Insira o CNPJ do importador no campo YT\_CGC

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360084174973/mceclip1.png)
