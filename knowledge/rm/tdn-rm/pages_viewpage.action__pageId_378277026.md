# 1011279 FINANCEIRO01-1047 DT PERMISSÃO PARA RECALCULAR PARCELAS DE ACORDO MESMO QUANDO NÃO EDITADAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Gestão Financeira. |
| **Função:** | Lançamento - Acordo - Geração das parcelas |
| **Situação/Requisito:** | Processo de Acordo, na etapa "Edição das Parcelas do Acordo", ao clicar no botão "Recalcula os valores das parcelas não editadas" o valor do acréscimo é zerado gerando diferença nos totalizadores. |
| **Solução/Implementação:** | O botão "Recalcula os valores das parcelas não editadas" será habilitado apenas quando existe a necessidade do recálculo. Está situação acontece após a edição de alguma parcela e as parcelas restantes, caso existam, não forem recalculadas. |
| **Conversores e Parâmetros:** | Não se aplica |
| **Tickets relacionados:** | 1011279 |
| **Requisito:** | FIN000164 |
| **Documento de Referência:** | Não se aplica |
