**ALTERAÇÃO DE LINGUAGEM DO BANCO DE DADOS:**

A linguagem default do Banco de Dados para a Base CorporeRM é English.

Acesse o banco de dados, expanda a raiz escolhendo o diretório "Security | Logins". Selecione o usuário "rm" com o botão direito do mouse e escolha a opção "Propriedades":

Na janela Login Properties – rm – no campo "Default Language" selecione a opção "English",linguagem padrão do Banco de dados CorporeRM:

Realize este mesmo processo para o usuário "sysdba" conforme imagen abaixo:

Realize o mesmo processo na instância do Nome do Bando de Dados. Clique em Propriedades: Em seguida selecine a opção "Advanced" e "Default Language."
