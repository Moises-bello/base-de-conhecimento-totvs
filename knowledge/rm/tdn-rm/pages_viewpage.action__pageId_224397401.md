# Experiência 5 - Consulta Rápida

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 12.1.5 |
| **Ambiente:** | MDI | RM.exe |
| **Passo a passo:** | **Objetivo:**  O Objetivo deste documento é explicar como funciona e ensinar a criar consulta rápida.  **Introdução:**  A consulta rápida é responsável em extrair e exibir informações do RM através Fluig.   **Criando uma Consulta Rápida:**  Consulta RápidatrueCadastro Para acessar o cadastro de consulta rápida acesse o menu "Consulta Rápida", que pode ser encontrado na guia "Ambiente" de qualquer módulo.Após abrir a visão clique em incluir.  Existem quatro tipos de consulta rápida:   | Tipo | Características | | --- | --- | | Padrão | São criadas pela TOTVS, não podem ser alterada. | | Action | Utiliza como fonte de dados o Data Server da Action escolhida. | | Data Server | Utiliza como fonte de dados o Data Server e permite customizar o Form de edição. | | Sentença SQL | Utiliza como fonte de dados o retorna da Sentença SQL escolhida. |   Tipo de Action:   | Tipo | Aplicativo no IDENTITY | | --- | --- | | Action MDI | A consulta rápida ficará disponível no IDENTITY **somente** no Aplicativo do RM.exe. | | Action Portal | A consulta rápida ficará disponível no IDENTITY **somente** no Aplicativo do RM Portal. |    Padrão 800600   Action 800600 Data Server 800600 Sentença SQL 800600 Atenção Após criar uma consulta Rápida, se o ambiente estiver integrado com o IDENTITY a consulta é automaticamente enviada para o Aplicativo referente ao tipo de action escolhida no IDENTITY. |
