# Ajuste no Formulário de Faturamento de Convênios

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |

| **Rotina:** | |  |  | | --- | --- | | Rotina | Nome Técnico | | Faturamento | Faturamento para Convênios | |
| **País(es):** | Brasil. |
| **Banco(s) de Dados:** | SQL Server® e Oracle® |
| **Tabelas Utilizadas:** | SZFATURACONVENIO |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Esta melhoria tem por objetivo auxiliar o usuário ao gerar um nova remessa, ter o feedback do sistema sobre uma remessa já criada com uma competência já cadastrada.

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações RMSaude (Patch) 12.1.16.021 deste chamado, prevista para o dia 17/08/2017.

## Procedimento para Utilização

* Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Faturamento/Particular e Convênios/Faturamento para Convênios".

* Selecione uma unidade de faturamento, convênio, digite a competência e clique no botão "Inicia",

* O sistema deverá exibir a mensagem abaixo, caso já tenha sido inserida uma remessa com uma competência já registrada.
