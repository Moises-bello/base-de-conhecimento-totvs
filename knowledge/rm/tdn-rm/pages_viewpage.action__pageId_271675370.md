# Não conformidade no retorno do WebService de autenticação da TISS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Atendimento Externo |
| **Situação:** | Ao acessar o menu Atendimento/Pronto Atendimento/Ambulatório/Registro de Atendimento Externo,  selecionar um paciente, ir na aba "Guia de Autorização", registrar uma "Guia de Solicitação de SP/SADT" e clicar no botão "Solicitar autorização TISS", o sistema apresentava a mensagem "Campo Guia precisa ter um valor". |
| **Solução:** | Ajuste realizado no formulário para a finalização do processo de solicitação de GUIA. |
