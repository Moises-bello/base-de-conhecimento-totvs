# Máscara de Impressão Relatórios Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Máscara de Impressão Relatórios Contábeis |
| **Situação/Requisito:** | Cliente informa que ao marcar o parâmetro ( Usa mascaras diferenciadas para impressão de relatórios ) e definir uma outra máscara, ao gerar o relatório na MDI, o relatório não está respeitando as máscaras definida no parâmetro acima. Mas ao gerar o relatório na versão Delphi, Relatórios versões anteriores > balancete, sistema respeita a parametrização informada. |
| **Solução/Implementação:** | Através da tela de parâmetros do módulo contábil é possível definir as máscaras que serão aplicadas nas contas, contábeis e gerenciais, dos relatórios fixos do sistema. Para atender essa configuração que existia na versão Delphi todos os relatórios foram alterados. |
