# Clicar duas vezes grid atendimento médico classificação de risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Classificação de Risco |
| **Situação/Requisito:** | Ao clicar sobre alguma senha usando o perfil médico na classificação de risco a senha não é chamada no painel de chamadas, tendo o médico chamar duas vezes e a senha muda de status. |
| **Solução/Implementação:** | Alterado o sistema para o dois cliques na grid do atendimento médico ter o mesmo funcionamento do botão chamar, ao dar dois cliques  a senha é exibida no painel de chamadas. |
