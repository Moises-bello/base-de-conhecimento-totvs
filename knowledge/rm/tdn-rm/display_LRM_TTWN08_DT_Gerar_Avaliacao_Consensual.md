# GERAR AVALIAÇÃO CONSENSUAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Gerar Consensual* |
| **Situação/Requisito:** | *Ao gerar avaliação consensual, mesmo com o parâmetro "finalizar automaticamente" marcado, o sistema erroneamente está enviado email para o gestor informando que ele deve responder a avaliação.* |
| **Solução/Implementação:** | *Ajuste no processo "Gerar consensual". Se for marcado o parâmetro "Finalizar automaticamente", não é enviado email para o gestor, informando que a avaliação consensual deve ser respondida.* |
