![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18519590856727) Tempo aproximado para leitura: **02:00 min** **Dúvida**É possível tirar a obrigatoriedade do campo "**W2\_AGENTE"**?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Uma vez que se tenha a Via de Transporte na "***Purchase Order**",* é necessário o preenchimento do campo "**W2\_AGENTE"** do Agente de Transporte. Tal ação faz parte das premissas para o prosseguimento do processo de importação.

Caso queira retirar a obrigatoriedade do campo, será necessário a tratativa via Ponto de Entrada.
