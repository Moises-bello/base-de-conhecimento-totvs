**Acidente de Trabalho dos funcionários**

Por este cadastro é possível visualizar as ocorrências de acidente de trabalho do funcionário cadastradas pelo menu SMT| SMT| Ocorrências Acidente Trabalho.

**Observação**

- O campo Descrição da ocorrência deve trazer os dados digitados no menu SMT|SMT| Ocorrências Acidente de Trabalho, pasta Descrição.

- Este cadastro não é editável e não permite alterações. As alterações deverão ser realizadas no menu SMT| SMT| Ocorrências Acidente Trabalho.

**Atenção**

Para qualquer ícone desabilitado, verifique com o Supervisor as permissões do usuário em questão em Cadastros| Seguranças| Perfis| pasta Acesso a menus.
