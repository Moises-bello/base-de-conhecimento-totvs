# Eliminação de valores

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Plano de contas paralelo |
| **Situação/Requisito:** | A aba Eliminação de Valores, existente no cadastro de plano de contas paralelas, deve ser exibida apenas para as coligadas controladoras. |
| **Solução/Implementação:** | O cadastro de contas paralelas foi modificado para que a aba Eliminação de Valores seja exibida somente para a coligada controladora. Vale ressaltar que para visualizar esta aba o plano de contas paralelo deve ter como finalidade "Consolidação de Saldos". |
