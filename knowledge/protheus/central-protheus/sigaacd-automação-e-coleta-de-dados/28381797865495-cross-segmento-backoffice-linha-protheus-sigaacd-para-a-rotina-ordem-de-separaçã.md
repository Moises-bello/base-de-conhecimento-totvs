![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28381797853335) Tempo aproximado para leitura: **00:01:00 min****Dúvida**A rotina Ordem de Separação (**ACDA100**) pode ser executada via ExecAuto?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**

Atualmente a rotina Ordem de Separação, avaliando os fontes não está preparada para usar ExecAuto.

Como a rotina não tem como usar o ExecAuto, pode ser registrada uma melhoria na Central Colaborativa, para registrar sua melhoria clique aqui **[Central Colaborativa TOTVS.](https://centraldeatendimento.totvs.com/hc/pt-br/community/topics)**
