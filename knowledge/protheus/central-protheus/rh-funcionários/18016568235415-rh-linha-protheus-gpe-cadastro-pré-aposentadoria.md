![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18016574300823) Tempo aproximado para leitura: **01:30 min** **Dúvida**O sistema possui rotina para cadastro pré aposentadoria?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O sistema padrão não possui rotina quanto a cadastro pré aposentadoria.

No cadastro do funcionário (Atualizações > Funcionários > Funcionários > Aba funcionais), existe o campo Aposentado (**RA\_EAPOSEN**), sendo possível informar se o funcionário é aposentado.
