Antes de iniciar a inscrição familiar, é necessário realizar a [parametrização.](https://tdn.totvs.com/pages/viewpage.action?pageId=856934701) Somente após a conclusão dessa etapa, será possível proceder com a inscrição no portal do processo seletivo.

Na aba de Inscrições, primeiro informe os dados do responsável pela inscrição. Após preencher os dados do responsável, informe os dados do primeiro candidato. Se houver mais candidatos na mesma família, adicione os dados de cada um após preencher os do primeiro candidato

A primeira etapa será para preencher os dados do responável pela inscrição, em seguida, preencha os dados do primeiro candidato. Caso existam responsáveis habilitados no processo seletivo, preencha os dados na segunda etapa. A proxima etapa será finalizar a primeira inscrição, e após isso, você vai escolher realizar a Próxima inscrição ou Finalizar.

* **Finalizar:** Se optar por finalizar, o formulário será fechado e você será redirecionado para a tela de informações. Todos os dados dos outros candidatos serão descartados.
* **Continuar:** Se optar por continuar, os dados do responsável pela inscrição serão mantidos, permitindo que você aproveite esses dados e os dos outros responsáveis do primeiro candidato para realizar as inscrições dos demais candidatos.

# Finalização da Inscrição

Processo seletivo configurado para permitir a inscrição de irmãos. Após a conclusão da inscrição, os candidatos serão redirecionados para uma página de finalização, onde serão listados todos os candidatos inscritos e seus respectivos status. Para o candidato que for inscrito o status será **verde**,para o candidato excedente terá o status **amarelo**, para o candidado que não for inscrito o status será **vermelho**.  
O usuário poderá realizar a emissão de  [comprovante](https://tdn.totvs.com/pages/viewpage.action?pageId=284884282) e realizar pagamento ([pix](https://tdn.totvs.com/display/LRM/Pagamento+com+Pix),  [cartão](https://tdn.totvs.com/pages/viewpage.action?pageId=489766168) ou [boleto](https://tdn.totvs.com/pages/viewpage.action?pageId=284884282)), caso o processo seletivo esteja parametrizado com taxa de inscrição e com comprovante.

**Comprovante de Inscrição:**

Para os candidatos com status **Inscrito** ou **Excedente**, será exibido um botão que permitirá a abertura do comprovante de inscrição.  
Se o processo seletivo exigir uma **taxa de inscrição**, o usuário poderá realizar o pagamento. Somente candidatos com status **Inscrito** poderão efetuar o pagamento. Serão exibidas as opções de pagamento que foram parametrizadas no processo seletivo.  
Somente na inscriçõ familiar, será possível emitir comprovantes e realizar pagamento para mais de um candidato ao final da inscrição.
