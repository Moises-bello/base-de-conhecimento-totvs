# RETORNO DE COBRANÇA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Retorno de Cobrança* |
| **Situação/Requisito:** | O cliente criou um campo complementar e adicionou no layout bancário. Ao importar o arquivo de retorno o sistema grava a informação do campo complementar do lançamento financeiro apenas quando o código do retorno é BAIXA. Para Registrado e Recusado o sistema não grava o campo. |
| **Solução/Implementação:** | Otimizado retorno de cobrança para preencher a informação do campo complementar no lançamento para código de retorno registrado ou recusado. |
