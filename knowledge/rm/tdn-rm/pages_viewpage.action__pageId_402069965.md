# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1 |
| **Ocorrência:** | Consulta Alocação de Patrimônio |
| **Ambiente:** |  |
| **Passo a passo:** | **Definição de processo:**  Todas as alocações de patrimônio realizadas com sucesso poderão ser visualizadas na tela de consulta de alocações.    **Disponível em:**  Menu Operações Patrimoniais | Consulta Alocações.    Neste módulo é possível visualizar todos os detalhes da alocação, tais como: Código da Alocação, a data em que a mesma foi realizada, o número do documento informado durante o processo, o usuário e data de criação e o texto informado no campo Observação.  Em “Anexos” estarão às informações referentes ao processo de alocação como o código do [cliente\fornecedor](http://wikihelp.totvs.com.br/WikiHelp/FIN/FIN.clientesFornecedores.aspx), a [filial](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Filial.aspx), o [responsável](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Responsavel.aspx), o [departamento](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Departamentos.aspx), o [centro de custo](http://wikihelp.totvs.com.br/WikiHelp/CTB/CTB.cadastroCentroCustos.aspx) e a [localização](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Localidade.aspx).      **Observações:** Para a exclusão das ocorrências de Alocação de Patrimônio | Selecione a ocorrência | Processos | Cancelamento de Alocação. |
