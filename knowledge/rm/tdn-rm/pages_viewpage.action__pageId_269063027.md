# SUBORDINADOS - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Subordinados - Portal* |
| **Situação/Requisito:** | Ao marcar férias, por exemplo, para funcionário de chapa xxxxx, antes de marcar as férias, está como "Férias vencidas de 0 a 6 meses e ainda não marcadas". Após marcar as férias, o status fica como D e "Férias vencidas de 0 a 6 meses e já marcadas". Quando consulta na guia Subordinados também está desta forma. Após aprovar as férias, o status fica como M e "Férias vencidas de 0 a 6 meses e já marcadas". Após processar(pagar) as férias, o status fica como "P" e "Férias vencidas de 0 a 6 meses e ainda não marcadas". Porém, esta descrição está incorreta, pois já estão marcadas e pagas. |
| **Solução/Implementação:** | *No caso de férias finalizadas e pagas terá a mesma tratativa das férias marcadas.* |
| **Chamados relacionados:** | *94659, 100083* |
