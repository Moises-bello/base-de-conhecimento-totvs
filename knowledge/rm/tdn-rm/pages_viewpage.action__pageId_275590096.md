# INSCRIÇÃO EM ATIVIDADE OFERTADA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Inscrição em atividades ofertadas |
| **Situação/Requisito:** | Sistema não permite inscrever um mesmo aluno em uma determinada atividade mais de uma vez utilizando o assistente de inscrição de alunos em atividades ofertadas sendo que a inscrição manual é permitida. |
| **Solução/Implementação:** | Foi criado o parâmetro de processo "Permite inscrição duplicada de um mesmo aluno na mesma atividade" que virá desmarcado por default. Ao ser marcado, o processo permitirá a inscrição de um aluno na mesma atividade inscrita anteriormente.    Ajuste no preenchimento default da carga horária aproveitada na tela do processo a partir da atividade ofertada.    Ajuste na gravação dos dados preenchidos na tela. O sistema não estava considerando a data de início,  data de término, carga horária e créditos informados pelo usuário, ou seja, estava sempre considerando os valores defaults preenchidos na atividade ofertada. |
