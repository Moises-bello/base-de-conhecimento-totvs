# Moedas - Cotações

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Moedas - Cotações* |
| **Situação/Requisito:** | Na primeira aba do processo é selecionado apenas uma moeda e várias outras são selecionadas automaticamente, assim faz-se necessário voltar e desmarcar as moedas selecionadas.  Ao terminar o processo é exibido um aviso falando que os registros foram atualizados, mas não é possível avançar o processo e a tela "Processo executado com sucesso não é exibida". |
| **Solução/Implementação:** | Melhorias feitas na tela do processo "Download de cotação de moedas". A aba de progresso de download é a ultima aba, não mostrando mais o botão avançar. O botão cancelar, agora é "Fechar" ao termino do download. |
