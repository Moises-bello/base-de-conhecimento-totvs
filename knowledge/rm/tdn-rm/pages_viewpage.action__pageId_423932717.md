# VINCULAR PREVISÃO DE MEDIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento.. |
| **Função:** | Cadastro de Contrato. |
| **Situação/Requisito:** | Ao tentar vincular duas ou mais previsões financeiras a uma mesma medição, pela tela "Vinculação de Medições" o sistema retorna erro: *"O replanejamento automático das previsões de Medição não permite vincular mais de uma Previsão de Medição a Medição."*. |
| **Solução/Implementação:** | Alterar mensagem de erro para *"É permitido adicionar apenas uma previsão de medição para uma medição."*. Atualização das documentações no WikiHelp e no TDN. |
| **Tickets relacionados:** | 4085352 |
