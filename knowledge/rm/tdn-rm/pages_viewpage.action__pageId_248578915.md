|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Fracionamento de Job - Lançamento de Grupo de Eventos* |
| **Situação/Requisito:** | *Ao executar o processo de Lançamento de Grupos de Eventos - Francionando os Jobs, o mesmo não obedeceu o filtro de filial (filtro inserido na tela de parâmetro do lançamento), ou seja, após a execução do processo, foi verificado que chapas aleatórias ficam sem o lançamento dos eventos no envelope.* |
| **Solução/Implementação:** | Ajuste no fracionamento de job, correção na montagem dos filtros. |
