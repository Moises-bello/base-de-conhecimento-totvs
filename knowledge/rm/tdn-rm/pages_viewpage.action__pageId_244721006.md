# INCLUSÃO DE BOLSAS NO CONTRATO DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Exclusão de bolsas no contrato do aluno* |
| **Situação/Requisito:** | *Ao excluir uma bolsa do contrato do aluno, através da tela de cadastro de bolsas, o sistema faz uma validação que compete apenas a alteração do cadastro e com isso, ocorre erro de referência nula, causando instabilidade no sistema.* |
| **Solução/Implementação:** | *Foi realizada otimização da exclusão de bolsas do contrato do aluno, de forma que a validação de alteração no escopo de aplicação da bolsa somente ocorra em caso de alteração no cadastro da bolsa aplicada ao contrato.* |
