![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18494885840919)Tempo aproximado para leitura:**00:02:00 min** **Dúvida**Qual o parâmetro para calcular a correção monetária?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Para a geração da correção monetária, é necessário que o parâmetro "**MV\_CALCCM"** esteja habilitado.
