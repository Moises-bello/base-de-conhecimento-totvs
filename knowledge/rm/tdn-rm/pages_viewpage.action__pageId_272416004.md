# BOLSA RETROATIVA RESULTA EM LANÇAMENTO BAIXADO PARCIALMENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | Bolsa Retroativa |
| **Situação/Requisito:** | Lançamentos estão ficando com o status de baixados parcialmente após a inclusão de uma bolsa retroativa. |
| **Solução/Implementação:** | Passou-se a considerar os valores de pagamento a maior ou pagamento a menor já preenchidos na baixa original. Com isso, o sistema manter o  status baixado do lançamento pois o que muda são os campos de bolsa e pagamentos a maior ou a menor. |
