![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:35 min****Dúvida**Como criar um novo código de seleção de Lançamentos Ativos para o processo de Geração de Lançamentos Financeiros?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**

Durante o processo de geração de lançamentos financeiros, é necessário selecionar um grupo de lançamentos para serem gerados. Deste modo é possível gerar lançamentos específicos para cada situação.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9451084922007)

Para incluir novos códigos de lançamentos ativos, acesse: **Administração de Pessoal | Cadastros Globais | Tabelas Dinâmicas | Selecione a tabela CODLANATIV |** Clique em Incluir

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9451087982231)

Cadastre um código para agrupar os lançamentos conforme a sua preferência.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9451114640407)

Após o cadastro, o código já estará disponível na geração de lançamentos, porém deverá cadastrar este código nos lançamentos que deseja agrupar.

Para vincular este código de lançamento ativo nos lançamentos que deseja agrupar, acesse: **Encargos | Cadastros Financeiros | Parâmetros | Aba lançamento Ativos** e marque o lançamento criado correspondente ao parâmetro.

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9451143291031)
