**Dúvida**  
Quais são os navegadores homologados para o Meu RH?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
Os navegadores que são homologados para o Meu RH são:  
  
*- Google Chrome*  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19360945178519)

*- Mozila Firefox*  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19360959718039)  
  
*- Microsoft Edge:*  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19360945205527)  
  
**O Meu RH não irá** ter as funcionalidades corretas, **no Navegador Internet Explorer.**  
Nele, poderão ocorrer diversas inconsistências que impedem o uso.  
  
Vale lembrar que o **Internet Explorer teve a sua última versão lançada em 2015.**
