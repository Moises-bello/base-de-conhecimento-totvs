|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |

| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Rateio de tomadores* |
| **Situação/Requisito:** | O sistema não consiste os dias a serem distribuídos para o tomador na alteração global de tomadores |
| **Solução/Implementação:** | Otimizado alteração global de tomador, de forma que ao marcar parâmetro "Consiste dias de tomadores", o sistema execute uma simulação na alteração dos valores e valide, não deixando o processo alterar a quantidade de dias a ratear em caso de inconsistência. |
