# ENTRADA DE DADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Entrada de dadis* |
| **Situação/Requisito:** | Ao tentar lançar a Entrada de Dados com os parâmetros "Usa Eventos Fixos" e "Mostrar campo referência" marcados o sistema parece desabilitar qualquer opção de parametrização ou lançamento, impossibilitando a utilização da Entrada de Dados. |
| **Solução/Implementação:** | Alterar o valor das propriedades do campo 'Mostrar campo referência' para que seja permitido tentar as demais parametrizações e lançamentos. |
| **Chamados relacionados:** | TUVQU3 |
