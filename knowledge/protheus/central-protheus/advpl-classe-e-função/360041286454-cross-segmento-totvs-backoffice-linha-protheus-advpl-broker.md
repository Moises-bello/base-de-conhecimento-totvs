![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura:**00:02:00 min****Dúvida**Ao configurar o modo debug está gerando o erro Totvs Broker Client Gateway  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - A partir da versão 12.1.17  
  
**Solução**Em modo debug, deve-se criar uma "Nova configuração de Ativação" em "Depurar Configurations" apontando para um SmartClient.exe onde no smartclient.ini deve ter a chave Brokerproxy=1 comentada.
