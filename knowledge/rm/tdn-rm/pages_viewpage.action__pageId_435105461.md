Quando os Componentes que usam o Tipo de Componente **Desconto de Correção Monetária** são inseridos na Modalidade de Vendas ou diretamente nas Condições de Financiamento de um Contrato de Vendas, o sistema apresenta na tela, os campos abaixo para serem parametrizados:

**Percentual de desconto (%):** Define o percentual de desconto que incidirá sobre a Correção Monetária, caso este seja fixo (preestabelecidono Contrato), se não for fixo, deixe o campo em branco para ser informado posteriormente na inclusão da venda;

**Início:** Informe a data de início do desconto caso este seja fixo, se não for fixo, deixe o campo em branco para ser informado posteriormente;

**Fim:** Informe a data de fim do desconto caso este seja fixo, se não for fixo, deixe o campo em branco para ser informado posteriormente.

Importante!

A parametrização deste Componente o mesmo não deve ser associado a nenhum Tipo de Parcela, porque o mesmo não gera parcelas avulsas.

Os Componentes que utilizam o Tipo de Componente Desconto de Correção Monetária são utilizados para compor os Valores das Parcelas dos Grupos aos quais eles estão associados.

O Surgimento destes Componentes deve ser parametrizados para a Geração do Plano de Financiamento.
