![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16302811080343) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**É possível alterar o código do C.A. (Certificado Aprovação) do EPI após efetuar movimentação?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho – Todas as versões  
  
**Solução**Não. Por questão de integridade o sistema não irá permitir alterar um dado se já foi movimentado o histórico. Em questões de auditoria isso teria impacto e por isto não podemos permitir a alteração.  
  
Visto ser erro processual do usuário ao realizar o cadastro, diante disto via sistema não temos como corrigir. Uma sugestão, seria agendar um analista inloco para **avaliação**se existe saída contorno, visto que os dados do EPI já podem ate mesmo ter sido enviado ao governo.
