# FREQUÊNCIA DIÁRIA NO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Frequência Diária no Portal* |
| **Situação/Requisito:** | *No Portal | Professor | Diário de classe | Frequência diária, um professor demitido continua com acesso ao portal, porém ao tentar digitar a frequência diária o exibe a seguinte mensagem de erro: "Não há nenhum plano de aula cadastrado para a pesquisa solicitada.". A turma/disciplina possui todos os planos de aula cadastrados corretamente e o professor está cadastrado como professor do horário em todos os horários dessa turma/disciplina.* |
| **Solução/Implementação:** | *Ajuste no portal para que o professor demitido e dentro do prazo de acesso ao portal após demissão consiga acessar a frequência diária.* |
