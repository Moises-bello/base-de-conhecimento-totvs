![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34843728732951) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível gerar comunicado dispensa funcionário (aviso prévio)?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**Não temos um modelo padrão de comunicado dispensa funcionário, pois o aviso prévio não tem um regra especifica, cada empresa elabora o comunicado de acordo com o que desejar.  
  
O sistema possui o programa **GPEWORD** para impressão de Documentos através do *Microsoft Word,* deste modo é possível elaborar o comunicado conforme necessidade.
