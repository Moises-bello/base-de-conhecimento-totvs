|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Alterar Aprovador da Requisição* |
| **Situação/Requisito:** | *Ao tentar executar o processo Alterar Aprovador Atual da Requisição para a requisição do tipo Substituição, cujo aprovador seja de outra coligada, a seguinte mensagem é apresentada: "Valor inválido para o campo CHAPA."* |
| **Solução/Implementação:** | *Ajuste no processo de alterar aprovador da requisição. Não é exibido erro referente ao lookup do aprovador atual, mesmo quando o aprovador for de outra coligada.* |
