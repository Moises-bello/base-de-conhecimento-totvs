![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22875023514519) Tempo aproximado para leitura: **00:10:00 min****Dúvida**Ao acessar a rotina apresenta Help:DADO\_PROTEGIDO Problema: Acesso restrito: este usuário não possui permissão de acesso aos dados dessa rotina Solução: Saiba mais em LGPD  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões  
  
**Solução**

Algumas rotinas no módulo financeiro estão implementando a opção de bloqueio para Dados Protegidos

Exemplo:

**FINR350 - Posição Fornecedor.**

Caso o usuário no configurador esteja com as opções desabilitadas

"192 - Dados Pessoais"

"193 - Dados Sensíveis"

[![](https://centraldeatendimento.totvs.com/hc/article_attachments/22875015704087)](https://centraldeatendimento.totvs.com/hc/article_attachments/22875015704087)

Ao acessar a rotina irá apresentar a mensagem

Help:DADO\_PROTEGIDO Problema: Acesso restrito: este usuário não possui permissão de acesso aos dados dessa rotina Solução: Saiba mais em LGPD
