**Dúvida**  
Como realizar a configuração Gestão de Contratos (SIGAGCT) x TOTVS Assinatura Eletrônica (TAE)?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões

**Solução**  
Este documento tem por objetivo explicar como funciona a integração entre Gestão de Contratos (SIGAGCT) x TOTVS Assinatura Eletrônica. Outras informações referente a Totvs Assinatura Digital devem ser consultadas na documentação oficial neste endereço TOTVS Assinatura Eletrônica (Manual Operacional).

Siga por gentileza o passo a passo do Link [Gestão de Contratos (SIGAGCT) x TOTVS Assinatura Eletrônica (TAE)](https://tdn.totvs.com/x/K1cBMg)

***Obs:***

***Pergunta:*** Como alterar usuário de autenticação no TAE da Integração com o GCT ?

***Resposta:*** Atualmente a integração do SIGAGCT com o Totvs Sign não possui uma funcionalidade ou configuração para se mudar ou alterar as credenciais de autenticação principais que foram incluídas no momento da implementação da funcionalidade, contidas na doc abaixo da integração, e que é a responsável pela inclusão/envio do doc integrado na plataforma:

[Gestão de Contratos (SIGAGCT) x TOTVS Assinatura Eletrônica (TAE)](https://tdn.totvs.com/x/K1cBMg)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29626447807767)

No caso, uma alternativa existente, conforme reporta a documentação acima, seria realizar a troca da senha deste usuário de acesso **na Plataforma do Totvs Sign**, para que então sejam solicitadas novas credenciais na integração posterior a esta alteração de senha, e assim podendo se inserir um novo usuário e senha da plataforma para essas credencias, as quais ficarão para as integrações a partir daí.

Lembrando que este usuário das credencias de comunicação precisam ter os devidos acessos a inclusão de docto (Permissão para Publicação) no Totvs Sign, conforme informa a documentação:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29626447811863)
