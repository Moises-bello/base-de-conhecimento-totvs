![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18246499174807) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**O Sistema realiza o cálculo de estabilidade quanto a demissão após retorno licença maternidade?

**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O sistema padrão não trata verbas indenizatórias referentes a rescisão contratual de empregada demitida após retorno licença maternidade, por este motivo, é preciso criar verbas sem ID de cálculo e lançar manualmente na rescisão.
