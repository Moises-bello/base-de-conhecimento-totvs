![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Cadastro de Operador Estrangeiro Duimp  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control*- a partir da versão 12.1.27  
  
**Solução**Permite a inclusão de Operador Estrangeiro.  
As informações devem ser preenchidas de acordo com as orientações descritas conforme tabela abaixo:

|  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | **Campo:** | **Descrição** | | **Cód. Importador:** | Informe o código do importador. | | **CNPJ Raiz:** | Informe o CNPJ raíz do importador, são as dez primeiras posições do CNPJ.**Exemplo:**12.345.678 | | **Nome do Atributo:** | Informe o nome de apresentação do Atributo. **Exemplo:** Detalhamento IBAMA | | **Cód.Fornec.:** | Informe o código do Fornecedor. | | **Loja Fornec.:** | Informe o código da Loja do Fornecedor. | | **TIN:** | Informe a filial + código do fornecedor + loja do fornecedor (este campo já é gerado automaticamente quando informado os campos código de fornecedor e loja. | | **Nome:** | Informe o nome do operador estrangeiro. | | **Endereço:** | Informe o endereço do operador estrangeiro. | | **Cidade:** | Informe a cidade do operador estrangeiro. | | **Subdivisão País:** | Informe código ISO 3166 da subdivisão / província. | | **País:** | Informe os dois primeiros dígitos do campo Subdivisão País. | | **Cód. Postal:** | Informe o código postal do endereço do operador estrangeiro. | | **Versão Manual** | Versão manual do operador estrangeiro | | **Versão** | Versão do Portal Único para o Operador Estrangeiro, ou Versão manual gatilhada caso esteja vazio. | |
