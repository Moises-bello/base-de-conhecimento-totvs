**Dúvida**Como configurar o Sistema para calcular médias no afastamento para funcionários comissionados?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**1. Acesse o módulo de Gestão de Pessoal;  
2. Entre na rotina **Tipos de Ausência** pelo caminho no menu **>Atualizações >Definições de Cálculo >Tipos de Ausência**;  
3. Selecione o Tipo de Ausência que deseja parametrizar e clique em **Alterar**;  
4. No bloco Informações de cálculo, no campo **N.Mes.C.Med.** informe a quantidade de meses de busca para as médias e no campo **Cat.Calc.Med**, informe a categoria "C - Comissionado":
