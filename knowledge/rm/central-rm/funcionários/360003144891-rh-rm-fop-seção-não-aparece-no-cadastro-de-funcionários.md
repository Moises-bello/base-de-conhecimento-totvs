Dúvida**O que fazer quando as seções foram cadastradas, porem não aparece no cadastro de funcionários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Existe algumas razões para que as seções não apareçam no cadastro de funcionários. Segue abaixo algumas possibilidades:  
  
1. **Máscara de seção:** As seções criadas precisam respeitar a máscara definida no sistema. Para validar a máscara utilizada na coligada, acesse **Configurações | Parametrizador | RH - Máscaras e Quebras**. Caso as seções cadastradas estejam com máscara diferente do informado no Parametrizador, não será possível selecioná-las no cadastro dos funcionários.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360004159451/mceclip1.png)  
  
2. **Seção Desativada:** Seções desativadas não são exibidas para vínculo de funcionários. É importante verificar se a seção está ativa no cadastro de seções. Para verificar, acesse **Administração de Pessoal | Seções** e veja se a opção **Desativada** está marcada:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360004155852/mceclip0.png)
