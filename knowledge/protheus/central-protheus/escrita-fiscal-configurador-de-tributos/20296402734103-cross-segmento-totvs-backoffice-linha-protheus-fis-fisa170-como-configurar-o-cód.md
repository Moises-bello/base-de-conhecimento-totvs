![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20296432388887) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Como configurar o código de reflexo?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - FIS - a partir de versão 12.1.2210  
  
**Solução**Segue abaixo as configurações de como configurar o reflexo no FISA170, vamos utilizar o exemplo do credito presumido.

MV\_ESTADO= SC

Código de lançamento = SC10000003

Alíquota do credito presumido 9%
