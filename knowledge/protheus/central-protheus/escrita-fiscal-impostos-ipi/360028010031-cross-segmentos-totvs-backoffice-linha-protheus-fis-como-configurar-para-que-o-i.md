**Dúvida**

Como configurar para que o IPI some na base do ICMS?  
  
**Ambiente**

Protheus  – Livros Fiscais – A partir da versão 11.80  
  
**Solução**

Para que o IPI seja somado na base do ICMS configure o campo abaixo:

**IPI na Base (F4\_INCIDE):** Sim.
