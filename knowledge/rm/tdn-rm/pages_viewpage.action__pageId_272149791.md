# Módulo de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Módulo de Caixa |
| **Situação/Requisito:** | Ao pesquisar um lançamento parcialmente baixado e vinculado a mais de um boleto, é visualizado em duplicidade na sessão de caixa alterando apenas o status do boleto. Cliente gostaria que fosse criada uma forma de visualizar somente os boletos de acordo com o filtro realizado na visão. |
| **Solução/Implementação:** | Melhoria no processo de Sessão de Caixa. Agora o sistema deixa o cliente realizar as pesquisas de acordo com o status do Boleto. |
