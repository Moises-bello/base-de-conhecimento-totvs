# 3221805 FINANCEIRO01-7782 DT NÃO É POSSÍVEL GERAR ARQUIVOS DE REMESSA DE COBRANÇA COM BOLETOS CANCELADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos. |
| **Módulo:** | TOTVS Gestão Financeira. |
| **Função:** | Remessa de Cobrança |
| **Situação/Requisito:** | O sistema não permite gerar o processo de "Remessa de Cobrança" para Lançamento associado a Boleto com status remessa 'Não Remetido' ou 'Pendente Remessa', e status "Cancelado". |
| **Solução/Implementação:** | Habilitada a geração de remessa quando o boleto está com status remessa 'Não Remetido' ou 'Pendente Remessa', e 'Cancelado'. |
