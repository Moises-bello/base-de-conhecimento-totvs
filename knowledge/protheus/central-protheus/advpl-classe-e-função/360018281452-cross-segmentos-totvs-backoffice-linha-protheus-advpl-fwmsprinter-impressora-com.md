Dúvida**Gostaria de fazer Impressão gráfica de etiqueta em impressora matricial utilizando a **FWMSPrinter**, onde papel ficasse aguardando a próxima impressão de etiqueta?

**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL– A partir da versão 11.80  
  
**Solução**A Classe **FWmsprinter** só funciona se passar pelo sistema operacional e a impressora com porta paralela a impressão é diretamente na porta.

**Nota.:**  
Para etiquetas com impressoras térmicas deve utilizar a Classe [MSCBPrinter.](http://tdn.totvs.com/display/public/mp/MSCBPrinter+-+Configura+Impressora+--+30557)
