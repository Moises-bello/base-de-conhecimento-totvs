|  |  |
| --- | --- |
| Situação | Tecla ENTER não funciona para expandir/colapsar uma TTree |
| Ocorrência | A tecla ENTER no ADVPL não pode ser utilizada com o SetKey e o comportamento padrão não segue o mesmo que o duplo clique do mouse. |
| Correção | Tecla ENTER agora segue o mesmo comportamento do duplo clique do mouse (em uma TTree), ou seja, expande/colapsa/seleciona um item em um TTree. |
| Informações adicionais | * Referente à ocorrência: TEC-7477 * Disponível em builds superiores a 7.00.131227A 2.2.1 |
