![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16025069652503) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Parâmetros usados para o envio de *E-mail e/ou Workflow*  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Os parâmetros usados no **envio de *E-mail* e/ou *Workflow*** são:   
  
**MV\_RELACNT** = - conta de autenticação do *e-mail*.  
**MV\_EMCONTA** = conta de autenticação do *e-mail*.  
**MV\_RHCONTA** = conta de autenticação do *e-mail*.  
**MV\_RELFROM** = *E-mail* utilizado no campo *FROM* no envio de relatórios por *e-mail*  
**MV\_RELAUSR** = - Usuário para Autenticação no Servidor de *Email*  
**MV\_EMSENHA** = Senha da Conta de *E-Mail* para envio de relatórios   
**MV\_RELPSW** = - Senha da Conta de *E-Mail* para envio de relatórios   
**MV\_RELAPSW** = - Senha para autenticação no servidor de *e-mail*  
**MV\_RHSENHA** = Senha da Conta de *E-Mail* para envio de relatórios   
**MV\_RELAUTH** = < .T. > - Servidor de *EMAIL* necessita de Autenticação?  
**MV\_RHAUTEN** = < .T. > - Servidor de *EMAIL* necessita de Autenticação?                            
**MV\_RELSERV** = < mail.exchangecorp.com.br:587 > - Nome do Servidor de Envio de *E-mail* utilizado nos relatórios Ex. [mail.uol.com.br](http://mail.uol.com.br/)  
**MV\_RHSERV** = < mail.exchangecorp.com.br:587 > - Nome do Servidor de Envio de *E-mail* utilizado nos relatórios Ex. [mail.uol.com.br](http://mail.uol.com.br/)  
**MV\_GCPPORT** = 587 - Porta do servidor de SMTP  
**MV\_PORSMTP** = 587 - Porta do Servidor SMTP                             
**MV\_RELSSL** = < .T. > - Define se o envio e recebimento de e-mails na rotina SPED utilizara conexão segura (SSL).             
**MV\_TAFSSL** = < .T. > - Define se o envio e recebimento de *e-mails* utilizara conexão Segura                           
**MV\_RELTLS** = < .T. > - Informe se o servidor de SMTP possui conexão do tipo segura ( SSL/TLS ).  
**MV\_TAFTLS** = < .T. > - Informe se o servidor de SMTP possui conexão do tipo segura ( SSL/TLS ).
