# Criar menu customizado no Portal RM

|  |  |
| --- | --- |
| **Produto:** | RM |
| **Versões:** | 12.1.16 ou Superiores |
| **Ocorrência:** | Criar menu customizado no Portal RM |
| **Ambiente:** | RM Portal |
| **Passo a passo:** | Introdução Neste módulo iremos mostrar procedimento para criar um menu customizado no Portal RM.    **1 -** Criar o menu  **1.1 -** Através da MDI acessar o contexto “Gestão de Conteúdo”      **1.2 -**  Acessar o menu “Menu Portal"      **1.3 -** Através do menu aberto adicionar um novo registro      **1.4** - Marque a Flag Customizado e selecione qual será o menu Pai.     Aviso Os menus Customizados devem sempre ser criados, no ultimo nível da arvore de menus.    **1.5** - Preencha os campos com as informações desejadas para o novo menu.      **2** - Definindo a imagem do novo menu  **2.1** - As imagens de icones do Portal ficam guardas no deretório Source (UNIDADE:\totvs\corporerm\Corpore.Net\), divididas em pastas conforme seu módulo.      **2.2** - Crie uma pasta (sem espaços no nome) dentro deste diretório e dentro desta pasta, coloque a imagem que será utilizada como ícone. Em nosso exemplo utilizamos o caminho **\Source\Novo-Menu\Images.**      **2.3** - No casdatro do menu, o campo Link da Imagem receberá o endereço da imagem (a partir da pasta Source) + o nome da imagem (com a extensão). Em nosso exemplo ficou como **\Source\Novo-Menu\Images\Logo\_TOTVS.jpg**.      **3** - Aplicação no Portal  Com o novo menu salvo, basta atualizar a página do Portal RM que o novo menu será apresentado.    Antes da aplicação    Depois da aplicação |
