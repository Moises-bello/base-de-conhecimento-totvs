![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:21 min****Dúvida**Como importar relatórios através do RM Reports?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar a importação de relatórios através do RM Reports, siga as orientações abaixo:  
  
1. Acesse: **Gestão | RM Reports** | **Processos | Importar Estrutura de Relatório.****![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9979176545303)**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9979188136215)  
  
2. Logo, será aberta uma janela para localização do relatório nas pastas do computador local. Assim, clique na opção **Adicionar Objetos.** Os relatórios padrão do sistema TOTVS são acessados através da ferramenta **TOTVS compartilhamento**, [clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/7781155867543-RH-RM-FOP-Como-fazer-download-de-arquivos-no-totvs-compartilhamento) para mais detalhes.  
  
Lembrando que pela ferramenta descrita acima também é possível realizar a importação do relatório.   
Para realizar a importação do relatório através desta rotina, deverá acessar o TOTVS compartilhamento e realizar o **download** da estrutura do relatório.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360014289552/mceclip2.png)  
  
3. Para melhor entendimento dos campos da tela acima, segue informações:  
  
**Código do relatório:** Apresenta o código do relatório selecionado.  
  
**Sistema para importação:** Aponta qual é o módulo para onde o relatório será disponibilizado.  
  
**Sobrescrever Existente:** Será marcada automaticamente quando o sistema identifica que o relatório selecionado para importação já existe no sistema. As informações dos campos são preenchidas automaticamente pelo sistema e não precisam de alterações.  
  
4. Para disponibilizar o relatório para todas coligadas, sem precisar importar novamente, realize o seguinte caminho:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9979395979415)  
  
Após habilitar a opção **Visível a todas as coligadas,** o mesmo relatório estará disponível a todas as coligadas cadastradas no RM.
