Ao acessar a opção de **2ª Via de Boleto**, o PDC apresenta ao usuário as ao seguintes informações:

Resumo:

* **Botão mostrar/ocultar:** Utilize este botão para exibir ou ocultar os valores dos boletos, Esta opção é muito útil quando se acessa o portal em locais públicos
* **Boletos em Atraso:** Exibe o somatório da quantidade de boletos em atraso. Esta informação é exibida conforme o acionamento do botão acima

Visão de Detalhamento dos boletos: São exibidas as informações abaixo:

* **Situação:** Exibe a situação do boleto Se vencido ou a vencer;
* **Boleto:** Ao clicar na imagem do código de barras do boleto, o sistema apresenta as opções:
  + **Baixar Boleto:** Acione esta opção para fazer o download do arquivo do boleto em PDF;
  + **Copiar Código de Barras:** Clique nesta opção para copiar o código de barras do boleto para a área de trabalho e posteriormente colá-la quando da realização do pagamento. Em alguns navegadores, é necessário aplicar a permissão para que a página do portal tenha acesso à área de transferência do dispositivo (desktop ou laptop);
  + **Fechar:** Utilize este botão para fechar esta janela;
* **PIX:** Caso o boleto esteja parametrizado para pagamentos via PIX, ao clicar nesta opção o sistema apresentará a opção para copiar o QR Code do PIX;
* **Contrato:** É o número do contrato de locação ao qual este boleto está associado;
* **Vencimento:** É a data de vencimento deste boleto;
* **Parcela (R$):** É o valor do boleto, sendo que esta informação é afetada pelo botão mostrar/ocultar descrito acima.
