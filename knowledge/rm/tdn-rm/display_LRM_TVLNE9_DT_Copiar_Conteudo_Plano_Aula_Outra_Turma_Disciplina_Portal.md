# COPIAR CONTEÚDO DE PLANO DE AULA PARA OUTRA TURMA/DISCIPLINAS - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Copiar Conteúdo de Plano de Aula para Outra Turma/Disciplina - Portal* |
| **Situação/Requisito:** | *Ao tentar fazer a cópia de plano de aula mesmo com o parâmetro educacional desmarcado (Parâmetros >> Educacional >> 15.04 - RM Portal >> 15.04.01 - RM Portal Gerais >> Portal Geral 2/7 >> Permitir que o professor consulte informações de períodos letivos encerrados no portal), o sistema exibe todas turmas/disciplinas com períodos letivos encerrados.* |
| **Solução/Implementação:** | *Ajuste no filtro da consulta que traz os dados para a exibição das turmas/disciplinas na cópia de conteúdo do plano de aula para outra turma/disciplina no portal, para que não seja exibido as turmas/disciplinas com período letivo encerrado caso o parâmetro "*Permitir que o professor consulte informações de períodos letivos encerrados no portal*" desmarcado.* |
