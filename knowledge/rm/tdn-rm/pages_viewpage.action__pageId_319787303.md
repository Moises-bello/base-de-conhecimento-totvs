O contexto de Cadastro do Sistema (RM) permite ao gerador utilizar dados a partir de cadastros padrões do RM, todas as tabelas disponíveis na tela de cadastro poderão ser utilizadas como fonte de dados da geração. Esta opção só está disponível no Gerador RM.

![](/download/attachments/319787303/cadastro_do_sistema_rm.png?version=1&modificationDate=1512921922000&api=v2)

1Nome do Servidor

Selecione o cadastro do RM que será utilizado para leitura dos dados. A chave primária do cadastro deverá ser informada na aba parâmetros do contexto. Para mais informações consulte [Parâmetros do Contexto](/pages/viewpage.action?pageId=319787287).
