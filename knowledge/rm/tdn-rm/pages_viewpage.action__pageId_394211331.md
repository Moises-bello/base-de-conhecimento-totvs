# ALTERAR SITUAÇÃO DE MATRÍCULA DE DISCIPLINA COM PRÉ-REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Alterar situação de matrícula |
| **Situação/Requisito:** | Ao realizar o processo para alterar situação de matrícula de uma disciplina ocorre o erro "O aluno não cumpriu o pré-requisito da disciplina". Porém, a disciplina de pré-requisito esta com situação aprovada, conforme análise curricular. |
| **Solução/Implementação:** | A rotina de verificação de pré-requisitos já cursados foi alterada para não ocorrer nenhum impedimento indevido na alteração de situação de matrícula. |
