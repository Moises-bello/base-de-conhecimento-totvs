# Escrituração Fiscal - Transferência de Ativo Imobilizado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Processo de Escrituração Fiscal |
| **Situação/Requisito:** | Escrituração Lançamento de Transferência - Ativo Imobilizado  Incluímos o Movimento de transferência, Informamos o bem na aba Patrimônio do Item do movimento.  Após a Escrituração do movimento, verificamos que no Totvs Gestão Fiscal que o Bem foi preenchido no lançamento de saída,  porém no lançamento de entrada ele não foi preenchido.  Ao preencher o Bem manualmente na aba Patrimônio do Item do lançamento e salvar foi apresentado a seguinte mensagem:  Não há lançamento de transferência do Ativo da filial origem para esta filial. |
| **Solução/Implementação:** | Ajustes realizados no Processo de Escrituração Fiscal/Inclusão de Lançamentos para Naturezas de Ativo imobilizado - Lançamentos de Transferência de Bens entre Filiais. |
