**Processo Cópia do Entendimento**   
Através desse processo é possível replicar o entendimento para ocorrências relacionadas de acordo com a opção escolhida.   
Inserir para o atendimento pai (mestre).  
A ocorrência pai (mestre) receberá o entendimento com status "Entendimento aguardando aprovação/reprovação".  
Inserir para os atendimentos filhos (detalhes).  
As ocorrências filhos (detalhes) receberão o entendimento com status "Entendimento aguardando aprovação/reprovação".  
Inserir para os atendimentos de mesmo nível (irmãos, de mesmo pai).  
A ocorrência de mesmo nível (irmãos, de mesmo pai) receberão o entendimento com status "Entendimento aguardando aprovação/reprovação".  
**Observação**  
As ocorrências que já possuírem entendimentos pendentes serão aprovados automaticamente pelo sistema sendo registrado no próprio entendimento.
