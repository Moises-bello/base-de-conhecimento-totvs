# Ajuste no Formulário de Registro de Atendimento Externo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão de Saúde |
| **Função:** | Registro de Atendimento Externo |
| **Situação:** | Ao processar/ realizar um solicitação de guia SP/SADT para a TISS, e clicar no botão NF para o envio da Nota Fiscal, o sistema gerava uma mensagem de exceção: "Erro durante o processamento, No user transaction is currently in progress". |
| **Solução:** | Foram realizados ajustes no formulário para que ao processar o envio de Nota Fiscal, não seja exibida nenhuma mensagem de exceção. |
