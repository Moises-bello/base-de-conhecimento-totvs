Este material possui um exemplo como proceder para realizar a inclusão de um Template onde o mesmo poderá ser utilizado através do Portal WEB **(Gestão de conteúdo)** para inclusão de atendimentos com os campos *Pre- estabelecidos* **(pelo Modelo de atendimento).**

**1)** **Acesse o Contexto: Gestão de relacionamento com o Cliente:**

**Neste primeiro momento será necessário preencher o Modelo ao qual o atendimento utilizará para preencher os campos pre definidos no mesmo, ao parametrizar este modelo é importante preencher todos os campos aos quais estarão sendo apresentados no atendimento quando selecionado.**

**- Selecione o Menu: Atendimentos -> Icone Modelo**

   
**- Em seguida será necessário associar o Padrão que será utilizado no Portal Web (Gestão de conteúdo).**

Importante informar o MODELO que foi parametrizado para que o mesmo seja associado ao Padrão Corpore.NET.

**2)** **Acessando o Portal WEB (Gestão de conteúdo)**

**Ao acessar o Portal com o usuário, selecione o módulo CRM**

**Ao clicar em Templates serão exibidos os templates disponibilizados para o usuário, bastando selecionar o template ao qual deseja utilizar.**

**- Será apresentado os campos preenchidos já pre estabelecidos pelo Modelo.**

**O usuário poderá alterar as informações no momento que desejar, bastando editar os campos.**

**Em seguida clique em Enviar para que o atendimento seja incluído.**

**- Ao final será apresentada a menagem informando que o atendimento foi incluido para o atendente responsável.**

**- Ao acessar o módulo gestão de Relacionamento com o cliente basta listar os atendimentos observando o atendimento incluido através do portal gestão de conteúdos.**
