#### 1º PASSO:

1. Acesse o RM.EXE:
2. Menu: Serviços
3. Icone: Actions do sistema (caso apareça a janela de filtros, execute-a)
4. Clique em Executar

#### 2º PASSO:

Na guia explorar, digite, por exemplo, (Cubo) aparecerá uma notificação informando o nome da Action que devemos procurar para editar.   
 Posicione o mouse em cima de Cubo. Net (aparecerá o nome da Action para pesquisarmos) D

Digite este nome no campo de pesquisa para localizar a Action:

#### 3º PASSO:

 Ao localizar a Action, clique duas vezes em cima dela:

#### 4º PASSO:

1. 1. **Finalize o sistema.**
   2. **Acesse:\totvs\CorporeRM\RM.Net**
   3. **Execute o aplicativo: RM.Host.ServiceManager.exe**
   4. **Pare o serviço: ( delete o arquivos \_Broker.dat)**
   5. **Inicie o serviço novamente e acesse o sistema validando os ajustes**
