|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **TIPO** | **Cadastro do PS** | **1º** | **2º** | **3º** | **4º** | **5º** | **6º** | **7º** |
| Alocação  Locais de Prova | Distribuição Caderno de Prova | Importação  Notas | Classificação | Chamada | Matrícula manual via Processo Seletivo RM | Matrícula automática |

| **Prova** | * Criação de *Etapas* na Área de Interesse Ofertada; * Vinculação de Provas na *Etapa*; |  |  |  |  |  |  |  |
| **Oferta Online** | * Parâmetro "*Utiliza venda online de cursos*" e " *Utiliza novo portal de inscrições*"; * Preenchimento da Aba "*Venda online de cursos*" na Área de Interesse Ofertada. * Não possui *Etapas* na Área de Interesse Ofertada; |  |  |  |  |  |  |  |
