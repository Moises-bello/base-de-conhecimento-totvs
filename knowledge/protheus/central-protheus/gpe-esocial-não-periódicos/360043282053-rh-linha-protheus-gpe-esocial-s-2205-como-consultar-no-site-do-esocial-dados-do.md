**Dúvida**  
Como consultar no *site* do eSocial dados do evento **S-2205** (Dados Cadastrais)?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Esse evento está localizado no menu **Empregado** e **Trabalhador sem Vínculo** após fazer *login* no [Portal eSocial](https://www.gov.br/esocial/pt-br). Para consultar os dados **cadastrais**, o empregador deverá digitar o CPF completo do trabalhador para buscar seus dados.  
  
Caminho para empregados: **Empregado > Gestão de Empregados***:*  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17269930574743)*  
  
Caminho para TSVE: **Trabalhador sem Vínculo > Gestão de Trabalhadores**:  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17269923531543)*  
  
Será exibida a seguinte tela:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17269880513943)

**Observação:**

* Para conhecer o manual completo de navegação no *site* do eSocial acesse: <https://www.gov.br/esocial/pt-br/empresas/manual-web-geral>
* Não recomendamos **inclusão/alteração** manual no *site* do **eSocial** devido a prejudicar a integridade entre os dados do sistema e governo gerando erros futuro.
