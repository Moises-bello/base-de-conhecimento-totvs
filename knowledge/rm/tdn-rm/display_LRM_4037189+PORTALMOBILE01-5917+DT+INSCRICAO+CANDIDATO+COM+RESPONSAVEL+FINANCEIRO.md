# Inscrição de candidato utilizando seus dados como responsável financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Inscrição de candidatos |
| **Situação/Requisito:** | Ao realizar a inscrição com um candidato que já existe, pelo Ensino Básico, o campo "Utilizados usuário selecionado como" estava vindo para selecionar somente a opção "Responsável da inscrição", porem o usuário é o próprio candidato. |
| **Solução/Implementação:** | Ajuste para que o combo de "Utilizar usuário selecionado como" seja carregado com os dados corretamente após o candidato que já existe realizar login para aproveitar os dados. |
