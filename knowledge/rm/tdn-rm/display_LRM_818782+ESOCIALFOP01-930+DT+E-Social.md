# E-Social

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Validador de base E-Social |
| **Situação/Requisito:** | Ao realizar o processo de validação da base de dados do E-Social, quando o funcionário possuía cadastrado nos anexos/Registro profissional, dois registros indicados como principal, o sistema apresentava um erro não tratado para o usuário, dificultando o ajuste por parte do cliente e entendimento do suporte. |
| **Solução/Implementação:** | Foi tratado o erro para que o sistema utilize um dos registros principais,e indique para o usuário na geração do xml que o usuário possui tal cadastro incorreto, e que deve ser ajustado. |
