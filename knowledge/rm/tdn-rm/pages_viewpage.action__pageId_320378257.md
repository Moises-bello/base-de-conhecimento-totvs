# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Fiscal |
| **Versões:** | 12.x |
| **Ocorrência:** | Cadastro de Período de Apuração |
| **Ambiente:** |  |
| **Passo a passo:** | O período de apuração deverá ser criado para a apuração dos tributos. Esse cadastro deverá respeitar a periodicidade informada no cadastro do tributo.    Vá em Obrigações Principais / Obrigações Acessórias.        Faça um filtro para exibição dos períodos e clique na opção Incluir.        Informe o tributo e data do início e fim do período. Lembrando que essa data deve corresponder a períodicidade do cadastro do tributo.  Clique em salvar e o período foi criado.        Para criar vários períodos para o ano todo faça o seguinte processo:    Vá em Obrigações Principais / no quadrante Apuração clique em Mais... e escolha a opção Inserir Períodos de apuração.        Informe o tributo, marque a coligada específica ou todas as Coligadas, informe o intervalo de filiais e marque a opção Considerar todo o Ano e informe o ano em questão.  Clique na opção Executar que os períodos serão criados conforme a periodicidade do cadastro de tributos. |
