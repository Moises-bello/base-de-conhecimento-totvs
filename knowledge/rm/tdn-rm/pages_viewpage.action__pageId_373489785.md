# Emissão de NF-e/NFC-e - Tag vTroco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Emissão de NF-e/NFC-e |
| **Situação/Requisito:** | Tornar possível que o cliente consiga emitir NF-e sem gerar financeiro para o movimento, pois atualmente a SEFAZ rejeita a nota informando que o valor do troco está incorreto |
| **Solução/Implementação:** | Foi modificado o processo de geração da NF-e/NFC-e para não gerar a TAG de troco quando o valor do mesmo for zero. |
