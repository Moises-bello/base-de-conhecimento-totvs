Os cadastros das remessas de Cobrança Eletrônica serão feitos pelo menu Movimentações Bancárias / Integração Bancária / Remessa Bancária ou poderá ser realizado também durante o processo de geração das remessas.

**Procedimento:**

Acesse o menu Movimentações Bancárias / Integração Bancária / Remessa Bancária / escolha o Processo e inclua uma nova.  
 Os dados solicitados são requeridos nos respectivos arquivos de remessa.

Em se tratando de remessa de Cobrança Eletrônica, se a remessa for no padrão CNAB240 você deverá complementar as informações, que serão exibidas na ativação da opção Padrão CNAB240 desta tela. Estas informações são requeridas pelo Bancos, conforme indicadas nos respectivos manuais de cobrança.
