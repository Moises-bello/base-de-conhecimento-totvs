Funções dos principais campos em **Autorizações OGA340**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução  
Principais Campos:**

| Campo | Descrição |
| --- | --- |
| Contrato | Código do contrato. |
| Tipo | Indica o tipo de autorização. Os valores aceitos são:   * E - Entrada; * S - Saída. |
| Data Inicial | Data de início de validade da autorização. |
| Data Final | Data final de validade da autorização. |
| Qtd. Ini | Quantidade inicial de autorização. |
| Qtd. Aut. Exced | Quantidade autorização para volumes excedentes. |
| Status | Indica a situação do registro de autorização. Esse campo é alterado automaticamente pelo sistema. As situações disponíveis são:   * A - Aberta; * I - Iniciada; * E - Encerrada. |
