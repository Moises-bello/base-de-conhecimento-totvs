# Aprazamento no PEP não aceita desmarcar

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Aprazamento PEP |
| **Situação:** | Após desmarcar alguns horários do aprazamento e gravar o item, os horários desmarcados voltam a aparecer |
| **Solução:** | Realizado ajuste para não recalcular os aprazamentos ao gravar o item |
