# Impressão de boleto no portal do aluno Corpore.NET

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Impressão de boleto |
| **Situação/Requisito:** | O boleto gerado em documento PDF não era exibido para o usuário na janela modal que é exibida. Os navegadores sempre realizavam o download do arquivo e mantinha a janela com a mensagem dizendo "Aguarde", mesmo após o download automático do arquivo. |
| **Solução/Implementação:** | Foi realizado o ajuste para exibição de documento PDF dentro do modal de exibição do boleto.  Caso o browser do usuário esteja configurado para não exibir documentos PDF no navegador, e sim realizar o download, será exibido uma mensagem pro usuário que foi realizado o download automático do boleto, e retirado a mensagem de "Aguardo" para o usuário. |
