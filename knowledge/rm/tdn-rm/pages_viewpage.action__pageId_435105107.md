**Novidades 12.1.22**

---

**Vendas**  
**Reformulação dos Menus do TIN**  
A partir desta versão os menus do TIN terão uma nova disposição para melhorar a usabilidade e colocar os menus mais utilizados de forma visível na tela. Os itens mais utilizados, aparecerão mais à esquerda da tela e os menos utilizados, mais à direita. A aba cadastro deixa de existir e os cadastros foram separados entre Venda e Aluguel. Outra mudança é em relação aos relatórios que serão separados entre Venda e Aluguel também. A aba de contabilidade continua, porém serão agrupadas as funcionalidades por Venda e Aluguel.  
Observação: Os itens no wikihelp estão agrupados exatamente como no sistema a partir da versão 12.1.22.  
   
**Parâmetros de Geração do Movimento**  
O cadastro de parâmetros da geração do movimento foi alterado para permitir o tipo de geração "Movimento de Despesas de venda".  
   
**Parâmetros de Integração Financeira**  
Assim como no módulo de alugueis, foram gerados na parte de Vendas, os parâmetros de integração financeira. Este cadastro será utilizado em conjunto com o cadastro de despesa de vendas.  
   
**Despesas de venda**  
O cadastro de despesas existente no módulo de aluguel foi evoluído para atender o módulo de vendas imobiliárias. Teremos o cadastro de despesas da subunidade, a integração com o módulo de materiais gerando movimentos e integração financeira para geração de lançamentos de reembolso.  
   
**Ferramenta de diagnóstico**  
**Ajuste nas diferenças de valores**: Agora será possível ajustar as diferenças de valores entre os lançamentos do TIN e os títulos correspondentes no Protheus.  
**Lançamentos remetidos no RM, mas não estão em Borderô no Protheus**: A ferramenta irá descobrir se existe no ambiente algum lançamento quem não exista o boleto no lançamento do TIN, mas no PROTHEUS o título correspondente esteja em Borderô. Como ação corretiva, será gerado o boleto no lançamento.   
**DE-PARA com ID de baixa duplicados no RM**: A partir da versão 12.1.22 é possível através da ferramenta de diagnóstico verificar todos os de-para que possuem ID de baixa duplicados.  
   
**Permissões de Condições de Financiamento.**  
Foram criadas para a versão revitalizada do TIN, as permissões para os processos existentes nas condições de financiamento, tanto do contrato, do aditivo e do distrato. Agora será possível escolher quais processos (Copiar plano, copiar modalidade, gerar plano, etc) o usuário poderá executar.   
   
**Comissão**  
A partir da versão 12.1.22 será possível realizar o parcelamento do valor da comissão. Este processo é habilitado tanto para a geração da comissão para o Fornecedor (Gestão de Estoque, compras e faturamento) quanto para o Funcionário (Folha de Pagamento).  
   
**Aviso PDC**  
Será mostrado um aviso para os usuários do PDC sobre a nova forma de licenciamento para utilização do PDC.  
   
**Cópia entre coligadas de Clientes/Fornecedores.**  
Ao utilizar o processo de cópia entre coligadas de Cli/For, os anexos referentes ao TIN (Dados complementares) serão copiados automaticamente para a coligada selecionada.  
   
**Processo de revitalização do TIN**  
Os clientes de outros segmentos que não possuem nenhuma venda, não terão no RM os avisos e os processos de execução da revitalização na migração para a versão 12.1.22  
   
**Aluguel**  
   
**Abaixo temos algumas novidades relacionadas as funcionalidades de Despesa para o Módulo de Aluguéis:**  
**Regras de Reembolso**  
Criado o cadastro de Regras de Reembolso, que será utilizado para definir qual a prioridade de cobrança das parcelas de reembolso de uma despesa. E possível priorizar entre Locatário e Locador, podendo inclusive selecionar as duas opções.  
**Tipos de Despesas**  
Criado o cadastro de Tipos de Despesas, que permite aos usuários criarem os tipos de despesas a serem utilizados na empresa. Um exemplo de tipo de despesa seria o IPTU.  
**Cadastro de Despesas**  
Criado o cadastro de Tipos de Despesas. Este cadastro permite cadastrar os tipos de despesas necessárias, podendo assim agrupar despesas que possuam um mesmo objetivo e características. Para maiores informações clique aqui.  
**Cadastro de Definição de Despesas**  
Criado o cadastro de **Definição de Despesas** para o usuário informar uma pré-definição dos dados que as despesas terão em comum quando as despesas forem geradas em lote. Para maiores informações clique aqui.  
**Processo de Geração de Despesa**  
No cadastro de **Definição de Despesas** foi disponibilizado o Processo de Geração de Despesa, para realizar de despesas destinadas a um ou mais imóveis.  
**Cadastro de Parâmetros de Geração de Movimento**  
No Cadastro de Parâmetros para Geração de Movimento, no campo Tipo de Geração foi inserida a opção de **Despesa de Aluguel**, para se adequar às novas funcionalidades envolvendo Despesas para o Módulo de Aluguéis.  
**Histórico de Inscrição Municipal**  
Foi disponibilizado no cadastro de Inscrição Municipal (Anexo de Imóveis) um histórico que possibilita visualizar as modificações realizadas. Esta melhoria se faz importante, para o gerenciamento das despesas.  
**Processo de Cancelar lançamentos financeiros de Reembolso**  
No **Cadastro de Despesas** e para o seu anexo de **Parcelas de Reembolso**, foi criado o Processo de **Cancelar lançamento financeiro** que excluí os lançamentos de reembolso de uma determinada despesa.  
**Processo de Cancelar integração das despesas**  
No Cadastro de Despesas foi criado o Processo de Cancelar integração de despesas, que tem o papel de excluir o(s) movimento(s) gerado no TOTVS Gestão de Estoque, Compras e Faturamento.  
**Observação:** Maiores informações sobre as funcionalidades relacionadas à despesa, estão disponíveis também nas páginas de suas respectivas funcionalidades do Help.
