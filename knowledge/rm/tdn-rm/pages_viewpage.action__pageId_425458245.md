**Linha** **RM x Protheus SigaMNT - Calendário de projetos Protheus**

---

**Cadastrar de Calendário**  
    
 Devido a integração Linha RM x Protheus SigaMNT os projetos podem ser utilizados em processos do Protheus SigaMNT , através dos cadastros efetuados no Linha RM.   
    
 Devido a algumas referencias obrigatórias dos projetos no Protheus SigaMNT houve a necessidade da criação de um calendário padrão para cada uma das empresas cadastradas. Antes do sincronismo de dados de Projeto, deve-se cadastrar um calendário padrão no Protheus SigaMNT.

1. Acessar o Protheus , Módulo SigaMNT
2. Acessar : Acessar : Base Atualizações / Cadastros Básicos / Calendários.
3. Incluir um novo calendário
4. Informar o código 001 ao código do  calendário para que ele seja referenciado
5. selecionar os horarios por dia da semana  do calendário.

**Observação :** A seleção de horas é replicada aos outros dias da semana . O projeto utiliza somente uma referência a este calendário, não importando os horários marcados.
