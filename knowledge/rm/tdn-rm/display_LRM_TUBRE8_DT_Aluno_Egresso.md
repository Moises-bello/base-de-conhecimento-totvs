# ALUNOS EGRESSOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Gestão de alunos egressos* |
| **Situação/Requisito:** | *O contexto para alunos egressos só era retornado, quando a situação de matrícula informada na matrícula no período letivo estava parametrizada para ser "Visível para seleção de contexto educacional no portal" e "Indica conclusão do curso".* |
| **Solução/Implementação:** | *O contexto do aluno egresso será carregado a partir da situação de matrícula do aluno no curso/habilitação. Para que o registro seja retornado, a situação de matrícula deve estar parametrizada para ser "Visível para seleção de contexto educacional no portal" e "Indica conclusão do curso" .* |
