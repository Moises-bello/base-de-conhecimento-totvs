Importante

A partir da versão **12.1.32.183** e **12.1.33.111** não será possível realizar a alteração de campos que sejam **critérios de unicidade de pessoa** (*CPF, Nome, Estado Natal, Naturalidade e Data de nascimento*).   
  
Portanto, é de suma importância se atentar no preenchimento das informações de unicidade, pois **não** será possível alterá-las posteriormente pelo portal.   
  
A regra se aplica ao candidato, pai(s), mãe(s), responsável financeiro, responsável acadêmico, responsável pela inscrição e também no processo de recuperação de dados do candidato.

Ao realizar login na central do candidato é possível acessar a opção "Alterar dados pessoais" no canto inferior esquerdo como demonstrado na imagem abaixo.

Acessando essa opção é possível verificar os dados pessoais informados no momento da inscrição e realizar a **atualização dos campos que não forem critérios de unicidade de pessoa** (*CPF, Nome, Estado Natal, Naturalidade e Data de nascimento*).

* A alteração dos dados pessoais somente poderá ser executada se o acesso a central for realizado utilizando "Senha";
* **A partir da versão 12.1.2205 -** Caso o Processo Seletivo não esteja parametrizado para "Utilizar senha para login do portal de inscrições" **a opção Alterar dados pessoais NÃO irá aparecer na central do candidato;**

Ao finalizar a alteração, clique em **Salvar**para que se aplique as modificações.

O campo e-mail somente será possível ser alterado se estiver parametrizado para alterar na parametrização do processo seletivo e o campo não ser uma forma de identificação para os candidatos acessarem o portal de inscrições. Estas parametrizações estão disponíveis .
