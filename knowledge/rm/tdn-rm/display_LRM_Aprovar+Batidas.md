**Aprovar Batidas**

Utilize este menu para aprovar todas as batidas que não foram aprovadas pelo chefe ou supervisor via RM Portal. Neste módulo serão listadas todas as batidas que estão com status "T" (trânsito) que não fazem parte do cálculo da movimentação do funcionário.

Obs.: As batidas apresentadas nesta tela irão corresponder a um período de datas considerando **todos os períodos** ativos de **todas as coligadas** das quais o usuário é chefe. Além disso, caso o parâmetro **Trabalhar com base no próximo período mensal** esteja **marcado** na coligada do chefe, o intervalo de datas considerará também períodos futuros das coligadas, mesmo que uma coligada que não seja a do chefe esteja com este parâmetro desmarcado.

Exemplo: Chefe da coligada 1, que tem subordinados na coligada 6.

Coligada 1 = Período ativo (01/02/20 - 28/02/20) Período futuro (01/03/20 - 31/03/20)  
Coligada 6 = Período ativo (01/01/20 - 31/01/20) Período futuro (01/02/20 - 28/02/20)

Datas a serem consideradas para mostrar as batidas com o parâmetro **marcado**: 01/01/20 - 31/03/20  
Datas a serem consideradas para mostrar as batidas com o parâmetro **desmarcado**: 01/01/20 - 28/02/20

Pelo menu "Aprovar Batidas" é possível controlar:

Para abrir a janela de "Identificação" é necessário editar uma batida em trânsito apresentada na visão de "Aprovar Batidas".

Na pasta de identificação é possível alterar:

**Batida -** O campo batida é informado a hora que o funcionário entrou com a batida que ainda não foi aprovada.

**Natureza -** A natureza identifica se a batida é uma entrada ou uma saída.

**Justificativa -** Conforme portaria 1.510/2009 do MTE, o campo justificativa é de preenchimento obrigatório para manutenção das batidas.
