![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26092434608791) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como se adequar ao leiaute S-1.3 eSocial e para quais releases está disponível as atualizações?  
  
**Ambiente**TOTVS RH - (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**A adequação dos produtos para atender ao **Leiaute S-1.3** do eSocial já está disponível para o **Protheus**: Releases com GE (Garantia Estendida), 12.1.2310 e superiores  
Para preparar o seu ambiente é necessário que esteja com os pacotes Expedição Continua ( RH e TAF) liberados a partir de **18/11/2024** aplicados, inclusive as **atualizações de dicionários.** Também é necessário que os parâmetros **MV\_VLESOC** e **MV\_TAFVLES** estejam com a versão **S\_01\_03\_00.****Expedição Continua eSocial RH e TAF**  
1. [Pacote e Dicionário Correções Expedição Continua RH](https://suporte.totvs.com/portal/p/10098/download#all/all/all/search/RH_EXPEDICAO)  
2. [Pacote e Dicionário Correções Expedição Continua TAF](https://suporte.totvs.com/portal/p/10098/download#all/all/all/search/TAF_EXPEDICAO)  
3. [Pacote e Dicionário Correções Expedição Continua MDT](https://suporte.totvs.com/portal/p/10098/download#all/all/all/search/MDT_EXPEDICAO)  
  
Outro ponto fundamental, é seguir as orientações da documentação abaixo para garantir que o TAF esteja adequado para realizar as transmissões utilizando o leiaute S-1.3  
[RH - Linha Protheus - TAF - eSocial - Atualização - Como atualizar a versão do layout no TAF E-social?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/18585564590999-RH-Linha-Protheus-TAF-eSocial-Atualiza%C3%A7%C3%A3o-Como-atualizar-a-vers%C3%A3o-do-layout-no-TAF-E-social&nbsp;)  
  
**Importante**: **O parâmetro em ambiente de produção só deve ser alterado após 02/12/2024, pois é o início do período de convivência do leiaute S-1.3.**Quer saber quais são as alterações realizadas no Protheus para essa adequação? Na *link* a seguir é possível verificar todos os itens e respectivos boletins técnicos:**[Leiaute S-1.3: Principais Alterações](https://tdn.totvs.com/pages/releaseview.action?pageId=887739380)**
