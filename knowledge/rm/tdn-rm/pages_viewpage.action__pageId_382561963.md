# Rematrícula com débito - Acordo ainda não efetivado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matrícula Online |
| **Situação/Requisito:** | Ao realizar um acordo de um lançamento vencido o sistema estava permitindo que o aluno realizasse a matrícula no portal mesmo estando em debito com a instituição e com o parâmetro para bloquear matricula para inadimplentes. |
| **Solução/Implementação:** | Foi realizado um ajuste na regra de matrícula para considerar todos os lançamentos, inclusive para lançamentos existentes sem a confirmação do acordo. |
