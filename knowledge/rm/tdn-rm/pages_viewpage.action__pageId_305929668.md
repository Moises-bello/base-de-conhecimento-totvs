# CÁLCULO DO CAMPO SALDO ACUMULADO NO RELATÓRIO DE EXTRATO DE CLIENTE/FORNECEDOR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Relatório de extrato de cliente/fornecedor. |
| **Situação/Requisito:** | A coluna **Saldo Acumulado** por cliente/fornecedor exibia valores incorretos considerando o somatório de todos os valores exibidos (inclusão e baixa) e não somente do cliente/fornecedor corrente. |
| **Solução/Implementação:** | Ajuste no relatório *Extrato Cliente Fornecedor somente com movimentação ou saldo*  para que totalize corretamente o valor para a coluna Saldo Acumulado considerando somente os valores do registro corrente de cliente/fornecedor. |
| **Conversores e Parâmetros:** | Informe os conversores/parâmetros. |
| **Tickets relacionados:** | 921372. |
| **Requisito:** | FINANCEIRO01-1105. |
