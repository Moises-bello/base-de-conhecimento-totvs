# Filtro por Tipo de Atendimento na tela de Faturamento para Convênios

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Faturamento para Convênios | |
| **Banco(s) de Dados:** | SQL Server® e Oracle® |
| **Tabelas Utilizadas:** | SZATENDIMENTO |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Adicionado na tela de Faturamento para convênios a opção de **Tipo de Atendimento**, para o usuário poder filtrar pelo mesmo Tipo de Atendimento excluído do Registro do Atendimento do paciente.

## Procedimento para Utilização

**Exemplo:**

       1.            No TOTVS Gestão Hospitalar (RM Saúde), acesse pela nova MDI o Faturamento / Faturamento para Convênios.

Crie ou acesse uma remessa em aberto

       2.            Na tela de seleção de filtros foi adicionado o filtro Tipo de Atendimento que é opcional.

       3.            Ao selecionar e clicar em Avançar o sistema filtrará também pelo Tipo de Atendimento dos pacientes cadastrados.
