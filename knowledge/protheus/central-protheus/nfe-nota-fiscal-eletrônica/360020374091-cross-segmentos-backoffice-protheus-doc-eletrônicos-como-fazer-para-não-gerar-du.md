**Dúvida**

Como fazer para não gerar duplicata no XML (fatura ou cobrança) ?

**Ambiente**

Cross Segmentos - Backoffice Protheus - Doc. Eletrônicos - NFe - a partir da versão 12.1.25

Cross Segmentos - TSS - a partir da versão 12

**Solução**

* Para a 4.00 foi criado um parâmetro para que não seja levado duplicata no XML, mesmo que gerado no Protheus.

**Parâmetro:**

Para não gerar a duplicata no XML configurar o  parâmetro  **MV\_GRUPCOB = .F.**
