# MÚLTIPLOS VÍNCULOS PARA SALÁRIO FAMILIA ESTÁ CONSIDERANDO COLIGADA INATIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Salário Família* |
| **Situação/Requisito:** | *Está sendo exibida mensagem de múltiplos vínculos para salário familia, considerando chapas da mesma pessoa, existentes em Coligadas inativas.*  *A consistência de múltiplos vínculos só deve considerar funcionários ativos, cadastrados em Coligadas ativas.* |
| **Solução/Implementação:** | *Ajuste na consistência de múltiplos vínculos para salário família, para considerar somente funcionários ativos, cadastrados em Coligadas ativas, ao exibir mensagem de obrigatoriedade da Chapa Centralizadora.* |
| **Chamados   relacionados:** | *TUBQLP, TUCNW7* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
