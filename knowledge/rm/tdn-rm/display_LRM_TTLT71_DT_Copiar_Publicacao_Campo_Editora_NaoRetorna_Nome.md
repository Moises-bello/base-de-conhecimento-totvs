# COPIAR PUBLICAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Copiar publicação* |
| **Situação/Requisito:** | *No TOTVS Gestão Bibliotecária foi solicitado que no processo de copiar publicações, o campo editora, quando utilizado a busca diretamente no campo carregasse mais informações do que somente o código da editora.* |
| **Solução/Implementação:** | *Foi feito um ajuste no campo para que ao utilizar a busca direta no campo, ao carregar os resultados, além do código, será carregado o nome e a remissiva da editora.* |
