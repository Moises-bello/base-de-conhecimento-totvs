**Dúvida**Automação Fiscal - ATUALIZAÇÃO - Como entrar em contato com o suporte do TAF?

**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial

**Solução em vídeo:**

**Solução (leitura):**

Para entrar em contato com a equipe do TAF E-social via chat, acesse a [Central de Relacionamento TOTVS](https://totvscst.zendesk.com/hc/pt-br/#home) e clique no ícone "iniciar chat".

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18029122941335)

Após clicar no ícone de início do chat,  será exibido um formulário para informar qual a área que deseja entrar em contato.

Preencha de acordo com a tabela abaixo:

|  |  |
| --- | --- |
| **Área** | Suporte Técnico |
| **País** | Selecione seu País |
| **Macrossegmento** | Cross Segmentos |
| **Produto** | TOTVS Backoffice (Selecionar seu produto) |
| **Módulo** | Automação Fiscal |
| **Agrupador de Rotina** | Escolher a dúvida ou Rotina com erro |

![Abrir chat.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/18029684600471)

Para abrir a solicitação em Ticket, basta acessar as opções "Meu espaço" e "Minhas solicitações", depois clique em "Abrir uma nova solicitação".

![GIF abrir ticket.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/18029722279959)

Para abrir uma solicitação via telefone basta ligar no número 4003-0015 e selecionar o caminho conforme seu produto.

|  |  |
| --- | --- |
| **TAF E-social Protheus** | 2-2-2-3-6-2 |
| **TAF E-social RM** | 2-2-2-3-6-3 |
| **TAF E-social Datasul** | 2-2-2-3-6-4 |

Caso entre em contato via ticket ou chat, informe sua dúvida ou erro junto com a [tela de diagnóstico](https://centraldeatendimento.totvs.com/hc/pt-br/articles/17988545143063/preview/eyJhbGciOiJIUzI1NiJ9.eyJpZCI6MTc5ODg1NDUxNDMwNjMsInJldmlzaW9uX2lkIjoiMDFIRE5XN0NNMlkxQVlDMzRKSFI4SFRTNFEiLCJleHAiOjE2OTgzMjM2Njl9.H9Y92-Z8OTxcN66OmrPYTJwxswmerfbnYuRh0OzY21g) para adiantar o atendimento.
