# NOME DO REQUISITO

| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Construção e Projetos.* |
| **Módulo:** | *Gestão Planejamento e Controle da Produção* |
| **Função:** | *Recalculo de custos .NET* |
| **Situação/Requisito:** | *Ao realizar o recalculo de custos .NET sem ter definido o tipo de movimento relacionado a "Entrada", "Devolução de materiais" ou "Entrada de subproduto" faz com que o custo dos componentes calculados seja zero.* |
| **Solução/Implementação:** | *Melhoria relacionada ao recalculo de custos para mesmo que um dos movimentos entre *"Entrada", "Devolução de materiais" ou "Entrada de subproduto" não tenha sido definido o calculo do custo do componente seja realizado corretamente.**  **Também pode ser solucionando simplesmente definindo os tipo de movimento relacionando a **"Entrada", "Devolução de materiais" e "Entrada de subproduto".**** |
