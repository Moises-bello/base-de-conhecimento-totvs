# PROPOSTA DE PROJETO DE PESQUISA - AVALIADORES

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cadastro de proposta de projeto de pesquisa |
| **Situação/Requisito:** | Na etapa de distribuição da proposta para avaliação, não era permitido a seleção de um avaliador que é coordenador de uma área de conhecimento. |
| **Solução/Implementação:** | O filtro que restringia a seleção de coordenadores de áreas e conhecimento foi removido por entendimento que qualquer pessoa, que seja avaliadora, ativa e não esteja ligada diretamente ao projeto, pode realizar a avaliação.  Com isso, excluem-se as pessoas que não sejam avaliadoras ou não estejam ativas, o proponente do projeto e a sua equipe. |
