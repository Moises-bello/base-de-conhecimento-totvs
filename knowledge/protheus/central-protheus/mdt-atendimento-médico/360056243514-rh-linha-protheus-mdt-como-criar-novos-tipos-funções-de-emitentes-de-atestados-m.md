Dúvida**Como criar novos tipos (funções) de emitentes de atestados médicos no modulo medicina e segurança do trabalho (SIGAMDT)?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho  - Todas as versões  
  
**Solução**Para criar novos tipos de emitentes de atestado deverá ser realizado os passos abaixo:  
  
1. Acesse o modulo Configurador (SIGACFG) no caminho: Base de Dados > Base de Dados > Tabelas Genéricas e busque pela tabela genérica **P1 - Funções do SESMT**.  
  
![cadstro_novo_emitente_2.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/360097764853)  
  
2. Acesse como alterar e insira a nova opção:  
  
![cadastro_novo_emitente_1.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/360095459134)  
  
3. Após esse processo, para que o emitente fique disponível no modulo Medicina e Segurança do Trabalho (**SIGAMDT**), efetue as configurações do artigo: **[MP - MDT - Seleção de quais emitentes serão liberados para a geração de atestados médicos](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360044452334)**
