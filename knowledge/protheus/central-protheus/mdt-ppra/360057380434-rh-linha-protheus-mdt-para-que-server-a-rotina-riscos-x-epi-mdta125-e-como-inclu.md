**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25627838191383)** Tempo aproximado para leitura: **00:02:00 min****Dúvida**Para que server a rotina **Riscos x EPI** (MDTA125) e como incluir?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Essa rotina é responsável por relacionar os **EPI's** (equipamento de proteção individual) necessários ao funcionário exposto a determinado **risco**. Vale lembrar que o risco é identificado por centro de custo, função, tarefa e departamento.

Para saber como incluir um **Risco** ou um **EPI** consulte:   
[**MP - MDT - Para que server a rotina Riscos (MDTA180) e como incluir**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360056319213)  
**[MP - MDT - Como cadastrar um Equipamento de Proteção Individual (EPI)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360048704353-MP-MDT-Como-cadastrar-um-Equipamento-de-Prote%C3%A7%C3%A3o-Individual-EPI-?source=search)**  
  
Para cadastrar, acesse no modulo **SIGAMDT (35)** o caminho: atualizações - PPRA - **Riscos x EPI** (MDTA125). Escolha o risco que irá relacionar os EPI's:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360097275674)  
  
Na próxima tela será possível escolher os EPI's, informar se a utilização é **obrigatória** ou **alternativa** e, se definido como alternativo, o campo **Família EPI** fica disponível para informar de qual família o EPI faz parte.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360097275754)  
  
**Observação**  
O vinculo também pode ser feito no caminho caminho: atualizações - EPI - **EPI x Riscos** (MDTA130). Por este local, primeiro é escolhido o EPI e depois é informado ao qual risco ele pertence.
