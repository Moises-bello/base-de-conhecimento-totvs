# Repasse de Bolsa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cadastro e execução do Repasse de Bolsa |
| **Situação/Requisito:** | Após a realização do Repasse, o sistema não está bloqueando os registros dos repasses cadastrados dentro da bolsa de crédito no contrato do aluno. |
| **Solução/Implementação:** | Melhoria no processo do repasse de bolsa para que os campos do cadastro do repasse não fiquem habilitados após a execução do repasse quando o total do repasse for igual ao valor esperado, pois antes o sistema estava deixando os campos do cadastro do repasse de bolsa habilitados para um repasse já processado. |
