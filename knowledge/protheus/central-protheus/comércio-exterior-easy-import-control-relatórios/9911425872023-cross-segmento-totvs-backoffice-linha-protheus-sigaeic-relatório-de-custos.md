Ao imprimir o relatório de custos é exibida a mensagem:

"Não foi possível gerar todos os relatórios, pois o(s) seguinte(s) processo(s) esta(ão) encerrado(s)"

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9911118671127)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**O relatório de custos não lista os processo que possuem a data de encerramento **(W6\_DT\_ENCE)** preenchida. Trata-se do comportamento padrão do relatório.
