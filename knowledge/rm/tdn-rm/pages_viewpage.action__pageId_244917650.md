|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |

| **Função:** | Emissão de Boleto no Portal do Aluno |
| **Situação/Requisito:** | Ao emitir o boleto pelo portal no educacional utilizando o navegador Chrome e clicar no ícone de download não é apresentada a opção para salvar em PDF, esta situação ocorre somente no navegar Chrome. |
| **Solução/Implementação:** | Quando o usuário estiver emitindo o boleto através do navegador Chrome será mostrada a informação abaixo orientando ao usuário.  Mensagem:  No navegador Chrome para realizar o download do boleto em PFD é necessário clicar no ícone de impressão no relatório apresentado acima e depois selecionar como destino a opção “Salvar como PDF”. |
