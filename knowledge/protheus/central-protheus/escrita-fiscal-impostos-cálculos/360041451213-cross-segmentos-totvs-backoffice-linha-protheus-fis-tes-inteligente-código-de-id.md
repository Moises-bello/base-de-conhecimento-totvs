**Dúvida**Ao incluir o cadastro de TES inteligente é apresentado o help abaixo, como solucionar?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360054337274/mceclip0.png)  
   
 **Ambiente**  
Microsiga Protheus – Livros Fiscais – A partir da versão 11.80  
  
**Solução**Verificar se há a tabela RV corretamente na SX5 , que é o contador para alimentar o campo FM\_ID.

Caso não haja a tabela RV na SX5 poderá criar via configurador.
