| --- | --- |

| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Turma/Disciplina Gerencial/Gerenciada - Replicação de Fórmula* |

| **Solução/Implementação:** | *Ajuste no cadastrado das turmas/disciplinas gerenciais para que seja replicado o campo Fórmula para cálculo de médias / aprovação para as gerenciadas.* |
