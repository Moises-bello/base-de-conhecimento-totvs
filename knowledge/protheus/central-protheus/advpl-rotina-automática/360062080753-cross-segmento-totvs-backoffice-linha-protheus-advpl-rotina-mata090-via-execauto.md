Dúvida**A rotina MATA090 possui ExecAuto?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus – ADVPL – Todas versões  
  
**Solução**A rotina MATA090 não tem rotina de ExecAuto, mas tem a funcionalidade de projeção onde é possível pré-cadastrar os valores.   
Outra funcionalidade é a opção de usar uma API (Rest) de comunicação para fazer os processos de consulta, inclusão, alteração e exclusão.
