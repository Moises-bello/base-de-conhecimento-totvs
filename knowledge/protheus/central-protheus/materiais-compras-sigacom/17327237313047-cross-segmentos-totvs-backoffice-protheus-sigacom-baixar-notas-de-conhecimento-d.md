Como baixar Notas de conhecimento de frete(CTE) ?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS COMPRAS - Versã0 12  
  
**Solução**

Possuímos o produto padrão do Protheus que seria a rotina **Importador XML** (COMXCOL), onde poderá baixar os XMLs da SEFAZ e incluir manualmente em uma pasta para integração com o módulo Compras.

Segue documentação para configuração :

[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Importador XML](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360026658994-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Importador-XML?source=search)

Regra Integração para casos de CT-e:

[Totvs Backoffice Protheus - SIGACOM - Inclusão de CTE via Importador XML](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4427846804503-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Inclus%C3%A3o-de-CTE-via-Importador-XML?source=search)

Há também o**TOTVS Transmite**, mas este é necessário assinar um contrato a parte para ter acesso ao portal onde serão visualizadas suas notas que são baixadas automaticamente da **SEFAZ** para o portal e por fim integradas ao compras caso haja necessidade (para este produto **é** possível integrar documentos do tipo **NFS**). Para este caso será necessário que contate seu ESN (gerente de contas).
