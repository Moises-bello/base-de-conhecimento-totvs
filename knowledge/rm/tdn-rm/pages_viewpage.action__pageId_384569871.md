| --- | --- |

| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Foto padrão utilizada pelo eduCONNECT |
| **Situação/Requisito:** | Quando o usuário do aluno e/ou responsável não possuir foto no TOTVS Educacional, o eduCONNECT utiliza uma foto do ícone do eduCONNECT. |
| **Solução/Implementação:** | Foi realizado uma otimização no TOTVS eduCONNECT, de maneira a utilizar a foto padrão do TOTVS Educa Mobile quando o usuário não possuir foto associada. |
