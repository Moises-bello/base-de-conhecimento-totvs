|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração automática de usuário (aluno, professor, funcionário de empresa)* |
| **Situação/Requisito:** | Na geração automática de usuário, alguns usuários não estavam gravando o perfil do sistema Educacional. Somente ocorria se logar em um contexto de outro sistema, por exemplo Fluxus, e em seguida gerar automaticamente um usuário aluno, professor ou funcionário de empresa. |
| **Solução/Implementação:** | Otimizado processo de geração automática de usuário, para sempre criar o perfil do usuário do aluno/professor/funcionário empresa com sistema Educacional (tabela GUSRPERFIL campo CODSISTEMA igual a “S”) e não o contexto logado. |
