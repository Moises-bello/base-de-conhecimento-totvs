**Dúvida**Qual o critério utilizado pelo sistema para aplicar as alíquotas de ICMS próprio?  
   
 **Ambiente**Protheus - Todas as versões

**Solução**

A alíquota do ICMS Próprio poderá ser definida conforme o estado de origem e destino da mercadoria, bem como os cadastros utilizados para aquele(s) determinado(s) produto(s).

Verifique no fluxograma abaixo, o critério que o sistema utiliza para aplicar as alíquotas de ICMS.
