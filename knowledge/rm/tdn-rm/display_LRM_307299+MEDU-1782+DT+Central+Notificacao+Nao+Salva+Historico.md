# CENTRAL DE NOTIFICAÇÕES

| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional / TOTVS Gestão Bibliotecária / TOTVS Processo Seletivo / TOTVS Avaliação e Pesquisa |
| **Função:** | Central de notificações |
| **Situação/Requisito:** | Ao enviar e-mails o histórico de envio não é salvo, mesmo quando o parâmetro para salvar o histórico está configurado nas definições globais de envio de e-mail. |
| **Solução/Implementação:** | Foi identificado que quando a nova central de notificação foi feita para os produtos (Educacional, Processo Seletivo, Avaliação e Pesquisa e Gestão Bibliotecária), não foi incorporada a função de salvar o histórico, sendo assim, esta foi implementada para salvar o histórico na tabela GMAILSEND conforme era feito antes, respeitando o parâmetro global de histórico de e-mails. |
