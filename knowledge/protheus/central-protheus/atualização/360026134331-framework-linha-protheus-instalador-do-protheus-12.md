**Dúvida**  
Como faço para baixar o instalador do Protheus 12?  
  
**Ambiente**  
Protheus - AppServer - Versão 12  
  
**Solução**  
Segue abaixo caminho para baixar o instalador do Protheus 12:  
  
1. Acesse o site <https://suporte.totvs.com/download>  
2. Linha Protheus  
3. TOTVSTEC-FRAMEWORK  
4. INSTALADORES  
5. Baixar o arquivo "INSTALADOR PROTHEUS VERSÃO 12.1.2510 COMPLETO"  
  
Obs.: se não estiverem aparecendo as versões, em **Filtros de pacotes** selecione **Todos pacotes disponíveis**.  
  
Após o download, siga os passos do Guia de Instalação para efetuar a instalação do Protheus 12:  
<http://tdn.totvs.com/pages/viewpage.action?pageId=235589249>
