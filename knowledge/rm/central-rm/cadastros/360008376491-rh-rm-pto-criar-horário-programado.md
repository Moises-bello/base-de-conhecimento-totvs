Dúvida**Como configurar horário Programado?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - Todas as versões  
  
**Solução**Esta funcionalidade deve ser utilizada, para determinar uma data específica para o funcionário utilizar um horário alternativo.Para realizar o cadastro de horários no **Automação de Ponto**, siga os passos abaixo:

1. Acesse o módulo de Automação de Ponto e acesse o menu **Cadastros | Funcionários**, e selecione a chapa do funcionário.   
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29071704522519)
2. Acesse a opção **Anexos | Horário Planejado | Horários Programados  
   ![horario_programado.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29071704524951)**
3. Na tela de anexo aberta clique no botão Incluir.  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29071683212951)
4. Selecione o código do horário desejado, o índice para ser vinculado, juntamente com a data de mudança.   
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29071704529687)
5. Clique no botão **Salvar** para armazenar as informações.

**Saiba mais**  
Para maiores informações sobre horários programados acesse o documento [Horário Programado](https://tdn.totvs.com/pages/viewpage.action?pageId=452719002).
