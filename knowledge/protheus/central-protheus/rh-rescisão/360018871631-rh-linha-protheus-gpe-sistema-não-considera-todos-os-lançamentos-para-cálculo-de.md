**Ocorrência**No módulo Gestão de Pessoal, o sistema não considera todos os lançamentos para cálculo de médias de 13º de rescisão complementar de comissionado.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12  
  
**Causa**Ao calcular a segunda complementar do funcionário, as verbas referentes a primeira complementar não entram na composição da média.  
  
**Solução**Efetuado ajuste para considerar todas as verbas lançadas entre a rescisão e a complementar para cálculo de médias.  
  
Para solucionar essa ocorrência, realize os seguintes passos:  
1. Realize o *backup* prévio;  
2. Aplique o pacote de atualização;  
3. Refaça o teste.

Link para acesso de pacotes de atualizações:
