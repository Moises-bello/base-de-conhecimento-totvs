**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Processos Trabalhistas - Todas as versões

**Pré-requisito**

Para ter acesso, ás novas rotinas do TAF, referente aos eventos de **Processos Trabalhistas,**é necessário:

1. Que o sistema esteja atualizado, com a última Expedição Contínua:

[Automação Fiscal - ATUALIZAÇÃO - Como atualizar o TAF E-social (Expedição Contínua)?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/18972648169239)

2. Que os menus estejam atualizados:

**Dicionário no Banco de Dados**, seguir a documentação abaixo:

[MP - FRAME - Atualização de menus que estão no Banco de Dados](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360026178872)

**Dicionário na pasta System**, seguir orientação abaixo:

O novo arquivo, com o menu atualizado, está disponível na Expedição Contínua (realize o download);

1. Copie o arquivo **sigataf.xnu** localizado dentro da pasta "**Menu**" da Expedição Contínua";

2. Cole dentro da pasta **system** do Protheus, peça para substituir os arquivos.

**Como acessar os novos menus no TAF:**

1**.** Acesse o módulo 84, Automação Fiscal - TAF;

2. No menu principal, selecione as opções:  "Atualizações" > "Eventos Esocial" > "Não-Periódicos"

3. O TAF disponibiliza acesso á três diferentes eventos de Processos Trabalhistas, **S-2500, S-2501 e S-3500** para o Esocial.

4. Os Links relacionados abaixo explicam como acessar cada um dos eventos pelo TAF:

[Automação Fiscal - Não Periódicos - S-2500 - Como acessar a Rotina de Processo Trabalhista](https://centraldeatendimento.totvs.com/hc/pt-br/articles/11300882852375)

[Automação Fiscal - Não Periódicos - S-2501 - Como acessar a rotina Informações de Tributos Decorrentes de Processo Trabalhista](https://centraldeatendimento.totvs.com/hc/pt-br/articles/11303052449175)

[Automação Fiscal - Não Periódicos - S-3500 - Como acessar a rotina Exclusão de Eventos - Processo Trabalhista](https://centraldeatendimento.totvs.com/hc/pt-br/articles/11303612578455)
