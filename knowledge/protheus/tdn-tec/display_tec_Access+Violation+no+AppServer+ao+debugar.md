Access Violation no AppServer ao debugar

|  |  |
| --- | --- |
| Situação | Access Violation no AppServer ao debugar |
| Ocorrência | Ao debugar um programa que tenha uma variável que o conteúdo seja um array vazio ocorria Access Violation |
| Correção | Proteção ao debugar variáveis com conteúdo arrays vazios |
| Informações adicionais | * Referente ao chamado: Não há chamado associado * Referente à ocorrência: TTEC-670 * Disponível em builds superiores a 7.00.131227A - 1.0.3 |
