# Validador E-Social

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | E-Social |
| **Situação/Requisito:** | Ao realizar a geração da validação da base de dados, e verificar a lista de funcionários com erros ou avisos, quando existiam funcionários diferentes, ao clicar em algum o sistema abria sempre o cadastro do primeiro funcionário para edição. |
| **Solução/Implementação:** | Foi ajustado o sistema para mudar a posição do bindingsource quando for selecionado outro funcionário na listagem e ao abrir o cadastro que seja aberto do funcionário correto. |
