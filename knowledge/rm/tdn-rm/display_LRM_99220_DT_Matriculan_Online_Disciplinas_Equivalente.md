# Matricula Online

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matricula Online - Disciplinas Equivalentes |
| **Situação/Requisito:** | Ao realizar a matricula online caso eu selecione somente uma disciplina e finalize, ao voltar novamente para a tela de matrícula, o portal não permite a matrícula na outra disciplina que é equivalente. |
| **Solução/Implementação:** | Realizamos um ajuste, o procedimento a ser adotado é de que o sistema não valide e não bloqueie a matrícula do aluno em disciplinas equivalentes, visto que a disciplinas pode ser considerada como Extra ou que a mesma seja equivalente a várias outras disciplinas e não podemos proceder com o bloqueio da matrícula. |
