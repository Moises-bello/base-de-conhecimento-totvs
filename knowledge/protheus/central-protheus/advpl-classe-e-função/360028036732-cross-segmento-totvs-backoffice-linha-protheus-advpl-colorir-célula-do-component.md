![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:01:00 min****Dúvida**Existe uma forma de colorir somente uma célula do componente **MsNewGetDados**?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Não, é possível define a cor de fundo das colunas e linhas através método TCBrowse:SetBlkBackColor
