# Matricula online

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matricula online |
| **Situação/Requisito:** | A turma possui 100 vagas e 2 subturmas, com 50 vagas em cada, quando o aluno realiza a matricula no portal, a clicar sobre a turma para verificar as informações não é apresentado a quantidade de vagas disponíveis por subturma. |
| **Solução/Implementação:** | Melhoria na visualização das informações da turma durante a realização da matricula online para que seja apresentada quantidade de vagas disponíveis por subturma. |
