# CONTRATO - CONDIÇÃO DE PAGAMENTO COM FÓRMULA 1ª PARCELA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Gerar Parcelas Condição de Pagamento. |
| **Situação/Requisito:** | Inconsistência na geração de lançamentos financeiros a partir do Contrato, onde a condição de pagamento utiliza fórmula no cálculo da primeira parcela. |
| **Solução/Implementação:** | Ajuste na rotina que Gera Parcelas da Condição de Pagamento a partir do Contrato para que considere a fórmula da 1ª parcela informada na condição de pagamento. |
| **Tickets relacionados:** | 2016519. |
| **Requisito:** | Contrato. |
