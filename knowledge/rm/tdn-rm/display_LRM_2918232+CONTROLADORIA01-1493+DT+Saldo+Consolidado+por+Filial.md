# Saldo Consolidado por Filial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cálculo do Saldo Consolidado |
| **Situação/Requisito:** | Cliente solicita melhoria no processo do Calculo do Saldo Consolidado no Bloco K (ECD), pois, de acordo com a empresa o saldo é apresentado de uma forma geral por coligada, porém a mesma trabalha apenas com uma filial Controladora (Filial 1) na coligada e o restante das filiais são gerados lançamentos gerenciais, com isso o saldo do bloco K considera todas as filiais da coligada onde o saldo apresentado não coincide com o saldo real das contas contábeis vinculadas. |
| **Solução/Implementação:** | Melhoria no cálculo do Saldo Consolidado do Bloco K para que sejá possível filtrar as filiais que serão consideradas na execução do cálculo.  Atenção: Lembramos que é de responsabilidade da empresa a utilização do filtro de filial. |
