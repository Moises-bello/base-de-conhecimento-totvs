# LANÇAMENTO FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Lançamento financeiro sem centro de custo da turma.* |
| **Situação/Requisito:** | *A nomenclatura do parâmetro para a busca do centro de custo da turma está errada. O parâmetro deve ser "Da Turma" e não "Da Turma/Disciplina",*  *uma vez que o sistema utiliza o centro de custo da turma cadastrada na matrícula do aluno e não da turma/disciplina.* |
| **Solução/Implementação:** | *Alteração da nomenclatura do parâmetro para "Da Turma".* |
