![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16301769734807) Tempo aproximado para leitura: **00:02:00min** **Dúvida**Como realizar o cadastro de instrutores?  
  
**Ambiente**TOTVS RH (Linha Protheus) -Treinamento - Todas as versões  
  
**Solução**Para realizar o cadastro de instrutores, acesse o Módulo Treinamento (SIGATRM), no seguinte caminho: Atualizações - Cadastros - Instrutores - Incluir.  
Este cadastro pode ser relacionado com uma matrícula, caso o instrutor seja um funcionário da empresa, lembrando que se este cenário for considerado o sistema irá respeitar sempre a filial logada para apresentar os funcionários alocados aquela filial.  
Ou o instrutor pode ser um terceiro sem vínculo com a empresa, neste caso não deve ser informado matricula.
