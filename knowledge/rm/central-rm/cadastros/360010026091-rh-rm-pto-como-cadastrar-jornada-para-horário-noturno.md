Dúvida**Como cadastrar horário para intervalo noturno?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 11.80  
  
**Solução**Para realizar o cadastro de horários noturno no **Automação de Ponto**, siga os passos abaixo.:

1. Acesse no cadastro de horário, a opção criar nova jornada.

Caso tenha dúvidas no passo-a- passo para localizar o menu de novo horário acesse a documentação:[Como cadastrar horário](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360000213808-RM-PTO-Como-cadastrar-hor%C3%A1rios).

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008255532)

2. Avance para a tela tipo de jornada, defina a opção trabalho.   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008296791)

3. Ao avançar você deverá definir os intervalos das batidas conforme datas, no exemplo a seguir note que a entrada foi defina no dia 01/07 e a saída no dia seguinte 02/07.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008296911)

4.  Ainda nesta tela você pode definir o intervalo 2, clicando na opção, novo.   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008297231)

5. Preencher os intervalos conforme a jornada desejada.   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008297631)

6. Após configuração do intervalo 2 avance para a tela de visualização da jornada, nesta opção o índice fim será considerado como índice início + 1. O índice fim sugerido deve ser mantido caso seja cadastrado outra jornada para o índice.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008297691)

7. Ao concluir o cadastro, a jornada será apresentada assim.   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360008260332)

8**. Atenção,** o ID jornada não poderá ficar com valor negativo, desta forma você deverá cadastrar uma nova jornada de trabalho/descanso para o índice 2 ou modificar o índice fim para 1.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360009289531)

9.Após a modificação o ID negativo deixará de ser apresentado.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360009254892)
