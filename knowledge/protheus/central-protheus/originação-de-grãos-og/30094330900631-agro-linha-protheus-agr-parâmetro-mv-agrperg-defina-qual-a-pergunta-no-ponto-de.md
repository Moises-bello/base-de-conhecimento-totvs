![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30094330878871) Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Para que serve o **Parâmetro MV\_AGRPERG**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O Parâmetro MV\_AGRPERG - Defina qual a pergunta no ponto de controle que identifica que o processo de separação de lotes está finalizado.

|  |  |
| --- | --- |
| **Linha de Produto:** | Microsiga Protheus |
| **Segmento:** | Agroindústria |
| **Módulo:** | SIGAAGR |
| **Função:** | O parâmetro MV\_AGRPERG é do tipo carcater.   Este parâmetro MV\_AGRPERG é usado no processo de expedição modelo 2 do UBS nas fontes do AGRO. É do tipo caractere e deve ser informado neste parâmetro o código da Pergunta(GVG\_CDPERG), a qual identifica que o processo de separação de lotes está finalizado. |
| **Parâmetro(s):** | MV\_AGRPERG |
| **País:** | Todos. |
| **Banco de Dados:** | Todos Homologados pela Totvs. |
| **Sistemas Operacionais:** | Todos Homologados pela Totvs. |
