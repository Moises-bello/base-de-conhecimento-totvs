# REQUISIÇÃO DE DESLIGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão de Pessoas |
| **Função:** | Requisição de Desligamento |
| **Situação/Requisito:** | Ao criar uma requisição de desligamento, marcando o flag "Listar apenas ex-funcionários" e escolhendo uma chapa cujo funcionário já foi demitido e marcando a opção "Gerar Substituição", ao clicar em SALVAR é apresentada a mensagem de erro e a requisição não é salva. |
| **Solução/Implementação:** | Realizado ajuste em requisição de desligamento, que gera substituição, para que a mesma seja salva corretamente mesmo quando o funcionário em questão já se encontre demitido e ainda não possua uma requisição de desligamento. |
