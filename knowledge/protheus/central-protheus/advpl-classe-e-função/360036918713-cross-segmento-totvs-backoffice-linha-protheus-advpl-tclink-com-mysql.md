**Dúvida**É possível utilizar a função [TCLink](https://tdn.totvs.com/display/tec/TCLink) (Conexão com um banco de dados SGBD através do DBAccess), com o banco MySql?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**O Banco ***MySql*** não está homologado para utilização no Dbacess.  
Banco *opensource* homologado temos ***PostgreSQL*****Saiba mais**[**Banco de dados homologado para o TOTVS DBAccess**](https://tdn.totvs.com/pages/viewpage.action?pageId=50528962)
