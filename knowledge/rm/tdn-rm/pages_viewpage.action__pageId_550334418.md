Ao realizar o faturamento de uma medição de contrato, o Sistema cria automaticamente o movimento 2.1.01 com a contabilização total do contrato.

Para contabilizar as receitas mensais, o usuário deve acessar o movimento 2.1.01 gerado e faturar para o movimento 2.2.01, conforme descrito a seguir:

O usuário deve preencher os campos conforme a seguir.

* **Tipo de Movimento**: Informar o tipo de movimento 2.1.01 – “Faturamento Contrato – Contabilização Contrato”;
* **Filial**: Informar a filial do movimento que deseja acessar.

Após clicar em “Ok”, o Sistema disponibilizará a tela de “Filtros” para exibição dos contratos, na qual o usuário deve selecionar o filtro desejado e clicar em “Executar”.

Neste momento, será apresentada a tela com os movimentos filtrados. E a partir do movimento gerado selecionado, o usuário deve “faturar” o mesmo para Contabilizar a Competência no mês desejado.

O usuário pode selecionar o movimento desejado e clicar no botão ( ) destacado em vermelho, ao invés de acessar os passos de “Processos | Faturar/Receber”.

A seguir, será apresentada a tela para faturamento:

Após clicar em “Executar”, o Sistema apresenta a tela para inclusão do novo movimento de contabilização da competência deseja.

O usuário deve informar apenas a data de emissão de acordo com o mês de competência que deseja contabilizar.

Neste momento será realizada a contabilização da competência desejada no Contrato. Este procedimento deve ser repetido a cada mês pelo usuário responsável.
