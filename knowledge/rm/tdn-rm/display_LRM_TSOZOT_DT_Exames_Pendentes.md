# EXAMES PENDENTES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Segurança e Saúde Ocupacional* |
| **Função:** | *Geração de Exames Pendentes* |
| **Situação/Requisito:** | *Ao executar a geração de exames pendentes, o sistema estava gerando pendencias de exames para funcionários que se encontram afastados (sem data de retorno).* |
| **Solução/Implementação:** | *Otimização no processo de geração de exames de forma que não sejam gerados exames pendentes enquanto o funcionário estiver afastado, e somente após o retorno do afastamento, no processo de geração de exames pendentes é que será realizada a validação da necessidade de gerar o tipo "Retorno ao Trabalho", conforme disposto na NR-7.* |

| **Chamados relacionados:** | *TSOZOT* |
