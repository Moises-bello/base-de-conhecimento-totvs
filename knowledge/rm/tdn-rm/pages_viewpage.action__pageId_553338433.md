Para demandas de ajuste na base do Cliente a área de Atendimento deve verificar, se é um acerto na base do cliente, com liberação de pacote ou apenas continuidade de um atendimento, onde o problema de parametrização de base já foi solucionado.

* **Acerto na base do Cliente, com liberação de pacote (com *commit* de fonte):**neste caso, deve ser utilizada a *issue type* de Manutenção e seguir o processo padrão.
* **Problema de parametrização na base do Cliente solucionado / Continuidade do Atendimento:**neste caso, a área de Desenvolvimento já resolveu o problema de parametrização do Cliente e foi sugerida uma outra forma de trabalhar, sendo necessário uma análise técnica pelo desenvolvimento. Para esta situação, deve ser utilizada a nova *Issue type* **Apoio - Cliente (*Issues* sem Commit de Fonte).**
