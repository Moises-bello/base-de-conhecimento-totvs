# CADASTRO DE BOLSAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Cadastro de bolsas |
| **Situação/Requisito:** | O cadastro de bolsas e o cadastro de bolsas no contrato do aluno limitam o valor ao número de casas decimais do Fluxus, porém outros processos como o de bolsa retroativa permitiam que uma bolsa fosse cadastrada com 4 casas decimais. O cadastro de bolsa retroativa evoluiu para seguir o número de casas decimais do Fluxus, porém, houve o entendimento que o sistema para valores de bolsas percentuais deve observar o parâmetro de casas de decimais para percentuais do Fluxus e para valores de bolsas utilizar o parâmetro de casas decimais para valores do Fluxus. |
| **Solução/Implementação:** | Foi realizada otimização dos cadastros de bolsa de forma que o sistema possa ter um tratamento diferenciado, com relação a quantidade de casas decimais, para bolsas cadastradas por valor ou por percentual. |
