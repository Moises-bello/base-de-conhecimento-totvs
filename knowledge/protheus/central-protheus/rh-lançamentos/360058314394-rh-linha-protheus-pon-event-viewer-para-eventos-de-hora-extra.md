**Dúvida**É possível enviar *Event Viewer* para eventos de hora extra?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**O SIGAPON não possui funcionalidade para envio de *e-mail* quando o colaborador efetuar uma marcação que gere hora extra. Caso necessite dessa funcionalidade, verifique a possibilidade de customização agendando atendimento de um analista Totvs in loco.
