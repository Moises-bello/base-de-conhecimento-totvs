# CANCELAMENTO DE ACORDO FINANCEIRO QUANDO O LANÇAMENTO GERADO POR ACORDO NÃO POSSUI SLAN

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Cancelamento de Acordo Financeiro* |
| **Situação/Requisito:** | *Sistema não cancelava o acordo quando o lançamento gerado não possuía vínculo com o Educacional (SLAN) mesmo tendo o CODAPLICACAO = 'S'* |
| **Solução/Implementação:** | Exclusão de tratamento no cancelamento de acordo para lançamentos gerados por acordo que não possuem um vinculo correspondente no Educacional. |
