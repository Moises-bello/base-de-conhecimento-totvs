Dúvida**Ao tentar compilar fonte, a ferramenta apresenta o *Error C2090 File not found NOMEDOINCLUDE.CH* **Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Esse erro ocorre pois no momento da compilação não é encontrado o *INCLUDE* dentro do diretório de *INCLUDES* do protheus

Acesse a pagina de downloads e baixe os includes necessários para a compilação.
