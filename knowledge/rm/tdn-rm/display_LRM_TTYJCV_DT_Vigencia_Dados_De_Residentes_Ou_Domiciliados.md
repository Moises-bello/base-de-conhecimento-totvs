# CADASTRAR VIGÊNCIA DE DADOS DE RESIDENTES OU DOMICILIADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastrar vigência de dados de residentes ou domiciliados* |
| **Situação/Requisito:** | Ao tentar inserir um registro de Dados de residente ou domiciliados onde já exista um registro com data final em branco e a data inicial do registro existente seja menor que a data inicial que está sendo gravado o sistema permite inserir a informação, fazendo com que exista dois registros com data final em branco e no mesmo período de vigência. |
| **Solução/Implementação:** | *É apresentado mensagem informando que existe uma vigência com data final em branco.* |
| **Chamados relacionados:** | TTYJCV |
