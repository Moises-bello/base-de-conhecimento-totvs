![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como cadastrar uma Despesa que não seja base de Custo e não calcule os impostos?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control*– Todas versões.  
  
**Solução**

Quando a despesa não for compor o custo do produto, cadastrar da seguinte forma, no Módulo 17- SIGAEIC em:

Atualizações \ Financeiro \ Cadastro de Despesas(EICA110):

- Base de custo = NÃO

- Base de imposto = NÃO

- Base de ICMS = NÃO
