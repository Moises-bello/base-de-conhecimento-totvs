# Objetivo:

---

       Este documento tem como objetivo demonstrar o uso do controle Linha.

# Introdução:

---

       Arraste o item Linha da Barra de Controles para o seu relatório para adicionar o controle.

# Linha:

---

       O controle é usado para desenhar linhas nos relatórios. Essas linhas só podem ser desenhadas dentro de uma banda específica.

Para desenhar uma linha entre várias bandas, use o controle Linha Multibandas.

# 

1Direção da Linha

Selecione uma das opções disponíveis expandindo a caixa para determinar a direção atual da linha.

2Estilo da Linha

Use a propriedade para especificar se o controle deve ser desenhado sólido ou tracejado.

3Largura da Linha

Digite ou use as setas na direita da caixa para especificar a largura da linha em pixels.
