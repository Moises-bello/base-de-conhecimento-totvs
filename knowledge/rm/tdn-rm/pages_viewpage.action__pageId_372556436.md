# Lançamento - Lançamentos Padrão

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Lançamento - Lançamentos Padrão |
| **Situação/Requisito:** | Ao gerar lançamentos padrões o mês e ano de competência (Aba Dados Adicionais) não acompanham o mês e ano do vencimento do(s) lançamento(s) gerado(s) no processo, de modo que o sistema replica a data (Mês/Ano de Competência) do lançamento principal nos mesmos. Observação: Na versão 11.52 o processo de "Lançamento Padrão" gera as parcelas com o Mês/Ano de Competência seguindo a data de vencimento. |
| **Solução/Implementação:** | Otimização no processo de geração de lançamento padrão. Agora o sistema preenche o campo mês competência corretamente acompanhando a data de vencimento de cada mês. |
