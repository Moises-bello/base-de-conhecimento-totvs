Como controlar direitos de usuários do projeto?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAPMS - Todas as Versões

**Solução**É possível controlar as alterações e manipulações dos projetos, atribuindo direitos de acesso para cada   
usuário. Dessa forma, podemos definir que, por exemplo, o usuário "X" tenha direitos totais sobre "Solicitações de Compras", porém acesso somente à visualização dos documentos do projeto.  
O usuário que cria o projeto possui automaticamente direito de acesso total a todas as operações desse   
projeto. Na rotina de Gerenciamento de Revisões, é possível atribuir direitos de acesso temporário para cada usuário em determinado projeto.  
Este, por sua vez, valerá somente enquanto o projeto estiver em revisão e, após ela, o direito de acesso será o definido no cadastro do projeto.

**Para cadastrar Usuários para Alteração de Projetos, seguir o procedimento :**  
1. “Atualizações” > “Projetos” > “Gerenciam. Projetos”;  
2.  Selecione o “Projeto  e clique na opção “Alt. Cadastro”;  
3. No “Campo – Ctrl. Usuário” selecione a opção “Habilitado” e confirme;

![usuario.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4421252022807/usuario.png)4. Selecione o “Projeto vá em : Outras Ações> Ferramentas > clique na opção “Usuários”;  
5. Selecione a “EDT ou Tarefa > Outras Ações > Usuários > "Incluir Usuário;"  
6. Escolha o  Código do usuário "AFX\_USER" no sistema para configuração dos direitos na estrutura do projeto;
