# PROGRAMAÇÃO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projeto* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Programação de Férias* |
| **Situação/Requisito:** | Foi realizada programação de férias futuras para funcionário com período atual também programado e a programação das férias futuras se sobrepôs as informações do período atual. |
| **Solução/Implementação:** | Ajuste na rotina de marcação de férias pelo portal para que não sobreponha informações de data de pagamento, inicio programação de ferias e fim programação de férias quando existir um registro com status 'M' ou 'P'. |
