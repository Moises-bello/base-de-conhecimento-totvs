![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26329997583767) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Por que Id 0318 apresenta valor inferior ao salário base?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O Id 0318 apresenta valor inferior ao salário base, pois no cálculo da folha de pagamento consta verba de desconto com Sim para Incorpora Salário.  
  
Exemplo:

Verba 435 Pensão Folha com Sim para Incorpora Salário.![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4409610796951)

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4409610814231)

Cálculo Folha de Pagamento![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4409610841751)

1.100,00 - 407,00 = 693,00 verba 318 Id 0318.

Para o Id 0318 apresentar o valor integral do salário base, é necessário editar a verba de desconto (neste exemplo a verba de pensão) com Não para o campo Incorpora Salário e recalcular a folha de pagamento.
