**Dúvida**  
Ocorrência de erro Type mismatch on compare on CONOUTR(CTBXLOG.PRW) 03/08/2017 19:00:07 line : 580

**Ambiente**

#### Cross Segmento - Backoffice Linha Protheus  – Contabilidade gerencial  – A partir da versão P12.1.17 **Solução**

Erro ocasionado pois o parâmetro MV\_CONOUTR, esta configurado como carácter, por padrão este parâmetro é numérico.

**Para detalhes consulte o link abaixo:**[Trace/Log para análise no desempenho da integração contábil - MV\_CONOUTR](http://tdn.totvs.com/pages/releaseview.action?pageId=51253724)
