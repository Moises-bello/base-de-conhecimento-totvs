![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34806420871191) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Por que cálculo rescisão apresenta valor diferente do salário base no id 0113 (desconto aviso prévio)?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) -Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**O cálculo de rescisão apresenta valor diferente do salário base no id 0113 (desconto aviso prévio), devido a configuração das verbas quanto aos campos Incorpora Salário e Base Cálculo.

**Exemplo:**

Verba de periculosidade está com Sim para Incorpora Salário.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/12886561982359)

Verba Id 0113 Desconto Aviso está como Base Incorporado.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/12886615790615)

Deste modo o id 0113 será calculado pelo valor salário base mais o valor de periculosidade.
