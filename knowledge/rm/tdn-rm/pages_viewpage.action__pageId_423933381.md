# Permitir realizar/alterar frequência diária em aulas geminadas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | TOTVS Educacional. |
| **Módulo:** | Educacional. |
| **Função:** | Frequência Diária. |
| **Situação/Requisito:** | O professor quando ia realizar a frequência diária no horário de aulas geminadas não era possível por serem duas aulas. |
| **Solução/Implementação:** | Foi realizado uma alteração no cadastro de frequência diária, permitindo que fossem permitidos digitar a frequência diária em horários geminados, mesmo que o horário atual ultrapasse o horário da aula anterior. Desde que a aula atual estivesse dentro do horário atual, permitido para a digitação da frequência. |
