# Cópia de Múltiplos Itens da Prescrição de Enfermagem

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | PEP | Prescrição de Enfermagem | |
| **Banco(s) de Dados:** | SQL Server® e Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Implementada a opção de selecionar vários itens para a mesma prescrição, podendo assim unir itens que tenham sido criados em prescrições de outros dias e tipos.

## Procedimento para Utilização

**Exemplo:**

1. No TOTVS Gestão Hospitalar (RM Saúde), acesse Prontuário e selecione um paciente.
2. Acesse a Enfermagem.
3. Insira duas ou mais prescrições.
4. Adicione uma nova prescrição baseada em um modelo anterior.
5. É possível selecionar mais de uma prescrição e todas essas serão agrupadas em apenas uma prescrição.
