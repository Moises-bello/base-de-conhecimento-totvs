## Descrição

Disponibilizados os seguintes relatórios na pasta de Objetos Gerenciais que foram convertidos para o novo gerador de relatórios (RM Reports) utilizando a ferramenta de conversão disponibilizada pela equipe de Framework.

|  |
| --- |
| 02.012-Ficha Física Financeira MODELO 2.RRM |
| 03.003-Vendas por Produto - Analítico.RRM |
| 05.003-Curva ABC de Produtos por Quantidade.RRM |
| 05.005-Curva ABC de Clientes por Valor.RRM |

## Importante

Os novos Relatórios do Book são distribuídos junto com a Biblioteca a partir da versão 12.1.8 na pasta de Objetos Gerenciais do instalador (Por exemplo: C:\totvs\CorporeRM\ObjetosGerenciais).

## Procedimento para Utilização

Os novos relatórios deverão ser importados no sistema utilizando os seguintes passos:

       1.            Acessar o RM Reports em Backoffice | Gestão de Estoque, compras e faturamento | Gestão | RM Reports

       2.            Acessar a aba de Processos | Importar Estrutura de Relatório

       3.            Selecionar os Objetos que se deseja importar e Executar o processo Importar Estrutura de Relatório para que o relatório fique disponível para execução.
