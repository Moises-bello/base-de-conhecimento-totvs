Base de Cálculo do tipo valor, com as mesmas incidências do evento com código de cálculo 127 - IRRF Partic. nos Lucros.  
 Este código de cálculo é utilizado no cálculo da pensão alimentícia de PLR quando o funcionário utilizar múltiplos vínculos.  
    
 O sistema faz o cálculo do IRRF PLR somente com a base do funcionário corrente, da mesma forma que o código de cálculo 127 quando não se utiliza múltiplos vínculos.
