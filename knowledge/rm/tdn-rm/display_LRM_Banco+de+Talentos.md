**Banco de Talentos**

O Banco de Talentos da linha RM foi totalmente redesenhado utilizando design mais moderno e usual, com isso, foram necessárias algumas alterações em sua parametrização/funcionamento conforme descritas abaixo:

- Alguns parâmetros referente ao Banco de Talentos foram descontinuados:

* Utilizar o novo processo de seleção: O novo Banco de Talentos não lista vagas de processos seletivos do Delphi (antigo processo de seleção).
* Grau de instrução para integração com LinkedIn: O LinkedIn mudou a política de acesso aos dados de usuários via integração. Neste momento o Banco de Talentos não tem integração com o LinkedIn.
* Relatório de impressão do currículo: A impressão segue um modelo padrão definido na implementação do Banco de Talentos.

- Possibilidade de acessar o Banco de Talentos pelo Fluig, desde que esteja instalado e configurado.

- Melhor personalização de layout do Banco de Talentos.

###### A partir da versão 12.1.2502 o Banco de Talentos será descontinuado para os clientes que nunca utilizaram ou acessaram o portal?
