**Integração TOTVS Folha de Pagamento RM x TOTVS Moda – Funcionário**

A Integração TOTVS Folha de Pagamento RM x TOTVS Moda tem o objetivo de enviar os dados do funcionário visando integrar estas informações para utilização dos dados com o BackOffice TOTVS Moda.

Para enviá-las deve-se parametrizar primeiramente as seguintes informações:

**Mensagem: EMPLOYEE**

**Versão: 2.003,** **3.00.2 (****para a conversão para a versão 3.00.2 é necessário abertura de issue para liberação do script****)**

Envio do funcionário para o TOTVS Moda.

**Exemplo de Json de Envio da mensagem:**

Dessa forma a integração atenderá os seguintes objetivos:

1) **Inclusão de Funcionário**: a inclusão de funcionário é gerada no TOTVS Folha de Pagamento e enviado para o sistema TOTVS Moda.  
2) **Alteração de Funcionário**: a alteração de funcionário é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.  
3) **Rescisão**: a rescisão de funcionário é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.  
4) **Alteração de filial no cadastro de seção**: a alteração de filial no cargo de seção é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.   
5) **Alteração de cargo no cadastro de função**: a alteração de cargo no cadastro de função é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.   
6) **Exclusão de Funcionário**: a exclusão de funcionário é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.   
7) **Rescisão Coletiva:** a rescisão coletiva é gerada no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.   
8) **Cancelar Rescisão**: o cancelamento de rescisão é gerado no TOTVS Folha de Pagamento e enviada para o sistema TOTVS Moda.
