## **03. SITUAÇÃO/REQUISITO**

Foi solicitado à equipe a possibilidade de importação dos empréstimos do crédito do trabalhador, utilizando a API do governo.

## **03. SOLUÇÃO**

Implementamos a alternativa de importação via API, utilizando funcionalidades de conexão que já existiam na TOTVS ( TAF e Middleware ), agora é possível importar o arquivo via API, uma funcionalidade alternativa além da função padrão que é via arquivo.
