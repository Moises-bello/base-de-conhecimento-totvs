# Objetivo

---

O objetivo deste documento é mostrar as possíveis integrações utilizadas via anexo para as telas geradas de Metadados.

# Geral

---

As integrações abaixo estão disponíveis para serem utilizadas com telas geradas via metadados, contanto que estejam habilitadas no sistema.

Não é necessário nenhum processo além de Gerar o Projeto de Metadados para que os anexos sejam incluídos.

ATENÇÃO

As integrações estão disponíveis a partir da versão 12.1.2602.100. Qualquer projeto já gerado antes desta versão, deve ser gerado novamente, nesta versão ou posterior, para que os anexos sejam habilitados.

Seguem os requisitos para ativar a integração, e, assim, habilitá-las nos Metadados:

### TOTVS Assinatura Eletrônica

Documentação de referência para habilitar integração: [Integração com TOTVS Assinatura Eletrônica](https://tdn.totvs.com/x/yCOOIQ)

### Repositório de Arquivos - FileRepo

Documentação de referência para habilitar integração: [Armazenamento de Arquivos (FileRepo)](https://tdn.totvs.com/x/TMbGLg)
