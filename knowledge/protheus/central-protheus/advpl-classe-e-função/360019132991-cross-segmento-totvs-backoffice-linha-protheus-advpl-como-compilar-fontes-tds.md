Dúvida**Como compilar fonte no TDS? 

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**

**Pré-requisitos:**

* Ter o TOTVS Developer Studio
* Cadastrar um projeto no TOTVS Developer Studio
* Habilitar um servidor

Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Abra o fonte que deseja compilar e selecione a opção compilar ou atalho **(CTRL+F9**);

![kcs_compilar.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360014879371)  
2. Processando a compilação;

![kcs_compilar2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360014844172)  
3. Finalizada com sucesso (observe a resposta no console TDS).

![kcs_compilar3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360014844252)

**Importante:**

O TDS 11.3.12 é compatível apenas com AppServer release 17.x.x.  
Para o uso com AppServer release 19.x.x é preciso utilizar o TDS 11.3.15, que passa a ser um plug-in do [VSCode](https://github.com/totvs/tds-vscode).
