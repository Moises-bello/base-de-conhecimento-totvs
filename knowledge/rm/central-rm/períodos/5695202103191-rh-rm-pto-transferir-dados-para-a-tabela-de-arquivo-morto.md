![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16980031633943) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como transferir os dados para a tabela de arquivo morto?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Totvs Automação de Ponto - A partir da 12.1.21  
 **Solução**

Para transferir os dados parar o arquivo morto, acesse o menu **Configurações | Períodos** e selecione um ou mais períodos desejados e acesse a opção **Processos | Transferir dados para a tabela de Arquivo Morto**.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29089120929303)
