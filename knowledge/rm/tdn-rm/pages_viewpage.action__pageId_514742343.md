A partir deste anexo, será possível associar os dados bancários ao empreendimento. Esses dados bancários terão os seguintes dados:

* **Filial**: Informe a filial dos dados bancários.
* **Convênio**: Informe o convênio que possui os dados do banco.
* **Tipo de Convênio**: Informe se os boletos gerados por estes dados bancários serão do tipo: **Registrado**, **Não Registrado**, **Registro Online**.
