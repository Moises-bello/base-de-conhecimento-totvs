# PROCESSO SELETIVO TERCEIRIZADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Matrícula e Cancelamento de Matricula pelo Processo Seletivo Terceirizado* |
| **Situação/Requisito:** | *Ao utilizar o processo seletivo terceirizado para matricular ou cancelar a matricula de candidato, o sistema não está salvados os dados da filiação corretamente na tabela correta (VFILIACAO - utilizada para o novo padrão de multi-parentalidade).* |
| **Solução/Implementação:** | *Foi feito o ajuste nos processo de matrícula e cancelamento de matricula para para que ao matricular o sistema salve corretamente na tabela VFILIACAO os dados do pai e mãe e no processo de cancelar matrícula faça a exclusão correta dos dados de filiação.* |
