Ao cadastrar ou editar um Empreendimento, na pasta Imagem, informe a imagem que estará vinculada ao Empreendimento:

* **Excluir Imagem:** O ícone irá remover a imagem gravado para o Empreendimento.
* **Carregar Imagem do disco:** O ícone apresentará uma janela onde poderá escolher o arquivo onde se encontra a imagem do empreendimento.
* **Salvar Imagem no disco:** O ícone apresentará uma janela onde poderemos salvar a imagem do Empreendimento no disco.
* Observação: Se a imagem estiver "truncada", é porque a imagem gravada no banco de dados depende de parâmetros do BDE (blob size), se este parâmetro estiver com tamanho pequeno, pode acontecer este problema.
