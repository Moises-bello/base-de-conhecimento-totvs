**App Minha Obra**

O App Minha Obra foi liberado para uso também em aparelhos com sistema operacional IOS. Nessa primeira publicação foram liberadas as funcionalidades Avanço Físico, Mão de Obra, Pedido e Pedido Extra. 

**Relatórios, Tabelas Dinâmicas e Visões de Dados do Smart View no TCOP**

Agora os Relatórios, Tabelas Dinâmicas e Visões de Dados do Smart View passam a ser gerados também diretamente do TCOP.[Saiba mais](https://tdn.totvs.com.br/pages/releaseview.action?pageId=751506740)

**Diário da Obra**

A partir dessa versão, o Diário de Obra (RDO) passa a contar com a integração ao **TOTVS Assinatura Eletrônica (TAE)**, permitindo que registros sejam assinados digitalmente, com validade jurídica, segurança e agilidade no processo de aprovação.[Saiba mais](https://tdn.totvs.com.br/pages/viewpage.action?pageId=841186300)

**Acordo Corporativo**

* O Acordo Corporativo agora passa a estar disponível também para os clientes cujo backoffice é Protheus.[Saiba mais](https://tdn.totvs.com.br/display/public/LRM/Acordo+Corporativo)
* Foi adicionada uma nova opção no Acordo Corporativo para o cálculo da data de entrega. Agora, é possível definir se o prazo será calculado em:  
  - Prazo Corrido(contando todos os dias);  
  -Dias Úteis (excluindo fins de semana e feriados). [Saiba mais](https://tdn.totvs.com.br/display/public/LRM/Acordo+Corporativo)

**Portal de Medição de Contrato**

* O Portal de Medição de Contrato agora exibe os dados do **aditivo** vinculado a cada medição. Essa melhoria proporciona mais detalhes e clareza durante a análise das medições.[Saiba mais](https://tdn.totvs.com.br/pages/viewpage.action?pageId=773893755)
* **Usuário para o Fornecedor:** Foi criada uma nova opção para facilitar a criação de usuários vinculados a fornecedores e projetos. Agora, o próprio usuário do sistema pode cadastrar usuários para os fornecedores sem depender do acesso do Administrador. Esses usuários já são criados com as permissões adequadas do portal e com todos os vínculos necessários para o funcionamento correto.[Saiba mais](https://tdn.totvs.com.br/pages/viewpage.action?pageId=993717010)

**Contrato**

* **Liberação do contrato:** Foi adicionada uma nova opção para o produto utilizado na liberação do período do contrato, sendo possível a partir de agora definir que será usado um "Produto Default ou Produto Associado(quando não houver produto default)". Essa melhoria traz mais flexibilidade e precisão no processo de liberação.[Saiba mais](https://tdn.totvs.com/pages/releaseview.action?pageId=421385359)
* **Anexos - Produto Default por Tarefa:** Neste novo anexo será possível definir um produto default para cada tarefa contratada. Este anexo tem prioridade sobre o produto default do contrato. Esta melhoria visa reduzir a necessidade de intervenção manual e garantir que o produto correto seja associado à tarefa correspondente de forma mais precisa e eficiente.

**Faturamento Direto**

* **Dedução do Faturamento Direto:** Foi criada uma nova opção para a dedução do faturamento direto, permitindo a partir de agora, além de, realizar o controle por Tarefa do Movimento ou por Movimento, realizar a informação do valor a deduzir sem nenhum vínculo com a Nota Fiscal do faturamento direto.[Saiba mais](https://tdn.totvs.com/pages/releaseview.action?pageId=421385359)
