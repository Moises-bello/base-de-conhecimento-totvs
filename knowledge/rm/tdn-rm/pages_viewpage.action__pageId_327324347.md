# Boleto com lançamento Baixado Por Acordo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Boleto |
| **Situação/Requisito:** | Ao realizar um acordo, um boleto registrado terá o seu lançamento "Baixado por Acordo", porém o status do boleto continuará sendo "Em aberto" até que seja recebido o retorno do banco com o cancelamento. Nestes casos estava sendo possível realizar o pagamento do boleto por cartão de crédito. |
| **Solução/Implementação:** | Foi realizado um ajuste para evitar a possibilidade de pagar um boleto registrado por cartão de crédito com status "Em aberto", no qual contém um lançamento "Baixado por Acordo". |
