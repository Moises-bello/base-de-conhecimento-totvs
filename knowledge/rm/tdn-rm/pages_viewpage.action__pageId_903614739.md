O login unificado dos portais, permite que a instituição realize a customização da logo na página de login.

As alterações das imagens **não são de responsabilidade da TOTVS**, pois estão ligadas à customização realizada pelo próprio cliente.

As customizações das imagens**devem ser realizadas em cada servidor web existente.**

Desta forma é **altamente necessário sempre** que tiver uma atualização de patch o cliente **salve as informações antes da atualização, e após a mesma, faça as modificações anteriormente realizadas**.

**1º-** Acessar a pasta **"FrameHTML\web\app\Edu\loginportais\assets\img\logos-login"**, no diretório onde está instalado o portal.

O sistema disponibiliza um arquivo para a imagem para o rodapé:

* **Imagem rodapé:** logo-rodape.png

Tamanho das imagens

Para que o banner tenha uma boa apresentação sugerimos que a imagem tenha a configuração:

* **Imagem rodapé:** 80px X 24px
