# CONTAGEM DE AVOS DE 13o SALÁRIO DEVE CONSIDERAR FINAL DO CONTRATO POR PRAZO DETERMINADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *13o.Salário* |
| **Situação/Requisito:** | *Quando o 13o. salário é calculado para funcionários com contrato por prazo determinado, está sendo considerado avos até dezembro, quando deveria contar somente até a data final do prazo.* |
| **Solução/Implementação:** | *Ajuste no cálculo do 13o. salário para que, no caso de funcionários com contrato por prazo determinado, seja considerado avos somente até a data final do prazo.* |
| **Chamados   relacionados:** | *TTSPVE, TUBSNK* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
