# HOMOLOGNET

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Homolognet |
| **Situação/Requisito:** | Sistema do Homognet está proporcionalizando o valor referente a rubrica 017 (Gratificação). |
| **Solução/Implementação:** | Criado o parâmetro "Considerar evento Base Gratificação com código da rubrica 017" no processo de geração do Homolognet. Se esse parâmetro estiver  marcado, o sistema verifica a existência de um evento do tipo Base que tenha a rubrica 017 vinculado. Com a opção desmarcado o sistema não teve alteração. |
