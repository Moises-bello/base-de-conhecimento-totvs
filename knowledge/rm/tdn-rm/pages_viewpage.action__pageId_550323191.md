A contabilização por competência do Sistema (TOTVS Educacional) tem como objetivo o reconhecimento das receitas Educacionais através da contabilização de provisão das receitas provenientes dos cursos. Para gerar a contabilização, o usuário deve seguir os passos abaixo:

Após acessar o Módulo Educacional, o usuário deve selecionar a aba “Financeiro/Contábil” conforme os passos a seguir.

Após selecionar a opção “Contabilidade”, o Sistema abre o assistente para contabilização por competência do Educacional.

O usuário deve informar os campos conforme definição a seguir:

* **Mês/Ano**: Informar a competência que deseja contabilizar ou estornar;
* **Operação:** Informar se a operação é de “Contabilização” ou “Estorno”, seguindo os critérios:
  + **Contabilização**: Para realizar a contabilização por competência;
  + **Estorno**: Para realizar o estorno da contabilização da competência desejada.
* **Data de Contabilização**: Informar em qual data a contabilização será registrada. **Observação**: Caso não seja informada nenhuma data neste campo, o sistema irá contabilizar no último dia do mês/ano informado no período de contabilização.
