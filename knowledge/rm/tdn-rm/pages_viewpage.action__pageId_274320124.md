# SOLICITAÇÃO DE ESTÁGIO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Solicitação de estágio |
| **Situação/Requisito:** | Ao aprovar a solicitação de estágio, caso o aluno seja menor de idade, apresentava mensagem de erro “Aluno é menor de idade favor definir o responsável legal”. |
| **Solução/Implementação:** | Ao aprovar a solicitação de estágio, caso o aluno seja menor de idade, deverá ser preenchido o campo “Responsável Legal” para que esta informação seja levada para o Termo de Compromisso. Necessário script para criação do campo SESTAGIOSOLICITACAO.CODRESPLEGAL CN.2017.05\_07. |
