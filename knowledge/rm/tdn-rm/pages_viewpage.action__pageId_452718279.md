Este histórico guarda toda a trajetória da pessoa na empresa relativa às transferências realizadas seja para a mesma coligada, ou para outra coligada.  
Não é possível incluir dados manualmente, pois o sistema sempre demonstrará as informações deste histórico conforme o cadastro do funcionário automaticamente.

O sistema utiliza os campos CODCOLIGADAORIGEM e CHAPAORIGEM da PFUNC, para apresentar os dados desse anexo.

**ATENÇÃO:** Os campos CODCOLIGADAORIGEM e CHAPAORIGEM devem estar preenchidos no funcionário Ativo e Demitido.
