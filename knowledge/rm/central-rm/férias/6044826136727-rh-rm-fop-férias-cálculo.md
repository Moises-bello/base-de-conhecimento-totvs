![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24102499143447) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como calcular férias?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar o cálculo de férias, acesse: **Férias | Cálculo**e realize as devidas parametrizações para o cálculo das férias.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6044443500695)  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6044455878423)

* **Período:**O sistema irá calcular as férias para todos os funcionários que estão com férias marcadas dentro do período informado;
* **Altera Pagamento:** Caso deseje uma data de pagamento diferente;
* **Seleção de funcionários:** Permite criar filtros para determinados funcionários, caso queira especificar os funcionários que terão suas férias calculadas.
