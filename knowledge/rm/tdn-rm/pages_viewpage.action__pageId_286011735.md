# Ajuste no Faturamento para Convênio IPERGS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento |
| **Situação:** | Ao realizar o faturamento para o convênio IPERGS, o sistema gerava itens de anestesia que estão marcados como fora da conta. |
| **Solução:** | Realizado ajuste para não gerar itens de anestesia que estiverem fora da conta, ao realizar o faturamento para o convênio IPERGS. |
