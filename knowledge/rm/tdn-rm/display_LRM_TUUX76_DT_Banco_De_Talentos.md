|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Banco de Talentos* |
| **Situação/Requisito:** | *Quando o interessado cadastra seu currículo, e o mesmo é aluno da instituição, o sistema duplica o cadastro do mesmo.* |
| **Solução/Implementação:** | *Ajuste no cadastro de novos usuários no Banco de Talentos. Quando o CPF utilizado já está cadastrado na base e o sistema está parametrizado para atualizar o cadastro de pessoas, a pessoa já cadastrada na base é vinculada a esse novo usuário. Se o sistema não estiver parametrizado para atualizar o cadastro da pessoa, não é permitido o cadastro de CPF repetido.* |
