### **Introdução**

---

O menu TAE - Assinantes Automáticos  está acessível através do menu de Anexos do Empreendimento.

Este cadastro é utilizado para facilitar a assinatura automática de um grande volume de documentos tanto no TCGI, quanto no Portal de Imóveis.

### Utilização

---

Ao acessar este cadastro o sistema apresenta os campos abaixo:

* **E-mail**: Informe o e-mail do usuário que irá assinar automaticamente os documentos gerados;
* **Senha:** Informe uma senha de acesso para este assinante;
* **Aplicação:** Selecione a qual aplicação este assinante está associado:
  + **Portal de Imóveis** ou **TCGI.**

**Importante**:

Ao realizar a assinatura automática de documentos enviados via portal de imóveis o sistema irá considerar somente os assinantes cadastrados com o tipo de aplicação "Portal de Imóveis".

Para saber mais sobre a assinatura de documentos no Portal de Imóveis, consulte a nossa documentação [clicando aqui.](https://tdn.totvs.com/pages/viewpage.action?pageId=572197716)
