# Fato Contábil gerado pela ECD (Sped Contábil)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Fato Contábil gerado pela ECD (Sped Contábil) |
| **Situação/Requisito:** | Ao criar a DRE através da estrutura de demonstrações contábeis para ser enviada para o Sped, foi criado alguns fatos contábeis utilizando expressões (exemplo: fato1 – fato 2). Ao gerar a demonstração via sistema trimestralmente, os valores batem corretamente, porém ao gerar o Sped, o registro J150 é criado com os valores diferentes pelos apresentados no sistema. |
| **Solução/Implementação:** | Ajuste da geração dos Fatos no SPED para que tenha o mesmo resultado que o apresentado no relatório da demonstração. |
