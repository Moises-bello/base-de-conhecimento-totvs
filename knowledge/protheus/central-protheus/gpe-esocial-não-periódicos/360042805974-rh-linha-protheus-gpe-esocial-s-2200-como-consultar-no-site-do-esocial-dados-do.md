**Dúvida**  
Como consultar no site do eSocial dados do evento **S-2200** (Cadastramento Inicial do Vínculo e Admissão)?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Esse evento está localizado no menu **Empregado** após fazer *login* no [Portal eSocial](https://www.gov.br/esocial/pt-br). Para consultar os dados **do trabalhador**, o empregador deverá digitar o CPF completo do trabalhador para buscar seus dados.  
  
Caminho: *Empregado > Gestão de Empregados:*  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17263213355671)*  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17263244147223)  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17267694221207)  
  
**Observação:**

* Para conhecer o manual completo de navegação no *site* do eSocial acesse: <https://www.gov.br/esocial/pt-br/empresas/manual-web-geral>
* Não recomendamos **inclusão/alteração** manual no *site* do **eSocial** devido a prejudicar a integridade entre os dados do sistema e governo gerando erros futuro.
