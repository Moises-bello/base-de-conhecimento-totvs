# Digitação de aula pelo professor no TOTVS Educa Mobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educa Mobile |
| **Função:** | Digitação de aula |
| **Situação/Requisito:** | Quando o professor digita o plano de aula em alguma aula no Educa Mobile e salva, o sistema retorna para a tela de seleção de etapas. O sistema deve retornar para a tela de seleção de aulas, pois isso dificulta muito a digitação de aulas pelo professor. |
| **Solução/Implementação:** | Foi realizado uma implementação no Educa Mobile, de maneira a facilitar a digitação de plano de aula pelo professor. Quando o professor salvar/confirmar uma aula no Educa Mobile, o sistema irá retornar para a tela de seleção de aulas, facilitando assim a digitação de aulas do professor. |
