# Atualização no número da guia ao autorizar procedimentos via web service

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Encerramento de conta |
| **Situação/Requisito:** | Ao autorizar um procedimento via web service o sistema não estava atualizando o número de guia gerado pela autorização no cabeçalho da guia. |
| **Solução/Implementação:** | Ajuste para que no momento da autorização o cabeçalho da guia seja atualizado com o novo número de guia gerado. |
