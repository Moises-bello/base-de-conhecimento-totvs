Versões inferiores a 12.1.2410.256Dados do remetente

Versões inferiores a 12.1.2410.256 os dados de remetente utilizados são os dados de remetente do PS, configurados nos parâmetros do Processo Seletivo na aba portal.

Nesse passo da parametrização, será possível parametrizar todas as informações referentes a notificação institucional da ficha médica flexível.

* **Destinatários para envio da notificação**

Este campo é responsável por centralizar todos os endereços de e-mail que serão notificados quando algum dado for inserido ou editado na ficha médica. Ao adicionar os endereços de e-mail, eles serão validados e em casos de qualquer inconformidade no conteúdo do campo será mostrado uma mensagem de alerta, conforme o print abaixo:

Observações

Para adicionar mais de uma endereço de e-mail é necessário separá-los por ponto e virgula.

* **Assunto**

Campo que permite a personalização do assunto do e-mail de notificação institucional.

* **Mensagem**

Este campo, permite a personalização do corpo do e-mail de notificação institucional e permite o uso das tags listadas na imagem abaixo:

Sempre que um responsável alterar a ficha médica, será enviado uma notificação para o(s) e-mail(s) parametrizado(s) com texto parametrizado acima.

Importante

Não será feito o envio do e-mail quando não parametrizado os campos: Destinatários para envio da notificação, Assunto e Mensagem

Nesse passo da parametrização, será possível parametrizar todas as informações referentes a notificação institucional da ficha médica flexível. Inclusive informações referente ao remetente para envio de notificação em caso de alteração da ficha médica.

* **Habilita envio de notificação.**Este campo define se o sistema deve ou não enviar notificações relacionadas às alterações na Ficha Médica Flexível.

  Campos envio de notificação
  + Para preencher os campos abaixo, o parâmetro **"Habilitar envio de notificação"** deve estar selecionado. Caso contrário, todos os demais campos permanecerão desabilitados.
  + A opção **"Habilitar envio de notificação"** só poderá ser marcada se a Ficha Médica Flexível estiver habilitada no passo **"Ficha Médica Flexível 1/2"**.
  + Para garantir que os novos campos não interfiram nas configurações já existentes, esta funcionalidade só terá efeito a partir do momento em que o cliente acessar o passo **"Ficha Médica Flexível 2/2"** pela primeira vez após atualizar o sistema para o patch que contém esta modificação.  
    Assim, quando o cliente abrir esse passo, caso já existam configurações anteriores preenchidas, o parâmetro **"Habilitar envio de notificação"** será ativado automaticamente e então todos os campos, inclusive os novos, deverão ser preenchidos obrigatoriamente para que o cliente consiga salvar as configurações.
* **Destinatários para envio da notificação**

Este campo é responsável por centralizar todos os endereços de e-mail que serão notificados quando algum dado for inserido ou editado na ficha médica. Ao adicionar os endereços de e-mail, eles serão validados e em casos de qualquer inconformidade no conteúdo do campo será mostrado uma mensagem de alerta, conforme o print abaixo:

Observações

Para adicionar mais de uma endereço de e-mail é necessário separá-los por ponto e virgula.

* **Dados do remetente.** Campo destinado a configuração do remetente das notificações de alteração da ficha médica flexível.
  + **Nome -** Nome do Remetente que será apresentado no e-mail de notificação;
  + **E-mail -** E-mail do remetente que será apresentado no e-mail de notificação. Ao adicionar o endereço de e-mail, ele será validado e em caso de qualquer inconformidade no conteúdo do campo será mostrado uma mensagem de alerta, da mesma forma que a imagem mostrada no item "**Destinatários para envio de notificação"**

    Dados do remetente

    Essa alteração foi feita para centralizar, em uma única tela, as configurações do remetente de notificações da Ficha Médica Flexível.
