**loggedUser** é um objeto do tipo  disponibilizada pela plataforma Fluig em todas os pontos de personalização e permite obter informações sobre o usuário logado.

# Descrição

Com ele o desenvolvedor pode validar, imprimir ou utilizar de outras maneiras os dados do usuário logado.

Em movimentação solicitações quando um usuário está substituindo outro, este é o usuário que está **substituindo**. O usuário que está sendo substituído pode ser obtido através do objeto . No caso de personificação, este objeto é referente ao usuário que está sendo personificado e não do usuário personificador.

# Sintaxe

js

# Exemplos de uso

## Imprimir os dados do usuário logado

jstrue

## Identificar se o usuário logado é diferente do usuário atual

jstrue

# Compatibilidade

Este objeto só está disponível a partir da versão 1.8.2.
