**Dúvida**Como corrigir a mensagem: Código de Banco não Cadastrado?  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360043214234/mceclip0.png)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**O erro ocorre devido ao posicionamento dos campos WB\_BANCO, WB\_AGENCIA, WB\_CONTA e WB\_DES\_BCO, sendo assim, ajustando os mesmos o conforme padrão do dicionário abaixo, a mensagem de erro não será apresentada.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360043215034/mceclip1.png)
