# Numeração de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Numeração de turma* |
| **Situação/Requisito:** | *Ao efetuar a numeração de turma e atribuir o último número do diário a novo aluno, ao visualizar a nova numeração é exibido para o aluno a ser enturmado o mesmo número de diário do último aluno encontrado.* |
| **Solução/Implementação:** | *Ajustes no processo de numeração de turma, quando selecionado a opção de atribuir o último número do diário a novo aluno e for selecionada a opção de visualização da nova numeração, para que os números de diário atribuído aos alunos sejam exibidos corretamente.* |
