**Tipo de Atendimento**

* **Exportaçao e Importação dos Tipos de Atendimento -**Disponibilizada nessa versão a possibilidade de exportar os Tipos de Atendimento e importá-los na mesma base ou em bases de dados diferentes, proporcionando, assim, muito mais agilidade nas criações dos fluxos e etapas dos tipos de atendimento a serem utilizados. [Saiba mais](https://tdn.totvs.com/pages/viewpage.action?pageId=425459518)

**Protocolo IMAP para Leitura de e-mails**

* **Parâmetro de Serviços TAA -** O serviço de gerar atendimentos através de grupo de e-mail traz, a partir dessa versão, a opção de protocolo IMAP para leitura de e-mail. [Saiba mais.](https://tdn.totvs.com/pages/viewpage.action?pageId=425459052)

**Autenticação OAuth 2.0 para Servidor Microsoft Exchange**

* **Gerar atendimento por grupo de email -** Foi disponibilizado no cadastro do grupo de e-mail, o tipo de autenticação OAuth 2.0, para o servidor de e-mails Microsoft Exchange, que desde outubro de 2022, deixou de aceitar a autenticação básica. [Saiba mais](https://tdn.totvs.com/display/LRM/Grupos+de+Emails)

**APP Minhas Aprovações**

* **Relatório de Aprovação do Pedido Extra -**Foi disponibilizado novo modelo de relatório para o aplicativo Minhas Aprovações no formato para celular, que permitirá a visualização dos dados dos itens de um Pedido Extra: **CRMREL0015 - WorkFlow Minhas Aprovações - Pedido Extra.**
