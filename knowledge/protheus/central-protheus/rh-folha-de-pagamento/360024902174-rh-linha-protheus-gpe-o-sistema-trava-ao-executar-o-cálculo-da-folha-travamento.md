**Dúvida**O sistema trava ao executar o cálculo da folha  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**1. Execute os procedimentos do trace do link: <https://centraldeatendimento.totvs.com/hc/pt-br/articles/360006726312>   
2. Abra o trace preferencialmente em um programa que organize os caracteres, por exemplo, Notepad++;  
3. Desça a barra de rolagem até o fim do arquivo;  
4. Verifique se apresenta por diversas vezes a **tabela REP** como no exemplo abaixo:![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360039261593/mceclip0.png)  
  
**5. Se o erro apresentado for semelhante ao apresentado no cálculo, será necessário aplicar o pacote acumulado do RH disponível no portal, em atualizações periódicas:**Pacote de Expedição Contínua do RH: <https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057829854>  
  
Obs.: se o erro apresentado no arquivo não apontar para a tabela REP, verifique o link <https://centraldeatendimento.totvs.com/hc/pt-br/articles/360029088632>. Se mesmo assim não for possível encontrar a solução, abra um ticket no suporte e envie o arquivo com o trace.
