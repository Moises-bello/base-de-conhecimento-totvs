# PORTAL - ALUNO - MATRÍCULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Rematrícula no Ensino Superior.* |
| **Situação/Requisito:** | *Quando não havia turma/disciplina ofertada com a disciplina da grade do aluno o processo buscava disciplinas equivalentes para matrícula. Quando haviam várias disciplinas equivalentes ofertadas, o aluno era matriculado nestas disciplina e as matrículas ficavam "duplicadas". Estas matrículas eram realizadas em disciplinas diferentes, porém equivalentes a mesma disciplina da grade do aluno.* |
| **Solução/Implementação:** | *Ajuste no processo de rematrícula no contexto de ensino superior para que o aluno seja matriculado apenas em uma disciplina equivalente, quando não houver turmas ofertando a disciplina da grade.* |
