Ao cadastrar ou editar o componente de Juros da Modalidade da Venda, informe os seguintes campos:  
  
**Tipo Juros Contrato**

* **Taxa de Juros %**:Informe o percentual de Juros de correção do contrato a ser cobrado neste componente caso este seja fixo, se não for fixo, deixe o campo em branco para ser informado posteriormente na inclusão de uma venda ou aluguel.
* **Tipo de Periodicidade**:Informe o prazo (Mensal, Anual etc) para realização dos reajustes de Juros de contrato caso este seja fixo, se não for fixo, deixe o campo em branco para ser informado posteriormente na inclusão de uma venda ou aluguel.

Este campo somente será habilitado se já estiver sido cadastrado um componente do tipo principal do mesmo grupo e ter o modelo de cálculo igual a Tabela Price.

* **Tipo de Juros**: Informe se será cobrado juros simples ou composto.
* **Referência de entrega do Componente**: Informe qual será a data de referência para determinar se o componente terá ação antes ou após a entrega do empreendimento. As referências podem ser:

* + Data da Entrega do Empreendimento
  + Data do Habite-se
  + Data da Entrega das Chaves
  + Data da Assinatura

Esta opção somente estará habilitada se o Modelo de cálculo escolhido no componente do tipo Principal desta modalidade for MODELO PADRÃO.

* **Aplicar reajuste de Juros**:Informe se este componente de Juros irá reajustar as parcelas vincendas, vencidas ou ambas.
