# REQUISIÇÃO DE ALTERAÇÃO DE DADOS FUNCIONAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Requisição de Alteração de Dados Funcionais* |
| **Situação/Requisito:** | *Se houver motivo parametrizado no PARAMETRIZADOR o campo de motivo de mudança da requisição ficará desabilitado. Se NÃO houver motivo no PARAMETRIZADOR o sistema habilitará o campo motivo de mudança na requisição.* |
| **Solução/Implementação:** | *Alteração no campo "Motivo de Mudança de Função" na Requisição de Alteração de Dados Funcionais. Se o sistema estiver parametrizado com um Motivo de Mudança de Função padrão, o campo continuará desabilitado. Se não houver essa parametrização, o campo estará habilitado sem ser obrigatório.* |
