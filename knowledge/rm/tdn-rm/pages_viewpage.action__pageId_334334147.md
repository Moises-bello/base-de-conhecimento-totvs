| **Dúvida:** | Como executar os scripts do eSocial nos Patch mais atuais? |
| **Resposta:** | Nas versões atuais do Totvs Folha de Pagamento, o sistema apresenta a mensagem abaixo relatando a necessidade da execução do script do eSocial:      É importante que o usuário tenha consciência de que o modelo de execução dos scripts foi alterado:     * Anteriormente executávamos os scripts pelo RM.Script.Executor.exe:            * Nas versões atuais os scripts serão executados através do RM.Atualizador.exe: |
