# REINF - VALOR RETIDO SUBCONTRATAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão de Estoque, Compras e Faturamento |
| **Função:** | Não se aplica. |
| **Situação/Requisito:** | Valor Retido Subcontratação - Reinf |
| **Solução/Implementação:** | Serviço de geração informação para uso do TOTVS Gestão Fiscal, que retornará dados necessários para a geração da Reinf referente ao Valor Retido Subcontratação.   * Em **Tributos e Valores | Tributos**, na grid de edição de tributos foi incluída uma nova coluna chamada **Valor Retido Subcontratação**. O seu preenchimento é opcional. * Essa coluna vai estar sempre visível, mas somente poderá ser editada quando o tributo correspondente for do tipo (DTRIBUTO.TIPOTRIBFISC) "INSS". |
| **Conversores e Parâmetros:** | É necessário executar o atualizar de base para ativação dos recursos;  Versões 12.1.18, 12.1.19 e 12.1.20 é necessário entrar em contato com suporte TOTVS para liberação do script. |
| **Tickets relacionados:** | Não se aplica. |
| **Requisito:** | MATESTCNTFTOF01-1939 |
