# SALÁRIO FAMÍLIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cálculo do Salário Família* |
| **Situação/Requisito:** | Para fins do disposto neste artigo, considera-se remuneração mensal do segurado o valor total do respectivo salário-de-contribuição, ainda que resultante da soma dos salários-de-contribuição correspondentes a atividades simultâneas.   Ao realizar um lançamento de salario família para múltiplos vínculos, o sistema calcula somente o salário base da chapa centralizadora, e ao acessar a outra chapa o sistema informa que o evento de salario família se encontra calculado na chapa centralizadora, porem o sistema não considera o salário base da chapa que não centralizadora. |
| **Solução/Implementação:** | *Ajustado cálculo do salário família ao considerar a base de cálculo de funcionários com múltiplos vínculos quando não utiliza chapa centralizadora de IRRF/INSS.* |
| **Chamados relacionados:** | *TVNWU9* |
