Dúvida**Ao tentar realizar a alteração do Histórico Salarial, é apresentada a seguinte mensagem de erro: **"Data de Processamento é menor que a data de Admissão". Favor Verificar.** Como corrigir?  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Nessa situação, basta acessar: **Configurações** | **Parametrizador | Funcionários | Restrições Cadastrai****s** e habilitar o parâmetro **Edita data de processamento:**  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360100414054/mceclip0.png)  
  
Avance a parametrização até o final para conclui-la. Após o processo, faça o Login no sistema e acesse novamente o Cadastro do Funcionário para realizar a alteração do Histórico Salarial com a data igual ou maior a data de Admissão.
