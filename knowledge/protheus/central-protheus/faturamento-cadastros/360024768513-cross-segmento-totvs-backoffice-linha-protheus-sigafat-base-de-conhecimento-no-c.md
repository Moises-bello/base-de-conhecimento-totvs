**Dúvida**

Como anexar arquivos no cadastro de Cliente (**MATA030 /CRMA980**)?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.

**Solução**

Para anexar arquivos no cadastro de cliente, realize os seguintes passos:

1. Acessar o Modulo Faturamento (05), Atualizações >> Cadastro >> **Cliente**;  
2. Localizar o Cliente que deseja incluir o arquivo "anexo" e clicar em **Alterar**;  
3. Dentro do Cadastro do cliente, acessar a opção Outras Ações >> "**Conhecimento**"  
4. No cadastro de Conhecimento, acessar a opção Outras Ações >> **Wizard**;  
5. Selecione o local onde o arquivo está armazenado, avançar, depois Finalizar;  
6. O Arquivo será encaminhado para a tela Inicial do cadastro da Base de Conhecimento;

Observação: Verificar a liberação de acesso do usuário através do configurador(SIGACFG).
