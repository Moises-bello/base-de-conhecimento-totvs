![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25609572846871) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Qual o objetivo do relatorio **SmartView ESTSV005 - Lista de Produtos a Endereçar**, e como configurar?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - A partir da versão 12.1.2310

**Solução**

A partir do objeto de negócio **Lista de Produtos a Endereçar**, é possível visualizar o saldo dos produtos que estão pendentes para endereçamento. O saldo a distribuir é gerado a partir de movimentações de entrada para produtos que possuem controle de localização (B1\_LOCALIZ = Sim).
