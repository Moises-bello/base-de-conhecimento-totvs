# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO PATRIMONIAL |
| **Versões:** | 12.1.16 ou superior. |
| **Ocorrência:** | Consulta/Cancela Ocorrências |
| **Ambiente:** |  |
| **Passo a passo:** | Todas as ocorrências existentes sejam Baixa Parcial ou Total, Acréscimo ou [T](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.OcorrenciaTranferenciaMonetaria.aspx)ransferência Monetária, Impairment, Reversão de Impairment, Avaliação Patrimonial,  podem ser visualizadas a partir da tela de consulta de ocorrências.  Existem também os filtros por tipo de ocorrência, facilitando esta consulta, disponível no menu Operações Patrimoniais | Consulta/Cancela | Selecione o tipo de ocorrência que deseja consultar.  Na tela de edição de ocorrências é possível visualizar qual o tipo da ocorrência, os patrimônios, as moedas de origem e destino, a data que foi realizada a ocorrência, os valores referentes a ocorrência, venda,  perda e ganho, a quantidade o fator.  Nesta tela também é possível visualizar o tipo de contabilização que foi realizada.      **Excluir ocorrências**  Caso deseje excluir as ocorrências deve-se selecioná-las e em seguida escolher a opção [Exclusão de Ocorrências](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.ExclusaoOcorrencia.aspx) em Processos. Outra maneira de executar este processo é a partir da tela de edição do patrimônio na aba ocorrências. |
| **Observações:** | Para mais informações sobre a Exclusão de Ocorrências clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=286750561). |
