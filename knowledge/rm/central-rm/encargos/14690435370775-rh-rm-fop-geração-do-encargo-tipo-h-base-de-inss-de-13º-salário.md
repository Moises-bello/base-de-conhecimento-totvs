![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17381809571991) Tempo aproximado para leitura: **00:01:30 min****Dúvida**No módulo Folha de Pagamento, como gerar encargo TIPO H - Base de INSS de 13º Salário ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para geração do encargo TIPO H - Base de INSS de 13º Salário, é necessário existir o lançamento de 13º salário, para lançamento de 13º salário.

Para realizar o lançamento do 13º salário acesse: **Folha mensal | Cálculo de 13º:**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/14690638564375)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/14688926673815)

Para calculo do encargo o sistema irá considerar (Proventos - Descontos) \* % encargo / 100) , verifique o cadastro do encargo o percentual a ser considerado será o informado no cadastro:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/14689001715223)

**Importante:**Verificar o código ativo associado ao cadastro do encargo pois no momento da geração do encargo será necessário selecionar o mesmo código ativo. Caso precise de apoio para criar o código ativo para vincular no encargo, utilize a documentação abaixo, após criar o código ativo, vincule o mesmo no cadastro do encargo.   
  
[RH - RM - FOP - Encargos: Criação de códigos ativos](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360021841391-RH-RM-FOP-Encargos-Cria%C3%A7%C3%A3o-de-c%C3%B3digos-ativos)
