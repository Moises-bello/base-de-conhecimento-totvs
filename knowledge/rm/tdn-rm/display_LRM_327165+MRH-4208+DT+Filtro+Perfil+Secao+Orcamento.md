# FILTRO POR PERFIL NO CADASTRO DE LOTAÇÃO DO ORÇAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Orçamento |
| **Situação/Requisito:** | Ao acessar o cadastro de quadro de vagas do orçamento, o sistema não está respeitando o filtro por perfil e deixa o usuário selecionar qualquer seção no lookup mesmo existindo filtro por perfil para bloquear tais seções. |
| **Solução/Implementação:** | Foi ajustado o cadastro de seção para que o mesmo respeite os filtros por perfil que forem utilizados, pois caso haja algumas restrição a visualização de alguma seção a mesma não seja apresentada. |
