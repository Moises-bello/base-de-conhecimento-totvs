# Ajustado travamento de tela ao estornar item já auditado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Auditoria interna pré-glosa |
| **Situação/Requisito:** | Ao realizar o estorno de um item já auditado o sistema estava travando a aba da elaboração de contas impedindo o usuário de realizar qualquer alteração na aba selecionada. |
| **Solução/Implementação:** | Alterado o sistema para não travar a aba onde foi tentando realizar o estorno do item. |
