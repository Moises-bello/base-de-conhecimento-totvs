# ORÇAMENTO QUADRO VAGAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Orçamento Admissão* |
| **Situação/Requisito:** | Sistema não considera demissões do ano anterior ao ano base para exibição de quadro de vagas por mês. |
| **Solução/Implementação:** | Alteração no fluxo de verificação de demitidos para o quadro de vagas do módulo de orçamento. Agora o sistema verifica com antecedência as demissões de anos base anteriores antes de verificar o ano base selecionado, dessa forma o sistema valida se houveram demitidos em anos anteriores que influenciam a totalização do quadro de vagas. |
| **Chamados relacionados:** | MRH-118 |
