# Extrato de Caixa - Evento Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Extrato de Caixa - Evento Contábil |
| **Situação/Requisito:** | O sistema está com divergência de comportamento quando refaz a contabilização do extrato com a regeração de  contabilização de extrato. Ao refazer a contabilização deveria buscar a mesma contabilização do regerar a  contabilização. Ao finalizar o processo o sistema exibe a seguinte mensagem: “Erro ao incluir o Lançamento 0.  Não é permitida a inclusão de Lançamento sem partida(s)”. |
| **Solução/Implementação:** | Otimização no processo de Regerar contabilização. Agora o sistema regera a contabilização corretamente. |
