# VALOR DA REMUNERAÇÃO NO RELATÓRIO DO PASSIVO TRABALHISTA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Passivo Trabalhista* |
| **Situação/Requisito:** | *O valor da remuneração não está sendo exibido no relatório do Passivo Trabalhista quando não está informado o evento de saldo salário no Parametrizador, pasta Rescisão.* |
| **Solução/Implementação:** | *Ajuste no relatório do Passivo Trabalhista para sempre informar o valor da remuneração, considerando o salário contratual do funcionário mais as fórmulas adicionais de remuneração, independente de estar ou não cadastrado o evento de saldo salário no Parametrizador, pasta Rescisão.* |
| **Chamados   relacionados:** | *TTNCFB* |
| **Versões/Release:** | *12.1.9, 12.1.10* |
