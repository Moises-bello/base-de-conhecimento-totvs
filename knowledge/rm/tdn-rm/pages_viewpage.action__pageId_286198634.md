# Disponibilização do Score " Escala de Shein " no Prontuário de Enfermagem PEP1

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | Rotina(s) envolvida(s) | | Prontuário Eletrônico - Formulário Dinâmico | |
| **Parâmetro(s):** | Parâmetros Gerais -> Integração -> PEP 2.0: URL Principal |
| **Requisito/S****tory/Issue (informe o requisito relacionado):** | MSAU-12726 |
| **Banco(s) de Dados:** | Oracle® e SQL Server® |
| **Sistema(s) Operacional(is):** | Windows® |

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações *12.1.16* deste chamado.

## Procedimento para Configuração

**CONFIGURAÇÃO DE PARÂMETROS**

1. No **TOTVS Gestão Hospitalar(RM Saúde)**, acesse ****Opções/Parâmetros/Parâmetros Gerais**** Configure o parâmetro a seguir:

|  |  |
| --- | --- |
| Itens/Pastas | *Integração -> PEP 2.0* |
| **Nome:** | *URL Principal* |
| **Tipo:** | *Texto* |
| **Cont. Por.:** | *Vazio* |
| **Descrição:** | Informa o endereço para login no PEP 2.0 |

## Procedimento para Utilização

1.          No TOTVS Gestão Hospitalar (RM Saúde), acesse o PEP do RM. O sistema apresenta a janela do PEP, selecione um paciente.

2.          Clique no botão Formulário Dinâmico.

3.          Fazer login na página do PEP 2.0.
