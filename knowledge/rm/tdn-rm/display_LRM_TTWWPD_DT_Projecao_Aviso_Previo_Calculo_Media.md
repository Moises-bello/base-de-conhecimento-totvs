# DESCONSIDERAR PROJEÇÃO DO AVISO PRÉVIO NO CÁLCULO DE MÉDIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão* |
| **Situação/Requisito:** | *No cálculo da média de férias vencidas na rescisão está sendo considerado o periodo da projeção do aviso prévio indenizado, quando está marcado o parâmetro para considerar o mês da rescisão nas médias.*  *Como se trata de um periodo em que o funcionário não trabalhou, não deve ser contabilizado no periodo de apuração das médias.* |
| **Solução/Implementação:** | *Ajuste no cálculo da média de férias vencidas na rescisão para desconsiderar o periodo da projeção do aviso prévio indenizado, nos meses de apuração das médias, mesmo quando é considerado o mês atual nas médias.* |
| **Chamados   relacionados:** | *TTWWPD* |
| **Versões/Release:** | *11.82.43* |
