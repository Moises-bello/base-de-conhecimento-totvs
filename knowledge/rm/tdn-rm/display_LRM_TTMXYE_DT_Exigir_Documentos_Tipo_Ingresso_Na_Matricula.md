# EXIGIR DOCUMENTO DO TIPO INGRESSO NA MATRÍCULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Exigir documentos do tipo ingresso na matrícula* |
| **Situação/Requisito:** | *O aluno entregou todos os documentos, porém não consegue realizar a matricula no portal, pois o sistema continua a exigir os documentos. Os documentos são do tipo ingresso e já constam como entregues.* |
| **Solução/Implementação:** | *Ajuste na cobrança de documentos do tipo ingresso, quando o parâmetro "Considerar documentos do tipo ingresso mesmo que não seja a primeira matrícula" estiver marcado, para que seja, verificado os documentos do tipo ingresso já entregues pelo aluno quando ingresso no curso, caso não constar nenhum entregue o sistema continuará cobrando os documentos.* |
