**Valor Tipo Parcela**   
 Campos apresentados na aba Valor Tipo Parcela:  
    
 O quadro Percentual possui os campos:  
    
 **Multa ao dia (%):** Informe o percentual da Multa ao dia para o pagamento das parcelas no Fluxus.  
    
 **Juros ao dia (%):** Informe o percentual da Juros ao dia para o pagamento das parcelas no Fluxus.  
    
 **Valor Multa:** Informe o Valor de Multa a ser registrado nas parcelas geradas para Fluxus.  
    
 **Valor Juros:** Informe o Valor de Juros a ser registrado nas parcelas geradas para Fluxus.  
    
 **Observação:** Para os campos acima, o usuário deve informar ou percentual ou Valor.  
    
 **Cod Conta Caixa:** Informe a Conta Caixa que será utilizado para o tipo de parcela. Se este campo não for preenchido, o sistema irá utilizar a conta caixa que está parametrizada na venda.  
    
 **Observação:**  
 Se nos parâmetros gerais do RM SGI, o parâmetro "Lançamento sem Conta Caixa" estiver marcado, o sistema não avisa nada, simplesmente gera os lançamentos para o fluxus SEM conta caixa.
