**Este histórico está disponível apenas para o contexto ENSINO BÁSICO.**

Para acessar o log de **Histórico: Currículo e Oferta → Aluno e Professor → Alunos → Log de movimentações**. Entretanto para que este log fique disponível é necessário marcar o parâmetro **Importar disciplinas reprovadas para o histórico**em Configurações | Parâmetros | Secretaria | Passo 3.

Este log somente é gerado pelo processo de geração de histórico (Menu | Matrícula e Avaliação | Rotinas periódicas | Geração do histórico) e se existir **disciplinas reprovadas**, caso não exista o mesmo não é gerado.
