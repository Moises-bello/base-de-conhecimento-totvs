# RESCISÃO COMPLEMENTAR ESTÁ SOBREPONDO VALOR DO CC109 LANÇADO NA DIFERENÇA 13o.

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Complementar* |
| **Situação/Requisito:** | *Quando é calculada Diferença de 13o. por Dissídio no mesmo envelope da Rescisão Complementar por Dissídio, como nos dois processos é utilizado o CC 109 para lançar a Base de FGTS 13o., um está sobrepondo o valor do outro.*  *Será necessário criar campos para o usuário informar eventos diferentes para cada processo, assim como já existe para o CC 69, Base FGTS Diferença Salarial.* |
| **Solução/Implementação:** | *Criação de dois campos no Parametrizador, pasta Folha Normal/Dissídio, para que o usuário possa informar códigos de eventos diferentes com CC 109, para serem lançados da Diferença de 13o. por Dissídio e na Rescisão Complementar por Dissídio.* |
| **Chamados   relacionados:** | *TVBTQD, TVCQC3* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
