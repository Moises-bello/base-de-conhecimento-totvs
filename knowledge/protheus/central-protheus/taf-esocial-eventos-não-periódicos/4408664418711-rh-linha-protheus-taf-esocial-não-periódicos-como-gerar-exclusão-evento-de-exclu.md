![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23691428634391) Tempo aproximado para leitura: **00:05:00 min****Dúvida**Como gerar S-3000 (Exclusão de Eventos) para o último registro gerado, dos eventos S-2205 e S-2206, último registro gerado?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Eventos Não Periódicos - S-2205 e S-2206 - Todas as versões  
  
**Solução**

Siga os passos abaixo para gerar corretamente evento de Exclusão (S-3000), para o último registro gerado, dos os eventos S-2205 e S-2206.

**1.** Pelo menu principal do TAF acesse: **Atualizações > eventos Esocial > Cadastro Trabalhador**

**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408662191639)**

**2.** Localize o colaborador que deseja realizar a exclusão;

**3.** Posicionado no colaborador, selecione o botão: **Outras Ações> Excluir > Excluir Registro**

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408662657687)

**4.** Será apresentada uma tela para selecionar o tipo de evento desejado:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408683447703)

**5**. Após selecionar o evento, no nosso caso, o S-2205 ou S-2206, será aberta uma tela informando que será gerado um evento S-3000 para o último evento válido, com recibo. Selecione o botão **Sim**, se estiver correto.

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408663073175)

**6.** O evento (S-2205 ou S-2206) será aberto para ter certeza das informações que serão excluídas, se estiver correto, selecione o botão **Confirmar**.

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408663260823)

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408663340055)

**7.** O evento S-3000 ficará disponível para transmissão na rotina de Monitoramento do TAF.

**FIQUE ATENTO:**

Se tentar realizar o processo descrito acima, para o último registro gerado, pela opção **Histórico de Alterações** (dentro da rotina de Cadastro do Trabalhador), será gerado um alerta com o processo correto.

Acessando o Histórico de Alterações:

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408663649303)

Tela Histórico de Alterações: **Outras Ações > Excluir Extp. > Excluir Registro**

![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408663997591)

Será apresentada a mensagem:

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4408683791639)

O correto é realizar a exclusão do último evento válido, pelo passo a passo que ensinamos nesta documentação.
