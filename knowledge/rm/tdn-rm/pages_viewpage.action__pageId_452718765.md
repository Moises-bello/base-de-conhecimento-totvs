Através deste módulo poderá visualizar, editar, incluir ou excluir as resilições cadastradas para o movimento de ensino importado.  
 Através da consulta é possível controlar:  
    
 **ID**  
 Código identificador da resilição. Campo obrigatório com valor gerado automaticamente.   
 **Data da Resilição**  
 Campo obrigatório para informar a data da resilição. Caso já tenha resilição cadastrada para o mesmo movimento, a data deve ser maior que a última.  
 **Tipo de Resilição**  
 Informe ou cadastre o tipo da resilição que será feita.   
 **Jornada Anterior**  
 Campo preenchido automaticamente sem ser possível alterar. Caso tenha outras resilições cadastradas para o mesmo movimento, o seu valor será de acordo com o mais recente. Se for a primeira resilição para o movimento, o valor será de acordo com o mesmo, caso já haja alguma resilição, ele será de acordo com a última cadastrada.  
 **Jornada Atual**  
 Preencha com o valor da jornada que o funcionário ficará após ser feito a resilição. Campo só será visível, caso o movimento de ensino seja por carga horária ou número de aulas semanais.  
 **Valor Fixo Anterior**  
 Campo preenchido automaticamente sem ser possível alterar. Caso tenha outras resilições cadastradas para o mesmo movimento, o seu valor será de acordo com o mais recente. Se for a primeira resilição para o movimento, o valor será de acordo com o campo valor fixo do movimento de ensino importado, caso já haja alguma resilição, ele será de acordo com a última cadastrada.
