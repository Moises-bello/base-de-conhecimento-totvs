# Cancelar atendimento com NF emitida

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de  Solicitação p/ Emissão de Nota Fiscal / Recibos |
| **Situação:** | Sistema não permitia o cancelamento de atendimentos com nota fiscal emitida no EMS. |
| **Solução:** | Realizado ajuste no botão que exclui Pedido do EMS, para que fique habilitado quando existir número de referência do EMS. |
