Dúvida**Correção **RUP** ao fazer atualização **UPDDISTR**.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão 12.1.23.  
  
**Solução**No release **12.1.23** ou superior, os **RUP** não são executados, baixe os arquivos de migração de atualização do release de acordo com a versão e os grave na pasta SystemLoad, confirme se todos os arquivos presentes no diretório correspondem ao release atual.  
É necessário também atualizar os arquivos de **Dicionário de Dados** (sxsbra.txt), Menus e Help de Campos na pasta **Systemload**. Faça um backup da pasta Systemload, limpe todo o contéudo da pasta inclua os arquivos relativos a versão a ser atualizada e realize o processo de migração.
