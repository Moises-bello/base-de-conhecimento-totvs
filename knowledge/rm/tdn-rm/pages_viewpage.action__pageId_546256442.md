## **02. SITUAÇÃO/REQUISITO**

Necessidade de uma permissão no perfil do usuário para habilitar o menu do eduCONNECT Pay dentro do eduCONNECT

## **03. SOLUÇÃO**

Criado o item de menu "Permite acesso ao eduCONNECT Pay" dentro das permissões de perfil do eduCONNECT  
Criada a tag se segurança 808100759 para essa permissão no perfil do usuário  
Somente será habilitado esse item de menu se estiver habilitado para utilização do Payments no license server
