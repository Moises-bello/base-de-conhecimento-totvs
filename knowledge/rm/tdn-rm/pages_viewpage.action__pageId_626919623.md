A inscrição em visitas técnicas/ventos tem como objetivo permitir ao usuário gerenciar as inscrições realizadas através de solicitações na Plataforma FLUIG.

=> Criar no FLUIG os papéis necessários para a execução do fluxo do projeto de inovação. É importante criar da mesma forma descrita abaixo pois o fluxo utiliza essa definição para referenciar os papéis.  
        Código = aluno| Descrição = Aluno  
        Código = pesquisador | Descrição = Pesquisador

Criar no FLUIG os grupos necessários para a execução do fluxo de inscrição em visitas técnicas/eventos. É importante criar da mesma forma descrita abaixo pois o fluxo utiliza essa definição para referenciar os grupos.

* Código = setor\_visitas| Descrição = Setor de Visitas

Em seguida, associar os usuários aos respectivos papéis cadastrados.

=> Associar adequadamente os usuários do FLUIG aos papéis criados anteriormente.

=> Importar o fluxo: Inscrição em Visitas Técnicas/Eventos para a ferramenta TOTVS Developer Studio (TDS).  
Caso não tenha alterado a instalação padrão dos produtos TOTVS, os arquivos zipados, contendo o(s) fluxo(s), estarão disponíveis em c:\totvs\CorporeRM\ObjetosGerenciais\Fluig.  
  
**Descrição do Processo:**

Logar com o usuário associado aos papeis de: "Aluno" ou "Inventor" e iniciar uma nova solicitação no FLUIG, escolhendo a opção:

* "FLUIG | Iniciar Solicitações | Educacional | Inovação, Pesquisa e Extensão | Visita Técnica/Evento | Inscrição em Visitas Técnicas/Eventos.

Ao selecionar esse fluxo será apresentado um formulário com o código do aluno vinculado ao usuário do FLUIG. Nele deverão ser informados o termo de responsabilidade e a visita técnica/evento em que o aluno deseja se inscrever, porém serão listadas somente as visitas cujo público-alvo contemple o curso e habilitação desse aluno. Vale ressaltar que alunos menores de idade não podem realizar inscrição, somente seus responsáveis legais. Ela deverá ser realizada de forma presencial por um usuário com o papel "Secretaria". Após preencher as informações necessárias o fluxo será finalizado.
