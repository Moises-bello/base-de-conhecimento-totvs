**Dúvida**O Sistema permite calcular rescisão sem os adicionais padrões para as verbas indenizatórias, uma vez que o funcionário tem direito ao adicional?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**O sistema não permite calcular rescisão sem os adicionais padrões para as verbas indenizatórias uma vez que o funcionário tenha direito, pois conforme legislação, para esse cálculo deve ser considerada a remuneração do funcionário, não apenas o salário base.
