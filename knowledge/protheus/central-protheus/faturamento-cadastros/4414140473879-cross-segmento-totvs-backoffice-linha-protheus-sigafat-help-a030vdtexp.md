![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Cadastrado um cliente estrangeiro e quando efetua-se a alteração, gera-se o help: A030VDTEXP

Problema: Não será possível escolher o País Brasil para o Cliente do Tipo Exportação (Origem Estrangeira)

Solução: Escolha um outro Tipo de Cliente ou altere o código do país dos campos Pais ou Pai/Bacen.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414140395799/mceclip0.png)  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT- Todas as versões  
  
**Solução**

Este help aparece sempre que se tenta colocar o código do pais (**a1\_pais**) como 105 - Brasil  ou Pais Bacen(**a1\_codpais**) com 01058 - Brasil para clientes do Tipo EX - estrangeiro, o sistema possui o bloqueio que não **permite** configurar um cliente do tipo exportação do País Brasil.

Neste caso, escolha outro pais para ajustar o cadastro do Tipo EX.
