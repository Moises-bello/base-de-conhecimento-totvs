**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15497196049175) Tempo aproximado para leitura: 00:01:00 min****Dúvida**Como bloquear a Readmissão de Funcionários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoas - Todas as versões  
  
**Solução**Para que o Funcionário seja **bloqueado para readmissão**, selecione o campo abaixo antes de calcular a Rescisão:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8605634467095)  
  
  
Com a opção marcada, se for feita uma tentativa de admissão para uma pessoa com o mesmo **CPF** do Funcionário demitido, a rotina **não permite o cadastro**, apresentando a mensagem abaixo ao tentar salvar o registro:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23390946120855)

Caso a empresa queira **recontratar o Funcionário**, altere o campo **Bloq. Admis.** para **Não** na aba Funcionais no cadastro do Funcionário:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8605721998359)  
  
**OBS:** Para Funcionários que não tiveram o bloqueio realizado no cálculo da rescisão, caso deseje realizar o bloqueio posteriormente, basta alterar o campo para SIM.
