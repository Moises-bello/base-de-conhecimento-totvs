**Pasta Identificação - Requisição de Transferência com Alteração de Dados Funcionais**

Na pasta Identificação os seguintes dados devem ser informados:

**Número -** Gerado automaticamente e com valor único.

**Status -** Será apresentado logo após a abertura da requisição como "Pendente". Este campo será alterado à medida que a requisição for avançando no fluxo de aprovações assumindo os valores parametrizados e definidos para cada etapa.

Para verificar a parametrização acesse: Configurações | Tipos de Requisições. Os status que poderão ser definidos pelo fluxo de aprovação são "Em Andamento", "Aprovado" e "Reprovado". Os status "Suspenso" e "Cancelado" serão definidos conforme a utilização do processo "Suspender requisição " e "Cancelar Requisição" respectivamente.

O status "Concluído" será determinado quando o processo "Concluir requisição" for realizado através do menu "Efetivar Transferência com Alteração de Dados Funcionais".

**Os status das requisições são representados pelas cores:**

Aprovada – cor verde

Cancelada – cor preta

Concluída – cor roxa

Em Andamento – cor amarela

Pendente – cor laranja

Reprovada – cor vermelha

Suspensa – cor azul

**Nome do Aprovador Atual -** Este campo não é editável e apresentará o nome do aprovador atual da requisição, ou seja, o responsável atual pela requisição, conforme definição do fluxo de aprovações.

**Conclusão -** Irá apresentar a data que a requisição foi concluída, ou seja, a data que foi realizada a efetivação da transferência.

**Requisitante -** Somente podem ser selecionados chefes da coligada na qual o usuário do Totvs Gestão de Pessoas esteja logado. Esta informação poderá ser modificada enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado.

Caso a requisição seja aberta pelo "Totvs RM Portal" este campo exibirá o nome do usuário logado não podendo ser modificado.

**Requisição Vinculada (PAI) -** Este campo não é editável e apresentará o número e nome da requisição PAI que gerou/motivou a transferência.

**Funcionário -** Para vinculação na requisição de transferência com alteração de dados funcionais serão exibidos os funcionários subordinados ao requisitante (exceto ex-funcionários). Se o funcionário selecionado for membro da CIPA, a requisição poderá ser criada, porém a sua conclusão mediante a transferência do funcionário só ocorrerá após o término do período de estabilidade conforme rege a NR 5. Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer tenha sido cadastrado.

**Previsão -** Deverá ser informada a data prevista para a transferência com alteração de dados funcionais, não podendo receber um valor inferior à data atual (data do dia). Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado. Por definição o sistema sugere a data atual.

**Justificativa -** Ao solicitar uma transferência com alteração de dados funcionais deverá ser informada uma justificativa para tal solicitação. Este campo poderá ser alterado enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado.
