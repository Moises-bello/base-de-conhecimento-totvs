# Validação de Período Letivo na Matrícula Online do Ensino Básico (Novo Portal Educacional)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Matrícula do Ensino Básico |
| **Situação/Requisito:** | Validação de Período Letivo durante o processo de Matrícula. |
| **Solução/Implementação:** | Foi realizado as validações referente à Habilitação/Período Letivo em que o aluno está realizando a matrícula no ensino básico. Estas validações podem ser apenas informativas ou bloquearem a matrícula, de acordo com parametrizações do Educacional.  As validações funcionam da mesma maneira que o já realizado no portal do Corpore.NET.  As validações realizadas são:   * Verifica débitos financeiros no Educacional TETERA, TETERA MASCADA * Verifica a Conta Corrente do aluno Pedrinho! * Verifica débitos financeiros na biblioteca * Verifica Documentos Pendentes * Verifica Ocorrências do aluno * Verifica a existência de um Plano de Pagamento válido para geração do contrato financeiro. |
