# Baixa - Baixa com Cheque Emitido

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixa - Baixa com Cheque Emitido |
| **Situação/Requisito:** | Ao efetuar a baixa de mais de um lançamento à pagar com o meio de pagamento igual a ‘Cheque’, o sistema está consistindo o valor do campo ‘Histórico default cheque a receber’ ao invés do histórico da natureza correspondente (‘A Pagar’). |
| **Solução/Implementação:** | Otimização no processo de baixa de mais de um lançamento à pagar com meio de pagamento igual a 'Cheque', agora o sistema está consistindo o valor do campo 'Histórico default cheque a receber/pagar' correspondente a natureza corretamente. |
