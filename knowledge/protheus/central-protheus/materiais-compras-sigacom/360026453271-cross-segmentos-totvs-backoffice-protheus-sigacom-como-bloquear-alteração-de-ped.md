**Dúvida**  
Como bloquear Alteração de Pedido de Compras Atendido - MV\_ALTPC ?  
  
**Ambiente**  
Protheus - Compras - A partir da versão 11

Mesmo após o registro do pedido de compras no sistema Protheus, ainda pode haver negociações entre o cliente e o fornecedor, como o aumento da quantidade de produto a ser fornecido ou a alteração do preço do item dentro do mesmo pedido. Essas alterações podem ocorrer até mesmo depois que o pedido foi totalmente atendido, desde que o sistema esteja configurado para permitir isso. Por essa razão, o sistema não bloqueia a modificação de pedidos, incluindo aqueles gerados a partir de cotações. Para controlar essas alterações, o sistema oferece dois parâmetros que são responsáveis pela gestão desse processo.

MV\_ALTPC - Bloqueia a alteração de pedido de compras atendido  
MV\_ALTPEDC - Define se pode alterar o pedido de compra já atendido, validando os campos de quantidade e preço do Pedido de Compras.
