# INSERIR FUNCIONÁRIO EM MOVIMENTAÇÃO DE PESSOAL COM REQUISIÇÃO DE SUBSTITUIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Pessoas |
| **Função:** | Inserir em Movimentação de Pessoal com Requisição de Substituição |
| **Situação/Requisito:** | Ao tentar inserir um funcionário horista em movimentação de pessoal utilizando uma requisição de substituição, o sistema acusa que o salário do funcionário é maior que o salário da requisição e pede para alterar o mesmo, porém o salário apresentado para o funcionário não é o salário hora, mas sim o salário mensal. |
| **Solução/Implementação:** | Ajuste na carga do salário do funcionário horista para inclusão na movimentação de pessoal utilizando uma requisição de substituição que foi gerada com base nos dados de funcionário horista. |
