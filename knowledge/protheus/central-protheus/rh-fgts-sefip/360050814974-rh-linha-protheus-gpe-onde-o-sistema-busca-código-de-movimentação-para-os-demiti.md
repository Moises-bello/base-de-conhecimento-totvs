**Ocorrência**Onde o sistema busca Código de movimentação para os demitidos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**A movimentação determinada para os funcionários demitidos são validados o que constam preenchidos no campo Cod. Afast. FGTS e Código A. M. da tabela S043.
