# Rateio Centro de Custo na Baixa Financeira X Lançamento Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Contabilização com Rateio por Centro de Custo |
| **Situação/Requisito:** | Valores da contabilização de baixa não refletem os valores do rateio do lançamento. |
| **Solução/Implementação:** | Ajuste na geração do percentual do rateio por centro de custo do item de baixa para que seja gerado o percentual com uma dizima maior possibilitando a integração contábil de gerar os valores do rateio conforme foram gerados no sistema financeiro. |
