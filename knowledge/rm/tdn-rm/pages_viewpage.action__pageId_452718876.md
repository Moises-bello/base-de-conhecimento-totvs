**Níveis das Seções**

Este cadastro guarda os possíveis níveis que um risco tem em uma seção. Não é necessário haver um cadastro único para uma seção, ou seja, uma mesma seção poderá ter vários riscos com vários níveis associados a ela porém, um mesmo risco em uma seção deverá ter apenas um nível de incidência.

Para este cadastro deverão ser preenchidos os dados solicitados na pasta apresentada, a partir da janela de edição.
