# SEFIP

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Geração SEFIP |
| **Situação/Requisito:** | Para funcionárias que tiveram licença maternidade durante o ano e rescisão no mês de Dezembro após o pagamento da segunda parcela, ao gerar a SEFIP FOLHA, está sendo levado a dedução da Licença Maternidade na SEFIP, porém essa dedução já foi levado na SEFIP 13°. |
| **Solução/Implementação:** | Ajuste na geração do SEFIP quando tiver licença maternidade no ano, e for demitido após o pagamento do 13º Salário. |
| **Tickets relacionados:** | 4710580 |
