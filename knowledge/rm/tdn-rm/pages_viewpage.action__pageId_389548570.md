|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matricula em disciplinas* |
| **Situação/Requisito:** | Ao executar o processo de matrícula em disciplina, o sistema não permitia avançar a tela do processo até o final, quando o aluno já tinha contrato no período letivo. |
| **Solução/Implementação:** | Otimização no processo “Matricular aluno nas disciplinas”, ao marcar o campo “Gerar Lançamento”,caso exista contrato no período letivo, será necessário preencher os campos de parcelas, cotas e escolher o contrato para habilitar avançar para a próxima tela. |
