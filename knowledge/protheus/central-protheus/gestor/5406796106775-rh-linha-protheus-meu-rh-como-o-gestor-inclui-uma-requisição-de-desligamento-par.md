**Dúvida**  
Como o Gestor inclui uma Requisição de Desligamento para um funcionário?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
Para que o Gestor tenha acesso a essa funcionalidade, é necessário habilitar a permissão relacionada através do módulo **18 Terminal de Consulta do funcionário** - [RH - Linha Protheus - MEU RH - Configuração de permissão de acesso as funcionalidades e menu do MEU RH](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360033892693)  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/5406187798551)  
  
  
**Acessar o menu Gestor → Requisições → Desligamento -> Clicar em  ![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8686633753239)**  
  
**![Requisi__o_de_desligamento.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/8686666263191)**  
  
Após incluir a solicitação de Desligamento, ela ficará com status **aguardando aprovação do RH.**  
  
**Obs.:** Em relação ao campo **"Gera nova contratação"** este flag é meramente informativo e usado para que o gestor que está desligando o colaborador informe ao RH pela efetivação de solicitação do portal.   
**A informação será apresentada pra o RH conforme exemplo abaixo:**  
  
**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8686813481751)**  
  
Para aprovar/reprovar a solicitação**, acessar o módulo 07 - Gestão de Pessoal - Miscelânea - Portal Protheus - Efetivar Solicitação**  
  
Abaixo segue demonstração para **aprovar** a solicitação de desligamento:  
  
Ao **aprovar** a solicitação, será aberta a tela para o cálculo da **Rescisão**:  
**![Aprovar_requisi__ode_desligamento.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/8686677186327)**  
  
Abaixo segue demonstração para a **reprovar** a solicitação de desligamento:  
**![Reprovar_requisi__o_de_desligamento.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/8686873482775)**  
  
**Principais Campos e Parâmetros:**

|  |  |
| --- | --- |
| **Campo:** | **Descrição:** |
| **Considerar ex-funcionários (RM)** | Flag que considera Ex-funcionários |
| **Colaborador** | Funcionário que vai ser solicitado o seu desligamento |
| **Data do desligamento (RM)** | Data em que o Colaborador vai ser desligado |
| **Tipo do desligamento** | Tipo de desligamento que vai ser realizado na solicitação |
| **Justificativa** | Explicação da solicitação de desligamento |
| **Gera nova contratação** | Flag que gera uma nova contratação |
| **Motivo da demissão (RM)** | Motivo por realizar a demissão do colaborador |
| **Dias de aviso prévio (RM)** | Quantidade de dias de aviso prévio do colaborador |

Importante ressaltar que, quando o funcionário possui estabilidade, o Meu RH não irá bloquear a requisição pelo Gestor, permitindo a inclusão.  
  
No momento do cálculo desta rescisão, o Protheus emitirá um alerta como o abaixo, dando a opção ao usuário prosseguir ou não.
