![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20149202921623) Tempo aproximado para leitura: **00:02:30 min** **Dúvida**Como bloquear a transferencia entre armazens? especificar um armazem para bloqueio na transferencia?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**

O bloqueio no armazem pode ser feito para somente o armazem, ou bloqueio do usuario para movimentar no armazem.

[Cross Segmento - Backoffice (Linha Protheus) - SIGAEST - AGRA045 - Como bloquear armazém para movimentações?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360022132132-MP-SIGAEST-AGRA045-Bloquear-Armaz%C3%A9m-para-movimenta%C3%A7%C3%A3o-?source=search)

Ja para bloquear da forma desejada com movimentos entre armazens, sugiro validar a utilização de um ponto de entrada na rotina de transferencia, onde configure a regra desejada, pois no padrão não tem esse tipo de bloqueio.

[Cross Segmento - Backoffice (Linha Protheus) - SIGAEST - MATA261 - Pontos de Entrada da rotina Transferência Múltipla](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500004779102-Cross-Segmento-Backoffice-Linha-Protheus-SIGAEST-MATA261-Pontos-de-Entrada-da-rotina-Transfer%C3%AAncia-M%C3%BAltipla)

caso não disponha de analista programador para realizar os ajustes, dispomos do serviço do time Hub Plataformas ([hub.plataformas@totvs.com.br](mailto:hub.plataformas@totvs.com.br)).
