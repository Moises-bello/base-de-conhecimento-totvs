|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *Construção e Prohetos* |
| **Módulo:** | *Gestão de Estoque, Compras e Fauramento* |
| **Função:** | *Registrar Orçamento* |
| **Situação/Requisito:** | Ao registrar o orçamento de um produto da cotação, informar um valor para o campo "Valor Despesa"   o sistema calcula o campo "Despesa" corretamente. Posteriormente zerando o "Valor Despesa", o sistema não está zerando o campo "Despesa". Com isso ao salvar a cotação é apresentado   a mensagem "O produto 07.06 do Cli/For C00001 está com o Percentual de despesa menor que   zero ou maior igual a 100". |
| **Solução/Implementação:** | Melhoria ao registrar orçamento na cotação para o campo Valor Despesa |
