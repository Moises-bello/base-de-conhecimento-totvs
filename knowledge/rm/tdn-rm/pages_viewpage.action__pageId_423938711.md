***Atenção!***   
   
Esta funcionalidade só está disponível para as bases já migradas para o Novo Modelo do BackOffice.  
   
Através deste anexo, será possível visualizar as diferenças encontradas entre os valores de Débito e Crédito por lançamentos para o lote selecionado.   
As diferenças de valores entre débitos e créditos são consistidas por lançamento, usuário e filial, respeitando sempre os Parâmetros do TOTVS Gestão Contábil. Se o parâmetro "Permite diferenças entre filiais" estiver desmarcado o controle de diferenças entre débitos e créditos será feito por filial, caso contrário, verificará apenas a diferença entre os valores de débitos e créditos por lançamento, independente das filiais utilizadas. Se o parâmetro "Permite mais de uma diferença" estiver desmarcado será permitido somente uma diferença por usuário.

**Observação**

* Quando houver uma diferença entre os valores de débitos e créditos em um determinado lançamento, este ficará bloqueado com o usuário que originou a diferença e, enquanto estiver bloqueado, somente este usuário poderá dar manutenção neste lançamento.
* Se houver um lançamento bloqueado em um determinado lote não poderão ser executados para este lote os processos de Integração de Lote ou de Agrupamento de Lançamentos.
