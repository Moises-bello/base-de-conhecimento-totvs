**Ocorrência**

Como retroceder data de acesso ao sistema

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.

**Causa**

Estou tentando acessar o sistema com uma data X e o sistema informa: "*O usuário não pode retroceder mais do que X dias"*

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360056946573/mceclip0.png)

Isso ocorre por que o usuário não está configurado para acessar com data retroativa.  
  
**Solução**

Para solucionar no cadastro do usuário, altere as permissões:  
      1. Acesse o cadastro de usuários no Configurador;  
      2. Selecione o usuário e clique em Alterar;  
      3. Vá ate a aba Parametrizações;  
      4. Altere o campo retroceder com a quantidade de dias que o usuário poderá retroceder no sistema;  
      5. Feito isso salve, e acesse o sistema novamente.
