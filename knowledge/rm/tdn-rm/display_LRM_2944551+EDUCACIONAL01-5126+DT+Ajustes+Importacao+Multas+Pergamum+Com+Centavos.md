# IMPORTAÇÃO DE MULTAS GERADAS NO PERGAMUM

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Educacional |
| **Função:** | Importação de multas geradas no Pergamum |
| **Situação/Requisito:** | Foi identificado que na integração com o Pergamum a importação de multas geradas pelo Pergamum não importa corretamente os "centavos" caso a multa possua centavos em seu valor. |
| **Solução/Implementação:** | Foi feito o ajuste para que seja importado corretamente e também um ajuste na base de dados para que o valor seja armazenado corretamente e também gere o lançamento correto. |
