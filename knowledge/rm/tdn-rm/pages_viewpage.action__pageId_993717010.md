# Cadastrar usuário para o fornecedor no Portal

Esta guia tem como objetivo ajudar você, a realizar o cadastro de usuário de fornecedor no portal de maneira simples e eficiente.

Primeiramente é necessário dar a permissão de acesso ao usuário que será o espelho do cadastro do usuário de Fornecedor para a opção abaixo que está dentro das permissões de contrato:

Ao dar permissão para "Gerar usuário de acesso para o portal de medição":

O assistente estará disponível no menu de processos dos contratos do TCOP pois para realizar o cadastro de usuário é necessário que o fornecedor possua contrato vinculado ou que seja participante do contrato.

Ao selecionar o processo acima:

## Campos Obrigatórios

**Usuário de Origem:** Usuário do RM já cadastrado de onde serão copiados os acessos para o Fornecedor.

**Usuário Novo:** Usuário Fornecedor que irá utilizar o Portal.

**Nome:** Nome do Fornecedor.

**Senha:** Composta de Caracteres especiais, letras e maiúsculas e minúsculas e números.

**E-mail:** E-mail do Fornecedor.

Ao carregar a tela do processo conforme imagem acima: 

* O Código do usuário, nome e email podem vir do cadastro do cli/for como sugestão de cadastro.
* Na vinculação de acesso ao perfil, irá listar somente os perfis que tem somente os acessos ao portal de medição.
* Neste cadastro, o vinculo ao projeto se dá na seguinte forma: projeto atual ou todos os projetos que o fornecedor tem contrato.
