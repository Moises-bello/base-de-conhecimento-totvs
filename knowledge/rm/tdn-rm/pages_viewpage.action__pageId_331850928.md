# Retorno de Cobrança

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Retorno Bancário de Cobrança |
| **Situação/Requisito:** | Ao efetuar o retorno de cobrança para determinado arquivo de um banco e na parametrização do retorno é informado outro banco, sistema não está validando quando o retorno é diferente de CNAB240 |
| **Solução/Implementação:** | No retorno de cobrança diferente de CNAB240 será validado se o banco do arquivo de retorno é o mesmo da parametrização do retorno |
