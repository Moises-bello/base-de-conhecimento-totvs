# MOVIMENTO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Movmento por competência* |
| **Situação/Requisito:** | *O sistema sempre preenche a data saída e a data de emissão do movimento com base na data atual do sistema. A prefeitura, a depender do layout que utiliza, considera a competência do movimento como a data de saída. Assim, caso seja necessária geração de uma nota referente a uma competência anterior e a prefeitura aceite, o sistema não suporta, fincando a data de competência do Educacional diferente da data de competência da nota fiscal gerada pela prefeitura.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de movimento de forma que, através de parametrização, as datas de emissão e saída do movimento sejam preenchidas com base na data de competência do movimento.* |
