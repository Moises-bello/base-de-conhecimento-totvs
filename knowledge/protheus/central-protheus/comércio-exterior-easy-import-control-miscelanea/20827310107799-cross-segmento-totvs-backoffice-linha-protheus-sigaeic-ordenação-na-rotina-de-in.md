![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20827338272663) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível ordenar os arquivos na rotina de Integração com o Despachante?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - a partir da versão 12  
  
**Solução**  
Atualmente a ordenação é feita por ordem alfabética do nome do arquivo, porem é possível utilizar o Ponto de Entrada "**CRIA\_INDEX"** para criação de índices, que irão refletir a ordenação da tela mencionada.
