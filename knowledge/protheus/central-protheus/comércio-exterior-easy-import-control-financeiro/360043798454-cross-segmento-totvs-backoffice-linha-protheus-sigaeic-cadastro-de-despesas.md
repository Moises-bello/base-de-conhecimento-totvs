**Dúvida**Como cadastrar Despesas (EICA110)?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**1. Selecione o menu Atualizações\Financeiro\Cadastro despesas.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059038514/mceclip0.png)  
2. Selecione  ![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059921893/mceclip1.png) .

3. Preencha os campos de acordo com o critério de rateio utilizado pelo despachante, se a despesa irá compor o custo do produto e utilize o campo “Tipo” para definir a regra de cálculo da despesa, ou seja, se a despesa é expressa em valor fixo, se terá sempre o mesmo montante, ou será apurada com base em % de outra despesa:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059038794/mceclip2.png)

Importante: Ao cadastrar uma despesa base de ICMS, utilize o botão “ICMS UF” para definir se o ICMS é ou não, base de cálculo em cada um dos estados do território nacional:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059922173/mceclip3.png)

4. Clique sobre o botão ![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360059039194/mceclip4.png) para gravar a alteração.
