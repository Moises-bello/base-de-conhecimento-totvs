**Curso E-Learning**  
    
 Para cadastrar um Curso E-Learning acesse RH | Gestão de Pessoas | Desenvolvimento | Cursos.  
    
 Após cadastrar o curso e clicar em Salvar, o Sistema irá questiona se o usuário deseja incluir um novo requisito de acesso para o curso que está sendo criado.   
 Para Cursos do tipo E-Learning, se o usuário clicar em não nessa confirmação, será exibida a seguinte mensagem:  
 "Após o funcionário finalizar o E-Learning, caso tenha sido aprovado, ele receberá todos os requisitos informados no cadastro do curso."   
 A mesma mensagem citada acima irá ser exibida caso um curso já existente que não seja do tipo E-Learning for alterado para o tipo E-Learning.  
    
 **Observações:**

1. O anexo "Plano de Aulas" esta desabilitado para Cursos do tipo E*-Learning.*
2. Como os cursos E-Learning são Cursos virtuais, as aulas já estão definidas bem como o controle das mesmas.
3. No momento do cadastro o checkbox  E-Learning deve ser marcado para que o Curso seja do tipo E-Learning.
4. Na tela de edição de Cursos se o Curso for E-L*earning*, não será possível desassocia-lo dessa condição. Logo, todo curso definido como E*-Learning* se manterá desse tipo.
