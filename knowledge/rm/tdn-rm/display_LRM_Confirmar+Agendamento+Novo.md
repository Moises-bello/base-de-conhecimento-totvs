painelVisão Geral

## **VISÃO GERAL**

Na etapa "Concluir Agendamento" será exibido um resumo dos dados selecionadas nas etapas anteriores como, dados de cadastro do paciente/usuário e dados do agendamento (procedimento, profissional, unidade de atendimento e data/horário). Após a conferência destas informações, o usuário poderá efetuar o agendamento clicando no botão "Concluir agendamento".

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Logar no Portal do Paciente, abrir a página de "Agendar", concluir as etapas "Dados", "Convênio", "Procedimento" e "Dados Data/Horário" e clicar no botão "Próximo". 

Ao entrar na etapa "Concluir Agendamento", o sistema irá carregar um resumo de todos os dados selecionados nas etapas anteriores. O usuário então deve conferir as informações cadastrais e de procedimentos apresentadas e, caso esteja de acordo, clicar no botão "Concluir Agendamento" para efetuar o agendamento.

Após este processo, caso o agendamento seja efetuado com sucesso, o sistema irá notificar o usuário com o envio de e-mail e exibir opções para:

* Voltar para a página inicial do Portal;
* Visualizar os agendamentos realizados;
* Cadastrar um novo agendamento.
Consulta

## **CONSULTA**

01. Ao abrir a etapa "Podemos confirmar a marcação?", o sistema irá carregar o resumo de todos os dados selecionadas nas etapas anteriores. No caso de agendamento para dependente, o usuário será notificado sobre este agendamento.

02. Após conferir os dados e clicar no botão "Concluir marcação", o sistema irá efetuar o agendamento e notificar o usuário.

03. Se o usuário clicar no botão "Voltar para menu inicial", o sitema irá redirecioná-lo para a página "Home".

Teleconsulta

## **TELECONSULTA**

01. Ao abrir a etapa "Podemos confirmar a marcação?", o sistema irá carregar o resumo de todos os dados selecionadas nas etapas anteriores. No caso de teleconsulta, o endereço será substituído por uma tag informativa.

02. Após conferir os dados e clicar no botão "Concluir marcação", o sistema irá efetuar o agendamento e notificar o usuário. Nessa etapa, os dados de Convênio, Plano, Subplano e Número da carteirinha são validados, e caso os dados sejam inelegíveis ou a carteirinha seja obrigatória para o plano e não informada, o usuário será informado por meio de uma mensagem de erro.  

03. Se o usuário clicar no botão "Visualizar agendamento", o sitema irá redirecioná-lo para a página "Meus agendamentos".

Exame

## **EXAME**

01. Ao abrir a etapa "Podemos confirmar a marcação?", o sistema irá carregar o resumo de todos os dados selecionadas nas etapas anteriores. No caso de exame, o usuário deverá marcar a opção de orientações de preparo para liberar o botão "Concluir marcação".

02. Ao clicar no botão "Visualizar", o sistema irá exibir todas as orientações de preparo cadastradas para o exame selecionado.

03. Ao marcar a opção "Declaro que li as Orientações/Preparo", o sistema irá liberar o botão "Concluir marcação".

04. Após conferir os dados e clicar no botão "Concluir marcação", o sistema irá efetuar o agendamento e notificar o usuário.

05. Se o usuário clicar no botão "Realizar novo agendamento", o sitema irá redirecioná-lo para a etapa inicial do processo de agendamento.

Ao abrir concluir marcação será enviado um email com as informações do agendamento.
