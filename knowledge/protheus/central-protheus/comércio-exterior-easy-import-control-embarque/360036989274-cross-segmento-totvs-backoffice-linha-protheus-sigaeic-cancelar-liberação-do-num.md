![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura:**00:02:00 min****Dúvida**Como realizar o cancelamento da liberação do numerário para excluir a despesa?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049280553/mceclip0.png)  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 12.1.017.  
  
**Solução**1. No módulo SIGAEIC em Atualizações\ Embarque \ Solicit.numerario.

2. Posicione no processo e selecione Manutenção:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049281153/mceclip1.png)

3. Selecione Outras ações \ Cancelar Liberação de Lote:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048389914/mceclip2.png)

4. Selecione outras ações \ Excluir para que seja possível excluir a despesa:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048390154/mceclip3.png)
