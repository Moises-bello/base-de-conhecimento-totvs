# Objetivo

O objetivo deste documento é ensinar como criar as aplicações do RM no Identity.

# Criando a aplicação

Após ingressar no identity, acesse o menu "Ações", "", preencha o campo "" com o nome do aplicativo que deseja criar e clique em .

Observações

 Para poder criar a aplicação é necessário que o usuário possua a permissão de **"Administrador Corporativo".**

Será exibido um menu  com 3 guias, onde serão cadastrados os dados do aplicativo.

#### Guia Overview

Onde serão inserido os dados básicos da aplicação.

#### Guia Entrar

Onde serão preenchido os dados do protocolo de comunicação, e o endereço do servidor que será responsável por responder as requisições de login.

#### Guia Provisionar

Observações:

Para utilizar a integração do RM.exe e Portal RM é necessário criar **uma aplicação para cada sistema**.
