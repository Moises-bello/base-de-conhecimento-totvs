Para acessar as Unidades, ao cadastrar ou editar um Empreendimento, clique em Anexo e depois em Unidade.  
Nesta opção de menu serão inseridas as Unidades dos Empreendimentos que serão usados no cadastro de SubUnidades;

No Menu Opções | Parâmetros | RM SGI | Parâmetros Gerais, será cadastrado o nome da tabela da Unidade que será utilizados no sistema. Utilizaremos como exemplo, o nome Bloco, para a Tabela Unidade.

Através do cadastro é possível controlar:

**Identificação**

Ao cadastrar ou editar uma Unidade, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* **Ref. Empreendimento**: Informe o Empreendimento a ser cadastrado uma Unidade. O sistema apresentará uma lista de opções de Empreendimentos já previamente cadastradas no sistema RM SGI no menu Cadastro | Empreendimentos;

Se este cadastro estiver sendo acessado pelo anexo do cadastro de Empreendimento, o campo Ref. Empreendimento estará desabilitado para edição.

* **Usuário**: É informado o Usuário que efetuou a última alteração do registro. Este campo está inabilitado para edição;
* **Data da Alteração**: É informado a Data da última alteração do registro. Este campo está inabilitado para edição;
* **Unidade**: Informe um nome para a Unidade;

O sistema verificará a quantidade de Unidades disponível no Empreendimento para a criação das Unidades. Se a quantidade de Unidades ultrapassar o número cadastrado no Empreendimento, o sistema não permitirá a inclusão.

* **Área Total (m2)**: Informe a área total em metros quadrados da Unidade;
* **Quantidade de Subunidades**: Informe a quantidade de Subunidades da Unidade;

O sistema verificará a quantidade de Subunidades disponível no Empreendimento para a criação das Subunidades. Se a quantidade de Subunidades ultrapassar o número cadastrado no Empreendimento, o sistema não permitirá a inclusão.

* **Copiar Unidade**: Ao clicar neste ícone, abrirá a janela de [Cópia de Unidade](http://tdn.totvs.com/pages/viewpage.action?pageId=469460972), onde poderemos efetuar a cópia de uma Unidade já existente para uma nova Unidade;
* **Gerar Subunidade**: Ao clicar neste ícone, abrirá a janela de Gerar Subunidade, onde poderemos gerar todas as Subunidades cadastradas na Unidade;
* **Localização**: Neste campo poderá ser informado um texto com o endereço da unidade. Ex.: cada quadra de um loteamento está numa localização diferente;   **Preços:**
* **Tabela de Preço**: O sistema apresentará neste campo, a Tabela de Preço ativa no cadastro do Empreendimento. Não será possível alterar este campo neste cadastro, somente no empreendimento;
* **Preço por m2**: Informe o preço por m2 das Sub-Unidades;
* **Preço Geral para Sub-Unidade**: Informe um preço geral para as Sub-Unidades;

Na geração automática de Sub-Unidades, estas serão geradas com o mesmo preço, podendo ser alterados posteriormente.

* **Valor Total de Sub-Unidade**: Campo calculado pelo sistema através do somatório do valor das Sub-Unidades.
* **Modelo:** Informe o modelo de garantia a ser utilizado por essa unidade. O modelo de Garantia contém todas as coberturas de Problemas residenciais que a unidade garante solução.

**Registradora Recebíveis:** Clique **[aqui](https://tdn.totvs.com/display/LRM/CERC+-+Unidades)** para consultar os campos relativos à esta aba.

**Campos Complementares**

Ao cadastrar ou editar uma Unidade, na pasta Campos Complementares, informe os Campos Complementares cadastrados no sistema.  
O sistema apresentará na janela todos os Campos Complementares já previamente cadastradas no menu Cadastro | Campos Complementares | Unidade.
