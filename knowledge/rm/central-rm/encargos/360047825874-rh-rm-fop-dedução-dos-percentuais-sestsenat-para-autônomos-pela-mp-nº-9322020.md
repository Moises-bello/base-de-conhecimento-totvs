**Dúvida**Como deduzir os percentuais SEST/SENAT para autônomos para atender a Medida Provisória Nº 932/2020?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões

**Solução**Para que o percentual de terceiros seja reduzido na geração da Guia de INSS e Folha Analítica, foi criado, no parametrizador, o campo **Percentual SEST/SENAT**, onde o usuário informa o percentual que deverá ser utilizado no cálculo do SEST/SENAT para autônomos da folha de pagamento. Caso o percentual não seja preenchido, o sistema continuará calculando o percentual de 2,5%.  
  
Acesse **Configurações | Parametrizador | Folha Normal | Encargos Sociais | Campo Percentual SEST/SENAT.** Este campo deve ser preenchido com o percentual desejável para o cálculo dos valores de terceiros para autônomos.
