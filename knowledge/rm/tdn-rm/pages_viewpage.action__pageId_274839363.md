# ANEXO DE VÍNCULOS NO LANÇAMENTO FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Vínculos entre lançamentos financeiros. |
| **Situação/Requisito:** | Não era possível visualizar o valor do vínculo no anexo Vínculos para o lançamento vinculado. |
| **Solução/Implementação:** | Incluído na visão do anexo de Vínculos do lançamento o campo "Valor Vínculo" que irá exibir o valor usado para o vínculo entre os dois lançamentos.  Para o lançamento origem do vínculo o anexo exibe os lançamentos vinculados. Para visualizar o valor do vínculo deve ser verificado o campo específico de acordo com o tipo: Valor Adiantamento, Valor da Nota de Crédito ou Valor de Devolução. Para os demais tipos de vínculos o valor é exibido pelo campo "Valor Vínculo" (que terá o mesmo valor de um dos campos Valor Adiantamento, Valor da Nota de Crédito ou Valor de Devolução). Já para as notas vinculadas esse anexo exibe o(s) lançamento(s) origem do vínculo. Nesse caso o campo com o "Valor Vínculo" exibe o valor usado no vínculo entre os dois lançamentos e o campo "Valor Vinculado" o somatório dos vínculos que o lançamento origem possui. |
