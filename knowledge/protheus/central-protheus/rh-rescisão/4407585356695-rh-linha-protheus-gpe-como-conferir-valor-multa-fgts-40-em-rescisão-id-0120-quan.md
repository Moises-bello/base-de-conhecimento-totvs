![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como conferir valor multa FGTS 40% em rescisão (id 0120), quando o cálculo possui o valor de saldo FGTS id 0118?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O saldo FGTS id 0118 é apresentado através da rotina Manutenção Saldos GPEM360 ou pela inclusão manual em rescisão. A multa FGTS 40% id 0120 é calculada através do valor saldo FGTS mais o FGTS 8% da rescisão referente as verbas com incidência para FGTS.  
  
**Exemplo:**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4407577670935/mceclip1.png)

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4407577699223/mceclip2.png)

Saldo FGTS id 0118: 1.117,48  
FGTS saldo de salário mais aviso id 0119: 172,13  
FGTS 13 salário id 0214: 10,29  
1.117,48 + 172,13 + 10,49 = 1.300,10  
1.300,10 \* 40% = 520,05 id 0120
