## Descrição

```
Alteração de dados funcionais progressivo das requisições e de transferência no processo de conclusão da tela de efetivação de requisições.  
O processo de conclusão de requisições de alteração de dados funcionais e de transferência com alteração de dados funcionais foi alterado para efetivar a próxima alteração de dados funcionais progressivo. Se não houver alteração de dados funcionais progressivo na requisição, o processo continuará seu comportamento normal, concluindo a requisição. 
```

## Procedimento para Utilização

 A próxima alteração de dados funcionais progressivo é a primeira pendente no anexo de alteração de dados funcionais progressivo, que pode ser acessado através da visão de efetivação de requisições **RH / Gestão de Pessoas / Valorização / Efetivações / Efetivar Alteração de Dados Funcionais / Efetivar Transferência c/ Alteração de Dados Funcionais**. No caso de houver apenas uma progressão ou de ser a última, o processo irá efetivar a progressão e também irá concluir a requisição. Caso houver mais de uma progressão, o processo irá efetivar apenas a próxima progressão e não irá concluir a requisição, pois a requisição só pode ser concluída depois de todas as progressões efetivadas.
