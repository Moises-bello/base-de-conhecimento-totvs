# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Contábil |
| **Versões:** | 12.1.17 |
| **Ocorrência:** | Tarefas |
| **Ambiente:** |  |
| **Passo a passo:** | **Definição do processo:**  Tarefa é a denominação dada à solicitação para execução de um determinado serviço, solicitada diretamente nos módulos onde os lançamentos contábeis são originados, para que seja executada dentro do próprio TOTVS Gestão Contábil.  Depois que a contabilização gerada por uma operação que teve origem em outro aplicativo, ou seja, em um módulo externo ao da contabilidade e é integrada ao lote zero, estes lançamentos não podem mais ser excluídos da contabilidade.  Se por algum motivo for necessário que estes lançamentos não sejam mais considerados na contabilidade, eles deverão ser Estornados pelo próprio aplicativo que os originou.  Através desta ação, são incluídos no TOTVS Gestão Contábil os lançamentos de Estorno, que deverão ser integrados também ao lote zero para que um cancele o efeito contábil do outro. Porém, tanto os lançamentos Estornados quanto os de Estorno ficarão registrados na contabilidade, um anulando o efeito contábil do outro.  Temos, contudo disponíveis no sistema alguns tipos de tarefas que permitem a exclusão de alguns lançamentos que tiveram origem em outros aplicativos, como os citados anteriormente.  Hoje o sistema disponibiliza os seguintes Tipos de Tarefas:  **- Exclusão Contabilidade Lote Zero:** Este tipo de tarefa envia uma solicitação ao TOTVS Gestão Contábil para excluir definitivamente da base de dados toda a contabilização gerada por uma operação, ou seja, solicita a exclusão dos lançamentos contábeis originados pela operação contábil, assim como os respectivos lançamentos de estornos desta operação. Desta forma excluirá toda a contabilização vinculada a determinada operação realizada em módulo externo ao da contabilidade.  **- Exclusão de Lançamentos de Estorno e Estornado:** Este tipo de tarefa envia uma solicitação para o TOTVS Gestão Contábil para excluir definitivamente da base de dados somente os lançamentos de estorno e os estornados que estiverem vinculados a determinada operação realizada em módulo externo ao da contabilidade, mantendo, porém, os lançamentos vinculados a esta operação que estiverem ativos.    Vale lembrar que as Tarefas devem ser solicitadas diretamente nos módulos onde os lançamentos contábeis são originados e para isto estes módulos deverão estar devidamente preparados para utilizar estes serviços.    As tarefas solicitadas são enviadas para o TOTVS Gestão Contábil e somente poderão ser realizadas por usuários que tenham permissões para gerenciá-las, podendo executar ou cancelar as tarefas solicitadas.  Tais permissões devem ser incluídas dentro do próprio cadastro do Tipo de Tarefa disponível no TOTVS Gestão.    **Procedimento (Permissão)**  Acesse o menu Utilitários > Permissões > Edite os Tipos de Tarefa e inclua o usuário que terá permissão para cancelar e executar Tarefas.              Somente os usuários associados ao Tipo de Tarefa poderão executar ou cancelar as solicitações agendadas.    **Envio de Email**  Os usuários responsáveis pela execução poderão receber notificações via e-mail quando alguma tarefa for solicitada. Para isto o endereço de e-mail nos cadastros dos usuários deve estar preenchido e as informações para envio de e-mails dentro dos Parâmetros Globais devem estar cadastradas.  Caso o usuário não tenha interesse em receber e-mails de novas tarefas geradas, deve desmarcar a opção 'Receber Email de Solicitações‘ nas permissões das Tarefas, conforme os prints acima.  O usuário solicitante recebe e-mail de confirmação quando a tarefa é executada ou cancelada, independente do parâmetro.  **Procedimento (Executar Tarefa)**  Na visão principal, anterior à esta tela, é possível visualizar o cadastro geral de todas as Tarefas solicitadas nos módulos externos ao da contabilidade, assim como o status de cada uma.        Ao editar uma solicitação de Tarefa ficarão visíveis para consulta todos os dados referentes à solicitação.        Para auxiliar na análise, antes de executar ou cancelar uma solicitação de Tarefa, além de serem mostradas as informações de origem, será possível, através dos respectivos links disponíveis nesta tela, acessar e Visualizar a contabilização e os próprios dados de origem facilitando assim a análise para o gerenciamento.            Somente os usuários com [permissão](http://wikihelp.totvs.com.br/WikiHelp/CTB/CTB.TarefasPermissoes.aspx), ou seja, aqueles que foram incluídos dentro do Tipo de Tarefa, é que poderão executar ou cancelar a solicitação de uma Tarefa.    Acesse o menu Utilitários > Gerenciador > Selecione a Tarefa > Processos > Executar Tarefa.      Nesta tela preencha a ‘Observação da Exclusão’, avance e execute.    Uma vez executada a Tarefa o seu status será atualizado e a contabilização será excluída conforme o Tipo da Tarefa.  Assim que a Tarefa for executada, um e-mail será enviado para o usuário solicitante da Tarefa. |
| **Observações:** | Dúvidas no processo de Solicitação, favor verificar com o aplicativo que originou a partida que se deseja estornar. |
