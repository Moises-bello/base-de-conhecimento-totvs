# **01.** **Visão Geral**

O processo **"Resetar Integrações Identity dos Usuários"** é uma ferramenta exclusiva para **Supervisores**.  O seu objetivo principal é permitir a remoção em lote ou individual de dados relacionados à integração dos usuários com serviços externos de autenticação e sincronização (Identity e OIDC).

Desse modo. ele realiza a limpeza dos seguintes dados:

1. Chave de ligação com o Identity
2. Permissão de login OIDC
3. Configuração do token de segurança (TOTP).

### Restrição de Acesso

* O processo é de uso restrito e **exibido apenas para usuários com perfil de Supervisor de Globais**. Para usuários comuns, a opção deve permanecer oculta ou inacessível no menu.

### Localização no Sistema

* **Caminho:** Serviços Globais→ Visão de Usuários -> Menu **Processos** -> **Resetar Integrações Identity dos Usuários**.

Seleção de registros

Para executar o processo, o ideal é selecionar os usuários desejados marcando a caixa de seleção ao lado de cada nome. Caso você avance sem selecionar nenhum registro, o sistema exibirá o seguinte aviso:

*"Este processo exige que seja selecionado ao menos um registro para sua execução. Como não foi feita nenhuma seleção, você deseja executá-lo para TODOS os X registros?"*

* Se você clicar em **Sim**, o processo será aplicado a **todos** os usuários que estão sendo exibidos na tela.
* Se clicar em **Não**, o processo será cancelado para que você possa fazer a seleção manual.
