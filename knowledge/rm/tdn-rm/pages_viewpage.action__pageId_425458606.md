Nesta etapa do processo será definido as consultas SQL que serão usadas na extração dos dados para o Educacenso. Será informado uma consulta SQL para cada registro.

**Importante**

As consultas SQL estarão disponíveis na pasta ObjetosGerencias dentro do instalador conforme exemplo abaixo: C:\totvs\CorporeRM\ObjetosGerenciais\Consultas SQL  
 Consultas que precisam ser importadas para a base: MEC.2016.00.00, MEC.2016.00.10, MEC.2016.20.00, MEC.2016.30.00, MEC.2016.40.00, MEC.2016.50.00, MEC.2016.51.00, MEC.2016.60.00, MEC.2016.70.00, MEC.2016.80.00).

As consultas necessárias devem ser importadas da seguinte forma: No ato da importação, sugere-se importar para todas as coligadas. Atentar para a aba parâmetros, e clicar em "Fixo", para que o código da consulta SQL fique exatamente com o mesmo nome da consulta importada.
