Dúvida**Como cadastrar Aviso Prévio Trabalhado Individual?  
  
**Ambiente**RM - Folha de Pagamento - A partir da versão 12.1  
  
**Solução**Para cadastrar o **Aviso Prévio Trabalhado**, realize os passos abaixo:  
  
**01.** Acesse **Folha de Pagamento | Administração de Pessoal | Funcionários** e selecione o funcionário. Clique no ícone **Aviso Prévio Trabalhado** para realizar o cadastro individual;  
  
**02.** Será apresentada a tela com os campos para preenchimento;  
  
![Sem_t_tulo.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360020471112)  
  
- Data de demissão previstaA data prevista de demissão poderá ser igual ou superior a data do aviso prévio cadastrado.  
  
- Tipo Redução AvisoSerá habilitado apenas se o tipo de demissão for igual a **2 - Inic. Empregador sem justa causa**.  
  
**03.** Após o cadastro do **Aviso Prévio Trabalhado** a situação dos funcionários selecionados serão alteradas para **V - Aviso Prévio**.
