**Dúvida**Este pedido nao pode ser alterado/excluído pelo módulo de Compras, pois foi emitido pelo módulo Easy Import Control.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
**Solução**A Purchase Order foi lançada no **S****IGAEIC**, para que a mensagem não seja apresentada , a mesma deve ser alterada  na origem do Pedido rotina **EICOPO400**, pelo **SIGACOM** não será permitida a alteração.
