**Dúvida**O que verificar quando o Sistema calcula na Base de INSS o valor dobrado sobre a verba de afastamento, quando o funcionário esta afastado por Auxilio Doença?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoas - Todas as versões  
  
**Solução**Na rotina Tipo de Ausências, Ausência 004 - Auxilio Doença verifique se o campo Encar. Emp. esta preenchido com 1-Cálculo Integral, pois quando preenchido dessa forma, o sistema duplica o valor do afastamento na Base de INSS, para correção, deixe o campo com 2-Cálculo pelos dias pagos:
