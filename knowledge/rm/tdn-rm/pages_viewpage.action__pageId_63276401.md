**PERMISSÃO DE ACESSO SIMULTÂNEO**

           Várias instituições possuem um número considerado de coligadas. A atribuição de acesso a cada uma destas coligadas para cada usuário é trabalhosa e demorada, caso o usuário escolhido terá acesso a todas as coligadas. Este processo atual é feita de forma manual registro por registro. Como realizar esta atribuição de uma melhor forma?

           A partir da versão **11.52.57** disponibilizamos uma opção de contexto que facilitará a atribuição destas permissões. Como realizar?

           Através da nova MDI acesse o segmento **“Serviços Globais”**. Depois que todas as opções de menu deste segmento ficarem a disposição escolha a guia **“Segurança | Acesso | Usuários”**. Selecione no contexto da visão o segmento “Serviços Globais”.

           Selecione um dos registros listados na visão e clique no ícone **“Editar”** . O sistema apresentará o formulário de edição de usuário. Neste formulário clique sobre a guia “Segurança”.

           Na guia você controla e gerencia a permissão de acesso a todas as coligadas, define status de supervisor, permite inclusão de relatórios e seleciona com quais perfis este usuário será associado. Para atribuição simultânea em uma destas permissões, clique com o botão direito sobre a área que demonstra as permissões do usuário.

          O sistema mostrará uma **caixa de contexto** onde é possível atribuir **acesso a todas as coligadas**, **supervisor em todas as coligas** e **permissão para incluir relatórios em todas as coligadas**, assim como o processo inverso de exclusão.

**Mesmo atribuindo permissão a todas as coligadas terei que relacionar o perfil em cada coligada uma por vez?**

**Não!** Para relacionar o mesmo perfil em todas as coligadas, clique com o botão direito sobre a área onde são apresentados os perfis disponíveis.

         O sistema mostrará uma segunda **caixa de contexto** onde será possível associar a este usuário o mesmo perfil em todas as coligadas.

         Com esta ferramenta será **mais fácil atribuir e gerenciar** estas permissões.
