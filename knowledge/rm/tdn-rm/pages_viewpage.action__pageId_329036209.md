# CRIAÇÃO DE ESTRUTURAS DE OFERTAS - INTEGRAÇÃO COM URÂNIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função** | Criação de estrutura de ofertas a partir de turmas/disciplinas |
| **Situação/Requisito:** | Ao executar o processo de criação de estruturas de ofertas, com a segurança estendida ativada, o sistema apresenta uma mensagem de inconsistência e não conclui sua execução. |
| **Solução/Implementação:** | Foi realizado um ajuste para permitir que as consultas utilizadas no processo de criação de ofertas, na integração com o Urânia, utilizassem os filtros da segurança estendida.  A segurança estendida pode ser configurada conforme a documentação: <http://tdn.totvs.com/x/OrkpE> |
