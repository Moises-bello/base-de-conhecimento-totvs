**Dúvida**Como configurar o rateio automático para despesas de acréscimo (Base Imposto) para DI Eletrônica (MV\_TEM\_DI - habilitado)?  
  
**Ambiente**Protheus – Easy Import Control – Todas versões  
  
**Solução**Neste caso, é necessário configurar o parâmetro **MV\_RATACRE**.

Configuração  
Parâmetro **MV\_RATACRE** como **.F.** , não irá ratear automaticamente as despesas de acréscimo.   
  
Parâmetro **MV\_RATACRE** como **.T.**, irá apresentar alerta para rateio automático das despesas de acréscimo:
