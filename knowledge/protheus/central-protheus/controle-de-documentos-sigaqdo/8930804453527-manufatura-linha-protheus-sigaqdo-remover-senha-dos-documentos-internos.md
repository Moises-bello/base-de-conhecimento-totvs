![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**No **SIGAQDO - Controle de Documentos**, como remover senha dos documentos do tipo interno?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**No **SIGAQDO**, para realizar a retirada de senha dos documentos internos, deve ser executada a rotina de remoção de senhas **QDOWIZREMS**. Este processo efetua a remoção de senha de todos os documentos. No link a seguir temos o passo a passo dessa execução: [Remoção de Senha dos Documentos Internos QDO - QDOWIZREMS](https://tdn.totvs.com/pages/releaseview.action?pageId=697726243)  
  
**Saiba mais**  
Também existe possibilidade de **remoção de senha dos documentos internos** implantando a solução de **leitura de documento em PDF**. Para saber mais acesse o artigo: [Manufatura - Linha Protheus - SIGAQDO - Habilitar leitura de documento em PDF](https://totvssuporte.zendesk.com/knowledge/articles/8930709565847/pt-br?brand_id=1509248)
