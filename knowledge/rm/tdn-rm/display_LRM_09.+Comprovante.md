Este step tem como objetivo de exibir o comprovante da matrícula para que o aluno/responsável possa imprimir assim que a rematrícula é efetuada com sucesso.

Para que o comprovante seja exibido é necessário que seja disponibilizado para impressão nos parâmetros.

 **Educacional| Configurações| Parâmetros| RM Portal| Matrícula| Comprovante matrícula 1/2**

No comprovante não será mais utilizado os parâmetros de Assinatura, Cabeçalho e visualização das turmas/disciplinas, para isso foram criadas tags para as informações de Filial, Coligada e Disciplinas.
