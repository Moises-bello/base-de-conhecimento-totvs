# SEFIP 13

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | SEFIP |
| **Situação/Requisito:** | Para funcionárias que tiveram licença maternidade durante o ano e rescisão no mês de Dezembro após o pagamento da segunda parcela, ao gerar a SEFIP 13, não está sendo levado a dedução da Licença Maternidade na SEFIP. |
| **Solução/Implementação:** | Ajuste no SEFIP 13 para quando o funcionário recebeu o 13º e depois foi demitido no mesmo mês. |
