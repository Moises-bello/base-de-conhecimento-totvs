# RESCISÃO ESTAGIÁRIO - TIPO DE DEMISSÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Capacitação e Projeto* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Rescisão estagiário utilizando o tipo de demissão igual a 5 ou 6.* |
| **Situação/Requisito:** | Ao realizar a transferência de um estagiário, não é permitido selecionar o tipo de demissão 5 e 6. |
| **Solução/Implementação:** | Permitido selecionar o tipo de demissão 5 e 6 quando o funcionário for do tipo estagiário. |
| **Chamados relacionados:** | TTJRLM |
| **Versões/Release:** | *12\_1\_8* |
