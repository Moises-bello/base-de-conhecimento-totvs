# Exportação e Atualização de Vinculo do Usuário Pergamum

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | ***Exportação e Atualização dos dados usuário Pergamum.*** |
| **Situação/Requisito:** | *Ao exportar ou atualizar os usuários do Pergamum só era gerado o vínculo para a filial e nível de ensino no qual o usuário estava logado.* |
| **Solução/Implementação:** | *Ao exportar ou atualizar os usuários do Pergamum, o sistema Totvs realiza um procedimento para cadastrar um vínculo para cada filiais e níveis de ensino que contenham o mesmo Pergamum* *parametrizado.* |
