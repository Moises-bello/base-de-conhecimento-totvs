|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |

| **Função:** | *Aviso Automático* |
| **Situação/Requisito:** | Quando há lixo na tabela 'PFAVISO' para alguns funcionários específicos os avisos automáticos não são processados para estes funcionários e os e-mails não são enviados. |
| **Solução/Implementação:** | Ajuste na rotina de Aviso Automático para o tipo Término de contrato para realizar a atualização do registro quando este possui data de envio antigo na base, desta forma o registro sofre atualização e evita que o lixo permaneça na base sem o envio do aviso. |
