A aba **Integração Registradora Recebíveis**, está disponível na de cadastro de Empreendimento.

Ao acessar esta aba, o sistema apresenta os seguintes campos:

**Tipo Registradora:** Esta informação é utilizada para indicar se este Empreendimento está integrado com a [CERC](https://www.cerc.inf.br/) (Central de Recebíveis) ou não. Este campo tem as seguintes opções:

* Nenhuma: Não está integrado à CERC; e
* CERC: Integrado à CERC (Central de Recebíveis).

**Responsável:** É a Pessoa Física que é a responsável por gerir esta integração. Esta Pessoa Física deve estar cadastrada como [Cliente/Fornecedor](https://tdn.totvs.com/pages/viewpage.action?pageId=421388786);

**Tipo de Uso:** É utilizado para informar o Tipo de Uso destinado ao Empreendimento. Para este fim, estão disponíveis as seguintes opções:

* Não Residencial;
* Residencial; ou
* Misto.

**Tipo de Implantação:** É utilizado para informar se o Empreendimento é do Tipo:

* Condomínio; ou
* Aberto

**Tipo de Incorporação:** É utilizado para informar se o Empreendimento é do Tipo de Incorporação, ou não. Sendo disponíveis as seguintes opções:

* Sim; ou
* Não.

**Nro da Averbação/Ônus:** É utilizado para registrar o Número da Averbação do Registro da Incorporação na CERC. Este campo está limitado a 200 caracteres;

**Data do Registro da Incorporação:** Informe a Data do Registro da Incorporação no CERC;

**Patrimônio de Afetação:** Informe se este Empreendimento é do Tipo de Patrimônio de Afetação ou não. Estão disponíveis as seguintes opções:

* Sim; ou
* Não.

**Número da Averbação do Patrimônio de Afetação:** É utilizado para registrar o Número da Averbação do Patrimônio de Afetação do Empreendimento. Este campo está limitado a 200 caracteres;

**Data da Constituição do Patrimônio de Afetação:** Informe a Data da Constituição do Patrimônio de Afetação deste Empreendimento;

**Link do Google Maps:** Caso o Empreendimento esteja disponível em algum site de serviço de pesquisa e visualização de mapas e imagens de satélite, como o [Google Maps](https://www.google.com.br/maps), informe a URL do mesmo. Ao clicar na informação deste campo, o sistema irá direcionar o Usuário para o link informado, abrindo o navegador padrão do Sistema Operacional da máquina de acesso. Este campo está limitado a 2.000 caracteres;

**URL do Site do Empreendimento:** Campo destinado a registrar a URL do site do Empreendimento. Ao clicar na informação deste campo, o sistema irá direcionar o Usuário para o link informado, abrindo o navegador padrão do Sistema Operacional da máquina de acesso. Este campo está limitado a 2.000 caracteres;

Nenhum dos campos acima tem preenchimento obrigatório e todos eles estão disponíveis na Tabela de ***Log do Empreendimento***, para fins de histórico de alterações.
