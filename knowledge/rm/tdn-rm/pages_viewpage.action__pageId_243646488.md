# CANCELAMENTO DE CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Ajuste contábil* |
| **Situação/Requisito:** | *Ao cancelar um contrato e ajustar a contabilização, utilizando o novo modelo, o sistema proporcionaliza o valor cancelado de bolsa entre as bolsas do contrato, conforme o percentual diferido, o que gera valores incorretos na apropriação do cancelamento de bolsa.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de cancelamento de contratos, de forma que o ajuste contábil, no novo modelo, calcule o valor cancelado de cada bolsa no momento de realizar a apropriação do cancelamento ao invés de proporcionalizar.* |
