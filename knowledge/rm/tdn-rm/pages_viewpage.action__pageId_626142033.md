Foram criados provedores de proteção de dados para os cadastros de Filial, Sócios, Contador e Representante, através dele será possível fazer a anonimização dos dados cadastrados a partir do CPF ou CNPJ.

**Filial**

O cadastro de Filial fica localizado em Cadastros | Filiais

Ao ser executado o sistema vai Anonimizar os dados da Filial que possui esse CNPJ.   
  
Dados anonimizados:  
CONTATO, EMAIL, DDD, TELEFONE, DDDFAX, FAX

**Sócio**

O cadastro do Sócio fica localizado na Filial em Anexos | Parâmetros ECF - Escrituração Contábil Fiscal | Anexos | Sócio

Ao ser executado o sistema vai Anonimizar os dados do sócio que possui esse CPF ou CNPJ.   
  
Dados anonimizados:  
CPFCNPJ, NOME, IDPAIS, CPFREPRESENTANTE

**Contador**

O cadastro de Contador fica localizado na Filial em Anexos | Dados Fiscais

O processo de Anonimização vai mascarar os dados do Contador a partir do CPF ou CNPJ.

Dados anonimizados:  
NOMECONTADOR, CPFCONTADOR, TELCONTADOR, CXPOSTALCONTADOR, EMAILCONTADOR, CELULARCONTADOR, TIPOINSCRCONTADOR, UFCRCCONTADOR, CRCCONTADOR, DIGITOCRCCONTADOR, NROLOGRADCONTADOR, UFCONTADOR, CODQUALIFICACAO

**Representante**  
  
O cadastro de Representante fica localizado na Filial em Anexos | Dados Fiscais

O processo de Anonimização vai mascarar os dados do Representante a partir do CPF ou CNPJ.

Dados anonimizados:  
NOMEREPRES, CPFREPRES, NROLOGRADREPRES, CXPOSTALREPRES, TELREPRES, FAXREPRES, CELULARREPRES, EMAILREPRES, CODQUALIFICACAO
