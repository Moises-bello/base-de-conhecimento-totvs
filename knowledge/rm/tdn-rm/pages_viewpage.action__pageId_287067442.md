# Validação da Inadimplência

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Validação da inadiplência do aluno |
| **Situação/Requisito:** | o sistema na matricula ou rematricula on-line (Portal) aplica a validação de inadimplência conforme o vencimento do boleto, ao realizar a matricula ou rematricula pela aplicação (RM.exe) valida a inadimplência pela data de vencimento do lançamento financeiro. |
| **Solução/Implementação:** | Com o objetivo de padronizar as regras de validação de inadimplência foi realizada uma melhoria na validação de inadimplência do aluno para que passe a considerar a data de vencimento do boleto e não mais a data de vencimento do lançamento, este comportamento já era aplicado nas validações realizadas pelo Portal. |
