**Dúvida**Como corrigir o error log ao Incluir Adiantamento no Controle de Câmbio - THREAD ERROR (USUÁRIO, PC-378) 17/06/2016 10:56:39 array out of bounds ( 0 of 0 ) on AP100TRATAPARC(EICAP100.PRW) ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Export Control – Todas versões.  
  
**Solução**

Caso o não utilize a Integração SIGAEIC x SIGAEFF , desabilitar o parâmetro MV\_EIC\_EFF.
