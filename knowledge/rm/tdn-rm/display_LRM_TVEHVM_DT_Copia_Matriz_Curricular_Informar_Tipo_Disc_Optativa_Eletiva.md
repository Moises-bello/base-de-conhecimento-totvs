# Copia de Matriz Curricular

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Copiar Matriz Curricular |
| **Situação/Requisito:** | No processo de cópia de matriz curricular ao adicionar uma nova disciplina ou alterar o período de uma disciplina da matriz curricular não foi disponibilizada a opção de mudar ou selecionar o tipo de disciplina “Eletiva ou Optativa”. Sempre ao adicionar uma nova disciplina o sistema considerava o tipo de disciplina como “obrigatória”. |
| **Solução/Implementação:** | Melhoria no processo de cópia da matriz curricular para que seja possível identificar o tipo da disciplina como optativa ou eletiva ao adicionar uma nova ou modificar uma já adicionada. |
