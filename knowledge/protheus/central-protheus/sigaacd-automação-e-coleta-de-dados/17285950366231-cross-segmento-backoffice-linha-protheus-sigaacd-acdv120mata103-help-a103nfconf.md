Como classificar uma Nota que esteja com divergência física? É possível? Ao tentar classificar esta exibindo o ***HELP A103NFCONF***. Como continuar?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/17286379182103)

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões

**Solução**

No padrão deve avaliar a conferência e revisar os itens divergentes. Mas caso desejar alterar esse padrão nesse cenário pode alterar o parâmetro **MV\_CLACFDV** para **.T.**. No momento da Classificaçção apresenta o HELP informando a divergência com as opções para Sim ou Não para continuar a Classifcação mesmo com divergências. Veja prints com exemplo abaixo:
