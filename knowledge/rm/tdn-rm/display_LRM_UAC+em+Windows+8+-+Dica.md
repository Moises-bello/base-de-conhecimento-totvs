#### UAC em Windows 8

Prezados, a versão do Windows 8 não está homologada para ser utilizada com nossos aplicativos nas versões (11.XX), porém um participante externo nos disponibiliou em nossa comunidade a algum tempo o caminho do registro que deverá ser alterado para que a mensagem abaixo não seja apresentada.:

Primeiro passo: Desabilitar o UAC no Windows:

Em seguida realizar os processos via registros do windows:

"Para desativar o UAC no Windows 8, acesse o registro alterando a key EnableLua para  **0**  **HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Po licies\System** "

**OBS: ESTA INFORMAÇÃO TRATA-SE DE UMA DICA, POIS ESTE SISTEMA OPERACIONAL NÃO ESTÁ HOMOLOGADO PARA UTILIZAÇÃO DE NOSSOS PRODUTOS.**
