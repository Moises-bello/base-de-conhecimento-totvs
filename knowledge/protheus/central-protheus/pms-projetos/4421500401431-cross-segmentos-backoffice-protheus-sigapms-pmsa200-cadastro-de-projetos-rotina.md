Como gerar projeto por rotina automática (Execauto)?

**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGAPMS - A partir da versão 12

**Solução**É possível com a função User Function MyPms200()

Prepare um Array com Cadastro de Projeto conforme as informações na observação, utilizar para opção 3=Incluir, 4=Alterar, 5=Excluir.

**Exemplo e maiores detalhes estão documentados em:  [PMSA200 Cadastro de Projetos - Rotina Automática](https://tdn.totvs.com/x/nAWNAg)**
