**Parecer de Transferência em Lote**

Os pareceres tem como objetivo registrar as alterações realizadas na requisição de transferência em lote. Cada parecer estará sempre vinculado a uma única requisição, porém, uma requisição poderá ter diversos pareceres.

Para acessar o parecer de uma requisição de Transferência em Lote o usuário deverá acessar a requisição desejada, Anexos | Parecer de Transferência em Lote.

**Pasta Identificação do Parecer da Requisição de Transferência em Lote**

Na pasta **Identificação** os seguinte dados devem ser informados:

**Emitido em** - Este campo exibirá a data e hora da emissão do parecer e não poderá ser alterado.

**Status** - Exibirá o status que a requisição assumiu conforme definição do fluxo de aprovação, porém, se a requisição não tiver sido incluída no fluxo, ou seja, quando o controle estiver sendo feito manualmente, este campo poderá ser alterado. Esta alteração será possível apenas no Totvs Gestão de Pessoas.

**Parecer emitido** - Deve conter o texto do parecer emitido pelo usuário.  
**Responsável** - Somente podem ser selecionados chefes da coligada na qual o usuário do Totvs Gestão de Pessoas esteja logado. Para informações relacionadas aos chefes das seções verifique o cadastro de chefes e supervisores.

Filial/Função e E-mail Após preenchimento do campo "Responsável" os dados relacionados a estes campos serão exibidos automaticamente. O campo "Filial/Função" deve exibir o nome da filial seguido do nome da função de lotação do funcionário selecionado no campo "Responsável". A informação do campo "E-mail" deverá ser automaticamente atualizada com o e-mail que constar no cadastro do responsável indicado. Para confirmar esta informação acesse Acompanhamento | Pessoas | Pasta Identificação.

**Pasta Dados da Requisição de Transferência em Lote**

Na pasta **Dados** da requisição podem ser visualizados/alterados os seguintes dados:

**Previsão Exibirá a data prevista na requisição**. Este campo poderá ser alterado ao criar um novo parecer para a requisição.

**Proposta de alteração Filial** - Este campo apresentará a filial proposta para alteração dos dados dos funcionários.

**Seção** - Este campo apresentará a seção proposta para alteração dos dados dos funcionários.

**Motivo da mudança de seção** - Este campo apresentará o motivo da mudança de seção selecionado na requisição e poderá ser alterado ao criar um novo parecer para a requisição.
