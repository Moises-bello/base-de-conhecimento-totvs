# Cadastro Parcela

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Aba "Lançamentos / Boletos " da Parcela |
| **Situação/Requisito:** | Após excluir o boleto de um lançamento gerado pelo educacional, na nova aba "Lançamentos / Boletos da parcela" o lançamento é removido dessa tela após atualizar a mesma, porém quando voltamos na tela da parcela o lançamento continua lá normalmente, mas se editar a parcela novamente e ir na aba "Lançamentos / Boletos da parcela" não consta nada, com isso confundindo o usuário.  OBS: Como foi uma exclusão de boleto, na aba "Lançamentos / Boletos da parcela" não deveria remover o lançamento de lá, pois o mesmo continua registrado no sistema. |
| **Solução/Implementação:** | Ajuste para que no cadastro da parcela seja mostrado na aba “Lançamento” o lançamento mesmo que o boleto tenha sido excluído. |
