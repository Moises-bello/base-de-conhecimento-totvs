## **02. SITUAÇÃO/REQUISITO**

Devido às alterações realizadas pelo INEP no layout do arquivo que é utilizado no envio de informações para o Educacenso em 2019, será necessária uma adaptação do sistema, a fim de atender todas as mudanças propostas.

## **03. SOLUÇÃO**

Cadastro de Instituição do MEC

O cadastro de Instituição do MEC foi alterado para atender as mudanças de leiaute do Censo da Educação Básica 2019

# Cadastro de relação de deficiências do Censo

A tela de relação de deficiências do Censo foi ajustada com as novas definições do leiaute disponibilizado em 2019. Dessa forma, as deficiências: ***Síndrome de Asperger, Síndrome de RETT***e ***Transtorno desintegrativo** **da infância*** foram removidas da caixa de seleção de deficiências do Censo.

Os relacionamentos que foram criados com as deficiências do Censo que foram descontinuados em 2019, serão exibidos em vermelho para a sua exclusão.

## 

# Dados da Turma para o Censo

A tela de dados da turma para o Cento foi ajustada com as novas definições do layout disponibilizado em 2019. Dessa forma,  alguns campos foram removidos e outros incluídos para anteder o novo leiaute.

## 

# Dados do Aluno para o Censo

A tela de cadastro de dados do Censo para o aluno foi ajustada de forma a conter o campos definidos no novo leiaute, alguns campos foram removidos e outros incluídos.

## 

# Dados da Gestor para o Censo

Foi criado o cadastro do gestor para o Censo, que é acessado através do anexo da instituição do MEC. Este cadastro foi necessário para atender no novo leiaute do censo 2019.

# Dados da Matrícula para o Censo

Na tela de cadastro de dados do Censo para a matrícula foi incluso um campo para a informação **"Tipo de atendimento especializado"** que o aluno pode precisar naquele curso.

## 

# Dados do Professor para o Censo

Na tela de cadastro de dados do Censo do professor foi inclusa uma nova aba para definição de informações que serão necessárias para o Censo 2019.

Os campos relacionados à formação/complementação pedagógica serão obtidos da tabela auxiliar de disciplinas do Censo: **SMECDISCIPLINA**,
