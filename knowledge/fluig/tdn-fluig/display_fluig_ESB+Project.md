Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**. 

A perspectiva TOTVS ESB tem como finalidade realizar a montagem e configurações dos diagramas. Através de componentes especializados pode-se configurar o fluxo de mensagens dentro do TOTVS ESB e realizar enviar essas instruções para o servidor ESB.

# Interface

---

Ao abrir a perspectiva TOTVS ESB, tem-se três áreas distintas.

1. O painel à esquerda demonstra uma listagem de projetos cuja finalidade é classificar e organizar os diagramas por finalidades específicas.
2. No painel central tem-se o diagramador que somente é habilitado quando criado/habilitado um diagrama.
3. No painel inferior é visualizado as propriedades dos componentes utilizados no diagramador bem como o log assistido para monitoramento do TOTVS ESB.

Para iniciar um projeto dentro desse ambiente, é necessário alguns passos:

* Acessar o menu principal **File**, item **New** e subitem **New ESB Project**.
* Aparecerá uma janela que conterá os seguintes campos:

| Campo | Descrição |
| --- | --- |
| Project Name | Nome do projeto que deverá ser único. |
| Title | Descrição resumida do projeto. |
| Description | Descrição detalhada do projeto. |

* Após preencher as informações, clicar no botão **Finish**.

Com os procedimentos adotados, aparecerá o novo item na listagem de projetos com o mesmo nome descrito no campo **Project Name**. Por padrão, possui três diretórios: maps, resources e validators. Nesse ambiente é possível realizar duas tarefas:

* [Criar e publicar os diagramas](http://tdn.totvs.com/display/fluig/Diagramas)
