# **Parametrização de Login na Central do candidato**

Para configurar quais serão os dados que o candidato pode escolher para fazer o login basta realizar o passo abaixo. Será possível escolher até 4 tipos de login.

**1-**Acesse o cadastro de Processo seletivo para parametrizar quais serão os dados para login.

 **TOTVS Processo Seletivo| Cadastros| Processo seletivo| Aba Parâmetros| SubAba Informações 1/2**

false

Conforme descrito acima, **SOMENTE** os 4 tipos de login podem ser escolhidos. Portanto, caso o processo seletivo receba estrangeiros, não deve ser marcado somente a opção de CPF.

Escolha também e-mail ou Código de usuário, para que o estrangeiro que não possua CPF, consiga realizar o login corretamente.

**2-**Escolha ao menos 1 forma de login que será disponibilizada no portal.

Aviso

Ao selecionar as formas de identificação "CPF", "Carteira de Identidade" ou "E-mail", esses campos devem estar marcado como visíveis e obrigatórios na subaba "Visibilidade/obrigatoriedade de campos".

**3-**Salve o cadastro e acesse a Central do candidato no portal.
