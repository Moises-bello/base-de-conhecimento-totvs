# Criação de botão para impressão de etiquetas de exames.

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Unidades de Diagnostico | Controle de pedido de exames | |
| **Parâmetro(s):** | Habilitar a parâmetro de perfil "Reemitir Etiqueta". |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | Oracle e Sql |

## Descrição

Foi necessária a criação do botão Reemitir Etiqueta para impressão das etiquetas dos exames liberados, pois era possível emitir as etiquetas somente após a emissão do pedido do exame.

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações da versão 12.1.9.003 do executável do RM Saúde.

## Procedimento para Utilização

1. Acesse o menu **Cadastros / Segurança / Perfis**.
2. Selecione qualquer perfil.
3. Acesse a Aba “**Acesso a menus**” e marque o parâmetro “**Reemitir Etiqueta**”.
4. Vincule um usuário ao perfil configurado.
5. Acesse o Menu **Unidades de Diagnóstico / Controle de pedido de exames**.
6. Localize um exame que já tenha sido liberado.
7. Em seguida, clique em “**Reemitir Etiqueta**”.
