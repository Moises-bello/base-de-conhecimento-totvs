**Dúvida** Qual menu utilizar para criação das rotinas para REINF 2.1?

**Ambiente**Microsiga Protheus - Livros Fiscais - A partir da versão 12.   
  
**Solução**

Para criação do menu referente as novas rotinas do TAF, realizar download e atualizar o arquivo SIGATAF.XNU.

[Menu REINF](http://suporte.totvs.com/totvs-tdi-files-maps/mapeamentos/portal-anexos/anexos/zendesk/20230227/TTVFLGP1J002-1677522775728-827617.zip)

 Para abrir o link, clique com botão direito do mouse > copiar endereço do link e cole em uma nova aba para gerar o DOWNLOAD.
