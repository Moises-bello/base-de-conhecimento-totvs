**Dúvida**  
Como ajustar os valores de retenção de PIS, Cofins e CSLL via ExecAuto,visto que, na baixa a pagar manual, é possível realizar uma baixa e ajustar os valores dos impostos?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA080 - A partir da release 12.1.17  
  
**Solução**  
Atualmente, não é possível realizar a manipulação dos valores de impostos calculados no momento da baixa via rotina automática **(ExecAuto)**. Caso seja uma necessidade, será necessário realizar a abertura de uma solicitação via Central Colaborativa para sugestão de melhoria.
