# Cadastro de atividade agenda

## **Características Requisito**

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Atividades Agenda de Atendimentos | SauAtividadesAction | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server®, Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## **Descrição**

Criação de aba "Procedimentos SUS" no cadastro de atividades da agenda, permitindo a associação de Procedimentos do sus (BPA) com a agenda, semelhante a funcionalidade de adicionar Taxas e Serviços.

## **Utilização**

1) Acesse **Cadastros > Uso Geral > Agendamento > Atividades**

2) Selecione um registro na lista, clique em editar e selecione a aba **Procedimentos SUS**

3) Clique para adicionar um novo procedimento

4) Selecione algum procedimento no filtro

5) Selecione a quantidade desejada

6) Clique em salvar
