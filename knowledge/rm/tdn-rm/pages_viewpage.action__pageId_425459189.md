A geração da referência bibliográfica para publicações do tipo CDROM, Disquete, Documento e FAX seguirão o padrão de referência:

Autor(es). **Título principal**. Nome arquivo. Tipo arquivo. Versão. Edição. Local: Editora, Ano. Volume. Número de páginas. Páginas incial e final. Unidades físicas (Número e descrição). ISBN. Home page.   
  
**Exemplo:**

MICROSOFT Project for Windows 95. Version 4.1. [S.l.]: Microsoft Corporation, 1995. 1 CD-ROM.

UNIVERSIDADE FEDERAL DO PARANÁ. Biblioteca Central. Normas.doc. Curitiba, 1998. 5 disquetes.

ALLIE’S play house. Palo Alto, CA.: MPC/ Opcode Interactive, 1993. 1 CD-ROM.

AVES do Amapá: banco de dados. Disponível em: <<http://www.bdt.org/bdt/avifauna/aves>>. Acesso em: 30 maio 2002.  **Legenda e Localização dos Campos:**

Legenda dos campos da publicação utilizados para geração da referência bibliográfica e localização dos mesmos na tela de configuração de campos da publicação {[14.01 - Controle do Acervo | 14.01.01 - Publicação| Configuração de Campos](http://fwrm-wiki:9999/WikiHelp/BIB/BIB.paramControleAcervo.aspx)}:

+ **Título principal:** Título -> Título principal;
+ **Autor:** Publicação -> Autores;
+ **Nome do arquivo*:***Detalhes específicos -> Nome do arquivo
+ **Tipo do arquivo:** Detalhes específicos -> Tipo de arquivo
+ **Versão:** Detalhes específicos -> Versão
+ **Local:** Publicação / Distribuição -> Local;
+ **Editora:** Publicação / Distribuição -> Editora;
+ **Ano:** Publicação / Distribuição ou Exemplar -> Ano;
+ **Volume:** Exemplar -> Volume;
+ **Número de páginas:** Descrição física ou Exemplar -> Número de páginas;
+ **Páginas inicial e final:** Detalhes específicos -> Página inicial e página final;
+ **Número de unidades físicas \*\*:** Detalhes específicos -> Número de unidades físicas;
+ **Descrição das unidades físicas \*\*:** Detalhes específicos -> Descrição física;
+ **ISBN:** Número normalizado -> ISBN
+ **Home page:** Detalhes específicos -> Endereço eletrônico;

**Obs.:** Texto em Cinza corresponde à localização do campo na tela de parâmetros para configuração de visibilidade e obrigatoriedade.
