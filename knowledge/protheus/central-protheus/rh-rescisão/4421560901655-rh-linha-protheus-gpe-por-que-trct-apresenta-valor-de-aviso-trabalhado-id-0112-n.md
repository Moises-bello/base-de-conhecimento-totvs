![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18530175575063) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que TRCT apresenta valor de aviso trabalhado id 0112 no campo 50?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Pelo layout TRCT Ministério do trabalho não há campo quanto a aviso prévio trabalhado, deste modo como aviso prévio trabalhado se trata do saldo de salário em rescisão, o valor do id 0112 é demonstrado no campo 50.
