# Cancelamento de Baixa com Histórico de Alteração de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | *Cancelamento de baixa* |
| **Situação/Requisito:** | *No cancelamento da baixa via tela de visão de lançamento, o sistema verifica se o item de baixa a ser cancelada é o último de item de baixa com status baixado ou cheque* |

| **Conversores e Parâmetros:** | *Histórico de Alteração de Lançamento habilitado* |
