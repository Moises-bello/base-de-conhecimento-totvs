# MENSAGEM DE NOTIFICAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Mensagem de notificação* |
| **Situação/Requisito:** | *Ao alterar a mensagem de notificação e inserir uma imagem ocorre o seguinte erro "Tag totRM.Edu.Lib.Academico.Central\_de\_Notificacao.EduTAGMensagemNotificacaoItem deve estar toda formatada ou não pode conter formatação." ao clicar em salvar.*  *O erro ocorre para os dois tipos de imagem .png e .jpg.* |
| **Solução/Implementação:** | *Foi corrigido o cadastro de mensagem de notificação para que o sistema não encontre as TAG's dentro do arquivo de imagem para mensagens do tipo HTML, dessa forma ao incluir imagens no corpo da mensagem de notificação o sistema não irá apresentar o erro.* |
