# Ajuste no Formulário Controle de Recebimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Saúde. |
| **Módulo:** | TOTVS Gestão Hospitalar. |
| **Função:** | Controle de Recebimentos. |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar no menu Tesouraria/Controle de Recebimentos, ao selecionar um convênio, unidade de faturamento, ir a aba Recebimento(s), selecionar uma fatura, incluir um recebimento com valor de recebimento a maior e clicar no botão Grava, o sistema não repassava ao TOTVS Gestão Contábil o pagamento como pagamento total, e era exibido como pagamento parcial. |
| **Solução:** | Foram realizados ajustes no sistema, para que ao enviar o pagamento ao Fluxos o sistema identifique o pagamento como total. |
