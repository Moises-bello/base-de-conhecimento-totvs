**Dúvida**  
Os clientes que utilizam o TAF segregado podem fazer a atualização para o release 12.1.2410?

**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Todas as versões

**ATENÇÃO:** Clientes que utilizam o TAF Segregado, não estamos orientando a migração de release para a release 12.1.2410, devendo migrar para a 12.1.2310.

**Solução**

Para os clientes que utilizam o TAF segregado (Módulo 84 somente), ou seja, aqueles que possuem integração com o RM Labore, Datasul Recursos Humanos ou outros, seguem as seguintes orientações:

* O "Instalador/atualizador" para o release 12.1.2310 encontra-se disponível.  
  Para realizar a migração de release da 12.1.033 para a release 12.1.2310, segue o link abaixo:  
  [RH - Linha Protheus - TAF - eSocial - ATUALIZAÇÃO - Como migrar o TAF de release para 12.1.33 utilizando o atualizador? (SEGREGADO)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020127812-RH-Linha-Protheus-TAF-eSocial-ATUALIZA%C3%87%C3%83O-Como-migrar-o-TAF-de-release-da-12-1-33-para-a-release-12-1-2310-utilizando-o-atualizador-SEGREGADO)
