# DIGITAR NOTAS/FALTAS POR ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Digitar nota/falta por aluno* |
| **Situação/Requisito:** | *A mensagem apresentada ao tentar digitar nota/falta para turmas/disciplinas encerradas não é intuitiva, ou seja, não deixa muito clara onde deve ser alterado essa data, pelo fato do início da mensagem começar com a frase “data limite para digitação”, com isso dando a entender que o local para ser alterado é dentro da etapa campo “DT. Limite digitação”.* |
| **Solução/Implementação:** | *Correção da mensagem para avisar quando a data final da turma/disciplina e menor do que a atual para digitação de nota/falta. Agora a mensagem apresentada é a seguinte: Esta Turma/Disciplina já está encerrada para digitação de notas/faltas. A data final para a Turma/Disciplina é ...* |
