**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19251149609751) Tempo aproximado para leitura: 00:01:30 min****Dúvida**O que verificar quando o adicional de Insalubridade não é calculado em folha de pagamento?

**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.

**Solução**

1-  Verificar se no **Cadastro do Funcionário** os campos referente ao Sindicato estão preenchidos

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7398602683159)

2- Ainda no cadastro do funcionário na aba Adicionais verifique se o campo referente a insalubridade esta preenchido de acordo com a necessidade da empresa.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7398630649111)

3- Verificar se no Cadastro do Sindicato aba Peric./Insal se esta preenchido corretamente

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7398963202199)
