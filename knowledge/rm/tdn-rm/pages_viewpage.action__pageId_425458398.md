**Vinculação de Cliente**   
O processo permitir ao atendente incluir registros de novos clientes na sua lista de Clientes não atuados. Ao selecionar a opção, é aberta uma tela para vinculação do novo cliente, com os seguintes campos para preenchimento:  
• Campanha: são exibidas para escolha todas as campanhas ativas no sistema; • Tipo do cliente: são exibidas para escolha todos os tipos de cliente existentes no sistema ( prospect, aluno, pessoa, professor, etc); • Cliente: esse campo permitir a seleção ou a inclusão de novo cliente, de acordo com o tipo selecionado acima. Como o campo Cliente é diretamente vinculado ao Tipo do Cliente, ele deve ser limpo caso o tipo seja alterado. O atendente poderá incluir um novo cliente, ou selecionar um já existente, desde que este já não esteja vinculado à um atendimento de um outro atendente, para a mesma campanha.  
Para que o usuário tenha acesso a funcionalidade, é necessário permissão no Perfil. A permissão está logo abaixo do item 'TOTVS Aprovações e Atendimento -> Meus atendimentos -> Atendimentos -> Operações de Telemarketing'
