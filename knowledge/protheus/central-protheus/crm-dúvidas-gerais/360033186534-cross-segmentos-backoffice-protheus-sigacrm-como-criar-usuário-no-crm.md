**Dúvida**

Como criar um usuário no CRM?

**Ambiente**Cross Segmentos - Backoffice Protheus - SIGACRM - A partir da versão 12.  
  
**Solução**

Siga o procedimento abaixo para criação do usuário:

1 -  Criar um vendedor através da rotina **MATA040.**

Caminho Menu: Atualizações - > Vendedores

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360042519794)

2. Vincular no cadastro de vendedor, o usuário do configurador, através do campo **A3\_CODUSER**.

3.  Incluir através da rotina **CRMA210** - Usuário do CRM. O mesmo usuário informado no campo  **A3\_CODUSER**.

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360042520654)

**Obs: O mesmo procedimento se aplica para criar o usuário no MOBILE CRM.**
