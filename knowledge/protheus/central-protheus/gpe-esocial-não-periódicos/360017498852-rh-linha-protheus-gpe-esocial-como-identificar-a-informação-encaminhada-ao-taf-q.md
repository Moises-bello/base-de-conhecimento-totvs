**Dúvida**  
Como identificar a informação encaminhada ao TAF quando gerados os eventos S-2205 e S-2206?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Para ter acesso às alterações que foram encaminhadas ao **TAF** através da geração dos eventos **S-2205** ou **S-2206** acesse o Cadastro do Trabalhador no **TAF** (Atualizações> Eventos eSocial> Trabalhador> Cadastro Trabalhador), clique em outras ações e **Exibir Histórico de Alterações.**  
  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/28311571269911)**  
  
Também foi disponibilizado um ***XML*** do GPE que é gerado no momento de integração dos dados. Este ***XML*** somente é gerado quando o parâmetro **MV\_XMLGPE** está habilitado, nele é possível verificar as qual evento foi integrado e as *TAGs* **enviadas do GPE** para o **TAF**.  
  
Para maiores informações referente a geração deste ***XML***, verificar *link* abaixo:  
[RH - Linha Protheus - GPE - eSocial - Como definir o local onde é gerado os arquivos XML's de eventos eSocial quando utilizado o parâmetro MV\_XMLGPE](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360035286913-RH-Linha-Protheus-GPE-eSocial-Como-definir-o-local-onde-%C3%A9-gerado-os-arquivos-XML-s-de-eventos-eSocial-quando-utilizado-o-par%C3%A2metro-MV-XMLGPE?source=search)   
  
**Importante**  
O evento S-2205 Alteração de Dados Cadastrais do Trabalhador, registra as alterações de dados cadastrais do trabalhador, tais como: documentação pessoal, endereço, escolaridade, estado civil, contato, etc.   
Para maiores informações, gentileza acessar o *link*:  
[RH - Linha Protheus - GPE - eSocial - S-2205 - Como gerar o evento S-2205 (Alteração de Dados Cadastrais do Trabalhador)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500001336262-RH-Linha-Protheus-GPE-eSocial-S-2205-Como-gerar-o-evento-S-2205-Altera%C3%A7%C3%A3o-de-Dados-Cadastrais-do-Trabalhador-?source=search)  
  
O evento S-2206 Alteração de Contrato de Trabalho registra as alterações do contrato de trabalho, tais como: remuneração e periodicidade de pagamento, duração do contrato, local, cargo ou função, jornada, entre outros. Para maiores informações, poderá acessar o *link*:
