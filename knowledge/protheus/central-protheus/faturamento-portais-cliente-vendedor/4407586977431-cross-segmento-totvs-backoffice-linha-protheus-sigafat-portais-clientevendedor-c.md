**Dúvida** Como criar usuário do Portal.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) -SIGAFAT - Portais (Cliente/Vendedor) - Todas as versões  
  
**Solução**1- Crie o usuário sistema no SIGACFG. Saiba como cadastrar **[AQUI;](https://tdn.totvs.com/x/dPgpE)**  
  
2- Crie o vendedor e informe o usuário do configurador na rotina cadastro de vendedor localizada no módulo Faturamento -> Atualizações -> Cadastro -> Vendedores:

![VENDEDOR.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4407586725655/VENDEDOR.gif)

3- Crie o usuário do portal na rotina cadastro de usuário localizada no módulo Faturamento -> Atualizações -> Portal -> Usuários:  
  
![PORTAL.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4407586811543/PORTAL.gif)

Observação: Faça a inclusão informando o código do usuário sistema, que o vinculo do vendedor é feito automaticamente, apresentando após salvar e visualizar o registro.
