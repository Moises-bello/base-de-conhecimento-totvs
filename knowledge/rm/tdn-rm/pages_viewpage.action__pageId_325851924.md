# Exemplo 1

**Lançamento gerado com os parâmetros de Valor Opcionais habilitados e sendo regerados em seguida com o parâmetro alterado para utilizar o Valor de Integração.**

* Lançamentos que são gerados antes da parametrização do valor de integração , ao se regerar irão manter os valores Opcionais mesmo o sistema estando marcado para utilização do mesmo.

Fin- Vlrs. Opcionais / Integração 1/3 -  Parâmetro marcado para usar o valor Opcional .

Fin – Flrs . Opcionais / Integração 2/3 – Parametro marcado para usar valor Opcional.

Fin – Vlrs. Opcionais / Integração 3/3 – Bolsas utilizadas de Valor Opcinais .

Contrato de Aluno possuindo uma Bolsa Condicional 50% de Desconto ( Valor Opcional ).

Gerando a Parcela 01.

Parcela Gerada e ( alterando o parâmetro para usar Valores de Integração ).

Fin – Vlrs. Opcionais / Integração 1/3 – Alterado para utilizar o Valor de Integração

Fin – Vlrs . Opcinais / Integração 2/3 – Habilitado para utilizer Valor de Integração .

Fin Vlrs.Opcionais/Integração 3/3 – Bolsasa utilizando o Valor de Integração .

Sistema mostra que no dia seguinta serão utilizados os Valores de Integração , pois o Lançamento foi Gerado usando os valores Opcionais no dia 26/12/2017.

Lançamento sendo Regerado no dia 27/12 , na qual o Parâmetro para buscar o Valor de Integração encontra-se Habilitado para novos lançamentos.

Lançamento regerado e Baixando.

Valores Opcionais e não Integração ( Bolsa Valor Opcinal ).

# Exemplo 2

**Gerando uma nova Parcela já com os parâmetros marcados na qual tem que passar a pegar o Valor Integração e não considerar mais os Valores Opcionais.**

Gerando Parcela 2 ( Já com Parametro habilitado )

Lançamento novo já pegando os novos Campos de Valores de Integração

Na parcela 2 com a Bolsa Condicional ( Valor integração )

Baixando o Lançamento

Aba – Saldo dos Valores de Integração

Mostra o desconto da Bolsa Condicional ( Valor de Integração ) e Pagamento a maior e a menor (  Valores de Integração ) Já habilitado.

250 da Bolsa com 100 pagamento pagos a Maior.

Valor na conta corrente do Aluno ( Pago a Maior ) – Valores de Integração.

# Exemplo 3

**Parcela 1 gerada com Parametro de Valor Opcional habilitado e a Baixa sendo efetuada utilizando os Valores Opcionais ( Pagamento a Maior ). Gerando Parcela 2 utilizando já o Valor de Integração e o valor Pago a maior passa para Pagamento a Maior da Integração na qual já encontra-se valendo o novo parâmetro.**

Baixando a Parcela.

Parcela = R$ 1.000,00 Reais

Valor pago a Maior = 500 Reais ( Valor Opcinal )

Bolsa = R$ 100,00 Reais

Total pago = R$ 1.400,00 Reais

Parcela 1 Baixada.

Conta Corrente do Aluno ( R$ 500,00 ) de Crédito.

Gerando Parcela 2 e baixando ( Utilizando já o novo parâmetro – VALOR DE INTEGRAÇÃO )

Baixando Lançamento ( Parcela 2 )

Sistema já desconta o Pagamento a maior feito no Valor Opcional e na Parcela 2 mostra a Aba ( Valores de Integração ).

Os R$ 500 Reais pago a maior na parcela 1 foram transferidos para Des Liquido para o Valor Integração.

Parcela 2 Baixada utilizando os R$ 500,00 Reais no Valor Integração , pagos pelo valor Opcional na Parcela 1 .
