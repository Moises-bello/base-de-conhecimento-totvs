É possível disponibilizar até 6 links úteis na tela de inscrições para o candidato que já está inscrito no processo seletivo. Para parametrizar quais serão os links visíveis para o candidato siga o passo abaixo:

**1º-**Acesse o cadastro de Processo seletivo para parametrizar quais dos links serão visíveis na tela de Inscrições.

 **TOTVS Processo Seletivo| Cadastros| Processo seletivo| Aba Parâmetros| SubAba Geral 3/3**

**2º-**Selecione quais serão os links. Pode-se marcar os 6, como pode não marcar nenhum, salve o cadastro e acesse o portal.
