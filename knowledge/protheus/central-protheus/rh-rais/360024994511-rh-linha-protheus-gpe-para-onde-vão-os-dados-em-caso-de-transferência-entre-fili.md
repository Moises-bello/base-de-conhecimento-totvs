Dúvida** Para onde vão os dados em caso de transferência entre filiais e empresas  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal –  Todas as versões  
  
**Solução**Caso a transferência seja efetuada entre empresa e/ ou filial que tenham o mesmo número de CNPJ será apresentado na rotina Manutenção Arquivo apenas um registro para esse funcionário.  
Caso tenham CNPJ diferentes, serão apresentados dois registros para o mesmo funcionário.
