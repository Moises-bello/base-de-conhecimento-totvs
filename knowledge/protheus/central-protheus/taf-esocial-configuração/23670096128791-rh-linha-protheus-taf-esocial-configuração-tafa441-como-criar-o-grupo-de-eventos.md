**Dúvida**  
Como criar o **Grupo de Eventos** no TAF, para **transmissão automática** eSocial (Schedule)?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Configurações - Schedule - Todas as versões  
  
**Solução**  
Para criar o **Grupo de Eventos**, com os eventos eSocial que deseja realizar a transmissão automática, pelo **Schedule**, siga as orientações abaixo:

1. No TAF, acesse o menu principal:

**Miscelanea>Esocial>Grupo de Eventos**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23670096093207)

2. Selecione o botão superior **"+Incluir" > selecione a filial > selecione o botão "ok"**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23673180110999)

3. Será aberta a rotina **TAFA441**, para configuração do **Grupo de Eventos:**

**ID:**Será preenchido automaticamente pelo sistema

**Código:** Insira um código para o seu Grupo de Evento

**Descrição:**Insira a descrição do grupo

**Grupo "Eventos Relacionados":**Selecione os eventos do eSocial, que serão transmitidos automaticamente pelo Schedule.

Exemplo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23672322136727)

4. Após preencher os campos, selecione o botão **"confirmar"**, para salva o registro.

5. O Grupo de Eventos será utilizado quando realizar a configuração processo **TAFSCHED4,** para o Schedule.

A documentação abaixo explica como configurar o Schedule para transmissão automática dos eventos eSocial

[RH - Linha Protheus - TAF - eSocial - Configuração - Como configurar o TAF para transmitir eventos automaticamente (Schedule) para o eSocial](https://centraldeatendimento.totvs.com/hc/pt-br/articles/23472097356439)
