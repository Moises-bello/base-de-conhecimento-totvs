![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como configurar a exibição do campo Tipo de Currículo na seção Dados do Currículo?  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/5515898131351/mceclip1.png)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Portal do Candidato – Todas as versões  
  
**Solução**Se faz necessário configurar o parâmetro **MV\_BLOQCPC ,** para que possa permitir ao cliente selecionar quais os tipo de currículos **não** poderão ser cadastrados no portal do candidato, ou seja, **não** estarão disponíveis no formulário de currículo para preenchimento. Atualmente as opções disponíveis são :

1- Estagiário  
2- CLT  
3- Concursado  
4- PJ  
5- Aprendiz  
  
Nesse parâmetro poderão estar informados quais os códigos que NÃO deverão ser mostrados para o candidato, exemplo:  
Caso seja informado no parâmetro: "345", apenas os itens 1-Estagiário e 2-CLT estarão disponíveis.  
  
**Importante!**  
Em seu portal caso não apresente o tipo de currículo para ser selecionado, avalie se o campo QG\_TP CURRI conforme documentação [RH - Linha Protheus - PORTAL CANDIDATO - Como definir os campos que serão apresentados no Currículo do Portal Candidato](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057817633-RH-Linha-Protheus-PORTAL-CANDIDATO-Como-definir-os-campos-que-ser%C3%A3o-apresentados-no-Curr%C3%ADculo-do-Portal-Candidato)
