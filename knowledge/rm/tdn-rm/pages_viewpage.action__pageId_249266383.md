# Habilitação da Concessão de Bolsa Futura

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Inclusão de Habilitação da Concessão de Bolsa Futura |
| **Situação/Requisito:** | Ao incluir uma nova Habilitação da Concessão de Bolsa Futura está apresentada uma não conformidade de violação de chave.  Quando o usuário preenche o curso o sistema preenche automaticamente o campo “Habilitação”, “Matriz curricular” e “Turno” o usuário logo em seguida altera o campo “Matriz Curricular” e tentar salvar ai é apresentado a mensagem. |
| **Solução/Implementação:** | Melhoria ao incluir uma nova Habilitação da Concessão de Bolsa Futura para que não seja apresentada não conformidade em relação a violação de chave. |
