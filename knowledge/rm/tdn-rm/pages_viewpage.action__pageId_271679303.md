# HISTÓRICO DE COMPRA DE VALE TRANSPORTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Histórico de Compra de Vale Transporte* |
| **Situação/Requisito:** | *Ao abrir o histórico de compra de vale transporte através do menu executar, se houver funcionários com a mesma chapa em coligadas diferentes, os dados do históricos são misturados na visão pois não há filtro de coligada.* |
| **Solução/Implementação:** | *Foi adicionado um tratamento para filtrar a coligada corrente e foi removida a chamada do histórico do menu executar. O histórico de compra de vale transporte deve ser acessado como os outros históricos, através do menu ANEXOS na visão de funcionários.* |
