**Dúvida**Para que serve o parâmetro **MV\_AGRWFSV**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O parâmetro **MV\_AGRWFSV** - **Servidor HTTP Workflow Utilizado para o Envio de E-mails** é do tipo caracter e está localizado na rotina **OGX017** - **Envio de E-mail**. Permite utilizar o servidor **HTTP Workflow** para o envio de *e-mails.*
