**Vinculação de Requisitos - Pessoa**

A vinculação dos requisitos no cadastro da pessoa tem como objetivo definir quais são os requisitos de acesso que a pessoa possui. O usuário deverá informar, por obrigatoriedade, também a maturidade de graduação que a pessoa possui para a competência vinculada a ela. Essas informações serão utilizadas nos processos do LNT e do Radar de Competências.

**Carga de Requisito -**No portal foi implementado o Processo Carga de Requisitos que permite que um requisito cadastrado no sistema seja solicitado pelo funcionário. A solicitação gera uma requisição de inclusão de requisito de acesso, a mesma pode ser visualizada pelo superior do funcionário que poderá aprovar ou recusar a solicitação.

**Processo de Aprovação -** Após a solicitação do requisito pelo funcionário, seu superior recebe a requisição de inclusão de requisitos de acesso, no menu Equipe / Subordinados é exibido um ícone informando se o subordinado possui requisições pendentes. Para analisar as solicitações pendentes, o superior deverá selecionar o funcionário e acessar o anexo para Aprovação / Reprovação. Os requisitos solicitados são exibidos em uma tela e existe um processo para a Aprovação e outro para a Reprovação das solicitações.

**Requisito Aprovado -** O requisito muda o estado para aprovado e inclui o requisito para o funcionário no anexo de Requisitos de Acesso do Cadastro de Candidatos; Requisito Reprovado: Altera a solicitação salvando o estado como Recusado.

**Observações:**

* No menu Carga de Requisitos são exibidos todos os requisitos de acesso e é informado o status de cada requisito;
* O usuário poderá solicitar os requisitos ainda não solicitados ou recusados;
* Ao acessar um requisito já aprovado ou solicitado, mas pendente de aprovação, o funcionário não poderá solicitar novamente este requisito.
