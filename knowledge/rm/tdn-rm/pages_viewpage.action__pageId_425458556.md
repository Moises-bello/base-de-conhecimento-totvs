Esta funcionalidade permite ao usuário digitar faltas para um ou mais alunos, e essas faltas serem aplicadas em todas as disciplinas do dia informado.

**Acesso a Funcionalidade:** Educacional > Matrícula e Avaliação > Notas e Faltas > Digitação de faltas por dia.  
   
**Executar Funcionalidade:**  
1.     A Tela dispõe de filtros para realizar a aplicação de faltas aos alunos, são eles:

* Curso: O usuário informa um curso, caso necessite;
* Série/Habilitação: O usuário informa uma série/habilitação do curso, caso o "curso" acima esteja informado;
* Turma: O usuário informa uma turma. Para utilizar este filtro, o curso/série **não são** obrigatórios;
* Situação de Matrícula: Situação de matrícula do aluno na disciplina. Sendo:
  + Se o aluno **tiver** resultado final (aprovado, reprovado, etc), este filtro vai considerar a situação final do aluno;
  + Se o aluno **não tiver** resultado final, este filtro vai considerar a situação do aluno na disciplina;
* Aluno: O usuário informa um aluno, através do seu RA ou NOME e adiciona na lista de alunos, caso a "turma" acima esteja informada;

2.     Diferente das outras telas de digitação, esta tela gera listas acumulativas. Ou seja, após selecionar os filtros desejado e clicar no botão [Adicionar alunos], estes serão adicionados um resultado anterior (se houver) de pesquisa.  
3.     Para concluir os alunos devem ser selecionados na lista e as modificações serem salvas pelo usuário.

**É importante ressaltar que não é possível realizar o lançamento de uma falta para uma data futura.**
