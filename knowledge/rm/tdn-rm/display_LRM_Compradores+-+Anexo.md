**Compradores**    
 A partir da versão 11.60 será disponibilizado o Anexo / Compradores na tela de edição de Vendas / Aluguéis. Neste Anexo o usuário deverá informar o(s) Comprador(es) para uma determinada Venda / Aluguel.   
    
 Com isso ocorrerá a remoção do campo Cliente da tela de edição Venda / Aluguel.
