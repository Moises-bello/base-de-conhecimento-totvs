Este processo permite que múltiplos registros de certificados/diplomas tenham suas situações alteradas simultaneamente. O usuário seleciona os diplomas gerados e executa o processo para que todos eles tenham a mesma situação alterada.  
 É possível alterar para as seguintes situações:

* Anulado - Emitido - Não emitido - Não retirado - Cancelado  
   Para entender o significado de cada uma destas situações, acesse a página de [Módulo de Diplomações / Certificações].
