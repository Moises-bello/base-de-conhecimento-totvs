## Descrição

Realiza as validações de pre/co-requisito pós seleção de disciplinas. assim que o usuário tenta avançar a etapa a matrícula realiza as validações pós seleção de disciplinas, caso o parâmetro "Desconsiderar pré/co-requisitos na montagem de sugestão de turmas/disciplinas" que se encontra no caminho Educacional -> Configurações -> Matrícula -> Sugestão de Disciplinas 1/2. Ou caso exista alguma fórmula visual parametrizada para execução "Após selecionar disciplinas na matrícula online" que se encontra no caminho Educacional -> Configurações -> Matrícula -> Fórmulas Visuais.
