# Alterações EFD-Contribuições 2019

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Geração EFD-Contribuições (PIS/COFINS) |
| **Situação/Requisito:** | Alterações do Layout EFD-Contribuições (PIS/COFINS) |
| **Solução/Implementação:** | 1 - Alterada a versão default do Layout para (5.00 - 005) 2 - Alterado o tamanho do campo NUM\_DOC\_IMP do registro C120 de 12 para 15 caracteres 3 - Acrescentada a opção "2 – Declaração Única de Importação" no registro C120 campo COD\_DOC\_IMP  4 - Acrescentado os campos no Registro M210: 5 - VL\_AJUS\_ACRES\_BC\_PIS - Valor do total dos ajustes de Acréscimo  6 - VL\_AJUS\_REDUC\_BC\_PIS - Valor do total dos ajustes de Redução  7 - VL\_BC\_CONT\_AJUS - Valor da Base de Cálculo da Contribuição  5 - Acrescentado os campos no Registro M610: 5 - VL\_AJUS\_ACRES\_BC\_COFINS - Valor do total dos ajustes de Acréscimo  6 - VL\_AJUS\_REDUC\_BC\_COFINS - Valor do total dos ajustes de Redução  7 - VL\_BC\_CONT\_AJUS - Valor da Base de Cálculo da Contribuição  Obs: Os novos campos dos registros M210 e M610 citados acima vão ser gerados em branco, não temos essas informações no sistema.  As novas implementações vão estar disponíveis para geração a partir de 2019. |
