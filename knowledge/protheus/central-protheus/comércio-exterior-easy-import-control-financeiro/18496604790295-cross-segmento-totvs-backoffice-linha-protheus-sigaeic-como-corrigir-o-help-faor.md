![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18496601846167)Tempo aproximado para leitura: **03:00 min** **Dúvida**Como corrigir o Help "FAORIEIC - Esse titulo foi gerado pelo SIGAEIC. Não pode sofrer manutenção"?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Para que o *Help* não seja apresentado, deve ser feita a compensação na origem do processo, rotina de controle de câmbio **"EICAP100"** do **SIGAEIC**.  
  
**Saiba mais:**[Controle de Câmbio - EICAP100](https://tdn.totvs.com/pages/releaseview.action?pageId=306858536)
