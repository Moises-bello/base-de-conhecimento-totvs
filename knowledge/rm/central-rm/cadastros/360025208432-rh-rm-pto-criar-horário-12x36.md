**Dúvida**  
Como criar horários com escala 12x36?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - Todas as versões  
  
**Solução**  
Para solucionar essa dúvida, abaixo segue vídeo de como criar um horário 12x36:

Abaixo segue o  passo a passo do processo:

1.  Selecione a guia **Cadastros,** menu **Horários por Intervalo** clique no incluir:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37648295283223)

2. Ao criar o cadastro do horário insira uma jornada de trabalho e uma jornada de descanso:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/37648319158423)

**Obs.:** A jornada de descanso do índice 2, deverá finalizar as 00:00 no índice 1, permitindo assim que o sistema considere de forma contínua todo o intervalo de descanso.
