# Unidade de Faturamento sem Condição Contratual

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Gestão Hospitalar |
| **Função:** | Faturamento para Convênios |
| **Situação/Requisito:** | Erro ao Criar Remessa para Unidade de Faturamento sem Condição Contratual |
| **Solução/Implementação:** | Incluída validação quando um convênio não possuir condição contratual com a unidade de faturamento selecionada para a criação da remessa.    Dessa forma o sistema não irá permitir que a remessa seja criada e irá avisar o usuário da situação. |
