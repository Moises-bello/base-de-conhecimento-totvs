# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Contabilização por competência |
| **Situação/Requisito:** | Os eventos de aumento e cancelamento não estão parametrizados para buscar o centro de custo do default contábil, porém os eventos, por sua vez, não suportam essa parametrização. Assim o evento de aumento mensal se comporta de forma diferente do evento mensal. |
| **Solução/Implementação:** | Foi realizada evolução dos eventos contábeis de aumento e cancelamento para suportar a parametrização de centro de custo por prioridade, de forma que possa ser possível parametrizar o evento para que o centro de custo seja obtido inicialmente do default contábil. |
