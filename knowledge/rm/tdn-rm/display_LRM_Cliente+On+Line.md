**Cliente On Line**

---

Para que os atendimentos sejam manipulados o usuário deve estar vinculado a um atendente no sistema. Visando atender esta regra, este atendente será utilizado pelos usuários do módulo Cliente On Line. Toda movimentação do cliente no módulo On Line será feito por esse registro.
