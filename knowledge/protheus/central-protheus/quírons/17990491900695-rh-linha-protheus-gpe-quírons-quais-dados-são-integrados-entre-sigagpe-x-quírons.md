![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17990482282775) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Quais dados são integrados entre SIGAGPE x Quírons?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Os dados que poderão ser **integrados do Protheus** para o Quírons, para inclusões/alterações/exclusões, são:  
**>** SQG - Cadastro de Candidatos **>** SRA - Funcionários **>** SR7 - Histórico Funcional/Alterações Salariais **>** SRB - Dependentes **>** SRE - Transferências **>** RA4 - Treinamentos **>** SQB - Departamentos **>** SQ3 - Cargos  
  
  
Existem dados que serão **consumidos diretamente pelo Quírons**, seja com objetivo de **consulta** ou por existir a possibilidade de **integração para o Protheus**, que são:  
**>** SP6 - Tipos de Abono (somente consulta)  
**>** CTT - Centro de Custo (somente consulta)  
**>** SR6 - Turnos de Trabalho (somente consulta)  
**>** SRJ - Funções (somente consulta)  
**>** RCM - Tipos de Ausência (somente consulta)  
**>** RCC - Tipos de Estabilidade (somente consulta)  
**>** RA2 - Tipos de Treinamento (somente consulta)  
**>** SRA - Funcionários (dados de Insalubridade e Periculosidade - alterações)  
**>** RFX - Estabilidade (inclusão, alteração e exclusão)  
**>** RF0 - Marcações de Ponto (inclusão, alteração e exclusão)  
**>** RA2/RA3 - Necessidade de Treinamento (inclusão, alteração e exclusão)
