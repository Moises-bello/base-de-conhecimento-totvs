![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25936816624023) Tempo aproximado para leitura: **00:01:05min** **Dúvida**Como realizar a configuração do Adapter da MATA010 para que seja compatível com a integração do Protheus Datasul  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**Conforme detalhes da equipe do Suporte DATASUL as versões compatíveis para a integração do Cadastro de Produto do lado Datasul seriam as rotas **3.001, 3.008 e 4.006**.

Maiores detalhes sobre a integração [clique aqui.](https://tdn.totvs.com/x/DZJUE)

Porém ao cadastrar essas versões no Adapter da MATA010 dentro do Protheus é apresentado o Help :

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25936833136023)

Avaliando as tag's envolvidas das versões citadas do Datasul, segue as versões do Protheus compatível:

|  |  |
| --- | --- |
| Datasul | Protheus |
| 3.001 | 3.003 |
| 3.008 | 3.007 |
| 4.006 | 4.007 |
