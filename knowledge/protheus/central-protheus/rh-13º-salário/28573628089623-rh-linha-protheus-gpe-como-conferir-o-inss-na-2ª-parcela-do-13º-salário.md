![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28573612002583) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como conferir o INSS na 2ª parcela do 13º Salário?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para o cálculo de INSS, o sistema irá verificar as verbas que estão com **SIM para INSS** (aba incidências no Cadastro de Verbas) e irá efetuar o cálculo obedecendo a **tabela progressiva da Folha (S001).**

-Tabela S001

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28573628065175)

-Cálculo Roteiro 132  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/28573612006807)  
  
No exemplo acima, as verbas 017 e 108 estão com SIM para INSS  
  
**Base INSS:** 1.200,00 + 4.000,00 = **5.200,00 (Verba 709 - ID 0019)**

1ª Faixa = 1.412,00 x 7,50% = 105,90  
2ª Faixa = 2.666,68 – 1.412,00 = 1.254,68 x 9,00% = 112,92  
3ª Faixa = 4.000,03 – 2.666,68 = 1.333,35 x 12,00% = 160,00  
4ª Faixa = 5.200,00 - 4.000,03 = 1.199,97 x 14,00% = 167,99

**INSS Total** = 105,90 + 112,92 + 160,00 + 167,99 = **546,81 (Verba 423 - ID 0070)**
