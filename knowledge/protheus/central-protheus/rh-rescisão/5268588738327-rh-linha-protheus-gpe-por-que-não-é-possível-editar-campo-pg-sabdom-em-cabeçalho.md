![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26681368774039) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Por que não é possível editar campo Pg Sab\Dom em cabeçalho rescisão antes do cálculo?

**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Não é possível editar campo Pg Sab\Dom em cabeçalho rescisão antes do cálculo devido na SRG o campo RG\_SABDOM esta como Visualizar em Propriedade na Base de Dados do Configurador.

Em Propriedade deve estar como Alterar para o campo Pg Sab\Dom ser editado antes do cálculo rescisão:
