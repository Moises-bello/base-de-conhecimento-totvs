|  |  |

| **Linha de Produto:** | *RM* |

| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Área de interesse ofertada - alterar vagas* |
| **Situação/Requisito:** | *Ao tentar alterar o número de vagas para um número menor que o atual em um processo seletivo que não utiliza controle de vagas, o sistema não permite alertando que o número de vagas é menor que os candidatos já inscritos e que devem ser feito cancelamentos de inscrição.* |
| **Solução/Implementação:** | *Foi feito o ajuste para que o sistema identifique se o processo seletivo utilize controle de vagas, pois essa validação só deve ser feita quando o processo seletivo utiliza controle de vagas.* |
