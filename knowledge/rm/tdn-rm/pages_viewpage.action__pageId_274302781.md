# Remover Paciente da Fila de Classificação de Risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de Classificação de Risco |
| **Situação:** | Ao clicar com o botão direito sobre a grid de classificação de risco, de uma linha que não esteja selecionada, o sistema não selecionava a linha, fazendo com que o usuário alterasse o registro que não foi selecionado. |
| **Solução:** | Ajuste no sistema para quando o usuário clicar com o botão direito do mouse sobre qualquer uma das grids da classificação de risco, selecione a linha antes de executar a ação do botão direito. |
