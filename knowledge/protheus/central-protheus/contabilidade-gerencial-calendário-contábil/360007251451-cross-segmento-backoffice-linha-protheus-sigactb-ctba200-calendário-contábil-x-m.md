**Dúvida**

Funcionalidade da rotina CTBA200 - Calendário Contábil x Moeda

**Ambiente**

Cross Segmento - Backoffice Linha Protheus - Contabilidade Gerencial - à partir da versão 11.80.

**Solução**

Para um mesmo calendário, pode haver mais de uma moeda amarrada. Porém, devem ser evitados conflitos entre calendários e moedas, isto é, para uma mesma moeda não deve ser utilizado mais de um calendário com exercício contábil similar.

* No sistema Protheus é exibido a tela abaixo avisando que não pode ser utilizado uma mesma moeda para um mesmo calendário contábil para o mesmo exercício.
