|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Parâmetros educacionais no perfil do usuário |
| **Situação/Requisito:** | É preciso remover o parâmetro "Restringir permissões no cadastro de mensagens", visto que a lógica para tal basta estar no ato de marcar ou não as categorias cujo usuário tem permissão. |
| **Solução/Implementação:** | Nos parâmetros educacionais, acessível pelo perfil do usuário, o controle para acesso às categoria do eduCONNECT será controlado bastando marcando ou desmarcando o check correspondente. Antes esta validação era controlada por um parâmetro situado abaixo desta lista, e não fará mais parte do sistema. |
