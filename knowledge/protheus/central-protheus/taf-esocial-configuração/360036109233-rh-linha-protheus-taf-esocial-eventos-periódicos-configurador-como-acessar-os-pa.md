**Dúvida**Como acessar os parâmetros do sistema no TAF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Todas as versões  
  
**Solução**

1. Para acessar os parâmetros do sistema, siga os passos abaixo:  
  
**a**. Acesse o configurador do sistema conforme documentação "Como acessar o Configurador do TAF": [Como acessar o configurador?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360036108413)  
  
**b.** Retorne a esta documentação após acessar o configurador.

2. No Configurador, vá para a seguinte opção: Ambiente -> Cadastros -> Parâmetros:

![1.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/360047286793)

3. A tela exibirá os valores dos parâmetros, que podem ser visualizados ou alterados conforme necessidade:![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360094459393)
