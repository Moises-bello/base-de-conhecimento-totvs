# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de lançamentos |
| **Situação/Requisito:** | Ao gerar lançamentos com a integração com o protheus ativada, o sistema permite, mediante parametrização, que o sistema gere lançamentos com o tipo "contábil". Com isso há uma degradação de performance e o envio indevido de mensagens de contabilização para o Protheus. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de lançamentos, de forma que todo lançamento financeiro gerado pelo TOTVS Educacional, quando a integração com o Protheus estiver ativa, seja do tipo não contábil. |
