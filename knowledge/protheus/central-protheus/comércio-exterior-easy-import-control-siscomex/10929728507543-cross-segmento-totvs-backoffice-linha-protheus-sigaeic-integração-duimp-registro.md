![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24650923331863) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como efetuar a Integração  DUIMP?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control*- a partir da versão 12.1.27  
  
**Solução**A nova rotina ***Integração DUIMP (EICDU100)*** através do menu :**Atualizações → Portal Único → Integração DUIMP (EICDU100)**.   
Os campos de ***ID*** e ***Sequência*** já serão carregados pelo sistema, onde o **ID** é uma numeração sequencial independente do Embarque e a ***Sequência** é* um sequencial para o mesmo Embarque.  
  
Para realizar a inclusão, basta seguir os passos:

1. Clicar no botão "+Incluir"
2. Informe o campo ***Embarque***, para que o sistema carregue os dados necessários.
3. Clicar no botão "Confirmar" no canto superior direito para salvar os dados.
4. Será apresentado a pergunta: "***Deseja iniciar a integração da DUIMP com o Portal Único*?**"
5. Confirmando, será iniciado a integração da **DUIMP** para o ***Portal Único***.
6. Caso contrário, será finalizado a inclusão com o processo no status "***Pendente de Integração***".
