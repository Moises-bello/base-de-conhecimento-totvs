Dúvida**Como funcionam os componentes de **Frete a paga**r?  
  
**Ambiente**TOTVS Logística - TOTVS TMS (Linha Protheus) - Gestão de Transportes (TMS) - Todas as versões  
  
**Solução**De forma geral, todos os Componentes de Frete existentes no módulo **TMS** estão presentes na rotina **TMSA030 - Componentes de Frete**, onde os Componentes do número 00 até 50 são utilizados para o processo de **Frete a Receber, utilizados no Contrato Cliente** e os Componentes do número 51 até 99 são utilizados para o processo de **Frete a Pagar, utilizados no Contrato Fornecedor**.
