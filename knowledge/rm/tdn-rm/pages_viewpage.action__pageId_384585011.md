# Criar Cartão de Visitante a partir do Registro de Atendimento Externo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Atendimento / Associar Cartão Visitante |
| **Situação/Requisito:** | Ao associar um cartão de visitante a um atendimento externo, não era exibido a opção de criar um novo cartão. |
| **Solução/Implementação:** | Ajustado para quando o RG/CPF do paciente não estiver associado a nenhuma visita anterior, exibir a opção para cadastrar um novo cartão. |
