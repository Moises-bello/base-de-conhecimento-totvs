O artigo explica como criar campos em relatórios Smart View no TOTVS Protheus. Relatórios padrão com "Smartview.Owner" não podem ser alterados diretamente, então é necessário duplicá-los para edição. Após duplicar, renomeie o relatório e personalize-o na etapa de design. Links adicionais oferecem mais informações sobre SmartView.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37481328258199) Tempo aproximado para leitura: **00:01:30 min**  
  
**Dúvida**  
Como criar campo em relatórios Smart View ?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) -Estoque/Custos - Todas as versões.  
  
**Solução**  
Identifique relatórios padrão na coluna "**Proprietário**", os  relatórios com o nome **Smartview.Owner** são os modelos padrão e não podem ser alterados diretamente.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37481314826007)

**Duplicando o relatório Padrão:**

Para permitir edições, é necessário duplicar o relatório:

1. Localize o relatório desejado
2. Clique em "Duplicar" : Isso criará uma cópia editável do relatório.![](https://centraldeatendimento.totvs.com/hc/article_attachments/37481314827031)

**Configurações Básicas:**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37481314828055)

* Renomeie o relatório: Dê um nome personalizado para facilitar a identificação.

  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/37481328262807)
* A etapa de design é onde a customização de relatórios no SmartView fica habilita para edição após a duplicação.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37481328262935)
