Este módulo tem como objetivo o cadastro de integrações dos produtos de RH com produtos externos aos da Totvs que são parceiros. As integrações são feitas por APIs. Hoje este módulo só pode ser utilizado quando se íntegra com a NG.

## Cadastro:

**Código do Parceiro:** Com qual parceiro esta sendo criada a integração.

**Url para o Servidor:** Qual a url base para a chamada das APIs do parceiro.

**Ativo:** Se a integração esta ativa ou não.

**Utiliza para todas as Coligadas:** Se essa integração será utilizada em todas as coligadas.

**Usuário da Aplicação Parceira:** Qual o usuário de autentificação no sistema parceiro.

**Senha:** Senha do usuário.

## Anexo: Entidades Integração

Após o cadastro é necessário o preenchimento das entidades de integração, que estão presentes no anexo. Este anexo já vem com todas as entidades que a integração precisa sendo necessário apenas preencher a url complementar.

**Código da Integração:** Qual integração aquela entidade pertence.

**Entidade:** Qual o nome da entidade de integração. Exemplo: Funcionário, Pessoa, Histórico Funcional.

**Complemento da URL de Acesso:** O complementa da url base para esta entidade específica.

**Testar Conexão:** Ao clicar neste botão será feito um comando de Get validando se a url apresentada está funcional.
