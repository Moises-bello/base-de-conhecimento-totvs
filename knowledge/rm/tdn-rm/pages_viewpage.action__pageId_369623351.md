# Notificações

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Portal MeuRH |
| **Função:** | Notificações |
| **Situação/Requisito:** | Ao acessar o Meu RH com um usuário que tem um perfil vinculado que tem permissão no menu "Meus Dados" e não tem permissão nos menus de férias ou aprovação de abono ocorre a seguinte mensagem de aviso: "Você não está autorizado a utilizar esta funcionalidade do sistema!" Via desktop esta mensagem é pequena e não atrapalha, mas via mobile a mensagem fica ocupando muito espaço na tela. |
| **Solução/Implementação:** | Ajuste realizado na tela inicial do aplicativo MeuRH, para que não seja exibida a mensagem "Você não está autorizado a utilizar esta funcionalidade do sistema!", quando o mesmo não possuir autorização aos recursos inclusos na notificação . |
