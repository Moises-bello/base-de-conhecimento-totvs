![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18848686487703) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**O arquivo seguro desemprego gera informação campo código da dispensa?

**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Conforme layout arquivo seguro desemprego não consta esse campo, assim o mesmo não é gerado em arquivo TXT (pela rotina GPEM090).

Essa informação é preenchida no posto de atendimento seguro desemprego.
