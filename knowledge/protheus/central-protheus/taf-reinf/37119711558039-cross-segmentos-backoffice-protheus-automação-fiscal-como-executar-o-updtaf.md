**Dúvida**  
Como executar o UPDTAF?

**Ambiente:**  
Cross Segmento - TOTVS BackOffice (Linha Protheus) - Configuração - Todas as versões

**Procedimento:**  
Para realizar este processo acesse o ambiente como UPDTAF.

![print1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37119711532567)

Ao abrir o UPDTAF, deve selecionar a release que deseja e a(s) empresa(s) que devem realizar o processo.

![print2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37119711532823)

Após isso, clique em processar e avance para a seguinte tela, onde o UPDTAF irá fazer compatibilizações necessárias no dicionario de dados para o Protheus (**não necessariamente apenas o parâmetro abaixo**).

![print3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37119678438679)

Posteriormente, clique em ''Finalizar'' que o processo do UPDTAF estará concluído.

**IMPORTANTE: É NECESSÁRIO QUE O PROCESSO EXECUTADO SEJA FEITO COM AMBIENTE DE MANEIRA EXCLUSIVA (SEM NENHUM USUÁRIO LOGADO NO AMBIENTE).**
