# REPROGRAMAÇÃO SALARIAL - FOLHA EDUCACIONAL (TOTVS FOLHA DE PAGAMENTO)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Reprogramação salarial - folha educacional (TOTVS Folha de Pagamento)* |
| **Situação/Requisito:** | *Na folha de pagamento um funcionário foi demitido, após um tempo o mesmo funcionário volta a ser admitido. Quando vamos no contexto do educacional professor e tentamos alterar chapa do professor pois a outra se encontra como demitido a mesma não tem a opção de selecionar outra chapa, vamos em anexo filiais do professor e desmarcamos o checkbox ativo e adicionamos a nova chapa desse professor após ser feito isso realizamos o processo de reprogramação salarial, porém ocorre um incidente com o aviso nenhum funcionário teve seus valores modificados. ERRO APRESENTADO: Nenhum funcionário teve seus valores modificados.* |
| **Solução/Implementação:** | **Tratamento no serviço fornecido pelo TOTVS Educacional para o TOTVS Folha de Pagamento, para que seja considerado as chapas das filiais do professor, no processo de Reprogramação Salarial, para professores em turmas/disciplinas, atividades complementares e atividades extras.** |
