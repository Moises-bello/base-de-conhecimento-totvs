**Dúvida**Existe alguma função que realize a leitura de um código de barras dentro de um arquivo, ou algo semelhante?  
 **Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Hoje não existe função disponível para realizar esse procedimento, pois depende de um periférico(equipamento para leitura). para obter uma sequencia de numero em um arquivo, é necessário utilizar funções de manipulação de arquivos
