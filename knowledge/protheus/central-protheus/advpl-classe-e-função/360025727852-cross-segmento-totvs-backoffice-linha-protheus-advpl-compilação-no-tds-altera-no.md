Dúvida**Após compilar alguns programas o Developer Studio alterou o nome do RPO... mudou para TTCP120.RPO..   
Como faço para mudar esse parâmetro para que não altera mais o nome do RPO ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Clique com o botão direito no servidor que deseja editar

![Screenshot_47.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360025060612/Screenshot_47.png)

Na aba **AMBIENTE** verifique a opção de Banco de Dados Principal, la nós escolhemos qual o tipo... DBF, CTREE, TOP... e dependendo qual você escolhe ele muda o nome do RPO. ![NOME_DO_RPO.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/360025074631/NOME_DO_RPO.jpg)
