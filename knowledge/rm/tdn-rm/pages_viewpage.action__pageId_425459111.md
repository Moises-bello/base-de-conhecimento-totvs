Ao gerar o lançamento das parcelas para o financeiro, serão gerados também automaticamente os respectivos boletos para cobrança bancária.

Para visualizá-los acesse o menu **Financeiro/Contábil | Contratos | Boletos**.

Esta janela permite consultar os dados dos boletos e seus respectivos lançamentos.

Os lançamentos podem ser gerados individualmente a partir da tela do contrato, onde para cada lançamento gerado será gerado automaticamente um boleto bancário correspondente.

Para fazer a geração de lançamentos em lote deve-se utilizar o processo 'Gerar lançamentos', disponível no menu **Financeiro/Contábil | Geração | Financeiro | Gerar lançamentos**, onde existe a possibilidade de agrupar os lançamentos gerados, conforme parametrização definida, em um único boleto bancário.

Caso seja necessário, após a geração dos boletos você poderá alterar a data de vencimento dos boletos e/ou lançamentos e se desejar, poderá também mandar imprimi-los.

O sistema pode ser parametrizado para que os alunos possam visualizar e imprimir os boletos bancários através do Portal do Aluno.
