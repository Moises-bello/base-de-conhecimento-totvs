**Dúvida**

Como incluir Atendimento Telecobrança com situação Cobrança Simples ?

**Ambiente**

Cross Segmentos - TOTVS Backoffice (Linha Protheus) - SIGATMK - Todas as Versões

**Solução**

Para atendimento com Cobrança Simples, é necessário seguir os procedimentos abaixo:

1. É necessário possuir títulos vencidos;

2. Gerar borderô, e alterar a situação =1"Simples";

3. Realizar a Geração da seleção de títulos. Esta rotina permite realizar uma pesquisa dos títulos a receber do ambiente financeiro (SE1), para que seja gerada uma base de dados (SK1), com todos os títulos vencidos e não pagos, disponibilizando-os para cobrança dos operadores. O objetivo é gerar uma base de pesquisa rápida de títulos, e apenas os campos chaves do título são criados no SK1;

4. Incluir Atendimento Telecobrança;
