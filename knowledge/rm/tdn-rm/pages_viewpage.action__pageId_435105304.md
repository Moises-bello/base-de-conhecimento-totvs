Um imóvel pode ter mais de uma inscrição municipal conforme avaliação da prefeitura municipal em virtude do layout arquitetônico da instalação. Em algumas cidades, por exemplo, edifícios com garagens comerciais, cada vaga pode receber um número diferente de inscrição municipal.  
A quantidade de inscrições municipais impactará na quantidade de guias de IPTU que serão geradas, impactando em processos futuros.  
Para atender essa necessidade, dispõe de um cadastro para vincular imóveis e inscrições municipais. Este cadastro está localizado em menu **Aluguel / Imóvel / Anexo de Inscrição Municipal**.  
**Campos mostrados na tela:**

**Figura 1 - Tela de cadastro da inscrição municipal**

**Definição dos campos:**

* **Id Inscrição:** Campo que mostra o código identificador da inscrição municipal que está sendo cadastrada. Este campo não permite edição, é preenchido pelo sistema;
* **Imóvel**: Mostra o Imóvel cuja Inscrição Municipal está associada. É possível acessar o cadastro de imóvel diretamente clicando no link em azul;
* **Cód. Inscrição Municipal:** Código da Inscrição Municipal do imóvel que é informado pelo usuário;
* **Descrição:** Neste campo é possível informar uma descrição para a inscrição municipal para poder identificar a motivação desta inscrição
* **Tipo de despesa**: Neste campo é possível associar um tipo de despesa à inscrição, facilitando também a identificação de cada inscrição
* **Área do terreno:** Neste campo é possível informar a área do terreno relativa a inscrição municipal cadastrada;
* **Área construída:** Neste campo é possível informar a área construída relativa a inscrição municipal cadastrada;
* **Valor venal:** Neste campo é possível informar o valor venal relativo a inscrição municipal cadastrada.

É possível cadastrar uma ou mais inscrições municipais por imóvel.
