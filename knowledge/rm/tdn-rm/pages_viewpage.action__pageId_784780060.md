Importante

Disponível a partir da versão **12.1.2302**prevista para fevereiro de 2023

Esta tela apresenta as Últimas Aquisições de Exemplares realizadas pela unidade bibliotecária.

Ao acessar a tela é possível visualizar os exemplares adquiridos e realizar buscas utilizando filtros para achar exemplares específicos.

Abaixo segue imagem dos filtros disponíveis

Configurações necessárias para o funcionamento da tela

Para que a listagem de exemplares apareça no portal é necessário realizar as seguintes configurações:

* Parametrizar o número de dias a ser verificado as últimas aquisições no portal;

**Caminho: Parâmetros > Parâmetros do sistema > Controle do acervo > Publicação**

* Cadastrar os exemplares desejados;

* Informar no cadastro dos exemplares a **data de compra** do mesmo. Isso é muito importante, pois o parâmetro de número de dias a ser verificado as últimas aquisições no portal olha para esta data.

* Para informar que um exemplar está disponível para empréstimo basta seguir o caminho indicado abaixo e marcar o campo **Permite empréstimo**.
