Em determinados casos, você precisa registrar um cheque em uma conta/caixa, mas ainda não sabe qual será a conta/caixa definitiva.   Com o processo de transferência de cheque, é possível registrar um cheque em uma determinada conta/caixa e posteriormente transferi-lo para outra conta/caixa.  
 A transferência de cheque é realizada através do processo "Transferir Cheque" do cadastro de Extrato de Caixa.

**Observação**

A transferência só é permitida para registros NÃO compensados.  
 É possível realizar a transferência de vários cheques ao mesmo tempo.  
 A transferência só é permitida para registros com "Recebimento Via Cheque".  
 Quando o cheque estiver cancelado, sua transferência para outra conta/caixa não será permitida.

Passo a Passo

* Selecione o registro de extrato de caixa que será transferido e abra o processo "Transferir Cheque";
* É apresentado o "Assistente para Transferência de Cheque";
* Informe ou selecione a Conta/Caixa para qual o cheque será transferido e conclua o processo.

Após a confirmação da transferência, os saldos das Contas/Caixa envolvidas serão atualizados.
