# Alterar nome menu RM Portal

|  |  |
| --- | --- |
| **Produto:** | RM |
| **Versões:** | 12.1.16 ou Superiores |
| **Ocorrência:** | Alterar nome menu RM Portal |
| **Ambiente:** | RM Portal |
| **Passo a passo:** | Introdução Neste módulo iremos mostrar procedimento para alterar nome dos menus no Portal.    **1 -** Alterar Nome.  **1.1 -** Através da MDI acessar o contesto “Gestão de Conteúdo”    **1.2 -**  Acessar o menu “Menu Portal"    **1.3 -** Através do menu aberto adicionar um novo registro      Através da tela é possível alterar o nome dos menus.  **2 -** No Exemplo abaixo iremos realizar alteração nos menus do módulo “RMLabore”  **2.1 -** Adicionar novo registro na opção “Identificador do Menu Pai”    Iremos selecionar o menu “Identificação” dentro de ‘Dados Cadastrais’    Após selecionar basta alterar o campo “Caption” para nome desejado          **2.2 –** Salvar registro      **3 –** Aplicação no portal  Com registro salvo basta atualizar a página do portal para que menu troque de ordem.  Antes do registro salvo    Depois do Registro Salvo |
