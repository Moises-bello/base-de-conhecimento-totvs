**Stored Procedure**

---

Stored Procedure ou Procedimento Armazenado é uma biblioteca de comandos em SQL para utilização junto ao banco de dados. Ela armazena tarefas repetitivas, aceita parâmetros de entrada e retorna um valor de status (para indicar aceitação ou falha na execução).

Uma stored procedure pode reduzir o tráfego na rede, melhorar o desempenho de um banco de dados, criar tarefas agendadas, diminuir riscos através de mecanismos de segurança entre a manipulação dos dados do banco.

Uma situação onde se utiliza as procedures é quando existem várias aplicações desenvolvidas em diferentes linguagens, ou que rodem em plataformas diferentes, porém executam a mesma função.
