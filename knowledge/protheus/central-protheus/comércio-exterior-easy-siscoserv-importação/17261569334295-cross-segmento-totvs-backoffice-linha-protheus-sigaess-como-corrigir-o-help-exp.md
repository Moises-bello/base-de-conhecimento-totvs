![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17261575918871) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como corrigir o "**Help Exp. Invoice -** Só é permitido utilizar fornecedor estrangeiro para importação de serviço"?  
  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/17261843853847)**

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Siscoserv* – A partir da versão 12.1.33  
  
**Solução**Para que a mensagem não seja apresentada, deve ser verificado o cadastro do Fornecedor, campos "**A2\_ESTADO -** Estado" e "**A2\_TIPO -** Tipo".

Para a devida correção, realize os procedimentos abaixo: 1. Acessar o módulo **SIGAEIC** em Atualizações \ Cadastros \ Fabricante/Forn.;​  
2. Posicione no fornecedor utilizado e selecione o Alterar;  
3. Na aba Cadastrais preencha o campo "Estado - **A2\_ESTADO (EX)"** e o campo "Tipo - **A2\_TIPO (X-Outros)".**  
4. Selecione Confirmar, após efetue o procedimento novamente.
