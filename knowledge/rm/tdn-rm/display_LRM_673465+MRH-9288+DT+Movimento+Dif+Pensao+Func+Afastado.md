# DIFERENÇA DE PENSÃO GRAVADA NO MOVIMENTO DO DEPENDENTE DE FUNCIONÁRIO AFASTADO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Pensão Alimentícia |
| **Situação/Requisito:** | No cálculo da diferença de pensão alimentícia de vários meses retroativos, quando o funcionário ficou o mês todo afastado, na movimentação de pensão do dependente está gravando o valor de diferença do mês anterior. |
| **Solução/Implementação:** | Ajuste na diferença salarial para não gravar valores incorretos de movimento de pensão em meses que o funcionário ficou afastado. |
| **Tickets relacionados:** | MRH-9288 |
