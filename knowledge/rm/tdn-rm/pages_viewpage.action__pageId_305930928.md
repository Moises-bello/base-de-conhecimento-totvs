# Ajuste no Formulário de Mudança de Categoria do Paciente

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Saúde. |
| **Módulo:** | TOTVS Gestão Hospitalar. |
| **Função:** | Mudança da Categoria do Paciente. |
| **Situação:** | Em Mudança da Categoria do Paciente, ao inserir um paciente que possua um item em um convênio especifico e que, este mesmo item não exista no convênio a ser transferido, o sistema não exibia a informação de que este item a ser transferido, não existe no novo convênio. |
| **Solução:** | Realizado o ajuste no formulário para que o item cadastrado na conta do paciente, que não existe no novo convênio, seja, devidamente informado para o usuário após finalizar o processo de Mudança de Categoria. |
