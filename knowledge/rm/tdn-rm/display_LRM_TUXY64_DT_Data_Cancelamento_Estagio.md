# TERMO DE COMPROMISSO ESTÁGIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Cancelamento do termo de compromisso do estágio* |
| **Situação/Requisito:** | *A data de cancelamento não era editável, sempre que cancelava um contrato o sistema atribuía a data atual como a data do cancelamento.* |
| **Solução/Implementação:** | Ajuste no termo de compromisso do estágio, habilitando o campo "Data de cancelamento" quando o status do contrato for Cancelado. Possibilitando que o usuário escolha a data de cancelamento, se o mesmo deixar em branco será salvo no banco a data atual. |
