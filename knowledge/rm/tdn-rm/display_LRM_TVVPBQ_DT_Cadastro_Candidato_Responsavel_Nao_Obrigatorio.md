# CADASTRO DE CANDIDATOS - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Cadastro de candidatos - portal* |
| **Situação/Requisito:** | *Ao cadastrar um candidato pelo portal, se estiver marcado a opção que obriga o preenchimento dos dados do responsável, o sistema permite que o após o cadastro do candidato, o mesmo cancele o cadastro do responsável e acesse diretamente pela tela de logon do portal do processo seletivo a opção de inscrição sem cadastrar o responsável, permitindo a inscrição sem o responsável obrigatório.* |
| **Solução/Implementação:** | *Foi feito o ajuste na validação dos responsáveis, assim, caso um responsável obrigatório não tenha sido cadastrado, ao tentar realizar a inscrição o sistema irá alertar sobre a obrigatoriedade e só permitirá a inscrição após o cadastro do responsável.* |
