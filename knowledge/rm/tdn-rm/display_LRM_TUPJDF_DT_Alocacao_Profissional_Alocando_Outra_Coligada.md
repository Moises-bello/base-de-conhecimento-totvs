# ALOCAÇÃO DE PROFISSIONAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Alocação de profissionais* |
| **Situação/Requisito:** | *Ao utilizar a alocação de profissionais em locais de prova e selecionar a opção de seleção de profissionais de outras filiais, o sistema carrega funcionários também de outras coligadas.* |
| **Solução/Implementação:** | *Foi identificado que a validação da coligada só era feita quando não era selecionado a opção para selecionar profissionais de outras filiais, sendo assim foi adicionado uma validação da coligada e a alocação passou a ser feita corretamente, somente pelos profissionais da coligada do processo seletivo.* |
