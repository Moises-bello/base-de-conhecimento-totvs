# CADASTRO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Férias* |
| **Situação/Requisito:** | *Ao realizar o cálculo das férias, a tela de execução de processo “trava” após a conclusão, impedindo o usuário de manipular o sistema por alguns segundos.* |
| **Solução/Implementação:** | *O motivo que causa a trava é que o sistema sempre recarrega os dados do cadastro de férias após a conclusão do processo. Foram feitas algumas melhorias ao carregar os dados das férias para reduzir esse tempo que o usuário aguarda.* |
