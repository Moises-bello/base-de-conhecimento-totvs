![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26904731553815) Tempo aproximado para leitura: **00:10:00 min** **Dúvida**É possível demonstrar no Portal do Cliente, somente os títulos, que foram gerados boletos via API FINA713 ou RDMAKE - Customizado?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - A partir do versão 12.1.2310  
  
**Solução**Para aplicar um filtro na visualização dos títulos, se faz necessário aplicar o ponto de entrada **PCTITQRY - Query personalizada para listagem de títulos.**
