![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Gostaria de saber se esta sendo criado uma tratativa no SIGAEIC para essa mudança no Siscomex de retificação de DI em caso de acréscimo?

[Retificação em caso de acréscimo](https://www.gov.br/receitafederal/pt-br/assuntos/aduana-e-comercio-exterior/manuais/despacho-de-importacao/importacao-de-graneis/procedimentos-gerais/retificacao-da-declaracao-de-importacao-de-granel-nos-casos-de-acrescimo-ou-extravio-de-mercadoria-1/retificacao-em-caso-de-acrescimo)  
  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – Easy Import Control – Todas versões  
  
  
**Solução**Atualmente a integração para retificação, tanto da **DI**, Não está no escopo do produto.

Há algum tempo atrás tivemos uma nova funcionalidade implementada para permitir que seja incluído  no sistema um processo relacionado a uma retificação de **DI** que foi feita no **Siscomex**. Porém esta documentação refere-se apenas à possibilidade de inclusão manual de um novo processo, utilizando o mesmo número da **DI** com versão diferente, de modo a ter no sistema o histórico  da operação realizada pelo importador no **Siscomex**.
