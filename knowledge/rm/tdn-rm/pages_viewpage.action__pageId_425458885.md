Com as atividades da bolsa do aluno e de concessão de bolsa futura, o cliente irá conseguir personalizar o sistema com regras de negócio de acordo com sua necessidade, ele poderá criar uma fórmula visual para incluir, excluir, alterar, cancelar uma bolsa do aluno e/ou incluir, excluir, alterar uma bolsa futura.

Fórmulas visuais

Para mais informações sobre fórmulas visuais acesse o a documentação: [Fórmula Visual - RM](https://tdn.totvs.com/pages/viewpage.action?pageId=403746948)

Acompanhe o procedimento necessário para a configuração deste processo.

1. ****Criando uma fórmula visual para Incluir ou Alterar uma Bolsa de Aluno:****Acesse: Gestão| Fórmula Visual| Fórmula Visual | Adicione uma nova fórmula visual |Adicione a atividade "Incluir ou Alterar uma Bolsa de Aluno" na fórmula visual.

   1
   incomplete
   **Incluindo uma Bolsa de Aluno:**
   * Preencha todos os campos necessários para a inclusão da bolsa do aluno, caso a bolsa preenchida já exista na base de dados, será feita uma atualização do mesmo, se não existir será realizada a inclusão.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a execução tenha ocorrido com sucesso a bolsa do aluno será incluída.

   2
   incomplete
   **Alterando uma Bolsa de Aluno.**
   * Preencha todos os campos, caso a bolsa preenchida já exista na base de dados, será feita a atualização do mesmo, se não será realizada uma inclusão.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a bolsa informada exista, e a execução tenha ocorrido com sucesso, a bolsa do aluno será atualizada.
2. ****Criando uma fórmula visual para Excluir uma Bolsa de Aluno.****

   Acesse: Gestão| Fórmula Visual| Fórmula Visual | Adicione uma nova fórmula visual |Adicione a atividade "Excluir Bolsa Aluno" na fórmula visual.

   * Preencha todos os campos necessários para a exclusão da bolsa do aluno.
   * Após o preenchimento dos dados, clique em "Salvar e Executar".
   * Caso a bolsa informada exista, e a execução tenha ocorrido com sucesso, a bolsa do aluno será excluída.
3. **Criando uma fórmula visual para Cancelar uma Bolsa do Aluno.**

   Acesse: Gestão| Fórmula Visual| Fórmula Visual | Adicione uma nova fórmula visual |Adicione a atividade "Cancelar Bolsa Aluno" na fórmula visual.

   * Preencha todos os campos necessários para o cancelamento da bolsa do aluno.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a bolsa informada exista, e a execução tenha ocorrido com sucesso, a bolsa do aluno será cancelada.
4. ****Criando uma fórmula visual para Incluir ou Alterar uma Concessão de Bolsa Futura.****

   Acesse: Gestão| Fórmula Visual| Fórmula Visual | Adicione uma nova fórmula visual |Adicione a atividade "Inclui ou Altera uma Bolsa Futura" na fórmula visual.

   3
   incomplete
   **Incluindo uma Concessão de Bolsa Futura.**
   * Preencha todos os campos necessários para a inclusão da concessão da bolsa futura, caso a bolsa preenchida já exista na base de dados, será feita uma atualização do mesmo, se não existir será realizada a inclusão.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a execução tenha ocorrido com sucesso a concessão de bolsa futura será incluída.

   4
   incomplete
    **Alterando uma Concessão de Bolsa Futura.**
   * Preencha todos os campos, caso a bolsa preenchida já exista na base de dados, será feita a atualização do mesmo, se não será realizada uma inclusão.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a concessão de bolsa futura informada exista, e a execução tenha ocorrido com sucesso, a concessão de bolsa futura será atualizada.
5. **Criando uma fórmula visual para Excluir uma Concessão de Bolsa Futura.**   

   Acesse: Gestão| Fórmula Visual| Fórmula Visual | Adicione uma nova fórmula visual |Adicione a atividade "Excluir Bolsa Futura" na fórmula visual.

   * Preencha todos os campos necessários para a exclusão da concessão da bolsa futura.
   * Após o preenchimento dos dados clique em "Salvar e Executar".
   * Caso a concessão de bolsa futura informada exista, e a execução tenha ocorrido com sucesso a concessão de bolsa futura será excluída.

**Observação:** A fórmula irá excluir as habilitações, os serviços, e os dados dos campos complementares vinculados à concessão de bolsa futura. A exclusão será executada mesmo com a informação da matriz aplicada (habilitação)
