# Extrato de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Extrato de Caixa |
| **Situação/Requisito:** | Ao acessar a visão de Extratos de Caixa filtrando os registros por uma data, executa-se depois um filtro na  coluna Conta/Caixa e depois filtra-se também apenas os Saques, através dos ícones facilitadores. Ao atualizar  a visão, o sistema desconsidera o filtro da coluna Conta/Caixa e exibe registros de outras contas. |
| **Solução/Implementação:** | Otimização no processo de filtros customizados na visão de lançamentos/extratos para exibir o número correto  de lançamentos/extratos visíveis e quando houver filtro de colunas ativos também. |
