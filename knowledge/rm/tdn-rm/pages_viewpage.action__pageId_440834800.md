# DIGITAÇÃO DE HISTÓRICO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Educacional |
| **Função:** | Digitação de Histórico |
| **Situação/Requisito:** | Ao entrar na Digitação do Histórico, o sistema está apresentando as séries todas fora da ordem. Na base de dados o sistema faz a mesma consulta e ordena corretamente as séries por código. Os dados na base aparentemente estão todas corretamente cadastradas. |
| **Solução/Implementação:** | A tela de Digitação de Histórico foi alterada para sempre mostrar as séries ordenadas pelo campo Ordem da série e pelo código. |
