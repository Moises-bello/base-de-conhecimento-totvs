**Ocorrência**  
Ao realizar a rotina de contabilização Offline do módulo do Ativo Fixo (CTBAATF) o sistema grava o campo CT2\_DATA com a data base logada do  usuário.  
  
**Ambiente**  
Microsiga Protheus - Ativo Fixo – A partir da versão 11.80  
  
**Solução**  
Para solucionar essa ocorrência,  retorne a data base do sistema para a data do cálculo de depreciação foi realizado e execute a contabilização Offline
