**Arquivo Fonte de Dados Tratado**

Neste módulo, poderão ser visualizados os registros de cada batida oriunda de importação ou digitada. Para cada batida coletada será gerado um tipo de registro Original, e para cada batida digitada será gerado um tipo de registro Incluído. O tipo de registro Original ou Incluído pode ser uma Batida considera ou desconsiderada para o cálculo.

Na visão dos registros é possível identificar o PIS do funcionário caso a importação seja feita utilizando o layout AFD.

As batidas originais do REP não poderão sofrer alterações; mas, para ajustes no ponto, poderão ser marcadas como "desconsideradas" e será OBRIGATÓRIA a justificativa desta desconsideração. Esta justificativa será de responsabilidade do USUÁRIO.

**Observações**

Batidas de refeição (refeitório, controle de quantidade de refeições) não serão consideradas.

Todas essas batidas também poderão ser visualizadas pelo  relatório arquivo fonte de dados tratado conforme Portaria 1510/2009.

Veja mais informações nas Adequações do RM Chronus à Portaria 1510/2009.
