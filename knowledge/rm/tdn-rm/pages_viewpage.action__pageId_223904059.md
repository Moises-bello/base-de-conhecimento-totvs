# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Geração de lançamentos* |
| **Situação/Requisito:** | *Ao gerar lançamentos financeiros do tipo contábil com 100% de gratuidade, o sistema não permite a geração dos lançamentos, mesmo que o sistema financeiro esteja parametrizado para permitir a geração de lançamentos contábeis com o valor líquido igual a zero.* |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de lançamentos, permitindo ao sistema, gerar lançamentos contábeis com valor líquido zerado, conforme parametrização do sistema financeiro. |
