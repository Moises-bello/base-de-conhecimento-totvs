# ATESTADO MEDICO CONSIDERA SOMENTE AFASTAMENTOS DA ÚLTIMA SEQUÊNCIA DO PERÍODO DE CARÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Atestado Médico |
| **Situação/Requisito:** | Cliente solicita que na apuração dos dias de Atestado Medico não sejam considerados os afastamentos anteriores aos últimos N dias, onde N é a quantidade de dias do período de carência para afastamentos do mesmo motivo. |
| **Solução/Implementação:** | Criação do parâmetro "Atestado médico considera somente afastamentos da última sequência do período de carência". |
