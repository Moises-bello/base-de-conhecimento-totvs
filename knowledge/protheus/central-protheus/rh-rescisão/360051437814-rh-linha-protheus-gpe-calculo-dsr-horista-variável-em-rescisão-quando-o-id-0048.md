**Dúvida**Calculo DSR horista variável em rescisão, quando o id 0048 é lançado manualmente.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - Todas as versões.  
  
**Solução**  
Em cálculo de rescisão horista com jornada variável, quando é lançado manualmente o id 0048 o sistema não calcula automaticamente o DSR, mesmo se o mnemônico P\_LDSRSALD estiver com conteúdo .T.   
Neste cenário o valor do DSR deverá ser informado manualmente.
