# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Fiscal |
| **Versões:** | 12.1.x |
| **Ocorrência:** | Aumentar o número máximo de registros na visão de Lançamentos |
| **Ambiente:** |  |
| **Passo a passo:** | Acesse o módulo de Serviços Globais → Serviços – Servidores de Aplicação        Execute um filtro de seleção e insira um novo registro e busque pelo ID Server:    FisLanFiscalEntradaData - Lançamentos de Entrada.        FisLanFiscalSaidaData - Lançamentos de Saída. Informe o número máximo de registros, como destacado nas imagens.        Para identificar a action de cada tela/processo, basta teclar: Ctrl + Alt + F9 |
| **Observações:** | Quanto maior for o número de registros configurados, maior será o tempo de resposta do sistema. Recomendamos o máximo de 1000 registros. |
