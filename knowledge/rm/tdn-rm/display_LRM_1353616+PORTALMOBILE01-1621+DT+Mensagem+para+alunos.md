# ENVIO DE MENSAGEM - PORTAL PROFESSOR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Envio de mensagens para alunos via portal do professor. |
| **Situação/Requisito:** | Ao selecionar os alunos para envio de mensagem, também eram exibidos os alunos cuja situação de matrícula estava parametrizada para não exibir na listagem de consultas do professor. |
| **Solução/Implementação:** | No envio de mensagem somente serão exibidos os alunos cuja situação de matrícula estiver parametrizada como "Disponível na listagem de consultas do professor". |
