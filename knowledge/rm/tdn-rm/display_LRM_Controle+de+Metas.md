Controle de Metas

FAQ: **Controle de Metas**

|  |  |
| --- | --- |
| Produto: | RM |
| Ambiente: | Unspecified |
| Versão: | 11.20 |

Avaliação

Este documento tem como objetivo orientá-lo a criar um controle de metas e realizar o seu acompanhamento.

Solução

Ao acessar o menu de controle de metas, uma tela bem simples é apresentada e traz apenas os dados pertinentes a esse controle.

Importante! O acompanhamento e lançamentos da meta devem ser realizados através do RM Portal, de acordo com o período de projeto vigente.

[![clip_image001](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwf76_8wI/AAAAAAAAFos/1Y5iV8jIcuE/clip_image001_thumb%5B1%5D.jpg?imgmax=800 "clip_image001")](http://lh5.ggpht.com/_G7KXZLoZDsY/TTlwfVwuC-I/AAAAAAAAFoo/lo1uHVEz6TU/s1600-h/clip_image001%5B4%5D.jpg)

Ao cadastrar um controle de metas, na opção de anexo, podemos criar uma meta e um grupo de avaliação.

[![clip_image002](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwhJd2OAI/AAAAAAAAFo0/NDbbJzJwogE/clip_image002_thumb%5B1%5D.jpg?imgmax=800 "clip_image002")](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwgrfAenI/AAAAAAAAFow/b94SzWK_s4o/s1600-h/clip_image002%5B4%5D.jpg)

O Grupo de Avaliação tem por objetivo montar um grupo de trabalho onde exista o papel do responsável por este grupo de trabalho e seus subordinados (Funcionários membros do grupo). O responsável pela equipe é a pessoa encarregada de gerenciar o desempenho e validar sobre o cumprimento das metas dos membros deste grupo. O cadastro é feito pela seguinte tela de cadastro:

[![clip_image003](http://lh6.ggpht.com/_G7KXZLoZDsY/TTlwh4KpkqI/AAAAAAAAFo8/3FeF2AuhrdE/clip_image003_thumb%5B1%5D.jpg?imgmax=800 "clip_image003")](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwhayo8HI/AAAAAAAAFo4/JfHyCW4BiyM/s1600-h/clip_image003%5B4%5D.jpg)

A aba de ***Funcionários membros do grupo*** é onde informamos os funcionários membros deste grupo de avaliação.

[![clip_image005](http://lh6.ggpht.com/_G7KXZLoZDsY/TTlwi8k90tI/AAAAAAAAFpE/KADZ2KC69FE/clip_image005_thumb%5B1%5D.jpg?imgmax=800 "clip_image005")](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwidOEgmI/AAAAAAAAFpA/z1pDJEUOFMo/s1600-h/clip_image005%5B4%5D.jpg)

As metas, como dito anterior, são os objetivos a serem alcançadas por este controle de metas, as metas podem ser vinculadas às Seções, Grupos de Avaliação, Equipes, Chapa (Funcionários) ou Externos.

[![clip_image006](http://lh6.ggpht.com/_G7KXZLoZDsY/TTlwkBvERjI/AAAAAAAAFpM/h13Oggax0mg/clip_image006_thumb%5B1%5D.jpg?imgmax=800 "clip_image006")](http://lh5.ggpht.com/_G7KXZLoZDsY/TTlwjLtTaBI/AAAAAAAAFpI/HnM7_ERpd1Y/s1600-h/clip_image006%5B4%5D.jpg)

A aba de ***Atribuição de membros da metas*** é responsável por definir quem serão os membros desta meta, as metas podem ser vinculadas às Seções, Grupos de Avaliação, Equipes, Chapa (Funcionários) ou Externos.

[![clip_image007](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwkz9_ulI/AAAAAAAAFpU/iNHMeZjWCzM/clip_image007_thumb%5B1%5D.jpg?imgmax=800 "clip_image007")](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwkT6RJ4I/AAAAAAAAFpQ/WSKdJirchs8/s1600-h/clip_image007%5B4%5D.jpg)

**O controle de metas no RM Portal**

No menu Recursos Humanos do portal, existe agora o menu Controle de metas, onde é possível incluir metas novas metas e acompanhamentos para metas já existentes. Para facilitar a utilização dos recursos WEB, a identidade visual das telas foi mantida.

Na WEB, é possível alem de cadastrar metas, fazer o cadastro de novos grupos de avaliação e fazer os lançamentos do acompanhamento das metas.

Ao acessar o menu de controle de metas, tem – se uma visualização das metas cadastradas sobre responsabilidade do usuário logado. Nesta visão, é possível também fazer a inclusão de novas metas:

[![clip_image009](http://lh4.ggpht.com/_G7KXZLoZDsY/TTlwlsTsBcI/AAAAAAAAFpc/6dxpeMu36wo/clip_image009_thumb%5B1%5D.jpg?imgmax=800 "clip_image009")](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwlWwAb2I/AAAAAAAAFpY/Rt2rJZbiCj8/s1600-h/clip_image009%5B4%5D.jpg)

No menu de Atribuição de metas, é responsável por definir quem serão os membros desta meta, as metas podem ser vinculadas às Seções, Grupos de Avaliação, Equipes, Chapa (Funcionários) ou Externos.

[![clip_image011](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwm9ZGNgI/AAAAAAAAFpk/kLmed9n_P1I/clip_image011_thumb%5B1%5D.jpg?imgmax=800 "clip_image011")](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwmHkda0I/AAAAAAAAFpg/F8tIpirtrh8/s1600-h/clip_image011%5B4%5D.jpg)

Nos anexos da tela de visão dos controles de metas, é possível criar também um grupo de avaliação conforme tela abaixo:

[![clip_image013](http://lh3.ggpht.com/_G7KXZLoZDsY/TTlwnoLbcDI/AAAAAAAAFps/BI3QSbVEnOA/clip_image013_thumb%5B1%5D.jpg?imgmax=800 "clip_image013")](http://lh5.ggpht.com/_G7KXZLoZDsY/TTlwnEDD0rI/AAAAAAAAFpo/0timcO5umfo/s1600-h/clip_image013%5B4%5D.jpg)

No menu de membros do grupo, é a associação de membros para este grupo de avaliação.
