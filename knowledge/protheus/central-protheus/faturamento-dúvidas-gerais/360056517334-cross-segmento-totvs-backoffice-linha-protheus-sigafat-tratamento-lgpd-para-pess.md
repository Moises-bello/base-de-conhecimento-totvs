**Dúvida**

Tratamento LGPD para pessoas físicas e jurídicas para proteção de dados sensíveis.  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.  
  
**Solução**

Acessar o Configurador(SIGACFG) >> Usuário >> Senhas Usuários, localizar o usuário que ira realizar a configuração, uma vez que habilitar o uso de proteção de dados, retirando dos usuários do sistema, **as opções 192 - Dados Pessoais e 193- Dados Sensíveis** nas restrições de acesso, o sistema irá inibir as informações para todos os tipos de cliente (**MATA030**), vendedor (**MATA040**) e transportadora (**MATA050**), independente de ser pessoa Física ou Jurídica.   

Hoje o tratamento LGPD, dos cadastros citados acima, não possuem configuração para diferenciar entre pessoa Física e pessoa Jurídica.

Para um tratamento diferenciado do que se tem atualmente somente por sugestão de melhoria.

As melhorias  devem ser incluídas diretamente no [**Portal do Cliente**](http://suporte.totvs.com/). Um espaço que você poderá sugerir melhorias, acompanhar a evolução das solicitações já realizadas, comentar, seguir, votar em sugestões feitas por outros clientes e muito mais!

A própria equipe de desenvolvimento responde diretamente ao cliente se irá considerar a melhoria nos próximos releases.
