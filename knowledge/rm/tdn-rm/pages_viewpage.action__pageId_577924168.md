Esta funcionalidade tem por objetivo realizar preenchimento dos resultados laboratoriais

sumarioResultados Laboratoriais 

## **01. TELA RESULTADOS LABORATORIAIS**

Unidade de Diagnóstico > Resultados Laboratoriais > Selecione o exame desejado e dê um duplo click.

preenchidos dos resultados laboratoriais 

## **02. TELA PREENCHIMENTO DOS RESULTADOS LABORATORIAIS**

1. Tela com os parâmetros a serem preenchidos dentro de um exame.

2. Na parte inferior selecione a ação para "Digitar Exame" e clique em salvar.

3. Com a mudança de Status para digitação, será possível digitar os valores na coluna de resultados como no exemplo abaixo.  
Após concluir a digitação mude a ação para "Concluir Digitação" e salve.

4. Após o status mudar para "Digitação Concluída" mudar a ação para "Liberar Resultado".

Validação de resultados

## **03. TELA DE VALIDAÇÃO DE RESULTADOS**

A tela de validação de resultados se abrirá sendo possível validar as informações digitadas do exame.

Responsável técnico

## **04. TELA DE RESPONSÁVEIS TÉCNICOS**

Após clicar em "Liberar" a seguinte tela de responsável técnico se abre. Selecione o médico responsável pelo laudo.

Observação: Se o usuário logado estiver relacionado a um responsável técnico, o sistema irá utilizar-lo como responsável do exame automaticamente e não será aberto esta tela.

Após o status seguir para "Liberado" temos a possibilidade da ação "Retornar Liberado para Correção" ou "Emitir o Resultado"

Após o status seguir para "Emitido" temos a possibilidade da ação "Cancelar Emissão de Resultados", "Reemitir Exame" ou "Entregar Exame"

Entregar Exame

## **05. TELA ENTREGA DO LAUDO**

Após o status seguir para "Entregar Exame" abrirá a tela de entrega do laudo, após preencher os dados salva os dados de entrega.

Após finalizar a entrega do laudo o seu status vai para "Entregue" tendo a possibilidade de "Cancelar a Entrega de Exame"
