# Portal - Copiar conteúdo do plano de aula

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | ************Educacional************ |
| **Módulo:** | ***********Totvs Gestão Educacional*********** |
| **Função:** | **Portal - copiar conteúdo do plano de aula** |
| **Situação/Requisito:** | **No Portal | Professor | Diário de classe, ao copiar o conteúdo de uma turma/disciplina para outra, apresentava mensagem "Não é possível copiar o conteúdo: a data de destino está fora do período de digitação." Mesmo quando a Etapa de Falta está com o campo “Dt limite conteúdo previsto” dentro do prazo. Somente ocorria se existisse no mesmo período, etapas do tipo Falta e do tipo Nota.** |
| **Solução/Implementação:** | No Portal | Professor | Diário de classe, ao copiar o conteúdo de uma turma/disciplina para outra, o sistema somente irá validar a data limite de conteúdo previsto para a etapa do tipo Falta, selecionada. |
