**Enviar e-mail para PDI**

Utilize essa opção para enviar e-mail aos chefes ou supervisores para efetuarem o PDI via RM Portal.

**Observação**

No RM Portal existem ícones que indicam a existência de um PDI para o funcionário. O mesmo pode apresentar 3 situações:

* Não existe PDI pendente: exibido sempre que não houver PDI para o funcionário, ou seja, não foi realizado ainda o processo "Enviar e-mail para PDI".
* PDI pendente: exibido apenas para o chefe da seção de lotação do funcionário, depois da prova ter sido respondida.
* PDI preenchido: exibido sempre que o PDI do funcionário já tiver sido preenchido.

**Atenção**

O e-mail do PDI só é enviado para os avaliadores após as provas terem sido respondidas. Na avaliação de modalidade 180º apenas após a execução das avaliações de consenso.
