O Help é apresentado ao tentar aprovar um Documento com uma data de emissão "futura" a que está sendo utilizada na rotina de Liberação de Documentos (MATA094), ou seja, maior do que a DataBase, é apresentado o Help DTEMISSUP,

![imagem1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7917752802455)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGACOM - Versão 12  
  
**Solução**

Alterando a DataBase (sistema) para a data de emissão do documento é possível prosseguir com a Aprovação do Documento apresentado na rotina.

**Observação:** No APP MEU PROTHEUS não é possível realizar a liberação de documentos com data de emissão futura, caso tente realizar a liberação irá ocorrer a mensagem abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25020036296471)

Nesse caso é necessário realizar a aprovação diretamente no Protheus.
