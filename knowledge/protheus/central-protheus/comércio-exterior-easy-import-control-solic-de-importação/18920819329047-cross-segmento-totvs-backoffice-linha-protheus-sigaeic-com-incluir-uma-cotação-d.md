![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18920851663127)Tempo aproximado para leitura: **03:00 min** **Dúvida**Com incluir uma Cotação de Preço?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 12.1.33  
  
**Solução**

**Procedimentos:**

**Para incluir uma Cotação de Preços:**

**1.** Ao selecionar a opção "Cotação de Preços", será apresentada uma tela com os quadros de concorrência incluídos. No browse estão disponíveis as seguintes opções: "**Inclui"**, "**Altera"**, "**Exclui"**, "**Avalia"** e "**Cancela"**.

**2.** Selecione opção "**Incluir**" e preencha os campos de cabeçalho conforme orientação do help de campo.

**3.** Para incluir itens, clique em**"Incluir"** (Na inclusão, atente-se ao fato de que a seleção pode ser por "Unid.Requisitante + No. de SI" ou através da digitação de cada produto).

**4.** Clique em **"Fornecedores"**e selecione os fornecedores para incluir no quadro de concorrência. Será apresentada uma tela para manutenção de fornecedores.

Preencha os dados dos fornecedores utilizando as opções disponíveis em Ações Relacionadas e clique em **"Ok"** para retornar à tela principal.

**5.** Clique em "Itens/Fornec.", selecione os fornecedores para incluir os preços no quadro de concorrência e confirme para prosseguir. Será apresentada uma janela para manutenção de "Produtos X Fornecedores".

**6.** Para alterar o preço do item, clique em **"Alterar"**. Será apresentada uma janela para digitação do preço FOB.

**7.** Preencha o valor FOB e confirme.

**8.** Para gravar o preço do item, clique em **"Gravar"**. O sistema retornará para a tela principal.

**9.** Para gravar o quadro de concorrência, clique em **"Ok"**.  
  
**Para imprimir uma Cotação de Preços:**

**1.** Na janela de manutenção de "Cotação de Preços", selecione um quadro de concorrência e clique na opção "Visualizar".

**2.** Clique em **"Impressão"**. Será apresentada uma tela com os parâmetros de impressão.

**3.** Preencha os campos conforme orientação do help e confirme.

**4.** Siga as orientações para impressão, conforme indicado no tópico.
