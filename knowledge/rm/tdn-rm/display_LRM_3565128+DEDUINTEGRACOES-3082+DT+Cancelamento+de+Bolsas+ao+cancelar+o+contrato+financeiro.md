# CANCELAMENTO DE CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Cancelar Contrato |
| **Situação/Requisito:** | Ao cancelar um contrato, o sistema mantém as bolsas do contrato com o status de ativas. Porém o efeito prático é como se estivem inativas, pois um contrato cancelado não pode gerar lançamentos financeiros. Por outro lado, caso o status de inativo seja importante para algum relatório gerencial, o sistema não permite que se inative as bolsas de um contrato cancelado. |
| **Solução/Implementação:** | Otimização no processo de cancelamento de contrato, de forma que o sistema, também inative as bolsas existentes no contrato. |
