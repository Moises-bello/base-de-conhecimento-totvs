# CÁLCULO DE EXAMES PENDENTES POR FÓRMULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Segurança e Saúde Ocupacional* |
| **Função:** | *Cálculo de Exames Pendentes por Fórmula* |
| **Situação/Requisito:** | *Ao gerar exames pendentes associados a uma fórmula que verifica a data de admissão do funcionário para gerar o exame periódico para 180 dias ou 365 dias, para funcionário que possui uma chapa demitida e outra chapa ativa, que possui o mesmo código de pessoa, o sistema calcula incorretamente.* |
| **Solução/Implementação:** | *Realizado ajuste na execução de fórmula da rotina de exames pendentes para que a mesma leve em consideração a chapa do funcionário.* |
