# VISIBILIDADE DOS BOLETOS NO ANEXO DO LANÇAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Anexo de boletos do lançamentos financeiro. |
| **Situação/Requisito:** | Boletos de lançamentos originados de outros módulos não eram exibidos quando a aplicação origem é um dos sistemas educacionais. |
| **Solução/Implementação:** | Os registros no anexo de boletos de lançamentos são sempre exibidos independente do módulo corrente selecionado. |
