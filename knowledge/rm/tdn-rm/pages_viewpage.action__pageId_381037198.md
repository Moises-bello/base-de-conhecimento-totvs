# Visualização da Baixa de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Baixas realizadas de lançamentos |
| **Situação/Requisito:** | No financeiro tem a opção ”Baixas Realizadas de Lançamentos” presente no menu “Contas a Pagar/Receber ”. Na visualização do item de baixa por essa opção, caso o item de baixa tenha valor de integração a aba “Dados Adicionais”(aba onde se encontra os valores de integração) é mostrar. E quando navega entre os registros a aba continua sendo mostrada independe se o item de baixa tem ou não os valores de integração. Porém caso o item de baixa a ser visualizado não tem valor de integração a aba não é mostrada. Isso é correto. Mas quando navega para um item de baixa que  tem valor de integração, a aba continua não sendo mostrar. Sendo que deveria ser mostrada. |
| **Solução/Implementação:** | Na tela de baixas realizadas de lançamentos, ao navegar entre os registros, a aba dados adicionais está sendo exibida somente para itens que possuem valor de integração. |
