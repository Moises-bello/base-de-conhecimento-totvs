# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO CONTÁBIL |
| **Versões:** | 12.1.16 |
| **Ocorrência:** | Copiar Centros de Custos entre Coligadas |
| **Ambiente:** |  |
| **Passo a passo:** | **Definição do Processo:**  Para agilizar e facilitar o cadastro, um centro de custo já cadastrado em uma coligada poderá ser copiado para outra coligada.  **Como Fazer:**  Acesse o cadastro dos Centros de Custos / selecione os centros de custos desejados / clique em processos / Copiar Centros de custos Entre Coligadas / selecione as coligadas desejadas / Executar.        No processo de cópia, o sistema consistirá, se na coligada destino já existe algum centro de custo com mesmo código do que está sendo copiado. Se já existir, a cópia não será efetuada. Se desejar, marque a opção ‘Substituir registros no destino se eles já existirem’ para que o sistema substitua os dados do centro de custo de origem no destino. |
| **Observações:** | As máscaras dos Centros de Custos entre as coligadas de origem e de destino devem, obrigatoriamente, serem iguais para que a cópia seja efetuada. |
