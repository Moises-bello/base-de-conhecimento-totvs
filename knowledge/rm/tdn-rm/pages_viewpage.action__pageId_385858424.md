# Inclusão de lançamento financeiro com histórico não formatado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Inclusão de Lançamento Financeiro |
| **Situação/Requisito:** | Ao realizar a inclusão de um lançamento não contábil através do RMNucleus com o mnemonico [DCG] o sistema não substituía pela descrição do centro de custo. |
| **Solução/Implementação:** | Ajuste realizada para não executar a formatação de histórico apenas para processamento de "Reajuste de Valores de Integração" |

| **Requisito:** | FIN000022 |
