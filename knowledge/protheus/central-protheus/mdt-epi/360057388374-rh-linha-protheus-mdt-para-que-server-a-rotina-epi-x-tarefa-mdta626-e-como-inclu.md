**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25627978216727)**Tempo aproximado para leitura: **00:02:00 min****Dúvida**Para que server a rotina **EPI x Tarefa** (MDTA626) e como incluir?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Essa rotina é responsável por relacionar os **EPI's** (equipamento de proteção individual) necessários a uma **tarefa**.   
Para saber como cadastrar um EPI ou Tarefa consulte:  **[MP - MDT - Como cadastrar um Equipamento de Proteção Individual (EPI)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360048704353-MP-MDT-Como-cadastrar-um-Equipamento-de-Prote%C3%A7%C3%A3o-Individual-EPI-?source=search)**.  
**[MP - MDT - Para que server a rotina Tarefas Por Funcionário (MDTA090) e como incluir](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360055465733)**.  
  
Para cadastrar acesse no modulo **SIGAMDT (35)** o caminho: atualizações > PPRA > **EPI x Tarefa** (MDTA626). Escolha a tarefa que vai ser relacionado os EPI necessários, e clique em **EPI**.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360097285354)  
  
Na próxima tela é possível escolher os EPI's que serão necessários para a tarefa.
