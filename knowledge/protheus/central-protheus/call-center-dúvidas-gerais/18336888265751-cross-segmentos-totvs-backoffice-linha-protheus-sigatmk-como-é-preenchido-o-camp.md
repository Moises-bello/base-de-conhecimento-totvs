![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18336935848343) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Preenchimento do campo "UB\_VALIPI"?  
  
**Ambiente**Cross Segmentos-TOTVS Backoffice (Linha Protheus)-SIGATMK -  todas as versões.  
  
**Solução**

O campo “UB\_VALIPI” é criado e preenchido (atualizado com valores), somente via aplicação de template “DCM”. O produto padrão SIGATMK não é responsável pela criação e preenchimento deste campo.

O SIGATMK possui uma pasta de impostos no “Televendas”, com suas respectivas informações de maneira padrão e, somente esta pasta que é de responsabilidade do produto para preenchimento.

O template DCM foi descontinuado para aplicação do modulo do Call Center.
