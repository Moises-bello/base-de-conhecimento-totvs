**Dúvida**Todos os dados devem ser levados para base atualizada no processo de upgrade? 

**Ambiente**Ciclo de Vida  
  
**Solução**

Todos os períodos em aberto ou passíveis de auditoria/retificação devem ser movidos para a base de dados no novo release.

Isso é muito importante, pois, após encerrada a Garantia Estendida, o release expirado não terá mais pacotes de atualização contemplando mudanças de legislação.

Somente os dados mais antigos, que precisam ser consultados na sua forma original, devem ser mantidos na base histórica.

Em caso de dúvidas, o time técnico de entrega de projetos deve ser consultado
