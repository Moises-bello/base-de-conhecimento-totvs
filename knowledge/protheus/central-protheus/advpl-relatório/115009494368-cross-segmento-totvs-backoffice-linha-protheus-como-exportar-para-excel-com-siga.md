**Dúvida**Como exportar para excel com SIGARPM?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL – Todas versões  
  
**Solução**A ferramenta SIGARPM tem essa limitação para exportar relatório para excel sendo assim, utilize a ferramenta TOTVS REPORT onde é possível realizar a criação de um relatório e importar um relatório em já criado, a ferramenta encontra-se no menu em Miscelanea-> TOTVS Report presente em todos os módulos. **Saiba mais**[ADV0001 SIGARPM não exporta para excel](http://tdn.totvs.com/display/PROT/ADV0001_RPM_SIGARPM_NAO_EXPORTA_PARA_EXCEL)
