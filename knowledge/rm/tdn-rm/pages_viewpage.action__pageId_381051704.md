| **Função:** | Preparação de dados para o Educacenso |
| **Situação/Requisito:** | Ao associar um curso que não é profissionalizante, ele é exibido na aba de cursos profissionalizantes para associação. |
| **Solução/Implementação:** | Foi detectado que o código validado estava desatualizado e mesmo foi atualizado conforme definição no layout do Censo.
