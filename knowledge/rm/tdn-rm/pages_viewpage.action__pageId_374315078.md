# Sistema não grava comentário das avaliações se a nota não for digitada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Portal do Professor |
| **Função:** | Notas de avaliações |
| **Situação/Requisito:** | Sistema não permitia informar um comentário caso a nota não estivesse preenchida. |
| **Solução/Implementação:** | Foi realizado ajuste para permitir que o professor acrescente um comentário mesmo se a nota não tiver sido informada. Pode ser utilizado para registrar, por exemplo, que o aluno não fez a prova por algum motivo específico. |
