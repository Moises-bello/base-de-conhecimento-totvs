**Grupo de objetivos do projeto** - Está opção define com qual grupo de objetivos o projeto irá trabalhar. Informe o grupo previamente cadatrado em Gestão de risco / Objetivos do projeto / grupo de objetivos.

**Escala** - Está opção define com qual escala o projeto irá trabalhar. Informe a escala previamente cadatrado em Gestão de risco / Escalas.

**Grupo de áreas de prioridade**- Está opção define com qual grupo de áreas de prioridade o projeto irá trabalhar. Informe a escala previamente cadatrado em Gestão de risco / Grupo de áreas de prioridade.

**Observação:**

Na seleção dos parâmetros acima somente estaram disponíveis registros ativos.
