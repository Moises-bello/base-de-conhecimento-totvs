Para acessar os Dados de Repasse do Empreendimento, ao cadastrar ou editar um Empreendimento, clique em Anexo e depois em Dados de Repasse do Empreendimento.  
Nesta opção de menu serão inseridos os Dados de Repasse do Empreendimento que serão usados para efetuar o Repasse no módulo gestão Financeira.

Além disso, a partir da versão 12.1.35, este cadastro também será usado para a geração do [lançamento residual do aluguel complementar,](https://tdn.totvs.com/pages/viewpage.action?pageId=435105013) para os casos onde o faturamento total é menor do que os valores de condomínio e de fundo promocional.

Através do cadastro é possível controlar:

**Identificação - Dados de Repasse do Empreendimento**

Ao cadastrar ou editar um Dados de Repasse do Empreendimento, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* Empreendimento: Neste campo estará o código do Empreendimento que receberá os Dados de Repasse. Este campo está desabilitado para edição;
* Participante: Informe o cliente que receberá o repasse;
* Percentual de Participação: Informe qual será o percentual de rapasse para o Cliente;
* Valor de Integração: Este campo está disponível na versão **12.1.2205** em diante. Nos casos onde os valores residuais sejam gerados para os sócios no aluguel complementar. devemos cadastrar aqui um valor de integração com a ação de desconta, para que o mesmo seja subtraído da cobrança do condomínio. Para saber mais sobre os cálculos residuais do aluguel complementar e seu repasse aos sócios do empreendimento, [veja o exemplo nesta página (clique aqui);](https://tdn.totvs.com/pages/viewpage.action?pageId=435105013)
* Usuário: É informado o Usuário que efetuou a última alteração do registro. Este campo está inabilitado para edição;
* Data Manutenção: É informado a Data da última manutenção do registro. Este campo está inabilitado para edição;

Para mais informações sobre o Repasse do Empreendimento, clique em:  e [Repasse com Multa, Juros e Desconto](https://tdn.totvs.com/x/fT7dKQ)

**Identificação - Fideicomiso**

Para atender ao mercado internacional foi criado o tipo de participação (Repasse)  que podem ser por Lançamentos financeiros ou por Fideicomiso. O Fideicomiso é um arranjo legal que permite a participação de mais de uma empresa nos ganhos financeiros. Diferente do Repasse atual, este gera um movimento ao invés do lançamento financeiro.

* Tipo Participação: Informe se o repasse será gerado através de um lançamento financeiro ou pelo Fideicomiso.
  + Caso o Fideicomiso for selecionado serão habilitados outros campos na tela:
    - Valor de Participação: Informe o valor fixo da participação do parceiro no empreendimento.
    - Parâmetros de movimento: Informe um conjunto de configurações default que trazem os dados para a geração do movimento.
    - **Observação**: Com o parâmetro de Fideicomiso selecionado, é possível escolher apenas participação por percentual, ou por valor, nunca os dois ao mesmo tempo.
