# Lançamento de Diagnose e Terapia na aba de Guia Autorização

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de Contas |
| **Situação:** | Ao realizar a inserção de diagnose e terapia pela Guia e Autorização, o valor do procedimento era calculado de uma forma diferente de quando é realizado pela elaboração de contas. |
| **Solução:** | Alterado o sistema para lançar diagnose e terapia com o mesmo valor, tanto pela guia e autorização quanto pela aba de diagnose e terapia da elaboração de contas. |
