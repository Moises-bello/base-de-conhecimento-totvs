# ACORDO DE LANÇAMENTO CONTÁBIL ORIGINADO DO EDUCACIONAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Acordo de lançamento financeiro. |
| **Situação/Requisito:** | Ao gerar acordo de lançamento originado do Educacional com contabilização gerada por evento contábil parametrizada para buscar default da matriz aplicada, caso o contrato vinculado não tenha essa informação ocorria uma inconsistência que impedia a execução do processo. |
| **Solução/Implementação:** | Ajustado o processo geração de contabilização pelo evento contábil para não gerar dados caso a matriz aplicada não esteja informada no contrato vinculado à parcela. |
