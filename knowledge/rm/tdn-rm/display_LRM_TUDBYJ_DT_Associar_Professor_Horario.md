# ASSOCIAÇÃO DO PROFESSOR AO HORÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Processo de associação de professores aos horários.* |
| **Situação/Requisito:** | *Quando o processo é executado selecionando uma turma/disciplina gerencial, o processo não replicava a associação para as turmas/disciplinas gerenciadas.* |
| **Solução/Implementação:** | *Ao executar o processo "Associar professor aos horários da Turma/Disciplina" selecionando uma turma/disciplina gerencial, a associação será replicada automaticamente para as turmas/disciplinas gerenciadas. Se uma turma/disciplina gerenciada for selecionada, esta disciplina não será atualizada e será informado no log do processo o motivo. Como a disciplina é gerenciada será informado no log o Id. da turma/disciplina gerencial.* |
