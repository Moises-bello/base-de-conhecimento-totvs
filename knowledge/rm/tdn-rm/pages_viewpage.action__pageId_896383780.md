Um bom planejamento é o primeiro passo para o sucesso na automação de testes. Antes de começar, é importante organizar seus esforços com base nos seguintes pilares:

1. Definir o escopo

Definir o que será e o que não será automatizado é fundamental para o planejamento.  
Defina um objetivo, crie um cronograma com os cenários de testes a serem automatizados informando data de conclusão para cada item e estabeleça metas semanais para acompanhamento.

As perguntas abaixo o ajudarão para esta definição:

- Quais partes do sistema serão testadas?  
- Quais cenários de cada módulo serão testados?  
- Qual é o objetivo do teste?  
- Sua empresa já utiliza um Roteiro de Homologação? Utilize-o para a montagem do escopo.

2. Priorizar testes

Nem todos os cenários precisam ser automatizados. Foque nos casos críticos que causam maior impacto na sua empresa.  
Se estiver começando agora com a ferramenta, inicie pelos cadastros e processos mais simples para depois aumentar a complexidade.

3. Estimativas de tempo e recursos

Planejar a capacidade produtiva do time para atuação na criação e manutenção das automações é primordial para atingirmos os objetivos. Considere o tempo necessário para criar e manter os testes, bem como os recursos tecnológicos envolvidos.

4. Ambiente de Teste

Crie um ambiente específico para a criação e execução dos testes automatizados. Dê permissão neste ambiente somente para as pessoas que irão trabalhar com automação e não permita que este seja utilizado para outro fim. Desta forma, garantirá que as execuções das automações não sofrerão interferências.

5. Escolha do time de Automação

Para se fazer um bom uso da ferramenta de automação e usufruir de todos os seus recursos, é necessário escolher as pessoas certas para isso. Devemos selecionar pessoas que acreditam neste projeto, que estão motivadas e querem fazer parte deste time. Identificar o conhecimento técnico de cada integrante também é fundamental.

6. Conhecimentos técnicos necessários

- Conhecimento de negócio do RM  
- Criação de Fluxograma  
- Consumo de Web Services  
- Consumo de API´s  
- SoapUI  
- Postman  
- Código C#  
- Sentença SQL
