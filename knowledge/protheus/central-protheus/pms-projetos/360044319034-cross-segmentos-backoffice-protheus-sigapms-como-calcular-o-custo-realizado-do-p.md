**Dúvida**

Como é calculado o custo realizado no Gestão de Projetos?  
  
**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGAPMS - A partir da versão 11.80.  
  
**Solução**

Os custos desta coluna serão referentes aos apontamentos amarrados ao projeto como documentos de entrada, remessas, requisições, apontamentos de recursos, títulos a pagar, movimentos internos. Semelhante à coluna **CRTE**, porém sem levar em conta a data base do sistema.

**CRTE - Custo Real do Trabalho Executado**  
Os custos desta coluna serão referentes aos apontamentos amarrados ao projeto como documentos de entrada, remessas, requisições, apontamentos de recursos, títulos a pagar, movimentos internos, observando a data base do sistema.

Para visualizar os custos no projeto rotina **PMSA410** - configure o modelo planilha (aperte F12 no browse e clique na opção planilha).
