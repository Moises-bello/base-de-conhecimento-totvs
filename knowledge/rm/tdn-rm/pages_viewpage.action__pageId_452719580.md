**Requisição de Transferência com Alteração de Dados Funcionais**

---

Este tipo de requisição tem por objetivo realizar alteração na lotação com ou sem modificação da função e/ou salário do funcionário.

Passos para criar uma Requisição de Transferência com Alteração de Dados Funcionais:

**1º Passo:** Criar uma Requisição pelo módulo Valorização | Requisições | Transferência com Alteração de Dados Funcionais.

**2º Passo:** Preencher os campos disponíveis. Para saber as particularidades dos campos, clique aqui. (link do help Pasta Identificação – Requisição de Transferência com Alteração de Dados Funcionais)

**3º Passo:** Aprovar/Reprovar a Requisição. Se a Requisição for aprovada e o flag "Gerar Substituição" estiver marcado, será gerada uma Requisição de Substituição, com os dados do funcionário que será transferido.

**4º Passo:** Transferir e alterar os dados do funcionário, concluindo a Requisição. Este procedimento pode ser realizado de duas formas: No Totvs Gestão de Pessoas, pelo menu Valorização | Efetivações | Efetivar Transferência com Alteração de Dados Funcionais. No Totvs Folha de Pagamento, caso exista licença deste produto, pelo menu Rotinas | Alterações Globais de Funcionários | Efetivar Transferência com Alteração de Dados Funcionais.

**Importante:**

- Se o flag "Transferir Vaga" estiver marcado e estiver parametrizado o controle de lotação, no momento em que for executado o processo de Efetivar Transferência com Alteração de Dados Funcionais, a vaga da seção atual do funcionário será transferida juntamente com o funcionário para a seção destino.

- Não se aplica a ex-funcionários.

- Somente as requisições aprovadas são relacionadas para serem efetivadas.

- Após executar o processo de Efetivar Transferência com Alteração de Dados Funcionais, o sistema atualiza automaticamente os dados do funcionário e seus respectivos históricos.

- As Requisições de Transferência com Alteração de Dados Funcionais que dependam de alteração de CNPJ somente podem ser efetivadas através do processo de rescisão do funcionário.

**Campos Complementares na Requisição de Transferência com Alteração de Dados Funcionais**

* Esta funcionalidade permite a inclusão de **Campos Complementares** nas **Requisição de Transferência com Alteração de Dados Funcionais**
* Os Campos Complementares criados para a Requisição de Transferência com Alteração de Dados Funcionais possuem **abrangência global**. Eles serão exibidos em **todas as coligadas** do sistema, independentemente da coligada em que foram criados ou da tabela dinâmica vinculada.
* Para visualizar e gerenciar a existência desses campos, siga o caminho no menu: **Valorização | Requisições | Campos Complementares | Requisição de Transferência com Alteração de Dados Funcionais**
