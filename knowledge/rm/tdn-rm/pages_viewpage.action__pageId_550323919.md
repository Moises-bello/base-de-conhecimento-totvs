Uma outra opção para contabilizar os contratos é realizar o filtro diretamente na tela de visão dos contratos, disponíveis no Módulo Educacional | Financeiro/Contábil | Contratos

Após executar o filtro para selecionar os contratos que serão contabilizados, o usuário deverá marcar os contratos, acessar Processos | Gerar Contabilização

Clicar em Avançar

O usuário deve informar os campos conforme definição a seguir:

* **Mês/Ano**: Informar a competência que deseja contabilizar ou estornar;
* **Operação:** Informar se a operação é de “Contabilização” ou “Estorno”, seguindo os critérios:
  + **Contabilização**: Para realizar a contabilização por competência;
  + **Estorno**: Para realizar o estorno da contabilização da competência desejada.
* **Data de Contabilização**: Informar em qual data a contabilização será registrada.   
  **Observação**: Caso não seja informada nenhuma data neste campo, o sistema irá contabilizar no último dia do mês/ano informado no período de contabilização.
