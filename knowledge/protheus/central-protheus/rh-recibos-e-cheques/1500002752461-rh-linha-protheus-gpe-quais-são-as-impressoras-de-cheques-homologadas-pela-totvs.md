**Dúvida**Quais são as Impressoras de Cheques homologadas pela **TOTVS** para uso nos módulos da linha Protheus?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**Os modelos de impressoras de cheques que foram homologadas pela TOTVS para uso nos módulos da linha Protheus estão listados abaixo:

| FABRICANTE | MODELO | VERSÃO | P12 32 bits | P12 64 bits |
| --- | --- | --- | --- | --- |
| Bematech | DP10 |  | SIM | NÃO - descontinuada pelo Fabricante |
| Bematech | DP10 PLUS |  | SIM | NÃO - descontinuada pelo Fabricante |
| Bematech | DP20 |  | SIM | NÃO - descontinuada pelo Fabricante |
| Bematech | DP20 PLUS |  | SIM | NÃO - descontinuada pelo Fabricante |
| Chronos | 31100 |  | SIM | NÃO |
| Itautec | ZPM-300 256M PRT41 | 01.03.00 | SIM | NÃO |
| PertoChek | PertoChek 501S |  | SIM | NÃO |
| PertoChek | PertoPay |  | SIM | NÃO |
| Schalter | NSC | 2.00 | SIM | NÃO |

  
**Todos os equipamentos homologados acima estão disponíveis apenas em plataforma *Windows***

A homologação de novos equipamentos é feita através de projetos específicos desenvolvidos pela fábrica de Software. Inclusive para atualização de EPROM.
