# Tag's na contabilização por competência

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Contabilização por competência. |
| **Situação/Requisito:** | Na contabilização por competência a tag [COM.D] não é substituída corretamente. |
| **Solução/Implementação:** | Na realização da contabilização por competência a tag [COM.D] deve ser substituída conforme informações presente no processo.  Essa tag está disponível somente na contabilização por competência. Na contabilização por caixa deve usar a tag [MDC] do TOTVS Gestão Financeira para informar a competência no complemento de histórico na contabilização |
