# CADASTRO DE ESTABILIDADE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de estabilidade.* |
| **Situação/Requisito:** | Ao visualizar o cadastro de estabilidade, quando o cliente possui integração do RMLabore com o Vitae porém não possui integração do SSO com o Vitae o sistema deve listar os tipos de estabilidades referente a CIPA.  Códigos : 7,8,9 da tabela PMOTIVOESTAB.  Pois como o controle de CIPA e feito pelo SSO e o cliente não possui integração, estas estabilidades deve poder ser controladas pelo RMLabore. |
| **Solução/Implementação:** | *Foi ajustado o sistema para quando o cliente integração do RMLabore com o Vitae porém não possui integração do SSO com o Vitae ao acessar o cadastro de estabilidade dentro do Labore, sejam listados os tipos de estabilidade referente a CIPA para ser utilizado pelo sistema.* |
