**Lançamentos Globais - Horário Obrigatório**

O horário obrigatório deve ser lançado para o funcionário quando o mesmo deve estar na empresa em um horário determinado, mesmo se este dia for dia de descanso ou compensado. Este horário deve ser lançado apenas para funcionários com banco de horas diário por ocorrência. Caso o funcionário não trabalhe no horário estipulado o sistema calculará atraso ou falta para o funcionário.

Para fazer o lançamento é necessário preencher os campos abaixo:

**Horários Obrigatórios**

Informe o intervalo de horas para o lançamento do horário obrigatório.

**Cancelar Horários Obrigatórios**

Marque esta opção para cancelar os horários obrigatórios lançados para o(s) funcionário(s). O sistema só irá cancelar se informar o intervalo de hora igual ao que foi lançado
