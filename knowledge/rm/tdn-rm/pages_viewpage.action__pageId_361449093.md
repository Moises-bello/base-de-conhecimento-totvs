# INCLUSÃO DA DATA DE VIGÊNCIA COMO DATA DE INÍCIO DE NEGOCIAÇÃO DTS NA CÓPIA CONDIÇÃO CONTRATUAL E FINANCEIRA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cópia Condições Contratuais e Financeiras |
| **Situação/Requisito:** | Rotina não considera data de vigência como data de início de Negociação DTS |
| **Solução/Implementação:** | Inclusão do valor da data de vigência na coluna DTININEGOC da tabela SZNEGOCIACAODTS |
