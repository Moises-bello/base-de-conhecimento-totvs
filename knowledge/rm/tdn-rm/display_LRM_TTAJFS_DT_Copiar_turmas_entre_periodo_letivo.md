# COPIAR TURMAS ENTRE PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Copiar turmas entre período letivo* |
| **Situação/Requisito:** | *Ao realizar a copia de turma entre período letivo o sistema exibiu a seguinte mensagem de erro: O Controle de vagas definido na matriz curricular obriga o preenchimento do numero máximo de alunos..* |
| **Solução/Implementação:** | *Ajuste no processo que efetua a copia da turma para outro período letivo, onde o mesmo não estava copiando o número máximo de alunos da turma origem para a turma de destino.* |
