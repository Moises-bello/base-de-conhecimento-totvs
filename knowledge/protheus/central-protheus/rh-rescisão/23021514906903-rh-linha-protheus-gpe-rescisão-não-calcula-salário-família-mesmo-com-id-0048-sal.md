![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23021526112023) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Por que rescisão não calcula salário família mesmo com ID 0048 (saldo de salário) com incidência Não salário família?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O sistema não calcula salário família mesmo com ID 0048 (saldo de salário) com incidência Não salário família, devido outras verbas em rescisão estarem com incidência Sim salário família exemplo hora extra/DSR hora extra, deste modo o valor destas verbas são somados ao salário cadastro funcionário e passando a base tabela salário família não calcula o valor.
