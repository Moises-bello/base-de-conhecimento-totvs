Observação:

Não se deve usar variáveis de contexto em atividades de Fórmula Visual, pois não é possível recuperar informações do contexto do sistema durante a execução dela.

Essas variáveis trazem dados atuais ou dados sobre o contexto do sistema. Leia mais sobre variáveis de contexto:

**Exemplo:** Na atividade de consulta SQL não se deve utilizar uma consulta com variável de contexto.
