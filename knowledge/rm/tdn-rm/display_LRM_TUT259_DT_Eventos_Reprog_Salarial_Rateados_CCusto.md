# RECÁLCULO DE EVENTOS LANÇADOS PELA REPROGRAMAÇÃO SALARIAL RATEADOS POR CENTRO DE CUSTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Reprogramação Salarial* |
| **Situação/Requisito:** | *Quando ocorre lançamento de eventos através da Reprogramação Salarial rateando por Centro de Custo, o valor do evento está mudando a cada recálculo.*  *S**ituação específica ocorrida na base do cliente, que fez com que o valor original do evento não correspondesse ao total do valor rateado na Reprogramação Salarial.* |
| **Solução/Implementação:** | *Ajuste no recálculo de eventos lançados pela Reprogramação Salarial, quando é rateado por centro de custo, e o valor original do evento não corresponde ao total do valor rateado.* |
| **Chamados   relacionados:** | *TUT259, TUUEUW* |
| **Versões/Release:** | *11.82.44, 12.1.11* |
