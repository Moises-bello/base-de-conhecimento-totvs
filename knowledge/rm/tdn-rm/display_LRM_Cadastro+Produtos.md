## **01. VISÃO GERAL**

São atividades que representam o processo de produção e a contabilização do seu resultado é registrada sob o título de custo dos produtos vendidos ou custo dos serviços prestados. Exemplos de produtos são os “atendimentos” realizados pela unidade de Enfermaria. Como consta no item anterior a tela Produtos Custo pode ser chamada direto da tela Produtos do Centro de Custo Detalhe, mas também é possível acessá-la através da opção Outros Cadastros/Produtos no menu principal do módulo.

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Clique no botão Incluir (Página em branco) para incluir um novo cadastro de produto. 2. No campo Código Produto informe um código para ser referência ao produto. 3. No campo Produto informe uma breve descrição. 4. Clique em OK. |
