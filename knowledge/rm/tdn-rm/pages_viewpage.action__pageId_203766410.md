# Como Gerar relatório de Consumo de Medicamento Alíquota Zero?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como Gerar relatório de Consumo de Medicamento Alíquota Zero? |
| **Passo a passo:** | Consumo de Medicamentos Alíquota Zero Nessa opção são listados todos os medicamentos de "alíquota zero" (produtos que possuem código TIPI) que foram lançados na conta do paciente dentro do período informado.  No relatório as colunas **Vr. Unit., Quantidade e Vr. Total** são os valores deste item na conta do paciente. As colunas COFINS, PIS e Total Impostos existem apenas no relatório e são calculados a partir do valor do item na conta e o percentual definido em **Parâmetros Gerais/Estoques II/Medicamentos Tributados (Lei 10.147/00).**   Gerando Relatório de Consumo de Medicamentos Alíquota Zero  1. No **TOTVS Gestão Hospitalar** acesse **Estoques/Consultas e Relatórios/Consumo de Medicamentos Alíquota Zero.** 2. Informe o período para geração do relatório. 3. Selecione a opção **Resumo**. 4. Clique em **Imprime**. |
