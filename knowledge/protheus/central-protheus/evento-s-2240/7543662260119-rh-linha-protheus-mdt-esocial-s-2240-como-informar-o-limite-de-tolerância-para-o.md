![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21247023496471) Tempo aproximado para leitura: **00:04:00 min** **Dúvida**Como informar o limite de tolerância para o eSocial e referenciar a NR15, ACGIH ou NHO01?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho – Todas as versões  
  
**Solução**Por padrão o módulo SIGAMDT oferta apenas um limite de tolerância.  
Se para o mesmo agente existe avaliações diferentes, deve ser realizado um cadastro para cada limite de tolerância.  
  
No menu Atualizações - PPRA - Agentes, para os códigos 01.18.001 (Sílicia livre) e 02.01.014 (Trabalhos com exposição ao calor), entre em **Outras Ações - Limite Tolerância**:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21247007183895)  
  
É possível incluir mais de um limite para cada agente, porém, para o eSocial será considerado a intensidade de maior valor.  
Foi disponibilizado o campo "Normativa" com as opções NR15, ACGIH (Conferência Americana de Higienistas Industriais Governamentais) e NHO01 (apresenta limites de tolerância mais conservadores que garantem maior nível de proteção).  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23085074938775)

De acordo com o MOS (Manual Orientação eSocial), só deve ser enviado um limite de tolerância quando utilizado os agentes 01.18.001 (Sílicia livre) e 02.01.014 (Trabalhos com exposição ao calor), sendo que para os demais agentes não é obrigatório ter um limite de tolerância.
