# Configuração de Esquema de Parâmetros - RM Portal - Gestão de Conteúdos

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 11.XX; 12.1.XX |
| **Ocorrência:** | Configuração de Esquema de Parâmetros – RM Portal – Gestão de Conteúdos |
| **Ambiente:** | Portal WEB - Gestão de Conteúdos |
| **Passo a passo:** | Na MDI, selecione o menu iniciar, Gestão de Conteúdos:     Na aba Ambiente, selecione o menu Parâmetros / RM Portal:    No assistente de implantação de processo, clique em avançar:     Selecione o Esquema de Parâmetros e clique em avançar:    Poderá criar novos esquemas de parâmetros, selecionando o menu incluir:    Ou parametrizar o esquema desejado, selecionando o menu Parametrizar:     Clique em avançar e configure conforme desejado:    A criação de novos esquemas também pode ser realizada através do cadastro de localidade, aba RM Portal, localidade, esquema de parâmetros: |
