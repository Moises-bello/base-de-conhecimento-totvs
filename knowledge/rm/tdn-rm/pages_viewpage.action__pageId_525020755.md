**O sistema foi evoluído para realizar a conversão dos Cli/For para Global.**

Este processo é recomendado para os usuários que já utilizam ou irão utilizar os cadastros de Cli/For globais, e aqueles que fazem integração com o Protheus pelo módulo Totvs Construção e Projetos e Totvs Gestão de Estoque, Compras e Faturamento com SigaMNT.

**Melhoria no [Template de Acordo](https://tdn.totvs.com/display/LRM/Template+de+Acordo).**

A opção "Data Aprovação/Sistema" foi alterada para "Data Sistema" mantendo o comportamento atual do sistema e foi criada a opção de "Data Aprovação/Efetivação" que terá outro efeito no processo e Acordo.

**Evolução do sistema para atender a rotina do Livro de Caixa do Produtor Rural.**

O Livro Caixa de Produtor Rural é uma rotina que necessita de informações de Pessoas físicas que realizam atividades de exploração Rural. O [cadastro de Terceiros](https://tdn.totvs.com/display/LRM/Cadastro+de+Terceiros) possibilita a identificação das partes terceiras envolvidas na exploração de propriedades rurais. 

**Melhoria no cadastro de [Cliente/Fornecedor](https://tdn.totvs.com/pages/viewpage.action?pageId=421388786).**

No cadastro de Cliente Fornecedor foi criado o campo  "Cadastro de Atividade Econômica da Pessoa Física" para informar os dados do cadastro de dados de atividades econômicas exercidas pela pessoa física.

**Melhoria no processo de [Acordo](https://tdn.totvs.com/x/G_EdGQ) e negociação online.**

Implementado no template de acordo um campo para que seja definido o valor do percentual a ser considerado na primeira parcela do acordo a ser gerado.
