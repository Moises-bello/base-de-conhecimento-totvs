Nesta opção cadastra-se a tabela de modelos de taxa.  
O cadastro de Modelos de Taxas consiste na efetuação de registros de todas as possíveis taxas.

**Observações**  
As taxas cadastradas podem ser copiadas para projetos locais através do menu Opções | Cópia de Itens, pasta Modelos de Taxas. Esse menu só fica habilitado quando o projeto de origem é um projeto Global.  
No processo de cópia de itens serão copiados apenas Modelos de Taxas com taxas cadastradas.

 Código   
Informe um código para o modelo de taxa. Não é permitida a inclusão de códigos repetidos, portanto, um código somente refere-se a um determinado modelo de taxa. Este campo é alfanumérico.

Descrição

Descrição do modelo de taxa.
