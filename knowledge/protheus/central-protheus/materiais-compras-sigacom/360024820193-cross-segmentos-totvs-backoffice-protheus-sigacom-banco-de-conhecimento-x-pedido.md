**Dúvida**Qual a tratativa / comportamento que o sistema efetua ao anexar Documento ao Pedido de Compras ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – A partir da versão 11.80  
  
**Solução**Ao efetuar a inclusão de um arquivo / conhecimento no item do Pedido, este ficará relacionado apenas para a linha posicionada / item posicionado.  
  
Ao consulta a tabela AC9 - (Relação de Objetos x Entidades), perceba que sistema efetua o relacionamento item a item e não para o Pedido de Compras como um todo.
