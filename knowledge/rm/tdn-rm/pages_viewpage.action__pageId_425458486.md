**Especialidade**   
Através deste cadastro é possível definir quais são as especialidades do atendente.   
**Atenção**  
Para qualquer ícone desabilitado, verifique com o Supervisor as permissões do usuário em questão em Cadastros | Segurança | Perfis | Pasta Acesso a Menus.  
Através deste cadastro é possível controlar:  
**Identificação**   
   
Na pasta Identificação devem ser informados os seguintes dados:  
Produto  
Selecione neste campo a especialidade (Produto) que o atendente possui. Se for o caso, um atendente pode ter mais de uma especialidade.   
Nível  
Selecione nesta opção, qual o nível de conhecimento que o atendente possui para a especialidade que está sendo cadastrada.   
Atendente default para esta especialidade  
Selecione esta opção se o atendente for fixo para esta especialidade, ou seja, se o atendente estará sempre atendendo a especialidade que está sendo cadastrada.   
Atendente preferencial para representante nesta especialidade  
Selecione esta opção se o atendente atende apenas representantes e clientes vips.
