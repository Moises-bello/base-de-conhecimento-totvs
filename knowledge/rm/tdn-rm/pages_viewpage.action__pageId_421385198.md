**Campo Livre 1** Informe o nome que deseja atribuir para o campo livre 1 do projeto. Este campo é alfanumérico, ou seja, permite armazenamento de textos.

**Campo Livre 2** Informe o nome que deseja atribuir para o campo livre 2 do projeto. Este campo é alfanumérico, ou seja, permite armazenamento de textos.

**Campo Livre 3** Informe o nome que deseja atribuir para o campo livre 3 do projeto. Este campo é alfanumérico, ou seja, permite armazenamento de textos.

**Campo Livre 4** Informe o nome que deseja atribuir para o campo livre 4 do projeto. Este campo é alfanumérico, ou seja, permite armazenamento de textos.

**Campo Livre 1 (valor)** Informe o nome que deseja atribuir para o campo livre 1 (valor) do projeto. Este campo é numérico, ou seja, permite armazenamento somente de valores.

**Campo Livre 2 (valor)** Informe o nome que deseja atribuir para o campo livre 2 (valor) do projeto. Este campo é numérico, ou seja, permite armazenamento somente de valores.

**Observação:**

São desativados, automaticamente, os campos livres que não possuem nome.
