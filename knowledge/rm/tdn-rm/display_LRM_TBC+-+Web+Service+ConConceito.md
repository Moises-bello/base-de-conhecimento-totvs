## **Introdução**

---

O Web Service **wsConConceito**é o responsável pela execução de conceitos do sistema

## **Como funciona**

---

   Estão expostos no **wsConConceito**alguns serviços, onde para consumi-los é necessário enviar através de uma requisição um envelope SOAP, passando os parâmetros de cada serviço.
