# INCLUSÃO DE BOLSAS NO CONTRATO DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Inclusão de bolsas no contrato do aluno* |
| **Situação/Requisito:** | *Ao incluir uma bolsa já existente no contrato, porém para escopo de parcelas diferentes, pode ocorrer do sistema não permitir a inclusão da bolsa, caso a data de vencimento das parcelas envolvidas sejam iguais.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de inclusão de bolsas, de forma que o sistema suporte a inclusão de uma mesma bolsa no contrato do aluno, com escopo de parcelas diferentes, independente da data de vencimento da parcela.* |
