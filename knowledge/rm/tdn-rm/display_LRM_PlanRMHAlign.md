# Descrição

---

Define o alinhamento horizontal de uma célula ou objeto.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| General | Define que textos serão alinhados à esquerda, números (inclui datas e horas) serão alinhados à direita, e valores lógicos serão centralizados. |
| Left | Define o alinhamento à esquerda. |
| Center | Define que o texto será centralizado |
| Right | Define o alinhamento à direita. |
| Fill | Define que o texto será repetido até que preencha a célula. |
| Justify | Define que o texto será justificado exceto a última linha que será alinhada à esqueda. |
| CenterAcrossSelection | Define que o texto será centralizado através das células vazias sem que elas sejam mescladas. |
| Distributed | Define que o texto será justificado inclusive a última linha. |
