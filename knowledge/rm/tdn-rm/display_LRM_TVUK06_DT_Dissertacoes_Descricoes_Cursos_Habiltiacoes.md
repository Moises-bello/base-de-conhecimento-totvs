# Informações de Dissertações e Descrições de Cursos e Habilitações

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Cadastro de Dissertações e Descrições de Cursos e Habilitações* |
| **Situação/Requisito:** | *As informações cadastradas na Matriz Aplicada de dissertações e descrições não estão aparecendo na página de Cursos da instituição no portal.* |
| **Solução/Implementação:** | *Após um melhoria no sistema para adequação a uma legislação as informações tiveram sua localização alterada do cadastro de Curso e Habilitação para o cadastro de Matriz Aplicada.*  *Essa alteração impactou na visualização dessas informações no portal, uma vez que elas não existem mais nos cadastro de Cursos e Habilitações.*  *Para a solução, os campos foram removidos da visualização no Portal.* |
