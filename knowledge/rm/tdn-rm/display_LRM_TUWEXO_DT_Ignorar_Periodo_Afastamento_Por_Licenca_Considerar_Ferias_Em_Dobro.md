# FÉRIAS EM DOBRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Férias em Dobro* |
| **Situação/Requisito:** | Processo de Férias em Dobro para funcionaria afastada por licença maternidade. Cliente solicita que o sistema dê a flexibilidade de estender ou não o período aquisitivo. |
| **Solução/Implementação:** | *Criado o parâmetro: 'Não interrompe contagem do período para pagto de férias em dobro no afast. por Licença Maternidade (E)'*   Com esse parâmetro o usuário pode definir se o período do afastamento por Licença maternidade será ou não considerado para verificar se o funcionário tem direito a férias em dobro. |
