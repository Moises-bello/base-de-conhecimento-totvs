# ANÁLISE CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Análise Curricular* |
| **Situação/Requisito:** | *Na análise curricular são exibidas como 'disciplinas extras' as disciplinas feitas em outros cursos, independente do curso/Habilitação selecionado.* |
| **Solução/Implementação:** | *Ajustes na exibição de 'disciplinas extras'  na análise curricular. Para não impactar os clientes que aceitam a utilização da análise curricular conforme é realizada hoje foi criado o parâmetro 'Exibir somente disciplinas extras realizadas no curso' (Parâmetro disponível em: Parâmetros Gerais -> Geral 2/6 ).*  *Ao selecionar esse parâmetro a análise curricular passará a exibir como disciplina extras somente as disciplinas matriculadas dentro do curso.*  *Obs: As disciplinas constantes em matrícula isolada aparecerão nas análises curriculares de todos os cursos/habilitação, já que a matrícula não faz parte de um curso específico.* |
| **Conversores e Parâmetros:** | *'Exibir somente disciplinas extras realizadas no curso'  *(Parâmetro disponível em: Parâmetros Gerais -> Geral 2/6 ).** |
