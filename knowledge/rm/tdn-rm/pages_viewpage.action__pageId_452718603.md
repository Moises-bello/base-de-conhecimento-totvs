**Processos - Reabrir Avaliação**

Por este processo é possível reabrir uma avaliação, para que seja possível respondê-la novamente.

**Observações**

- O sistema não deve permitir que avaliações "finalizadas", onde já ocorreu a atualização das competências no cadastro dos funcionários, sejam reabertas.

- Modalidade 90 e 360 graus: O sistema deve reabrir a avaliação selecionada.

- Modalidade 180 graus, reabrindo uma avaliação não-consensual: Todas as consensuais relacionadas com a que está sendo reaberta serão removidas.

- Modalidade 180 graus, reabrindo uma avaliação consensual: Caso seja selecionada apenas uma avaliação que é consensual, deve apenas reabrir.

- O sistema não deve reabrir uma avaliação que tenha a data limite para execução menor que a data atual.

**Atenção**

- Ao responder a avaliação novamente, as respostas anteriores devem ser visualizadas no RM Portal.

- A avaliação reaberta deve passar a ter o status do andamento como "em andamento" (cor laranja).
