![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16036970633495) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como realizar o agendamento de exames de forma global?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Segurança e Saúde Ocupacional - Todas as versões.  
  
**Solução**A criação de agenda de exames de forma global, ocorre através do processo de Assistente de Agendamento Automático. Para criar as agendas, siga os passos abaixo:

* Acesse o menu **PCSMO | Assit. Agenda de Exames** e ao abrir o assistente clique em avançar:  
  ![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9451917313943)
* Em **Opções do Agendamento**: Neste passo o usuário deverá informar os dados do agendamento e do convênio como: data de início do agendamento, número de atendimentos por horário e as opções de convênio (menor preço, menor tempo ou informar convênio específico).    
  ![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452367059607)
* **Seleção de Pessoas:** Neste passo deverão ser selecionadas as pessoas que terão exames agendados. O usuário terá a opção de escolher pessoas ou funcionários e de criar filtros para selecionar as pessoas desejadas.   
  ![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452424877463)
* **Seleção de Médicos:** Nesse passo o usuário pode informar se deseja "Prosseguir o agendamento de exames sem agendar consultas clínicas" ou "Agendar consultas clínicas para análise do resultado dos exames". Caso o usuário escolha em agendar consultas clínicas, o campo "Tipo de Consulta" e "Médico" serão habilitados para preenchimento.  Caso não deseje basta avançar este passo.   
  ![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452483170199)
* **Seleção de Exames:** Neste passo deverão ser selecionados os exames para agendamento. Poderão ser selecionados por tipo de exame, os exames pendentes, ou outros exames.   
  ![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452542372119)
* **Pessoas x Exames:** O sistema exibe as pessoas e os respectivos exames agendados. Para visualizar os exames clique sobre o sinal de +, para expandir a arvore.![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452583238551)  
  Neste passo ainda é possível remover algum exame que o funcionario não deva realizar, para isso selecione o exame e clique no botão Remover Exames Selecionados:  
  ![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9452661517719)  
    
  Ao avançar, será concluído o processo e assim para cada exame agendado é salvo um registro do na agenda de exames com os respectivos dados informados no processo. Caso a opção de agendamentos de exames seja selecionada os exames serão gerados estando vinculados à uma consulta clínica para análise dos mesmos. Essa consulta irá ser criada com o status "Agendada".
