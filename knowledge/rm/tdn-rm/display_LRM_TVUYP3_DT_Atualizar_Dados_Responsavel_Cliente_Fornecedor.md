# ALUNOS - RESPONSÁVEIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Alunos - responsáveis* |
| **Situação/Requisito:** | *No cadastro de alunos, na guia responsáveis, quando é atualizado os campos de telefones de uma pessoa que é vinculada a responsável financeiro do aluno, quando é selecionado a opção para atualizar os dados do responsável financeiro os telefones não são atualizados, somente o primeiro telefone, quando o mesmo é inserido a primeira vez como responsável financeiro do aluno, todos os telefones são inseridos corretamente no cadastro de cliente fornecedor.* |
| **Solução/Implementação:** | *Foi feito um ajuste na função que atualiza os dados do cliente fornecedor para que atualize também todos os telefone (telefone 1, 2, 3 e fax), para todos os itens de endereço do cliente fornecedor (principal, pagamento e entrega).* |
