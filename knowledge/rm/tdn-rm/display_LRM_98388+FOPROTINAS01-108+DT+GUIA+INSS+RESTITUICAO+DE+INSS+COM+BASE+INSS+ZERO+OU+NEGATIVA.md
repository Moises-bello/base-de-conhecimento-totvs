# GUIA INSS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | Calculo do INSS Segurado com restituição de código de calculo 153  - RESTITUICAO INSS 13o SALARIO. |
| **Situação/Requisito:** | Os eventos de código de cálculo 92 - RESTITUICAO DE INSS e 153 - RESTITUICAO INSS 13o SALARIO estavam sendo abatidos do valor dos eventos de código de cálculo 3 - INSS mesmo com base INSS ou base INSS 13 zeradas ou negativa. |
| **Solução/Implementação:** | Os eventos de código de cálculo 92 - RESTITUICAO DE INSS e 153 - RESTITUICAO INSS 13o SALARIO passam a ser  abatidos do valor dos eventos de código de cálculo 3 - INSS somente se as bases INSS ou base INSS 13 forem positivas. Igualando o comportamento do SEFIP e Folha analítica. |
