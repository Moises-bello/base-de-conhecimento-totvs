![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31884520743831) Tempo aproximado para leitura: **00:00:10 min** **Dúvida**Qual é a diferença entre os **tipos de imposto** com prefixos como *PI- / CS- / CF-* e os códigos *PIS / COF / CSL*?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA040- Todas as versões  
  
**Solução**Os tipos de impostos são definidos conforme o parâmetro **MV\_BR10925**.  
Quando esse parâmetro está configurado, ao informar os dados de baixa, o sistema grava os tipos de impostos como **PIS / COF / CSL**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/31884482436503)

E quando o parâmetro está configurado para gerar os impostos no momento da emissão, os tipos são gravados como **PI- / CS- / CF-**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/31898484871831)
