**Dúvida**Como Lançar Afastamentos (ausências / atestados) para um Funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para lançar uma ausência para o funcionário, realize os seguintes passos:  
  
1. Acesse a rotina de **Cadastro de Ausências**através do menu **Atualizações > Lançamentos > Ausências**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10844242121239)  
  
2. Selecione o funcionário que deseja incluir e clique em **Manutenção**

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10844249623191)  
  
3. Preencha campos de acordo com o **Código da Ausência** informado no campo **R8\_TIPOAFA (****Cód. Ausenc.)**e os dados de documento comprobatório de ausência apresentado pelo funcionário - atestado, por exemplo.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10844306971799)

**Observações:** O campo **Sequência** é preenchido automaticamente pelo sistema.  
  
**Importante**: Para **afastamento que são sequencia de um afastamento anterior**, é necessário informar o **número de sequencia** para que o sistema faça o cálculo correto dos dias a serem pagos pela empresa (15 dias):  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10844349894039)
