![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22395668206231) Tempo aproximado para leitura: **00:01:30** min **Dúvida**Geração de CNAB para autônomo   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O conceito de geração do arquivo CNAB para autônomos segue a mesma regra de geração para celetistas:   
  
1) Cadastro do autônomo com CPF e dados de Banco, Agência e Conta:   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/22399248251543)

2) Existir cálculo de folha com valor de líquido:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22399248232087)

3) Configurar as perguntas com os filtros principais configurados para busca do valor. Exemplo: Roteiro AUT, Processo: 00003, Categoria A - Autônomo. Abaixo um processamento da rotina de CNAB para esta categoria:

![gif cnab AUTONOMO.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/22399248257943)
