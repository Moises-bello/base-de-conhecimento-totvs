Esta opção permite a geração do movimento tendo como referência os boletos gerados para pagamento dos profissionais que são cadastrados como cliente/fornecedor. Para a geração do movimento o usuário deverá seguir os passos abaixo:

Descontinuação

À partir das versões 12.1.2506.281, 12.1.2510.203 e 12.1.2602.125 este processo foi descontinuado.

**Pré requisitos:**

* O cliente/fornecedor do funcionário do processo seletivo deve ser do tipo fornecedor ou ambos.
* Este processo só será executado se primeiro for executado o processo de .

O processo para geração do movimento está disponível no menu de processos do processo seletivo.

 

* **Tipo de movimento:**Escolha o tipo de movimento correspondente.
* **Data de emissão do movimento:** escolha qual será a data de emissão do movimento. As opções são:
  + Data de emissão do lançamento
  + Data de vencimento do lançamento
  + Data de baixa do lançamento (somente para lançamentos baixados)
* **Dia fixo relacionado ao mês/ano da data de emissão do movimento:**Informe um dia fixo para a data de emissão do movimento.
* **Gerar movimentos para boletos de valor líquido igual a zero:** marque esta opção para que seja possível gerar movimentos referentes a lançamentos com valor liquido igual a zero.
