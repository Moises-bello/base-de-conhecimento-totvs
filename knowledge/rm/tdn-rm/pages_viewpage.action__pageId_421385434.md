Através desta integração será possível utilizar todos os recursos deste poderoso software de gerenciamento e acompanhamento de projetos, tais como: PERT / CPM GANTT Integração com o MS Office Gráficos e relatórios diversos  
 Você poderá criar os projetos / planilhas diretamente no Construção e Projetos, exportá-los para o MS Project, utilizar as ferramentas disponíveis no MS Project para atualizar estes projetos e sincronizar os mesmos com o Construção e Projetos através de variadas opções.  
 No MS Project você poderá visualizar de diversas formas o seu projeto utilizando as várias opções que o MS Project disponibiliza.  
 É mantida a compatibilidade dos códigos das tarefas com o NET (número de estrutura de tópico) do MS Project, isso porque esse código é muito mais estável, pois não é permitida intervenção direta do usuário.  
 Ao Exportar a planilha de tarefas do Construção e Projetos para o MS Project é possível definir em qual grandeza será exportada a tarefa para o MS Project. Basta selecionar no campo Unidade da Coluna Duração em qual unidade se deseja exportar o projeto. É possível escolher entre Minutos, Horas e Dias, o default é a grandeza Minutos.
