# Título do Educa Mobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educa Moible |
| **Função:** | Título do TOTVS Educa Mobile |
| **Situação/Requisito:** | Ao acessar o TOTVS Educa Mobile através do eduCONNECT, o título definido no eduCONNECT não é propagado para o TOTVS Educa Mobile. |
| **Solução/Implementação:** | Foi realizado otimização do título do eduCONNECT para que seja propagado e carregado no TOTVS Educa Mobile quando o usuário acessar o TOTVS Educa Mobile de dentro do eduCONNECT. |
