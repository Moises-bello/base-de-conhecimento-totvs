## 

**CONTEÚDO**

## **01. VISÃO GERAL**

O processo de importação dos dados do Censo deve ser feita para atualizar as informações de alunos e professores com as informações que são geradas pelo INEP, após o período de coleta dos dados do Censo. É utilizado tanto para o Censo da Educação Básica quanto para o Censo da Educação Superior. Porém, para o Censo Superior, apenas o arquivo de alunos pode ser importado porque não existem informações de professores para serem atualizadas.

O objetivo da atualização dos dados do Censo através da importação é para que na próxima coleta de dados do INEP essas informações possam ser geradas e enviadas.

No Censo Superior, a atualização das informações não é obrigatória porque os dados atualizados não são de envio obrigatório para o INEP. Já no Censo Básico, é imprescindível fazer a atualização antes da segunda etapa do Censo (que é o envio da Situação do Aluno). As informações atualizadas na importação são obrigatórias para o envio ao INEP nessa segunda etapa.

## **02. UTILIZAÇÃO**

Antes de fazer a importação, deve ser feita exportação do arquivo contendo os dados do Censo através do portal do INEP. Esse arquivo que deve ser utilizado na importação. Para isso, basta selecionar o arquivo e executar o processo de Importação de dados do Censo Escolar.

### Campos que serão atualizados na importação do Censo Superior

Código INEP do aluno na tela de Dados do Censo Escolar do aluno

### Campos que serão atualizados na importação do Censo Básico

Código INEP da Turma na tela de dados do Censo da turma

Código INEP do Gestor na tela de cadastro de gestores

Código INEP do professor na tela de Dados do Censo Escolar do professor

Código INEP do aluno na tela de Dados do Censo Escolar do aluno

**Novidades!!!** A partir da versão 12.1.31, houve alteração no processo de importação do Censo Básico. Agora é possível consultar o arquivo e visualizar o histórico da importações.
