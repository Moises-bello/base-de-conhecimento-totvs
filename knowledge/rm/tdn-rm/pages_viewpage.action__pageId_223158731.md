# Quais são as configurações e cadastros da TISS 3.02.00 no TOTVS Gestão Hospitalar?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | TISS 3.02.00 |
| **Ocorrência:** | Quais são as configurações e cadastros da TISS 3.02.00 no TOTVS Gestão Hospitalar? |
| **Passo a passo:** | **Motivos de Alta - ANS**  Cadastro de motivos de alta TISS, utilizado no momento de informar os dados TISS do atendimento.  Menu de acesso: **Cadastros/Uso Geral/TISS/Motivos de Alta – ANS**.      **Conselho Profissional**  Cadastro de conselho profissional, utilizado no cadastro dos prestadores.  Menu de acesso: **Cadastros/Uso Geral/TISS/Conselho Profissional**.      **Tipo de Acomodação**  Cadastro dos tipos de acomodações, utilizados para associação à classe de acomodação dos leitos do hospital. Através dessa associação, o sistema sabe que tipo de acomodação do padrão TISS o paciente estava alocado para enviar no *XML*.  Menu de acesso: **Cadastros**/**Uso Geral/TISS/Tipo de Acomodação**.      **Grau de Participação**  Cadastro de grau de participação de um prestador ao procedimento realizado. Essa rotina tem por objetivo associar os tipos de participações internos do sistema aso valores de referência utilizados pela **ANS**.  Menu de acesso: **Cadastros/Uso Geral/TISS/Grau de Participação**.      **Regras para Definição do CBO**  Nessa opção é possível cadastrar uma regra para aplicação dos CBOs dos prestadores para determinados procedimentos realizados. Para a criação de uma regra de aplicação é possível definir para qual tipo de procedimento é aplicável (Honorário ou Diagnose e Terapia/SADT) ou se não será aplicado. Há, também, as opções para ser informados o prestador, grau de participação a ser considerada para aplicação da regra ou a especialidade. Informe também o CBO que será utilizado na aplicação da regra.  Menu de acesso: **Cadastros**/**Uso Geral/TISS/Regras para Definição do CBO**.      **Motivos de Glosa ANS**  Cadastro de motivos de glosa utilizado para validações nos lançamentos enviados nos *XMLs* das diversas rotinas do TISS. Os motivos de glosa serão utilizados por grupo de classificação (Atendimento, Autorização/Solicitação, Diagnóstico, Diária, Elegibilidade, Exames, Gases Medicinais, Guia, Honorários, Material, Medicamento, Mensagens de Sistema, Odontologia, OPM, Outros, Pacotes, Prestador, Procedimento, Procedimentos em Série, Protocolo, Regra de Valorização, Revisão de glosa, Taxas e aluguéis).  Menu de acesso: **Cadastros**/**Uso Geral/TISS/Motivos de Glosa – ANS**.      **Correlação Unidade de Medida**  Opção utilizada para efetuar a correlação das unidades de medidas de produtos utilizados no **TOTVS Gestão Hospitalar / TOTVS Gestão de Estoque** com as unidades de medidas da **ANS** padrão TISS. Essa correção é importante ser feita para que, no momento de encerrar uma conta que utilize padrão TISS 3.02.00 da **ANS** as unidades de medidas utilizadas nos produtos da conta do paciente sejam validadas de acordo com a tabela de domínio da **ANS**.  Menu de acesso: **Cadastros**/**Uso Geral/TISS/Correlação Unidade de Medida**.      **Versão Tiss**  Nessa rotina são informados quais relatórios são referentes às guias impressas da TISS (Guia de Resumo de Internação, Guia de honorário Individual, Guia de SP/SADT, Guia de Solicitação de Internação, Guia de Consulta, Guia de Outras Despesas, Guia de Solicitação de SP/SADT, Guia de SP/SADT Terceiros). É possível informar os relatórios por versão do TISS não se aplicando mais a parametrização de guias nos parâmetros gerais.  **Menu de acesso: **Cadastros/Uso Geral/TISS/Versão TISS**.**      **Condições Contratuais com o Convênio**  Nas **Condições Contratuais com o Convênio**, na aba **Geral** deve ser informada a versão TISS que o convênio utiliza no campo “**Versão dos arquivos XML**”. As demais configurações deverão permanecer as mesmas caso o convênio já utilize versões anteriores da TISS como padrão de faturamento.  Menu de acesso: **Cadastros**/**Faturamento/Condições Contratuais com o Convênio**.      Na aba **WebService** informe os endereços dos webservices da operadora para rotinas de validação online como Solicitação de Elegibilidade, Solicitação de Autorização, Envio de Lotes de Guias, Solicitação de Cancelamento de Guias, Solicitação de Status de Autorização, Solicitação de Demonstrativo de Retorno.  Menu de acesso: **Cadastros/Faturamento/Condições Contratuais com o Convênio**.      **Cadastro de Produtos**  Em cada produto utilizado no **XML** da TISS deve ser configurado o registro do produto na **ANVISA**.  Menu de acesso: **Cadastros/Estoque/Produtos/Botão Anexos/Informações – TOTVS Saúde**.      **Atualização dos Códigos TUSS para os Produtos**  Temos três formas de atualização do código TUSS para os produtos para serem enviados no **XML** do TISS:   * Atualização manual do produto.   Entre na tabela de preço utilizada pelo convênio e preencha o campo “**Código Específico**” com o código TUSS. Para produtos onde o código possuir 10 dígitos preencha o campo “**Código Específico (10 dígitos)**”.  Menu de acesso: **Cadastros/Estoque/Produtos/Botão Anexos/Informações – TOTVS Saúde/Botão Anexos/Tabela de Preço.**      **Importação do Brasindice / Simpro**  As tabelas Brasindice e Simpro já possuem a opção de exportação dos arquivos com o código TUSS o que possibilita a associação desses códigos com os produtos do sistema de forma automática após a importação no sistema. Para realizar a importação dos códigos proceda da seguinte forma:  Acesse a rotina de importação do Brasíndice (**Utilitários/Rotinas/Importação/ Atualização BRASÍNDICE**) ou do SIMPRO (**Utilitários/Rotinas/Importação / Atualização SIMPRO**) e importe os arquivos normalmente marcando a opção “**Atualizar produtos com o código TUSS**”.        **Cadastro de Procedimentos TUSS**  A TUSS padroniza os código e nomenclatura dos procedimentos médicos e com isso os códigos enviados no *XML* precisam ser configurados. Isso pode ser feito de duas formas:  Associando código TUSS em uma tabela diferente da TUSS utilizada pelo convênio (Aplicação em tabelas de procedimentos e DTS).  Há casos onde o convênio, contratualmente, utiliza uma tabela diferente da TUSS para valorização e pagamento e, somente, no XML e impressão das contas serão enviados os códigos TUSS. Para configurar o sistema para utilizar esse caso preencha o código TUSS no campo código próprio no cadastro de cada procedimento.  Menu de acesso: **Cadastros/Faturamento/Tabelas de Procedimentos e Serviços**.    Em conjunto com essa configuração é necessário habilitar o parâmetro “**Imprime Código Próprio do Convênio**” nas condições contratuais.    **Importação da Tabela TUSS**  Casos onde o convênio utiliza a própria tabela TUSS para efetuar valorização de pagamentos, podem ser importadas no sistema e o próprio código TUSS será o código do procedimento/DTS da tabela. Com isso não há a necessidade de preenchimento do código próprio. Para novas tabelas a serem importadas solicite ao convênio o *XLS* da tabela e abra um chamado no portal TOTVS solicitando o *script* de importação da tabela. |
