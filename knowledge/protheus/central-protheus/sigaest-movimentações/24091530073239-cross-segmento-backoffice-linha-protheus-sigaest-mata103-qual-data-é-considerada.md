Qual data é considerada para o Movimento no Kardex (MATC030) quando incluimos Documento de Entrada no Protheus?

![d1_dtdigit 1.JPG](https://centraldeatendimento.totvs.com/hc/article_attachments/24091787934103)

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões  
  
**Solução**

Ao incluir um Documento de Entrada no Protheus a Data considerada é a Data Base definida no acesso ao Protheus. Verificando nas tabelas vai popular o **campo D1\_DTDIGIT** com essa informação.
