# GERAÇÃO DE LANÇAMENTOS FINANCEIROS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Regerar lançamentos financeiros pertencentes a contratos que possuem movimento por competência gerado. |
| **Situação/Requisito:** | Ao tentar regerar um lançamento financeiro pertencente a um contrato que tenha movimento gerado em regime de competência, o sistema não permite que o lançamento seja regerado devido um vínculo existente entre o movimento e o lançamento financeiro. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimento em regime de competência, de forma a não criar vínculos entre lançamentos financeiros e movimentos gerados em regime de competência. |
