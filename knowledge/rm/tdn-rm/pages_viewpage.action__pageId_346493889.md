# Retorno bancário com lançamentos repetidos no arquivo.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Retorno Bancário de Cobrança. |
| **Situação/Requisito:** | Ao realizar o retorno de cobrança com vários boletos e lançamentos repetidos no arquivo, o sistema realiza a baixa do lançamento pelo valor liquido ao invés de respeitar o valor do arquivo. |
| **Solução/Implementação:** | Ajuste no retorno bancário para realizar a baixa do boleto de acordo com o valor do arquivo. |
| **Requisito:** | FIN000169 |
