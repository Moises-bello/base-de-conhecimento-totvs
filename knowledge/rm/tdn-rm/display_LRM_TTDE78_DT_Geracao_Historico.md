# GERAÇÃO DE HISTÓRICO - ENSINO BÁSICO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Geração de histórico do Ensino Básico* |
| **Situação/Requisito:** | *Ao gerar histórico para o aluno da mesma serie do período letivo (2014, por exemplo) passado onde o aluno repetiu toda a série no período letivo do ano seguinte (2015), o processo sobrepõem do ano anterior (2014).* |
| **Solução/Implementação:** | *Ajuste no processo de geração de histórico para que não ocorra a sobreposição dos anos anteriores. A sobreposição somente ocorrerá se for do mesmo ano, porém para isso, deverá estar marcado o parâmetros "Sobrepor séries já existentes" na execução do processo.* |
