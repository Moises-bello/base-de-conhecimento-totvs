**Dúvida**  
Não foi possível carregar os dados para colaborador  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
Validar configuração do usuário no SIGACFG, se for o caso criar um novo e dar todas as permissões e acessos conforme [**documentação**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360043729194-RH-Linha-Protheus-MEU-RH-Como-cadastrar-um-Usu%C3%A1rio-do-Protheus-via-Configurador-para-acesso-ao-MEU-RH)  
  
Geralmente existe algum problema no cadastro do usuário no SIGACFG, houve casos que só funcionou após criar um novo e dar todas as permissões conforme documentação acima.
