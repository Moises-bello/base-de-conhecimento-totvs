# ALTERAÇÃO DO CAMPO DE VERIFICAÇÃO DE INADIMPLÊNCIA NO SERVIÇO PARAMETRIZADO PARA ACORDO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Cadastro de Serviços / Parametrização de serviços para Acordo* |
| **Situação/Requisito:** | *Sistema está permitindo alterar o flag de verificação de inadimplência de serviços parametrizados para geração de acordo.* |
| **Solução/Implementação:** | *Não permitir alteração do campo de verificação de inadimplência se o serviço estiver sendo utilizado como parâmetro de tesouraria para geração de acordo financeiro.*  *Fazer o tratamento da seleção do serviço para acordo após o campo de verificação de inadimplência ser alterado a fim de que os serviços não fiquem inconsistentes como o parâmetro considerado.* |
