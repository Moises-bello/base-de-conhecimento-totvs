***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)***Tempo aproximado para leitura: **00:00:45 min** **Duvida**Como copiar os parâmetros do parametrizador de uma coligada para outra?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para copiar os parâmetros do parametrizador entre coligadas, siga os passos abaixo:  
  
1. Acesse **Configurações | Copiar parâmetros entre coligadas**;  
  
2. Selecione os parâmetros que deseja copiar para a nova coligada;  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11143872017815)  
  
3. Você pode ignorar ou sobrescrever os parâmetros no destino, caso já exista;  
  
4. Selecione a coligada de destino;  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11143873686295)  
5. Avance e conclua o processo.
