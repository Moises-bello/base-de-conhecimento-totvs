**Dúvida** Na rotina de Cadastro de Bens do Ativo Fixo (ATFA012), não é possível efetuar a manutenção do repositório de imagens.  
   
 **Ambiente**Protheus – Ativo Fixo – A partir da versão 11.80  
  
   
**Solução**

|  |
| --- |
| Quando a acessar o Repositório de Imagens do Ativo Fixo, e a Manutenção estiver desabilitada, siga as instruções a seguir:  Através do Configurador (SIGACFG), acesse o cadastro do usuário e, em Restrições de Acesso > Acessos, localize a pergunta 151 - "Manutenção no Repositório de Imagens", e deixe-a selecionada.    Solicite que o usuário efetue o logout do sistema, e efetue um novo acesso. Ao entrar novamente o Repositório de Imagens, verificamos que o botão "Manutenção" é novamente habilitado. |
| **Observação:**  **É recomendado que habilite estas opções somente para os usuários que deverão manipular o Repositório de Imagens.** | É recomendado que habilite estas opções somente para os usuários que deverão manipular o Repositório de Imagens. |
