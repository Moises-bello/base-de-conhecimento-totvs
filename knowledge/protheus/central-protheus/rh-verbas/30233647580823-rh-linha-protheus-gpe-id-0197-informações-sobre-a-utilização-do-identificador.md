**Dúvida**Qual a finalidade da verba com ID de cálculo **0197**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução:**O **ID 0197** é um identificador utilizado em outros países para cálculos específicos.   
No Brasil, este ID **não é considerado para cálculos dentro do sistema**, sendo tratado como um identificador legado, dessa forma, não há impacto no processamento das rotinas nacionais quando este ID está presente no sistema.
