Após criar várias revisões, é possível comparar com a versão anterior?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAPMS - Todas as Versões

**Solução**

O sistema sempre guarda a versão anterior à revisão completa, quando é iniciada uma nova revisão. Nesta opção é possível comparar diferentes versões de revisões (e de simulações) em uma interface gráfica muito amigável. Para comparar, deve-se escolher as versões que se deseja comparar, assim será exibida uma tela como a que segue :

![comparar_revisao.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4421271009175/comparar_revisao.png)

Para visualizar os detalhes da diferença, deve-se clicar com o botão direito na entidade modificada   
(incluído ou excluída) e selecionar a opção de comparar, será exibido o detalhe como segue:

![detalhes_compare.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4421283627287/detalhes_compare.png)
