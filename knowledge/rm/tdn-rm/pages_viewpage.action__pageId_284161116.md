# Exceção Gerada ao Finalizar o Processo de Movimentação de Estoque com Integração EMS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Movimentação de Estoque |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu: **Estoque/Movimentação de Estoque**, selecionar uma movimentar e clicar no botão "Processa", era exibido pelo sistema a seguinte mensagem: - Uma exceção foi acionada pelo destino de uma chamada. |
| **Solução:** | Foram ajustadas as rotinas de processo de movimentação para que não seja exibida nenhuma exceção durante o processo. |
