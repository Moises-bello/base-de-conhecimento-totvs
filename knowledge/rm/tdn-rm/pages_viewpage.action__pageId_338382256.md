# CONCESSÃO DE BOLSA FUTURA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Concessão de bolsa futura* |
| **Situação/Requisito:** | *No assistente de concessão de bolsa futura, o sistema só permite escolher uma habilitação/filial caso o aluno já possua matrícula naquela habilitação/filial. Nos níveis de ensino “Ensino Básico” entendemos que este comportamento não está correto, para o “Ensino Básico”, esta restrição não deveria ser aplicada, uma vez que a “habilitação” representa a “série” em que o aluno será matriculado.* |
| **Solução/Implementação:** | *Foi alterado o assistente de concessão de bolsa futura para que no ensino básico a consulta realizada seja igual a feita no cadastro de bolsa futura, sendo a consulta em cima da grade (Atual e próxima) do aluno e não na matricula no período letivo e habilitação filial.*. |
