<Resumo do que foi contemplado na alteração associada a essa nota de release> 

|  |  |
| --- | --- |
| Situação | Quando a classe TCColumn possui o bloco de definição de cor de fundo definido, a cor da linha seleciona não é exibida. |
| Ocorrência | Por exemplo, ao criar uma grade com as cores cinza e amarelo, ao selecionar uma linha, não é exibida a cor azul indicando que a linha está selecionada. |
| Correção | Corrigido o componente TCBrowse para quando a linha é selecionada |
| Informações adicionais | * Referente ao chamado: não há chamado associado * Referente à ocorrência: SCHTML-304 * Disponível a partir da build 7.00.131227A - 3.0.11 |
