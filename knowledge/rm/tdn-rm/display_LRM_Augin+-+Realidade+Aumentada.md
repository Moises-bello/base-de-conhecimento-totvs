O Augin é a principal plataforma de Realidade Aumentada da América Latina, para a Construção Civil.

**O que é Realidade Aumentada?**

A Realidade Aumentada (RA) é a tecnologia que permite misturar elementos virtuais ao mundo real. Na construção civil a RA pode ser usada para ver um projeto no mundo real.

**Preciso de Equipamentos Especiais para usar o Augin?**

Não, você pode ver o projeto em 3D em qualquer dispositivo móvel. Para visualizar os modelos em Realidade Aumentada, você precisa de um aparelho celular ou tablet, Android ou Iphone, capaz de rodar as plataformas [ARCore](https://developers.google.com/ar/discover/supported-devices) ou [ARKit](https://developer.apple.com/library/archive/documentation/DeviceInformation/Reference/iOSDeviceCompatibility/DeviceCompatibilityMatrix/DeviceCompatibilityMatrix.html). *Os celulares mais comuns, a partir de 2017, já possuem essa tecnologia.*

Após o cadastro, o Totvs Construção Obras e Projetos permite que seja enviado do o Arquivo IFC do sistema diretamente para o Aplicativo em: **Menu BIM | Visualização do Modelo 3D | Augin.**

Ao selecionar esta opção o sistema irá abrir a tela de Login do Augin conforme imagem abaixo:

Efetue o Login e clique em Enviar. O sistema irá enviar o arquivo que foi aberto pela [Visualização do Modelo 3D](https://tdn.totvs.com.br/pages/viewpage.action?pageId=556379451).

Salvar meus dados de login

Caso o Processo seja executado com a opção **Salvar meus dados de login**habilitada, ao abrir novamente o processo o sistema irá trazer os dados de E-mail e Senha do ultimo login, otimizando a execução do processo para próximas envios.

Caso queira alterar os dados de login, E-mail e senha, basca clicar na opção **Esquecer meus dados ou entrar com outro usuário.**Sendo assim será permitido logar com outra conta Augin.

Após enviar, o sistema permite **Ver o log do envio**. Basta clicar nesta opção da tela.
