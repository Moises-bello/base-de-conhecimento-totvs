# APROPRIAÇÃO DIRETA DE PRODUTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Manutenção |
| **Função:** | Requisição de Materiais |
| **Situação/Requisito:** | Ao consumir os serviços de Apropriação Direta de Produto a mensagem abaixo é apresentada:  "**Ocorreu um erro ao efetuar a leitura do registro:** **Não foi encontrado o atributo de segurança no {Nome do DataServer ou Processo}."** |
| **Solução/Implementação:** | Liberado acesso ao DataServer **MntApropriacaoPrdData** para consulta de dados;  Liberado acesso ao DataServer **MntItmApropriacaoPrdData** para consulta de dados;  Liberado acesso ao processo **MntApropriacaoDiretaProdutoProc** para a inclusão da Apropriação Direta de Produto. |
| **Tickets relacionados:** | 3445726 |
| **Requisito:** | MATESTCNTFTOF01-2992 |
| **Documento de Referência:** | [Processo de Apropriação Direta de Produtos](http://wikihelp.totvs.com.br/WikiHelp/MNT/MNT.ApropriacaoDiretaProdutos.aspx) |
