**Dúvida**Como configurar o TAF para controlar acesso para a Lei Geral de Proteção de Dados(LGPD)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Automação Fiscal - 12.1.27  
  
**Solução**

**Lei nº 13.709 - Lei Geral de Proteção de Dados**

Para adequar o Sistema Protheus à Lei Geral de Proteção de Dados foi necessária a adaptação da apresentação dos dados dessa rotina, de modo a realizar o tratamento dos dados sensíveis e/ou pessoais, com a utilização dos processos de Controle de Acesso.

O Administrador do Sistema é o responsável por estabelecer se as regras de controle das informações serão aplicadas a um único usuário ou a um grupo de usuários. A configuração desse acesso dos usuários e/ou grupo de usuários aos dados sensíveis e pessoais está disponível no módulo Configurador (SIGACFG) através dos acessos 192 e 193 (Relação de Acessos x Rotina).  
As alterações referentes ao módulo Financeiro sofreram mudanças nos campos Dados Pessoais e Dados Sensíveis, serão inibidos as informações para os usuários que não possuir permissão.

Para configurar o TAF para o LGPD verifique com mais detalhes o TDN abaixo.  
O procedimento realizado é via Configurador:
