# Sistema não carrega a quantidade correta da diluição

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | PEP |
| **Situação/Requisito:** | Ao prescrever um medicamento que possua diluição e o diluente possui uma quantidade em Ampola, o sistema não calcula a quantidade do diluente em ML corretamente |
| **Solução/Implementação:** | Ajuste realizado para considerar a quantidade do diluente em ML |
