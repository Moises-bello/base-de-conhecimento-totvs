|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |

| **Situação/Requisito:** | *Foi identificado que mesmo com o parâmetro para utilizar e-mail da biblioteca como remetente, o sistema continua enviando e-mails utilizando os dados do remetente da coligada.* |
| **Solução/Implementação:** | *FFoi identificado que os dados do remetente não estavam sendo preenchidos corretamente no momento do envio, foi feito o ajuste e quando o parâmetro para enviar utilizando e-mail da biblioteca estiver marcado será enviado corretamente com o remetente definido.* |
