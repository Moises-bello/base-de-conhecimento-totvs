**Dúvida**Quais São os Tipos de Movimento das Provisões de Férias e 13º Salário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17

**Solução**Ao calcular as Provisões de Férias e 13º Salário, quando houve movimentação para o funcionário no mês de cálculo da **Provisão**, o sistema apresenta um código diferente para cada movimentação no campo "**Tipo de Movimento**" (**RT\_TIPMOVI**).

Abaixo segue o detalhamento de cada Movimentação:

1. Tipo de Movimento **1** : **Demitido**.  
Esse movimento é apresentado quando o funcionário foi desligado no mês de cálculo de provisão, gerando as Baixas de Rescisão, como no exemplo abaixo:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000566462)

2. Tipo de Movimento **2** : **Congelado Férias**.  
Esse movimento é apresentado quando o funcionário está afastado com Congelamento de Férias, como no exemplo abaixo:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000566682)

3. Tipo de Movimento **3** : **Congelado 13o**.  
Esse movimento é apresentado quando o funcionário está afastado com Congelamento de 13º Salário , como no exemplo abaixo:

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000567022)

4. Tipo de Movimento **4** : **Congelado Férias/13o**.  
Esse movimento é apresentado quando o funcionário está afastado com Congelamento de Férias e de 13º Salário , como no exemplo abaixo:

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000567322)

5. Tipo de Movimento **5** : **Transf. Saída**.  
Esse movimento de Transferência de Saída é apresentado quando o funcionário foi transferido de Empresa, Filial, Centro de Custo, Item Contábil ou Classe Valor,  gerando Baixas de Transferências, como no exemplo abaixo:

![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360101663313)

6. Tipo de Movimento 6 : **Transf. Entrada**.  
Esse movimento de Transferência de Entrada é apresentado quando o funcionário foi transferido de Empresa, Filial, Centro de Custo, Item Contábil ou Classe Valor,  gerando a entrada dos valores de Transferências, como no exemplo abaixo:

![mceclip11.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360101663493)
