Nesta tela o usuário pode cadastrar os países que serão utilizados para a identificação das publicações, bem como suas siglas. A associação de um país à publicação pode ser realizada no momento de cadastro ou mesmo editando uma publicação existente.  
   
**Exemplo de cadastro de países:**

|  |  |  |
| --- | --- | --- |
| **CÓDIGO** | **DESCRIÇÃO** | **SIGLA** |
| 01 | Estados Unidos da América | EUA |
| 02 | Brasil | BRA |
| 03 | Afeganistão | AFG |
| 04 | Argentina | ARG |
