# HISTÓRICO DE ALTERAÇÃO DE MATRÍCULA PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Histórico de alteração de matrícula período letivo |
| **Situação/Requisito:** | Quando se realiza o processo de mudança de turma (ensino básico), o sistema realiza o registro do log da turma de origem, porém não realiza o registro da alteração no log da turma de destino. |
| **Solução/Implementação:** | Foi identificado uma validação incorreta no momento da geração do log, sendo assim foi feito a alteração e a partir de agora o sistema registra o log da turma antiga e também registra o log na turma nova. |
