Caso a integração com o Fluig esteja ativa, este processo possibilita a adição de participantes e moderadores nas comunidades de todas as entidades cadastradas. Para as entidades: Turma, Turma/disciplina, sub-turma, curso, habilitação (serie), por conter mais de uma comunidade, há a possibilidade de definir quais comunidades serão alvo do processo.   Selecionar os alunos que devem ser incluídos como participantes da comunidade O usuário poderá optar por não chamar nenhum aluno

**Selecionar os professores:** O usuário poderá optar por não chamar nenhum professor Para as entidades de turma, turma/disciplina e sub-turma deve ser possível definir para cada professor o seu papel na comunidade (participante ou moderador)  
**Selecionar os coordenadores:** O usuário poderá optar por não chamar nenhum coordenador Para todas as entidades deve ser possível definir para cada coordenador seu papel na comunidade (participante ou moderador)  
**OBS:** Neste processo é possível alterar o tipo de participação de todos os professores e coordenadores de uma única vez.  
**Atividade ofertada** Selecionar os inscritos: Os inscritos devem ser selecionados em três passos: • Pessoa • Professor • Alunos Para todos os passos o usuário terá a opção de não chamar nenhum participante  
Regras para que um usuário possa ser definido como participante ou moderador de uma comunidade  
**Aluno** Os alunos com situação de matrícula que estabeleça o status de ativo na comunidade do Fluig.   Situação de matrícula no curso apenas para o ensino superior: impacto nas comunidades do curso e habilitação.   Situação de matrícula no período: impacto nas comunidades de turma quando ensino superior e para curso, serie e turma quando ensino básico.   Situação de matrícula na disciplina: impacto nas comunidades das turmas/disciplinas e sub-turmas.  
**Professores**  Os professores devem estar associados à turma/disciplina ativas.  A data atual deve estar compreendida entre a data inicial e final de participação dos professores nas turmas/disciplinas.  Os professores devem estar ativos.  
**Coordenadores**  A data atual deve estar compreendida entre a data inicial e final de participação do coordenador na comissão coordenadora da matriz aplicada.  
**Observação:** Para incluir participantes e moderadores nas comunidades é necessário que os mesmos tenham usuário, que este mesmo usuário esteja cadastrado no Fluig.
