# INSCRIÇÃO CANDIDATO - DEFICIÊNCIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão de Processo Seletivo. |
| **Função:** | Opções de deficiências disponíveis na inscrição do processo seletivo. |
| **Situação/Requisito:** | Adição de novos campos de deficiências e subdeficiências no processo seletivo. Após adição dos campos de deficiências(Mental, Intelectual, Fala e Reabilitação), os campos devem ser visualizados nos portais, durante inscrição do candidato. |
| **Solução/Implementação:** | Adição dos campos acima, nos portais, durante execução da inscrição de um novo candidato. |
| **Conversores e Parâmetros:** | Em versões anteriores a 12.1.20, será necessário executar o script CN.2018.03\_03. |
