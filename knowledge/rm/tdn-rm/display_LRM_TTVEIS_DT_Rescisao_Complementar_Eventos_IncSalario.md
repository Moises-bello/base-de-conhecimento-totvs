# RESCISÃO COMPLEMENTAR COM EVENTOS QUE INCIDEM SALÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Complementar* |
| **Situação/Requisito:** | *Eventos adicionais de rescisão calculados por fórmula, que incidem salário, não estão sendo considerados no cálculo da média na rescisão complementar, quando o aumento salarial é no mês seguinte da demissão, durante o periodo da projeção do aviso prévio indenizado.* |
| **Solução/Implementação:** | *Ajuste no cálculo das médias na rescisão complementar, quando o aumento salarial é no mês seguinte da demissão, durante o periodo da projeção do aviso prévio indenizado, para considerar na base de salário o mesmo valor da rescisão original, nos eventos adicionais calculados por fórmula.* |
| **Chamados   relacionados:** | *TTVEIS* |
| **Versões/Release:** | *11.82.43* |
