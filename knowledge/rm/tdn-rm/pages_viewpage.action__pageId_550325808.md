Este processo é executado a partir da tela de “**Inscrição dos candidatos**”.  O candidato possui um status de opção para cada uma das áreas ofertadas na qual ele se inscreveu. De modo geral, não é necessário que usuário altere manualmente o status de um candidato. Porém, isso pode ser feito por meio do processo de alteração de status quando se desejar desclassificar o candidato nas seguintes situações:

* *O candidato não compareceu para fazer as provas;*
* *O perfil do candidato não é adequado;*
* *O candidato não passou na entrevista;*
* *O candidato se utilizou de métodos ilícitos para se beneficiar na seleção*

Antes de executar o processo de classificação, se o usuário desejar, ele pode desclassificar o candidato por um dos motivos acima. Dessa forma, mesmo que tenha feito prova e possua notas inseridas no Sistema, o processo de classificação não o classificará nessa opção.

O usuário pode selecionar Nº candidatos na tela de “Inscrição do candidato” e executar o processo de “Alterar status das opções do candidato” ou selecionar apenas o candidato e executar o processo.

Processo para um candidato específico.

Ao selecionar o(s) candidato(s) para o(s) qual(s) deseja alterar o status e iniciar o processo, a tela a seguir será exibida

Nesta tela o usuário deve configurar na coluna “***Novo status***” o status para o qual o “***Status atual***” deve ser alterado. O Sistema permite a alteração somente se o candidato não tiver passado pela chamada. Após ter sido executada a chamada de um candidato, só é possível alterar o status da opção se a chamada de sua área ofertada for cancelada.

O botão “Limpar alterações” serve para limpar o valor do campo “Novo status” de todas as opções no grid de uma única vez. Já o botão “Alterar todos para” serve para definir um mesmo valor para o campo “Novo status” em todas as opções no grid de uma única vez. Ao final, o Sistema apresenta as alterações de status que foram realizadas e as que não foram por algum motivo.
