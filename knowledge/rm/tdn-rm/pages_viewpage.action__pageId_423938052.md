Conciliação é o processo onde os dados apontados via código de barras são confirmados.  
 Na Conciliação por Estrutura são apresentados os itens de ordem que já foram apontadas via código de barras, é possível editar o item e alterar as informações de quantidade produzida e quantidade perdida.

**Processo de Conciliação de Apontamento por Estrutura**

Esse processo é utilizado para efetivar os dados informados no apontamento via Código de Barras por Estrutura.  
 Para finalizar o apontamento de um item com uma quantidade menor que a prevista deve ser marcada a opção "Termina?".  
    
****Importante**:**Na Conciliação de Apontamento por Estrutura a opção "Termina?" é utilizada somente para finalizar apontamentos de itens com quantidade menor que prevista.  
 Quando um item for apontado com quantidade igual ou maior a prevista, o item será automaticamente concluído, independente de estar marcada a opção "Termina?".
