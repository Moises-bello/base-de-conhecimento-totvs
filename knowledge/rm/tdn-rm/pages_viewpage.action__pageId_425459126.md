Agora no cadastro de feriados existente no sistema, há a possibilidade de associar eventos acadêmicos para que o usuário selecione quais tipos de eventos acadêmicos deseja ignorar no momento da geração do plano de aula ou reserva de recursos e instalações.  
 **Obs.** Acesse o novo cadastro tipos de Eventos Acadêmicos, informe os dados.   
  No cadastro de calendário foi adicionado um novo campo codcoligada para que a visão seja filtrada de modo que apenas os calendários que tenham codcoligada igual á coligada corrente ou a coligada global, serão exibidos. Além da inclusão dos anexos para armazenar os Eventos acadêmicos e para armazenar a lista do contexto.   
 ***Lembrete****:*Para modificar os eventos acadêmicos é necessário que o usuário esteja logado no contexto correto, mesmo que ele tenha acesso a outro contexto que lhe dê a permissão.    
 ***Atenção:*** O Processo de cópia de feriados entre calendários mudou para Cópia de eventos Acadêmicos entre Calendários  
 No cadastro de [Parametrização por curso](http://tdn.totvs.com/pages/viewpage.action?pageId=425458887) agora é possível escolher um calendário para ser utilizado, da mesma forma que ocorre na tela de cadastro de Períodos letivos.  
              No processo de  a opção de desconsiderar feriados de um tipo específico durante a sua geração mudou, agora o usuário seleciona mais de um tipo de feriado para os quais não deseja gerar o plano de aula e também possui a opção para que o usuário selecione uma lista de tipos de eventos acadêmicos para os quais o plano de aula não deve ser gerado. Assim este processo passa a verificar o calendário definido na parametrização por curso, caso não tenha um calendário definido, verifica o calendário configurado no cadastro do período letivo.     
              No processo de [Reserva de instalações](http://tdn.totvs.com/pages/viewpage.action?pageId=425458914) existe uma opção de considerar a tabela de feriados para a geração do período de reserva. Agora o usuário seleciona mais de um tipo de feriado para os quais não deseja efetuar a reserva e também pode selecionar uma lista de tipos de eventos acadêmicos para os quais a instalação não deve ser reservada.
