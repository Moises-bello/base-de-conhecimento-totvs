*Atenção!*  
   
Esta funcionalidade só está disponível para as bases já migradas para o Novo Modelo do BackOffice.  
   
Ao executar o processo de rateio gerencial o sistema grava um histórico com os dados dos lançamentos gerados, mapas e itens de rateios processados permitindo a rastreabilidade e, caso seja necessário, permite que o processo seja desfeito.   
Cada histórico corresponde a uma execução do processo com os seus respectivos dados.
