Foi feita uma correção no TMultiGet para que quando ele seja desabilitado, suas barras de rolagem ainda funcionem.

|  |  |
| --- | --- |
| Situação | TMultiGet desabilitado sem interação nas barras de rolagem. |
| Ocorrência | Ao desabilitar um TMultiGet ele fica com suas barras de rolagem inativas, não possibilitando interação do usuário para verificar todo o seu conteúdo. |
| Correção | A correção garante que as barras de rolagem do TMultiGet não fiquem travadas quando ele é desabilitado. |
| Informações adicionais | * Referente ao chamado: TWBBAC * Referente à ocorrência: SSIM-1275 * Disponível em builds superiores a 7.00.131227A 2.3.11 |
