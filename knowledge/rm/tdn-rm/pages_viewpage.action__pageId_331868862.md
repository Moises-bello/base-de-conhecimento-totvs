# RENOVAÇÃO DE EMPRÉSTIMO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Bibliotecária. |
| **Função:** | Renovação de empréstimo via portal. |
| **Situação/Requisito:** | Ao realizar a renovação de empréstimo via portal o cálculo da nova data de entrega utilizava dias, mesmo que a regra de renovação estivesse configurada para realizar o cálculo baseado em horas.   Esta inconsistência só existia no processo de renovação via portal. |
| **Solução/Implementação:** | Ajuste no cálculo de renovação de empréstimo, quando realizado via portal, para que o cálculo da nova data de entrega leve em consideração a parametrização da regra de renovação(dia ou hora). |
