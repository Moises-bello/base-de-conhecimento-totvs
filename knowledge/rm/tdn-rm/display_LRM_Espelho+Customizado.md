Os Tipo de Ocorrência cadastrados pelo usuário estarão disponíveis para visualização por meio do espelho do cartão de ponto. No RM Portal, o usuário pode escolher o tipo de ocorrência customizada para visualizar o total calculado no período e o evento de código de cálculo 0043, sendo que:

* **Evento pago (customizado):** o usuário pode escolher o código de cálculo que foi lançado com a atitude pagar para o movimento.
* **Evento descontado (customizado):** o usuário pode escolher o código de cálculo que foi lançado com a atitude descontar para o movimento.
* **Evento compensado (customizado):** o usuário pode escolher o código de cálculo que foi lançado com a atitude compensar para o banco de horas.
