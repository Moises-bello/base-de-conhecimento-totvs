![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16034297341847) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como realizar a exportação de arquivos XML gerados para o eSocial no RM e TAF dos eventos de SST?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Segurança e Saúde Ocupacional - Todas as versões  
  
**Solução**

Para exportar o arquivo XML gerado pelo sistema para atender os eventos do eSocial, siga os passos abaixo:  
  
• **RM**1. Acesse no modulo de Folha de Pagamento o menu **eSocial | Fila de Eventos:    
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146336335511)**

2. Selecione e  edite o evento que já tenha o XML gerado e clique no botão **Salvar XML:** **![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146342036631)**

3. Escolha um diretorio e salve o arquivo em sua maquina, e anexe o arquivo no ticket de atendimento.  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146387972503)

**• TAF**1. Acesse **Atualizações | Eventos eSocial | Não Periodicos** e selecione o menu conforme o evento desejado.  
Exemplo: Extrair XML do S-2210 Ocorrencia de acidente de trabalho, clique no menu **Cat - Comun. Acid. Trab.**

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146502772247)  
2. Após abrir o cadastro, clique sobre o registro em questão (no caso do exemplo acima, o funcionário desejado) e clique em **Outras ações | Gerar XML eSocial:**  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146540997143)  
  
3. Selecione o tipo de XML que deseja gerar, 1 - XML TAF ou 2 - XML RET e clique em confirmar:   
![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146594236311)  
**Obs.:** Caso tenha sido apontado erro de retorno do governo (**erro inciados com RET**) gere os dois arquivos.  
  
4. Selecione o diretorio, onde o arquivo será salvo e clique em Abrir:   
  
![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146644068119)  
5. Ao aparecer a tela com da confirmação da geração do arquivo, clique em OK:    
![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12146696684695)  
  
6. Acesse o caminho onde o arquivo foi salvo e anexe no ticket:  
  
**Importante**Lembre-se que o processo deverá ser feito conforme o evento desejado.   
  
Segue abaixo os nomes para cada evento:  
   • S-2210 :Clique no menu **Cat - Comun. Acid. Trab.**  
   • S-2220: Clique no menu **Monitor.  Saúde Trabalhador**  
   • S-2240: Clique no menu **Cond. Amb. Trabalho**  
   • S-2500: Clique no menu **Processos Trabalhistas  
   •** S-2501: Clique no menu **Info. Tributos Decorrente de Proc. Trabalhista**
