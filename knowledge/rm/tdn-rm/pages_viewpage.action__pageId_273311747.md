# CADASTRO DE FUNCIONÁRIO DA EMPRESA - ESTÁGIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Cadastro de Funcionário da Empresa - Estágio* |
| **Situação/Requisito:** | *O aluno ao incluir uma solicitação de estágio via portal poderá associar um funcionário já cadastrado ou realizar o cadastro de um novo na própria solicitação, entretanto não é exibido a função e sim apenas o cargo. É necessário que o sistema retorne a função.* |
| **Solução/Implementação:** | *Ajuste no campo que traz a listagem dos funcionário para que seja exibido a coluna função além do nome e cargo do funcionário na solicitação de um estágio feito pelo aluno no portal.* |
