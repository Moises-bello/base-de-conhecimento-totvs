# Navegação iOS do TOTVS eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Navegação entre páginas |
| **Situação/Requisito:** | 1- Ao realizar a navegação entre páginas do aplicativo com sistema iOS, o botão "voltar" (<) no topo do aplicativo exibe o título da página anterior, ocasionando uma perda considerável no visual do aplicativo, quando acessado em dispositivos com tela menor. 2- O padrão das funcionalidades "Calendário" e "Download" de arquivos está diferente dos outros aplicativos. |
| **Solução/Implementação:** | Foi realizado ajuste para dispositivos com sistema iOS, de maneira que seja exibido apenas o botão voltar (<) no topo do aplicativo sem título. Outro ajuste foi nas funcionalidades de calendário e download de arquivos para que estes possam exibir o padrão do dispositivo, mantendo o comportamento dos demais aplicativos que utilizam estes recursos. |
