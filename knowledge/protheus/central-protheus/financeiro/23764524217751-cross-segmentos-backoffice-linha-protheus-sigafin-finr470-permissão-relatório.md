![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23764533716631) Tempo aproximado para leitura: **02:00 min** **Dúvida**Usuário sem permissão ao acessar o FINR470?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Financeiro - Todas as versões  
  
**Solução**Para o usuário ter acesso ao **relatório FINR470**, é necessário seguir o passo a passo:

 ![](https://totvssuporte.zendesk.com/attachments/token/L35yD1tPqPPIf8CYCAANOzdiq/?name=image.png)  
   
![](https://totvssuporte.zendesk.com/attachments/token/VIaKwl0FptFZtf6CPHkM6pcmc/?name=image.png)

Deve ser validado se usuário possui acesso ou não no grupo priorizado, se sim, validar acesso no grupo, caso contrário diretamente no usuário.

Pode ser problema no **profile deste usuário**, quando isso ocorre orientamos a criar novo usuário sem copiar os acessos de nenhum outro liberando os acessos que devem ser liberados manualmente.
