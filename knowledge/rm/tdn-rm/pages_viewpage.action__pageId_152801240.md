| Produto | **RM** |
| --- | --- |
| **Sintoma** | **Ao gerar contabilização ocorre o erro: O período para digitação de Lançamentos Contábeis para o usuário não foi preenchido. Favor acessar o cadastro do usuário e conferir.**  **Cliente não utiliza RM Saldus.** |
| Solução | Nos casos onde o cliente não utiliza RM Saldus para preencher o período para digitação do usuário acesse na nova MDI o menu: Serviços Globais -> Segurança -> Usuários -> em "Sistema:" selecione Gestão Contábil -> localize o usuário, edite-o e em anexos selecione "Período para Manutenção de Lançamentos Contábeis", preencha com um intervalo que compreenda a data da contabilização a ser efetuada pelo usuário. |
