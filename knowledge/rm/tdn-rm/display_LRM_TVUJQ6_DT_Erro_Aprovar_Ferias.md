# SUGESTÃO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias* |
| **Situação/Requisito:** | Quando o Chefe/Supervisor acessa e edita uma sugestão de férias de seu subordinado através do menu Gestão de Férias no RM Portal, ocorre o seguinte erro:     Ocorreu um erro ao efetuar a leitura do registro:     Parâmetros do grupo de acesso ao envelope de pagamento de férias ('Data limite' e 'Dias anteriores para disponibilidade') devem ser informados. |
| **Solução/Implementação:** | *Ajustado o preenchimento do parâmetro 'Data limite' nos parâmetros do RM Portal - Férias.  O problema ocorre quando o parâmetro nunca foi definido pelo usuário e nos parâmetros exibe como se tivesse um valor.* |
| **Chamados relacionados:** | *TVUJQ6* |
