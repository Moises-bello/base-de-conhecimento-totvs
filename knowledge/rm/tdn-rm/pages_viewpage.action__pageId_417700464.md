**Novidades da Versão 11.80.0**

---

|  |  |  |
| --- | --- | --- |
| **11.80.0 - Importação de CID** |  |  |
| **.** | Na aba utilitários -> importação foi desenvolvido a importação de CID. Agora partir de um período informado o sistema importa todos os cids informados na internação do paciente. |
|  |  |
| **11.80.0 - Importação de Procedimento Invasivo** |  |  |
| **.** | Na aba utilitários, importação foi desenvolvido a importação de procedimento Invasivo. O Usuário pode importar para a base todos os procedimentos invasivos realizados no período informado. |
