# Data de Nascimento do Recém Nascido

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro de Recém Nascidos |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Atendimento/Internação/Registro de Internações", o sistema mostrava data incorreta, mostrava "minutos e segundos" no lugar do "ano" e também não calculava corretamente o número de dias/mês e ano, conforme a data de nascimento informada. |
| **Solução:** | Foram atualizados as rotinas de gravação de "novo recém nascido" e "cálculo de idade". Também foi necessário atualizar a base de dados. |
