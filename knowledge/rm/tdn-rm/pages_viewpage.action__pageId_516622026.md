## **01. VISÃO GERAL**

O cadastro de convênio tem a finalidade de cadastrar todos os convênios disponíveis no software de Gestão Hospitalar.

## **02. EXEMPLO DE UTILIZAÇÃO**

|  |  |
| --- | --- |
| Menu/Caminho: | Saúde/controle de infecção hospitalar/cadastros/convênios |

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Selecione o filtro desejado ou clique em fechar para prosseguir. 2. Será exibida a tela de visualização de Convênios. 3. Clique em **Incluir** (Ctrl + Insert). 4. Preencha o nome do convênio. 5. O campo código do cliente é usado para viabilizar a importação de dados de outros sistemas. 6. Clique em **Salvar**, e em **OK**. |
