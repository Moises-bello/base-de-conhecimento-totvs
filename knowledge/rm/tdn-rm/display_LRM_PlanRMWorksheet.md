# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Essa classe representa a uma planilha de um livro (arquivo).

# Membros da classe

---

## Propriedades

|  |  |
| --- | --- |
| Cells | Retorna uma instância de PlanRMRange que abrange todas as células da planilha. |
| Index | Retorna o índice da planilha na coleção. |
| Locked | [Obsoleto] Define se o conteúdo da planilha será protegido. |
| Name | Define o nome da planilha. |
|  | Provém acesso às opções de setup da planilha. |
| ProtectContents | Define se o conteúdo da planilha será protegido. |
| Queries | Retorna a coleção de consultas da planilha. |
| Shapes | Retorna a coleção de formas da planilha. |
| UsedRange | Retorna uma instância de PlanRMRange que representa a porção da planilha que está em uso. |
| WindowInfo | Retorna uma instância de PlanRMWorksheetWindowInfo que representa as opções da janela. |
| Worksheets | Retorna a coleção proprietária dessa planilha. |

## Métodos

|  |  |
| --- | --- |
| AddColumns | [Obsoleto] Adiciona colunas na planilha. |
| AddRows | [Obsoleto] Adiciona linhas na planilha. |
| CopyAfter | Cria uma cópia da planilha atual e a insere depois da planilha passada como parâmetro. |
| CopyBefore | Cria uma copia da planilha atual e a insere antes da planilha passada como parâmetro. |
| Delete | Apaga a planilha atual. |
| DeleteColumns | [Obsoleto] Remove colunas da planilha. |
| DeleteRows | [Obsoleto] Remove linhas da planilha. |
