![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:10 min****Dúvida**Como realizar envio e-mail para os funcionários de maneira global?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para efetuar envio de e-mails para os funcionários cadastrados na base de dados, execute os passos abaixo:   
  
1. Acesse **Configurações | Enviar e-mails para funcionários**:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414131677847/mceclip0.png)  
  
2. Selecione os filtros de acordo com os funcionários que receberão os e-mails:  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414140315671/mceclip1.png)  
  
3. Após acessar o menu anterior, será direcionado a tela abaixo onde deverá ser preenchido os dados do remetente:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414140337559/mceclip2.png)  
  
4. Caso o e-mail seja apenas um texto, utilize a opção Mensagem Livre. Caso queira anexar um relatório do sistema, selecione a flag **Enviar relatório como Anexo**. Selecione o relatório que será gerado. Preencha o assunto e o texto do e-mail. Avance e execute:  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414140355351/mceclip3.png)  
  
**Importante**  
Para efetuar o envio de e-mails, é necessário que o sistema já esteja com a parametrização correta. Caso tenha dúvidas sobre a configuração, acesse a seguinte documentação: [RH - RM - FOP - Configuração de envio de e-mail para funcionários](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4413010063767-RH-RM-FOP-Configura%C3%A7%C3%A3o-de-envio-de-e-mail-para-funcion%C3%A1rios)
