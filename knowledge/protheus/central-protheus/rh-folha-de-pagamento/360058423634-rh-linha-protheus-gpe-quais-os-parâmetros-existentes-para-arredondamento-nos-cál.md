Dúvida**Quais os parâmetros existentes para arredondamento nos cálculos do Protheus?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**O Sistema permite o arredondamento **automático** no valor **líquido** de **13º Salário** (**somente** no roteiro **132)**, **Adiantamento**, **Férias, Folha de Pagamento** e do roteiro **VEX** - **Valores Extras**.

Acesse - configurador - base de dados - dicionário - base de dados - parâmetros

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360098843954)

Acesse - atualizações - definições de cálculo - mnemônicos (GPEA300)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18885708514199)

**Importante**  
Os parâmetros atendem arredondamentos até **R$ 1,00**, portanto seu conteúdo deve ser **1.00**, conforme exemplo abaixo:
