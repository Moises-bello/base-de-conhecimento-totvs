***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)***Tempo aproximado para leitura: **00:01:00 min****Dúvida**Quais são as regras de compartilhamento de tabelas no módulo **SIGAQNC - Controle de Não Conformidade?**  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Não Conformidades (SIGAQNC) – Todas as versões  
  
**Solução**As tabelas a seguir relacionadas, devem sempre seguir o mesmo modo de compartilhamento da tabela **QI2 - Ficha de Não Conformidade**. Quando a tabela **QI2** estiver em modo **exclusivo**, todas as tabelas abaixo devem também estar em modo **exclusivo**. O mesmo se aplica ao modo **compartilhado**.

|  |  |
| --- | --- |
| Tabela | Descrição |
| **QI2** | **Ficha de Não Conformidade** |
| **QI3** | **Plano de Ação** |
| **QI4** | **Ação Corretiva x Equipes** |
| **QI5** | **Ação Corretiva x Ações / Etapas** |
| **QI6** | **Ação Corretiva x Causas** |
| **QI7** | **Ação Corretiva x Documentos** |
| **QI8** | **Ação Corretiva x Custos** |
| **QI9** | **Ação Corretiva x Não-Conformidades** |
| **QIA** | **Códigos Seqüenciais** |
| **QIE** | **Documentos Anexos Plano / Etapas** |
| **QIF** | **Documentos Anexos Fichas** |
| **QIG** | **Log Transferências Não-Conformidades** |
