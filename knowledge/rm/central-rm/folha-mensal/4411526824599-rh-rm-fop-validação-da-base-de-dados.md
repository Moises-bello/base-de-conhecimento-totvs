![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **0min 45sec****Dúvida**Como realizar a verificação da base de dados?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**É possível realizar a verificação da base de dados no que diz respeito ao cadastro de funcionários, gerando logs de inconsistências.  
  
Para realizar a verificação da base de dados, realize os seguintes passos:  
  
**1.** Acesse: **Folha Mensal | Validações | Validação da Base de Dados.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6446128393239/mceclip0.png)** **2.** Após acessar o módulo, o usuário deverá informar a seleção de funcionários para os quais deseja fazer a verificação.
