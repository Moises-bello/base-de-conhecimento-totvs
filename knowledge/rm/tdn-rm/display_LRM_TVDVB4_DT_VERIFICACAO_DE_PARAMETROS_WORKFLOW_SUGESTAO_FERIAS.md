# SUGESTÃO DE FÉRIAS (WORKFLOW FLUIG)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | Sugestão de Férias (Workflow Fluig) |
| **Situação/Requisito:** | *Ao acessar o workflow de sugestão de férias no fluig, os campos de "dias de abono" e "primeira parcela do 13º" eram exibidos mesmo quando os parâmetros estavam desmarcados no grupo de acesso do funcionário.*  *O parâmetro de enviar as férias direto para o cadastro de funcionário também não estava sendo respeitado.* |
| **Solução/Implementação:** | *Foram tratados os parâmetros para ocultarem os campos do formulário caso os parâmetros estejam desmarcados.* |
| **Chamados relacionados:** | TVDVB4, TV5969 |
