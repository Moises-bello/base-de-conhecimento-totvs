**Galeria de Fotos**

---

**Descrição**  
   
Esta funcionalidade permite a Incorporadora de criar álbuns de fotos do empreendimento para os usuários finais acompanharem as evoluções das obras.

|  |  |
| --- | --- |
|  | Como Fazer |

---

**Gestão**  
   
O usuário administrador é responsável por criar e gerenciar os álbuns de fotos. Ele consegue visualizar uma lista com todos os álbuns já criados e alguns de seus dados tais como título, descrição e a data. A lista vem ordenada do servidor pela data, os álbuns mais recentes aparecem primeiro.  
Na listagem é possível clicar no botão "Fotos" de cada galeria e o sistema irá abrir uma janela modal com todas as fotos da galeria, podendo navegar entra elas através do clique do mouse ou do teclado.  
   
Na tela de criação de um novo álbum, o administrador insere as informações de título, descrição, data, empreendimento, o andamento da obra e as fotos.  
   
Apenas o campo de título é obrigatório. As demais informações podem ser preenchidas posteriormente na edição do álbum.  
O campo de data é preenchido somente pelo usuário. O sistema não altera este campo. Portanto fica a cargo do usuário decidir se a data informada é referente a última atualização ou a data de criação do álbum.  
No campo empreendimento o usuário pode selecionar um empreendimento para associar ao álbum de fotos. Caso o álbum seja abrangente para todos os empreendimentos, então o campo deve permanecer vazio.  
No campo Andamento da Obra, é possível relacionar o álbum de fotos com algum andamento da obra já previamente cadastrado para o empreendimento selecionado. Este campo só é permitido ser utilizado quando o empreendimento for definido.  
Para inserir as fotos no álbum, o usuário pode utilizar o botão "Escolher arquivos", onde irá abrir uma janela para seleção de múltiplos arquivos. Ou então o usuário pode clicar e arrastar as fotos para dentro da caixa disponível na tela. O sistema permite as extensões: jpeg, png e gif. Cada foto pode ter no máximo 500kb. O usuário pode excluir as fotos do álbum.  
O usuário terá permissão de alterar os álbuns já criados e também excluí-los.  
Um campo de busca por título e/ou descrição foi criado para auxiliá-lo na busca de galerias.  
   
Será possível incluir links para vídeos do YouTube e também links de fotos que aparecerão no carrossel. Neste caso não há limite de MB para a inclusão do arquivo, pois buscará diretamente da internet.

Importante Vídeos

Somente serão aceitos vídeos com link da plataforma YouTube.  
- Serão aceitos links de compartilhamento e links da barra de endereços do navegador com patch "watch" no link, conforme exemplos a seguir.  
**Exemplos:**  
Link de compartilhamento: <https://youtu.be/jJM3zT5inZw>  
Link de barra de endereços:  <https://www.youtube.com/watch?v=jJM3zT5inZw>

   
Tanto os vídeos quanto as fotos ficarão visíveis para o Cliente no Carrossel da galeria de vídeos/fotos, quanto no andamento da obra.

Fotos

A galeria de fotos suporta arquivos com até 2 megabytes.

   
**Cliente**  
   
Na visão do comprador do imóvel, o portal exibe todas as galerias de fotos associadas ao empreendimento corrente. Cada galeria possui como capa a primeira foto cadastrada. O portal exibe o título da galeria e a data informada.  
Os álbuns são ordenados no servidor pela data de publicação, os mais recentes aparecem no topo da página.  
   
Ao clicar na galeria, o portal encaminha o usuário para a página de detalhe do álbum, onde serão exibidos o título, a data, a descrição, o andamento da obra que foi associado e todas as fotos.  
   
Ao clicar em uma determinada foto, o sistema abre uma janela modal com a foto selecionada. Nesta janela o usuário consegue navegar pelas outras fotos através do clique do mouse ou pelo teclado.  
   
Ao clicar no andamento da obra, caso exista, o portal encaminha o usuário para o menu Andamento da Obra, já exibindo as fotos relacionadas ao andamento selecionado.
