Baixa - Baixa de Créditos/Devoluções Vinculados

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | Baixa - Baixa de Créditos/Devoluções Vinculados |
| **Situação/Requisito:** | Ao utilizar o processo de Baixar Créditos/Devoluções vinculados em um lançamento 100% vinculado o sistema  baixa o lançamento, mas não atualiza o status do boleto mantendo o mesmo em aberto. |
| **Solução/Implementação:** | Otimização no processo de baixar Créditos/Devoluções vinculados. Agora o sistema atualiza corretamente o  status do boleto do lançamento de aberto para baixado ao realizar a baixa Créditos/Devoluções vinculados. |
