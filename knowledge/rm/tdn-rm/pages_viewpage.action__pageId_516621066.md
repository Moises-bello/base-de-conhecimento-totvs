## **01. VISÃO GERAL**

Este cadastro diz respeito ao agrupamento dos procedimentos que são importados. Após serem importados, o usuário poderá definir um grupo de forma a otimizar seus processos.

## **02. EXEMPLO DE UTILIZAÇÃO**

|  |  |
| --- | --- |
| Menu/Caminho: | Saúde/controle de infecção hospitalar/cadastros/procedimento cirúrgico/agrupamento de procedimento de origem |

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Será exibido uma tela de filtro com todas os procedimentos de origem. 2. Selecione com duplo clique o filtro desejado ou clique em fechar para prosseguir. 3. Serão exibidos na tela todos os agrupamentos que o sistema possui. 4. Clique em **Incluir** (Ctrl + Insert). 5. Será aberta a tela de cadastro de agrupamento. 6. Preencha o **código** de identificação. 7. No campo **Descrição**, preencha o nome do agrupamento. 8. Clique em **Salvar** para gravar o cadastro efetuado. 9. Clique em **OK**, para concluir o cadastro e retornar para a tela de visualização. |
