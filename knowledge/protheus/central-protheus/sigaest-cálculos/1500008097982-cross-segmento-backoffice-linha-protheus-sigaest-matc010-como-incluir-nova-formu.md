**Dúvida**

Ao acessar à rotina Formação de Preços - MATC010 - e tentar incluir  uma linha com uma formula de cálculo o Protheus não permite, ele permite apenas editar uma linha já existente. Como incluir uma nova linha?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões  
  
**Solução**Para realização de inclusão de uma nova linha, basta selecionar uma célula que contem dados e depois clicar em **incluir**. Veja detalhes no GIF abaixo:

![Incluindo_linha_nova_de_formacao_de_pre_os.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500011764462)

**Não consigo adicionar na linha pontilhada. É normal?**

Note que, se o usuário clicar sobre as linhas pontilhadas, não é possível fazer a inclusão. Veja detalhes abaixo:

![falha_ao_tentar_incluir_linha_pelo_pontilhado.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500012062321)

Com isso, finalizamos este artigo.
