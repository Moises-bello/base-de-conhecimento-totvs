Nesta tela são apresentadas todas as mensagens que foram criadas para serem enviadas às integrações incluídas no Cadastro de Integrações. Aqui é possível ver as mensagens que foram enviadas ou não e os retornos que elas tiverem.

**Identificador:**identificador interno da mensagem.

**Id. da Integração:**identificador da integração da qual a mensagem pertence.

**Código do Parceiro:**  a qual parceiro essa mensagem está sendo enviada.

**Entidade:**qual a entidade essa mensagem representa.

**Data de Envio:**data que a mensagem foi enviada.

**Status da Mensagem:**status da mensagem, ou seja se ela já foi enviada, esta com algum erro ou deu tudo certo.

**Tipo Operação:**qual o tipo de operação feito pela mensagem (GET, POST, PUT ou DELETE)

**Tipo de API:**se a API do parceiro é síncrona ou assíncrona.

**Data Aceite:** data que a API de destino aceitou a mensagem enviada

**Retorno:**retorno da API destino quando não houve erro.

**Erro:**mensagem de erro retornada pela API destino.

**Mensagem:** corpo da mensagem enviada.

## Processo: Enviar Mensagem

Este processo envia as mensagem selecionadas para suas respectivas APIs destinos. Só será feito o este envio de mensagens que estão com o status **Não Enviado** e **Erro**.
