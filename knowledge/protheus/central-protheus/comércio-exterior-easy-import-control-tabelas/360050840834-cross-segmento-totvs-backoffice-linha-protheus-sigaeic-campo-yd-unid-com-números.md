Dúvida**Por qual motivo o Campo YD\_UNID vem gravado com conteúdo numérico?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**O campo **YD\_UNID** é de carga padrão e apresenta desta forma para utilização da integração com o Siscomex, o qual é numérico, sendo assim esta de acordo, pois a tabela SYD é de utilização do módulo SIGAEIC.  
  
Obs. Está é uma carga padrão, podendo ser cadastrados números e letras.
