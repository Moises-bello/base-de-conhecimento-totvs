# COPIAR TURMAS ENTRE PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Copiar Turmas Entre Período Letivo* |
| **Situação/Requisito:** | *Ao executar o processo de cópia de turma entre período letivo e o alterando a Matriz Aplicada não copia os professores da turma de origem para a turma de destino..* |
| **Solução/Implementação:** | *Ajuste no processo de cópia de turmas entre período letivo para que o sistema copie os professores de acordo com a matriz aplicada de origem para a matriz aplicada de destino para aquelas turmas/disciplinas aonde a disciplina seja a mesma em ambas as matrizes aplicadas.* |
