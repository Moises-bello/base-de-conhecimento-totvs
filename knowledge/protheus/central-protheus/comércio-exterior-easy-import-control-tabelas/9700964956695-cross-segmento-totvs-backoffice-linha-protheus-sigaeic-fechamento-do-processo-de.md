![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura:**00:02:00 min** **Dúvida**Quando recebemos uma invoice referente a um pedido de software via download (sem mídia) qual o procedimento que devemos seguir para lançar no SIGAEIC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**Quando é download, se encaixa em importação de serviços, ou seja, não tem necessidade de usar o SIGAEIC, pois não tem processo logístico, aduaneiro, etc. É só gerar uma nota fiscal de importação de serviços (procedimento que pode ser feito pelo módulo de compras mesmo),  e o utilizar o módulo Siscoserv, é possível integrar por lá para poder controlar o câmbio, caso não queria controlar cambio, paga direto pelo financeiro mesmo.
