# Ajuste da tela de cadastro de leitos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastros |
| **Situação:** | Na inclusão ou alteração de um leito, ao digitar uma unidade de atendimento, o sistema permitia a digitação de unidades de atendimento sem vínculo com o perfil do usuário. |
| **Solução:** | Realizado ajuste para não carregar unidade de atendimento que não esteja vinculada ao perfil do usuário, na tela de inclusão/alteração de leitos. |
