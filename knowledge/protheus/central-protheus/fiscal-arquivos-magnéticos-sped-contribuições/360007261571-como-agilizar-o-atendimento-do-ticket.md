**Dúvida**

Para agilizar o atendimento do ticket e tratar o incidente de forma pontual é fundamental que a abertura do ticket seja realizada para a correta equipe de suporte.

**Ambiente**

Protheus a partir da versão 12.1.23

**Solução**

Em dúvidas com relação à:

|  |  |
| --- | --- |
|  |  |
| Arquivos Magnéticos gerados através do módulo de Livros Fiscais. | PROTHEUS ARQUIVOS MAGNÉTICOS |
| GIA SP e EFD ICMS/IPI E CONTRIBUIÇÕES gerados através do TAF. | PROTHEUS AUTOMAÇÃO FISCAL |
| Extrator Fiscal para atender ao E-Social e REINF: | TAF/eSOCIAL/REINF/TSS |
|  |  |
