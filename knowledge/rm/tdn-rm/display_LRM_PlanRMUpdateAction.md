---

2
complete

# Descrição

---

Define o tipo de ação que foi aplicada às células da planilha.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| AddRows | Define que linhas foram adicionadas à planilha. |
| DeleteRows | Define que linhas foram removidas à planilha. |
| AddColumns | Define que colunas foram adicionadas à planilha. |
| DeleteColumns | Define que colunas foram removidas à planilha. |
