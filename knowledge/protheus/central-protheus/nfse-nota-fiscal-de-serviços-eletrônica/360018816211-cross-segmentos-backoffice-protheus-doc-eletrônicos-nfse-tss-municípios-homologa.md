**Dúvida**Quais são os municípios homologados para emissão de NFSe via (Web Service e TXT/XML) pelo TSS?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.  
  
**Solução**Segue abaixo a Relação de Municípios Homologados de NFSe no TSS:  
- <http://tdn.totvs.com/pages/releaseview.action?pageId=4814340>  
  
A coluna versão, informa a partir de qual versão do TSS o município está homologado.  
  
Já as colunas **Cancelamento**, **Substituição** e **Consulta** **RPS**, informam se estas respectivas Prefeituras possuem estes serviços via Web Service.
