# Ajuste no Formulário de Orçamento de Clientes

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Orçamento para clientes |
| **Situação:** | Ao pesquisar um procedimento que não constava na tabela de procedimentos e ou de taxas e serviços, era exibida a seguinte a mensagem: "Não há linha na posição 0". |
| **Solução:** | Ajuste realizado no formulário **Faturamento/Particular e convênios/Orçamento para clientes**, para que ao inserir um procedimento que não consta na tabela, seja exibida a mensagem: "Procedimento selecionado não consta na tabela XXX", onde XXX é o número da tabela. |
