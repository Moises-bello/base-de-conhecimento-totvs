![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20401181453847) Tempo aproximado para leitura: **00****:03:00 min****Dúvida**Como liberar acesso de usuário para o facilitador?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Financeiro - Todas as versões  
  
**Solução**Para liberar especificamente o **Facilitador**, siga o procedimento abaixo:  
   
Marque a opção de **acesso 2** **(Alterar Produtos)**, para isso, acesso o módulo configurador **(SIGACFG)**, vá em:  
**Usuários -> Senhas -> Usuários**  
   
Encontre o usuário desejado, vá em **"Alterar"**, após isso acesse a aba **"Restrições de acessos"** e **"Acessos"** e Marque o **Acesso 2**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20401150623895)

**Importante**  
Para o usuário priorizar acesso por regra de grupo será necessário realizar o mesmo procedimento no grupo atrelado ao usuário.
