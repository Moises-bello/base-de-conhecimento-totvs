O Processo **Atualizar em Lote** pode ser utilizado para atualizar as informações relativas à Registradora de Recebíveis comuns para vários Empreendimentos e que são utilizadas no Processo [Integrar com Registradora](https://tdn.totvs.com/pages/viewpage.action?pageId=736166527).

Para acessá-lo utilize o menu de Processos da visão de Empreendimentos ou através da tela de edição destes.

Ao acessar este processo o sistema apresenta uma tela com os campos abaixo:

* **Região:** Informe a [Região](https://tdn.totvs.com/pages/viewpage.action?pageId=435105499) na qual este empreendimento está localizado;

* **Cartório:** Informe o [Cartório](https://tdn.totvs.com/pages/viewpage.action?pageId=435105389) no qual este empreendimento está registrado;

* **Responsável:** Informe o responsável por este empreendimento. Este campo utiliza informações do cadastro de [Cliente/Fornecedor](https://tdn.totvs.com/pages/viewpage.action?pageId=435104893);

* **Tipo de Registradora:** Informe qual a entidade Registradora de Recebíveis à qual este empreendimento está associado. Atualmente para este campo, há somente as opções listadas abaixo:

* + Nenhuma;
  + CERC.

* **Uso:** Informe o tipo de uso ao qual este empreendimento se destina. As opções disponíveis são:

* + Não Residencial;
  + Residencial;
  + Misto.

* **Tipo de Implantação:** Informe o tipo de implantação utilizado para este empreendimento. As opções são:

* + Aberto; ou
  + Condomínio.

* **Tipo de Incorporação:** Informe se este empreendimento é do tipo incorporação ou não;

* **Patrimônio de Afetação:** Informe se o empreendimento é um patrimônio de afetação ou não.
