# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.20 |
| **Ocorrência:** | Liberar Exercício Contábil |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**  Com o crescimento da base de dados e acúmulo de exercícios fechados, o usuário poderá ter a necessidade de excluir exercícios anteriores que não tem mais utilidade, e poderá ser feito através do processo de **Liberar Exercício**.  O processo apaga (**exclui definitivamente**) da base de dados os “Históricos de Contabilização” e atualiza o status do Exercício como Exercício Liberado.  Após a execução não será mais possível a visualização dos lançamentos, apenas estarão disponíveis para a consulta os saldos das contas contábeis, que poderá ser visualizado através da visão de Exercícios em Anexos > Saldo Final do Exercício Contábil.   **Observações:**  Para termos um período a ser liberado é preciso termos realizado o Fechamento de Exercício, caso contrário será apresentado a seguinte mensagem:      **Importante:**   * O usuário somente poderá liberar os exercícios sempre por ordem de mais antigo. E apenas um por vez. * Para a Execução basta marcar a opção de confirmação de Leitura. * Processo **irreversível**, por isso não deixe de fazer um **Backup** da base de dados. |
