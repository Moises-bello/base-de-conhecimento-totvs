**Dúvida**Como identificar o código de retorno da Sefaz do campo F3\_CODRSEF ?

**Ambiente**

Cross Segmentos - Backoffice Protheus - Doc. Eletrônicos - NFe - a partir da versão 12.1.25

Cross Segmentos - TSS - a partir da versão 12

**Solução**

1- Para identificar qual a mensagem do **código de retorno da Sefaz do campo F3\_CODRSEF**, abra o link abaixo:

*[Manual de Orientação do Contribuinte - versão 6.00](https://www.nfe.fazenda.gov.br/portal/exibirArquivo.aspx?conteudo=URCYvjVMIzI=)*

2- Estes códigos estão **da página 118 até a página 130** conforme a imagem de exemplo abaixo:
