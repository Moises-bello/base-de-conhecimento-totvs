**Dúvida**O Sistema realiza o cálculo de estabilidade pré-aposentadoria em rescisão?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Como não é previsto em legislação e sim categoria sindical o sistema padrão não trata verbas indenizatórias referentes a rescisão contratual de empregados que possuem estabilidade pré-aposentadoria, por este motivo, é preciso criar verbas sem ID de cálculo e lançar manualmente na rescisão.
