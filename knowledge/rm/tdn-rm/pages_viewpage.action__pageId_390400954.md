# Máscara para Matrícula do Trabalhador

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Configuração da Máscara para Matrícula do Trabalhador |
| **Situação/Requisito:** | No parametrizador da máscara para matrícula do trabalhador, ao informar no campo 'Coligada' o valor 2, o sistema apresenta a mensagem: 'O tamanho da máscara definido para o campo 'Coligada' deve ser superior a 1 caracteres'. |
| **Solução/Implementação:** | Foi ajustado a mensagem da máscara de parâmetros da matricula do funcionário de modo que exiba corretamente a quantidade mínima de dígitos da coligada a ser preenchido. |
