É possível obter um registro de log de acesso dos colaboradores referente a data, hora e origem do acesso via web ou app ao Meu RH?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**Esse tipo de controle não está disponível no MEU RH. Porém todos os acessos (**logins**) realizados seja via **web** ou via **aplicativo** ficam registrados no **console.log** geral do MEU RH. No console é demonstrado o login do usuário autenticado, a data e a hora. **Não** é possível identificar a **origem do acesso**, se o funcionário acessou o MEU RH via navegador web ou através do aplicativo no celular.Segue abaixo um exemplo de como é apresentado no console.log quando o usuário acessa o MEU RH:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8532019847447)
