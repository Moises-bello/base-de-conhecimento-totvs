Sumário

Tela para seleção de prestador, nessa tela é possível usar os filtros disponíveis para seleção de um(a) prestador(a).

A tela possui também um filtro para exibição apenas de prestadores cadastrados com CRM.

Se a opção **Apenas Médico** não estiver selecionada, o sistema RM buscará todos os prestadores, independentemente do conselho profissional vinculado.

Para encontrar a **Pesquisa de Prestadores**, deve-se ir em **Unidade de Diagnóstico > Pedidos de Exames**, selecionar o paciente e abrir um pedido de exame.

Se a opção **Apenas Médico** estiver selecionada, o sistema RM realizará a busca apenas por prestadores cadastrados com o conselho profissional **CRM**
