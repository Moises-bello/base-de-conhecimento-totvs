# PROCESSO SELETIVO RM - MATRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Processo Seletivo RM - Matricular |
| **Situação/Requisito:** | No menu “Processo Seletivo RM – Matricular”, caso ocorresse alguma inconsistência que impedisse a matrícula no período letivo, o aluno não era gravado, porém o usuário ficava incorretamente gravado na tabela de usuários. |
| **Solução/Implementação:** | Alterado no menu “Processo Seletivo RM – Matricular”, ao salvar o aluno, a geração automática dos usuários será executada somente após a matrícula no período letivo. |
