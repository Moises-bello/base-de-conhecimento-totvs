![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26395574807319) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como cadastrar os novos Id's de cálculo relacionados a dedução simplificada do IRRF?  
  
**Ambiente**

TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - Todas as versões  
  
**Solução**Para auxiliar na conferência dos cálculos, foi realizada a criação dos identificadores de cálculo 1913 a 1924. Esses Id's não são obrigatórios, para cadastro.   
Caso a empresa deseje cadastrar os id's para auxilio no cálculo, deverão ser criadas verbas para cálculo do Tipo de Código 4 - **Base (Desconto)**, sem quaisquer incidência para folha e e-social (verificar qual código vigente no leiaute atual, para Rendimento com tributação isenta), Natureza e-social informativa "9989" (verificar possíveis alterações na vigência da natureza no leiaute atual do e-social).
