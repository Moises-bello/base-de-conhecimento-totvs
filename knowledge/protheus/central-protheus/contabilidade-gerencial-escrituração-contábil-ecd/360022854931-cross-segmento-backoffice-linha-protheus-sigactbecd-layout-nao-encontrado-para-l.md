**Ocorrência:**

Rotina CTBS001 ao "exportar dados" para gerar o arquivo txt da ECD, é gerado erro que o layout não foi encontrado.

Help :ECDNOLAY

Problema: LayOut não encontrado

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360020337612/mceclip0.png)  
**Ambiente**Protheus– Contabilidade Gerencial – A partir da versão 11.80  
  
**Solução:**

Verifique se os arquivos XML's, foram descompactados na pasta system/Leiaute8.

* [Pasta do leiaute para geração do arquivo texto](https://tdn.totvs.com/pages/releaseview.action?pageId=536725577)
* [Arquivos XML](http://tdn.totvs.com.br/pages/releaseview.action?pageId=235331339)

Importante! Para LINUX é necessário que os arquivos estejam nomeados com letras minusculas.
