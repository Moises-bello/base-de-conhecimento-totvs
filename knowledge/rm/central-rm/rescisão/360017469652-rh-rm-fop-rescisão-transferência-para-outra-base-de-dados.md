Dúvida**Como realizar a transferência de funcionário para outra base? Ou, como realizar a demissão de funcionário por motivo de transferência sem informar nenhuma coligada de destino presente no sistema?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar a transferência de um funcionário para outra base de dados, execute os seguintes passos abaixo:  
  
**01.** Selecione a chapa do funcionário;  
**02.** Acesse o cadastro da rescisão;  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9172818428823/mceclip2.png)  
  
**03.** Em tipo de demissão, informe os tipos **5 - Transferência sem ônus p/ Cedente** ou **6 - Transferência com ônus p/ Cedente** e preencha o restante das datas e informações, além do motivo da demissão;  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9172800826647/mceclip1.png)  
  
**04.** Clique em **salvar** e logo após, transferir funcionário;  
**05.** Ao avançar, marque a flag **Realiza transferência para outra base de dados** e execute o processo.   
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9172730610455/mceclip0.png)  
  
Ao finalizar, o funcionário ficará com situação D - Demitido.  
  
**Atenção**  
Este processo não engloba o processo de admissão nas outras bases de dados ou em outros sistemas de folha de pagamento. Assim, o processo de readmissão deste funcionários nestes aplicativos deverá ser feito após este processo separadamente e conforme as instruções específicas da base de dados ou aplicativo utilizado.
