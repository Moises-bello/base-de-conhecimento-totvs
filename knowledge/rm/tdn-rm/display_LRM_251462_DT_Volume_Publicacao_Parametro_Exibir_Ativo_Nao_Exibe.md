# CADASTRO DE PUBLICAÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Bibliotecária* |
| **Função:** | *Cadastro de publicações* |
| **Situação/Requisito:** | *Foi identificado que ao criar/editar uma publicação que tenha configurado o parâmetro para exibir o item "VOLUME" para um determinado tipo de publicação, o item "VOLUME" não é exibido na tela.* |
| **Solução/Implementação:** | *Foi identificado que o parâmetro com a definição de exibição do item é carregado corretamente, porém a criação do controle na tela não é executada, sendo assim foi feito um ajuste na criação dos controles para que também crie o item "VOLUME" caso esteja configurado para exibir este item para o tipo de publicação escolhida.* |
