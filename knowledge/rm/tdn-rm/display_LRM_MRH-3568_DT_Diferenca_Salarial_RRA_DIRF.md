# REGISTRO DE VALORES DE RRA NA TABELA DE HISTÓRICO PARA A DIRF

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projeto* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Diferença Salarial* |
| **Situação/Requisito:** | *Durante o cálculo da diferença salarial com RRA o sistema passará a incluir um registro na tabela PFHSTRRA contendo os seguintes dados:*  *Chapa, Ano de competência do pagamento do RRA, Mês de competência do pagamento do RRA, Período de pagamento do RRA, Data de Pagamento, Valor total dos rendimentos tributáveis, Quantidade de meses, Valor total da pensão alimentícia, Valor da contribuição previdenciária oficial, Valor do IRRF, Calculado pelo sistema.* |
| **Solução/Implementação:** | *Tratamento nos processos de Diferença Salarial, Diferença de Férias, Diferença de 13o. Salário e Rescisão Complementar para criação de registro na tabela PFHSTRRA com os valores de RRA, para informação na DIRF.* |
