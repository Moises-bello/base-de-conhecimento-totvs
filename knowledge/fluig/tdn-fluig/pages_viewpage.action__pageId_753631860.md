# **FAQ**

#### **1- Como solicitar a criação de uma conta no Identity?**

Para solicitar a criação de uma conta no Identity, é necessário abrir um ticket pela [Central de Atendimento](https://centraldeatendimento.fluig.com/hc/pt-br), através das opções **Nova Solicitação → Suporte Técnico**.

#### **2 - Quais dados devem ser informados na solicitação?**

|  |  |
| --- | --- |
| **Assunto** | Criação de empresa no Identity |
| **Descrição** | Informações para criação do contexto:   1) Nome da Empresa 2) Código do contexto (subdomínio no Identity - sujeito à aprovação): [codigo\_contexto].[fluigidentity.com](http://fluigidentity.com) 3) Nome e sobrenome do administrador do contexto 4) E-mail do administrador do contexto |
| **Tipo da solicitação** | Suporte Técnico |
| **Impacto** | Dúvida sobre o produto |
| **Agrupador de serviços** | Fluig |
| **Produto** | Fluig Identity |
| **Módulo** | Identity |

#### **3 - Quantos ambientes serão criados?**

Se os dados informados estiverem corretos serão criados dois ambientes: produção (**[fluigidentity.com](http://fluigidentity.com)**) e homologação (**[customerfi.com](http://customerfi.com)**).

#### **4 - São necessários usuários administradores para cada ambiente criado?**

Não. Tanto o ambiente de produção, quanto homologação, serão criados com o mesmo usuário administrador.

#### **5 - Por quanto tempo os dados dos usuários cadastrados serão mantidos, no caso de desativação da empresa?**

Ao final do contrato ou ao solicitar a desativação da empresa no Identity, os dados dos usuários cadastrados serão mantidos por até 18 (dezoito) meses, caso o cliente deseje reativá-la.

#### **6 - Se for solicitada a exclusão dos dados de usuários, é possível resgatá-los posteriormente?**

Não. Se o cliente solicitar a exclusão imediata dos dados dos usuários, é um processo irreversível e não será possível resgatá-los.
