# Filtra unidade de atendimento do prestador na classificação de risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Classificação de Risco |
| **Situação/Requisito:** | Ao selecionar nos parâmetros gerais a opção de filtrar as unidade de atendimento do prestador e acessar a classificação de risco com usuário médico o sistema estava filtrando todas as unidades. |
| **Solução/Implementação:** | Alterado o sistema para filtrar somente as unidades definidas para o prestador quando o parâmetro de filtrar unidades de atendimento estiver marcado. |
