![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15789667618455) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como retificar data de admissão e data opção FGTS no eSocial?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as Versões  
  
**Solução**Realize a alteração no cadastro do funcionário, importante ressaltar que caso tenha cálculo para esse trabalhador, o sistema não irá permitir a alteração através da rotina para garantir a integridade das informações  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/15786222581015)  
  
O campo data opção FGTS somente deverá ser preenchido caso a categoria do trabalhador seja diferente de 104 conforme [leiaute eSocial](https://www.gov.br/esocial/pt-br/documentacao-tecnica) vigente.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/15789644189975)  
  
Após ajuste, a retificação do registro poderá ser realizada conforme documentação abaixo:  
[RH - Linha Protheus - GPE - eSocial - S-2200 - Como retificar evento S-2200](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360033905013-RH-Linha-Protheus-GPE-eSocial-S-2200-Como-retificar-evento-S-2200)
