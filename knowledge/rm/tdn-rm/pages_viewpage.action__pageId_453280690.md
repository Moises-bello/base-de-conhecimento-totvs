# Realizar/Alterar frequência diária em aulas geminadas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Frequência diária no portal do professor |
| **Situação/Requisito:** | Quando o professor logava no portal e tentava marcar a frequência diária para o aluno em uma aula geminada e o parâmetro "Permitir realizar/alterar frequência diária somente durante o horário da aula" estava marcado, o mesmo não conseguia marcar a falta de todas as aulas geminadas. |
| **Solução/Implementação:** | Ajuste na validação de horário da frequência diária para aulas geminadas, possibilitando selecionar todo período de aula geminada. |
