# Ressarcimento ICMSST

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Gerador de Saída |
| **Situação/Requisito:** | Incluir no contexto de apuração do ICMS os campos do novo Anexo criado no Período de Apuração que armazenam os valores apurados no encerramento. Documento completo com a especificação: <http://tdn.totvs.com/pages/viewpage.action?pageId=403048724#0-2>. |
| **Solução/Implementação:** | No Contexto foi incluído todos os campos do Anexo referente ao Ressarcimento ICMS ST e foram ligados ao Layout CAT42, no Gerador de Saídas. |
