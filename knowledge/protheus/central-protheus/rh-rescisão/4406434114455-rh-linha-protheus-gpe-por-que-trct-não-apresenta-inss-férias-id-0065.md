![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18693039161111) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que TRCT não apresenta INSS Férias Id 0065?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Pelo layout TRCT do ministério do trabalho, não há rubrica de INSS férias e sim somente a rubrica 112.1 Previdência Social, deste modo nesta rubrica será apresentado o INSS total da rescisão (INSS saldo de salário Id 0064 mais INSS Férias id 0065).

**Exemplo:**

**Cálculo rescisão.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18693044042263)

**INSS salário ID 0064 = 60,04**

**INSS férias   ID 0065 = 231,45**

**Total INSS = 60,04 + 231,45 = 291,49**
