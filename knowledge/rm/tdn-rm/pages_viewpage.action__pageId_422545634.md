Com o intuito de facilitar a integração com outros sistemas é disponibilizado no TOTVS Gestão Fiscal  o recurso de importação de [Lançamentos Fiscais](http://tdn.totvs.com/pages/viewpage.action?pageId=422546023) por arquivo texto.  
 Um arquivo de importação pode conter vários registros e para cada um deles deve existir as informações a seguir:

|  |  |
| --- | --- |
| **Informação a ser importada** | **Tipo da Linha** |
| [Dados do Lançamento Fiscal](http://tdn.totvs.com/pages/viewpage.action?pageId=422545686) | L |
| Dados dos Itens do Lançamento Fiscal | I |
| Bens do Lançamento Fiscal | Q |
| Itens Cancelados do Cupom Fiscal | H |
| Lotes dos itens do Lançamento Fiscal | J |
| Dados da Referência dos Itens | G |
| Dados de Exterior | A |
| Outros Tributos do Item | B |
| Complemento dos Tributos INSS ou FUNRURAL | W |
| Outros Tributos do Lançamento | O |
| Notas Fiscais que acobertam a carga transportada | T |
| Dados do Transporte | S |
| Dados do Modal do Lançamento Fiscal | M |
| Rateio de Centro de Custo do Lançamento Fiscal | U |
| Rateio de Departamento do Lançamento Fiscal | D |
| Notas Fiscais de Terceiros associadas ao Lançamento Fiscal | P |
| Referências do Lançamento Fiscal | E |
| Dispositivo de Segurança do Lançamento Fiscal | F |
| Contabilização do Lançamento Fiscal | C |
| Rateio Gerencial da Contabilização do Lançamento Fiscal | R |
| Notas de Empenho associadas ao Lançamento Fiscal | N |
| Enquadramento Siscoserv | K |
