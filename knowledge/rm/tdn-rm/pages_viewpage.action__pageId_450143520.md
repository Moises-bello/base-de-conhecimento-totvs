# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | BackOffice |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Retorno de Cobrança em Lote |
| **Situação/Requisito:** | Ao executar o retorno de cobrança em lote, havendo algum erro e não ocorra a renomeação do arquivo, este será reprocessado para sempre. |
| **Solução/Implementação:** | Mesmo que ocorra um erro no processamento, o arquivo de retorno será renomeado para como .OLD, cabendo ao usuário renomeá-lo novamente para o nome original caso desejado. |
