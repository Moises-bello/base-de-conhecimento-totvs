Esta janela permite cadastrar e editar as provas/avaliações das turmas da instituição.

Estas avaliações são utilizadas na integração com o RM Testis e seu cadastro é uma precondição para digitar notas de avaliação do aluno.

O campo Código da prova no RMTestis é utilizado para associar esta avaliação a uma prova correspondente no RM Testis
