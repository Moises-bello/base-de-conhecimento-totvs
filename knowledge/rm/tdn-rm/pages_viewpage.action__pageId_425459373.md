**Cadastro de Turmas Integração E-Learning**   
  
 No cadastro de turmas há uma nova situação para turma definindo que esta seja especificamente uma turma exclusiva para integração E*-Learning*. Essa nova situação define um novo comportamento que pode ser atribuído a turmas que possuam cursos E-Learning integrados com LMS.   
    
 Para cadastrar uma Turma Integração E-Learning acesse **RH | Gestão de Pessoas | Desenvolvimento | Turmas.**  
    
 No cadastro de uma nova Turma do Tipo E-Learning é necessário marcar o checkbox **Turma Integração *E-Learning****.*  
 Esse *checkbox* só estará disponível se o curso escolhido for do tipo E-Learning.   
    
 Não é possível alterar uma Turma do tipo Integração E-Learning para outro tipo e nem as outras turmas poderão mudar as suas situações para Turma Integração E-Learning.  
    
 **Turmas com esse novo tipo de situação terão as seguintes características:**

* A quantidade de vagas não é obrigatória;
* Estão diretamente relacionadas a um curso de *E-Learning*;
* São definidas com essa situação pelo próprio usuário, no momento de sua criação;
* Desabilitar o anexo "Aulas";
* Bloquear os processos Gerar Aulas da Turma e Recalcular Período Baseado nas Aulas;

Ao término do cadastro de uma Turma Integração *E-Learning*, o Sistema irá mostrar uma mensagem de confirmação, onde o usuário poderá selecionar se deseja criar por *default* as avaliações de conhecimento de Pré-Teste e Pós-Teste automaticamente. Se usuário não desejar criar automaticamente as avaliações *default* para *e-learning*, ele poderá criá-las manualmente em outro momento.  
    
 **Observações:**

1. Não necessariamente uma turma que possua um curso de *E-Learning* é uma Turma Integração *E-Learning*. Estas devem ser definidas exclusivamente pelo usuário no momento de sua criação. Caso for associado um curso *E-Learning* e não for definida como Turma Integração *E-Learning*, a turma será idêntica a uma usual, tendo apenas um curso *E-Learning* associado a ela.
2. O checkbok "Turma Integração *E-Learning*" deverá ser habilitado para edição somente se houver integração com LMS ativa.
3. O lookup de pesquisa de cursos exibirá o campo E-Learning para permitir a visualização dessa informação. Também será possível pesquisar por esse campo.
4. Para Turmas Integração *E-Learning*, é bloqueada a edição de cursos, para que nesse tipo de situação, a turma tenha sempre o mesmo curso E*-Learning* associado.
