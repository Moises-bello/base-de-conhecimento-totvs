Para conceder permissão ao menu “Atualização de Action Cadastradas” o usuário estar associado a um perfil com permissão no menu “Atualizar Tabela de Actions”.

Conforme PRINT abaixo, segue menu a ser habilitado:

Para acessar as configurações deve estar logado no sistema “Serviços Globais” com usuário supervisor.

Para verificar quais usuários são supervisores dos sistemas, consulte a tabela GPERMIS.
