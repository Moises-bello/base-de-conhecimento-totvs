|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Copiar processo seletivo* |
| **Situação/Requisito:** | *Ao utilizar o processo de cópia de processos seletivos, o mesmo sempre define o valor das áreas ofertadas igual ao valor do processo seletivo, sendo que as áreas podem ter valores diferentes.* |
| **Solução/Implementação:** | *Foi feito um ajuste na cópia do processo seletivo para que carregue também o valor das áreas ofertadas de origem para que sejam definidas nas novas áreas copiadas.* |
