Copiar célula no TCBrowse não está funcionando

|  |  |
| --- | --- |
| Situação | A cópia de informação de uma célula no TCBrowse não funciona. |
| Ocorrência | Ao apertar as teclas Ctrl+C em uma célula do TCBrowse, a informação dela não é copiada para a área de transferência do SO. |
| Correção | Corrigido para que agora a cópia da informação aconteça corretamente para quando a célula não for para agregar algum recurso, e sim somente texto. |
| Informações adicionais | * Referente ao chamado: TTLUZA * Referente à ocorrência: SSIM-236 * Disponível em builds superiores a 131227A-20151209 |
