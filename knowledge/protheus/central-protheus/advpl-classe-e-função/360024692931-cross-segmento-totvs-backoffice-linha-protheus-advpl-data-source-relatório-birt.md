Dúvida**A ferramenta BIRT no TDS 11.3, não está criando uma conexão com o *Protheus Data Source*, quando eu seleciono uma nova *Data Source* não aparece a opção "Protheus Data Source"

![](https://totvssuporte.zendesk.com/attachments/token/PDsBCxtZKjIi1e4GZUKJTOZKL/?name=newdatasource.png)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Verifique se aparece TDSBIRT como instalado pois ele disponibilizará o ***Data Source***.

- Acesse instalar novo Programa na aba Ajuda / Help

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360022967652/mceclip2.png)

- no campo "Instar de" / "*Work with*" adicione o endereço **<http://ds.totvs.com/updates/tds113/>**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360022998911/mceclip0.png)
