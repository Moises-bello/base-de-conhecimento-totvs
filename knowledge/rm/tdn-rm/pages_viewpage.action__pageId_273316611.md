# Folha Analítica

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Emissão das bases |
| **Situação/Requisito:** | O relatório de Folha Analítica em .net está considerando a seleção de "bases" unificada, dessa forma  uma mesma base será utilizada para Funcionários, totais por seção e totais gerais.  Na Folha Analítica Delphi era possível definir as bases separadamente. |
| **Solução/Implementação:** | O relatório de folha analítica foi ajustado para que o usuário possa definir a seleção de bases separadas.  Sendo:   - Funcionários  - Totais por seção  - Totais gerais. |
