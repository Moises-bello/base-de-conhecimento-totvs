Este processo possibilita a geração do Projeto Licitante, com Obras e/ou Serviços do Projeto aberto (Projeto origem).  
 Selecione um projeto e na aba Concorrência Eletrônica selecione "Gerar o Projeto de Licitação" (Projeto | Selecionar | Projeto | Projeto | Conc. Eletrônica | Gerar Proj. Licitação).  
 O sistema copia para o projeto de licitação todos os Insumos e Composições que são utilizados pelas Tarefas selecionadas .  
 Aparecerá na tela a visão "Gerar o Projeto de Licitação", que utiliza a Cópia de Itens do TOP que automaticamente reconhece que trata-se de uma geração de Projeto de Licitação e executa todos os procedimentos necessário isolando o processo da Cópia de Itens normal.

**Atenção:** Com a opção "Vinculado" marcada, ao finalizar a cópia de Tarefas ou SubProjetos, o sistema apresenta a mensagem "Gostaria de adicionar uma nova opção de projeto para o Projeto Destino?", clicando em Sim, um novo código automaticamente é gerado na opção Projeto Destino, onde poderá criar uma nova Licitação.  
    
 Também é possível copiar Insumos e Composições que não estão associados a Tarefas. Isso pode ser útil para que as empresas licitantes tenham mais opções de escolha dos recursos.  Por exemplo: Um usuário deseja enviar duas Composições que sejam semelhantes e podem ser substituídas em uma Tarefa sem alterar o Serviço a ser executado.  
 Todos os recursos Globais são transformados em Locais. Isto é necessário para diminuir a complexidade do módulo de Equalização das Licitações. Veja em    
 Com a limitação de 24 (vinte e quatro) caracteres na criação do Projeto, ao gerar um Projeto de Licitação o sistema considera apenas os 20 (vinte) primeiros caracteres do código para compor o código default da Licitação gerada, acrescentando o auto incremento 'L' (licitação) ao início do código + .incremento (Exemplo .1) ao final do código.
