![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:20 min****Ocorrência**Ao acessar alguma rotina dentro da folha de pagamento, ocorre o seguinte erro: **Input string was not in a correct format**.  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Causa**O erro acima se trata de um erro genérico e pode estar associado a vários motivos dentro do sistema RM, sendo eles: Salvar cadastro de funcionário; Salvar cadastro de seção; Editar cadastro de funcionário existente; acessar envelope de pagamento no Portal; etc.  
 **Solução**Para solução do erro, é necessário se atentar a algumas observações, segue abaixo locais a serem conferidos:

- Se existe espaçamento ao realizar algum cadastro;

- Se existe algum caractere especial que esteja impactando na conclusão;

- Verificar se as informações cadastradas estão coerentes ao esperado da campo preenchido;

- Se existe campo obrigatório sem está preenchido.
