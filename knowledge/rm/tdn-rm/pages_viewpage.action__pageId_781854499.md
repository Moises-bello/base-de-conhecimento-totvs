### **1.0 - Tipos de relatórios**

* **Gerador de Relatórios (Antigo):** a IE poderá parametrizar os relatórios do antigo gerados (Relatório Delphi).

* **RM Reports:** a IE poderá parametrizar os relatórios criados no RM Reports.

A partir da versão: 12.2302.210

A listagem dos relatórios, será exibido o Código da Coligada em seguida o código do Relatório.

Essa implementação foi necessária para que, a Instituição de Ensino, consiga diferenciar quais os relatórios estão configurados  na Coligada Global (*conforme imagem abaixo*) e os relatórios que estão parametrizados para a coligada corrente.

Para os relatórios configurados como Global será apresentado o valor 0 (zero) e para a coligada corrente será apresentado o Código da Coligada.

Observação

Essa informação não será exibida nos portais para os usuários: Aluno, Professores e Responsáveis ( Acadêmico e Financeiro). Essa informação ficará restrita apenas para a Instituição de Ensino.

Os relatórios RM.Reports são criados/configurados em: **TOTVS Gestão Educacional | Gestão | Ferramentas de Análise RM.Reports**

A configuração são exibidas, seguindo a regra abaixo:

* **Relatórios disponibilizados para alunos (Tipos: SECRETARIA, TESOURARIA, ALUNOS)**

* **Relatórios disponibilizados para professores (Tipo: TURMAS)**
