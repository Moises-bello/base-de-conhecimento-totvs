# ATUALIZAÇÃO DE ENDEREÇO DO RESPONSÁVEL FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Atualização de Endereço do Responsável Financeiro* |
| **Situação/Requisito:** | *Ao replicar o endereço do aluno para o responsável financeiro, o e-mail do aluno está substituindo o e-mail cadastrado dentro do cliente/fornecedor (responsável financeiro desse aluno).* |
| **Solução/Implementação:** | *Foi implementando uma flag de atualizar e-mail na tela de seleção de parâmetros para o processo de atualizar endereço do cliente/fornecedor de acordo com o endereço do aluno. Caso seja selecionado a opção atualizar e-mail do cliente/fornecedor o valor de e-mail atualizado receberá o que esta salvo no campo de e-mail do aluno, caso não seja selecionado o cliente/fornecedor continua com seus valores após a execução do processo de cópia de endereço.* |
