# Publicação do arquivo final do TCC

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Publicação do arquivo final do TCC.* |
| **Situação/Requisito:** | *Ao efetuar a publicação do arquivo final do TCC a tela onde é selecionado o arquivo não é finalizada automaticamente caso o sistema emita alguma mensagem de alerta ou erro.* |
| **Solução/Implementação:** | *Ao efetuar a publicação do arquivo final do TCC, caso o sistema emita alguma mensagem de alerta ou erro, a tela onde é realizada a seleção do arquivo será finalizada automaticamente.* |
