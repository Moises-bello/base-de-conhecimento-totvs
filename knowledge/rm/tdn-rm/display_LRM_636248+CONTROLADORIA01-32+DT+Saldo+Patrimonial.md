# Saldo do Cálculo Patrimonial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Cadastro Patrimônio |
| **Situação/Requisito:** | Ao realizar o processo de reversão de Impairment, na versão 12.1.15, o sistema não apresenta o Impairment realizado na versão 11.20, impossibilitando a realização da reversão do mesmo. |
| **Solução/Implementação:** | Foi adicionado o campo Valor Impairment na aba Saldo do Cálculo Patrimonial, existente nos cenários de cálculo do cadastro de patrimônio. Ele deve ser preenchido após o fechamento de todos os períodos anteriores a competência atual e, em seguida, a depreciação do patrimônio deve ser recalculada. Após este procedimento é possível realizar a recuperação do impairmet. |
