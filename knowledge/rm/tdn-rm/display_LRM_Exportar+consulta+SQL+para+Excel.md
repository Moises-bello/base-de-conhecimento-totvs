# Exportar Consulta SQL para Excel

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 11.XX; 12.1.XX |
| **Ocorrência:** | Exportar consulta SQL para Excel |
| **Ambiente:** |  |
| **Passo a passo:** | Para exportar o resultado de uma consulta SQL para uma planilha de Excel execute os seguintes procedimentos abaixo:   Via aplicativo Delphi   Acesse de qualquer aplicativo o menu “Utilitários | Consultas SQL”:    Caso o acesso ao RM seja realizado através da MDI, acesse o Menu Gestão |Visões de Dados (SQL):    Crie um filtro para acessar as consultas:    Clique no menu Novo (Incluir):    Será apresentada a tela abaixo, porém com os campos em branco.  Preencha os campos “Código” e “Titulo” conforme desejado e no campo maior descreva a consulta SQL solicitada.  No exemplo abaixo descreve o select “SELECT \* FROM GPARAMS” (Sem aspas). Depois de preenchida as informações clique em salvar.      O sistema apresentará duas mensagens que podem ser confirmadas:        Após salvar a consulta, clique no menu “Executar” para que a mesma seja gerada:    Na tela seguinte com o resultado da consulta SQL executado, acesse o menu “Exportar | Exportar para XLS”. Salve o arquivo no diretório de preferência e encaminhe o mesmo anexo ao atendimento. |
