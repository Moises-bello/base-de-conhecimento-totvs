**Dúvida**Como proceder para atualizar Lib no Protheus?  
  
**Ambiente**Protheus – Totvs Backoffice - Cross Segmentos (Linha Protheus) - AppServer  
  
**Solução:**

1 - Baixe o pacote de Lib via Portal do cliente: <https://suporte.totvs.com/>

 - Linha Protheus;

 - Totvs Tec Framework;

 - Lib

2 - Selecione a última Lib de acordo com sua base de dados.  
  
No exemplo abaixo será baixada a Lib para uma base TopConnect Harpia. A última Lib disponível na data da criação deste artigo era a do dia 16/04/2024. Necessário observar para sempre atualizar a mais recente.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23389745124887)
