# Alocação de candidato em locais de provas

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Alocação de candidatos em locais de provas* |
| **Situação/Requisito:** | *Ao alocar candidatos, confirmar presença e alterar o local do processo seletivo, o registro no Controle de Presença não estava sendo atualizado, fazendo com que o processo de Importação de Gabarito não funcionasse corretamente.* |
| **Solução/Implementação:** | *Foi realizado um ajuste no sistema, de forma que ao alterar o local do processo seletivo, seja atualizado o registro do Controle de presença.* |
