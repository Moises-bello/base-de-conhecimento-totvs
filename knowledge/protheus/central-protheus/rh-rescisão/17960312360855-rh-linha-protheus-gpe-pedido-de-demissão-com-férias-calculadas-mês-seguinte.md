![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17960259469719) Tempo aproximado para leitura: **01:30 min** **Dúvida**O sistema apresenta mensagem ao calcular pedido de demissão com férias calculadas mês seguinte?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Sim. O sistema emite mensagem de alerta quanto a afastamento posterior a data de demissão.

**Exemplo:**

**Cálculo férias mês 07.2023 - período 03.07.2023 até 17.07.2023.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/17960156652439)

**Pedido de demissão em 16.06.2023.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/17960176466583)

Para calculo deste rescisão conforme exemplo, o cálculo de férias deverá ser excluído.
