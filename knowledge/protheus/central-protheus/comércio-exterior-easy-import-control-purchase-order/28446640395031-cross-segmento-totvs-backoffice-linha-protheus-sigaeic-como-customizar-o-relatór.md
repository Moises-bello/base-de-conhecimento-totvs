![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28446640363159) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como posso customizar o relatório do Purchase Order do SIGAEIC?**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - a partir da versão 12.1.2210  
  
**Solução**Neste caso, será necessário utilizar o arquivo "**EICPO151.APH**", disponibilizado na Expedição Contínua do COMEX: **[Pacotes de Atualizações - Comércio Exterior - P12](https://tdn.totvs.com/pages/releaseview.action?pageId=526987588)**Com o arquivo em questão, será possível proceder com as personalizações conforme os passos abaixo:

**1-)** Renomear o arquivo "**EICPO151.APH**" por "**EICPO151.AHU**";  
**2-)** Realizar as alterações necessárias para as customizações;  
**3-)** Compilar o arquivo "**AHU**" no repositório.
