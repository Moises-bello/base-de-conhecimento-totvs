## **02. EXEMPLO DE UTILIZAÇÃO**

Para cadastrar os tipos de documentos, siga o passo a passo abaixo:

Na ova **MDI do RM Saúde** acesse **Cadastros> Registro e Controle> Outros cadastros> Tipos de Documentos.**

2. Selecione o filtro Todos para mostrar todos os tipos de documentos já cadastrados no sistema.

3. A tela fornecerá a opção de criar uma nova coluna, para isso deve-se abrir a janela ''novo'', clique no **ícone de incluir** (folha em branco).

4. Selecione primeiramente o tipo do documento que deseja cadastrar.

5. Preencha em Descrição o nome do Documento.

6. No campo Cód. Pendência clique nos "..." e selecione o que se encaixa ao documento.

7. Após todo preenchimento clique em **Salvar** e o documento estará disponível para utilização dentro do sistema.

IMPORTANTE

Não é possível cadastrar um documento com um **Tipo** que já anteriormente foi cadastrado.
