# Descrição

Este cadastro permite o cadastro de modelos de mensagens para uso em rotinas específicas do sistemas.

Este cadastro é possível de forma geral para todos os processos seletivos ou exclusivo para um processo seletivo de forma específica, ou seja, caso a mensagem esteja no cadastro do processo seletivo, esta será usada exclusivamente por ele, se não existir o sistema irá buscar uma geral.

## Cadastro geral:

### Tipos de mensagens:

| Categoria | Descrição |
| --- | --- |
| Senha | Enviar e-mail para o candidato com sua senha de acesso ao portal |
| Geral | Enviar e-mail para o candidato com a confirmação da inscrição no portal |
| Geral | Confirmação da matrícula no TOTVS Educacional |
| Geral | Enviar token para a validação da assinatura do contrato de matrícula |
| Geral | Enviar e-mail para o candidato com a prova gerada pelo Prova Fácil utilizando SSO |
| Geral | Enviar e-mail informando que a assinatura do contrato será validada com TOTVS Assinatura Eletrônica |
| Geral | Enviar e-mail de confirmação do cadastro de novo usuário no Portal do e-commerce |
