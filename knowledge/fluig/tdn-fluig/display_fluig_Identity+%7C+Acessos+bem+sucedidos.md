# Falando de acessos bem sucedidos...

---

Este relatório apresenta os acessos efetuados com sucesso ao contexto da empresa no TOTVS Identity. Uma tentativa de acesso é considerada bem sucedida quando conclui o login.

O relatório de acessos bem sucedidos considera a etapa de autenticação via e-mail/usuário e senha, e validações adicionais, como CAPTCHA e token MFA.

## Acessar relatório

---

**01.** Acionar o menu **Relatórios**.

**02**. No quadro **Acessos bem sucedidos**, acionar o botão **Visualizar**.

#f2f2f2#f2f2f2

O relatório de acessos bem sucedidos será apresentado, trazendo por padrão os dados registrados nos últimos 30 dias. Para alterar os resultados apresentados, é necessário revisar os filtros.

## Filtrar registros

---

**01.** Abrir o relatório conforme os passos do item .

**02**. Acionar o botão Filtrar.

**03**. Preencher os campos de filtro conforme desejado.

#f2f2f2#f2f2f2

Os filtros disponíveis são:

**Data inicial / Data final**A data e a hora de início e de fim que devem ser consideradas na consulta (horário de Brasília).

**Endereço de IP**Registros relacionados a um endereço IP específico.

**04.** Acionar **Filtrar**.

## Exportar relatório

---

**01.** Abrir o relatório conforme os passos do item .

**02**. Acionar a opção **Exportar**.

**03**. Na mensagem de confirmação, acionar a opção **Enviar**.

#f2f2f2#f2f2f2

Serão exportados em um arquivo CSV os registros exibidos na página no momento em que o botão Exportar é acionado. Um *link* com validade de 48 horas será enviado ao endereço de e-mail do administrador que solicitou o relatório para que seja feito o *download* do arquivo exportado.

Para importar os dados do relatório para o Microsoft Excel, consulte [essa documentação](https://tdn.totvs.com/x/gRKmGg).
