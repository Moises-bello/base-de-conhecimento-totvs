**Categorias de Tipos de Requisição**

---

Esta tela possui o objetivo de agrupar tipos de requisição geral, permitindo identificar facilmente quais tipos de requisição são de uma determinada área ou propósito, conforme a necessidade de cada empresa.   
Este agrupamento será utilizado no portal Meu RH, quando o sistema estiver parametrizado para utilização do novo fluxo de requisição, permitindo que os colaboradores encontrem de forma mais fácil as solicitações que necessitam.  
  
Como exemplo, podemos citar o agrupamento por áreas:

* Requisições de RH;
* Requisições de TI;
* Requisições de Facilities;
* Requisições Administrativas;
* Requisições Financeiras;
* Requisições Jurídico;
* Requisições Comercial;

Seguindo este exemplo, na categoria Requisições de RH, poderíamos ter os tipos de requisição:

* Solicitação de Benefícios - Auxílio Creche;
* Solicitação de Benefícios - Vale Transporte;
* Solicitação de Benefícios - Vale Refeição;
* Solicitação de Benefícios - Gympass;
* Solicitação de Benefícios - Plano de Saúde;
* Solicitação de Benefícios - Plano Odontológico;

Na categoria de TI, poderíamos ter:

* Solicitação de equipamentos;
* Devolução de equipamentos;

Na categoria de Facilities, poderíamos ter:

* Solicitação de Locker;
* Solicitação de Crachá;

Nesta tela é possível cadastrar uma categoria apenas informando uma breve descrição para ela.   
Além de incluir novas categorias o usuário poderá editá-las, inativá-las ou excluí-las.   
No processo de exclusão é necessário que a categoria não esteja vinculada a nenhum tipo de requisição.

Campos disponíveis:

**Cód. Categoria -** Código identificador da categoria do tipo de requisição gerado automaticamente pelo sistema.

**Categoria do tipo de requisição -** Descrição da categoria do tipo de requisição geral. Não é permitido cadastrar mais de uma categoria com a mesma descrição em uma mesma coligada.

**Ativo -** Determina se uma categoria está ativa ou não.

Para que esta tela seja exibida é necessário que o perfil vinculado ao usuário logado possua a permissão na tela e que o sistema esteja parametrizado para utilizar o novo fluxo de requisição geral no Meu RH.
