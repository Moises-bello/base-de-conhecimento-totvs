![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23341351074711) Tempo aproximado para leitura: **00:01:00 min****Dúvida**É possível informar a quantidade de um item no embarque maior do que a quantidade informada no purchase order?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**Sim, com o parâmetro **MV\_LIBQTEM = .T.** é possível informar uma quantidade do item no embarque maior do que a informada no P*urchase Order*.

[Como utilizar o parâmetro MV\_LIBQTEM na rotina de embarque ou desembaraço](https://tdn.totvs.com/pages/releaseview.action?pageId=189313880)**
