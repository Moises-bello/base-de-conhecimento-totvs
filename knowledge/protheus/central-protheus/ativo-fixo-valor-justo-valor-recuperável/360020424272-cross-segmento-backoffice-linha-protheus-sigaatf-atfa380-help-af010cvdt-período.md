**Dúvida**

Help : AF010CVDT

Problema : Período para efetivação Invalido

**Ambiente**  
Cross Segmento - Backoffice Linha Protheus - Ativo Fixo  – A partir da versão 12.  
  
  
**Solução**

Situação está sendo apresentada pois o bem esta sendo efetivado dois meses após o ultimo calculo

Ex:

Ultimo calculo de  depreciação MV\_ULTDEPR -31/10/18

A efetivação está sendo realizada  através da rotina ATFA380 com a data base de 06/12/2018

Conclusão :

Efetivação deve ser realizada data posterior ao ultimo calculo

Ultimo calculo de  depreciação MV\_ULTDEPR -31/10/18

A efetivação deve ser realizada entre 01/11/2018 a 30/11/2018
