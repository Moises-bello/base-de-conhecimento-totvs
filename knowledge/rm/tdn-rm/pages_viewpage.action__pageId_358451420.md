# Exibição de disciplinas filhas no portal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional. |
| **Função:** | Visualização de notas no portal |
| **Situação/Requisito:** | O aluno não visualizava disciplinas filhas no portal educacional para visualização das notas de avaliações.  As disciplinas filhas não estavam parametrizadas na grade com o parâmetro "Imprime no boletim".    Este parâmetro também é utilizado como pré-requisito para exibição da disciplina no portal educacional. |
| **Solução/Implementação:** | Foi alterado o nome do parâmetro de "Imprime no boletim" para "Imprime no boletim e exibe no portal". A alteração do nome do parâmetro foi realizada para deixar claro para os clientes que este parâmetro não é exclusivo para exibição da disciplina em relatórios, mas também é verificado para exibição da disciplina no portal para manter a coerência do que é exibido em relatórios e no portal para pais e alunos. |
