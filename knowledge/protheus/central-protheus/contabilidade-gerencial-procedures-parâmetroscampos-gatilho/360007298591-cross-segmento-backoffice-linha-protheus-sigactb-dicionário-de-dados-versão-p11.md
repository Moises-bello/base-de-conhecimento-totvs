**Dúvida**

Como posso baixar o dicionário de dados para o Protheus versão 11.80

**Ambiente**

Protheus - Contabilidade Gerencial - 11.80

**Solução**  
 Para solucionar essa dúvida, realize os seguintes passos:  
 **1.**Ao entrar no portal de downloads, opte pelo produto Protheus, conforme imagem:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360007575192/mceclip0.png)

**2.**Abrirá uma tela onde será possível escolher a versão desejada, escolha a versão 11 como na imagem:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360007626171/mceclip1.png)

**3.**Agora escolha qual o tipo de ambiente é utilizado na base onde deseja aplicar o dicionário:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360007626851/mceclip2.png)

**4.**Após abrir a pagina com os pacotes, vá em categorias > Dicionário de Dados:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360007626911/mceclip3.png)

**5.**A partir de agora basta escolher o dicionário desejado:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360007626931/mceclip4.png)
