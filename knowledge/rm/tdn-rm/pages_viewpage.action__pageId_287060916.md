# Sistema não apresenta item na emissão de etiquetas de código de barras

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Etiquetas de Código de Barras |
| **Situação:** | Sistema não apresentava item na emissão de etiquetas de código de barras mesmo com saldo positivo. |
| **Solução:** | Ajuste realizado para que o sistema apresente os itens com saldo positivo desde que esteja configurado corretamente, conforme os parâmetros selecionados.  Ou seja, se filtra produtos da unidade de atendimento da parcial, o produto deve possuir unidade de atendimento vinculada a ele. |
