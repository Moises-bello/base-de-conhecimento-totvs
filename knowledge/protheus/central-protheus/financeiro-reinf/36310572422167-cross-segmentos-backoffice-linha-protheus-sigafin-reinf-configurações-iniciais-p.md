**Dúvida**  
Como configurar o sistema para iniciar o uso do extrator fiscal?

![]()  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA989 - A partir da release 12.1.33.

**Solução**  
Para darmos início, validar a documentação do TAF com as configurações iniciais.

[Cross Segmentos - Backoffice Protheus - TAF - REINF - Procedimento Completo Reinf](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4403541989783-Cross-Segmentos-Backoffice-Protheus-TAF-REINF-Procedimento-Completo-Reinf)

Solicita-se a validação da configuração dos seguintes parâmetros correspondentes:

* MV\_TAFVLRE → 2\_01\_02
* MV\_TAFAMBR → 1 – Produção / 2 – Homologação
* MV\_INTTAF → N
* MV\_TAFLPRC → 2000
