## Descrição

Foi disponibilizado conceitos do módulo de integração para realizar a importação e exportação dos cadastros de Campos do Layout do Registro Online.

## Procedimentos para Utilização

  

* Acessar o módulo de integração, Conceitos (ETL)

* Realizar a importação dos conceitos através do Menu de Processos. Informe o Conceito e Execute.
* Faça o Download dos Conceitos através do hyperlink () ou acesse a pasta de instalação da versão na pasta Objetos Gerenciais, Conceitos e faça a importação.   
    
  + Lembrando que neste link existe um arquivo exemplo com alguns campos já implementados no sistema para realizar a importação.

* Selecione um dos conceitos para executar e escolha um arquivo .txt para exportar os cadastros ou importá-los.

* Após o processamento o arquivo destino ou a base de dados será atualizada.
