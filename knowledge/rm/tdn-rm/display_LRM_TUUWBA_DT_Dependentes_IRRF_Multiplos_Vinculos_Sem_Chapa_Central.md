# DEPENDENTES DE IRRF COM MÚLTIPLOS VÍNCULOS SEM CHAPA CENTRALIZADORA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *IRRF* |
| **Situação/Requisito:** | *No cálculo do IRRF de Múltiplos Vínculos, quando está marcado o parâmetro "Calcula IRRF/INSS de múltiplos vínculos sem chapa centralizadora", está deduzindo somente os dependentes da chapa corrente.*  *Como é considerada a base dos outros vínculos, deve deduzir também todos os dependentes que incidem em IRRF, cadastrados em todos os vínculos.* |
| **Solução/Implementação:** | *Ajuste no cálculo do IRRF de múltiplos vínculos para deduzir da base todos os dependentes com incidência em IRRF, cadastrados em todos os vínculos do funcionário corrente.* |
| **Chamados   relacionados:** | *TUUWBA, TVBEHS* |
| **Versões/Release:** | *12.1.12, 11.82.45* |
