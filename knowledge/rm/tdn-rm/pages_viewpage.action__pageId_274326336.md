# Baixa - Cálculo do Valor Líquido

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financiera |
| **Função:** | Baixa - Cálculo do Valor Líquido |
| **Situação/Requisito:** | Ao realizar a baixa de um lançamento financeiro baixado parcialmente, o sistema está acrescentando o valor integral de integração do SGI, não abatendo o valor já baixado. |
| **Solução/Implementação:** | Otimização no calculo do valor líquido na baixa de lançamentos. Agora o sistema calcula corretamente os valores de integração do SGI de forma que é acrescentado apenas o valor que falta para baixar. |
