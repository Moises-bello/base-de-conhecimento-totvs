# Módulo de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Módulo de Caixa |
| **Situação/Requisito:** | O sistema está calculando o somatório valor líquido incorretamente na sessão de caixa quando um lançamento (baixado parcialmente) que possui mais de um boleto associado é apresentado na visão. |
| **Solução/Implementação:** | Otimização no processo de somatório total do valor líquido e do valor a pagar na sessão de caixa. Agora o sistema soma o valor líquido e o valor a pagar corretamente dos lançamentos, não deixando repetir quando é apresentado o mesmo lançamento duas vezes na visão. |
