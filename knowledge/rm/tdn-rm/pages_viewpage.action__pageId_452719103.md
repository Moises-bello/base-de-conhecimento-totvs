**Cópia de abono entre coligadas**   
Este assistente irá auxiliá-lo na cópia de abonos entre as coligadas do sistema e na janela de Parâmetros da cópia o sistema lista todas as coligadas disponíveis na base de dados para se fazer à cópia de registro. Selecione a coligada ou as coligadas que deseja fazer a cópia e clique no botão Avançar.

**Observação:**Caso o abono a ser copiado tenha evento relacionado, a coligada destino deve ter este evento cadastrado no cadastro de evento. Caso não tenha o abono não será copiado.
