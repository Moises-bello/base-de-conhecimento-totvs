# Parametrização por Curso

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Seleção do plano de pagamento personalizado |
| **Situação/Requisito:** | Na parametrização por curso o sistema não estava listando no lookup de plano de pagamento personalizado todos os planos de pagamento parametrizado para a matriz aplicada cadastrada.  Identificamos que este cenário ocorre somente quando o TOTVS Educacional está parametrizado para que o modelo de plano de pagamento seja por “Período da Matriz Aplicada”. |
| **Solução/Implementação:** | Quando o sistema estiver parametrizado para que o modelo de plano de pagamento seja por “Período da Matriz Aplicada”, realizamos uma melhoria no cadastro de parametrização por curso para que no lookup do plano modelo para personalização sejam listados todos os planos conforme o cadastro de Habilitações e Períodos do Plano (anexo do Plano de Pagamento). |
