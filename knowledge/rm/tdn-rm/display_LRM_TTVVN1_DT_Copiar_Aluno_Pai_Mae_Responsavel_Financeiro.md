# COPIAR ALUNO OU PAI/MÃE COMO RESPONSÁVEL FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Copiar aluno ou pai/mãe como responsável financeiro* |
| **Situação/Requisito:** | *Ao copiar Pai/Mãe para o Responsável financeiro, o sistema não está copiando a Empresa e o Cargo que está na mesma tela.* |
| **Solução/Implementação:** | *Ajuste na cópia de Pai/Mãe para responsável financeiro para que seja copiado a Empresa e o Cargo para o anexo Profissional do cadastro do cliente/fornecedor que o cadastro do responsável financeiro. Entretanto o campo Cargo somente será copia se o responsável financeiro for o próprio aluno, pois este campo cargo é alimentado pelo cadastro do aluno na aba Endereço | aba Profissional.* |
