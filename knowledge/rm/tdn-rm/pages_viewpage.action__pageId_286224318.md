# Ajuste no Formulário Encerramento de Contas sem Débitos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Encerramento de Contas sem Débitos |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Faturamento"/"Particular e Convênios"/"Encerramento de Contas sem Débitos", exibir a lista de contas sem débito e clicar em um registro, era exibida a mensagem: "Nenhum construtor sem parâmetro foi definido para este objeto". |
| **Solução:** | Foram realizados ajustes no formulário para que o sistema finalize o processo de abertura do registro sem nenhuma exceção.. |
