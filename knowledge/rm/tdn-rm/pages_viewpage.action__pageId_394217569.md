# O modelo do tipo de atendimento não aparece no momento da abertura da solicitação.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Novo portal do aluno |
| **Função:** | Requerimento |
| **Situação/Requisito:** | No momento da abertura de uma solicitação, o portal não estava preenchendo o campo "Solicitação" com o valor parametrizado no modelo de atendimento dentro do Ágilis. |
| **Solução/Implementação:** | Ajuste na abertura do requerimento, para que o campo "Solicitação" viesse preenchido com o valor  parametrizado no modelo de atendimento dentro do Ágilis. |
