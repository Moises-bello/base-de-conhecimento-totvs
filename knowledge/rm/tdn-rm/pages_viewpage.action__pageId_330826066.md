# Ao imprimir boleto no portal do aluno o sistema gera um novo boleto.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Registro Online |
| **Situação/Requisito:** | Ao realizar a impressão de um boleto não registrado no portal do aluno o sistema está gerando um novo boleto para o lançamento do aluno. |
| **Solução/Implementação:** | Ao realizar a impressão agora o sistema registra o boleto que estão 'não remetido' e não gera um novo boleto. |
