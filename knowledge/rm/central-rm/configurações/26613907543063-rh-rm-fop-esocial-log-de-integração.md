![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26613907528215) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como gerar o log detalhado do processo de integração para análise dos retornos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - À partir das versões 12.1.2310.231, 12.1.2402.176, 12.1.2406.108 e Superiores.

**Solução**Esta funcionalidade tem como objetivo ajudar a identificar possíveis erros nas integrações principais do nosso sistema. Os logs gerados fornecerão informações detalhadas sobre a integração, incluindo status e conteúdo.  
Os processos incluídos são: Conexão do TAF Integração com o TAF Atualizar Status  
Para que o Log de Integração valide as informações, é necessário primeiramente configurá-lo e, após nova integração o mesmo estará disponível para visualização.
