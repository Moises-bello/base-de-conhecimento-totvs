# PESQUISA DE TURMA/DISCIPLINA NA OCORRÊNCIA DE ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Ocorrência de Aluno |
| **Situação/Requisito:** | Quando o aluno está cursando uma turma/disciplina em uma filial diferente da dele, a pesquisa de turma/disciplina do cadastro de ocorrência não permite selecioná-la utilizando quando o sistema está logado na filial do aluno. |
| **Solução/Implementação:** | A pesquisa de turma/disciplina do cadastro de ocorrência foi alterada para permitir selecionar as turmas/disciplinas que o aluno está cursando em filiais diferentes da dele, mesmo com o sistema logado na filial do aluno. |
