# Alteração DAPI-MG

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Rotina Estadual DAPI-MG |
| **Situação/Requisito:** | Ao gerar a DAPI lançamentos com CFOP 1.934 não estão sendo considerados na rotina. |
| **Solução/Implementação:** | Ajuste na geração da rotina para incluir a Natureza de Operação "x.934" no filtro de Lançamentos Fiscais  para gerar a Linha 24. |
