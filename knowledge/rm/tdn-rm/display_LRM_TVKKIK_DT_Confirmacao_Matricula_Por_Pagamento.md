# CONFIRMAÇÃO DE MATRÍCULA POR PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Confirmação de Matrícula Por Pagamento* |
| **Situação/Requisito:** | *Ao inserir duas parcelas no contrato do aluno onde cada parcela está vinculada a um serviço diferente, baixar um desses lançamentos e executar o processo de confirmação de matrícula, onde o sistema exibiu mensagem que a matrícula não foi confirmada, porém, mesmo a matrícula não estando confirmada o sistema alterou a situação de matrícula nas disciplinas do aluno.* |
| **Solução/Implementação:** | *Ajuste no processo de confirmação de matrícula por pagamento para primeiramente qual situação de matrícula o aluno será alterado se é de parcelas baixadas ou não baixadas, a partir dai efetuar a alteração de forma correta.* |
