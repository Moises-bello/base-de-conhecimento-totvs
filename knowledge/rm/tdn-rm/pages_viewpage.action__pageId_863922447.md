Na inscrição via portal do TOTVS Processo Seletivo utilizando a inscrição para vários membros da mesma família, ressaltamos que, caso o processo seletivo esteja configurado para aplicar o [critério de busca por usuários cadastrados](https://tdn.totvs.com/pages/releaseview.action?pageId=284884269) ou [aproveitamento de dados de](https://tdn.totvs.com.br/display/public/LRM/Aproveitar+dados+do+cadastro+de+Pessoa) pessoas, este será aplicado em duas situações:

1. No início da inscrição, quando o critério parametrizado for exclusivamente **"CPF", "passaporte" ou "registro geral"**.
2. Para os demais critérios, a busca pelo candidato ocorrerá no momento do preenchimento dos dados do responsável pela inscrição.

Caso seja encontrado um usuário com os mesmos dados preenchidos, será apresentada uma mensagem conforme o exemplo abaixo.

Após realizar o login, o usuário será redirecionado para a tela de inscrição, onde poderá continuar preenchendo os demais dados.

### E quando estiver utilizando o controle de vagas?

Quando o controle de vagas é utilizado para inscrições de vários membros da mesma família, o processo passa a utilizar o  [recurso de reservas de vagas](https://tdn.totvs.com/pages/viewpage.action?pageId=863921945). Nesse cenário, se o usuário já estiver cadastrado, a seguinte mensagem será exibida:

Mensagem para candidatos que conseguiram a vaga

Mensagem para candidatos excedentes

**Importante:** A vaga é reservada imediatamente após o usuário informar os dados dos candidatos e clicar em "continuar". Mesmo que o usuário seja redirecionado para a página de login, sua vaga já estará garantida. No entanto, é necessário que o login seja feito dentro do tempo limite para a conclusão da inscrição. Após o login, o tempo limite será renovado, garantindo que o usuário não perca o tempo gasto durante o processo de autenticação.

Caso o usuário já esteja autenticado na central do candidato e selecione **“Nova inscrição”** ou **“Novo dependente”**, será redirecionado para a tela de inscrição com os dados previamente preenchidos, podendo prosseguir dentro do fluxo que considera o controle de reserva de vagas em ampla concorrência.
