# Ajuste na Crítica da AIH

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hopsitalar |
| **Função:** | Elaboração de AIH |
| **Situação:** | Ao lançar um procedimento onde o tempo de internação é menor que o tempo médio de permanência, o sistema não validava a AIH, mesmo que a quebra de crítica tenha autorização do responsável do SUS. |
| **Solução:** | Realizado ajuste para que o sistema permita validar a AIH quando o tempo de internação for inferior ao tempo médio permanência do procedimento. |
