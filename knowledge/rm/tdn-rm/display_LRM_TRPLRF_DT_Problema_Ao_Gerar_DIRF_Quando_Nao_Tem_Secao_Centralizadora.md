# DIRF EM ARQUIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *DIRF em Arquivo* |
| **Situação/Requisito:** | *Ao gerar a DIRF em Arquivo em base que não tem seção centralizadora o sistema gera o arquivo no leiaute incorreto.* |
| **Solução/Implementação:** | *Alterado a geração da DIRF para considerar a primeira seção da quebra quando não tem seção centralizadora. Dessa forma o sistema passa a gerar no leiaute correto.* |
