# O Sistema não pode encontrar o caminho especificado

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | Todas. |
| **Ocorrência:** | Ao tentar acessar o prontuário eletrônico, o sistema informa que não pôde encontrar o caminho especificado. |
| **Passo a passo:** | **1º Passo)** Acessar o sistema TOTVS; **2º Passo)** Acessar o módulo Saúde e acessar o menu Opções -> Parâmetros -> Parâmetros Gerais **3º** **Passo**) Na opção de Pesquisar, pesquise por “URL” e acesse “URL INTEGRATION PEP”    **4º Passo)** Apague todos os preenchimentos desta tela. |
