# Tags de Valores no contrato Educacional durante o processo de matrícula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Gestão Educacional |
| **Módulo:** | Educacional |
| **Função:** | Tags de valores de contrato financeiro durante o processo de matrícula online (Corpore.NET) |
| **Situação/Requisito:** | Ao adicionar as tags [VALOR P], [NUM PARC P], [VALOR PARC P] e [VALOR LIQUIDO P], os valores não eram apresentados no contrato financeiro durante o processo de matrícula online no Corpore.NET. |
| **Solução/Implementação:** | Foi realizado a substituição dos valores quando utilizado estas tags no contrato financeiro do processo de Matrícula Online do Corpore.NET. |
