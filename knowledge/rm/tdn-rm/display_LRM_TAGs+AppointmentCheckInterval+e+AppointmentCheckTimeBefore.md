# Objetivo:

---

       O objetivo deste documento é explicar o funcionamento das tags "AppointmentCheckInterval" e "AppointmentCheckTimeBefore".

# Introdução:

---

       Ao adicionar algum compromisso na agenda existe essas duas tags que tem como objetivo ajudar o usuário a lembrar dos seus compromissos.

# O que é?

---

**- AppointmentCheckInterval:** É o intervalo de checagem para verificação das tarefas de compromisso. A cada quantos minutos o sistema deve checar se existe um novo compromisso.   
*Exemplo*: A cada 8 minutos quero que o sistema checa se existe um novo compromisso.

**- AppointmentCheckTimeBefore:** Quanto tempo antes do compromisso iniciar você deseja ser notificado.   
*Exemplo:* Quer ser notificado 30 minutos antes do compromisso, então, se existe um compromisso às 15h, será notificado desse compromisso às 14h30minutos.
