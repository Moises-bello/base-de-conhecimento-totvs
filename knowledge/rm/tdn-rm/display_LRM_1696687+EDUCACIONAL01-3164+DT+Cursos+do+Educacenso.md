# CURSOS DO EDUCACENSO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Censo da Educação Básica |
| **Situação/Requisito:** | A rotina do Educacenso não está buscando os cursos que possuem código do INEP nulo. Porém, quando o código do INEP está vazio no banco (e não nulo), o curso aparece no Censo. |
| **Solução/Implementação:** | A rotina do Educacenso foi alterada para não listar os cursos que possuem o código do INEP nulo ou vazio no banco de dados. |
