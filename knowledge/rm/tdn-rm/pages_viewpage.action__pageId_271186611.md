# Relatórios de depreciação

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *Totvs Gestão Patrimonial.* |
| **Função:** | *Relatórios de depreciação.* |
| **Situação/Requisito:** | Ao gerar o relatórios agrupamento por conta ( sintético ) sistema está apresentando o valor de 333.479,50 Mas ao gerar o relatório de Depreciação (sintético) sistema está apresentando outro valor 328.943,49*.* |
| **Solução/Implementação:** | Desenvolvimento dos relatórios: Relatório de Depreciação Completo, Relatório de Depreciação Completo (Sintético) e Relatório de Depreciação Completo por Filial (Sintético) para contemplarem a coluna Ajuste Acumulada. Estes relatórios apresentam uma nova coluna que demonstra o valor que foi retirado da depreciação acumulada (coluna Ajuste da Acumulada).  Com esta nova coluna os relatórios apresentam o mesmo valor da depreciação mensal que foi contabilizado, consequentemente o valor de Ajuste da Acumulada corresponde ao valor da acumulada que foi contabilizado na baixa ou transferência monetária*.* |
