Nesta tela é possível cadastrar um modelo de avaliações para cada etapa do Modelo de etapas do período letivo.

Ao cadastrar uma turma disciplina, se você associar pelo processo do sistema o modelo de etapas para esta, o modelo de avaliações virá por default, caso exista cadastros do mesmo.
