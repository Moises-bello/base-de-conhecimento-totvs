**Dúvida**  
É possível efetuar o login no MEU RH integrado via **Fluig Identity?**  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Meu RH – Todas às versões  
  
**Solução**  
Para o Meu RH com Integração ao Protheus, está disponível a nova forma de realizar *login* no App via ***Fluig Identity.***  
  
**Por ora, esta modalidade de login está disponível apenas no** ***browser*** **(navegadores).**  
**No App ainda não possui a implementação.**  
  
Foi implementada a integração do Meu RH com o ***Fluig identity***contratado junto a TOTVS, dessa forma, os clientes que possuem essa contratação, poderão utilizar essa modalidade de *login.*  
  
Após a contratação, a interface criada a nível de *Framework*, identificará que o cliente possui o ***Fluig Identity*** cadastrado.  
  
Quando isso ocorrer, ao acessar o Meu RH via *browser* (navegadores), o usuário será direcionado para uma tela de pré-login, onde poderá digitar o *e-mail.*  
  
Para que as configurações sejam efetuadas corretamente, será necessário seguir **todos os passos** documentados no artigo a seguir:  
[**https://tdn.totvs.com/display/NPR/Login+do+Meu+RH+Integrado+com+o+Fluig+Identity**](https://tdn.totvs.com/display/NPR/Login+do+Meu+RH+Integrado+com+o+Fluig+Identity)  
  
Para cliente em ***Cloud*** **da TOTVS**, será necessário solicitar em um *ticket* à Equipe, uma apoio para realização de toda a configuração obrigatória.
