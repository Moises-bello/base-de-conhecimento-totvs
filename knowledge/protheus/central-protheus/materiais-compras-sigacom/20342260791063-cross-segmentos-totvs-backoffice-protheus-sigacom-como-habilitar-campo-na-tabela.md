![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245796887) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Como habilitar campo para Bloquear uso de um Cadastro de Aprovador - Campo AK\_MSBLQL

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Compras - Todas as versões

**Solução**Para se bloquear o uso de um cadastro de aprovador, é recomendado se habilitar o Campo Reservado de bloqueio de uso de cadastro através do configurador na tabela SAK (Cadastro de Aprovadores - AK\_MSBLQL) e no cadsatro de Aprovadores deixar o campo com o conteúdo = SIM.

Desta forma o aprovador ficará bloqueado para ser incluido em um novo cadastro de Grupo de Aprovação.

Segue telas demonstrativas:

Tela 1 - Abaixo mostra o acesso pelo configurador, na tabela SAK clicar no icone "Campos reservados"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245797399)

Tela 2 - Ticar a opção "Bloqueio Automático", clique no botão finalizar verificando o campo habilitado na tabela e salve no Disquete do configurador

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245797783)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245798167)

Tela 3 - Tela com o campo já configurado após o processo anterior

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245798935)

Tela 4 - Abaixo o Cadastro  de Aprovadores com o campo em funcionamento:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245799447)

***Importante:***

Caso o campo não apareça na rotina verifique se o nível de campo é o mesmo do usuário logado:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245799831)

Ou Ajuste o nível do campo no configurador para Nível 1 assim todos usuários terão acesso a visualização do campo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20342245800215)
