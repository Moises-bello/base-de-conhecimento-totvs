# Lançamento - Alteração

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento - Alteração |
| **Situação/Requisito:** | O sistema está permitindo alterar a conta/caixa de um lançamento com a contabilização de inclusão integrada ao lote zero, mesmo que o usuário selecione a opção ‘sim’ na mensagem apresentada pelo sistema quando um campo que pode influenciar na contabilização (inclusão) é modificado. |
| **Solução/Implementação:** | Otimização na alteração de lançamentos. Agora o sistema não permite a alteração da conta/caixa de uma lançamento com a contabilização de inclusão integrada ao lote zero. |
