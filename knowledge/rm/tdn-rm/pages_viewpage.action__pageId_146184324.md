**Objetivo:**A finalidade da atividade "Consulta SQL" é executar consultas SQL cadastradas no sistema.

Primeiramente é necessário arrastar a atividade "Consulta SQL" para o "fluxo de trabalho" sequencial em sua fórmula visual.

|  |
| --- |

Após atividade ter sido adicionada ao fluxo de trabalho, é necessário configurar as propriedades da atividade.

|  |
| --- |
| **Propriedades**  As propriedades abaixo também podem ser preenchidas clicando com o botão direito na atividade "Consulta SQL" e selecionando a opção "Selecionar Consulta SQL"  **Código da Aplicação:** Aplicação que a Consulta SQL pertence.  **Código da Coligada:** Coligada que a Consulta SQL pertence. No caso de consulta global deve-se utilizar a coligada 0.  **Código da Sentença:** Consulta SQL que deseja associar à atividade. |

**Obs: Será possível acessar o resultado da consulta sql somente após a execução da atividade.**

Importante:

Não se deve usar variáveis de contexto na Consulta SQL de uma atividade de Fórmula Visual, pois não é possível recuperar informações do contexto do sistema durante a execução dela.
