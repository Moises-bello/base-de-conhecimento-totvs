**Objetivo:**A finalidade da atividade "Executar Fórmula" é executar uma fórmula do sistema utilizando a Fórmula Visual.

Primeiramente é necessário arrastar a atividade "Executar Fórmula" para o "fluxo de trabalho" sequencial em sua fórmula visual.

|  |
| --- |
|  |

Após atividade ter sido adicionada ao fluxo de trabalho, é necessário configurar as propriedades da atividade.

|  |
| --- |
| **Propriedades Obrigatórias:**  **Aplicação da Fórmula:** É o código da aplicação que a fórmula foi criada.  **Código da Fórmula:** Código da fórmula criada.  **Código do Usuário:** Código do usuário que vai executar a fórmula.  **Linha do Contexto:** Contexto que deseja executar a fórmula. |

Após preencher as propriedades basta executar a fórmula visual.
