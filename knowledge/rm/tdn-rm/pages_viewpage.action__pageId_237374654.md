# CADASTRO DE BOLSAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Cadastro de bolsas no contrato do aluno* |
| **Situação/Requisito:** | *O campo "SBOLSAALUNO.TIPODESC" fica somente leitura se a bolsa não permitir alterar valor ou se o campo "SBOLSAALUNO.DESCONTO" não permitir alterar valor. Assim, caso seja definida restrição na lib somente para o campo "SBOLSAALUNO.TIPODESC", o sistema não respeita a parametrização feita no perfil do usuário.* |
| **Solução/Implementação:** | Foi realizada otimização no cadastro de bolsas do contrato para que a restrição criada no perfil do usuário para acesso ao campo tipo de desconto prevaleça. |
