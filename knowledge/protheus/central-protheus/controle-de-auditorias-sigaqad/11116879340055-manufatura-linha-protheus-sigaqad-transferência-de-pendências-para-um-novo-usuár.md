![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:45 min****Dúvida**Como **transferir as pendências** do usuário atual para um novo usuário?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Auditorias (SIGAQAD) - Todas as versõe  
  
**Solução**Para transferir **todas** as pendências de um usuário para outro, realize os seguintes passos:  
1. Realize *login* no Sistema com um usuário diferente do usuário que possui as pendências.  
2. Acesse a rotina **QADA015 - Transferência** e selecione o usuário que possui as pendências a serem transferidas.  
3. Clique no botão **Transferir**.  
4. No canto superior direito marque a opção **Todas as Pendências**.  
5. Selecione na *Grid* o usuário que receberá a pendência ou utilize o botão **Pesquisar Usuário**.   
6. Clique no botão **Marcar/Desmarcar Usuários** para selecionar todas as pendências.  
7. No lado direito da tela clique no botão **Salvar**.  
7. Confirme a transferência de pendências.
