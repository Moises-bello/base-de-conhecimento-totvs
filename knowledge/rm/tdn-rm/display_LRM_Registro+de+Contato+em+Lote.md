**Registro de Contato em Lote**

Este assistente tem por objetivo gerar o registro de contatos com candidatos de uma etapa de seleção em lote, agilizando assim a tarefa de registrar os contatos realizados (Anexo Registro de Contato).  
Para efetuar essa operação o usuário deve acessa a visão "Candidatos da Etapa", em seguida crie um filtro e/ou selecionar os candidatos da etapa que se deseja criar o registro de contato. Em seguida deverá executar o processo "Registro de Contato em Lote".

Os campos que deverão ser preenchidos pelo usuário são  Tipo de contato, Data/hora de Contato e Observações.

O campo "Tipo de contato" permite escolher dentre os registros de contatos já cadastrados no sistema, que estejam "Ativos".

O campo "Responsável pelo contato" será automaticamente preenchido com a identificação do usuário que está executando este registro.

Uma vez informados os devidos valores para os campos e executado o processo, o sistema irá criar um registro de contato para cada os candidatos selecionados na etapa.
