# IMPRIMIR RELATÓRIO - MATRÍCULA NO PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Processo "Imprimir Relatório" no menu "Matrícula no período letivo".* |
| **Situação/Requisito:** | No processo “Imprimir relatório” do menu “Matrícula no período letivo” estava listando somente relatórios do “Gerador de Relatórios (Antigo)”, mesmo marcando para utilizar relatórios do “RM Reports”. |
| **Solução/Implementação:** | Otimização no processo “Imprimir relatório” do menu “Matrícula no período letivo”.  Serão listados relatórios do “RM Reports” caso tenha marcado no parâmetro Educacional | Secretaria | Relatórios”, campo “Tipo de relatório” igual a “RM Reports”.  O sistema passa a habilitar na tela do processo a lista de parâmetros existentes no relatório selecionado.  Caso esteja configurado para gerar relatório “Gerador de Relatórios (Antigo)”, a tela do processo “Imprimir relatório” listará somente relatórios do antigo gerador. |
