**Dúvida**

Como alterar a data de disponibilidade das movimentações bancárias via **CTBA940?**

**Ambiente**

Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Financeiro - A partir da release  12.1.2210

**Solução:**

Para ajustar a data de disponibilidade de um título, siga os passos abaixo:

1. 1. **Selecione o registro desejado** na tela "dados não encontrados".
   2. Acesse o sub-menu **"Disponibilidade"**, clicando em **"Ações"**, conforme demonstrado abaixo:  
      ![Design sem nome.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/32986128306199)
   3. Na tela que será exibida, configure a nova data conforme necessário.

> Como no exemplo abaixo onde esta sendo alterado apenas os registros selecionados, para a data do dia 06/01/2025 em uma movimentação que originalmente estava com a disponibilidade em 03/01/2025.
>
> ![](https://centraldeatendimento.totvs.com/hc/article_attachments/28956912592151)

**Importante 📢️:**

* **Somente registros não conciliados** podem ter a disponibilidade alterada. Caso o registro esteja conciliado, será necessário desconciliá-lo antes de realizar qualquer atualização.
* **Não é permitido definir uma data de disponibilidade anterior à data de movimento.**  
  Caso essa tentativa ocorra, o sistema exibirá uma mensagem informando que **a alteração não pode ser salva**.
