![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18439774424087) Tempo aproximado para leitura: **02:00 min****Dúvida**Não está sendo possível preencher o campo "**Carga Tr.Eq**" **(WZ\_RED\_CTE)** sem antes preencher o campo "**B.C. ICMS**" (**WZ\_TP\_CALC)** dentro do Cadastro CFO (EICOP100).  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – A partir da versão 12.1.33.  
  
**Solução**Informamos que houve uma mudança e melhoria dentro do Produto, onde foi criado o campo **"WZ\_TP\_CALC".** Caso o campo em questão não seja preenchido, o sistema não fará o cálculo do **ICMS** corretamente.
