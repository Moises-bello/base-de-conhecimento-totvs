# PERÍODO AQUISITIVO FINALIZANDO EM 28 DE FEVEREIRO DE ANO BISSEXTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Férias* |
| **Situação/Requisito:** | *No processo de Finalizar Férias não está tratando vencimento em 28/02 de ano bissexto.*  *Em um periodo aquisitivo de 01/03 a 28/02, no ano bissexto deve ter o vencimento em 29/02.* |
| **Solução/Implementação:** | *Ajuste no módulo Finalizar Férias, para que em um periodo aquisitivo de 01/03 a 28/02, quando for ano bissexto altere o vencimento para 29/02.* |
| **Chamados   relacionados:** | *TUYCCX, TUWZFA* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
