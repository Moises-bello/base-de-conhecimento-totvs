# CONVERSOR DE MATRICULAS EM DISCIPLINAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *IEducacional* |
| **Módulo:** | *Conversor de Bases do RM Classis* |
| **Função:** | *Conversor de Matrículas em Disciplinas* |
| **Situação/Requisito:** | *Ao contrário do TOTVS Educacional o RM Classis permite o registro de matriculas em disciplinas sem informação de data. Registros migrados com a data nula podem causar erros nos processos de transferência de turma.* |
| **Solução/Implementação:** | *As datas de matrícula em disciplina que se encontram nulas no RM Classis passaram a ser migradas preenchidas com a mesma data da matrícula no período letivo correspondente.* |
