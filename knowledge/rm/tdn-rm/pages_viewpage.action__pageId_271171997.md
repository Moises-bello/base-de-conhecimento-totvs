# Relatório Razão - Centro de Custo / Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Razão - Centro de Custo / Contábil |
| **Situação/Requisito:** | Cliente entrou em contato informando que quando coloca duas contas no relatório Razão por Centro de Custo que tem saldo mais não tem movimentação o relatório da erro: ‘Não foram encontradas informações mínimas para geração do relatório’. Porém no Balancete por centro de custo roda normalmente. O relatório Razão deve apresentar o mesmo comportamento do relatório Balancete no processo de emissão nesta situação. |
| **Solução/Implementação:** | Ajuste do relatório Razão Centro de Custo / Contábil para que caso o centro de custo não possua 'Saldo Anterior/Movimentação/Saldo Atual' mas as contas que tem lançamento para o mesmo no período informado tenham esses valores o centro de custo seja impresso no relatório. |
