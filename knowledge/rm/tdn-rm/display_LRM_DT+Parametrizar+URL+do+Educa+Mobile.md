# Parametrizar URL do Educa Mobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Gestão Educacional |
| **Módulo:** | eduCONNECT |
| **Função:** | Parametrização da URL do Educa Mobile |
| **Situação/Requisito:** | No TOTVS Educacional, nos parâmetros do eduCONNECT não é possível realizar alteração da URL do Educa Mobile. |
| **Solução/Implementação:** | Foi disponibilizado uma nova aba (eduCONNECT 4/4) com a URL do Educa Mobile que o eduCONNECT utiliza para realizar autenticação e acesso pelo aplicativo. Assim,  o usuário do TOTVS Educacional que está integrado com o eduCONNECT poderá realizar a alteração de sua URL do Educa Mobile, sem a necessidade de entrar em contato  com a TOTVS para realizar essa alteração. |
