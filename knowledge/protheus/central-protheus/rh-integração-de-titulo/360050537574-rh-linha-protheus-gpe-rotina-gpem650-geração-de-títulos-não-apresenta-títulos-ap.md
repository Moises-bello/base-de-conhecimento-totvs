**Dúvida**Rotina GPEM650 (geração de títulos) não apresenta títulos após processamento  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal– A partir da versão 12.1.17  
  
**Solução**1. Verificar as informações de configuração do título :  
  
a)  Verificar se a verba selecionada está correta e se existe no cálculo.   
b) Observar se a legenda da verba está verde ( caso esteja vermelha, clica duas vezes na legenda para que fique verde, assumindo a condição de positivo).  
c) Verificar se a tabela selecionada para busca está de acordo com o cálculo.   
Exs: Folha aberta (tabela SRC) / Folha fechada (tabela SRD) / Rescisões e Férias (tabela SRR).  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077539234)

2. Verificar as configurações de todos os parâmetros da rotina, principalmente:  
  
a) Se a data de busca de pagamento compreende a data de pagamento do cálculo   
b) Se código o título informado está correto.
