# DISTRIBUIÇÃO DE VAGAS DE COTAS FEDERAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Processo Seletivo* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Chamada de candidatos - Distribuição de vagas de cotas federais* |
| **Situação/Requisito:** | *O sistema não está calculando corretamente a quantidade de vagas de cotas federais na chamada de candidatos.* |
| **Solução/Implementação:** | *Foi verificado que ao calcular a quantidade de vagas para deficientes o sistema estava arredondando o valor para cima, quando deveria arredondá-lo para abaixo.*  *Essa operação estava gerando uma diferença nos demais grupos de cotas e foi corrigida.*  *Segue exemplo disponibilizado pelo MEC, para conferência: <http://portal.mec.gov.br/cotas/sobre-sistema.html>* |
