Será criado novo recurso que determina formatos para importação de dados e um menu especifico para a importação. Os dados poderão ser oriundos de uma planilha Excel.   
 Cadastros que devem ser importados no módulo de aluguel do TIN:  
 1. Locador   
 2. Locatário   
 3. Procurador  
 4. Beneficiário   
 5. Administrador de Condomínio   
 6. Fiador   
 7. Imóvel   
 8. Contrato de Administração   
 a. Imóveis   
 b. Locadores (Procuradores/Beneficiários)   
 9. Contrato de Locação  
 a.Itens do contrato de locação  
 b. Locatários   
 c. Corretores   
 d. Fiadores   
 e. Garantias   
 10. ~~Eventos Financeiros Avulsos~~   
 11. Lançamentos Financeiros = parcelas que está faltando dos tributos somente os que não geraram documento no Protheus ainda   
 12. Documento (controle de documentação)   
 Tributos do último exercício ano e cadastros anexos  
 Analisar como considerar os lançamentos gerados a partir da data de corte menos a data de primeiro vencimento   
 Tedesco mandar quanto falta de reembolso  
 Seguro do último ano e cadastros anexos   
 Cadastros auxiliares que não estão contemplados neste orçamento:

* Profissão
* Filial
* Centro de Custo
* Tipo de Logradouro
* Município
* Estado
* Pais
* Código Modelo de Contrato
* Código Regra Vencimento
* Parâmetro de Integração Financeira
* Tipo de Evento Financeiro
* Código do Tipo de Locação
* Índice
* Fórmula de Reajuste
* Fórmula Rescisória
* Relatórios / DIMOB   
   Para todos os novos cadastros deve ser permitida a criação de campos complementares.   
   Funcionalidades que NÃO serão atendidas:

* Não está contemplada a documentação detalhada do processo;
* Toda e qualquer solicitação fora do escopo desta proposta deverá ser efetuada mediante nova proposta;
* Não está prevista nesta proposta qualquer atualização de dados específicos ou parametrização de base de dados especificas do cliente que não se refiram ao desenvolvimento em questão;
* Este documento é uma proposta comercial com uma breve descrição do escopo. Caso no momento do detalhamento houver uma discordância muito grande entre o proposto e a necessidade, poderá haver uma nova análise de viabilidade da proposta;

Novos Cadastros relevantes como controle de Seguro e Controle de Despesas e tributos devem ser importandos no lugar do Evento financeiro.
