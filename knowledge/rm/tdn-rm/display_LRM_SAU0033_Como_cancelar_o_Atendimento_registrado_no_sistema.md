# Como cancelar o Atendimento registrado no sistema?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como cancelar o Atendimento registrado no sistema? |
| **Passo a passo:** | **Cancelamento de Atendimento**  Nessa opção é realizado o cancelamento de atendimentos (internos/externos) registrados no sistema. Somente poderão ser cancelados aos atendimentos que não possuam lançamentos de itens de consumo na Elaboração de Contas. Na existência de consumo para o paciente (movimentação de estoque), este deverá ser excluído, para que então o cancelamento do atendimento possa ser realizado. Como cancelar o Atendimento registrado no sistema?  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Internação/Cancelamento de Atendimento**. 2. Será exibida tela inicial de cancelamento de atendimentos. 3. Clique em **Registra**. 4. Será exibida a tela para busca do atendimento. 5. Informe o Nome do Paciente ou número do Prontuário para realizar a busca. 6. Clique em **Pesquisa**. 7. Selecione o Paciente e clique em **OK**. 8. Selecione o Atendimento e clique em **OK**. 9. Selecione o Motivo do Cancelamento, como por exemplo, Evasão do Paciente. 10. Se desejar inclua observações e clique em **Grava**. 11. Clique em **Sim** para confirmar o cancelamento do atendimento. |
