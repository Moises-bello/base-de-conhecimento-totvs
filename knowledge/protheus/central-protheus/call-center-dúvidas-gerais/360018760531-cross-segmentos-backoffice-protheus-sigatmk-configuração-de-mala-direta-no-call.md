**Dúvida**

Como configurar Mala Direta no Call Center?  
  
**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGATMK - A partir da release 12

**Solução**

Para configurar:

**1 -** Em Call Center, Atualizações, Marketing, Lista de contatos, inclua uma nova lista.

**2 -** Defina o tipo de lista como "Marketing" e a entidade que deseja encaminhar a lista.

**3 -** Defina o tipo de contato como "Mala Direta", o nome da lista e o operador que a executará.

**4 -** Informe no campo Arquivo, o local onde foi colocado os arquivo \*.dot de layout de Mala Direta.

**5 -** No campo endereço, informe qual o endereço que a Mala Direta será enviada, exemplo "Comercial".

**6 -** Selecione a opção Etiqueta igual a Sim e na sequência, informe o local onde foi colocado o arquivo \*.dot de layout de Etiqueta.

**7 -** No campo contato, informe o código do contato.

**8 -** Confirme a inclusão do contato. O sistema exibirá uma mensagem, se deseja imprimir a Mala Direta.

**9 -** Após a geração dos arquivos para a impressora, basta imprimir a mala direta.

Para visualização das telas de configuração, ou acessar aos arquivos .dot, acessem a FAQ: **[TMK0030 Configuração de Mala Direta no Call Center](http://tdn.totvs.com/pages/viewpage.action?pageId=274307995)**
