# DIFERENÇA DE FÉRIAS PROPORCIONALIZA VALORES ANTES DO ABATIMENTO DO QUE JÁ FOI PAGO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Diferença de Férias* |
| **Situação/Requisito:** | *Ao gerar Diferença de Férias para funcionário que já recebeu diferença proporcionalizada, com aumento salarial somente no segundo mês das férias partidas, estão sendo calculados valores de diferença novamente.*  *Isso ocorre porque o abatimento dos valores já pagos está sendo executado antes de efetuar a proporcionalização da diferença.* |
| **Solução/Implementação:** | *Ajuste no processo de Diferença de Férias para que, no caso de aumento salarial somente no segundo mês das férias partidas, proporcionalizar os valores de diferença antes de abater os valores já pagos ao funcionário.* |
| **Chamados   relacionados:** | *TUNDYW, TVBQW7* |
| **Versões/Release:** | *12.1.12, 11.82.45* |
