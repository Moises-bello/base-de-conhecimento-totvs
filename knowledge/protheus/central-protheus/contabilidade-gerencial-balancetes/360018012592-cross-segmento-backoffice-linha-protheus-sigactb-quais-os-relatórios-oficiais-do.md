**Dúvida**Quais os relatórios oficiais do modulo contábil

**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus - TOTVS Contabilidade Gerencial - à partir da versão P12  
  
**Solução**

Para os relatórios**Balancete Modelo 1** **(CTBR040)**, **Diário Contábil (CTBR110), Balanço Patrimonial(CTBR500), DRE (CTBR510), DMPL (CTBR530), DFC (CTBR560)** e **Razão Contábil (CTBR400)** foi disponibilizado a opção **Personalizar** apenas para inserir a margem esquerda na página para impressão e encadernação dos relatórios.

Para esta funcionalidade é necessário configurar o parâmetro **MV\_CTBPOFF** com o valor = **.F.**.

As demais opções disponíveis nessa configuração não podem ser alteradas, para que não ocorra um efeito colateral nos relatórios.

**Exemplo:** Ao alterar o tamanho da fonte as informações ficam sobrepostas.

**Importante**

Devido à exigências legais, estes relatórios não estão disponíveis para personalização ou customização. Desta forma, os mesmos não se encontram disponíveis para download.
