![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19140368649751) Tempo aproximado para leitura: **02:00 min** **Dúvida**Como tratar a Exportação via *Courier*?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus– *Easy Export Control* – A partir da versão 12.1.33.  
  
**Solução**É possível registrar declarações de exportações via *Courier* utilizando o *Easy Export Control*. Para isso, deve-se seguir o mesmo modelo utilizado no Portal Único, indicando a forma de exportação relativa ao tipo de processo no campo **"Forma Export" (EEC\_FOREXP)** da aba **"DUE"** do Embarque de Exportação (certifique-se de estar com o cenário de integração com a DUE, parâmetro "**MV\_EEC0053"**, habilitado).  
Adicionalmente, podem ser utilizados os demais campos existentes no sistema para registrar em caráter informativo as demais informações do processo, ou mesmo incluir campos de usuário caso julgar necessário, sem impacto nas declarações de exportação.
