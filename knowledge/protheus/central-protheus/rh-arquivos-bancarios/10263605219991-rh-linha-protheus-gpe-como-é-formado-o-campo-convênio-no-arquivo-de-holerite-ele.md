![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32324001252375) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como é formado o campo convênio no arquivo de holerite eletrônico Santander?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Conforme layout do holerite eletrônico do Santander, o campo convênio tem 20 posições, sendo a junção dos campos banco + agência + convênio:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10262681968919)  
  
Para montar o campo no arquivo, o Sistema considera o conteúdo das perguntas banco, agência e convênio da geração do arquivo, juntando o conteúdo dos três campos e montando o campo Convênio no arquivo:
