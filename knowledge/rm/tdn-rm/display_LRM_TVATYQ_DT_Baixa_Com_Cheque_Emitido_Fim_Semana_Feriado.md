|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa com cheque emitido |
| **Situação/Requisito:** | Na baixa de lançamento com cheque emitido o parâmetro aceita baixar a receber ou a pagar em finais de semanas e feriados não é observado |
