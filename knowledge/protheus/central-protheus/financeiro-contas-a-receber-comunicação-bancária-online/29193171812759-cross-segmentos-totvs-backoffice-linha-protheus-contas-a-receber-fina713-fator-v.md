![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29193152662807) Tempo aproximado para leitura: **00:10:00 min** **Dúvida**Boleto API FINA713 trata de alguma forma o fator vencimento de 22.02.2025?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Fiscal - Todas as versões]  
  
**Solução**O Protheus somente trata o fator vencimento apenas na **Geração do arquivo de remessa (FINA150)**

Para geração de cobranças via API FINA713, fica de responsabilidade do banco a geração do fator vencimento na linha digitável do código de barras.

Para geração de boletos RDMAKE customizados, é necessário avaliar sua customização se está adptada ao Fator Vencimento abaixo

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29193152664471)

Para mais dúvidas, sugerimos abrir chamado junto ao suporte do banco.
