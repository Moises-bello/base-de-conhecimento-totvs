**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16502932846743) Tempo aproximado para leitura: 00:01:00 min****Dúvida**Como é feita a importação de histórico de horários?  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 11.80  
  
**Solução**O processo de importação de histórico de horários é efetuado no módulo de Folha de pagamento, através do menu **Configurações | Importações | Importação de dados Folha de Pagamento.**

![importar_historico_horario.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29044421024663)

**Importante**

O arquivo deve ter layout conforme documentação a seguir.

[Layout Para Importação de Histórico de Horário](https://tdn.totvs.com/pages/releaseview.action?pageId=452719198)
