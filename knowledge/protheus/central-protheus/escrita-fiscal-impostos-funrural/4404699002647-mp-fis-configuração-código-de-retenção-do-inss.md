**Dúvida**  
Como configurar o código de retenção do **INSS** no documento de entrada?  
  
**Ambiente**  
Cross Segmento - Microsiga Protheus – Livros Fiscais – A partir da versão 11.80  
  
**Solução**

Para configurar o código de retenção do **INSS** no documento de entrada realize os seguintes passos:

1. Verifique no **Configurador** os parâmetros abaixo e configure o código de retenção;

**MV\_RETINPF** - Código de retenção de **INSS** Fornecedores PF;

**MV\_RETINPJ** - Código de retenção de **INSS** Fornecedores PJ;

OBS: Quando gerar o documento de entrada, o código de retenção irá gravar no financeiro no campo E2\_RETINS;
