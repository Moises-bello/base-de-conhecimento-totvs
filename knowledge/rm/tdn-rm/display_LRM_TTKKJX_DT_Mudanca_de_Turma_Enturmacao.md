# Mudança de turma - Enturmação

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Mudança de turma no processo de enturmação* |
| **Situação/Requisito:** | *Ao efetuar a mudança de turma através do processo de enturmação, quando existe choque de horário, mesmo que o sistema esteja parametrizado para permitir a matrícula nessa situação, é lançada uma exceção cancelando a mudança.* |
| **Solução/Implementação:** | *Ao efetuar a mudança de turma através do processo de enturmação, quando existir choque de horário, caso o sistema esteja parametrizado para permitir a matrícula nessa situação, a mudança será realizada.* |
