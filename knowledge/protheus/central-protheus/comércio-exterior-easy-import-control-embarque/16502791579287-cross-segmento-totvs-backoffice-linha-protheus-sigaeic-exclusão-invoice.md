![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16502786143639) Tempo aproximado para leitura: **05:00 min** **Dúvida**Por que o botão para excluir a Invoice não é apresentado na rotina de embarque?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16504180271895)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**O botão de "**Exclusão**" é exibido na tela principal de manutenção das Invoices. Neste caso, quando uma Invoice possuir baixa, seja por liquidação ou compensação, o botão não será exibido.
