**Dúvida**Como deve ser definido o Compartilhamento de Tabelas SIGAGPE x SIGATAF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as Versões  
 **Solução**Antes de Iniciar a **Carga Inicial**, verifique se o compartilhamento das Tabelas do **SIGAGPE (Gestão de Pessoal)** x **SIGATAF (Totvs Automação Fiscal)** estão compatíveis, isto porque a integração dos dados de **Folha** com o **TAF** é  feita dentro do mesmo Banco de Dados, basicamente os registros são lidos das tabelas **origem**, que são tabelas do **SIGAGPE** e gravados nas tabelas **destino** que são tabelas do **SIGATAF**.

Por esta razão os compartilhamentos devem ser iguais, para que não haja duplicidade de dados e nem gravação em Filiais incorretas.

Acesse o *link* para ver a relação de tabelas **GPE** X **TAF**:**[eSocial - Como deve ser definido o Compartilhamento de Tabelas SIGAGPE x SIGATAF](http://tdn.totvs.com/display/PROT/Como+deve+ser+definido+o+Compartilhamento+de+Tabelas+SIGAGPE+x+SIGATAF)**
