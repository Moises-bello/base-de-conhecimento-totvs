|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |

| **Função:** | Cheques |
| **Situação/Requisito:** | Parâmetro Data Default Vencimento do cheque pré-datado não é validado ao emitir um cheque para vários lançamentos informando dados somente uma vez. |
| **Solução/Implementação:** | Melhoria na tela de recebimento de cheques, para que ao selecionar as opções "Um cheque para cada lançamento" e "Informar dados apenas uma vez" o sistema  passe a tratar a data de vencimento default parametrizada, recebendo a data do lançamento, não mais repetindo a data de vencimento informada na tela de  recebimento do cheque. |
