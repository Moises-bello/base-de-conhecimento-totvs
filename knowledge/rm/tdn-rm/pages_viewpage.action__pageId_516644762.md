**Implementada melhoria nos V[alores de Integração](https://tdn.totvs.com/x/6k_2Hw) para lançamentos provenientes do módulo Gestão Financeira**

Os valores de integração poderão ser parametrizados no Gestão Financeira para que os lançamentos inseridos no módulo carreguem esses valores de integração para o lançamento financeiro.

**Evolução do sistema para atender a rotina do Livro de Caixa do Produtor Rural - [LCDPR](https://tdn.totvs.com/x/ZUI9I)**

Desenvolvido layout  FINLAY0060 - LCDPR - Livro Caixa Digital Produtor Rural.TotvsGen para atender a demanda de geração de dados da rotina sobre informações de Pessoas físicas que realizam atividades de exploração Rural. 

**Implementado Campo Complementar para [Itens de Baixa](https://tdn.totvs.com/x/fOEdGQ)**

Implementado no cadastro de Campos Complementares a opção para Itens de Baixa.

**Melhoria na cópia dos campos complementares do [Adiantamento](https://tdn.totvs.com/x/gOEdGQ) para o Crédito de Adiantamento**

Os dados dos campos complementares do Lançamento de Adiantamento, serão carregados como default para o lançamento de Crédito de Adiantamento.
