# Ajuste no Formulário Faturamento AIH, BPA, APAC

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento AIH, BPA e APAC. |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu: **Faturamento/Faturamento SUS/Faturamento AIH, BPA e APAC**, abrir o formulário, selecionar a unidade de faturamento, convênio, marcar o tipo de faturamento para BPA, exibir os registros, selecionar os registros que deseja que não sejam faturados e clicar no botão iniciar, é possível verificar que era exibido uma mensagem de exceção:  "Erro na gravação de faturamento. Violação de acesso no endereço 4D5F0385 no módulo 'SQLORA8.DLL'. |
| **Solução:** | Ajuste realizado no formulário: **Faturamento/Faturamento SUS/Faturamento AIH, BPA, APAC,** para que ao iniciar o processo de faturamento, seja finalizado de acordo com o esperado. |
