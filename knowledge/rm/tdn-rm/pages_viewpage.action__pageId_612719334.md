**APP Minhas Aprovações**

* **Relatórios para aprovação -**Foi disponibilizado modelo de relatório para o aplicativo Minhas Aprovações, que permitirá a visualização dos dados das solicitações a serem aprovadas, para:
  + **Pedidos**
  + **Adiantamentos de Contratos**
  + **Liberação de Período (Boletim de Medição)**

Esses relatórios poderão ser utilizados caso a integração do TCOP com o TAA para a geração dos respectivos workflows esteja ativada.  [Saiba mais](https://tdn.totvs.com/x/1tQdGQ)
