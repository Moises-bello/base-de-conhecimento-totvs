A partir da versão 11.50 o TOTVS Incorporação conta com o recurso Geração de 2ª Via de Boleto Web para os contratos de vendas imobiliárias. Para iniciar a utilização destes recursos, sugerimos realizar os passos descritos em .   
Os requisitos para a geração de segunda via de boleto são:

* Acessar os parâmetros Web | Boleto | SegundaVia do TOTVS Incorporação e informar o relatório para a impressão do boleto. A confecção deste relatório fica a critério da empresa que utiliza esta implementação.
* Na base de dados deve-se associar cada cliente à um usuário do sistema, desta forma os mesmo poderão acessar a base via web e realizar a geração da segunda via do boleto.
* Deve-se também iniciar o os serviços em Ambiente | Gerenciador de Jobs.
