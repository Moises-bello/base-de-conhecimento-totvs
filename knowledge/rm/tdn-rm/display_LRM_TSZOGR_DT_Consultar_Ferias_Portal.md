# CONSULTA DE FÉRIAS (PORTAL)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Consulta de Férias* |
| **Situação/Requisito:** | Após mudar as tabelas e estruturas de dados relacionados às férias, a página de Consulta de Férias do portal continuou usando a antiga visão, limitando a visualização das informações. |
| **Solução/Implementação:** | *Foi atualizada a página para usuários que utilizem o Cálculo .Net para a nova estrutura, permitindo também que sejam visualizadas agora as férias com status de "Finalizadas no Próximo Mês", "Lançadas" ou "Pagas".* |
