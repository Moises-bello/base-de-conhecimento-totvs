|  |  |
| --- | --- |

| **Situação/Requisito:** | *Existem casos que o lançamento está gerado em uma conta caixa, e por algum motivo precisamos cancelar esse lançamento e gerar novamente em uma conta caixa diferente, ao gerar o lançamento mesmo informando uma conta caixa diferente o sistema puxa a conta caixa do lançamento antigo que está cancelado.* |
| **Solução/Implementação:** | *Foi incluído uma validação no processo de geração de lançamentos para atualizar a conta caixa e dados bancários ao regerar lançamentos que são do status cancelados.* |
