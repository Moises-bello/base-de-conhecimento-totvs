# RESCISÃO COLETIVA COM REQUISIÇÃO DE TRANSFERÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Pessoas |
| **Função:** | Rescisão Coletiva com Requisição de Transferência |
| **Situação/Requisito:** | Ao fazer um transferencia atraves do processo de rescisão coletiva usando uma requisição de transferencia em lote ou individual ocorre erro.  O funcionário é transferido, porém a requisição não é concluída, ficando como aprovada. |
| **Solução/Implementação:** | Realizado ajuste para que seja aplicada tratativa sobre a requisição aplicada na Rescisão coletiva, afim de identificar se a mesma é de Transferência, Transferência com Promoção, Transferência em Lote ou Desligamento. |
