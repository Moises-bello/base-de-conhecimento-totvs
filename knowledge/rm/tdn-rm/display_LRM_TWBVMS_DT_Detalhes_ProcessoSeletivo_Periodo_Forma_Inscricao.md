# DETALHES DO PROCESSO SELETIVO - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Detalhes do processo seletivo - portal* |
| **Situação/Requisito:** | *Foi identificado que ao visualizar os detalhes de um processo seletivo que tenha mais de uma forma de inscrição, o período de inscrição mostradona tela, sempre será o da última forma de inscrição, não a menor e maior data.* |
| **Solução/Implementação:** | *Foi feito o ajuste para que o sistema exiba a menor datas as formas de inscrição ativas e a maior data, assim a data inicial e final ficam de acordo com a realidade do processo seletivo.* |
