Dúvida**Como realizar a liquidação e estorno da liquidação do título tipo INV?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**Procedimento para liquidação:  
1- Acesse a rotina de Atualizações \ Financeiro \ Controle Cambio (EICAP100);  
2. Posicione no processo e selecione Alterar;  
3. Posicione na parcela e selecione Outras Ações \ Liquidar;  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360070716493/mceclip1.png)  
4. Preencha os dados de liquidação e selecione o Salvar:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360069607654/mceclip2.png)

5. A data de liquidação será preenchida, selecione Salvar, para gravação da baixa:   
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360070716633/mceclip3.png)

Procedimento para Estorno:

1- Acesse a rotina de Atualizações \ Financeiro \ Controle Cambio;  
2. Posicione no processo e selecione Alterar;  
3. Posicione na parcela e selecione Outras Ações \Estornar Liquidação:  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360070716713/mceclip4.png)  
4. Confirme o estorno selecionando Sim:  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360070716753/mceclip5.png)  
5. A data de liquidação será apagada, após selecione Salvar:  
![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360069607834/mceclip6.png)
