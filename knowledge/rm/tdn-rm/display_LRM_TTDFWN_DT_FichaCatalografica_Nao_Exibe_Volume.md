# EXEMPLARES - FICHA CATALOGRÁFICA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Ficha catalográfica de exemplares* |
| **Situação/Requisito:** | *Foi identificado que ao gerar a ficha catalográfica o volume cadastrado para o exemplar não estava sendo exibido.* |
| **Solução/Implementação:** | *Foi identificado que na montagem da ficha catalográfica, realmente não estava sendo carregado os dados do volume do exemplar, foi realizado o ajuste conforme o "Código de catalogação anglo-americano" nos itens 1.5B1 e sub-seções 2.5B16, 2.5B17, assim quando o exemplar de uma publicação tiver volume cadastrado, o mesmo será exibido na geração da ficha catalográfica.* |
