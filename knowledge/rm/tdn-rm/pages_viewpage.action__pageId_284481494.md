# Ajuste ao Alterar Número da Guia do Atendimento Externo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao alterar o número da guia no registro de atendimento externos, o sistema apagava o valor do campo número guia prestador. |
| **Solução:** | Realizado ajuste para não apagar o número da guia prestador ao alterar o número da guia no registro de atendimentos externos. |
