**Concorrência Eletrônica**

---

A concorrência eletrônica permite que o usuário envie informações referentes aos insumos e composições, que são utilizadas nos itens que estão sob processo de cotação eletrônica, para as empresas participantes. Permite também que seja feita toda a equalização de tarefas, insumos e composições.  
    
 **Etapas** **do processo:**

* Criar o projeto de licitação com a tarefas/composições/insumos a serem processadas.
* Exportar dados do projeto que foi criado para planilhas do Excel as tarefas/composições/insumos a serem enviadas para as empresas que participarão da licitação.
* Importar as planilhas preenchidas pelas empresas que participam da licitação. Será criado um novo projeto para cada importação realizada.
* Realizar equalização das licitações para comparar as planilhas que foram importadas.

Gerar Contrato da Licitação.  
    
 **Observações:**  Para realizar as demais etapas da Concorrência Eletrônica como: Gerenciador, Equalização, Negociação entre outros é necessário gerar um Projeto de Licitação.
