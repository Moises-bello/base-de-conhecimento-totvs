# EDIÇÃO DE PEDIDO DE MATERIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Edição de Pedido de Material. |
| **Situação/Requisito:** | Deverá ser criado a pagina de edição de Pedido de Material  Ter como referencia o protótipos criados.  Remover na edição do pedido o Tipo de Geração no canto direito do protótipo.  Alterar o link 'todos os produtos' para 'editar itens'.  Realizar a codificação do Histograma Resumo. |
| **Solução/Implementação:** | Foi desenvolvido a edição de pedido de material de forma responsiva para os dispositivos: mobile, tablet e desktop.  A edição possui:   * Itens do pedido (Insumo e produto associado) * Informações do Pedido (Status, Data Requisição e Tipo de Requisição * Configurações (Utiliza Preço Orçado, Tipo de Movimento e Local de Estoque) * Histograma Resumo.   Pela edição é possível realizar a mudança de tipo de movimento e local de estoque, alem de informar a utilização de preço orçado |
