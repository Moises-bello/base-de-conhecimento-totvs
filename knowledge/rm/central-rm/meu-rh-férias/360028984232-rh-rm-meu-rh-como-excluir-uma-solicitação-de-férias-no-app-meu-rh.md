**Dúvida**Como excluir uma solicitação de férias no app **Meu RH**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Meu RH - A partir do release 12.1.17  
  
**Solução**Assim como é possível efetuar solicitações de férias pelo aplicativo **Meu RH**, também é permitido **cancelar as marcações**. O cancelamento pode ser feito pelos próprios usuários do aplicativo desde que as solicitações não tenham sido aprovadas pelo gestor. 

A **exclusão** de uma solicitação pode ser feita através dos seguintes passos:

1. Primeiramente, acesse a tela de Férias.

2. No canto superior direito do quadrado azul, com as informações da solicitação, existe uma sequência de três pontos (...). Essa sequência de pontos representa um menu. Clique nesse menu.

3. Após acessar o menu, clique no botão "Excluir".

4. Depois de clicar no botão "Excluir", uma nova janela será mostrada para o usuário. Nessa tela, é possível tomar duas ações. A primeira é cancelar o processo de remoção clicando no botão "Cancelar". Ao escolher essa opção, o aplicativo retorna para a tela de Férias e nenhuma modificação é feita. Por outro lado, se o botão "Excluir" for pressionado a solicitação será removida do sistema.
