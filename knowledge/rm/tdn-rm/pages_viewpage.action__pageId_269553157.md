# MATRICULA ON LINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Portal - Matricula online* |
| **Situação/Requisito:** | No Portal, o sistema não está permitindo realizar matricula online caso esteja marcado os parâmetros “Não altera a situação de matrícula na disciplina (apenas para matrícula on-line)” e ao mesmo tempo o “Bloqueia alteração de situação de matrícula nas disciplinas”. |
| **Solução/Implementação:** | No Portal, ao realizar matricula online o sistema deverá realizar a matrícula caso estiver marcado o parâmetro da situação de matrícula “Não altera a situação de matrícula na disciplina (apenas para matrícula on-line)”, mesmo que esteja marcado o parâmetro “Bloqueia alteração de situação de matrícula nas disciplinas”. |
