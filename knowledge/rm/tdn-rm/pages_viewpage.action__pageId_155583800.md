| **Sintoma** | **Como fazer para adicionar valores à base de cálculo das médias?** |
| Solução | Para adicionar valores à base de cálculo, no caso de médias, é necessário criar uma fórmula e informá-la na aba “fórmulas adicionais” em Opções | Parâmetros | RM Labore.  A fórmula deverá ser informada conforme o tipo de média específica. Seja ela média de Férias, 13º salário ou Aviso Prévio.  Média de Férias  Acesse: “Parâm. Férias | Fórmulas adicionais”  Média de 13º Salário  Acesse: “Parâm. 13º Salário | Fórmulas adicionais”  Média de Aviso Prévio  Acesse: “Parâm. Rescisão | Fórmulas adicionais”  *Obs. É necessário que o parâmetro "Despreza fórm. base salário" esteja desmarcado dentro do sindicato do funcionário para cada uma das médias (Férias, 13º salário ou Aviso Prévio.)* |
