# SITUAÇÃO DE DISCIPLINAS QUE POSSUEM MAIS DE UMA EQUIVALÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Análise curricular |
| **Situação/Requisito:** | No cadastro de equivalência está definido que a disciplina B, elimina a disciplina A, mas na análise curricular está exibindo a disciplina C (reprovada) como equivalente e não a disciplina B que o aluno está cursando.  Se desmarcamos o parâmetro (Parâmetros -> Secretaria -> Geral 2/7) "Exibir disciplinas equivalentes reprovadas na análise curricular", o mesmo na análise não irá exibir que o aluno já cursou a disciplina em algum momento e foi reprovado. Com o parâmetro marcado a disciplina que está sendo exibida como equivalência não é a que está cadastrada em Cursos / Habilitações | Anexos | equivalências de disciplinas. |
| **Solução/Implementação:** | Alteração na análise curricular para mostrar a disciplina equivalente que o aluno está cursando quando ele possuir, para a mesma disciplina da grade, uma equivalente cursando e outra equivalente reprovada. |
