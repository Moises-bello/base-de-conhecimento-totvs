# Geração do grupo de pagamentos para NF-e de Ajuste ou Devolução

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Totvs Gestão Fiscal |
| **Função:** | Envio de NF-e |
| **Situação/Requisito:** | Ao enviar uma NF-e de devolução ou ajuste está sendo apresentado a rejeição:  871/Rejeicao: O campo Forma de Pagamento deve ser preenchido com a opcao "Sem Pagamento" |
| **Solução/Implementação:** | Ao enviar uma NF-e de devolução ou de Ajuste, o grupo de pagamento deve ser gerado com a tag tPag contendo o valor 90 ( Sem Pagamento ) conforme prevê o manual da SEFAZ |
