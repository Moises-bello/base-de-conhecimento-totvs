**Dúvida**  
Quais são os cadastros necessários para realizar o controle de exames e consultas medicas ocupacionais ?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - Segurança e Saúde Ocupacional -  Todas as versões  
  
**Solução**  
Para realizar o controle de exames e consulta medicas ocupacionais:

1. Criar o exame. Acesse no módulo Segurança e Saúde Ocupacional através do menu **PCMSO | Exames**:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846855370263)

2. Criar a entidade que realizará o exame no módulo Gestão de Pessoas no menu **Desenvolvimento | Entidades**.   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846855372183)

3. Associar o exame a entidade, através do cadastro de convênio no módulo Segurança e Saúde Ocupacional no menu **PCMSO | Convênios**.   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846855373591)

**Importante**  
Caso deseje ter o controle de exames pendentes, realize os passos abaixo. Caso não deseje ter o controle passe para o passo 4.   
  
-  Criar um perfil de exames com os exames necessários, acessando o menu **PCMSO | Perfil de Exames e** vincule a **Bateria de Exames** nos anexos.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846855374999)

- Associe o Perfil de Exames para a Associação que estará atrelada ao funcionário de alguma maneira em **PCMSO** | **Assist. Associação de Perfil.**

Para associar, basta arrastar o Perfil de Exame para a **Função, Seção e/ou Lotação**desejada.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846859357079)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846855379607)

- Gerar os exames pendentes. No cadastro de funcionários, selecione os registros desejados e vá em **Processos | Gerar Exames Pendentes**.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846859360279)

4. Após o a consulta e/ou exame ser realizado, é necessário realizar o cadastro. Acesse o menu **PCMSO | Prontuário Medico** e realize a inclusão.    
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26846859361815)
