# Novo Portal do Processo Seletivo - Campo do Campus como obrigatório

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Portal Processo Seletivo |
| **Função:** | Inscrição |
| **Situação/Requisito:** | No momento da inscrição, se o candidato escolhe uma cidade que possui multicampi, o sistema não obriga o preenchimento do campo "campus" |
| **Solução/Implementação:** | Foi realizada manutenção para tornar o campo "campus" obrigatório quando a cidade informada possui mais de um campus disponível, exigindo assim que o candidato informe para qual está fazendo a inscrição. |
