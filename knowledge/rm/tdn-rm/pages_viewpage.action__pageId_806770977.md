## **02. SITUAÇÃO/REQUISITO**

Realizado ajustes na descrição de campo e logs para indicar as configurações para o TAF e Middleware.

## **03. SOLUÇÃO**

Adequado o sistema para indicar que o processo é utilizado tanto para o TAF, quando para o Middleware. As seguintes tratativas no produto TOTVS Folha de Pagamento foram realizadas:

**1)** Ajustado a descrição do parâmetro abaixo:

**De:** Envio de XML para o TAF  
**Para:** Envio de XML para o TAF/Middleware

**2)** Ajustada a mensagem apresentada no processo "Enviar XML" do evento "S-2230-Afastamento Temporário".

**3)** Ajustada a mensagem apresentada no processo "Enviar XML" do evento "S-2299-Desligamento".
