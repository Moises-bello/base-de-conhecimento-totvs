# Envio de E-mail - Importação da Cotação Web

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Gestão de Estoque, Compras e Faturamento* |
| **Função:** | *Importação de Cotação Web* |
| **Situação/Requisito:** | O processo responsável por importar a cotação da Web não está comunicando o Comprador através de E-mail. |
| **Solução/Implementação:** | Foi criado o parâmetro "Enviar E-mail para o Comprador" no processo responsável por importar cotação da Web. Com este parâmetro marcado, o comprador da cotação será comunicado  quando a mesma estiver sido importada através de E-mail. |
