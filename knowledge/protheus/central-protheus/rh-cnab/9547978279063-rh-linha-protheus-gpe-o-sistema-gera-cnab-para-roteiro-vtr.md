![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22686469412503) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**O sistema gera Cnab para roteiro VTR?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões.  
  
**Solução**Para geração do arquivo CNAB é necessário existir uma verba de líquido no cálculo realizado, e este cálculo seja referente ao roteiro desejado (roteiro, data de pagamento, verba de líquido). Não há por padrão uma verba específica de líquido para este roteiro, de modo que na geração ocorra cálculo de VTR, com verba de líquido e contrapartida.

Como alternativa, por padrão , existe a possibilidade de efetuar pagamentos extras dentro do roteiro de cálculo VEX.
