No processo de matrícula é possível realizar a baixa de .

Esta funcionalidade pode ser habilitada via .

O uso desta funcionalidade visa facilitar o processo de matrícula, uma vez que usuário poderá informar a entrega de documentos exigidos pela Instituição durante o próprio processo.

Caso o aluno tenha pendências relacionadas à documentação obrigatória, o usuário será informado com uma lista de documentos a ser entregue pelo aluno.

Na lista de documentos retornados, será possível inserir a quantidade de documentos entregues e a data de entrega de cada documento.

Após a informar a entrega da documentação, o processo de matrícula será executado normalmente.  
    
 Observação:

Esta funcionalidade não impede que o aluno seja matriculado. Caso o usuário queira realizar a matrícula mesmo com pendências na documentação, é necessário que este tenha permissão e aceite continuar com o processo de matrícula, mesmo com as pendências listadas.

   
 Para fins de controle, será armazenado no sistema o usuário responsável por cadastrar essa informação.

Exemplo:

Em Instituição de Ensino foram cadastrados documentos obrigatórios para que o aluno pudesse ser matriculado.   
 Durante o processo de matrícula, caso o aluno tenha pendências relacionadas a documentação obrigatória não entregue, o sistema retornará uma lista com os documentos pendentes do aluno.  
 Na lista com documentos obrigatórios não entregues, o usuário informará a quantidade de documentos entregues e a data de entrega de cada documento.  
 Após adicionar esta informação ao sistema, o aluno será matriculado normalmente.
