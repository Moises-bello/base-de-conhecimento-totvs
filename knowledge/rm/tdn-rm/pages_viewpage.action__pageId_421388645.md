Este processo poderá ser executado quando o lançamento estiver bloqueado por concorrência. Uma vez bloqueado o lançamento para baixa o sistema irá consistir a parametrização definida e o usuário que disparou no sistema o bloqueio. Para execução do processo é preciso que o usuário de execução tenha permissão de acesso ao menu do sistema. O desbloqueio poderá ser realizado pelo usuário que efetuou o bloqueio e/ou no caso de ausência desse usuário o supervisor poderá também executar o processo.

O processo está disponível no menu Utilitários | Ajuste na Base | Corrigir Lançamentos Bloqueados por Concorrência.
