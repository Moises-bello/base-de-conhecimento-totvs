Nesta página é possível acessar a agenda do aluno: Através desta funcionalidade o aluno pode acompanhar através uma agenda todas as atividades direcionadas a ele, datas de trabalhos, lição de casa, atividades curriculares.

O calendário é exibido de forma que cada tipo de 'compromisso' é identificado por uma cor para facilitar a consulta.   
Para definir os itens que irão aparecer no calendário do aluno acesse: Configurações | Parametros | RM Portal | RM - Portal - Gerais  
Visualização da Agenda do Aluno no portal:  
Acesse: **Portal |Acadêmico |Agenda do Aluno**  
A agenda do aluno será exibida por dia / semana / mês e cada item é identificado por uma cor seguindo a legenda.

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
|  | **Segunda-feira** | **Terça-feira** | **Quarta-feira** | **Quinta-feita** | **Sexta-feira** |
|  | **20 de junho** | **21 de junho** | **22 de junho** | **23 de junho** | **24 de junho** |
| **07:00 às 07:50** | **Avaliação**  **(Calculo I)** |  | **Encerramento de**  **Matricula** |  | Atividades inscritas   (Laboratório) |
| **08:00 às 08:50** |  | **Limite de entrega**  **de trabalho** |  |  |  |
| **09:00 às 09:50** |  |  |  | Lição de casa  (Estatística) |  |

Quando uma atividade do calendário é selecionada o aluno consegue ver os detalhes como: Período Letivo, curso, turma, turma/disciplina...
