**Dúvida**

É  possível mudar a palavra " Página " ou " Folha " na impressão dos relatórios contábeis apresentada no canto superior direito?  
  
  
**Ambiente**  
Protheus – Contabilidade Gerencial – A partir da versão 11.80

**Solução**

Para solucionar essa dúvida, configurar o parâmetro MV\_CTBPAG. A configuração deste parâmetro permite substituir a palavra "página" pela palavra "folha" do cabeçalho padrão dos relatórios contábeis.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013416832)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013420432)

Observação:  
Caso o parâmetro MV\_CTBPAG não esteja configurado, o sistema assume, no cabeçalho, o texto padrão "Folha" para alguns relatórios.
