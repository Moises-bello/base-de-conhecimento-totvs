# AVALIAÇÃO DE DESEMPENHO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Avaliação de Desempenho* |
| **Situação/Requisito:** | *No preenchimento da avaliação consensual (180), a sinalização de comentário obrigatório (ícone vermelho) muda de lugar de acordo com a visualização selecionada: se abertas as avaliações de dois ou mais funcionários aparece na coluna Av. Gestor, que já está preenchida. Se selecionada apenas um funcionário aparece na coluna Consensual, que é o correto.* |
| **Solução/Implementação:** | *O sistema permitia a abertura de mais de uma avaliação, sendo uma delas consensual, de forma equivocada. Quando isso acontecia, havia a inconsistência dos comentários obrigatórios. Foi feito um ajuste na AD para que a AD Consensual só seja aberta individualmente, sem permitir que ela seja aberta junto com outro avaliação.* |
