**Dúvida**  
É possível incluir um novo tipo de disciplina no campo Tipo - TIT\_TIPO?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**  
Não é possível incluir um novo tipo de disciplina novo, o campo TIT\_TIPO não é customizável.   
As opções disponíveis são Punição e Mérito.   
  
Uma sugestão seria criar um campo novo, copiando as configurações deste campo e adicionar mais opções.  
[Framework - Linha Protheus - Criar campo novo](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360034355393-Framework-Linha-Protheus-Criar-campo-novo)
