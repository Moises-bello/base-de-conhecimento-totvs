Os produtos TOTVS estão em constante evolução para transpor desafios e acompanhar cada etapa da jornada digital da sua empresa.

Por este motivo, comunicamos que a utilização da solução **Gestão de Frete Embarcador (SIGAGFE) com Banco de Dados OpenEdge** será descontinuada em **30/06/2023.**

A seguir, esclarecemos as possíveis dúvidas sobre a transição para a solução Gestão de Frete Embarcador com novo Banco de Dados:

**Posso realizar o upgrade para o release 12.1.33?**

Ao realizar o upgrade para o release 12.1.33, você **não** deve migrar o dicionário de dados para banco de dados.  

O release 12.1.33 para a solução Gestão de Frete Embarcador é o último release que terá suporte ao banco de dados OpenEdge, desde que o dicionário de dados não seja migrado para banco.

*Portanto, para continuar com o suporte técnico até a data da descontinuação, você não deve migrar o dicionário de dados para o banco de dados.*

**O que vai acontecer com os meus dados?**

Todos os clientes que ainda utilizam a solução Gestão de Frete Embarcador **com o Banco de Dados OpenEdge**, devem realizar a conversão de sua base de dados do Gestão de Frete Embarcador para outro banco de dados homologado pela TOTVS Linha Protheus, entre eles: PostgreSQL (código aberto e gratuito), Oracle ou  MSSQL.

**O que vai acontecer se eu não migrar para um banco de dados homologado até a data da descontinuação?**

Se você não realizar a migração para um novo banco de dados homologado até a data da descontinuação, não terá mais suporte para eventuais situações encontradas nesta versão/banco e enquanto não migrar, não poderá atualizar para as próximas versões, a exemplo da 12.1.2210.

Os relatórios e consultas customizadas em Progress (OpenEdge)  possivelmente irão requerer adequações após a data da descontinuação. Portanto é importante planejar a migração destes customizados. A TOTVS pode te ajudar na exceção da migração. Caso seja do seu interesse, contate seu ESN (Executivo de Soluções e Negócios) para saber mais.

**O que vai acontecer após a data da descontinuação?**

Conforme nossa Política de Ciclo de Vida de Software, a partir da data de descontinuação, a TOTVS não irá evoluir, prestar suporte ou dar manutenção para a solução Gestão de Frete Embarcador com banco de dados OpenEdge.

**Existe algum conversor para realizar a migração dos dados?**

Preparamos uma documentação para te ajudar nesta transição.

Acesse aqui: <https://tdn.totvs.com/display/tec/DBTools>.

Esta documentação permite que a migração para o novo banco de dados seja realizada pela sua equipe especializada. Caso não possua uma equipe especializada em sua empresa ou se preferir, a TOTVS fornece esse serviço sob demanda. 

 

**Preciso fazer a validação do novo banco de dados em meu ambiente?**

Recomendamos que, para assegurar o sucesso na adoção do novo banco de dados, seja realizada a validação da aderência e definição de configurações específicas e novas parametrizações, seguidas de rodadas de testes. 

 

Estamos à disposição para esclarecer qualquer dúvida. Basta entrar em contato com o seu ESN (Executivo de Soluções e Negócios)!
