<Resumo do que foi contemplado na alteração associada a essa nota de release> 

|  |  |
| --- | --- |
| Ocorrência | Ao editar alguma célula do componente TCBrowse que contenha o campo do tipo combobox só é possível ir para a próxima célula se pressionar a tecla ESC. Pressionando as teclas ENTER ou TAB a tela fica travada. |
| Correção | Corrigido o componente para que quando pressionar ENTER ou TAB o cursor vá para a próxima célula. |
| Informações adicionais | * Referente ao ticket: 4723618 * Referente à ocorrência: MTEC-2285 * Disponível a partir da build 7.00.131227A - 4.2.3 |
