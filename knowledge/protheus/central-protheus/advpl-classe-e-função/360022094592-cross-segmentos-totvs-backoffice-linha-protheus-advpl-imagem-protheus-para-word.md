Dúvida**Preciso atribuir uma imagem no documento .dot, isto é possível por Macro, integrando ao Protheus  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Não há como inserir um arquivo de imagem,  cria macro via integração do OFFICE não é possível,  para as macros direto no Word, pode utilizar função para execução da mesma exemplo: **[Ole\_ExecutaMacro](http://tdn.totvs.com/display/public/PROT/OLE_ExecuteMacro)****Saiba mais**[Integração Microsoft Office](http://tdn.totvs.com/pages/releaseview.action?pageId=6815135)
