## **01. VISÃO GERAL**

A alteração de contexto é necessária para segregar dados e garantir a precisão das operações, direcionando o trabalho para a **Coligada** correta no sistema. Ao mudar, o sistema recarrega a sessão e ajusta automaticamente todos os filtros e parâmetros para exibir apenas os dados da nova empresa selecionada.

No PEP RM é possível definir o contexto que ficará associado ao usuário.

Passo a Passo

## **02. EXEMPLO DE UTILIZAÇÃO**

Acessar o menu alterar contexto

* Ao selecionar o sistema irá listar as coligadas que o usuário possui acesso vinculado ao seu perfil.

Ao confirmar o sistema irá realizar a troca de coligada e solicitar o login novamente.
