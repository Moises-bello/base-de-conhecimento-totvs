**Dúvida**O módulo de Exportação SIGAEEC trata exportações via courier?  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Export Control* – Todas versões.  
  
**Solução**Não, este recurso não está disponível no sistema até a versão corrente, para o módulo de Exportação.
