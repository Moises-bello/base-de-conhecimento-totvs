**Tipo de Aditivo**   
Nesta opção de menu serão mostrados os Tipos de Aditivos que serão usados no Sistema.  
   
Esta é uma tabela fixa do sistema com os tipos de aditivos contratuais. O usuário terá a opção de mudar apenas o nome externo do tipo de aditivo.  
   
**Identificação - Tipo de Aditivo**  
   
Ao editar um Tipo de Aditivo, abrirá a janela de edição onde iremos editar os seguintes campos:  
   
**Código:**  
Código do Tipo de Aditivo. Este campo é fixo do sistema e não poderá ser alterado;  
   
**Nome Interno:**  
Nome do Tipo de Aditivo. Este campo é fixo do sistema e não poderá ser alterado;  
   
**Nome Externo:**  
Informe o nome que irá aparecer ao efetuar um Aditivo com este tipo de Aditivo.   
   
   
**Exemplo:**  
Tipo de Aditivo = TC – Troca de Comprador (Esta descrição é fixa do sistema). Caso o usuário queira outra descrição, ele poderá usar o campo "Nome Externo", colocando, por exemplo, Cessão de Direitos;
