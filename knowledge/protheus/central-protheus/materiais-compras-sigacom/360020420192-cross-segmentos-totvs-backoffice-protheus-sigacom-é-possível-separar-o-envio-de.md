**Dúvida**

É possível separar o envio de *email* enviados pelo Totvs Colaboração por Departamentos ou tipo de documentos?  
  
**Ambiente**

Microsiga Protheus – Estoque/Custos – A partir da versão 11.80  
  
  
**Solução**

Este tratamento somente é possível através de customização, uma vez que o evento é um cadastro único.  
Neste cenário é necessário criar um grupo de usuários para NF e outro grupo para CTE. Criar uma nova função ADVPL para identificação do grupo e tipo da nota e assim realizar a chamada da *user function* através do schedcomcol/comxcol.
