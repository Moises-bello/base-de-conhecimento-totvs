O relacionamento da tabela permite que uma única tabela do contexto faça a leitura de dados de várias tabelas do banco de dados de uma única vez. Esta funcionalidade irá criar uma sentença SQL contendo uma cláusula LEFT JOIN e permitirá que os campos da tabela sejam selecionados na lista de campos da tabela.

Para mais informações consulte: <https://www.google.com.br/search?q=o+que+é+left+join&oq=o+que+é+left+join>

![](/download/attachments/319787292/pagina_de_tela.png?version=1&modificationDate=1512921895000&api=v2)

1Tabela Relacionada

Selecione qual tabela do banco de dados deseja fazer o relacionamento.

2Coluna Chave

Selecione a coluna da tabela principal que será utilizada no JOIN. Esta informação será utilizada para gerar a cláusula ON do JOIN, e para cada coluna chave, deverá ser selecionada a respectiva coluna detalhe.

3Coluna Detalhe

Selecione a coluna da tabela do relacionamento correspondente a coluna chave para geração da cláusula ON.

4OK

Clique para adicionar o relacionamento na tabela.

5Cancelar

Clique para cancelar a adição do relacionamento.
