![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21162800107799) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Chamada via webservice utilizando o Dataserver FOPFUNCDATA, onde o sistema estar apresentado o seguinte erro " could not get response" Maximum response size reached"  como ajustar?  
   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução** Quando está sendo realizado Chamada via webservice utilizando o Dataserver FOPFUNCDATA, onde o sistema estar apresentado o seguinte erro " could not get response" Maximum response size reached" , deverá utilizar filtro com quebra de 1000 chapas, o erro ocorre devido a uma limitação de tecnologia.
