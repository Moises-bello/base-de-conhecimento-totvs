**Dúvida**Por que o gerar TRCT apresenta a mensagem "Não há dados a exibir"?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**Nos parâmetros para a geração do TRCT caso não tenha filial deixe os campos Filial De / Até de Branco a ZZZZZ

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500006761542/mceclip1.png)

Campos Centro de Custo De / Até = Branco a ZZZZZZZZ

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500006940841/mceclip2.png)

Os campo com preenchimento de datas coloque uma data extensa, conforme exemplo abaixo
