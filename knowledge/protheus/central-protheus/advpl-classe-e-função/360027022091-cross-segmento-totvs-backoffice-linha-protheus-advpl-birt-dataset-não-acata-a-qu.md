**Dúvida**Fiz um Dataset com a seguinte sintaxe query select \* FROM ZA1990 where ZA1\_MUSICA >= ? pois no Birt (Eclipse) ao definir ? ele cria o parâmetro automaticamente.

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**As querys com parâmetros não estão funcionando no BIRT, como a ferramenta será descontinuada e não sofrerá manutenções.

Neste caso pode utilizar o Dataset - ADVPL, para gerar um aquivo ADVPL, segue artigo abaixo para auxilio no desenvolvimento.
