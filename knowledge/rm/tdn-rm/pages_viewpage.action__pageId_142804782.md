Este gatilho é utilizando no momento em que é feita a leitura da “descrição” do controle de Lookup. Caso seja necessária alguma ação neste ponto, deve-se utilizar este gatilho.

No caso de Lookup, temos duas opções:

- Leitura dos valores (quando navega nos registros ou quando o código do lookup é alterado)

- Leitura da visão (quando clica no botão de lookup ou abre a janela de autocomplete)

Criando uma Fórmula para disparar uma exceção após a leitura dos Valores de lookup

Selecionado o Gatilho Após a leitura dos valores de lookup de Consultas SQL

Selecionada Atividade Gerar Exceção

Tendo consultas SQL anexadas o usuário impede que seja inserido uma nova ou que seja feito a troca da consulta através da Fórmula Visual

Exceção gerada ao selecionar um novo valor de lookup
