**Dúvida**O Binário Lobo-Guará irá funcionar com qualquer versão do License Server Virtual?  
   
 **Ambiente**Protheus - AppServer - Versão 12  
  
**Solução**Não, o Binário (Servidor de Aplicação) do Protheus na versão Lobo-Guará funcionará **apenas** com versão igual ou superior a **01.03.012** do License Server Virtual.
