**Dúvida**

Após a atualização da Lib, liberada a partir de: 17/11/2025, é necessário a atualização do License Server para utilização do Protheus?

**Ambiente**

Protheus - Configurador - Versão 12

**Solução**

Sim, conforme informação no release notes da versão de Lib: [License Server 3.7.0 passa a ver a versão mínima para funcionameto do Protheus](https://tdn.totvs.com/x/JgUYP). A partir da Lib com data de: 17/11/2025, será necessário a utilização da última da versão do License Server disponível no Portal do Cliente.

Procedimento para atualização do License: [Atualização do License Server](https://tdn.totvs.com/display/framework/TOTVS+License+Server+Virtual#TOTVSLicenseServerVirtual-Atualiza%C3%A7%C3%A3odoLicenseServer)
