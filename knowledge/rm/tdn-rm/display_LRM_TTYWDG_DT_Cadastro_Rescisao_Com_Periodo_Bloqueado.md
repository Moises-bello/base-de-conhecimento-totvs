# ALTERAÇÕES NO CADASTRO DE RESCISÃO COM PERIODO BLOQUEADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Rescisão* |
| **Situação/Requisito:** | *Está sendo permitido alterar dados de uma rescisão já calculada, cujo período do envelope está bloqueado.*  *Como não é possível efetuar o recálculo da rescisão com o período bloqueado, não pode permitir alterações cadastrais.* |
| **Solução/Implementação:** | *Ajuste no cadastro de rescisão individual para não permitir alterar dados cadastrais, quando o período do envelope de rescisão estiver bloqueado.* |
