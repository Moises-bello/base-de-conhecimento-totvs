![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19358041577239) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como resolver o Erro Sefip 300435 - CBO Inválido?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Esse erro acontece quando o CBO está incorreto no cadastro da função ou quando o programa SEFIP está desatualizado e o CBO não é apresentado na base do programa Sefip.

**1**- Acesse a rotina **Atualizações / Cadastro / Funções** e caso o cadastro esteja incorreto efetuar a alteração para o CBO válido.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19358053340567)

**2** - Caso o CBO esteja correto verifique se o programa Sefip está atualizado conforme o site da Caixa Econômica Federal.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19358065255319)

**OBS:** Caso o programa do Sefip esteja atualizado e o CBO esteja cadastrado corretamente entrar em contato com a Caixa Econômica Federal para verificar qual é a solução para este cenário.
