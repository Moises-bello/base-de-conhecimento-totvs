![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:35 min****Dúvida**Como solucionar o erro **Não foi possível enviar o arquivo para o TOTVS Assinatura Eletrônica. Motivo: {0}Forbidden - Forbidden"** gerado nos processos do TOTVS Assinatura Eletrônica no RM?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Durante a integração de documentos do RM com o TOTVS Assinatura Eletrônica, pode gerar o erro: **Não foi possível enviar o arquivo para o TOTVS Assinatura Eletrônica. Motivo: {0}Forbidden - Forbidden**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11545730018839)

Este erro ocorre quando o usuário utilizado na execução do processo não ter permissões de **Publicador** em seu cadastro de usuário no TAE.

Para solucionar este erro, utilizando um usuário administrador no TOTVS Assinatura Eletrônica acesse: Usuários, localize o usuário que deseja alterar as permissões.

Conceda a permissão ao usuário como **Publicador** para que seja possível que integre novos documentos.
