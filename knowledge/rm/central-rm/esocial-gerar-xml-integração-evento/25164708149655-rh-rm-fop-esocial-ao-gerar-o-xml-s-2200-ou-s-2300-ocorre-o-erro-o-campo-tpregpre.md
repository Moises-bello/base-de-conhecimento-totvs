![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25164718702615) Tempo aproximado para leitura: **00:02:00 min****Ocorrência**Ao gerar o XML S-2200 ou S-2300 ocorre o erro O campo 'tpRegPrev' do registro 'vinculo' é obrigatório e não está preenchido.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25164708127255)

**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - Todas as versões  
  
**Causa**O erro ocorre quando não é preenchido o **Tipo de Regime Previdenciário**no cadastro do funcionário.  
  
**Solução**  
Para solucionar essa ocorrência, realize os seguintes passos:  
1. Acesse **Administração de Pessoal | Funcionários** edite o funcionário com o erro;  
2. Em **Situação** preencha com alguma das opções válidas;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25164708129815)

3. Regere o XML.
