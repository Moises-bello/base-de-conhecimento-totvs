# Validação Estorno/Cancelamento de um Exame na Elaboração de Contas

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Atendimento | Registro de Atendimento Externo | |
| **Banco(s) de Dados:** | Oracle®, SQL Server® |

## Descrição

Implementação da validação no estorno/cancelamento de um exame na elaboração de contas.

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações da versão 12.1.16.029 da biblioteca do RM Saúde.

## Procedimento para Utilização

       1.           Solicitar um exame através do Registro de Atendimento.

       2.            Cancelar/estornar o exame na tela de Elaboração de Contas. Observe a mensagem de aviso:

       3.            Realize o estorno/cancelamento diretamente na tela de Registro de Atendimento, aba Pedido de Exames.
