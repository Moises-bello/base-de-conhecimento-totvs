# Atualização de valores - Atualização dos códigos Mat/Med

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atualização de Valores |
| **Situação/Requisito:** | Ao executar a atualização de valores para Materiais e Medicamentos, e atualizar os codigos de Mat/Med o processo não separava a atualização dos códigos para materiais e/ou medicamento, fazendo com que um material tivesse o mesmo código de um medicamentos. |
| **Solução/Implementação:** | Ajustada para separar a atualização dos códigos para materiais e/ou medicamento. |
| **Tickets relacionados:** | [Ticket #3350451](https://totvssuporte.zendesk.com/agent/tickets/3350451 "Open ticket in Zendesk Support") |
