![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19964233503895) Tempo aproximado para leitura: **00:04:00 min** **Dúvida**A TES não está sendo preenchida (gatilhada) automaticamente no Novo Fluxo de Compras mesmo com Cadastro de Produto preenchido - NFC (PGCA010)  
  
**Ambiente**  
Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Compras/GCT - Protheus Release 12.1.2210.  
  
**Solução**Como no NFC utiliza interface POUI, por este motivo não está sendo preenchido automaticamente, como ocorria na antiga cotação rotina MATA150, neste novo processo é necessario preencher a TES manualmente.
