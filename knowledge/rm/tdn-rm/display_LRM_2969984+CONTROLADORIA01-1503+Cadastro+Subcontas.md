# Cadastro de Subcontas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro de conta contábil - Subcontas |
| **Situação/Requisito:** | Cliente informou que no cadastro das contas contábeis, ao acessar os anexos das subcontas e informar duas contas com a mesma natureza, o sistema apresenta a mensagem "Já existe Subconta com esta mesma natureza já cadastrada para esta conta contábil.", porém o de acordo com o manual da receita é possível cadastrar até duas contas com as naturezas 90, 91, 92, 93 e 95. |
| **Solução/Implementação:** | Devido a uma alteração realizada no manual da receita foi necessário modificar o cadastro de subcontas. Ele passou a permitir a inclusão de até duas subcontas com natureza 90, 91, 92, 93 e 95. |
