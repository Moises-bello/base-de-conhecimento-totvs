# Ajuste no Formulário de Registro de Glosa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Glosa |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Faturamento/Controle de Glosa", realizar uma pesquisa para uma fatura a ser glosada, clicar no botão "Abrir Conta", selecionar alguma das Tabs(Honorários, Diárias, Taxas e Serviços, Material e Medicamentos, Diagnose e Terapia e Resumo) para alterar um valor diretamente no Grid e clicar no botão "Conclui", o sistema não exibia nenhuma mensagem informando de que havia informações não salvas em algum Tab. |
| **Solução:** | Realizado ajuste no formulário Registro de Glosas quanto a exibição da mensagem caso aconteça o informado acima. |
