**Dúvida**Quais métodos **HTTP** utilizados no **PROTHEUS** ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 12  
  
**Solução  
*Endpoints*** devem usar os métodos **HTTP** adequados e devem respeitar a idempotência da operaçãoOs métodos HTTP utilizados no **p****rotheus** são:  
  
***GET***  
Utilizado para **visualizar** um recurso ou uma lista de recursos.  
  
***POST***Utilizado para **criar um registro**, na requisição devem ser enviados os dados que serão inclusos.  
  
***PUT***Utilizado para **alterar um recurso**. Deve ser passado um identificador como **pathParm.**

***DELETE***Utilizado para **excluir um recurso.
