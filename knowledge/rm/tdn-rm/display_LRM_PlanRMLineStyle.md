# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define o estilo da linha de um objeto.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| None | Define que não existirá linha. |
| DashDotDot | Define uma linha com traços e pontos. |
| DashDot | Define uma linha com traços e pontos. |
| Dot | Define uma linha com pontos. |
| Dash | Define uma linha com traços. |
| SlantDashDot | Define uma linha com traços paralelos e pontos. |
| Continuous | Define uma linha sólida. |
| Double | Define uma linha dupla e sólida. |
