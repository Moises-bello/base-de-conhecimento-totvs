No módulo Financeiro, ao tentar aprovar uma prestação com status "Em aberto" apresenta o Help F665VLDCF

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26600530487831)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões  
  
  
**Causa**Não é permitido aprovar solicitações de viagem que estejam com status 'em aberto'  
  
**Solução**Como a solicitação está com o status "Em aberto" não é possível realizar a aprovação, deve encaminhar para aprovação no botão do print a seguir:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26600498773911)

Após confirmar essa ação, irá mudar o status para amarelo "Aguardando aprovação" e será possível seguir com o processo de aprovação normalmente.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26600530491415)
