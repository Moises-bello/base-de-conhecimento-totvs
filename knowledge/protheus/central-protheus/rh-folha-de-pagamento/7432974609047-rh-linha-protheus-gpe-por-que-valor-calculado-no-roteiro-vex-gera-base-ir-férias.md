![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26334181116823) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que valor calculado no roteiro VEX gera base IR férias no cálculo da folha de pagamento?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O valor calculado no VEX gera base IR férias no cálculo da folha de pagamento, devido a verba calculada no VEX possuir incidência Sim para IRRF e Sim para Ref Férias.

Com Ref Férias com Não, o valor será considerado para a base IRRF folha id 0015.
