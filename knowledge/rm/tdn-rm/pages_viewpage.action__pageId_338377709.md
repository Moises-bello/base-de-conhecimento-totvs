# COPIAR MODELO DE ETAPA PARA OUTRO PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Parametrização por curso* |
| **Situação/Requisito:** | Na Parametrização por Curso, ao executar o processo “Copiar Modelo de etapa para outro período letivo”, quando o código da etapa de Nota era o mesmo do código da etapa de Faltas, o sistema copiava incorretamente as datas digitadas nas faltas destino para notas destino. |
| **Solução/Implementação:** | Ajuste no processo de cópia de modelo de etapa para outro período letivo para que copie as datas de início e término das etapas do período letivo de origem para o de destino, considerando o tipo da etapa (falta e/ou nota). |
