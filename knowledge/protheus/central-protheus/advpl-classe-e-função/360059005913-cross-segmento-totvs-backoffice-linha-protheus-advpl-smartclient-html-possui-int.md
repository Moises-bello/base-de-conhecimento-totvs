Dúvida**SmartClient HTML possui integração com Excel ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – ADVPL – A partir da versão 12.1.23  
  
**Solução**O SmartClient HTML não integra com EXCEL, pois o navegador não tem acesso ao sistema de arquivos da estação.

É possível apenas gerar XML através das classes FWMsExcelEx e FWMsExcel, a abertura deste deve ser efetuada manualmente.
