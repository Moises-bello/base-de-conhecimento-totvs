Este processo permite o usuário alterar a data de vencimento de todos os lançamentos gerados para um determinado fechamento de condomínio.  
   
Ao executar o processo, o sistema exibe uma tela para o usuário informar uma nova data de vencimento. Após a execução, esta nova data será aplicada para todos os lançamentos.  
O processo pode ser utilizado para múltiplos fechamentos.  
No anexo  do fechamento de condomínio, também foi disponibilizado o mesmo processo para alterar as datas. Neste caso, o usuário consegue selecionar apenas os lançamentos que ele deseja alterar.
