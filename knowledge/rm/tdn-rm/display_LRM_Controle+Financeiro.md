**Controle Financeiro**

Por este módulo será possível visualizar informações de quais funcionários utilizaram determinado benefício, o valor e a descrição do mesmo.

Será possível também a criação de campos complementares referentes ao controle financeiro de benefícios. Ao criar os campos complementares, os mesmos deverão estar ativos e ter uma linha no arquivo XML com o mesmo nome para que a validação seja efetuada.

Caso exista um campo complementar que esteja no arquivo XML, porém inativo, o sistema emitirá uma mensagem informando que o campo deve ser ativado. Da mesma forma, se um campo complementar estiver no arquivo XML mas não estiver cadastrado no sistema, uma mensagem de alerta também será emitida.

O sistema irá disponibilizar um processo no qual será possível realizar a importação destas informações através de um arquivo XML.

Para realizar a importação do arquivo XML acesse: Valorização | Benefícios, escolha o benefício que receberá as informações, clique em: Processos | Importar Arquivo para Controle Financeiro.

Definido o caminho onde se encontra o arquivo, será necessário realizar a validação deste, clicando em: "Validar Arquivo".

Feito isso, basta clicar em: "Executar" para finalizar o processo e concluir a importação das informações.
