# CADASTRO DE PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Cadastro de processo seletivo |
| **Situação/Requisito:** | Ao cadastrar um Processo Seletivo parametrizado para “Utilizar novo portal de inscrições”, e como forma de identificação para acessar o Portal de inscrições selecionado como E-mail ou CPF ou Carteira de Identidade, o sistema não permite salvar o cadastro do processo seletivo sem que seja preenchido como visível/obrigatório o campo E-mail, CPF ou Carteira de Identidade. Porém, a aba onde parametrizamos os campos visíveis/obrigatórios somente estão sendo exibidos após salvar o cadastro do Processo Seletivo. |
| **Solução/Implementação:** | Ajuste para bloquear o parâmetro "Utiliza novo portal de inscrições" enquanto for um cadastro novo. |
