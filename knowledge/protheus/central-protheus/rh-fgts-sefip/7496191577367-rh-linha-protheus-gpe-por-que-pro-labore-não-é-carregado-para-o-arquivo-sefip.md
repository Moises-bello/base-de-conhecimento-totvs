![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18393273153303) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que pro-labore não é carregado para o arquivo Sefip?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Os principais motivos do pro-labore não ser carregado para o arquivo Sefip são:

- Falta de PIS no cadastro pro-labore;  
- Arquivo Sefip gerado por base FGTS (deve ser gerado por base INSS pois pro-labore não possui FGTS);  
- Cadastro indevido quanto aos campos categoria Sefip e categoria E-social.
