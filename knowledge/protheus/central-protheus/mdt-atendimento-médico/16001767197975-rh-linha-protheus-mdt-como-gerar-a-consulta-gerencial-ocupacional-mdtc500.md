![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16001753000727) Tempo aproximado para leitura: **00:02:00min** **Dúvida**Como gerar a consulta Gerencial Ocupacional MDTC500?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Ao acessar o módulo SIGAMDT em **Consultas- Gerencial Ocupacional - Gerencial Ocupacional.**

Para saber sobre o objetivo da rotina consulte: [RH - Linha Protheus - MDT - Qual o objetivo da rotina Gerencial Ocupacional MDTC500](https://centraldeatendimento.totvs.com/hc/pt-br/articles/16001357985815)  
Estão disponíveis as seguintes opções Filtros, Cancelar e Confirmar.  
  
O quadro de Filtros, tem como objetivo fazer o filtro de apresentação do conteúdo da consulta. Para efetivar a consulta, selecionar o botão chamado **Gerar Consulta** e para limpar as informações de filtro, selecionar o botão chamado **Nova Consulta**.

|  |  |
| --- | --- |
| Campo | Descrição |
| Tipo de Análise | O campo possui 5 (cinco) opções de escolha que influenciam no resultado do filtro:   * Absenteísmo * Exames * Diagnósticos * Doenças * Acidentes |
| De (Data) | Permite a seleção de um período de tempo inicial no qual resultará o filtro do Tipo de Análise. |
| Ate (Data) | Permite a seleção de um período de tempo final no qual resultará o filtro do Tipo de Análise |
| Período | Permite a seleção de um período de tempo no qual resultará o filtro do Tipo de Análise. É possível selecionar entre 2 (duas) opções:   * Anual * Mensal |
| Visualizar por | Permite a seleção de registro que ordenará o filtro de acordo com cada Tipo de Análise.  Opções disponíveis para cada **Tipo de Análise**:  * **Absenteísmo**   + Centro de Custo   + Função   + Funcionário   + CID   + Motivo   + Tipo de Ausência      * **Exames**   + Centro de Custo   + Função   + Funcionário   + Resultado   + Tipo de Exame      * **Diagnósticos**   + Centro de Custo   + Função   + Funcionário   + Massa Corpórea   + Tipo de Atendimento   + Pressão Sanguínea      * **Doenças**   + Centro de Custo   + Função   + Funcionário   + CID      * **Acidentes**   + Centro de Custo   + Função   + Funcionário   + CID   + Objeto Causador   + Natureza da Lesão   + Parte Atingida   + Com Afastamento   + Sem Afastamento   + Tipo de Acidente |
| De | Permite a seleção dos registros iniciais de acordo com o conteúdo selecionado no filtro de **Visualizar****Por**. A opção está disponível apenas para os tipos:  Definições de **Visualizar Por** que não habilitam esse campo:  * **Diagnósticos**   + Massa Corpórea   + Tipo de Atendimento   + Pressão Sanguínea      * **Acidentes**   + Com Afastamento   + Sem Afastamento |
| Ate | Permite a seleção dos registros iniciais de acordo com o conteúdo selecionado no filtro de **Visualizar****Por**. A opção está disponível apenas para os tipos:  Definições de **Visualizar Por** que não habilitam esse campo:  * **Diagnósticos**   + Massa Corpórea   + Tipo de Atendimento   + Pressão Sanguínea      * **Acidentes**   + Com Afastamento   + Sem Afastamento |
