# Bolsa Retroativa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Bolsa Retroativa |
| **Situação/Requisito:** | O log no processo de inclusão de bolsas retroativas não esta correto, o mesmo não informa o numero de lançamentos processados apos a inclusão da bolsa. |
| **Solução/Implementação:** | Realizamos uma melhoria no log do processo de bolsa retroativa  1º O Log passa a mostrar informações das bolsas concedidas ou excluídas  2º O log passa a detalhar de forma mais organizada e objetiva os contratos, RA, parcela e lançamentos que foram atualizados  3º Os erros apresentado durante a execução do processo ficam separados ao final do log demonstrando apenas informações dos contratos e lançamentos que não foram atualizados |
