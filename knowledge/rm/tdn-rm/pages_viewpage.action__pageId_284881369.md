# Ajuste ao Incluir Guia/Autorização

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao inserir uma guia de solicitação de SP/SADT com parametrização para gerar o número da guia automático, o sistema inseria o mesmo número de uma guia já autorizada. |
| **Solução:** | Realizado ajuste para que, ao inserir uma guia de solicitação de SP/SADT com parametrização para gerar o número da guia automático, o sistema insira um novo número de guia, caso já exista um procedimento autorizado. |
