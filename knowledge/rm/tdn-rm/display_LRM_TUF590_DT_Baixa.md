# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Baixa de lançamentos. |
| **Situação/Requisito:** | Lançamentos vinculados parcialmente a devolução com rateio por centro de custo, onde o restante do lançamento possui um cheque emitido. Ao baixar o cheque emitido, o item de baixa do lançamento de devolução não possui os rateios por centro de custo. |
| **Solução/Implementação:** | Ajustes no serviço de baixa com cheque, a fim de que ao baixar um lançamento vinculados parcialmente a devolução, onde o restante do lançamento possui um cheque emitido, o item de baixa da devolução tenha os valores rateados corretamente. |

| **Chamados relacionados:** | NA |
