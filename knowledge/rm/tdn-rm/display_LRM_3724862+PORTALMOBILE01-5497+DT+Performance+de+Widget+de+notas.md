# Performance de Widget de notas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Gestão Educacional |
| **Módulo:** | Educacional |
| **Função:** | Widgets de notas |
| **Situação/Requisito:** | Ao abrir uma tela no novo portal do aluno onde possui o widget de Notas de Etapas ou Notas de Avaliações, a performance na abertura da tela era bastante prejudicada, causando uma longa demora para carregamento dos dodos. |
| **Solução/Implementação:** | Foi realizado uma melhoria de performance nos widget de notas, permitindo que as informações fossem exibidas com uma performance adequada para o funcionamento das telas em que elas são inseridas. |
