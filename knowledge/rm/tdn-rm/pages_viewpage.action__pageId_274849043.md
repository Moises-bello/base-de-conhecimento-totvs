# DESABILITAR CONTABILIZAÇÃO EM ITEM DE BAIXA NÃO CONTÁBIL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Item de baixa. |
| **Situação/Requisito:** | Item de baixa com Status Contábil como "Não contábil" está permitindo editar a contabilização e acessar os processo de contabilização (Regerar Contabilização de baixa, Estornar Contabilização de Baixa Integrada ao Lote Zero, Solicitar a Exclusão de Operação Contábil da Baixa) via visão. |
| **Solução/Implementação:** | O botão "Contabilização" da tela do item de baixa, e os processos relacionados à contabilização, ficarão desabilitados quando o status contábil for "Não Contábil". |
| **Conversores e Parâmetros:** | N/A. |
| **Tickets relacionados:** | N/A. |
| **Requisito:** | FINANCEIRO01-850. |
