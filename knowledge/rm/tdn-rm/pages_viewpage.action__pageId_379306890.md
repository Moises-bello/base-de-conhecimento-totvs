# Continuidade de Afastamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Gerenciador de Saídas e Importação de dados do RM Labore |
| **Situação/Requisito:** | O relatório de saídas 'FOPLAY0019 09.003.002 Exportação de Históricos de Afastamento.TOTVSGen' deve ser alterado para exportar o campo 'Dt. Inicial da continuidade de aft.'.  O processo de Importação de Dados de RM Labore deve importar esse campo. |
| **Solução/Implementação:** | Foi ajustado o relatório de exportação para incluir o campo DTINICONTINUIDADEAFT.  Foi Ajustado o processo de importação de histórico de afastamento para incluir o campo DTINICONTINUIDADEAFT. |
