![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24991478060183) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Sistema efetua cálculo de PLR para funcionários com o tipo de contrato Intermitente?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**No padrão do sistema, no módulo de Folha de Pagamento, o roteiro PLR não efetua cálculo para funcionários com o tipo de contrato Intermitente.   
  
Caso deseje efetuar este pagamento, os valores poderão ser pagos no roteiro FOL.
