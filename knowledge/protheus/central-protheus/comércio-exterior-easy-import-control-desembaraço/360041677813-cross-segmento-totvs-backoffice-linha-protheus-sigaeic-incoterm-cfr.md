**Dúvida**Como lançar a Purchase Order com o Incoterm do tipo CFR?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**No Incoterm *CFR*, o vendedor é responsável pelo pagamento dos custos necessários para colocar a mercadoria a bordo do navio. O vendedor é responsável pelo pagamento do frete até o porto de destino designado.

Ao lançar Purchase Order o campo W2\_FREINC "Frete Incl." deve estar destacado como incluso  igual a "SIM" para que a mensagem referente o valor não seja apresentada.
