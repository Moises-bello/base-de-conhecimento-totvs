# MALA DIRETA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Mala direta |
| **Situação/Requisito:** | Acessando a tela de mala direta e ao efetuar uma busca de uma consulta sql que era utilizada na mala direta o sistema não filtrava e trazia as consultas por código da aplicação, sendo assim listava todas as consultas de todos os sistemas.  Foi identificado também que ao utilizar a opção de "geração de arquivos" o sistema não permitia a inclusão de cabeçalho e rodapé no documento. |
| **Solução/Implementação:** | Foi feito o ajuste para que sejam filtradas as consultas do Educacional, foi feito o ajuste para incluir e editar cabeçalho e rodapé. Foi identificado também que a geração do arquivo era feita somente em HTML, mesmo selecionando outros formatos foi efetuado o ajuste nos mesmo para que os arquivos fossem gerados corretamente nos demais formatos.  Para geração de arquivo com cabeçalho e rodapé é necessário que seja selecionado a opção de "Gerar arquivos" e a inclusão poderá ser feita utilizando os botões destacados em vermelho: |
