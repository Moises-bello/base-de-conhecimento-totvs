# Retrospectiva de Saldos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Relatório Retrospectiva de Saldos |
| **Situação/Requisito:** | Ao realizar a emissão do relatório Retrospectiva Centro de Custo / Contábil são exibidos centros de custo que não tiveram movimentação, o que não ocorria no Delphi. Isso causa uma visão poluída e gasta mais papel. |
| **Solução/Implementação:** | O relatório Retrospectiva foi alterado para permitir que a opção "Exibir Contas Sintéticas" possa ser desmarcada quando o tipo de informação for "Centro de Custo". Desta maneira os centros de custo de nível superior não serão exibidos, deixando o relatório menos poluído. |
