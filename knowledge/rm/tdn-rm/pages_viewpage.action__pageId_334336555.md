# TIPO FRETE NO MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Tipo de Frete no Movimento. |
| **Situação/Requisito:** | Ao configurar o tipo de movimento com **Tipo de Frete** **igual a Edita**, na inclusão de um novo movimento o campo **Tipo Frete** não exibe corretamente as opções de frete. |
| **Solução/Implementação:** | Ajuste na tela de **Identificação de Transporte** do Movimento, para correta exibição das opções Tipo de Frete. |
