# GERAR PDI

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Gerar PDI* |
| **Situação/Requisito:** | *Ao acessar o menu "Acompanhamento" –> "PDI" –> "Anexos" -> "Participantes". Quando os participantes foram gerados a partir de uma AD que possui avaliação consensual, os mesmos estão sendo duplicados no PDI.* |
| **Solução/Implementação:** | *Ajuste no processo "Gerar PDI a partir da avaliação de desempenho associada". Quando a AD possui avaliações consensuais, as mesmas não são consideradas ao trazer os participantes para o PDI.* |
