# Criação da Issue

|  |  |
| --- | --- |
| **Linha de Produto:** | Snowden |
| **Segmento:** | Framework |
| **Módulo:** | Suporte |
|  |  |
| **Situação/Requisito:** | Criação de tickets no suporte do zendesk dos incidentes identificados pelo sistema. |
| **Solução/Implementação:** | Toda vez que um novo incidente for cadastrado, o sistema irá verificar se já existe um suporte cadastrado para este incidente, e caso não haja, irá realizar a abertura do mesmo. utilizando as informações do cliente.  Isso será feita através de uma iteração do snowden com a api do zendesk |
| **Conversores e Parâmetros:** | Não haver suporte cadastrado para o incidente |
|  |  |
| **Requisito:** | Criação da Issue |
