**LAYOUT METADADOS:**

É possível realizar aimportação de um Metadados exportado, recuperando o layout de origem.

Para isso siga os passos abaixo:

Edite um Metadados e clique em Definir Layout:

Clique em Salvar

Verifique se o arquivo XML foi salvo com sucesso.

Depois de exportar o Layout faça o mesmo processo.

Edite um Metadados.

Clique em Definir Layout

Porém no lugar de Salvar clique em Carregar.

Selecione o XML exportado e importe, o Layout será o mesmo do original.

Para maiores informações:Para mais informações consulte o [WikiHelp](http://wikihelp.totvs.com.br/WikiHelp/GLB/GLB.MetadadosTipoDados.aspx).
