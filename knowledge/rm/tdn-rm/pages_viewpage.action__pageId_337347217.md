# Mensagem ao liberar prescrição com item de débito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | PEP 2 - Prescrição de Procedimentos |
| **Situação/Requisito:** | Ao liberar no PEP 2 uma prescrição contendo item de débito, era apresentado uma mensagem "Object reference" |
| **Solução/Implementação:** | Alterado no RM para não apresentar a mensagem ao liberar um item de débito vindo do PEP 2 |
