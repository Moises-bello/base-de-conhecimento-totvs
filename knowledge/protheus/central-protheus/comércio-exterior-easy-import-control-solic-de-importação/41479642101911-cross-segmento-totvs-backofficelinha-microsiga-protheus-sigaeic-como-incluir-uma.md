O artigo explica como incluir uma Solicitação de Importação no SIGAEIC do TOTVS Protheus: acessar a janela de manutenção de SI, selecionar "Incluir", preencher os campos do cabeçalho conforme o help, conferir os dados e clicar em "Ok" para gravar.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/41479642092951) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
Como incluir uma Solicitação de Importação dentro do SIGAEIC.  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAEIC - Todas as Versões  
  
**Solução**  
1-) Na janela de manutenção de SI, selecione em **Incluir**. Será apresentada a janela para inclusão;  
2-) Preencha os campos do cabeçalho conforme a orientação do help;  
3-) Confira os dados e clique em **Ok**para gravar.
