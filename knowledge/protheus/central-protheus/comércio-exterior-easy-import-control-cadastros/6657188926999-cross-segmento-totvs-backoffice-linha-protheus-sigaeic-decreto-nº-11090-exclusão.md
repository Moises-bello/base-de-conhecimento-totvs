**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura: **00:02:00 min****Dúvida**Qual o procedimento a ser efetuado sobre o decreto do presidencial Nº 11.090,  que exclui o valor da capatazia da base do II ? Site do [Decreto Nº 11190](http://www.planalto.gov.br/ccivil_03/_ato2019-2022/2022/decreto/D11090.htm?utm_campaign=informa_0082022_-_exclusao_do_custo_da_capatazia_da_base_de_calculo_do_imposto_de_importacao&utm_medium=email&utm_source=RD+Station)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - Todas as versões  
  
**Solução**Favor, ajuste o cadastro da despesa da capatazia para não ser base de **imposto**. Será necessário acessar a rotina de Cadastro de Despesas (**EICA110**):  
1. Acessar - SIGAEIC - Atualizações - Financeiro - Cadastro de Despesas

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6657917844887/mceclip0.png)  
2. Selecione a despesa de capatazia.  
3. Clique no botão alterar.  
4. Alterar a o campo Base de Imposto (**YB\_BASEIMP**) de 1-Sim para **2-Não**.   
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6657966155415/mceclip1.png)
