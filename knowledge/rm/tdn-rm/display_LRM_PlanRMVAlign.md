---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define o alinhamento vertical de um texto.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Top | Define que o texto será mostrado no topo. |
| Center | Define que o texto será mostrado centralizado. |
| Bottom | Define que o texto será mostrado na parte inferior. |
| Justify | Define que um texto rotacionado verticalmente será justificado. |
| Distributed | Define que um texto rotacionado deve ser quebrado e alinhado para formar bordas retas na esquerda e na direita, incluindo a última linha. |
