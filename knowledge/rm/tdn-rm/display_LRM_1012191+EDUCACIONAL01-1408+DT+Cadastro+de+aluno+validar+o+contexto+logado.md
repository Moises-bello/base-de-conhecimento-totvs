# CADASTRO DE ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Cadastro de aluno |
| **Situação/Requisito:** | Ao inserir novo aluno, o sistema não validava se o usuário preencheu todas as informações do contexto, então a geração do RA ficava incorreta por acessar os parâmetros de um contexto inválido. |
| **Solução/Implementação:** | Otimização no cadastro de Aluno, onde o sistema irá validar se o contexto escolhido é correto e se foi configurado Parâmetros Educacional para este mesmo contexto. |
