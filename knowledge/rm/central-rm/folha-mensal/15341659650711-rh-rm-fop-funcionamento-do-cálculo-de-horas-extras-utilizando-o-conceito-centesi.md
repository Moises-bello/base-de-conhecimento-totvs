![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15341644684055) Tempo aproximado para leitura: **00:03:59 min** **Dúvida**Como funciona o cálculo de horas extras utilizando o conceito **centesimal e sexagesimal?**  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Quando for necessário efetuar cálculos com horas é preciso **converter o padrão de horas (sexagesimal) para o centesimal**. Não é possível realizar operações matemáticas utilizando a nomenclatura de horas e minutos.

**Exemplo 1:**

Suponha que um colaborador atrasou 1h30 minutos. Na referência do demonstrativo de pagamento irá aparecer como 1.50 ao invés de 1h30. 

Isto ocorre, pois quando falamos em cálculos que envolvem horas e minutos no demonstrativo de pagamento, é incorreto tomar como base os minutos do relógio e multiplicar pelo salário/hora do colaborador, pois, os sistemas se utilizam de valores numéricos de base decimal ou centesimal para calcular. Ou seja, as horas da forma como são lidas no relógio não servirão de base para cálculos de adição, subtração, multiplicação ou de divisão.

**Exemplo 2:**Um empregado horista tem seu valor estipulado por hora trabalhada de R$ 50,00.  
Veja a tabela como ficaria com horas diferenciadas.

|  |  |
| --- | --- |
| **Hora trabalhada** | **Valor R$** |
| 00:30 | 25,00 |
| 01:00 | 50,00 |
| 01:30 | 75,00 |
| 02:00 | 100,00 |
| 02:30 | 125,00 |

  
Se efetuar o cálculo utilizando os minutos, o resultado não corresponderá com a tabela.  
2,30 x 50,00 = 115,00 (deveria ser 125,00 o empregado saiu perdendo R$ 10,00)

Por isso é necessário **converter** os minutos (padrão sexagesimal) para centesimal.

Logo 02:30 corresponde no formato centesimal 2,5.  
**2,5 x 50,00 = 125,00 (cálculo correto para 02:30)**  
O mesmo cálculo deve ser feito ao realizar a média de horas extras de um período. Não é possível somar as horas, deve-se primeiro converter para o formato centesimal. Após a conversão, apura-se a média e então é convertido de volta para sexagesimal.
