## Descrição

Migração das telas de cadastro de empresas, cadastro de funcionários, cadastro de convênios, cadastros de vagas, cadastro de público alvo dos convênios, cadastro de público alvo das vagas e cadastro de candidatos às vagas, todas relacionadas à rotina de Central de Estágios do TOTVS Educacional para o ambiente do FLUIG, utilizando a TOTVS HTML Framework.

## Procedimento para Implantação

Os itens de menu para acesso às telas da Gestão de Estágio disponíveis no Fluig estarão disponíveis a partir da instalação da release 12.1.9.

## Procedimento para Configuração

Os itens de menu para acesso às telas da Gestão de Estágio disponíveis no Fluig serão configurados através de permissões de acesso.

## Procedimento para Utilização

1. Tela de Cadastro de Empresas  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de uma nova empresa.  
   Ao clicar no botão "Funcionários" será aberta a tela de cadastro de funcionários.  
   Ao clicar no botão "Convênios" será aberta a tela de cadastro de convênios.  
   Ao clicar no botão "Vagas" será aberta a tela de cadastro de vagas.
2. Tela de Cadastro de Funcionários  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de uma nova empresa.
3. Tela de Cadastro de Convênios  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de um novo convênio.  
   Ao clicar no botão "Público Alvo" será aberta a tela de cadastro de público alvo do convênio.
4. Tela de Cadastro de Público Alvo dos Convênios  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de um novo público alvo para um convênio.
5. Tela de Cadastro de Vagas  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de uma vaga de estágio.  
   Ao clicar no botão "Público Alvo" será aberta a tela de cadastro de público alvo da vaga.  
   Ao clicar no botão "Candidatos" será aberta a tela de cadastro de candidatos à vaga.
6. Tela de Cadastro de Público Alvo das Vagas  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de um público alvo para uma das vagas da empresa.
7. Tela de Cadastro de Candidatos à Vagas  
   Acessar o item de menu do Fluig correspondente à essa funcionalidade para efetuar o cadastro de um candidato à uma das vagas da empresa.
