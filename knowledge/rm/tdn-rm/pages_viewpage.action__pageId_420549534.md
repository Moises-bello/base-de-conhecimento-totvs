# CANCELAMENTO DE LANÇAMENTO - BOLSA RETROATIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cancelamento de lançamento financeiro. |

| **Solução/Implementação:** | Permitir cancelar o lançamento financeiro vinculado à parcela de serviço "Bolsa Retroativa" gerada na exclusão da bolsa retroativa |
