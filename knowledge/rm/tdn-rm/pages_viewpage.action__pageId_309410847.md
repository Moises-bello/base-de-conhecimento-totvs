# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.17 |
| **Ocorrência:** | Zerar Orçamento |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**  Este processo permitirá ao usuário excluir ou zerar, por ano/mês, orçamentos de valores estimados e criados para as contas contábeis.  Para a execução do processo deve-se informar o ano e o tipo de ação a ser executada sendo:   * Excluir orçamento para o ano inteiro: Todos os orçamentos contidos neste ano serão excluídos independente de contas, valores ou outras características; * Zerar orçamento para o ano inteiro: Todos os orçamentos contidos neste ano terão seus valores zerados independente de contas, valores ou outras características; * Zerar orçamento para alguns meses: Todos os orçamentos contidos no intervalo de meses selecionados terão seus valores zerados independente de contas, valores ou outras características;   **DESENVOLVIMENTO/PROCEDIMENTO:**  **1 - Acesse o caminho Orçamento / Zerar Orçamentos e selecione o ano do orçamento:**                                             * Excluir orçamento para o ano inteiro: Todos os orçamentos contidos neste ano serão excluídos independente de contas, valores ou outras características; * Zerar orçamento para o ano inteiro: Todos os orçamentos contidos neste ano terão seus valores zerados independente de contas, valores ou outras características; * Zerar orçamento para alguns meses: Todos os orçamentos contidos no intervalo de meses selecionados terão seus valores zerados independente de contas, valores ou outras características;   Para a última opção o sistema abrirá uma tela para informação dos meses que serão zerados: Informe o mês inicial e mês final: |
| **Observações:** | O processo não pode ser revertido, desta forma, tenha sempre um backup atualizado. |
