# Imprimir as Contas no Faturamento com banco Oracle

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Imprimir Conta |
| **Situação:** | O sistema não Imprimia as Contas no Faturamento com banco Oracle® |
| **Solução:** | Foi realizado ajuste no sistema de impressão de Contas no Faturamento para a base Oracle.  **Obs:** Em Menu: Opções > Parâmetros > Parâmetros Gerais > Aba Impressão Conta/Extrato >  Marcar a opção "Formulário Contínuo 80 Colunas - ' 1 Folha". |
