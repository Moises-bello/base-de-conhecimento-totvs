O aplicativo Meu Coletor de Dados reconhece apenas o código de barras B1\_CODBAR, não o código GTIN (B1\_CODGTIN). Para incluir o GTIN, é possível solicitar desenvolvimento personalizado ou sugerir melhoria via Central Colaborativa TOTVS, onde o time de produto avaliará a viabilidade. Se aprovado, pode ser feita uma customização para implementação da funcionalidade.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40269933139735) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
No aplicativo Meu Coletor de Dados, temos como usar o Código GTIN?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**  
Atualmente no Aplicativo Meu Coletor de Dados  reconhece o B1\_CODBAR. Sendo a única codificação de barras validada atualmente pelo aplicativo.  
   
Porém, temos algumas alternativas para que se chegue neste objetivo (que o B1\_CODGTIN seja consumido pelo aplicativo em seus processos):

* Via Processo de Desenvolvimento Participativo, cotar com o time de Desenvolvimento para que criem um ponto de entrada exclusivo para a sua empresa de acordo com suas necessidades (detalhes neste link: <https://tdn.totvs.com/pages/releaseview.action?pageId=589518919> na opção " **Criação de novo Ponto de Entrada**")
* Via Central Colaborativa, onde você pode documentar sua sugestão de melhoria e o time de Produto avaliará e lhe dará um retorno sobre a viabilidade de inclusão desta funcionalidade no padrão. Deixarei abaixo todo o detalhamento sobre a central.
