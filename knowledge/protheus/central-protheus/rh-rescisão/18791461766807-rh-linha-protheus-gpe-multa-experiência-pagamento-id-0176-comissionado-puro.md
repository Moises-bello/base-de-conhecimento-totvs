![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18791467382295) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como conferir cálculo multa experiência pagamento ID 0176 comissionado puro?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Em caso de quebra contrato experiência pelo empregador funcionário comissionado puro categoria C, o cálculo ID pagamento 0176 será com base valor garantia de comissão.
