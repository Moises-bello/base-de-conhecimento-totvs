**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura: **00:01:00 min****Dúvida**É possível distribuir um documento para vários usuários ou distribuir vários documentos para um determinado usuário?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**É possível distribuir determinado documento para vários usuários ao mesmo tempo utilizando a rotina **QDOA120 - Manutenção de Distribuição**. Nesta rotina, deverá seguir o procedimento abaixo:

1. Utilizar a opção **Distribuir por Documento**
2. Selecionar o documento desejado
3. Clicar em **OK**
4. Clicar em **Marc/Des**para marcar todos os usuários
5. Clicar em **Continua**.

Ainda na rotina **QDOA120**, é possível distribuir vários documentos para um determinado usuário, utilizando a opção**Distribuir por Destinatário**, seguindo o procedimento abaixo:

1. Selecionar a opção **Usuários**
2. Selecionar o usuário em questão
3. Clicar em **OK**
4. Clicar em **Marc/Des**para marcar todos os documentos
5. Clicar em **Continua.**
