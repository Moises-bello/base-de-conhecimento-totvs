## **01. VISÃO GERAL**

A funcionalidade tem como objetivo realizar o alerta ao profissional solicitante quando o mesmo exame será prescrito no tempo menor do que o preconizado pela instituição. Esta funcionalidade auxilia o corpo clínico no controle de solicitação de exames, segurança do paciente e custos para instituições e convênios médicos. A funcionalidade não  é impeditiva para o profissional seguir com a solicitação, ela tem o objetivo de alertar o profissional.

**2.2 Cadastro no SLA**

É necessário realizar o cadastro no RM para que o alerta respeito do SLA (em dias) determinado para uma nova solicitação de exames.

RM → Cadastros → Cuidados com o Paciente → Outros cadastros → **Cadastro de Alerta de Exames**

| Tópico | Descrição |
| --- | --- |
| 1 - Acrescentar | Realizar o cadastro de um novo SLA para um determinado exame nas unidades pertinentes |
| 2 - Id. Unidade de Atendimento | Selecionar qual(is) unidades de atendimento devem seguir o SLA para o exame especificado |
| 2. Cod. Exames | Selecionar qual(is) exames devem seguir o SLA nas unidades de atendimento especificadas |
| 4 - Prazo para o exibir o alerta (dias) | Determinar em dias qual o tempo mínimo preconizado para solicitação do mesmo exame para o paciente. |

**2.2 Alerta no PEP**

O alerta está parametrizado para ser realizado durante a solicitação de exames via Prescrição Médica ou Solicitação de Exames. O alerta não é impeditivo para o profissional seguir com a solicitação do exame.
