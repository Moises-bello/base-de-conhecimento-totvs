# Relatórios Automáticos por Unidades de Atendimento

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | Todas |
| **Ocorrência:** | Como parametrizar relatórios automáticos por unidade de atendimento |
| **Passo a passo:** | **1º Passo)** Crie um relatório para o que desejas. Nota: É necessário possuir os parâmetros CODCOLIGADA, CODPACIENTE e CODATENDIMENTO. Nota: O relatório NÃO pode possuir campos de base, somente consultas SQL.    **2º Passo)** Acessar o menu Cadastros -> Uso Geral -> Unidades de Atendimento.    **3º** **Passo**) Na aba “Relatórios”, parametrize o relatório indicado.    **4º Passo)** Faça o teste. Ao registrar um atendimento na Unidade, veja que o sistema pergunta se desejas imprimir o relatório parametrizado. |
