**Ocorrência**Ao gerar TRCT de Rescisão não Efetiva é gerado a mensagem "Não há relatórios para exibir"  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Causa**  
Correção / Ajuste na função GPER140.PRX  
  
**Solução**

Aplique o pacote de correção de acordo com sua release:

12.1.2310 [https://suporte.totvs.com/portal/p/10098/download?e=1123885](https://suporte.totvs.com/portal/p/10098/download?e=1080347)

12.1.2410 <https://suporte.totvs.com/portal/p/10098/download#detail/1170810>

OBS.: Para a release 12.1.2310 deve ser aplicado o pacote apenas para clientes com GARANTIA ESTENDIDA, se aplicado em ambiente sem garantia estendida, o ambiente é BLOQUEADO!
