# Objetivo:

---

       O objetivo deste documento é mostrar os pré-requisitos necessários para o correto funcionamento do mashups.

# Introdução:

---

       Para que o Mashups funcione corretamente é necessário realizar algumas pré-configurações. A primeira delas é estar com o Proxy Mashups instalado e atualizado. Atualmente o Proxy Mashups está na versão 6.0.  Segue link para download e manual de instalação caso haja dúvida:

* **[Proxy Mashups 6.0](http://mashups.totvs.com.br/TOTVSMashups.Setup.zip)**
* **[Manual Instalação Proxy Mashup](http://tdn.totvs.com/pages/viewpage.action?pageId=224443860)**

       Após a instalação do proxy é necessária a instalação dos pacotes Redistribuíveis do Visual C++ para Visual Studio 2013 (vc\_redist.x86.exe e vc\_redist.x64.exe). Disponível nos links abaixo e também na pagina do **[Mashups](http://mashups.totvs.com.br/).**

* **[Pacote Redistribuível vc\_redist.x86.exe](https://download.microsoft.com/download/2/E/6/2E61CFA4-993B-4DD4-91DA-3737CD5CD6E3/vcredist_x86.exe)**
* **[Pacote Redistribuível vc\_redist.x64.exe](http://download.microsoft.com/download/7/b/a/7bafb681-05f8-4d13-98af-9bc6c93b3536/vcredist_x64.exe)**

       O serviço deverá ser instalado em uma máquina Windows 7/2008R2 64 BITS, com suporte a .NET Framework 4.0 ou superiores e com pelo menos 4 GB de RAM e 4 núcleos de processamento. Ele deverá ter permissão de saída para internet sem necessidade de proxy. Também poderá comunicar em qualquer porta com qualquer site, utilizando os protocolos HTTP e HTTPS.
