## **02. SITUAÇÃO/REQUISITO**

Ao gerar o relatorio de 'TINREL0065 - Informe de pagamentos - IR' informando um cliente que possuí mais de uma venda o arquivo não estava sendo gerado corretamente.

## **03. SOLUÇÃO**

Realizados ajustes no sistema para que seja gerado um único arquivo PDF contendo uma pagina para cada venda. Com isso em um único arquivo é possível visualizar as informações de todas as vendas do cliente.
