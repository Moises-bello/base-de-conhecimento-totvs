**Dúvida**

Como liquidar um câmbio no SIGAEIC?  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Export Control – Todas versões.

**Solução**

Execute os procedimentos abaixo:

1. Acesse o módulo SIGAEIC em Atualizações\ Financeiro \ Controle Cambio (EICAP100).

![](https://totvssuporte.zendesk.com/attachments/token/8C8q9iDImcPNV8SQbR5WcLFvh/?name=inline-216241873.png)​

2. Selecione o tipo do processo  de **Desembaraço**e clique em **Alterar.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027123332/mceclip1.png)

3. Posicione no câmbio a ser liquidado, selecione **Outras Ações** e **Liquidar.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027123672/mceclip3.png)

4. Informe os dados abaixoe  selecione Salvar o processo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360027126672/mceclip1.png)
