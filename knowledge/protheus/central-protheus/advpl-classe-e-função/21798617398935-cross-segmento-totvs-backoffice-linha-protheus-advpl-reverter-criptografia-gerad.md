![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21798630160151) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**É possível reverter a criptografia gerada pela função SHA1?  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões

**Solução**

SHA1 (Secure Hash Algorithm 1) é uma função unidirecional, o que significa que ela é projetada para ser computacionalmente impossível reverter o processo de hashing para obter os dados originais a partir do hash gerado.
