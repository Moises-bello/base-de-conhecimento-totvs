**Dúvida**  
Como ajustar o cadastro do usuário para solicitação de viagens?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA666 -Todas as versões  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

1. No modulo **34 Contabilidade Gerencial,**acesse **Atualizações** > **Cadastros de pessoas APDA020**  
2. Clique no cadastro do usuário desejado e selecione alterar.   
  
3. Na aba **Dados Gerais** preencha o campo **Cod. Usr** **Siga** com o código gerado pelo sistema criado no cadastro de usuários do sistema

4. Na aba **Viagem** preencha o campo **Aprovador** com o código de cadastro do superior imediato do usuário para a liberação a aprovações de solicitação de viagens. Na mesma aba é importante ajustar o campo **Perm. Adto** (Permite Adiantamento) = **Sim**,para ser liberado adiantamento de valores ao usuário para uma nova viagem.
