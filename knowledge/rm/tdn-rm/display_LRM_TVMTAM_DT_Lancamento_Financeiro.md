|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Lançamento financeiro* |
| **Situação/Requisito:** | Ao gerar o lançamento Financeiro no RM Labore pelo módulo de geração do SEFIP, Guia de INSS e/ou pelo processo normal, o mesmo não está sendo gerado por Centro de Custo. Não gera erro ao executar o processo de lançamento financeiro.  Obs.: O lançamento financeiro gerado no RM Labore será integrado ao Protheus. Ou seja, toda parametrização foi realizada para integrar a outro BackOffice |
| **Solução/Implementação:** | Ajuste realizado nas rotinas Guia de Inss, SEFIP e GRRF, para que seja possível ao cliente gerar lançamentos rateados por centro de custo quando integrado com o Protheus |
