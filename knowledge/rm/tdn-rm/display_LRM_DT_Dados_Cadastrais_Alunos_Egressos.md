# Dados cadastrais do aluno

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Totvs Educacional |
| **Módulo:** | Educacional |

## Descrição

Foi implementado nos dados pessoais do aluno no portal, as informações profissionais (empresa, cargo e endereço).

As informações do aluno no portal, é dividida agora em duas abas "Dados pessoais" e "Dados profissionais".

Os dados continuam obedecendo a parametrização que já existia:

* Apenas consulta
* Solicitar alteração para Filial do aluno: Foi adicionado no e-mail as informações referente aos dados profissionais
* Solicitar alteração para o Nível de Ensino do aluno: Foi adicionado no e-mail as informações referente aos dados profissionais
* Permitir alteração (A atualização será feita imediatamente no banco de dados)
