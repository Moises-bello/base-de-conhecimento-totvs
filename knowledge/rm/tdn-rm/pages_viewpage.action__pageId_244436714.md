# TRANSFERÊNCIA ENTRE FILIAIS COLETIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Coletiva* |
| **Situação/Requisito:** | *Ao efetuar uma transferência sem ônus para cedente na rescisão coletiva, o sistema deixa um registro ativo e um registro demitido para registro de entrada e saída.*  *O registro demitido está ficando sem o rateio fixo em seu histórico. Essa informação é crucial para a contabilização das provisões.* |
| **Solução/Implementação:** | *O registro do rateio fixo foi mantido no registro demitido e replicado para o novo registro incluído no processo de rescisão coletiva para transferência entre filiais.* |
| **Chamados relacionados:** | *TVAOZO* |
