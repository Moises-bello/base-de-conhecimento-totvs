**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20117107312407)** Tempo aproximado para leitura: **00:03:00 min****Dúvida**Qual é a origem das informações da seção II registros ambientais (campos **exposição a fatores de risco**15 ao 15.9) do relatório PPP?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho – Todas as versões  
  
**Solução**Esta documentação refere-se exclusivamente a versão do PPP impresso no Módulo de Medicina e Segurança do Trabalho, rotina MDTR700, não tendo nenhuma relação com o PPP Eletrônico maiores informações consulte: **[RH - Linha Protheus - MDT - Qual diferença entre o PPP impresso no Módulo Medicina MDTR700 e o PPP da Previdência Social consultado através do APP Meu INSS](https://centraldeatendimento.totvs.com/hc/pt-br/articles/14223826251287)**Veja abaixo a tabela com origem das informação dos campos 15 a 15.9 do relatório PPP.O relatório de Perfil Profissiográfico Previdenciário (rotina MDTR700) é gerado através Caminho SIGAMDT: Atualizações > Relatórios > PPP > Perfil Profissiogr.

| **Nº** | **Campo** | **Origem** | **Conteúdo** | **Parâmetros (caso exista)** |
| **15** | **EXPOSIÇÃO A FATORES DE RISCO** | Estas informações são obtidas basicamente das rotinas de Riscos (TN0), e estão vinculadas pergunta “Considerar Risco” da tela de parâmetros para emissão do PPP. Esta pergunta pode ser selecionada para as seguintes opções:  Todos: O programa irá listar as informações de todos os riscos, a que o funcionário está exposto.  Consta no PPP: O programa irá listar as informações dos riscos a que o funcionário está exposto, mas considerando apenas dos riscos que foram cadastrados com o campo “Considerar” igual a “Aso e PPP” ou “PPP”.  Observação: 1 - Em ambos os casos o programa só irá listar os riscos se o campo “Data de Avaliação” estiver preenchido. 2 - Se mudar alguma das informações entre os itens 15.2 e 15.8 o programa imprimirá uma nova linha no PPP. | | |
| 15.1 |  | Diversos | Data de início e término da exposição do funcionário ao Fator de risco. Este período é definido considerando-se as seguintes datas: de    * Admissão do funcionário (SRA). * Início do funcionário no c.custo (SRE). * Saída do funcionário do c.custo (SRE). * Início no funcionário na Função (SR7). * Saída do funcionário da Função (SR7). * Quebra de data por tempo de Afastamento (SR8). (gera conforme pergunta "**Tipos de Afastamentos**"). * Reconhecimento e avaliação do Risco (TN0). * Início e término da tarefa (TN6). (somente se houverem tarefas por funcionário,). * Data da entrega do EPI. (se o funcionário recebeu EPI para se proteger do risco) | **MV\_PPPDTRI**- Define se o tempo de exposição ao fator de risco sem proteção será apresentado no PPP ou não. |
| 15.2 | Tipo | Dados Exames | Esta informação é obtida da rotina de Exames por Agente (TMA), com base no código do Agente da rotina de Riscos (TN0). Identifica se o Agente é F (Físico), Q (Químico), B (Biológico), E (Ergonômico), M (Mecânico). |  |
| 15.3 | Fator de Risco | Dados Exames | Esta informação é obtida da rotina de Exames por Agente (TMA) do campo “Nome do Agente”, com base no código do Agente da rotina de Riscos (TN0). Obs.: Para os agentes do Tipo Q (Químico), o programa irá obter esta informação do campo “Subs. Ativa”, caso este campo não seja informado o programa imprimirá o conteúdo do campo “Nome do Agente”. |  |
| 15.4 | Intens./Conc. | Dados do Risco | Esta informação é obtida da rotina de Riscos (TN0). |  |
| 15.5 | Técnica Utilizada | Dados do Risco | Esta informação é obtida da rotina de Riscos (TN0). |  |
| 15.6 | EPC Eficaz | Dados do Risco | Esta informação é obtida da rotina de Riscos (TN0), sendo necessário efetuar o relacionamento Risco x EPC (TNX).  Obs.: O campo "EPC Eficaz" deve estar = Sim. |  |
| 15.7 | EPI Eficaz | Dados do Risco | O programa obtém a informação da seguinte forma: Verifica na rotina de Riscos x EPI (TNX), se para o risco a que o funcionário está exposto, existe um EPI relacionado. Atenção: o programa leva em consideração o número do risco e não o código o agente. Verifica na rotina de EPI x Funcionário (TNF), se o funcionário recebeu o EPI, e estava utilizando durante o período a que esteve exposto ao risco. |  |
| 15.8 | C.A. EPI | Dados EPI | Obtém esta informação da rotina de EPI x Funcionários (TNF). Faz referência ao campo "Núm. C.A." (TNF\_NUMCAP). |  |
| 15.9 | Atendimento aos requisitos das NR-06 e NR-09 do MTE pelos EPI informados |  | **Medida de Proteção:** Faz referência aos cadastros de Risco e Medida de Controle.  No risco o campo "EPC Eficaz"= SIM e o campo TN0\_MEDCON estiver preenchido (campo que busca o código da Medida de Controle – Somente TIPO = EPC) deve atribuir S- SIM, porém, o Tipo do Controle de Medida deve ser "Proteção Coletiva", caso umas das informações estarem diferente, será atribuído N – NÃO.  **Condição de funcionamento do EPI:** Foram observadas as condições de funcionamento e do uso ininterrupto do EPI ao longo do tempo, conforme especificação técnica do fabricante, ajustada às condições de campo. Se em qualquer período que o funcionário estiver exposto a risco ele não possuir EPI entregue, deve atribuir N a esta pergunta, caso contrario S.  Será validado a data de entrega do EPI (Funcionário x EPI) e Período Exposição do Risco (TN0). Se em qualquer período que o funcionário estiver exposto ao risco e não possuir EPI entregue ao funcionário, o campo será geração com N - NÃO.  **Prazo de Validade:** Foi observado o prazo de validade, conforme Certificado de Aprovação-CA do MTE Serão analisadas todas as entregas de EPI, verificando se ele foi entregue antes do prazo de validade e substituído dentro do prazo de validade também. Foi observada a periodicidade de troca definida pelos programas ambientais, comprovada mediante recibo assinado pelo usuário em época própria.  No cadastro do EPI x Fornecedor (TN3) é analisado o vencimento do Certificado de Aprovação (C.A.) + a entrega do EPI, validando se a entrega foi antes do prazo de validade e substituído dentro do prazo de validade.  Obs.: Lembrando que essas informações são de acordo com o período de exposição do funcionário ao risco.  **Periodicidade da Troca do EPI:** Para cada período de utilização de um EPI, será verificado se o prazo estabelecido de utilização do EPI não foi ultrapassado. Exemplo: Protetor Auricular está definido com 60 dias de utilização. Se o funcionário utilizá-lo em um período maior que 60 dias, será indicado N para este item no PPP.  No cadastro de EPI x Fornecedor é verificado os dias de utilização e o tipo de durabilidade, se for definido como **GERAL** será contabilizado os dias corridos não abatendo faltas e afastamentos, e se definido como **USO**, será descontado as faltas e afastamentos do funcionário.  **Higienização do EPI:** Essa informação é definida a partir dos campos Periodicidade (em dias) da Manutenção / Higienização do EPI (Tabela Epi x Fornecedor) e Data da Manutenção / Higienização do EPI (Tabela Epi’s Entregue x Funcionário). Para o EPI que teve definida a quantidade de dias para manutenção / higienização, será verificado se a data da manutenção está preenchida ou não.  É validado a data de manutenção da entrega do EPI (TNF) e período de manutenção do cadastro EPI x Fornecedor (TN3).  Informações adicionais:  Verificar na tabela de Riscos x EPI (TNX), se para o risco a que o funcionário está exposto, existe um EPI relacionado. Atenção – o programa leva em consideração o número do risco e não o código o agente.  Verifica na tabela de EPI x Funcionário (TNF), se o funcionário recebeu o EPI, e estava utilizando durante o período a que esteve exposto ao risco.  No cadastro de Risco x EPI, verificar quais e quantos Epi's estão obrigatórios para aquele risco.  No cadastro de funcionários x EPI, garantir que todos os Epi's obrigatórios foram entregues ao funcionário.   Verificar se os parâmetros da coluna ao lado estão ativos. | **MV\_NG2KEPI -** Indica se a empresa utiliza EPI em caráter complementar, mesmo quando o EPC for eficaz.  **MV\_NG2CEPI -** Indica se a empresa consiste o EPI.  **MV\_NG2CEPC -** Indica se a empresa consiste o EPC. |
