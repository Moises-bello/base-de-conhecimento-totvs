# Transferência de Grupos Contábeis - Moeda Funcional

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Transferência de Grupos Contábeis |
| **Situação/Requisito:** | Cliente utiliza a Moeda Funcional e no ano passado enviou a ECD com a parametrização manual. Foi implementado o Controle de Moeda Funcional disponibilizado nos parâmetros das Rotinas Legais. Mais de acordo com a cliente só esta implementação não é o suficiente, pois o encerramento das contas de resultado também devem afetar as contas de ajuste de Moeda Funcional de forma separada do que hoje tratamos no processo de Transferência de Grupos Contábeis. |
| **Solução/Implementação:** | Melhoria no processo de Transferência de Grupos Contábeis para que seja possível realizar o encerramento de forma separada para as contas de Moeda Funcional. Para tal foi disponibilizado a opção de criação de um molde para moeda funcional onde é filtrado apenas as contas que são indicadas para como sendo as utilizadas para Moeda Funcional. |
