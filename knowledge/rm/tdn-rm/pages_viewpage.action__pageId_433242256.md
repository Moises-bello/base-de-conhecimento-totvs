# MALA DIRETA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Mala direta |
| **Situação/Requisito:** | Ao enviar e-mail pela mala direta, o sistema não obedecia o filtro utilizado na grid de visão, enviando incorretamente o e-mail para todos os registros retornados na consulta utilizada. |
| **Solução/Implementação:** | Otimização no envio de mala direta, ao filtrar registros na tela da visão será enviado e-mail somente para os registros filtrados. |
