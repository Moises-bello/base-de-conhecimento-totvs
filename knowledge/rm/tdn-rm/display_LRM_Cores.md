Subprojetos: Informe a cor que deseja atribuir para os Subprojetos.

Etapas: Informe a cor que deseja atribuir para as Etapas.

Serviço cotado: Informe a cor que deseja atribuir para os Serviços Cotados.

Serviço associado a Composição: Informe a cor que deseja atribuir para os Serviços associados a uma Composição.

Serviço associado a Insumo: Informe a cor que deseja atribuir para os Serviços associados a um Insumo.

Serviço indireto: Informe a cor que deseja atribuir para os Serviços de custo indireto.

**Observação:** Estes parâmetros não têm incidência sobre o módulo de Contratos.

**Atenção:** Será mostrado nesta pasta o resultado desta parametrização com as cores de cada um dos itens da planilha. Para que as alterações sejam refletidas, é necessário reabrir a Planilha de Atividades e clicar no ícone Layout - Voltar Layout Padrão. Se o Projeto utilizar a Planilha de Serviços, é necessário realizar o mesmo processo acima para que as alterações sejam aplicadas.
