|  |  |

| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Copiar Modelo de Etapa Para Outro Período Letivo* |
| **Situação/Requisito:** | *Após ir no período letivo e utilizar o processo de copiar modelo de etapas para outro período letivo o sistema realiza o processo de cópia, porém ao ir no período de destino os modelos de etapas estão com as data bem futura a qual está no cadastro de origem.* |
| **Solução/Implementação:** | *Ajuste no processo de cópia de modelo de etapa para outro período letivo para que copie as datas de início e término das etapas do período letivo de origem para o de destino.* |
