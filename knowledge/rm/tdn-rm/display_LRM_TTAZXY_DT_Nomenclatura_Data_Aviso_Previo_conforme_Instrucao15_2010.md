|  |  |

| **Função:** | *Edição dos Parâmetros do Passivo Trabalhista* |
| **Situação/Requisito:** | *Nomenclatura da data do aviso deve seguir a instrução Normativa SRT 15/2010* |
| **Solução/Implementação:** | O relatório do passivo trabalhista passa a seguir a nomenclatura da  Instrução Normativa SRT nº 15/2010 para data do aviso, a saber:   1. Parâmetro "Aviso Prévio Indenizado" marcado A data do aviso passa  a ser "Data de Início do Aviso Indenizado"; 2. Parâmetro "Aviso Prévio Indenizado" Desmarcado A data do aviso passa  a ser "Data de Início do Aviso Prévio"; |
