Assim como as configurações de parâmetros e perfis, o acesso ao TOTVS Educa Mobile está disponível para usuários já cadastrados, desde que possuam as permissões necessárias. Para novos alunos, o processo de criação de usuários segue o mesmo padrão utilizado para o sistema e o portal.
