# Não era Possível Pesquisar Descrição e Código na mesma Interação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Etiquetas de Código de Barras |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu **Estoque/Etiquetas de Código de Barras**, selecionar o local de estoque, selecionar o relatório de impressão de Etiquetas de Código de Barras, clicar no botão "Pesquisa", irá exibir o formulário "Pesquisa de Itens do Estoque".  Neste formulário digite o nome fantasia, o código e clique no botão de pesquisar, o resultado da pesquisa era a mensagem: "Inválid field name. ORA-00904: Identificador Inválido". |
| **Solução:** | Ajuste realizado no formulário para que ao pesquisar o processo de pesquisa finalize sem nenhuma exceção.. |
