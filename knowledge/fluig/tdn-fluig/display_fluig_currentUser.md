**currentUser** é um objeto do tipo  disponibilizada pela plataforma Fluig em todas os pontos de personalização e permite obter informações sobre o usuário atual

# Descrição

Com ele o desenvolvedor pode validar, imprimir ou utilizar de outras maneiras os dados do usuário atual. Este usuário é o usuário que está executando a ação.

Em movimentação solicitações, este é o usuário que está **movimentando** ou o usuário que **está sendo substituído**. Para ter informações do usuário substituto, use o objeto . E no caso de personificação, este objeto é referente ao usuário que está sendo personificado.

# Sintaxe

js

# Exemplos de uso

## Imprimir os dados do usuário atual

jstrue

# Compatibilidade
