Como aumentar o tamanho do campo CNF\_PARCEL do Cronograma Financeiro ?  
  
**Ambiente**

Protheus – Gestão de Contratos – A partir da versão 12.1.23

**Solução**

*Acesse o módulo configurador -> Base de dados -> Dicionário -> Base de dados*

**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6299691233047/mceclip0.png)**

**Selecione a tabela CNF**

**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6302192856343/mceclip1.png)**

**Selecione o campo CNF\_PARCEL**

**![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6302281856535/mceclip2.png)**

*Proceda com aumento do grupo de campos ( 011 ) Parcela:*

O tamanho mínimo é 1 e o tamanho máximo é 4.
