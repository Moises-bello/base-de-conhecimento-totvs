# ERRO APÓS RESETAR A SENHA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Login Portal do Aluno (novo) |
| **Situação/Requisito:** | Está ocorrendo um erro após o resetar a senha de um aluno no Portal, onde é informado que a senha expirou e ao redirecionar para a tela de alteração ou digitação de uma nova senha, o portal redireciona para a tela de login, não permitindo o avanço por parte do usuário.  Quando o aluno digita a senha (que ocorreu o reset via aplicação TOTVS Educacional), o portal avisa que a senha está expirada, porém, após selecionar "OK" deveria redirecionar para a tela de alteração de senha, mas o portal redireciona para a própria tela de login, não permitindo avanço ou acesso por parte do aluno. |
| **Solução/Implementação:** | A tela de login do Portal do Aluno (novo) não havia a possibilidade de alterar a senha, sendo assim foi implementada a funcionalidade para que o usuário possa realizar o procedimento. |
