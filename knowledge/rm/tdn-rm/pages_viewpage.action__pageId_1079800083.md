# 1. Sobre

Foram adicionados os campos do grupo retTrib ao objeto de negócio do DANFE-COM.

Os campos não foram adicionados ao relatório do DANFE-COM mas podem ser adicionados conforme necessidade editando uma cópia do relatório pelo SmartView.

Os seguintes campos foram adicionados:

| Nome | Campo XML |
| --- | --- |
| Valor PISRF | imposto.retTrib.vRetPIS |
| Valor COFINSRF | imposto.retTrib.vRetCofins |
| Valor CSLLRF | imposto.retTrib.vRetCSLL |
| BC IRRF | imposto.retTrib.vBCIRRF |
| Valor IRRF | imposto.retTrib.vIRRF |
