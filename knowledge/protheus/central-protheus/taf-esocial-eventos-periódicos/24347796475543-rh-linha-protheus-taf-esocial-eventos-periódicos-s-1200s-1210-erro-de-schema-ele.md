**Ocorrência**  
Erro de schema ao transmitir S-1200 ou S-1210:

Erro de schema: Element '{<http://www.esocial.gov.br/schema/evt/evtRemun/v_S_01_03_00>}evtRemun', attribute 'Id': [facet 'length'] The value 'ID12444120600000020260511120738890938' has a length of '37'; this differs from the allowed length of '36'.

**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Eventos periódicos - Todas as versões  
  
  
**Solução**

1- Para correção, acesse o evento que está rejeitado com o erro de schema, e clique para retransmitir o evento novamente

![](https://centraldeatendimento.totvs.com/hc/article_attachments/40497190690967)

2- Exclui evento inconsistente no TAF.

[RH - Linha Protheus - TAF - eSocial - Como excluir eventos com status inconsistente no TAF](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360035475634-RH-Linha-Protheus-TAF-eSocial-Como-excluir-eventos-com-status-inconsistente-no-TAF)
