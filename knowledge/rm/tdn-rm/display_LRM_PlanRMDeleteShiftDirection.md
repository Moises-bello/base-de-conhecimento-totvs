# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define se deve deslocar as células para a esquerda ou para cima para substituir as células removidas.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Left | Define que as células devem ser deslocadas para a esquerda afim de substituir as células removidas. |
| Up | Define que as células devem ser deslocadas para a cima afim de substituir as células removidas. |
