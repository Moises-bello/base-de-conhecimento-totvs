# Arredondamento valor total honorário XML Faturamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento para convênios |
| **Situação/Requisito:** | Valor unitário do produto está sendo arredondado para duas casas. Quando o valor termina em "5", é arredondado para cima. Entretanto o valor total não é atualizado com o valor pós arredondamento. |
| **Solução/Implementação:** | Realizado ajuste no arredondamento do valor total. |
