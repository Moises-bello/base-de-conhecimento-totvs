# EXPORTAR DE DADOS DOS CANDIDATOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Exportar dados dos candidatos* |
| **Situação/Requisito:** | *Foi identificado que ao exportar as informações dos candidatos para um arquivo, o sistema está apresentando um erro de conversão de dados.* |
| **Solução/Implementação:** | *Identificamos que o sistema estava realizando um relacionamento entre os números de inscrição do Processo Seletivo e do Enem, onde os tipos dos campos e as informações são diferentes um do outro.*  *Como o sistema não pode realizar o relacionamento entre esses campos, o sistema foi alterado para considerar apenas o número de inscrição do Processo Seletivo entre suas tabelas.* |
