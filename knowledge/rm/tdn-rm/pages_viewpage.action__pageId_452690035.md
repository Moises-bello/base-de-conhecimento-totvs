# MONTAGEM DE QUADRO DE HORÁRIOS - INCLUSÃO DE PROFESSORES EM SUBTURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Montagem de quadro de horários* |
| **Situação/Requisito:** | *Ao realizar a inclusão de um professor em uma subturma, o sistema está incluindo o professor em todas as subturmas da turma.. Quando há choque de horário e o usuário possui permissão, o sistema não está incluindo o professor na turma.* |
| **Solução/Implementação:** | *Foi realizado um tratamento para que seja identificado quando a turma possui subturma para que seja realizado o filtro incluindo o código da subturma. Dessa forma, a inclusão e a validação de choque de horário se fará com os horários da própria subturma..* |
