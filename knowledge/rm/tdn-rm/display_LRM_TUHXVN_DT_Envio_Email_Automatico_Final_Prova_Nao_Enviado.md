# ENVIO AUTOMÁTICO DE EMAIL AO FINAL DE PROVA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Avaliação e Pesquisa* |
| **Função:** | *Envio automático de e-mail de resultado ao finalizar uma avaliação* |
| **Situação/Requisito:** | *Foi identificado que mesmo com a configuração de enviar e-mail ao final de uma avaliação o sistema não estava enviado os emails quando a avaliação é executada pelo RM Executor via webservice.* |
| **Solução/Implementação:** | *Foi identificado que o sistema não estava localizando a mensagem de resultado do local correto e nem validava se o texto do resultado estava vazio, após o ajuste o envio passou a ser feito corretamente, desde que a prova seja executada pelo RM Executor via webservice e a prova esteja configurada para exibir resultados e enviar e-mail ao final da prova.* |
