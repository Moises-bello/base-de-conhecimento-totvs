## **01. VISÃO GERAL**

Após a digitação do laudo, o usuário poderá escolher o status Digitação Concluída.

Estando no status concluído, o usuário poderá seguir para o status Liberar Resultado ou voltar para Digitar Exame (figura 1)

Figura 1 - Status Digitação Concluída

Estando no status Liberado o usuário poderá para "Retornar Liberado para Correção". (Figura 2)

Se o “Parâmetro Geral > Aba Unidade Diagnóstico II > Restringe o retorno de exames liberados para correção” - **Somente o usuário que Liberou o exame pode retornar para correção!**

Se o “Parâmetro Geral > Aba Unidade Diagnóstico II > Limite de dias para permitir retornar resultado de exame de Liberado para Correção” - **Existe um limite de dias que permite retornar para correção após o exame ser liberado.**

Figura 2: Retornar Liberado para Correção

Caso o usuário continue retornando o status e volte para o status Em Digitação (Retornar para Digitação) (Figura 3)

Figura 3 - Voltando o status para Retornar para Digitação

Após a correção do laudo o usuário poderá seguir novamente para o status de Digitação Concluída.

Caso o parâmetro de envio de notificações esteja habilitado (Figura 4) e o laudo seja alterado após a liberação sistema irá enviar uma notificação de Alteração de Laudo para o processamento de mensagens.
