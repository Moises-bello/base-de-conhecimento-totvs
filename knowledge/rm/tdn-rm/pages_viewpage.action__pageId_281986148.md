# Conceito Importação Campos Complementares

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Patrimonial. |
| **Função:** | Conceito |
| **Situação/Requisito:** | Não está sendo possível importar, via conceito, o arquivo de campos complementares dos patrimônios. |
| **Solução/Implementação:** | Após realizar uma análise foi constatado que o conceito responsável por importar os campos complementares dos patrimônios está correto, porém o arquivo de importação criado pelo cliente possui vários registros inconsistentes. Para executar o conceito com sucesso o cliente precisará acertar o arquivo de importação e excluir os registros da tabela IPATRIMONIOCOMPL, porém apenas aqueles que existem no arquivo e na tabela. |
