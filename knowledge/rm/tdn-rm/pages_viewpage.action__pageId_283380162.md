# CENTRAL DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Central do aluno |
| **Situação/Requisito:** | A central de aluno não mostra as notas e faltas das etapas, quando o usuário possui 2 perfis onde somente um deles está marcado o parâmetro educacional “Visualizar consulta de notas e faltas na central do aluno”. |
| **Solução/Implementação:** | Otimizado a Central do Aluno, para permitir visualizar notas e faltas das etapas, quando estiver marcado o parâmetro do perfil do usuário “Visualizar consulta de notas e faltas na central do aluno” em qualquer um dos perfis deste usuário. |
