# Geração de Lançamento Financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Geração de Lançamento Financeiro |
| **Situação/Requisito:** | Se incluirmos uma bolsa de crédito para uma parcela que já tenha lançamento gerado, depois regeramos o lançamento para contemplar a bolsa de credito, o lançamento financeiro referente a bolsa de credito está sendo gerado com o tipo contábil diferente do tipo contábil do lançamento financeiro de origem. |
| **Solução/Implementação:** | Melhoria no serviço de geração de lançamento financeiro que é executado após a inclusão da bolsa de crédito para uma parcela que já tinha lançamento, para que o tipo contábil do lançamento financeiro de crédito esteja conforme o lançamento financeiro de origem. |
