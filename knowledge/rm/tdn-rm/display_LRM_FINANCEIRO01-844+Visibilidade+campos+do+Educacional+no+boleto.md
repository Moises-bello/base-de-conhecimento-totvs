# VISIBILIDADE DE CAMPOS DA INTEGRAÇÃO EDUCACIONAL X BACKOFFICE PROTHEUS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Boletos. |
| **Situação/Requisito:** | Campos exclusivos da integração Educacional x Backoffice Protheus estavam visíveis no cadastro de boletos. |
| **Solução/Implementação:** | Os campos Valor Original, Valor Desconto, Bolsa e Bolsa Especial, Código e Nome do Responsável Financeiro (esses dois somente na visão) só ficarão visíveis se a visão de boletos for chamada de dentro do Educacional e a nova integração Educacional x Backoffice Protheus ativa. |
