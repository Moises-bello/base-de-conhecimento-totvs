**Dúvida**Existe um modelo de configuração para os Lp´s 5C4, 5C5, 5C6 e 5C7 ?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro -FINA960 - A partir 11.8  
  
**Solução**Não temos nenhum exemplo, porém o mesmo pode utilizar o ponto de lançamento. Segue a documentação:  
<https://tdn.totvs.com/display/public/PROT/FIN0004_LPAD_Pontos_de_lancamentos_Utilizando_ctba085>  
  
Para o**LP 5C4** -> Contabilização do Cabeçalho - Utilizará a **tabela FR4**  
Para o **LP 5C5** -> Contabilização do Item do Componente - Utilizará a**tabela FR5**  
  
Agora para Estornos  
**LP 5C6** ->Estorno do Cabeçalho - Utilizará a **tabela FR4**  
**LP 5C7** -> Estorno do Item do Componente - Utilizará a **tabela FR5**
