**Dúvida**  
Pontos de Entrada no **Cadastro de Sindicato - GPEA340**  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.25  
  
**Solução**  
  
O Fonte **GPEA340** está codificado com a estrutura MVC, neste caso, não existem pontos de entrada com tratamentos específicos.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/33621095342103)

Existe o modelo de dados para customizar conforme necessidade, um ponto de entrada único, como segue abaixo.  
  
**GPEA340**  
**- Nome do Modelo: GPEA340**  
**- AddFields: GPEA340\_RCE**  
**- AddGrid: GPEA340\_RG4**  
  
Segue também exemplo de como utilizar os modelos de dados no formato MVC.  
  
[Ponto de Entrada padrão MVC - Exemplo de utilização](https://tdn.totvs.com/pages/viewpage.action?pageId=208345968)  
  
**Importante**  
**O Suporte Técnico não auxilia no desenvolvimento de customizações, assim, caso necessite de auxílio neste processo, orientamos a fazer o agendamento de um analista TOTVS in loco com seu Gerente de Contas.**
