Composição das Parcelas não são apresentadas na Condição de Pagamento

FAQ: **Composição das Parcelas não são apresentadas na Condição de Pagamento**

|  |  |
| --- | --- |
| Produto: | Unspecified |
| Ambiente: | Unspecified |
| Versão: | 11.00 |

Sintoma

* **Sintoma**

As composições das parcelas da condição de pagamento não são apresentadas no cadastro de “Condição de Pagamento”.

Causa

* **Causas**

1- Nos parâmetros da condição de pagamento o “***Número de Composição das Parcelas***” não esta definido. Caminho dos parâmetros Integrações / Financeira / Condição de Pagamento.

Solução

* **Solução**

1- Informe a quantidade de parcelas que deseja utilizar no campo “***Número de Composição das Parcelas***” dentro dos parâmetros da Condição de Pagamento no caminho Integrações / Financeira / Condição de Pagamento
