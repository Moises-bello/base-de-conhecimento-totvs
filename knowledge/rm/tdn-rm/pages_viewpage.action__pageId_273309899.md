# Requisições de Promoção e de Desligamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão de Pessoas |
| **Função:** | Requisições de Promoção e de Desligamento |
| **Situação/Requisito:** | As Requisições de Alteração de Dados Pessoais e Transferência com Alterações de Dados Pessoais apresentam uma mensagem padrão referente a controle de lotação ao desmarcar o campo Gerar Substituição. Esta mensagem não deveria ser apresentada caso o sistema não esteja parametrizado para trabalhar com controle de lotação. |
| **Solução/Implementação:** | Realizado ajuste para que seja exibida a mensagem ao desmarcar a opção Gerar Substituição apenas se o sistema estiver parametrizado para utilizar controle de lotação. |
