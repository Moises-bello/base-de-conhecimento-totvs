# Efetivar Alteração de Dados Funcionais

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Efetivar Alteração de Dados Funcionais |
| **Situação/Requisito:** | Ao calcular a rescisão para o próximo mês e o colaborador tiver progressão para depois da rescisão, e executar a efetivação da progressão, o sistema altera o salário mesmo tendo rescisão calculada. Sendo assim, o salário fica inconsistente com os cálculos. |
| **Solução/Implementação:** | Ajustado o processo de efetivação de progressão salarial e assim verificar a situação e data de demissão do colaborador e executar o processo de progressão salarial. |
