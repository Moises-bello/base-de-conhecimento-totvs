![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20954736321815) Tempo aproximado para leitura: **00:02:00 min** **Dúvida** Como alterar NCM do item no Desembaraço (EICDI502)?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão 12.1.33.

**Solução**Realize o procedimento abaixo para ajuste do peso do item:  
1. Acesse a rotina de Atualização\Desembaraço\Manutenção , posicione no processo e selecione alterar;  
2. Selecione Outras Ações\Itens;  
3. Desmarque o item e informe o NCM e selecione OK;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20954736325143)

4. Após selecione Salvar para gravar o processo.
