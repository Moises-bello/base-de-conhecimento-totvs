**Dúvida**Como efetuar a gravação das despesas base de ICMS no documento de entrada em 'Outras Despesas'?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**

Foi criado o parâmetro MV\_EIC0037 que define se as Despesas Base ICMS devem ser consideradas no campo Outras Despesas na rotina de Recebimento de Importação (EICDI154), conforme boletim: [Criação do Parâmetro MV\_EIC0037 - THZR46](https://tdn.totvs.com/pages/releaseview.action?pageId=126718064)
