**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura: **00:01:30 min  
  
Ocorrência**Ao gerar SEFIP apresenta erro:Processo deve ser informado para o código de recolhimento indicado. Vara/JCJ devem ser informadas para o código de recolhimento indicado (650)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Causa**Falta de parametrização correta do sistema  
  
**Solução**Para solucionar essa ocorrência verifique os passos abaixo:  
  
1. Acessar **Encargos | Parâmetros INSS\FGTS**;  
2. Alterar o Código de Recolhimento da SEFIP para: **650 - Recolhimento ao FGTS**;  
3. Iniciar Todas as Seções no SEFIP;  
4. Editar as seções;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360012586071/mceclip0.png)  
  
5. Acessar **Valores I** e preencher as informações;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360012580672/mceclip1.png)  
  
6. Após informar os dados, salvar o registro e realizar novamente a geração de SEFIP.
