![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19278002822935) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como realizar o cadastro de Tipo de objetivo?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Avaliação Pesquisa e Desempenho – Todas as versões  
  
**Solução**O cadastro tipo de objetivo é utilizado para **definir os tipos de objetivo, planos ou metas**, que se deseja obter **em função do resultado de uma avaliação de desempenho,** aplicados aos participantes da organização.  
  
Ao cadastrar o tipo de objetivo, deve ser definido **uma escala para determinar o cumprimento do objetivo proposto, seu grau de importância e pesos.**  
  
Exemplos de Planos e Metas:

|  |  |
| --- | --- |
| • | Plano para o desenvolvimento profissional individual; |

|  |  |
| --- | --- |
| • | Plano de desenvolvimento pessoal; |

|  |  |
| --- | --- |
| • | Planejamento de metas; |

|  |  |
| --- | --- |
| • | Plano para treinamento estratégico. |
