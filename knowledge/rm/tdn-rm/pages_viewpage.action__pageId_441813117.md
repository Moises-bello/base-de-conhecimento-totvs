## **02. SITUAÇÃO/REQUISITO**

Parametrizar qual tipo de movimento do RM Núcleus a ser utilizado no processamento de Requisições à Paciente dos Kits

## **03. SOLUÇÃO**

Criado o parâmetro "Movimento (Requisição a paciente)" no agrupador "Kit Pré-Montado". Quando o mesmo estiver preenchido, o sistema utilizará este tipo de movimento para baixar o kit. Caso contrário, o sistema utilizará o movimento de saída.

Passo 01, Passo 02, Passo 03, Passo 04passo1,passo2yespasso1

Parametrizar o tipo de movimento para baixa do kit ao utilizá-lo

nopasso2

Processar a requisição contendo um kit. Ao processar, o sistema utilizará o novo parâmetro caso esteja preenchido.
