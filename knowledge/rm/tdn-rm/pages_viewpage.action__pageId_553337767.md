Para gerenciamento Ágil das atividades do projeto pode-se criar um Board do tipo *Kanban* ou *Scrum*. Para isso deve-se:

1. Acessar a ferramenta JIRA (**<http://jiraproducao.totvs.com.br/>**).
2. Acesse o painel de navegação do projeto.
3. Clicar em **(...)** no menu superior esquerdo, opção ***Create board***;
4. Escolher a opção ***kanban*** ou ***Scrum***.
5. Escolher a origem de dados do Board.
6. Informe no campo ***Board name*** o nome do Board;
7. Para finalizar, clique em ***Create board***.

***Scrum*:** possui todas as opções do *Scrum*: *Backlog* da Versão, *Epics*, *Sprints*, *Kanban* e *Burndown*.

***Kanban*:** possui apenas o quadro de acompanhamento das atividades, não possui a visão do *Backlog* do projeto, ele deve ser utilizado apenas para visualização dos status das atividades pelas colunas configuradas.

Caso escolha criar um ***Kanban Board***, apenas esta será a sua visão.

Caso escolha criar um ***Scrum Board***, esta será a sua visão de *Backlog*. O *Backlog* no *Scrum* são todas as tarefas do *Board* que estão planejadas em *Sprints* ou que estão no *Backlog* do projeto, conforme as configurações realizadas. Não são apresentadas as subtarefas.

**Dicas**

1. As *Issues* criadas com status *backlog* são incluídas automaticamente no *backlog* do produto.
   1. As issuetypes *Story*, Manutenção, Legislação e Ponto de Entrada já iniciam no status *backlog*.
2. O Product Owner deve priorizar o que será entregue no próximo *release*.
3. Caso um item seja retirado do *backlog* do produto, este deve ser cancelado ou voltar para o *status* banco de ideias.
   1. No EPIC está disponível no status banco de ideias.
