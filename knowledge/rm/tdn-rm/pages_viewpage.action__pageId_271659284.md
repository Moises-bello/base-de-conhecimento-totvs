# Cancelamento de lançamentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Cancelamento de lançamentos. |
| **Situação/Requisito:** | Ao gerar um Aditivo de Renegociação de Contrato no TIN, a Data de Cancelamento do lançamento financeiro não é preenchida nas parcelas que são canceladas do plano anterior. |
| **Solução/Implementação:** | Ao cancelar um lançamento, caso a data de cancelamento não seja informada, será utilizada como data de cancelamento a data de emissão do lançamento. |
