**Eventos a serem Lançados no RM Labore**

Após selecionar um funcionário, acesse esse anexo para visualizar os eventos que poderão ser lançados para o RM Labore, ou seja, os eventos que estão cadastrados no parâmetro do sindicato do funcionário. É possível selecionar o evento e efetuar o lançamento através do processo "Lançamento de eventos para o RM Labore".

**Observação**

Para que um evento seja lançado no RM Labore, ele deverá estar incluído na Pasta de Eventos a Serem Lançados no RM Labore - Sindicato RM Chronus.

Para cada parâmetro Sindicato RM Chronus, devem ser cadastrados quais os eventos que, se presentes no movimento do funcionário que possui este parâmetro Sindicato RM Chronus, serão lançados para o RM Labore.
