# EXAMES PRESCRITOS ESTAO GERANDO COBRANÇA MESMO PARAMETRIZADO PARA NÃO LANÇAR ITENS DE DÉBITO - ASSOCIAÇÃO MEDQUALIS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de conta. |
| **Situação:** | Itens de exames parametrizados para serem lançados como débito na conta do paciente, quando prescritos pelo PEP não  estavam caindo na conta conforme o parâmetro configurado. |
| **Solução:** | Correção na rotina para lançamentos de exames prescritos no PEP, serem registrados no RM com o parâmetro correto. |
