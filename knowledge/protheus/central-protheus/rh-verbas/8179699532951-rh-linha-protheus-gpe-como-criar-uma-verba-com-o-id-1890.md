![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21385506471063) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como criar uma verba com o ID 1890 - 1/3 Abono Pago Mês Anterior?  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**Entre na rotina Verbas pelo caminho **>Atualizações >Definições de cálculo >Verbas**;  
Clique em Incluir;  
Cadastre a verba com as seguintes definições:  
- Verba é do tipo **Desconto**,  
- Deve ficar com **SIM para IR** e **SIM** no campo **Ref Fer  
-** O campo Id p/Calculo deve ficar com **1890**- Qtde.Lancto deve ficar com 9  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8179586288151)  
  
Após configuração, clique em Confirmar.  
  
**IMPORTANTE:** A verba de ID 1890 não é obrigatória desde que o campo IR dos IDs 0206 e 0208 estejam com NÃO, porém, caso a incidência dessas verbas esteja com SIM, a criação da verba para o ID 1890 se torna obrigatória para fechar o período, caso contrário, será apresentado log informando a necessidade da criação da verba para que os valores fiquem corretos para o eSocial.
