# Anexo de ajuste de SPED no lançamento fiscal (situação tributária)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Lançamento Fiscal |
| **Situação/Requisito:** | Criação de um Anexo no Lançamento Fiscal que irá armazenar os valores de ajustes e os valores adicionais. Deverá existir também, a opção de inclusão, edição e exclusão manual.  Futuramente esses valores serão calculados na inclusão (e também no processo de Escrituração) com base nos defaults informados no CFOP. |
| **Solução/Implementação:** | O cadastro de ajuste está disponibilizado na situação tributária do lançamento fiscal, na aba: "Ajuste Sped", conforme a figura a seguir:    Desta forma é possível incluir, editar ou excluir os registros.  O sistema não permite inserir o mesmo código de ajuste para o mesmo item duas vezes. |
