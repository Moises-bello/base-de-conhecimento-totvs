**Dúvida**Por que o cálculo de rescisão apresenta o ID 1692-Insalubridade Férias Indenizadas?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**O ID 1692-Insalubridade férias indenizadas se trata da insalubridade referente a verba indenizatória férias vencidas, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1692.**
