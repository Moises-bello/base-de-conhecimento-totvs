# Novo Portal do Aluno: Percentual de faltas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Novo Portal do Aluno |
| **Função:** | Faltas |
| **Situação/Requisito:** | Cliente informa que no novo Portal do Aluno é exibido o Percentual de falta do aluno, mesmo se o parâmetro "Limite de faltas" (Educacional > Secretaria > Geral 4/6 > Limite de faltas > % Limite de faltas) não estiver preenchido. |
| **Solução/Implementação:** | Foi realizado ajuste para garantir que o campo de percentual de faltas só aparece na tela de faltas do novo portal do aluno se o parâmetro em questão estiver preenchido, conforme ocorre no portal do aluno antigo. |
