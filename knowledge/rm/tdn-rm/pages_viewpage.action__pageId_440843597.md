# MATRÍCULA EM LOTE EM DISCIPLINAS DE OUTRAS FILIAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Matrícula em lote* |
| **Situação/Requisito:** | *Ao executar o processo de matrícula em lote, mesmo com a permissão, não parametrização por curso para matrícula em outras filiais, não consigo filtrar turmas de outras filiais.* |
| **Solução/Implementação:** | *Foi realizado acerto no processo para que as lookups de Turma e Turma/Disciplina possam exibir cadastros de outras filiais, caso a parametrização por curso das matrizes envolvidas no processo em lote tenham essa permissão.*  *Parâmetro da parametrização por curso:*   * *Currículo e Oferta | Parametrização por curso | Aba: Configuração de matrícula | Permite matrícula em turmas/disciplinas de filiais diferentes*   *OBS.: Caso haja uma ou mais matriz que tenha uma parametrização que não permite a matrícula em outra filial, será apresentada uma mensagem informando que não é possível fazer tal operação.* |
