# EMISSÃO DE BOLETOS - PORTAL - AGRUPAMENTO DE MOVIMENTAÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Emissão de boletos - portal* |
| **Situação/Requisito:** | *Foi identificado que quando utilizado o agrupamento dos lançamentos quando as movimentações geram valores, ao acessar o portal o boleto é gerado corretamente, porém a descrição do lançamento na tela mostra somente um empréstimo e o valor deste empréstimo, ou seja, quando o usuário gerar o boleto o valor será diferente pois o lançamento consta o total de todas as movimentações daquele agrupamento.* |
| **Solução/Implementação:** | **Foi identificado que o portal só carrega um empréstimo, sendo que o lançamento foi de vários empréstimos agrupados, sendo assim foi feita uma alteração na tela que lista os boletos para pagamento para que mostre todos os itens de um empréstimos que gerou um determinado lançamento agrupado.** |
