## **01. VISÃO GERAL**

Auto texto são blocos reutilizáveis de texto, que através de abreviações de palavras ou trechos de texto servem como atalho para facilitar a digitação de informações que são repetidas com grande frequência.

Laudo de Imagens

## **02. TELA LAUDO DE IMAGENS**

Para Cadastrar um Autotexto de imagem acesse:

**No menu Unidade de diagnóstico> Laudos de imagem**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Botão Substituir | Substitui ou inclui texto. |
| Atalho Ctrl+Espaço | Substitui ou inclui texto. |

Regras de Utilização

## **03. REGRAS DE UTILIZAÇÃO**

1. **PRE-REQUISITOS:***Mnemônico* e respectivo *Texto de substituição* cadastrados na tela CADASTROS > UNIDADE DIAGNÓSTICO > Autotexto para Laudo de Imagem.
2. **SOMENTE** a opção do **Botão Substituir** permite a utilização de mnemônicos compostos. Exemplo: TESTE DIGITAÇÃO
3. Utilizando o **Botão Substituir** do formulário é possível substituir de duas formas:
   1. Selecionando o mnemônico digitado e tomando cuidado para não selecionar "espaço" junto, pois caso contrário o sistema não identificará a palavra.
   2. Posicionar o cursor a frente do mnemônico digitado.
4. Utilizando o **Atalho Ctrl+Espaço** também é possível substituir de duas formas:
   1. Apertar o atalho após digitar o mnemônico desejado. **Obs.: Não reconhece mnemônicos compostos.**
   2. Selecionando o mnemônico digitado e apertando o atalho, porém a seleção deve ser feita no sentido da esquerda para direita de forma que o cursor termine no final da palavra selecionada.
