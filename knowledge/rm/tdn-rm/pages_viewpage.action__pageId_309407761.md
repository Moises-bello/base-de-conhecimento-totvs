# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.17 |
| **Ocorrência:** | Alteração de Orçamento |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**  Este processo permite alterar os valores de orçamentos já criados.  Existem dois tipos de alteração que podem ser realizadas:  - Por Realizado: permite que seja copiado para o orçamento atual o valor realizado no período informado nos campos: Data Inicial e Final;  - Por Percentual: permite que o usuário aumente ou diminua o valor do orçamento atual usando os símbolos (+/-). Lembramos que não é necessário informar o símbolo (%) que já faz parte do campo.  **DESENVOLVIMENTO/PROCEDIMENTO:**  **1 - Acesse o caminho Orçamento / Alteração de Orçamentos:**              **2 - Informe como o orçamento será alterado, através do Tipo de Alteração:**   * Se a alteração for por realizado deve-se informar: ano, conta contábil e o período de movimentação da conta que deseja alterar, para que o sistema tenha condições de fazer os cálculos:                                                  * Se a opção for por percentual deve-se informar: ano e conta contábil / Avançar a tela / informe o valor para o mês que deseja alterar, aumentando ou diminuindo os valores, conforme a figura abaixo:                                                 No exemplo acima iremos aumentar 10% no mês de janeiro e diminuir 25% no mês de fevereiro. |
| **Observações:** | Ao realizar este processo verifique se realmente existe movimentação no período informado e se todos os campos informados no orçamento, estão devidamente preenchidos nos lançamentos contábeis.  Exemplo: Se no orçamento contém departamento, centro de custo, ou conta gerencial preenchida, consequentemente os lançamentos deverão estar também com estes campos preenchidos. |
