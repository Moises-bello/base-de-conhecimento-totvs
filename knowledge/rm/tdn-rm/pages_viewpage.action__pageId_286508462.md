# DIVULGAÇÃO DOS RESULTADOS NA ÁREA PÚBLICA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo. |
| **Função:** | Portal - Público - Divulgação de Resultados. |
| **Situação/Requisito:** | O resultado do processo seletivo não estava ficando disponível no portal para o candidato acessar.  Quando clicava em 'Divulgação de Resultados', a página era direcionada para a tela de login do portal acadêmico TOTVS. |
| **Solução/Implementação:** | Ajustes no resultado do processo seletivo que não estava ficando disponível no portal para o candidato acessar inserindo um arquivo de configuração do servidor para acesso à página. |
