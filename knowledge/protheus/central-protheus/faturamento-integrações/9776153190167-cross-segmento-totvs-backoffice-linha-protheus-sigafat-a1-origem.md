**Dúvida**Qual a finalidade do campo A1\_ORIGEM ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões  
  
**Solução**O campo A1\_ORIGEM é utilizado para registros gerados via Integração (sistema RM da Totvs por exemplo), não é um campo permitido para alterar o conteúdo.
