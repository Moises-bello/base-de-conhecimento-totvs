![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Há no Compras um relatório de Pedidos de Compras vinculado às Notas vinculadas para esse pedidos ?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Compras Fiscal - Todas as versões

**Solução**No Padrão do módulo de Compras, não há um relatório padrão que traga os Pedido Gerados e as Notas de Entrada Vinculadas / Amarradas a esses pedidos.

Caso se deseje, pode-se realizar a customização de um dos relatórios padrões do sistema para que atenda a esta necessidade.
