O erro HELP A240LOTENE no TOTVS Protheus ocorre quando não há saldo disponível para o lote solicitado. Para identificar um lote com saldo, pressione F4 no campo Lote para visualizar os saldos disponíveis e selecionar um lote apto para consumo.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17854034468631) Tempo aproximado para leitura: **00:03:00 min**  
  
**Dúvida**

Ao tentar requisitar saldo de um Lote específico, apresenta o ***HELP A240LOTENE*** e impede a conclusão, como identificar a causa do HELP?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/17854200827159)

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões  
  
**Solução**

No padrão o **HELP A240LOTENE** é apresentado quando não tem saldo disponível para o Lote que esta tentando requisitar.

Para esse cenário o mais adequado é no campo Lote da rotina que esta tentando requisitar o Saldo do Lote, pressione a tecla F4 para apresentar a tela de Saldos Por Lote, para visualizar qual Lote esta disponível para consumo. Veja um exemplo abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/17854515625495)
