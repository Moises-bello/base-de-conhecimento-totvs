**Dúvida**Sistema não carrega as verbas Base de IRRF mês anterior (ID 0106) e IRRF mês anterior (ID 0107) para o roteiro ADI, e sim para o roteiro FOL ao efetuar o fechamento da folha.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12  
  
**Solução**O fonte GPEM120 valida o campo **RA\_PERCADTO**, cadastro do funcionário aba funcionais campo **% Adiantamento**, onde se estiver com o campo zerado, a Bases de IRRF mês anterior e IRRF mês anterior serão carregadas para o roteiro FOL. Para ajustar ou visualizar o campo acesse **Atualizações > Funcionários > Funcionários (GPEA010)**.
