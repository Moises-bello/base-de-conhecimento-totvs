# Ajuste no Log na Geração do Movimento de Nota Fiscal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Tesouraria |
| **Situação:** | Ao gerar um pedido de emissão de NF no RM Saúde, o sistema gerava movimentos em duplicidade no RM Nucleus. |
| **Solução:** | Realizada a inclusão do número da movimentação gerada no RM Nucleus nos logs do RM Saúde, para facilitar a identificação da duplicidade. |
