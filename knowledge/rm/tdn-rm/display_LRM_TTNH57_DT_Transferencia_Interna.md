# Transferência interna

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Transferência Interna* |
| **Situação/Requisito:** | *Ao realizar a transferência interna o usuário era obrigado a informar uma turma de destino ou marcar o parâmetro "Transferir disciplinas em curso".* |
| **Solução/Implementação:** | *Otimizados os processos de Transferência interna e Transferência interna entre coligadas, permitindo que sejam executados sem a obrigatoriedade de informar uma turma de destino ou marcar o parâmetro "Transferir disciplinas em curso". Quando o usuário optar por não informar uma turma, o aluno será transferido, porém não será gerada a matrícula nas disciplinas e somente será gerada a matrícula no período letivo. Vale ressaltar que se o usuário não informar uma das opções acima, uma mensagem de notificação será exibida.* |
