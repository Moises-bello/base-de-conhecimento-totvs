**Dúvida**Exemplo de xml para importação de planilha orçamentaria via MILE

**Ambiente**Protheus – SIGAPCO – A partir da versão 11.80  
  
   
**Solução**A rotina **Manutenção de Planilha Orçamentaria** (**PCOA100**), não possui interface automática para inclusão da planilha, somente para itens orçamentários(interface parcial), no cenário atual não temos como integrar com a ferramenta **MILE**(**Model Integrator Layout Engine**), uma vez que o **MILE** somente efetua *input* de dados para a **interface total**.
