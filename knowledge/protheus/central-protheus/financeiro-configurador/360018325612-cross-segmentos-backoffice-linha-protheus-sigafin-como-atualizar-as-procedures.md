**Dúvida**

Como instalar as novas procedures com o Novo Gestor de Stored Procedures (CFGX051M)?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Todos os Módulos - Todas as versões.

**Solução**

É fundamental manter o sistema atualizado antes de realizar as atualizações das procedures.

O sistema utiliza assinaturas para verificar a compatibilidade entre os fontes e os processos. Esse procedimento é essencial para evitar falhas, como o erro "Erro na chamada do processo".

![](https://centraldeatendimento.totvs.com/hc/article_attachments/39770830177943)

A principal alteração na interface será a exibição das empresas disponíveis no ambiente, juntamente com todos os processos existentes para gerenciamento, tudo em uma única janela.

**As procedures do financeiro são 8, 9 e 10.**

![](https://tdn.totvs.com/download/attachments/651665430/image2022-7-12_15-6-26.png?version=1&modificationDate=1657649186450&api=v2)

**Para realizar a instalação:**

Escolha as empresas nas quais os processos serão instalados.

![](https://tdn.totvs.com/download/attachments/651665430/worddav466b0dd8c744edb398d910a1d5096981.png?version=1&modificationDate=1637355053203&api=v2)

Escolher os processos que serão instalados.  
![](https://tdn.totvs.com/download/attachments/651665430/worddavf76c7baf5789bc32949472a7886ca589.png?version=1&modificationDate=1637355053233&api=v2)

Após selecionar as empresas e os processos, clique no botão ![](https://tdn.totvs.com/download/attachments/651665430/worddav4fff3b945bb21f990a9906fa19377a01.png?version=1&modificationDate=1637355052693&api=v2)

Será exibida uma janela com um aviso solicitando confirmação para iniciar a instalação.  
![](https://tdn.totvs.com/download/attachments/651665430/worddav8fe1d5633e397e85ac15845d2cfe1ac9.png?version=1&modificationDate=1637355053263&api=v2)

A instalação somente poderá ser realizada se os processos selecionados não estiverem sendo utilizados por outra rotina no momento.

Ao confirmar, uma nova janela será exibida, mostrando o progresso da instalação.

![](https://tdn.totvs.com/download/attachments/651665430/worddav178d711de5a613775647d6c2fe253bb3.png?version=1&modificationDate=1637355053297&api=v2)

Ao final do procedimento, uma janela será exibida contendo o log da operação realizada.  
![](https://tdn.totvs.com/download/attachments/651665430/worddavea0373c72c852f8ca614d13136e334fc.png?version=1&modificationDate=1637355053327&api=v2)

No botão **Outras Ações**, é possível gerar o relatório do log.

Ao fechar a janela de log, a interface principal será atualizada para refletir o status atual.

![](https://tdn.totvs.com/download/attachments/651665430/worddav44e49501a3f84a3368d84b70723d7403.png?version=1&modificationDate=1637355053363&api=v2)
