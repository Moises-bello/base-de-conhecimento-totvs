**TOTVS Incorporação x BackOffice Protheus - Cadastro Cliente/Fornecedor**

---

O cadastro de cliente/fornecedor é realizado no Protheus e sincronizado para o RM.

Para incluir um cliente/fornecedor acesse: SigaFin | Atualizações | Cadastros | Cliente Para visualizar no RM o cadastro sincronizado, acesse: BackOffice | Gestão Financeira | Cadastro | Clientes Fornecedores

**Dados Sincronizados**

* Código
* Nome fantasia
* Tipo Entidade
* Data de criação
* Situação do Registro (ativo ou inativo)
* ID
* Endereço/Rua
* Endereço/Número
* Endereço/Complemento
* Endereço/Bairro
* Endereço/Cidade
* Endereço/CEP

**Observação**

O BackOffice envia para o TIN, quem pode alterar ou excluir este cliente será somente o Protheus, o TIN só pode receber o cadastro do Protheus.
