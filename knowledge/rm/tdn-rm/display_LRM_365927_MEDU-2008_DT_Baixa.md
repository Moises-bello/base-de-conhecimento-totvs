# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | Ao realizar uma baixa de um lançamento utilizando o meio de pagamento igual a cheque, o sistema não válida se o documento digitado no campo CPF/CNPJ é a opção no qual o usuário marcou correspondente ao documento permitindo a inclusão de qualquer coisa. |
| **Solução/Implementação:** | Otimização no processo de baixa de um lançamento utilizando o meio de pagamento igual a cheque. Agora o sistema valida corretamente as opção inseridas no campo CPF/CNPJ da forma da opção marcada pelo usuário. |
