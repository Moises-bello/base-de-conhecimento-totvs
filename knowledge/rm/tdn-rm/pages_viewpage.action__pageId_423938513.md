***Atenção!***

Esta funcionalidade só está disponível para as bases já migradas para o Novo Modelo do BackOffice.

Rateio é uma distribuição gerencial que se faz no valor contábil lançado na partida, para ser utilizada em análises gerenciais e tomada de decisões.

Esta pasta de Rateio será disponibilizada somente se uma das contas contábeis informadas no Débito ou no Crédito da partida possuir distribuição gerencial e aparecerá como *Rateio Débito* se a conta contábil informada para o Débito possuir distribuição gerencial ou como *Rateio Crédito* se a conta contábil informada para o Crédito possuir distribuição gerencial. Pode-se consultar o cadastro da conta contábil para saber se a mesma possui ou não distribuição gerencial.

Se a conta contábil informada na partida possuir distribuição gerencial e no cadastro da conta tiver sido informado um rateio default, ao acessar esta pasta o rateio já estará definido conforme o default da conta contábil.

Caso a conta contábil informada na partida tenha distribuição gerencial, mas não possua no seu cadastro um rateio default, o rateio deverá ser informado neste momento e, neste caso, o sistema não permitirá que o lançamento seja salvo caso o rateio não seja informado ou não feche em 100% com o valor contábil lançado.

Para incluir o rateio na partida, informe a conta gerencial e em seguida o Valor do rateio ou se prefeir, informe o Percentual do rateio seguido de % (Ex: 100%).

A cada inclusão ou alteração de rateio, utilize o botão **Confirmar rateio gerencial** para que o mesmo seja processado.

Se o valor do rateio não fechar com o valor da partida e, caso o valor do rateio seja o correto, pode-se utilizar o botão **Atualiza o valor da partida a partir do valor rateado**.

Caso tenha sido feita alguma alteração qualquer no rateio, como alteração da conta gerencial ou do percentual, e se deseja restaurar novamente o rateio default informado no cadastro da conta, basta clicar no botão **Recuperar o rateio gerencial default da conta contábil**.

Para incluir, alterar ou excluir um Rateio utilize os Ícones Globais.
