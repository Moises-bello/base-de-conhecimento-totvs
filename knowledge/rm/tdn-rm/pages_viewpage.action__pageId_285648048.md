# Mensagem Hora Inválida

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Guia Faturamento TISS |
| **Situação:** | Ao realizar a inserção de uma solicitação de autorização SADT e solicitar a autorização desta e o cancelamento, o sistema emitia um alerta ao alterar a guia de solicitação após o cancelamento. |
| **Solução:** | Alterado o sistema para que não seja mais necessário a trigger na tabela SZATENDAUTORIZ efetuando uma validação pelo código. |
