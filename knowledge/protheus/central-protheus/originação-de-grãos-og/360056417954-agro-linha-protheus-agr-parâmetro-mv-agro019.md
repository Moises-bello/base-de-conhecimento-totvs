**Dúvida**Para que server o parâmetro **MV\_AGRO019**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O parâmetro **MV\_AGRO019 - Indica se será consumido o FIFO dos produtos com rastros por lotes** é do tipo **lógico**. Indica se os produtos com rastros por lotes serão feito o consumo **FIFO - First in, First out** conforme o saldo.  
As opções possíveis que o parâmetro pode assumir são: **.T. - TRUE**, **.F. - FALSE**.
