A tela **Aparência do Aplicativo** permite configurar os elementos visuais exibidos no app *Meu Imóvel*, garantindo que o aplicativo mantenha a identidade visual do Portal selecionado e oferecendo opções de personalização tanto para o tema claro quanto para o tema escuro.

Essas configurações definem a logomarca utilizada no app, bem como as cores principais e secundárias que compõem o layout em ambos os temas.

# **Configurações de Aparência**

## **Logomarca**

Permite definir a logomarca exibida no aplicativo.

* **Logo atual:** Exibe a imagem atualmente configurada.
* **Selecionar arquivo:** Permite escolher um novo arquivo de imagem para a logomarca.

Regras para o envio da logomarca:

* Formatos suportados: **.PNG** e **.SVG**
* Tamanho máximo: **1 MB por arquivo**
* Largura máxima recomendada: **150 pixels**  
  *(Utilizar preferencialmente logomarcas em formato horizontal para melhor exibição.)*

---

## **Tema Claro**

Define as cores utilizadas pelo aplicativo quando o usuário estiver com o tema claro ativo.

* **Cor Principal:**  
  Cor predominante do tema claro, aplicada em botões, elementos de destaque e componentes primários.  
  Exemplo padrão: **#3696CE**
* **Cor Secundária:**  
  Cor complementar usada em elementos secundários, ícones ou detalhes visuais.  
  Exemplo padrão: **#48DB74**

---

## **Tema Escuro**

Permite ativar e configurar o visual do aplicativo quando o tema escuro estiver habilitado.

* **Ativar tema escuro:**  
  Habilita ou desabilita o uso do tema escuro no app.

Quando ativado, as seguintes configurações ficam disponíveis:

* **Cor Principal:**  
  Cor principal aplicada em componentes de destaque no modo escuro.  
  Exemplo padrão: **#082535**
* **Cor Secundária:**  
  Cor complementar utilizada para elementos secundários e realces no modo escuro.  
  Exemplo padrão: **#A4D100**
