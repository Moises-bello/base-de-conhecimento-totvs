**Dúvida**  
Como bloquear acesso de um funcionário ao App Meu RH?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
É possível bloquear manualmente o acesso de um funcionário ao App Meu RH.  
  
Para isso, acesse o módulo **53 - SIGAAPD do Protheus e, na rotina Atualizações -> Participantes -> Cadastro**, localize o funcionário, acesse a opção de "Alterar" e localize o campo abaixo:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/14625497016855)  
  
Este campo, indica para o App Meu RH, se o cadastro daquele funcionário, estará ativo para acesso ao App, se o campo estiver como Não, o funcionário não terá acesso, até que o campo retorne para a opção SIM.
