# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Totvs Educacional. |
| **Função:** | Geração de Lançamento. |
| **Situação/Requisito:** | Existem casos que o lançamento está gerado com um dado bancário, e o aluno solicitada que a parcela seja alterada para outro dado bancário diferente. Desta forma, é necessário cancelar o lançamento e gerar novamente para em um dado bancário diferente solicitado pelo aluno. |
| **Solução/Implementação:** | Otimização no processo de geração de lançamentos para atualizar os dados bancários ao regerar lançamento que estão cancelados conforme cadastro no default de dados bancários. Essa otimização também irá atualizar a conta caixa ao regerar lançamento que estão cancelados. |
