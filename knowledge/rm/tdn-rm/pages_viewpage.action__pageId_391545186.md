# Ordenação de disciplinas na tela de Nota/Falta por etapa do Corpore.NET

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Nota/Falta por etapa |
| **Situação/Requisito:** | As disciplinas exibidas na tela de Nota/Falta por etapa no Corpore.NET ao acessar com um usuário de aluno, não eram ordenados pelo código da disciplina. Aparentando uma ordenação aleatória na visualização do conteúdo. |
| **Solução/Implementação:** | Foi aplicado uma ordenação pelo código da disciplinas, e pelo nome da disciplina na lista de exibição de Notas e de Faltas. |
