O SISTEC é o Sistema Nacional de Informações da Educação Profissional e Tecnológica, que disponibiliza mensalmente informações sobre os cursos técnicos de nível médio, suas respectivas escolas e alunos matriculados.   
    
 Como o SISTEC ainda não oferece um mecanismo automatizado para troca de informações (como acontece com o CENSO) será incorporado ao book de relatórios do TOTVS Educacional um conjunto de relatórios que tem como finalidade facilitar o processo de cadastro no SISTEC.  
    
 Os relatórios criados foram:

|  |  |  |
| --- | --- | --- |
| **Código** | **Nome** | **Descrição** |
| EDUREL0065 | SISTEC - Unidade de Ensino | Este relatório lista as unidades de ensino com seus respectivos diretores e níveis de ensino. |
| EDUREL0066 | SISTEC – Cursos | Este relatório lista os cursos disponibilizados pelas unidades de ensino. |
| EDUREL0067 | SISTEC – Ciclo de Matrículas dos Alunos | Este relatório lista os alunos matriculados nas matrizes aplicadas das unidades de ensino. |
| EDUREL0068 | SISTEC – Turmas Oferecidas – PRONATEC | Este relatório listas as turmas disponibilizadas. |
| EDUREL0069 | SISTEC – Solicitação de inscrição da IE no FIES | Este relatório consolida as informações necessárias para solicitar a inscrição no FIES a unidade de ensino. Que precisa preencher alguns formulários com informações sobre a mantenedora, corpo dirigente, corpo docente, estrutura curricular e estrutura institucional. |

   
 A parametrização dos dados, está disponível no mesmo cadastro dos dados do CENSO, que agora passa ter o nome de "Dados para o CENSO Escolar e SISTEC".
