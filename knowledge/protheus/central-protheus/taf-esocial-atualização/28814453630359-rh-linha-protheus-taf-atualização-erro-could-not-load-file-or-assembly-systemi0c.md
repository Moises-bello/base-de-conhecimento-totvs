Ao realizar a atualização do TAF (Segregado) utilizando o novo atualizador TAF, é apresentado o erro:

**Could not Load file or assembly 'System.I0.Compression**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28814502171415)

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - ATUALIZAÇÃO - Todas as versões  
  
**Solução**Para o erro apresentado durante a atualização do TAF (segregado), é necessário instalar o Net Framework para Windows:

Link para download e orientação:

[Instalador offline do Microsoft .NET Framework para Windows](https://support.microsoft.com/pt-br/topic/instalador-offline-do-microsoft-net-framework-4-8-para-windows-9d23f658-3b97-68ab-d013-aa3c3e7495e0)

\*\*Importante: Após a instalação reiniciar o **servidor**.
