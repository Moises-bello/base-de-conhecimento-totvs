## **01. VISÃO GERAL**

Essa funcionalidade deve ser utilizada para visualizar/imprimir as guias Tiss exigidas pelos convênios.   
Para que as guias tenham os campos exibidos corretamente, deve-se preencher os campos correspondentes no atendimento do paciente.  
O sistema exibirá os tipos de guias e então, basta selecionar quais se deseja imprimir.

Exemplo de Utilização

## **02. EXEMPLO DE UTILIZAÇÃO**

* No menu Faturamento | Faturamento para Convênios | Elaboração de Contas, selecione um atendimento para um convênio que utilize o padrão ANS - Tiss
* Selecione uma parcial, clique em Processos e selecione a opção Imprimir Guia no padrão ANS - TISS
  + Selecione a opção de Imprimir ou visualizar
  + Selecione os tipos de guias
  + Clique em Avançar e Executar
  + As guias serão visualizadas/impressas de acordo com os relatórios parametrizados em Cadastros | TISS |  Versão TISS.
  + Esta funcionalidade só aceita os relatórios feitos no TOTVS ReportsIMPORTANTE!
