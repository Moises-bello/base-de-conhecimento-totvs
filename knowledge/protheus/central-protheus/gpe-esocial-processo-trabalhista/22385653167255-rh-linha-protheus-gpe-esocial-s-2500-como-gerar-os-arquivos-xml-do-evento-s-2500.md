![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22385697860759) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como gerar os arquivos XML do evento S-2500 (Processo Trabalhista) no modulo SIGATAF para análise?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**

**1.** Acesse no modulo SIGATAF (84) o caminho: **Atualizações > Eventos eSocial > Não Periódicos > Processo Trabalhista** (TAFA608).  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/22385653146135)  
  
**2.** Clicar no botão Filtro Processo/CPF e filtre o Processo e/ou CPF que deseja gerar o XML.

* Quando o sistema localizar o trabalhador clique no botão **XML ERP** **x TAF**;
* Quando for apresentada a janela com os XMLs clique em **Gerar XML ERP** e **Gerar XML TAF**, salvando no local de sua preferência.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22385653147287)  
  
**3.** Caso o suporte tenha solicitado esses arquivos encaminhe no ticket os dois arquivos gerados.
