**Dúvida**Como gerar DARF com código de recolhimento diferente de 0561?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.  
  
**Solução**

No padrão quando o campo destacado abaixo está em branco, o sistema gera a DARF com o código de recolhimento 0561, porém para prestadores de serviços são utilizados outros códigos. Desta forma o campo abaixo **deverá ser preenchido com o código de recolhimento**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028161592)

Após isso, na geração da Darf o sistema irá gerar o relatório de forma unificada

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028157491)

Porém as Guias estarão separadas
