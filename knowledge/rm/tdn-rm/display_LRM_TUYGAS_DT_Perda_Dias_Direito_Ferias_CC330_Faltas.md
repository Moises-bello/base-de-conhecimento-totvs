# PERDA DE DIAS DE DIREITO DE FÉRIAS DEVIDO A FALTAS NO CC 330

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Férias* |
| **Situação/Requisito:** | *No cálculo da rescisão quando o funcionário possui férias proporcionais, e o periodo aquisitivo vence com a projeção do aviso previo indenizado, a perda de dias de direito devido a faltas não está sendo calculada corretamente no evento de CC 330, FÉRIAS PROPORCIONAIS SEM AVISO PRÉVIO.* |
| **Solução/Implementação:** | *Ajuste no evento de CC 330 para tratar corretamente a perda de dias de direito, quando ocorrem faltas no decorrer do periodo aquisitivo do funcionário.* |
| **Chamados   relacionados:** | *TUYGAS, TVAMAD* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
