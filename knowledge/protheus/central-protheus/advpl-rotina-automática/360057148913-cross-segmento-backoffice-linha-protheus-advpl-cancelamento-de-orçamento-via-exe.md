Dúvida**É possível utilizar o cancelamento de orçamento via ExecAuto MATA415?  
  
**Ambiente**Protheus – ADVPL– A partir da versão 12.  
  
**Solução**

Não é possível executar o cancelamento de orçamentos via ExecAuto.  
Porém existe a configuração para cancelamento automático de orçamentos no padrão da rotina.

Opções disponíveis via rotina automática MATA415:  
3- Incluir / 4- Alterar / 5- Excluir
