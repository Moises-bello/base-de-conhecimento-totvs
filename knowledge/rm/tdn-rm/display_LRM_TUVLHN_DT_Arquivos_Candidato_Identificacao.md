# ARQUIVOS DO CANDIDATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Processo Seletivo* |
| **Função:** | *Arquivos do candidato* |
| **Situação/Requisito:** | *Quando o candidato utiliza a opção de enviar arquivos, é exibido todos os arquivos já enviados por ele, sem identificar qual o processo seletivo do arquivo, gerando confusão, pois se o candidato tentar enviar para a área ofertada o mesmo arquivo, o sistema não permite.* |
| **Solução/Implementação:** | *Foi feito um ajuste na tela de arquivos, para mostrar qual é o processo seletivo de cada arquivo, também foi inserido um campo na tela que irá mostrar qual é o processo seletivo da área de interesse do candidato, facilitando assim a identificação do processo seletivo que está sendo feito o envio do arquivo.* |
