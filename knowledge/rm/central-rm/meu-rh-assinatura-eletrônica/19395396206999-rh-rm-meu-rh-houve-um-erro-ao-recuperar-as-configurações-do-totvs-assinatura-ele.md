**Ocorrência**  
Ao acessar o Menu Totvs Assinatura Eletrônica é apresentado o erro 'Houve um erro ao recuperar as configurações do Totvs Assinatura Eletrônica'  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - Meu RH - A partir da versão 12.1.2302.164  
  
**Causa**  
O Erro abaixo é apresentado devido a ausência ou erro no cadastro do usuário(e-mail)/senha publicador no grupo de quiosque utilizado pelo usuário do Meu RH.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19448307298583)  
  
**Exemplo:** e-mail incorreto, espaço em branco,  caracteres especiais, senha incorreta ou o usuário é um usuário de **SERVIÇO.**  
  
**Solução**  
Informar no grupo de quiosque modulo Folha de Pagamento etapa Assinatura eletrônica o e-mail e a senha do usuário publicador da plataforma TAE que será utilizado para integrar os documentos do RM com o TAE **(Não pode ser USUÁRIO DE SERVIÇO).**  
  
Modulo **Folha de Pagamento / aba configurações / parametrizador / RM Portal / Totvs Assinatura Eletrônica.**  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19395363450775)  
  
Para cadastro de um usuário com nível de publicador na plataforma TAE acesse: [Fluxo Administrador TAE(Totvs Assinatura Eletrônica).](https://tdn.totvs.com/display/public/TAE/Manual+Operacional#deck_gestao--440824956)  
  
**Importante:** Somente serão apresentados para o usuário do Meu RH os documentos publicados pelo usuário publicador informado no seu grupo de quiosque.
