**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24581421103383)** Tempo aproximado para leitura: **00:01:30 min****Ocorrência**Sistema não calcula adiantamento para funcionários admitidos no mês  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da Versão 12.  
  
**Causa**Esse incidente ocorre quando a **data de pagamento** informada no **cadastro de períodos** para o roteiro **ADI** é menor que a data de admissão do funcionário  
  
**Solução**Para verificar se o cadastro de períodos está correto, realize os seguintes passos:  
  
**1.** Acesse **Atualizações -> Definições de Cálculo -> Períodos**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018991301)

**2.** Dentro do período em aberto, verifique se a **data de Pagamento** do Roteiro **ADI** esta **inferior** a data da admissão do (s) funcionário (s). Caso esteja, será necessário alterará-la.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500018991521)

Após realizar o ajuste, recalcule o adiantamento.
