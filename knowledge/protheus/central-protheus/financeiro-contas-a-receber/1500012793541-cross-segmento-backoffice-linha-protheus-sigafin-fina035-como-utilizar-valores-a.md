**Dúvida**  
Como utilizar valores acessórios no Contas a Receber?  
  
**Ambiente**  
Cross Segmento - Backoffice Linha Protheus - Financeiro - A partir da versão 12.1.17  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:  
1. Cadastre os **Tipos de Valores Acessórios**, acessando o menu **Atualizações>Cadastros>Tipos de Valores** ***Acessórios***:

![](https://tdn.totvs.com/download/attachments/311631483/image2017-11-7_19-31-38.png?version=1&modificationDate=1510093898000&api=v2)

2. Por meio do menu de contexto da **rotina de Títulos a Receber** (**FINA040**), é possível vincular um **Título** **a Receber** previamente cadastrado com algum **Tipo de Valor Acessório** pré-definido. Para isso, basta posicionar o título ao qual se deseja vincular e, em seguida, selecionar a opção "*Valores Acessórios*" no menu de contexto, conforme exemplo abaixo:  
![](https://tdn.totvs.com/download/attachments/311631483/image2017-11-7_19-56-12.png?version=1&modificationDate=1510095372000&api=v2)  
![](https://tdn.totvs.com/download/attachments/311631483/image2017-11-7_19-56-52.png?version=1&modificationDate=1510095412000&api=v2)

Atenção: Ao tentar incluir um novo valor acessório, o sistema verificará se já existe outro registro com o mesmo código e saldo. Caso seja identificado, será apresentada a mensagem de ajuda F040VACOD, impedindo a inclusão do novo registro.
