# SALÁRIO COMPOSTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Funcionários | Salário Composto* |
| **Situação/Requisito:** | Ao realizar a alteração de salário composto por centro de custo a data informada no campo Data da mudança não é considerado no histórico. Após a alteração o histórico é preenchido com a última data de alteração presente no registro principal do salário composto. |
| **Solução/Implementação:** | Ajustado o processo de composição salarial para salvar a data de mudança do centro de custo. |
