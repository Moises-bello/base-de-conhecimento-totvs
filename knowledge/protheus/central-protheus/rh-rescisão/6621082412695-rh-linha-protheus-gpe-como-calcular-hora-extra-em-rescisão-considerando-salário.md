![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26764553509271) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como calcular hora extra em rescisão considerando salário base mais gratificação (verba sem ID)?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para calculo de hora extra considerando salário base mais gratificação, a verba de gratificação deve estar com Sim para Incorpora Salário e a verba hora extra como campo Base Cálculo com Salário Incorporado. Deste modo o sistema considera como base para cálculo da verba hora extra a soma do salário base mais gratificação.  
  
Verba gratificação campo **Incorpora Salário** com **SIM**:**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6621043428759)**

Verba hora extra campo **Base Cálculo** com **2-Salário Incorporado**:**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/6621059448983)**
