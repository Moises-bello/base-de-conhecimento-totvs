# Movimento de Convênio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Movimento de Convênio |
| **Situação/Requisito:** | Na funcionalidade de movimentação de convênios, acessível através do menu: “Administração de Pessoal>Movimento>Movimentação dos Funcionários”, existe um problema ao se alterar o código do serviço manualmente. Mais especificamente, durante o cadastramento de uma nova movimentação, ao inserir um código do serviço do convenio e alterá-lo, manualmente, antes de salvar a modificação, o sistema acata o primeiro código e não o mais recente. |
| **Solução/Implementação:** | Foram realizados ajustes para garantir que qualquer alteração no lookup, “Código do serviço do convênio”, atualize as informações da tela corretamente. |
