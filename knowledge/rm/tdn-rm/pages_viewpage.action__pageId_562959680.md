O processo de excluir últimas medições está disponível a partir da versão 12.1.31 e foi criado no intuito de facilitar a exclusão de forma global das últimas medições cadastradas no sistema.

Para executar o processo é preciso primeiro, conceder permissão no perfil do usuário como mostra a imagem abaixo:

Após isso basta acessar o processo em **Medidor / Processos / Excluir últimas medições.**

O processo somente irá excluir as últimas medições cadastradas para os medidores selecionados.

Não é possível excluir uma medição que não seja a última cadastrada. Também não é possível excluir uma medição que já esteja integrada num fechamento.
