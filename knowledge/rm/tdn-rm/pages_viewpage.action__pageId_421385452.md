Facilitando a utilização da Apropriação é possível realizar importação dos dados para preenchimento das informações.  
    
 Para realizar o processo basta acessar o menu: Projeto | Conversões | Importar Apropriação de Serviço/Insumo via Excel e preencher os campos solicitados na tela que será aberta.  
 Os campos Código da Tarefa e Quantidade, que estão em negrito são obrigatórios. Porém é possível importar também:

* Código do Insumo
* Data da movimentação
* Data da Apropriação
* Código do funcionário
* Código do Func. Resp.
* Código Pessoa
* Código Pessoa Resp.
* Código do Evento
* Código do Bem
* Preço
* Moeda
* Código do Motivo de Improdutividade
* Observação

**Observação** O campo Código do Motivo de Improdutividade no momento da inclusão ou na edição desde que a tarefa não seja vinculada com Mobilidade ou Timesheet.  
  
 Para que a coluna Código do Motivo de Improdutividade seja importado com sucesso, o código informado na coluna referente a este campo na planilha a ser importada deverá estar cadastrado no sistema através do menu: Cad. Gerais | Motivos de Improdutividade.  
  
  
**Como realizar a importação** 1º - Acessar: Projeto | Conversões | Importar Apropriação de Serviço/Insumo via Excel; 2º - Na tela de importação, informe o caminho do arquivo de Importação; 3º - O campo Linha Inicial é utilizado devido a necessidade do arquivo Excel ter um cabeçalho ou identificação dos dados da importação, portanto deve ser indicado pelo usuário onde será o início da importação; 4º - Informar nos campos que serão importados o valor da coluna em que a informação está definida no arquivo Excel.

**Exemplo:** Se o Código da Tarefa no arquivo Excel está localizado na coluna A do arquivo, na tela de importação no campo Código da tarefa será inserido o valor 1.
