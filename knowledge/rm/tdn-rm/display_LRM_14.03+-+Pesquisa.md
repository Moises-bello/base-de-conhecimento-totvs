14.03.01 - Pesquisa ao Acervo  
    
 O objetivo desta etapa é definir as características gerais da pesquisa ao acervo.  
    
 **Não fazer diferenciação entre (Ç e C):** Este parâmetro define que ao realizar uma pesquisa, o sistema irá considerar, no texto da pesquisa, **C** e **Ç** como caracteres iguais.  
    
 **Retornar exemplares baixados:**Este parâmetro define que exemplares com o status "Baixado" também serão apresentados na listagem dos resultados da pesquisa.  
    
 **Normalizar texto digitado na pesquisa pelo autor:** Este parâmetro define que ao digitar o texto para uma pesquisa por autor, o texto será normalizado para realizar a pesquisa.  
    
 **Não exibir exemplares com situação que não permite empréstimo:** Este parâmetro define que na pesquisa não serão apresentados exemplares com situação que não permite empréstimo.  
    
    
 **Atenção**  
    
 Ao normalizar o texto digitado na pesquisa, o sistema irá buscar apenas por autores que estejam com o nome normalizado no cadastro de autores, ou seja, se um autor estiver cadastrado no sistema com seu nome fora do padrão normalizado, caso seja realizada uma pesquisa em que o usuário informe seu nome, ao normalizar o texto da pesquisa, este autor não será encontrado.  
    
    
 **Pesquisa ao acervo - Visualização dos detalhes:** Etapa destinada a configurar os campos disponíveis para pesquisa e os campos de exemplar exibidos no resultado da pesquisa. Em "Campo disponíveis para pesquisa" é selecionado os campos disponíveis na caixa "Busca por" para consulta geral e avançada. E em "campos exemplar" é definido quais campos serão visualizados quando for exibido os detalhes de um exemplar retornado em uma consulta.  
    
 14.03.02 - Pesquisa no Portal  
    
 O objetivo desta etapa é definir as características da pesquisa no portal.  
    
 **Filtro por unidade na Web:** Este parâmetro define qual o filtro de unidades será utilizado para pesquisa (Todas as unidades, Unidade logada), fazendo com que o sistema pesquise na(s) unidade(s) correspondente(s) ao filtro.  
    
 14.03.03 - Pesquisa Pública  
    
 O objetivo desta etapa é definir as características gerais do acesso público à pesquisa do portal.   
    
 **Gerador de URL:** Este parâmetro possui um campo para que o usuário informe o endereço físico do site correspondendo ao diretório Corpore.Net. Após o campo estar informado, basta clicar no botão "Gerar URL", para que seja gerada uma URL a ser utilizada para acesso da pesquisa pública.  
    
 Exemplo:   
    
 http:/ /www.instituicao.com.br/corpore.net/Source/Bib-Biblioteca/Public/BibFirewall.htm?CodColigada=1&CodFilial=1&CodUnidade=5  
 **Título e imagem:** Nesta etapa é possível definir se serão exibidos título e imagem personalizados no portal e no modo de consulta quiosque.
