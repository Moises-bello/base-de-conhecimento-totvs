**Dúvida**Como incluir manualmente Férias indenizadas ID 0086 ou Média Férias Indenizadas ID 0248 na rescisão em lançamento por funcionário para correta impressão no TRCT?

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

1. No cálculo da Rescisão, em Lançamentos por Funcionários, ao incluir verba de ID 0086-Férias Indenizadas ou 0248-Média Férias Indenizadas é necessário preenchimento do campo **Num identificador** com o período aquisitivo do funcionário no formato **AAAAMMDD - AAAAMMDD** (**deve conter espaços entre o traço**), preencha também o campo **Horas** com a quantidade respectiva aos **avos** Ex: 4.12 ( 4/12 avos):

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360080018854/mceclip0.png)

Após os lançamentos as verbas serão carregadas para o TRCT com o período aquisitivo.
