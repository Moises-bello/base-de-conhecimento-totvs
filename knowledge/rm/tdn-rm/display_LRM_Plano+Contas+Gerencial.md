**Foram mapeados dados pessoais ou sensíveis que estão de acordo com a Lei Geral de Proteção de Dados Pessoais. O cumprimento de obrigação legal é hipótese legítima do tratamento dos seus dados conforme a Lei n° 13.709/2018.**

O Plano de Contas Gerencial tem por objetivo facilitar a contabilização da distribuição dos custos para contas específicas de rateio que deverão ser cadastradas neste Plano Gerencial. Este plano de Contas facilitará em muito o rateio contábil. Ao fazer um lançamento, é só informar as contas gerenciais e o percentual que o sistema rateará automaticamente os valores para você.

A opção "Enviar para o SPED Contábil" permite que a conta gerencial seja enviada para o arquivo referente ao SPED Contábil. Para que esta opção esteja disponível deve-se selecionar em Ambiente/Parâmetros/RM Saldus/Rotinas Legais/SPED Contábil/SPED Contábil 1/2, no parâmetro Considerar para o Centro de Custo, a opção Conta Gerencial.

**Obervação**

Caso existam associações de contas e centro de custo ao plano de contas referencial (SPED Contábil), ao selecionar a opção "Conta Gerencial" e concluir a parametrização, elas serão perdidas. Para desmarcar a opção "Enviar para o SPED Contábil" de uma conta gerencial deve-se verificar se a mesma não está associada a alguma conta paralelo (SEPD Contábil). Para alterar, excluir ou incluir um Plano de Contas Gerencial utilize a barra de ferramentas.

**Campos Complementares**

Nesta pasta serão visualizados os campos complementares existentes e ativos que estão vinculados à conta contábil, para que você faça aqui o preenchimento de cada campo complementar como queira. Ao cadastrar os campos complementares, você pode definir Valores (informações) que servirão como default para o preenchimento dos campos. Caso você tenha definido valores *defaults* para os campos, ao acionar este botão os campos serão preenchidos automaticamente com os valores definidos anteriormente no cadastro do campo complementar sem que você tenha que ir campo a campo digitar manualmente as informações.

**Observação**

Se você acionar este botão e confirmar, caso já existam informações cadastradas nos campos complementares, estas serão sobrepostas pelos Valores que estiverem como default no cadastro dos campos complementares. O botão <Excluir> que se encontra nesta pasta, NÃO irá excluir o campo complementar, este botão serve para excluir a conta contábil, se você clicar neste botão e não existir nenhum lançamento para esta conta a mesma será excluída.

**Atenção**

Para excluir um campo complementar de conta você deverá acessar Cadastros \ Campos Complementares \ Contas Contábeis (ou Gerenciais), selecionar na pasta "Lista de campos complementares" o campo a ser excluído e clicar no botão <Excluir> (este procedimento não se trata necessariamente de uma exclusão, pois este campo NÃO será removido da Base de Dados, ele somente se tornará um campo Inativo e este poderá ser ativado novamente).
