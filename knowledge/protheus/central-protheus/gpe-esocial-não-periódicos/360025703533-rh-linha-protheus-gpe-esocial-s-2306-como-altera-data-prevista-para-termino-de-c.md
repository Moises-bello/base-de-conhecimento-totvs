**Dúvida**  
Como alterar data prevista para término **(dtPrevTerm)** de contrato para estagiário no SIGAGPE?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as Versões  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

**1.** Acesse o cadastro do estagiário dentro do modulo **SIGAGPE**;

**2.** Dentro do cadastro clicar no botão **Outras Ações** e em seguida na opção **Inf. Exclusivas Estagiário**;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28088590395927)

**3.** Preencher o campo **Dt Fim Estag;**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28088590401047)

Dessa forma a **tag dtPrevTerm**será preenchida no evento **S-2306** com a nova data de termino para contrato do estagiário.
