# COPIAR PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Copiar processo seletivo |
| **Situação/Requisito:** | Ao executar o processo "Copiar processo seletivo" a partir de outro módulo diferente do Educacional, o sistema gravava o código da filial igual a zero e não permitia visualizar o processo gerado na filial de origem. |
| **Solução/Implementação:** | Alterado processo “Copiar processo seletivo“ quando for executado de outro módulo diferente do Educacional, será gravado o código da filial corrente. |
