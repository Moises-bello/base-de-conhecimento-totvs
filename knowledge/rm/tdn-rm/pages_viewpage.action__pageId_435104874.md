Os Cadastros de Aluguel são essenciais para a utilização das rotinas de Aluguel. Inicialmente, estas são as Pré-Condições para a inclusão dos Cadastros do Aluguel:

* **Gestão de Estoque Compras e Faturamento**
  + Incluir Natureza Financeira a Pagar - Analítica
  + Incluir Natureza Financeira a Receber - Analítica
* **Financeiro**
  + Incluir Cliente e Fornecedor
  + Incluir Conta-Caixa
  + Incluir Tipo de Documento a Receber
  + Incluir Tipo de Documento a Pagar
  + Incluir Tipo de Documento a Pagar para Repasse
* **Contabilidade**
  + Incluir Centro de Custo
* **Fiscal**
  + Incluir Departamento
* **Globais**
  + Incluir Índice Para Reajuste

Atualmente os Cadastros de Aluguel estão distribuídos da seguinte forma:
