# Permissão "Filtros Relatórios":

---

No cadastro de Perfis, na aba "Acesso a Menus", foi criada uma separação entre as permissões "Filtros Globais" e "Filtros Relatórios". Para melhor usabilidade de restrição para filtros.

     De acordo com a restrição aplicada acima, para um usuário associado a esse Perfil, o funcionamento dos filtros ocorrerá da seguinte forma:

1Filtros Globais

Em telas abertas pela MDI onde há o cadastro de um Filtro Global, as opções de alteração serão bloqueadas para o usuário, no entanto, o botão "Novo" continuará ativo.

Ao criar um novo Filtro, este será disponiblizado para alterações, sendo exibido em "Meus Filtros".

Filtros Relatórios

Em uso de Filtros para Relatórios, no Lookup, o filtro será exibido abaixo de "Filtros Globais", permitindo que o usuário o modifique.
