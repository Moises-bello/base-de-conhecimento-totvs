**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Compras- Versão 12

**Ocorrência**Quando um XML é reprocessado, o código de erro COM053 é registrado tanto na tela do Monitor quanto na tabela CKOCOL (campo CKO\_CODERR)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20447092849687)

Não há cadastro de conversão da unidade **"Unidade de Medida"** para o produto **"Produto"**. O cadastro é obrigatório quando MV\_CSDXML = .T."

**Solução**

Para garantir a consistência, verifique se o cadastro de produto x fornecedor (A5\_UNID) está devidamente preenchido e se o cadastro do Fator de Conversão de Unidade de Medida (ESTA0001)
