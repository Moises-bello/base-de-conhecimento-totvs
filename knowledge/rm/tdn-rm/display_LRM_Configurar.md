**Configurar**

Para fazer uso de uma integração deve-se primeiro realizar as configurações necessárias para que a mesma esteja disponível e possa ser utilizada.   
 As integrações devem ser parametrizadas através do Assistente de Configuração: RM.exe | Integração | Ferramentas | Configurar  
    
 É necessário fornecer usuário e senha para conexão com o Banco de Dados e após avançar, selecionar a Integração que deseja configurar. O assistente irá realizar as configurações automaticamente.  
    
 ***Nota:*** *Quando forem liberadas atualizações de uma integração, e a mesma está sendo utilizada, é necessário que o configurador seja executado novamente.*
