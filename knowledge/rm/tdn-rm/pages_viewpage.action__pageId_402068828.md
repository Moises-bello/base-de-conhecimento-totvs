# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1 |
| **Ocorrência:** | Consulta de Transferências de Controle |
| **Ambiente:** |  |
| **Passo a passo:** | **Definição do processo:**  Todas as [transferências de controle](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.TransferenciaControle.aspx) realizadas com sucesso poderão ser visualizadas na tela de Consulta de Transferência.    **Disponível em:**  Menu Operações Patrimoniais | Consulta Transferência de Controle.      Esta tela permite visualizar todos os detalhes da transferência citados abaixo: O Código da Transferência, a data em que a mesma foi realizada, o número do documento informado durante o processo, o usuário, data de criação e o texto informado no campo Observação.  Em “Anexos” estarão as informações do [patrimônio](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Patrimonio.aspx) e dos destinos como o código do patrimônio, a [filial](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Filial.aspx), o [responsável](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Responsavel.aspx), o [departamento](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Departamentos.aspx), o [centro de custo](http://wikihelp.totvs.com.br/WikiHelp/CTB/CTB.cadastroCentroCustos.aspx) e a [localização](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Localidade.aspx).      **Observações:** Para a exclusão das ocorrências de Transferência de Controle | Selecione a ocorrência | Processos | Cancelamento de Transferência de Controle. |
