Através da Correção de Apontamento é possível corrigir separadamente cada apontamento realizado na atividade, fazendo qualquer tipo de alteração nas quantidades apontadas da atividade, materiais, recursos e data/hora de alocação, índices de registro de produção e paradas de atividade.   
Na aba Apontamento(s) é apresentado o histórico de todos os apontamentos realizados na atividade, registrado a cada apontamento parcial da atividade.   
Nesse histórico, cada linha registra todos os dados de cada apontamento feito.   
Para realizar a correção deve-se navegar entre os registros de apontamento e escolher o apontamento que se deseja alterar, as demais abas apresentarão os dados conforme o registro de apontamento selecionado.

***Dica***: É possível navegar entre as abas na tela de apontamento utilizando atalhos do teclado, os mesmos são:

|  |  |
| --- | --- |
| **Aba** | **Atalho** |
| Apontamentos | ALT + A |
| Cabeçalho | ALT + D |
| Material Consumido | ALT + M |
| Perda Material | ALT + P |
| Subproduto Gerado | ALT + S |
| Trabalho Efetivo | ALT + T |
| Registro de Produção | ALT + Q |
| Parada de Atividade | ALT + I |
