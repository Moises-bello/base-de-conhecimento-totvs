Dúvida**Precisa instalar o CNAB Cloud? Como utiliza-lo?

**Solução**No CNAB Cloud podemos gerar um modelo de layout mais atual ao layout do banco informado ( Remessa e Retorno ) Modelo 2 - 240 Posições, para utilização das rotinas abaixo:

**Configuração CNAB**

CFGX049B - Cnab Cloud  
CFGX049 - CNAB Modelo 2

**Utilização do CNAB**

FINA420 - Arquivo envio ao banco ( Remessa )  
FINA430 - Arquivo de Retorno CNAB  
FINR650 - Relatorio de Retorno CNAB
