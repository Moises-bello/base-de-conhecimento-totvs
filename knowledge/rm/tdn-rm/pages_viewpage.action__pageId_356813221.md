# REMETENTE DO E-MAIL DE INSCRIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Avaliação e Pesquisa |
| **Função:** | Enviar e-mail de inscrição |
| **Situação/Requisito:** | Caso o envio de e-mail seja parametrizado no tipo e-mail do remetente como "E-mail alternativo", o sistema envia ao lado do remetente um texto escrito: “Em nome de [corpore@rm.com.br](mailto:corpore@rm.com.br)” |
| **Solução/Implementação:** | Foi substituído o e-mail fixo [corpore@rm.com.br](mailto:corpore@rm.com.br) pelo e-mail default parametrizado no sistema quando for utilizada a opção de e-mail alternativo. |
