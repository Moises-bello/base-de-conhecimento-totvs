![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18440163928471) Tempo aproximado para leitura: **02:00 min****Dúvida**Precisamos atualizar o campo "**C7\_TPFRETE** (Tipo de Frete)" para que a informação seja registrada na Nota de Entrada de Importação.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – A partir da versão 12.1.33.

**Solução**Dentro do Produto Padrão, o SIGAEIC não envia tal informação para preenchimento do campo "**C7\_TPFRETE** (Tipo de Frete)". Neste caso, será necessário o tratamento via Ponto de Entrada.
