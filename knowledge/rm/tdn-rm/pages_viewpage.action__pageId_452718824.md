**Assistente Lançamento Exames**   
O Assistente de Lançamento de Resultados permite que os resultados dos exames sejam lançados para as pessoas cadastradas no sistema de acordo com as configurações a serem definidas nos passos do assistente. O assistente apresenta os seguintes passos:  
1) Dados da Consulta Neste passo deverão ser informados os dados da consulta como: código, tipo de consulta, data, nome e registro do médico.  
**Observação:** - Se o exame estiver vinculado a uma Consulta, o processo não vai iniciar com a etapa "Dados da Consulta". E ao final da execução do processo, a Consulta poderá ter o seu status alterado.  
2) Seleção de Pessoas Neste passo deverão ser selecionadas as pessoas que terão exames lançados. O usuário terá a opção de criar filtros para selecionar as pessoas desejadas.  
3) Seleção de Exames Neste passo deverão ser selecionados os exames para o lançamento. Poderão ser selecionados por tipo de exame, os exames pendentes, os exames agendados ou outros exames. Ao avançar para o próximo passo o sistema exibe as pessoas e os respectivos exames relacionados através do passos anteriores.   
Para inserir o resultado do exame, basta dar um duplo clique sobre o nome do exame desejado, o sistema irá abrir uma janela para que os dados do exame sejam preenchidos. Os campos tipo de exame, data do exame e entidade são de preenchimento obrigatório.  
Caso algum dos exames selecionados para o lançamento não tenha os dados do resultado preenchido, o assistente não permitirá avançar para o próximo passo.  
4) Concluir Lançamento de Exames O sistema conclui o lançamento dos exames e inclui um registro com os dados da consulta e os exames realizados no Prontuário do funcionário. Caso o exame lançado seja igual a um exame que esteja pendente para o funcionário, o mesmo não será mais exibido na aba de exames pendentes.  
**Observação** Caso a opção "Replicar informações para todos os exames?" esteja marcada, todos os exames lançados neste processo terão os mesmos dados da consulta.  
**Atenção** Para qualquer ícone desabilitado, verifique com o Supervisor as permissões do usuário em questão em Cadastros | Segurança | Perfis | pasta Acesso a Menus.
