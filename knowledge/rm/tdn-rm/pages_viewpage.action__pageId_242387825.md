# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Estorno da contabilização de um contrato* |
| **Situação/Requisito:** | *O sistema não consegue estornar uma parcela mensal que tenha sido estornada anteriormente e depois contabilizada. Assim, ao estornar a primeira parcela mensal com essas condições, o sistema também não estorna o contrato por ainda existirem parcelas mensais contabilizadas.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de estorno da contabilização por competência de forma que o sistema passe a suportar o estorno de contratos que já tenham sido estornados anteriormente.* |
