**Dúvida**Como aumentar o tamanho de casas do campo de Unidade de Medida no Protheus?  
  
**Ambiente**Microsiga Protheus - Estoque/Custos - A partir da versão 12.1.17  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
1. Acessar ao Configurador (SIGACFG);  
2. Acesse Base de Dados -> Dicionário -> Base de Dados;  
3. Acesse Dicionário de dados -> Grupo de campos -> Unidade de medida e clicar para editar:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500003765342)

4.  Selecione o tamanho desejado da unidade de medida, sendo o mínimo 2 e máximo 10 conforme exemplo abaixo:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360102647114)

5. Após isso, basta salvar as alterações clicando no ícone do disquete:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360102647154)
