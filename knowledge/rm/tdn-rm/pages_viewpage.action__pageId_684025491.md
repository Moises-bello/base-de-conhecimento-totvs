Quando é feito qualquer alteração na Movimentação de Eventos dos Funcionários, seja manual ou por processo, é inserido um registro de log na tabela PFHSTENTMOV. O mesmo pode ser visualizado através da Manutenção de Eventos do Funcionário | Log's ou Pelo Menu Histórico de Alterações.

Neste log é armazenado os valores anterios a alteração / exclusão do registo:

Pelo Menu de Histórico de Alterações é possivel filtar pelo status, origem, chapa, períodos, etc de vários registros, sem precisar acessar cada Movimentação de Eventos dos Funcionários de cada funcionário:

false

Não é permitido incluir, alterar ou excluir registros deste cadastro. O mesmo é disponível somente para visualização.
