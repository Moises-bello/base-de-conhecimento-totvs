O Book de Relatórios tem o  objetivo de otimizar o dia-a-dia dos usuários.

Os relatórios importados não poderão ser alterados, porém, o usuário terá a possibilidade executar a "Cópia" para realizar a alteração conforme a sua necessidade.

Para a parametrização, o usuário deverá ter um conhecimento prévio da estrutura da base de dados, para que os filtros sejam aplicados de forma correta e retorne a informação conforme a estrutura do relatório.

|  |  |  |
| --- | --- | --- |
| **Código** | **Nome** | **Descrição** |
| EDUPSREL0001 | Listagem de salas | O relatório retorna todas as dependências físicas situadas no(s) prédio(s) que serão utilizados nos processo(s) seletivo(s). |
| EDUPSREL0002 | Listagem de candidatos com necessidades especiais | O relatório lista todos os candidatos que possuem necessidades especiais inscritos no(s) processo(s) seletivo(s). |
| EDUPSREL0003 | Relação de Inscritos Ausentes | O relatório lista a relação dos candidatos inscritos no(s) processo(s) seletivo(s) que estiveram ausentes em dia de prova. |
| EDUPSREL0004 | Comprovante de Inscrição | Relatório gera o comprovante da inscrição do candidato inscrito no processo seletivo. |
| EDUPSREL0005 | Relação Inscritos x Vagas | O relatório lista a relação de candidatos x vaga por área de interesse ofertada. |
| EDUPSREL0006 | Ficha de Inscrição sem Boleto | Este relatório gera as fichas de inscrições anônimas, baseadas no lote de inscrições gerado pelo processo "Gerar Inscrições Anônimas". |
| EDUPSREL0007 | Relação de Controle de Impressão de Fichas | O relatório gera o controle de todas as fichas de inscrição anônimas que foram geradas pelo sistema. |
| EDUPSREL0008 | Relação Inscritos X Candidatos por Tipo de Inscrição | O relatório gera o número de candidatos inscritos x número de candidatos que efetivaram a inscrição. |
| EDUPSREL0009 | Relação de inscritos valor zero | O relatório lista os candidatos do processo seletivo que tem o valor de inscrição = 0. |
| EDUPSREL0010 | Relação de Candidatos Inscritos Geral | O relatório lista os candidatos inscritos no processo seletivo. |
| EDUPSREL0011 | Relação de Candidatos Inscritos por Curso | O relatório lista os candidatos inscritos no processo seletivo por curso ofertado. |
| EDUPSREL0012 | Relação de Candidatos Inscritos por Data | O relatório lista os candidatos inscritos no processo seletivo por data de inscrição. |
| EDUPSREL0013 | Relação de Telefones para Call Center | O relatório lista os candidatos inscritos no processo seletivo. |
| EDUPSREL0014 | Relação de Candidatos por local de prova | O relatório lista os candidatos inscritos no processo seletivo por local de prova. |
| EDUPSREL0015 | Lista de Presença | Gera a lista de presença dos candidatos por local de prova. |
| EDUPSREL0016 | Ensalamento Geral | Gera a lista de candidatos e suas alocações nas salas de prova. |
| EDUPSREL0017 | Localização de Candidatos por Sala | Informar a localização dos candidatos em salas de prova por ordem alfabética. |
| EDUPSREL0018 | Relação de Candidatos com Pendências | Lista os candidatos do processo seletivo que estão com pendências de documentos ou financeira. |
| EDUPSREL0019 | Ranking de Indicações por Aluno | Lista o ranking de alunos que foram indicados durante a inscrição do candidato |
| EDUPSREL0020 | Contagem de Ausentes por Sala | O relatório gera a lista de salas do processo seletivo para controle do número de candidatos ausente. |
| EDUPSREL0021 | Controle de Entrega de Brindes | O relatório gera a lista de alunos indicados para controle de da entrega de brindes. |
| EDUPSREL0022 | Ata de Ocorrência | O relatório gera as atas de ocorrência por local de prova. |
