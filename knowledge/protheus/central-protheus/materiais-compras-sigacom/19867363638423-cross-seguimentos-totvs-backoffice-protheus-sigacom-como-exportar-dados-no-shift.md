![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19867356109335) Tempo aproximado para leitura: **02:00 min** **Dúvida**Como exportar dados no Shift+F6 utilizando a nova interface POUI?  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Compras/GCT - Protheus - A partir da versão da release 12.1.2310.

**Solução**1-) Central de Diagnóstico, Clicar em Recursos do sistema, opção extrato das Informações, conforme o print a baixo:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19867363620759)

2-) Confirmar a rotina de exportar dados.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19867363621399)

3-) Selecione o diretorio e insira um nome para o arquivo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19867356111383)

4-) Será apresentado a mensagem de arquivo exportado conforme abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19867356112023)

5-) Na pasta que foi salvo, será possível visualizar o arquivo exportado:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/19867363622295)
