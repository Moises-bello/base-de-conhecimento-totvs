![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21986516993047) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como o sistema preenche o campo D1\_TEC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Compras- Todas as versões  
  
**Solução**

O campo D1\_TEC é utilizado pelo módulo SIGAEIC, ou seja, ele é preenchido somente quando as notas de entrada são geradas a partir do módulo SIGAEIC. O campo é gravado com a NCM informada no produto ao gerar pré-nota na rotina de Recebimento de Importação, do módulo SIGAEIC.
