**Dúvida**  
É possível realizar a importação de dados via MILE no módulo **SIGAQIE - Inspeção de Entradas**?  
  
**Ambiente**  
TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Inspeção de Entradas (SIGAQIE) - Versão 12  
  
**Solução**  
Atualmente, a importação através da ferramenta **MILE** - *Model Integration Layer Engine* não está disponível para os módulos de **Gestão da Qualidade,** incluíndo o **SIGAQIE.**

Esta limitação ocorre pois as rotinas que compõem estes módulos não foram desenvolvidas utilizando as técnicas de **ExecAuto** - Execução Automática ou a arquitetura **MVC** - *Model View Controller*, que são requisitos técnicos indispensáveis para a integração via MILE.

**Importante**  
Caso esta funcionalidade seja necessária para sua operação, orientamos registrar uma **Sugestão de Melhoria** no [**Portal do Cliente**](https://suporte.totvs.com/portal/10098/customer-portal/). Neste canal, a equipe de produto da TOTVS realiza a avaliação de novas demandas, permitindo que você acompanhe a evolução da solicitação, interaja com comentários e vote em sugestões de outros usuários através [**Central Colaborativa**](https://centraldeatendimento.totvs.com/hc/pt-br/community/topics).
