Nesta opção serão definidas as permissões de acesso a projetos por usuário.  
 Após a concessão de acesso aos projetos para cada usuário, os usuários terão acesso somente aos projetos concedidos e aos projetos que o próprio usuário inserir.

**Observações:**

A visão de usuários, utilizada para conceder permissão de acesso a projetos por usuário, deve listar somente os usuários que possuem acesso ao Totvs Obras e Projetos.  
 Só é permitida a exclusão e a Cópia de Itens de projetos que o usuário possuir acesso.

Passo a Passo:

1. Selecione os usuários que você deseja alterar a permissão de acesso a projetos.
2. Em seguida selecione no botão "Processos", a opção "Conceder permissão de Acesso a Projetos".
3. Na primeira tela do Assistente de concessão de permissão de acesso a projetos, clique em "Avançar".
4. Na segunda tela do Assistente de concessão de permissão de acesso a projetos, marque os projetos em que cada usuário possuirá acesso. Deve-se marcar para cada usuário, os projetos em que o mesmo acessará.
5. Na terceira tela do Assistente de concessão de permissão de acesso a projetos, clique em "Concluir".

**Dica:**Para marcar ou desmarcar todos os projetos no assistente de concessão de permissão de acesso a projetos, dê um clique com o botão direito do mouse na visão onde são listados os projetos.
