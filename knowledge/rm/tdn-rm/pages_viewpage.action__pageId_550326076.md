Este processo é executado a partir da tela de “Processos Seletivos”. A instituição pode utilizar este processo quando desejar reaproveitar as configurações que foram feitas para um Processo Seletivo realizado anteriormente. Ao final da execução, um novo Processo Seletivo será criado a partir do Processo Seletivo escolhido como base.

O assistente do processo ajuda o usuário a redefinir as configurações do Processo Seletivo base para adequá-las ao novo Processo Seletivo. O processo reaproveita a maioria das configurações feitas para o Processo Seletivo base sem que seja necessário redefini-las. O assistente torna mais fácil para o usuário a redefinição das  configurações que, provavelmente, ou obrigatoriamente, serão diferentes no novo Processo Seletivo.

         

Clicar no lookup para buscar o Processo Seletivo que deseja-se copiar:

     

     

Nesse passo o usuário deve informar qual será o Processo Seletivo utilizado como base. Ele também deve fornecer as informações básicas que são requeridas sempre que se cadastra um novo Processo Seletivo:

**Nome** - Deve ser informado o nome do novo Processo Seletivo.

**Instituição** - Assim como no [Cadastro de Processo Seletivo](#Cadastros_Processo_Seletivo), se o Processo Seletivo estiver sendo realizado para terceiros, este campo deve ser preenchido com uma instituição existente na tabela auxiliar “[Instituição de Ensino](#Tabela_Auxiliar_Instituição)”. A escolha de uma instituição diferente da que foi definida no Processo Seletivo base, inviabiliza a cópia das áreas ofertadas para este novo Processo Seletivo. Nesse caso, o passo de seleção de áreas ofertadas para reutilização não será exibido. Isso ocorre porque cada instituição tem as suas áreas clientes específicas.

**Arquivo do edital** - Assim como no [Cadastro de Processo Seletivo](#Cadastros_Processo_Seletivo), deve ser escolhido para este campo o arquivo do edital do novo Processo Seletivo.

Defina as datas de início e término de cada uma das etapas do novo processo seletivo

Neste passo, o usuário deve especificar o calendário do novo Processo Seletivo. As informações são validadas da mesma maneira que ocorre quando a criação do Processo Seletivo é feita pelo “[Cadastro de Processo Seletivo](#Cadastros_Processo_Seletivo)”.

Neste passo, o usuário deve escolher as áreas ofertadas a serem copiadas do Processo Seletivo base para o novo Processo Seletivo, conforme a definição dos campos:

**Áreas ofertadas utilizadas anteriormente** - Nessa lista devem ser escolhidas as áreas que serão recriadas e cujas configurações devem ser replicadas no novo Processo Seletivo. As definições para “Valor da Inscrição” e “Portaria” não são copiadas a partir do Processo Seletivo base. Os valores para estes dois campos são os mesmos definidos globalmente para o novo Processo Seletivo no passo anterior.

**Copiar também as etapas das áreas ofertadas** - se for marcado, o processo de cópia replica as definições de cada etapa presente nas áreas ofertadas base. Como as definições de etapas envolvem a especificação de datas e horários dentro do calendário do novo Processo Seletivo, será exibido como próximo passo a “Configuração de etapas”.  Esse passo adicional, serve para que o usuário consiga configurar mais facilmente a forma como as etapas serão recriadas e configuradas no novo Processo Seletivo. Se a opção não for marcada, o passo “Configuração de Etapas” nem mesmo será exibido.

**Copiar as provas definidas para cada etapa -** Quando for marcada, as provas definidas nas etapas das áreas ofertadas base, também serão copiadas. Esta opção somente estará disponível se a opção “Copiar também as etapas das áreas ofertadas” estiver marcada.

**Copiar os critérios de desempate para cada etapa -** Quando for marcada, os critérios de desempate definidos nas etapas das áreas ofertadas base, também serão copiadas. Esta opção somente estará disponível se a opção “Copiar também as etapas das áreas ofertadas” estiver marcada.

Neste passo, devem ser reconfiguradas as etapas existentes nas áreas ofertadas que serão reutilizadas. O processo só avançará para o próximo passo, se todas as etapas da lista estiverem com o status “Todos os dados foram preenchidos”.

Neste passo, devem ser escolhidas as formas de inscrições que serão copiadas para o novo Processo Seletivo a partir do Processo Seletivo base. As definições de validade para a nova forma de inscrição não serão copiadas das definições base. No novo Processo Seletivo, a validade das formas de inscrição copiadas será igual à data de início e término do período de inscrição do novo calendário.

Neste último passo, o usuário pode informar que deseja que os mesmos locais utilizados no Processo Seletivo base também sejam utilizados no novo Processo Seletivo. Além disso, ele também pode definir que o processo “[Alocar profissionais em locais do Processo Seletivo](#processo_alocar_profissionais)” seja executado na sequência. A opção de se executar o processo de alocação será dada se o a opção de copiar os locais tiver sido marcada.

**AVISO:** Existir um Processo Seletivo previamente cadastrado na base de dados é um pré-requisito para a execução do processo

E na tela do Processo Seletivo/Venda Online de Cursos será exibido o processo seletivo que foi realizado a cópia.
