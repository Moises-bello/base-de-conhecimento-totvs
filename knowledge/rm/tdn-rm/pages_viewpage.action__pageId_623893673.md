| Parâmetro |
| --- |
| **Adicionar reserva automaticamente para o corretor** Ao efetuar uma proposta, o sistema pode adicionar uma reserva para o corretor para a unidade que ele criou a proposta. |
| **Alterar a unidade para a seguinte situação quando reservada** Quando uma unidade é reservada, ela deverá mudar de situação. Este parâmetro serve para escolher qual situação usar. |
| **Alterar a unidade para a seguinte situação quando uma proposta for adicionada para ela** Quando uma unidade recebe uma proposta, ela deverá mudar de situação. Este parâmetro serve para escolher qual situação usar. |
| **Distrato: Período em dias para ler distrato de unidade no backoffice** Informe a quantidade de dias a ser subtraído da **data atual** para que o sistema possa calcular e fazer a leitura dos distratos no backoffice baseado no resultado da substração (data atual - parametro). **Atenção:** O valor máximo permitido é de 180 dias, qualquer valor superior a isso será considerado apenas os 180 dias. |
| **Enviar E-mail quando a reserva do usuário entrar em vigor** Ativa ou desativa o envio de E-mail quando a reserva entra em vigor. |
| **Enviar E-mail quando a reserva ou proposta do usuário faltar X minutos para cair** Defina em minutos quanto tempo para notificar os usuários antes que sua reserva caia. Digite 0 para desativar. |
| **Enviar SMS quando a reserva do usuário entrar em vigor** Ativa ou desativa o envio de SMS quando a reserva entra em vigor. |
| **Enviar SMS quando a reserva ou proposta do usuário faltar X minutos para cair** Defina em minutos quanto tempo para notificar os usuários antes que sua reserva caia. Digite 0 para desativar. |
| **Limite de reservas por corretor** Número de reservas global para cada corretor. Informe 0 ou nulo para sem limite. |
| **Período de Retenção de Proposta (em horas)** Quando uma proposta é feita para a unidade, quantas horas a reserva ficará ativa (não cumulativo). |
| **Período de Retenção de Reserva (em horas)** Quando é adicionado uma reserva, porém sem proposta, quantas horas a reserva ficará ativa até que a próxima entre em vigor. |
| **Período para Aumentar nas Reservas (em horas)** Quando se deseja aumentar o tempo da reserva, este será o número padrão sugerido. |
| **Quantos dias para considerar que a unidade está "Em Proposta"** Quando é adicionado uma reserva para uma unidade no qual o corretor possui ou criou uma proposta, a situação da unidade será alterada para "Em Proposta" (ver parâmetro). Este parâmetro determina, quantos dias a contar para determinar que uma unidade está em proposta. |
| **Sincronizar unidades ao abrir mapa de disponibilidade** Ao parametrizar com valor **não**, será assumido que por questão de performance NÃO será sincronizado situação das unidades com o backoffice. Quando definido como **sim**, toda vez que abrir mapa de disponibilidade será sincronizado situação das unidades, impactando na performance. |
