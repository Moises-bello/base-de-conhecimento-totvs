Tenho o mesmo produto com mais de um código de barras, **somente as embalagens são diferentes**. No cadastro do produto consta apenas o campo B1\_CODBAR, como cadastro outros códigos de barras para o mesmo código de produto? É possível?  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões  
  
**Solução**

É possível sim, além do campo **Código de Barras (B1\_CODBAR)** no cadastro de Produtos, pode incrementar pela rotina **Códigos de Barras por Produto (LOJA210)** novos códigos de Barras. Veja um exemplo nos prints abaixo:
