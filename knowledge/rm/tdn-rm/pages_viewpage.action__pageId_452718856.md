**Relatório de Saúde**

Como padrão, o sistema disponibilizará um modelo de **Relatório de Saúde (PCMSO)** baseado em local de trabalho lembrando que cada empresa deve adaptar este modelo a sua própria realidade. No book de relatórios do sistema serão disponibilizados os itens que compõem o relatório modelo, e para correta geração do mesmo, estes deverão ser importados para o sistema pelo menu **Gestão | RM Reports | Processos| Importar Estrutura de Relatório.**

**Criando o tipo de relatório:** Acesse: **Relatórios | Tipos de Relatórios**, e incluia um novo tipo de relatório, marcando a opção: "Saúde". Para geração do modelo de PCMSO, com o relatório selecionado clicar em: **Processos | Gerar Modelo de PCMSO.**

Caso o cliente deseje alterar o modelo de PCMSO disponibilizado pelo sistema, na aba/anexo: "Itens do Relatório" será possível incluir itens do tipo texto, onde ao clicar no botão: "Editar Texto", será exibido um editor de texto para o usuário digitar suas informações. Na mesma aba, o usuário poderá incluir um relatório a partir do Gerador.NET, neste caso, basta selecioná-lo no LOOKUP de relatórios e selecionar o relatório desejado.
