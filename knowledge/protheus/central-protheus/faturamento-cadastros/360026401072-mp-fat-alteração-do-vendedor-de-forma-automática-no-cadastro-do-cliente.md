**Dúvida**

Como alterar o código de vendedor (**SA3-mata040**)para vários clientes (**SA1**-**MATA030**) sem ter que acessar cada cadastro em separado?  
   
 **Ambiente**

Microsiga Protheus - em todas as versões.  
  
**Solução**

Dentro do padrão do sistema, não há uma rotina automática que efetue atualização automática, sendo necessário entrar cadastro a cadastro para efetuar a alteração.

Uma opção alternativa seria tentar utilizar um ponto de entrada na alteração do cadastro para a necessidade via customização, sendo necessário ter um analista programador para tratar programação do ponto no sistema.

Em último caso, se optar por tratar a alteração via banco de dados, orientamos que um especialista em banco de dados (**DBA**) efetue o processo para que não haja nenhuma perda de informações.

**Obs1** - Ponto de entrada - o suporte não auxilia em customizações, o atendimento do suporte apenas indica os possíveis pontos a serem utilizados.

**Obs2** - Banco de dados: O Atendimento do suporte Help Desk não efetua alterações de banco de dados, sem se recomenda a alocação de um analista DBA para realização e manutenção do banco de dados do cliente.
