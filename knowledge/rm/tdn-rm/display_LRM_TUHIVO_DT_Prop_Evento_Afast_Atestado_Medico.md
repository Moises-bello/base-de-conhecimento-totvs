# PROPORCIONALIZAÇÃO DE EVENTOS POR AFASTAMENTO NÃO CONSIDERA PERIODO DE ATESTADO MÉDICO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Folha Mensal* |
| **Situação/Requisito:** | *Quando um funcionário inicia o afastamento no primeiro dia de fevereiro, no cálculo de um evento com a opção de proporcionalização marcada no cadastro do evento, não está sendo considerado os primeiros 15 dias de atestado médico.*  *O problema só ocorre na competência fevereiro.* |
| **Solução/Implementação:** | *Ajuste no tratamento de proporcionalizar o evento pelos dias de afastamento, para considerar os primeiros 15 dias a serem pagos pela Empresa.* |
| **Chamados   relacionados:** | *TUHIVO, TVBILP* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
