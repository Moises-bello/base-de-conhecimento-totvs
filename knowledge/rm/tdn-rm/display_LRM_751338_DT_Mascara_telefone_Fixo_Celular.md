# Máscara de telefone fixo e celular

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Inscrição de candidato no Processo Seletivo |
| **Situação/Requisito:** | Erro de máscara de telefone fixo e celular, devido a diferente quantidade de dígitos. |
| **Solução/Implementação:** | Foi adaptado a máscara do Portal do Processo Seletivo para funcionar, conforme o RM, onde a máscara parametrizada irá funcionar também pelo portal.  Nos parâmetros do Processo Seletivo é possível definir a máscara conforme abaixo, onde o "D" indica um dígito opcional. Desta forma, o Portal do Processo Seletivo irá aplicar esta máscara para os campos de Telefone Fixo e Celular, contendo um dígito opcional. |
