Dúvida**Como realizar a aplicação de Patch no Protheus TDS  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL– A partir da versão 11.80  
  
**Solução:**

**1.** Com o TDS instalado e devidamente configurado posicionar o projeto que deseja aplicar o patch.

**2.**Selecionar o ícone de uma pasta com uma engrenagem que fica no cabeçalho da tela(Aplicar Patch)

**3.**Em seguida abrirá uma janela para selecionar o arquivo.

**4.**Buscar a pasta onde esta o arquivo exemplo,**(500648\_MMAN-11454\_12.1.7\_TTTP120)**selecionar.

**5.**Na sequencia abrirá uma tela para aplicar o conteúdo selecionado caso o sistema possua arquivos mais recentes exibira a mensagem de que existe arquivos mais atuais no seu RPO porém tem a opção de inserir apenas os que são mais novos contido no arquivo, feito isso estará aplicado.
