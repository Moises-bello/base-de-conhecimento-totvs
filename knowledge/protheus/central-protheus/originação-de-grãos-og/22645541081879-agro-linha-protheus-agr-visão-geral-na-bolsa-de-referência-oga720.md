![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22645541059351) Tempo aproximado para leitura: **00****:00:25 min** **Dúvida**Qual é a **Visão Geral na Bolsa de Referência OGA720**?  
  
**Ambiente**TOTVS Agro – TOTVS Agro – Comercialização (Linha Protheus) - Originação de Grãos (OG) – Versão 12  
  
**Solução**  
Este programa permite **incluir** e **manutenir** as bolsas de referência. A bolsa de referência é a representação no Sistema de uma bolsa de valor de mercado e permite realizar integração com Sistema de terceiro para atualização de índices. Quando essa integração está devidamente configurada, os índices são **cadastrados/atualizados** automaticamente no programa Índices de Mercado.

É possível também informar a quantidade de contratos futuros que permite realizar o controle de cobertura de hedge quando sistema está configurado para gestão de risco **MV\_AGRO041**.
