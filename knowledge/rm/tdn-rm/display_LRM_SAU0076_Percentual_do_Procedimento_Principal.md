# Percentual do Procedimento Principal

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 12.1.X |
| **Passo-a-passo** | 1º Passo)  Entrar no menu Cadastros > Faturamento > Condições Contratuais do Convênio  Selecione o convênio que vai ser alterado o Percentual do Procedimento Principal        2º Passo)  Ao entrar no convênio,na opção "Padrão de Faturamento e Codificação" clicar na tabela.        3º Passo)  Após Clicar na tabela, vai abrir a tela de Padrões de Faturamento e Codificação, para ajustarmos os percentuais do Procedimento Principal, Secundário Mesma Via e Procedimento Via Diferente, incluímos o percentual para cada opção. Após realizar a configuração clicar em Salvar e depois Ok. |
