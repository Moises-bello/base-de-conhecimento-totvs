Dúvida**Como anonimizar os dados do colaborador no MEU RH?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
Acesse o módulo 18(SIGATCF) e acesse no menu o caminho > Atualizações > Configurações > Usuários > Permissões Meu RH.  
  
Altere a permissão de "ACESSO AO PERFIL" para "**Não**".  
![Untitled__Oct_26__2021_2_19_PM__1_.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4411529805975)  
  
Após essa alteração o perfil não será mais exibido no Meu RH, fazendo os dados estarem anonimizados:
