# CONCESSÃO DE BOLSA FUTURA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Concessão de Bolsa Futura |
| **Situação/Requisito:** | Em versões anteriores no cadastro de concessão de bolsa futura o campo "Todos os serviços" vinha como default desmarcado. Agora o campo passou a ter como valor default a seleção, ocasionando confusão e possibilitando erros na utilização dele pelo usuário. |
| **Solução/Implementação:** | Ajustes para que o comportamento do campo volte a ser o de versões anteriores. O default do campo voltará a ser o de não selecionado. |
