# Troca de contexto no portal redireciona para página principal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Alteração de contexto |
| **Situação/Requisito:** | Ao alterar o nível de ensino do professor no portal, a página atual não era mantida e o professor era redirecionado para a página principal do portal |
| **Solução/Implementação:** | Foi realizado ajuste na rotina de seleção de contexto para garantir que o professor permaneça na mesma página ao alterar o nível de ensino. |
