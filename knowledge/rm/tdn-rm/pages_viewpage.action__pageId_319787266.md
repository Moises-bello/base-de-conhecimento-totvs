Nesta tela você deverá informar as propriedades para conexão com o banco de dados que será utilizado pelo gerador. Cada tipo de banco de dados contém propriedades específicas que devem ser informadas para fazer a conexão. Essas propriedades são baseadas em ConnectionStrings. Para saber mais informações sobre Connection Strings, acessse: <https://www.connectionstrings.com/>

![](/download/attachments/319787266/conexao.png?version=1&modificationDate=1512921821000&api=v2)

1Tipo de Conexão

Selecione aqui o tipo de banco de dados da conexão.

2Propriedades

Informe aqui as propriedades para conexão com o banco de dados selecionado.

3Descrição

Exibe a descrição da propriedade selecionada.

4Testar

Clique para testar a conexão com o banco de dados de acordo com as propriedades informadas.

5OK

Clique para salvar as alterações da conexão com o banco de dados. Ao clicar em OK o sistema irá fazer um teste de conectividade com o banco de dados informado.

6Cancelar

Clique para cancelar as alterações da conexão com o banco de dados.
