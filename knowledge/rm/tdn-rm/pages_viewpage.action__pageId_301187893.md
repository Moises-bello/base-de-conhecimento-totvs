| **Ocorrência:** | Recálculo do Segundo Valor dos Lançamentos Contábeis |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do Processo:**  Os valores dos lançamentos são informados em moeda corrente, mas o sistema apresenta também o 2º Valor para os lançamentos, tomando como base outra moeda.  Sabemos, porém, que o valor de determinadas moedas precisam ser reajustados constantemente e, consequentemente, o 2º Valor que havia sido calculado automaticamente na inclusão do lançamento.  Este processo possibilita a qualquer momento fazer o **Recálculo do 2º Valor** tomando como base a Moeda indicada para o recálculo.  Esta moeda não precisa ser necessariamente a mesma moeda indicada nos Parâmetros como moeda para o 2º Valor.  O recálculo do 2º Valor será aplicado somente nos lançamentos filtrados para o processo, conforme os dados indicados nos filtros de seleção para o recálculo.    **Parametrização necessária:**  Para utilização desta funcionalidade será necessário habilitar o parâmetro "Usa 2º valor" Nos Parâmetros do Sistema. Acesse: Ambiente / Parâmetros / Totvs gestão contábil / Avançar / Clique em Lançamentos / Avançar / Lançamentos 2/4 / marque a opção "Usa segunda valor" e defina qual a moeda será utilizada para os cálculos.      Os valores informados para os lançamentos são sempre feitos em moeda corrente, entretanto, no momento da inclusão dos lançamentos, o sistema pode calcular automaticamente o segundo valor em outra moeda, basta que isto também seja definido nos Parâmetros do Sistema:        Assim, os valores dos lançamentos continuam sendo informados em moeda corrente, mas o sistema apresenta também o 2º Valor para os lançamentos, tomando como base outra moeda. Sabemos, porém, que os valores de determinadas moedas precisam ser reajustados constantemente e, consequentemente, o 2º Valor que havia sido calculado automaticamente na inclusão do lançamento. Basta acessar o menu: Escrituração Contábil / Recalculo / Processo de Recalculo do segundo Valor dos Lançamentos Contábeis:        Este processo possibilita a qualquer momento fazer o Recálculo do 2º Valor tomando como base a Moeda indicada para o recálculo. Esta moeda não precisa ser necessariamente a mesma moeda indicada nos Parâmetros como moeda para o 2º Valor.  O recálculo do 2º Valor será aplicado somente nos lançamentos filtrados para o processo, conforme os dados indicados nos filtros de seleção para o recálculo.      **Regras para o recálculo:**    - O 2º Valor é calculado, pegando-se o Valor do lançamento e dividindo-o pelo valor da cotação da Moeda no dia informado conforme regras repassadas nos filtros.  - Se a opção ‘Usa cotação da data do lançamento’ estiver marcada o sistema utiliza para o cálculo a cotação da moeda cadastrada na data do lançamento, caso não esteja marcada, utiliza a cotação da moeda cadastrada na Data da 2ª Moeda, que é informada na tela da partida do lançamento e, caso esta Data da 2ª Moeda esteja em branco, utiliza a data do lançamento.  - Se o 2º Valor dentro da tela da partida do lançamento estiver em branco, o sistema somente fará o cálculo se a opção ‘Recalcula inclusive quando Segundo Valor = 0’ estiver marcada.  - O sistema verifica se existe cotação na data informada para execução do processo (data do lançamento ou data da 2ª moeda), caso não exista busca a primeira cotação cadastrada com data menor que a data informada para o processo, se ainda assim não existir cotação cadastrada, busca a primeira cotação cadastrada com data superior à data informada para o processo. Se para nenhuma das opções tiver cotação cadastrada o sistema não fará o recálculo.    **Exemplos de Recálculo do 2º Valor:**    O 2º Valor é calculado levando-se em consideração o Valor do Lançamento, a Data e a Cotação cadastrada para a Moeda utilizada no processo.
