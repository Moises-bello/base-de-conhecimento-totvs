# QUADRO DE HORÁRIO DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Prédio, Bloco e Sala visualizado no quadro de horário no portal do aluno.* |
| **Situação/Requisito:** | *A informação de Prédio, Bloco e Sala, disponível na visão de quadro de horário do aluno retornava a informação duplicada e gerava confusão no entendimento.* |
| **Solução/Implementação:** | *Ajuste no retorno do Prédio, Bloco e Sala da turma/disciplina e adição da mesma informação cadastrada no horário. Quando o Prédio, Bloco e Sala for informado no horário, esta informação pode ser visualizada pelo aluno no próprio Quadro de Horário, basta clicar no item  "Informações Adicionais".* |
