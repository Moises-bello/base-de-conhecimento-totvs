**Dúvida**Ao realizar a validação do arquivo da RAIS no programa GDRAIS é apresentada a seguinte mensagem de erro:  
0570 - Data base é obrigatória para estabelecimento com empregados no ano-base  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 11.80  
  
**Solução**Através do módulo SIGACFG - Configurador, no cadastro da empresa/filial, na aba complementos informar a data base:
