Este módulo foi disponibilizado com o objetivo de bloquear a inclusão/exclusão de dados controle de faltas no cadastro do funcionário até uma determinada data, seja a atualização através do RM Chronus, inclusão manual ou importação.  
    
 Quando o usuário processar este módulo informando uma data fim de bloqueio, o sistema não irá permitir o processo através do RM Chronus ou importação até a data fim do bloqueio, somente a partir desta data o processo será efetuado.  
    
 Para os dias bloqueados, o sistema irá permitir a edição apenas dos campos "Abonar Falta" e "Observação". Atendendo a necessidade do usuário necessitar bloquear o controle de faltas apenas para não aceitar o processo através do RM Chronus, mas necessitar ajustar algum dia de falta.  
 **Exemplo:**   
 Pagamos a 2ª parcela em 20/12, sendo que o cálculo da 2ª parcela foi realizado em 16/12 devido ao prazo para pagamento, ou seja, as faltas foram consideradas até o dia 16/12.  
 Neste caso não é necessário bloquear o controle de faltas, pois o RM Chronus poderá enviar as faltas normalmente no período, e caso tenha algum ajuste, ao pagar a diferença de 13º salário, esta situação será contemplada.
