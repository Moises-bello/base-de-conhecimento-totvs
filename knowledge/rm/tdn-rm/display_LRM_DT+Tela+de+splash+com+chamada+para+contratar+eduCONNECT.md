Os usuário do sistema (TOTVS Educacional), precisam visualizar as informações do eduCONNECT para conseguir conhecê-lo e contratá-lo.

## **03. SOLUÇÃO**

Foi realizado ajuste no TOTVS Educacional para criar uma tela que permita ao usuário do sistema conhecer e contratar o eduConnect diretamente pelo sistema.
