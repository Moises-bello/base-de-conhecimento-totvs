# PRAZO DETERMINADO NA CONTAGEM DE AVOS DA PROVISÃO DE 13o.SALÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Provisão de 13o.Salário* |
| **Situação/Requisito:** | *Ao considerar o prazo determinado, do cadastro do funcionário, na contagem de avos de 13o. salário, pode haver inconsistências no caso de utilizar este campo para contratos de experiência.*  *Se o parâmetro não for desmarcado, após o prazo deste contrato, o número de avos de 13o. fica incorreto.* |
| **Solução/Implementação:** | *Ajuste na contagem de avos de 13o. salário, para considerar a data final do prazo determinado, somente quando na 1a.parcela é considerado avos até dezembro, e o final do prazo é posterior à competência atual.* |
