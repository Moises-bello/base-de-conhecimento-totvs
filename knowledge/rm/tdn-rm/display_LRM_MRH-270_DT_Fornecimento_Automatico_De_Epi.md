# FORNECIMENTO AUTOMÁTICO DE EPI

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Segurança e Saúde Ocupacional |
| **Função:** | Fornecimento Automático de EPI |
| **Situação/Requisito:** | Ao realizar empréstimos de EPIs para um número muito grande de funcionários simultaneamente em mais de uma máquina às vezes ocorrem erros de chave primária. Realizando os mesmos empréstimos em apenas uma máquina o erro não ocorre. O sistema está parametrizado para trabalhar sem integração e sem controle de estoque. |
| **Solução/Implementação:** | Realizado ajuste de forma que não exista concorrência ao realizar empréstimos de EPIs simultâneos utilizando a parametrização sem integração e sem controle de estoque. |
