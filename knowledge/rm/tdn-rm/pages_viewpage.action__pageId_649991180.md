## **01. VISÃO GERAL**

Processo a ser executado para troca de dados da produção que foram gravados incorretamente. Nesse processo poderá ser feita a troca de produção gravada na tabela PPRODUCAOAGRARIA respeitando a parametrização e o período informado.

Os valores que não forem preenchidos no painel **valores atuais** não farão parte da troca, o mesmo ocorre com o painel **novos valores** quantidade não preenchidas não serão trocadas.

Ao preencher qualquer campo do painel - **valores atuais** (**por exemplo “Tarefa”**), é necessário que no painel - **Novos Valores** eu tenha preenchido o campo “**Tarefa**”.

## **03. TELA: **Troca de Dados da Produção****

****Principais Campos e Parâmetros****

| Campo | Descrição |
| --- | --- |
| Quebra de Seção | Selecione a quebra |
| Seleção de funcionários | Selecione os funcionários |
| Data Produção | Selecione a data de produção a ser trocada |
| Forma de exibição do log | Simples / Detalhado |
| Valores Atuais - Unidade Agrária | Informe a unidade agrária a ser trocada |
| Valores Atuais - Fração Agrária | Informe a fração agrária a ser trocada |
| Valores Atuais - Programação | Informe a programação a ser trocada |
| Valores Atuais - Horas | Informe o número de horas a ser trocado |
| Valores Atuais - Tarefa | Informe a tarefa a ser trocada |
| Valores Atuais - Quantidade | Informe a quantidade a ser trocada |
| Novos Valores - Unidade Agrária | Informe o novo valor da Unidade Agrária a ser gravado na tabela PPRODUCAOAGRARIA |
| Novos Valores - Fração Agrária | Informe o novo valor da fração agrária a ser gravado na tabela PPRODUCAOAGRARIA |
| Novos Valores - Programação | Informe o novo valor da programação a ser gravado na tabela PPRODUCAOAGRARIA |
| Novos Valores - Horas | Informe o novo valor da horas a ser gravado na tabela PPRODUCAOAGRARIA |
| Novos Valores - Tarefa | Informe o novo valor da tarefa a ser gravado na tabela PPRODUCAOAGRARIA |
| Novos Valores - Quantidade | Informe o novo valor da quantidade a ser gravado na tabela PPRODUCAOAGRARIA |
