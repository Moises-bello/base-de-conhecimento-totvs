# Assistente de Concessão de Bolsas Futuras

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Assistente de concessão de bolsas futuras |
| **Situação/Requisito:** | Depois de selecionar o aluno e ao tentar selecionar a matriz aplicada, são listados apenas os cursos que o aluno esteja matriculado. |
| **Solução/Implementação:** | Ajustes para que, no assistente de concessão de bolsas futuras, no contexto de ensino básico, ao selecionar a matriz aplicada seja exibida todas as matrizes, mesmo que o aluno não esteja matriculado. Para o ensino superior continuará a ser exibido apenas as matrizes baseado na matrícula do aluno. |
