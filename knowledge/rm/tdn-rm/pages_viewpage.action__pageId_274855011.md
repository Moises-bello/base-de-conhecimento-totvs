# Liberar prescrição no PEP 2

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | PEP 2 |
| **Situação:** | Ao realizar a liberação da prescrição médica no PEP 2, era apresentada a mensagem informando que ocorreu um erro na comunicação com o HIS. |
| **Solução:** | Como a integração Hospitalar é com o RM Saúde não com o HIS, foi alterado o sistema para não apresentar essa mensagem ao liberar a prescrição médica. |
