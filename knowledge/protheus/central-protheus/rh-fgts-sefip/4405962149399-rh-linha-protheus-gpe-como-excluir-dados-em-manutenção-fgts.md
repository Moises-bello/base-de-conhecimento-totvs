![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34012851604119) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como excluir dados em Manutenção FGTS?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**A exclusão de dados na rotina Manutenção FGTS pode ser feita de duas formas:  
1. Para excluir todos os registros de uma só vez em Manutenção FGTS, clique em **>Outras Ações >Excluir**:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405973938711)  
Clique em Confirmar para realizar a exclusão:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405973997207)

2. Para excluir registros específicos, clique em Alterar:  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405974028567)  
Selecione os registros que serão deletados com a tecla DELETE e clique em Confirmar:  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405974051991)
