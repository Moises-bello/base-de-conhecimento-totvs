**Ocorrência**Ao tentar efetuar o Login dentro do CloudConnect, é retornado o seguinte erro de acesso: **"Unspecified error. Check error log for more info"****Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Fast/Smart Analytics – Todas versões.   
  
**Causa**Este erro ocorre pois o GoodData alterou o endereço do server cadastrado. O antigo cadastro **"secure.gooddata.com"** foi alterado para **"analytics.totvs.com.br"****Solução**Para solucionar essa ocorrência, realize o seguinte procedimento:  
**1.** Altere o endereço do server de **"secure.gooddata.com"** para **analytics.totvs.com.br"** e em seguida continue o acesso normalmente.
