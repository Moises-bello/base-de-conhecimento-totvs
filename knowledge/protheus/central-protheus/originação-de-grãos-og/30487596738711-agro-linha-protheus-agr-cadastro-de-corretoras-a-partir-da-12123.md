![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30487556754583) Tempo aproximado para leitura: **00:01:00min** **Dúvida**Como realizar o **Cadastro de Corretoras a partir da 12.1.23**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução****Cadastro de Corretoras:**

|  |  |
| --- | --- |
| **Produto:** | Microsiga Protheus |
| **Ocorrência:** | Procedimentos para Cadastrar Corretoras que possam ser informados nos contratos de venda e compra a partir da release 12.1.23. |
| **Ambiente:** | Protheus - Originação de Grãos - Versão 12.1.23 |
| **Passo a passo:** | **O exemplo apresentado é para o contrato de compra, mas o mesmo pode ser utilizado para o contrato de venda.**  **1 - Acessar Gestão de Agronegócio > Atualização >> Cadastros Gerais >>> Fornecedores**  Clique na opção Incluir para adicionar um novo fornecedor. O novo registro deve ter os dados da sua corretora.  Após finalizar o cadastro, acesse Outras Ações → Relacionadas → Contatos.  Informe os contatos que serão vinculados ao Fornecedor. Esse contato indica os dados do corretor. Para incluir um novo contato, utilize a opção de Consulta Padrão (F3) do campo Código. A tela apresentará os contatos existentes no sistema. Utilize a opção Incluir da tela de Consulta Padrão para adicionar novos contatos.    **2 - Acessar Gestão de Agronegócio > Atualização >> Comercialização >>> Negociações >>>> Contrato de Compras >>>>> Contrato de Compras**  Acesse a opção Incluir ou Alterar para um contrato de compra existente.  Na pasta Corretoras, informe o código do Fornecedor que identifica a sua corretora no campo Cod. Crtra. No campo Cod.Corretor informe o Contato que foi vinculado no cadastro de Fornecedor. Utilize a Consulta Padrão para filtrar apenas os contatos da corretora informada. |
| **Observações:** | A funcionalidade descrita neste documento é válida somente para a release a partir da 12.1.23. |
