# Editar observação de movimentações de estoque

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Estoque | Movimentação de estoque | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | Oracle® e SQL Server® |

## Descrição

Realizado ajuste para permitir a edição das informações de observação de uma movimentação de estoque do tipo prescrição médica.

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações 12.1.16.005 do RM Saúde.

## Procedimento para Utilização

       1.            No TOTVS Gestão Hospitalar, acesse o menu Estoque > Movimentação de estoque;

       2.            Selecione uma movimentação do tipo prescrição médica e clique em editar;

       3.            Selecione um item da movimentação e clique no campo observação;

       4.            Altere a descrição do campo;

       5.            Ao sair do campo observação, o sistema irá apresentar uma mensagem perguntando se deseja salvar a alteração.

       6.            O sistema deve salvar a alteração realizada.
