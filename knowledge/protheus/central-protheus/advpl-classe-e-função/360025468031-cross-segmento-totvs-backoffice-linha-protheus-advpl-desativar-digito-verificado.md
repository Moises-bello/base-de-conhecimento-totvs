![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:01:00 min****Dúvida**Gostaria de saber como desativar o cálculo do digito automático da classe FWMSPrinter utilizando o método Code128C

```
oPrinter:Code128C ( nLinha,50, cBar,40 ) 
```

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Não existe parâmetro na classe que atenda essa necessidade e também não temos nenhuma função ou método que permita gerar o código sem o digito.
