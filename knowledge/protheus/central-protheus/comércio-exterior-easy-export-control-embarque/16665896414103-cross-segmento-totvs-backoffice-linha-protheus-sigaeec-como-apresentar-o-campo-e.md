![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16665880299927) Tempo aproximado para leitura: **02:00 min** **Dúvida**Como apresentar o campo "**EET\_VALORR" "Valor R$"** na tela das despesas nacionais?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665468836759)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 12.1.33.

**Solução**Para que o campo "**EET\_VALORR" "Valor R$"** seja apresentado em tela:

1. Acesse o módulo SIGACFG em Base de Dados, selecione Dicionário / Base de dados.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665917431575)

2. Selecione Dicionário de Dados

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665911838743)

3. Selecione a lupa

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665926715543)

4. Selecione Procurar Por e informe a tabela **EET**, após selecione Buscar.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665661694103)

5. Posicione no campo **EET\_VALORR** e selecione a folha com o lápis.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665769185943)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665796008343)

6. Na Aba **Uso,** marque o campo a opção **Browse**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16665735453207)
