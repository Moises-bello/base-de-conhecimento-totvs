***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023739612/time.png)***Tempo aproximado para leitura: **00:00:50 min** **Dúvida**Quais os procedimento para a ativação e conversão da base de dados para o novo **WMS - Warehouse Management System**?  
  
**Ambiente**TOTVS Logística - TOTVS WMS (Linha Protheus) - Gestão de Armazenagem (WMS) – A partir da versão 12.1.16  
  
**Solução**A partir da *release* **12.1.16** foi liberado o novo **WMS**, o qual possui um controle de estoque exclusivo.  
A atualização para este novo produto deve ser realizada em conjunto com a atualização do **ERP - Enterprise Resource Plannig** por completo, aplicando **Dicionário de Dados** e **RPO -** **Repositório de Objetos do Protheus** referentes ao pacote de atualização **12.1.16** ou **superior**.  
  
**Saiba mais**  
Para consultar o procedimento detalhado, acesse o *link*: [DT SIGAWMS - Migração Novo WMS](https://tdn.totvs.com/pages/viewpage.action?pageId=516207199)
