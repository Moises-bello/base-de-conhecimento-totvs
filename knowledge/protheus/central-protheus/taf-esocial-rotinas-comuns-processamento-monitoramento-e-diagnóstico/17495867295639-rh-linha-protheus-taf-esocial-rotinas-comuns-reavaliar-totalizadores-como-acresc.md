![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17495872743959) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Como acrescentar a opção **Reavaliar Totalizadores** no menu do TAF ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Reavaliar Totalizadores (TAFREAVALI) -

Todas as versões.

**Solução**

A rotina **Reavaliar Totalizadores** (TAFREAVALI), foi disponibilizada temporariamente, para ser acrescentada no menu do TAF (SIGATAF).

Para que a mesma fique disponível ao acessar o TAF, será necessário **criar o menu** pelo **configurador SIGACFG.**

1. Crie o menu **Reavaliar Totalizadores,** seguindo a documentação do link abaixo:

[Passo a passo para criar o menu Reavaliar Totalizadores](https://tdn.totvs.com/display/public/TAF/Reavaliar+Totalizadores#tabs-proc1)

2. Após criar o menu, acesse novamente o módulo do TAF (SIGATAF).

3. O novo menu ficará disponível no caminho: **Miscelanea > Ajuste de Base > Reavaliar Totalizadores**:

![image2023-6-11_18-9-31.png](https://tdn.totvs.com/download/attachments/769982521/image2023-6-11_18-9-31.png?version=1&modificationDate=1686517771587&api=v2)

4. Verifique a documentação abaixo, que explica como utilizar a rotina "Reavaliar Totalizadores":

[Automação Fiscal - Rotinas Comuns - Reavaliar Totalizadores, como utilizar a rotina.](https://centraldeatendimento.totvs.com/hc/pt-br/articles/17496282095127)
