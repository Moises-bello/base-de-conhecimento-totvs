# ATUALIZAÇÃO DO ENDEREÇO DO ALUNO NA MATRÍCULA DO PROCESSO SELETIVO RM

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Educacional |
| **Função:** | Informe a função. |
| **Situação/Requisito:** | Sistema não está atualizando o endereço do aluno quando estamos fazendo uma matricula do PS de um usuário que já existe PPESSOA, ou seja, no nomento da inscrição no Processo seletivo o candidato preencheu seu novo endereço, mas ao matricular esse endereço não foi levado para o campo de endereço da PPESSOA que já existia. |
| **Solução/Implementação:** | A rotina de matrícula do processo seletivo RM foi alterada para atualizar o endereço da pessoa quando ela já estiver cadastrada. |
