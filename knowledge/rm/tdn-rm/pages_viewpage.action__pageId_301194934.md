|  |  |
| --- | --- |
| **Linha de Produto:** | RM |

| **Módulo:** | Totvs Educacional |
| **Função:** | Ocorrência de aluno |
| **Situação/Requisito:** | O sistema estava permitindo excluir ocorrências do aluno, mesmo quando estivesse marcado o campo “Responsável ciente da ocorrência”. |
| **Solução/Implementação:** | Otimização no cadastro de ocorrência do aluno, somente no nível de ensino básico, onde não permitirá excluir registro que estejam marcado o campo “Responsável ciente da ocorrência”. |
