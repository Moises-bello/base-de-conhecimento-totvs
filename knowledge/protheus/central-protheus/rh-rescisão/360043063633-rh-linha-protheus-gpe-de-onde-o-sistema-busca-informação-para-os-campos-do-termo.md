**Dúvida**De onde o sistema busca informação para os campos do termo de rescisão **IMPRESH**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) – GPE Gestão de Pessoal – A partir da versão 11.80  
  
**Solução**

Sistema busca informação do cadastro de verbas**(Atualizações > Definição de Cálculo > Verbas)**, campo **V. homolognet “RV\_HOMOLOG**”.

Caso esteja preenchido o sistema leva a informação que está neste campo para este termo de rescisão.

Quando esta em branco sistema busca informação dentro do fonte.
