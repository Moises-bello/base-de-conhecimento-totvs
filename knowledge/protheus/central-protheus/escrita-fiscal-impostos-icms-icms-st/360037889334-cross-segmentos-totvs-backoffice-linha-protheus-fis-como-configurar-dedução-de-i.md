**Dúvida**

Como configurar dedução de (ICMS Próprio do ST) Entrada ou Saída?

**Ambiente**

Protheus – Livros Fiscais – A partir da versão 11.80  
  
**Solução**

Informe no**TES campo Ded ICMS ST (F4\_ICMSTMT). Apesar do help informar que é para o Estado de MT, funciona para todos os Estados, Entradas e Saídas**, por padrão este campo vem em branco porém funciona como "SIM" para não dedução, preencher este campo como "NÃO"

Obs. Já foi solicitado melhoria/correção deste Help.
