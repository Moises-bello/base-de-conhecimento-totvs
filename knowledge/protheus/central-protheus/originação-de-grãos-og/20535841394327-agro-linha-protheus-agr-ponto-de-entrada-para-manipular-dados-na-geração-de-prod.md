![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20535839185815) Tempo aproximado para leitura: **00:00:55 min****Ocorrência**  
No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para encontrar o ponto de entrada para manipular dados na geração de produção é apresentada a ocorrência **Ponto de Entrada para manipular dados na geração de produção**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é preciso realizar o processo para encontrar o ponto de entrada para manipular dados na geração de produção no Sistema.  
  
**Solução**  
Para solucionar essa ocorrência, o **Ponto de Entrada** é o **OGX013GER - Permite Manipular dados da Geração  de produção no Romaneio por Produção**, ele é chamado ao confirmar o romaneio de produção  **OGX013 - Funções do Romaneio por Produção**.
