# Inconsistência e-mail de inscrição

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Processo Seletivo |
| **Módulo:** | Novo Portal Processo Seletivo |
| **Função:** | Envio de confirmação de inscrição por e-mail |
| **Situação/Requisito:** | Cliente informa inconsistência no envio de confirmação de inscrição do novo portal do processo seletivo por e-mail. Ao clicar no link enviado por e-mail, o mesmo é redirecionado para outra inscrição, também realizada no novo portal. |
| **Solução/Implementação:** | Foi realizado ajuste para garantir que o link de e-mail enviado ao candidato/responsável corresponda à inscrição realizada, e, ao clicar no link, o mesmo será redirecionado para a inscrição correta. |
