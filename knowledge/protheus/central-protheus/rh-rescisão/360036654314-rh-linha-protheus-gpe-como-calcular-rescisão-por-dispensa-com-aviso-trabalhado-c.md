**Dúvida**Ao calcular rescisão por dispensa com Aviso Trabalhado, é possível alterar os dias da projeção para trabalhados ao invés de indenizados?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) GPE - Gestão de Pessoal - A partir da Versão 12.1.17  
  
**Solução**Ao calcular rescisão por dispensa com **aviso trabalhado**, o sistema trás automaticamente 30 dias trabalhados e os demais dias de projeção como indenizados, porém é possível fazer ajuste manual para que os dias de projeção também fiquem como trabalhados, para isso deve ser alterado a quantidade de dias de aviso no **campo Dias A.P.Cum** para os dias que de fato o funcionário irá cumprir, abaixo exemplo:  
Funcionário com 33 dias de aviso prévio, onde irá cumprir os 33 dia de aviso.  
Sistema irá carregar automaticamente os campos conforme abaixo:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047966534)

Para que ele trabalhe os 33 dias, altere o **campo Dias A.P.Cum** para 33, assim o sistema entenderá que será trabalhado os 33 dias:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048840313)
