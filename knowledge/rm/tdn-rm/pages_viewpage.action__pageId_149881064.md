| **Sintoma** | **Como possibilitar o usuário a utilizar uma outra coligada?** |
| Solução | Somente o usuário com nível de "Supervisor" poderá liberar o acesso para outra coligada.  No Delphi, acessando o menu: Cadastros -> Segurança -> Usuários -> clique duas vezes no usuário que deseja dar acesso -> vá até a aba Segurança -> Marque a coligada que deseja que o usuário acesse  Pela nova MDI acesse o menu de seleção de aplicativos e  selecione Serviços Globais.  Agora vá em: Segurança -> Usuários a direita de “Sistema:”, selecione o sistema RH / Folha de Pagamento -> clique duas vezes no usuário que deseja dar acesso -> vá até a aba Segurança -> Marque a coligada que deseja que o usuário acesse |
