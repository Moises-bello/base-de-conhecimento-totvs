![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30034788814359) Tempo aproximado para leitura: **00:03:00 min****Dúvida**Como efetuar a ativação dos campos de log, para visualização em tela durante o detalhamento?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Protheus Release 12.1.33.  
  
**Solução**

A tabela em questão possui um limite de colunas que podem ser exibidas simultaneamente. Para habilitar um novo campo, é necessário desabilitar um dos campos atualmente ativos, caso o limite já tenha sido atingido.

### **Procedimento para Alterar a Exibição de Campos**

1- Acesse a configuração de exibição da tabela e etapa desejada, aqui vamos fazer uma validação para o campo **USUARIO** ser ativado, e para isso, precisamos desativar algum dos outros campos ja ativos, por causa da limitação dos campos ja preenchidos.

![img1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30034955655191)

2- Identifique os campos que estão atualmente ativos, e então desative um dos campos de sua escolha, para ativar o campo de Usuario, veja abaixo, desativei o campo **HORA** para ativar o campo **USUARIO**.

![img2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30034955655703)

**Resumo:**

- Desabilite um campo ativo para liberar espaço para um novo campo.

- Habilite o campo desejado.

- Salve as alterações e verifique a exibição na interface.

**Na exportação do log, todos os campos serão apresentados independentemente das configurações de exibição.**
