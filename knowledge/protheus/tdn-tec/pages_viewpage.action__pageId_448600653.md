Define se SSL deve ser usado para comunicar com o controlador do AppDynamics.

## Valores válidos

| Valor | Descrição |
| --- | --- |
| 0 (Padrão) | Não usa SSL para comunicar com o controlador do AppDynamics. |
| >= 0 | Usa SSL para comunicar com o controlador do AppDynamics. |

## Observações

* O uso de SSL deve ser confirmado junto à área responsável pela administração do controlador do AppDynamics.

## Exemplo

Define o uso do SSL para comunicar com o controlador do AppDynamics como verdadeiro.
