# Cliente/ Fornecedor

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Gestão Financeira. |
| **Função:** | Desvincular/Vincular Cli/For |
| **Situação/Requisito:** | Quando existe a integração com o Protheus, o processo de Desvincular/Vincular Cli/For não funciona corretamente, quando selecionamos mais de um cadastro de pessoa, pois a máscara que é respeitada é a que está definida nos parâmetros financeiros e não é possível inserir uma nova máscara. |
| **Solução/Implementação:** | Ajustado processo de Desvincular/Vincular Cli/For, para que a máscara do cliente fornecedor, não seja validada quando Integrado com Protheus. |
