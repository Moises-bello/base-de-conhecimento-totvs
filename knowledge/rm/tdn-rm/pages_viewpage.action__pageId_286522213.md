# Campo Tipo de Taxa ou Serviço conforme o código selecionado

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | Rotina | Nome Técnico | | Elaboração de Contas | Lançamentos na Conta do Paciente | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server® e Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Na tela de "Elaboração de contas", na aba "Taxas e Serviços", o valor default do "Tipo" foi parametrizado para que mude o campo "Tipo" conforme o código selecionado.

## Procedimento para Utilização

* Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Tesouraria e Lançamentos na Conta do Paciente".
* Selecione um paciente com atendimento gerado
* Clique na Aba Taxas e Serviços e Incluir, observe que o  campo "Tipo" vem com "Taxas" selecionado
* Ao pesquisar um código de serviço o campo "Tipo" é atualizado.
