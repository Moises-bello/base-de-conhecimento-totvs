## Descrição

Criado um parâmetro para permitir definir uma fórmula para acrescentar valor á base de cálculo do IRRF para pessoa física sobre aluguel.

## Procedimento para Utilização

1. Foi criado o parâmetro "Acrescentar valor á base de cálculo", na etapa 02.01.01.02.01, para permitir definir uma fórmula para acrescentar valor à base de cálculo para geração do IRRF de pessoa física. Esse acréscimo somente será realizado sobre o código receita de alugueis e o parâmetro "Data  Base para Geração" for igual a "Baixa".
