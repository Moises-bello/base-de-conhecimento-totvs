Correção - TGrid causa encerramento do SmartClient durante a navegação entre linhas

|  |  |
| --- | --- |
| Situação | Durante a navegação através do teclado entre as linhas de um componente TGrid populado, o SmartClient é encerrado repentinamente. |
| Ocorrência | Ocorre principalmente quando são utilizadas as teclas Home e End, mas pode ocorrer também através das setas para cima e para baixo quando a navegação exigir o scroll dos registros. |
| Correção | Foi aplicada uma correção no componente TGrid. |
| Informações adicionais | * Referente ao chamado: 5485150 * Referente à ocorrência: MTEC-2526 * Disponível em builds iguais ou superiores a 7.00.170117A - 17.3.0.7 |
