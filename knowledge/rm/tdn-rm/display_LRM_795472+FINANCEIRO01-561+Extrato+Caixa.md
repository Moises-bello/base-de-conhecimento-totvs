# Extrato Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Extrato Caixa |
| **Situação/Requisito:** | Após inserir um evento contábil na contabilização de um extrato de caixa manual, são carregadas as partidas. Se editar uma das partidas e realizar qualquer alteração, o evento contábil some do campo. Após salvar o extrato, além do evento contábil, a contabilização também some. |
| **Solução/Implementação:** | Ajustado a inclusão de extrato manual, para que ao editar um evento de um extrato contábil que esta sendo incluído, e fechar o formulário de contabilidade compartilhada, caso o usuário abra novamente o formulário de contabilidade compartilhada, sem salvar o extrato, a contabilidade que foi editada na primeira vez passa a ser exibida. |
