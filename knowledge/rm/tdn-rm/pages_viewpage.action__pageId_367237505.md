# Data contábil na rematrícula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Rematrícula de Aluno. |
| **Situação/Requisito:** | Na tela de rematrícula do aluno os campos referente às datas de competência contábil não são carregados automaticamente mesmo quando o plano de pagamento tenha essas informações. |
| **Solução/Implementação:** | Otimização no processo de rematrícula do aluno para que caso as datas de competência contábil não são informadas, o sistema irá buscar do plano de pagamento configurado na parametrização por curso. Isso é necessário, pois o processo de rematrícula é realizado para vários alunos ou para um aluno.   Caso as datas sejam informadas  durante o processo, o sistema irá respeitar as datas informadas no processo. |
