|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Devolução de empréstimo . |
| **Situação/Requisito:** | Na realização de devolução de empréstimo que contém valores para lançamento financeiro o sistema apresenta mensagem indevida referente à configuração do evento contábil de inclusão do lançamento parametrizada no parâmetro Inclusão presente em "TOTVS Gestão Bibliotecária → Parâmetros / Configurações → Integração → Financeiro → Integração - Financeiro 2/4 → Evento Contábeis". |
| **Solução/Implementação:** | Otimização na devolução de empréstimo que contém valores para lançamento financeiro gerar o lançamento conforme o tipo contábil configurado nos parâmetros do sistema. |
