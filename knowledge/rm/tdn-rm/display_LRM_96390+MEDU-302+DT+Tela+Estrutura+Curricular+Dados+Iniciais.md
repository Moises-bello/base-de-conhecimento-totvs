# ESTRUTURA CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Estrutura curricular* |
| **Situação/Requisito:** | *Ao acessar a tela, o sistema já carrega informações de matrizes antes de gerar o seu filtro, sendo que o mesmo deveria ser carregado em branco.* |
| **Solução/Implementação:** | *Foi identificado que o sistema carrega toda estrutura curricular que está com status de ATUAL, sendo assim foi feito uma alteração para que ao carregar a tela a primeira vez o sistema não carregue nenhuma informação, se o usuário clicar em "selecionar" mesmo com os filtros vazios porém com a opção de status ATUAL marca o sistema trará as informações.* |
