# AGENDAMENTO/ENVIO DE MENSAGENS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Educacional |
| **Função:** | Agendamento/envio de mensagem |
| **Situação/Requisito:** | Quando não tem disciplinas matriculadas o sistema não está enviando mensagens para os responsáveis, a mensagem é enviada  somente para o aluno. Quando realizamos a matricula nas disciplinas ele envia para todos. |
| **Solução/Implementação:** | Aperfeiçoada a consulta SQL para desconsiderar o fato de um aluno estar matriculado em uma determinada  disciplina para enviar de mensagens a seus responsáveis. O fato de um aluno não estar matriculado em uma  disciplina não o descaracteriza de recebimento, menos ainda, seus responsáveis. |
