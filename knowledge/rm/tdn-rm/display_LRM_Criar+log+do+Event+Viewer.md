Para melhor análise da situação reportada, solicitamos que nos encaminhe o Log do Event Viewer, assim que a inconsistência ocorrer, informando a Data/Hora no qual o erro ocorreu.

Proceda com as orientações abaixo para criação do log do Event Viewer:

   
 Acesse o Event Viewer (Visualizador de Eventos do Windows) Painel de Controle -> Ferramentas Administrativas -> Visualizador de Eventos:

 

Selecione o Menu Logs do Windows -> Aplicativo:

 

Clique no menu Salvar Eventos como:

 

Salve o arquivo e anexe ao chamado para análise.
