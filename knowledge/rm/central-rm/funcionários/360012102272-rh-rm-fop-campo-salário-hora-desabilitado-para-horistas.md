Dúvida**  
Como fazer para habilitar a edição do campo **Salário Hora** para funcionários horistas?  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9040324672151/mceclip3.png)  
 **Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para solucionar esta situação, acesse **Configurações | Parametrizador | Folha Normal | Horistas e Tarefeiros** e desmarque o parâmetro **Edita salário mensal para horistas/tarefeiros**.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9040221817623/mceclip1.png)  
  
Após desmarcar o parâmetro acima, o campo Salário Hora será habilitado para os horistas:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9040284410391/mceclip2.png)
