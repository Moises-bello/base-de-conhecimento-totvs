# Inconsistência no WebService Cancelamento Guia

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Atendimentos Externos |
| **Situação:** | O campo data estava fora do padrão hh:MM:ss.  Não havia mensagem de retorno mostrando falha no retorno do WebService. |
| **Solução:** | Foi alterado o padrão hora para receber apenas hh:MM:ss.  Foi adicionada mensagem de retorno quando o WebService não executar o retorno correto. |
