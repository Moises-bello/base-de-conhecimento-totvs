Este processo é usado para efetuar a cópia dos Eventos Contábeis.

O objetivo deste processo é realizar a cópia do evento contábil de uma coligada para outra coligada.

Se você precisar incluir um evento em uma coligada que seja idêntico a outra coligada, não faça manualmente, utilize o processo de "Cópia de Evento". A tarefa será realizada com mais agilidade e com mais segurança.

Marque os eventos a serem copiados, acesse o "processo" "Cópia de Evento", marque a coligada para onde as informações serão copiadas e confirme a operação.

**Observação**   
- Não é possível realizar a cópia de informações se na coligada de destino não existir um campo para tal informação.  
   
- Quando este fato ocorrer você tem duas opções para realizar a cópia:  
1ª - excluir a informação do campo, salvar a edição e repetir o processo;  
2ª - acessar a outra coligada, criar o mesmo campo para a informação e repetir o processo.
