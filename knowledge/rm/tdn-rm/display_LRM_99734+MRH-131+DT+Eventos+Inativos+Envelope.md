# EVENTOS INATIVOS SENDO LANÇADOS NO ENVELOPE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Folha Mensal |
| **Situação/Requisito:** | Quando um evento que já está cadastrado para lançamento no Grupo de Eventos é marcado como Inativo, ele continua sendo lançado normalmente para o envelope do funcionário. |
| **Solução/Implementação:** | Ajuste no controle de eventos inativos para não permitir o lançamento do evento para o envelope, mesmo que já esteja cadastrado no Grupo de Eventos. |
| **Tickets relacionados:** | MRH-131 |
