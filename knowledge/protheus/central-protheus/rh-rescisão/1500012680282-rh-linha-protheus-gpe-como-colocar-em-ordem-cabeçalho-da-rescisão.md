**Dúvida**Como colocar em ordem cabeçalho da rescisão?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**

1- Via Configurador acesse  Base de dados/ Dicionário/ Base de dados/

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019713682)

2 - Dicionário de Dados

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019984641)

3- Clique na lupa

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019984681)

4- Busque pela tabela SRG

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019714142)

5- Abra os campos em editar

![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019714162)

6- Campos

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019714182)

7- Conseguirá ordenar os campos através das setas.

![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019984861)

![mceclip10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019714242)
