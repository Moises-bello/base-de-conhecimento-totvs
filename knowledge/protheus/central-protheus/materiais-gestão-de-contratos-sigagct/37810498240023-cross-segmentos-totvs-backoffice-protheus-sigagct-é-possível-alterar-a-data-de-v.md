**Dúvida**

Na inclusão de Caução Manual no SIGAGCT é possível alterar ou selecionar a data de vencimento do titulo PA da Caução que é gerada gerada ?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões

**Solução**

No padrão do rotina de inclusão de Caução Manual, a data de vencimento do título é gerada com a mesma data que sua data de emissão, que é a data base do sistema em que se está realizando essa inclusão da caução.

O sistema não possui uma funcionalidade ou parametrização para realização deste processo de se alterar o vencimento de uma Caução gerado através do módulo.

   
Caso deseje pode-se avaliar a possibilidade através de uma customização conforme a necessidade.
