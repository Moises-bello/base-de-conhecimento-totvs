Esta janela permite cadastrar e calcular tanto as faltas quanto as notas dos alunos.   
**Observação:**

* Quando o período letivo já estiver encerrado, não será permitido digitar as notas e faltas de etapas.
* Para encerrar o período letivo, é necessário marcar a opção período letivo encerrado, em Cadastro / acadêmicos / período letivo.
* Preenchendo o campo Nº de aulas dadas e mudando de campo ou salvando os dados o sistema irá perguntar se deseja atualizar o nº de aulas dadas para todos os alunos.
* Caso o parâmetro bloquear alterações de notas e faltas em Cadastros / acadêmicos / auxiliares / situação de matrícula / pasta status na disciplina esteja desmarcado não será possível digitar notas e faltas para os alunos que possuem esse status de matrícula
* Situação da Matrícula: Filtra alunos com a situação de matrícula na disciplina conforme regra abaixo:
  + Se o aluno **tiver** resultado final (aprovado, reprovado, etc), este filtro vai considerar a situação final do aluno;
  + Se o aluno **não tiver** resultado final, este filtro vai considerar a situação do aluno na disciplina;
* Os campos para digitação de falta não aceitam números com casas decimais.
* Os campos relacionados as nota, aceitam casas decimais conforme definido na disciplina da grade curricular.
