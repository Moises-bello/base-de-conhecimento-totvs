# Log Processos Exportação e Importação MATRIX

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Troca de Informações com o Matrix | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server®/ Oracle® |
| **Tabelas Utilizadas:** | SZHISTORICOSTATUS |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Melhoria consiste na criação de um registro do histórico do status, durante o processo de troca de informações com o **MATRIX**, possibilitando a consulta do status da exportação/importação.

## Procedimento para Utilização

**Enviar pedido para o Matrix**

1. Acesse o menu **Unidade Diagnóstico / Controle de Pedidos de Exame**.
2. Utilize o filtro desejado para listar os registros e clique em **OK**.
3. Selecione um ou mais registro na lista e clique em **Troca de informações com o Matrix**.
4. Utilize a opção **Exportar Todos os Pedidos**ou **Exportar Pedido Selecionado**.

**Visualizar o Histórico de Controle do Pedido Enviado para o Matrix**

1. Acesse o menu **Unidade Diagnóstico/Controle de Pedidos de Exame**.
2. Utilize o filtro desejado para listar os registros e clique em **OK**.
3. Acesse um registro que foi exportado para o **Matrix** (dê duplo clique no registro).
4. Ao acessar o registro selecionado no passo anterior (passo 3), selecione a aba **Histórico de Controle**.
5. Ao acessar a aba **Histórico de Controle** é possível visualizar que o histórico do envio para o **Matrix** foi registrado na coluna **Ação Executada**.

Observação

O processo é o mesmo para registros recebidos do **Matrix**.
