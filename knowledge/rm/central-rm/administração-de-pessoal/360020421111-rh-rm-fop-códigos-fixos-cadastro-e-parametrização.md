Dúvida**Qual o processo para cadastro e parametrização dos códigos fixos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, verifique o passo a passo orientado abaixo:  
  
1. Acesse: **Administração de Pessoal | Funcionários** e selecione o funcionário desejado. Logo, clique em **Anexos | Folha de Pagamento | Códigos Fixos**. Feito isso, cadastre um novo código fixo clicando no ícone **Incluir** e a tela abaixo será aberta.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4993870574103/mceclip0.png)  
  
Segue abaixo orientações dos campos do cadastro do código fixo:

* **Código do evento:** Irá selecionar o evento que deseja parametrizar como código fixo;
* **Valor:** Poderá informar o valor do evento, mas não é necessário preencher o campo;
* **Nº de Vezes de Lancto:** Deverá colocar o número de vezes que ele será lançado;
* **Tipo de Lançamento:** Esse campo é o que o sistema valida para realizar o lançamento do código fixo. Selecione se você deseja que este código fixo seja lançado na Folha, Rescisão, 13º Salário ou nas Férias.

**Importante**Para o campo **Nº de Vezes de Lancto,** o sistema irá contar cada lançamento realizada com o código fixo. Se em um mesmo mês o código fixo for lançado para folha, férias e rescisão, cada lançamento será contabilizado.  
  
Caso os tipos de lançamento já cadastrados não atendam completamente a demanda da empresa, é possível cadastrar novos tipos através das tabelas dinâmicas. Para saber mais sobre este tema, veja o artigo a seguir: [RH - RM - FOP - Tabelas Dinâmicas: Criando tipos de códigos fixos](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360015482951-RM-FOP-Tabelas-Din%C3%A2micas-Criando-tipos-de-c%C3%B3digos-fixos).
