PainelVisão Geral

## **VISÃO GERAL**

A página de "Resultados de Exame" permite o usuário consiga visualizar o resultado de todos o exames realizados, sejam este de imagem ou laboratoriais.

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Após efetuar o login no Portal do Paciente, o usuário será direcionado para a página "Home", onde poderá visualizar os resultados de exames realizados através dos links:

* Menu lateral > link "Agendar";
* Dashboard principal > link "Agendar consulta ou exame".

O sistema irá carregar os últimos 5 pedidos, caso seja necessário, o usuário poderá carregar mais pedidos clicando no botão "Carregar mais".

Resultado de Exame

## **RESULTADOS DE EXAME**

01. Após efetuar o login no Portal do Paciente, clicar no link "Resultados de Exame" localizado na barra de menu lateral ou no link "Resultados de Exame" localizado no dashboard principal.

02. O sistema irá carregar os últimos 5 pedidos, ordenados em forma cronológica do mais recente para o mais antigo. Exames cancelados não são incluídos nessa tela.

03. Clicar no botão "Carregar mais" para visualizar mais 5 pedidos.

Slider Exames / Baixar laudo

## **SLIDER EXAMES**

01. o sistema irá carregar todos os exames que estão dentro do mesmo pedido

Abaixo do nome do exame no card, será exibido o seu status. Pode ser algum dos seguintes status: Liberado, Emitido, Entregue, Liberado para Recepção, Cancelado, Reconvocado ou Pendente, a depender do exame.

## **05. BAIXAR LAUDO**

01. Clicar no botão "Baixar Laudo" para visualizar o resultado do exame em formato PDF.

02. O sistema irá abrir o resultado em uma nova aba do navegador, desta forma, o usuário poderá visualizar a informação, assim como realizar o download ou imprimir o resultado.

02. Clicar no botão "Baixar todos os laudos" para visualizar o resultado de todos os exame que possui laudo em formato PDF.

Historico Evolutivo

## **HISTÓRICO EVOLUTIVO**

01. Para exames laboratoriais, clicar no botão "Histórico" para visualizar o histórico evolutivo do exame.

02. O sistema irá carregar o histórico do resultado do exame em um modal.

03. Caso o exame possua apenas um parâmetro, o mesmo será exibido diretamente no modal.

04. Caso o exame possua mais de um parâmetro (por exemplo, hemograma completo), o sistema irá exibir abas clicáveis para que o usuário visualize cada parâmetro individualmente.
