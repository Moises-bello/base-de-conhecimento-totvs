# Lista de Campos:

---

Pela lista de campos você poderá visualizar os campos das tabelas e consultas SQL adicionadas ao relatório, bem como arrastar os campos desejados a suas bandas.  
Veja quais são os recursos:

**Listagem de Campos em árvore:** você visualiza os campos das tabelas adicionadas, bem como campos das consultas SQL e parâmetros. Para incluir os campos no relatório basta que você clique e arraste o campo à banda desejada.

**Barra de pesquisa:** Caso desejar encontrar um campo específico, você pode digitar o nome do campo na barra de pesquisa

.**Exibir Apenas Campos Utilizados**: Se quiser exibir apenas os campos de tabelas incluídas no relatório marque o parâmetro.
