# EXCLUSÃO DE CONTRATOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Exclusão de contratos que houvessem sidos contabilizados anteriormente |
| **Situação/Requisito:** | Ao tentar excluir um contrato que não possua parcelas e bolsas, cuja a contabilização, feita no modelo antigo e não integrado ao lote oficial, tenha sido estornada, o sistema não permitia a operação. |
| **Solução/Implementação:** | Foi realizada otimização do processo de estorno da contabilização não integrada ao lote oficial, para o modelo antigo de contabilização, de forma vínculos desnecessários seja removidos para permitir que um contrato que não tenha parcelas e bolsas possa ser excluído após o estorno da contabilização não integrada ao lote oficial. |
