# FREQUÊNCIA DIÁRIA - PORTAL DO PROFESSOR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Frequência diária - Portal do Professor. |
| **Situação/Requisito:** | A sugestão de aulas dadas na digitação de frequência diária não levava em consideração os horários das subturmas e sugeria um total de aulas incorreto. |
| **Solução/Implementação:** | A sugestão de aulas dadas toma como base também os horários na subturma. Desta forma, quando há uma ou várias subturmas cadastradas, a quantidade de horário informada em cada subturma será levado em consideração no cálculo do total de aulas. |
