# RESCISÃO COMPLEMENTAR ESTÁ LANÇANDO CC 51 QUANDO EXISTE PAGAMENTO DE DIFERENÇA 13o. DISSIDIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Complementar* |

| **Solução/Implementação:** | *Ajuste na Rescisão Complementar, para que o valor lançado no CC 180 só seja considerado como adiantamento, no CC 51, quando a diferença de 13o. for calculada após a demissão do funcionário.* |
