**Dúvida**Como Incluir uma nova espécie para que seja mencionada no campo F1\_ESPECIE ?  
  
**Ambiente**Protheus – Compras – A partir da versão 11.80  
  
**Solução**Para criar a espécie e que esta seja mencionada no campo F1\_ESPECIE no documento de entrada, segue procedimento:

1. Entrar no módulo do configurador
2. Escolher o Menu Base de Dados -> Dicionário -> Base de Dados
3. Clicar na opção do diretório Tabelas Genéricas
4. Pesquisar a tabela 42 conforme tela 1
5. Editar a tabela 42
6. Clicar em Itens no diretorio
7. Incluir a nova espécie na grid selecionando o ultimo registro e puxar uma linha abaixo para editar
