**Dúvida**  
Existe a possibilidade de alterar o logotipo da empresa na tela do Protheus?  
  
**Ambiente**  
Protheus - Smartclient - Todas as versões  
  
**Solução**  
Sim, é possível. Para realizar a mudança do logo de identidade do cliente, o administrador deverá criar uma imagem **.PNG** (Portable Network Graphics), e disponibilizar no diretório STARTPATH do Sistema, com a seguinte nomenclatura:  
**LGMID.PNG** - Para logo utilizado por todos os grupo de empresas  
**LGMID##.PNG** - Para logo utilizado para um grupo de empresas específico e filial. No lugar que foi informado o ## no exemplo, deverá ser informado o código do grupo de empresas e, caso necessário, filial. Ex.: LGMID01.PNG  
A dimensão recomendada para a imagem de identidade do cliente é de **165x160 pixels**.
