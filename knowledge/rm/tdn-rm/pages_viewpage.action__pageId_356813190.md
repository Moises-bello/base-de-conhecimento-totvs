# Mensagem de log para boleto próximo ao vencimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Log de mensagens (sucesso) do processo Agendamento/envio de mensagens para objetivo "Boleto próximo ao vencimento" |
| **Situação/Requisito:** | Ao executar o processo "Agendamento/envio de mensagens" com objetivo "Boleto próximo ao vencimento", o sistema não exibe os usuários que foram notificado no eduCONNECT. |
| **Solução/Implementação:** | Foi realizado um ajuste no TOTVS Gestão Educacional no processo "Agendamento/envio de mensagens", de maneira a disponibilizar no log final a lista de usuários que foram notificados para mensagem com o objetivo "Boleto próximo ao vencimento". |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | N/A |
| **Requisito:** | N/A |

divs

Aperfeiçoado o envio de mensagens aos pais do aluno quando este estiver matriculado em dois ou mais cursos.
