| **Situação/Requisito:** | *Ao cadastrar aluno como responsável financeiro pela tela de cadastro do aluno e o mesmo possuir um apóstrofo em seu nome, ocorre o seguinte erro: "Incorrect syntax near 'S'. Unclosed quotation mark after the character string ') /\*AND\*/ SET FMTONLY OFF; SET NO\_BROWSETABLE OFF;'.".* |
