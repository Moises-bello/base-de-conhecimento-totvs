# COPIAR PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Copiar processo seletivo* |
| **Situação/Requisito:** | *Ao utilizar o processo de cópia de processo seletivo de uma outra filial o sistema não está preenchendo corretamente a coluna "CODFILIAL" da tabela "SPSPARAMETROPS", o valor definido para a filial do novo processo seletivo gerado é 0, somente nesta tabela.* |
| **Solução/Implementação:** | *Foi identificado que o sistema não passava a filial do contexto do novo processo seletivo, assim o valor ficava como 0, foi feito o ajuste para que a filial seja salva corretamente no novo processo seletivo gerado pelo processo de cópia.* |
