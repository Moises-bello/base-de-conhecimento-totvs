Para o TOTVS Educacional, é considerado como irmão todo aluno que tem mesmo Pai ou Mãe ou Responsável financeiro.

Este cadastro tem importância para dar descontos para Irmãos.  
    
 A partir deste anexo é possível cadastrar Alunos que sejam Irmãos. É importante ressaltar que caso se altere o nome de algum aluno e este é irmão de algum outro aluno, a alteração é propaga e atualizada. O sistema disponibiliza um processo chamado de , localizado em Atividades Acadêmicas | Assistentes, cujo seu objetivo é efetuar este cadastro de forma automática de todos os alunos da coligada.
