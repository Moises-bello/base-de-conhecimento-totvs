# Pesquisa Plantonistas

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Registro de Atendimentos Externos | |
| **Chamados Relacionados** | TTNT79 |
| **Requisito (ISSUE):** | SAUHRM01-47 |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | MSSQL®, Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Implementada opção de pesquisa por médico plantonista no Registro de Atendimentos Externos. 

## Procedimento para Utilização

       1.            Acesse o menu **Unidades diagnóstico/Registro de Atendimentos Externos**.

       2.            Preencha as informações referentes ao atendimento e abrir a tela de pesquisa de prestador.

       3.            Selecione a opção "**Plantonistas**", digite o nome do médico e clique em um dos botões de pesquisa.
