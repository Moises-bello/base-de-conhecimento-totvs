# FORMA DE INSCRIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Forma de inscrição* |
| **Situação/Requisito:** | *Foi identificado que o sistema não estava permitindo duas formas de inscrição no processo seletivo com intervalos de datas diferentes, mesmo estes intervalos dentro do período do processo seletivo.* |
| **Solução/Implementação:** | *Ao cadastrar a segunda forma de inscrição o sistema validava a data como a da forma anterior e não com a do período do processo seletivo. Foi feito o ajuste na validação do período e as formas de inscrição passaram a permitir corretamente datas diferentes desde que dentro do período do processo seletivo.* |
