# IMPORTAR AUTÔNOMOS DE OUTROS BACKOFFICES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Importar autônomos de outros backoffices* |
| **Situação/Requisito:** | Ao marcar a opção "Importar autônomos externos(integrados de outros BackOffices)" a opção "Importar autônomos do RM Fluxus / RM Nucleus" continua habilitada no processo da SEFIP e Folha Analitica. |
| **Solução/Implementação:** | Ao marcar a opção "Importar autônomos externos(integrados de outros BackOffices)" a opção "Importar autônomos do RM Fluxus / RM Nucleus" deve ser desabilitada no processo da SEFIP e Folha Analitica. |
| **Chamados relacionados:** | TVLTJB |
