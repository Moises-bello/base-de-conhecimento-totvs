![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28479740743575)Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como corrigir a  mensagem rejeição "A informação não pode ser vazia, ela é obrigatória." "$.carga.identificacao", ao fazer o envio da DUIMP?  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus)  – Easy Import Control- a partir da versão 12.1.2310  
  
**Solução**Para que a rejeição não seja apresentada, é necessário preencher o campo Presença de Carga **(W6\_PRCARGA)**, no desembaraço de importação, na aba embarque, conforme o Help de campos e após isso faça a integração novamente.
