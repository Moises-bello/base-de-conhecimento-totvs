|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Parametrizador Funcionário - Chapa Sequencial |
| **Situação/Requisito:** | Quando o sistema está parametrizado para cadastro automático de  chapas sequencias e o parâmetro somente valida o dígito verificador da chapa está marcado, ao tentar cadastrar um funcionário, retorna erro, pois não conseguiu validar o sequenciamento das chapas. |
| **Solução/Implementação:** | Quando a opção de Validar Dígito Verificador estiver selecionado, a opção de chapa sequencial não ficará mais habilitada. |
