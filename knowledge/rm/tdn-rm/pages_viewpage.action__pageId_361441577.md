# Mensagem Validação Plano

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Mensagem de validação do Plano ao criar um atendimento externo de um agendamento. |
| **Situação:** | A mensagem solicitando que seja selecionado um plano está aparecendo antes da tela ser carregada, ao criar um atendimento externo de um plano quando não há plano selecionado no atendimento ou definido nos dados do cliente. |
| **Solução:** | Removida a mensagem de validação neste instante da tela. |
