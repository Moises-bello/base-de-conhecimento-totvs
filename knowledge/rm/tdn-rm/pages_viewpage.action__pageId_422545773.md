## **01. Inclusão**

Nesta opção, o usuário determinará os períodos de apuração para cada imposto. O sistema abrirá a tela de consulta/cadastro dos períodos e apresentará todos os períodos cadastrados conforme o exercício selecionado.

O sistema permite incluir novos períodos somente se a data estiver dentro do exercício corrente.

## **02. Exclusão**

Ao excluir um período de Apuração, o sistema verificará se existem Lançamentos Fiscais ou Movimentos no TOTVS Gestão de Estoque, compras e Faturamento neste período (se Sistema de Gestão Fiscal for integrado ao Sistema de Gestão de Estoque e Faturamento).

Caso exista, este período não poderá ser excluído. O sistema também não permite excluir os Períodos de Apuração que possuem guias cadastradas.

Só será permitida a exclusão de períodos que ainda não foram referenciados em alguma outra tabela do sistema.

## **03. Observações**

Ao informar Início de Período e Fim Período o sistema consiste a periodicidade do tributo informada em Cadastros | Tributos. O sistema apresenta mensagem quando o período informado não está conforme a periodicidade do tributo.

A partir da versão 12.1.27 na visão de período de apuração foi disponibilizado a tecla de atalho **F6** para execução do processo Abertura de Período e **F7** para Encerramento de Período.

A partir da versão 12.1.2406.100, o processo de o Cálculo dos DOCS não escriturados foi adicionado no encerramento do Período de acordo a parametrização necessária. Para mais informações sobre o processo, acesse a documentação do [Cálculo dos DOCS não escriturados](https://tdn.totvs.com/pages/viewpage.action?pageId=427048633).
