**Dúvida**

Como corrigir o erro no campo CKO\_CHVDOC no Importador de XML ou Totvs Colaboração?

![WhatsApp Image 2025-08-05 at 10.11.29.jpeg](https://totvssuporte.zendesk.com/attachments/token/rEXwihS7yIrUljQkvzWwieHvM/?name=WhatsApp+Image+2025-08-05+at+10.11.29.jpeg&lotus_request=true)

**Ambiente**

Protheus – Compras – A partir da versão 12

**Solução**

Para o campo CKO\_CHVDOC foi realizado um ajuste para que ele atenda as novas atualizações para status de documentos NFSe, para isso é necessário alterar o campo CKO\_CHVDOC para o tamanho 50.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/33958767110039)

Documentação referente a esse ajuste: [PROTHEUS - Tamanho do número de documento e série](https://tdn.totvs.com.br/pages/viewpage.action?pageId=896382488)
