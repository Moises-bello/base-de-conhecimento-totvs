# PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Classificação do candidato do processo seletivo. |
| **Situação/Requisito:** | A mensagem de validação do processo de classificação do candidato não estava esclarecendo corretamente qual o tipo de classificação não devia ter etapa cadastrada. |
| **Solução/Implementação:** | No processo de seletivo, para melhor entendimento, foi alterado a mensagem de validação da classificação do candidato, informando que os tipos de classificação “manual” e “por odem de inscrição” não devem ter etapas cadastradas na área de interesse ofertada.  Exemplo de mensagem: “Não existe nenhuma área ofertada para qual poderá ser executada a classificação manual. Para este tipo de classificação, não é permitido que a área de interesse tenha etapa cadastrada”. |
