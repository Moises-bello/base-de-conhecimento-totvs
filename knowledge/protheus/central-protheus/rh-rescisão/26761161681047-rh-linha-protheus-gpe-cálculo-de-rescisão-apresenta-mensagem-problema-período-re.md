**Dúvida**Cálculo de rescisão apresenta mensagem - Problema: Período referente a data de demissão já foi integrado:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26761161651607)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**O cálculo rescisão apresenta a mensagem Problema: Período referente a data de demissão já foi integrado, devido o roteiro RES mês vigente folha estar integrado. Para calcular rescisão o roteiro RES mês vigente folha não deve estar integrado.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26761569188503)

Acesse Miscelânea -> Cálculos -> Integrações -> Selecione o roteiro RES e Cancelar integração  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26761585591191)

Em seguida refaça o processo de cálculo de rescisão.
