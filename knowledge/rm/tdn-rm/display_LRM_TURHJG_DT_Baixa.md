# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | A 'Data Default de Baixa a Pagar' está definida nos parâmetros como 'Comp. Cheque', porém ao baixar o  lançamento o sistema busca a data de contabilização da data de baixa. |
| **Solução/Implementação:** | Otimização na baixa de lançamentos. Agora o sistema obedece corretamente a funcionalidade do parâmetro de Data  Default de Baixa a Pagar como Comp. Cheque que pega a data de Compensação do Extrato definido durante a baixa. |
| **Conversores e Parâmetros:** | N/A |
| **Chamados relacionados:** | TVCYN1 |
| **Requisito (ISSUE):** | FIN000040 |
