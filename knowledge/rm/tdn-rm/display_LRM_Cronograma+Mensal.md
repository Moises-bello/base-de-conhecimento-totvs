Foi desenvolvido no TOTVS Obras e Projetos, através do novo gerador (TOTVS Report) o Relatório de Cronograma Mensal que permite o usuário visualizar e/ou imprimir os dados de um cronograma mensal.  
    
 As informações disponibilizadas neste relatório poderão ser exportadas para o Microsoft Excel e outros aplicativos conforme padrão do gerador  de relatórios, proporcionando um melhor gerenciamento e controle das atividades associadas ao projeto.  
    
 Este relatório tem a finalidade de exibir a relação de atividades e a quantidade destas atividades que serão executadas no mês do plano operacional, apresentar o peso/custo da atividade e detalhar o uso dos recursos de mão de obra necessários para execução das atividades.

 Para visualizar o relatório o usuário deverá primeiramente gerar a "Curva S" do projeto selecionado e, em seguida acessar o menu Relatórios | Mobilidade | Cronograma Mensal.  
    
 A interface do relatório é composta pelos seguintes campos:  
    
 **Relatório:** Neste campo o usuário deverá escolher qual relatório deseja visualizar, o preenchimento deste campo é obrigatório.  
 **Peso da Tarefa:** Valor que determina o peso que a atividade a ser executada no mês tem como um todo.  
 **Períodos do Projeto:** Período no qual serão apresentados os dados do Cronograma.  
 **Tarefas do Projeto:** Tarefas cadastradas no projeto.  
    
 Após informar os dados nos filtros, o usuário deve acionar o Botão "Gerar" para exibição do relatório.  Caso o usuário não tenha informado nenhum filtro, o sistema exibirá um relatório com todos os registros cadastrados para o projeto selecionado pelo usuário.
