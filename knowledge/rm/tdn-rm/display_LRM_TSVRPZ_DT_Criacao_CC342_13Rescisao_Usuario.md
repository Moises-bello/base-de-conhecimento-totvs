# CC342 13o.RESCISÃO USUÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *13o.Rescisão* |
| **Situação/Requisito:** | *Cliente solicita criação de um novo código de cálculo, semelhante ao CC 48 - 13o.Rescisão, mas com o valor calculado pelo usuário.* |
| **Solução/Implementação:** | *Criação do novo código de cálculo 342 - 13º SALÁRIO RESCISÃO CALCULADO PELO USUÁRIO.*  *Este CC terá o mesmo tratamento do CC 48 - 13º SALÁRIO RESCISÃO, com a única diferença de que o lançamento e cálculo do valor serão de total responsabilidade do usuário.*  *O lançamento do CC 342 não inibe o CC 48.* |
