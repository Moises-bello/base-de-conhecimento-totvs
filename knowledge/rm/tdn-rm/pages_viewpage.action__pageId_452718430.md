**Classificação de Tipo de Rua**   
Cadastro utilizado para definição de códigos no Anexo "Codificação de Tipo de Rua" do cadastro de Logradouros. Esta classificação quando relacionada no parametrizador, em "De/Para de Endereço", no campo "Conceito de Classificação para Tipo de Rua", definirá qual código será levado para o eSocial.
