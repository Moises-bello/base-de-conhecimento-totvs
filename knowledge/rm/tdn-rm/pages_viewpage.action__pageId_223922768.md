# Número de Caracteres do Nome do Paciente na Agenda

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Agenda | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER e Oracle |
| **Tabelas Utilizadas:** | SZAGENDAMENTO |
| **Sistema(s) Operacional(is):** | Windows**®** |
| **Versões/Release:** | 12.1.8 |

## Descrição

Implementação na **Agenda**, de forma que aceite no campo "**Nome do Paciente**" até setenta caracteres.

## Procedimento para Utilização

1. Acesse **Atendimento / Agendamento / Agenda de Atendimentos**;
2. Selecione uma agenda com horários livres;
3. Selecione um horário para realizar o agendamento;
4. Informe o nome de um paciente com até 70 caracteres.
