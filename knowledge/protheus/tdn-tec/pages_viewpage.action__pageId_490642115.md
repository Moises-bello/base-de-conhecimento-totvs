### Application Server - Status de Versão em Notas de release

### 1) Status do Release:

Refere-se ao **status de homologação** onde a cada geração de um novo release, o terceiro numero que compõe a versão (17.3.**X**.Y) é incrementado e a nova versão passa por um teste sistêmico.

| Status | Descrição |
| --- | --- |
| RedAGUARDANDO HOMOLOGAÇÃO | Release em processo de homologação. |
| GreenHOMOLOGADO | Release já validado, homologado e disponibilizado para o cliente. |

### 2) Status de Versão:

Refere-se ao **status de liberação** de versões de binários **homologados** que podem conter **correções de bugs, vulnerabilidades ou melhorias**. Inicialmente, por meio do processo de **expedição oficial,** a versão é liberada aos times internos para validação e posterior publicação no Portal.

| Status | Descrição |
| --- | --- |
| Yellowem desenvolvimento | Versão encontra-se em desenvolvimento. |
| Blueem homologação | Versão encontra-se em testes pelos QA |
| GreenEXPEDIDO | Versão validada, expedida e liberada para o cliente. |
