# Itaquaquecetuba/SP - Lei de Transparência Fiscal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Municípios Homologados |
| **Situação/Requisito:** | Solicitação para geração das informações da lei da transparência fiscal no layout único do TSS para o município de **Itaquaquecetuba/SP.**  valcartri - Valor CargaTributária valpercartri - Percentual Carga Tributária valfoncartri - Fonte Carga Tributária |
| **Solução/Implementação:** | Foi implementado a geração das tags conforme orientação da prefeitura, seguindo o preenchimento dos campos abaixo:  **valcartri**: Valor total aproximado dos tributos TITMMOVFISCAL.VLRTOTTRIB **valpercartri**: Alíquota aproximada dos tributos somar: TPRDCODFISCAL.ALIQIBPTFEDERAL,TPRDCODFISCAL.ALIQIBPTESTADUAL, TPRDCODFISCAL.ALIQIBPTMUNICIPAL **valfoncartri**: Fonte do cálculo TITMMOVFISCAL.CHAVEIBPT |
