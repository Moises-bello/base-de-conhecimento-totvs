**Dúvida**Temos algum Ponto de Entrada para a rotina  **Cadastro de Importadores (EICA005)**, pois gostaria de validar alguns campos do cadastro tais como o Código do País, Estado, etc.?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**A rotina **EICA005** é feita em MVC, e neste caso, podem ser utilizados todos os pontos de entrada padrão do MVC.  
O nome do modelo de dados deste fonte,  é **"IMPP035"** com estas informações é possível customizar.
