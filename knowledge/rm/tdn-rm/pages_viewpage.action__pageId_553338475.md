### **DOCUMENTO DE REFERÊNCIA (NOVA VERSÃO - REVITALIZAÇÃO DO TDN)**

Artefato que apresenta os principais procedimentos realizados nos produtos TOTVS, e com o objetivo de orientar o cliente na execução das suas rotinas diárias. É composto pela ambientação, que expõe os itens de uso geral em todo o produto e as demais pastas que correspondem ao módulo, com um documento para cada programa.

**Artefato obrigatório na entrega do produto pronto;**

**Pode ser elaborado em qualquer etapa do Processo de Desenvolvimento Ágil.**

Para criação deste documento, você precisar estar logado no **TDN (TOTVS Developer Network)** e na *space* do seu Produto.

O template pode ser encontrado a partir do botão  e o documento está identificado como "**Documento de Referência (New)**".

---

O template contempla todas as informações necessárias para um bom documento de referência (help do produto). O preenchimento de todos os campos é obrigatório.

No item **04. TELA XXXXX Principais Campos e** Parâmetros, há um modelo para uso de box IMPORTANTE. Ele é muito útil para evidenciar alguma informação que o cliente deve se atentar. Caso não seja necessário, pode ser excluído.

Sempre que criar um **Documento Técnico** sobre uma inovação ou uma manutenção que afete o **Documento de Referência**, não se esqueça de atualizá-lo!

#### **Labels (tags/rótulos):**

As *tags* têm duas funções muito importantes para os documentos no TDN:

Garantir o funcionamento do *workflow* de aprovação das páginas, cujo fluxo é determinado pelas *tags* de artefato;

São utilizadas no mecanismo de busca da Central de Ajuda;

A utilização de *labels* é **obrigatório**, mas caso queira utilizar outras *labels* que possam facilitar a busca de páginas, é permitido, desde que sigam os padrões de construção de *labels* obrigatórias.

Para construí-las, é preciso seguir algumas regras:

Use apenas letras minúsculas;

Utilize \_ entre as palavras;

Não utilize caracteres especiais;

Não acentue as palavras;

Não insira espaços entre palavras.
