**TOTVS Obras e Projetos x BackOffice Protheus - Cadastro Unidade de Medida**

---

No Protheus são realizadas a inclusão, alteração e exclusão da unidade de medida. No TOP deverá ser permitido apenas a consulta dos registros, ou seja, as permissões de Incluir, Alterar e Excluir devem ser negadas. Os dados são sincronizados automaticamente.  
    
 ***Observação:***

Para o fator de conversão existe uma limitação de número de casas decimais. Neste caso, se a inclusão no TOP não for bem sucedida, a inclusão no Protheus não será concluída.   
    
 Para realizar inclusão, alteração ou exclusão no Protheus, acesse: Protheus | SigaCom (módulo padrão) | Atualizações | Cadastros | Unidade de Medida   
 Para visualizar as unidades sincronizadas no TOP, acesse: RM | BackOffice | Compras, Estoque e Faturamento | Cadastros | Mais | Tabelas Auxiliares | Unidade  
    
 **Dados Sincronizados**  
    
 Os dados sincronizados do Protheus para o TOP referente ao cadastro Unidade de Medida são:

* Código da coligada
* Código da unidade
* Descrição
* Código da unidade base
* Fator de conversão
* Se é unidade base ou não
* Quantidade de casas decimais Sigla
