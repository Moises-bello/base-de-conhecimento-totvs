**Pasta Pareceres - Requisição de Treinamento**

Os pareceres tem como objetivo registrar as alterações realizadas na requisição de Treinamento. Cada parecer estará sempre vinculado a uma única requisição, porém uma requisição poderá ter diversos pareceres. Para acessar o parecer de uma requisição de Treinamento o usuário deverá acessar a requisição desejada, Anexos | Parecer de Treinamento.

**Pasta Identificação do Parecer da Requisição de Treinamento**

Na pasta Identificação os seguinte dados devem ser informados:

**Emitido em -** Este campo exibirá a data e hora da emissão do parecer e não poderá ser alterado.

**Status -** Exibirá o status que a requisição assumiu conforme definição do fluxo de aprovação, porém, se a requisição não tiver sido incluída no fluxo, ou seja, quando o controle estiver sendo feito manualmente, este campo poderá ser alterado. Esta alteração será possível apenas no Totvs Gestão de Pessoas.

**Parecer emitido -** Deve conter o texto do parecer emitido pelo usuário.

**Responsável -** Somente podem ser selecionados chefes da coligada em que o usuário está logado. Para informações relacionadas aos chefes das seções verifique o cadastro de chefes e supervisores. **Filial/Função e E-mail -** Após preenchimento do campo "Responsável" os dados relacionados a estes campos serão exibidos automaticamente. O campo "Filial/Função" deve exibir o nome da filial seguido do nome da função de lotação do funcionário selecionado no campo "Responsável". Em caso de alteração do nome do responsável, o conteúdo desde campo deverá ser automaticamente atualizado. A informação do campo "E-mail" deverá ser automaticamente atualizada com o e-mail que constar no cadastro do responsável indicado. Para confirmar esta informação acesse Acompanhamento | Pessoas | Pasta Identificação.

**Pasta Dados da Requisição do Parecer de Treinamento**

Na pasta Dados da requisição podem ser visualizados os seguintes dados:

**Requisitante -** Pessoa que solicitou o treinamento.

**Justificativa -** Justificativa do Treinamento.

**Curso -** Curso no qual será realizado o treinamento.

**Entidade -** Entidade que ministra o Curso escolhido para o treinamento.

**Previsão -** Data prevista para início do treinamento.

**Data prevista final -** Data prevista para final do treinamento.

**Hora início -** Hora prevista para início do treinamento.

**Hora fim -** Hora prevista para fim do treinamento.

**Carga horária -** Carga horária prevista para o treinamento.

**Pasta Treinados - Parecer da Requisição de Treinamento**

Na pasta Treinados podem ser visualizado/alterado os seguintes dados:

**Aprovado -** Deverá ser informado se o treinado está aprovado ou não para realizar o treinamento.

**Chapa -** Deverá ser informada a chapa do funcionário que realizará o treinamento.

**Tipo demanda -** Deverá ser informado o tipo de demanda para o treinamento.
