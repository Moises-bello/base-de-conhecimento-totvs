# Ajuste na Tela de Controle de Ocupação de Leitos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Na tela de controle de ocupação de leitos, o sistema exibia alas vinculadas à unidades de atendimento que o usuário não tinha acesso. |
| **Solução:** | Realizado ajuste na tela de controle de ocupação de leitos para exibir somente alas vinculadas às unidades de atendimento que o usuário tenha acesso. |
