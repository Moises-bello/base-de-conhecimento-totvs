Disponibilizado o processo de Qualificação de Fornecedores. Através do processo de [Qualificação de Fornecedores](http://tdn.totvs.com/pages/viewpage.action?pageId=423938862) pode-se avaliar e definir se o fornecedor está qualificado para fornecer produtos/serviços, conforme requisitos pré-definidos pela empresa.

Disponibilizada a importação/exportação de dados do TOTVS Gestão de Estoque, Compras e Faturamento via Conceito e Gerador de Saída, estão disponíveis para importação e/ou exportação os seguintes processos:

1. [Produto](http://tdn.totvs.com/pages/viewpage.action?pageId=423938138)
2. [Movimento](http://tdn.totvs.com/pages/viewpage.action?pageId=423938143)

Migração das seguintes rotinas para .Net:

1. [Importação de Cotação Web](http://tdn.totvs.com/pages/viewpage.action?pageId=423938016)
2. [Lotes de Exportação Contábil](http://tdn.totvs.com/pages/viewpage.action?pageId=423937996)
3. [Relatório de Previsão de Faturamento de Contrato](http://tdn.totvs.com/pages/viewpage.action?pageId=423938763)
4. [Importação de dados via XML - Integração Ponto de Venda](http://tdn.totvs.com/pages/viewpage.action?pageId=423937950)

Melhorias no processo de conclusão do [movimento integrado ao TOP](http://tdn.totvs.com/pages/viewpage.action?pageId=423938740). Criado o parâmetro para permitir a alteração da quantidade do movimento gerado pelo TOP. Quando a quantidade efetivada é inferior à solicitada, passou a ser possível fazer o estorno da quantidade não pedida para o TOP. Nesse caso, é possível gerar outro movimento da quantidade restante.
