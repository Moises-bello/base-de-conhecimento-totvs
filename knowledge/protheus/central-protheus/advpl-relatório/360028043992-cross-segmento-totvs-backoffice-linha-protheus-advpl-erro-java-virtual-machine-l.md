***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura: **00:02:00 min*** **Dúvida**

Ao executar pelo menu o relatório BIRT gera erro or log.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028341132/mceclip0.png)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – ADVPL – A partir da versão 11.80

**Causa**

Esse erro ocorre pois a chamada no menu está com o Tipo errado "Relatorio iReport"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028341752/mceclip1.png)  
  
**Solução**Modifique para Tipo "Função de Usuário"

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/360028341832/mceclip2.png)**
