# MENU DE ESCRITURAÇÃO DE LANÇAMENTOS FISCAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | BackOffice. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Menus dos Sistema. |
| **Situação/Requisito:** | Ao criar uma nova coligada o Menu de Escrituração de Lançamentos disponível em Integrações não estava disponível ao usuário para acesso, pois o campo DPARAMETROS.HABILITAESCRITURACAO é criado com 0 em novas coligadas. |
| **Solução/Implementação:** | A partir de agora, o sistema não irá verificar se o parâmetro DPARAMETROS.HABILITAESCRITURACAO é igual a 1 para habilitar o Menu. Ao criar uma nova coligada, o Menu de Escrituração de Lançamentos disponível em Integrações será **habilitado sempre**. |
| **Conversores e Parâmetros:** | Integrações | Escrituração de Lançamentos. |

| **Requisito:** | MATESTCNTFTOF01-6094. |
