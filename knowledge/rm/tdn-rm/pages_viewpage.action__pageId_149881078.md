| **Sintoma** | **O que é um "código de cálculo"?** |
| Solução | Código de cálculo é um campo da tabela de eventos, representado por um número, cujo significado está associado a uma tabela interna criada pela TOTVS. Este número indica para o RM Labore qual a natureza do evento, de forma que o sistema possa calcular o valor de alguns deles automaticamente (como acontece com o INSS, IRRF, salário família, desconto do vale transporte, etc.) e/ou identificar valores para relatórios oficiais (como é o caso de honorários pagos e assistência médica, por exemplo) ou para o próprio cálculo de outros eventos (como é o caso de DSR perdido, base de INSS em outros empregos, total entregue de vale transporte, etc).  Alguns eventos estão previamente vinculados a um código de cálculo. Outros exigem a criação de fórmulas para serem calculados. Nada impede, no entanto, que se criem fórmulas para os eventos associados a códigos de cálculo. Neste caso, o sistema dará prioridade às fórmulas. |
