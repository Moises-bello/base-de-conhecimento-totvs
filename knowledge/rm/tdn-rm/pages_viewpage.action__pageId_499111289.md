A atividade Incluir Lançamento Contábil permite informar os dados do lançamento. As principais propriedades existentes nela são:

* **Lote referenciado:** Faz referência a atividade em que foram informados os dados do lote. Essa é uma propriedade obrigatória, pois para incluir o lançamento é necessário informar o lote.
* **CodDiario:** Campo não utilizado no Brasil.
* **CodLancamento:** Identificador do lançamento. Essa propriedade deve ser associada a uma atividade responsável por auto incrementar o identificador do lançamento.
* **DescLancamento:** Descrição do lançamento.
* **IntegraChave:** Esse campo já foi utilizado para indicar a integração entre um módulo contábil e as origens que envia contabilização.
* **SeqDiario:** Campo não utilizado no Brasil.
