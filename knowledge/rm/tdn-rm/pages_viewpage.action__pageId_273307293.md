# Cadastro da Baixa da Avaliação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Patrimonial |
| **Função:** | Contabilização de baixa da avaliação |
| **Situação/Requisito:** | Ao contabilizar a baixa de patrimônios avaliados o sistema não obedece a parametrização de execução do processo de baixa e incorretamente solicita o preenchimento das contas para apuração de perda ou ganho. |
| **Solução/Implementação:** | O processo de contabilização de baixa da avaliação foi alterado para que as contas de apuração de perda ou ganho não sejam apresentadas quando o parâmetro "Apura perda e ganho", existente no processo de baixa, estiver desmarcado. |
