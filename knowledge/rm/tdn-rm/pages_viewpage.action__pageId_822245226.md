---

Para a versão 12.1.2402 do RM, o TGM requer a instalação dos seguintes requisitos:

ASP.NET Core 6.0solid

**Informações de download**

---

Para baixar a versão mais atualizada do ASP.NET Core 6.0, acesse o link: <https://dotnet.microsoft.com/pt-br/download/dotnet/6.0>
