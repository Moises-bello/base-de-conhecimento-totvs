![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **01:30 min** **Dúvida**Por que rescisão pedido de demissão aviso prévio trabalhado não calcula média aviso prévio id 0250?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**A rescisão pedido de demissão aviso prévio trabalhado não calcula média aviso prévio id 0250, devido o tipo de rescisão pedido demissão. A média aviso prévio id 0250 só será calculado para tipo de rescisão onde ocorra o pagamento da indenização aviso prévio (em tipo de rescisão dispensa pelo empregador ou rescisão acordo 484-A da CLT).
