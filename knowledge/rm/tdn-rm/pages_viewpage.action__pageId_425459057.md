Para configurar o gabarito é necessário o preenchimento de alguns campos:

* Período letivo: Selecione o período letivo correspondente a etapa e avaliação aos quais o gabarito será aplicado
* Cód. Gabarito / Descrição: Insira um código e uma descrição. Estes tem como objetivo identificar o gabarito.
* Cód. Etapa / Cód. Prova: Selecione um código para a etapa e um para a prova.
* Descontar questão certas a cada errada: Quando o parâmetro é marcado, o sistema anula automaticamente um resposta certa quando o aluno marca uma resposta errada.

Estas etapas/provas não têm relacionamento direto com as etapas cadastradas no sistema, ou seja, é possível informar etapa 999 sem que a mesma exista. Todavia, o sistema irá verificar se a etapa existe no "Processo de correção de gabarito"
