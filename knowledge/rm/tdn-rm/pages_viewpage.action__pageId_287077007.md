# Retorno de Cobrança Eletrônica

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Financeira |
| **Função:** | Retorno de Cobrança Eletrônica |
| **Situação/Requisito:** | Sistema não estava respeitando o parâmetro  "No retorno bancário utilizar os valores do arquivo, sobrepondo os do lançamento" quando marcado e assim não gravando os valores de acordo com o arquivo de retorno de cobrança |
| **Solução/Implementação:** | Será gravado os valores de juros, multa, desconto e opcionais do arquivo de retorno bancário quando o parâmetro "No retorno bancário utilizar os valores do arquivo, sobrepondo os do lançamento" estiver marcado |
| **Conversores e Parâmetros:** | "No retorno bancário utilizar os valores do arquivo, sobrepondo os do lançamento" |

| **Requisito:** | FIN000172 |
