No menu Brinde na Compra o usuário poderá criar cadastros de brindes, que serão associados posteriormente a uma proposta. Estes brindes poderão também ser exibidos no contrato da proposta.

Para adicionar algum brinde na compra, basta acessar o menu Pré-Venda>>Brinde na Compra, ou então basta que as proposta tenham brindes cadastrados, que na simulação da proposta serão listados os brindes cadastrados.

Nesta opção você deverá associar o brinde da proposta ao empreendimento desejado, basta clicar no botão Adicionar.

Será exibido a tela de cadastro do brinde, com os campos:  
Dados do Brinde na Compra:

* **Nome:** Nome que será informado para este novo cadastro;
* **Valor**: Campo onde é inserido o valor monetário do brinde;
* **Descrição**: Campo para detalhar informações sobre este brinde;
* **Ativa**: Campo para marcar se o brinde está ativo (disponível para ser selecionado) ou inativo (não disponível), permitindo o controle do uso desse brinde;
* **Empreendimento**: Seleção do empreendimento específico onde o brinde será válido, vinculando o brinde a um local ou unidade específica; (será necessário selecionar antes da seleção do produto);
* **Produtos e Quantidade**: Permite a especificação dos produtos que o cliente deve adquirir para se qualificar para o brinde, incluindo a quantidade necessária de cada produto;
* **Adicionar**: Botão para adicionar produtos e quantidades à lista para a obtenção do brinde, permitindo configurar diferentes combinações de produtos e quantidades;
* **Salvar**: Botão para salvar o cadastro do brinde com todas as informações configuradas;

**Pesquisa de Brinde na Compra**

É possível realizar a pesquisa do brinde na compra pelo "Nome", "Descrição" ou "Empreendimento", adicionando alguma das informações do brinde desejado no campo "Pesquisa".

Outra possibilidade de ordenação será utilizando a seta na coluna "Nome"  em ordem crescente ou decrescente.
