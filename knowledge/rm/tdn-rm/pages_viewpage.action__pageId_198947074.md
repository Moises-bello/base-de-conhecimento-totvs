# Como habilitar ou desabilitar o botão Escolha de Lote na Movimentação de Estoque

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.82.39.x e 12.1.5.x |
| **Ocorrência:** | Durante uma movimentação de estoque, na escolha do Item o botão para escolha do lote está desabilitado |
| **Passo a passo:** | Acesse o TOTVS GESTÃO HOSPITALAR (RM Saúde).  Acesse o menu Opções / Parâmetros / Parâmetros Gerais.    Na aba "Estoques II"  Logo abaixo do parâmetro para escolha de Utilizar ou não o método PEPS para escolha do lote.    Ao marcar o parâmetro para utilizar o método PEPS, o checkbox abaixo é liberado    Com este checkbox marcado, é possível alterar o Lote/Validade de um produto no momento da movimentação de estoque. |
| **Observações:** | Este parâmetro foi implementado a partir da versão 11.82.39.004 do RM Saúde. |
