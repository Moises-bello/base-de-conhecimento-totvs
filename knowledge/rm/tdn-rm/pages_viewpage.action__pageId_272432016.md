# MUDANÇA DE TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | Mudança de Turma |
| **Situação/Requisito:** | *No processo de mudança de turma, ensino básico, o sistema apresentou mensagem de “Disciplina: 01 - Violação de chave estrangeira”. Somente ocorria quando o mesmo código da Turma existia em períodos letivos diferentes.* |
| **Solução/Implementação:** | Otimizado processo de mudança de turma, ensino básico, para permitir transferir o aluno de uma turma que tenha o mesmo código da turma em períodos letivos diferentes, por exemplo Turma 01 existe no período letivo 2016 e 2017. |
