# Filtro de Coligada/Filial/Departamento dos relatórios contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Filtro de Coligada/Filial/Departamento dos relatórios contábeis |
| **Situação/Requisito:** | Ao imprimir o Balancete, utilizamos 'Ativar Filtro' na parte 'Selecionar Coligada / Filial / Departamento'. Marcamos apenas a Filial e deixamos suas dependências desmarcadas. Gerando o relatório tudo funciona normalmente, entretanto quando clico em 'Voltar' para gerar novamente escolhendo uma nova data, as dependências da 'Filial' aparecem marcadas. |
| **Solução/Implementação:** | Ajuste no controle do filtro por Coligada/Filial/Departamento para que ao marcar uma filial sem marcar os seus departamentos, executar o relatório e clicar em 'Voltar' para executar o relatório novamente os departamentos não fiquem marcados. |
