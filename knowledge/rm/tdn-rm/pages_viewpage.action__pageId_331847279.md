# Implementado o Tipo de Afastamento Mandato Sindical Ônus Emrpegador

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Folha de Pagamento |
| **Módulo:** | Afastamento |
| **Solução/Implementação:** | Implementado um novo tipo de afastamento (N - Mandato Sind. Ônus Empreg.) |
| **Requisito:** | [FOPCALCULO01-1711](http://jiraproducao.totvs.com.br/browse/FOPCALCULO01-1711) |

Conforme necessidade de clientes, foi criado um novo tipo de afastamento. Nomeado **N - Mandato Sind. Ônus Empreg.** ele deverá ser cadastrado, quando um funcionário foi eleito para o sindicato, mas ainda continuará sendo custeado pela empresa.

No cadastro do afastamento para o funcionário, estará disponível o tipo N.

Selecionando-o para o funcionário, ele ganhará estabilidade, enquanto continuará recebendo normalmente da empresa com todos os direitos.
