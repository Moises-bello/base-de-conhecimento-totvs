# INCLUSÃO DE SERVIÇO EXTRA VIA SESSÃO DE CAIXA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Inclusão de serviço extra* |
| **Situação/Requisito:** | *Ao tentar incluir um serviço extra, através da sessão de caixa, para um aluno que possua em seu contrato mais de um responsável financeiro, o sistema acusa erro não gerando assim, a parcela e seu respectivo lançamento financeiro. O erro ocorre ao retornar a identificação dos lançamentos financeiros criados, através de um mapeamento único entre parcela e lançamento financeiro. Quando a parcela possui dois ou mais lançamentos financeiros, ocorre erro ao tentar incluir um novo mapeamento para a mesma parcela..* |
| **Solução/Implementação:** | *Foi realizada otimização do registro de serviço extra, através da sessão caixa do sistema TOTVS Gestão Financeira, de forma a permitir a inclusão de serviço extra para quando o aluno possui mais de um responsável financeiro em seu contrato.* |
