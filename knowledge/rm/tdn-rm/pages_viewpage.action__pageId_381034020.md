# GERAÇÃO DE MOVIMENTO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de movimentos em regime de competência |
| **Situação/Requisito:** | Para algumas situações específicas, a data de competência final, para movimentos, do período letivo estava sendo registrada com o primeiro dia do mês, fazendo com que o processo de geração de movimento não encontrasse nenhuma competência a ser processada. |
| **Solução/Implementação:** | Foi realizada otimização do cadastro de período letivo, de forma que o sistema registre a data final de competência para a geração de movimento utilizando sempre o último dia do mês da competência final. |
