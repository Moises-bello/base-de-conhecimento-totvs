# PORTAL DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Widget - Boleto próximo do vencimento. |
| **Situação/Requisito:** | No portal do aluno podemos habilitar um widget que exibe informações do boleto próximo ao vencimento. Neste widget podemos realizar a visualização do boleto e pagamento via cartão. Como no sistema podemos parametrizar se um determinado serviço pode ser pago via cartão de crédito e/ou débito, o widget não respeitava esta parametrização e sempre exibia a opção de pagamento via cartão, mesmo que o serviço não permitisse o pagamento. Obs.: Na visão de extrato financeiro o sistema exibia as opção com o comportamento correto. |
| **Solução/Implementação:** | Ajuste no widget de "Vencimento do próximo boleto" para que o botão de pagamento com cartão tenha o mesmo comportamento de visualização da tela de extrato financeiro. |
