![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20533380976407) Tempo aproximado para leitura: **00:00:40 min****Ocorrência**  
No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para encontrar o ponto de entrada **AG35DMNU** é apresentada a ocorrência **Ponto de Entrada AG35DMNU**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é necessário realizar o processo para encontrar o ponto de entrada **AG35DMNU** no Sistema.  
  
**Solução**  
Para solucionar essa ocorrência, o **Ponto de Entrada** é o **AG35DMNU** serve para incluir novos itens no menu das **Ações Relacionadas**.
