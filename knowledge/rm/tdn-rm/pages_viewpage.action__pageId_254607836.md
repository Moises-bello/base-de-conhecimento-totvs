# Mudar Turma / Turno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Mudança de Turma / Turno |
| **Situação/Requisito:** | Ao realizar o processo de mudança de turma para um aluno do ensino básico que foi trocado de turma outras vezes o sistema não esta respeitando o parâmetro "Aproveitar Contrato". |
| **Solução/Implementação:** | Melhoria no processo de mudança de turma para o ensino básico para que o parâmetro “Aproveitar contrato” seja aplicado também quando o aluno já esteve matriculado na turma. >> Aluno matriculado “turma A” transfiro para a “turma B” => Aproveita contrato >> Mesmo aluno transfiro da “turma B” para “turma A” => Também tem que aproveitar o contrato |
