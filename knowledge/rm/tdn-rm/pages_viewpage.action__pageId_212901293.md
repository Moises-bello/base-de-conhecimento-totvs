# GERAR LANÇAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Gerar Lançamento* |
| **Situação/Requisito:** | *Quando ocorrer baixa automática de um lançamento, o cliente necessita que seja gravado data de vencimento nas informações: data de baixa e data de contabilização de baixa, independente da parametrização já apresentada para os demais lançamentos baixados* |
| **Solução/Implementação:** | *Implementado os seguintes parâmetros Educacional de integração financeira, que permitirá durante uma baixa automática, gravar a data de vencimento nas informações de "data de baixa" e "data de contabilização de baixa":  parâmetros "Data da baixa igual ao vencimento" e "Data de contabilização de baixa igual ao vencimento" Obs.: Os novos parâmetros somente serão habilitados se estiver marcado o item "Baixar automaticamente lançamentos com valor liquido igual a zero" e não utilizar integração com sistema Protheus.* |
