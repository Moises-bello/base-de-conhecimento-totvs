**Dúvida**Como corrigir a mensagem "Não foi encontrado o código do despachante na relação DE/PARA"?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4406506701207/mceclip0.png)  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**

1. Selecione o menu Atualizações\Miscelânea\Tabela De\Para.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4406506849559/mceclip2.png)

2. Selecione incluir.

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4406506886935/mceclip3.png)

3. Preencha os  campos e o código do despachante enviado no arquivo de integração conforme layout:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4406507154839/mceclip5.png)
