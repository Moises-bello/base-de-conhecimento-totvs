# OPÇÕES PARA CÁLCULO NO RELATÓRIO DE EXTRATO DE CLIENTE/FORNECEDOR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Relatório de Extrato de Cliente/Fornecedor. |
| **Situação/Requisito:** | Sistema calculava incorretamente os valores de inclusão e baixa, havendo diferenças entre o que era apresentado entres diferentes versões. |
| **Solução/Implementação:** | A opção "Usa valor do adiantamento para obter o valor do lançamento" passa a ser chamada "Considerar Valor de Adiantamento para obter o valor do lançamento". Quando marcada o Valor de Adiantamento será subtraído do valor do lançamento ao carregar o saldo anterior e os extratos. Essa opção funcionará independente da outra existente "Subtrair impostos e tributos do valor do lançamento". |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | 572905. |
| **Requisito:** | FINANCEIRO01-132. |
