Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**. 

A finalidade desse componente é notificar o usuário por e-mail caso ocorra alguma falha no processo.

Este componente é muito parecido ao MailSender, porém o que os diferencia é que o MailNotifier só pode ser ligado ao componente OnError.

Para maiores informações referente as propriedades disponíveis do componente, acesse a descrição da tela .
