**Assistente de Lançamento Manual**

Este processo tem a finalidade de fazer o lançamento manual das notas (respostas) aplicadas na avaliação, tendo a possibilidade de avaliar todos os participantes de uma só vez.

**Atenção:** Quando há integração com o RM Testis este processo não pode ser executado. Uma mensagem de aviso será exibida para o usuário:

*"Este processo não pode ser executado, pois a avaliação não foi exportada para o RM Testis".*

Caso queira informar os resultados manualmente deverá desmarcar a integração com o RM Testis.
