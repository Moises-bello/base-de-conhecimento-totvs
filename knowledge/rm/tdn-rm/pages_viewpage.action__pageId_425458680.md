É possível manter o histórico de ingresso do aluno no curso/habilitação, onde o usuário pode armazenar as informações de ingresso do aluno no curso.

**Exemplo:** Um aluno ingressou no curso no ano de 2000 e foi jubilado no ano de 2010, e para que este aluno possa ingressar no curso novamente, ele deve realizar um novo processo seletivo (vestibular). Ao realizar matrícula do aluno no mesmo curso, os dados do ingresso anterior serão armazenados em forma de histórico, facilitando o controle sobre o histórico de ingressos do aluno no curso.  
 A inclusão de um histórico de ingresso pode ser realizada de três maneiras:

* Via histórico de ingresso onde o usuário pode realizar o cadastro informando os dados necessários.
* Ao alterar a "Data de ingresso" do aluno no curso. Ao realizar uma alteração nesta data, o sistema, caso o usuário queira, armazenará os dados do histórico anterior.
* Ao realizar matricula via processo seletivo (RM ou Terceirizado). Quando um candidato(ex-aluno) realizar a matricula via processo seletivo, o sistema irá incluir um registro no histórico de ingresso com os dados anteriores e atualizará os dados do "Ingresso" para os dados da matrícula atual.

**Observações:**  
 Também é possível armazenar o histórico das provas realizadas nos processo seletivos, para isso o sistema conta com um anexo para históricos de avaliações, que pode ser acessado via histórico de ingressos.
