**Dúvida**Como corrigir Help AVG0000094 - Problema: Data de Declaração de Transito Aduaneiro não informada?

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405304591895/mceclip2.png)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução** É necessário preencher a data no campo **Dt. Decl.Adua** (W6\_DT\_DTA), aba **cadastrais** do Desembaraço:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405304672279/mceclip3.png)
