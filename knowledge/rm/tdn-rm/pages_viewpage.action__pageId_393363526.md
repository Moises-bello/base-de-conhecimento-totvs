# Adequação do Status da Importação no relatório descritivo de Cultura Parcial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Controle de Infecção Hospitalar |
| **Função:** | Apoio Gerencial > Culturas > Parcial |
| **Requisito:** | Com a nova implementação de Validação do Status de Importação da Cultura Parcial, no relatório Descritivo de Cultura Parcial,o registro da cultura Parcial continua constando |
| **Solução:** | Com a nova implementação de Validação do Status de Importação da Cultura Parcial, no relatório Descritivo de Cultura Parcial,o registro da cultura Parcial que teve seu status da importação validado, ou seja alterado de 0 para 1, não aparece mais no relatório |
