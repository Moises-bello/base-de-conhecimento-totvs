![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21468196988951) Tempo aproximado para leitura: **00:00:30 min****Dúvida**Como realizar **Configuração dos Menus**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12.1.23  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

**1.** Verifique o **Configurador - SIGACFG**, acesse **Ambientes/Cadastro/Menu (CFGX013)**. Informe a nova opção de menu, *informe **o nome do módulo***, conforme instruções a seguir.

|  |  |
| --- | --- |
| **Menu** | Informe o Menu em que estará localizada a rotina |
| **Submenu** | Informe o Submenu em que estará localizada a rotina |
| **Nome da Rotina** | Informe o Título da rotina |
| **Programa** | Informe o Fonte da rotina |
| **Módulo** | Informe o Nome do(s) produto(s) a ser utilizado ou “Todos” |
| **Tipo** | Informe a Função |
