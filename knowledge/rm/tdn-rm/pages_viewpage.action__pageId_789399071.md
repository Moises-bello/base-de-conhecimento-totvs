O menu "**Mais opções"** dará acesso ao restante dos itens de menu. O menu será acessado na parte inferior direita do aplicativo.

**Observação:** Caso o celular esteja em modo paisagem, o menu se autoajustará para que o acesso aos itens seja feito de forma mais confortável, conforme abaixo:

Ordenação dos menus

O aplicativo permite que o usuário configure a ordem dos itens do menu de acordo com sua preferência no dispositivo que esta sendo utilizado (Esta ordenação é por dispositivo, ou seja, caso seja feito um acesso em outro dispositivo o menu será ordenado de forma padrão).

Gerenciar armazenamento

Este recurso visa otimizar o espaço no dispositivo, permitindo a exclusão de imagens da **Agenda Infantil** acumuladas no app: **Meu eduCONNECT**.

Na seção **"Gerenciar armazenamento"**, o usuário encontra:

1. **Tamanho do arquivo armazenado:** Indica o espaço total ocupado pelos downloads no dispositivo.

1. **Manter os últimos:** Oferece filtros por período (**7, 30, 90 ou 360 dias**) para exclusão seletiva ou limpeza total. Ao confirmar a ação, o sistema remove os arquivos antigos de forma **definitiva** para liberar memória no celular.

Ao selecionar um determinado período, será exibido o botão **'Limpar armazenamento'**. Em seguida, uma mensagem de confirmação será apresentada para que o usuário valide a exclusão dos arquivos armazenados.
