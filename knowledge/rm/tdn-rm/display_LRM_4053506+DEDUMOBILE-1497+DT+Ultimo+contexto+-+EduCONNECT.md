# Definição do último contexto do usuário do eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Seleção de contexto |
| **Situação/Requisito:** | Ao logar no Educonnect com algum aluno e clicar em qualquer menu, o aplicativo sempre pede que seja selecionado um período letivo/contexto.  No portal o sistema memoriza o último contexto acessado pelo aluno e não fica pedindo toda vez que o usuário faz login. |
| **Solução/Implementação:** | Aprimorada a usabilidade do eduCONNECT na seleção do contexto no Acadêmico, quando o usuário se tratar de um responsável. Agora é o último contexto definido é salvo, e você não precisa ficar definindo-o todas as vezes que você entra no Acadêmico. |
