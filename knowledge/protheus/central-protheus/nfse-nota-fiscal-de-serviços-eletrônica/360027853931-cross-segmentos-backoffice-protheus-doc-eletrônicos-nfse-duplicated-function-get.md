**Ocorrência**Ao aplicar um Patch está ocorrendo o erro: **duplicated function GETMUNSIAF (FOUND in FISA022.PRW).**  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.  
  
**Causa**O problema está sendo causado por estar aplicando um Patch do TSS no RPO do Protheus.

**Solução**Valide se o Patch está sendo aplicado no RPO correto.
