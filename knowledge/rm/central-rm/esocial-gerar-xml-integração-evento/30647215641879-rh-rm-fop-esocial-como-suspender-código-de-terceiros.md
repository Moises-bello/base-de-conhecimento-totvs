![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30647188335127) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como enviar ao governo a suspensão de código de terceiros?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - Todas as versões.  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:  
1. Necessário cadastrar o Processo Administrativo / Judicial e enviar o S-1070 ao governo. Para mais informações [CLIQUE AQUI](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360008847432-RH-RM-FOP-eSocial-Cadastro-do-evento-S-1070-Tabela-de-Processos-Administrativos-Judiciais);

1.1 XML S-1070 gerado com os dados do Processo. É necessário ajustar o a competência do evento, para que a vigência do S-1070 seja gerada corretamente;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30647188335383)

2. Após, acesse a **Administração de Pessoa | Seções | Edite a Seção Desejada | Dados p/ INSS**e informe a **Cod. Recolhimento Suspenso para Terceiros** que foi definido no processo**.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30647188336791)

2.1 Se a suspensão for completa, conforme exemplo supracitado, é necessário detalhar cada código de acordo com a descrição e FPAS da empresa, definidos na [Tabela 04 - Códigos e Alíquotas de FPAS/Terceiros](https://www.gov.br/esocial/pt-br/documentacao-tecnica/leiautes-esocial-versao-1-3-nt-02-2024-rev-29-10-2024/tabelas.html);

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30647188337943)

2.2. Para isto, acesse na seção Anexos | Processo Judicial de Terceiros Outras Entidades;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30647188340503)

3. Gere o XML S-1020 e integre ao governo. É necessário ajustar o a competência do evento, para que a vigência do S-1020 seja gerada corretamente;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30647215623447)

4. Verifique a necessidade de retificar os periódicos de meses anteriores, caso o processo seja retroativo.
