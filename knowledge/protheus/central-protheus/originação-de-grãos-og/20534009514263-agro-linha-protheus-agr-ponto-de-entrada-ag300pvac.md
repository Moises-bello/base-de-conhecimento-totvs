![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20534001982999) Tempo aproximado para leitura: **00:00:40 min****Ocorrência**  
No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para encontrar o ponto de entrada **AG300PVAC** é apresentada a ocorrência **Ponto de Entrada AG300PVAC**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é preciso realizar o processo para encontrar o ponto de entrada **AG300PVAC** no Sistema.  
  
**Solução**  
Para solucionar essa ocorrência, o **Ponto de Entrada** é o **AG300PVAC** serve para incluir novos itens no menu das **Ações Relacionadas**.
