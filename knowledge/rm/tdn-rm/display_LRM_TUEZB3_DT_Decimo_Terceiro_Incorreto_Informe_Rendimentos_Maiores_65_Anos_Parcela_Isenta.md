# DIRF/INFORME DE RENDIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *DIRF/Informe de Rendimentos* |
| **Situação/Requisito:** | Ao realizar a geração do informe de rendimentos para funcionários aposentados > 65 anos, o sistema não está apresentando o valor do 13º Salário (Linha 01 do Quadro 5). Situação ocorre quando os seguintes parâmetros estão marcados: - Deduz > 65 anos; - Código de Receita 3533; - Aposentadoria (aba situação); |
| **Solução/Implementação:** | *Ajustado preenchimento do décimo terceiro no informe de rendimentos quando tem parcela isenta referente a funcionários maiores de 65 anos.* |
| **Chamados relacionados:** | *TUEZB3,TUFZO6* |
