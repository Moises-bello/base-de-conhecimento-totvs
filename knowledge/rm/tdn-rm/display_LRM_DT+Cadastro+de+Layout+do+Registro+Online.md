## Descrição

O cadastro de Layout do Registro Online tem o objetivo é cadastrar as Tags/Campos para associar as fórmulas configuradas para enviar os dados do registro online dos boletos para o banco.

## Procedimento para Utilização

       1.            Defina no cadastro de perfil o acesso a inclusão, alteração e edição do Layout de Registro Online.

  2.            Acesse o cadastro de Layout do Registro Online no menu anexos do cadastro de Bancos e Agências.

       3.            Incluir/Alterar as tags para os Bancos.
