![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Rateio de despesas via integração TXT do despachante gravação do campo **WN\_RATEIO**.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - Todas as versões  
  
**Solução**A integração de nota fiscal via TXT, não faz o tratamento de rateio no campo **WN\_RATEIO**, pois todas as tratativas são realizadas pelo despachante, no sistema apenas são integrados os valores enviados pelo despachante.

Ao  incluir a nota pelo recebimento de importação, o rateio é feito e o campo **WN\_RATEIO**, pois os valores são calculados pelo sistema.
