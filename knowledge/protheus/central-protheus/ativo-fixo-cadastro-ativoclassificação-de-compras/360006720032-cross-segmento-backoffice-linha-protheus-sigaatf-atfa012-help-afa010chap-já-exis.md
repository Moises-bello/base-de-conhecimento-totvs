**Dúvida**Como cadastrar o mesmo código de plaqueta para um código de bem com itens diferentes?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360014140072)  
  
**Ambiente**Protheus – Ativo Fixo – A partir da versão 12.1.17  
  
**Solução**

* Acessar o cadastro Ativo Fixo (atfa012) e digitar F12 altere o parâmetro Repete chapa? = Sim

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/360014140572)**

* Dessa forma o sistema permite incluir bem com o código "N1\_CHAPA" repetidos

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/19452189453335)**
