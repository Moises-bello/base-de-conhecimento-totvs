**Motivo Distrato**

---

Nesse cadastro é possível informar quais tipos de Motivos para o Distrato são necessários.   
    
 Ao incluir um novo Motivo Distrato, é exibida uma tela com os seguintes campos:   
    
 Código Motivo Distrato: Esse campo define o código do Motivo Distrato, campo preenchido automaticamente pelo sistema;   
 Descrição Motivo Distrato: Esse campo define a descrição do Motivo Distrato;  
 Gerar parcelas no distrato: Esse campo define se o distrato poderá gerar parcelas, possui as seguintes opções:

* **Não:** Ao selecionar essa opção o Distrato não poderá realizar cadastro de Condições de Financiamento e Geração de Plano de Financiamento.
* **Sim:** Ao selecionar essa opção o Distrato poderá realizar cadastro de Condições de Financiamento e Geração de Plano de Financiamento.
* **Sim com confirmação:** Ao selecionar essa opção o Distrato poderá realizar cadastro de Condições de Financiamento e Geração de Plano de Financiamento, mediante a uma confirmação de mensagem.
