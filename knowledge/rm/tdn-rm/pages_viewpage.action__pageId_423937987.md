Nesta funcionalidade você poderá visualizar, cadastrar, excluir e alterar dados dos responsáveis pelos patrimônios na empresa. Para cadastrar um funcionário diretamente no RM Bonum, o parâmetro "Usar funcionários do RM Labore como responsáveis" deve estar desmarcado. Se preferir, ao invés de cadastrar os nomes aqui, você poderá usar os funcionários do RM Labore. Para isso, no parâmetro, basta ativar a opção "Usar funcionários do RM Labore como responsáveis".

**Atenção**

Ao optar por usar funcionários do RM Labore como responsáveis, a janela passará a ter uma única função que é a de visualizar os registros, não permitindo qualquer alteração de dados.

**Observação**

Você também poderá copiar os funcionários do RM Labore, utilizando o processo Copiar Funcionários Folha no menu Utilitários.
