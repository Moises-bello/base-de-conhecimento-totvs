A funcionalidade de exportação de planilha para o Excel permite ao usuário exportar os dados contidos nas planilhas de atividades, serviços ou cenários para um novo arquivo do Excel, incluindo fórmulas para calcular os seguintes campos: "Valor da Planilha"; "Custo Parcial"; "Valor Unitário"; "Valor Parcial"; "% Planilha"; "% na Obra".

Saiba mais aqui sobre exportações em ambientes 3 camadas.

Abaixo temos explicações de como realizar as exportações:

EXPORTAR PLANILHA PARA O EXCEL (.xls):

Acessar a Planilha (Atividades/Serviços/Cenários) > Acessar "Processos" > "Exportar Planilha para o Excel com fórmulas" > Selecionar a localização onde será realizada a exportação > Definir o nome da planilha do Excel a ser criada > Clicar em "Executar".

**Observação:**  
 Não é necessário ter nenhum software instalado (exemplo: Microsoft Excel) na máquina do usuário para que este processo possa ser executado.
