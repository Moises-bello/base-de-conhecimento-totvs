**Dúvida**Ao tentar incluir um mesmo produto e cliente na rotina de cadastro de Produtos x Cliente, tentando mudar o campo **A7\_CODCLI** (Cod.Prod.Cli), o sistema exibe o **Help: A370001**.  
   
 **Ambiente**

Microsiga Protheus - todas a versões.   
  
**Solução**

A Rotina de Cadastro de Produtos x Clientes (**MATA370**) permite a amarração entre um código de produto no Protheus (**tabela SB1**) com somente um produto do cliente, conforme informado na issue.

O help A37001 é apresentado para informar ao usuário que ocorreu a validação desta regra com a finalidade de manter a integridade do banco de dados, e não permitir a duplicação dos registros referentes a um código de produto no Protheus para um mesmo cliente no cadastro de Produtos x Clientes.
