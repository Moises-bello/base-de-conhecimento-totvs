# Prestadores inativos aparecendo na busca de profissionais

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro de Prestador / Integração PEP 2.0 |
| **Situação/Requisito:** | Ao realizar a busca dos profissionais no PEP 2.0 também eram exibidos os profissionais que estavam com a situação inativa. |
| **Solução/Implementação:** | Ajuste na consulta para que o RM Saúde retorne apenas os prestadores que estiverem ativos. |
