# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de lançamentos* |
| **Situação/Requisito:** | *A geração de lançamentos contábeis, em transação externa, abre uma transação com o banco de dados para cada boleto, porém fecha a transação para apenas um boleto. Assim, ao gerar mais de um lançamento contábil, o sistema não consegue finalizar a transação, descartando assim, todo o processamento de matrícula.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de lançamentos, permitindo ao sistema, gerar lançamentos para mais de uma parcela, durante a matrícula de um aluno em um período letivo.* |
