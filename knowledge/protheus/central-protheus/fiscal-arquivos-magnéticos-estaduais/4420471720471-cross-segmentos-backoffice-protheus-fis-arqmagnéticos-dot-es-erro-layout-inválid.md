**Dúvida**

Ao validar arquivo DOT é apresentado o erro Layout Inválido.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4420458574999/mceclip0.png)

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Livros Fiscais - a partir da versão 12.

**Solução**

O erro apresentado na validação do arquivo,  trata-se de uma atualização necessária no validador para importar o arquivo.

Mesmo após baixar o validador já na versão 3.0.0.0 é necessário baixar e executar o arquivo "Atualização DOT" destacado na imagem abaixo no site da SEFAZ ES:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4420452195735/mceclip1.png)

Link contendo o arquivo "Atualização DOT"

<https://sefaz.es.gov.br/dot-declaracao-de-operacoes-tributaveis>

Após atualizar o arquivo será importado com sucesso:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4420458969111/mceclip2.png)
