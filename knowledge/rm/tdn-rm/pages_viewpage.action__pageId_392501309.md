# Paginação na lista de Calendários na tela de Reserva e Instalação de recursos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Reserva de Instalação e Recursos |
| **Situação/Requisito:** | Ao carregar a lista de Calendários disponíveis no combobox da tela de Reserva de Instalação e Recursos, o portal exibe uma primeira quantidade de registros disponíveis na lista de calendários e exibe um Scroollbar, indicando mais registros. Ao rolar a barra de scroll o sistema não retorna mais informações, ocultando o scroll e não exibindo o restante das informações. |
| **Solução/Implementação:** | Foi realizado o ajuste para permitir que seja exibido todos os registros de calendário no combobox, permitindo que todos os registros fossem listados. |
