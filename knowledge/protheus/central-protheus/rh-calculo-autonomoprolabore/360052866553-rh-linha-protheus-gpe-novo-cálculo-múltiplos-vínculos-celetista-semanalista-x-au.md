**Dúvida**Novo cálculo múltiplos vínculos - Celetista semanalista x Autônomo Semanalista  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.25  
  
**Causa**Visando atender a nota orientativa 2019.20 do E-social, a rotina de múltiplos vínculos internos sofrerá algumas alterações para que fique compatível com o que o governo espera receber em se tratando de múltiplos vínculos de empresas diferentes.   
  
**Solução**

Celetista semanalista x Autônomo Semanalista

Primeira semana celetista:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305851031)

Conferência do cálculo

*INSS = 150,81*

Base INSS = Salário Horista + DSR => 1603,32 + 246,66 = 1849,98

1º Faixa = 1045,00 \* 0,075 => 78,37

2º Faixa = 1849,98 – 1045,00 => 804,98 \* 0,09 => 72,44

Soma das faixas => 78,37 + 72,44 = 150,81

Primeira semana autônomo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305853463)

Conferência do cálculo

*INSS = 88,00*

Base \* % INSS AUT => 800,00 \* 0,11 => 88,00

Executando a rotina Múltiplos Vínculos

Como o pagamento é semanal, é preciso do ajuste do cálculo antes do fechamento do período para a segunda semana.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305856407)

Após o cálculo do múltiplos vínculos a primeira semana do primeiro vinculo permanece inalterada

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283588503)

Segundo vinculo, primeira semana:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305860503)

Conferência do cálculo

*INSS = 140,68*

Base primeiro vinculo + Base segundo vinculo \* % INSS AUT – INSS primeiro vinculo =>

1849,98 + 800,00 \* 0,11 – 150,81 => 140,68

*IRRF = 34,08*

Base primeiro vinculo + Base segundo vinculo \* % IRRF – Dedução – IR já descontado =>

1699,17 + 659,32 \* 0,075 – 142,80 =  34,08

Realizado o fechamento dos períodos para cálculo da segunda semana

Primeiro vinculo primeira semana:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283593879)

Segundo vinculo, primeira semana:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305864215)

Executado cálculo da folha para segunda semana primeiro vinculo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241305868183)

Conferência do cálculo

*INSS = 226,11*

Base INSS = Base primeira semana + Base segunda semana => 1849,98 + 1849,98 => 3699,96

1º Faixa = 1045,00 \* 0,075 => 78,37

2º Faixa = 2089,60 – 1045,00 => 1044,60 \* 0,09 => 94,01

3º Faixa = 3134,40 – 2089,60 => 1044,80 \* 0,12 => 125,37

4º Faixa = 3699,96 – 3134,40 => 565,56 \* 0,14 => 79,17

Soma das faixas => 78,37 + 94,01 + 125,37 + 79,17 = 379,92 – 150,81 (inss já descontado) = 226,11

 

*IRRF = 143,65*

Base primeira semana + Base segunda semana \* % IRRF – Dedução =>

1699,17 + 1623,87 \* 0,15 – 354,80 =  143,65

Cálculo segunda semana do segundo vinculo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283605911)

Conferência do cálculo

*INSS = 88,00*

Base primeira semana + Base segunda semana \* % INSS AUT – INSS primeiro vinculo =>

800,00 + 800,00 \* 0,11 – 88,00 => 88,00

Executando a rotina Múltiplos Vínculos novamente

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283607831)

Consultando o cálculo do primeiro vinculo, segunda semana:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283610775)

Conferência do cálculo

*INSS = 197,43*

Base primeira semana primeiro vinculo + Base segunda semana primeiro vinculo + Base segunda semana primeiro vinculo

=> 1849,98 + 1849,98 + 800,00 => 4499,96

1º Faixa = 1045,00 \* 0,075 => 78,37

2º Faixa = 2089,60 – 1045,00 => 1044,60 \* 0,09 => 94,01

3º Faixa = 3134,40 – 2089,60 => 1044,80 \* 0,12 => 125,37

4º Faixa = 4499,96 – 3134,40 => 1365,56 \* 0,14 => 191,17

Soma das faixas => 78,37 + 94,01 + 125,37 + 191,17 = 488,92

Soma INSS – INSS primeira semana primeiro vinculo – INSS primeira semana segundo vinculo

* 488,92 – 140,68 – 150,81 = 197,43

*IRRF = 232,27*

Base primeira semana primeiro vinculo + Base segunda semana primeiro vinculo Base segunda semana primeiro vinculo \* % IRRF – Dedução – IRRF já descontado

* 1699,17 + 1652,55 + 659,32 \* 0,225 – 636,13 – 34,08 = 232,27

Consultando o cálculo do segundo vinculo, segunda semana:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26241283613463)

Conferência do cálculo

*INSS = 94,07*

Base primeira semana primeiro vinculo + Base segunda semana primeiro vinculo + Base segunda semana primeiro vinculo + Base segunda semana segundo vinculo

=> 1849,98 + 1849,98 + 800,00 + 800,00 => 5299,96

5299,96 \* 0,11 => 582,99

Soma INSS – INSS primeira semana primeiro vinculo – INSS primeira semana segundo vinculo – INSS segunda semana segundo vinculo

* 582,99 – 140,68 – 150,81 – 197,43 = 94,07

*IRRF = 161,45*

Base primeira semana primeiro vinculo + Base segunda semana primeiro vinculo Base segunda semana primeiro vinculo + Base pagamento dois segundo vinculo\* % IRRF – Dedução – IRRF já descontado

* 1699,17 + 1652,55 + 659,32 + 705,93 \* 0,275 – 869,36 – 34,08 – 232,27 = 161,45

#### **Rotina GPEM930**

Desenvolvimento de nova rotina (GPEM930) onde será possível consultar todos os funcionários que possuam mais de um vínculo e efetuar o cálculo deles isoladamente do restante dos funcionários. O cálculo através das demais rotinas continua funcionando normalmente, o diferencial desta tela é que será possível calcular todos os vínculos de uma só vez.
