Este assistente atualiza o campo Nº de alunos Labore, do cadastro de turmas com os alunos matriculados.  
 Geralmente, esta rotina é executada pelo cliente no mês de fevereiro. Assim, ao acessar esta funcionalidade, o sistema irá apresentar um grupo de opções para confirmação (sim ou não); caso o mês atual não seja fevereiro, o default desta caixa de opção será "sim"; senão será "não".
