|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de Contas |
| **Situação/Requisito:** | Os itens lançados na aba de guia autorização não estão sendo lançados na Elaboração de Conta do Paciente, era exibido uma mensagem e os itens acabavam não sendo mostrados. |
| **Solução/Implementação:** | Alterado o sistema para lançar os itens na elaboração de contas do paciente. |
