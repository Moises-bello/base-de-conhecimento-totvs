Esta pasta será utilizada para que o usuário possa relacionar quais Códigos de Ajustes se aplicam a cada Produto. Para cada Código associado, o usuário deve informar, também, para quais CST's aquele código de aplica.

Lista de CST's: 00; 10; 20; 30; 40; 41; 50; 51; 60; 70, 90, 02, 53 e 61.

Regras

* O campo **Indicador do Código de Ajuste** será preenchido de acordo com o cadastro de Código de Ajuste. A princípio serão apresentado os Códigos de Ajuste referentes ao registro E115 do Sped Fiscal.
* Não será permitido incluir o mesmo CST para o Produto com Códigos de Ajustes do mesmo Estado.
