**Dúvida**É permitido a utilização de campos obrigatórios para integração com API padrões?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL– A partir da versão p12

**Solução**

Na utilização de API padrões não é permitido incluir novos campos, visto que na sua estrutura só irá permitir os campos que foram desenvolvidos para aquela API, contidos na documentação de cada API.

Nesse cenário caso seja imprescindível, deverá ser criada uma API customizada para que seja enviado os campos desejados.
