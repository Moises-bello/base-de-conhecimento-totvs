# Objetivo:

---

          O objetivo deste documento é evidenciar como é realizado o consumo de licença do Smart View quando integrado ao RM.

# Introdução:

---

          O Smart View, quando utilizando **Provedores Nativos Integrados**, deixará à cargo do ERP o consumo de licenças do License Server, quando determinado como necessário pelo mesmo. Assim sendo, o consumo de licenças fica a cargo do RM.

Conectores SQL

No caso de uso de conectores SQL diretamente pelo Smart View, o consumo será realizado diretamente pelo Smart View

# Consumo:

---

         Dessa forma, o consumo de licenças no RM se dará **de acordo com o módulo****em que se encontra o Objeto de Negócio**. Dessa forma, é possível controlar quais recursos consumirão licenças de determinado módulo.
