Esta etapa define como será o tratamento de importações de dados de sistemas legados.  
    
 **Parâmetros**  
 Usar chapa na importação do histórico de endereços   
 Ao marcar este parâmetro, na importação de histórico de endereço será informada a chapa e não o código de pessoa.

**Observação**  
 Para que o parâmetro funcione corretamente, ao exportar os dados, deverá utilizar o relatório 'Exportação de Histórico de endereço por chapa'.

Utiliza importação do movimento de ensino de sistema acadêmico de terceiros  
 Parâmetro para habilitar o módulo de Gestão Educacional. Este módulo será utilizado por clientes que importam o movimento de ensino de sistema acadêmico de terceiros.  
    
 Executar a verificação da base após a importação de dados  
 Este parâmetro torna obrigatória a verificação da base de dados após realizar a importação de dados.
