## **01. VISÃO GERAL**

Após Liberar o exame é permitido retornar para correção caso seja necessário.

Se o “Parâmetro Geral > Aba Unidade Diagnóstico II > Restringe o retorno de exames liberados para correção” diz que **somente usuário que realizou a Liberação pode retornar para correção.**

Se o “Parâmetro Geral > Aba Unidade Diagnóstico II > Limite de dias para permitir retornar resultado de exame de Liberado para Correção” diz que **existe um limite de dias para retornar para correção após o exame ser liberado.**

Clicar em "Retornar Liberado para Correção"
