![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25342084137239) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como realizar o cálculo de varias filiais, processos ou períodos diferentes?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - TOTVS Gestão de Pessoal - Todas as versões  
  
**Solução**

Para atender a necessidade foi criada a rotina GPEM020A que possibilita a seleção dos roteiros, de diferentes processos, períodos e filiais, para que o cálculo ocorra sequencialmente.

Para realizar os cálculos múltiplos acesse Miscelânea > Cálculos > Cálculos múltiplos (GPEM020A), ao acessar a rotina selecione os roteiros, períodos e filiais conforme a necessidade.
