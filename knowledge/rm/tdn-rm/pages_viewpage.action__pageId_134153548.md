***Objetivo:*** *Demonstrar qual é o procedimento para configurar a integração entre o RM e o Sharepoint.*

Atenção

A configuração da Integração RM x Sharepoint foi removida a partir da versão 12.1.2410.

Atenção

*Esta integração f**unciona somente com a versão 2003 do MS Sharepoint, pois esta integração foi descontinuada.*

Primeiramente, devemos ativar a integração Sharepoint nos parâmetros Globais. No RM.Exe, abra a aba Ambiente, clique em Parâmetros e depois em Globais.

|  |
| --- |

Vá para a aba SharePoint, marque o campo “Usar a integração com o SharePoint” e salve.

|  |
| --- |

Agora devemos configurar a integração

Acesse o menu integração

|  |
| --- |

Vá para a aba Ferramentas e clique em Parâmetros

|  |
| --- |

Clique no Item 50.07 - Linha RM X GED (Gerenciamento Eletrônico de Documentos) e depois em Avançar

|  |
| --- |

Nesta tela, informe os parâmetros de conexão com o servidor do SharePoint. Este passo é necessário para efetuar a comunicação com o SharePoint. Após informar os dados, teste a conexão.

|  |
| --- |

 Configuração finalizada, vamos aos testes. Abaixo, a tela do SharePoint sem nenhum registro.
