Nesta opção cadastra-se os Tipos de Parcelas disponíveis no sistema.  
Através do cadastro é possível controlar:

**Identificação**

Ao cadastrar ou editar um Tipo de Parcela, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* Código: Informa o código para o Tipo de Parcela;
* Descrição: Informe a descrição do Tipo de Parcela. Ex.: Mensal;
* Pág. / Rec.: Informe se este Tipo de Parcela é a Pagar ou a Receber;
* Histórico do Lançamento no RM Fluxus: Informe um histórico padrão que será gerado para os lançamentos do RM Fluxus para o tipo de parcela;
* Variáveis pré-Definidas: Informe as variáveis que já estão definidas neste campo que irão para o campo histórico;  Símbolos do histórico padrão:  [VND] => Número da Venda  [UNI] => Código da unidade  [SUB] => Código da Sub-unidade [EMP] => Código do Empreendimento  [NOM] => Nome do Empreendimento
