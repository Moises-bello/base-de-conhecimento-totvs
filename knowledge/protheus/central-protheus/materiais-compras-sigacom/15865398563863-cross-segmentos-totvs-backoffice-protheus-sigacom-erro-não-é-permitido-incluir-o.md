![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15865461702167) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Ao incluir um documento de entrada, o sistema gera o erro "Não é permitido incluir outro tipo de pedido junto com o pedido gerado pelo módulo SIGAPLS", conforme print abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/15865159586071)  
**Ambiente**Microsiga Protheus  – Compras – A partir da versão 12  
  
**Causa**Normalmente esse help é apresentado quando o campo **C7\_LOTPLS** está com algum conteúdo.  
  
**Solução**Verifique se no PC que está sendo vinculado na NF de entrada, se o campo abaixo está preenchido com algum conteúdo :  
   
![](https://totvssuporte.zendesk.com/attachments/token/95CQQoH0bQV3ABcGCsTL3uxvN/?name=image.png)
