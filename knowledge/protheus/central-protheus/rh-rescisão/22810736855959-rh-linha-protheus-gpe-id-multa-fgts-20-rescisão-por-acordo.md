![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22810736842519) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Existe ID especifico de multa FGTS 20% rescisão por acordo?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Não existe ID especifico de multa FGTS 20% rescisão por acordo. O valor multa FGTS 20% rescisão por acordo será calculado no ID 0120 (mesmo ID que calcula a multa FGTS 40%), pois ambos valores se tratam de indenização FGTS, só tendo diferença quanto ao percentual.

Cadastro ID 0120.
