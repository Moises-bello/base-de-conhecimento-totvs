PainelVisão Geral

## **VISÃO GERAL**

A página de "Cadastro" permite a criação de um usuário para acesso ao Portal do Paciente.

**OBS 1:** Caso o usuário já tenha seu cadastro na unidade dentro do RM, então o sistema fará uma ligação entre o cadastro pre existente no RM com os dados do Portal. Desta forma o usuário final irá cadastrará normalmente seus dados mas o sistema exibirá os dados já cadastrados pela unidade dentro do RM.

**OBS 2:**Caso o usuário já tenha um cadastro no portal do paciente , então o mesmo exibirá uma notificação de Cadastro já existente.

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Para que seja possível efetuar o cadastro, as informações devem atender os requisitos mínimos, como:

* Todos os itens obrigatórios devem ser preenchidos (os itens obrigatórios são marcados com um \*);
* Atender os critérios de validação de CPF, Telefone, E-mail, Senha e Confirmação de Senha;
* Concordar com os Termos de Serviço;
* Concordar com a Política de Privacidade.
Cadastro Completo

## **CADASTRO COMPLETO**

01. Acessar o Portal do Paciente e clicar no botão Cadastrar no "Portal".

02. Preencher os campos solicitados.

Informação

O botão **Carregar documento**permite ao usuário enviar fotos de documentos para extrair com o uso de IA informações como CPF, Nome, Nome da mãe, Sexo e data de nascimento de documentos como Identidade ou CNH.   
O DTA suporta o carregamento dos seguintes formatos de arquivo: PDF, PNG, JPEG, JPG e WEBP.

Este recurso está disponível a partir da versão **12.1.2510.100** e em todas as versões superiores.

         

03. Após preencher as informações corretamente e concordar com os Termos de Serviço e Política de Privacidade, clicar no botão "Concluir".

04. Ao término da validação das informações e cadastro no portal, o usuário será redirecionado novamente para a página de "Login".

Descarte do Cadastro

## **DESCARTE DO CADASTRO**

01. Durante o processo de cadastro, caso seja necessário, o usuário poderá interromper a operação clicando no botão "Voltar".

02. Se algum campo já estiver preenchido, o usuário será questionado se realmente deseja sair do cadastro.

03. Se clicar no botão "Não", o usuário poderá continuar preenchendo o formulário. Se clicar no botão "Sim", o usuário será redirecionado para a página de "Login" e todas as informações serão descartadas.
