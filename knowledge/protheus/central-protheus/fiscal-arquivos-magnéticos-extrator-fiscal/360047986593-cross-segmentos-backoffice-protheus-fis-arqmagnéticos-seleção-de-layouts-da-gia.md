**Dúvida**Ao executar o Extrator Fiscal para extrair informações referente a GIA SP via Schedule os layouts de integração serão selecionados de forma automática?  
  
**Ambiente**  
Protheus – Livros Fiscais – A partir da versão 12  
  
**Solução**Será necessário configurar os layouts antes de executar a primeira extração via schedule.

Para as demais extrações os layouts serão selecionados de forma automática.

Abaixo procedimentos em tela:

Na tela abaixo clique no botão "Parâmetros"  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360069154134/mceclip0.png)

Será apresentando a wizzard para preenchimento.  
No campo "Layouts para seleção" escolha a opção 1-Sim e clique em Ok.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360070219673/mceclip1.png)

Será apresentado a tela abaixo para que possa efetuar a primeira configuração dos layouts.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360069154494/mceclip2.png)
