# EDIÇÃO DE PEDIDO DE MATERIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Edição de Pedido de Material Extra. |
| **Situação/Requisito:** | Deverá ser criado a pagina de edição de Pedido de Material Extra. |
| **Solução/Implementação:** | Foi desenvolvido a edição de pedido de material extra de forma responsiva para os dispositivos: mobile, tablet e desktop.  A edição possui:   * Itens do pedido * Informações do Pedido (Status, Data Requisição e Usuário Responsável) * Configurações (Utiliza Preço Orçado, Tipo de Movimento e Local de Estoque)   Será possível editar o pedido apenas quando o status do pedido for "Em criação".  Pela edição é possível realizar a mudança do tipo de movimento e local de estoque, alem de informar a utilização de preço orçado. |
