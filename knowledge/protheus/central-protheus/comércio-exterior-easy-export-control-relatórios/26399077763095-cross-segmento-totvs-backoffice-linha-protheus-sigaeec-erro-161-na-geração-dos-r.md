Esta ocorrendo um erro na impressão de documentos de exportação não gerando PDF. Como resolver este problema?

![ERRO 161.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26399056769303)

**Ambiente**Cross Segmento - TOTVS *Backoffice* (Linha Protheus) – *Easy Import Control* – a partir da versão 12.1.2210  
  
**Solução**

Devido a atualizações no navegador Google Chrome, alguns relatórios que utilizam essa plataforma para impressão precisaram ser ajustados. Existem duas formas de resolver o problema:

* Atualização disponível: A correção está inclusa no pacote acumulado de expedição continua dos módulos de comércio exterior Protheus a partir do release 12.1.2210.
* Solução alternativa: Para quem não possui garantia estendida ou utiliza versões anteriores à 12.1.2210, há um contorno para exibir o relatório sem erros:
  + Defina o Microsoft Edge como navegador padrão.
  + Durante a execução dos relatórios, é necessário encerrar o serviço do navegador Edge.
