****Equivalên**cia de campos**

A configuração destes campos é necessária, para relacionar as informações do RM TOP com as colunas do MS Project, e vice versa.

* Campo Linha base para envio das Datas e Duração Programada no Sincronismo com o MS-Project: Campos de início e término programados eram enviados ao campo Linha Base 1 do MS-Project obrigatoriamente, sem a possibilidade de parametrização. Este envio se faz necessário pois o MS-Project pode alterar o valor das Datas e Duração Programadas. O campo é de apenas de escrita no MS-Project, sem o retorno destes valores no Sincronismo. Esta parametrização permite que escolha o campo do MS-Project que será preenchido com os valores do Programado. Poderá ser escolhido também o não envio desta informação.
* Descrição: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber a descrição da/s tarefa/s;
* Unidade: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber a unidade da/s tarefa/s;
* Código Auxiliar da Tarefa: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o código auxiliar da/s tarefa/s;
* Campo Livre 1: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 1 da/s tarefa/s;
* Campo Livre 2: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 2 da/s tarefa/s;
* Campo Livre 3: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 3 da/s tarefa/s;
* Campo Livre 4: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 4 da/s tarefa/s;
* Campo Livre 5: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 5 da/s tarefa/s;
* Moeda da Tarefa: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber a moeda da/s tarefa/s;
* Quantidade: define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber a quantidade da/s tarefa/s;
* Campo Livre 1 (Valor): define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 1 (Valor) da/s tarefa/s;
* Campo Livre 2 (Valor): define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 2 (Valor) da/s tarefa/s;
* Campo Livre 3 (Valor): define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 3 (Valor) da/s tarefa/s;
* Campo Livre 4 (Valor): define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 4 (Valor) da/s tarefa/s;
* Campo Livre 5 (Valor): define-se uma coluna padrão para qualquer projeto (MS Project) à ser utilizado na sincronização, para receber o campo livre 5 (Valor) da/s tarefa/s.
