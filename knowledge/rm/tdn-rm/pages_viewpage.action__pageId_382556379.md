# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1.18 ou superior |
| **Ocorrência:** | Visualizar Contabilizações |
| **Ambiente:** |  |
| **Passo a passo:** | Esta funcionalidade permite que sejam visualizadas as movimentações patrimoniais contabilizadas já integradas e não integradas ao Totvs Gestão Contábil.  Acesse o **menu Contabilização | Visualizar Contabilizações**.  Acessando este menu o usuário pode verificar a data da contabilização, a descrição, qual moeda foi utilizada, a origem, se ela se encontra integrada ou não integrada ao módulo contábil e caso já tenha sido integrada é possível visualizar a operação contábil integrada.    Acessando Anexos\detalhes da contabilização serão apresentados os dados da contabilização, entre eles, conta contábil, filial, centro de custo e valor. Editando a contabilização estes dados são apresentados no formato de lançamento\ partida contábil.    Tela da edição da contabilização:    **Observação:**  Não é possível realizar exclusão ou solicitar a exclusão da contabilização (via tarefa) através deste menu, apenas pelo cadastro do patrimônio. |
