![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18432442622999) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Ao efetuar a devolução de exportação, via documento de entrada, o produto não fica disponível para fazer um novo embarque.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Export Control* – Todas versões   
  
**Solução**Ao fazer a devolução da mercadoria via documento de entrada, o produto não ficará disponível para o pedido de exportação, o item irá voltar para análise de qualidade e posteriormente para o estoque.
