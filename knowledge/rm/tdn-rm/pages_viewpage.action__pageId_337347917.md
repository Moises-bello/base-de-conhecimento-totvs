# INSCRIÇÃO NO ENSINO BÁSICO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo. |
| **Função:** | Inscrição de dependente no processo seletivo do ensino básico. |
| **Situação/Requisito:** | Alguns campos de Data, mesmo preenchidos, invalidavam o formulário do responsável pela inscrição e impedia a conclusão da inscrição. Como solução de contorno, era necessário que o usuário digitasse a data novamente, forçando assim uma revalidação do formulário. |
| **Solução/Implementação:** | Ajuste no componente de Data para que não invalide o formulário, quando houver um valor preenchido automaticamente. Obs.: O campo é preenchido automaticamente quando o responsável pela inscrição solicita a inscrição de um novo dependente. |
