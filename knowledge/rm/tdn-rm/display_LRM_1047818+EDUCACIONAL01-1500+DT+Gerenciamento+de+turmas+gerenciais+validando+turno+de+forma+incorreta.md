# VALIDAÇÃO DE TURNO SENDO APLICADA DE FORMA INCORRETA NO USO DE TURMA GERENCIAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | Utilização de turmas gerenciadas e gerenciais. |
| **Situação/Requisito:** | O sistema não está permitindo a associação de turmas gerenciadas a turma gerenciais que tenham períodos diferentes. |
| **Solução/Implementação:** | Realização de um ajuste para permitir a associação de turmas gerenciadas a turma gerenciais, mesmo que tenham turnos diferentes.  Serão validados apenas os horários das turmas e não mais os turnos. |
