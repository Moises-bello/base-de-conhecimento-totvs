Dúvida**Como gerar *logprofiler* das rotinas do TAF e SIGAGPE para análise de lentidão e problemas de performance?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para análise de lentidão e/ou problemas de performance no sistema é necessário gerar um arquivo *log* específico para que seja analisado o tempo de execução de cada rotina no sistema, para isto deve-se seguir a documentação para geração do arquivo corretamente:  
<http://tdn.totvs.com/pages/releaseview.action?pageId=243638663>  
  
Também é possível gerar o arquivo utilizando o comando *shift*+F6 no acesso a qualquer rotina do Protheus. Avance até o item 4 conforme imagem e inicie a geração.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19463548999063)
