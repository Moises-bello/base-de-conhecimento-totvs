# ACESSO AO CADASTRO DE SERVIÇOS (PARAMETRIZAÇÃO DE CARTÃO DE CRÉDITO)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | Cadastro de serviços |
| **Situação/Requisito:** | Mensagem de erro ao tentar editar um serviço, impossibilitando o acesso ao cadastro quando existe parametrização incompleta/incorreta de pagamentos via cartão de crédito. |
| **Solução/Implementação:** | Foi realizada a troca da mensagem de erro (que bloqueava o acesso ao serviço) por uma mensagem informativa que mostra ao usuário que existe uma parametrização incorreta e como ajustá-la, sem que o acesso ao cadastro seja restringido. |
