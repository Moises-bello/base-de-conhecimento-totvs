Foi criado o processo de **Encerrar Seguro** na tela de **Seguro** do **TOTVS Incorporação**.   
Para usar este recurso basta acessar a tela de **Seguro | Processo Encerrar Seguro**.

**Abaixo temos a tela do Encerramento de Seguro:**

**Figura 1 - Processo de Encerramento de Seguro**

Observações

* O sistema possibilita o encerramento de mais de uma apólice ao mesmo tempo.
* Após o encerramento de uma apólice, os dados da mesma não poderão ser alterados.
* A apólice só poderá ser encerrada caso não existam lançamentos de reembolso e movimentos com vencimento posterior à data de encerramento.
* A data default para o encerramento deve ser a data do final da apólice.
* Após a realização do Encerramento, o status do seguro será alterado para Encerrado.
