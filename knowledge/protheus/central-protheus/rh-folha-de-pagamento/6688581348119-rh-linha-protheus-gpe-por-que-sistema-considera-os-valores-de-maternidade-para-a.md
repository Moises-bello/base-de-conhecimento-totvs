![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26355076839575) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que o sistema considera os valores de maternidade para a verba de Base INSS mesmo sem considerar para os encargos patronais?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O sistema considera os valores das verbas de maternidade para a base de INSS mesmo que não considere para o INSS patronal pois os valores de maternidade ainda fazem base para o desconto de INSS da funcionária, portando o valor da maternidade será considerado para a verba de Base INSS (IDs 0013 e 0014) para que seja feito o cálculo do desconto do INSS da funcionária.
