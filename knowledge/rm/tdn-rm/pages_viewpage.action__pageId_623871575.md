# Sumário

---

Sumário

# Objetivo

---

Este documento tem como objetivo exemplificar a forma de utilização do processo de importação de notas do sistema prova fácil no **TOTVS Processo Seletivo**.

**Recurso disponível a partir da versão 12.1.32.**

# Pré-requisitos

---

É necessário que esta funcionalidade seja permitida através dos perfis de globais.

# Processo

---

O processo permite importar notas de provas executadas através do Prova Fácil para o **TOTVS Processo Seletivo**, de modo que seja possível executar a clasificação dos candidatos.

Ao término do processo será gerado um Log de Retorno do processo exibindo a(s) nota(s).

É necessário que esta funcionalidade seja permitida através dos perfis de globais.

# Parâmetros

---

* **Importar notas de candidatos já importados**

Ao habilitar todos os candidatos, mesmo os que já tenham sido importados, terão suas notas importadas novamente do sistema Prova Fácil.

* **Importar notas zerada para candidatos com presença não confirmada**

Ao habilitar todos os candidatos, independente se executaram ou não a prova terão as notas importadas. Os candidatos com presença não confirmada terá 0 atribuido como nota.

Parametro disponível somente a partir da 12.1.2306.
