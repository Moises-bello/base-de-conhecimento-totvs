Dúvida**Como rodar o RM atualizador?

**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões

**Solução**Caso o RM esteja na mesma versão, o sistema irá somente rodar os scripts pendentes da base. Caso esteja executando de alguma versão superior, o sistema irá atualizar o banco de dados de acordo com a versão executada.

Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Acesse a pasta de instalação do **CorporeRM,** abra a pasta **RM.Net**.  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8658447294103/mceclip0.png)  
  
2. Selecione o arquivo **RM. Atualizador.**  
![22-10-2019_10-37-36.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049672733/22-10-2019_10-37-36.png)  
  
3. Insira o usuário e senha, em seguida clique no Alias para localizar a base que será atualizada.  
![22-10-2019_10-39-08.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049673253/22-10-2019_10-39-08.png)  
  
4. Preencha o **Alias** nome que será dado a base, **Tipo de Banco** se a base é **SQL** ou **Oracle**, **Servidor de banco** nome da maquina onde a base está hospedada e a **Base de Dados** Instância da base após clique em **Ok**.  
![22-10-2019_11-41-39.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048790994/22-10-2019_11-41-39.png)  
  
5. Clique em **Avançar**.  
![22-10-2019_10-42-34.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048791154/22-10-2019_10-42-34.png)  
  
6. Após o sistema irá verificar se os requisitos estão de acordo para continuar com a atualização, se estiver tudo de acordo clique em **Avançar.**  
![22-10-2019_10-42-47.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048793434/22-10-2019_10-42-47.png)  
  
7. Marque a opção **Não desejo analisar os possíveis impactos ou já realizei este procedimento**, após clique em **Avançar** novamente.  
![22-10-2019_10-43-07.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048795854/22-10-2019_10-43-07.png)  
  
8. Marque as opções conforme imagem abaixo e selecione se você deseja realizar a atualização em uma base de **Produção** ou **Homologação** e**Avançar** novamente.  
![22-10-2019_10-43-19.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048796034/22-10-2019_10-43-19.png)  
  
9. Aceite os termos e clique em **Avançar**.  
![22-10-2019_10-43-31.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049696473/22-10-2019_10-43-31.png)  
  
![22-10-2019_10-43-39.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049696753/22-10-2019_10-43-39.png)  
  
10. Desmarque a opção **Atualizar as estatísticas da Base de Dados TOTVS RM,** clique em **Avançar**.  
![22-10-2019_10-43-50.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048797314/22-10-2019_10-43-50.png)  
  
11. Clique em **Iniciar Atualização**, ao final do processo caso não haja nenhum erro clique em **Avançar**.  
![22-10-2019_10-44-45.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360048797514/22-10-2019_10-44-45.png)  
  
12. Em **Resumo** o sistema mostrará **Avisos,** **Erros** e **Erros Críticos** caso ocorram, após clique em avançar novamente.  
![22-10-2019_10-45-01.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049698533/22-10-2019_10-45-01.png)  
  
13. Por fim clique em **Concluir** para finalizar o processo.  
![22-10-2019_10-45-10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049699193/22-10-2019_10-45-10.png)
