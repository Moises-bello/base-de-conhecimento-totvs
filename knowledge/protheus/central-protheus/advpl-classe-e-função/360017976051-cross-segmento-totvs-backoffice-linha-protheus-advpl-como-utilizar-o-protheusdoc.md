Dúvida**Como realizar a geração dos arquivos de documentação com base no ProtheusDoc utilizando o IDE TOTVS Developer Studio 11.3?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 12.1.17  
  
**Solução**Diferente do TDS 11.2, para gerar a documentação com base no ProtheusDoc, são necessários os passos abaixo:  
  
1) Uma vez gerados os comentários das funções, clique em Arquivo > Exportar...  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013200752/mceclip0.png)  
  
2) Dentre as opções listadas, selecione TOTVS > ProtheusDoc  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013202792/mceclip0.png)  
  
3) Selecione os fontes que deseja na composição da documentação  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013202852/mceclip1.png)  
  
4) Selecione as opções desejas e crie uma pasta para geração dos arquivos  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/360013211831/mceclip2.png)
