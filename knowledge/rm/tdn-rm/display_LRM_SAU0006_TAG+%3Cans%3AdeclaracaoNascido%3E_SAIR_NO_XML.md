# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.8x e 12.1x |
| **Ocorrência:** | Como fazer para sair a TAG <ans:declaracaoNascido> no xml. |
| **Passo a passo:** | 1° passo: Realizar um atendimento interno para uma paciente feminino,       2° Em Dados do Atendimento, no campo “Tipo de atendimento” colocar  internação obstétrica    , e  no campo “Clinica “ colocar  ginecologia e obstetrícia  .    3° Ainda em dados de atendimento clicar no botão TISS  e marcar o checkbox “Atendimento a RN”     4° Após  ir em atendimento > internação >  Cadastro de recém  Nascido. Clicar em incluir recém nascido e buscar pelo cadastro realizado anteriormente (no caso a mãe  do RN).    5° Nesta tela você deverá informar o sexo a condição e o número declaração Nascimento.      6° Após basta encerrar a conta que a TAG <ans:declaracaoNascido>  vai estar  no xml. |
