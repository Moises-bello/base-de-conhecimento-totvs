Neste momento será apresentado os passos que o usuário deve realizar para gerar o acordo no Sistema.

O usuário pode utilizar o filtro para selecionar os lançamentos desejados.

Após exibir os lançamentos que deseja fazer o acordo, o usuário deve selecionar os lançamentos e acessar a opção “Processos | Gerar Acordo”.

Após selecionar o acordo, o usuário deve dar continuidade ao processo clicando em “Avançar”.

Os campos só estarão disponíveis para edição se o “Template” utilizado permitir tais alterações.

O usuário deve informar:

* **Data do Acordo:** Informar a data que o acordo está sendo realizado;
* **Usar Juros Futuros:** Informar a utilização de juros futuro:
  + **Não utiliza juros:** Marcar esta opção em caso de não utilizar juros futuros;
  + **Juros Simples:** Marcar esta opção para utilização de juros futuros simples;
  + **Juros Compostos:** Marcar esta opção para utilização de jutos futuros compostos.
* **Acréscimo:**
  + **Valor Acréscimo ou % de acréscimo:** Informar o valor ou percentual de acréscimo do acordo;
* **Desconto:**
  + **Valor Desconto ou % de desconto:** Informar o valor ou percentual de desconto do acordo.
* **Quantidade de Parcelas:** Informar a quantidade de parcelas serão geradas no acordo;
* **Vencimento da Primeira Parcela:** Informar a data de vencimento da primeira parcela;
* **Observação:** Informar observações a respeito do acordo.

Após preencher estas informações, o usuário deve clicar em “Avançar”.

Em seguida serão exibidas as parcelas a serem geradas pelo acordo com seus respectivos valores e vencimento conforme informado na tela anterior. Se o usuário desejar alterar qualquer parcela, deve editar a mesma e realizar a devida alteração.

Após clicar em “Executar” o processo será finalizado.
