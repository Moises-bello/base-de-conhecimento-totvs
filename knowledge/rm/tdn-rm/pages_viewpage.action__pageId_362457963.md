# Fato Contábil utilizando Expressão x Filtro Complementar

|  |  |
| --- | --- |

| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Fato Contábil Usando Expressão x Filtro Complementar |
| **Situação/Requisito:** | Cliente informa que o filtro complementar não funciona quando utilizado em determinado fato contábil, onde este é um dos somatórios de outros fatos contábeis, que se utiliza a expressão. |
| **Solução/Implementação:** | Melhoria na forma como as Demonstrações calculam os fatos baseados em filtro complementar para que expressões que utilizam tais fatos possam recuperar o valor mesmo quando a expressão foi incluída antes do fato que contém o filtro complementar. |
