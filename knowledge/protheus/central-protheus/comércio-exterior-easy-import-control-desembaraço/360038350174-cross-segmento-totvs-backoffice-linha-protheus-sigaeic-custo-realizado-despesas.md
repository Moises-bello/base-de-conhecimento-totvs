Dúvida**Quando já gerado o custo realizado, não apresenta a despesa **Base de Custo = SIM**, como apresentar a mesma?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – Todas versões  
  
**Solução**No módulo Easy Import Control com o custo realizado já gerado, para que a rotina passe a considerar a nova despesa "Base de Custo = SIM" é necessário que seja feito o estorno do custo realizado e efetuar o procedimento abaixo para gerar o mesmo:

1. Selecione o menu Atualizações\Desembaraço\Receb. Importação:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360052150053/mceclip0.png)

2. Posicione sobre o processo e selecione Outras Ações\Custo Realiz:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360052150073/mceclip1.png)

3. Selecione a opção Itens:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051251314/mceclip2.png)

4. Selecione a opção Grava:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051251334/mceclip3.png)

5. Neste momento o custo realizado será gravado:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360052150213/mceclip4.png)
