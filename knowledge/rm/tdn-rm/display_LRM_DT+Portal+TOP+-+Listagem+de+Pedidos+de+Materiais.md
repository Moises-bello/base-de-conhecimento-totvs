# LISTAGEM DE PEDIDO DE MATERIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Pedido de Material. |
| **Situação/Requisito:** | * Criar a listagem de pedidos baseado nos protótipos feitos     Critérios de Aceite:     * É necessário implementação  para mobile * É necessário apenas a listagem dos pedidos * É necessário implementação da exclusão do pedido. * Não é necessário a edição ou processos do pedido   . |
| **Solução/Implementação:** | Foi desenvolvido a listagem de pedido de material de forma responsiva para os dispositivos: mobile, tablet e desktop.  A listagem possui filtros por intervalo de data e status do pedido de material.  Pela listagem é possível excluir um pedido de material, possui um link para ir para a página de edição e detalhes e links para processos correspondentes ao pedido de material. |
