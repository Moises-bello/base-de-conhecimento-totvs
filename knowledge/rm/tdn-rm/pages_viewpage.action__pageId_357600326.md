# CENSO - GERADOR DE SAÍDA - DOCENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Censo - Gerador de Saída - Docente* |
| **Situação/Requisito:** | *Ao utilizar os dados do último processo na geração do arquivo para o censo do ensino superior o mesmo não estava carregando e salvando os dados do professor na instituição do MEC (SPROFESSORINSTITUICAOMEC), com isso não é gerado nada no arquivo de saída.* |
| **Solução/Implementação:** | *Ajuste no processo de preparação do arquivo para o Censo Escolar do Ensino Superior, para que quando não é utilizado os dados do último processo, o mesmo carregue e salve os dados do professor na instituição do MEC (SPROFESSORINSTITUICAOMEC).* |
