O Book de Relatórios tem o  objetivo de otimizar o dia-a-dia dos usuários.

Os relatórios importados não poderão ser alterados, porém, o usuário terá a possibilidade executar a "Cópia" para realizar a alteração conforme a sua necessidade.

Para a parametrização, o usuário deverá ter um conhecimento prévio da estrutura da base de dados, para que os filtros sejam aplicados de forma correta e retorne a informação conforme a estrutura do relatório.

|  |  |  |
| --- | --- | --- |
| **Código** | **Nome** | **Descrição** |
| BIBREL0001 | Publicação | Lista as publicações e seus exemplares. |
| BIBREL0002 | Controle de Empréstimos | Lista os empréstimos realizados no determinado período. |
| BIBREL0003 | Controle de Devolução | Lista as devoluções realizadas no determinado período. |
| BIBREL0004 | Controle de Reservas | Lista as reservas realizadas no determinado período. |
| BIBREL0005 | Etiqueta - Carteirinha do Usuário | Gera etiquetas com código de barras dos usuários da biblioteca. |
| BIBREL0006 | Etiqueta - Controle Interno | Listagem de etiquetas de controle Interno da publicação. |
| BIBREL0007 | Etiqueta - Código do Exemplar | Gera etiquetas com código de barras dos exemplares da biblioteca. |
| BIBREL0007.1 | Etiqueta - Código do Exemplar - Código de barras grande | Gera etiquetas com código de barras dos exemplares da biblioteca porém quando a junção do código da publicação e o código de exemplar for grande e exceder o tamanho do componente de código de barras do relatório BIBREL0007. |
| BIBREL0008 | Aquisição por Área e Subárea do Conhecimento | Informa o número de publicações e exemplares por área e subárea de conhecimento. |
| BIBREL0009 | Histórico de Empréstimos por Cliente | Lista os empréstimos realizados por usuário da biblioteca. |
| BIBREL0010 | Resultado de Pesquisa - Publicação | Lista a ficha Técnica por publicação |
| BIBREL0011 | Resultado de Pesquisa - Exemplar | Lista a ficha Técnica das Publicações por exemplares. |
| BIBREL0012 | Listagem Sintética de Publicações | Lista as informações resumidas das publicações. |
| BIBREL0013 | Ficha Técnica de Publicações | Lista as informações detalhadas das publicações e exemplares. |
| BIBREL0014 | Relação de Empréstimos | Lista a relação de empréstimos realizados. |
| BIBREL0015 | Listagem de Usuários | Lista os usuários da biblioteca. |
| BIBREL0016 | Relação de Devolução | Lista a relação de devoluções realizadas. |
| BIBREL0017 | Recibo de empréstimo (padrão para impressora tipo bematech) | Recibo de empréstimo utilizado para impressão em impressoras tipo bematech porém que utilizem o pool de impressão. |
| BIBREL0018 | Recibo de devolução (padrão para impressora tipo bematech) | Recibo de devolução utilizado para impressão em impressoras tipo bematech porém que utilizem o pool de impressão. |
