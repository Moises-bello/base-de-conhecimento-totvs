Para processos seletivos do nível de ensino básico, alguns campos não serão exibidos pois não são necessários: "Situação de matrícula no curso" e "Situação de matrícula nas disciplinas".

Informações

Para que os dados de deficiência do candidato sejam replicados ao Aluno matriculado que já existe na base de dados, deve-se marcar o parâmetro "Sobrescrever as informações de deficiência do aluno", disponível na aba "Matrícula | Acadêmico", para um novo aluno na base de dados o sistema sempre irá levar os dados de deficiência.

**Observação: Apenas os dados referentes ao aluno serão sujeitos a sobrescrita em caso de aproveitamento de pessoa, os dados dos responsáveis não serão alterados.**

Matrícula

Caso seja informada uma turma nas definições de matrícula será possível parametrizar o sistema para que o seja ignorados disciplinas concluídas ou em curso, ou seja, caso o candidato já tenha sido aluno e está sendo matriculado em uma turma que possui disciplinas que já foram concluídas ou estão em curso no passado, o sistema poderá ignorar estas disciplinas e prosseguir com a matrícula sem impedimento.   
Para mais informações acesse: [Parâmetros de Matrícula](https://tdn.totvs.com/pages/viewpage.action?pageId=829296188)

Obs: esta modificação estará disponível à partir da versão 12.1.2406 prevista para Junho de 2024.
