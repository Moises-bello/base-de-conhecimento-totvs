# LOOKUPS DE CENTRO DE CUSTO NÃO RESPEITAM O PARÂMETRO GLOBAL "Exibir Centros de Custos que não permitem lançamentos"

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Lookups de centros de custos* |
| **Situação/Requisito:** | *Lookups de centros de custos não respeitam o parâmetro global "Exibir Centros de Custos que não permitem lançamentos" e algumas telas mostram centros de custos que permitem lançamentos e outras não.* |
| **Solução/Implementação:** | *Foi realizado um ajuste a fim de se respeitar o parâmetro global citado e filtro fixos para centros de custos que permitem lançamentos para telas do financeiro: Contrato, Repasse de Bolsas, Aproveitamento de valores em conta corrente.*  *Foram alteradas as telas:*  *- Contrato (Financeiro Contábil -> Contratos):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Os centros de custos exibidos são sempre os centros de custos que permitem lançamentos com o parâmetro de globais marcado ou não* *- Repasse de Bolsas (Financeiro Contábil -> Assistentes -> Repasse de Bolsas):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Os centros de custos exibidos passaram a ser sempre os centros de custos que permitem lançamentos com o parâmetro de globais marcado ou não* *- Aproveitamento de valores em conta corrente (Anexo de Alunos -> Conta Corrente -> Processo Aproveitar Valores em Conta Corrente):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Os centros de custos exibidos passaram a ser sempre os centros de custos que permitem lançamentos com o parâmetro de globais marcado ou não* *- Aproveitamento de valores em conta corrente para vários registros (Financeiro Contábil -> Assistentes -> Aproveitar valores em conta corrente):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Os centros de custos exibidos passaram a ser sempre os centros de custos que permitem lançamentos com o parâmetro de globais marcado ou não* *- Ofertar Matriz Curricular (Processo da Matriz Curricular):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastro de Matriz aplicada (Anexo da Matriz Curricular -> Matriz Aplicada):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Excluído o filtro do lookup de centro de custo que só filtrava os centros de custos que permitem lançamentos.* *- Parâmetros de sistema de Bolsa Retroativa* *(Parâmetros do Educacional -> Integração -> Financeiro -> Educacional* *O sistema deverá estar sendo executado em uma base com o novo modelo de bolsa retroativa habilitado. Para habilitar o mesmo, deverá ser executada a sentença "UPDATE SPARAMGERAL SET VALORBOOLEAN = 'S' WHERE IDPARAMETRO = 'HABILITANOVOMODELOBOLSARETROATIVA'".)* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastrar Turmas/Disciplinas (Processo da Turma)* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastro rápido de turmas / turmas disciplinas (Atividades Acadêmicas -> Assistentes)* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastro de Turmas Disciplinas:* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Excluído o filtro do lookup de centro de custo que só filtrava os centros de custos que permitem lançamentos.* *- Cadastro de turmas:* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastro de atividades extras (Anexo do cadastro de professor):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* *- Cadastro de grupos de atividades (Currículo e Oferta -> Mais -> Componentes Curriculares -> Anexo Modalidades -> Editar Modalidade e acessar o grupo de atividade):* *- Alterada a herança do lookup de centro de custo para RM.Ctb.Lib.WinForms.RMSCtbCCustoLookup e setada a propriedade para respeitar o parâmetro global de exibição de centros de custos que permitem lançamentos* |
