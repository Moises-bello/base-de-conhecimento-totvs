## **01. VISÃO GERAL**

## Esta tela tem como objetivo visualizar uma evolução já registrada do paciente.

## **02. IMPORTANTE**

## Paciente deve ter ao menos uma Evolução registrada no sistema;

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Ao entrar na evolução com status de visualização os campos apareceram bloqueados, sendo possível visualizar os dados, executar a ação de voltar, salvar um modelo de evolução ou reimprimir. 2. Ações dos botões:    1. **Voltar**: voltará para a tela de listagem de evolução;    2. **Salvar como modelo**: salvará informações da tela para usar como modelo de futuras evoluções, [saiba mais sobre Salvar como modelo](https://tdn.totvs.com/display/SaudePiloto/Salvar+como+modelo).    3. **Imprimir:**gerará novamente o impresso da evolução. |
