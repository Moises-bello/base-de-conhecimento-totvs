Processo utilizado para realizar a exportação de um ou mais XML para um diretório especificado pelo usuário.

O usuário poderá salvar todos os xml de notas Pendentes, Autorizadas, rejeitadas, inconsistentes. Para exportação de XML de NF-e cancelada será gerado os arquivos de autorização e do cancelamento.

***Nota:*** O usuário deve ter acesso no diretório (local/rede) de leitura e escrita para realizar esse processo.
