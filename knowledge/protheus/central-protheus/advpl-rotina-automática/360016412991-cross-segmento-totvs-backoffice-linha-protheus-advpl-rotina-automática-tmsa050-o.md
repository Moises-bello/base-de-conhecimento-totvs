Dúvida**Na rotina automática TMSA050 é possível executar o calculo de Frete via ExecAuto?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus – ADVPL – A partir da versão P12.1.17  
  
**Solução**O TMS não possui execução de rotinas automáticas para o cálculo do frete, assim como gravação do Valor informado X Documento (tabela DV1).  
Para importação dos dados do CT-e, pode ser utilizada a importação de documentos, verificar a documentação em [TMSImpDoc Importar CTRC](https://tdn.totvs.com/display/public/PROT/TMSImpDoc+-+Importar+CTRC)
