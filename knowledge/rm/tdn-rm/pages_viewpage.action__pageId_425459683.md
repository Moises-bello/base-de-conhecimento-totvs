Por este processo é possível definir a obrigatoriedade de resposta das questões no momento da realização de uma avaliação utilizando o RM Executor ou Executor Web. Para executar esse processo é necessário selecionar qual(is) questão(ões) deverão ter resposta obrigatória na prova para isto, deve-se marcar a opção "Definir questão(ões) como obrigatória(s)". Caso deseje voltar uma questão marcada como obrigatória para não obrigatória basta deixar a opção "Definir questão(ões) como obrigatória(s)" desmarcada e executar o processo novamente. No log serão exibidas quais questões foram definidas como obrigatórias.

Observação

É possível visualizar na visão "Questões da prova" quais questão são de reposta obrigatória .

Atenção

Ao executar uma prova via RM Executor ou Executor Web que possui questões obrigatórias não respondidas, a prova não pode ser finalizada, exceto se o tempo de limite for atingindo ou se o usuário fechar o browser (caso seja feita pelo Executor Web).
