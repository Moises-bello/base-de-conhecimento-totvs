# DIRF/INFORME DE RENDIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *DIRF/Informe de Rendimentos* |
| **Situação/Requisito:** | Ao gerar o Informe de Rendimentos quando funcionário recebe o evento Previdência Privada e o mesmo está com a opção de “Dedutível de IRRF”, o sistema está abatendo no total de rendimento item 03 linha 01. |
| **Solução/Implementação:** | Ajustado para não considerar no Informe de Rendimentos o evento Previdência Privada no total de rendimento item 03 linha 01. |
| **Tickets relacionados:** | *MRH-6903* |
