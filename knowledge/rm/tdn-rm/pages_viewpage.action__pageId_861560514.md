# Objetivo

---

O controle de faixa etária permite definir que uma determinada área ofertada só aceite candidatos nascidos em um determinado período.

Quando for selecionado uma área ofertada na etapa onde é informado os nomes do candidatos que possui controle de faixa etária a inscrição só poderá prosseguir se for informado uma data que esteja entre o período permitido da área ofertada.

# Utilização

---

Ao selecionar uma área ofertada que possua controle de faixa etária será exibido um texto informando qual o período permitido na data de nascimento e o campo para informar a data de nascimento. 

Caso seja informado uma data que não esteja no período permitido, o campo será limpo e será informado uma mensagem alertado sobre a inconsistência no período na data, lembrando que só será possível prosseguir com a inscrição após informar uma data válida.
