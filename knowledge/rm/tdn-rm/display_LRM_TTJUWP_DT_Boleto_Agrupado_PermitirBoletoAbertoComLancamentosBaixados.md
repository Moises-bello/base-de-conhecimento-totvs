# Mudança de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Gerar lançamento* |
| **Situação/Requisito:** | *Para o Educacional, o status do boleto ficará “Em Aberto”, ao gerar um boleto agrupando lançamento Em Aberto com lançamento Baixado. Esta situação ocorrerá somente quando existir uma bolsa de 100% para apenas uma parcela.* |
| **Solução/Implementação:** | *Melhoria no processo de baixa de boleto agrupado, quando contém um lançamento baixado automaticamente com bolsa de 100% e demais em aberto, o status do boleto se manterá “Em Aberto”.* |
