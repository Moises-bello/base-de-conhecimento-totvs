# ATUALIZAÇÃO DE REFERÊNCIA EM BAIXA DE LANÇAMENTO VINCULADO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção de Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Baixa de lançamentos. |
| **Situação/Requisito:** | Sistema não atualiza corretamente os campos de referência de baixa (tabela FRELLAN) dos lançamentos vinculados quando os mesmos eram baixados e havia outros lançamentos vinculados à mesma origem não baixados. Com isso, o cálculo do valor líquido do lançamento origem do vínculo apresentava valor negativo. |
| **Solução/Implementação:** | Ajustado o processo de baixa para correta atualização das referências de baixa na tabela de relacionamento entre lançamentos. |
| **Conversores e Parâmetros:** | N/A. |
| **Tickets relacionados:** | N/A. |
| **Requisito:** | FINANCEIRO01-352. |
