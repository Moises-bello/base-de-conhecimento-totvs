***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)*** Tempo aproximado para leitura: **00:00:45 min** **Dúvida**Qual é o objetivo da rotina **O.S. - Ordem de Serviço Corretiva - MNTA420**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Manutenção de Ativos (SIGAMNT) - Todas as versões  
  
**Solução**A rotina **O.S Corretiva - MNTA420** tem por objetivo gerar uma **O.S**. que receba o máximo de urgência para ser atendida. O usuário seleciona o **Bem** para o qual irá incluir a ordem, e o programa irá gerar uma **O.S**. para o **Plano de Manutenção** igual a **000000**, que é destinado às manutenções corretivas.  
A **O.S. Corretiva** pode ser incluída tanto para **Bem** como **Localizações**, nas situações de **Cancelada**, **Liberada** ou **Pendente**. É possível prever insumos e incluir etapas genéricas para a **O.S.**
