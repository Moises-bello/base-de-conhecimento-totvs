# Período de baixa na baixa com cheque

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa com cheque |
| **Situação/Requisito:** | O parâmetro "período de baixa" não é verificado na baixa com cheque |
| **Solução/Implementação:** | Na baixa com cheque emitido a data da baixa informada será validada se está dentro do período de baixa configurado nos parâmetros do sistema |
| **Conversores e Parâmetros:** | Contas a Pagar ou Contas a Receber -> Baixa -> Manutenção de Baixas -> Baixa 1/5 -> Período para baixa |
