**Dúvida**Quais as impressoras homologadas para uso no SIGAACD?

**Ambiente**

Protheus SIGAACD versão A partir da versão 11.80

**Solução**

O Protheus para os processo do SIGAACD não mais homologa por modelo ou marca, mas sim por linguagem de programação da impressora, isso devido ao grande número de modelos existente no mercado.

Segue as linguagens homologadas, veja um modelo que faça uso de uma dessas linguagens.

• ZPL - Linguagem de programação do fornecedor Zebra  
• EPL – Linguagem de programação do fornecedor EPL  
• DPL – Linguagem de programação do fornecedor DATAMAX  
• IPL – Linguagem de programação do fornecedor INTERMEC
