![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/27623096597143) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como alterar o Fabricante do item no Desembaraço **(EICDI502)**?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão 12.1.2210.  
  
**Solução**Para realizar a alteração do Fabricante do Item do Desembaraço é necessário executar o procedimento abaixo:  
1. Acesse a rotina de Atualização\Desembaraço\Manutenção , posicione no processo e selecione alterar;  
2. Selecione Outras Ações\Itens;  
3. Desmarque o item e informe o novo fabricante e selecione OK;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27623096605847)

4. Após selecione Salvar para gravar o processo.
