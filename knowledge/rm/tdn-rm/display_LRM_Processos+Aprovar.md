**Processos Aprovar**

**Aprovar Batidas -** Selecione a(s) batida(s) que deseja aprovar e selecione o processo Aprovar. Ao executar este processo o sistema mudará o status da batida para "D" digitado e as batidas farão parte do cálculo. Os registros das mesmas no Arquivo Fonte de Dados Tratado passarão de Incluída desconsiderada para Incluída considerada.

**Considerar Justificativa(s) do(s) Subordinado(s) -** Selecionando essa opção o sistema irá executar o processo preservando a justificativa informada pelo subordinado.

**Preencher Justificativa -** Selecionando essa opção será habilitado um novo campo para ser preenchida a justificativa de aprovação das batidas, a justificativa informada irá sobrepor a justificativa dos subordinados.

**Considerar Justificativa(s) do(s) Subordinado(s) -** Selecionando essa opção o sistema irá executar o processo preservando a justificativa informada pelo subordinado.

**Preencher Justificativa -** Selecionando essa opção será habilitado um novo campo para ser preenchida a justificativa de desconsideração das batidas e a justificativa informada irá sobrepor a justificativa dos subordinados
