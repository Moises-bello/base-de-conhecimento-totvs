# GERAR BOLETO PARA NOTA DE CRÉDITO, NOTA DE CRÉDITO DE ADIANTAMENTO E DEVOLUÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Geração de boletos. |
| **Situação/Requisito:** | Necessidade de gerar boletos para lançamentos de devolução, nota de crédito ou nota de crédito de adiantamento cujos vínculos já estão baixados. |
| **Solução/Implementação:** | Será permitido gerar o boleto para lançamentos de devolução, nota de crédito ou nota de crédito de adiantamento cujos vínculos já estão baixados ou para aqueles que não possuem vínculos. Não será permitido cancelar a baixa do lançamento vínculo caso o boleto da devolução, nota de crédito ou nota de crédito de adiantamento esteja ativo. |
