# CADASTRO DO ALUNO - FILIAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Cadastro do aluno - Filiação.* |
| **Situação/Requisito:** | *Ao dar um duplo clique na grid de filiação é emitida uma mensagem informando que os dados do aluno devem ser salvos antes de abrir a edição da pessoa, mas mesmo após salvar o registro a mensagem continua sendo exibida e a edição de pessoa não é aberta.* |
| **Solução/Implementação:** | *Ajustes para que a mensagem informando a necessidade de salvar os dados do aluno questione o usuário se deseja salvar o registro. Caso o usuário clique na opção 'Sim' o registro do aluno é salvo e a tela de edição da pessoa é exibida.* |
