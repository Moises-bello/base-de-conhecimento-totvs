**Dúvida**  
Como utilizar a funcionalidade de Facilitador no Cadastro de Fornecedores(**MATA020**)?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Compras (SIGACOM) - Todas as versões.

**Solução**  
A rotina de Cadastro de Fornecedores (**MATA020**) possui um facilitador para alteração do cadastro, essa funcionalidade é utilizada quando é necessário atualizar o conteúdo de diversos campos ao mesmo tempo, sem que seja necessário acessar o formulário de cadastro e alterar campo a campo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/33661338608663)

O sistema apresentará uma tela informando que o Facilitador foi iniciado e iniciará as etapas:

* Etapa 1/5  - Campos a serem alterados:

![1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33661138215191)

Nesta etapa é possível selecionar os campos que deseja alterar na etapas posteriores, nela é possível buscar o campo pelo nome através da pesquisa.

* Etapa 2/5 - Filtro:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/33661138217111)

É possível realizar um filtro de quais registros deseja alterar, se, por exemplo, for selecionado um filtro onde "Loja" é igual a '00' por exemplo, o sistema irá realizar a alteração de todos os cadastros de cliente que possuem o campo "Loja" (A2\_LOJA) preenchido com '00'.

* Etapa 3/5  - Grupo:

![3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33661138220695)

Nesta etapa é formado um grupo dos campos que serão apresentados para alteração na próxima etapa

* Etapa 4/5 - Edição:

![4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33661154314391)

O sistema apresenta os campos selecionados na etapa anterior, indicando qual era o conteúdo antigo deles e permitindo inserir a informação nos campos de conteúdo novo.

* Etapa 5/5 - Resumo:

![5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33661154317463)

Nesta etapa o sistema demonstra tudo que será realizado, podendo verificar os campos, os filtros e os grupos que serão editados após a confirmação.
