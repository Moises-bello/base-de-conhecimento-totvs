A atualização automática do SmartClient agora funciona no sistema operacional MacOSX.

|  |  |
| --- | --- |
| Situação | Existe a necessidade de implementar a atualização automática do SmartClient para o sistema operacional MacOSX. |
| Ocorrência | A funcionalidade não existe. |
| Implementação | A atualização automática do SmartClient agora também pode ser feita em sistemas operacionais MacOSX. O AppServer deve ser configurado para tanto conforme documentação da funcionalidade, e deve estar no mínimo na versão 17.3.0.14. |
| Informações adicionais | * Referente ao chamado: #2417848 * Referente à ocorrência: ITEC-307 * Disponível em builds superiores a 17.3.0.9 |
