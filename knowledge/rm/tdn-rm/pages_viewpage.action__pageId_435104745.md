No Cadastro de Imóveis, foi criado o anexo de **Matrículas do Imóvel** para realização do cadastro de uma ou mais matrículas vinculadas ao imóvel.  
 Um imóvel pode ter mais de uma matricula quando são unidos vários terrenos para construir um único imóvel.  
 A regularização do imóvel pode demorar anos e enquanto a unificação em um único registro não acontece, deve-se registrar todos, e manter a data (inicio e fim) a data final só será preenchida se um novo registro for criado para unificar os anteriores.

**Campos da tela:**

* **Código:** Campo que mostra o código da matrícula cadastrada. Não é possível editar este campo, a informação é inserida pelo sistema.
* **Data de início:** Informação da data de início da matrícula. Este campo é obrigatório.
* **Data final:** Esta data não é obrigatório e só será preenchida se um novo registro for criado para unificar os anteriores.
* **Descrição:** Campo utilizado para informar uma descrição do cadastro de matrícula realizado. Este campo é obrigatório.
