**Dúvida**No sistema é possível cadastrar Kits de Produtos para que determinada Venda contemple os itens do Kit no Faturamento?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.

**Solução** **O módulo Faturamento não trabalha com o conceito de Kit**. Para que os produtos tenham baixa de estoque, é necessário que estejam devidamente relacionados individualmente no Pedido de Vendas e no respectivo Documento de Saída.

| **Exemplo: Cesta básica** **- Produto caixa de papelão promocional** **- Produto arroz** **- Produto feijão** **- Produto farinha de trigo** |
| --- |

Não há como mencionar "Cesta básica" na Nota de Saída pois, para que seja dada baixa no estoque é necessário registrar o devido produto na nota, inclusive para questões fiscais.
