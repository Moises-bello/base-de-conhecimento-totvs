Ainda nos Processos do Modelo 3D do Projeto, temos o Processo de Copiar Arquivo IFC, dentro desse Processo temos duas Ações, veja.

*"Para executar este Processo **não** se faz necessário selecionar nenhum Arquivo IFC"*

**Compartilhar**

Ao selecionar a Ação de compartilhamento, é possível compartilhar o mesmo Arquivo IFC com outros Projetos.

* Após um retorno positivo do Processo quanto ao Compartilhamento do Arquivo IFC, o sistema utiliza o mesmo Arquivo que encontra-se na pasta configurada no arquivo *host.config.*Desta forma, caso o Arquivo receba alguma alteração em um dos Projetos compartilhados, as alterações irão refletir para todos os Projetos.
* Durante a execução do compartilhamento, é possível alterar a Descrição do Modelo.
* O sistema permite que um arquivo compartilhado seja excluído do Projeto, porém só será excluído da Pasta configurada no arquivo *host.config*caso não esteja em mais de um Projeto.

**Copiar**

Ao selecionar a Ação de Cópia, é possível copiar um Arquivo IFC de um projeto para o outro.

* Após executado, o sistema gera uma cópia do Arquivo IFC no Projeto corrente.
* Durante a execução do compartilhamento, é possível alterar o Nome e a Descrição do Modelo.

*"Durante a execução do Processo, seja com a Ação de Compartilhar ou Copiar, o sistema apresenta apenas projetos que o usuário tenham permissão de acesso."*
