# Login no EducaMobile com sessão gravada em banco de dados

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Login do EducaMobile |
| **Situação/Requisito:** | O cliente gostaria de registrar a sessão do EducaMobile em banco de dados, através da configuração da "session state", usando o SQL Server, mas não era possível. |
| **Solução/Implementação:** | Otimizada a autenticação do EducaMobile através do método de gravação de sessão no banco de dados, que delega a gravação da sessão de um usuário no banco, não necessitando que esta seja gerenciado pelo IIS. |
