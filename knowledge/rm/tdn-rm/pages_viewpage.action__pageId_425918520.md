Este modo de acesso ao **Executor de Avaliações e Pesquisas** é realizado quando existe uma prova que não permite a mudança de tela e o sistema não bloqueia o acesso ao Gerenciador de Tarefas do Windows.

Para acessar o **Executor de Avaliações e Pesquisas** no modo administrador devem ser realizado os seguintes procedimentos:

**1 -** Abrir o Executar do Windows. O acesso ao Executar pode ser realizado através do atalho Tecla Windows + R.

**2 -** Colocar a linha de comando no Executar do Windows passando o parâmetro /ADMIN/ conforme a seguir:  
 <caminho do executável> + \ + nome do executável + espaço + /ADMIN/ ou <caminho do executável> + \ + nome do executável + espaço + /admin/

Exemplo: C:\ totvs\CorporeRm\RMExecutor\RM.TstExec.Executor.exe /ADMIN/

**3 -** Executar o comando.

**Observação**

No modo de acesso administrador, quando o sistema não consegue desabilitar o acesso ao Gerenciador de Tarefas será exibido mensagem de aviso ao usuário ao iniciar e finalizar a prova.
