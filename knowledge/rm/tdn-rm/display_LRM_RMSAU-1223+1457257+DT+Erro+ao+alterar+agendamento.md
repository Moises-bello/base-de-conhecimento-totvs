# Erro ao alterar agendamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Agenda de Atendimentos |
| **Situação/Requisito:** | Ao realizar o cadastro de uma agenda de atendimento a mesma estava mostrando uma mensagem de erro, foi verificado que a mensagem era originada por causa da falta de implementação da verificação da TISS quando a agenda está configurada para realizar a pesquisa direto no convênio via web service. Versão 3.03.02 da TISS não estava implementada. |
| **Solução/Implementação:** | Versão 3.03.02 da TISS implementada. Quando a agenda está configurada para realizar a pesquisa direto no convênio via web service. |
