## Procedimento para Utilização

Para acessar a página de Cadastro de Transportadoras em HTML, é preciso entrar no Fluig ou diretamente no endereço do servidor na qual as páginas estão hospedadas.

Existe o menu:

Gestão de Estoque, Compras e Faturamento | Transportadoras

Este menu leva para a página de listagem com informações dos transportadoras.

Nos itens listados, estão disponíveis as opções Editar e Excluir.

A página de inclusão de registro possui os campos para inserir ou editar um Transportadora.
