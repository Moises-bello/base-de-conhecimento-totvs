# GERAR CONTABILIZAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Educacional |
| **Função:** | Gerar Lançamento |
| **Situação/Requisito:** | Ao gerar lançamentos, para alunos que não possuem turma, é mostrado erro, solicitando o centro de custo, que está parametrizado, para buscar da turma, porém no Gestão Financeira, o centro de custo não é obrigatório. |
| **Solução/Implementação:** | Otimizado processo de "Gerar Lançamento", para observar o parâmetro Financeiro "*"*Recursos Adicionais |Rateio Centro de Custo/Natureza Orçamentária" onde  Obrigatoriedade = "Não Obrigatório*". Caso não seja informado o centro de custo, o sistema não irá fazer o rateio .* |
