**Dúvida**  
Como configurar Impressão de Cheques FINR480 para evitar o Erro " Nenhum cheque foi encontrado para Emissão"?  
   
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINR480 - Todas as versões  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

1. Configurar o layout da impressão do cheque através da rotina **Cheques** (**Miscelânea** > **Arquivos** > **Cheques**(**CFGX015**)

 2. Acesse a rotina **Impressão de Cheques** (**FINR480**) e configure os parâmetros.

 3. Cheque pronto para ser impresso.

**Importante:**O processo de homologação de novos equipamentos deve ser solicitado ao agente de relacionamento TOTVS, no qual seja registrado o projeto e assim avaliado pela equipe especialista.
