**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12 **Solução**Parâmetro MV\_AGRQTPE - Quantidade permitida de excedente no ticket pesagem:

|  |  |
| --- | --- |
| **Linha de Produto:** | Microsiga Protheus |
| **Segmento:** | Agroindústria |
| **Módulo:** | SIGAAGR |
| **Rotina:** | O parâmetro MV\_AGRQTPE  é do tipo numérico e está localizado na rotina de Romaneio de Saída de Algodão (AGRA750) .   Indica  a quantidade (UN produto) que deve ser somada ao ticket de pesagem para permitir exceder o ticket de pesagem.  Caso o parâmetro não exista no dicionário ou não possua valor informado a quantidade padrão será 0, desta forma validando que não ultrapasse o saldo do ticket. |
| **Parâmetro(s):** | MV\_AGRQTPE |
