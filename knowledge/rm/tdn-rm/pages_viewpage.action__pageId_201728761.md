# APROVEITAMENTO DE CONTRATO NA MUDANÇA DE TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Mudança de turma* |
| **Situação/Requisito:** | *Com o sistema parametrizado para aproveitar o contrato financeiro na mudança de turma, ao realizar o processo de mudança de turma, onde o status de matrícula no período letivo da turma de destino não exigir contrato financeiro, o sistema cancela o contrato financeiro existente.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de mudança de turma de forma que o sistema não mais irá cancelar o contrato financeiro se, ao executar o processo de mudança de turma, o status de matrícula no período letivo de destino não exigir um contrato financeiro.* |
