![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20002193541527) Tempo aproximado para leitura: **03:00:00 min** **Dúvida**Como fazer para imprimir um relatório com os pedidos de uma determinada legenda? Por exemplo como imprimir apenas pedidos de legenda laranja?  
  
**Ambiente**Protheus – Compras – A partir da versão 12.1.33  
  
**Solução**Para imprimir um relatório com os pedidos de uma determinada legenda, no caso a legenda laranja, vamos criar um filtro no browse da rotina MATA121 (pedido de compras) e depois imprimir o browse da rotina.

**1º passo:** Acesse a rotina MATA121, clique em "filtrar"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20002178969751)

**2º passo:** Criar um filtro de acordo com a legenda que deseja e aplicá-lo. Para isso, segue duas documentações abaixo. A primeira, explica o que significa cada legenda e a segunda, como fazer os filtros para cada uma das legendas.

[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Legendas - Rotina Pedido de Compras](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360029175971) 

[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Como filtrar o pedido de compras para mostrar por legenda no browser](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360025984513-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Como-filtrar-o-pedido-de-compras-para-mostrar-por-legenda-no-browser)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20002193547927)

Após aplicar o filtro, o sistema trará apenas os pedidos com a legenda desejada.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20002178972823)

3º passo: Clicar em "Outras Ações" -> "imprimir Browse"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20002178976279)

O sistema irá imprimir apenas os pedidos que foram filtrados e estão aparecendo no browse

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20002193560727)
