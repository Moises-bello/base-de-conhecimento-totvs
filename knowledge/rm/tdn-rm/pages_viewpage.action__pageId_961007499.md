**TOTVS Assinatura Eletrônica**

**Gerais**

Oferece opções de publicação do documento na integração com *TOTVS Assinatura Eletrônica;*

Permite também, solicitar assinatura eletrônica (TAE) no envio para aprovação:

Marcando a opção Manual, ao mover o período para aprovação, ele irá direto para a coluna "*em Liberação"* no portal de medição de contratos. Isso ocorrerá quando os dados da liberação ainda serão preenchidos, antes do envio para assinatura. Dessa forma, ao concluir o preenchimento das informações de liberação, a solicitação de assinatura será feita de forma manual pelo sistema.  Marcando a opção Automático, após a medição, quando o usuário avançar o período para "*em Aprovação"* no portal, a assinatura será solicitada. E quando assinado, poderá ser enviado para o Suprimento/Faturamento.

**Contratos**

Define os cadastros e os tipos de contrato que irão utilizar Assinatura Eletrônica.

Permite informar para cada cadastro que for utilizar assinatura eletrônica, um relatório para envio dos dados do respectivo processo, que poderá ser um relatório disponibilizado no TOTVS Compatilhamento ou customizado.

Permite da mesma formar informar para cada cadastro um bloqueio caso este processo seja dependente da assinatura.

Para os períodos de contrato, foi disponibilizado além dos parâmetros descritos logo acima, a possibilidade de anexar documentos (PDF) à medição, auxiliando no Portal de Medições de Contrato de Fornecedor; e a opção de mais um relatório default do tipo Recurso Smat View para o Boletim de Medição .

Marcando a opção de **Enviar anexo da medição**, este arquivo será enviado juntamente com o relatório para assinatura no TAE.

**RDO**

O usuário pode optar por utilizar ou não o TOTVS Assinatura Eletrônica no RDO do portal Diário de Obra. Caso a opção esteja habilitada, a integração com a Assinatura Eletrônica será realizada automaticamente ao arrastar o card no Kanban dos RDOs.
