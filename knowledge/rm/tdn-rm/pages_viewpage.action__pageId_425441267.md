Atenção

Esta funcionalidade está disponível a partir da versão 12.1.23

Importante

Quando a instituição parametrizar para que seja possível enviar mais que um documento, e o candidato selecionar dois ou mais documentos, que ultrapassem 20mb, irá ocorrer um erro para o candidato. Para que o candidato finaliza a inscrição corretamente, é necessário uma configuração adicional no web.config. Onde a instituição irá definir o tamanho máximo, na requisição. Para isso basta seguir os passos do documento abaixo:

<https://centraldeatendimento.totvs.com/hc/pt-br/articles/360028748511-RM-EDU-Incluir-arquivos-com-mais-de-30Mb-no-Upload-de-Materiais-Portal-do-Professor>

Após inserir as tags informadas acima, o candidato conseguirá enviar documentos sem problemas.

Na área ofertada do processo seletivo é possível informar os documentos que serão pedidos naquela inscrição podendo ser esses documentos obrigatórios ou não. A partir da versão 12.1.23 será possível parametrizar esse documento para ser obrigatório no momento da inscrição, ou seja, o candidato só conseguirá finalizar a inscrição caso envie a documentação solicitada do formulário de inscrição.

Foi criado um novo parâmetro para que esse documento seja obrigatório ou não no momento na inscrição que se encontra no cadastro de áreas ofertadas| Documento exigido.

 **TOTVS Processo Seletivo| Cadastros| Área de interesse ofertada| Aba Documento exigido**

Importante

Este novo parâmetro só estará disponível para o Novo Portal de Inscrições.
