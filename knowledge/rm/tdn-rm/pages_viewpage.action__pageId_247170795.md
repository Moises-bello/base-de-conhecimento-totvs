# Ajuste de Transação

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Ajuste de Transação* |
| **Situação/Requisito:** | *Ao executar o processo de ajuste de transação estava sempre trazendo as informações dos lançamentos baixados na tela de ajuste de transações e assim poluindo a visão.* |
| **Solução/Implementação:** | *Feito tratamento no processo de ajuste de transação para os casos onde o lançamento está baixado, o processo execute apenas uma vez* |
