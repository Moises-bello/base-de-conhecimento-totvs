# Quais são os cadastros relacionados à Segurança?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Módulo:** | Cadastros |
| **Assunto:** | 1. Como cadastrar Códigos de Acesso? 2. Como cadastrar Perfis? 3. Como cadastrar Usuários? 4. Como cadastrar Permissões de Acesso? |

### 1. Como cadastrar Códigos de Acesso?

Nessa opção é realizado o cadastro de Códigos de Acesso.

1. No **TOTVS Gestão Hospitalar** acesse **Cadastros/Segurança/Códigos de Acesso**.
2. Clique em **Incluir** (página em branco).
3. Preencha o Código de Acesso.
4. Informe a Descrição.
5. Preencha o Usuário de acesso ao banco de dados.
6. Clique no ícone (**Chave**) para incluir senha.
7. Preencha a Nova Senha e a confirmação de senha.
8. Clique em **OK**.

### 2. Como cadastrar Perfis?

Nessa opção é realizado o cadastro de Perfis

1. No **TOTVS Gestão Hospitalar** acesse **Cadastros/Segurança/Perfis**.
2. Clique em **Incluir** (página em branco).
3. Preencha o Código de Perfil.
4. Preencha a identificação do Perfil.
5. Marque a caixa **Ativo**.
6. Clique em **OK**.
7. Acesse o cadastro novamente.
8. Clique na guia **Acesso a Campos**.
9. Para alterar permissões, expanda o item.
10. Utilizando as caixas **Pode Consultar** e **Pode Alterar**, defina as permissões dos campos para o perfil.
11. Marque a caixa **Exibir apenas campos com restrição** para restringir a lista a campos com restrição.
12. Caso o usuário possua restrições, serão listadas na guia **Restrições**.
13. Clique na guia **Acesso a Menus**.
14. Para aplicar permissão ou proibir acesso, expanda os itens de menu.
15. Selecione o item.
16. Clique em **Permitir Acesso** para que o perfil tenha acesso aos menus.
17. Clique em **Proibir Acesso** para negar acesso ao perfil.
18. Clique na guia **Acesso a** **Relatórios/Planilhas**.
19. Clique em **Incluir** (página em branco).
20. Selecione o grupo.
21. Preencha o nível de alteração e o nível de emissão.
22. Clique em **OK**.
23. Na tela inicial de cadastro de perfil, clique em **OK**.

### 3. Como cadastrar Usuários?

Nessa opção é realizado o cadastro de Usuários.

1. No **TOTVS Gestão Hospitalar** acesse **Cadastros/Segurança/Usuários**.
2. Clique em **Incluir** (página em branco)**.**
3. Preencha o usuário para acesso.
4. Informe o Nome do usuário.
5. Informe o e-mail do usuário.
6. Selecione o código de acesso.
7. Marque a caixa **Ativo**.
8. Clique no ícone (**Chave**) para incluir senha.
9. Preencha a Nova Senha e a confirmação de senha.
10. Selecione a data de início da validade.
11. Caso a troca de senha deva ser realizada periodicamente, marque a caixa e preencha o período.
12. Para que a senha seja alterada no próximo login marque a caixa.
13. Informe a data de expiração da validade ou marque a caixa para que nunca expire.
14. Clique na guia **Segurança**.
15. Selecione a Coligada.
16. Determine se o usuário é Superior e se ele pode incluir relatórios.
17. Clique na guia **Rede**.
18. Informe o usuário e Domínio de rede.
19. Clique na guia **Redes Sociais**.
20. Preencha as informações das Redes Sociais do Usuário.
21. Clique em **OK**.

### 4. Como cadastrar Permissões de Acesso?

1. Nessa opção são visualizadas as Permissões de Acesso dos usuários.
2. No **TOTVS Gestão Hospitalar** acesse **Cadastros/Segurança/** **Permissões de Acesso**.
3. Para verificar as permissões do TOTVS Gestão Hospitalar, clique em **+** em RM Saúde/Janus.
