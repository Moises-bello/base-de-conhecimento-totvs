Ao tentar inserir custo no campo D3\_CUSTO1 na rotina MATA241 do Protheus, o Help A240F5VAL aparece quando a TM (Tipo de Movimentação) não permite valorização (F5\_VAL = Não). Para resolver, use uma TM com F5\_VAL = Sim ou deixe o campo em branco para concluir.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/27164809906839) Tempo aproximado para leitura: **00:01:00min**  
  
**Dúvida**  
Ao realizar uma movimentação na rotina Movimentações Multipla  MATA241, é apresentado o Help: A240F5VAL, o que fazer?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27164809908887)  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**  
Este help é apresentado ao inserir o custo no campo "**D3\_CUSTO1**" porém a **TM (Tipo de Movimentação)** informada não é valorizada **(F5\_VAL = Não)**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27164809910679)

**Neste caso as opções para resolução são:**

- Para que o custo seja informado, utilizar uma TM que esteja com o campo "**F5\_VAL = Sim**", permitindo assim que o valor seja informado;

- Caso queira manter a TM, não será possível informar o custo, deixando o campo em branco a inclusão será concluída;
