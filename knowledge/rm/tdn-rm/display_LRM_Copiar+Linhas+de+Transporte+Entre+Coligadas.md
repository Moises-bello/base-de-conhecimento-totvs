Este assistente irá auxiliá-lo na cópia de registro(s) entre as coligada(s) do sistema.  
 Para utilizar o assistente clique no botão Avançar.

**Parâmetros da cópia**

Na janela de Parâmetros da cópia o sistema lista todas as coligadas disponíveis na base de dados para se fazer à cópia de registro. Selecione a coligada ou as coligadas que deseja fazer a cópia e clique no botão Avançar.

**Observação**

A coligada não ficará disponível caso o usuário não tenha permissão de incluir Linhas de Transporte na coligada destino.

**Substitui registros no destino se eles já existirem**

Marque esta opção quando já existir a Linha de Transporte na coligada de destino e deseja alterar seus dados pelos dados da Linha de Transporte da coligada de origem. Caso contrário o sistema manterá os dados da Linha de Transporte na coligada de destino.

**Concluindo o Assistente de Cópia de Registros entre Coligadas**

Para fazer a cópia da Linha de Transporte entre as coligadas clique no botão 'Concluir'.
