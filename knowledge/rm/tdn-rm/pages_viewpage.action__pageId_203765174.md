# **Como realizar a mudança de Unidade de Atendimento/Faturamento de atendimento de paciente?**

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como realizar a mudança de Unidade de Atendimento/Faturamento de atendimento de paciente? |
| **Passo a passo:** | **Mudança de Unidade de Atendimento/Faturamento**  Nesta opção é possível realizar a mudança de Unidade de Atendimento e Unidade de Faturamento de Parciais de atendimento do paciente. Não é possível realizar a alteração caso a parcial já possua Nota Fiscal já emitida. Como alterar Unidade de Atendimento/Faturamento?  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Internação/Mudança de Unidade de Atendimento/ Faturamento**. 2. Clique no botão **Pesquisa (raio).** 3. Informe o nome do paciente e/ou efetue a busca clicando em **Internados** **nesta data**. 4. Selecione o paciente desejado e clique em **OK**. 5. Em seguida, informe a nova Unidade de Atendimento e a nova Unidade de Faturamento. 6. Caso o paciente possua mais de uma Parcial, selecione uma para mudança. 7. Clique em **Processa.** 8. Ao final do processamento o sistema irá emitir um relatório de todos os lançamentos NÃO transferidos para a nova Categoria. |
