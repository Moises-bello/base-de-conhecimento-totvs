![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22976981302167) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como calcular reajuste salarial para funcionários horistas  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) -Gestão de Pessoal - A partir da versão 12.  
  
**Solução**1. Cadastro do funcionário com categoria horista:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22977012179863)

2. Cálculo do Dissídio (caminho rotina Miscelânea / Reajuste / Salarial)  
Informe a categoria : H - Horista:  
 **Atenção:**

Atualiza Cadastro? : **NÃO**  
Atualiza Função? : **NÃO**  
Atualiza Base Dissídio? : **NÃO**  
Utilize estas opções para que possa ser realizada a conferência das alterações que serão realizadas. Altere para SIM e execute a rotina novamente somente quando os valores de salário alterados estiverem conferidos, uma vez que não é possível desfazer o processo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22977012181143)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22977012183447)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22976981310359)

**Importante:**   
O valor da faixa salarial informado, deverá ser o valor HORA, e não o valor composto do salário x horas trabalhadas  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/22977217239063)

3. Confirme o cálculo na opção SALVAR e será apresentado o relatório de conferências:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/22977191344919)
