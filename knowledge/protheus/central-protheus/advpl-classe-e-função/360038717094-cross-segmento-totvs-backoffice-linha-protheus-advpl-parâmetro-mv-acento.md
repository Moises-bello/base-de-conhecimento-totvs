*![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)*Tempo aproximado para leitura:**00:02:00 min****Dúvida**Utilizando o parâmetro MV\_ACENTO como N, existe algum recurso que permite ele criar um campo customizado que aceite qualquer carácter  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - a partir da versão 12  
  
**Solução**Hoje o sistema está preparado para permitir a gravação de acentos quando parâmetro está ligado.  
Um comportamento diferente poderá trazer alguns problemas para o sistema, uma vez que, por default, com o parâmetro desligado, não é esperado nenhum acento existente.
