| Sintoma | **O que é Máscara?** |
| Solução | **Máscara é uma sequência de dígitos que determinam como os dados deverão ser informados em campos pré-definidos nos Parâmetros do Sistema (Código Seção, Chapa, CEP, etc.) Esta sequência consiste basicamente na definição do número de dígitos, bem como seus respectivos tipos (letras, números e símbolos).**  **A máscara é formada pelos seguintes caracteres:**  **Símbolo - Significado**  **# - Para números**  **L - Para campo alfabético e de preenchimento obrigatório.**  **l - Para campo alfabético e de preenchimento facultativo.**  **A - Para campo alfanumérico e de preenchimento obrigatório.**  **a - Para campo alfanumérico e de preenchimento facultativo.**  **Q - Para qualquer caractere, menos os separadores ( : . , ; / )**  **Observação: Por exemplo, se a máscara de um código for L#.##, o código poderá ser: A1.01, sendo que se digitado a11, o sistema passará a "a" (minúsculo) para "A" (maiúsculo) e preencherá as outras casas com "0".** |
