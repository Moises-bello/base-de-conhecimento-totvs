# Relatório Diário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Diário |
| **Situação/Requisito:** | Cliente entrou em contato informando que ao realizar a emissão do relatório Diário com o campo 'Contrapartida inversa' habilitada, identificou que no processo de emissão a contra partida inversa repete a conta contábil devedora, ao invés de apresentar a contra partida, para as contas credoras o incidente não é apresentado. |
| **Solução/Implementação:** | Ajuste no relatório Diário para que ao marcar para exibir o campo Contra Partida Inversa seja apresentado a conta inversa da partida nessa coluna. |
