# Objetivo:

---

       O objetivo deste documento é trazer uma visão de como é feita a inclusão de objetos gerencias pelos anexos.

# Introdução:

---

Além de anexos referentes à visão principal, é possível controlar a inclusão de objetos gerenciais que variam os resultados de acordo com a seleção dos registros. Veja abaixo quais são os objetos:

# Gráficos:

---

**Incluir Gráficos à visão:**

* Acesse Anexos | Gráficos | Inserir Gráfico.
* Selecione o gráfico que você deseja incluir à visão e execute o processo.
* Em seguida é só selecionar o gráfico que é listado no menu Anexos | Gráficos.

**Links dos gráficos anexos:**

        Depois de incluir o gráfico como anexo você pode exportá-lo para imagem (jpg ou png) ou arquivo de Gráfico (.TOTVSGraf). Se preferir, pode enviar para e-mail ou exportar como anexo (.TOTVSGrafAnex).

**Incluir Gráficos anexos exportados:**

        Para incluir gráficos anexos exportados (é necessário utilizar a extensão .TOTVSGrafAnex) acesse Anexos | Gráficos | Importar Gráfico Anexo.

# Consultas SQL:

---

**Incluir Consultas SQL à visão**

* Acesse os Anexos | Consulta SQL | Inserir Consulta SQL.
* Selecione a consulta que você deseja incluir à visão e execute o processo.
* Em seguida é só selecionar a consulta que é listada no menu Anexos | Consulta SQL.

**Componentes das consultas SQL anexas**

       Depois de incluir a Consulta SQL como anexo você pode realizar tarefas comuns à tela de resultado da consulta SQL, e ainda exportá-la para arquivo de SQL anexa (.TOTVSConsSQLAnex).

**Incluir Consultas SQL anexas exportados**

       Para incluir Consultas SQL anexas exportadas ((é necessário utilizar a extensão .TOTVSConsSQLAnex) acesse Anexos | Consultas SQL | Importar Consulta SQL Anexa.

# Relatórios RM Reports:

---

**Incluir Relatórios do RM Reports à visão**

* Acesse os Anexos | Relatórios | Inserir Relatório.
* Selecione o relatório que você deseja incluir à visão e execute o processo.
* Em seguida é só selecionar o relatório que é listado no menu Anexos | Relatórios.

**Componentes dos Relatórios Anexos**

        Depois de incluir o gráfico como anexo você pode realizar tarefas como pesquisar um dado no relatório, definir uma cor à página, incluir marca d’água, salvar o relatório para vários formatos ou mesmo enviar para e-mail.
