Dúvida**Como cadastrar novos códigos de empréstimo para preenchimento do campo **Tipo de empréstimo**, utilizado para o cadastro de empréstimos no cadastro do funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
 **Solução**Os códigos de empréstimo ficam armazenados em uma tabela dinâmica específica para este fim, onde é possível cadastrar novos itens, seguindo os passos abaixo:  
  
1. Acesse a aba **Administração de pessoal | Cadastros globais | Tabelas dinâmicas**;  
2. Altere a opção **Sistema**para o módulo **folha de pagamento**, para que sejam exibidas as tabelas do módulo;    
3. Pesquise pela tabela de código **INT30:**  
4. Acesse o cadastro da tabela, selecionando a aba **Itens da tabela** e realize o cadastro de um novo código através do botão **Incluir:****![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10976325034775)**
