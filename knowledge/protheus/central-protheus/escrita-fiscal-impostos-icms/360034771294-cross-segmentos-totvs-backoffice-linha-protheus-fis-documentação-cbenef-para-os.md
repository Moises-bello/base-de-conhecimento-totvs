**Dúvida**

Como gerar a TAG cBenef para os estados RS, RJ, PR, DF, GO, SC e ES?  
  
**Ambiente**

Microsiga Protheus - Todas versões  
  
**Solução**

A geração da informação para a tag cBenef é realizada via rotina FISA140 "Produto vs Valores declaratórios".

Após emissão da nota fiscal no Protheus será gravada a tabela CDV, o XML utiliza esta tabela para gerar a tag cBenef e o SPED Fiscal utiliza para gerar o bloco E115.
