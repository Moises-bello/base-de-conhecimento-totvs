# Redesenho do preenchimento automático do código da receita e alíquota

|  |  |

| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Serviço de Tributação |
| **Situação/Requisito:** | Código de receita de tributo retido na fonte não considera o tributo para qual aplicar no preenchimento automático |
| **Solução/Implementação:** | Redesenhar o comportamento do sistema quanto à seleção de alíquota e código de receita para os tributos federais retidos (IRRF, IRRF-PJ, PIS-RF, CSRF, COSIRF, CSLL-RF, COFINS-RF, INSS e FUNRURAL).  Para corrigirmos a demanda registrada nesta issue serão necessárias as seguintes implementações:  **1.** **Cadastro do Produto – Anexo Tributos do Produto**    Habilitar o campo Código de Receita (TTRBPRD.CODIGORECEITA) para os tributos IRRF, IRRF-PJ, CSRF, PIS-RF, COFINS-RF, CSLL\_RF, COSIRF, INSS e FUNRURAL.
