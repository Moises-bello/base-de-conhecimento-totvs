# MANTER O CONTRATO ORIGINAL NA TRANSFERÊNCIA INTERNA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Transferência Interna |
| **Situação/Requisito:** | Ao realizar a transferência interna, onde o aluno é movimentado para um outro curso/habilitação/matriz e, posteriormente, retorna ao mesmo curso de origem o sistema cadastra um novo contrato, mesmo parametrizando o processo para manter o contrato de origem. |
| **Solução/Implementação:** | Alteração na rotina de transferência interna para não gerar um novo contrato quando o aluno é movimentado para um outro curso/habilitação/matriz e, posteriormente, retorna ao mesmo curso de origem e o parâmetro para manter o contrato de origem está marcado. |
