**Dúvida**  
Como corrigir a mensagem "Quantidade Estatística não preenchida"?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* - a partir da versão 12.1.2310.  
  
**Solução**  
Deve ser preenchido o campo EIJ\_QT\_EST " Qtde Estatic" nas adições do processo de importação, com a quantidade estatística do produto.
