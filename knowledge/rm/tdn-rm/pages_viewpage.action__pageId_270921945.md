# Agenda - Compromisso para vários usuários

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 12.1.XX |
| **Ocorrência:** | Configurando Compromisso para Vários Usuários |
| **Ambiente:** | Nova MDI |
| **Passo a passo:** | Acessando o sistema   Para adicionar compromissos globais no Sistema RM/ RM Portal, acesse a nova MDI (RM.exe) > Serviços Globais > Gestão > Agenda;   Configurando o compromissoPasso a Passo1º Passo Na barra superior, serão apresentados os controles da agenda.  Clique em **Compromisso para vários usuários**;         2º Passo Clique em **Avançar** e depois em **Criar Compromisso**.     3º Passo Será apresentada a visão para configuração do compromisso, configure conforme sua necessidade e clique em **Salvar e fechar**.  Após isso verifique as informações e clique em **Avançar**.     4º Passo Nesta tela, você poderá filtrar **Perfis / Usuários** que terão acesso ao compromisso criado ou clique em **Todos** (para liberar as permissões para todos os usuários).     DicaDica Caso a opção de **Lembrete** tenha sido configurada o sistema apresentará um lembre para os usuários conectados.   false O compromisso sincronizará com seus compromissos do Outlook e destinatários **somente** se o **Microsoft Outlook** estiver **instalado na máquina** utilizada para criar o compromisso 5º Passo Visualização da agenda dentro da nova MDI, com o compromisso criado:     Visualizando compromisso no RM Portal   Acesse o RM Portal > Ferramentas > Agenda de Compromissos;    Ao acessar o menu Agenda de Compromissos, será a presentada a visão abaixo, clique em **Mostrar mais** para visualizar os compromissos marcados para o dia selecionado: |
| **Observações:** | Para que os usuários consigam visualizar os compromissos criados.  No perfil associado ao usuário no sistema **Serviços Globais**, dê permissão de acesso aos itens de menu conforme sua necessidade (vide imagem abaixo). |
