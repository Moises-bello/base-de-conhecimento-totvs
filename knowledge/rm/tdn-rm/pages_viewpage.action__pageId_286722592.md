# Reabertura de competência

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Reabertura de competência |
| **Situação/Requisito:** | Ao tentar reabrir uma competência o sistema informa que existem depreciações/correções contabilizadas, para um patrimônio específico. Foi efetuada uma pesquisa e não foi identificada nenhuma justificativa para esta mensagem. |
| **Solução/Implementação:** | Não estava sendo possível excluir, através do processo de reabertura de competência, as transferências patrimoniais que foram realizadas com a opção "Unificar mantendo-se as quantidades de origem" marcada. O processo foi alterado para que todas as ocorrências existente no período vigente sejam excluídas com sucesso. |
