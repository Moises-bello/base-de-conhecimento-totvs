**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25627808225815)** Tempo aproximado para leitura: **00:02:00 min****Dúvida**Para que server a rotina **Plano de Ação x Risco** (MDTA650) e como incluir?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Essa rotina é responsável por relacionar o Plano de Ação aos Riscos da empresa visando minimizar o risco já identificado.  
Para saber como incluir um **Risco** ou um **Plano de Ação** consulte:   
[**MP - MDT - Para que server a rotina Riscos (MDTA180) e como incluir**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360056319213)  
**[MP - MDT - Para que server a rotina Plano de Ação (MDTA615) e (SGAA090) e como incluir](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057396294)**  
  
Para cadastrar acesse no modulo **SIGAMDT (35)** o caminho: atualizações > PPRA > **Plano de Ação x Risco** (MDTA650). Escolha o Plano de Ação, e clique em **Riscos**.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360099611973)  
  
Na tela seguinte será possível escolher os Riscos que farão parte deste Plano de Ação.
