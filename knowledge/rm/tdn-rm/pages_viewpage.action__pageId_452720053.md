**Copiar configuração de Avaliação**

Executando este processo, o sistema irá criar uma nova avaliação a partir de uma já existente. O processo copia toda a estrutura da avaliação selecionada para uma nova, solicitando que o usuário informe seu novo código, nome e a data de abertura e se a mesma será copiada para a coligada atual ou outras coligadas.
