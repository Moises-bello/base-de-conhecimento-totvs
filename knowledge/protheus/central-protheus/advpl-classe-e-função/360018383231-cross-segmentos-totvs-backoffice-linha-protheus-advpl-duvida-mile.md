![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:01:00 min****Dúvida**Estamos no processo de implantação do Protheus e migrando os SX's para o banco de dados.  
Existe algum impacto no uso da ferramenta Mile com os SX's no banco de dados?  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 12.1.17  
  
**Solução**O MILE pode ser usado em ambiente com dicionário no banco sem problemas.  
Mas essa opção só está disponível para novas instalações e não pode ser utilizado para migração de base já existente. Essa opção só está disponível para clientes pilotos.
