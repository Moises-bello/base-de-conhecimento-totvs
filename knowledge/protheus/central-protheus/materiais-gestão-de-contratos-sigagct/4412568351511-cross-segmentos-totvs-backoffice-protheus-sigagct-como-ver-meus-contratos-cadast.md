![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Como ver meus contratos cadastrados ?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões  
  
**Solução**Hoje no módulo padrão de gestão de contratos, a possibilidade de ver o contrato cadastrado no sistema é trave´s da rotina de Manutenção de Contratos ( CNTA300 ) em "Gestão de Contratos -> Atualizações -> Contratos -> Manutenção (CNTA300)":

Nos Browse da rotina, pode-se verificar os contrato cadastrados, onde cada um se encontra com o seu respectivo Status, conforme e a legendas da rotina:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4412552894871/mceclip0.png)

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4412560675095/mceclip2.png)

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4412568336151/mceclip1.png)

No padrão do módulo, não há disponível um relatório especifico de listagem dos contratos cadastrados, porém pode-se, caso se deseje, realizar o download do fontes padrões dos relatório disponíveis para uma customização conforme desejado. Abaixo segue artigo com instruções para este download:

[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Fontes de Relatórios de Compras para personalização](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360022534771)
