# Bolsa Retroativa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Bolsa Retroativa |
| **Situação/Requisito:** | A partir da versão 12.1.14 o sistema não esta permitindo adicionar mais de duas casas decimais no campo "Percentual" do processo de bolsa retroativa |
| **Solução/Implementação:** | Voltamos com o comportamento para que o cliente possa digitar mais de duas casas decimais, e abrimos uma nova issue para realizar a melhoria abaixo:  A partir da versão 12.1.16 o TOTVS Gestão Educacional passará a considerar na digitação dos percentuais de Bolsa a quantidade de casas decimais parametrizada na integração Financeira através do parâmetro "Nº Decimais Percentual" e não mais o parâmetro "Nº Casas Decimais". |
