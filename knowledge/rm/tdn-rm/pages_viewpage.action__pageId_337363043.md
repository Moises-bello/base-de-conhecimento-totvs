# Ajuste no cadastro de paciente - Não permitir CPF duplicado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro de Paciente. |
| **Situação/Requisito:** | Ao cadastrar um paciente o RM não verifica se o CPF cadastrado estava duplicado, mesmo parametrizado para não permitir o cadastro para o mesmo CPF. |
| **Solução/Implementação:** | Implementada a rotina para verificar se caso parametrizado não permitir o cadastro do CPF duplicado, e também não permite cadastro de CPF inválido. |
