Evento Base de Cálculo e do tipo valor, com as mesmas incidências do evento com código de cálculo 61 - IRRF FÉRIAS ENVELOPE.  
 Este código de cálculo é utilizado no cálculo da pensão alimentícia de férias quando o funcionário utilizar múltiplos vínculos.  
    
 O sistema faz o cálculo do IRRF Férias somente com a base do funcionário corrente, da mesma forma que o código de cálculo 61 quando não se utiliza múltiplos vínculos.
