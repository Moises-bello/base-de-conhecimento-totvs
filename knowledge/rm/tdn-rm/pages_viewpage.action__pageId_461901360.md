# Defaults Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Defaults Contábeis |
| **Situação/Requisito:** | Necessito que dentro do cadastro de naturezas do módulo "TOTVS Gestão Fiscal" seja possível informar defaults de contas contábeis sintéticas. Esta possibilidade deve ser possível apenas nos defaults do cadastro de natureza, nos demais defaults disponíveis em outras tabelas o comportamento deve continuar o mesmo, ou seja, apresentar somente as contas contábeis analíticas. |
| **Solução/Implementação:** | O default contábil, existente no cadastro de natureza do módulo Totvs Gestão Fiscal, passou a exibir contas contábeis sintéticas e analíticas. Para os demais defaults o comportamento continua o mesmo. |
