|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Geração de IRRF PJ |
| **Situação/Requisito:** | Cálculo do IRRF Pessoa Jurídica é feito incorretamente quando o parâmetro 'Geração do IRRF por documento fiscal' está habilitado. Foram gerados dois lançamentos para o mesmo cli/for pessoa jurídica na data. O valor do IR da segunda nota não é calculado corretamente. |
| **Solução/Implementação:** | Ajuste no processo de gerar IRRF PJ para calcular corretamente o valor ao utilizar o parâmetro "Geração do IRRF por documento fiscal" |
