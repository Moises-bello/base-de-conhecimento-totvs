# Objetivo:

---

   O objetivo desse documento é demonstrar como visualizar um Cubo através do RM.Bis.CuboViewer.exe.

# Exportar Cubo:

---

   Após acessar um cubo, clique no menu Exportar / Arquivo CUBX, conforme abaixo:

   Selecione o destino onde o onde deseja salvar o arquivo e observe o tipo de saída que deve estar como Documentos CUBX (\*.cubx)

# RM.Bis.CuboViewer.exe:

---

Acesse o diretório C:\totvs\CorporeRM\RM.Net e localize o aplicativo RM.Bis.CuboViewer.exe

Execute o aplicativo o aplicativo RM.Bis.CuboViewer.exe e localize o cubo o qual foi exportado

   O cubo será aberto sem a necessidade de abrir o RM.

Neste processo é permitido somente a visualização do cubo, caso haja a necessidade de atualização, o sistema deverá ser acessado para que seja executado o procedimento padrão de atualização do cubo.
