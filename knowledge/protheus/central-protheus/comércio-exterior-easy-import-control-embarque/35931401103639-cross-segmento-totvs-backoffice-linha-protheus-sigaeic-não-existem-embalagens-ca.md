**Dúvida**  
Como corrigir a mensagem "Não existem embalagens cadastradas para esse processo"?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* - a partir da versão 12.1.2310.  
  
**Solução**  
Deve ser preenchido o campo W6\_VOLUMES "Volumes" na aba DI/DUIMP, no Desembaraço do processo de importação, com a embalagem do produto.
