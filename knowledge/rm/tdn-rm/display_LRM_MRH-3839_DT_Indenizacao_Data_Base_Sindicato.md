# PAGAMENTO INDEVIDO DA INDENIZAÇÃO NA DISPENSA ANTES DA DATA BASE DO SINDICATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projeto* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão* |
| **Situação/Requisito:** | *Quando a data base do Sindicato é no próximo ano, o cálculo da rescisão está pagando a “INDENIZAÇÃO ADICIONAL NA DISPENSA ANTES DATA BASE” (CC 344), para funcionários que não tem direito a indenização.* |
| **Solução/Implementação:** | *Ajuste no lançamento do CC 344 quando a data base do Sindicato é no próximo ano.* |
| **Chamados relacionados:** | MRH-3839 |
| **Requisito (ISSUE):** | MRH-3839 |
