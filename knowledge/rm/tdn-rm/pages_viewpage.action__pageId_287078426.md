# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Fiscal |
| **Versões:** | 12.1.x |
| **Ocorrência:** | Alteração do Perfil do usuário nova MDI atribuindo acesso ao Gerador de Saídas |
| **Ambiente:** |  |
| **Passo a passo:** | Liberação do perfil do usuário para criação de categorias de layout gerador de saídas.    No menu de produtos da linha RM, entre em Serviços Globais, Segurança -> Perfis.        Altere o Sistema para Integração, e edite o perfil do seu usuário.        Na aba “Acesso a Menus” e localize o item 01.01.05 – Gerador de Saídas, e libere o acesso ao filho 01.01.05.02.            **Lembrando que é necessário conferir se há permissão para o perfil nos Sistemas de Serviços Globais, Gestão Fiscal e Integração.**    Agora, basta acessar o menu de Integração -> Integração - Gerador de Saídas -> Categoria. O botão de incluir está liberado. |
| **Observações:** | Recomenda-se que seja dado acesso a todo o grupo 01.01.05 - Gerador de Saída. |
