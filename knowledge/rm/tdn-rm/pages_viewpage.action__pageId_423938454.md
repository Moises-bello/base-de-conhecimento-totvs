A importação de Lançamentos de Indicador de Uso tem como finalidade adquirir dados de históricos de indicador de uso, que estão registrados em arquivos do computador, e importá-los para o sistema.   
Essa funcionalidade nos possibilita uma entrada dos dados de Indicador de Uso de maneira mais fácil, sem que esta inserção seja feita uma a uma.  
Para isso, é necessário um arquivo de dados que contenha informações de histórico de indicadores de uso e importá-los mediante layout já cadastrados no sistema.   
Para usar a funcionalidade, basta informar o layout de importação desejado e indique ao sistema o local do arquivo a importar.   
Após cada importação, será registrado um histórico das importações realizadas com sucesso.  
***Atenção!***  É muito importante que o Layout cadastrado esteja condizente com o conteúdo dos arquivos a serem importados.   
Informações como "qual separador de campos utilizar" e "posição dos campos no arquivo" são necessárias e primordiais para o sucesso da operação.
