# LOG DE MÉDIA DE COMISSÃO DE 13o. EM JANEIRO ESTÁ EXIBINDO DEZEMBRO DO ANO ANTERIOR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *13o.Salário* |
| **Situação/Requisito:** | *No log da média de comissão de 13o. na competência janeiro, quando não existe nenhum mês para apuração da média, por não considerar o ano anterior, está sendo demonstrado o mês de dezembro do ano anterior.*  *O problema está somente na exibição do log, os valores calculados estão corretos.* |
| **Solução/Implementação:** | *Ajuste no cálculo da média de comissão de 13o. na competência janeiro, para informar no log que não existe periodo para apuração das médias.* |
| **Chamados   relacionados:** | *TUBLI8, TUCHO9* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
