# Validar Guias de Resumo de Internação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento TISS |
| **Situação/Requisito:** | Inconsistência no momento de imprimir o relatório de guia de outras despesas. |
| **Solução/Implementação:** | Para evitar duplicidade de itens no relatório criou-se uma validação no encerramento da conta  e na edição das guias (não permite editar número da guia e senha) quando a conta já estiver faturada. |
