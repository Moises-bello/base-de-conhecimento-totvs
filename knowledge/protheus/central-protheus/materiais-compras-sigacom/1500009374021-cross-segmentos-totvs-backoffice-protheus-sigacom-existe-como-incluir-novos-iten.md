**Dúvida**Há como incluir novos itens / produtos em uma Cotação de Compras?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Compras - Todas as versões  
  
**Solução**Em uma Cotação de Compras já gerada, na funcionalidade padrão do sistema não há uma forma de inclusão de novos Itens / Produtos para uma cotação já gerada.

Caso se necessite incluir um novo item em uma cotação, é necessário excluir a cotação existente, e gerar uma Cotação de Compras nova baseada em SCs que possuam o novo Item/Produto desejado.
