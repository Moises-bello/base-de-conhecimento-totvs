# Adição de imagens das mensagens para texto livre no eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Adição de imagens das mensagens para texto livre no eduCONNECT |
| **Situação/Requisito:** | As mensagens cujo texto era livre permitiam adicionar imagens maiores que 100 kbytes, o que não era permitido à template de mensagens. |
| **Solução/Implementação:** | Otimizada a verificação do tamanho das imagens enviadas no corpo das mensagens do eduCONNECT, de forma que não podemos inserir imagens com tamanhos superiores a 100 kbytes. |
