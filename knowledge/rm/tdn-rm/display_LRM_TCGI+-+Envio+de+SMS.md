# **ENVIO DE SMS**

# 

# Para envio de SMS :

Para a ação de envio de SMS, será possível definir o texto do SMS com auxílio de mnemônicos (utilizar os existentes no assistente de cobrança).

Atenção.

Para utilizar esta funcionalidade é necessário contratar um plano de serviço de SMS. Para maiores informações, acesse [SMS Corporativo Via Mashup](https://tdn.totvs.com/display/LRM/SMS+Corporativo+Via+Mashup).
