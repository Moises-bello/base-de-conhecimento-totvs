![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Qual a função do campo data de vigência presente na tela de parâmetros para atualização de NCMs através do Totvs Comex Conteúdo?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**O campo data de vigência serve para determinar a data inicial para busca de atualizações. O sistema irá buscar por atualizações realizadas após a data informada. Caso deseje buscar por todas as atualizações, o campo pode ficar em branco.
