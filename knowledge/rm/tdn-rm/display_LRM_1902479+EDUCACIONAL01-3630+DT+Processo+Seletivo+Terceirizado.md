# PROCESSO SELETIVO TERCERIZADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matricula de aluno via processo seletivo terceirizado.* |
| **Situação/Requisito:** | *Ao realizar a importação de candidato do processo terceirizado o sistema não atualiza os novos dados cadastrais (Bairro, por exemplo), devido ao fato de já existir uma pessoa cadastrada no sistema.* |
| **Solução/Implementação:** | *Foi incluído o parâmetro "Atualizar dados da pessoa existente" que tem a função de atualizar os dados da pessoa existente de acordo com os dados informados para o candidato do processo seletivo.* |
