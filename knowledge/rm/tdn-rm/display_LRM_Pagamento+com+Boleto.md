Possibilitar ao usuário o pagamento do título com boleto e registrar o mesmo online para retorno do IPTE caso o mesmo não esteja registrado.

Usuário terá a opção de copiar o IPTE para a área de transferência ou compartilhar o IPTE através do compartilhamento padrão do sistema operacional de cada dispositivo.

 

A exibição do **Menu de Pagamento** e botão para pagamento com "**BOLETO**" deve seguir algumas parametrizações, acesse as regras [cliquando aqui](https://tdn.totvs.com/).

A impressão do boleto obedecerá as mesmas regras descritos em [Boleto - Portal do Aluno](https://tdn.totvs.com/x/auhvI).

Pagamento Boleto

Na tela de seleção de método de pagamento, o usuário selecionará a opção "**Boleto**" e avançará para o próximo passo

O próximo passo é a visualização do resumo dos lançamentos do boleto. Para mais detalhes do resumo dos lançamentos clique .

Após prosseguir com o pagamento, o usuário verá uma tela informando o valor pago e o IPTE do mesmo caso a geração do IPTE tenha ocorrido com sucesso conforme abaixo:

Se for possível a impressão do boleto e o mesmo já estiver registrado, será exibido o IPTE para o usuário.

Caso o boleto não possua uma linha digitável gerada (IPTE) ou não seja possível a impressão do boleto, será exibida uma mensagem de validação para o usuário.

Copiar código

Ao clicar no botão de "Copiar código" ou no texto da linha digitável, será feita a cópia da linha digitável (IPTE) para a área de transferência conforme abaixo:

Baixar PDF do boleto

Ao clicar no botão "Baixar PDF do boleto", o PDF do boleto será aberto para visualização, conforme funcionalidade do sistema operacional de cada dispositivo.

Compartilhar

Ao clicar no respectivo botão, o PDF do boleto poderá ser compartilhado, conforme funcionalidade de compartilhamento do sistema operacional de cada dispositivo.

O título só aparecerá na aba "Pagos" quando o pagamento do boleto for confirmado pela instituição financeira.

## **TABELAS UTILIZADAS**

* FLANBOLETO - Tabela de lançamentos de boletos
