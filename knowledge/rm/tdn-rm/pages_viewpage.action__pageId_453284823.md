# Adicionado "Visualizar HTML" no informações do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | TOTVS Educacional. |
| **Módulo:** | RM.exe. |
| **Função:** | Parâmetros Portais - Informações do Aluno. |
| **Situação/Requisito:** | Não era possível adicionar texto HTML no informações do aluno para fosse possível "embedar" um vídeo no mural do aluno. |
| **Solução/Implementação:** | Foi implementado em Configurações > Parâmetros > RM Portal > RM Portal - Gerais > Portal - Geral 12/13 a opção de Visualizar HTML para as informações do aluno. Informação que aparece no Mural do Aluno no Novo Portal do Aluno. Ao Marcar a checkBox "Visualizar HTML" é possível adicionar um texto HTML.  . |
