![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21704718111127) Tempo aproximado para leitura: **00:00:20 min****Ocorrência**A mensagem de erro: O campo versão do leiaute eSocial não está preenchido com um leiaute vigente.  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - Todas as versões  
  
**Causa**Esse erro normalmente ocorre quando a informação do Leiaute não é preenchida no parametrizador.  
  
**Solução**  
Para solucionar essa ocorrência, realize os seguintes passos:

1. Acesse o menu **Configurações | Parametrizador | eSocial | Configurações Gerais 1/7**;  
2. Confirme se o campo esta preenchido com a  Versão do Leiaute;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/21704704324247)

3. Preencha o campo Versão do Leiaute é avance ate o final.
