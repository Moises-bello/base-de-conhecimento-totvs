# Relação de cadastro entre contextos

Este processo permite que o sistema execute o relacionamento "de-para" dos dados de um contexto de origem para um contexto de destino. A funcionalidade estará disponível para o Ensino Básico e Ensino Superior.

Ao acessar a tela de relacionamento, o sistema irá preencher automaticamente os dados de origem de acordo com o contexto logado. Porém é possível alterar essas informações.

Após o preenchimento dos contextos de origem e destino, serão mostrados os cadastros que podem ser incluídos relacionamentos.

A relação de cadastro entre contextos pode ser feita:

* entre coligadas de origem e destino;
* entre filiais de origem e destino;
* entre níveis de ensino de origem e destino.

## Relação de cadastro entre coligadas

Os cadastros possíveis para realizar o relacionamento entre as coligadas são:

* Atividades;
* Disciplina;
* Modalidade;
* Período Letivo;
* Situação;
* Tipo de Aluno;
* Tipo de Ingresso;
* Tipo de Ocorrência;
* Tipo de Participação;
* Turno.

## Relação de cadastro entre filiais

Os cadastros possíveis para realizar o relacionamento entre as filiais são:

* Período letivo;
* Turno.

## Relação de cadastro entre níveis de ensino

Os cadastros possíveis para realizar o relacionamento entre os níveis de ensino são:

* Período letivo;
* Situação
* Turno.
