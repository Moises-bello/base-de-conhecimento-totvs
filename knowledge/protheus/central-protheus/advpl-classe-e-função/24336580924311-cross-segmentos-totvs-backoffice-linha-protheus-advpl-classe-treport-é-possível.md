![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24336580914199) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível incluir uma ordem em relatório customizado utilizando a classe TReport?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**Não é possível incluir uma ordem no relatório customizado utilizando a classe TReport. As ordens já são pré-definidas internamente e são funcionalidades do padrão.
