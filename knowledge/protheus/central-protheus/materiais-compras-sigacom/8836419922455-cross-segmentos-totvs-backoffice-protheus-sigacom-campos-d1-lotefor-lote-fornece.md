Qual a diferença dos campos  D1\_LOTEFOR e D1\_LOTECTL

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS COMPRAS - TVersão 12  
  
**Solução**

O campo ***D1\_LOTEFOR*** é só um informativo que é informado o código do lote enviado pelo fornecedor. Já o campo ***D1\_LOTECTL*** este é o campo de Controle de Lote do Sistema utilizado pelo módulo de Estoque/Custos. e é utilizado para produtos que possuem controle de rastreabilidade no estoque.

Ele pode ter o mesmo código do fornecedor ou outro interno.

Toda movimentação de requisição para o produto deverá ser informado o lote.

Para dúvidas sobre controle de lote no sistema, pode ser verificado junto á equipe do suporte ao módulo de Estoque/Custos.
