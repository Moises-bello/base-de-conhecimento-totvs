# Ajuste no Registro de Atendimento pela Agenda de Atendimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao realizar o registro de um atendimento externo através da agenda de atendimento e informar um procedimento com coparticipação, o sistema não descontava o valor da coparticipação para realizar o lançamento na conta do paciente. |
| **Solução:** | Realizado ajuste para diminuir o valor da coparticipação do valor do procedimento quando o registro de atendimento externo for realizado através da agenda de atendimentos. |
