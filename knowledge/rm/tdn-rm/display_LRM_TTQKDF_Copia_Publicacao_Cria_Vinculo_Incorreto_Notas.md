# COPIAR PUBLICAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Copiar publicação* |
| **Situação/Requisito:** | *Ao efetuar uma cópia de uma publicação que possui os campos da seção de notas, o sistema não efetua a cópia correta, ele está mantendo os dados iguais nas duas publicações, sendo que se alterado os dados em uma publicação, estes dados são refletidos para a publicação que foi copiada.* |
| **Solução/Implementação:** | *Foi feito o ajuste no processo de cópia de publicação, para que identifique se existe dados na seção de notas, se existir, estes são criados e as novas referências a estes dados são inseridos na nova publicação.* |
