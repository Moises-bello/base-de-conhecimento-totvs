# INSCRIÇÃO CANDIDATOS - NOVO PORTAL PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Processo Seletivo** |
| **Função:** | *Inscrição de candidato - Novo portal* |
| **Situação/Requisito:** | Ao realizar uma inscrição todos os campos obrigatório, nas informações de área de interesse, deveriam ser preenchidos, mesmo que contivessem apenas um registro.   No portal antigo, o comportamento seria a seleção automática após a seleção do processo seletivo a ser matriculado. |
| **Solução/Implementação:** | Realização de um acerto no portal, de forma que após a definição do processo seletivo a ser inscrito, os campos grupo de interesse, área de interesse ofertada, local de realização de prova, forma de inscrição, idioma e campus, sejam selecionados automaticamente, caso tenham apenas um registro. |
