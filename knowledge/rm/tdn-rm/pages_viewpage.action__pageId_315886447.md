# Não permitir incluir lançamento com valor líquido igual a zero em borderôs de pagamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Inclusão de Borderô |
| **Situação/Requisito:** | Ao realizar a inclusão de um borderô o sistema não pode incluir os lançamentos que possuam valor líquido igual a zero na sua data de vencimento. |
| **Solução/Implementação:** | Agora o sistema não inclui os lançamentos com valor líquido igual a zero, e caso exista algum, o sistema irá apresentar no log do processamento os lançamentos que não foram incluídos. |
