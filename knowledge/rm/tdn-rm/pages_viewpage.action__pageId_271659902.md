# FÓRMULAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Fórmulas* |
| **Situação/Requisito:** | *A função de fórmula "BASEIRRF" retorna o valor da base da competência atual. Não existe uma fórmula que retorne o valor da competência da execução do processo.* |
| **Solução/Implementação:** | *Criada a função de fórmula "BASEIRRFEXEC" para retornar o valor da base de IRRF da competência sendo considerada no processo. As formulas utilizadas no relatório de Envelope de Pagamento devem ser alteradas para utilizar a nova função.* |
