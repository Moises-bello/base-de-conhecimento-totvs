# TSKTD3\_DT\_Movimento\_Integrado\_Agilis\_Com\_Relatorio\_Repasse

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Construção e projetos.* |
| **Módulo:** | *Gestão de estoque compras e faturamento.* |
| **Função:** | *Criar movimento que gera atendimento com relatório de repasse.* |
| **Situação/Requisito:** | *Ao criar um movimento, que gere atendimento no agilis, caso o numero do movimento fosse usado no relatório de repasse do atendimento, o mesmo vinha com um número provisório inválido para esse movimento.* |
| **Solução/Implementação:** | *Ao criar um movimento, que gere atendimento no agilis, agora o email de repasse será enviado somente após a renumeração do número do movimento, assim, caso esse número do movimento seja usado em um relatório de repasse, o mesmo terá um valor verdadeiro.* |
