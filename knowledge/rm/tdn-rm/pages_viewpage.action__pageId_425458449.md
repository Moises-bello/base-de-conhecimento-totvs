**Gerar Atendimento à Partir de Outro**   
Este processo irá copiar dados de um atendimento selecionado e irá gerar um novo de acordo com os campos selecionados. Para execução deste processo, deverá existir exatamente um atendimento selecionado. O usuário terá a opção de utilizar os seguintes campos do atendimento para executar o processo:   
Assunto, Categoria Geral, Cliente, Código de Classificação, Coligada, Contato do Cliente, Contato do Representante, Detalhe do Produto, Discussão, Localidade, Número de Série, Origem do Contato, Prioridade, Produto, Representante, Solicitação, Tipo de Atendimento, Entendimento e Tipo de Contato.  
Além dos campos acima, o usuário terá a disposição todos os campos complementares e todos os campos de parâmetro do atendimento selecionado para cópia.  
**Observação**  
Para visualização do campo Número de Série no processo de geração a partir de outro, é necessário configurar os parâmetros do sistema.  
O processo está disponível para os atendimentos web.
