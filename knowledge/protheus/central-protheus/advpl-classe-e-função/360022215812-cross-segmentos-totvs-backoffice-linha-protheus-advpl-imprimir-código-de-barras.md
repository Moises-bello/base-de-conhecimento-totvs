Dúvida**Utilizando o Método Int25() é possível imprimir o código de barras na vertical.  
Existe algum parâmetro neste método ?  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Atualmente não existe parâmetro ou método especifico para impressão de código de barra na vertical.
