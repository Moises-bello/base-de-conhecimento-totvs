# Filtra unida de atendimento nas demais rotinas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Filtrar unidade de atendimento nas demais rotinas |
| **Situação:** | Necessário que o sistema tenha o comportamento esperado quando o parâmetro "Filtra unidades de atendimento" para as Demais funções estiver marcado nas telas de Cadastro de Leitos, Cadastro de Exames e de Condições Financeiras com Convênio. |
| **Solução:** | Validado o parâmetro nas telas de Cadastro de Leitos, Cadastro de Exames e de Condições Financeiras com Convênio, e caso ele esteja marcado, filtrar as informações somente para as unidades de atendimento do perfil do usuário. |
