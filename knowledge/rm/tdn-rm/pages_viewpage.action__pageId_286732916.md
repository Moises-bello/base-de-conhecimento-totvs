# Exclusão de patrimônio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Exclusão de patrimônio |
| **Situação/Requisito:** | O cliente tentou excluir um subtítulo existente no cadastro patrimônio, porém ao executar o processo é exibida uma mensagem informando que houve violação de chave estrangeira. Vale ressaltar que não existem patrimônios associados a este subtítulo e a mensagem não indica qual tabela foi violada. |
| **Solução/Implementação:** | Quando não é possível excluir um título ou subtítulo uma mensagem, informando os motivos que impediram a execução deste processo, é exibida. Foi acrescentada a ela informações referentes a tabela que possui vínculo com o título ou subtítulo em questão. |
