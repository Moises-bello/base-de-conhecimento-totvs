# Cálculo da Fórmula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Cálculo da Fórmula |
| **Situação/Requisito:** | Quando um evento está associado a uma fórmula que o cálculo retorna um valor negativo, o evento está sendo lançado no envelope com valor zerado. |
| **Solução/Implementação:** | Criado o parâmetro 'Não zerar evento de fórmula quando o valor retornado for negativo', que, quando marcado, não irá zerar o valor retornando pelo fórmula e lançará para o envelope o valor conforme calculado. |
