O login unificado dos portais, permite recuperar a senha quando necessário.

false

Essa funcionalidade está disponível **apenas quando o login é realizado via usuário e senha cadastrado no RM.exe**

Recuperar senha

Na tela de login, basta clicar no link "Esqueceu sua senha?", e usuário será redirecionando para a tela de alteração de senha, onde serão solicitados o usuário e o e-mail cadastrado no RM.exe

Após informar os dados, será enviado um link para o e-mail informado para que o usuário altere a senha.

Ao clicar no link, o usuário será redirecionado para uma página, para que seja informado a senha e a confirmação da nova senha.

Após alterar a senha e clicar no botão "Confirmar", o usuário será redirecionado para a tela de login, com a mensagem que a senha foi alterada com sucesso.

Alterar senha no próximo login

Quando a opção "**Alterar senha no Próximo**" esteja **marcada**no cadastro do usuário.

Ao informar o usuário e senha e clicar no botão "Entrar", o usuário será redirecionado para a tela de alteração se senha.

O usuário será redirecionado para uma nova tela com uma mensagem informado o motivo pelo qual o mesmo deverá alterar a senha.   
Neste momento, o usuário deverá informar o código do usuário, a senha atual e a nova senha/confirmação da nova senha, e posteriormente clicar no botão "Confirmar".

Após clicar no botão "Confirmar", o usuário será redirecionado para a tela de login, onde será necessário informar o código do usuário e a nova senha para acessar o portal.
