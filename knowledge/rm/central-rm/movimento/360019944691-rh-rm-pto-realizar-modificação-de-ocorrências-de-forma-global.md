**Dúvida**  
Como fazer uma modificação de ocorrências global?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 11.80  
  
**Solução**Para fazer uma modificação de ocorrências global, siga os passos abaixo.

1. No módulo de **Automação de Ponto** selecione a guia **Movimento** e o menu **Ocorrência Calculada**.  
   ![2018-11-19_09_37_45-TOTVS_S_rie_T_Servi_os__RM__Alias__CorporeRM___1-TOTVS_SA.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360015645551)
2. Realize um filtro para selecionar as ocorrências que deseja alterar e selecione o menu **Processos** e depois **Gerar Modificação de Ocorrência**.  
   ![2018-11-19_09_37_25-TOTVS_S_rie_T_Servi_os__RM__Alias__CorporeRM___1-TOTVS_SA.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360015645571)
3. Caso selecione as ocorrências antes de gerar a modificação de ocorrência, apenas as ocorrências selecionadas serão alteradas. Caso não selecione nenhum registro, o sistema irá exibir o alerta abaixo, aguardando a confirmação para executar o processo para todas as ocorrências da visão.  
   ![2018-11-19_09_38_07-RM.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360015593232)
4. A janela de **modificação de ocorrências** será aberta. Selecione o tipo de ocorrência destino desejada, a atitude e deixe o campo de data início e fim em **branco**. Caso deseje, poderá também preencher uma justificativa para o processo.  
   ![2018-11-19_09_38_53-Gerar_Modifica__o_de_Ocorr_ncia.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360015645591)
5. Após a execução, realize um recálculo dos espelhos dos funcionários para verificar as alterações realizadas.

**Saiba Mais**  
Para mais informações sobre a modificação de ocorrências, acesse o documento [Modificação de Ocorrências](https://tdn.totvs.com/pages/releaseview.action?pageId=452719212)

Para realizar a modificação de ocorrência de  forma individual, por dentro do espelho do cartão, acesse o documento [RH - RM - PTO - Realizar modificação de ocorrência individual](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360000929287-RM-PTO-Como-realizar-uma-modifica%C3%A7%C3%A3o-de-ocorr%C3%AAncia)
