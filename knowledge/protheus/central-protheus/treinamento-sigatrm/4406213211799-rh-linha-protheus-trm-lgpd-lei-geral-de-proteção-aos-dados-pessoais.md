**Dúvida** **LGPD - Lei Geral de Proteção aos Dados Pessoais** no Protheus Recursos Humanos.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Treinamento - A partir da versão 12.1.27  
  
**Solução**O Protheus possui rotinas e recursos para que nossos Clientes façam o controle de dados protegidos do sistema, que é normalmente é um dos itens previstos em legislações de controle de dados pessoais, como por exemplo, no Brasil, a LGPD(dados pessoais e sensíveis).  
  
**Controle de dados protegidos - Protheus 12:** <https://tdn.totvs.com/display/public/PROT/Controle+de+dados+protegidos+-+Protheus+12>  
A anonimização é o último ato para eliminar definitivamente, informações sensíveis ou pessoais vinculadas à uma determinada pessoa.

**Anonimização de Dados Protegidos**<https://tdn.totvs.com/pages/viewpage.action?pageId=532024154>

Para **Ajustes de bloqueio de acesso ou ofuscamento de campos** com **informações** classificadas na **LGPD** em logs de processamento, mensagens em tela, relatórios e demais rotinas: <https://tdn.engpro.totvs.com.br/pages/releaseview.action?pageId=547239455>  
  
Todos os dados contidos no ***Cadastro de Dados Protegidos*** enviados pela Totvs são apenas sugestões. O cliente sempre deve conseguir incluir ou alterar dados e estas devem ser as  informações que serão utilizadas pelo sistema.
