# MOVIMENTAÇÕES - RENOVAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Movimentações - Renovação* |
| **Situação/Requisito:** | **Ao renovar um empréstimos e alterar a data de devolução, o sistema não salva a data informada, e sim a data padrão para o tipo de publicação, como se fosse feito um novo cálculo da data de devolução do empréstimos.** |
| **Solução/Implementação:** | *Foi identificado que no processo de renovação o sistema faz novamente um cálculo de data devolução, assim, substituindo a data que foi informada. Foi feito o ajuste para que o sistema sempre considere a data informada, assim salvando corretamente a renovação.* |
