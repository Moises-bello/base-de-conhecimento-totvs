# Incluir/Excluir Bolsa Retroativa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Incluir/Excluir Bolsa Retroativa* |
| **Situação/Requisito:** | *Permitir incluir/excluir bolsa retroativa, mesmo quando a contabilidade está Integrada ao Lote Zero e marcado o parâmetro Saldus “Habilitar verificação do bloqueio de contabilidade”. Esta situação somente será possível caso esteja marcado o parâmetro Educacional “Refaz automaticamente conciliação de extrato no processo de inclusão/exclusão de bolsa retroativa”.* |
| **Solução/Implementação:** | *Alterado processo de inclusão/exclusão de bolsa retroativa para permitir execução mesmo quando a contabilidade está Integrada ao Lote Zero e marcado o parâmetro Saldus “Habilitar verificação do bloqueio de contabilidade”. Esta situação somente será possível caso esteja marcado o parâmetro Educacional “Refaz automaticamente conciliação de extrato no processo de inclusão/exclusão de bolsa retroativa”.* |
