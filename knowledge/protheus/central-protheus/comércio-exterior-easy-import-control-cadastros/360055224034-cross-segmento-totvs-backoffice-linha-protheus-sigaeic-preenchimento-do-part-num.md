**Dúvida** Qual cadastro é feito para Preenchimento do *Part-Number*?  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Para que o campo seja preenchido com o número do *Part-Numbe*r, no cadastro de  Produto x Fornecedor rotina MATA061, onde  deve ser preenchido o campo "Cod.Prod.For." (A5\_CODPRF) o *Part-Number*.
