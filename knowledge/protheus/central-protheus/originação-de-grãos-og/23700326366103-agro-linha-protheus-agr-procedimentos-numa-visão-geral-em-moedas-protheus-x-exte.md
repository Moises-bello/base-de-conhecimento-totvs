![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23700326349207) Tempo aproximado para leitura: **00:04:30 min****Dúvida**Quais são os **Procedimentos numa Visão Geral em Moedas Protheus x Externo**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**  
Para acessar esta rotina, de forma automática é criado os cadastros com base nas moedas cadastradas nos parâmetros **MV\_MOEDA(MV\_MOEDA1,MV\_MOEDA2....MV\_MOEDA99)** **do Sistema Protheus**, realize os seguintes passos:

**1.** Acesse no módulo **SIGAAGR**: **Atualizações > Comercialização > Cadastros Básicos > Moedas Protheus x Externo**;  
  
**Para vincular a moeda do Protheus a uma moeda do Sistema externo:**

**1.** Acesse no módulo **SIGAAGR**: **Atualizações > Comercialização > Cadastros Básicos > Moedas Protheus x Externo**;

**2.** Posicione no registro que deseja alterar;

**3.** Clique em **Alterar**;

**4.** Informe o campo **Cód Atual** com o código do **Sistema externo** para a moeda, para atualizar a cotação atual da moeda;

**5.** Informe o campo **Cód Futura** com o código do **Sistema externo** para a moeda, para atualizar as cotações futuras da moeda;

**6.** Clique em **Confirmar**.  
  
**Para vincular a moeda do Protheus a um índice de mercado:**

**1.** Acesse no módulo **SIGAAGR**: **Atualizações > Comercialização > Cadastros Básicos > Moedas Protheus x Externo**;

**2.** Posicione no registro que deseja alterar;

**3.** Clique em **Alterar**;

**4.** Informe o campo Índice conforme **F3** do campo;

**5.** Clique em **Confirmar**.  
  
**Para Visualizar uma Moeda Protheus X Externa:**

**1.** Acesse no módulo **SIGAAGR**: **Atualizações > Comercialização > Cadastros Básicos > Moedas Protheus x Externo**;

**2.** Posicione no registro que deseja visualizar;

**3.** Clique em **Visualizar**.
