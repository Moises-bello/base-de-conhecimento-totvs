# Relatório Retrospectiva

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Retrospectiva |
| **Situação/Requisito:** | Ao realizar a emissão do Relatório Retrospectiva quando uma determinada conta contábil teve movimentação em meses anteriores, e uma movimentação atual, porém zerando a conta é apresentada a mensagem: Não foram encontradas informações mínimas para a geração do relatório. |
| **Solução/Implementação:** | Ajuste no relatório Retrospectiva para que caso no intervalo de meses selecionado a conta fique zerada por exemplo a partir de um determinado mês, essa conta seja exibida para que mostre o saldo nos demais meses quando é marcado para gerar o relatório por Saldo. |
