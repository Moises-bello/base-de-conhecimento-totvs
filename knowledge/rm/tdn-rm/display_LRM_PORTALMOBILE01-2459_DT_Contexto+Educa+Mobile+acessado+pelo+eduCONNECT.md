# Contexto Educa Mobile acessado pelo eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educa Mobile |
| **Função:** | Contexto do Educa Mobile para responsável |
| **Situação/Requisito:** | Ao acessar o eduCONNECT com um responsável (por exemplo, responsável acadêmico) que possua mais de um aluno, ao acessar a funcionalidade "Acadêmico" o TOTVS Educa Mobile não carregava corretamente o contexto do dependente selecionado no eduCONNECT, forçando com que o responsável tivesse que realizar a seleção do contexto para o dependente desejado. |
| **Solução/Implementação:** | Foi realizado um ajuste no eduCONNECT e TOTVS Educa Mobile, de maneira que ao selecionar um dependente no eduCONNECT e acessar a opção "Acadêmico", o dependente seja carregado (contexto) no TOTVS Educa Mobile e o usuário não precise alterar o contexto. |
