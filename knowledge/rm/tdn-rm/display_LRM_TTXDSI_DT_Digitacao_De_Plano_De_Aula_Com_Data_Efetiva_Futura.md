|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Digitação de plano de aula pelo Portal* |
| **Situação/Requisito:** | *Quando o sistema está parametrizado, para não permitir a digitação de conteúdo, posterior a data atual, o sistema emite a mensagem: a data do conteúdo realizada deve ser preenchida, porém a data já esta preenchida, a mensagem deve ser corrigida, para: a data do conteúdo realizado não pode ser maior que a data atual, ou algo do tipo.* |
| **Solução/Implementação:** | *Ajuste no cadastro de plano de aula do Portal na validação realizada quando o parâmetro "Permitir lançamento de conteúdo efetivo (realizado) de dias posteriores ao atual " não está marcado.* |
