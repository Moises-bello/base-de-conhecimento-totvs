Este cubo exibe informações dos contratos de locação e suas movimentações. Através dele é possível visualizar informações como os valores original e de integração de cada lançamento, a data da baixa, natureza, data de vencimento, entre outros.

As movimentações exibidas são filtradas dentro de um período (data de vencimento) que é informado pelo usuário ao atualizar o cubo.

O cubo exibe os contratos de todas as coligadas.

As seguintes informações estão disponíveis:

* Coligada
* Contrato de locação
* Imóvel
* Cliente
* Lançamentos
  + Origem
  + Natureza
  + Status
  + Data da baixa
  + Valores: original e de integração
  + Data do vencimento
  + Referência (IDLAN)
  + Dias de atraso
