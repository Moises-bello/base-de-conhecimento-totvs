# CHOQUE DE HORÁRIO NA RESERVA DE INSTALAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Reserva de Instalação* |
| **Situação/Requisito:** | *Ao realizar a reserva de uma instalação por um período maior que 1 dia, o sistema apresenta um choque de horário com outras salas.* |
| **Solução/Implementação:** | *Foi identificada a falta de um filtro na utilização de períodos maiores para a realização de uma reserva de instalação. Os sistema não se restringia a apenas a sala selecionada e gerava um choque com outras salas que possuíam os mesmo horários reservados.*  *Foi realizado o acerto no filtro do choque de horário para a validação dos horários, apenas, da sala selecionada.* |
