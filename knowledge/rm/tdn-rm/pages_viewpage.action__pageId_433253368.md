# EDIÇÃO DE PEDIDO DE MATERIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Inclusão de Pedido de Material Extra. |
| **Situação/Requisito:** | Deverá ser criado a pagina de Inclusão de Pedido de Material Extra. |
| **Solução/Implementação:** | Foi desenvolvido a Inclusão de pedido de material extra de forma responsiva para os dispositivos: mobile, tablet e desktop.  A Inclusão possui:   * Itens do pedido (só será possível incluir pedidos após salvar o pedido novo) * Informações do Pedido (Status, Data Requisição e Usuário Responsável) * Configurações (Utiliza Preço Orçado, Tipo de Movimento e Local de Estoque)   Após salvar o pedido será redireciona para a tela de edição do pedido.  Na inclusão é possível realizar a mudança do tipo de movimento e local de estoque, alem de informar a utilização de preço orçado.   * Deverá pegar o valor default do tipo de movimento de pedidos configurado nos parâmetros do sistema. |
