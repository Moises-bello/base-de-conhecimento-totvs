# Envio NFS-e (txt)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Envio da NFS-e |
| **Situação/Requisito:** | Quando são enviadas simultaneamente várias notas com o mesmo Cliente\Fornecedor e o Telefone está vazio é apresentado a mensagem:  Erro no preenchimento dos dados do Tomador: Referência de objeto nao definida para uma instância de objeto. |
| **Solução/Implementação:** | Ajuste no tratamento do campo Telefone do Tomador quando o mesmo está vazio. |
