Os produtos TOTVS estão em constante evolução para transpor desafios e acompanhar cada etapa da jornada digital da sua empresa.

Por esse motivo, comunicamos que o **TBC (TOTVS Business Connect) via IIS** **não será mais expedido** no pacote de instalação do RM a partir da release 12.1.2302, que estará disponível para download a partir de **03 de fevereiro de 2023**.

As mesmas integrações existentes utilizando tal solução deverão ser **substituídas pela utilização do TBC via Host**.

A todos os clientes que utilizam o TBC via IIS, sugerimos que **realizem o ajuste indicado** para que a integração seja feita via Host, visto que a solução já não sofre atualizações de tecnologia e segurança há algum tempo e, de alguma forma, em se tratando de integrações, precisamos evitar possíveis vulnerabilidades e problemas de segurança com os ambientes dos clientes.

A seguir, esclarecemos as possíveis dúvidas sobre a **integração TBC via Host**:

**Como posso utilizar a integração TBC via Host?**

O ajuste na integração para usar o TBC via Host deve ser feito conforme estas instruções: <https://tdn.totvs.com.br/display/LRM/Web+Services>

***Importante:*** Para uso da integração TBC via Host, permanece a necessidade da **licença TOTVS I** (mesma licença que foi adquirida quando da contratação da integração TBC via IIS).

Caso precise de apoio para fazer o ajuste da integração, é possível contratar a equipe de Serviços da TOTVS.

**O que vai acontecer se eu não fizer o ajuste da integração até a data da descontinuação?**

É necessário se planejar para fazer o ajuste da integração **antes** da atualização para a release 2302, pois ao realizar a atualização, a integração via IIS será perdida.

**O que vai acontecer após a data da descontinuação da integração via IIS?**

Apenas o suporte técnico será mantido até o término do ciclo de vida das versões atendidas pela RM.

**Existe alguma documentação para conhecer a nova integração?**

Acesse aqui [WebServices - Como Habilitar Webservice via RM Host](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360003035312)

**Preciso fazer a validação da integração via Host no meu ambiente?**

Recomendamos que, para assegurar o sucesso nesse processo, seja realizada a validação da aderência e definição de configurações específicas e novas parametrizações, seguidas de rodadas de testes.

Estamos à disposição para esclarecer qualquer dúvida. Basta entrar em contato com o seu ESN (Executivo de Soluções e Negócios)!
