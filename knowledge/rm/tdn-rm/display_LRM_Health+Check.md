# Introdução

---

**Health Check** é um **serviço rest (JSON)** responsável por **checar a saúde da aplicação**. Através dele conseguimos realizar:

* Testes de Conexão à um banco de dados.
  + Opcional: AliasName [Nome do Servidor]
* Testes de Conexão ao License Server
* Testes de consumo de uma licença teste [SLOT Predefinido].
