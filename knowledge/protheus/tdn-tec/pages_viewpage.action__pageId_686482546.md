Quando a atualização automática do SmartClient é realizada com sucesso, a mensagem final aparece com ícone de erro.

|  |  |
| --- | --- |
| Situação | A mensagem de sucesso não condiz com o ícone de erro. |
| Ocorrência | Foi utilizada a interface já pronta de erro crítico para a mensagem de sucesso. |
| Melhoria | Foi criada uma interface com o ícone de informativo para exibir que a atualização ocorreu com sucesso. |
| Informações adicionais | * Referente ao chamado: #13517362 * Referente à ocorrência: DTCLIENT01-3222 * Disponível em builds superiores a 20.3.1.0 |
