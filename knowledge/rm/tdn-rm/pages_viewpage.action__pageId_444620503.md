# Lançamento Fiscal - FCP (Fundo de Combate a Pobreza) Próprio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Cadastro de Lançamento Fiscal |
| **Situação/Requisito:** | Solicitação da criação de um campo referente ao FCP Próprio no Item e no Lançamento. |
| **Solução/Implementação:** | No Item:   * O campo Percentual  FCP ICMS Próprio e Valor  FCP ICMS Próprio foram criados, na guia “Valores ICMS”. O campo de Percentual pode-ser alterado seu valor e o campo Valor é apenas informativo. * Foi renomeado o texto de “%FECP Item” -> “% FECP ST/DIFAL” * Foi renomeado o texto de “Valor ICMS FECP Item” -> “Valor ICMS FECP ST/DIFAL”     No Lançamento:   * na guia “ICMS e IPI”, o campo Valor FECP ST foi removido e o campo Valor  FECP ICMS Próprio foi adicionado a tela, apenas para caráter informativo. * na guia “Substituição Tributária”, o campo Valor  FECP ST foi adicionado a tela, apenas para caráter informativo. * na guia “Diferencial de Alíquota”, o campo Valor  FECP DIFAL foi adicionado a tela, apenas para caráter informativo. |
