# ÁREAS DE INTERESSE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Áreas de interesse* |
| **Situação/Requisito:** | *Foi identificado que quando um processo seletivo utiliza agrupadores e os grupos possuem nomes com caracteres especiais, as áreas de interesses não são carregadas corretamente no portal do processo seletivo.* |
| **Solução/Implementação:** | *Foi identificado que existia uma função para tratar alguns caracteres que estava impedindo que as áreas fossem carregadas, foi feito o ajuste e também foi configurado para que o grupos não aceitem parênteses pois podem impactar no carregamento das áreas de interesse.* |
