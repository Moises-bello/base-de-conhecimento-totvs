Ao criar o projeto será apresentada a tela de navegação / administração do mesmo.

O “Project Fields” poderá ser preenchido seguindo os passos:

1. Administração do Projeto > Project Fields > Actions > Associate Scheme > Escolher a opção “PMO” > Associate.
2. Depois deve-se retornar a tela de navegação do projeto “Back to Project” e seguir os passos:
3. Add-ons > Project Fields > Edit > preencher com os dados > Save.
