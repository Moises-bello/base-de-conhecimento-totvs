As constantes do sistema são caracteres simples ou numerais que são usados para representar dados de registros no sistema, quando este é gravado no banco de dados. Em alguns casos uma mesma constante pode representar status distintos, dependendo da parametrização no sistema. Conhecer o significado de cada uma e quando elas são atribuídos é importante na execução de algumas tarefas, como ao criar um filtro, executar uma sentença ou gerar um relatório gerencial.

Constantes de Ordem de Serviço - Tabela OFORDEMSERVICO

* **Origem da criação de uma Ordem de Serviço**

Define a origem da criação da Ordem de Serviço, gravando na tabela **OFORDEMSERVICO** no campo PLANO.

| Constante | Representação |
| --- | --- |
| N | Cadastro Manual |
| P | Geração de OS Automática |
