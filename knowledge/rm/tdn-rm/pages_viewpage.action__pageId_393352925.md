# O novo portal do aluno não está respeitando os parâmetros da aba "Campos Invisíveis - Cliente Online" do Ágilis.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Novo portal do aluno |
| **Função:** | Requerimento |
| **Situação/Requisito:** | No momento da abertura da solicitação, o novo portal do aluno não estava obedecendo a aba de parâmetros "Campos Invisíveis - Cliente Online" do Ágilis. |
| **Solução/Implementação:** | Ajuste na abertura de solicitações pelo novo portal do aluno. A partir de agora o novo portal do aluno obedecerá as parametrizações realizadas na aba "Campos Invisíveis - Cliente Online" do Ágilis. |
