O Layout do gerador contém todas as propriedades e regras de leitura e transformação dos dados para geração dos registros de saída. Ele é a base do gerador de saídas e pode ser exportado/importado utilizando o formato XML.

![](/download/attachments/319787264/layout.png?version=1&modificationDate=1512921816000&api=v2)

1Arquivo

Representa um arquivo do Layout. Cada Layout deve conter pelo menos um arquivos. Clique duas vezes no nome do arquivo para alterar as suas propriedades. Para mais informações consulte a [Configuração do Arquivo](/pages/viewpage.action?pageId=319787269).

2Registro

Representa um registro do Layout. Cada Layout deve conter pelo menos um registro que por padrão será associado automáticamente ao primeiro arquivo do Layout. Você pode arrastar e soltar os registros para move-los na hierarquia da árvore. A ordem dos registros define a ordem em que os registros serão salvos no arquivo gerado. Para mais informações consulte a [Configuração do Registro](/pages/viewpage.action?pageId=319787271).

3Contextos

Clique para selecionar a visão de contextos do Layout, onde poderão ser definidas as configurações dos contextos, e ser visualizados a sua estrutura de dados. Para mais informações consulte a [Configuração do Contexto](/display/LRM/Manual+-+Contextos).
