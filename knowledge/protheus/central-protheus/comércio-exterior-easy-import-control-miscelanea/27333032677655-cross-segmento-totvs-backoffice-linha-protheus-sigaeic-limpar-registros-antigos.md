**Dúvida**É possível limpar os registros antigos de Integração com o Despachante?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - a partir da versão 12.2210.  
  
**Solução**

Através de personalização de rotina via ponto de entrada **"DELETA\_REGISTRO" ,** é possível fazer a limpeza dos registros antigos.
