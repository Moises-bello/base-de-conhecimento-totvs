![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26840790478615) Tempo aproximado para leitura: **00:30:00 min****Dúvida**É possível configurar o Mingle e o Alias para o aplicativo Meu Coletor de Dados?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**Atualmente, o aplicativo **Meu Coletor de Dados não** possui a possibilidade de integrar-se ao Mingle.

O Mingle é uma solução interna da Totvs que atua como um gateway, permitindo que o ambiente do cliente seja acessado pelos aplicativos.

Clique aqui [Aplicativos TOTVS suportados](https://tdn.totvs.com/display/public/MIN/Aplicativos+TOTVS+suportados) que teria  uso o Mingle.
