Dúvida**Qual o procedimento para Solicitação de Numerário rotina EECNU400?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Export Control* – A partir da versão 11.80  
  
**Solução**1. Acesse a rotina Atualizações\Embarque\Solicit. Numerario(EECNU400).  
2. Selecione Manutenção  
3. Selecione Outras Ações\Incluir  
4. Informe os dados da despesas  
5. Selecione Outras ações \ Efetiva , para geração da despesa no Financeiro.  
6. Preencha os dados referente ao banco e selecione Salvar  
7. Para exclusão do título selecione Outras ações \ Cancela Efet.
