| **Sintoma** | **Como fazer a exportação de horários pelo RM Labore?** |
| Solução | A exportação de horários no RM Labore não é feita via gerador de relatórios. Para este caso há um botão (o penúltimo botão apresentado na tela de batidas- Exportação de horários0) no cadastro de horários, aba batidas, que permite a Exportação dos horários. Após exportação do arquivo texto, basta fazer a importação na base que desejar. |
