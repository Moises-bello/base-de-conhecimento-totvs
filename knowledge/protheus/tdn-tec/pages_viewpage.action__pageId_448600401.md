Define o nome ou endereço IP do host do controlador do AppDynamics.

## Valores válidos

| Valor | Descrição |
| --- | --- |
| BTMONITOR\_HOST\_DEFAULT (Padrão) | Nome padrão do host do controlador do AppDynamics. Este nome é inválido e não deve ser usado. |
| <nome\_do\_host> ou <endereço\_IP\_do\_host> | Nome ou endereço IP definido pelo usuário, respeitando as regras padrão de cada. |

## Observações

* O nome do host do controlador do AppDynamics fornecido deve respeitar as regras padrão de nome de host;
* O endereço IP do host do controlador do AppDynamics fornecido deve respeitar as regras padrão de endereço IP de host.
