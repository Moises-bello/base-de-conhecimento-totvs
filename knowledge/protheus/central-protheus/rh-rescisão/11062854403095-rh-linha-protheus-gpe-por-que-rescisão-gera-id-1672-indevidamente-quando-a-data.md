![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que rescisão gera id 1672 indevidamente quando a data de demissão contabiliza 12/12 avos de 13º salário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**A rescisão gera id 1672 mesmo com a data de demissão contabilizando 12/12 avos de 13º salário, devido a configuração dos ids de desconto adiantamento 13 salário (ids 0116, 0183 e 0247). Caso em rescisão os id de adiantamento 13º salário esteja com Sim para INSS, o valor é abatido em base e deste modo calcula a diferença no id 1672.
