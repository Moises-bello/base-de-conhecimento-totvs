![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que rescisão complementar por dissídio não apresenta diferença de bases FGTS 13 salário ID 0294 e FGTS 13 salário em rescisão ID 0214?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para rescisão complementar por dissídio, a diferença de bases FGTS 13 salário é calculada no ID 0398 e a diferença de FGTS 13 salário rescisão é calculada no ID 0400. Para isso, devem existir uma verba relacionada ao ID 0398 e outra relacionada ao ID 0400.
