# Importação de Lançamentos Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Conceito de importação de lançamentos contábeis |
| **Situação/Requisito:** | Após executar o conceito de importação de lançamentos contábeis é identificada uma inconsistência no arquivo de importação. O Log informa que o rateio a crédito para a conta 2.0.0.00.0.0001 deve ser informado, porém no arquivo existem muitos registros referenciando essa conta, dificultando a localização do registro inconsistente. O cliente deseja que o rateio inconsistente possa ser localizado mais facilmente. |
| **Solução/Implementação:** | O conceito de importação de lançamentos contábeis foi alterado para que o Log exiba mais detalhes sobre os rateios inconsistentes. Serão adicionados no Log alguns detalhes do rateio como valor, código do histórico, complemento e 2º data. Essas informações irão facilitar a localização, no arquivo de importação, do registro inconsistente. |
