**Dúvida**

É possível configurar o Mile para a Rotina Manutenção de Contratos (CNTA300)?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Gestão de contratos  - Todas as versões

**Solução**

O modelo de Contratos(CNTA300) é muito complexo e requer a chamada de métodos auxiliares para realização da importação dos dados de maneira consistente, por conta disso **não é possível utilizar o Mile**. Nossa recomendação é a criação de uma rotina customizada para importação dos dados, seguindo os exemplos apresentados na nossa documentação no link [[GCT0109 - Exemplos de Rotina Automática - Rotina CNTA300](https://tdn.totvs.com/x/SiI0E)]

Nela é possível encontrar exemplos de como utilizar o modelo do CNTA300, realizar revisões, aprovação de alçada de contratos, gerar cronograma financeiro e contábil.
