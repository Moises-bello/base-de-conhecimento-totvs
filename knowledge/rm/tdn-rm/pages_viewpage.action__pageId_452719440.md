**Pasta Montagem - Avaliação de Desempenho**

Esta pasta permitirá a definição da montagem da avaliação de desempenho. Alguns dados serão automaticamente definidos, porém, o usuário poderá alterar conforme a sua preferência.

Serão apresentadas três sub-pastas: Competências, Ações e Fatores Organizacionais.

**Sub-pasta: Competências** – Exibe as competências técnicas e/ou comportamentais agrupadas por cargo ou pela função. Estas informações dependerão da forma como o usuário definiu as configurações da avaliação. Serão exibidas todas as competências, que estejam vinculadas às funções, porém o usuário poderá retirar algum registro que não deva ser avaliado. Para a correta exibição das competências, a função do avaliado deve estar associado a um cargo.

**Dica**

Ocorrendo uma exclusão inválida o usuário poderá restaurar os dados originais. Para isto clique no registro (nome) da função ou do cargo e com o botão direito do mouse selecione a opção "Restaurar competências".

Após este procedimento, todas as competências técnicas e/ou comportamentais vinculadas à função serão exibidas novamente.

**Atenção**

Caso queira avaliar alguma competência que não esteja vinculada à função, o usuário não poderá adicioná-la nesta tela. Deverá ser seguido o procedimento de vinculação de competência na função, pelo próprio cadastro de função, pela opção "Anexos". Existe ainda uma outra opção para a montagem da avaliação:

**Definir pesos das competências** – Permite informar o peso que determinada competência tem para um funcionário específico na função/cargo exercidos por ele. Esta opção é utilizada somente quando a modalidade definida for "Mista".

**Sub-pasta: Ações – Exibe as ações que serão avaliadas**.

As ações serão exibidas caso o usuário tenha definido este item para ser avaliado nas opções de configurações da avaliação. Serão associadas, para cada funcionário que será avaliado, todas as ações existentes em planos de metas onde ele se encontra com um participante. Sendo que estes planos devem estar ativos e em aberto. Caso o usuário deseje poderá retirar algum registro que não deva ser avaliado.

**Dica**

Ocorrendo uma exclusão inválida o usuário poderá restaurar os dados originais. Para isto clique no registro (nome) do item avaliado e com o botão direito do mouse selecione a opção "Restaurar fatores organizacionais". Após este procedimento, todas as ações serão exibidas novamente. É possível editar a Competência e Fatores Organizacionais, para isso basta selecionar o registro e clicar com o botão direito do mouse.

**Atenção**

Caso queira avaliar alguma ação que não esteja vinculada a algum plano de metas, o usuário não poderá adicioná-la nesta tela. Deverá ser seguido o procedimento de vinculação das ações no plano de metas, pelo próprio cadastro de planos de metas, através do menu Gerência de RH.

Existe ainda uma outra opção para a montagem da avaliação:

**Definir pesos das ações** – Permite informar o peso que determinada ação tem para um funcionário específico na função/cargo exercidos por ele. Esta opção é utilizada somente quando a modalidade definida for "Mista", e o modelo de avaliação for 180 graus ou 360 graus.

**Sub-pasta: Fatores Organizacionais**

- Exibe os fatores organizacionais que serão avaliados. Os fatores organizacionais serão exibidos caso o usuário tenha definido este item para ser avaliado nas opções de configurações da avaliação. Serão exibidos todos os fatores organizacionais vinculados à seção, na qual o funcionário se encontra lotado, porém o usuário poderá retirar algum registro que não deva ser avaliado. Para a visualização dos registros o usuário deverá definir a opção para filtro e em seguida clicar na opção "Filtrar". O aplicativo já disponibilizará alguns filtros, porém, o usuário poderá alterá-los ou ainda criar novos filtros, para isto utilize a opção "Criar filtros".

**Dica**

Ocorrendo uma exclusão inválida o usuário poderá restaurar os dados originais. Para isto clique no registro (nome) do item avaliado e com o botão direito do mouse selecione a opção "Restaurar fatores organizacionais". Após este procedimento, todas as ações serão exibidas novamente.

**Atenção**

Caso queira avaliar algum fator organizacional que não esteja vinculado à seção na qual o funcionário se encontra lotado, o usuário poderá adicioná-lo nesta tela. Basta utilizar uma opção para filtros e após a exibição dos fatores selecionar um registro e adicioná-lo à pessoa na qual o fator será avaliado. Para adicionar novos registros aos avaliados utilize o processo de "arrastar/soltar"

Existe ainda uma outra opção para a montagem da avaliação:

**Definir pesos dos fatores ocupacionais** – Permite informar o peso que determinado fator organizacional tem para um funcionário específico na função/cargo exercidos por ele. Esta opção é utilizada somente quando a modalidade definida for "Mista".
