# Grupo AAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Ficha Financeira |
| **Situação/Requisito:** | Ao acessar a ficha financeira, pasta base AAS do funcionário que gozou férias partidas, na competência no qual o funcionário recebeu a verba de Férias Pagas Mês anterior e 1/3 de Férias Pagas anterior, o sistema apresenta a mensagem de erro: 'O Total de Bases discriminadas estão inconsistentes com o valor cadastrado no Grupo 0'.  Ao apresentar a mensagem, o sistema é travado, não permitindo sair da tela, somente abortando o aplicativo. |
| **Solução/Implementação:** | Foi corrigido o travamento na tela da Base AAS que impedia o usuário de continuar operando o sistema. Também foi corrigido o erro que gerava não conformidade nos valores da Base AAS. |
