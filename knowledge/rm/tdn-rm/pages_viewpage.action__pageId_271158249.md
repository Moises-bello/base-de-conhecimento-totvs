# Ajuste na Exportação para o Ministério da Saúde sobre a Quantidade de Recém Nascidos Vivos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Exporta Informações para o Ministério da Saúde |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar,acessar o menu "**Utilitários\Rotinas\Exporta Informações para o Ministério da Saúde**", informar a "Unidade de Faturamento",  "Mês/Ano Competência" e clicar no botão "Exportar", era possível identificar no arquivo gerado pela importação que a quantidade de nascidos vivos não era gravada. |
| **Solução:** | Realizado ajuste no formulário para que se possa obter a informação da quantidade de nascidos vivos no arquivo de exportação. |
