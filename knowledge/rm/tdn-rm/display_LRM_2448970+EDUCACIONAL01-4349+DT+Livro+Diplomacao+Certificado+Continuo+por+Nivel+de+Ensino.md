# CERTIFICADO E DIPLOMA - LIVRO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Certificado e diploma - Livro |
| **Situação/Requisito:** | Foi identificado que ao cadastrar um livro com "Reinício do livro" do tipo "Contínuo" e tiver o mesmo tipo aberto dentro da coligada o sistema impede a criação informando que já existe sendo que o cliente precisa que a validação seja feita pelo contexto coligada, filial e nível de ensino. Foi incluído um novo tipo no "Reinício do livro", o tipo incluído consiste no "Contínuo por nível de ensino", assim ao utilizar este tipo o sistema irá validar se existe um livro aberto somente no contexto do nível de ensino. |
