![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17565370781975) Tempo aproximado para leitura: **00:00:07 min****Ocorrência**Após realizar a importação do layout via Totvs Compartilhamento e acessar o Gerador de Saídas, o layout apenas fica visível para o usuário mestre, de modo que, outros usuários não conseguem visualizar o layout importado.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Causa**Essa ocorrência se dá devido o perfil do usuário não estar incluído na categoria a qual o layout pertence. Sendo assim, o perfil destes usuários deve ser incluído na categoria a qual o layout pertence.  
  
**Solução**Segue abaixo orientações de como incluir o perfil do usuário na categoria.  
  
[Cross Segmentos - Backoffice RM - BI - Criação de categorias para utilização no Gerador de Saídas](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360007257111-Cross-Segmentos-Backoffice-RM-BI-Cria%C3%A7%C3%A3o-de-categorias-para-utiliza%C3%A7%C3%A3o-no-Gerador-de-Sa%C3%ADdas)
