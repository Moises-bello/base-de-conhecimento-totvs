Ao cadastrar ou editar um Empreendimento, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* **Empreendimento:** O sistema traz um número sequencial para identificação primária do empreendimento (Auto-preenchimento, Obrigatório);
* **Código:** Informe o código do empreendimento a ser cadastrado (Obrigatório);
  + Atenção: O campo Código do Empreendimento pode ser parametrizado para receber uma máscara de código, ou seja, receber uma formatação para o preenchimento do código. Basta preencher esta máscara no menu Opções | Parâmetros | RM SGI | Ajustes | Máscara do código do Empreendimento.
* **Nome:** Informe o nome do empreendimento ou da obra;
* **Nome Fantasia:** Informe o nome fantasia do empreendimento ou da obra;
* **CNPJ / CEI:** Informe o número do Cadastro Especial do INSS;
* **Inscrição Estadual:** Caso exista, informe a inscrição estadual do empreendimento;
* **Inscrição Municipal:** Caso exista, informe a inscrição municipal do empreendimento;
* **Data Base:** Informe a data em que o empreendimento foi lançado ou alterado, onde será utilizado para gerar as fotos de alteração dos dados para o log e a ficha financeira;
* **Data de Entrega:** Informe a data em que o empreendimento será entregue ao cliente;
* **Exibe Data Entrega no PDC:** Ao marcar essa opção, a data de Entrega do Empreendimento será exibida no Portal do Cliente, ao desmarcar essa data será ocultada no PDC;
* **Mudar Data Entrega**: Ao clicar neste ícone, abrirá a janela de Troca de Data de Entrega, onde poderemos alterar a data de Entrega do Empreendimento;
  + Atenção: Para efetuar a troca da data de entrega do empreendimento, é necessário informar a nova data de entrega, o motivo para alteração de data entrega e o tipo de parcela para alteração da data de vencimento.
* **Data do Habite-se:** Quando as obras estiverem concluídas e a documentação já tiver sido apresentada, o cidadão deve solicitar a vistoria para concessão do Habite-se (para construções novas) ou da Aceitação (para reformas, modificações, transformações de uso, loteamentos ou instalações comerciais);
* **Mudar Data do Habite-se:** Ao clicar neste ícone, abrirá a janela de Troca de Data do Habite-se, onde poderemos alterar a data de Entrega do Habite-se;
  + Atenção: Para efetuar a troca da data do Habite-se, é necessário informar a nova data de entrega, o motivo para alteração de data entrega e o tipo de parcela para alteração da data de vencimento.
  + **Observação**: Após a concessão do habite-se/aceitação, será fornecida uma certidão que possibilitará o registro do imóvel junto ao Registro Geral de Imóveis (RGI) e/ou à Secretaria Municipal de Fazenda.
* **Data da Fundação:** Informe a data de fundação do empreendimento;
* **Data do Lançamento:** Informe a data de lançamento do empreendimento;
* **Usar data base:** Será utilizada como referencia para venda do empreendimento;
* **Situação Operacional:** Utilizado no cadastro de proposta para filtrar os empreendimentos a serem exibidos.
* **Reserva:** Utilizado para identificar se o empreendimento entra para a lista de empreendimentos processados pelo DIMOB.
* **Indica se usa TAC:** Indica se o Empreendimento usa TAC;
* **Tipo de Empreendimento:** Possui as opções "Loteamento" ou "Condomínio" e permitirá ao usuário classificar o tipo de empreendimento, onde a diferença entre os dois tipos consiste em: no loteamento se compra apenas a área referente ao lote, e no condomínio se compra a fração ideal que engloba não apenas a área de uso privativo, como também a de uso comum;
* **Origem do endereço para DIMOB:** Indica qual deve ser a origem do endereço para a geração do DIMOB, pode assumir os seguintes valores: "Empreendimento" ou "Apto";
* **Deduzir FGTS com terreno permutado:**Indica que em um contrato de venda deste empreendimento que seja **Minha Casa Minha Vida**, ao gerar ao gerar as parcelas de acordo com o andamento da obra, fara abatimento do valor do terreno no valor do FGTS de acordo com as regras descritas na documentação do processo
* **Tipo de Endereço:** Indica o tipo de endereço do empreendimento;
* **CEP:** Indica o CEP do empreendimento, possui um recurso que permite a busca automática do CEP;
* **Tipo de Logradouro:** Indica o tipo de logradouro do Empreendimento, podendo assumir os seguintes valor: Rua, Acesso, Aeroporto, Alameda, Atalho,  Avenida, etc. A nomenclatura do campo segue o modelo estabelecido pelos Correios do Brasil;
* **Logradouro:** Nome do logradouro, em conjunto com o tipo do Logradouro formam a descrição do endereço, como por exemplo, "Avenida" + "Paulista". Este modelo de descrição é compatível com o modelo disponibilizado pelos Correios do Brasil;
* **Nro:** Indica o número do endereço;
* **Complemento Endereço:** Indica o complemento do endereço (Bloco, Apartamento, Casa, etc);
* **Bairro:** Indica o nome do bairro;
* **Cidade:** Nome do município, informado pelo usuário no cadastro de município;
* **UF:** Nome do Estado, informado pelo usuário no cadastro de estado;
* **País:** Indica o nome do país, informado pelo usuário no cadastro de país;
* **Descrição do Endereço:** Indica a descrição do endereço do empreendimento;
* **Telefone:** Indica o telefone do empreendimento;
* **Ramal:** Indica o ramal do empreendimento;
* **Fax:** Indica o fax do empreendimento;
* **Celular:** Indica o celular do empreendimento.
