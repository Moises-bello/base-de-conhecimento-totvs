**Distribuição gerencial** é a *divisão* ou *rateio* que pode ser feito nos valores dos lançamentos contábeis para apropriação dos gastos/receitas das empresas em uma ou mais contas gerenciais.

Sempre que em um lançamento for utilizada uma conta contábil cujo campo Rateio esteja marcado, a distribuição gerencial do valor contábil será exigida para a complementação do lançamento. Se no cadastro da conta contábil tiver sido definido um padrão (default) para o rateio, a distribuição gerencial será feita automaticamente nas contas gerenciais definidas no padrão, caso a conta contábil não tenha um padrão definido, a distribuição gerencial deverá ser feita no momento da inclusão do lançamento, indicando-se as contas gerenciais.

Este módulo permite alterar a distribuição gerencial existente nos lançamentos contábeis de uma forma global e automatizada.

Para iniciar o processo de alteração é necessário que primeiro se informe o(s) lote(s) e filtros para seleção dos lançamentos. Em seguida informe os dados para alteração. A alteração da distribuição gerencial pode ser feita indicando-se *manualmente* as contas de origem, de destino, percentuais para a nova distribuição ou utilizando-se uma *estrutura* previamente cadastrada contendo informações pré-definidas de contas e percentuais para o novo rateio.

Uma vez executado este processo todas as distribuições gerenciais existentes na base e selecionadas para este processo serão alteradas definitivamente conforme a parametrização utilizada, não sendo possível retornar à situação anterior.
