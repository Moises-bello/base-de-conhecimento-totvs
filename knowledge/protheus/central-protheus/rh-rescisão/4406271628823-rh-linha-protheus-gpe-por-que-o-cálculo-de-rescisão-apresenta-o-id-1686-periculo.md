**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34626662342807) Tempo aproximado para leitura: 00:02:00 min****Dúvida**Por que o cálculo de rescisão apresenta o ID 1686-Periculosidade Médias Férias Indenizadas?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**O ID 1686-Periculosidade Médias Férias Indenizadas se trata da periculosidade referente a verba indenizatória Médias Férias Indenizadas, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1686.**
