# LIBERAÇÃO DA COMPETÊNCIA ATUALIZAR DEPENDENTE DE IRRF QUE COMPLETOU 25 ANOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Liberação da Competência* |
| **Situação/Requisito:** | *Na Liberação da Competência, marcando o parâmetro para atualizar dependentes de IRRF, é desmarcada a incidência de IRRF automaticamente para dependentes que completaram 22 anos no mês, porém para os dependentes que têm o parâmetro "Universitário/Escola Técnica 2º" marcado, não está sendo desmarcada a incidência em IRRF quando completa 25 anos.*  *O correto é desmarcar também para os dependentes que cursam universidade ou escola técnica e completaram 25 anos na competência.* |
| **Solução/Implementação:** | *Ajuste no processo de Liberação da Competência para tratar também os dependentes que cursam universidade ou escola técnica e completaram 25 anos na competência, no controle do parâmetro para atualizar dependentes de IRRF.* |
| **Chamados   relacionados:** | *TUE462, TUN981* |
| **Versões/Release:** | *11.82.43, 12.1.11* |
