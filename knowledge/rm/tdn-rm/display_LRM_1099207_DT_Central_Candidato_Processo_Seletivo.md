|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo. |

| **Situação/Requisito:** | O sistema estava exibindo mensagem "Inscrição paga" quando o candidato logava no sistema. Essa notificação erra exibida desnecessariamente. |
