# Mensagem de alerta na troca da data base da geração de tributos.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Alteração do parametrizador do TOTVS Gestão Financeira |
| **Situação/Requisito:** | Foi alterado a data base para geração do IRRF de Vencimento para Baixa,  Ao gerar o arquivo da DIRF 2018 buscando os dados do RM Fluxus identificou que o arquivo apresentou somente os valores para os meses de novembro e dezembro (período após a alteração do parâmetro). |
| **Solução/Implementação:** | Adicionada uma mensagem de alerta ao passar pelo parâmetro de data base de geração dos impostos IRRF-PJ, IRRF-PF e INSS |
| **Conversores e Parâmetros:** | Geração de IRRF-PF, Geração de IRRF-PJ e Geração de INSS |
