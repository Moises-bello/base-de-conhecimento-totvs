**Ocorrência**Sistema não está apresentando tela de opções para a geração de rescisões complementares  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Causa**Isso ocorre porque o sistema valida se a rescisão complementar está sendo calculada pra um período aberto ou fechado.  
  
**Solução**Se estiver calculando uma rescisão complementar de um mês fechado o sistema apresentará a mensagem:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360101847833)  
Se efetuar o cálculo da complementar para o mês vigente, ou seja o mês aberto, o sistema apresentará a mensagem com as opções de recalculo / complementar ou complementar por dissidio:![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000744062)
