**Dúvida**Precisamos de uma classe que possamos informar o arquivo físico, neste caso o PDF, e este seja enviado para impressora sem a necessidade de abrir o arquivo em tela, é possível?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL –Todas versões  
  
**Solução**Não temos classe ou função que seja possível essa tratativa, pois é necessário o smartclient para visualizar o arquivo.
