# RAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |

| **Função:** | *RAIS* |
| **Situação/Requisito:** | Sistema está levando CNPJ no Campo Contribuição Associativa (Segunda Ocorrência) da Rais.  O campo CNPJ não está preenchido no cadastro do funcionário na Guia Rais e também não foi informado via Campo Complementar. |
| **Solução/Implementação:** | *Ajustado o preenchimento do campo 'Contribuição Associativa (Segunda Ocorrência)' quando não tem valor e é o mesmo da *'Contribuição Associativa (Primeira Ocorrência)'*.* |
