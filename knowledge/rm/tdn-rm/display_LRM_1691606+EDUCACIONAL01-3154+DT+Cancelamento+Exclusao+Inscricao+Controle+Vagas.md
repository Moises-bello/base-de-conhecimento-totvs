# CANCELAMENTO E EXCLUSÃO DE INSCRIÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Cancelamento e exclusão de inscrições* |
| **Situação/Requisito:** | *Ao tentar cancelar uma inscrição o sistema não permite e emite erro pois o processo seletivo utiliza controle de vagas e ao tentar cancelar uma inscrição e alterar um candidato excedente para inscrito o sistema não consegue fazer esta alteração pois o processo seletivo não está mais um período válido de inscrição.* |
| **Solução/Implementação:** | **Foi criado um parâmetro na tela de cancelamento e exclusão de inscrição que o usuário poderá escolher se altera ou não a lista de excedentes, se o parâmetro desmarcado o processo continuará validando o período de inscrição, se desmarcado desconsidera a validade do processo seletivo.** |
