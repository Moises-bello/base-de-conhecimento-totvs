**Dúvida**Como gerar o arquivo Inspetor de Objetos / Exportar Dados na versão 12.1.2310 do Protheus?  
  
**Ambiente**A partir da versão 12.1.2310  
  
**Solução**

Para solucionar essa dúvida, realize os seguintes passos:  
  
**1.**Aperte**Shift+F6**no Protheus para acessar a**Central de Diagnóstico:**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/24074712082199)  
  
**2.**Na Central de Diagnóstico, gire o scroll do mouse para baixo e localize os **Recursos do Sistema**, após clique em **Extrato das Informações:**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/24074672993303)  
  
3.**Ao clicar em **Extrato das Informações**, o sistema perguntará se deseja continuar, selecione**Sim:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/24074712087191)  
  
4.**Em seguida basta **selecionar uma pasta,** digitar o**nome do arquivo** e clicar em **salvar:**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24074672997399)
