Para gerar a Ficha Financeira com a opção "Posição Atual da Base" desmarcada, é essencial que a venda tenha passado por todo o processo de criação até sua efetivação, garantindo assim um registro completo de seu [histórico](https://tdn.totvs.com/pages/viewpage.action?pageId=421388636). No caso de vendas importadas, pode ocorrer a ausência de informações históricas, nestes casos a Ficha Financeira ficará sem conteúdo.

Neste processo é possível executar os seguintes relatórios:

**Ficha Financeira:** Ao executar esse processo, é exibida uma tela com os seguintes campos:

* **Relatório:** Nesse campo é possível definir que modelo de relatório será utilizado na geração.
* **Data Base:** Permite definir qual a Data Base será utilizada para a geração do relatório.
* **Imprimir Resíduo:** Esse parâmetro define se o Resíduo será exibido no relatório.

**Informe de Pagamentos para IR :** Ao executar esse processo, é exibida uma tela com os seguintes campos:

* **Relatório:** Nesse campo é possível definir que modelo de relatório será utilizado na geração.
* **Data Base:** Permite definir qual a Data Base será utilizada para a geração do relatório.
* **Imprimir Resíduo:** Esse parâmetro define se o Resíduo será exibido no relatório.

**Ficha Financeira - Enviar e-mail:** Ao executar esse processo, é exibida uma tela com os seguintes campos:

* **Relatório:** Nesse campo é possível definir que modelo de relatório será utilizado na geração.
* **Data Base:** Permite definir qual a Data Base será utilizada para a geração do relatório.
* **Imprimir Resíduo:** Esse parâmetro define se o Resíduo será exibido no relatório.
* Assunto: Esse campo define qual será o Assunto do e-mail que será enviado ao final da execução do processo;
* **Corpo do e-mail:** Esse campo define qual será o Corpo do e-mail que será enviado ao final da execução do processo;
* **Outros Destinários:** Define quais serão os destinatários que poderão receber o e-mail;
* **Enviar e-mail para o comprador principal:** Esse campo define que deverá ser enviado o relatório para o comprador principal da venda a qual o processo está sendo executado;
* **Enviar e-mail para todos os compradores:** Esse campo define que deverá ser enviado o relatório para todos os compradores da venda a qual o processo está sendo executado;

**Informe de Pagamento para IR - Enviar e-mail:** Ao executar esse processo, é exibida uma tela com os seguintes campos:

* **Relatório:** Nesse campo é possível definir que modelo de relatório será utilizado na geração.
* **Data Base:** Permite definir qual a Data Base será utilizada para a geração do relatório.
* **Imprimir Resíduo:** Esse parâmetro define se o Resíduo será exibido no relatório.
* Assunto: Esse campo define qual será o Assunto do e-mail que será enviado ao final da execução do processo;
* **Corpo do e-mail:** Esse campo define qual será o Corpo do e-mail que será enviado ao final da execução do processo;
* **Outros Destinários:** Define quais serão os destinatários que poderão receber o e-mail;
* **Enviar e-mail para o comprador principal:** Esse campo define que deverá ser enviado o relatório para o comprador principal da venda a qual o processo está sendo executado;
* **Enviar e-mail para todos os compradores:** Esse campo define que deverá ser enviado o relatório para todos os compradores da venda a qual o processo está sendo executado.
