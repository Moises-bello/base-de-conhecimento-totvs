# INTEGRAÇÃO FLUIG LMS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Alteração de usuário integrado ao Fluig LMS |
| **Situação/Requisito:** | Sistema não estava permitindo alterar usuário do aluno quando integrado ao Fluig LMS e não utiliza integração SAML (identity), mesmo que ele não estivesse sido enviado ao LMS. |
| **Solução/Implementação:** | Foi realizado um acerto na validação ao alterar usuário do aluno ou do professor.  O usuário, do aluno, não poderá ser alterado, caso o mesmo já esteja integrado ao Fluig LMS e não haja utilização da integração com SAML (Identity). |
