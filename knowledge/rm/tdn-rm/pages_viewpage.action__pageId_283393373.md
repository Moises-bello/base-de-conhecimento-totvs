# Ajuste no Formulário Faturamento para Convênio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão de Saúde |
| **Função:** | Faturamento para Convênios |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar Nova MDI, ir ao menu: **Faturamento/Faturamento para Convênios**, criar uma nova remessa, selecionar um "Tipo de Paciente", um "Tipo de Guia", preenche a "Competência", selecionar mais de "100" (pois é conhecimento que o sistema separa as remessas em grupos de 100 guias) e finalizar o processo, é possível verificar que o sistema informava que o processo foi finalizado, porém ao verificar os dados referentes as remessas na relação de itens processados de acordo com o filtro adequado, é possível verificar que a última remessa estava com o status "Em Aberto" e seus valores apareciam zerados. |
| **Solução:** | Realizado ajustes nas rotinas para a adequação ao processo. |
