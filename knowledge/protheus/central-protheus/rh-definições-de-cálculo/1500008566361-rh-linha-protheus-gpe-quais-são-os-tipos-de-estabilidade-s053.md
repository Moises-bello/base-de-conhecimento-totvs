**Dúvida**Quais são os tipos de estabilidade cadastrados na S053?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**Na tabela **S053** são definidos os **tipos de estabilidades utilizados pelo eSocial.** As categorias de trabalhadores estão disponibilizadas na **Tabela 01 – Categorias de Trabalhadores** através do **Manual de Orientação no portal oficial do eSocial.**

|  |  |  |
| --- | --- | --- |
| **Campo** | **Descrição** | **Detalhes** |
| **DSCEST** | **Descrição** | Informe a descrição acerca do tipo de estabilidade. |
| **MOTEST** | **Motivo** | Informe o motivo da estabilidade de acordo com as opções: |
| 01 = Acidente de Trabalho; |
| 02 = Mandato Sindical; |
| 03 = Mandato Eleitoral; |
| 04 = Gravidez; |
| 05 = Prestação de Serviço Militar; |
| 06 = Convenção Coletiva de Trabalho; |
| 07 = Candidato da CIPA; |
| 08 = Eleito Titular CIPA; |
| 09 = Eleito Suplente CIPA; |
| 10 = Membro do Conselho Nacional da Previdência Social (CNPS); |
| 11 = Membro de Comissão de Conciliação Prévia; |
| 12 = Empregados eleitos diretores de sociedades cooperativas; |
| 13 = Membros do Conselho Curador do FGTS; |
| 99 = Outros; |
| **TPESTB** | **Tipo** | Informe o código identificador do tipo de estabilidade. |

Caso seja necessário e precise cadastrar a tabela S053, acesse **Atualizações> Definições de Cálculos > Manutenção de tabelas (GPEA320)**. Selecione a tabela S053 > Outras Ações > Alterar e inclua conforme a necessidade as informações.
