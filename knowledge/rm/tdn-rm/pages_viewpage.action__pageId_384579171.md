# Digitação do Histórico

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Digiitação do Histórico |
| **Situação/Requisito:** | Ao tentar digitar uma nota de histórico quando essa possui mais de 6 caracteres, o sistema exibe a seguinte mensagem de erro: *Disciplinas do histórico[1]: A Column 'NOTA' excede o limite de MaxLength* Falha ao ativar restrições. Uma ou mais linhas contêm valores que violam as restrições non-null, unique ou foreign-key. |
| **Solução/Implementação:** | Evolução no recurso de digitação de nota do histórico para que seja permitido digitar a quantidade de caractere (10) permitida pelo banco de dados. |
