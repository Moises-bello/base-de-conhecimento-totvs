# Baixar Créditos/Devoluções Vinculados

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixar Créditos/Devoluções Vinculados |
| **Situação/Requisito:** | Ao fazer a baixa de um lançamento com boleto vinculado através do processo "Baixar Créditos/Devoluções Vinculados" onde o mesmo fica parcialmente baixado o sistema não cria um novo boleto com o valor que permanece em aberto no lançamento mesmo o parâmetro “Não gerar outro boleto para lançamento após baixa parcial” estando desmarcado. |
| **Solução/Implementação:** | Ajuste para gerar um novo boleto com o valor que permanece em aberto no lançamento após a baixa utilizando o processo "Baixar Créditos/Devoluções Vinculados". |
