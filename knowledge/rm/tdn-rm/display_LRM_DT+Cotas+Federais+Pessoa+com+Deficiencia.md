# COTAS FEDERAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Cotas federais |
| **Situação/Requisito:** | Em Dezembro de 2016 o governo federal fez uma alteração na lei de cotas federais (**[LEI Nº 12.711](http://www.planalto.gov.br/ccivil_03/_ato2011-2014/2012/lei/l12711.htm)**) através da alteração na **[LEI Nº 13.409](http://www.planalto.gov.br/ccivil_03/_Ato2015-2018/2016/Lei/L13409.htm#art1),** está alteração contempla agora que além dos percentuais de vagas para cotas federais compostas de estudantes de escolas públicas, pessoas com baixa renda e por autodeclarados pretos, pardos e indígenas, a alteração na lei inclui um percentual de pessoas com deficiência, sendo que todos estes percentuais são baseados nos dados percentuais populacionais disponibilizados pelo IBGE. |
| **Solução/Implementação:** | Foi realizada a implementação dos campos relacionados a cotas federais na tela de configuração das cotas no processo seletivo bem como alterado toda a classificação e chamada de candidatos para que atenda este novo requisito da pessoa com deficiência em processos seletivos que utilizem cotas federais. |
| **Tickets relacionados:** | EDUCACIONAL01-929 |
