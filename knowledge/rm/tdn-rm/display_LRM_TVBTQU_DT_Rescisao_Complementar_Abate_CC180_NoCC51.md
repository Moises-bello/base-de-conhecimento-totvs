# RESCISÃO COMPLEMENTAR ESTÁ ABATENDO O VALOR DO CC180 NO EVENTO DE CC51

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Complementar* |
| **Situação/Requisito:** | *No cálculo da Rescisão Complementar está sendo abatido no evento de CC 51 (Adiantamento de 13o.) o valor do CC 180 (Diferença de 13o.Dissídio) indevidamente.*  *O valor do CC 180 só deve ser abatido no CC 51 quando a rescisão ocorre na competência dezembro, logo após o pagamento da 2a.Parcela do 13o.Salário.* |
| **Solução/Implementação:** | *Ajuste na Rescisão Complementar para abater o valor do evento de CC 180 no CC 51 somente nos casos de rescisões na competência dezembro, logo após o pagamento da 2a.Parcela do 13o.Salário.* |
| **Chamados   relacionados:** | *TVBTQU, TVCFC0* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
