![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/27076063382295) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**É possível configurar o campo Biometria (TM0\_INDBIO) do cadastro da Ficha Médica para que fica definitivo como SIM?  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/27076058129943)  
  
**Ambiente**TOTVS RH - (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**No padrão não é possível configurar para sempre apresentar o campo com SIM. Para atender a necessidade da empresa poderá verificar com analista inloco a possibilidade de customização.   
  
O impacto em fazer alteração no inicializador é que o sistema não seguirá mais o fluxo padrão que é inserir um valor padrão no campo, ou seja ao alterar o inicializador o comportamento do sistema será outro, sendo caracterizado uma customização.  
  
Alterando os valores padrões para outros valores válidos o sistema tera apenas a mudança de comportamento, mas o desenvolvedor precisa garantir a eficácia dessa alteração através de testes para garantir a integridade.
