**Dúvida**Temos um Ponto de entrada para adicionar botões na rotina de recebimento de Importação (EICDI154)?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control*– Todas versões  
  
**Solução**É possível utilizar o ponto de entrada **IDI154MNU** para adicionar botões na rotina de recebimento de importação.
