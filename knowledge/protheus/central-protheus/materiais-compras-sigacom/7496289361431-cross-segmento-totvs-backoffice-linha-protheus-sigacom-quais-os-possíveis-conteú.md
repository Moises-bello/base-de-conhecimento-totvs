![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34633237076375) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Quais os possíveis conteúdos do campo C1\_OBS de uma Solicitação de Compra ?

**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - SIGACOM - Versão 12  
  
**Solução**

O campo C1\_OBS pode constar com os seguintes status:

1 - Observação inclusa pelo usuário

![imagem2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7621080689431)

2 - Solicitação gerada por Ponto de Pedido

![imagem3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7621068955799)

3 - Solicitação gerada por Aglutinação

![imagem4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7621083771927)

4 - Solicitação Cancelada pelo Sistema

![imagem1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/7496121593111)

Observação: Esse status é apresentado quando houve encerramento/exclusão de uma Ordem de Produção (OP) vinculada a Solicitação de Compra não atendida, sendo assim a OP é cancelada
