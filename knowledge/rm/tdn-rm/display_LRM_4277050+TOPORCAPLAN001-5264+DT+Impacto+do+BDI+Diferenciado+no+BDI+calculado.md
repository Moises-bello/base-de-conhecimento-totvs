# IMPACTO DO BDI DIFERENCIADO NO BDI CALCULADO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Cálculo do BDI |
| **Situação/Requisito:** | De acordo com a documentação do produto, uma das variáveis do cálculo do BDI calculado é o custo direto e indireto. Entretanto o Total Direto e Indireto utilizados na fórmula do bdi calculado, estão buscando o VALOR e não o custo. |
| **Solução/Implementação:** | Desmarcando o novo parâmetro "BDI Diferenciado impacta no BDI calculado" é possível calcular o BDI sem o impacto do BDI Diferenciado que é aplicado às Tarefas, pois o cálculo irá se basear nos custos direto e indireto. |
