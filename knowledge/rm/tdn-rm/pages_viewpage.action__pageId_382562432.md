|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |

| **Função:** | Inclusão de Aluno via WebServices. |

| **Solução/Implementação:** | Otimização da inclusão de novo aluno com pessoa já existente via WebServices para que o sistema não atualiza os campos relacionados a pessoa não informados (retirados) no XML. |
