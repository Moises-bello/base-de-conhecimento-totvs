![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**A função Help() possui documentação?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**A função Help exibe a ajuda especificada para o campo e permite sua edição. Se for um help novo, o texto informado é apresentado em tempo de execução.  
Exemplo:

```
Help('',1,'DATAFIN',,'Não é possível inserir títulos se a data base for anterior a data do parâmetro XXX',1,0)   
Help(" ",1,"NUMSEQ",,"XXX",4,15)
```
