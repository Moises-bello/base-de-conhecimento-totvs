# Mensagem de erro - Confirmação de rematrícula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Portal |
| **Função:** | Confirmação de rematrícula |
| **Situação/Requisito:** | Ao realizar a matricula do aluno no portal e caso ocorra algum problema após finalizar a confirmação de matrícula, o portal não exibe a mensagem de erro por completo quando é utilizado o navegador Google Chrome, com isso não tem como saber o que está ocorrendo com a matrícula para que possamos ajustar no sistema e finalizar a mesma. |
| **Solução/Implementação:** | Foi tratado a mensagem de erro para ser apresentado apenas o resumo do processamento. |
