# PROCESSO SELETIVO TERCEIRIZADO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Matrícula através do processo seletivo terceirizado |
| **Situação/Requisito:** | Ao efetuar uma matrícula, utilizando o processo seletivo terceirizado, o sistema não filtra os planos de pagamento, de forma a exibir somente os planos vigentes. |
| **Solução/Implementação:** | Foi realizada otimização do processo de matrícula, dentro do processo seletivo terceirizado, de forma que, ao selecionar um plano de pagamento, somente sejam listados os planos de pagamento vigentes. |
