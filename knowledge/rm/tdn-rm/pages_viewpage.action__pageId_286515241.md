# SOLICITAÇÃO EXTRAORDINÁRIA NO FLUIG

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Solicitação Extraordinária no Fluig |
| **Situação/Requisito:** | No Fluig, ao executar o processo de Acompanhamento de Pesquisa, para o tipo de acompanhamento “Solicitação Extraordinária”, apresetava mensagem de erro de chave estrangeira, quando marcasse para excluir o participante, mas não marcava para excluir o seu plano de trabalho. |
| **Solução/Implementação:** | Alterado a validação do acompanhamento de projeto de pesquisa, ao escolher o tipo de acompanhamento igual a “Solicitação Extraordinária”. Caso seja solicitado para remover o Participante, é obrigatório também marcar para remover o plano de trabalho deste participante. |
