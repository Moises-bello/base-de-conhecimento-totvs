**Dúvida**  
Quais são os pontos de entrada disponíveis para o processo do REINF que envolvem informações do módulo Financeiro?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA989 - a partir da release 12.1.33  
  
**Solução**  
Para viabilizar a integração das informações do módulo Financeiro ao processo do REINF, estão disponíveis os seguintes pontos de entrada:  
  
[DT PE F989T158 REINF - Extrator (FINA989) - Ponto de entrada F989T158](https://tdn.totvs.com/display/PROT/DT+PE+F989T158+REINF+-+Extrator+(FINA989)+-+Ponto+de+entrada+F989T158)

[F989DTCTB - Ponto de entrada para manipular a data contábil do T154](https://tdn.totvs.com/pages/viewpage.action?pageId=806757590)

[F989CPQY - Ponto de entrada na query de títulos a pagar](https://tdn.totvs.com/pages/viewpage.action?pageId=736187438)

[F989CRQY - Ponto de entrada na query de títulos a receber](https://tdn.totvs.com/pages/viewpage.action?pageId=736187072)

[DT PE REINF - Ponto de Entrada para Gravação LEM\_DTCONT](https://tdn.totvs.com/pages/viewpage.action?pageId=806773421)

[F989T158 - Ponto de entrada para manipular os dados dos registros T158AA, T158AB e T158AC](https://tdn.totvs.com/pages/viewpage.action?pageId=811728162)

[F989CPIN - Ponto de entrada para alterar filtro de títulos a pagar com INSS](https://tdn.totvs.com/pages/viewpage.action?pageId=736190267)

[F989CRIN - Ponto de entrada para alterar filtro de títulos a receber com INSS](https://tdn.totvs.com/pages/viewpage.action?pageId=736190150)
