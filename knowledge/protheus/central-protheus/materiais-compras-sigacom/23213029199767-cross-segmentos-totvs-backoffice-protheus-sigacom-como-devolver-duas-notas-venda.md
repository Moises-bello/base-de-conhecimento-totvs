![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23213058667799) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**É possível devolver duas notas de saída em apenas uma nota de devolução utilizando o botão Retornar da rotina documento de entrada MATA103 ?  
  
**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Gestão de Compras - A partir da versão 12  
  
**Solução**Sim, é possível devolver duas notas de venda em apenas uma nota de devolução utilizando o retornar. Para isso, acesse a rotina do documento de entrada (MATA103), clique em "Outras ações" e "Retornar", conforme print abaixo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23213029159063)

O sistema irá abrir a tela para preenchermos o filtro para buscar as notas de saída. Será necessário preencher o código do cliente/fornecedor, loja, data de saída de-até e marcar a opção "Cliente/Fornecedor". Será essa opção que irá permitir que selecionemos mais que uma nota para a devolução.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23213029163671)

Depois disso clicamos em Ok e o sistema apresentará a tela do print abaixo. O sistema habilitará uma caixa de seleção que permite selecionar as notas desejadas.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23213058674711)
