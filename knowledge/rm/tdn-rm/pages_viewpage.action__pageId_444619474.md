# Sugestões de compra

---

Através desta tela é possível cadastrar sugestões de compra de publicações para a biblioteca.  
    
**Solicitar compra de exemplares**  
Neste processo o usuário deve informar os dados da publicação e o produto referente, cadastrado no TOTVS Gestão de Estoques, Compras e Faturamento, para poder solicitar a compra dos exemplares da publicação.  
   
**Enviar e-mail a usuários com sugestões adquiridas**  
Neste processo o usuário deverá informar o texto do e-mail que será enviado para todos os usuários cuja sugestão de compra esteja adquirida.  
   
 **Atenção:**

* Quando o usuário informar uma chapa que se refira a funcionários cadastrados em coligadas diferentes, o sistema irá apresentar uma tela com todos os funcionários que, possuem a chapa informada, para serem importados.
* Quando a situação da sugestão for **Adquirido**, essa sugestão não poderá ser excluída.
