## **02. SITUAÇÃO/REQUISITO**

Criar um processo de importação para o Evento R-1000. Este processo tem como objetivo importar um Evento R-1000 através do xml autorizado em outro aplicativo.

Ele deverá atualizar os principais com Evento com base nos dados do xml, além de gravar no histórico que o Evento foi importado.

## **03. SOLUÇÃO.**

Implementada Importação de XML do Evento R-1000.

Disponível a partir da versão 12.1.2302
