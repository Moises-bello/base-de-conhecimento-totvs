**Devido ao final do suporte estendido, as plataformas de banco de dados MS SQL Server 2008 e MS SQL Server 2008 R2, a partir de 09/07/2019, deixarão de fazer parte da portabilidade de toda linha de produtos RM.**

Abaixo tabela com os prazos de suporte das versões afetadas de acordo com a Microsoft;

**Segue abaixo o link da documentação oficial da Microsoft sobre o fim do suporte estendido as versões afetadas:**

<https://support.microsoft.com/pt-br/lifecycle/search?alpha=sql%20server%202008>

**A atualização é altamente recomendada uma vez que a Microsoft não mais disponibiliza correções nem melhorias para o produto a partir da data mencionada, além de não ser possível abertura de tickets de suporte junto a própria Microsoft. Em relação ao suporte por parte da linha RM, este continuará, porém demandas que caracterizem limitações das versões SQL Server 2008 e SQL Server 2008 R2 não poderão ser tratadas visto que o fornecedor da própria ferramenta não a suportará.**

**Abaixo link da Microsoft com recomendações de Migração do SQL Server 2008 / SQL Server 2008 R2:**

<https://www.microsoft.com/en-us/sql-server/sql-server-2008>

**Recomendamos que o banco de dados seja migrado para uma versão mais atual. Caso ainda esteja em uso a versão em Delphi de algum produto da linha RM, este deve ser migrado para a versão SQL Server 2012 e utilizado o ODBC em conjunto com o BDE de acordo com documentação abaixo:**
