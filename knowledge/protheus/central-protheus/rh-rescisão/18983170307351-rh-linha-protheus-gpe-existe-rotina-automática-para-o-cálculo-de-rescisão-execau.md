![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18983160166551) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Existe rotina automática para o cálculo de rescisão (execAuto)?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**A rotina de rescisão não tem execução por rotina automática (ExecAuto, seja pelo fonte GPEM040 ou GPEM630, somente ponto de entrada em MVC).   
  
Para acessar a documentação do modelo do ponto de entrada da rotina GPEM040 acesse [AQUI](https://tdn.totvs.com/pages/releaseview.action?pageId=680971161).
