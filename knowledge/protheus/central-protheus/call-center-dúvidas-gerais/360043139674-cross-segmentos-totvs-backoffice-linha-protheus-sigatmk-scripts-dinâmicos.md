**Dúvida**

Como configurar Scripts Dinâmicos?  
  
**Ambiente**

Cross Segmentos-TOTVS Backoffice (Linha Protheus)-SIGATMK – A partir da versão 12.  
  
**Solução**

Para configurar é necessário:  
1. Os Scripts são cadastrados na rotina **Scripts Dinâmicos (TMKA360)**;  
2. Os scripts serão relacionados diretamente no **Cadastro de Campanhas (TMKA310)**;  
3. Para acionar o Script no atendimento, a campanha deve ser preenchida e o script é acionado em **Outras Ações** -> **Script de Campanha**;  
4. Selecione o Script que deseja executar;  
5. O sistema apresentará o Script para preenchimento de acordo com as perguntas configuradas;  
6. O Relatório de **“Scripts x Atendimentos” (TMKR029)** apresenta as respostas dos Scripts por atendimento e o **Score** alcançado.
