#### **1 – Introdução**

Os tipos de requisições são classificações obrigatórias para as requisições. Têm o propósito de qualificar a finalidade da requisição e permitir configurações gerais, aplicáveis às requisições de um mesmo tipo.

**2 – Acesso ao módulo**

Delphi: Acesse o menu “Opções | Parâmetros | RM Vitae | Tipos de Requisição”

Nova MDI: Acesse o menu “Configurações | Tipos de Requisição”

#### **3 – Campos da Tela**

#### 3.1 – Identificação

**•** **ID Requisição** Este campo é gerado automaticamente pelo sistema e não pode ser editado.

**• Ativo** Este campo indica se o tipo de requisição está disponível para uso no sistema.

**• Tipo Requisição**

Neste campo deve ser informado o nome do tipo de requisição.

**• Fluxo de Etapas**

**- Grupo de Atendimento**     Neste campo deve ser informado o grupo de atendimento já cadastrado no sistema. Caso haja licença do RM Agilis pode ser criado novos grupos de atendimento para serem utilizados nas requisições.

**- Tipo de Atendimento**     Neste campo deve ser informado o tipo de atendimento já cadastrado no sistema. Caso haja licença do RM Agilis pode ser criado novos tipos de atendimento para serem utilizados nas requisições.

**• Relatório Gerencial** Neste campo pode ser informado o relatório de acordo com o tipo de requisição cadastrado.

**• Instruções para o Portal**

Neste campo pode ser informado uma instrução para ser visualizada no Portal pelo usuário que utilizará a requisição.

#### **3.2 – Mapeamento do Fluxo**

Esta pasta destina-se ao cadastramento, consulta e/ou alteração do mapeamento das etapas que será realizado exclusivamente através do RM Vitae. O mapeamento do fluxo é obrigatório e passará a existir somente após a definição do “Grupo de Atendimento” e “Tipo de Atendimento” citados anteriormente.

Quando houver integração com o RM Agilis, é possível utilizar um fluxo de etapas pré-definido deste sistema. Caso não exista integração com o RM Agilis, o RM Vitae utilizará um fluxo padrão que não poderá ser modificado pelo usuário. Este fluxo padrão determina que uma requisição inserida no fluxo de aprovação, deve ser encaminhada para a análise do chefe imediato do aprovador atual até que ela seja aprovada ou reprovada.

Em todo caso, deve existir pelo menos uma etapa final mapeada para cada tipo de requisição existente para o correto funcionamento do processo.
