# VALOR HORA NO ENVELOPE DE PAGAMENTO QUANDO FUNCIONÁRIO TEM SALARIO COMPOSTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Valor hora no envelope de pagamento para funcionário com salário composto.* |
| **Situação/Requisito:** | O valor do salário hora do funcionário dobra em casos que o funcionário possui eventos de salário composto para meses anteriores ao atual. |
| **Solução/Implementação:** | *Foi realizado alteração para o valor do campo seguir o calculo "Soma Salario / Soma Jornada"* |
| **Chamados relacionados:** | TTYVMR |
| **Versões/Release:** | *12.1.10* |
