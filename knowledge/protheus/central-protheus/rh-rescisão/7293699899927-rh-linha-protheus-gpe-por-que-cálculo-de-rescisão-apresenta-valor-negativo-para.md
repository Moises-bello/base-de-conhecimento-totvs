![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18428915765015) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que cálculo de rescisão apresenta valor negativo para o id 0670?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O incidente pode ocorrer devido o id 1446 ser cadastrado como verba tipo desconto. O id 1446 se trata do valor 13 salário indenização em rescisão por licença maternidade, deste modo o mesmo é uma verba do tipo provento, assim o valor do id 1446 é apresentado no id 0670 base provento.
