# Validação de CID Primário no sumário de alta

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Sumário de Alta |
| **Situação:** | Sistema permitia encerrar o sumário de alta com CID Secundários sem que existisse um CID Primário cadastrado. |
| **Solução:** | Criada validação para não permitir cadastrar um CID Secundário sem que exista um CID Primário cadastrado. |
