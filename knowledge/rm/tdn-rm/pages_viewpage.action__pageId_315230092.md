# VISÃO DE EMPRÉSTIMOS - OBSERVAÇÃO

| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Visão de empréstimos - Observação |
| **Situação/Requisito:** | Foi identificado que ao adicionar uma observação em um empréstimo o mesmo não é exibido na visão de empréstimos e o campo de observações na visão de empréstimos está bloqueado para edição. Foi identificado que o sistema não estava salvando corretamente a observação ao realizar um empréstimo, sendo assim foi feito o ajuste e também foi ajustado o campo de observações na visão de empréstimos para que fique habilitado para edição. |
| **Solução/Implementação:** | Foi identificado que o sistema não estava salvando corretamente a observação ao realizar um empréstimo, sendo assim foi feito o ajuste e também foi ajustado o campo de observações na visão de empréstimos para que fique habilitado para edição.
