**Dúvida**  
Como importar dados para as tabelas do Protheus como cadastros, histórico de funcionários e histórico de movimentos da folha de pagamento para o módulo SIGAGPE.   
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões.

**Solução**  
Oferecemos algumas soluções para importação de dados para as tabelas do módulo SIGAGPE, que permitem a inclusão de dados em grandes quantidades, incluindo automaticamente registros que seriam informadas manualmente na rotina padrão.  
Abaixo algumas opções: 

**1. MILE: Model Integrator Layout Engine**

* [MILE - Model Integrator Layout Engine](https://tdn.totvs.com/display/framework/MILE+-+Model+Integrator+Layout+Engine)
* [Configuração de MILE em rotinas do GPE](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360059771073-RH-Linha-Protheus-GPE-Configura%C3%A7%C3%A3o-de-MILE-em-rotinas-do-GPE)

**2. Execauto: Rotina Automática**

* [Atendimento | Execauto](https://tdn.totvs.com/pages/viewpage.action?spaceKey=GDPA&title=Atendimento+%7C+Execauto)
* [Rotina Automática (Execauto) em rotinas do SIGAGPE](https://centraldeatendimento.totvs.com/hc/pt-br/articles/41005221053079-RH-Linha-Protheus-GPE-Rotina-Autom%C3%A1tica-Execauto-em-rotinas-do-GPE)

**3. Integração EAI**

* [EAI Protheus](https://tdn.totvs.com/display/framework/EAI+Protheus)
* [Como Fazer - Configuração do Protheus para a Integração](https://tdn.totvs.com/pages/viewpage.action?pageId=286007939)

4. **Customização**  
O cliente/usuário pode criar um fonte e configurá-la para importar as informações necessárias para a tabela que deseja. 

**Importante:**O Suporte padrão não auxilia na criação de layouts de importação e customizações.
