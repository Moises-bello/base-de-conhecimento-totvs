# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Contábil |
| **Versões:** | 12.1.XX |
| **Ocorrência:** | Erro no Registro 0000 |
| **Ambiente:** |  |
| **Passo a passo:** | **Processo:**  Erro apresentado ao validar o arquivo da ECD no PGE (Programa Gerador de Escrituração):  **TAMANHO DO CAMPO INVÁLIDO.  9 - COD\_MUN**  **Análise/Solução**  Para verificar o tamanho do código do município, favor acessar o menu:  Ambiente/Parâmetros/TOTVS Gestão Contábil/Rotinas Legais/Avançar.  Informar no campo ‘Classificação do Município (IBGE)’ o código '1 - IBGE'.  **Obs.:** O registro em questão é cadastrado no menu Cadastros/Municípios/Classificação de Municípios.  Para verificar qual a codificação do seu município em relação ao IBGE, favor acessar Cadastros/Municípios   * Selecione o município desejado, * Vá em Anexos/Codificação de Município, * Clique 2X na opção IBGE, * E veja se o código informado esta correto. |
