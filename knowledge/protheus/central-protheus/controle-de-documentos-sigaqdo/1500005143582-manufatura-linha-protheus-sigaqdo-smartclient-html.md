**Dúvida**É possível utilizar o módulo **SIGAQDO - Controle de Documentos** no **SmartClient HTML**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**A partir da *release* **12.1.2210** o **SIGAQDO** está homologado para uso via navegador *Web Browser*, tendo como premissa o uso da nova tecnologia **WebApp + WebAgent** em todas as estações.  
  
**Saiba Mais**  
Para mais detalhes sobre esta tecnologia acesse o link [Homologado para SmartClient HTML](https://tdn.totvs.com.br/pages/releaseview.action?pageId=306851898).
