Evento destinado a enviar as informações utilizadas para a atualização dos dados contratuais relativos aos trabalhadores que não possuem vínculo emprego/estatutário com a empresa/órgão público.  
 **Observação:** Sempre que o usuário realizar uma alteração no cadastro de funcionário, serão verificados nos campos abaixo se foram alterados e deverá criar um gatilho considerando as datas de alterações informadas na alteração (histórico).  
 Será criado um gatilho para cada uma das datas diferentes, agrupando por data de alteração:

* Salário
* Função
* Transferência entre Seções
* Cargo de confiança
