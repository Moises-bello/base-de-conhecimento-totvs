Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**. 

Na aba Diagrams é possível visualizar os diagramas que foram enviados ao motor. É possível ainda deletar as rotas que foram enviadas após realizar o deploy.

### Diagrams Available

Permite visualizar os diagramas disponíveis.

| Campo | Descrição |
| --- | --- |
| Receiver Name | Exibe o nome do componente receiver configurado na rota. |
| Comments | Exibe os comentários que foram adicionados a respeito do diagrama. |
| Reload | Ao pressionar o botão 'Reload' as informações de diagramas disponíveis são atualizadas caso algum diagrama tenha sido adicionado ou deletado. |
| Delete | Ao selecionar um diagrama da tabela, e pressionar o botão 'Delete' a rota é excluída do motor. |
