# GERAÇÃO DE PARCELAS DE PLANOS DE PAGAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de parcelas de planos de pagamentos* |
| **Situação/Requisito:** | *Na rotina de geração de parcelas de planos de pagamentos, em casos onde existam mais de 1 plano de pagamento selecionado para o processo, as competências das parcelas são geradas de forma a não respeitar a parcela a partir do segundo plano de pagamento selecionado no processo.* |
| **Solução/Implementação:** | *Foi ajustado o processo de geração de parcelas de planos de pagamentos para que nos casos citados (presença de mais de um plano de pagamento) a geração das competências respeite a parcela.* |
