A partir da versão 12.1.2306, caso o usuário não possua a informação do último "Alias" utilizado no login, será apresentado como padrão o primeiro da lista de Alias disponíveis para aquele usuário no lugar de exibir o campo vazio.

Após o primeiro login, a informação será salva no perfil do usuário normalmente.

Atenção

Caso o último "Alias" utilizado no login não seja encontrado para seleção, o campo Alias ficará em branco. Isso ocorre caso o nome do Alias tenha sido alterado.
