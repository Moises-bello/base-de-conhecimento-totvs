**Dúvida**Quais são as extensões do arquivo CNAB de acordo com cada modelo selecionado?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**  
Na rotina **Geração Arquivo de Líquidos - GPEM080**, de acordo com o modelo selecionado, será apresentada as extensões dos arquivos de configuração para geração do arquivo CNAB.

Nos *prints* abaixo, observe as opções conforme cada modelo selecionado:   
  
**1) Para o CNAB modelo 1:**  
Extensões .CPE   
Extensões .REM  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360083650474)

**2) CNAB Modelo 2:**Extensões .2PE  
Extensões .2RE  
Extensões .2PR  
Extensões .2RR

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360083650494)
