**Dúvida**Como pode ser definido os cursos e treinamentos exigidos para exercer determinado cargo ou função?  
Necessidade de treinamento.

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) -Treinamento - Todas as versões  
  
**Solução**O Treinamento tem como objetivo principal a definição, planejamento e execução dos projetos e programas de treinamentos e  cursos para desenvolvimento profissional em uma empresa.  
O termo Treinamento é empregado como preparo específico para o bom desempenho das várias tarefas que compõem os diferentes cargos. As ações de treinamento são normalmente executadas dentro da própria empresa, mais especificamente, no próprio ambiente de trabalho, sob a responsabilidade de um instrutor preparado para este fim.  
  
A partir dos dados coletados na análise de cargos é possível elaborar o perfil do profissional adequado para ocupar determinado cargo na estrutura organizacional de uma empresa. Para compor o perfil do profissional é necessário o conhecimento da essência do trabalho a ser realizado, suas responsabilidades e atribuições. Todos estes dados estão disponíveis no Cadastro de Cargos.  
  
Função é usualmente conceituada como um conjunto de ações ou tarefas de natureza e níveis semelhantes, executadas por uma ou mais pessoas qualificadas ou com formação específica para tal. A função está diretamente ligada à natureza do trabalho e ao processo exigido para a produção de um bem ou de um serviço.  
  
Esta rotina permite efetuar o cadastro/manutenção de todas as funções exercidas pelos colaboradores de uma empresa. O sistema possibilita ainda que sejam relacionados os cursos necessários para cada função.  Esta forma, ao gerar uma "Necessidade de Treinamento", o sistema verifica os cursos necessários tanto para o cargo quanto para a função de um colaborador.  
  
Para iniciar esta definição deverá ser apontado em seus respectivos cadastros os cursos necessários para desenvolver determinada função/cargo.  
  
Para isto acesso o módulo 26 **( SIGATRM)**, no seguinte caminho: Atualizações > Cadastro > Cursos Internos.   
Realize o cadastro de todos os cursos avaliados necessários, para posteriormente ser vinculado aos cargos e funções existentes na empresa.  
Na **Pasta Curso**, deve ser informados, todos os dados do curso, como sua descrição, tipo do curso, duração e valor.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077053593/mceclip2.png)  
  
Na **Pasta Entidades**, devem ser relacionadas as entidades que podem ministrar o curso.  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077055073/mceclip3.png)  
  
Na **Pasta Materiais**, devem ser relacionados os materiais de treinamento necessários para a realização do curso, bem como a identificação de quem é o responsável pelo material, se a própria empresa ou a Entidade.  
  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360075939554/mceclip5.png)  
  
Após a definição dos cursos, deve ser realizado a amarração no cadastro de **Cargo** ou **Função**, para isso acesse o seguinte caminho: Atualizações > Cadastro > Cargo.   
Realize o cadastro conforme definição da empresa e deverá relacionar com o(s) curso(s) necessário para o cargo na aba Curso.

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077057193/mceclip6.png)  
  
Mesma amarração deve ser realizada para o cadastro de funções, definir todos os cursos necessário para exercer determinada função,  para isto acesse: Atualizações > Cadastro > Funções > Pasta Curso   
Vincule corretamente os cursos necessários e salve.  
  
![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077057473/mceclip7.png)
