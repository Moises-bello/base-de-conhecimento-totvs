**Objetivo:**A finalidade da atividade de "Executar Processo" como o próprio nome já diz é executar processos do sistema.

Primeiramente é necessário arrastar a atividade "Executar Processo" para o "fluxo de trabalho" sequencial em sua fórmula visual.

|  |
| --- |

Após a atividade ter sido adicionada ao fluxo de trabalho é necessário configurar as propriedades da atividade.

|  |
| --- |

Neste exemplo vou executar o processo de compensação de cheque manual, onde necessário preencher a propriedade "nome do processo". Para preencher basta clicar no ícone que encontra-se na propriedade e digitar o processo escolhido.

|  |  |
| --- | --- |

Agora só falta adicionar o gatilho ou o processo que a formula visual será vinculada. Neste exemplo escolhi o processo "Extrato de Caixa".

|  |  |  |
| --- | --- | --- |

Para executar o processo bastar ir na visão "Extrato de Caixa", selecionar o registro que deseja compensar e logo após acessar o menu "Processos -> Fórmula Visual -> Executar Processo (nome da sua fórmula visual)" que o processo será executado.

|  |  |
| --- | --- |
