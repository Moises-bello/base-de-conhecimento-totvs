# Método de login do EducaMobile para eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educa Mobile |
| **Função:** | Login do TOTVS Educa Mobile a partir do eduCONNECT |
| **Situação/Requisito:** | Ao acessar o TOTVS Educa Mobile dentro do eduCONNECT, o sistema está acusando erro pela falta do método de login chamado "LoginExternoApp". |
| **Solução/Implementação:** | Foi disponibilizado o método de login (LoginExternoApp) do TOTVS Educa Mobile que o eduCONNECT utiliza nas versões mais novas (12.1.18 ou superior), pois o eduCONNECT em versão mais nova deve conseguir realizar login no TOTVS Educa Mobile na versão 12.1.17. |
