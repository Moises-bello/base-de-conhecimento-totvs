Como realizar cadastro de classes salarial no modulo arquitetura organizacional  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Arquitetura Organizacional – Todas as versões  
  
**Solução**Esta rotina permite a criação dos itens que irão compor os níveis das classes salariais da empresa.  
  
A Classe Salarial será utilizada na [Classificação dos Cargos](https://interno.totvs.com/mktfiles/tdiportais/helponlineprotheus/p12/portuguese/csaa120.htm), onde podem ser agrupados **cargos que pertençam à mesma classe salarial,** para que sejam identificados na tabela salarial, de acordo com as necessidades de cada empresa.  
  
Para realizar um **cadastro de classe salarial** é necessário seguir os seguintes passos:  
  
1-Acessar o modulo 70- Arquitetura organizacional

2-Acessar o seguinte caminho  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19409038010519)  
  
3- Realizar a inclusão de uma classe salarial
