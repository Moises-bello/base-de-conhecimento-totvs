Parêmetros do sistema de Gestão de Pessoas utilizados no portal do Meu RH.

Exibir nome social do funcionário:

Ao marcar este parâmetro, se no cadastro do funcionário o campo de Nome Social estiver preenchido, em todos os pontos do Meu RH, ao exibir as informações de nome do funcionário será exibido o nome social cadastrado para ele. Caso o parâmetro esteja desmarcado, será exibido apenas o nome cadastrado para o usuário, mesmo ele tendo um nome social informado.

**Observação**: Para documentos legais como Informe de rendimentos, por exemplo, pode ser que o nome social não esteja disponível.

Considerar a nova requisição geral para o Meu RH:  
  
Ao marcar este parâmetro irá disponibilizar as requisições gerais para utilização no Meu RH.   
No ERP será exibido o cadastro de Categorias de Tipo de Requisição, desde que o perfil do usuário possua permissão na tela de Cadastro de Tipos de requisição (Passo 1) e uma nova aba no cadastro de Tipos de Requisição para que seja possível determinar quais perfis terão permissão para solicitar o tipo de requisição geral no Meu RH (Passo 2).  
Para que os menus das requisições gerais seja exibido no Meu RH para um usuário, além do parâmetro é necessário que o perfil vinculado a ele possua permissão para acesso as requisições gerais (Passo 3) e que ele possua permissão para solicitar algum tipo de requisição geral.
