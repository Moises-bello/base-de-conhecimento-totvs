# 1. Sobre

Esta atualização permite que o conteúdo do doc-e tenha acentuação e caracteres especiais sanitizados.

# 2. Versões para atualização

A solução está disponível a partir dos patches:

Biblioteca RM

* 12.1.2510.257

Esta atualização não estará disponível na versão 12.1.2602.

# 3. Detalhe da Alteração

* **Retirar Acentuação** permite que as acentuações sejam removidas do texto.
* **Texto para Sanitização do Doc-e** permite informar quais caracteres devem ser removidos do texto.

Os campos afetados por estes parâmetros podem ser consultados no link
