## Etapa 2 - Carga Inicial

A Carga Inicial é a geração dos eventos de Tabela e Eventos Iniciais do eSocial, que são as primeiras informações que devem ser enviadas ao Governo.

### 2.1 Gerar Gatilhos Eventos Inicias

Para que um registro de carga inicial seja criado na fila de evento e assim possa ter seu XML gerado, acesse:

TOTVS de Folha de Pagamento | eSocial (beta) | Gerar Gatilho de Eventos Iniciais

#### Link de apoio:

* [Gerar Gatilhos Iniciais](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.GerarGatilhosIniciais.aspx)

### 2.2 Gerar XML

Com os gatilhos gerados, podemos dar inicio a geração dos Eventos Inicias, para isso acesse:

TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML , selecionando em Tipo de Eventos, Eventos Inicias

OBS: Lembrando que a geração do XML poderá ser feita pelo caminho supracitado ou pela Fila de Eventos.

Para gerar os XMLs em lotes, recomendamos a execução através do processo TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML.

Para gerações pontuais, como exemplo, ajuste de poucos eventos, indicamos que seja feito através do

TOTVS de Folha de Pagamento | eSocial (beta) | Fila de Eventos, selecionando-o(s) e clicando no botão "Gerar XML".

#### Link de apoio:

* [Eventos Iniciais](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.EventosIniciais.aspx)
* [Carga Inicial](http://tdn.totvs.com/display/PROT/2.+Carga+Inicial)

Após geração dos XMLs dos Eventos Inicias com sucesso, a transmissão para o TAF poderá ser realizada.

#### Link de Apoio:

* [Integrar TAF](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.IntegrarTAF.aspx)

### 2.3 Eventos de Tabela

Caso o passo acima tenha sido executado com êxito, não é necessário gerar os eventos de tabela, pois eles estão contidos nos   
eventos iniciais.

           O que são eventos de tabela?

São os eventos responsáveis por uma série de informações que validam os eventos não periódicos e periódicos, buscam otimização  
na geração dos arquivos e no armazenamento das informações no Ambiente Nacional do eSocial, por serem utilizadas em mais   
de um evento do sistema ou por se repetirem em diversas partes do layout.

Para gerar dos XML em lotes, recomendamos TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML

Para geração pontual do XML, como em ajuste em eventos de tabela gerados com erro e em outros casos indicamos TOTVS de Folha de Pagamento | eSocial (beta) | Fila   
de Eventos.

Para gerar, exclusivamente os Eventos de Tabela, acesse:

  TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML selecionando em Tipo de Eventos, Eventos de Tabelas.

#### Link de apoio:

[Eventos De Tabelas](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.EventosDeTabelas.aspx)

## Etapa 3 - Rotina Mensal

Após envio dos Eventos Iniciais/Tabelas, a base do Governo estará abastecida de dados para receber os eventos Periódicos e não   
Periódicos.

A rotina específica da folha de pagamento, férias e rescisão pode ser executada normalmente, sendo que para rescisão foi criado   
o módulo 'Aviso prévio' para atender o eSocial.

#### Link de apoio:

* [Aviso Prévio](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.AvisoPrevio.aspx)

### 3.1 Eventos Periódicos

Composto de eventos que têm sua periodicidade definida, tais como: folha de pagamento, imposto de renda retido na fonte, dentre outros.

Para gerar os eventos periódicos siga os passos abaixo:

### 3.1.1 Período de Apuração

Determina a competência das informações da folha de pagamento que serão enviadas para o eSocial.

Para criar o período de apuração acesse:

    TOTVS de Folha de Pagamento | eSocial (beta) | Período de Apuração

#### Link de apoio:

* [Período de Apuração](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.PeriodoApuracao.aspx)

### 3.1.2. Geração dos eventos periódicos.

Os eventos periódicos não possuem gatilho automático, ou seja, todas as vezes que incluímos, excluímos ou alteramos um evento periódico,   
será necessário gerar novamente o XML através do caminho:

    TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML selecione a opção Eventos Periódicos

Para gerar os XML em lotes, recomendamos TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML.

Para geração pontual do XML, como ajustes em alguns eventos periódicos, indicamos TOTVS de Folha de Pagamento | eSocial (beta) | Período   
de Apuração, na aba Eventos da Folha E-Social

#### Link de Apoio:

* [Eventos Periódicos](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.EventosPeriodicos.aspx)

Após geração dos XMLs dos Eventos Periódicos com sucesso, a transmissão para o TAF poderá ser realizada.

#### Link de Apoio:

* [Integrar com o TAF](http://tdn.totvs.com/pages/viewpage.action?pageId=284855354)

### 3.2 Eventos Não Periódicos

São os eventos que não têm uma data especifica para ocorrer tais como rescisão, admissão, alteração salarial entre outros.

### 3.2.1 Dissídio Coletivo/ Acordo Coletivo

Para atender o eSocial, com relação a dissídio e acordo coletivo, acesse:

TOTVS de Folha de Pagamento | eSocial (beta) | Dissídio/Acordo Coletivo

#### Link de Apoio:

* #### [Dissídio/ Acordo Coletivo](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.DissidioAcordoColetivo.aspx)

### 3.2.2 Geração dos eventos Não Periódicos

Os eventos não periódicos possuem geração de gatilho automático, ou seja, todas as vezes que ocorre um evento não periódico,   
automaticamente o sistema gera um gatilho na fila de eventos, indicando que o XML precisa ser gerado e enviados para o TAF.

Para gerar o XML de eventos não periódicos acesse:

TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML selecione a opção Eventos não periódicos.

Para gerar os XML em lotes, recomendamos TOTVS de Folha de Pagamento | eSocial (beta) | Gerar XML.

Para gerações pontuais do XML, como ajuste de um determinado trabalhador por exemplo, indicamos

TOTVS de Folha de Pagamento | eSocial (beta) | Fila de Eventos.

**Link de Apoio:**

* [Eventos Não Periódicos](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.EventosNaoPeriodicos.aspx)

# Processos Acessórios

São processos que não estão diretamente ligado a uma etapa, mas que fazem parte do processo de geração do eSocial.

### 1. Fila de eventos

Nesse módulo será possível gerenciar todos os eventos gerados, sendo possível gerar o XML, integrar com o TAF, verificar o  
 status da geração do XML e da integração com o TAF.

Pela Fila de Eventos também é possível verificar o Ticket TAF que é o protocolo de entrega do XML ao TAF.

Como é possivel criar vários filtros de visualização, podemos considerar a fila de eventos, como um monitor de informações do eSocial.

Caminho de acesso:

TOTVS de Folha de Pagamento | eSocial (beta) | Fila de Eventos

#### Link de Apoio:

* [Fila de Eventos](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.FilaEventos.aspx)

### 2. Integrar com o TAF

A integração em lote com o TAF é realizada em:

TOTVS de Folha de Pagamento | eSocial (beta) | Integrar com o TAF

#### Link de Apoio:

* [Integrar com o TAF](http://tdn.totvs.com/pages/viewpage.action?pageId=284855354)

### 3. Atualizar status Integração TAF

Nesse módulo será possível atualizar o status da integração TOTVS Folha de Pagamento com o TAF.

O TAF irá retornar se o XML dos eventos foram integrados com sucesso (para esse caso é preenchido o ticket TAF) ou se houve erro  
e as informações incorretas terão que ser corrigidas, o XML regerado e o envio para o TAF, feito novamente. Para executar o processo acesse:

TOTVS de Folha de Pagamento | eSocial (beta) | Atualizar Status Integração TAF

#### Link de apoio:

* [#Atualizar Status Integra TAF](http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.AtualizaStatusIntegraTAF.aspx)
