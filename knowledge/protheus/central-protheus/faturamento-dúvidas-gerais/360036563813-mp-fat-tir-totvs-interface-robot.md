**Dúvida**

Como obter apoio para implementação e erros da ferramenta **TIR (Totva Interface Robot)**?  
   
 **Ambiente**

Microsiga Protheus - a partir da release 12.1.17.  
**Solução**

O **TIR - Totvs Interface Robot** - é uma ferramenta open source para utilização do cliente efetuar testes de automação no Protheus.

Este atendimento não é efetuado no suporte padrão de atendimento ao ERP Microsiga Protheus, qualquer dúvida de utilização podem ser consultados os documentos na página do **GITHUB** ou mesmo postar as dúvidas através do canal **GITHUB**, da opção **Contact** (conforme abaixo) ou direto no link : **[totvs-tir/General](por%20se%20tratar%20de%20uma%20ferramenta%20opensource,%20%20esse%20%C3%A9%20o%20meio%20de%20comunica%C3%A7%C3%A3o)**
