**Requisitos da Etapa Padrão**

O cadastro dos requisitos no perfil de vaga, tem como objetivo filtrar os candidatos na pesquisa de uma seleção de público interno. Na pesquisa, quem tiver os requisitos definidos no perfil de vaga, permanece na seleção.

**Observação:**

A lista de requisitos para a vinculação deve ser filtrada pela função definida no perfil de vaga. Cada função possui uma lista de competências, que por sua vez possui uma lista de requisitos.
