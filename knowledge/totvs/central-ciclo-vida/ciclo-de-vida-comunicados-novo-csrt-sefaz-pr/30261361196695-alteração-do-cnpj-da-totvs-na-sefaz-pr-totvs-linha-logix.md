A TOTVS, sempre comprometida em garantir maior controle, efetividade dos processos e aos negócios de seus clientes, está adequando **seus produtos e serviços** para atender às exigências do novo [Código de Segurança do Responsável Técnico - CSRT](https://sped.fazenda.pr.gov.br/NFe/Pagina/CSRT), conforme determinação da Secretaria da Fazenda do Estado do Paraná (SEFAZ-PR).

A SEFAZ/PR fixou que o prazo para atender as adequações necessárias para essa determinação é **01/04/2025.**

Para atender essa exigência, estamos realizando a troca do CNPJ do produto Logix na SEFAZ/PR: 

|  |  |
| --- | --- |
| De CNPJ: | Para CNPJ: |
| **53.113.791/0006-37** | **53.113.791/0017-90** |

Em função disso, solicitamos que **você** realize as seguintes ações para manter seu ambiente operacional:

1) Solicitar Autorização de Uso com a TOTVS (considerando o novo CNPJ -**53.113.791/0017-90**) no portal da SEFAZ/PR.

2) **Abrir um ticket para a equipe de CST-Serviços Jurídicos**, via email: [servicosjuridicos.cst@totvs.com.br](mailto:servicosjuridicos.cst@totvs.com.br),  com o título “Cadastro de Linha de Produtos (CSRT)” para: solicitar o vínculo com o **novo** CNPJ, indicando o produto Logix.

Não deixe para última hora! A não execução destas ações poderá acarretar no bloqueio de emissão e transmissão de NF-e e NFC-e a partir de 01/04/2025.

Recomendamos que realize as ações listadas acima até o dia **17/03/25.**

O **pacote contendo a atualização do CNPJ do responsável técnico** estará disponível em nossa Central de Downloads a partir de **11/03/25**. Para acessar o pacote, consulte os links abaixo:

* [Logix 32 bits](https://suporte.totvs.com/portal/p/10098/download#detail/1188845)
* [Logix 64 bits](https://suporte.totvs.com/portal/p/10098/download#detail/1188846)

|  |
| --- |
| **Este comunicado é válido para os clientes que utilizam TSS - **Transmissão de Documentos Eletrônicos** para emissão de NF-e.**  **Para os clientes que utilizam TOTVS Colaboração (Neogrid), não há necessidade de realizar o procedimento.** |

Estamos à disposição para esclarecer qualquer dúvida. Basta entrar em contato com nossa equipe de CST ([servicosjuridicos.cst@totvs.com.br](mailto:servicosjuridicos.cst@totvs.com.br)).
