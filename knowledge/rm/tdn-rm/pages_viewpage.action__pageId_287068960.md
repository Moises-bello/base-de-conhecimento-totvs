# GERAÇÃO DE PLANO DE AULA CONSIDERANDO CARGA HORÁRIA COMO HORAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Gera Plano de Aula |
| **Situação/Requisito:** | Ao gerar um plano de aula com uma disciplina de 60h, com aula de 0:50 minutos, era pra ser gerados um total de 72 planos de aulas, quando marcados na tela do processo a opção "NÃO ULTRAPASSAR A CARGA HORÁRIA DA DISCIPLINA" e também estiver marcado o Parâmetro Educacional | Secretaria: “Considerar a carga horária da disciplina como horas”.  Só estava gerando 60 planos de aula, considerando aula de 1:00 h |
| **Solução/Implementação:** | Correção na rotina de geração de plano de aula para gerar corretamente a quantidade de planos de aula, de acordo com tempo da aula, utilizando a opção de considerar carga horária da disciplina como horas. |
