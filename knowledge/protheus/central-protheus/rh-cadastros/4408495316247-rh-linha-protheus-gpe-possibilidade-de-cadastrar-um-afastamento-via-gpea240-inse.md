![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26492866305303) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Possibilidade de cadastrar um afastamento via GPEA240 inserindo horas de atestado, quando cliente não utiliza o SIGAPON.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - Todas as versões  
  
**Solução**Essa funcionalidade **é exclusiva do módulo Ponto Eletrônico**, não sendo possível via GPEA240 - lançamento de Ausências, a inclusão de um afastamento na SR8 de horas, **somente dia(s)**.  
  
No módulo de **Medicina**, via rotina **Atestado Médico**, é possível cadastrar o atestado de horas com o CID, porém seria apenas para inclusão, pois esse afastamento não refletiria no módulo de Gestão de Pessoas.  
  
No mais, **apenas uma melhoria** caberia nesse caso, para na rotina de Ausências, quando o cliente **não utiliza o SIGAPON**, seja permitido a inclusão de atestado em horas de afastamento.
