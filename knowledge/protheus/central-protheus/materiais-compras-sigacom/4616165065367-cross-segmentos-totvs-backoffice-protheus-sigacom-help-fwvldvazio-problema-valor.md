**Ocorrência**Ao incluir/alterar um usuário no Grupo de Compras (**MATA086**) apresenta o HELP

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4616068263575/mceclip1.png)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Compras - Todas as versões.  
  
**Causa**A causa desse HELP é devido tamanho diferente entre os campos que se integram.  
  
**Solução**Para correção do HELP basta deixar os campos abaixo com o mesmo tamanho:

AJ\_US2NAME

Y1\_NOME

AI\_USRNAME

AJ\_US2NAME
