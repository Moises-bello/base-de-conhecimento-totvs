# Lançamento - Boleto

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento Boleto |
| **Situação/Requisito:** | Quando o boleto é gerado pelo RM Classis Ensino Básico ou Superior, a troca da conta caixa deve ser realizada através do próprio RM Classis. Não pode ser utilizada a funcionalidade do Financeiro, que possui outra regra para a geração de boletos através do id. do boleto. |
| **Solução/Implementação:** | Otimização no processo de atualização de conta/caixa e data de vencimento de boleto quando o lançamento for gerado pelo RM Classis Ensino Básico ou Superior. Agora o sistema não deve possibilitar a utilização desses processos por realizar uma regra para a geração de nosso número de forma diferente. |
