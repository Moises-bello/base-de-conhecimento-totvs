Dúvida**Cadastro Cadastro Fabricante/Fornecedor tabela SA2.   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**O cadastro de  Fabricante/Fornecedor "SA2" dentro dos módulos de Comex  você pode definir  no campo **A2\_ID\_FBFN**se este cadastro se refere a um 1- Fabricante,  2- Fornecedor, 3- Todos, 4- Exportador ou 5 - Beneficiário.  Este campo fica dentro da aba Outros do cadastro de Fabricante/Fornecedor "MATA020".

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360056242513/mceclip2.png)

Para que seja utilizado com todas as opções no campo "**A2\_ID\_FBFN**" pode configurar com a opção 3 -Todos.
