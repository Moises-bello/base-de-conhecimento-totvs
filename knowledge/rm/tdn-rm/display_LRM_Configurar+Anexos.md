**Configurando Anexo:**

             Através da tela de Configurar Anexos podemos anexar actions secundárias em uma action principal.

falseConfigurando Anexo

**Configurando Anexos:**

Configurar AnexosEscopo

Escopo – Permite que a visualização da action seja restrita a um determinado perfil ou usuários. Por default sua visibilidade é concedida a todos.

Menus

Action | Grupo | Remover – Através destes botões é feita a manipulação das actions nos menus.

- Através do botão “Grupo” é possível criar uma nova opção no menu, com a finalidade agrupar outras Actions Anexas.

- Através do botão “Action” pesquisa as actions para serem inclusas.

- Utilizado para remover as actions e os agrupadores.

falseObservações:

- Só é possível a exclusão das actions criadas por usuários.

- Não é possível remover um agrupador sem antes remover suas opções de menu (filhas).

Relacionamento

Definimos as chaves de ligação da visão onde a action será carregada.

**Ativo** – Feita a inclusão da action automaticamente esta opção é marcada, caso queira desativar a action, desnarqye a opção.

**Obrigatório** - Quando marcada essa opção e a action for de inclusão de registros, a action será carregada automaticamente e seu preenchimento obrigatório

**Carregar Automaticamente** – Sempre que acessado a visão, onde foi associada esta action, o sistema a carregará automaticamente (Mas não será obrigatório seu preenchimento).

Campos do relacionamento com tipos diferentes

Caso os campos do relacionamento entre as Actions Mestre / Detalhe sejam de tipos diferentes, uma mensagem será apresentada ao usuário informando a impossibilidade de se adicionar àquela Action como anexo.

Adicionando uma Nova Action ao Menu

Selecione o botão "" para inserir uma nova action. Em seguida na tela "Pesquisar", localize a action desejada e selecione-a.

Adicionando um Relacionamento

Selecione o action incluída anteriormente e clique no botão "" para adicionar o(s) relacionamento(s).

Action Adicionada em Anexos

A action adicionada será visualizada em Anexos.

Adicionando um Grupo de Action

Selecione o botão "" para inserir um novo agrupador. Em seguida será aberta a tela "Adicionar Grupo". Atribua o nome ao novo grupo.

Adicionando uma nova action no grupo

Selecione o grupo criado anteriormente e clique em "" para adicionar uma action ao grupo. Em seguida na tela de pesquisar, localize a action desejada e selecione-a.

Grupo de Action Adicionado em Anexos

O grupo de action adicionado será criado em Anexos.
