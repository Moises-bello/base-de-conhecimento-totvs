**Dúvida**Como corrigir Help AVG0000185 ?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360094663453)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
  
**Solução**Verifique a data de Embarque informada no campo **W6\_DT\_EMB**,  caso esteja sendo informada uma data inferior no campo Data Contrat **WB\_DT\_CONT,** será apresentada a mensagem.  
Help("",1,"AVG0000185"  "Data da contratação menor que a Data de Embarque"
