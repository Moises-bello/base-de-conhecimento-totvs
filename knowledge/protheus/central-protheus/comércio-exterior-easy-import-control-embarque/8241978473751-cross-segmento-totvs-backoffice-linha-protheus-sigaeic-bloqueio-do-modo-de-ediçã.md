![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28511397837335) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Bloqueio do modo de edição campo **W6\_TIPOREG** com a opção **2 - DUIMP.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/28511374925719)**  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – Easy Import Control- a partir da versão 12.1.2310.  
  
**Solução**Ao selecionar a opção **2-DUIMP** no Desembaraço de Importação, automaticamente o campo **W6\_TIPOREG** ficará bloqueado para edição quando o processo tiver invoice vinculada, para que seja possível editar o campo  exclua a invoice do processo.
