| **Módulo:** | *ENADE* |
| **Função:** | *Geração do arquivo de alunos inscritos no ENADE* |
| **Situação/Requisito:** | *O processo de geração do arquivo atualiza o indicador de situação do aluno no ENADE e até esta versão só podia ser revertido editando-se os registros de cada aluno individualmente.* |
| **Solução/Implementação:** | *O Assistente de geração de arquivos agora pode ser parametrizado para "reverter o processo anterior".*  *O usuário deve selecionar os mesmos alunos para os quais foi gerado um arquivo incorreto e marcar o checkbox "reverter o processo anterior".* |
