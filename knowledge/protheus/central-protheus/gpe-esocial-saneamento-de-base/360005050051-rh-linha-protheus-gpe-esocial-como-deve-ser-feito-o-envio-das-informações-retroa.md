Dúvida**Como deve ser feito o envio das informações retroativas para o esocial quando a empresa não seguiu os prazos do governo?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para enviar eventos retroativos é premissa que o passo a passo da documentação abaixo tenha sido seguido caso seja uma nova filial e ainda não tenha sido realizado o envio das informações de carga inicial  
[RH - Linha Protheus - GPE - eSocial - Como integrar os eventos de uma nova Filial para ao TAF](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360028575974-RH-Linha-Protheus-GPE-eSocial-Como-integrar-os-eventos-de-uma-nova-Filial-para-ao-TAF)   
  
Para os eventos **não periódicos** existe a possibilidade de transmissão *Offline* do RH para o TAF nas rotinas de **Rescisão,** **Transferência e Férias**para isso, acesse as rotinas no SIGAGPE - outras ações - integrar com o TAF.  
Demais afastamentos já estão no GPE deverão ser incluídos de forma manual no TAF;   
  
Para as **alterações salariais**, **cadastrais e contratuais** não terá como enviar o registro retroativo, pois ao fazer a carga inicial dos eventos S-2200 e S-2300 o registro vai para o TAF com a situação atual do cadastro, ou seja, o evento S-2200/S-2300 vai estar com as ultimas alterações do trabalhador, pois já estava vinculado no cadastro do trabalhador no momento da carga inicial.

* Consulte o parecer detalhado da nossa **consultoria de segmentos** no *link*: <http://tdn.totvs.com/x/2YN9Fg>

**Importante:**  
O governo estabeleceu prazos para entrega de cada evento, o envio retroativo de informações pode acarretar em multas para a empresa.
