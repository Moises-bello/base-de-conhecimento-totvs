# ALTERAÇÃO GLOBAL DE EVENTOS PROGRAMADOS - COMPORTAMENTO INCLUIR - CENTRO DE CUSTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Alteração Global de Eventos Programados* |
| **Situação/Requisito:** | No processo de alteração global de eventos programados o campo ‘Utilizar Centro de Custo’ fica disponível para seleção mesmo quando a base não está parametrizada para trabalhar com centro de custo. |
| **Solução/Implementação:** | Verificado no Parametrizador se a opção "Utilizar Centro de Custo" está marcada, se sim, habilita o campo Centro de Custo no comportamento Incluir da tela de "Alteração Global de Eventos Programados". |
