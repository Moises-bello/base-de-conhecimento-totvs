## **02. SITUAÇÃO/REQUISITO**

 Quando a etapa de nota, possui fórmula associada, ao digitar nota de avaliação para um determinado aluno, o sistema salva corretamente a nota, porém, replica o valor igual 0 para todos os alunos da turma/disciplina.

## **03. SOLUÇÃO**

Otimizado o processo para que seja possível registrar nota de avaliação, apenas para o aluno que teve o valor inserido, quando a etapa possui fórmula associada.
