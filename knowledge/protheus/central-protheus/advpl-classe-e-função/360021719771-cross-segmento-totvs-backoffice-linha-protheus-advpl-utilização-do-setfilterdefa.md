Dúvida**Como realizar um filtro Default (**setFilterDefault**)  com um Browser de array com a Classe **FwBrowser**?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – ADVPL – A partir da versão 11.80  
  
**Solução**Não há como usar setfilterdefault em browse de array. Nesse caso o cliente deverá montar o array já filtrado.
