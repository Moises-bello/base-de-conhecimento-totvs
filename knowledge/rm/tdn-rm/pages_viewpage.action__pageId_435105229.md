**Base de Cálculo por Empreendimento**    
Esta opção é responsável por mostrar o resultado de uma Composição de Base de Cálculo.  
A tela é apenas de visualização e é possível conferir os seguintes campos:  
   
   
**Aba Identificação - Base de Cálculo por Empreendimento**  
   
**Empreendimento:**  
Identificador e Descrição do empreendimento que foi apurado.  
   
**ID do Andamento:**  
Identificador do Andamento da Obra que foi apurado.  
   
**Data Início:**  
Data de início do período da Apuração.  
   
**Data Fim:**  
Data de término do período da Apuração.  
   
**ID do Evento de Apuração:**  
Identificador e Descrição da Composição da base de Cálculo  
   
**Valor:**  
Resultado total da Composição da base de cálculo do empreendimento.  
   
**Observação:**  
O valor visto aqui é o resultado de uma Composição da Base de Cálculo. Caso a Base de cálculo seja parametrizada para considerar subunidades, o valor exibido por empreendimento será o somatório dos valores calculados para cada subunidade, sendo assim, se estiver parametrizado para considerar somente as subunidades vendidas, o somatório será apenas destas. O mesmo ocorrerá para os casos parametrizados para considerar apenas as subunidades distratadas.
