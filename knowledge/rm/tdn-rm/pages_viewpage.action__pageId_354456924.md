# Digitação de Notas e Faltas no Diário de Classe

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Digitação de Nota/Falta |
| **Situação/Requisito:** | Ao realizar a digitação de Faltas no Diário de Classe do Corpore.NET, é necessário atualizar a informação de Aulas dadas no cadastro de Etapa.  Quando essa digitação era feita em uma Turma/Disciplina gerenciada, era exibido uma mensagem informando que esta alteração não pode ser feita em uma turma gerenciada, e sim em uma gerencial. |
| **Solução/Implementação:** | Foi realizado uma alteração na réplica das informações de uma turma/disciplina gerencial, para as gerenciadas, tornando possível também esta réplica de informações quando elas são cadastradas diretamente em uma turma/disciplina gerenciada.  Nestes casos, as informações de Etapas, Plano de aula e Avaliações serão replicadas para as outras turma/disciplina gerenciadas e também a sua turma/disciplina gerencial. |
