| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT / TOTVS Educa Mobile |

| **Situação/Requisito:** | O cabeçalho dos sites que aparecem nos links externos do Educa Mobile quando acessado pelo browser estão cortados. |
| **Solução/Implementação:** | Foi realizado ajuste no TOTVS Educa Mobile e eduCONNECT, de maneira que ao acessar um link externo, seja possível retornar para o menu: Acadêmico. |
