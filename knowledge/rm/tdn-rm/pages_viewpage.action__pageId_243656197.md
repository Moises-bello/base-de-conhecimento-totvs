# SALVAR PERFIL DA FOLHA ANALÍTICA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Salvar perfil já existente na folha analítica* |
| **Situação/Requisito:** | Ao salvar um perfil que já existe na tela da folha analítica, na aba de seleção de coligadas a coligada selecionada não está marcada e a opção de "Usar Parametros especificos" tambem não está marcada. |
| **Solução/Implementação:** | Salvar um perfil já existente, sendo que a aba de seleção de coligadas deve permanecer com o perfil que já existia. |
