# Não exibir o tipo de Senha Preferencial para unidade pediatria no Toten

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Toten de Pronto Atendimento |
| **Situação:** | No toten de solicitação de senhas para unidades de atendimento pediátrica, era exibido o tipo de senha preferencial, porém todas as senhas para essa unidade são preferenciais. |
| **Solução:** | Alterado o sistema para permitir que algumas unidades de atendimento não tenham a opção de senha preferencial. |
