# Indicação Cliente/Fornecedor - Processo Seletivo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Processo Seletivo |
| **Função:** | Inscrição |
| **Situação/Requisito:** | Cliente informa que, ao realizar uma inscrição no novo portal do processo seletivo onde na forma de inscrição está marcada a opção "Indicação de cliente/fornecedor?", no portal vai ter a opção de informa código do fornecedor, porém se informa nesse campo o código do fornecedor o portal não finaliza a inscrição do candidato. |
| **Solução/Implementação:** | Foi realizado ajuste para permitir que ao incluir uma indicação, a inscrição possa ser finalizada de forma correta. |
