# BOLETO FIXO (HTML) PORTAL DO PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Boleto fixo (HTML) portal do processo seletivo* |
| **Situação/Requisito:** | *No TOTVS Processo Seletivo foi identificado que quando um processo seletivo utiliza um boleto em HTML, o sistema ao gerar o boleto, mostra na tela no cabeçalho do boleto o código do do banco como sendo o cadastro do banco no nosso sistema, não mostra o código FEBRABAN.* |
| **Solução/Implementação:** | *F*oi identificado que na montagem do boleto html o código utilizado pelo sistema realmente é o código do cadastro do banco em nosso sistema, sendo assim, foi feito uma alteração para que na montagem do boleto html o sistema sempre utilize o código FEBRABAN.** |
