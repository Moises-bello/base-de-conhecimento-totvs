# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Contabilização por Competência* |
| **Situação/Requisito:** | *Ao contabilizar uma parcela mensal, integrá-la ao lote zero, estorna-la e em seguida recontabilizá-la, o sistema verifica se aquela competência já foi contabilizada, porém como existe uma parcela mensal de estorno para aquela competência, o sistema entende que não é necessário contabilizar.* |
| **Solução/Implementação:** | Foi realizada otimização do processo de contabilização por competência, de forma a permitir a recontabilização de uma parcela mensal após uma operação de estorno do lote oficial. |
