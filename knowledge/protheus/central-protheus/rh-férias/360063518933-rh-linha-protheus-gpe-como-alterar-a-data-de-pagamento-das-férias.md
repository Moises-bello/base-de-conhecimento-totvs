**Dúvida**É possível alterar **data de pagamento** de férias no cálculo?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**  
A alteração da data de pagamento das férias é possível. Se o cálculo for executado pela rotina de **Férias - GPEM030**, altere a data diretamente no campo **Dt. Rec. Fer** no cabeçalho do cálculo, conforme imagem abaixo;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/14933102388503)  
  
  
Se o cálculo for executado pela rotina de **Férias Coletivas/Programadas - GPEM060**, nos parâmetros de cálculo, informe sim no campo **Dt Pagto Informada?** e no campo **Dt Pagto Fer. Prog,** informe a data de pagamento conforme necessidade;  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/14933466724503)  
  
**Observação:** Este procedimento não é válido para postergar o pagamento para o 5° dia útil, apenas para antecipar o pagamento das férias. Para postergar para o 5° dia útil, segue documentação específica abaixo  
[Pagamento de Férias no 5° dia útil do mês subsequente](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360045055114-RH-Linha-Protheus-GPE-MP-927-2020-Como-efetuar-o-calculo-das-ferias-com-pagamento-no-5%C2%BA-dia-%C3%BAtil-dos-m%C3%AAs-subsequente)
