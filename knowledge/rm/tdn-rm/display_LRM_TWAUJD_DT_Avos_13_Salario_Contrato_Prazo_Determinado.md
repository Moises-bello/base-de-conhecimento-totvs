# AVOS 13 SALARIO CONTRATO PRAZO DETERMINADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias Portal* |
| **Situação/Requisito:** | Quando o 13o. salário é calculado para funcionários com contrato por prazo determinado, está sendo considerado avos até dezembro, quando deveria contar somente até a data final do prazo. |
| **Solução/Implementação:** | Quando o 13o. salário é calculado para funcionários com contrato por prazo determinado, não estava sendo considerado avos até dezembro, quando deveria contar somente até a data final do prazo.  Verificação de vínculo da RAIS para pagamento de avos de 13º até dezembro. Validar o vínculo RAIS, se for  4 - Trab. temporário, regido p/ lei 6.019 de 03.01.74  5 - Contr. trab. p/ CLT, p/ tempo determ. ou obra certa  9 - Contr. trab.Prazo Determinado (Lei 9601 de 21.01.1998),  entende-se que é Contrato de Experiência portanto não pagará até Dezembro |
