# Objetivo:

---

       O objetivo deste documento é trazer uma visão de como funciona a tela de Configurações do TReports.

# Introdução:

---

       Na tela de Configurações é possível editar o Servidor de Licença e habilitar os botões "Geração de Log" e "Parâmetros/Filtros" no Visualizador de Relatórios.

falseConfigurações TReports1Servidor de Licença

       Nas configurações de **Servidor de Licença**, para editar as informações, basta informar os campos:

***Endereço IP:*** Informe o IP do servidor de licença.  
       ***Porta:***Informe a porta do servidor de licença.  
       ***CNPJ:***Informe o CNPJ para consumo da licença.

false

A licença é consumida ao gerar ou agendar a geração de um relatório. Para isso, é necessário informar um Servidor de Licença válido.

Certifique-se de que seu Servidor de Licenças está ativo clicando no botão "Testar Conexão".

Será necessário informar um CNPJ válido para salvar alterações.

Obs:

    Na versão 12.1.29, patch 198, o CNPJ passa a ser opcional apenas para empresas estrangerias, podendo ficar vazio ou inserir outro tipo de registro.
