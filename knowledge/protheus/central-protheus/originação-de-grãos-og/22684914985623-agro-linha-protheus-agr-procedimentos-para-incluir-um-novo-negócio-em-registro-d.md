![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22684922151063) Tempo aproximado para leitura: **00****:01:00 min****Dúvida**Quais são os **Procedimentos para incluir um novo negócio em Registro de Negócio**?  
  
**Ambiente**TOTVS Agro – TOTVS Agro – Comercialização (Linha Protheus) - Originação de Grãos (OG) – Versão 12  
  
**Solução**  
Para solucionar essa dúvida, siga os seguintes passos:  
  
**Para incluir um novo negócio:**

**1.** Selecione **Incluir** na tela principal. O Sistema apresenta a tela para facilitar a inclusão;

**2.** Preencha os dados solicitados. Selecione **Ok** para utilizar a inclusão facilitada ou cancela para descartar;

**3.** Preencha os dados conforme orientação do *help* de campo. Veja os principais campos no tópico **[Principais Campos](https://tdn.totvs.com/pages/editpage.action?pageId=485869656#RegistrodeNeg%C3%B3cio-PrincipaisCamposprincipaiscampos)**;

**4.** Confira os dados e confirme a inclusão. Os dois *status* ficarão como pendentes e na cor **Vermelha**.  
  
**Para confirmar um novo negócio:**

**1.** Verifique pois, será necessário receber aprovação do **Cliente e Aprovação** do negócio e assim gerar contrato com *status* previsto e a situação do negócio mudar para aprovado na cor **Verde**;

**2.** Veja os principais campos no tópico: [**Principais Campos**](https://tdn.totvs.com/pages/editpage.action?pageId=485869656#RegistrodeNeg%C3%B3cio-PrincipaisCamposprincipaiscampos);
