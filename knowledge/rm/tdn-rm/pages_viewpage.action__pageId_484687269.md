**Tipo de Movimento de Pedido de Material para Faturamento Direto:**

Tipo do movimento para contratos a pagar: Define o tipo de movimento para geração de pedidos de faturamento direto para contratos a pagar;

Tipo do movimento para contratos a receber: Define o tipo de movimento para geração de pedidos de faturamento direto para contratos a receber;

**Adiantamentos e Retenções de Contratos (Somente integrado com BackOffice Protheus)**

Liberar Adiantamentos ou Retenção:

**Titulo Financeiro a Pagar/Receber:**Define que ao enviar o Adiantamento/Retenção para o BackOffice Protheus será gerado um titulo financeiro a pagar/receber;

**Pedido de Compra/Venda:** Define que ao enviar o Adiantamento/Retenção para BackOffice Protheus será gerado um pedido de Compra/Venda.

**Obs.:** Os campos de "Tipo de movimento contratos a Pagar/Receber" serão automaticamente alterados para o tipo de movimento correto para geração do pedido ou titulo financeiro.

Quando estiver parametrizado como "Pedido de Compra /Venda" será possivel rastrear o movimento gerado no anexo de contrato "Retenções Contratuais"

Porem quando estiver parametrizado como "Titulos Pagar/Receber" a integração EAI2 não contempla a funcionalidade de rastreabilidade.

**Adiantamentos (Somente integrados com BackOffice RM)**

**Tipo de movimento contratos a Pagar:** Define o tipo de  movimento utilizado para geração do movimento de adiantamento a Pagar.

**Produto Padrão Contratos a Pagar:** Informar produto padrão para geração de adiantamentos do tipo de mão de obra.

**Tipo de movimento contratos a Receber:**Define o tipo de  movimento utilizado para geração do movimento de adiantamento a Receber.

**Produto Padrão Contratos a Receber:** Informar produto padrão para geração de adiantamentos do tipo mão de obra.
