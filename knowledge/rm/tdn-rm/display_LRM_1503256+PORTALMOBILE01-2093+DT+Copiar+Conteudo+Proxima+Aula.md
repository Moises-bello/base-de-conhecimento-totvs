# COPIAR CONTEÚDO PARA A PRÓXIMA AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Copiar conteúdo (previsto/realizado) para próxima aula |
| **Situação/Requisito:** | Quando o professor copiava o conteúdo previsto ou realizado para a próxima aula o sistema copiava para a próxima aula mesmo, independente se a aula era ministrada por outro professor. |
| **Solução/Implementação:** | Ajuste para quando o professor for copiar o conteúdo (previsto ou realizado) para a próxima aula, copiar para a próxima aula do professor naquela turma disciplina. |
