O Gerador de Saída é uma ferramenta criada para exportar dados de qualquer módulo da linha RM.

Quando se fala em layout refere-se a organização. Definir o layout de um escritório por exemplo é organizar as mesas e armários da melhor maneira possível para que se possa aproveitar o espaço da sala. No caso de rotinas legais, layout é um arquivo que define a organização das informações solicitadas: ordenação, hierarquia, formato de dados e formato de arquivo.

Sempre que se trabalha com exportação de informações deve-se definir um layout para auxiliar na leitura das mesmas por uma pessoa ou um outro sistema.

Com o uso da ferramenta foram disponibilizados no book do Gestão Financeira alguns relatórios e layouts importantes para o gerenciamento e controle de fluxo de dados, entre eles temos o "[Livro Caixa Produtor Rural -LGPD](https://tdn.totvs.com/x/ZUI9I)" .

Temos também layouts que seguem o padrão da  "Ermst & Young" para extração de dados de modo que se obtenha informações sobre contas em apoio à auditoria do demonstrativo financeiro.  Essa extração de dados facilitará a auditoria das informações financeiras de um cliente para garantir que o mesmo esteja de acordo com as normas e leis brasileiras, garantindo a idoneidade do mesmo.

* FINLAY0068 - Exportacao de Contas a Receber - ErnstYoung
* FINLAY0069 - Exportacao de Contas a Pagar - ErnstYoung
