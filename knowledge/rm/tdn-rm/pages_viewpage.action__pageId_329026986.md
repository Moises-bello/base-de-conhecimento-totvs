# Exibição de boleto em PDF no Histórico Financeiro do Corpore.NET

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Gestão Educacional |
| **Módulo:** | Educacional |
| **Função:** | Exibição de boleto em PDF no histórico financeiro |
| **Situação/Requisito:** | Na tela de Histórico Financeiro, ao clicar no ícone de boleto para a sua exibição, não era possível visualizar o documento em PDF dentro da Modal que aparece na tela.  Em alguns casos onde o browser do usuário não suporta essa exibição, o sistema realiza o download automático do boleto para a máquina do usuário. Nesses casos, o usuário continuava visualizando a mensagem de "Aguarde", mesmo o download do arquivo já ter sido realizado. |
| **Solução/Implementação:** | Foi corrigido o problema que impossibilitava a exibição dos arquivos PDF dentro do Modal que é exibido ao clicar no ícone de boleto em computadores que estavam aptos a exibirem esse documento.  Já para os computadores que possuem browsers que não tenham o suporte ou plugin para exibição de arquivos PDF, é exibida uma mensagem de alerta dentro do Modal para o usuário, informando que não foi possível exibir o boleto e que o download irá ser realizado automaticamente. |
