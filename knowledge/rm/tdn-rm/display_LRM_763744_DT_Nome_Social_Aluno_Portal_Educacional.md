# NOME SOCIAL DO ALUNO NO PORTAL EDUCACIONAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Nome Social do aluno no Portal Corpore.NET |
| **Situação/Requisito:** | Mesmo parametrizado para ser exibido o nome social de alunos que possuem esta informações preenchida, alguns pontos do portal educacional do Corpore.NET exibiam o nome civil ao invés do nome social. |
| **Solução/Implementação:** | Foi realizado as alterações para que fossem exibidos o Nome Social no Portal do Aluno no Corpore.Net.  O processo de Geração de Usuário também levará em consideração o nome social no momento da geração do usuário, caso isso esteja parametrizado. |
