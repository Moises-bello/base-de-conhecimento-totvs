****01. DADOS GERAIS****

|  |  |
| --- | --- |
| Linha de Produto: | RM |
| Segmento: | BackOffice |
| Módulo: | Gestão Fiscal |
| Função: | Rotina Estadual DMA-BA |

**02. SITUAÇÃO/REQUISITO**

Ao gerar a Rotina DMA-BA e selecionar a opção "Inscrição Única", a   
Rotina seja gerada agrupando as informações por Inscrição Estadual da Filial Selecionada.

**03. SOLUÇÃO**

Melhoria na Rotina DMA-BA para quando o campo:  
OBRIGAÇÃO DE PREENCHIMENTO DE CS-DMA esteja marcado com a opção  "Inscrição UNICA"  
o sistema gere o Arquivo com os dados consolidados por Inscrição Estadual da Filial selecionada.
