**Dúvida**  
Como compilar os arquivos .TRP dentro do meu repositório?

**Ambiente**  
Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 12.1.2310

**Solução**  
Para compilar arquivos com extensão .TRP, é necessário configurar as extensões no Visual Studio Code. Abra as configurações do usuário (Ctrl + Shift + P, selecione "Open User Settings JSON") e adicione a extensão .TRP às configurações JSON, na lista de extensões suportadas para compilação.
