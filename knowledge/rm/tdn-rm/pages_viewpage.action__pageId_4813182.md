BLOCK

Não existe quantidade de produto na cotação a ser gerada

FAQ: **Não existe quantidade de produto na cotação a ser gerada**

|  |  |
| --- | --- |
| Produto: | Unspecified |
| Ambiente: | Unspecified |
| Versão: | 11.00 |

Sintoma

* **Sintoma**

Não existe quantidade de produto na cotação a ser gerada

Causa

* **Causas**

1- A quantidade efetivada é maior que a quantidade solicitada.

2- O parâmetro “Permite Cotação Parcialmente Gerada” está marcado nos parâmetros da cotação, mas o item não foi marcado para gerar Ordem de Compra dentro da Cotação, (caminho / Editar cotação/ ícone “Composição /Itens de Movimentos).

Solução

* **Solução**

1- Dentro do quadro comparativo de compras, dar um “duplo clique” na linha do item e do fornecedor para em seguida verificar se a “Qtd. Efetivada” é maior que a “Qtd. Solicitada”, se for não será possível gerar Ordem de Compra para o item em questão.

2- Se o parâmetro “Permite Cotação Parcialmente Gerada” estiver marcado o item a ser gerado para a Ordem de Compras deverá ser marcado no caminho / Editar cotação/ ícone “Composição /Itens de Movimentos. Lembrando que esta opção só estará disponivel a partir do momento que o quadro comparativo de compras estiver marcado.
