![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19275924484375) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como realizar o cadastro de Escala e Grau de Importância?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Avaliação Pesquisa e Desempenho – Todas as versões  
  
**Solução**O cadastro de escalas e/ou grau de importância são utilizados na [classificação de habilidades](https://centraldeatendimento.totvs.com/hc/pt-br/articles/19261588786583) e na criação de alternativas e questões.  
  
Um exemplo de utilização deste conceito é **na avaliação de cursos**, onde, para várias questões, são utilizadas as mesmas alternativas.  
  
Exemplo de Escala

|  |  |  |
| --- | --- | --- |
| Código | 01 | |
| Descrição | Pontuação | |
| Tipo | Escala | |
| Item | Descrição | Valor |
| 01 | Ótimo | 100 |
| 02 | Regular | 70 |
| 03 | Ruim | 10 |

  
Exemplo de Grau de Importância:

|  |  |  |
| --- | --- | --- |
| Código | 02 | |
| Descrição | Importância 01 | |
| Tipo | Grau de Importância | |
| Item | Descrição | Valor |
| 01 | Alto | 3 |
| 02 | Médio | 2 |
| 03 | Baixo | 1 |

  
O exemplo acima demonstra a importância do conhecimento de uma determinada habilidade para um cargo.  
  
**Para cadastrar habilidades acesse o módulo 53 - SIGAAPD > Clique no menu Atualizações > Cadastros > Escala e Grau de Importância > Clique em Incluir e preencha os dados:**
