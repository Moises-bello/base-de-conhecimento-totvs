**Dúvida**  
É possível ter acesso a ***Carol/Clock-in*** através do **Meu RH**?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – Todas as versões  
  
**Solução**  
Hoje no Meu RH há possibilidade de acessar um atalho para o ***Clock-in*** através do Smartphone.  
Este botão terá validade somente se, o funcionário tiver os dois aplicativos instalados no Celular.  
  
Acesso via menu **Ponto →** ***Card*** **Ponto via** ***Clock-in***  
![7688 - 1.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/19362095593623)  
  
  
No primeiro acesso em seu smartphone é direcionado para a Loja para realizar o download e instalar o Aplicativo **TOTVS RH** ***Clock-in Mobile*****: Reconhecimento facial**  
  
Obs.: É necessário permitir ao aplicativo acesse as principais funcionalidades do smartphone.  
![7688 - 7.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/19362121883031)  
  
Para saber mais, acesse [**TOTVS RH CLOCK IN BY CAROL**](https://tdn.totvs.com/x/vMF3I).
