# MENSAGEM COM COMPROMISSO NO eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Gestão Educacional |
| **Módulo:** | eduCONNECT |
| **Função:** | Adicionar mensagem como compromisso do eduCONNECT |
| **Situação/Requisito:** | Como usuário do eduCONNECT, é necessário ter uma opção de adicionar uma mensagem ou enquete recebida ao calendário do dispositivo, para conseguirmos assim agendar um lembrete caso necessário. |
| **Solução/Implementação:** | Foi criada a opção de adicionar evento na edição da mensagem, que possibilita a criação de um compromisso no calendário do dispositivo Android ou iOS, de forma que o título e descrição do evento referem-se ao assunto e corpo do texto da mensagem/enquete. Por padrão, o compromisso tem duração de 1 hora e possui lembrete de 15 minutos antes do evento. Após a adição do compromisso, o usuário poderá editar o compromisso como bem entender, alterando datas, lembretes e horários. |
