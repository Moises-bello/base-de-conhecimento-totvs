**Ocorrência**  
Ao enviar a SEFIP apresenta o seguinte erro : 180086 código CNAE inválido, verifique se o campo está preenchido corretamente.  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Causa**  
Esse erro ocorre pois no programa da SEFIP no cadastro da empresa não existe o código CNAE que está informado no sistema.

![](https://totvssuporte.zendesk.com/attachments/token/wozBCkLsN756vxnpJbLvWxNhL/?name=inline-309357413.png)

**Solução**

Verifique se o código cadastrado condiz com que está no programa da SEFIP.
