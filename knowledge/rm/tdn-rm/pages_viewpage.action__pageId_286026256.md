# Integração Bancária - Remessa de Pagamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Integração Bancária - Remessa de Pagamento |
| **Situação/Requisito:** | Hoje o sistema contempla 3 opções do campo “Aviso de credito ao fornecedor” no cadastro de pagamento de integração bancária. No manual Febraban tem mais outras opções de aviso ao fornecedor. O cliente solicita que seja verificado analise para implementação das opções restante que consta no manual. |
| **Solução/Implementação:** | Melhoria no cadastro de remessa de pagamento. A melhoria foi adicionar outras opções de avisos no campo “Aviso de credito ao fornecedor” de acordo com o manual Febraban.  Opções:   * 0 - Não emite Aviso * 2 - Emite aviso para o Remetente * 5 - Emite aviso para o Favorecido * 6 - Emite aviso para o Remetente e Favorecido * 7 - Emite aviso para o Favorecido e 2 vias para o Remetente |
