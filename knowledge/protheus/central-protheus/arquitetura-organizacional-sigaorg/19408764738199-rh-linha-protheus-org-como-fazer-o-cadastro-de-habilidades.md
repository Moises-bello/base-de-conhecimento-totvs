**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19408758256535) Tempo aproximado para leitura: 00:03:00 min** **Dúvida**Como realizar cadastro de habilidades no modulo arquitetura organizacional  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Arquitetura Organizacional – Todas as versões  
  
**Solução**Sobre o cadastro de habilidades, esta rotina **permite efetuar o cadastro/manutenção de todas as funções exercidas pelos colaboradores de uma empresa**.   
  
O sistema possibilita ainda que sejam **relacionados os cursos necessários para cada função**. Desta forma, **ao gerar uma** **Necessidade de Treinamento**, o sistema **verifica os cursos necessários tanto para o cargo quanto para a função de um colaborador.**
