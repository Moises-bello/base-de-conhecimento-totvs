# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO PATRIMONIAL |
| **Versões:** | 12.1.15 e superiores |
| **Ocorrência:** | Integrar Aquisições Compras |
| **Ambiente:** |  |
| **Passo a passo:** | Este módulo tem como objetivo integrar compras de imobilizados realizadas pelo sistema de Compras/Estoque (RM Nucleus) com o Sistema de Gestão Patrimonial, cadastrando os imobilizados e preparando os mesmos para cálculos de depreciação, inventario etc. Este processo envolve itens de notas fiscais que ao serem integrados, irão gerar patrimônios no sistema de Gestão Patrimonial.  **Regras na Integração de Compras:**  Para que seja realizada a correta integração do Totvs Gestão de Compras com o Totvs Gestão Patrimonial, deve ser realizada uma prévia parametrização. Assim, o sistema irá integrar os Itens da Nota (Ativos Imobilizados) conforme desejado.  -Caso esteja utilizando formula no processo de integração, acesse os parâmetros do Tipo de Movimento utilizado nas aquisições de Ativo Imobilizado, os campos da **Etapa – Patrimônio**, devem está corretamente preenchidos.  Observação : O sistema possibilita utilizar duas formulas distintas, uma para o campo ( valor de aquisição ), que será preenchido com  (formula valor do Bem).   É outro (valor base de depreciação), que será preenchido com (formula valor de depreciação do Bem).       * **Integrar RM Bonum:**   Para realizar a integração deve selecionar a opção 'Compra de Imobilizado'.   * **Localização (Compra Ativo Imobilizado):**   Se desejar informar a localização do Patrimônio deverá preencher com a opção “Edita”, caso contrário, o campo deve ser preenchido como “Não Edita” de forma que o campo não será apresentado na inclusão do item de movimento.   * **Fórmula Valor do Bem, e/ou Formula Valor de Depreciação do Bem**   Esta informação deve ser preenchida quando o usuário optar em fazer a integração no “TOTVS Gestão Patrimonial” considerando que o valor do Patrimônio no Bonum deve ser o valor de retorno desta fórmula.  -Acesse o movimento e verifique se os Produtos dos itens do movimento possui a aba Integração com os campos (Grupo de Contas e Grupo de Bens) preenchidos.      **Realizando a Integração de Compras:**  Disponível através do menu **Utilitários | Integrar Aquisições Compras**.  Para que seja realizada a correta integração do Totvs Gestão de Compras com o Totvs Gestão Patrimonial, deve ser realizada uma prévia parametrização. Assim, o sistema irá integrar os Itens da Nota (Ativos Imobilizados) conforme desejado.  Na primeira etapa de parametrização é necessário optar pela data de emissão ou data de entrada/saída da nota. O sistema irá realizar a integração considerando a data selecionada para o campo Data de Aquisição.  Como opção, pode ser definido o número do documento e o intervalo de data das notas, ou uma data apenas se preferir, repetindo a data nos dois campos (Como default é apresentado o período patrimonial em aberto). A próxima etapa de parametrização permite o usuário selecionar as filiais cujos dados serão processados, o tipo de movimento sendo possível selecionar apenas tipos de movimentos que são referente à integração do sistema de Compras com o sistema de Gestão Patrimonial e o Cliente\Fornecedor que deseja buscar as informações.    Obrigatoriamente deve selecionar as notas a serem integradas. Serão exibidas para seleção apenas as notas que obedecem à parametrização anterior:    Posteriormente poderá selecionar uma das opções abaixo definido assim a descrição do Patrimônio:      **Tipos de campos**     * **Descrição do patrimônio**   **Nome Fantasia** Ao marcar esta opção, o campo descrição do cadastro do patrimônio receberá o conteúdo do campo Nome Fantasia, informado no cadastro do produto.  **Descrição do Produto**Ao marcar esta opção, o campo descrição do cadastro do patrimônio receberá o conteúdo do campo Descrição, informado no cadastro do produto.  **Histórico do Item**Ao marcar esta opção, o campo descrição do cadastro do patrimônio receberá o conteúdo do campo Histórico, informado no item de movimento.  **Nome Fantasia do Produto + Histórico do Item** Ao marcar esta opção, o campo descrição do cadastro do patrimônio receberá o conteúdo do campo Nome Fantasia, informado no cadastro do produto, mais o conteúdo do campo Histórico, informado no item de movimento.  **Descrição do Produto + Histórico do Item** Ao marcar esta opção, o campo Descrição do cadastro do patrimônio receberá o conteúdo do campo Descrição, informado no cadastro do produto, mais o conteúdo do campo Histórico, informado no item de movimento.    **Considerar para o valor de aquisição:**   * **Preço unitário:** O **Preço Unitário** do item do movimento será utilizado para preenchimento do campo onde for selecionado. (TITMMOV.PRECOUNITARIO) * **Valor unitário:**O **Valor Unitário** do item do movimento será utilizado para preenchimento do campo onde for selecionado. (TITMMOV.VALORUNITARIO) * **Valor Financeiro:** O **Valor Financeiro** do item do movimento será utilizado para preenchimento do campo onde for selecionado. (TITMMOV.VALORFINANCEIRO) * **Fórmula Valor do Patrimônio:** Os valores calculados à partir das fórmulas definidas nos parâmetros do TOTVS Gestão de Estoque, Compras e Faturamento, calculados durante a inclusão do Movimento, serão utilizados para preenchimento do campo onde for selecionado. (Valor de Aquisição = TITMMOV.VALORBEM; Valor Base de Depreciação = TITMMOV.VALORBASEDEPRECIACAOBEM) * **Utilizar Responsável:**   Ao marcar esta opção, o campo de Responsável abaixo desta flag ficará disponível para edição, onde deverá filtrar e selecionar o cadastro de um [Responsável](https://tdn.totvs.com/pages/viewpage.action?pageId=317312488) previamente cadastrado e parametrizado no módulo Gestão Patrimonial. Esta informação será registrada no cadastro do patrimônio na aba Dados Adicionais.     * **Incluir patrimônio mantendo as quantidades informadas nos Itens da Nota**   Ativando esta opção ao realizar a integração com Compras o sistema manterá os patrimônios agrupados, realizando apenas um único cadastro para o patrimônio no sistema de Gestão Patrimonial. Os patrimônios gerados no sistema de Gestão Patrimonial terão a quantidade exatamente igual à quantidade informada para o item na nota fiscal.  Não ativando esta opção o sistema desmembrará as quantidades dos itens da nota criando um cadastro para cada unidade do item e, neste caso, o valor da quantidade de cada item será sempre arredondado, gerando sempre patrimônios com quantidade inteira, observando a seguinte regra: para quantidades menores que 0,50 será gerado no mínimo 1 patrimônio com quantidade igual a 1 unidade, de maneira que cada item da nota gere pelo menos 1 patrimônio correspondente no sistema de Gestão Patrimonial.  Exemplos:  A NF 1001 possui 10 unidades do item "Cadeira com Encosto". Ao realizar a integração, caso você marque esta opção, o sistema de Gestão Patrimonial criará apenas 1 cadastro de patrimônio contendo 10 unidades da cadeira. esta opção o sistema de Gestão Patrimonial criará 10 cadastros contendo cada um, 1 unidade de cadeira.  A NF 1002 possui: 1,50 unidades do item "Ferro" 0,37 unidades do item "Aço" 0,74 unidades do item "Alumínio"  Ao realizar a integração, caso você marque esta opção, o Sistema de Gestão Patrimonial criará 3 patrimônios com as mesmas quantidades de cada item da nota:  "Ferro"        quantidade = 1,5 "Aço"          quantidade = 0,37 "Alumínio"   quantidade = 0,74  Caso você desmarque esta opção, o Sistema de Gestão Patrimonial desmembrará os itens e criará 4 patrimônios sempre com quantidade inteira:  "Ferro"      quantidade = 1 "Ferro"      quantidade = 1 "Aço"        quantidade = 1 "Alumínio"   quantidade = 1     * **Gerar código do bem e do patrimônio automaticamente**   Marcando esta opção o sistema irá gerar o código de bem e o código do patrimônio automaticamente respeitando sempre o grupo Default cadastrado no Grupo de Patrimônios do patrimônio. Caso contrário a integração ficará pendente para edição no menu Integrar Aquisição Pendente.     * **Considera a falta do Grupo de patrimônios como erro**   Esta opção funciona como uma segurança para você realizar sua integração sem erros. Ao marcá-la o sistema irá conferir se todos os produtos da nota fiscal que você está integrando estão com seus grupos de contas cadastrados. Caso algum patrimônio não esteja com o Grupo de patrimônios cadastrado o sistema NÃO integrará nenhum patrimônio desta nota. Caso você opte por não marcá-la o sistema fará a integração dos demais patrimônios da nota, exceto dos patrimônios que não tiverem seu Grupo de patrimônios cadastrado no sistema de Compras. Na dúvida sobre o cadastro de Grupo de patrimônios nos patrimônios faça a integração com esta opção marcada. Ou então não deixe de conferir o arquivo de Log gerado pelo sistema mesmo que não tenha dado nenhum erro na integração.  Com esta opção desmarcada você poderá integrar parcialmente as notas fiscais, isto facilitará quando você possuir uma nota fiscal contendo alguns itens do ativo imobilizado e outros não. Desta forma você poderá integrar apenas os itens necessários.  Exemplo:  Nota 029 Item 01: Mesa 10 X 15     (Grupo de patrimônios 02) Item 02: Teclado Troni      (Grupo de patrimônios 03) Item 03: CD virgem Sony Item 04: Jogo de copos.  Com esta opção desmarcada somente os itens 1 e 2 serão integrados por possuírem Grupo de patrimônios, caso contrário esta nota não será integrada devido à falta do Grupo de patrimônios nos demais itens.  Lembre-se que os Movimentos integrados terão uma mensagem de identificação no sistema de Compras, neste caso a mensagem aparecerá normalmente, porém somente dois itens foram integrados. E você não poderá mais alterar nenhum registro neste movimento.     * **Gerar o código do patrimônio a partir do título do patrimônio definido no produto**   Com esta opção o Sistema de Gestão Patrimonial vai pegar o default de Grupo de Patrimônios direto dos cadastros de produto no RM Nucleus e não mais o default informado em "Cadastros Grupo de Patrimônios" do Sistema de Gestão Patrimonial.         * **Trazer o rateio de centro de custo do item de movimento para o rateio gerencial do Patrimônio**   Esta opção permite que o rateio de centro de custo do Item do movimento seja preenchido no patrimônio. **Vale ressaltar que  todas as opções que cita ITEM, refere se ao itens apresentados dentro do movimento, conforme imagem abaixo, ou seja, informar o rateio de centro de custo dentro do Movimento.**         * **Trazer o centro de custo do item da nota para o patrimônio**      * **Trazer o departamento do item da nota para o patrimônio**   Estas opções permitem que o Centro de Custo e Departamento do Item do movimento | Identificação | Aba Tabelas, seja preenchido no cadastra de patrimônio | Dados Adicionais | Centro de Custo e Departamento.              * **Trazer o tipo do documento para o patrimônio**   Para que estes dados sejam trazidos o Tipo de Movimento no RM Nucleus deve ser parametrizado da seguinte forma:  Em Ambiente | Parâmetros | Tipos de Movimento, na etapa Fis - Escrituração 1/2 | Tipo de Documento Escrituração | Código Default | Edite o documento informado | Dados Adicionais | Informe o nº do código do modelo do documento que você deseja utilizar na integração. O código que você escolher estará amarrado a um código de Tipo de Documento que será utilizado no campo Tipo de Documento do cadastro de patrimônio do RM Bonum.         * **Adicionar histórico do item no campo Observação do patrimônio**   Para que este campo seja preenchido, acesse os parâmetro do sistema Gestão de Estoque (RM Nucleus), edite o movimento de integração (Bonum) etapa **Item - Campos Livres 2/2**,  marque a opção EDITA.         * **Recurso opcional que permite a composição de patrimônios:**   [Construir patrimônios a partir dos itens da nota](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Composicaopatrimonio.aspx)  Não será possível marcar essa opção quando for selecionada mais de uma nota fiscal. O sistema exibirá a mensagem:  “Para utilizar recurso construir patrimônio a partir dos itens da nota é necessário selecionar uma nota por vez".  Quando a opção “Construir patrimônio a partir dos itens da nota” estiver marcada, as opções “Incluir patrimônio mantendo as quantidades informadas nos itens da nota” e "Considera a falta do grupo de patrimônio como erro" ficarão desabilitadas, pois estas informações poderão ser preenchida no momento da constituição do novo patrimônio.  O processo de construir patrimônio possibilita manipular as informações para criação do patrimônio. Por exemplo : Campo descrição | Unidade | Quantidade | Grupo de Patrimônio | Responsável | Observação | Valor  Aquisição | Valor Base Depreciação.        **Observação:** Para alterar os campos | Quantidade | Valor  Aquisição | Valor Base Depreciação. Deve ser alterado no campo em verde conforme abaixo:        - Possibilita selecionar mais de um Item para criar somente um patrimônio, como por exemplo :  O movimento possui 4 Itens.  Teclado ====== 100,00 Mouse =======20,00 Monitor ======300,00  Ao selecionar as 3 notas, informa a descrição por exemplo Computador, e clicar em Construir patrimônio, o sistema irá construí somente um patrimônio   Computador  ==== 420,00.   - Possibilita quebrar os patrimônio pela quantidade desejada, Exemplo: possui um Item com a quantidade 4,        Atenção:  Ao integrar o Sistema de Gestão Patrimonial com o sistema de Compras/Estoque, o sistema estará validando se o patrimônio está com o título inativo, ou seja, se no sistema de Compras estiver utilizando um Grupo de patrimônios que possui um título inativo no Sistema de Gestão Patrimonial, não irá  possibilitar a integração.  Após realizar as parametrizações desejada para integração, observe que serão  gerados o códigos de patrimônio conforme título informado no item do movimento.       **Observação:** - Após a integração dos bens, o sistema não fará cálculos de depreciação automaticamente. O usuário terá que disparar os cálculos.  **Exclusão de Patrimônio originado do Gestão de Compras:** Ao realizar exclusão de patrimônios originados do Gestão de Compras, o sistema irá automaticamente excluir todos registros vinculados aquela nota. |
