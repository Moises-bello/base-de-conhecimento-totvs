**Dúvida**  
O que deve ser analisado quando ocorrer o erro: O evento S-1280 não foi enviado. Verifique a na tabela S037 se a empresa está configurada com recolhimento sobre o faturamento?  
  
**Ambiente**  
TOTVS RH - (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**  
Para o erro mencionado ao realizar a geração do evento S-1280, acesse **atualizações - definição cálculo - manuntenção de tabelas - S037.**  
Caso o campo Recolher S/Faturamento estiver como N, o sistema gera a mensagem no log informando que o evento não será gerado.  
Para o sistema realizar a geração, **o campo Recolhe S/Faturamento** deve estar com preenchimento **S.**  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/34377911412759)**  
  
**Após alteração na tabela S037, realize novamente a geração do evento S-1280.**
