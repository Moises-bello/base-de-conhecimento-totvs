# ECF Layout 2018 - Alteração de Layout

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Geração da ECF |
| **Situação/Requisito:** | Layout ECF 2018 - Alteração de Layout  Alterar o Layout da ECF para gerar conforme a versão 0004. |
| **Solução/Implementação:** | Foi adicionado o Campo 33 - IND\_DEREX no registro 0020 do Layout da ECF.
