| **Ocorrência:** | Bloqueio/Desbloqueio de Lotes |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**  **Bloquear** um lote significa colocá-lo sob o domínio de um determinado usuário, tornando-o indisponível aos outros usuários.   * Qualquer usuário, desde que tenha permissão em seu perfil para esta ação, pode bloquear um lote para seu uso. * Quando um lote estiver bloqueado com um determinado usuário, na janela principal onde se tem uma visão geral dos lotes cadastrados, o nome do usuário ficará relacionado ao lote em questão.   Um exemplo de utilização do bloqueio de um lote seria quando um usuário precisa conferir um lote e enquanto realiza esta conferência, deseja que ninguém acesse o mesmo.  Assim, até terminar a tarefa, o lote ficará bloqueado com o usuário que realizou o processo.  Já o **desbloqueio** dos lotes tem por objetivo, então, desbloquear os lotes que estejam bloqueados com usuários, seja porque o usuário que o bloqueou já finalizou o uso desejado, seja porque o lote permaneceu bloqueado indevidamente, tornando-o disponível novamente para o uso de outros usuários.   * O desbloqueio só pode ser executado pelo próprio usuário com o qual o lote está bloqueado ou por um usuário que tenha perfil de Supervisor.    **Parametrização Necessária:**  1 - Para realizar o processo de **Bloquear Lote**, acesse o menu **Escrituração Contábil/Lotes**, selecione o lote desejado e clique no menu **Processos/Bloquear Lote**:      2 - Caso o lote não seja selecionado inicialmente na visão de lotes, selecione os lotes que serão bloqueados através do processo, podemos informar na lista de lotes selecionados um ou mais lotes para serem bloqueados.  Informe um motivo para o bloqueio deste lote no sistema. Esta informação é obrigatória para que o lote seja bloqueado:        3- Ao clicar no botão **Executar**, os lotes selecionados serão bloqueados pelo usuário que está executando este processo.   * Enquanto um lote estiver bloqueado, nenhum processo poderá ser executado para este lote, nem mesmo pelo próprio usuário que o bloqueou. * O lote também ficará bloqueado caso haja diferença entre Débitos e Créditos.     1- Para realizar o processo  de **Desbloquear Lote/Lançamentos**, acesse o menu **Escrituração Contábil/Lotes**, selecione o lote desejado e clique no menu **Processos/Desbloquear Lote/Lançamentos**:      2 - Caso o lote não seja selecionado inicialmente, selecione os lotes que serão desbloqueados através do processo. Podemos informar na lista de lotes selecionados, um ou mais lotes para serem desbloqueados:      3- Ao clicar no botão Executar, os lotes selecionados serão desbloqueados pelo usuário que está executando o processo. |
