# Seleção de relatórios nos parâmetros do Portal Educacional

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Parâmetros de Relatórios |
| **Situação/Requisito:** | Ao marcar ou desmarcar as opções contidas no ListBox de relatórios disponíveis, que seriam exibidos no portal do aluno, as opções não eram de fato alteradas corretamente na base de dados. (Configurações > Parâmetros > RM Portal > RM Portal - Gerais) |
| **Solução/Implementação:** | Foi alterado uma propriedade do componente ListBox que altera a forma de identificação e pesquisa dos itens selecionados, de busca binária para o tipo padrão, sem pesquisa binária. Tornando a identificação dos registros marcados de forma correta. |
