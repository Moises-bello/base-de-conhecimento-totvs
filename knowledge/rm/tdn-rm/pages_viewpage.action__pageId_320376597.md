# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Novo modelo de contabilização por competência |
| **Situação/Requisito:** | Ao gerar contabilização por competência, utilizando o novo modelo de contabilização, informando uma data de contabilização na tela do processo, o sistema não aplica a data de contabilização informada nos lançamentos contábeis gerados pela operação contábil. |
| **Solução/Implementação:** | Foi realizada otimização do processo de contabilização por competência (novo modelo), de forma que, ao preencher a data de contabilização na tela do processo, essa data de contabilização seja levada para os lançamentos contábeis gerados pela operação. |
