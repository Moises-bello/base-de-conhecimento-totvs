# Cadastro de Eventos Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro de Eventos Contábeis |
| **Situação/Requisito:** | Ao abrir uma tela de cadastro de evento contábil por exemplo no modulo financeiro e na sequencia mudar para o modulo de estoque e na tela que foi aberta de evento editar qualquer evento retorna mensagem "Valor inválido para o campo Processo" pois o contexto em que a tela foi aberta é diferente do atual contexto, porém essa mensagem não é intuitiva. |
| **Solução/Implementação:** | Melhoria na tela de cadastro de Eventos Contábeis para que a mesma identifique se o contexto na qual a tela foi aberto é diferente do contexto em que o sistema se encontra no momento de incluir/salvar alguma modificação. |
