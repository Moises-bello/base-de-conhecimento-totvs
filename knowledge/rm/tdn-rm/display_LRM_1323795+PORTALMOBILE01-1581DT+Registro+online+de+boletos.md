# EXTRATO FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Registro online de boletos na visão de extrato financeiro(Portal do aluno). |
| **Situação/Requisito:** | Ao acessar a visão de extrato financeiro no portal do aluno, quando o sistema estava parametrizado para permitir o registro online de boletos, todos os boletos eram registrados automaticamente ao acessar a visão. |
| **Solução/Implementação:** | Após ajuste o boleto só será enviado para registro quando o aluno clicar na emissão do boleto(via portal). |
