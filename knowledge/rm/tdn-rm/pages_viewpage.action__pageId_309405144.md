| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.17 |
| **Ocorrência:** | Cópia de Orçamentos |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**   ---   Este processo permite copiar orçamentos já existentes no sistema, para que seus valores sejam utilizados em orçamentos de outros períodos ou gerar novos orçamentos a partir de valores obtidos na movimentação de contas que possuam orçamentos.  Quando o usuário escolhe como origem do novo orçamento, o orçamento anterior, o sistema irá copiar todos os dados já informados para o novo orçamento, tendo o usuário a opção de alterar os dados de filial, departamento e centro de custo, se o orçamento anterior foi lançado, por exemplo, para apenas uma filial este pode ser copiado alterando-se a filial a cada cópia feita para preencher os orçamentos nas filiais anteriormente não informadas.  Já quando é feita a opção pela movimentação da conta, o sistema irá retornar os valores realizados na mesma dentro de um determinado período, podendo também ser feita a alteração de filial, departamento e centro de custo a cada cópia executada.  **DESENVOLVIMENTO/PROCEDIMENTO:**  **1 - Acesse o caminho Orçamento/Cópia de Orçamentos:**              **2 - Na tela de informação de dados informe os campos Ano de Origem, Novo Ano e se desejar os Novos Dados para os **Orçamentos**:**                                                **3 - Na tela seguinte poderão ser alterados os campos filial, departamento e centro de custo, para o novo orçamento:**                                                **4- Quando a origem dos novos orçamentos informada for Movimentação da Conta, o sistema abrirá os campos data inicial e final a fim de que possa calcular o valor da movimentação, conforme abaixo:** |
| **Observações:** | A cópia do orçamento somente poderá ser realizada escolhendo as opções: Orçamento Anterior ou Movimentação da Conta, caso a empresa realize este processo mais de uma vez, mesmo alterando a origem dos novos orçamentos e informando os mesmos campos em: Novos Dados para o Orçamento, o sistema irá apresentar a mensagem de erro, endo chave duplicada. |
