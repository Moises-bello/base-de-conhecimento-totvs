|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |

| **Situação/Requisito:** | *Ao editar os campos complementares disponíveis no registro de matrícula no período letivo pela primeira vez uma mensagem de erro era retornada. Vale ressaltar que a mensagem era exibida, porém não impedia a gravação do registro.* |
| **Solução/Implementação:** | *Ajuste no carregamento dos campos complementares e gravação no banco de dados, evitando que uma mensagem de erro seja exibida ao editar o registro pela primeira vez.* |
