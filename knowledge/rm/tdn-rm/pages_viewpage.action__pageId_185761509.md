Os serviços do Corpore RM com as funcionalidades para utilização do TOTVS | HTML Framework estarão disponíveis em 2016. No momento versões controladas serão disponibilizadas para as equipes de Segmentos envolvidas no projeto de Experiências de Uso

Versão

 Disponível à partir da versão 12.1.6 da linha RM.

A Experiência de Uso #8 consiste na unificação das interfaces no Fluig utilizando o [TOTVS | HTML Framework](http://tdn.totvs.com/display/tec/TOTVS+%7C++HTML+Framework)

Requisitos para **testes** do **Corpore RM** com o [TOTVS | HTML Framework](http://tdn.totvs.com/display/tec/TOTVS+%7C++HTML+Framework):

* Leitura e entendimento do [TOTVS | HTML Framework](http://tdn.totvs.com/display/tec/TOTVS+%7C++HTML+Framework)
* [TOTVS | Developer Studio](http://tdn.totvs.com/display/tec/Developer+Studio) versão mínima 11.3
* [Plugin](http://tdn.totvs.com.br/display/tec/3.+IDE) do TOTVS | HTML Framework instalado no **TOTVS | Developer Studio**
* RM Host com o serviço RMSRestDataServer ativado (procurar equipe de Framework)
* Baixar a aplicação centralizadora (html-app) do [TOTVS | HTML Framework](http://tdn.totvs.com/display/tec/TOTVS+%7C++HTML+Framework) e copiar os diretórios do pacote no diretório virtual do **IIS** ou no diretório webapps do **TomCat**
