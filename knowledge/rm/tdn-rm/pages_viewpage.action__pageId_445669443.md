# Guia de INSS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Guia de INSS |
| **Situação/Requisito:** | Ao calcular a 2ª parcela para o funcionário, e logo em seguida, em outro período realizar a demissão do mesmo, o sistema lança os códigos de cálculos 371 - SEGUNDA PARCELA 13º LICENÇA MATERNIDADE no período 3 e o 373 - 13º RESCISÃO LICENÇA MATERNIDADE PROVENTO no período 10. Ao gerar as de INSS Normal e INSS 13º Salário, o valor esta sendo deduzidos nas 02 guias. |
| **Solução/Implementação:** | Corrigido o erro na Guia de INSS que deduções de 13° do salario maternidade eram considerado na Guia de INSS normal. |
