# Vincular publicação no complemento da disciplina

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Corpore.Net |
| **Função:** | Vinculação de publicação ao complemento da disciplina |
| **Situação/Requisito:** | O processo de vinculação de publicação não desconsiderava docentes demitidos |
| **Solução/Implementação:** | Durante o processo de vinculação de publicação a um complemento de disciplina validamos se o docente é um funcionário e só considera o mesmo se a situação do funcionário não seja demitido, caso o docente não seja um funcionário ( não possua integração com o Labore ) validamos a situação do docente junto a vinculação do docente com a filial (anexo de professor). |
