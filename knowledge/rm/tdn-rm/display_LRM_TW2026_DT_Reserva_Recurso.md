# RESERVA DE RECURSO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Reserva de Recurso* |
| **Situação/Requisito:** | *Na reserva de recursos ocorre erro de choque de horário entre o horários iguais do fim e início de um mesmo recurso. Exemplo: recurso reservado em 19:00 as 19:50 e se tenta reservar o recurso em 19:50 as 20:40, ocorre choque.* |
| **Solução/Implementação:** | *Ajuste na reserva de recursos para que não ocorra choque de horário entre o horários iguais do fim e início de um mesmo recurso. Exemplo: recurso reservado em 19:00 as 19:50 e se tenta reservar o recurso em 19:50 as 20:40.* |
