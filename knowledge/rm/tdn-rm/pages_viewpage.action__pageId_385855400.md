# TRANSFERÊNCIA DE EXEMPLARES ENTRE FILIAIS / UNIDADES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Bibliotecária* |
| **Função:** | *Transferência de exemplares entre filiais / unidades* |
| **Situação/Requisito:** | *Ao realizar a transferência de exemplares das Publicações, o sistema não estava considerando o parâmetro *"Utilizar número do tombo por tipo de publicação"*, ao realizar a transferência pra outra filial, por já existir o número de tombo na filial destino mesmo que em tipo de publicação diferente, uma exceção era levantada e era preciso gerar um novo código de tombo para o exemplar transferido.* |
| **Solução/Implementação:** | *Foi realizado um ajuste no processo "Transferência de exemplares entre filiais / unidades", para ser considerado os parâmetros "Utilizar número do tombo por tipo de publicação" e "Utilizar número do tombo global".* |
