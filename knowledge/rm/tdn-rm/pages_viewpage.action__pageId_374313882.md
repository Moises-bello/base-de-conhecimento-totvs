# MONTA/DEFAZ KIT - Carregar itens do Kit

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Monta/Desfaz Kit |
| **Situação/Requisito:** | O sistema somente lista os itens que compõem o kit após sair do campo e somente lista a segunda grid após sair do campo Procedimento. |
| **Solução/Implementação:** | Realizado o ajuste para que os itens que compõem o kit sejam listados ao selecionar o kit e ao sair do campo.    Os itens que são controlados por lote ou por número de série, aparecerão na segunda grid com um tom amarelo na célula correspondente |
