**Tabela de Preços**

O cadastro de Tabela de preços é responsável por atribuir valores de venda as subunidades dos Empreendimentos. Através da parametrização do módulo Incorporação é possível utilizar múltiplas tabelas de preço para atribuir valores de uma mesma subunidade de um empreendimento.

**Pré-condições:**  
1- Ter Parametrizado o sistema para a utilização de Múltiplas Tabelas de Preço ou não.

2- Ter permissão de acesso e para incluir Tabelas de Preço.

3- Ter incluído um Empreendimento com suas respectivas Unidades e Subunidades.

4- Ter incluído uma Modalidade de Venda.

**Incluindo uma nova Tabela de Preços**

**Passo 1**- Acesse: TOTVS RM/ Projetos/ Incorporação(SGI)/ Cadastros/ Manutenção de Empreendimentos/ Tabela de Preços 

**Passo 2-** O sistema exibirá a janela de filtros. Se não deseja criar um filtro ou não houver nenhuma tabela de preços cadastrada, clique em [Fechar]. 

**Passo 3-** Se algum filtro foi executado, os registros de tabela de preço cadastrados serão exibidos. Clique em [Incluir] 

**Passo 4-** Será exibido o formulário de cadastro de Tabelas de Preço. Preencha os campos conforme desejar e clique em [Salvar]. Os campos do formulário são:

**Aba Identificação**

**• Número da Tabela de Preço** - Número que será atribuído a tabela de preços. Campo com capacidade para 10 dígitos numéricos

**• Versão da Tabela de Preço** - Número da versão qual a tabela de preços se encontra

**• Número da Tabela de Preço de Origem** - Se a tabela de preços não for da versão 1, o campo será preenchido automaticamente com o número da Tabela de Preços que a originou através da execução dos processos de Gerar Preço e Reajustar ou Importação de Planilha Excel

**• Descrição da Tabela de Preço** - Nome da tabela de preços. Campo preparado para receber até 50 caracteres.

**• Código do Empreendimento** - Empreendimento qual suas subunidades poderão ter o preço atribuído.

**• Modalidade de venda** -  São as regras estabelecidas para que um contrato de venda possa contemplar uma subunidade que utilize esta tabela. As regras são aplicadas ao plano de financiamento.

**• Preço Por Metro Quadrado**

**• Preço Base** - Preço de Referência para a venda de um imóvel

**• Data de Início de Vigência** -  Data inicial da Validade de uma tabela de preços. A partir desta data é possível gerar Contratos de Venda utilizando  a tabela.

**• Data de Término de Vigência** - Data final da Validade de uma tabela de preços. A partir desta data não será possível gerar Contratos de Venda utilizando  a tabela.

**• Detalhe da Tabela de Preço** - Informações da tabela de preço.

**• Situação da Tabela de Preço** - Situação qual a Tabela de preços se encontra.

* + Em preparação
  + Efetivada
  + Cancelada
  + Revogada

**• Tipo de Tabela de Preços** - Campo habilitado para seleção apenas se o sistema estiver parametrizado para a utilização de Múltiplas Tabelas de Preço.

* + Padrão
  + Secundária

**• Portal** - Checkbox responsável por informar se pertence ao Portal Web.

Importante!

Para fins de histórico, o sistema só permite a exclusão de tabelas Em Preparação, sejam elas do Tipo Padrão ou Secundária.

**Aba Reajuste**

Os dados da aba Reajuste são preenchidos automaticamente ao executar o processo Reajustar Tabela de Preço.

**• Percentual Fixo** -  Percentual de Reajuste das subunidades da Tabela de Preço se for efetuado um Reajuste por Percentual

**• Valor Fixo** -  Valor fixo estabelecido de Reajuste das subunidades da Tabela de Preço se for efetuado um Reajuste por Valor Fixo

**• Símbolo** - Moeda ou índice utilizado no reajuste. Preenchido apenas se for efetuado um Reajuste por moeda

**• Data Inicial** - Data de início para cálculo do reajuste

**• Data Final** - Data final utilizada no cálculo do reajuste

**• Cotação Inicial** - Cotação que foi utilizada inicialmente, que deve coincidir com a Data Inicial

**• Cotação Final** - Cotação que foi utilizada no fim. Deve coincidir com a Data Final
