# DocumentServiceRest Data Type

Documents

Properties

| name | data type | description |
| --- | --- | --- |
| maxUploadSize | [Response](https://api.fluig.com/old/json_Response.html) | Get the max upload size parameter |
| uploadURL | [Response](https://api.fluig.com/old/json_Response.html) | Get the user upload url    In Fluig the upload process is done in two steps:    1. User get URL of the repository link; 2. With the URL, he sends the file and uploads it.  Important informations: Some information have to be set in request header for upload.    1. Authorization: Is an information group required for server confirmation that you are really you. More information: <http://www.w3.org/Protocols/rfc2616/rfc2616-sec14.html> 2. Content-Type: Example: "image/jpeg", "application/xml", "application/ms-word"... 3. Accept: "application/json"; 4. companyId: User's Company id . More information: <http://yourserver/api/public/ecm/drive/config;> 5. userId: User's id. More information: <http://yourserver/api/public/ecm/document/loggedUser;> |
| chunkedUploadURL | [Response](https://api.fluig.com/old/json_Response.html) | Get the chunked upload url With this URL it is possible to send chunked parts of one file, instead the entire file. |
| ~~loggedUser~~ | ~~[Response](https://api.fluig.com/old/json_Response.html)~~ | ~~Get information the user logged~~ |
| Properties inherited from [GenericBean](https://api.fluig.com/old/json_GenericBean.html) | | |
| errorHandler | [ErrorHandler](https://api.fluig.com/old/json_ErrorHandler.html) |  |
