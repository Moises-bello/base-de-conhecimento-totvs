**Dúvida**Por que o cálculo de rescisão por justa causa não apresenta o ID 0017?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O cálculo de rescisão por justa causa não apresenta ID 0017, devido a configuração tipo de rescisão em tabela S043 (acesso tabela: Definições de Cálculo/Manutenção Tabelas). Para o tipo de rescisão por justa causa, deve conter N em FGTS mês Rescisão, assim o cálculo apresenta o ID 0017.
