Dúvida**Foi gerado um contrato no **FATA400** **-** **Contrato de Parceria**em que determinado item do **contrato** foi **faturado** em sua totalidade, porém, por uma necessidade que ocorreu, o cliente não aceitou **a semente da empresa** e fez uma **Nota de Devolução**. Foi gerada a entrada da **Nota de Devolução** vinculando a **Nota de Saída**, e desta forma o saldo voltou para o **estoque** da empresa, mas não voltou para o **contrato**. Qual é o procedimento que a empresa deve efetuar para que o **saldo volte para o contrato** e a nota seja emitida novamente?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - UBS - Unidade de Beneficiamento de Sementes - Versão 12  
  
**Solução**No produto padrão não existe um procedimento para fazer com que **o saldo volte para o Contrato de Parceria**. Para este caso o correto que é gerar um **Novo Contrato**.
