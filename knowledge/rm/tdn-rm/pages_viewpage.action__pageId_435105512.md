**Dados das parcelas dos componentes**

* **Valor de Venda:** Será o somatório das parcelas que sejam de componentes de tipos "1-Entrada" e "2-Principal".
* **Total de Juros:** Será o somatório das parcelas que sejam de componentes do tipo "3-Juros Fixo".
* **Total de CM:** Será o somatório das parcelas que sejam de componentes do tipo "4-Correção Monetária".
* **Outros valores:** Será o somatório das parcelas que sejam de componentes de tipos diferentes de "1-Entrada", "2-Principal", "3-Juros Fixo" e "4-Correção Monetária" , desconsiderando os componentes que sejam de tipo "a pagar".
* **Valor Devolução:** Será o somatório das parcelas de componentes que sejam de tipo "a pagar". Este campo estará disponível para customização do relatório e não estará visível no relatório oficial.
* **Valor de Venda Atualizado:** Será o somatório das parcelas que sejam de componentes de todos os tipos, desconsiderando os componentes que sejam de tipo "a pagar".
* **Total Pago:** Será o somatório dos valores pagos de componentes de todos os tipos, desconsiderando os componentes que sejam de tipo "a pagar".
* **Saldo Devedor:** Será o somatório das parcelas menos o somatório dos valores pagos de componentes de todos os tipos.
