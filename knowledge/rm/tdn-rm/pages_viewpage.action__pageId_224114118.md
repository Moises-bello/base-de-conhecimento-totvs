# Objetivo

O objetivo deste guia é apresentar as configuração e demonstrar a integração do ERP RM com o IDENTITY e FLUIG

# Pré Requisitos RM

Para que a integração seja realizada é necessário que o WebService do RM esteja exposto através do Serviço do Host e deve possuir um Alias default configurado.

Para mais informações de como expor o WebService do RM e configurar o Alias default basta seguir a documentação: [WebService RM](http://tdn.totvs.com/x/2rdbDQ).

# Criando Aplicativos RM no IDENTITY

Após configurar o WebService do RM é necessário realizar a criação dos App´s RM exe e RM Portal no IDENTITY.

Para mais informações de como criar os App´s do RM basta seguir a documentação: [Aplicação RM no IDENTITY](http://tdn.totvs.com/x/4btbDQ).

# Configurando a Integração

Após criar os aplicativos RM no IDENTITY é necessário configurar a integração

Para mais informações de como configurar a integração basta seguir a documentação: [Fluig OnClick](http://tdn.totvs.com/x/3b5bDQ)

# Executando o Sincronismo

Após configurar a integração execute o sincronismo.

Para mais informações de como executar o sincronismo basta seguir a documentação: [Sincronismo](http://tdn.totvs.com/x/18hbDQ).
