**Dúvida**  
Como consultar no *site* do eSocial dados do evento **S-2300** (Trabalhador Sem Vínculo de Emprego/Estatutário - Início)?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Esse evento está localizado no menu **Trabalhador sem Vínculo** após fazer *login* no [Portal eSocial](https://www.gov.br/esocial/pt-br). Para consultar os dados **do trabalhador**, o empregador deverá digitar o CPF completo do trabalhador para buscar seus dados.  
  
Caminho: **Trabalhador sem Vínculo > Gestão de Trabalhadores***:*  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17263031055767)*  
  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17262929235095)*  
  
*![](https://centraldeatendimento.totvs.com/hc/article_attachments/17267244492311)*  
  
**Observação:**

* Para conhecer o manual completo de navegação no *site* do eSocial acesse: <https://www.gov.br/esocial/pt-br/empresas/manual-web-geral>
* Não recomendamos **inclusão/alteração** manual no *site* do **eSocial** devido a prejudicar a integridade entre os dados do sistema e governo gerando erros futuro.
