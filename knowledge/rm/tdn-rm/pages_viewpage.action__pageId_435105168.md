Este processo é responsável por ler as Apurações Realizadas e processar sua devida Contabilização.

ObservaçãoEste processo pode ser executado para um ou mais empreendimentos simultaneamente, sendo que todos os selecionados para execução devem estar devidamente parametrizados. O sistema identifica automaticamente qual período deve ser contabilizado para cada empreendimento, considerando sempre o menor período Apurado. 

Para eventos contábeis que utilizam rateio gerencial, a origem da conta deve ser '**Rateio Dinâmico - Apuração Contábil**' para que o rateio seja aplicado corretamente.
