# IMPORTAÇÃO DE CANDIDATO A PARTIR DA SELEÇÃO DO RM VITAE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Avaliação e Pesquisa* |
| **Função:** | *Importação de candidato a partir da seleção do RM Vitae* |
| **Situação/Requisito:** | *Ao utilizar o processo de importação de candidato a partir da seleção do RM Vitae, não é retornado nenhum processo de seleção e nenhum candidato.* |
| **Solução/Implementação:** | *Foi identificado que este processo está obsoleto e não deve ser utilizado. Após a reestruturação do módulo de recrutamento no Totvs Gestão de Pessoas, a definição de provas para candidatos em processos de seleção deve ser feita diretamente pelo painel de seleção no módulo de recrutamento do Totvs Gestão de Pessoas.* |
