## Funcionalidades

Existem três funcionalidades principais: Tabela, Campo e Relacionamento.

### **Tabela**

Esta funcionalidade permite consultar entre as tabelas disponíveis no Metadados, seleciona-la e adicionar a Estrutura de Dados do modelo de negócio.

Nova Tabela ZMDMARCAS foi adicionada a estrutura de dados.

### Campo

Permite adicionar um novo campo na tabela selecionada.

O campo NOVO\_CAMPO foi adicionado a tabela ZMDMARCAS

### Relacionamento

Podemos criar um relacionamento entre duas tabelas, informando quais são as chaves entre as tabelas Filha e Pai.

Para mais informações sobre criar relacionamentos, [veja mais aqui](https://tdn.totvs.com/display/public/LRM/Criando+um+relacionamento+entre+tabelas+de+Metadados)
