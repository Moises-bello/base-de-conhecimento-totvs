**Dúvida**  
Como ajustar parametrização para gerar o evento S-2200 do GPE para o TAF, quando o sistema estiver emitindo a mensagem: S-2200 - não existem informações para serem geradas?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Para que ocorra a geração do evento S-2200 sem que ocorra a mensagem, **não existem informações para serem geradas** quando os dados dos colaboradores estiverem corretos, seguir procedimento abaixo:  
  
1.Verificar o complemento cadastral está configurado de acordo com o *link* a baixo:   
[TAF - SIGATAF - Complemento cadastral (TAFA050) - Amarração 1:1](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360043508233)  
[TAF - SIGATAF - Complemento cadastral (TAFA050) - Mudança da amarração de N:1 para 1:1](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360042996074)  
  
2.Após configurar novamente, revise as configurações do *link* abaixo para o envio do evento S1005:   
<http://tdn.totvs.com/display/PROT/eSocial+%7C+Protheus+-+Entregas+Legais+-+S-1005>
