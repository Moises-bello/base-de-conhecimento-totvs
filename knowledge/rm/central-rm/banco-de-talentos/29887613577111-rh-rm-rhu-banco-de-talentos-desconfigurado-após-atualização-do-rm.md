**Dúvida**  
Após atualizar a versão do RM, ao acessar o Banco de Talentos o mesmo é exibido desconfigurado, conforme imagem abaixo:   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29887613555479)  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - A partir da versão 12.1  
  
**Solução**  
Desde o dia 08/01/2025 o instalador do RM deixou de incluir o Banco de Talentos, pois este passou a contar com um instalador próprio.   
  
Tal informação esta disponível para sua validação em nossos canais de comunicação, inclusive no TOTVS News exibido ao acessar a MDI (sistema RM):   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29947916918295)   
  
Houveram algumas inconsistências na criação das pastas via instalador disponibilizado pela equipe de produto, mas este encontra-se ajustado e novos instaladores foram liberados.  
  
Seguem links da Central de Downloads >>> das versões 12.1.2402, 12.1.2406 e 12.1.2410, 12.1.2502, no qual poderão efetuar o download do instalador do **Banco de Talentos** para a respectiva versão que esteja utilizando:

**- 12.1.2402**:  <https://suporte.totvs.com/portal/p/10098/download#detail/1182526>  
**- 12.1.2406**: <https://suporte.totvs.com/portal/p/10098/download#detail/1182527>  
**- 12.1.2410**: <https://suporte.totvs.com/portal/p/10098/download#detail/1182528>  
- **12.1.2502**: <https://suporte.totvs.com/portal/p/10098/download?e=1191283>  
  
**Importante**

- Os instaladores do Banco de Talentos **não serão mais versionados a partir da versão 12.1.2506**. Portanto, poderão utilizar quaisquer um dos links compartilhados acima para sua correta instalação.   
- Após execução do instalador, é imprescindível limpar o cache do navegador utilizado para acesso ao **Banco de Talentos**.

- Caso o ambiente seja **N Camadas**, a instalação deverá ser realizada no **servidor principal**, onde existe o serviço do Host.
