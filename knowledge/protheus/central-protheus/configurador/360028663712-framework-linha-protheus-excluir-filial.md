**Dúvida**  
Como fazer para excluir uma Filial no Protheus?  
  
**Ambiente**  
Protheus - Configurador - Todas as versões  
  
**Solução**  
Para excluir alguma Filial, siga o procedimento abaixo:  
Obs.: é recomendável efetuar o backup do arquivo sigamat.emp (com os serviços parados)  
  
1. Acesse o Configurador  
2. Menu Ambiente > Empresas > Filial  
3. Selecione a Filial desejada e clique sobre ela  
4. Clique em Outras Ações > Excluir
