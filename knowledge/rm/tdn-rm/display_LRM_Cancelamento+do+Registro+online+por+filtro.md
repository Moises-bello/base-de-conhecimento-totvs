Processo permite realizar o [Cancelamento do Registro Online](https://tdn.totvs.com/display/LRM/Cancelamento+de+Registro+online) de boletos através de filtro selecionado em tela através do menu:  
Movimentações Bancárias | Integração Bancária | Processos em Lote | [Cancelamento de Registro Online Por Filtro](https://tdn.totvs.com/display/LRM/Cancelamento+de+Registro+Online+Por+Filtro).

Ao adentrar no processo, deverá preencher com um filtro que busque os boletos desejados para realizar o cancelamento do registro online;

O processo permite agendamento para execução recorrente.

O TOTVS Gestão Financeira disponibiliza dois modelos de cancelamento de registro:

Cards3Modelo de Registro Online v2

Processo disponível atualmente apenas para o (s) seguinte (s) banco (s):

* Itaú
* SICOOB
* Banco do Brasil. Obs: O cancelamento do registro poderá ser realizado após 30min do registro do boleto junto ao Banco. Caso tente cancelar antes deste prazo, o Banco poderá retornar uma mensagem com este aviso.

**Importante**: A opção de Modelo de Registro Online do [Convênio](https://tdn.totvs.com/pages/viewpage.action?pageId=421388845) deve ser selecionada como API 'v2'. 

4Modelo de Registro Online v3

Processo disponível atualmente apenas para o (s) seguinte (s) banco (s):

* SICOOB

**Importante**: A opção de Modelo de Registro Online do [Convênio](https://tdn.totvs.com/pages/viewpage.action?pageId=421388845) deve ser selecionada como API 'v3'.
