Quando tento imprimir uma etiqueta na rotina Wizard de Impressão ocorre o Help "NO\_IX Função de usuário não compilada no repositório".    
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19741892394775)  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) -Estoque/Custos - Todas as versões.  
  
**Solução**

Quando ocorre o Help "**NO\_IX Função de usuário não compilada no repositório**" é necessário fazer o seguinte procedimento.

* Compilar o Rdmake da impressora via VSCODE, segue abaixo o Rdmake de todas as impressoras.

* [Rdmake.7z](https://centraldeatendimento.totvs.com/hc/pt-br/article_attachments/360012935551) (10kB)
