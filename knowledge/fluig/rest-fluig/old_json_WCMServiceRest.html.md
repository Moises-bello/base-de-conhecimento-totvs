# WCMServiceRest Data Type

WCM core services

Properties

| name | data type | description |
| --- | --- | --- |
| ~~version~~ | ~~[Response](https://api.fluig.com/old/json_Response.html)~~ | ~~Get version of the system~~ |
| versionV2 | [Response](https://api.fluig.com/old/json_Response.html) | Get version of the system |

| theme | [Response](https://api.fluig.com/old/json_Response.html) | Display the current tenant theme. |
| configuration | [Response](https://api.fluig.com/old/json_Response.html) | Return system configuration information. Used by mobile application |
