Dúvida**

Como acessar a rotina de Cadastro dos Trabalhadores Autônomos para informar na Folha de Pagamento (S-1200 - RPA)?

**Ambiente**

TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF - Todas as versões

**Solução**

1 - Acesse o TAF (**SIGATAF**);

2 - Acesse a rotina **Trabalhador Autônomo (TAFA473)**  
Caminho: Atualizações -> Eventos eSocial -> Trabalhador -> Trabalhador Autônomo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25251701622679)

**Cadastrando o trabalhador autônomo para gerar a Folha de Pagamento (S-1200 - RPA)**

3 - Se precisar cadastrar o Trabalhador Autônomo no TAF, clique no botão **Incluir**:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/25251701629591)

4 - Preencha com os dados como CPF, Data de Nascimento e Nome do trabalhador, e, caso necessário, as informações da sucessão de vínculo trabalhista, conforme tela abaixo e em seguida **Confirmar**:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25251672149655)  
  
**Como consultar os registros:**

4 - Para acessar o período de apuração, acessa a barra de pesquisa e clique no ícone com 3 barras verticais e uma seta apontando para baixo:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360050081313)

5 - Clique na aba Coluna e veja as opções para realizar o filtro dos horários cadastrados:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049191534)

6 - Digite o valor que deseja procurar no sistema e clique na Lupa:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360050081333)

**Como separar os registros por status:**

7 - Para verificar qual(is) status o registros dos eventos estão, basta acessar documentação abaixo:

[TAF - FUNCIONALIDADES - Como verificar o status do evento para o e-Social](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360037818153)

**Como excluir o evento:**

8 - Selecione o evento que deseja excluir e vá em **Outras Ações > Excluir > Excluir Registro**. Para mais detalhes acesse a documentação abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25251701636247)

[Excluindo registros no TAF](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024544651-RH-Linha-Protheus-TAF-eSocial-FUNCIONALIDADES-Como-excluir-os-registro-do-eSocial)
