# Atividades Agendadas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Anexo de arquivos na reserva de instalação |
| **Situação/Requisito:** | Ao tentar consultar os arquivos anexos de uma reserva de instalação através da tela da agenda, ocorre a mensagem de não conformidade que impede o acesso.  *“Referência de objeto não definida para uma instância de um objeto.”* |
| **Solução/Implementação:** | Melhoria no acesso aos anexos da reserva de instalação através da agenda para que não seja apresentada nenhuma mensagem de não conformidade. |
