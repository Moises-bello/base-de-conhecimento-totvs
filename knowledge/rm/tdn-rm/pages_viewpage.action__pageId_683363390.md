## **02. SITUAÇÃO/REQUISITO**

O cliente deseja que os funcionários que foram demitidos possam ser readmitidos. Assim, o processo irá reaproveitar os dados dos registros anteriores para realizar a nova admissão, inclusive campos complementares.

Essa necessidade é bastante comum para contratação de funcionários em época de safra.

## **03. SOLUÇÃO**

Foi disponibilizado um processo onde permite que o usuário selecione funcionários demitidos para readmissão, reaproveitados os dados já existente na base e possibilitando colocar campos defaults e/ou alterar dados.

Exemplo:

O funcionário foi contratado por 3 meses e foi demitido, depois de alguns meses, a empresa precisa readmitidos para trabalhar em uma nova safra.
