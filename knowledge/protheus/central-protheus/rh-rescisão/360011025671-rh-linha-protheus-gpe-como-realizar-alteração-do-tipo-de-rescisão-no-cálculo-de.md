**Dúvida**Como fazer alteração do Tipo de Rescisão quando por determinação judicial é necessário o cálculo de rescisão complementar onde a rescisão original foi por justa causa e na complementar deverá ser pagas as verbas de uma rescisão sem justa causa?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.

**Solução**Na versão 12 não é possível alterar o Tipo de Rescisão no cálculo de uma rescisão complementar pois já foi enviado os dados da rescisão original para Sefip, CAGED, RAIS (se for rescisão de anos anteriores) e eSocial.

Para pagamento das verbas determinadas judicialmente, caso o cliente use o módulo de Processos Judiciais, pode ser feito o lançamento das verbas por ele para que seja gerado um título para pagamento e assim seja feita a contabilização,

Caso não seja usado o módulo de Processos Judiciais, esses lançamentos podem ser feitos direto pela Caixa, porém os valores não serão contabilizados.
