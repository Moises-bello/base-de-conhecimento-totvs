# Objetivo

---

        O objetivo deste documento é demonstrar como funciona a parametrização **Compartilhar a conexão dos Subscribers para acesso à tabela de controle de identificadores**, encontrada na aba **Configurações Públicas**, nos **Parâmetros Globais**.

# Como Funciona

---

       Caso habilitada, o sistema passa a compartilhar o *dbs*, com a intenção de diminuir o número de conexões ao banco de dados para obtenção de controle de identificadores (exemplo: acesso à *GAUTOINC*).

# Parametrização Padrão
