**Dúvida**Como sistema se comporta para calculo de salário família para semanalista?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O cálculo do salário família para semanalista será efetuado sempre na última semana de pagamento.

O Sistema valida todos os pagamentos para compor a base de salário família, ou seja, se em algum dos pagamentos o funcionário tiver direito ao benefício, mas na composição de todos os pagamentos a soma do salário for maior que o teto do salário família, o funcionário não receberá o benefício.

Verifique que para o funcionário que teve o Pagamento 01 a maior o sistema não trouxe o salário família em nenhum dos dois pagamentos, validando os dois pagamentos para a composição do cálculo:
