# Mensagem de enquete do eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Mensagens de enquete |
| **Situação/Requisito:** | Ao acessar as mensagens de enquete no eduCONNECT, o aplicativo estava permitindo responder/alterar a mesma enquete mais de uma vez, quando essa enquete fosse respondida em outro dispositivo do mesmo usuário. |
| **Solução/Implementação:** | Foi realizado uma ajuste no eduCONNECT, para não permitir que o usuário alterar/responder uma enquete que ele já tenha respondido, mesmo quando este usuário acessar outro dispositivo. |
