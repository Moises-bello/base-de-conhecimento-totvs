**Dúvida**  
O Sistema grava a data base na rotina ATFA036, considerando que foi realizado a baixa com data retroativa?   
   
 **Ambiente**  
Protheus – Contabilidade Gerencial – A partir da versão 11.80  
  
   
**Solução**  
Após realizar a baixa do bem do ativo fixo, com data retroativa dentro do próprio mês, respeitando a data do MV\_ULTDEPR, não é gravado em nenhum campo a data base do sistema. O sistema grava somente a data efetiva da baixa: N4\_DATA e N3\_DTBAIXA.
