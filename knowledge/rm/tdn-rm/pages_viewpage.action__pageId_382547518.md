# Serviço financeiro para geração do registro 1600 do Sped Fiscal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Serviços de dados para Sped Fiscal. |
| **Situação/Requisito:** | Lançamento gerado com forma de pagamento cartão de crédito ou cartão de débito foi faturado para N faturas que posteriormente são baixadas em meses distintos. Ao gerar o registro 1600 do Sped Fiscal para cada mês o sistema não deve considerar os lançamentos faturados mas sim os vencimentos de fatura. |
| **Solução/Implementação:** | Desconsiderar os lançamentos faturados na geração dos dados de pagamento com cartão para registro 1600 do Sped Fiscal. |
