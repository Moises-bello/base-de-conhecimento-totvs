# Acesso de coordenador ao portal acadêmico

|  |  |
| --- | --- |
| **Produto:** | Gestão Educacional |
| **Versão:** | 12.1.14 |
| **Processo:** | Permissão de funcionários/professores com perfil de Coordenador |
| **Data da publicação:** |  |

No portal corpore.net, os Funcionários e Professores cadastrados no sistema poderão executar o papel de Coordenador da Matriz Aplicada do curso, para este perfil o Coordenador terá acesso a todas as turmas/disciplinas que pertencem à mesma como se fossem professores destas disciplinas. Para está nova funcionalidade, o Coordenador poderá executar o papel de professor nos menus: Digitação de Notas de Avaliação, Digitação de Notas e Faltas, Cadastro de Avaliação, Digitação de Frequência Diária, Digitação de Plano de Aula, e Turmas Disciplinas do Professor.

Ao cadastrar o Coordenador na Matriz Aplicada, o usuário será obrigado a informar qual a função do novo coordenador; a função alocada neste campo, não determina o acesso ilimitado aos menus do portal, o mesmo só será permitido através do processo de geração de usuário (Serviços Globais) onde permite configurar o perfil do Coordenador.

A alteração executada pelo usuário Coordenador que não sejam nas turmas nas quais ele está vinculado como professor, serão armazenadas em um Log .

Serviços Globais | Segurança | Perfil | Acesso aos menus | Outras Permissões | Portal | Professor

Primeiramente, é cadastrado o perfil de coordenador, para ter acesso às funcionalidades no portal.
