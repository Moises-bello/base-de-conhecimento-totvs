Dear Customer,

 TOTVS products are in constant evolution to overcome challenges and follow each step of your company's digital journey.

For this reason, we inform you that **TBC via IIS****will no longer be expedited** in the RM installation package beginning on release 12.1.2302, which will be available for download starting **February 3, 2023**.

The existing integrations that use this solution must be **replaced by the use of TBC via Host**.

To all customers that use TBC via IIS, we suggest that you **perform the adjustment indicated** so that the integration is made via Host, since the solution has not been updated for security and technology in a while and, in the case of integrations, we must somehow avoid potential vulnerabilities and security issues with customers' environments.

Below, we clarify possible questions related to the **TBC integration via Host**:

**How can I use the TBC integration via Host?**

The adjustment in integration to use TBC via Host must be performed according to these instructions: <https://tdn.totvs.com.br/display/LRM/Web+Services>

***Important:*** To use the TBC integration via Host, it is still necessary to have the **TOTVS I license** (the same license acquired when the TBC integration via IIS was contracted.)

Should you need support to perform the integration adjustment, you can hire the TOTVS Service Team.

**What will happen if I do not adjust the integration up to the discontinuation date?**

You must plan to adjust the integration **before** the update to release 2302 because, when the update is finished, the integration via IIS will be lost.

**What will happen after the discontinuation date of the integration via IIS?**

Only the technical support will be maintained up to the end of the life cycle of the versions served by RM.

**Does any documentation exist to get to know the new integration?**

Click here <https://tdn.totvs.com/pages/viewpage.action?pageId=89620766> /

**Do I need to validate the integration via Host in my environment?**

To guarantee success in this process, we recommend that you validate the adherence and definition of specific configurations and new parameter settings, followed by test cycles.

We are available to solve any questions. Contact your ESN (Business Solutions Manager)!
