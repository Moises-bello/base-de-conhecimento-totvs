![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:14 min****Ocorrência**No módulo Folha de Pagamento, ao realizar a troca de seção no cadastro do funcionário é apresentado o seguinte o erro: **Valor inválido para o campo "seção".**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11633373753623)  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Causa**Esse incidente ocorre, pois está sendo realizada a troca de seção que contém CNPJ diferente do que o funcionário se encontra.   
  
**Solução**A troca de seção dentro do cadastro do funcionário somente será permitida pelo sistema quando for uma mudança para outra seção com o mesmo CNPJ. Para mudança de seção com CNPJ diferente do que o funcionário se encontra no momento será necessário realizar o processo de transferência entre coligadas ou filiais. Caso tenha dúvidas nesse processo, segue abaixo documentação orientando como realizar a transferência de um funcionário entre filiais ou coligadas.  
  
[RH - RM - FOP - Transferência entre filiais ou coligadas](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020186252?source=search)
