# Permitir exibir formatação HTML na linha digitável do TOTVS Educa Mobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educa Mobile. |
| **Função:** | Linha digitável por fórmula |
| **Situação/Requisito:** | Ao parametrizar a geração da linha digitável por fórmula no TOTVS Educa Mobile, e na fórmula tivesse o retorno formatado por tags HTML, o sistema não estava respeitando essas tags para formatar a informação na página. |
| **Solução/Implementação:** | Foi realizado ajuste no TOTVS Educa Mobile, de maneira a permitir a formatação da linha digitável, quando o retorno da fórmula associada conter tags HTML. |
