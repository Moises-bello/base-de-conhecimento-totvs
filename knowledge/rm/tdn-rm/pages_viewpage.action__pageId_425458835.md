**Cliente/Fornecedor**   
Esta janela permite visualizar os clientes cadastrados, tanto os ativos quanto os inativos.   
Através do cadastro é possível controlar:  
**Identificação**   
   
Esta tela permite editar os dados de identificação dos clientes.  
Abaixo é mostrada a descrição dos campos presentes nesta pasta e o procedimento correto para preenchê-los.  
Código Informe o código para o cliente / fornecedor. Não é permitida a inclusão de códigos repetidos, portanto, um código somente refere-se a um cliente / fornecedor respectivo.  
Global Marque este campo se o cliente / fornecedor incluído for um cliente comum a todas as coligadas.  
Observação  
Se você tem várias coligadas e alguns clientes e fornecedores são comuns a todas, utilize esta opção, desta forma não será necessária à inclusão do mesmo cliente/fornecedor para cada uma das coligadas.  
Depois da inclusão, este campo não poderá mais ser marcado ou desmarcado.  
Nome Fantasia  
Informe o nome fantasia do cliente / fornecedor.  
Data de Nascimento  
Informe a data de nascimento do cliente / fornecedor, se for da categoria 'Pessoa Física'.  
Nome Informe o nome do cliente / fornecedor. Neste campo pode-se informar a razão social do cliente / fornecedor cadastrado.  
Estado Civil  
Selecione o estado civil do cliente / fornecedor, se for da categoria 'Pessoa Física':  
Casado  
Desquitado   
Divorciado  
Outros  
Solteiro   
Viúvo  
Classificação  
Selecione uma das opções disponíveis (cliente, fornecedor ou ambos).  
Categoria Selecione uma das opções disponíveis (pessoa física ou pessoa jurídica). Se a categoria do Cliente/Fornecedor for 'Pessoa Física' será solicitado o número de dependentes do mesmo.  
CNPJ/CPF/CEI  
Informe neste campo o CNPJ, CPF ou CEI do cliente / fornecedor.  
Inscrição Estadual  
Informe a inscrição estadual do cliente / fornecedor.  
Inscrição Municipal  
Informe a inscrição municipal do cliente / fornecedor.  
Identidade (número, órgão emissor e estado emissor)  
Informe os dados referentes à identidade, se for da categoria 'Pessoa Física'.  
Número de dependentes  
Informe o numero de dependentes do cliente / fornecedor, se for da categoria 'Pessoa Física'.  
Tipo de Cliente/Fornecedor  
Informe se está incluindo um cliente, fornecedor ou ambos (se ele é um cliente e um fornecedor). Clique no campo, que estarão expostos as três opções descritas anteriormente.  
Ativo Marque este campo quando o cliente / fornecedor estiver ativo, isto é, quando ele estiver sendo utilizado para compras ou vendas. Este campo tem como default a marca, que significa que está ativo, para desativar, clique no quadrinho.  
Bloqueado  
Marque este campo quando o cliente / fornecedor estiver bloqueado.

Nesta pasta são cadastrados os dados referentes ao endereço principal, endereço de pagamento e endereço de entrega do cliente / fornecedor.

Cod. Município  
Caixa Postal  
CEP Caixa Postal

**Dica**  
Informe os campos que achar necessário.  
Preenchendo o endereço principal há um ícone para se realizar a copia dos dados para o endereço de entrega e endereço de pagamento.

Cliente - Campos Complementares   
Em Cadastro | Campos Complementares | Atendimento, podemos cadastrar campos relacionados à ocorrência, que por ventura não existem no aplicativo para atender a qualquer necessidade específica.   
Após o cadastro dos campos, para visualizarmos os mesmos, basta editarmos qualquer ocorrência e acessarmos a aba "Campos Complementares". Poderemos então, preencher os campos de acordo com a nossa necessidade.  
**Atenção**  
Se não houver nenhum campo complementar cadastrado ou os mesmos não estiverem ativos, a aba "Campos Complementares" da edição do atendimento não ficará visível.  
Aqui é feito o preenchimento dos campos complementares.  
Para as funções abaixo, podem-se utilizar as respectivas teclas de atalho:  
Inclusão  Ctrl + Ins  
Exclusão  Ctrl + Del  
Edição   Ctrl + Enter
