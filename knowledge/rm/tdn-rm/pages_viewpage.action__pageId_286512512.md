# Solicitação de Procedimento pela Agenda de Atendimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Agenda de Atendimento |
| **Situação:** | Ao efetuar a solicitação de autorização de procedimentos pela tela de agenda de atendimento, e registrar o atendimento, o número da guia da operadora não era preenchido corretamente. |
| **Solução:** | Alterado o sistema para incluir o número da operadora no campo correto, quando este for feito também pela agenda de atendimento. |
