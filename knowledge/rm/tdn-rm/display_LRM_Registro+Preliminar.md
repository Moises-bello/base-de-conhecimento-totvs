falseATENÇÃO:

A partir da release **12.1.2502**, o cadastro foi migrado para a tecnologia **Smart UI**, tornando esta documentação obsoleta. Para informações atualizadas, consulte a nova documentação disponível neste [[link](https://tdn.totvs.com/display/LRM/Registro+Preliminar+-+SmartUI)].

      O cadastro de Registro Preliminar irá permitir que o usuário do departamento pessoal possua um cadastro para informar dados básicos de um funcionário que será admitido, utilizando um registro de pessoa existente.  
      Na inclusão de um Registro Preliminar, estarão disponíveis os campos:

* Pessoa
* Data de Admissão (Prevista)
* CPF da Pessoa (Esse campo é para conferência dos dados da Pessoa, **não é possível modificá-lo**)

No campo Pessoa, o usuário deverá buscar uma pessoa já existente na base de dados.   
     Quando existe a integração Labore / Vitae e a obrigatoriedade de requisição para admissão, ao incluir um funcionário é exibida a tela de Pré-cadastro que faz a busca por todas as pessoas que já estão associadas a uma requisição, nesta mesma tela existe o ícone 'Exibir somente pessoas com registro preliminar' que irá filtrar as pessoas que já possuem o cadastro no Registro Preliminar.  
     No caso da não existência de integração Labore / Vitae e a não utilização de requisição para admissão, ao incluir um novo funcionário, dentro do cadastro existe um ícone que permite localizar uma pessoa já cadastra na base de dados e que também possui um Registro Preliminar

**Obs.:** Os campos do Registro Preliminar são de preenchimento obrigatório.

**Obs2.:** As informações contidas neste cadastro serão utilizadas pelo eSocial.

**Observação:**

Os dados deste cadastro serão enviados para o eSocial através do evento S-2190 -Admissão de Trabalhador-Registro Preliminar. Para incluir de um novo registro de Pessoa para sua utilização no Registro Preliminar, é necessário ao usuário ter permissão de "Incluir Pessoa" no sistema TOTVS Gestão de Pessoas.
