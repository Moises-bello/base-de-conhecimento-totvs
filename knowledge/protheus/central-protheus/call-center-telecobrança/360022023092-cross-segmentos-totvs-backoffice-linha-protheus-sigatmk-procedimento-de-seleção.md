**Dúvida**

Qual é o procedimento de Seleção de Títulos ao utilizar o Grupo de Cobrança?

**Ambiente**  
Cross Segmentos-TOTVS Backoffice (Linha Protheus)- SIGATMK- Callcenter– A partir da versão 11.80  
  
  
**Solução**

No pré-atendimento ao não selecionar o titulo a ser cobrado, é gerado automaticamente para o operador.

O sistema possibilita ao operador recusar o atendimento.

Para possibilitar a rejeição, verifique os parâmetros:

**MV\_TMKREJE** - Possibilita rejeitar o atendimento apresentado. 

**MV\_TMKSELV** - Indica se na solicitação de novo pré-atendimento, o sistema prioriza os títulos mais antigos com maior valor.

**MV\_TMKSELN** - Indica se na solicitação de novo pré-atendimento o sistema prioriza os títulos mais novos com maior valor.
