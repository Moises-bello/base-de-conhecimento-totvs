# Inclusão de Bolsa Retroativa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Inclusão de bolsa retroativa |
| **Situação/Requisito:** | Ao incluir uma bolsa retroativa para uma parcela em que o lançamento já esteja baixado e que tenha um outro desconto que não seja a bolsa, por exemplo, desconto pagamento 5º dia útil o sistema esta apresentando a seguinte mensagem:  Valor que está sendo baixado para o Lançamento Coligada XXX | IdLan = YYYY é maior que o valor líquido. |
| **Solução/Implementação:** | Melhoria no processo de bolsa retroativa para que o valor de desconto não seja recalculado ao ajustar a baixa para considerar o valor da bolsa que esta sendo incluída. |
