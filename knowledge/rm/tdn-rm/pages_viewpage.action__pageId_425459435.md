**Correspondência - Conversão**

---

A operação Conversão permite que um dado de entrada seja transformado para o tipo de dado escolhido.

Os parâmetros para configurar a operação são:

*Alimentação*

* **Entrada:** Ponto de entrada da operação ou campo.

*Identificação*

* **Nome:** Nome da operação.
* **Nome:** Campo somente leitura, tem como valor o tipo da operação.

*Parâmetros*

* **Tipo de Dados:** Tipo de dados resultante da operação, que pode ser:  
    
  + Texto (converte para String)
  + Inteiro (converte para int64)
  + Decimal (converte para Double)
  + Data (converte para DateTime)
