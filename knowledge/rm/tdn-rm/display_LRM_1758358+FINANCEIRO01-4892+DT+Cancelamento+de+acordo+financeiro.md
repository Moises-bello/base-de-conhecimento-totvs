# CANCELAMENTO DE ACORDO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Cancelamento de acordo |
| **Situação/Requisito:** | Ao cancelar um Acordo onde ocorreu acréscimo de valor, esta quantia é mantida no lançamento que havia sido baixado por acordo, fazendo com que seu valor líquido, considere um valor que não existe mais. O parâmetro Detalhar valores do Acordo no lançamento gerado está desabilitado. Assim, os valores de acréscimo e desconto são enviados para o lançamento baixado por acordo. |
| **Solução/Implementação:** | Otimizado o processo de cancelamento de acordo para verificar se deve ser atualizado os valores de acordo no lançamento de origem. |
