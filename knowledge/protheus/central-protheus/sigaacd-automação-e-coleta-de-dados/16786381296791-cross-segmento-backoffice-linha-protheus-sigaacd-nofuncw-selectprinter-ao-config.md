![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16786412484247) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Ao tentar configurar impressora de etiquetas no ACD, apresenta o ***HELP NOFUNCW SELECTPRINTER*** referente rotina não disponível.  Como resolver?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16786588598423)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões

**Solução**

O ***HELP NOFUNCW SELECTPRINTER*** é exibido devido o ***fonte ACDXFUN*** constar desatualizado no ambiente, para correção é necessário aplicar o pacote acumulado do estoque. No link abaixo constam os pacotes necessários apra atualização.
