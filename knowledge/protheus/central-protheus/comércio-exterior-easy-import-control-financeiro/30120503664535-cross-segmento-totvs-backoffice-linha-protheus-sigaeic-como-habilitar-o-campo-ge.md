Como habilitar o campo **gera provisórios** (YB\_GERPRO) dentro da rotina de cadastro de despesas?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**

Este campo é habilitado quando o parâmetro **MV\_EASYFIN** esta ligado, conteúdo igual a "**S**" e **MV\_EASYFPO** ou **MV\_EASYFDI** esteja ligado, conteúdo igual a "**S**".
