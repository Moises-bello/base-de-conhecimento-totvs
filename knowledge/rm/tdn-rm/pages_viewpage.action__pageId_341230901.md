# GERAÇÃO DE USUÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de usuários* |
| **Situação/Requisito:** | *No processo de geração de usuários, é permitida a seleção de geração para responsáveis financeiros, mas não é possível a seleção de um perfil de segurança para o mesmo.* |
| **Solução/Implementação:** | *Foi realizado um ajuste no sistema, onde foram incluídos os 3 campos para seleção dos perfis de segurança para o responsável financeiro.*  *Os campos serão exibidos ao selecionar a geração de usuário para o responsável financeiro.*  *Foram alterados o processo de geração de usuários e a parametrização para a geração automática de usuários.* |
