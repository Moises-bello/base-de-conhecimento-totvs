***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34187279974679) Tempo aproximado para leitura: 00:01:30 min*****Ocorrência**No módulo **Gestão de Pessoal**, ao gerar a SEFIP o código de terceiros não é gerado no arquivo SEFIP.RE.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Causa**Esse incidente ocorre, pois o sistema não reconhece as informação contida na tabela S037 informando que não é optante pelo simples e na tabela S038 código dos terceiros a ser enviado.  
  
**Solução**Para solucionar essa ocorrência, realize os seguintes passos:  
1. Executar *backup* prévio antes de aplicar o pacote;  
2. Aplicar o pacote de correção;  
3. Gerar o arquivo SEFIP.RE novamente
