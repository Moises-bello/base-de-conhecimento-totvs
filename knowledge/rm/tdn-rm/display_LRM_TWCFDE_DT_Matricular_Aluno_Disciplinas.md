# MATRICULAR ALUNO NAS DISCIPLINAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Educacional* |
| **Função:** | *Matricular aluno nas disciplinas* |
| **Situação/Requisito:** | *Ao matricular o aluno em uma disciplina de uma grade diferente da sua e essa disciplina possua como requisito uma disciplina já concluída como equivalência, o processo emite a validação de corequisito não cumprido, bloqueando a matrícula.* |
| **Solução/Implementação:** | *Ajustes na validação do corequistio na matrícula de uma disciplina. Caso o corequisito da disciplina já tiver sido concluída pelo aluno anteriormente, mesmo como equivalência, o processo não deve bloquear a matrícula.* |
