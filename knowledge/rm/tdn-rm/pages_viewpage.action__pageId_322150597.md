# Sistema permite baixar lançamento registrado com parâmetro de permitir desmarcado.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixa de Lançamento |

| **Solução/Implementação:** | Ajuste para que ao realizar a baixa de lançamentos a receber com status cnab igual a registrado o sistema apresente a mensagem de erro. |
