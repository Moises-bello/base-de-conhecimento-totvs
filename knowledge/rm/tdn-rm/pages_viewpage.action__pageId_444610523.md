# Cálculo 13º Salário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Cálculo 13º Salário |
| **Situação/Requisito:** | Inconsistência no processo de Cálculo de 13o. Salário da 1a. parcela quando utiliza a fórmula adicional com a função CALCMEDJOR. Ao definir o segundo parâmetro com N - NÃO, para não considerar a fórmula adicional somente desta fórmula/função, está retirando também do campo formula adicional na média normal. |
| **Solução/Implementação:** | Ajuste no cálculo da 1a. parcela de 13o. salário, que não estava aceitando total das fórmulas adicionais com valor negativo. |
