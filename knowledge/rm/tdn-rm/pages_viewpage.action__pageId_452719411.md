**Requisição de Alteração de Dados Funcionais**

---

Este tipo de requisição tem por objetivo atualizar os dados funcionais pela alteração da função e/ou do salário atuais. Passos para criar uma Requisição de Alteração de Dados Funcionais:

**1º Passo:** Criar uma Requisição pelo módulo Valorização | Requisições | Alteração de Dados Funcionais.

**2º Passo:** Preencher os campos disponíveis. Para saber as particularidades dos campos, acesse nas informações complementares - Identificação.

**3º Passo:** Aprovar/Reprovar a Requisição. Se a Requisição for aprovada e o flag "Gerar Substituição" estiver marcado, será gerada uma Requisição de Substituição, com os dados do funcionário que terá seus dados alterados.

**4º Passo:** Alterar os dados funcionais do funcionário, concluindo a Requisição. Este procedimento pode ser realizado de duas formas: No Totvs Gestão de Pessoas, pelo menu Valorização | Efetivações | Efetivar Alteração de Dados Funcionais. No Totvs Folha de Pagamento, caso exista licença deste produto, pelo menu Rotinas | Alterações Globais de Funcionários | Efetivar Alteração de Dados Funcionais.

**Importante:**

- Não se aplica a ex-funcionários.

- Somente as requisições aprovadas são relacionadas para serem efetivadas.

- Após executar o processo de Efetivar Alteração de Dados Funcionais, o sistema atualiza automaticamente os dados do funcionário e seus respectivos históricos.

- Após incluir progressões, os dados da requisição só poderão ser alterados caso exclua a progressão existente.

Como forma de acompanhamento dos processos relacionados à requisição serão enviados e-mail´s com mensagens padronizadas, podendo ainda optar-se pela notificação ao gestor de RH e ao gestor de departamento pessoal. O processo de notificação poderá ser parametrizado no aplicativo. Para isto, verifique em Configurações | Parametrizador | Requisições | Configuração de E-mails

**Campos Complementares na Requisição de Alteração de Dados Funcionais**

* Esta funcionalidade permite a inclusão de **Campos Complementares** nas **Requisição de Alteração de Dados Funcionais**
* Os Campos Complementares criados para a Requisição de Alteração de Dados Funcionais possuem **abrangência global**. Eles serão exibidos em **todas as coligadas** do sistema, independentemente da coligada em que foram criados ou da tabela dinâmica vinculada.
* Para visualizar e gerenciar a existência desses campos, siga o caminho no menu: **Valorização | Requisições | Campos Complementares | Requisição de Alteração de Dados Funcionais**
