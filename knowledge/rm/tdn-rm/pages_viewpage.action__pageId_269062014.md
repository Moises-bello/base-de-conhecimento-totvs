# Lançamento - Cálculo do IR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Lançamento - Cálculo do IR. |
| **Situação/Requisito:** | Durante a inclusão de um lançamento que gera IRRF, ao acessar a aba Tributos o botão para calcular o valor do IRRF "Raio" fica desabilitado. |
| **Solução/Implementação:** | Ajustado o botão de cálculo do IRRF para poder ficar habilitado quando o cliente/fornecedor for pessoa jurídica. Somente deve ficar desabilitado quando o cliente/fornecedor for pessoa física e possuir fórmula para cálculo de outras deduções variáveis. |
