Os cadastros das remessas serão feitos pelo menu Movimentações Bancárias / Integração Bancária / Remessa Bancária ou poderá ser realizado também durante o processo de geração das remessas.

**Procedimento:**

Acesse o menu Movimentações Bancárias / Integração Bancária / Remessa Bancária / escolha o Processo e inclua uma nova.   
 Os dados solicitados são requeridos nos respectivos arquivos de remessa.
