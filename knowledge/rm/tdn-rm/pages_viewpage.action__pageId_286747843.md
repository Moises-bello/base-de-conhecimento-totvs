# Edição de Partidas Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Edição de Partidas Contábeis |
| **Situação/Requisito:** | Ao realizar a alteração de centro de custos dentro de alguns lançamentos no lote zero e salvar o sistema está carregando outro código de centro de custos, e em algumas partidas a descrição da filial também é alterada, e ao reabrir o lançamento novamente, o sistema carrega o centro de custo que foi alterado. |
| **Solução/Implementação:** | Melhoria na tela de edição de partidas para que ao alterar qualquer campo os textos que aparecem nos campos Filial, Centro de Custo e Departamento não se alterem. |
