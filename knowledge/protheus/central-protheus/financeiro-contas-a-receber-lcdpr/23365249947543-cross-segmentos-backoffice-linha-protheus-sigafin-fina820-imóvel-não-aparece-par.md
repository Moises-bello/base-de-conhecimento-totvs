![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23365249906455) Tempo aproximado para leitura: **00****:03:00 min** **Dúvida**Como fazer com que o imóvel apareça para ser selecionado na geração do arquivo **LCDPR**?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas versões  
  
  
**Solução**Somente irá aparecer para seleção na etapa 3 da geração do arquivo, os imóveis que o declarante selecionado na 1 etapa estiver como declarante, seja como proprietário "Neste caso já aparecerá normalmente" ou terceiro, se estiver como terceiro deve estar conforme abaixo para que mostre o imóvel para seleção.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23365257486231)

Ou seja, se o campo **Tp. Pessoa** estiver como terceiro, este imóvel não vai aparecer para ser selecionado no **Wizard**.
