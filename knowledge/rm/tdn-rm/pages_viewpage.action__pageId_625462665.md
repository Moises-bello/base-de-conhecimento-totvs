## **01. VISÃO GERAL**

Funcionalidade que permite ao usuário salvar modelos de prescrição para utilizar posterior.

Exemplo de Utilização

## **02. EXEMPLO DE UTILIZAÇÃO**

No menu de prescrição enfermagem, após o usuário preencher os itens da prescrição, é possível registrar a mesma como modelo. Dessa forma, o usuário poderá utilizar o modelo cadastrado para lançamentos em outras prescrições.

Para tanto, basta clicar no botão salvar modelo.

Informar um nome para o modelo e se o mesmo será publico(todos os usuários terão acesso) ou privado (apenas o próprio usuário terá acesso).

Após salvar o modelo, para acessar o mesmo, basta clicar no botão de + usar modelo.

Será habilitada a tela com os modelos públicos e privados cadastrados. Neste momento será possível selecionar o modelo que deseja ser utilizado, alterar/editar ou excluir o mesmo da lista.

Clicando em selecionar, o modelo selecionado será carregado em tela.

Ao aplicar um modelo, apenas itens que não estavam suspensos serão adicionados.

Ao clicar em alterar, o modelo será aberto em tela com formato de edição. O usuário poderá fazer as alterações e gravar as mesmas para deixar registrado no modelo, basta clicar no botão de finalizar edição.

Caso o usuário opte por excluir, ele será questionado. Caso confirme, o modelo deixará de fazer parte da lista cadastrada.
