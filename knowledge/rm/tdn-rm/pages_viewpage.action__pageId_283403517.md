# Convênio sendo listando mais de uma vez na tela de faturamento da antiga MDI

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento |
| **Situação:** | Ao efetuar a pesquisa de convênio na tela de faturamento para convênio da antiga MDI, o sistema apresentava um convênio para cada data de vigência, fazendo com que convênios que tenham duas ou mais vigências apareçam na tela o mesmo número de vezes que o numero de vigência. |
| **Solução:** | Alterado o sistema para listar somente um convênio no combo da tela de faturamento para convênios da antiga MDI. |
