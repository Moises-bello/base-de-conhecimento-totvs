![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20941569567639) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como utilizar o e-mail substituto para o Workflow.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – BI - Workflow - Todas as versões.  
  
  
**Solução**Por meio da rotina "**WFA007**" via "**Configurador**" é possível inclui e-mails substitutos para os usuários envolvidos no processo de Workflow e a Data de Vigência para tal substituição. Também é possível configurar Hora Início e Hora Fim para contemplar um agendamento mais eficiente.  
No Menu basta acessar: "**Configurador / Ambiente / Workflow / E-mails substitutos**"
