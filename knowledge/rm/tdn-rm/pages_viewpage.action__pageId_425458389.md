**Preços**   
Para cada local de entrega pode ser definidos uma data e um preço.   
Esta janela permite o cadastro de datas e preços de entrega para cada localidade.   
Por exemplo: Se a entrega do resultado for na filial Sergipe, o preço vai ser diferente se a filial for em Belo Horizonte. O preço de entrega também pode diferenciar se a mesmo for em datas diferentes em localidades iguais.   
Siga os próximos passos.   
Código da Entrega:  
O sistema preenche automaticamente esse campo com o código do local de entrega vinculado.   
Código do preço:  
O sistema preenche automaticamente o campo com o código do preço que está sendo cadastrado.   
Data que foi definido o preço  
Informe neste campo a data em que vai ser entregue o resultado do fluxo definido no tipo de atendimento.   
Valor para o tipo de atendimento  
Informe neste campo o valor de entrega correspondente à data.
