# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | Ao realizar a baixa de um lançamento financeiro, está apresentando a seguinte mensagem de erro: "O Lançamento não pode ser salvo pois a soma das partidas a débito R$ 180,00 é diferente da soma das partidas a  crédito R$ 183,60". Caso seja selecionado a opção para visualizar o evento contábil (após reiniciar o processo de baixa) sem  realizar nenhum tipo de edição na contabilização, o mesmo é baixado com sucesso. |
| **Solução/Implementação:** | Otimização na baixa de lançamentos contábeis. Agora o sistema respeita a alteração feita pelo cliente no client  (Tela) nos valores dos itens de evento no evento contábil que utilizam formula de Multa, Juros, Descontos e  Valores Opcionais. |
