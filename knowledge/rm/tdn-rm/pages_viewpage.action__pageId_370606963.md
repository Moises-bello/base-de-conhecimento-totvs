# Erro ao digitar frequência diária no portal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Frequência diária |
| **Situação/Requisito:** | Era apresentado o erro de referência de objeto, ao digitar frequência diária no portal, quando um aluno possuía duas matrículas com uma de transferência interna |
| **Solução/Implementação:** | Era apresentado erro quando um aluno possuía mais de uma matrícula com situações de matrícula diferentes.  Passou agora a permitir a digitação de frequência mesmo se o aluno possuir mais de uma matrícula. Caso uma destas matrículas possua a situação de matrícula que indica transferência e esteja disponível para digitação de notas. |
