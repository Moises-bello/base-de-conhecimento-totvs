# CAMPOS CORTADOS NA TELA DE PARÂMETROS DO FUNCIONÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Cadastro de Funcionario* |
| **Situação/Requisito:** | Nome dos campos de "Nro. Dependente Salário Família" e "Média Salário Maternidade" estão sendo cortados na tela de paramentros do funcionario. |
| **Solução/Implementação:** | Foi alterado o nome dos campos "Nro. Dependente Salário Família" para "Nro. Depend. Sal. Família:" e de "Média Salário Maternidade" para "Média Sal. Matern:". |
| **Versões/Release:** | *12.1.8* |
