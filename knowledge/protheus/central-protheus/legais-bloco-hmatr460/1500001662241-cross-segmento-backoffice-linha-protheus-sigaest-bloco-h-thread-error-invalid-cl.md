**Dúvida**Ao gerar o SPED Fiscal com o Bloco H gera o error.log "THREAD ERROR - invalid class ESTFWSX3UTIL on ESTCHKDIC". O que fazer para resolver este problema?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.

**Solução**Para solucionar este problema, siga os passos abaixo:

**1. Atualize o seu ambiente com os Acumulados de Estoque e Livros Fiscais**

Para correção deste error.log, houveram atualizações no produto com relação aos fontes responsáveis pela geração do SPED Fiscal com Bloco H. Então, basta atualizar os acumulados conforme a sua release:
