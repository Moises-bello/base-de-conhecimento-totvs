# CADASTRO DE RESPONSÁVEL FINANCEIRO - CADASTRO DE ALUNOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Cadastro de responsável financeiro - Cadastro de alunos |
| **Situação/Requisito:** | Ao tentar cadastrar um novo responsável financeiro no cadastro do aluno, ou seja, será criado um novo cliente/fornecedor no TOTVS Gestão Financeira o sistema não valida as permissões, assim, mesmo que o usuário não tenha permissão no cadastro de cliente/fornecedor o sistema permite que seja feito o cadastro, até mesmo cadastrando mais de um cliente/fornecedor. |
| **Solução/Implementação:** | Foi feito um ajuste para que o sistema valide as permissões do cadastro de cliente/fornecedor do educacional/financeiro, assim se o usuário não possuir permissão o sistema irá alertar que não será possível efetuar o cadastro de um novo cliente/fornecedor pois o usuário não tem permissão. |
