# Geração de lançamento durante a rematrícula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Rematrícula |
| **Situação/Requisito:** | Ao finalizar a rematrícula e ela não for concluída por alguma validação realizada, era gerado um lançamento financeiro mesmo com a matrícula não sendo confirmada. Por exemplo, em situações que não há mais vagas na turma. |
| **Solução/Implementação:** | Se ocorrer algum erro de validação no processo de rematrícula, o lançamento financeiro não será gerado. |
