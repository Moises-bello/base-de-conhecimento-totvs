# EXCLUSÃO DE AGENDAMENTO NO CANCELAMENTO DA INSCRIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Cancelar Inscrição |
| **Situação/Requisito:** | Quando a inscrição é cancelada o agendamento deve ser liberado para que a data/horário seja disponibilizada para outros candidatos. |
| **Solução/Implementação:** | Foi incluída uma rotina para remover os agendamentos do candidato ao cancelar a inscrição do mesmo. Antes, a remoção do agendamento era feita apenas na exclusão da inscrição. |
