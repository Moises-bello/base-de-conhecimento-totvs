# FUNCIONÁRIO - LOCALIZAR PESSOA REGISTRO PRELIMINAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Contrução e Projetos* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Funcionário - Localizar Pessoa / Registro Preliminar* |
| **Situação/Requisito:** | Ao realizar a admissão de um funcionário utilizando a requisição de admissão, o sistema não respeita a data de admissão informada na requisição. |
| **Solução/Implementação:** | Ao selecionar uma pessoa pelo Localizar Pessoa / Registro Preliminar, foi realizado a mesma validação que é feita ao dar tab no campo Data de Admissão, para preencher os campos de data da mudança com a mesma data da admissão. |
