# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Usado como um índice em PlanRMBorders para definir a borde de uma célula ou um grupo de células.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| DiagonalDown | Define uma borda diagonal que começa no canto superior esquerdo e termina no canto inferior direito. |
| DiagonalUp | Define uma borda diagonal que começa no canto inferior esquerdo e termina no canto superior direito. |
| EdgeBottom | Define uma borda na parte inferior. |
| EdgeLeft | Define uma borda na parte esquerda. |
| EdgeRight | Define uma borda na parte direita. |
| EdgeTop | Define uma borda na parte superior. |
| InsideHorizontal | Define uma borda horizontal entre as linhas quando selecionado uma grupo de células com mais de uma linha. |
| InsideVertical | Define uma borda vertical entre as colunas quando selecionado uma grupo de células com mais de uma coluna. |
