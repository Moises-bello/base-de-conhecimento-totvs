**Dúvida**

Ao incluir uma Solicitação de Importação, sistema retorna a seguinte mensagem:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360043920913/mceclip0.png)  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Para a devida correção realize os procedimentos abaixo: 1. Acessar o módulo **SIGAEIC** em Atualizações \ Cadastros \ Fabricante/Forn.;​  
2. Posicione no fornecedor utilizado e selecione o Alterar;  
3. Na aba Outros informe no campo **Identificac.** (A2\_ID\_FBFN) como 3-TODOS;  
4. Selecione Confirmar, após efetue o procedimento novamente.
