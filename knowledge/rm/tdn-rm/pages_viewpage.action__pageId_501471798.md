## **02. SITUAÇÃO/REQUISITO**

O configurador de integração deverá ser alterado para que a integração padrão de instalação seja a versão com o identificador 1021 e o mesmo deverá continuar disponibilizando a versão com o identificador 1012 para quem, ainda, a utiliza.

## **03. SOLUÇÃO**

Ajuste no processo do Configurador para possa exibir como padrão a integração com o identificador 1021 como padrão para novas instalações e a integração com o identificador 1012 apenas para sistemas que mantêm essa integração ativa.

## **04. DEMAIS INFORMAÇÕES**
