# Novo Portal do Aluno não carregava o local de entrega selecionado quando existia apenas um local de entrega.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Educacional. |
| **Função:** | Requerimentos - Portal do Aluno. |
| **Situação/Requisito:** | Ao criar um requerimento que gera lançamento financeiro no Portal do Aluno(novo), é obrigatório que o local de entrega seja definido.  Quando existia apenas um local de entrega, o mesmo não carregava selecionado. |
| **Solução/Implementação:** | Ajuste feito ao carregar tela de requerimento, quando existe apenas um local de entrega, o mesmo já carrega selecionado. |
