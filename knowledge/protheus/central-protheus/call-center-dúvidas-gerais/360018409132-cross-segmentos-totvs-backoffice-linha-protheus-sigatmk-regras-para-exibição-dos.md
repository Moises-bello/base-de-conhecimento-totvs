**Dúvida**

Qual a regra para exibição das Ocorrências Pendentes x Operador na rotina de Atendimento Telemarketng (**TMKA271**)?

**Ambiente**

Cross Segmentos-TOTVS Backoffice -(Linha Protheus-)SIGATMK - a partir da versão 11.  
  
**Solução**

1. Primeiramente, é necessário cadastrar o **Grupo de Atendimento**(**TMKA040**);

2. Com os grupos cadastrados, precisamos vinculá-los aos operadores;

3. O sistema possui as seguintes ocorrências cadastradas;

4. Ao acessar a rotina de Ocorrências pendentes X Operadores, as seguintes ocorrências serão exibidas.

Para visualização das telas, acesse a FAQ: **[Regras para exibição dos Chamados Pendentes X Operadores](http://tdn.totvs.com/display/PROT/TMK0058_Chamados_pendentes_X_Operador)**
