# CADASTRO PUBLICAÇÃO - CLASSIFICAÇÃO E SUBCLASSIFICAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Cadastro de publicação - Classificação e subclassificação* |
| **Situação/Requisito:** | *No cadastro de publicação foi identificado que o campos classificação e subclassificação ficam habilitados ao criar ou editar uma publicação quando o parâmetro "Utilizar área conhecimento integrada com CDU / CDD" está habilitado sendo que com este parâmetro habilitado o correto são os campos classificação e subclassificação ficarem desabilitados, tendo os valores preenchidos somente se quando definida uma área e subárea do conhecimento.* |
| **Solução/Implementação:** | *Foi identificado que a validação do parâmetro só era feita após salvar a publicação, assim os campos só eram desabilitados ao salvar, foi feito o ajuste para que ao iniciar a tela o sistema verifique o parâmetro e desabilite os campos.* |
