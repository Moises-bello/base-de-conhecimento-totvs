**Dúvida**Quais Coletores de Dados são homologados para uso no módulo Automação e Coleta de Dados (SIGAACD)?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - A partir da versão 11.80  
  
**Solução**O módulo Automação de Coleta de Dados (SIGAACD) não possui lista de coletores de dados homologados para utilização. Somente são considerados aptos os coletores de dados que trabalham com o protocolo **VT100**.  
  
**Informação importante:** A TOTVS não realiza homologação de coletores de dados.
