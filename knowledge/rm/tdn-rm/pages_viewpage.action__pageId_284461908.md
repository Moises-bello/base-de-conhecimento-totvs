|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Inclusão de lançamento contábil |

| **Solução/Implementação:** | Ao salvar um lançamento contábil o campo documento, da partida, passou a respeitar o parâmetro "Preenchimento com zeros à esquerda". |
