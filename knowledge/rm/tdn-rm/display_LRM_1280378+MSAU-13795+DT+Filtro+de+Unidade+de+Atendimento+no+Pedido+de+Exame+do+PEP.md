# Filtro de Unidade de Atendimento no Pedido de Exame do PEP

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário |
| **Situação:** | Na aba de avaliações complementares do prontuário, o sistema exibia exames de unidades de atendimento que o usuário não tinha acesso. |
| **Solução:** | Realizado ajuste para exibir somente exames de unidades de atendimento que o usuário tenha acesso, na aba de avaliações complementares do prontuário. |
