# Objetivo:

---

       O objetivo deste documento é trazer uma observação ao "salvar como" uma Planilha.Net em xls ou xlsm.

# Introdução:

---

       A Planilha.Net possui uma barra de "Ações do Documento", que tem como objetivo gerenciar as Configurações da Planilha, consultas SQL e Gráficos .

       Ao salvar uma Planilha.Net utilizando a opção "Salvar como". A planilha passará a ser uma Planilha do Excel como outra qualquer.

false

*Ao utilizar a opção **“Salvar Como”** o menu **“Ações do Documento”**, disponível nas Planilhas.Net, não ficará disponível no arquivo de Excel salvo.*

       Ao incluir uma nova Planilha.Net, existe a opção "Carregar Planilha" que permite utilizar um arquivo de Excel salvo em seu computador para criação de uma nova Planilha.net.

       As planilhas que forem criadas utilizando a opção "Carregar Planilha" utilizando um arquivo de Excel criado a partir do processo de "Salvar Como" de uma Planilha.Net não terão o menu “Ações do Documento” disponível.

false

*Somente arquivos **Excel na extensão xls** podem ser utilizados na opção “Carregar Planilhas” e criar uma Planilha.Net.*
