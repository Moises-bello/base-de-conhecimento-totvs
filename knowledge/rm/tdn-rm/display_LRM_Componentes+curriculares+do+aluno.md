Recurso disponível apenas no nível de ensino superior. São componentes curriculares personalizados e individuais para o aluno. Eles são importantes para o  e se assemelham aos componentes da matriz original do curso do aluno.

É possível por meio de um processo copiar os dados dos componentes da matriz aplicada do curso do aluno para o [currículo individual](https://tdn.totvs.com/pages/viewpage.action?pageId=425459061) localizado em: **Currículo e Oferta - Estrutura Curricular - Mais - [Assistente para cópia da matriz para o currículo individual](https://tdn.totvs.com/pages/viewpage.action?pageId=859576542).** Este processo copia todas as informações existente dos componentes da matriz aplicada do curso do aluno, para mais informações do processo que efetua esta cópia, [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=859576542).

A partir as versões **12.1.2402.189, 12.1.2406.121 e 12.1.2410** o currículo individual passa a atender a legislação que tange a [curricularização da extensão](https://tdn.totvs.com/pages/viewpage.action?pageId=665272884). Com isso foi criado o campo **Componentes de extensão**, tem por objetivo dizer se este componente é de extensão ou não.
