Os campos para parametrização desta integração estarão disponíveis caso exista convênio entre a empresa e uma operadora de crédito habilitada pela TOTVS. Atualmente as operadoras de créditos disponíveis são a BV Financeira e Creditas.

Caso exista o convênio, os campos habilitados são:  
**Evento de desconto de Crédito Consignado:** Neste campo estarão disponíveis os eventos com código de cálculo 438.

**Evento de base de cálculo do valor a ser descontado:** Neste campo estarão disponíveis os eventos com código de cálculo 439.
