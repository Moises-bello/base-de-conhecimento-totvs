# FORMULÁRIO DE INSCRIÇÃO PARA O PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Processo Seletivo. |
| **Função:** | Inscrição para o processo seletivo. |
| **Situação/Requisito:** | Ao parametrizar um processo seletivo para exigir sobrenome o sistema não estava com um comportamento desejável ao fazer a busca da pessoa. |
| **Solução/Implementação:** | Ajustes ao buscar informações de candidatos já cadastrados quando utiliza sobrenome no formulário de inscrição do novo portal do processo seletivo. Foi inserido também um campo no formulário de inscrição para o usuário digitar o sobrenome. Caso o usuário possua mais de uma inscrição, a busca irá retornar os dados com inscrição mais recentes. |
