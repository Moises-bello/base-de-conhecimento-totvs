**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34626482465047) Tempo aproximado para leitura: 00:01:30 min****Dúvida**Por que o cálculo de rescisão apresenta o ID 1691-Periculosidade Médias 13 Sobre Aviso?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**

O ID 1691-Periculosidade Médias Médias 13 Sobre Aviso se trata da periculosidade referente a verba indenizatória Médias 13 Sobre Aviso, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1691.**
