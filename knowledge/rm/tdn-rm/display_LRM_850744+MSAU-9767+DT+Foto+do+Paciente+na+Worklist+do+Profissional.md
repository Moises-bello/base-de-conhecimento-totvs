# Foto do paciente na worklist do profissional

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | PEP 2.0 |
| **Situação:** | O sistema apresentava uma mensagem de não conformidade no carregar o worklist do usuário, quando o parâmetro "Visualizar foto do paciente nos itens da Work List" estava habilitado. |
| **Solução:** | Realizado ajuste para carregar a worklist do profissional quando o parâmetro "Visualizar foto do paciente nos itens da Work List" estiver habilitado corretamente. |
