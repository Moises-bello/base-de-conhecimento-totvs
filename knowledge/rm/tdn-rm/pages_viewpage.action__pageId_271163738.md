# Alteração de Extrato de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | *Alteração de Extrato de Caixa* |
| **Situação/Requisito:** | No extrato de caixa, ao alterar uma tabela opcional e selecionando para não regerar contabilidade, ao salvar o registro sistema esta tentando regerar contabilidade. |
| **Solução/Implementação:** | Não tentar regerar contabilidade quando usuário alterar uma tabela opcional no extrato de caixa e seleciona para não regerar contabilidade. |
