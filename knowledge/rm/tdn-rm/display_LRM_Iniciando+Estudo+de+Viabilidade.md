O estudo de Viabilidade é uma capa do estudo a ser realizado. Neste cadastro deve ser informado o Nome do estudo (adotando sua principal característica) e o Tipo de Estudo (que traz a regra de análise)  
 Para começarmos, na tela Inicial do Estudo de Viabilidade no Menu Cadastro/Estudo de Viabilidade é necessário clicarmos no botão "Novo" localizado no canto superior esquerdo da Tela, feito isso, uma nova tela é aberta com o seguintes campos:  
    
 Identificação  
 **Tipo de Estudo:** Nesse campo informamos em qual Tipo de Estudo, a versão de Estudo será desenvolvida.  
 **Estudo:** Indica qual o número de Identificação do Estudo de Viabilidade.  
 **Situação:** Exibe o Status do Estudo de Viabilidade.  
 **Data da Situação:** Informa qual a ultima Data de Modificação da Situação do Estudo.  
 **Usuário Cadastro:** Exibe qual o usuário Cadastrou o Estudo de Viabilidade.  
 **Usuário Aprovação:** Informa qual usuário aprovou o Estudo de Viabilidade realizado.  
 **Data de Cadastro:** Exibe a data de Cadastro do Estudo de Viabilidade em questão.  
    
 Pasta Fase do Estudo  
 Divide o Estudo em Fases. Ex.: Anti-Projrto, Projeto, Obra, etc.  
 **Código:** Exibe o código da Fase de Estudo.  
 **Nome:** Exibe o nome da Fase de Estudo.  
    
 Pasta Versão do Estudo  
 Exibe informações sobre a versão do Estudo em questão.  
 Feito isso, devemos criar uma Nova versão de Estudo. Para criar uma nova Versão de Estudo devemos clicar no botão "Novo" localizado no canto superior esquerdo da Tela de "Versão de Estudo"; logo em seguida aparecerá uma nova tela com os seguintes campos:  
 **Versão:** Exibe o número da versão do Estudo de Viabilidade.  
 **Nome:** Exibe o nome da Versão do Estudo de Viabilidade.  
 **Data Cadastro:** Informa quando a Versão do Estudo de viabilidade foi cadastrada.  
 **Data de Cálculo:** Exibe data e hora do último cálculo realizado daquela versão de Estudo de Viabiliade.  
 **Usuário:** Informa qual usuário cadastrou a Versão do Estudo de Viabilidade.  
 **Observações:** Permite ao usuário escrever algum comentário sobre a Versão do Estudo de Viabilidade.  
    
 Pasta identificação  
 Mostra qual é a versão do estudo em questão. Esta Pasta possui os seguintes Campos:  
 **Versão:** Exibe o número da versão do Estudo de Viabilidade.  
 **Nome:** Exibe o nome da Versão do Estudo de Viabilidade.  
 **Data Cadastro:** Informa quando a Versão do Estudo de viabilidade foi cadastrada.  
 **Data de Cálculo:** Exibe data e hora do último cálculo realizado daquela versão de Estudo de Viabiliade.  
 **Usuário:** Informa qual usuário cadastrou a Versão do Estudo de Viabilidade.  
 **Observações:** Permite ao usuário escrever algum comentário sobre a Versão do Estudo de Viabilidade

 Sub-Pasta Vendas  
 Os dados pertinentes as vendas das unidades são inseridos nessa Pasta. Podemos montar vários perfis de vendas, para cada perfil informamos a quantidade de unidades vendidas e em quantos períodos eles serão vendidos, qual o período inicial das vendas e a sua periodicidade. Podemos informar ou não o tipo da unidade vendida, caso seja informada o valor da receita será o valor da unidade, caso não seja informado o valor será uma média dos valores das unidades.  Importar Estudo  
 Para importar um Tipo de Estudo já pronto, temos que primeiramente criar um novo tipo de Estudo clicando no botão "Novo" e informar o Campo "Nome" e o campo "Tipo de Código". Logo em seguida Clicar no botão Processos / Importar Tipo de Estudo.  
 O Sistema irá abrir a tela para informarmos onde está o Tipo de Estudo Padrão TOTVS  "Viabilidade de Empreendimentos Imobiliários" que já vem pronto no Instalador RM Solum a partir da versão 10.70.0   
 Por definição esse Tipo de Estudo vem na pasta CorporeRm / RMSolum / Modelos de Viabilidade. Basta selecionar o mesmo e salvar.
