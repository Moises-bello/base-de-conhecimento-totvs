# Situação Projeto Pesquisa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Alteração de Situação de Projeto e Pesquisa |
| **Situação/Requisito:** | Ao finalizar o cadastro da solicitação do Projeto de Pesquisa pelo Fluxo o usuário responsável pela classificação dos projetos e acessar o sistema RM | Atividades Acadêmicas | Inovação, Pesquisa e Extensão | Alteração de Situação de Projeto de Pesquisa e realizar a buscar de todas as solicitações e realizar a classificação.    Porém ao clicar em selecionar o sistema apresenta uma mensagem de não conformidade. |
| **Solução/Implementação:** | Realizada uma validação ao selecionar as informações do projeto na alteração de situação de projeto e pesquisa para que seja apresentada uma mensagem informando que nenhum projeto foi encontrado, pois quando não existia projeto o sistema estava apresentando uma mensagem de não conformidade não tratada e agora tratamos a mensagem. |
