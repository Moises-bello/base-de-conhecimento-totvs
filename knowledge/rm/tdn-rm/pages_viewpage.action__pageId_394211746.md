# Cálculo da Diferença Salário Família

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Lançamento Diferença Salarial |
| **Situação/Requisito:** | Cliente informa que o funcionário em Janeiro tinha 3 dependentes de Salário Família , em fevereiro passou a ter apenas 2 pois um deles fez 14 anos. Em Março foi calculada uma diferença salarial retroativa a janeiro, mas dentro da ficha financeira identificou que está sendo pago a diferença de salário família para 3 dependentes em Fevereiro, sendo que o correto no entendimento do cliente é considerar apenas 2 dependentes. |
| **Solução/Implementação:** | Ajuste do cálculo da diferença de salário família quando o número de dependentes é diferente entre os meses originais que entram para o cálculo. |
