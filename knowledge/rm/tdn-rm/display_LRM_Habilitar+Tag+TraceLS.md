# Habilitar TAG TraceLS

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 11.xx, 12.xx |
| **Ocorrência:** | Orientações para habilitar trace do License Server |
| **Ambiente:** |  |
| **Passo a passo:** | Com a finalidade de gerenciarmos o processo de execução do License Server necessitamos habilitar a tag "tracels" no arquivo do RM Host e a tag LSDebug no arquivo appserver.ini no servidor de licenças (License Server).   Para habilitar o tracels no Servidor de Host, siga as orientações abaixo:   A tag é:      <add key="tracels" value="true" />    1. Acesse o diretório "C:\totvs\CorporeRM\RM.Net".  2. Edite o arquivo **RM.Host.Service.exe.config** utilizando o bloco de notas.  3. Inclua no contexto do arquivo a tag"<addkey="tracels"value="true"/>".  Abaixo segue exemplo do contexto original e alterado do arquivo RM.Host.Service.exe.config:     |  |  | | --- | --- | | **RM.Host.Service.exe.config ANTES** **(Contexto** **Original)** | **RM.Host.Service.exe.config DEPOIS** **(Depois** **da** **alteração)** | | <?xml version="1.0" encoding="utf-8"?> <configuration>  <appSettings>  <add key="JobServer3Camadas" value="true" />  <add key="Port" value="8050" />  <add key="HTTPPort" value="8051" />  <add key="FileServerPath" value="\\BHD050102134\TEMP" />  <add key="ActionsPath" value="C:\totvs\CorporeRM\RM.Net;C:\totvs\CorporeRM\Corpore.Net\Bin" />  <add key="LibPath" value="C:\totvs\CorporeRM\RM.Net" />  <add key="EnableDynamicLocalization" value="false" />  <add key="EnableCompression" value="false" />  <add key="LocalizationLanguage" value="pt-BR" />  </appSettings>  <runtime>  <gcServer enabled="true" />  </runtime> </configuration> | <?xml version="1.0" encoding="utf-8"?> <configuration>  <appSettings>  <add key="JobServer3Camadas" value="true" />  <add key="Port" value="8050" />  <add key="HTTPPort" value="8051" />  <add key="FileServerPath" value="\\BHD050102134\TEMP" />  <add key="ActionsPath" value="C:\totvs\CorporeRM\RM.Net;C:\totvs\CorporeRM\Corpore.Net\Bin" />  <add key="LibPath" value="C:\totvs\CorporeRM\RM.Net" />  <add key="EnableDynamicLocalization" value="false" />  <add key="EnableCompression" value="false" />  <add key="LocalizationLanguage" value="pt-BR" />  **<add key="tracels" value="true" />**  </appSettings>  <runtime>  <gcServer enabled="true" />  </runtime> </configuration> |     4. Reinicie o serviço do RM Host para que esta alteração seja computada:        Após realizar essa configuração no RM, acesse o servidor de licenças (License Server), abra o arquivo appserver.ini (UNIDADE:\totvs\TOTVSLicenseVirtual\bin\appserver), na seção [environment], adicione a chave LSDebug=2, renomeie o arquivo console.log (UNIDADE:\totvs\TOTVSLicenseVirtual\bin\appserver) e reinicie o serviço do License Server nos serviços do Windows.  Segue abaixo conteúdo original e alterado do arquivo **appserver.ini**:    | **Conteúdo Original:** | Depois da alteração: | | --- | --- |     Após habilitar a tag tracels no Host e a tag LSDebug no appserver.ini, assim que ocorrer a inconsistência (ou simule a inconsistência), localize o arquivo de log do host na pasta Log (C:\totvs\CorporeRM\RM.Net\Processos\Logs\Broker) e envie-nos uma cópia para análise via Ticket.   O caminho é:   C:\totvs\CorporeRM\RM.Net\Processos\Logs    Caso não localize os logs na pasta C:\totvs\CorporeRM\RM.Net\Processos\Logs avalie se no ambiente está configurado a tag LogPath, caso esteja, gentileza acessar o diretório configurado e avaliar se os logs estão sendo gerados no caminho informado. Caso utilize múltiplos hosts, habilite a tag em todos os arquivos de configuração, Exemplo: **RM.Host.Service.exe.config** , **RM.Host.Service1.exe.config** , **RM.Host.Service2.exe.config** , **RM.Host.Service3.exe.config, etc.  A tag tracels deve ser habilitada em todos os hosts do ambiente (todas as máquinas que possuem host), pois o server é stateless.**  Além do arquivo de log do host, nos envie o log do License Server para melhor análise. O arquivo de log do License Server é o arquivo console.log (localizado em: UNIDADE:\totvs\TOTVSLicenseVirtual\bin\appserver) na máquina na qual o License Server está instalado. |
| **Observações:** | Após enviar-nos os arquivos de log, pode-se deletar as tags dos arquivos para não gerar perda de performance em seu ambiente. |
