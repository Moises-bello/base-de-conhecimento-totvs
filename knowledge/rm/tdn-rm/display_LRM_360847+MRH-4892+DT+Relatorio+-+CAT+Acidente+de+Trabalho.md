|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Segurança e Saúde Ocupacional |
| **Função:** | Relatório - CAT Acidente de Trabalho |
| **Situação/Requisito:** | Sistema emite erro ao cadastrar como candidato CIPA funcionário que teve transferência entre coligadas e ainda possui estabilidade na coligada anterior. |
| **Solução/Implementação:** | Melhorado a consulta do relatório que preenche o campo 38 (CGC), agora ela verifica se o campo 36 (Local do Acidente) é igual a '2 - em empresa onde a empregadora presta serviço', e preenche o campo 38 com CGC ou CNPJ do local do acidente.
