O [Totvs Assinatura Eletrônica](https://produtos.totvs.com/ficha-tecnica/tudo-sobre-o-totvs-assinatura-eletronica/) funciona como um organizador dos documentos que necessitam de Assinatura Eletrônica para fins de autenticação de Contratos do Totvs Construção Obras e Projetos.

**Assista ao vídeo abaixo para saber como adquirir a versão TRIAL do TOTVS Assinatura Eletrônica.**

Para utilizar a Assinatura Eletrônica, é necessário que o sistema esteja parametrizado para esta funcionalidade. [Veja como é simples!](https://tdn.totvs.com/pages/releaseview.action?pageId=562963400)

Após a parametrização acesse a aba **Projeto | TOTVS Construção Obras e Projetos | Projetos (ou atalho F6) | Contratos | Assinatura Eletrônica.**

Conheça o Processo dentro de cada funcionalidade:

Durante a utilização das Funcionalidades acima, o sistema permite que alguns **Processos dependentes da Assinatura** sejam bloqueados. Para que isso ocorra basta selecionar a flag:

Para o bloqueio dos processos o sistema permite ainda, escolher quais **Tipos de Contrato**irão validar o bloqueio, sendo eles **A pagar, A receber ou Ambos**.

Conheça quais processos são bloqueados durante o uso da Funcionalidade:

**Cadastro de contrato**

* Não Assinado:
  + Faturamento Direto;
  + Medição do Item;
  + Alterar Status (Os status bloqueados para alteração são Em Andamento, Paralisado);
* Assinado:
  + Alteração Cli/For;
  + Associar Itens e Objetos;

**Períodos de Contrato**

* Não Assinado:
  + Liberação de Período;
* Assinado:
  + Medição;

**Aditivos Contratuais**

* Não Assinado:
  + Não usa Status de Contrato:
    - Medição do Item do Aditivo;
  + Usa Status de Contrato:
    - Alteração do Status do Aditivo - Os Status bloqueados são Em Andamento, Cancelado, Paralisado e Concluído;
* Assinado:
  + Associar Itens;
  + Alterar Aditivo;

**Adiantamento de Contrato**

* Não Assinado:
  + Liberação do Adiantamento;
* Assinado:
  + Alteração do Adiantamento;

Como forma de facilitar e agilizar o envio do Documento para Assinatura, é possível definir um **Relatório Default** do book, onde ao executar os processos o sistema irá gerar o Relatório selecionado, salvá-lo em formato **.pdf**e enviá-lo para autenticação.

Tipo do Relatório

Só será disponibilizado como Relatório Default os relatórios que forem do tipo Contrato ou Medição.

A partir dai é possível parametrizar a utilização da Assinatura para as rotinas de:

* [Cadastro de Contrato](https://tdn.totvs.com.br/display/LRM/Contratos+-+TOP);
* [Períodos de Contrato](https://tdn.totvs.com/pages/releaseview.action?pageId=421385176);
* [Aditivos Contratuais](https://tdn.totvs.com/display/public/LRM/Aditivos+Contratuais);
* [Adiantamento de Contrato](https://tdn.totvs.com/display/public/LRM/Adiantamento+de+Contrato);

Compra

Dentro de todas as funcionalidades que dispõem da Assinatura Eletrônica será disponibilizado um ícone  que direcionará para a página na qual será realizado o envio do documento de extensão **.pdf**para autenticação.

Caso o sistema não esteja parametrizado para utilizar o TOTVS Assinatura Eletrônica, o sistema irá exibir uma tela direcionando para a compra da funcionalidade. Veja;
