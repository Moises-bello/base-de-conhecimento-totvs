**Ocorrência**Como realizar a configuração do complemento cadastral para gerar a GIA-SP pelo TAF?  
  
**Ambiente**Microsiga Protheus – Livros Fiscais – A partir da versão 12.1.17  
  
**Solução**Para realizar a configuração do complemento cadastral para geração da GIA, siga os seguintes procedimentos:   
  
1. Acesse o módulo **84-TOTVS Automação Fiscal -**> **Atualizações -**> **Empresa -**> **Complemento Cadastral**e acione a opção **Incluir**;  
  
2. Acesse as pastas **Complemento do Estabelecimento** -> **Informações do Estabelecimento**e preencha os campos:   
**Filial TAF** = Informe o Código da Filial a ser utilizada pelo TAF - Exemplo = **01**  
**Cód. Filial** = Informe o Código da Empresa+Código da Filial - Exemplo = **9901**3. Acesse as pastas **Complemento do Estabelecimento** -> **Obrigações Fiscais**e preencha o campo:  
**Código Obrig.** = Informe o código da Obrigação Fiscal.   
  
4. Após concluir as configurações acione a opção **Confirmar**.  
  
**Importante:**Caso existam obrigações fiscais que devam ser entregues por cada uma das filiais cadastradas, será necessário efetuar este mesmo procedimento para todas as filiais.   
  
Se em minha empresa existirem diversas filiais, terei que executar este procedimento filial por filial?    
R. Não, pensando nisso foi disponibiliza a opção Amarração Automática 1 x 1, onde será possível amarrar todas as filiais existentes ao TAF. Para efetuar este procedimento acione as opções: **Outras Ações** -> **Amarração Automática** 1 x 1
