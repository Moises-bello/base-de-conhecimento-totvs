# Objetivo:

---

       Verificar se uma consulta SQL está relacionado a algumas funcionalidades pré-mapeadas do sistema.

# Introdução:

---

       É possível verificar se uma consulta SQL está sendo utilizada por algum recurso do RM. Para isso, deve-se seguir os passos listados no item abaixo.     

# Verificação:

---

**Passo 1 -** Na tela Visão de Dados do RM, selecione a consulta SQL desejada e acesse o Menu Processos/Procurar Referências (F3), ou apenas aperte a tecla F3.

**Passo 2 -** Feito isso, será exibido uma janela informando se a consulta está presente em algum Relatório, Fórmula, Fórmula Visual, Gerador de Saídas, Gráfico, Filtro, Filtro do Gerador de Relatórios ou Objeto de Negócio.
