# Como gerar Etiquetas de Estoque?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como gerar Etiquetas de Estoque? |
| **Passo a passo:** | Etiquetas de Estoque No TOTVS Gestão Hospitalar é possível imprimir as etiquetas de estoque por lote, validade e quantidade. Configurando Parâmetros de Impressão  1. No **TOTVS Gestão Hospitalar** acesse **Opções/Parâmetros/Parâmetros de Impressão**. 2. Efetue a configuração de impressora para Etiquetas. 3. Clique em **Grava**.  Imprimindo Etiquetas de Estoque  1. No **TOTVS Gestão Hospitalar** acesse **Estoques/Etiquetas de Código de Barras**. 2. Será exibida a tela para impressão de etiquetas. 3. Marque a caixa **Emitir etiquetas com código de barras** para incluir o código de barras do produto na etiqueta. 4. Selecione o tipo de etiqueta: de produtos ou de embalagens e o número de colunas. 5. Informe o Lote e a Validade. 6. Informe a Quantidade e o CRF do responsável. 7. Informe a data em que foi embalado. 8. Clique no botão **Produto do Estoque** para selecionar o item de estoque. 9. Clique em **Imprime**.  Etiquetas de Código de Barra Com intuito de tornar a rotina do almoxarifado ainda mais fácil, o sistema permite a impressão das etiquetas de código de barra. É importante que toda parametrização seja feita no TOTVS Gestão de Estoque, Compras e Faturamento quanto ao uso de Código de Barras, para posterior vinculo o Código de Barra ao produto. Vinculando Código de Barras a um Produto  1. No **TOTVS Gestão Hospitalar** acesse **Cadastros/Estoques/Produto**. 2. Utilize os filtros para facilitar a busca pelo produto. 3. Dê duplo clique sobre o produto cadastrado. 4. Clique na guia **Código de Barras**. 5. Clique em **Incluir** (página em branco). 6. Preencha o número do código de barras. 7. Selecione a Unidade de Medida clicando em '' **...**''. 8. Utilize o campo Observação se necessário. 9. Selecione o Preço de Venda e clique em **OK**.  Imprimindo Etiquetas de Código de Barras de Produto  1. No **TOTVS Gestão Hospitalar** acesse **Estoques/Etiquetas de Código de Barras**. 2. Será exibida a tela para impressão de etiquetas. 3. Clique no botão **Pesquisa** para selecionar o item de estoque. 4. Informe o número de etiquetas. 5. Caso o produto não possua código de barras cadastrado, clique em Inserir para incluir o número do código de barras. 6. Caso o produto possua código de barras cadastrado informe o Lote. 7. Clique em **OK**. 8. Informe a Validade. 9. Clique em **OK**. |
