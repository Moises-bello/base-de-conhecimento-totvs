# Mudança na rotina de exibição de banner no processo seletivo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Novo Portal do Processo Seletivo. |
| **Função:** | Exibição do Banner. |
| **Situação/Requisito:** | Quando era criado um processo seletivo sem data o processo seletivo não era carregado. |
| **Solução/Implementação:** | Foi feita a alteração para carregar processo seletivo sem datas para que posso fazer um banner para divulgação de informações do mesmo.  Processo Seletivos sem datas - Carrega e mostra o banner  Processo Seletivos com data porem com datas passadas - Não carrega e não mostra banner  Processo Seletivo com qualquer data válida - Carrega e mostra o banner. |
