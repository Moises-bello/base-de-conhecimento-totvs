## **01. Visão Geral**

Nessa aba temos são informadas as relações do contrato com a unidade de faturamento e as respectivas tabelas de preços daquele contrato. Para chegarmos até essa tela, devemos ir em **Cadastro> Faturamento> Condições Contratuais**

1. **Unidade de Faturamento:** Informa para qual Unidade de Faturamento (Filiais) aquele contrato está vinculado.
2. **Convênio:** Informa para qual Convênio aquele contrato está vinculado.
3. **Padrão de Faturamento e Codificações:** Campo usado para indicar qual o Padrão de Faturamento e Codificação será usado para o referido Convênio.
4. **Data Vigência:** Data inicial de vigência do contrato. Cada Parcial será analisada a sua data de inicio com um contrato que esteja vigente, para que todos os como lançamentos respeitem as configurações e parâmetros do contrato.
5. **Procedimento:** Campo para informar qual a tabela de preços que será utilizada no contrato para precificação dos Honorários, Diagnose e Terapia.
6. **DTS:** Campo para informar qual a tabela de preços que será utilizada no contrato para precificação dos Diárias, Taxas e Serviços.
7. **Tabelas de Preço Especial:** Campo para informar qual a tabela de preços que será priorizada no contrato para precificar os Honorários, Diagnose e Terapia quando houver a necessidade de regras específicas para cobrança.
8. **Porte Anestésico:** Campo para informar qual a tabela de preços que será utilizada no contrato para precificação dos Portes Anestésicos.
9. **Tabela de Materiais:** Campo para informar qual a tabela de preços que será utilizada no contrato para precificação dos Materiais.
10. **Tabela de Medicamentos:** Campo para informar qual a tabela de preços que será utilizada no contrato para precificação dos Medicamentos.
11. **Unidade Custo Operacional:** Campo para informar o valor da Unidade Custo Operacional (UCO). Esse campo só estará habilitado quando uma tabela do tipo CBHPM estiver informada no campo Padrão de Faturamento e Codificação.
12. **Limite para Apresentação de Contas (em dias):** Campo para informar o número de dias que o convênio aceitará as contas, contando a partir da data do inicio da Parcial. Caso o tempo seja excedido, no momento do encerramento da conta, será exibida mensagem alertando.
