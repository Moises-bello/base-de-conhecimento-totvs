# Cotação Limpar Itens Excluídos

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento |
| **Função:** | Editar cotação. |
| **Situação/Requisito:** | Ao excluir um item da cotação e inserí-lo novamente o sistema não atualiza campo de unidade e quantidade alterados no movimento de origem. |
| **Solução/Implementação:** | Adicionamos um botão para limpar itens excluídos que limpa os registros no banco de dados permitindo assim a atualização  dos campos dos itens ao inserí-los novamente na cotação. |
