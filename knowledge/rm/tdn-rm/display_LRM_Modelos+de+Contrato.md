**Modelos de Contrato**   
Nesta opção de menu serão inseridos os Modelos de Contrato ou modelos de documento utilizados pela empresa. Estes modelos serão atualizados dinamicamente no Microsoft Word.  
   
**Observação:**  
Para a geração do contrato será preciso criar um arquivo de modelo de documento no Word (modelo.dot) e associar a este modelo os Mneumônicos do sistema, que estão na opção de menu Cadastro | Tabelas Adicionais | Mnemônico de Contrato.  
   
   
**Identificação - Modelos de Contrato**   
   
Ao cadastrar ou editar um Modelo de Contrato, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:  
   
   
**Código:**  
Informe o código para o Modelo de Contrato;  
   
**Descrição:**  
Informe a descrição do Modelo de Contrato. Ex.: Contrato Padrão;  
   
**Arquivo:**  
Informe o diretório onde se encontra o modelo de contrato ou modelo de documento correspondente;  
   
**Observação** Ao tentar criar um arquivo com o nome "Con", o Windows exibirá uma mensagem de erro não impeditiva. (A mensagem é exibida pelo Windows e não pelo Imobiliário).  
O termo "con", por exemplo, origina-se da palavra "console" e prepara o sistema para entradas de texto a partir do teclado, trata-se de uma antiga herança que os  sistemas operacionais Windows carregam do MS-DOS.  
Confira a lista de comandos reservados ao sistema: CON, PRN, AUX, CLOCK$, NUL, COM0, COM1, COM2, COM3, COM4, COM5, COM6, COM7, COM8, COM9, LPT0, LPT1, LPT2, LPT3, LPT4, LPT5, LPT6, LPT7, LPT8, LPT9.  
   
**Contrato:**  
Informe se o modelo em questão é um contrato ou não. Se for um contrato, será exibido no cadastro de Incluir Contrato. Se não for um contrato, será exibido na cadastro de Gerar Documento.  
   
**Situação:**  
Marque se o Modelo de Contrato está ativo ou não. Se o campo estiver como "Não", este não poderá ser utilizado pela rotina de geração de documentos no Microsoft Word;
