**Ocorrência**O registro do evento S-XXXX com ID: XXXXX não foi encontrado no TSS.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4409099132055)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Causa**Quando no *log* da importação dos arquivos XML's for apresentada a mensagem **O registro do evento S-XXXX com ID: XXXXX não foi encontrado no TSS**. **Obs.: O XML nao foi importado,** atente-se que se trata de observação, o registro estará no Middleware mas não foi localizado no TSS o XML utilizado para transmissão ao governo. Caso isso ocorra, algumas informações descritivas podem não ser apresentados no Monitor, pois seriam extraídas do XML.  
  
**Solução**Neste cenário não será possível visualizar algumas informações no monitoramento entretanto, não haverá impacto nas integrações de eventos futuros.
