Após as configurações, para gerar o link de acesso ao portal, basta acessar o RM| Módulo Biblioteca| Parâmetros / Configurações| Parâmetros do sistema| Pesquisa | Pesquisa pública, clique no primeiro botão "Gerar URL", embaixo será gerado uma url contendo o contexto, para que seja possível carregar as parametrizações para o portal.

Com a URL gerada, basta informar o domínio parametrizado no IIS.

Ex.: [http://portalcliente.com.br/FrameHTML/web/app/Edu/PortalBiblioteca/#/?c=1&f=1&b=5](http://localhost/FrameHTML/web/app/Edu/PortalBiblioteca/#/?c=1&f=1&b=5)
