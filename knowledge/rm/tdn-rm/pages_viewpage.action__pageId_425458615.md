**Matrícula Disponível para impressão**: Este parâmetro tem como objetivo determinar a exibição da matrícula online.

**Disponível para menores de 18 anos**: Este parâmetro tem como objetivo determinar a exibição da matrícula online, caso o aluno, pai, mãe, responsável acadêmico ou financeiro (caso o responsável financeiro seja pessoa jurídica, o parâmetro não irá influenciar) seja menor de idade e o parâmetro estiver marcado, o mesmo poderá realizar a matricula pelo portal. Campo disponível a partir da versão **12.1.2406**.

**Período de Matrícula**: Determina qual o período letivo que estará disponível na matrícula online.

**Situação de matrícula após a matrícula:** Determina qual a situação de matrícula que o aluno irá assumir após a finalização da matrícula online.  
    => **No Período Letivo**: Nova situação de matrícula que o aluno irá assumir na Matrícula do Período letivo.                                                       
    => **Na Disciplina**: Nova situação de matrícula que o aluno irá assumir nas Turmas/disciplinas (**apenas para o ensino superior**). A partir da versão **12.1.2402** este campo passa a ser disponível também para o ensino básico e é obrigatório preencher para a rematrícula no portal do aluno do ensino básico.

A partir das versões 12.1.2306.159 e 12.1.2310 foram incluídos dois novos campos para parametrização, válidos apenas para o ensino básico, que são:

    => **No itinerário formativo**: nova situação de matrícula que o aluno irá assumir na **matrícula do itinerário formativo**.                                                       
    => **Na Disciplina**: Nova situação de matrícula que o aluno irá assumir na **matrícula nas disciplinas do itinerário formativo.** 

**Permitir alteração de dados cadastrais durante a matrícula**: Permite a alteração dos dados cadastrais durante o processo de matrícula online.

**Exibir créditos financeiros na matrícula online**: Este parâmetro tem como objetivo exibir a quantidade de créditos financeiros que o aluno possui ao selecionar uma turma/disciplina.

**Permite alteração de dados da ficha médica do aluno durante a matricula:**

**Não exige fiador em caso de alunos com 100% de bolsa / desconto:**Se o parâmetro estiver marcado e o aluno tiver 100% de bolsa incondicional e/ou desconto incondicional, não exigido o fiador na matricula do aluno.
