# ECD Substitutiva

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Speed |
| **Situação/Requisito:** | O cliente realizou a entrega da ECD com o Razão Auxiliar Z e o Livro Diário com Escrituração Resumida. Posteriormente foi necessário gerar a ECD substitutiva 2016, pois a data dos atos constitutivos foi informada incorretamente. Ao gerar o arquivo substituto para o Razão Auxiliar não foi exibida a aba J801, para adicionar o arquivo, por isso o PVA apresentou a seguinte mensagem: "Registro Obrigatório não encontrado J801". Paliativamente o cliente foi orientado a gerar o registro diretamente no PVA da EFB. |
| **Solução/Implementação:** | O processo de geração do SPED Contábil foi modificado para que a aba J801 (Termo de verificação para fins de substituição da ECD) seja exibida para todos os tipos de escrituração quando a opção "Indicador de Finalidade da Escrituração" for Substituta. |
