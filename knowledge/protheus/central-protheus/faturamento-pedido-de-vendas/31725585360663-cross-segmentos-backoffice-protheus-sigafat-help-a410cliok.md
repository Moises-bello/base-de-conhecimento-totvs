![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31725570044695) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como resolver o Help A410CLIOK?  
  
**Ambiente**Cross Segmentos - Backoffice Protheus - SIGAFAT - Todas as versões  
  
**Solução**Quando for alteração deve-se verificar se o pedido já foi alguma vez entregue, em caso afirmativo, não será permitido alterar o cliente para não gerar inconsistências.

Para verificar se já foi faturado, pode ser verificado se o "Qtd. Entregue (C6\_QTDENT)" é diferente de zero em alguma das linhas do pedido de venda.

Se necessário, crie um novo pedido de venda com o cliente desejado da alteração.
