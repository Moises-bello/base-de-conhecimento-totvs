Por este processo é possível enviar e-mails para os candidatos que executaram uma prova, informando-os sobre os resultados obtidos nela.

**Configuração do e-mail**

Nesta etapa, o usuário deve informar o assunto e o texto do e-mail, além do tipo (TXT ou HTML).

No texto do e-mail é possível utilizar tags pré-definidas no sistema que representam alguns dados do candidato.

Exemplo

Ao informar a tag ***NOME\_CANDIDATO*** no texto do e-mail, ela será substituída pelo nome do candidato. Assim como, a tag ***INSCRICAO*** será substituída pelo código da inscrição do candidato.  
   
Observação

    O usuário poderá utilizar o texto pré-definido nos parâmetros do sistema para ser enviado no e-mail.  
   
Tipo de operação

   Nesta etapa é possível enviar os e-mails para os candidatos ou realizar uma simulação do envio. Neste último caso, o sistema apenas apresenta em log como o texto será visualizado pelo candidato que receber o e-mail.
