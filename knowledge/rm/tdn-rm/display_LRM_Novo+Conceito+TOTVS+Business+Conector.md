**Conceito**

---

No TOTVS Business Conector existe uma ferramenta chamada Conceito. Com ela é possível importar e exportar dados de uma conexão origem para uma conexão destino. Também guarda quais campos de cada sistema estão envolvidos na integração, e quais as correspondências entre os atributos de origem e destino.   
    
 O conceito é a entidade que armazena as informações de uma integração específica, e é composto pelas abas:

* Ligação
* Propriedades

**Agendamento e Execução Múltipla de Conceitos**  
    
 É possível realizar o agendamento/execução múltiplos de conceitos. Para isso, selecione os conceitos desejados na visão de Conceito e execute o processo "Processar Novo Conceito". Será aberta uma tela para configurar o agendamento do processo. Após a parametrização, os conceitos estarão agendados e serão executados conforme configurado.  
     
 **Configurações Importantes - RM.Host.Service**

Quando o RM.exe estiver sendo executado utilizando o RM.Host.Service, é necessário que altere o usuário relacionado ao serviço, para isto acesse "Serviços | RM.Host.Service | Logon" e informe um usuário que tenha perfil de administrador, logo após a alteração deve se reiniciar o Host.
