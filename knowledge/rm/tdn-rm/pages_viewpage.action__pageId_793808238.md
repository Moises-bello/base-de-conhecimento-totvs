# Introdução

---

Campos complementares(Novo) são os campos que podem ser criados dentro do aplicativo, utilizando uma tela angular.

# Objetivo

---

Complementar informações de um cadastro, com os dados que você desejar e da maneira que desejar, utilizando uma tela mais moderna.

# Criando um campo complementar

---

Para criar um novo campo complementar foi definido as mesmas regras da tela de campos complementares no Winforms:

Os campos **Nome da Coluna** e **Descrição** devem ser informados, além disso o **Nome da Coluna** deve ser único.

É possível selecionar o tipo de campo, por inteiro, alfanumérico, logico, data, real ou texto, é possível também definir ordem, tamanho, valores default e informar uma tabela dinâmica existente para compor o campo complementar.

# Tela de listagem

---

Foi criado uma tela de listagem, onde podemos visualizar todos os campos criados, além de filtrar campos desejados.

# Tela de edição

---

Foi criado também uma tela de edição, que pode ser acessa clicando ao lado esquerdo do campo desejado, acessando a opção editar. Não é possível editar todos os dados dos campos complementares, exemplo Nome da Coluna ou tipo de campo.

# Ativar/Desativar campos complementares

---

Foi criado uma funcionalidade para ativar e desativar campos complementares

O botão de excluir apenas desativa o campo complementar

Importante

Não é possível excluir um campo complementar, apenas desativa-lo

# Campos complementares associado à tabela dinâmica

---

Foi criado uma funcionalidade para associar um campo complementar à uma tabela dinâmica.
