# Toten de senha não exibe especialidade corretamente

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Toten |
| **Situação:** | Ao acessar o plantão no painel de classificação de risco, remover o plantão configurado para a unidade do dia e acessar o toten de senhas, o sistema continuava exibindo as especialidades que não estavam mais ativas no sistema. |
| **Solução:** | Realizado ajuste no sistema para listar no toten somente as senhas de especialidades ativas. |
