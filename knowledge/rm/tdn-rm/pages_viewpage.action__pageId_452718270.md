No cadastro de funcionários poderá existir os dados bancários onde serão informados os dados para depósito de salário do funcionário. Qualquer alteração no número do banco, agência, conta corrente ou código da operação gerará um registro no histórico de dados bancários. Este histórico será preenchido:  
1) Pela alteração de dados bancários no cadastro do funcionário;

2) Pela edição do usuário diretamente no histórico de dados bancários;

3) Pela importação de dados.

4) Pelo botão 'Desmarcar', disponível na tela.
