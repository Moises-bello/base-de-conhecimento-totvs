# Rotina Municipal DES-BH

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Rotina Municipal DES-BH |
| **Situação/Requisito:** | Cliente solicita que a DES BH seja gerada de forma centralizada. |
| **Solução/Implementação:** | Implementado campo "Gerar Centralizada" em “Rotinas Legais\Rotinas Municipais\Apuração de ISS\Selecionar estado de Minas Gerais\DES”.  Este campo foi criado para permitir centralizar informações de filiais que tenham mesma inscrição municipal e pertençam ao mesmo município da filial selecionada para geração da rotina. Vide campo criado:    Obs.: Se o campo "Gerar Centralizada" estiver desmarcado, sistema irá gerar a DES-BH apenas com os dados da filial selecionada. |
