# GetExternalGrammar

Retorna um xml contendo o schema de todos os tipos utilizados pelo serviço. Os schema dos tipos são extraídos somente da tabela principal do dataset do RMSDataServer.

## Exemplo de utilização

Método: GET

URL: <http://localhost:8051/rmsrestdataserver/service/globais/schema>
