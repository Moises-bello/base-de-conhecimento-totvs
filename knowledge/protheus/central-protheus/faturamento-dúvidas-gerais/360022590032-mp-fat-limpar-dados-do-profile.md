**Dúvida**Como realizar a limpeza dos dados do Profile?  
   
 **Ambiente**Microsiga Protheus – Faturamento – A partir da versão 11.80  
   
**Solução**Realize a limpeza dos dados profile e realize o teste.

Para limpar dados de usuários:

**1.** No ambiente Configurador **SIGACFG**, na opção Ambiente - Cadastro  - Manutenção de Profile, localizar o usuário que terá suas configurações reiniciadas;  
**2.** Caso seja necessário reiniciar as configurações, clique na opção Excluir;  
**3.**Será apresentada uma tela para definir se será apagado somente o registro posicionado ou todos os registros do usuário.
