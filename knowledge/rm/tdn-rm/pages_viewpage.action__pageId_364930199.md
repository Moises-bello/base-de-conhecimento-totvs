# MATRÍCULA EM TURMA/DISCIPLINA SEM VAGA - LISTA DE ESPERA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matrícula em Turma/Disciplina sem Vaga - Lista de Espera* |
| **Situação/Requisito:** | *O processo de matrícula está colocando o aluno em lista de espera quando não há vagas na turma/disciplina mesmo possuindo a permissão especial de Matricular em turmas com excesso de alunos.* |
| **Solução/Implementação:** | *Ajuste na validação do processo de matrícula para que quando não se tem vaga na turma/disciplina e o usuário tenha permissão de matricular em turmas com excesso de alunos, o processo ao final de sua execução coloque o aluno como matriculado (situação de matrícula que foi escolhida no processo) e não na situação de matrícula que indica que é uma lista de espera.* |
