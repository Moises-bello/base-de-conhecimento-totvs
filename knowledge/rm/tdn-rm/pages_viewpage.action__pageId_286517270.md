# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Alteração do código de Contas Contábeis |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do Processo**  Processo para correção de código da conta contábil ou movimentações de contas dentro do plano para eventuais ajustes:    **Regras Gerais**  Ao alterar o código de uma conta deve ser considerada a hierarquia do plano, ou seja, se a conta for transferida de um grupo para outro, as contas sintéticas do novo grupo já devem estar criadas quando da alteração do código.  **Parametrização Necessária**  1 - Ao acessar o processo informe a conta atual e seu novo código, após clique em incluir para que os dados sejam informados na lista de alteração:  2 - A quantidade de dígitos da nova conta deve ser igual da conta anterior    3- Após esta fase deve-se informar uma justificativa para a alteração do código da conta e executar o processo. |
| **Observações:** | Recomenda-se fazer pequenas listas de contas a serem alteradas para que o processo fique mais rápido e evite-se retrabalho, já que se houver qualquer erro no processamento da lista informada, as demais alterações serão descartadas. |
