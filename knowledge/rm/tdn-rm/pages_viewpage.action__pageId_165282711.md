**Introdução**

Procedimentos para alterar a configuração do XSLT de saída (XML enviado para o Protheus).

**Desenvolvimento/Procedimento**

Acesse o RM:

Acessar cadastro de Transformação:

Edite o registro "Ativo Fixo" referente a versão 1.001, logo em seguida edite o campo "XSLT Saída":

Altere a informação de destacada abaixo para "CODPATRIMONIO":

Salve as informações e realize os testes de integração.

Esta alteração fara com que o campo "Código do Patrimônio" seja enviado na tag CODE do XML que será integrado ao Protheus.

Para maiores informações:
