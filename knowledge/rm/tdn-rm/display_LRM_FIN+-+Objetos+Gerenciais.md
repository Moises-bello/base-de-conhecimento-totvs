O relatório passa a solicitar o preenchimento de três parâmetros: Data Inicial, Data Final, Apenas Compensados? (S)im ou (N)ão

Se o usuário optar por exibir apenas os extratos compensados, o Saldo Anterior considera todos os extratos compensados com data de compensação anterior à data inicial, serão listados todos os extratos compensados com data de compensação entre a data inicial e a data final. Caso contrário, o Saldo Anterior considera todos os extratos com data anterior à data inicial, serão listados todos os extratos não cancelados com data entre a data inicial e a data final. Caso haja mais de uma conta/caixa contemplada pelo filtro, o relatório faz uma quebra de página, exibindo cada uma separadamente.
