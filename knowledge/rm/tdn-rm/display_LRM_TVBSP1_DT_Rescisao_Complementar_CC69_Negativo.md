# RESCISÃO COMPLEMENTAR NÃO PERMITE CC 69 NEGATIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão Complementar* |
| **Situação/Requisito:** | *Na Rescisão Complementar não está permitindo evento de CC 69 (Base FGST Dissídio) com valor negativo.*  *Quando ocorre em um mesmo envelope Diferença Salarial por Dissídio e Rescisão Complementar por Dissídio, caso um dos processos retorne Base FGTS negativa, o valor deve ser lançado para abater na Base FGTS apurada no outro processo.* |
| **Solução/Implementação:** | *Ajuste na Rescisão Complementar para permitir evento de CC 69 (Base FGST Dissídio) com valor negativo.* |
| **Chamados   relacionados:** | *TVBSP1, TVCEYX* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
