Campo CEI não é apresentado nas Movimentações

FAQ: **Campo CEI não é apresentado nas Movimentações**

|  |  |
| --- | --- |
| Produto: | Unspecified |
| Ambiente: | Unspecified |
| Versão: | 11.00 |

Sintoma

* **Sintoma**

O Campo CEI do movimento não é apresentado na inclusão de movimento.

Causa

* **Causas**

1- O tipo de movimento não esta parametrizado para “Gerar Escrituração”.

2- Não existir tributo, seja no item ou no movimento onde o tipo do tributo seja **INSS.**

Solução

* **Solução**

1- Parametrizar o tipo de movimento para gerar escrituração.

2- Parametrizar um tributo seja no item ou no movimento onde seu tipo seja **INSS.**

Observações
