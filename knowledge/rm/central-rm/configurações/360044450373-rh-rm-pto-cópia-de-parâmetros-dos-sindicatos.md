**Dúvida**  
Como realizar uma cópia de parâmetros do Sindicatos?

**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - Todas as versões

**Solução**  
Para realizar uma cópia de Sindicatos, siga o passo a passo abaixo:  
  
Acesse o menu **Configurações | Parametrizador,** ao abrir o assistente clique em avançar. Selecione o processo **Sindicato** e avance novamente.   
![parametrizar_sindicato.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29588925547927)

Selecione o Sindicato no qual deseja copiar os parâmetros, e acesse a opção **Processos | Copiar parâmetros do sindicato:**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29588972663959)

Insira um código para o novo sindicato juntamente com uma descrição e execute.   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29588925552407)

**Saiba mais**  
Para mais informações sobre o sindicato, acesse a documentação [Sindicato](https://tdn.totvs.com/display/public/LRM/Sindicato)
