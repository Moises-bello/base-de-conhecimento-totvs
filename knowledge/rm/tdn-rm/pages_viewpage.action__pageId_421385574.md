Essa rotina é realizada com o coletor iniciando/disparando uma requisição para o ERP, isto é, o Coletor Móvel de maneira manual e/ou automática acionará um WebService disponibilizado pelo ERP passando algumas informações e este retornará as informações para o coletor.  
 Para realizar a sincronização dos dados básicos, o usuário deverá informar os seguintes parâmetros (login, senha, coligada e o caminho do WebService).

**Importante**

Para que ocorra a exportação dos dados básicos para o coletor, o Coletor Móvel utilizado deve estar associado à pelo menos uma Folha Tarefa, o usuário deve está ativo no sistema e a opção "Permite Sincronizar Dados" deve está marcada.
