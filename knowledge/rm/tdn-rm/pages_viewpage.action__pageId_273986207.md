# Relatório Razão Gerencial Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Razão Gerencial Contábil |
| **Situação/Requisito:** | Ao gerar o Relatório Razão Gerencial / Contábil, para um período anual, o saldo atual é exibido corretamente, porém ser não existir movimentação no período informado o saldo é exibido zerado, mesmo havendo saldo anterior. |
| **Solução/Implementação:** | O Relatório Razão Gerencial / Contábil foi modificado para que o saldo atual leve em consideração o saldo anterior quando o período informado não possuir movimentação. |
