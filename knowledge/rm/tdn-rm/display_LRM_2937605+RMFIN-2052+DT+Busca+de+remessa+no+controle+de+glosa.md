# Busca de remessa no controle de glosa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Glosa |
| **Situação:** | Ao selecionar o paciente o sistema informa que a remessa não foi localizada. |
| **Solução:** | Alterada a pesquisa da remessa para que utilize a data de entrada do paciente e não a de saída, pois o faturamento pode ser antes da data de saída. |
