**Banco de Horas Funcionário**   
**Usa compensação manual de horas:** Para compensar as horas utilizando banco de horas por período o campo Utiliza Compensação Manual de Horas no parâmetro do funcionário deve estar marcado. Ao marcá-lo será exibido três tipos de ocorrências:

* **Atrasos:** Marcando este campo, os atrasos irão para o banco de horas, caso contrário, irão para o movimento.
* **Faltas:** Marcando este campo, as faltas irão para o banco de horas, caso contrário, irão para o movimento.
* **Horas Extras:** Marcando este campo, as horas extras irão para o banco de horas, caso contrário, irão para o movimento.

**Observações:**  
Ao marcar a opção de horas extras serão enviadas para o banco as ocorrências de horas as extras de compensado, descanso, feriado e normal.  
As Horas só serão lançadas para o banco de horas se as mesmas estiverem autorizadas e os eventos a serem calculados estiverem com a opção Utiliza Compensação Manual de Horas marcada.
