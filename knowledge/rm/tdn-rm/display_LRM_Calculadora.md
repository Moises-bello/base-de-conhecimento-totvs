O RM possui uma calculadora embutida dentro do próprio sistema, para a maior facilidade de uso principalmente de cálculos:

Para abri-la à qualquer momento, aperte **CTRL + F6**. Para acessá-la pelo **RM**, alguns produtos tem o botão específico dentro de seu sistema, mas ela também pode ser acessada a qualquer momento seguindo a ordem de abas: **Gestão → Calculadora**

Após utilizá-la, para transferir os valores, basta clicar no botão **Transferir.**O valor vigente será transferido para a **Área de Transferência do Sistema Operacional (Copia/Cola),**então, basta acessar o campo necessário e colar o resultado transferido.
