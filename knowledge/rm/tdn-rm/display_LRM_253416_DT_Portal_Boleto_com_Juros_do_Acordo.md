# Portal - Extrato Financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Portal - Extrato Financeiro |
| **Situação/Requisito:** | No Portal, o extrato financeiro não mostrava os valores discriminados de juros/acréscimo/desconto do Acordo Financeiro |
| **Solução/Implementação:** | - Otimizado no Portal | Extrato Financeiro, quando está marcado o Parâmetro Fluxus | Contas a Receber | Acordo – “Detalhar valores do Acordo no Lançamento Gerado (Desconto, Acréscimo, Juros)”, o sistema irá demonstrar os valores detalhados do acordo.  - O valor Bruto do boleto também demonstrará a somatória do valor original com os valores do acordo.  - No Parâmetros Educacional | RM Portal, foi acrescentado no campo “Extrato financeiro – Colunas a Exibir”, as opções “Acréscimo do Acordo, Juros do Acordo, Desconto do Acordo.  Obs.:  O relatório utilizado para impressão do boleto deverá contemplar estes campos. Verificar nos Parâmetros Educacional | Tesouraria | Relatórios, qual o relatório identificado para impressão de boleto. |
