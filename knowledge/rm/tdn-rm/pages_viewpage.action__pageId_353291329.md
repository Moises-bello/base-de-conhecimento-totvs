# NF-e - 4.00 - DANFE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | NF-e - 4.00 - DANFE |
| **Situação/Requisito:** | Ao transmitir uma nota fiscal com o tipo de frete como ***"Transporte próprio Destinatário" (Tag ModFrete=4)*** ou ***"Transporte próprio Remetente" (Tag ModFrete=3)***, a Danfe é impressa como "Sem Frete". |
| **Solução/Implementação:** | Efetuada melhoria para que sejam apresentadas as opções ***"Transporte próprio Destinatário" (Tag ModFrete=4)*** ou ***"Transporte próprio Remetente" (Tag ModFrete=3)*** na DANFE.  - Se tratando de "Transporte próprio Destinatário" vai ser preenchido na DANFE como "PRÓPRIO DESTINATÁRIO".  - SE tratando de "Transporte próprio Remetente" vai ser preenchido na DANFE como "PRÓPRIO REMETENTE". |
