Desconto do tipo valor.O sistema permite ao usuário criar mais de um evento com este código de cálculo.

**Observação**

Este evento será utilizado somente para os eventos fixos da pasta Códigos Fixos em Cadastro | Funcionários | pasta Base de Cálculo, e que estejam com número de vezes determinado.  
 Quando cadastrados os Códigos fixos no Cadastro de Funcionários e for informado o número de vezes que cada um deverá ser lançado na folha, se o usuário efetuar algum cancelamento, o sistema acumulará automaticamente mais um lançamento (nº de vezes) no campo Códigos Fixos (Cadastros | Funcionários | Base de Cálculos | Códigos Fixos).
