# Disciplinas do EducaMobile

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS EducaMobile |
| **Função:** | Acesso às disciplinas EducaMobile |
| **Situação/Requisito:** | Ao acessar o menu disciplinas do educa mobile, são listadas as disciplinas do aluno, mas ao clicar em uma disciplina que esteja com status diferente de cursando exibe um erro na tela de detalhes da disciplina selecionada. A situação ocorre para as disciplinas que possuem status de resultado final. |
| **Solução/Implementação:** | Aperfeiçoado o acesso às disciplinas no EducaMobile uma vez que a disciplina se encontra em status diferente de "cursando". |
