![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29621346868887) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Qual o objetivo do relatorio **SmartView ESTSV022 - Lista de Produtos**, e como configurar?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - A partir da versão 12.1.2310

**Solução**

A **Listagem de Produtos** permite visualizar os produtos existentes na base de dados de uma maneira simples, intuitiva e objetiva. Este objeto de negócio permite a seleção de múltiplas filiais para exibição dos resultados e caso nenhuma filial seja selecionada, o objeto de negócio irá trazer os resultados da filial corrente.
