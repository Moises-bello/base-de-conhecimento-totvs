![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25786518631703) Tempo aproximado para leitura: **00:05:00 min** **Dúvida** Existe Revisão para Alteraçao do Campo "Caução" (CN9\_FLGCAU) no contrato ?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Gestão de Contratos - Todas as versões

**Solução**Não existe nenhum Tipo de Revisão  no módulo Gestão de Contratos que permita alterar o campo "Caução"  (CN9\_FLGCAU) do cabeçalho do Contrato, que define se o contrato possui ou não caução.

A unica Revisão para o processo de Caução que existe é para o ajuste do  campo percentual mínimo de Caução (CNA9\_MINCAU)  para Contratos com Caução Manual, conforme artigo abaixo:

[Cross Segmentos - Totvs Backoffice Protheus - SIGAGCT - Como alterar o campo de percentual mínimo de caução (CN9\_MINCAU) em contratos com a situação vigente ?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360027025671-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGAGCT-Como-alterar-o-campo-de-percentual-m%C3%ADnimo-de-cau%C3%A7%C3%A3o-CN9-MINCAU-em-contratos-com-a-situa%C3%A7%C3%A3o-vigente?source=search)
