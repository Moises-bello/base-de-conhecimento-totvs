# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

A classe PlanRMFactory disponibiliza métodos estáticos para criação de instâncias de PlanRMWorkbook.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
|  | Cria uma instância de PlanRMWorkbook. |
|  | Cria uma instância de PlanRMWorkbook a partir de uma planilha existente. |
|  | Cria uma instância de PlanRMWorkbook a partir de um objeto existente em memória. |
|  | Cria uma instância de PlanRMWorkbook a partir de um registro no banco de dados. |
|  | Retorna a extensão padrão para o formato de planilha definido no objeto PlanRMWorkbook. |
