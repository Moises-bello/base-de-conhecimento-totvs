**Dúvida**

type mismatch on \* on MAFISVICMS(MATXFIS.PRX) 11/02/2019 14:19:25 line : 14813  
  
**Ambiente**

Protheus – Livros fiscais – A partir da versão 12.1.17]  
  
**Solução**

Para solucionar essa dúvida, realize os seguintes passos:  
1. Abra o configurador;  
2. Abra o campo de parâmetros;  
3. Abra o campo MV\_ICMPAD;  
4. Altere o conteúdo para NUMÉRICO.
