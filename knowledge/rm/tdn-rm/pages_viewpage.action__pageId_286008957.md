# Objetivo

       O objetivo deste documento é demostrar como utilizar corretamente a caixa de edição "hora-minuto" no formulário metadados.

# Configuração

---

         Neste documento iremos demonstrar o passo a passo para configurar o uso da caixa de edição de hora.

**Passo a passo para configurar:**

false.1ª Passo

No menu "Tipo de Dados", crie um tipo: 'System.TimeSpan', conforme imagem abaixo:

2ª Passo

Em seguida é necessário criar uma nova tabela e no campo 'HORAMINUTO' associar o Tipo de Dados ao 'TimeSpan' criado anteriormente.

3ª Passo

Posteriormente, no menu "Modelo de Negócios", adicione a tabela criada anteriormente e na aba 'Controles', defina o tipo de controle como: "Caixa de edição de hora".

       Agora é só preencher as próximas telas e gerar o projeto Metadados com sucesso!
