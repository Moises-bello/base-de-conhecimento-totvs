# EXCLUSÃO DE MATRIZ CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Educacional* |
| **Função:** | *Excluir matriz curricular* |
| **Situação/Requisito:** | Ao tentar excluir a matriz curricular, caso essa tenha oferta em diferentes filiais, o usuário recebia apenas erro de FK. |
| **Solução/Implementação:** | Feito ajuste no momento de excluir a matriz curricular para avisar ao usuário que essa matriz está sendo ofertada em diferentes filiais, impedindo assim erro de FK. |
