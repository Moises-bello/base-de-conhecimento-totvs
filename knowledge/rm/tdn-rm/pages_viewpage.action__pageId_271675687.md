# DIRF

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Construção e Projetos.* |
| **Módulo:** | *TOTVS Folha de pagamento.* |
| **Função:** | *Emissão DIRF.* |
| **Situação/Requisito:** | *O valor da dedução para o 13º salário de dependente está sendo multiplicado pelo número de dependentes que incide IRRF quando informado nas demais chapas estando o parâmetro "Calcular IRRF/INSS de múltiplos vínculos sem chapa centralizadora" desmarcado.* |
| **Solução/Implementação:** | Quando o parâmetro "Calcular IRRF/INSS de múltiplos vínculos sem chapa centralizadora" estiver desmarcado o sistema irá obter o valor da dedução de 13º salário dos dependentes somente da chapa centralizadora evitando duplicar os valores de dedução*.* |
