# Integração RM x TAF

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Geração de Registros para Integração TAF |
| **Situação/Requisito:** | Cliente está solicitando a implementação da geração do registro T157 (Cadastro de Obras) |
| **Solução/Implementação:** | Foi implementado o registro T157 no Layout TAF.  **Dicas para geração do registro:**  Para gerar o registro T157 o lançamento fiscal deve ser vinculado ao Projeto.        No cadastro de Projetos o campo "Indicativo de Prestação de Serviços" deve ser diferente de "Não se Aplica".  Caso seja "Não se Aplica" o mesmo não será gerado. |
