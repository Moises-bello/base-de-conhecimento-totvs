# Lançamentos com divisão de repasse não aparecem na folha de pagamento de prestadores

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Folha de pagamento de prestadores |
| **Situação/Requisito:** | O sistema não estava apresentando as divisões de repasse na tela de folha de pagamento de prestadores |
| **Solução/Implementação:** | Foi alterada a rotina de criação de divisão de repasse para ser feita a inserção na tabela de repasse |
