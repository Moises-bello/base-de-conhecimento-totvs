![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20949347615511) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como incluir um movimento em um cadastro de banco novo?  
  
**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA100 - Todas as versões  
**Solução**

Antes de realizar o procedimento precisa alterar a **data base** do sistema, caso queira que o saldo inicial comece no dia **02/02** precisa alterar a data base do sistema para o dia 01/02, pois o saldo final é o saldo inicial do banco.

Após a criação do **cadastro do banco**, acesse **Atualizações** -> **Movimentação Bancários** -> **Movimentos Bancários**.

Selecione **Outras Ações -> Receber**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20949347621143)

Informe os dados do banco, valor e clique **Salvar**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20949347621911)
