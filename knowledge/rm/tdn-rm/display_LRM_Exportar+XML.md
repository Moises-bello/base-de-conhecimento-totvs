Este processo permite gerar arquivos de exportação em lote para envio de dados para o eSocial.

**EXPORTAR XML de RETORNO**

Ao marcar este parâmetro é possível realizar a exportação em lote do XML de retorno do eSocial dos eventos periódicos S-1200 e S-1210 e não periódicos S-2299 e S-2399 (disponível para quem utiliza o middleware).

false

**A Exportação XML de retorno está** **disponível** **a partir das versões:**

* 12.1.33.255
* 12.1.34.154
* 12.1.2205.100
* e Superiores.

**ATENÇÃO:**  
O sistema irá considerar para geração do XML os registros da Fila de Eventos e do Período de Apuração conforme seleção e com status diferente de "0-Pendente".
