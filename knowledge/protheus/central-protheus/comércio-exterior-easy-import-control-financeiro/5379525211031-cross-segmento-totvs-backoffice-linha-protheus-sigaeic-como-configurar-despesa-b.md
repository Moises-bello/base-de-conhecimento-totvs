![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como configurar a despesa base de ICMS?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**Para cadastro da despesa base de imposto, configurar conforme passo a passo:

1. Acesse o módulo 17- SIGAEIC, em Atualizações -> Financeiro -> Cadastro de despesas (EICA110), selecione o incluir ou alterar.   
   Preencha os campos:   
   Campo YB\_BASECUSS - Base de custo    = SIM  
   Campo YB\_BASEIMP - Base de imposto  = NÃO  
   Campo YB\_BASEICM - Base de ICMS       = SIM  
   Na aba ICMS UF, para o estado do importador, preencher o campo como 1- Sim.
