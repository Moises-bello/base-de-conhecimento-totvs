# Exibir observação da Agenda - Agendamento de Exames

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Atendimento / Agendamento / Agenda de Atendimentos / Agendamento de Exames | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server® / Oracle® |
| **Tabelas Utilizadas:** | SZAGENDAMENTO |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

A melhoria possibilita que o  TOTVS Gestão Hospitalar exiba as observações da Agenda de Atendimentos no processo de Agendamento de Exames.

## Procedimento para Utilização

Observação

Para que ocorra a exibição da observação durante o processo de Agendamento de Exames, é necessário que a observação tenha sido informada no Cadastro da Agendas da agenda correspondente.

Acesse o Cadastro das observações no menu **Cadastros / Uso Geral / Agendamento / Agendas.**

Selecione uma agenda.

Informe uma observação no campo **OBS** e salve o Registro.

1. Acesse menu **Atendimento** / **Agendamento** / **Agenda de Atendimentos.**
2. Clique no botão **Agendar Exames.**
3. Preencha os seguintes dados obrigatórios para avançar na etapa **Dados do Paciente** / **Avançar.**

   1. **Paciente**: Nome do Paciente.
   2. **Atividade**: Atividade realizada no atendimento.
   3. **Especialidade do Agendamento**: Especialidade clínica do Atendimento.
   4. **Exames**: Exames agendados para o atendimento.
4. Clique no botão **Incluir Agenda**
5. Selecione a agenda na qual a observação foi cadastrada, conforme observação no início deste documento.
6. A observação será exibida após a seleção da agenda.
