Dúvida**É possível vincular Nota de Formação de Lote DUE no release 12.1.17?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Export Control* – 12.1.017.  
  
**Solução**Para tratar no release 12.1.017 foi disponibilizado o ponto de entrada [DU400NFREM](http://tdn.totvs.com/pages/viewpage.action?pageId=412887020).

A funcionalidade de vinculo de Notas para Formação de Lotes somente será disponibilizada no release 12.1.023 conforme divulgado no boletim: [Rotina de vinculação das notas fiscais de saída para formação do lote de exportação](http://tdn.totvs.com/pages/viewpage.action?pageId=444609121)  
Este tipo de operação não era contemplado no padrão das versões anteriores do Protheus se tornando uma funcionalidade padrão a partir do release 12.1.023 do Protheus.
