# CANCELAMENTO DE CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Processo de cancelamento de contrato e alteração de situação de matrícula |
| **Situação/Requisito:** | Sistema está cancelando o lançamento de bolsa de crédito quando o lançamento do aluno está baixado no cancelamento de contrato e alteração de situação de matrícula com cancelamento de contrato. |
| **Solução/Implementação:** | Não permitir o cancelamento de lançamentos de origem ou lançamentos de bolsa de crédito se um dos dois lançamentos tiver um status diferente de "Em aberto - 0" ou "Cancelado - 2" no cancelamento do contrato independente do processo que chamar o cancelamento. |
