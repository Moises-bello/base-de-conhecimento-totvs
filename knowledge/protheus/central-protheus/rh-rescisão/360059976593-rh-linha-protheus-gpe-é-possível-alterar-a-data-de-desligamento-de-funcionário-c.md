**Dúvida**É possível alterar a data de desligamento de funcionário onde o período que ele foi desligado já esta fechado?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O Sistema não permite fazer alteração de data de desligamento de funcionário onde o período de cálculo que houve o desligamento já esta fechado, pois para alterar a data de desligamento é necessário o recálculo da rescisão e pelo fato do período já estar fechado, o sistema não permite o recálculo.

Com o período fechado, não é possível alterar informação em nenhum roteiro de cálculo: **RES, FER, BEN, PLA,** **VRF e VTR**.
