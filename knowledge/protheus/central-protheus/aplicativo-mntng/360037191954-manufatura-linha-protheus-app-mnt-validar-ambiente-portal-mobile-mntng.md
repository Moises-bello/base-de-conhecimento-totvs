**Dúvida**Como validar o ambiente no **Portal Mobile**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Aplicativo MNTNG - Versão 12  
  
**Solução**Com a empresa cadastrada, é necessário realizar o *login* com o usuário criado no**[Portal Mobile](https://portalmobile.ngi.com.br/)**.  
Estando logado, vá para a aba de **Configurações,**informe o alias Mingle cadastrado. Essa informação deve ser preenchida corretamente para o bom funcionamento do produto. O botão **Validar** **conexão** que é representado pela **seta →** avalia se o serviço se encontra *online*.

![](https://totvssuporte.zendesk.com/hc/article_attachments/14123400159383)

Se o serviço está *online*, é apresentada uma opção de **Validar ambiente.** Ao selecionar a mesma, informe seu **login** e **senha** do **Protheus**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/14123432468119)

Desta forma será validado se o ambiente está apto a utilizar o **Aplicativo**. Caso uma das filiais não esteja adequado, será apresentado em tela o que há de errado com a mesma. Caso uma das funcionalidades esteja adequada será possível prosseguir, porém é necessário realizar a adequação para utilizar a funcionalidade que não está apta. É necessário realizar essas configurações antes de iniciar a próxima etapa.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/14123800093847)
