**Fiador Pessoa Física**

Através deste menu poderemos cadastrar os Fiadores Pessoa Física a serem  informados no momento da venda.  
Um Fiador, é aquele que se responsabiliza por alguém pelo cumprimento de uma obrigação ou de um dever, é um avalista.  
   
**Aba Identificação**  
   
**Código:** Este campo será gerado automaticamente pelo sistema.  
**CNPJ/CPF:** Informe o CNPJ ou CPF do Fiador.  
**Atenção:**  
Este campo pode ser único ou não. Irá depender se o parâmetro estiver marcado no menu **Opções | Parâmetros | RM SGI | Parâmetros Gerais**, a opção 'CGC / CPF Único para Fiadores'.  
**Nome:** Informe o nome completo do Fiador (Obrigatório).  
**Tipo de Pessoa:** Este campo será gerado automaticamente pelo sistema. Será preenchido como Pessoa Física.

**Cliente/Fornecedor:**  Esse campo é para associar a pessoa ao Cadastro de Cliente/Fornecedor para rastrabilidade da LGPD (Permitir marcarar os dados e sua proteção).  
**Observação:** Caso necessite, utilize este campo para alguma informação complementar do vendedor.  
   
**Aba Pessoa Física**  
   
**C.I.:** Informe o registro geral do Fiador;   
**Data Emissão:** Informe a data de emissão do R.G.;  
**Órgão Emissor:** Informe o órgão emissor do R.G.;  
**Data Nascimento:** Informe a data de nascimento do Fiador;  
**Profissão:** Informe qual a profissão do Fiador, o sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Profissões;   
**Local Trabalho:** Informe o local de trabalho do Fiador;  
**Nome Pai:** Informe o nome do pai do Fiador;  
**Nome Mãe:** Informe o nome da mãe do Fiador;  
**Estado Civil:** Informe qual o estado civil do Fiador, o sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Estado Civil;  
**Naturalidade:** Informe qual a naturalidade do Fiador, o sistema apresentará na lista de opções os tipos já cadastrados no sistema;  
**Nacionalidade:** Informe a nacionalidade do Fiador;  
**Tel. Comercial:** Informe o telefone comercial do Fiador;  
**Conjuge:** Informe o cônjuge do Fiador, o sistema apresentará na lista de opções os cônjuges já cadastrados.  
**Sexo:** Informe o sexo do Fiador;  
   
**Aba Endereço**  
   
**Logradouro:** Nome da rua, Av, praça, etc.  
**Número:** Número do endereço  
**Tipo de Endereço:** O sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Tipo Endereço (Obrigatório);  
**Complemento:** Complemento do endereço  
**Bairro:** Bairro do Fiador  
**CEP:** CEP do Fiador  
**Cidade:** Cidade do Fiador  
**Estado:** O sistema apresentará na lista de opções todos os Estados já cadastrados (Obrigatório);  
**Telefone:** Telefone do Fiador  
**Ramal:** Ramal do Fiador  
**Celular:** Celular do Fiador  
**Fax:** Fax do Fiador
