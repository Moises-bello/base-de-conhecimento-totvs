# Relatório Retrospectiva

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Retrospectiva |
| **Situação/Requisito:** | Ao realizar a emissão do relatório retrospectiva informando centro de custo que contenha uma máscara grande o relatório corta o código de centro de custo. |
| **Solução/Implementação:** | O relatório Retrospectiva de Saldos foi alterado para que o centro de custo e as contas, gerencial e contábil, sejam exibidas sem cortes. O campo Código Reduzido também adotou o mesmo comportamento. Vale ressaltar que o campo Descrição será redimensionado de acordo a quantidade de caracteres que estivem disponíveis na linha, ou seja, a quantidade máxima de caracteres que uma linha comporta menos a quantidade de caracteres utilizados pelas outras colunas exibidas pelo relatório. |
