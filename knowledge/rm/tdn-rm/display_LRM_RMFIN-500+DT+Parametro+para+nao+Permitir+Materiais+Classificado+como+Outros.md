# Parâmetro para não Permitir Materiais Classificado como Outros

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Saude. |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prescrição Médica. |
| **Situação:** | Ao fazer uma prescrição médica o sistema ao selecionar o material estava apresentando produtos cadastrados como outros e assim permitindo que o médico prescrevesse itens que não são MATMED. |
| **Solução:** | Criado o parâmetro que só permitirá prescrever produtos classificados como materiais, medicamentos, órtese e prótese. |
