# ENVIAR EMAILS PARA FUNCIONÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Enviar emails para funcionários* |
| **Situação/Requisito:** | Ao tentar "Enviar e-mails para funcionários" no final do processo é apresentado uma tela de erro, onde não é informado quais funcionários não enviou o email. |
| **Solução/Implementação:** | Ao gerar o processo de "Enviar e-mails para funcionários", caso exista algum e-mail incorreto deve ser apresentado ao final do processo a tela informando que o processo foi concluido com resalvas, e no log informar quais chapas não foi enviado o e-mail. |
| **Chamados relacionados:** | TULKRU, TTMUBV |
