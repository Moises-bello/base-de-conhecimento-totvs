# Escrituração - Lançamento Fiscal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Totvs Gestão Fiscal |
| **Função:** | Escrituração - Lançamento Fiscal |
| **Situação/Requisito:** | Ao realizar o Processo de Escrituração de lançamentos Fiscais (.Net), não é carregado para o Lançamento Fiscal o município  informado no movimento, e sim o do Cliente Fornecedor. |
| **Solução/Implementação:** | Ajustado o Processo de Escrituração Fiscal para escriturar corretamente o município para o  Lançamento Fiscal conforme informado no Movimento. |
