![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22686183767191) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como excluir os dados da rotina Manutenção arquivo da DIRF?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**1. Entre na rotina **Manutenção Arquivo** pelo caminho **>Miscelânea >DIRF >Manutenção Arquivo**;

2. Posicione no registro que quer excluir:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12238306528919)

3. Clique em **>Outras Ações >Excluir**:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12238346529303)

4. Clique no botão **Confirmar**, para confirmar a exclusão:  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12238405141399)  
  
Sistema excluirá o registro da rotina Manutenção Arquivo.
