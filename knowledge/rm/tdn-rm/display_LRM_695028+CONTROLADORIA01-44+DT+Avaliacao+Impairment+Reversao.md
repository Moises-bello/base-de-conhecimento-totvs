# Avaliação patrimonial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Processos de Avaliação, Impairment e Reversão de Impairment |
| **Situação/Requisito:** | Não é possível realizar a avaliação patrimonial de um bem que não deprecia. O processo de avaliação obriga a informar uma taxa superior a zero. |
| **Solução/Implementação:** | Os processos de avaliação patrimonial, impairment e reversão de impairment foram alterados para que seja possível informar taxa de depreciação ou vida útil restante iguais ou superiores a zero. Essa modificação tem como embasamento legal o CPC 28. |
