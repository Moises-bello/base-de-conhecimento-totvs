# PERIODICIDADE DE EXAMES ATRAVÉS DE FÓRMULA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão de Pessoas |
| **Função:** | Periodicidade de exames através de fórmula |
| **Situação/Requisito:** | Cliente precisa executar o cálculo da periodicidade de exames com base em uma fórmula, porém as fórmulas do Vitae/SSO fazem uso do contexto de pessoa, o que impacta quando a pessoa tem múltiplos vínculos. |
| **Solução/Implementação:** | Realizada adequação/downgrade de função de fórmula que executa fórmulas de outros sistemas, com isso a chamada de fórmulas de outras aplicações a princípio funciona de forma assertiva. |
