Este assistente permite ao usuário obter uma "fotografia" dos dados pertinentes ao Censo escolar do ensino básico e arquiva-los, em distintas linhas do tempo para futuro envio ao Educacenso. Para isto é gerado arquivo(s) no formato XML com base em uma data de corte informada. Ao gerar o arquivo base, o mesmo poderá ser visualizado no formato padrão do Educacenso e realizar a manutenção das informações geradas para o Censo.

No assistente é possível informar qual será a data de corte para o Censo escolar e gerar o arquivo com os dados que serão enviados ao MEC.  Assim é gerado um arquivo "base" no formato XML, que poderá ser visualizado as informações do mesmo, de acordo com as divisões dos registros do arquivo do Censo. Este arquivo base poderá ser alterado e salvar uma nova versão XML. Várias novas versões do arquivo base que são de manutenção poderão ser criadas. O arquivo base não poderá ser excluídos mas os arquivos de manutenção, sim.

Em uma arquivo selecionado o usuário terá a opção de remover algum item na lista de registro ou caso um aluno tenha mais de uma matricula no período letivo utilizar o recurso para considerar o último registro de matrícula do aluno.  
O usuário poderá criar várias versões XML, por isso será necessário definir o XML oficial a ser usado pelo gerador de saídas que gerará o arquivo final a ser enviado para o MEC utilizando o botão XML oficial.
