# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Geração de lançamentos.* |
| **Situação/Requisito:** | *O sistema, ao validar o valor total de bolsas atribuídas ao lançamento financeiro, considera o valor de desconto com arredondamento de casas decimais, o que pode causar uma diferença de valores que invalidam as bolsas por superarem o valor original do lançamento financeiro..* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de lançamentos, afim de evitar que a validação dos valores de bolsa possam ser influenciados pelo arredondamento do valor de desconto da parcela.* |
