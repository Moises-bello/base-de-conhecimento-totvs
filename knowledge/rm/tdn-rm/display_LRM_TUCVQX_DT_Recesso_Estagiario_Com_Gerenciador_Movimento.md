# RECESSO DE ESTAGIÁRIO UTILIZANDO GERENCIADOR DE MOVIMENTO

|  |  |
| --- | --- |

| **Segmento:** | *C&P* |

| **Função:** | *Recesso de Estágio* |
| **Situação/Requisito:** | *O cálculo do recesso para estagiário não está sendo feito corretamente quando é utilizado gerenciador de movimento.*  *O evento de CC 332 - RECESSO DE ESTÁGIO é lançado com o valor zerado.* |
| **Solução/Implementação:** | *Ajuste no cálculo do evento de CC 332 - RECESSO DE ESTÁGIO, para que já seja enviado para o Gerenciador de Movimento com o valor calculado, assim como ocorre com os eventos do recibo de férias.* |
