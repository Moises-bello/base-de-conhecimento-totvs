# URL EXTERNA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Url's Externa* |
| **Situação/Requisito:** | *Ao acessar uma Url Externa(via portal Educacional) que necessite das informações do contexto, o usuário era obrigado a acessar outra página do portal que carregasse este contexto e só após este acesso o contexto era enviado para a Url externa.* |
| **Solução/Implementação:** | *Adicionado controle de seleção de contexto na visão de Url's Externas no portal do Aluno e Professor. O controle tem o objetivo de facilitar o preenchimento do contexto do usuário logado, permitindo que Url's externas utilizem esta informação, quando necessário.* |
