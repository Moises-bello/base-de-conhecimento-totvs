**Dúvida**Qual a rotina do **adapter** de recebimento dos dados do romaneio?   
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O **adapter** de recebimento dos dados do romaneio é o **OGI250 - Adapter de Recebimento dos dados do Romaneio**   
  
O cadastro de romaneio foi implementado para que seja possível a recepção dos dados de outra solução. Para isso foi desenvolvido um **Adapter EAI - Possibilita habilitar ou desabilitar as mensagens que serão integradas**
