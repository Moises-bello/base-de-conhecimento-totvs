# MATRICULA NA DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Curriculo e Oferta* |
| **Função:** | *Matrícula na disciplina do aluno* |
| **Situação/Requisito:** | Ao editar uma disciplina que tenha nota final lançada, o sistema incorretamente mensagem para confirmar alteração. Não houve nenhuma alteração no registro, portanto não deveria habilitar o botão “Salvar”. |
| **Solução/Implementação:** | Alterado cadastro de “Matrícula na disciplina” para não habilitar o botão salvar quando editamos uma disciplina que tenha nota final lançada e não foi realizado nenhuma alteração no registro. |
