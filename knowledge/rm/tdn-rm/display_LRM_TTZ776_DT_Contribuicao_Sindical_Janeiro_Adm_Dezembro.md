# CONTRIBUIÇÃO SINDICAL EM JANEIRO DE ADMITIDOS EM DEZEMBRO DO ANO ANTERIOR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Contribuição Sindical* |
| **Situação/Requisito:** | *Não está sendo descontada a Contribuição Sindical em janeiro, de funcionários admitidos em dezembro do ano anterior.*  *Conforme o Artigo 602, da Lei nº 11.648, "Os empregados que não estiverem trabalhando no mês destinado ao desconto da imposto sindical, serão descontados no primeiro mês subseqüente ao do reinício do trabalho".* |
| **Solução/Implementação:** | *Ajuste no cálculo da Contribuição Sindical para efetuar o desconto dos funcionários admitidos em dezembro, na competência janeiro do ano seguinte.* |
| **Chamados   relacionados:** | *TTZ776, TUANRB, TUBAVR* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
