# Como imprimir lista de preços de produtos?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como imprimir lista de preços de produtos? |
| **Passo a passo:** | **Lista de Preços**  Nessa opção é possível Visualizar/Imprimir uma lista de preços das tabelas cadastradas, ou seja, a listagem de todos os preços de produtos da instituição. A impressão pode ser ordenada por Nome Comercial do Produto, Código do Produto ou Código Específico. Visualizando/Imprimindo Lista de Preços  1. No **TOTVS Gestão Hospitalar** acesse **Estoques/Consultas e Relatórios/Lista de Preços**. 2. Será exibida a tela para Visualização/Impressão da lista de preços. 3. Selecione a forma de classificação da lista (por Nome Comercial, Código de Produto ou Código Específico). 4. Selecione a Tabela. 5. Clique em **Imprime**. |
