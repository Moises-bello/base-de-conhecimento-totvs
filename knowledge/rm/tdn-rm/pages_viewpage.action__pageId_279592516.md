# NÚMERO MÁXIMO DE ALUNOS NAS SUBTURMAS DE TURMAS MISTAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Cadastro de SubTurmas |
| **Situação/Requisito:** | Sistema não exibe o campo de número máximo de alunos para subturma de uma turma mista ou turma livre. |
| **Solução/Implementação:** | Exibir o campo de número máximo de alunos nas subturmas de turmas mistas ou turmas livres do ensino superior.  Caso sejam turmas com vínculo a uma matriz curricular, o sistema somente exibirá o número máximo de alunos na subturma se o controle de vagas for por turma disciplina.  Caso seja ensino básico, o campo citado não será exibido. |
