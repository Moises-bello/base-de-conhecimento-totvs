![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20435140272919) Tempo aproximado para leitura: **00h05min****Dúvida**Os documentos não estão aparecendo na rotina do monitor (COMXCOL) do importador XML.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS COMPRAS - A partir da Versão 12  
  
**Solução**

Para solucionar essa dúvida, realize os seguintes passos:

**Passo 1: Abra a Rotina do Monitor**

* Acesse a interface ou sistema onde a rotina do monitor está disponível.

**Passo 2: Verifique os Parâmetros**

* Analise os parâmetros da rotina do monitor.
* Identifique quais parâmetros são essenciais e verifique se todos estão preenchidos.

**Passo 3: Valide os Parâmetros**

* Implemente verificações de validação para garantir que os parâmetros estejam preenchidos corretamente.
* Examine se os valores estão dentro dos limites aceitáveis.

**Passo 4: Verifique Filtros Aplicados**

* Caso a rotina do monitor utilize filtros, verifique se estão corretamente aplicados.
* Certifique-se de que os filtros não estão excluindo dados importantes ou retornando resultados indesejados.

![recording-2024-01-09-10-52-37 (online-video-cutter.com) (1).gif](https://centraldeatendimento.totvs.com/hc/article_attachments/20435145208087)

Após realizar todos os passos acima validar se os docmentos serão apresentados normalmente na rotina.
