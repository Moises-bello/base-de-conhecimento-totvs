# Alteração de Juros e Multa em lançamentos que possuem boleto

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Alteração de Lançamento |

| **Solução/Implementação:** | Permitido alterar o valor de Juros e Multa de Lançamentos vinculados a Boleto Não Registrado. |
