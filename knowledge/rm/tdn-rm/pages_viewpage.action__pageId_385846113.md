# A descrição do tipo de preço não estava sendo alterada de acordo com o preço atualizado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Importação / Atualização BRASÍNDICE |
| **Situação/Requisito:** | Ao realizar a atualização dos itens de estoque, o valor do produto era alterado de acordo com o tipo de preço aplicado porém não alterava a descrição do tipo de preço utilizado na atualização. |
| **Solução/Implementação:** | Ajustado para alterar a descrição do tipo de preço de acordo com o tipo de preço aplicado na atualização do item. |
| **Documento de Referência:** | <https://totvssuporte.zendesk.com/agent/tickets/3353071> |
