# INCLUSÃO DE MOVIMENTO PARAMETRIZADO PARA BAIXAR O LANÇAMENTO FINANCEIRO UTILIZANDO MEIO DE PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | *Gestão de Estoque Compras e Faturamento* |
| **Função:** | Inclusão de movimento com vários meios de pagamento parametrizado para baixar o lançamento quando a data de vencimento for igual a data de emissão. |
| **Situação/Requisito:** | Ao inclui movimento informando vários meios de pagamento com a data de vencimento igual a data de emissão do movimento parametrizado para baixar lançamento o sistema desconsiderava o meio de pagamento informados no movimento, baixando todos os lançamentos  com o mesmo meio de pagamento |
| **Solução/Implementação:** | Melhoria na inclusão de movimento com mais de um meio de pagamento parametrizado para baixar o lançamento quando a data de vencimento seja igual a data de emissão do movimento. |
