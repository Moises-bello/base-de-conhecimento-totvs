# SUGESTÃO DE FERIAS (PORTAL)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias (Portal)* |
| **Situação/Requisito:** | Nos parâmetros do portal, ao marcar "Enviar direto para o cadastro de funcionários" nos parâmetros de férias, o sistema só respeitava em caso de chefe marcando férias para o subordinado. |
| **Solução/Implementação:** | Foi removida a verificação que aplicava o parâmetro apenas para chefes cadastrando férias para os funcionários. |
