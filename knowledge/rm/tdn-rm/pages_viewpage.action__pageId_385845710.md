# MATRÍCULA NO PROCESSO SELETIVO RM

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Matrícula do Processo Seletivo RM |
| **Situação/Requisito:** | Ao realizar a matricula de um candidato do processo seletivo RM, que não possui responsável financeiro cadastrado e marcar o parâmetro para que o responsável financeiro do aluno, seja o mesmo do candidato, o sistema informa mensagem de erro de referência de objeto. |
| **Solução/Implementação:** | Foi incluída uma mensagem de aviso ao tentar realizar a matricula de um candidato do processo seletivo RM, que não possui responsável financeiro cadastrado, com o parâmetro para que o responsável financeiro do aluno seja o mesmo do candidato marcado. Dessa forma não aparecerá mais o erro "Referência de objeto não definida para uma instância de um objeto." |
