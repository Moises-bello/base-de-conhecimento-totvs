**RMLabore**

Processo: **Cadastro de férias futuras (.Net)**

Versão: 11.5X ou superior

Este roteiro irá auxiliar no cadastro férias futuras na Máquina de Cálculo (.Net)

1. Dentro do cadastro de funcionários, selecione o mesmo e vá no botão de cadastro de períodos aquisitivos

Tela Delphi (Clique para visualizar imagem)Tela .Net (Clique para visualizar imagem)

Como pode ser visto na tela .Net, o período aquisitivo atual é o 15/01/2013 a 15/01/2014.

2. Para incluir férias futuras, basta clicar em incluir o novo período aquisitivo e realizar os passos seguintes

a) Incluir o período aquisitivo futuro, através do botão **Incluir**

Clique para visualizar imagem

b) Digitar o período aquisitivo futuro e salvar o cadastro. No exemplo o período aquisitivo futuro é 15/01/2014 a 14/01/2015

Clique para visualizar imagem

**Obs.** Todos os períodos aquisitivos futuros são criados com a Situação “Fechado”. Isto, para que o sistema entenda que não é o período aquisitivo atual do funcionário. Quando o período aquisitivo atual é finalizado, ele passará para o status "Fechado" e, existindo período futuro cadastrado, o sistema passará o status dele para “Aberto”.

3. Para incluir o gozo de férias futuros, deverá clicar editar o Período aquisitivo, e na aba “Período de Gozo”, poderá incluir a marcação de férias futuras

Clique para visualizar imagem

4. No exemplo, a sugestão de gozo futuro será 01/12/2014 a 30/12/2014. Pode ser incluído períodos partidos.

Clique para visualizar imagem

O período de gozo deverá ficar com o status "Marcado", conforme imagem:

Clique para visualizar imagem

Você também pode acessar o cadastro do período de gozo futuro e calcular as férias do funcionário para visualizar o recibo. Está é uma das vantagens do cálculo .Net.

**Obs.** Poderá incluir **N** períodos aquisitivos futuros.
