# Ajuste no Formulário de Prestadores

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão de Saúde |
| **Função:** | Prestador |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu Unidade de Cadastro/Uso Geral/Prestador, preencher a identificação, salvar, clicar em OK, abrir o mesmo prestador preencher os dados do complemento 1 e salvar, o sistema exibia a mensagem: "Filial padrão para cadastro de cliente/fornecedor não informada nos parâmetros de integração". |
| **Solução:** | Foram realizados ajustes no formulário para que ao registrar o Prestador, não sejam exibidas mensagem de exceção. |
