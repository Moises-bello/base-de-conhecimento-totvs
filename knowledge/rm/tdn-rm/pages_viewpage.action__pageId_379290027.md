# **Configurações de Endereços**

É necessária para amarração entre as diversas possibilidades de utilização de endereço no sistema.

No menu eSocial I Endereços deverá parametrizar:

#### Classificação de Países:

Deverá incluir um cadastro para ser informado na parametrização da codificação de países e realizar sua amarração com os parâmetros do eSocial.

#### Países:

Deverá apresentar a relação de países já cadastrados no sistema. Em sua edição acesse o menu Anexos I Codificação de País e informe a Classificação de Países criada no passo anterior. Informe também o código do país conforme o exigido no documento Anexo I - Tabelas do eSocial.

#### Classificação de Nações:

Este é o cadastro base que é utilizado para vínculo no cadastro do Funcionário em "Nacionalidade".   
Neste cadastro não é permitida a inclusão ou exclusão de novos itens, apenas a edição, com finalidade de se informar o país ao qual se relaciona.

[Dica!Como realizar a associação da Tabela de Países do layout do eSocial no cadastro do sistema?](http://tdn.totvs.com/pages/viewpage.action?pageId=334334090)

#### Classificação de Municípios:

Cadastro utilizado para definição de códigos no Anexo "Codificação de Municípios" do cadastro de Municípios.  
Este cadastro, quando relacionado no parametrizador em "De/Para de Endereço" no campo "Conceito de Classificação para Códigos de Município", definirá qual código será levado para o eSocial.

#### Municípios:

Nesta opção, serão visualizados os municípios para utilização no sistema. Em sua edição acesse o menu Anexos I Codificação de Município e informe a Classificação de Município criada no passo anterior. Informe também o código do município conforme o exigido no leiaute do eSocial.

[Dica!Como realizar a Classificação de Municípios?](http://tdn.totvs.com/pages/viewpage.action?pageId=334334080)

#### Classificação de Logradouros:

Cadastro utilizado para definição de códigos no Anexo "Codificação de Tipo de Rua" do cadastro de "Logradouros".  
Esta classificação quando relacionada no parametrizador, em "De/Para de Endereço", no campo "Conceito de Classificação para Tipo de Rua", definirá qual código será levado para o eSocial.

#### Logradouros:

Nesta opção serão visualizados os tipos de Logradouros a serem utilizados no sistema.

Os registros de Logradouros assim como os de Países e Municípios, deverão ter sua informação de codificação em seu anexo "Codificação de Tipo de Rua". Em sua edição acesse o menu Anexos I Codificação de Município e informe a Classificação de Município criada no passo anterior. 

[Dica!Como realizar a Classificação de Logradouros do eSocial?](http://tdn.totvs.com/pages/viewpage.action?pageId=334334014)
