# IDENTIFICAÇÃO DE HORÁRIOS DE SUBTURMAS NA ALOCAÇÃO MANUAL DE SALAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Alocação manual de salas |
| **Situação/Requisito:** | Em uma turma/disciplina com muitos horários e vários em subturmas diferentes, não é possível identificar de que turma é o horário. |
| **Solução/Implementação:** | Foi realizada uma alteração para que a árvore de horários das turmas/disciplinas seja quebrada por subturmas. Dessa forma, serão exibidos os horários abaixo de sua subturma. |
