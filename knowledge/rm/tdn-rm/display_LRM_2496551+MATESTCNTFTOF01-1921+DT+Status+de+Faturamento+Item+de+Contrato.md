# ITEM DE CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Item de Contrato. |
| **Situação/Requisito:** | Visão de itens de contrato não possui a coluna Status de Faturamento |
| **Solução/Implementação:** | Disponibilizado na visão de **Itens de Contrato (Edição Contrato \ Itens** e **Anexo Itens de Contrato)** a coluna **Status Faturamento**.  Para que esta coluna seja apresentada é necessário **Configurar Colunas,** marcar a coluna **Status Faturamento** ou marcar o parâmetro **Restaurar Configuração Padrão**. |
| **Conversores e Parâmetros:** | Não se aplica. |
| **Tickets relacionados:** | Não se aplica. |
| **Requisito:** | CtrItmCntAction. |
| **Documento de Referência:** | <http://wikihelp.totvs.com.br/WikiHelp/EST/EST.ItensContrato.aspx>. |
