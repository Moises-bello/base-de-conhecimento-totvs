# NOTAS DE AVALIAÇÃO COM FÓRMULA VISUAL NO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Notas de Avaliação com Fórmula Visual no Portal* |
| **Situação/Requisito:** | *No portal, na tela de 'Notas avaliação', ao salvar os registros lançados, uma fórmula visual é executada, exibindo uma mensagem exceção. Porém, após clicar no botão 'OK' da mensagem, são perdidas todas as notas lançadas, que ainda não foram salvas.* |
| **Solução/Implementação:** | *Ajuste na tela de Notas de avaliação para que ao salvar os registros lançados não se perca os dados que ainda não foram salvos ao exibir uma exceção por uma fórmula visual.* |
