Tarefa:  
 Selecione o código da tarefa ao qual o insumo pertence. Esse código pode ser um serviço, etapa ou obra. Caso não saiba o código da tarefa, realize a busca através do botão de filtro  
  
 Observação  
  
 Ao selecionar o código da tarefa, o nome, a descrição, a unidade e a quantidade da mesma serão preenchidas automaticamente. Se o nome for selecionado, o código, a descrição, a unidade e a quantidade serão preenchidas automaticamente.  
  
 Data Movimento:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
  
 Data Apropriação:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
  
 Moeda:  
 O valor default deste campo será de acordo com os parâmetros do projeto. Parâmetros do projeto – Leis/ Outros – Moeda do projeto. Como se trata de um campo editavél, pode-se alterar a moeda.  
 Uma apropriação pode ser efetuada em outra moeda.

Sugestão de Apropriação:  
Você pode lançar a quantidade equivalente da apropriação. Ao "calcular/Lançar", o sistema fará uma validação nos campos preço e quantidade da composição ou do insumo. E caso algum desses campos esteja zerado será exibido mensagem relatando quais composições ou insumo não constam a informação, e não será lançado na Apropriação múltipla de Serviço.  
Se os campos preço e quantidade do insumo estiveram com informação após calcular será lançada a informação na Apropriação múltipla de serviço.

Cód. Insumo:  
 Informe o código do insumo que está sendo apropriado.  
 Caso não saiba o código do insumo, realize a busca através do botão de filtro  
  
 Descrição do Insumo:  
 Informe a descrição do insumo que está sendo apropriado.  
 Ao informar o código do insumo este campo é preenchido automaticamente.   
  
 Unidade Insumo:  
 A Unidade do insumo que está sendo apropriada será exibida neste campo.  
  
 Data Apropriação:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
  
 Quantidade:  
 Informe a quantidade do insumo que está sendo apropriado.  
  
 Preço Unitário:  
 Ao informar o insumo o sistema busca o preço do insumo.  
 Se no momento do cadastro do insumo, não foi informado o preço, na apropriação pode-se informar o preço do insumo.  
  
 Data Movimento:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
  
 Moeda:  
 O valor default deste campo será de acordo com os parâmetros do projeto. Parâmetros do projeto – Leis/ Outros – Moeda do projeto. Como se trata de um campo editável, pode-se alterar a moeda.  
 Uma apropriação pode ser efetuada em outra moeda.
