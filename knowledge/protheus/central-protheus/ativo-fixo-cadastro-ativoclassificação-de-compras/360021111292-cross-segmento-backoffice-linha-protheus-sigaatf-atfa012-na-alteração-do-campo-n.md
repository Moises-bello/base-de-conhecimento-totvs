**Ocorrência**

Na alteração do campo N3\_TIPO, retorna mensagem "A010JADIG - este item já se encontra digitado no cadastro de ativos"

**Ambiente**

Cross Segmento - Backoffice Linha Protheus – Ativo Fixo  – A partir da versão 11.80  
  
**Causa**No cadastro do ativo, permite informar o tipo 01 somente uma vez.  
Informando o mesmo tipo na próxima linha para o mesmo ativo é gerada esta mensagem "A010JADIG - item já se encontra digitado no cadastro de ativo"
