**Outros - Integração - Parâmetros do Projeto**

**Integrado com o Folha de Pagamento ( RM Labore):**

Caso esta opção esteja habilitada, a integração com o RM Labore estará ativa.

**Integrado com Manutenção (RM Officina)**

Caso esta opção esteja habilitada, a integração com o RM Officina estará ativa.

**Observação:**

A importação de produtos (insumos) do RM Nucleus só é possível se o parâmetro "Integrado com o RM Nucleus" ou "Integrado com o RM Officina" estiver ativo.

Caso contrário, a tela se abrirá mas, o botão OK ficará desativado.

**Integrado com o Gestão Patrimonial (RM Bonum)**

Caso esta opção esteja habilitada, a integração com o RM Bonum estará ativa.

**Considerar funcionário/terceiro de:** Pode se definir por coligada , filial ou todos.
