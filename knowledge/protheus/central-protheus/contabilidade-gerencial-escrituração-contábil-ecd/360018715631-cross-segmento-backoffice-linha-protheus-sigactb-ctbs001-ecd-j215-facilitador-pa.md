**Ocorrência**ECD J215, facilitador para detalhamento do DMPL.  
  
**Ambiente**Protheus – Contabilidade Gerencial – A partir da versão 11.80  
  
  
**Solução**

O registro  J215 (Detalhe do Fato Contábil) deve ser incluído a cada nova revisão. Como facilitador, temos a opção para recuperar de uma revisão anterior o que já foi digitado.

* Rotina CTBS001 + ECD Incluir + Passo 3/3

![](http://tdn.totvs.com/download/attachments/235591998/image2016-4-28%207%3A44%3A51.png?version=1&modificationDate=1461841854000&api=v2)

* Na tela de Detalhamento do Fato, pressione **F12**

![](http://tdn.totvs.com/download/attachments/235591998/image2016-4-28%208%3A28%3A25.png?version=1&modificationDate=1461841857000&api=v2)

* Digite a Revisão que contém os dados da DMPL a qual queira copiar.  
    
  ![](http://tdn.totvs.com/download/attachments/235591998/image2016-4-28%208%3A46%3A39.png?version=1&modificationDate=1461841858000&api=v2)
* Clique para o início da tela:  
    
  ![](http://tdn.totvs.com/download/attachments/235591998/image2016-4-28%208%3A51%3A4.png?version=1&modificationDate=1461841859000&api=v2)
* Os dados serão exportados para a revisão atual:  
    
  ![](http://tdn.totvs.com/download/attachments/235591998/image2016-4-28%208%3A56%3A9.png?version=1&modificationDate=1461841861000&api=v2)
* Caso precise incluir ou alterar alguma informação, os botões estão disponíveis no rodapé da página.
* Clique em SAIR e o mesmo procedimento poderá ser feito para inclusão do registro J215.
