**Documentos**

---

Neste anexo é possível vincular Documentos ao Contrato, que serão exibidos no Portal do Cliente (PDC). Ao incluir um documento é exibida a seguinte tela:

* **Nome:** O nome do documento que será exibido no Portal;
* **Ativo:** Define se o documento está ativo ou não. Esse status é exibido no Portal do Cliente;
* **Publicar no Portal:** Define se o documento poderá ser exibido ou não no Portal do Cliente;
* **Arquivo:** É possível selecionar o arquivo ao qual se deseja vincular a venda. Este arquivo deverá estar no formato pdf.
* **Baixar:** Permite baixar o arquivo para a máquina no qual o sistema está sendo executado.
* **Visualizar:** Permite visualizar o documento ao qual a tela de edição está sendo exibida.

**Log de Documentos**

---

À partir da versão **12.1.33**, estará disponível neste menu a opção de visualização do log de documentos. Este log tem por finalidade, gravar numa tabela os dados de acesso de um determinado documento, quando o mesmo é acessado no PdC ou no aplicativo Meu Imóvel.  
Serão gravadas as seguintes informações:

* **Usuário**: Usuário (Comprador) que acessou o arquivo;
* **Código do documento**: O ID do documento acessado;
* **Documento**: Descrição do documento;
* **Origem**: Se o documento foi acessado via Meu Imóvel ou via PdC;
* **IP**: O IP de origem do acesso;
* **Usuário criador do registro**: Lista o usuário (login) que gerou o registro na tabela;
* **Data de criação do registro**: Lista a data de inclusão do registro na tabela.
