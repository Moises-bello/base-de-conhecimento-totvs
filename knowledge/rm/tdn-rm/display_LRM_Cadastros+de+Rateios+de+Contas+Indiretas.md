## **01. VISÃO GERAL**

Para as **Contas de Custo** do tipo **Indireta** é necessária à configuração dos critérios de rateio específicos a cada um dos itens de custos identificados sob essas condições. 

Utilizando o exemplo abaixo, o Critério de Rateio "% de Consumo de Energia" do tipo pré-definido, possui os valores percentuais que cada centro de custo gasta em média.

Ao importar ou digitar a despesa da conta "ENERGIA ELETRICA" o sistema irá fazer o rateio dos R$ 10.000 para cada centro de custo com o seu respectivo percentual.

## **02. EXEMPLO DE UTILIZAÇÃO**

Gestão de contas > cadastros > rateio de contas indireta

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão   * **Configurando a Conta de Custo Indireta com o Critério de Rateio** | 1. Localizar a conta de custo para qual será feita a configuração do critério, após isso dar um duplo clique para entrar no modo de edição. 2. Para configurar o critério, primeiro é necessário que a coluna **Tipo Aplicação** da conta de custo em questão esteja configurada como **Indireta**. 3. Em seguida clique na aba Critério Rateio Conta Indireta. 4. Clique em Incluir (Página em branco) para incluir uma nova associação de critério de rateio a conta de custo e informe os campos abaixo.     * Código Filial: Informar qual o código da filial de qual critério de rateio será utilizado, o sistema permite que vários critérios de filiais diferentes sejam vinculados com a conta.    * Código Critério Rateio: Informar o código do critério de rateio.    * Clique em OK para salvar e fechar ou em Salvar para salvar e permanecer em tela. |
