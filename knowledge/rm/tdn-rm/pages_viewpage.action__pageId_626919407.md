Esse cadastro permite que o usuário do FLUIG solicite o seu cadastro como um pesquisador ou extensionista. Isso permitirá que o usuário possa participar de editais publicados pela instituição.  
 Criar no FLUIG os papéis necessários para a execução do fluxo do projeto de inovação. É importante criar da mesma forma descrita abaixo pois o fluxo utiliza essa definição para referenciar os papéis.  Código = reitoria |   Descrição = Reitoria  
 Em seguida, associar os usuários ao respectivo papel cadastrado.  
 Associar adequadamente os usuários do FLUIG aos papéis criados anteriormente.  
    
 Importar o fluxo: Cadastro Pesquisador/Extensionista para a ferramenta TOTVS Developer Studio (TDS).   
 Caso não tenha alterado a instalação padrão dos produtos TOTVS, os arquivos zipados, contendo o(s) fluxo(s), estarão disponíveis em c:\totvs\CorporeRM\ObjetosGerenciais\Fluig.  
 ·       
 **Descrição do Processo:**  
 Obs: Não é necessário estar vinculado a nenhum papel para realizar essa solicitação, basta ter um usuário com acesso ao FLUIG.  
 O usuário deve iniciar uma nova solicitação no FLUIG, escolhendo a opção:

* "FLUIG | Iniciar Solicitações | Educacional | Inovação, Pesquisa e Extensão | Pesquisador | Cadastro de Pesquisador/Extensionista".

O formulário de cadastro será aberto com o código da pessoa vinculada ao usuário do FLUIG, sendo esse o usuário que será cadastrado como pesquisador no TOTVS Educacional.  
 Além dos dados disponíveis na tela, o usuário solicitante deverá incluir, na aba de anexo, o seu currículo lattes. Esse anexo é obrigatório e será usado para importar o currículo do pesquisador para o TOTVS Educacional.  
 Após preencher os dados necessários ao cadastro, o usuário enviará a solicitação para a etapa de "Definir Características", onde outro usuário do FLUIG, vinculado ao papel de "Reitoria", complementará as informações, e caso tenha alguma incoerência o mesmo poderá retornar o fluxo ao solicitante para realizar ajustes. Esse processo pode acontecer quantas vezes for necessário até as informações do pesquisador estarem corretas. Se tudo estiver correto, o usuário vinculado ao papel de "Reitoria" concluirá o cadastro do solicitante como pesquisador/extensionista.
