Através desse processo é possível definir uma inscrição comum para todos os candidatos de uma prova, ou definir uma inscrição única para cada candidato em todas as provas em que ele estiver inscrito.  
    
 Ao executar este processo será possível:

* **Associar uma inscrição para cada pessoa nas suas avaliações de acordo com as provas selecionadas** Selecionando esta opção, o usuário deverá selecionar as avaliações onde cada candidato terá uma inscrição particular, sendo igual para todas as avaliações selecionadas, ou seja, cada candidato utilizará uma mesma inscrição para executar todas as provas que forem selecionadas no processo.
* **Associar uma inscrição para todas as pessoas de acordo com as provas selecionadas** Selecionando esta opção, o usuário deverá selecionar as avaliações onde todos os candidatos terão a mesma inscrição.

**Atenção**

Esse processo não poderá ser executado para avaliações que estejam sendo utilizadas no TOTVS Educacional.
