**Dúvida**Quais são as opções disponíveis na rotina MATA094?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Compras - Todas as versões.

**Solução**

As opções que temos na rotina de Liberação de documentos são: Aprovar, Rejeitar, Bloquear, Estornar, Pendencias de subordinados, Aprovar pelo Superior.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/31298383304087)

**Aprovar:**Opção utilizada para aprovar os documentos

**Pendências de subordinados:**Opção utilizada pelo superior para buscar os documentos pendentes dos subordinados para realizar a aprovação.

**Rejeitar:** Opção utilizada para rejeitar o documento (Sem reversão pela rotina)

**Bloquear:** Opção utilizada bloquear o documento para que ele não tenha continuidade até a aprovação para desbloqueio.

**Estornar**: Opção utilizada para estonar uma aprovação

**Aprovar pelo Superior:** Opção utilizada para transferir o documento para superior ou aprovar.
