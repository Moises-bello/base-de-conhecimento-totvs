![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18790194146071) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como conferir cálculo multa experiência desconto ID 0177 comissionado puro?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Em caso de pedido de demissão em contrato de experiência funcionário comissionado puro categoria C, o cálculo ID desconto 0177 será com base valor garantia de comissão.
