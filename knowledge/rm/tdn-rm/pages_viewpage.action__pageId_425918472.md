Por este processo é possível importar candidatos cujas características pessoais sejam relacionadas à prova.

O usuário deverá escolher as seleções apresentadas no processo para que selecione os candidatos, pertencentes à essas seleções, que serão importados para a prova. Para cada candidato importado, será criada uma inscrição.
