**Pessoas**

Este cadastro guarda informações de todas as Pessoas cadastradas na base de dados independente do seu papel (Candidato, Aluno, Professor, Funcionário e etc).

**Atenção**

O cadastro de Pessoas, a partir da versão 10.70, passa a ser dividido entre Pessoas, Candidatos e Funcionários, cada um assumindo o seu papel dentro do sistema.

**Observação**

Pela visão de Pessoas é possível identificar as pessoas Portadoras de Necessidades Especiais (PNE) e determinar o critério de exibição de Pessoas, utilizando filtros. Pelo cadastro é possível controlar:

**Pasta Identificação - Pessoas**

Pelo  menu Identificação podem-se definir os dados relativos às Pessoas, tais como Nome, Apelido, Data de nascimento, Sexo, Naturalidade, Estado Natal, Estado civil, Tipo sanguíneo, Nacionalidade, Cor/raça, Grau de instrução, Email e Código do Usuário.

**Pasta Informações Adicionais - Pessoas**

Pelo menu Informações Adicionais pode-se definir se é portador de algum tipo de necessidade especial ou se precisa de algum recurso específico para ter acesso à empresa contratante.

**Pasta Endereço Principal - Pessoas**

Pelo menu Endereço Principal é preenchido o endereço da pessoa e este pode ser preenchido utilizando o recurso de preenchimento automático do CEP, buscando dados importados da base dos Correios realizados pelo menu Utilitários| Importação de CEPs.

**Observação**

A nomenclatura dos campos Telefone I, Telefone II e Telefone III pode ser alterada nos parâmetros do sistema pela pasta Geral | Preferências.

**Pasta Documentos Básicos - Pessoas**

Pelo menu Doc. Básicos pode-se preencher dados de documentos das pessoas, tais como CPF, Carteira de Identidade, Título de Eleitor, Carteira de Trabalho e Carteira de Motorista.

**Pasta Documentos Estrangeiros - Pessoas**

Pelo menu Doc. Estrangeiros pode-se preencher dados de documentos das pessoas, tais como Passaporte e outros dados gerais de pessoa estrangeira.

**Pasta Campos Complementares - Pessoas**

Pelo menu Campos Complementares pode-se preencher os campos complementares que foram anteriormente cadastrados através do menu Cadastros| Campos Complementares| Pessoa.

**Pasta Registro Profissional – Pessoas**

Pelo menu Registro Profissional pode-se preencher os dados profissionais da Pessoa, contendo as seguintes informações:

* **Registro Principal, Número do Registro -** Número do registro do profissional no órgão regulamentador da profissão,
* **Codigo do Orgão da Classe -** Sigla do órgão regulamentador da profissão da pessoa, como por exemplo, CRM,CREA
* **UF Expedição Registro -** Sigla do Município de expedição do documento no órgão regulamentador da profissão.

**Foto**

Funcionalidade para adicionar uma imagem que identifica a pessoa, suporta os tipos, Jpeg, Gif e Bmp.

A partir da versão 12.1.2209, novas funcionaldiades:

* Novo tipo suportado PNG, na lista de tipos de arquivos para selecionar.
* Botão para girar a imagem de forma manual.

**Observação**

Ao alterar o registro profissional de uma Pessoa vinculada ao cadastro de Profissional de Saúde, serão sincronizadas as informações de **Nome, Número do Registro e UF do Registro** deste Profissional de Saúde com os respectivos dados deste Registro Profissional.
