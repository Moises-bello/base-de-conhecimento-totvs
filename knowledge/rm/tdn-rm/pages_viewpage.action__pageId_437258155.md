# Escrituração - Campo Complementar não está sendo escriturado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Totvs Gestão Fiscal |
| **Função:** | Escrituração |
| **Situação/Requisito:** | Ao realizar a escrituração pelo processo migrado, não foi escriturado o campo complementar. |
| **Solução/Implementação:** | Ajuste no processo de escrituração para que o sistema carregue o campo complementar presente no item de movimento para o item do lançamento fiscal. |
