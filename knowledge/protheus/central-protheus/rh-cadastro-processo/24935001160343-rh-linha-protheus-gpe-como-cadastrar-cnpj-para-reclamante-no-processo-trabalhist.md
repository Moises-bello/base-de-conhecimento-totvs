![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24935001138711) Tempo aproximado para leitura: **00:00:30****Dúvida**Como cadastrar CNPJ para Reclamante no Processo Trabalhista?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**O cadastro de Reclamante existente dentro da rotina de Processos Trabalhistas (APTA100), é relacionado aos Funcionários que tiveram vínculo com a empresa, ou seja, serão utilizados dados de Pessoa Física como Reclamante, por este motivo, **não é possível o cadastro a partir de um CNPJ.**
