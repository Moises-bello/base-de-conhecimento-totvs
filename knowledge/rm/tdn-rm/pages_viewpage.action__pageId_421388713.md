O simulador de aplicações financeiras é uma ferramenta que permite visualizar o comportamento de uma determinada aplicação sem a necessidade de realizar o processo comum de cadastramento, podendo ser utilizada com índices passados ou previsões de índices futuros.

Através da barra de menu, acesse o ícone "Movimentação Bancária / Aplicação Financeira / Simulador.

* Inclua um filtro.
* Clique em "Incluir".
* Informe a descrição, a natureza e demais campos.
* Clique em "Novo" para inserir os dados para a simulação.
* Após a inclusão, selecione e acesse "Processo / Calcular simulação".
* Acesse a pasta "Movimentos da Simulação" para detalhes da operação.

**Importação / Exportação**  
  
 Para exportar dados do simulador:  
Inserir um simulador para o tipo de aplicação Financeira Calcular a simulação em Processos/Calcular Simulação Para exportar a simulação, selecione e acesse: Processos/Exportar Simulação Escolha a aplicação "Destino" ou se preferir você pode incluir um novo tipo de aplicação que receberá esses dados simulados.
