Dúvida**Posso chamar uma Static Function no MenuDef ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.8  
  
**Solução**Não é possível realizar a execução de funções staticas na chamada do MenuDef().   
Em um menu somente funções devem ser criadas pois isto interfere diretamente no controle de privilégios do sistema.
