**Dúvida**Como calcular salario família para funcionário afastado por licença maternidade?  
  
**Ambiente**TOTVS RH - (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**

Para calcular salario família para funcionários afastados é necessário que no cadastro de tipos de ausência esteja habilitado o campo Pg. Sal Fam (Paga salário família).  
  
Exemplo:

Acesse atualizações > definições de cálculo > **tipos de ausência.**O campo RCM\_SALFAM é composto por 4 opções:

**1=Início do Afastamento:** para que o Salário Família seja pago no início do afastamento  
**2=Retorno do Afastamento:** para que seja pago no retorno do afastamento  
**3=Paga**: para que seja sempre pago  
**4=Não** **paga:** para que o Salário Família não seja pago.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10404048017431)

Após alteração do tipo de ausência, o afastamento deve ser lançado em Atualizações > Lançamentos > Ausência.
