**Dúvida**Como realizar uma cópia de Sindicato entre coligadas?

**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - Todas as versões.

**Solução**Para realizar uma cópia de Sindicato entre coligadas, siga o passo a passo abaixo:  
Acesse a guia **Configurações > Parametrizador.**  
Selecione a opção Sindicato e avance.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24131941580567)

Selecione o Sindicato no qual deseja copiar para outra coligada.  
Acesse **Processos > Copiar sindicato entre coligadas**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/24131941593879)**

Selecione a coligada para qual deseja copiar o sindicato selecionado, e a opção Executar.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24131995314967)  
  
**Importante**   
É importante lembrar que a cópia do sindicato entre coligadas levará somente as informações referente a parametrização, os eventos do sindicato origem não são copiados para o novo sindicato. Portanto deverão ser incluidos manualmente no sindicato destino após a cópia das parametrizações.

**Saiba mais**Para maiores informações sobre o sindicato, acesse a documentação [Sindicato](https://tdn.totvs.com/display/public/LRM/Sindicato)
