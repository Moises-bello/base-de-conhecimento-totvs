# CANCELAR ÁREA OFERTADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Processo Cancelar Área Ofertada* |
| **Situação/Requisito:** | *O botão de selecionar todos no processo de cancelar área ofertada deveria ser bloqueado, porem se clicar do lado do botão ele seleciona todos as áreas.* |
| **Solução/Implementação:** | *Foi realizado a substituição do controle responsável pela exibição dos registros de área ofertada. Este novo controle permite o melhor gerenciamento dos registros.*  *O cabeçalho da coluna de seleção passou a ficar ativo, sendo que ao avançar o processo, é realizado a validação da quantidade de registros selecionados (esta validação já existia no sistema, e o processo pode ser executado apenas para um registro por vez).* |
