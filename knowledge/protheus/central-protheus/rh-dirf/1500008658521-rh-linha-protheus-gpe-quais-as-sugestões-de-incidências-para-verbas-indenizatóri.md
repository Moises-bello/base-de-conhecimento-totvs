**Dúvida**Quais as sugestões de incidências para verbas indenizatórias de rescisão na DIRF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE  Gestão de Pessoal - Todas as Versões.  
  
**Solução**As sugestões de incidência para a DIRF de verbas indenizatórias de rescisão são **E** e **E1** conforme abaixo:

|  |  |
| --- | --- |
| **Chave** | **Descrição** |
| E | Indenização por Rescisão |
| E1 | Indenização por Rescisão 13o |

O ajuste deve ser realizado na rotina de **Verbas**, pelo caminho **>Atualizações >Definições de Cálculos >Verbas,** aba **Anuais,** campo **DIRF:**
