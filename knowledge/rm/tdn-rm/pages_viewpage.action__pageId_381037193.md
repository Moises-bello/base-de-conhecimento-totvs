# Acordo - Campo Observação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Acordo |
| **Situação/Requisito:** | Cliente informa que após atualizar para a versão 12.1.18.156, ao gerar o Acordo Financeiro, a área de texto destinada a 'Observação' possui um tamanho menor que nas versões anteriores, como por exemplo na versão 12.1.17. De acordo com o cliente a mudança no tamanho do campo está afetando o processo da empresa e o mesmo solicita que o campo tenha o mesmo tamanho das versões anteriores. |
| **Solução/Implementação:** | O campo Observação, do acordo financeiro, foi alterado para comportar até 10000 caracteres. |
