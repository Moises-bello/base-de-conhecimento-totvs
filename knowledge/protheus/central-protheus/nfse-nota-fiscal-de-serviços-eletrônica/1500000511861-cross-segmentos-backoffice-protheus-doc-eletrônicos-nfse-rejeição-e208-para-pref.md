**Dúvida**Ao transmitir uma NFS-e na rotina FISA022 para prefeituras que trabalham com o provedor GINFES, ocorre a rejeição abaixo:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360099444014/mceclip2.png)

**Ambiente**Cross Segmentos - TOTVS Backoffice Protheus - TOTVS Doc. Eletrônicos - Todas as versões.  
  
**Solução**A orientação da prefeitura para esse erro é a seguinte:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000559642/mceclip3.png)  
  
Para corrigir esse erro é necessário realizar a configuração fiscal disponível no link abaixo:  
- [ISS ZERO](https://tdn.totvs.com/pages/releaseview.action?pageId=210043808)  
  
Para saber se o município usa o provedor GINFES, acesse o documento abaixo, localize o município e verifique a coluna **'Provedor'**.   
- [Municípios Homologados](https://tdn.totvs.com/pages/releaseview.action?pageId=4814340)
