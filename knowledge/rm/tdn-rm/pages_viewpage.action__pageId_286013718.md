# Processar Mapa de Dispensação com Integração EMS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Mapa de Dispensação |
| **Situação:** | Ao realizar o processamento do mapa, os itens processados do mapa não eram enviados para o EMS. |
| **Solução:** | Alterado o sistema para sempre que processar o mapa de dispensação, enviar todos os itens pendentes para a integração com EMS. |
