**Dúvida**

Consulta Genérica tabela SC7 traz apenas primeira linha correta

**Ambiente**Protheus – Compras – versão 12.1.17

**Solução**

No módulo **Compras**, ao tentar extrair o relatório de consulta genérica da tabela SC7  é apresentada de forma correta apenas a primeira linha ao exportar para arquivos CSV.

Para solucionar essa ocorrência, realize os seguintes passos:  
1. Acessar o modulo de Compras, Consulta, Cadastros, Genéricos;  
2. Selecionar a tabela SC7;  
3. Clique selecionando o formato XML depois MS Excel para que o relatório seja gerado da forma correta.
