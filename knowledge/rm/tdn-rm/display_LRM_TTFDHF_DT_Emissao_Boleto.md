Implementação de uma mensagem para informar ao usuário quando o relatório configurado para emissão de boletos pelo portal não estiver parametrizado corretamente.

* *Parametrizar o relatório como default para pagamentos no portal.*
* *Acessar portal > educacional > biblioteca > emissão de boletos.*
