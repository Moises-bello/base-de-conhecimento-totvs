**Dúvida**  
Como selecionar mais de uma Purchase Order para um único Embarque/Desembaraço?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Para incluir mais de uma Purchase Order, realize o procedimento abaixo:

1. Acesse a rotina de Embarque/Desembraço e informe o Pedido Base:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029237732/mceclip0.png)

2. Selecione outras ações/Itens:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029240271/mceclip1.png)

3. Será apresentada a tela abaixo, selecione (?):

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029240431/mceclip3.png)

4. Selecione a PO a ser inserida, clique em OK:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029240851/mceclip5.png)

5. Pressione Tab ou Enter do teclado para adicionar o PO, após selecione Salvar:

![mceclip10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029241952/mceclip10.png)

6. Será apresentada a tela abaixo, após selecione os itens para inclusão no embarque:

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029241211/mceclip8.png)

Caso embarque/Desembaraço já esteja cadastrado a inclusão do PO pode ser realizada selecionando o botão Selecao PO's / PLI's :

![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360029239452/mceclip9.png)
