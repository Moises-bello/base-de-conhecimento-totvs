A Partir da versão 12.1.33, foi criada está tela para permitir que os documentos solicitados aos alunos sejam verificados, avaliados e validados de forma mais fácil. Sem a necessidade do usuário da secretaria ter que realizar a conferência através de cada anexo do aluno.

**Observação:** As permissões de acesso são as mesmas para o anexo de [documento solicitados](https://tdn.totvs.com/display/LRM/Documentos+solicitados) do aluno.

Para visualizar, acesse: Currículo e Oferta | Aluno e Professor | Aluno | Documentos solicitados

Nessa tela é possível realizar filtros para escolher os documentos a serem avaliados bem como a edição dos mesmos diretamente na grid.

As informações que podem ser alteradas na grid são:

* **Data Entrega**
* **Data Prevista**
* **Quantidade entregue**
* **Situação do documento**
* **Motivo de rejeição do documento**

O botão **"Arquivo"** , permite visualizar o documento anexado pelo aluno.

A situação do documento só poderá ser alterada para recusado se o motivo de rejeição do documento for informado.

Se não existir documento anexado, ao clicar no botão de anexo, é exibida mensagem indicando que não existe arquivo para exibir.

O usuário pode realizar o ajuste de várias linhas de uma única vez, basta fazer os ajustes desejados e ao final clicar no botão de Salvar, apresentado na visão.

Importante frisar por uma limitação da tela por ser uma grid editável não é possível executar fórmula visual em ambiente três camadas, pelo menu processos.
