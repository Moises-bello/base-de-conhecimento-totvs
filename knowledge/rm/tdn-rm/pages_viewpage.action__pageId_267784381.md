# Parâmetros Integração Financeira

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Parâmetros Integração Financeira |
| **Situação/Requisito:** | 1º A descrição do parâmetro que identifica o campos de valores opcionais de bolsas condicionais está com a descrição igual a “Utilizar escalonamento de bolsas”.   2º Quando o parâmetro bolsas condicionais não está preenchido é apresentada a mensagem “Utilização de bolsas condicionais exige um valor opcional associado a esse tipo de bolsa”, porem o campo não fica habilitado para preenchimento. |
| **Solução/Implementação:** | 1º Ajustada a descrição do parâmetros para que a descrição seja "**Utilizar bolsas condicionais**".  2º Melhoria nas validações dos parâmetros de bolsa do educacional para que seja possível informar o valor opcional que controla as bolsas condicionais mesmo se já existir bolsa e o parâmetro ainda não tenha sido informado. |

| **Chamados relacionados:** | TVPYPY |
