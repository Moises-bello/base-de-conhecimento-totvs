# PARÂMETRO PARA PROP.SALÁRIO FAMILIA PELOS DIAS DO MÊS ESTÁ VINCULADO AO CAMPO INCORRETO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Parametrizador* |
| **Situação/Requisito:** | *Ao marcar ou desmarcar o parâmetro "Considera dias do mês p/ proporcionalização" existente no Parametrizador, pasta Folha Normal/Salário Familia, não modifica a forma de cálculo do evento de CC 5 para admitidos no mês.*  *Foi verificado que o parâmetro está vinculado ao campo incorreto na tabela PPARAMADICIONAIS.* |
| **Solução/Implementação:** | *Ajuste no Parametrizador, para vincular o parâmetro "Considera dias do mês p/ proporcionalização" da pasta Folha Normal/Salário Familia, ao campo correto da tabela.* |
