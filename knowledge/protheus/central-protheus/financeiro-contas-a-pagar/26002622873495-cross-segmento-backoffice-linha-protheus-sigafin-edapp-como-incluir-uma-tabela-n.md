![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622821783) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como incluir uma tabela na consulta genérica?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA330 - Todas as versões  
  
**Solução**

Através do Configurador SIGACFG vai até Ambiente/ Cadastros/ Menus

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622825495)

Desmarque todos os menu e seleciona somente o Financeiro e aperte OK

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002664341015)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622831383)

Adicione todos os menus para o lado direito

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002664345623)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622833815)

Em seguida selecione a pasta Consultas/ Cadastros/ Genéricos e vai na opção Detalhes

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002664351127)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622843159)

No exemplo estou adicionando a tabela F75 e F76 e após selecionar é só clica no botão OK

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002664354199)

Depois e só na opção Gerar e coloca um nome para o Menu, pode usar o mesmo SIGAFIN ou criar um novo para o sistema não sobrescrever o antigo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002664356247)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622851607)

Após salvar é só entrar novamente no Protheus e buscar pela tabela.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26002622853399)
