![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28790849754391) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Após atualizar o sistema, quando acesso as rotinas do TAF, é apresentada a mensagem:

**invalid class TOTVS.FRAMEWORK.CSS.PROTHEUSTHEME**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28790849760919)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - ATUALIZAÇÃO - Todas as versões  
  
**Solução**Para o erro reportado, atualize a LIB, utilizando a documentação abaixo:

[RH - Linha Protheus - TAF - ATUALIZAÇÃO - Como atualizar o TAF E-social (Expedição Contínua)?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/18972648169239)

1. No item 1 da documentação, está disponível os links para download da LIB, conforme versão do Protheus.

2. O item 8.3 da documentação, demonstra como aplicar a patch da LIB pelo VSCode.
