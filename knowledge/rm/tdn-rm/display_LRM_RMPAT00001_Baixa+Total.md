# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO PATRIMONIAL |
| **Versões:** | 12.1.15 ou superior. |
| **Ocorrência:** | Baixa Total |
| **Ambiente:** |  |
| **Passo a passo:** | Este processo permite baixar os valores dos patrimônios de forma parcial (retirando somente o valor definido durante o processo) ou total (retirando todo o valor do mesmo). O sistema permite que a baixa seja realizada de forma individual (somente um patrimônio selecionado) ou simultaneamente (definindo uma faixa de patrimônios).  **Parametrização** Para que a contabilização da ocorrência de baixa seja realizada deve-se marcar o parâmetro "Contabilizar Ocorrências" e definir o Código do Lote (no sistema contábil) que receberá os lançamentos correspondentes. Acesse o menu Ambiente | Parâmetros | Gestão de Patrimônio  Integração > Integração Contábil.  **Situações em que a baixa não será realizada:** - Em patrimônios inativos; - Em patrimônios considerados Títulos; - Em patrimônios totalmente depreciados; - Em patrimônios totalmente baixados em período anterior; - Valor da baixa maior que o valor corrigido do patrimônio; - Data da baixa menor que a última ocorrência existente para o patrimônio envolvido; - Data do processo fora do período de cálculo. **Exemplo:**Data da baixa  01/02/2010, período de cálculo do sistema patrimonial 01/2011.  **Procedimento** Acesse o Menu Operações Patrimoniais | Baixa | Clique em Incluir | Selecione o patrimônio | Avance.      **Seleção dos dados complementares** Ao baixar totalmente o(s) patrimônio(s) o valor a ser considerado para cálculo será o Valor Corrigido do patrimônio. Todos os ajustes serão realizados de forma que o(s) patrimônio(s) fique(m) com o Saldo Residual zerado(s).  A Baixa Total permite que seja informado um valor de venda para cada patrimônio selecionado, caso sejam escolhidos mais de um patrimônio. Para isto deve-se marcar a opção “Informar valor de venda por patrimônio”.  Outro recurso disponível para baixa total é a opção que permite baixar patrimônios agregados. Desta forma cada patrimônio agregado ao patrimônio informado no processo será baixado totalmente. Este recurso é valido apenas ao selecionar a opção “Baixar Agregados”.  Outra maneira de baixar o patrimônio é parcialmente. O valor baixado no patrimônio será igual ao informado no campo 'Valor da ocorrência'. Este valor será aplicado no Valor Base Corrigido do patrimônio e servirá como base para os cálculos dos outros valores relacionados ao mesmo.  Para a Baixa Parcial é necessário que se informe o “Valor da Ocorrência” (valor a ser baixado) e, opcionalmente, a “Quantidade” de itens referentes ao(s) patrimônio(s) que será(ão) baixado(s).      **Observações:** As opções “Baixar agregados” e “Informar valor de venda por patrimônio” são válidas somente para o tipo de Baixa Total.  Se o campo “Informar valor de venda por patrimônio“ não estiver marcado as informações da baixa (valor, data, etc.) irão valer para todos os patrimônios (patrimônios principais e patrimônios agregados). Caso contrário irá valer para todos os patrimônios (patrimônios principais e patrimônios agregados), exceto o valor, pois cada um possuirá o próprio.    **Data da baixa**A data a ser utilizada no processo deverá considerar a Data Base do patrimônio, a última ocorrência para este patrimônio e a Data de Aquisição do mesmo, ou seja, a data precisa estar dentro do período de cálculo, deverá ser maior que a última ocorrência cadastrada e maior que a Data de Aquisição.  **Valor da venda**Opcionalmente, pode-se informar o valor da venda dos patrimônios a ser aplicado para cada patrimônio baixado automaticamente.  **Motivo de Baixa**O motivo de baixa deve estar previamente cadastrado antes da execução do processo. Para maiores informações sobre o cadastro do [motivo de baixa](https://tdn.totvs.com/display/LRM/Motivo+de+Baixa).  **Contabilização** A contabilização da baixa respeitará as informações definidas no Evento Contábil de Baixa para criação dos lançamentos. Ao marcar esta opção a [contabilização da baixa](https://tdn.totvs.com/pages/viewpage.action?pageId=423938350) ficará como pendente, podendo ser realizada posteriormente após a execução com sucesso da baixa.    **Observações:**Para a contabilização o sistema considera a data do lote e a data da ocorrência, ou seja, o sistema não contabilizará ocorrência com data fora do período do lote contábil. A contabilização só será realizada caso seja marcada a opção Contabilizar Ocorrência.    **Campo Observações** Campo livre que permite que sejam descritas informações que, posteriormente, podem ser visualizadas no histórico da ocorrência.  **Log** Após cada execução de Baixa (Total ou Parcial) será exibido um log contendo informações referentes ao processo.  O resultado da baixa pode ser conferido a partir da aba Cálculo Razão no tela de edição do patrimônio.  **Histórico de ocorrências realizadas** Após a execução, com sucesso, do processo o sistema armazena as informações relacionadas as [ocorrências](https://tdn.totvs.com/pages/viewpage.action?pageId=444596526) no menu Operações Patrimoniais. Outra forma de visualizar as ocorrências realizadas é a partir da aba de Ocorrências da tela de edição do patrimônio.  **Excluir ocorrências** Caso deseje excluir as ocorrências pode-se selecioná-las na aba Ocorrências (tela de edição do patrimônio) e escolher a opção Exclusão de Ocorrências em Processos. Outra maneira de executar este processo é a partir da tela de [consulta de ocorrências](https://tdn.totvs.com/pages/viewpage.action?pageId=444596526) no menu Operações Patrimoniais.  **Índices** Para as bases de dados que utilizam índice será respeitada a seguinte regra: Caso a moeda não use índices todos os valores correspondentes a índices serão ignorados. Se a moeda utilizar índices e não for encontrada uma cotação na data informada o sistema buscará na data anterior mais próxima.  **Apura perda e ganho** Marcando esta opção o sistema irá habilitar os controles de Conta para caso de Perda e Conta para caso de Ganho. Esta contabilização é opcional, podendo ser utilizada para contabilizar uma perda ou o ganho ao realizar a baixa de um bem.      A forma de contabilização será a seguinte: Caso haja ganho Será debitada (D) a conta da baixa e creditada(C) a conta de ganho informada no campo Conta para caso de Ganho.  Caso haja perda Será creditada (C) a conta da baixa e debitada (D) a conta de ganho informada no campo Conta para caso de Ganho.  O valor do lançamento de ganho / perda será calculado da seguinte forma: PerdaGanho = VrVenda - (VrOcorrência - VrDepreciação)    **Informar Valor de venda por patrimônio:** O sistema irá permitir informar o valor da venda por patrimônio, ou seja, caso você execute o processo de baixa para vários patrimônios, será permitido informar o valor de venda separadamente.      **Informar valor de venda por cenário** Marcando a opção 'Informar valor de venda por cenário', o sistema irá permitir informar o valor de venda por cenário.      Através dos parâmetros do módulo Patrimonial é possível definir algumas informações para o processo de Baixa.  Acesse o Menu Ambiente | Parâmetros | Gestão de Patrimônio | Ocorrências | Baixa | Específicos Baixa de Bens.  **Desativar patrimônio após sofrer baixa total** Define se quando o patrimônio sofrer a baixa total será colocado como inativo, através do campo correspondente no cadastro de patrimônio.      Acesse o Menu Ambiente | Parâmetros | Gestão de Patrimônio | Cadastro de Bens | Baixa de Bens.  **Desativar todos os dados dos patrimônios inativos** Define se os campos do cadastro de patrimônios serão bloqueados após inativação. |
