**Habilitar os Parâmetros para Informar as Fórmulas de repasse de Cálculo de Juros, Multa e Desconto**
 
\*Passo  1-\* Acesse: BackOffice/ TOTVS Gestão Financeira/ Ambiente/ Parâmetros/ TOTVS Gestão Financeira. \*Passo  2-{\*}Acesse: Contas a Pagar, Manutenção de Lançamentos/ Lançamentos e clique em \[Avançar\]. \*Passo  3-{\*}Acesse a aba \[valores Opcionais\]. \*Passo  4-{\*}Marque o checkBox do 4º, 5º e 6º parâmetro, para habilitar o seu preenchimento.Informe os valores abaixo:
\*+4º parâmetro+\*]]>

* **Nome:** Repasse Juros
* **Ação**: Acrescentar
* **Fórmula:** Não informar código de Fórmula
* **% Default:** 0
* **Dias de Atraso:** 0

**5º parâmetro**

* **Nome:** Repasse Multa
* **ação:** Acrescentar
* **Fórmula:** Não informar código de Fórmula
* **% Default:** 0
* **Dias de Atraso:** 0

**6º parâmetro**

* **Nome:** Repasse Desconto
* **ação:** Descontar
* **Fórmula:** Não informar código de Fórmula
* **% Default:** 0
* **Até Vencimento:** CheckBox Desmarcado

**Passo  5-** Avance até o Final. Os campos serão habilitados para preenchimento na aba Parâmetros do Cadastro de Tipo de documento.
