# Histórico Alteração de Boletos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Histórico Alteração de Boletos |
| **Situação/Requisito:** | Após a evolução para gravar o histórico de alteração de boletos (tabela **FBOLETOHISTORICO**), o sistema está causando o travamento no ato da geração da remessa em alguns casos. |
| **Solução/Implementação:** | Otimização no processo de histórico de alteração de boletos. Foi criado um parâmetro acessando **Financeiro > Contas a Receber > Baixas > Baixa a Receber** **> **Atualizar Histórico de Alteração de Boleto**** para que o cliente possa habilitar ou desabilitar este processo de Log. |
