**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)** Tempo aproximado para leitura:**00:00:40 min****Dúvida**Como aumento a quantidade de funcionários exibidos na visão?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para aumentar a quantidade de funcionários exibidos na visão, sigo os passos abaixo:  
  
1. Acesse **Serviços Globais | Serviços | Servidores de Aplicação**;2. Ao abrir esta tela, caso exista cadastro do server **FopFuncData,** edite o cadastro conforme passo 03. Caso não exista, crie um novo cadastro informando no campo ID do Server o server **FopFuncData**;  
3. No campo **Número máximo de registro**, informe o máximo de funcionários desejado para serem visualizados na visão ou informe 999999 e salve.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10757133912599)  
  
**Importante**Para identificar o ID do Server correspondente ao cadastro que deseja exibir mais registros, acesse o menu correspondente a ele e pressione: Ctrl + Alt + F9, conforme exemplo no print abaixo:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10757085062039)
