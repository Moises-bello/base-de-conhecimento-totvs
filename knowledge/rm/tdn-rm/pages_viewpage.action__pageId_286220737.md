# ACESSO AOS CADASTROS NECESSÁRIOS SEM UTILIZAR INTEGRAÇÃO COM O SSO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Folha de Pagamento. |
| **Função:** | CAGED |
| **Situação/Requisito:** | Permitir acesso aos cadastros necessários para gerenciar a realização de exames toxicológicos admissionais/demissionais diretamente pelo módulo de Folha de Pagamento. A realização desses cadastros tornou-se necessária para o Empregador que admitir ou desligar MOTORISTAS PROFISSIONAIS, que deverá declarar os campos Código Exame Toxicológico, Data Exame Médico (Dia/Mês/Ano), CNPJ do Laboratório, UFCRM e NRCRM, relativos as informações do exame toxicológico que trata o art. 24 da Lei nº 7.998 de 1990, os quais foram incluídos no layout do cadastro (Portaria MTb nº 945/2017, que visa conferir mais efetividade ao cumprimento da portaria MTb nº 116/2015). |
| **Solução/Implementação:** | Os funcionários que terão os novos campos acrescidos nos registros “C” ou “X” serão:      1. Os admitidos ou demitidos no Mês e; 2. Código do CBO PFUNCAO.CBO2002 igual a um dos códigos abaixo (somente números):          2.1.     782310 - Motorista de furgão ou veículo similar;         2.2.     782320 - Condutor de ambulância;         2.3.     782405 - Motorista de ônibus rodoviário;         2.4.     782410 - Motorista de ônibus urbano;         2.5.     782415 - Motorista de trólebus;         2.6.     782505 – Caminhoneiro autônomo (Rotas regionais e internacionais);         2.7.     782510 - Motorista de caminhão (Rotas regionais e internacionais); e         2.8.     782515 – Motorista operacional de guincho.  Observação: Caso a competência do CAGED não seja a Atual, deve verificar o Histórico de função para obter o CBO     Nos registros C e X, para os funcionários que satisfaçam as condições acima, após o campo “CEP Residência do Trabalhador” deverá informar:   1. Código Exame Médico 2. Data Exame Médico (DDMMAAAA) 3. CNPJ LABORATÓRIO 4. UF DO MÉDICO 5. CRM DO MÉDICO.      Porém, para os funcionários que não possuem os CBO´s acima, os campos devem ficar em branco com 51 espaços, totalizando um filler de 81 espaços.    **PROCEDIMENTO PARA IMPLANTAÇÃO.**  Instalar os últimos patch do Release a partir da versão 12.1.15. Rodar o script fechado criado pelo SSO , acesse o link **<http://wikihelp.totvs.com.br/WikiHelp/FOP/FOP.ExecutorScriptCaged.aspx>** para saber como fazer. Importar o layout **TOTVS Report “FOPREL0014 - Caged para conferência.TotvsReport** que contempla os novos campos    **PROCEDIMENTO PARA CONFIGURAÇÃO**  Verifique se a integração com o Vitae encontra-se desativada      Cadastre o exame correspondente ao Exame Toxicológico      Acesse o parametrizador do SSO      Informe o novo exame toxicológico cadastrado para ser usado na composição dos novos campos do registro C do CAGED        Cadastre o Médico responsável pelo exame para obtenção do CRM e seu respectivo UF      Cadastre a Entidade (Laboratório) responsável pela realização do Exame Toxicológico para obtenção do CNPJ      Relacione no Convênio a Entidade (Laboratório) com o Exame Toxicológico       No Anexo 'Segurança e Medicina' da Visão de Funcionário, cadastre a consulta e o exame toxicológico admissional ou demissional        Abra o 'Prontuário Médico' e inclua a Consulta Médica relacionada ao Exame Toxicológico       Preste atenção especial no preenchimento dos campos 'Serviço de Saúde Responsável' e 'Código do Médico'        Após salvar a consulta médica inclua o Exame Toxicológico       Informe os dados do Exame. O campo 'Tipo de Exame' é fundamental para que o CAGED saiba se o exame é admissional ou demissional. Preste atenção também ao preenchimento dos campos 'Exame', 'Entidade', 'Data do exame' e 'Código do Laudo (Padrão DENATRAN)'          Após Cadastrar no prontuário o Exame Toxicológico para Admissão ou Demissão. Pode-se emitir o CAGED em RH \ Folha de Pagamento \ Encargos \ CAGED.            Os novos campos são contemplados nas seguintes saídas:      1. Conferência em Tela:             2. Conferencia no layout para arquivo texto:            3. Arquivo a ser importado pelo Validador do CAGED.        Caso o CBO da função seja o de motorista (um dos listados acima), as seguintes situações poderão gerar mensagens de aviso no log:   * Esquecer de informar o código do exame no parametrizador; * Esquecer de preencher algum campo exigido; * Cadsatrar o exame posterior à admissão ou mais de 120 dias após demissão; * Informar o tipo do exame (admissional/demissional) erroneamente ou esquecer de informar; * Agendar exame diferente do que consta no parametrizador.           Para mais informação sobre a consulta médica acesse: <http://wikihelp.totvs.com.br/WikiHelp/SMT/SMT.ProntuarioMedico.aspx> |
