# APROVAÇÃO DE FREQUÊNCIA - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Aprovação de Frequência - Portal* |
| **Situação/Requisito:** | *Não conformidade de exibir as turmas/disciplinas para o professor na tela de aprovação de frequência mesmo ele não sendo do tipo coordenador na turma/disciplina quando o parâmetro "Utilizar turma/disciplina gerencial na digitação de notas, faltas, avaliação, freqüência diária..." estiver marcado nos parâmetros da Secretaria.* |
| **Solução/Implementação:** | *Ajuste no portal para que quando o parâmetro "Utilizar turma/disciplina gerencial na digitação de notas, faltas, avaliação, freqüência diária..." da secretaria estivesse marcado, as turmas/disciplinas em que o professor está incluído não apareçam na aprovação de frequência no portal caso ele não seja coordenador delas.* |
| **Conversores e Parâmetros:** | *N/A* |
| **Chamados relacionados:** | *TVHOW7 e TVHP70* |
