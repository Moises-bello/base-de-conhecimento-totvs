# RMSAU-3896 -  Erro na integração com backoffice diferentes em coligadas diferentes

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Integração com Backoffice EMS |
| **Situação/Requisito:** | Ao integrar com Backoffice o parâmetro INTEGRASAUDEEMS está sendo fixo da coligada 0 |
| **Solução/Implementação:** | O parâmetro deve ser lido da coligada logada, quando não existir lerá da coligada 0 |
| **Requisito:** | RMSAU-3896 |
