**Dúvida**

Como configurar acesso por usuário no Gerenciamento de Projetos?

**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGAPMS - Todas as versões

**Solução**

É possível controlar as alterações e manipulações dos projetos, atribuindo direitos de acesso para cada usuário, desta forma, podemos definir que determinado usuário tenha direitos totais sobre "Solicitações de Compras" por exemplo porém para documentos do projeto, seu acesso seja somente para visualização.

Opções do menu da rotina Usuários

Existem dois tipos de informações que podem ser visualizadas a partir da referência do projeto:

* Legenda: Indica o que significa cada ícone na visualização da estrutura.
* Fase: Indica todas as operações e configurações (permitidas ou não) para a fase do projeto.
* Filtro : Esta opção permite filtrar as tarefas que serão visualizadas, de acordo como estado de sua execução (todas, finalizadas ou pendentes), a data prevista (filtro de/até) e/ou de um determinado recurso.
* Usuários : Por esta opção é possível incluir, excluir e modificar as propriedades dos usuários das tarefas/EDTs.  Os acessos podem ser definidos como:

  + Bloqueado (sem nenhum acesso)
  + Visualizar
  + Alterar
  + Controle total

  Para configuração : A cessar a rotina Gerenciamento de projeto> posicione no projeto em questão > Outras Ações > Ferramentas > usuários > Seleciona Tarefa/Edt no qual o usuário irá conceder o acesso;![Screenshot_1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360103516433)OBS: O usuário que cria o projeto possui automaticamente direito de acesso total a todas as operações desse projeto.
