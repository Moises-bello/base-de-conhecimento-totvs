**Dúvida**

Como configurar uma conta de e-mail para utilizar no NFC (PGCA010) quando o parâmetro PGCWF está desativado?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Compras - Versão 12.1.2210

**Solução**

Para configuração da conta, é necessário acessar o Configurador via "**SIGACFG / Workflow / Contas de e-mail".**

Ao incluir a conta, siga os seguintes parâmetros:  
  
\* O campo remetente não deve ser preenchido com caracteres especiais.  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/38801704670871)

**Importante:**

***\*\* Lembrando que para utilizar a conta GMAIL com o TOTVS | Application Server, é necessário configurar as "Senhas de App" conforme a documentação abaixo.***

**\*\*Esse processo serve para quando o parâmetro MV\_PGCWF está desativado, essa conta de email será utilizada para todos os compradores que utilizarem a rotina.**

**\*\*Caso tenha dúvida de como incluir contas de um provedor diferente do GOOGLE é necessário entrar em contato com o suporte do provedor ou com a sua equipe de TI.**
