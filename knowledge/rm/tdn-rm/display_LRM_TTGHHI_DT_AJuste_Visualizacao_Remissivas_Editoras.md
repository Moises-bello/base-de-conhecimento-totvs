# EDITORAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Bibliotecária* |
| **Função:** | *Informe a função.* |
| **Situação/Requisito:** | *A visualização das editoras e suas remissivas estava sendo mostradas de uma forma confusa, que poderia gerar dúvidas no usuário no momento da operação da seleção da editora de uma publicação.* |
| **Solução/Implementação:** | *Feito o ajuste na visualização das editoras e suas remissivas no cadastro de publicações, para facilitar o entendimento e visualização, ao pesquisar uma editora, será exibido sempre a editora e o campo remissivas, sendo que o campo remissiva sempre será precedido pelo nome da editora, independente de quantas remissivas uma editora tiver, todas serão precedidas pelo nome principal da editora, facilitando assim a identificação da editora. Foi implementado também a possibilidade de pesquisar uma editora pela remissiva.* |
