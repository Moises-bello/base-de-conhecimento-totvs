# AVALIAÇÃO - QUESTÃO CONDICIONAL - SALVAR AUTOMATICAMENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs avaliação e pesquisa* |
| **Função:** | *Execução de avaliação de pesquisa de opinião - questão condicional - salvar automaticamente* |
| **Situação/Requisito:** | *Quando é executada uma avaliação do tipo pesquisa de opinião com questões condicionais e que esteja configurada para salvar automaticamente em um intervalo de tempo, quando é executado a função de salvar automaticamente, o sistema salva corretamente as opções do usuário, porém as questões condicionadas, voltam a situação anterior, ou seja, se é marcada uma determinada opção que oculta uma questão, assim que a função para salvar automaticamente executa, a questão que deveria estar oculta retorna visível.* |
| **Solução/Implementação:** | *Foi feito um ajuste na montagem da tela para que a função de retorno da método de salvar automaticamente o sistema recarregue os componentes da tela, assim exibindo as questões condicionadas corretamente.* |
