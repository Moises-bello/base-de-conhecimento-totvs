# PORTAL - DIÁRIO DE CLASSE - COPIAR CONTEÚDO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Portal - Diário de Classe - Copiar conteúdo para outra turma/disciplina* |
| **Situação/Requisito:** | No Portal, ao acessar o link Diário de classe e escolher a opção "Copiar conteúdo para outra turma/disciplina", o sistema permitia incorretamente copiar para uma turma/disciplina cujo Período Letivo estivesse Encerrado. |
| **Solução/Implementação:** | *Alterado no Portal, ao acessar o link Diário de classe e escolher a opção "Copiar conteúdo para outra turma/disciplina", o sistema somente listará turmas/disciplinas DESTINOS cujo período letivo não esteja encerrado.* |
