**Dúvida**

Como é preenchido o Código de Usuário (**U7\_CODUSU**) na rotina de Operadores (**TMKA090**)?

**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGATMK - Todas as versões.  
  
**Solução**

Na rotina, Operadores (TMKA090), o preenchimento direto no campo **Cod. Usuário (U7\_CODUSU)**, não surtira efeito na gravação do registro, após salvar a inclusão do Operador, Pois o procedimento correto seria através do **"Outras Ações"** -> **"Usuário",** selecione o usuário a qual deseja vincular ao Operador para o cadastro.

Efetuando o cadastro conforme indicado, o campo **Cod. Usuário (U7\_CODUSU)** será preenchido com o Usuário.

**Importante:** Caso selecione o código de Usuário a qual já possui um operador cadastrado/vinculado será apresentado o **HELP: TMKOPERAD**
