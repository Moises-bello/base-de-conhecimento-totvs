# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Contábil |
| **Versões:** | 12.1.20 |
| **Ocorrência:** | Importação de Conceito |
| **Ambiente:** |  |
| **Passo a passo:** | Para realizar a importação de dados por arquivo texto no Totvs Gestão Contábil será utilizada a ferramenta "RM Conector", que facilita a execução destas operações de forma dinâmica, utilizando a própria regra dos cadastros da contabilidade.  Esta ferramenta pode ser acessada através do Menu Utilitários > Rm Conector  Processos | importar Conceito |
| **Observações:** | Todos os conceitos para importação estão disponível no caminho  C:\TOTVS\CorporeRM\ObjetosGerenciais\Conceito  Arquivo com a extensão (concept) deve ser processado como novo conceito. Arquivo com extensão (.ICP) devem ser processado como conceito. |
