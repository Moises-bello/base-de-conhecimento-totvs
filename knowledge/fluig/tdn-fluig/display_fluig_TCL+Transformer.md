Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**.

A finalidade desse componente é converter um arquivo de TXT para XML por meio de um arquivo TCL (*Text Converter Language*).

TCL trata-se de uma linguagem que converte mensagens de texto para XML e vice-versa. Essa conversão é necessária para que se possa utilizar os recursos do XSL.

| Campo | Descrição |
| --- | --- |
| Name | Inserir uma identificação para a configuração do componente. |
| File Name | Inserir o nome do arquivo TCL que servirá como mapa da transformação. |
