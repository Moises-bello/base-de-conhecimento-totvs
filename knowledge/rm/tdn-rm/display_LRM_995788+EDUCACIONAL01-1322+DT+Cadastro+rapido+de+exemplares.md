# CADASTRO RÁPIDO DE EXEMPLARES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Cadastro rápido de exemplares* |
| **Situação/Requisito:** | *Ao executar o processo de cadastro rápido de exemplares o sistema impede a geração de exemplares que possuem o mesmo número de exemplar, quando o parâmetro para exibição de mensagem para exemplares com mesmo número estiver marcado.* |
| **Solução/Implementação:** | *Foi removida a restrição na execução do processo de cadastro rápido de exemplares, que impedia a sua execução para exemplares com mesmo número.*  *A alteração removeu a restrição, porém, caso o parâmetro esteja marcado, o sistema irá gerar os exemplares, mas apresentará um aviso ao final do processo.*  *Processo*:  ***Educacional | Gestão Bibliotecária | Acervo | Publicações***  *Processos | Cadastro rápido de exemplares*    *Parâmetro:*  ***14.01 - Controle de acesso | 14.01.01 - Exemplar | Exemplar 2/2 | Exibir mensagem de alerta para duplicação do campo nº exemplar*** |
