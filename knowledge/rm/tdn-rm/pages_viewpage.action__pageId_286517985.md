# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Copiar Contas Contábeis entre Coligadas |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do Processo**  Para agilizar e facilitar o cadastro de uma Conta Contábil ou Gerencial já cadastrada em uma coligada poderá ser copiada de uma coligada para outra utilizando o processo para copiar contas.  **Regras Gerais**   * As máscaras entre as coligadas origem e destino devem, obrigatoriamente, ser iguais para que a cópia seja efetuada. * Contas globais não poderão ser copiadas. * No processo de cópia, o sistema consistirá se na coligada destino já existe alguma conta (seja global ou não) com mesmo código da que está sendo copiada. Se já existir, a cópia não será efetuada. * Toda a hierarquia de contas sintéticas (todos os níveis anteriores, ou seja, os pais da conta que está sendo copiada) deve existir na coligada destino, caso contrário, a conta não será copiada. * Se para a cópia for selecionada, por exemplo, a conta sintética 1, será copiada apenas a conta sintética 1. Não será copiado todo o grupo 1 (as contas filhas do grupo 1 não serão copiadas). * Se a conta origem exigir rateio, a conta copiada também exigirá rateio, porém os rateios default da conta origem não serão copiados. A conta destino (cópia) ficará com rateio default vazio. (exclusivo para cópia de contas contábeis). * Os campos complementares não serão copiados.   **Parametrização Necessária**  1 - Selecione a(s) conta(s) a ser(em) copiada(s) e acesse o processo:                    2 - Na tela seguinte, o sistema abrirá a seleção da coligada/destino: |
