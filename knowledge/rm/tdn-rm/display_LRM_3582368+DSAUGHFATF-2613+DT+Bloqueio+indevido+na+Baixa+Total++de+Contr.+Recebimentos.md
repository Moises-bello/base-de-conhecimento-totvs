# Bloqueio indevido na Baixa Total de Contr. Recebimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Recebimentos |
| **Situação/Requisito:** | Bloqueio da baixa total indevidamente pois não considerava o valor original da baixa. |
| **Solução/Implementação:** | Alterada a verificação da baixa total ao gravar a baixa, onde só é permitida a baixa total caso o valor original da baixa seja igual ao valor a receber. |
