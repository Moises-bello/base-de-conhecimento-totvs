![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29013113633687) Tempo aproximado para leitura: **00:01:00****Dúvida**Como inserir a seta, para ordenar os registros, em uma coluna na tela da rotina?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**Este recurso da seta, é exibido quando o campo da coluna é um índice da tabela. Nesse caso seria necessário que o campo estivesse no índice por padrão ou é possível incluir em um novo índice.

Para maiores informações de como criar o índice clica nesse boletim:

* [Framework - Linha Protheus - Como criar índices no Protheus](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360019903692-Framework-Linha-Protheus-Como-criar-%C3%ADndices-no-Protheus)

Caso necessite de apoio para criação, entre em contato com o time de Suporte de Framework.
