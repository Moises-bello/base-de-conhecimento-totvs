![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23127814668567) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como gerar um evento S-2205 (Alteração de Dados Cadastrais do Trabalhador) com data retroativa?  
  
**Ambiente**TOTVS RH - (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**1. Altere a data base do sistema para a data retroativa que deseja enviar o evento:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23127814670743) ![](https://centraldeatendimento.totvs.com/hc/article_attachments/23127801531799)  
  
2. Realize a alteração no **Cadastro do Funcionário (GPEA010)** ou **Cadastro de Dependentes (GPEA020)**  
Para mais detalhes acesse a documentação abaixo:  
[RH - Linha Protheus - GPE - eSocial - S-2205 - Como gerar o evento S-2205 (Alteração de Dados Cadastrais do Trabalhador)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500001336262-RH-Linha-Protheus-GPE-eSocial-S-2205-Como-gerar-o-evento-S-2205-Altera%C3%A7%C3%A3o-de-Dados-Cadastrais-do-Trabalhador)  
  
3. Após salvar a alteração será gerado o evento S-2205 conforme a data base do sistema **(Passo 1)**
