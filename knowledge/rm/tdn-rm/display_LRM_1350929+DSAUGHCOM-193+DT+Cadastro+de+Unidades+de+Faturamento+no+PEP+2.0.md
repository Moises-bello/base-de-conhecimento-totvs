# Cadastro de Unidades de Faturamento no PEP 2.0

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro de Unidades de Atendimento |
| **Situação/Requisito:** | Ao cadastrar uma unidade de Faturamento, o sistema também cadastrava essa unidade no PEP 2.0 mesmo quando parametrizado que elas não realizam atendimento. |
| **Solução/Implementação:** | Ajustado para não integrar o cadastro das unidades de Faturamento quando estiver parametrizado para não registrarem atendimento. |
| **Documento de Referência:** | Ticket #1350929 |
