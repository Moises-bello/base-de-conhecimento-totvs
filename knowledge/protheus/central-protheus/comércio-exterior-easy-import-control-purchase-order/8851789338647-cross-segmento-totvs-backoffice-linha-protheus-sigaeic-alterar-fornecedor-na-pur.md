![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Preciso alterar o Fornecedor na *Purchase Order*, porém o campo está desabilitado.   
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus) –*Easy Import Control*– Todas versões]  
**Solução**O sistema não permite alterar o fornecedor após a gravação da *Purchase Order "PO".* Nesse caso,  para alterar o fornecedor, é necessário estornar a *PO*.
