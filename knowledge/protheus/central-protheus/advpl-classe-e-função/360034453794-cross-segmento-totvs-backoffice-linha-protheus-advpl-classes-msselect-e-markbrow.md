**Dúvida**Como ajustar as larguras das colunas para as Classes "*MsSelect*" e "*MarkBrow*"?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL– Todas versões  
  
**Solução**As classes não permite alterar o tamanho da coluna via fonte, pois são calculadas automaticamente na criação das telas para melhor dimensionamento.
