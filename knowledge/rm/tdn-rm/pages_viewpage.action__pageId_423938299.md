Através deste Processo é possível aplicar um Cliente/Fornecedor aos Produtos marcados.   
 **Operação:** Neste campo é marcado se a Operação será para Incluir ou Excluir o Cliente/Fornecedor dos Produtos selecionados.

**Cliente/Fornecedor:** Neste campo é selecionado o Cli/For que será incluído ou excluído para os produtos marcados.

**Tabela de Classificação de Produto Tipo:** Para que o processo seja executado com sucesso é necessário que para este campo seja selecionada a Tabela de Classificação assinalada dentro do Cadastro de Produtos | Detalhes | Classificação.
