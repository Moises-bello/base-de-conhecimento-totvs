**Parâmetros do Abono**

**Utiliza nova gestão de abono:** Habilitando este parâmetro o processo de inclusão e exclusão de abono será realizado considerando a tabela AABONOFUNCIONARIO. Ao selecionar o parâmetro para utilizar a nova gestão os campos “Considera como horas o limite de abono” e “Considera abonos por intervalo” são desabilitados e bloqueados para edição.

**Considera como horas o limite de abono:** Habilitando este parâmetro o sistema permitirá cadastrar no módulo Cadastros | Cálculos | Abonos, o limite de abonos em horas. Com o parâmetro desmarcado, esse limite será considerado em dias. Caso o funcionário ultrapasse o limite de horas abonadas informado no cadastro do abono durante o período parametrizado, o sistema emitirá uma mensagem no momento do lançamento de abono informando que o funcionário ultrapassou o limite de horas estabelecido.

**Observações:**

1) Com este parâmetro habilitado, os campos "Hora de Início" e "Hora de Término" no cadastro de abonos, ficarão habilitados e será desabilitado o campo "Número de horas a serem abonadas".

2) Este parâmetro deve estar marcado se utilizar integração com o sistema RM Vitae, para cadastrar atestado e lançar abono para o RM Chronus. Os atestados no RM Vitae são cadastrados por intervalo.

3) No lançamento de abono sintético sempre é considerado o lançamento de abonos por horas. Diretamente nas telas de “Lançamento global de abonos” e “Abonar” são mostradas as opções de lançamento por intervalo ou número de horas.

**Considera abonos por intervalo:**Habilitando este parâmetro, será necessário informar o intervalo de horas para se cadastrar um abono para o funcionário. Desabilitando este parâmetro o sistema trará como default no momento do cadastramento do abono, o número de horas de falta, ou atrasos que o funcionário possui naquele dia já calculado em sua movimentação.

**Observação:**Ao utilizar o lançamento de abonos por intervalo é recomendado que esse parâmetro esteja marcado para que o sistema calcule corretamente os intervalos abonados.

**Abono utilizado para Atestado do Labore:** Informe neste campo o abono que será utilizado para o afastamento do TOTVS Folha de Pagamento.

**Observação:** Este abono será utilizado somente para os 15 primeiros dia de afastamento, pagos pela empresa.
