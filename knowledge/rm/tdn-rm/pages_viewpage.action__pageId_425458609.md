**Título da rotina de matrícula**: Este campo tem como objetivo apresentar uma mensagem a ser exibida na apresentação do processo de Matrícula Online. Caso este campo não este preenchido, será exibido o texto padrão do sistema.

**Mensagem de matrícula Não-disponível**: Este campo tem como objetivo apresentar uma mensagem a ser exibida na apresentação do processo de Matrícula Online quando a matrícula não estiver disponível. Caso este campo não este preenchido, será exibido o texto padrão do sistema.

**Mensagem de confirmação de matrícula**: Este campo tem como objetivo apresentar uma mensagem a ser exibida na confirmação do processo de Matrícula Online . Caso este campo não este preenchido, será exibido o texto padrão do sistema.
