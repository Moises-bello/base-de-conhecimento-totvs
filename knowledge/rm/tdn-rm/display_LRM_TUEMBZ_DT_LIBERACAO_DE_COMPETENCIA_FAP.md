# LIBERAÇÃO DE COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Liberação de Competência* |
| **Situação/Requisito:** | *Ao realizar a Liberação de Competência, a vigência das alíquotas FAP das seções eram atualizadas mesmo o parâmetro para atualizar estando desmarcado.* |
| **Solução/Implementação:** | *Foi corrigido o tratamento para atualizar apenas as alíquotas que estiverem com o parâmetro de atualização da vigência marcados.* |
