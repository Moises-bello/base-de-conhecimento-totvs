Os relacionamentos devem ser criados quando o contexto do um conjunto de dados possuir mais de uma tabela. Este relacionamento irá permitir ao gerador percorrer os dados das tabelas filhas para cada registro da tabela pai de forma hierárquica. Gerando registros hierarquizados da mesma forma. Uma tabela filha só poderá ser associada a um registro cujo registro pai esteja associado a tabela pai quando o tipo de relacionamento for Um para muitos. Caso o relacionamento seja um para um, a associação da tabela filha ao registro não é necessária, pois ela pode ser associada a qualquer registro que esteja associado a tabela pai.

![](/download/attachments/319787297/propriedades_do_relacionamento.png?version=1&modificationDate=1512921909000&api=v2)

1Nome

Informe o nome do relacionamento.

2Tabela Pai

Selecione a tabela pai do relacionamento.

3Tabela Filha

Selecione a tabela filha do relacionamento.

4Tipo de Relacionamento

Selecione o tipo de relacionamento que pode ser Um para muitos (padrão) ou Um para Um.

5Coluna Chave

Informe os campos chave da tabela pai para fazer o relacionamento.

6Coluna Detalhe

Selecione os campos da tabela filha para fazer o relacionamento.

7OK

Clique para salvar os dados do relacionamento.

8Cancelar

Clique para cancelar as alteração do relacionamento.
