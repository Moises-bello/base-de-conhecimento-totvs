A [Lei Nº 13.709/18](http://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/L13709.htm), **Lei Geral de Proteção de Dados Pessoais**, regula sobre coleta, armazenamento, tratamento e compartilhamento de dados pessoais, impondo mais proteção sobre estes dados e, também, severas penalidades para o seu descumprimento.

Com base nela, estão sendo implementados os serviços de anonimização para disponibilização através do SGDP - Serviço de Gestão de Dados Pessoais e algumas regras de restrição a dados consumidos através de dataservers por meio dos serviços SOAP e Rest.
