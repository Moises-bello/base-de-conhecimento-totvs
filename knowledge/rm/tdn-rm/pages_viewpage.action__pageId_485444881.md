Base de cálculo do tipo valor.Este código de cálculo será utilizado para informação do total pago de diferença salarial na rescisão complementar referente dissídio coletivo. Este valor não compõe a base de cálculo do inss do mês porque já existe calculado sobre este valor o inss diferença salarial.  
   
**Atenção**  
   
A diferença do Aviso Prévio Indenizado sempre será acumulada no CC 69, para que o valor saia na GRRF.  No SEFIP será tratado para que o valor do CC 99 não seja considerado novamente, e assim duplicar o recolhimento.

Valores de base de RRA também são acumulados neste evento.
