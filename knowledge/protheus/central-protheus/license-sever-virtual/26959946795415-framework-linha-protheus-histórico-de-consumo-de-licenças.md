**Duvida:**   
Como visualizar o histórico de consumo de licenças no Monitor do License Server?

**Ambiente**  
Protheus – Servidor de Licenças - Todas as versões

**Solução**

O histórico de consumo fornece informações detalhadas sobre o uso do License Server ao longo do tempo. Nesta visualização, é possível acessar:

* **Licenças Concorrentes:** Exibe o histórico de uso simultâneo da licença selecionada, comparando as licenças disponíveis com os picos de uso.
* **Conexões:** Apresenta a relação entre o número de licenças utilizadas e licenças negadas, permitindo verificar o volume de uso de cada licença selecionada.
* **Usuários:** Exibe todas as conexões de usuários, incluindo informações como licença utilizada, rotina acessada, tempo de uso, entre outras.

**Passos para acesso:**

* Acesse o servidor onde foi instalado o License Server.
* Abra o Totvs License Server Monitor.
* No Monitor, selecione a aba **Histórico de Consumo**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26959927839895)

Na aba Histórico de Consumo é possível consultar as licenças utilizadas em seu ambiente de acordo com o período programado para se manter este histórico.

Nesta aba, é possível visualizar ou exportar os dados de uso de licenças, conexões dos usuários, entre outras informações para um arquivo .CSV.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26959927841047)

Na guia de conexões se tem todos os usuários que acessaram o sistema e as informações de conexão deste usuário, assim como as licenças utilizadas por este.
