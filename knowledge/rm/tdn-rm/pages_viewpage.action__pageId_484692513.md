# Envio de mensagens: nota do aluno não respeita a parametrização de casas decimais

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Envio de mensagens |
| **Situação/Requisito:** | Quando é enviada uma mensagem (e-mail ou eduCONNECT) e essa mensagem possui o campo  NOTA (do aluno) o valor do campo não está respeitando a parametrização de casas decimais conforme é feito no portal. |
| **Solução/Implementação:** | Otimizado o processo para que o eduCONNECT respeite a parametrização de casas decimais informado no cadastro   da disciplina. |
