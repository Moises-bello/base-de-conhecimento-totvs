# Honorários Duplicados

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Informações Cirúrgicas |
| **Situação:** | O sistema duplicava os itens na conta do paciente, quando era utilizado o processo de envio de dados para o faturamento, no registro de informações cirúrgicas. |
| **Solução:** | Ajuste realizado para que o sistema faça o envio dos dados de Registro de Informação Cirúrgica para o faturamento sem duplicidade de valores na conta do paciente. |
