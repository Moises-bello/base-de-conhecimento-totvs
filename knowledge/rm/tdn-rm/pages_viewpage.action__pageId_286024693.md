|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Conceito de importação de lançamentos contábeis |

| **Solução/Implementação:** | O conceito de importação de lançamentos contábeis foi alterado para que o sistema não consista, para coligadas que não acessam contas globais, o reduzido e o código das contas existentes na coligada global. |
