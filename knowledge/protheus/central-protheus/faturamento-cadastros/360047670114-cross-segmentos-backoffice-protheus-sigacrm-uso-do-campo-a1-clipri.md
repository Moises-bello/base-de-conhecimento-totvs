**Dúvida**

Qual a finalidade do campo "**Cli. Primar."** (**A1\_CLIPRI)**?  
  
**Ambiente**Cross Segmentos - Backoffice Protheus - SIGACRM - Todas as versões.

**Solução**

O campo **"Cli. Primar."** (**A1\_CLIPRI)** é usado para informar e localizar os sub-clientes de um cliente principal.

Caso seja um cliente secundário (sub-cliente), serve para confirmar qual é o cliente principal vinculado à ele.

Para informar o cliente principal, acesse a rotina **"Clientes" (CRMA070)** e selecione o cliente principal no campo **"Cli. Primar."** (**A1\_CLIPRI)**. 

Observação: O campo é informativo
