Neste módulo será possível realizar a aprovação de dados cadastrais realizadas por funcionários através do Totvs RMPortal.

As alterações cadastrais disponíveis são: Endereço, Banco de Pagamento, Carteira de Motorista, Apelido, Passaporte e Sugestão de Programação de Férias.

Após a aprovação dos dados, serão substituídas as informações constantes no cadastro do funcionário pela informação cadastrada pelo funcionário.

Este módulo permite ao supervisor imediato aprovar ou não as alterações cadastrais realizadas pelo funcionário através do Totvs RMPortal.

**Realizando alteração de endereço através do Totvs RMPortal**

Para realizar alteração de endereço através do Portal, o usuário deverá logar, digitando seu usuário e senha, logo depois acessar: Dados Cadastrais | Endereço | Alterar Endereço, digitar todas as informações desejadas e salvar.

**Aprovando alteração de endereço realizada pelo funcionário**

Para realizar aprovação de alteração de endereço realizada pelo funcionário, o supervisor deverá logar no Totvs Folha de Pagamento e acessar: Rotinas | Aprovação de Alterações Cadastrais (.Net), clicar no botão "Dados para Aprovação", neste momento aparecerão todos os funcionários que possuem dados cadastrais a serem aprovados, clicar no botão "Endereço", verificar as informações e decidir se serão aprovadas ou não. Para aprovar as informações basta agora o supervisor clicar no botão "Aprovar" e para cancelar clicar no botão "Cancelar".
