![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30647348092183) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**É possível **utilizar** as **funcionalidades** do **Meu RH** para **integração** para **outros produtos**?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Meu RH – Todas as versões  
  
**Solução  
Atualmente** o **Meu RH** **não permite** este tipo de **customização** e o **Suporte Padrão não atende** esse tipo de **questionamento**, devido à restringir a atuação quanto aos **produtos oferecidos exclusivamente pela TOTVS**.  
  
Apesar do Meu RH utilizar tecnologia ***REST API*** para seu funcionamento, os ***end-points*** por ele utilizados **não são disponibilizados para customização**.  
  
Temos atualmente a **documentação de *API'S*** **homologadas** que são utilizadas para customizações, que segue abaixo:  
**<https://api.totvs.com.br/>**  
  
É possível também **criar os *end-points* customizados**, de acordo com as necessidades da empresa, ao seguir os exemplos abaixo:  
**[Como criar um serviço REST no protheus](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360052976074)**
