# Lançamento vinculado a fatura não é visualizado no portal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Extrato financeiro do aluno |
| **Situação/Requisito:** | Após realizado a fatura de um lançamento de origem Educacional, o boleto associado deixa de aparecer no portal do aluno |
| **Solução/Implementação:** | O Financeiro na versão 12.1.20 começou a cancelar o boleto associado após a geração da fatura, desta forma será apresentado ao aluno o boleto com o a situação de cancelado |
