# Token da Aplicação

|  |  |
| --- | --- |
| **Produto:** | Fluig |
| **Passo a passo:** | **Objetivo:**  O objetivo deste guia  é ensinar como baixar o Token de aplicações no Fluig.  **Introdução:**  Após ingressar no identity, acesse o menu "Ações", "", e procure pelo aplicativo que deseja pegar o Token.    Selecione o aplicativo e clique em Token de Configuração    Será exibido o Token daquele aplicativo.   Observação **É necessário o TOKEN do aplicativo RM exe e do RM Portal caso utilizado.** |
