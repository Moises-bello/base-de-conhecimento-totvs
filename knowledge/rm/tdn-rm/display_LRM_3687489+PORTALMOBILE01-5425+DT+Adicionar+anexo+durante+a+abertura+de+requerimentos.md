# Adicionar anexo durante a abertura de requerimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Requerimentos |
| **Situação/Requisito:** | Durante a abertura do requerimento não é possível adicionar anexos. Apenas é possível adicionar, após a abertura do requerimento, sendo necessário encontrar o requerimento listado, para posteriormente adicionar um anexo. |
| **Solução/Implementação:** | Durante a abertura do requerimento, foi adicionado um botão chamar "Adicionar anexo" no qual permite adicionar um arquivo anexo durante a abertura do requerimento. |
