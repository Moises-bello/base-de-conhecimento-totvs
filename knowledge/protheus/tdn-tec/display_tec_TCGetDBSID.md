TCGetDBSID

Retorna uma string que identifica a conexão atualmente em uso no SGDB utilizado.

## Sintaxe

false

## Retorno

| Nome | Tipo | Descrição |
| --- | --- | --- |
| cRet | caractere | Retorna um identificador string único, que identifica a conexão atual no SGDB. |

## Observações

* É necessário conexão com o DBAccess para uso desta função.

## Exemplos

cppEclipsetruefalse

## Abrangência

Este recurso requer um TOTVS | Application Server com build igual ou superior a **7.00.100812P**, bem como um DBAccess Server com build igual ou superior a **20100927**.
