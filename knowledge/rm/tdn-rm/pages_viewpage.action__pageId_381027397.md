# Introdução

---

        No parâmetro Global **Diretório de Rede Comum** deve ser informado um diretório compartilhado na rede, onde o sistema deverá ter permissão para manipular arquivos. Atualmente esse parâmetro é usado em processos de Planilhas. A seguir esse fluxo será melhor detalhado.

# Configuração

---

        Para configurar o parâmetro, acesse o menu 'Ambiente > Parâmetros > Parâmetros Globais > Configurações Públicas > Diretório de Rede Comum'.

        Informe nesse campo um caminho de rede onde o sistema utilizará para armazenar arquivos.

  É importante que esse diretório esteja compartilhado na rede e com as devidas permissões de acesso concedidas.

        Veja abaixo onde esse parâmetro é utilizado atualmente no sistema.

# Utilização em Planilhas

---

      O parâmetro acima é utilizado atualmente no processo de Geração de Planilhas em Lote, o mesmo possibilita a exportação do resultado de uma Consulta SQL em uma planilha.

O resultado será exportado para o Diretório de Rede Comum configurado conforme o exemplo acima. Para mais informações, acesse a página: [Geração de Planilhas em Lote](http://tdn.totvs.com/x/VEkSCw)
