**Dúvida**  
Inserção de botão para localizar arquivos nas perguntas do CNAB a Pagar.  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões.  
  
**Solução**

Para solucionar essa dúvida, realize os seguintes passos:  
1. No padrão, as opções para arquivo de configuração e entrada permitem apenas o preenchimento como texto, conforme imagem:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21711679886487)  
2. Para incluirmos o botão de localização do arquivo, devemos acessar o configurador (SIGACFG) > Base de Dados >Perguntas ;  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21711679890327)  
3. Localizar o arquivo de configuração, AFI430, através da lupa, selecionar a linha "arquivo de configuração?", e ir no ícone de alteração.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21711733156247)

4. Selecionando os itens da ordem 3 e 4, "arquivo de entrada?", "arquivo de config?", respectivamente, vá até a coluna objeto e altere de "edit" para "file"  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21711679899031)   
5. O resultado será esse:   
  
Possibilitando navegar pelas pastas para encontrar os arquivos.   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21711679900951)
