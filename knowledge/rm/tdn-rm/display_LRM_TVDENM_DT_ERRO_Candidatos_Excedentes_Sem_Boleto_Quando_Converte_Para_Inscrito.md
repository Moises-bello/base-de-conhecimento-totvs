# CADASTRO DE CANDIDATOS EXCEDENTES

# 

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Área de interesse ofertada - candidatos excedentes* |
| **Situação/Requisito:** | *Em um processo seletivo marcado para inscrever excedentes, inscrito alguns candidatos como excedente, porem caso depois de ter inscrito os excedentes aumentar o número de vagas na área ofertada, o sistema não gera boleto para os excedentes que conseguiram a vaga. Ao alterar o número de vagas no cadastro de área ofertada o sistema deveria gerar os boletos.* |
| **Solução/Implementação:** | *Implementado método que verifica se existem vagas não preenchidas no registro da área de interesse, e caso existam candidatos excedentes, converte-os para inscritos.* |
