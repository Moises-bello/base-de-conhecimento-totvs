## **02. SITUAÇÃO/REQUISITO**

Para atender a [Lei Nº 13.709/18](http://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/L13709.htm) foi criado o processo "anonimizar usuários", este processo irá verificar se o usuário do processo seletivo possui algum vínculo com algum processo seletivo, se não possuir o processo irá excluir o usuário, caso este possua algum vínculo o sistema irá verificar algumas regras e se o usuário for elegível para anonimizar o sistema irá alterar os campos permitidos e definidos para um valor fictício (ex: 000).
