![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19276381923223) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como Cadastrar Cursos ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Recrutamento e Seleção de Pessoal - Todas as versões  
  
**Solução**Este cadastro tem como objetivo relacionar os cursos efetuados por um candidato na fase de **Recrutamento e Seleção ou de Treinamento**, quando cursos de aperfeiçoamento profissional.  
  
Os cursos podem ser classificados, em campo respectivo como sendo referentes a:

|  |  |
| --- | --- |
| • | Formação Acadêmica |

|  |  |
| --- | --- |
| • | Idiomas |

|  |  |
| --- | --- |
| • | Certificados |

|  |  |
| --- | --- |
| • | Cursos |

  
Esta classificação permite a visualização **dos tipos de cursos no Portal do Candidato e no Portal Gestão do Capital Humano.** Os cursos recebem um código e são destacados na pasta "Histórico Extracurriculares" do Cadastro de Funcionários do ambiente Treinamento.

**Acessar a rotina Atualizações > Cadastros > Cursos > Incluir**Preencha os dados conforme orientação do help de campo, com atenção especial ao seguinte:  
  
• Tipo - Selecione o tipo de curso desejado para classificar o curso em cadastro, conforme informado no cadastro de Tipos de Cursos.![](https://centraldeatendimento.totvs.com/hc/article_attachments/19276373916695)
