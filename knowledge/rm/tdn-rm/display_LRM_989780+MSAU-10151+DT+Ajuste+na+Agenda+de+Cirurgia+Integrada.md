# Ajuste na Agenda de Cirurgia Integrada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Informações Cirúrgicas |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Cuidados com o Paciente/Centro Cirúrgico/Registro de Informações Cirúrgicas", ao vincular um agendamento de cirurgia para um paciente, e processar o faturamento desta cirurgia em "Registro de Informações Cirúrgicas/Processos/Enviar dados para o faturamento", o status da cirurgia permanecia inalterado, quando deveria ser alterado para "Cirurgia Concluída". |
| **Solução:** | Foram realizados ajustes no formulário para que o sistema altere o status da cirurgia após o faturamento. |
