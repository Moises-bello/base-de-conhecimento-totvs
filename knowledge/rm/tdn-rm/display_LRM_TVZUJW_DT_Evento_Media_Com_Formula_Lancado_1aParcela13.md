# EVENTO DE MEDIA COM FÓRMULA ESTÁ SENDO LANÇADO NA 1a PARCELA DE 13o

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *13o. Salário* |
| **Situação/Requisito:** | Quando o funcionário é comissionista, e o evento de media de 13º informado no sindicato é calculado por fórmula, ao lançar a primeira parcela de 13º salário, está lançando também o evento de media. |
| **Solução/Implementação:** | Ajuste no cálculo da 1ª parcela de 13º salário para não lançar eventos de media informado no sindicato, quando são calculados por fórmula.. |
| **Chamados relacionados:** | *TVZUJW* |
