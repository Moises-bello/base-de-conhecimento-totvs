## **VISÃO GERAL**

A página de "**Login**" permite que um usuário acesse o Portal do Prestador.

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Para que seja possível efetuar o login no Portal, o usuário deve informar os dados de acesso (CPF e Senha). Feito isto, o sistema irá validar os dados informados e poderá seguir com o processo de login para o Portal ou interromper a ação e notificar o usuário.

Caso seja de interesse do usuário, este poderá marcar a opção "Lembrar usuário", desta forma, ao acessar futuramente o Portal do Prestador, o sistema irá carregar automaticamente o CPF do mesmo.

**Importante:**

Por critérios de segurança, os dados de acesso somente estarão disponíveis enquanto a sessão atual do usuário estiver ativa, ou seja, todos os dados serão redefinidos nos seguintes casos:

* Fechar a tab atual no navegador;
* Abrir uma nova tab no navegador;
* Fechar por completo a janela do navegador.

**Esqueci a senha**

A página "Esqueceu a Senha" permite que usuário redefina uma nova senha de acesso ao Portal do Prestador caso o mesmo a tenha esquecido ou por algum motivo não consiga fazer o login.

Depois de preenchidos os dados e concluir o processo, será enviado um e-mail de recuperação de senha para o endereço de e-mail informado com link para criar a nova senha.
