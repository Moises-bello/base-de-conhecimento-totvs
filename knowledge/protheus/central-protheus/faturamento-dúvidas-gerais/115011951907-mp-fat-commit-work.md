**Ocorrência**  
   
 Error.log: commit work - Error : -256 (S1000) (RC=-1) - [Informix][Informix ODBC Driver][Informix]Transaction not available. ( From tInformixConnection::Commit )  
   
 **Causa**  
   
 A inconsistência ocorre no momento de migrar a versão 11.80 para 12.  
   
 **Ambiente**  
   
 Microsiga Protheus - a partir da versão 12.  
   
 **Solução**

Atualizar o DBACCESS com a versão do Portal do Cliente.

Maiores informações e acesso do pacote DBACCESS citado em questão, acesse o link do tdn: <http://tdn.totvs.com/pages/viewpage.action?pageId=286500930>
