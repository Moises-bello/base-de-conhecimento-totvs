**Dúvida**INSS de 13º não é apresentado no cálculo do intermitente.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O INSS do 13º Salário é calculado anualmente, isso significa que todo calculo para intermitente, o sistema verifica se existe base e pagamento de INSS de 13º no ano para fazer o calculo do mês atual.

Ao verificar que no ano o funcionário já atingiu o teto desconto de INSS, o sistema não gerará mais a verba de desconto de INSS de 13º, somente irá gerar a Base para conferência e validação dos valores.
