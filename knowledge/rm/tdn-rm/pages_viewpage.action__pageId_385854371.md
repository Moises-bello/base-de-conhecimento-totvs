# SUBSTITUIR RESPONSÁVEL FINANCEIRO NA MATRÍCULA DO PROCESSO SELETIVO RM

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Matrícula do Processo Seletivo RM |
| **Situação/Requisito:** | Ao fazer a matrícula de um candidato no processo seletivo RM, marcando a opção para aproveitar o RA e também a opção para utilizar o candidato como responsável financeiro, o responsável financeiro do aluno não é alterado, permanecendo o pai do aluno, como estava antes. |
| **Solução/Implementação:** | Foi criada uma opção na matrícula do processo seletivo RM para substituir o responsável financeiro quando utilizar RA existente. |
