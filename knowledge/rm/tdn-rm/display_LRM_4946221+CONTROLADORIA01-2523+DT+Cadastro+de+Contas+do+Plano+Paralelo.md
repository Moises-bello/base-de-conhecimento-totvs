# Cadastro de Contas do Plano Paralelo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro de Contas do Plano Paralelo |
| **Situação/Requisito:** | Após implementar o campo da Natureza da conta para envio do SPED no plano referencial para atender o bloco K, este campo passou a ser obrigatório também quando usamos somente para o registro I051. Exemplos: O cliente deseja associar uma conta, ao salvar é apresentado uma mensagem falando que este campo é obrigatório. Favor retirar a obrigatoriedade quando o tipo do plano referencial for para o I051. |
| **Solução/Implementação:** | Ajuste para que o campo Natureza do SPED "NATSPED" seja obrigatório apenas quando o plano de contas paralelo for do tipo "Consolidação de Saldos". |
