![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19143194811543)Tempo aproximado para leitura: **02:00 min** **Dúvida**Como corrigir a mensagem **"Importador do Purchase Order é diferente do importador do Ato Concessório"**?  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19143204027927)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control -  A partir da versão 12.1.33.  
  
**Solução**Para que a mensagem não seja apresentada, o código informado no campo "**W2\_IMPORT - Importador"** deve ter o mesmo conteúdo do "**ED0\_IMPORT - Beneficiária**". Caso estejam diferentes, será apresentada a mensagem impedindo o prosseguimento de inclusão do Pedido de Licença de Importação **P.L.I.**
