**Ocorrência**

Ao consumir serviço do Protheus, os metodos do webservice retorna o erro “***PRTCHKUSER : WebService invalido para este login***”

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – ADVPL – A partir da versão 11.80  
  
**Causa**Serviço padrão indisponível   
  
**Solução**Esse serviço é padrão do protheus é necessário validar se o Serviço padrão "***USERPORTAL**"* está gerando o mesmo erro.
