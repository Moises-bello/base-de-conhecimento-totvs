A interface principal do editor de Layouts do gerador de saídas é baseada em duas abas com a árvore de registros e de contextos. Uma parte principal onde são configurados os componentes do Layout (Arquivos, Registros e Contextos) e uma barra de ferramentas com as principais operações.

![](/download/attachments/319787259/principal.png?version=1&modificationDate=1512921803000&api=v2)

1Barra de Ferramentas

A barra de ferramentas possuiu os botões para adicionar ou remover Registros, Arquivos e Contextos no Layout. Além de outras ações como Executar, Gerar a documentação e gerar o código fonte do Layout para validação. Para mais informações consulte [Barra de Ferramentas](/display/LRM/Manual+-+Barra+de+Ferramentas).

2Estrutra do Layout

Na árvore de estrutura são exibidos todos os componentes do Layout, você pode alternar entre a visão de Layout, onde são exibidos as componentes do Layout, Arquivos e Registros ou na aba Contextos onde são configurados e exibidos os dados dos contextos de origem do Layout. Para mais informações consulte [Layout](/display/LRM/Manual+-+Layout).

3Configuração do Layout

Nesta área serão abertas as abas para configuração dos vários componentes do Layout. Cada componente tem uma configuração específca de acordo com o seu tipo. Para alterar um componente você deve clicar na árvore de Layout para editar as propriedades do Layout, Arquivo, Registro ou Contexto. Para mais informações consulte [Layout](/display/LRM/Manual+-+Layout).
