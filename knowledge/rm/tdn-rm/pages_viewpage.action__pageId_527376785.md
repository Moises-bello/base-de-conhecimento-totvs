## **02. SITUAÇÃO/REQUISITO**

Problemas diversos no processo de alocação manual de salas para turma disciplina gerencial:  
-Ao alocar a turma/disciplina gerencial ou os horários da turma/disciplina gerencial, as informações de campus/polo, prédio, bloco e sala não estão sendo levadas para as gerenciadas.  
-Ao alocar um horário de uma turma/disciplina gerencial, que possui mais de um horário, são alocados todos os horários das gerenciadas.  
-Ao desalocar os horários da turma/disciplina gerencial, a alteração não é refletida para as gerenciadas.

## **03. SOLUÇÃO**

Ajustes no processo de alocação manual de sala para que as alocações/desalocações de horários em turma/disciplina gerencial seja refletidas corretamente para todas as gerenciadas.
