Permite a gestão dos periódicos da biblioteca, oferece serviço de visualização das assinaturas vencidas e com vencimento próximo proporcionando uma melhor administração dos periódicos, além disso, disponibiliza um sistema de recebimento de periódicos, efetuando cadastro automático do exemplar recebido e montagem da fila de leitura de forma automática.

**Vencimento da Assinatura:** Esta opção é utilizada para listar todas as assinaturas ativas que falta, no máximo, certo número de exemplares para terminar. Este número de exemplares deverá ser informado pelo usuário.

**Exemplares a Receber:** Esta opção é utilizada para utilizada para listar todos os exemplares a receber em um determinado período. Utilizando a opção de "exemplares a receber", será disponibilizado o processo "receber exemplar", onde o sistema irá criar um exemplar com base no exemplar da assinatura, associando-o à publicação, além de gerar o controle de leitura, atualizar o status do exemplar e a fila de reservas.

**Assinaturas Vencidas:** Esta opção é utilizada para para listar todas as assinaturas vencidas em um determinado período definido.

**Alterar periódicos recebidos:** Este processo permite alterar a situação de um periódico recebido, ou seja, é possível retornar para o status "a receber" ou "cancelado", quando a alteração é feita, o sistema busca os exemplares gerados por este periódico e irá cancelar o exemplar, ou seja, o sistema irá adicionar as informações de baixa no exemplar inviabilizando sua movimentação.

**Atenção**

* Somente serão exibidos os periódicos com assinaturas ativas.
* Todos os tipos de resultados da tela de controle de periódicos poderão ser exportados para o Excel.
