# APROVEITAR DADOS DO USUÁRIO JÁ CADASTRADO NO NOVO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Aproveitar dados de usuário já cadastrado no novo portal |
| **Situação/Requisito:** | Como não era necessário logar no sistema, se alguém soubesse os dados de identificação do usuário já cadastrado, essa pessoa poderia acessar o portal de inscrição trocando a senha do usuário. |
| **Solução/Implementação:** | Downgrade da implementação para só deixar o usuário aproveitar os dados de inscrição se ele efetuar o login. |
