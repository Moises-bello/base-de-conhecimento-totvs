**Dúvida**Como criar uma base nova já com o Dicionário de Dados no Banco de Dados  
   
 **Ambiente**Protheus - AppServer - A partir da versão 12.1.023  
   
**Solução**A partir do Binário e LIB do quadro abaixo, o Dicionário de Dados do Protheus pode ser inicializado diretamente no Banco de Dados, ao invés de ser utilizado na pasta System. Essa alteração visa proporcionar maior agilidade na leitura do dicionário, centralização dos dados no SGBD, otimização nas buscas de informações, entre outras. Para que seu dicionário de dados seja inicializado no banco de dados, seguem abaixo as características, requisitos e procedimentos.

| --- |
