# Exibição dos documentos na rematrícula - Novo Portal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Portal do Aluno |
| **Função:** | Rematrícula |
| **Situação/Requisito:** | Cliente informa que, ao realizar a rematrícula (Educação Básica), são exibidos os documentos referentes ao período letivo vigente e não os documentos do período letivo que ele está realizando a rematrícula. |
| **Solução/Implementação:** | Foi realizado ajuste para tratar corretamente a exibição dos documentos de acordo com o período letivo selecionado na matrícula. |
