**Dúvida**  
MEU RH - É possível o Gestor visualizar o anexo de uma solicitação de abono na rotina de aprovação?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - MEU RH - todas as versões  
  
**Solução**  
Foram implementadas melhorias na rotina de aprovações, para que seja possível para o gestor visualizar o arquivo de imagem das solicitações de abono que tiverem atestado anexado.  
Dessa forma, o gestor poderá ter mais dados para poder avaliar o pedido.  
  
O arquivo de imagem poderá ser baixado por meio das opções abaixo:  
Na tela inicial da rotina de aprovações: ![](https://tdn.totvs.com/download/thumbnails/646237990/image2021-10-26_17-0-35.png?version=1&modificationDate=1635278597797&api=v2)  
No detalhe de uma solicitação de abono com anexo: ![](https://tdn.totvs.com/download/thumbnails/646237990/image2021-10-26_17-2-20.png?version=1&modificationDate=1635278597757&api=v2)
