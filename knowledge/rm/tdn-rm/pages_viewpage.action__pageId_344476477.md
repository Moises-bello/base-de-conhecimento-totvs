# MATRÍCULA EM DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Validação de correquisito durante a matrícula online. |
| **Situação/Requisito:** | Quando o aluno já havia cursado uma disciplina de correquisito e reprovado na mesma, mesmo que fizesse uma nova matrícula em outro período letivo e estivesse com esta disciplina em curso, ela não era validada como um correquisto válido e impedia a matrícula na disciplina relacionada. |
| **Solução/Implementação:** | Ajuste na validação das disciplinas de correquisito que estejam em curso, permitindo que a disciplina relacionada seja matriculada, quando o aluno está matriculado na disciplina de correquisito pela segunda vez. |
