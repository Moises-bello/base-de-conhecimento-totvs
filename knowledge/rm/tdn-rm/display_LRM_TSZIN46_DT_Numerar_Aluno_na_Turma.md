# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Matrícula* |
| **Função:** | *Numeração do aluno na Turma* |
| **Situação/Requisito:** | Em algumas situações, quando os registros de matricula na disciplina do aluno não continham o número dos alunos na turma, o processo de atribuir o próximo número sequencial a um novo aluno da turma provocava modificações indevidas na numeração de outros alunos. |
| **Solução/Implementação:** | *O processo foi corrigido de modo a considerar como referência a numeração dos alunos na turma mantida no registros de matrícula no período letivo, evitando-se a ocorrência de situações em que a numeração pudesse ser modificada indevidamente.* |
