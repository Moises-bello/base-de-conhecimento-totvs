![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31349169483543) Tempo aproximado para leitura: **00:02:30 min** **Dúvida**Como conferir cálculo multa pedido contrato de experiência ID 0177 mensalista?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**

O sistema faz o calculo pedido dispensa contrato de experiência ID 0177 mensalista conforme quantidade dias para complementar o período de experiência, sendo que a contagem é continua e assim é considerado dia 31. Com a quantidade de dias para complementar o período de experiência o ID 0177 apresenta 50% do valor.

Demissão: 26/03/2025

Vencimento primeira experiência: 14/04/2025

Do dia 27/03/2025 (após dia demissão) até 14/04/2025 constam 19 dias.

2.000,00 \ 30 \* 19 = 1266,67 \* 50% = 633,33 Valor ID 0177.
