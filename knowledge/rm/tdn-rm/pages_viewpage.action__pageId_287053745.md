# Ajuste no lançamento de honorários sem adicional de DHE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de contas |
| **Situação:** | Ao lançar um honorário com a opção "Sem adicional de DHE" o sistema lançava o item com o valor nulo. |
| **Solução:** | Realizado ajuste para lançar o honorário com valor correto quando a opção "Sem adicional de DHE" estiver marcada. |
