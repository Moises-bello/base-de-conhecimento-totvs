**Dúvida**  
No cálculo de rescisão para que funcionários que não recebem verbas rescisórias, como realizar o cadastro desta rescisão?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para realizar o calculo da rescisão, realize os seguintes passos:  
  
1. Acesse: **Configurações | Parametrizador | Rescisão | Cálculo.**  
  
**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415445217687)**  
  
2. Para que o sistema não calcule verbas rescisórias para funcionários, desabilite os campos destacados na imagem abaixo.  
  
![Screenshot_1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360089255253)  
  
3. Após desabilitar os campos acima, deverá acessar **Administração de pessoal | Funcionários | Selecionar o estagiário | Rescisão** e informa os dados da rescisão e calcular normalmente.

**Importante:** O campo  **Tipo de Demissão** deve ser preenchido de acordo com a legislação vigente aplicável ao estagiário. Em caso de dúvidas quanto ao correto preenchimento, recomenda-se consultar o setor jurídico da empresa para obter mais informações.

O sistema não irá lançar verbas rescisórias para os funcionários cadastrados com os tipos **D - Diretor, C - Conselheiro, A - Autônomo e T - Estagiário**, seguindo a parametrização informada no Parametrizador.
