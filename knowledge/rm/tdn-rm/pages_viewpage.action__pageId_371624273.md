# Falta de botão de nova inscrição na central do candidato

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Processo Seletivo |
| **Função:** | Central do Candidato |
| **Situação/Requisito:** | Não era possível incluir uma nova inscrição no ensino básico, a partir da central do candidato, para um dependente existente, no novo portal do processo seletivo. |
| **Solução/Implementação:** | Foi realizado ajuste para permitir que o responsável pela inscrição consiga incluir nova inscrição para um dependente existente a partir da central do candidato. |
