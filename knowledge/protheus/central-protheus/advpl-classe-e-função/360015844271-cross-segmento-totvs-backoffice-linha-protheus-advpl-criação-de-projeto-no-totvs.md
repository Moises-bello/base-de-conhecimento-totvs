Dúvida**Como criar um projeto e utilizar IDE (*Integrated Development Environment*) Totvs Developer Studio?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – TOTVS Developer Studio – A partir da versão 11.80  
  
**Solução**PRÉ-REQUISITOS**:**Instalar o TDS, saiba mais em: [Cross Segmento - TOTVS Backoffice Linha Protheus - ADVPL - Como instalar o totvs developer studio](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360018541431)

1. Crie um novo projeto clique em Arquivo > Novo > Projeto:  
   ![](http://tdn.totvs.com/download/attachments/274333264/image2017-5-19%2011%3A20%3A54.png?version=1&modificationDate=1495203984000&api=v2)
2. Selecione a opção "Projeto TOTVS" e clique em avançar:  
   ![](http://tdn.totvs.com/download/attachments/274333264/image2017-5-19%2011%3A34%3A43.png?version=1&modificationDate=1495204642000&api=v2)
3. Informe um nome para o Projeto:  
   ![](http://tdn.totvs.com/download/attachments/274333264/image2017-5-19%2011%3A35%3A43.png?version=1&modificationDate=1495204702000&api=v2)
