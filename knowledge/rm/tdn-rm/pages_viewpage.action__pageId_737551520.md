A **Visão das Registradoras**, está disponível no anexo e no menu lateral do cadastro do Empreendimento .

Ao acessar esta aba, o sistema apresenta as seguintes informações que foram integradas: Tipo Registradora, Código do Empreendimento, Data de Registro, Código de Integração, Usuário Criação, Data Criação, Usuário Alteração, Data Alteração.
