**Dúvida**Como incluir verbas na base de cálculo da pensão alimentícia no Protheus?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da Versão 11.80  
  
**Solução**Para que uma verba faça base de cálculo para a pensão alimentícia, esta verba deve estar com SIM no campo Pensão Alim., este campo fica na aba Incidências do cadastro da Verba, para acessar a rotina **Verbas**, no menu acesse pelo caminho **>Atualizações >Definições cálculos >Verbas**:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360071857754)

Uma vez as verbas parametrizadas com SIM no campo Pensão Alim., caso queira que todas elas montem a base do cálculo da pensão (desde que existam no cálculo da folha do funcionário), não é necessário informar elas no campo Verb. Bd. Calc no cadastro de beneficiários, mas caso queira que apenas verbas específicas sejam consideradas na base da pensão, o campo deve ser preenchido com as verbas.

Para isso, acesse a rotina **Beneficiários** pelo caminho **>Atualização >Funcionários >Beneficiários**, clique em Alterar se já tiver dados de beneficiário ou incluir para inclusão;

No campo **Verb. Bs. Calc**, dê um enter, o sistema irá abrir a tela abaixo para seleção as verbas que deseja incluir na base de cálculo da pensão:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/13263328636823)

**Observação:** As verbas com legenda verde são verbas de provento com SIM no campo Pensão, as verbas com legenda vermelha são verbas de desconto com SIM no campo pensão, e as verbas com legenda cinza são verbas com Não no campo pensão.
