![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23445808131351) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como realizar o cadastro de advertências para os funcionários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - **12.1** e superiores.  
  
**Solução**Para realizar o cadastro de uma advertência para o funcionário, é necessário que em seu ambiente já tenham sido cadastrados os '**Motivos de Advertências**' e as '**Punições**'.  
  
Para cadastrar os '**Motivos de Advertências**', acesse: **Gestão de Pessoas** >> **Gestão Organizacional** >> **Advertências** >> '**Motivos de Advertências**':  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23445762761111)  
  
Os motivos poderão ser cadastrados de acordo com a necessidade da organização. Abaixo alguns exemplos:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23445808135831)  
  
Para cadastrar as '**Punições**', acesse: **Gestão de Pessoas** >> **Gestão Organizacional** >> **Advertências** >> '**Punições**':  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23498366694935)  
  
As punições poderão ser cadastradas de acordo com a necessidade da organização. Abaixo encaminho alguns exemplos:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23498366711191)  
  
Após cadastrar as informações de base, bastará acessar **Acompanhamento** >> **Funcionários** e selecionar o funcionário desejado >> **Anexos** >> **Gestão de Pessoas** >> **Advertências**:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23498366719127)  
  
E inclua para o funcionário a advertência, conforme desejado:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23498414638231)
