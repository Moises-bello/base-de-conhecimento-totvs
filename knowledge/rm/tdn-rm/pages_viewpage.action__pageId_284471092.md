# GERAÇÃO DE CERTIFICADOS/DIPLOMAS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Atividade Acadêmica - Geração de certificados/diplomas |
| **Situação/Requisito:** | No processo “Geração de certificado/diploma”, o status estava ficando incorretamente como “Pendente” quando no cadastro do aluno as informações do Enade estavam “Não compareceu” no primeiro período e “Dispensado” no período letivo posterior. |
| **Solução/Implementação:** | Otimização no processo de “Geração de certificado/diploma”, para tratar corretamente o status Apto ou Pendente ao verificar o Enade do aluno Dispensado da prova. |
