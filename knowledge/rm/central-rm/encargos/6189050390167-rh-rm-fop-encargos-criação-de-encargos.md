![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30557163989015) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como incluir novos Encargos para realizar contabilização?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para cadastrar um novo código ativo para geração de encargos, siga os passos abaixo:  
  
1. Acesse a aba **Encargos | Cadastros | Encargos**;  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10267656429591)  
  
2. Será exibida a tela para cadastro do novo código do Encargo, que deverá ser preenchida seguindo a necessidade da empresa

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10267658842263)
