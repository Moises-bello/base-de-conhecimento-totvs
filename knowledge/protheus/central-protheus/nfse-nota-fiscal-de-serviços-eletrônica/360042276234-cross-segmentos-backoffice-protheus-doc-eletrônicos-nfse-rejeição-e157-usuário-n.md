**Ocorrência**Ao realizar a transmissão de uma NFSE para o Município de Duque de Caxias/RJ ocorre a rejeição "**E157 - Usuário não está autorizado a utilizar esse serviço para esse contribuinte."**  
  
**Ambiente**  
Cross Segmentos - TOTVS Backoffice Protheus - TOTVS Doc. Eletrônicos - Todas as versões.  
  
**Causa**Após a alteração de Layout/Provedor se faz necessário uma nova liberação da prefeitura para transmissões Web Service.  
  
**Solução**Entrar em contato com a prefeitura e solicitar a liberação para transmissão via Web Service no novo sistema.  
  
*Obs.: Caso já esteja habilitado, verificar se o CNPJ e Inscrição Municipal contidos na nota estão de acordo com o cadastro da empresa habilitada.*
