Produto

**RMLabore**

**Processo:** **Geração do arquivo de Seguro Desemprego**

Versão: 11.8X ou superior

1. Acesse o menu Rescisão -> Seguro desemprego

Clique para visualizar a imagem.

2. Informe um perfil de parâmetros e clique em avançar;

Clique para visualizar a imagem.

3. Informe os dados para geração como a competência em que os funcionários foram demitidos, o código de quebra e seleção de funcionários, após informe o local para geração do arquivo.

Clique para visualizar a imagem.

**Obs.** É importante que o usuário de rede possua acesso a pasta selecionada no campo "Localização do(s) arquivo(s)":

4. Selecione a coligada que deseja gerar o arquivo e clique no botão "Adicionar parâmetros à coligada".

Clique para visualizar a imagem.

5. Marque o parâmetro "Usar Parâmetros específicos" e verifique a quebra de seção, e caso queira informar a chapa do funcionário para geração do arquivo, clique em "Seleção de funcionários", após preencher as informações clique em ok, e depois em executar.

Clique para visualizar a imagem.

**Observação:** As fórmulas para cálculo de horas semanais ou as fórmulas para remuneração (Último, Penúltimo, Antepenúltimo) são opcionais caso queira realizar o cálculo de forma diferente da que o sistema realiza, ficando a criação das mesmas sob responsabilidade do cliente.

6. Após a geração, basta importar o arquivo no site: <http://granulito.mte.gov.br/sdweb/empregadorweb/index.jsf>   
 Obs. Dúvidas referentes aos menus do site, gentileza entrar em contato com o MTE.\_GoBack
