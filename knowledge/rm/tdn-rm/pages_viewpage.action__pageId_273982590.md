# Relatório do book - Reports

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Relatório do Reports. |
| **Situação/Requisito:** | O saldo anterior do relatório estava considerando todas as contas caixas independente do filtro de lançamentos que foi informado. Ex: Foi informado um filtro de lançamentos onde existiam somente 1 conta caixa, mas o saldo anterior apresentado não era somente as contas caixas dos lançamentos. |
| **Solução/Implementação:** | Foi feito um ajuste no relatório no saldo anterior, feito ajuste inserindo uma quebra por conta caixa no relatório e o nome do mesmo também foi alterado. Com os ajustes o saldo anterior apresentado passou a ficar correto. |
