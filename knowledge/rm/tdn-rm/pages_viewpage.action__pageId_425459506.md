\*11.50.0 - Matrícula em regime de dependência \[Ensino Básico\]\*
 
Implementado no TOTVS Educacional, para o contexto básico, a matrícula em regime de dependência. [Veja mais...|Matrícula em regime de dependência]   \*11.50.0 - Matrícula no período letivo\*
 
Implementado no TOTVS Educacional, o campo para a informação do Coeficiente de Rendimento do aluno no período letivo. Este campo, se encontra na tela de [matrícula no período letivo|Matrícula no Período Letivo] e é preenchido APENAS ATRAVÉS DE FORMULA, pela função GravaCampoPL('CR','VALOR')   \*11.50.0 - Matrícula em cursos\*   Disponibilizado no Aplicativo agora, a possibilidade de acessar direto a tela de Curso/Habilitações. Até a versão anterior, Curso/Habilitações era somente anexo do cadastro de alunos, agora é possível acessá-lo através do Matrículas e Avaliações -> Matrículas em Curso.   \*11.50.0 - Importação de Histórico \[Ensino Básico\]\*   - Implementado no contexto do ensino básico, a opção de ser importar disciplinas com status final de reprovado. Para esta opção foi criado na tela de parâmetros a opção "Importar disciplinas reprovadas para o histórico".   - Implementado na rotina de Log do Aluno a possibilidade de consulta do Log de Importação de Histórico para o contexto de ensino básico. Para que esta opção esteja disponível o parâmetro de importar histórico de disciplinas reprovadas deve estar marcado.   \*11.50.0 - Diário de Classe - Portal\*   Implementado no portal o Diário de Classe, que consiste em um agrupador de várias funções do professor, a fim de agrupar atividades, tais como: - Digitação de notas; - Minhas Turmas; - Frequência diária; - Cadastro de Avaliações; - Plano de aula.   \*11.50.0 - Disciplinas extras de um curso\*   Criado o conceito de Disciplinas extras de um curso, este possibilitará que a instituição tenha na analise curricular todas as disciplinas que o aluno cursou na instituição que não fazem parte do curso dele, para um possível aproveitamento de estudos ou apenas para conhecimento. [Mais...|Disciplinas Extras]   \*11.50.0 - Assistente para cadastro de Equivalência de alunos\*
Implementado no Gestão Educacional um assistente para permitir o [cadastro de equivalências para alunos|Assitente para Cadastro de Equivalência de Alunos], isso possibilita que a IES tenha como inserir uma equivalência somente para um aluno ou para um grupo   \*11.50.0 - Aproveitamento de Estudos - Exclusivo para esta habilitação\*   Implementado o parâmetro [Exclusivo para esta habilitação|Equivalência de Disciplinas]. O aproveitamento de estudos será válido somente para a habilitação na qual o aluno está matriculado.   \*11.50.0 - Aproveitamento de Estudos - Disciplinas não pertencentes a Matriz Curricular\*   Implementado o parâmetro [Informar disciplinas que não pertencem à Matriz Curricular no Aproveitamento de Estudos|Aproveitamento de Estudos]. É possível informar disciplinas que não pertencem à Matriz Curricular do aluno no Aproveitamento de Estudos   \*11.50.0 - Equivalência - Ordem de verificação\*   Implementado a [Ordem de Verificação da Equivalência|Equivalência de Disciplinas] para o aluno.   \*11.50.0 - Ocorrência - Seleção de Alunos\*   Implementado a possibilidade de selecionar alunos no [Assistente para cadastro de ocorrências para os alunos.|Assistente para cadastro de ocorrências para os alunos.]    \*11.50.0 - Campos Complementares\*
 
Implementado o Cadastro de [Campos complementares|Campos Complementares - EDU], para as telas de:  - Cursos/Habilitações do aluno;  - Matrizes Curriculares;  - Matricula no período letivo.
 
\*11.50.0 - Cópia de Matriz Curricular\*

No cadastro de situação de matrícula foi disponibilizado um parâmetro para que, ao assumir tal status, a disciplina não seja cobrada apenas nas parcelas posteriores àquela data, ou seja, o valor anteriormente gerado não será devolvido ao aluno com desconto nas outras disciplinas. \*11.50.0 - Envio de Emails\*
 
Implementado o processo de [Envio de e-mails|Envio de E-mail - EDU], a opção de filial, para que seja possível enviar um e-mail 'em nome' da filial.
 
\*11.50.0 - Solicitação - Envio de Emails\*
 
Implementado a possibilidade de enviar email ao aluno no momento da abertura da solicitação.
 
\*11.50.0 - Controle de vagas\*
 
Otimizado o cadastro de turma e turma/disciplina para validar o preenchimento do campo de numero máximo de alunos. Pois o controle de vagas precisará desta informação para ser feito. A validação é feita com base na informação se o controle é feito por Turma ou por Turma disciplina.
 
\*11.50.0 - Serviços para personalização - Plano de Pagamento\*
 
O cadastro de [serviços para personalização|Personalização de Plano de Pagamento] é um anexo do [plano de pagamento|Plano de Pagamento] onde é listado os serviços associados às parcelas do plano, onde o usuário define se o serviço é obrigatório ou não durante a personalização do plano de pagamento.
 
\*11.50.0 - Consulta de boletos\*
 
Implementado o assistente para alterar o vencimento dos boletos. A funcionalidade é simples, seleciona-se os boletos que se deseja alterar o vencimento e aciona o assistente. Depois de informado a nova data de vencimento. Após a utilização deste, o lançamento(s) em questão será alterado(s) para a(s) nova(s) data(s) de vencimento informada(s). Só lembrando que na tela de parcelas, a data de vencimento não sofrerá alterações, apenas será alterado o Lançamento/Boleto.

\*11.50.0 - Personalização de Plano de Pagamento\*
 
Otimizado no sistema a opção de manter o  " botão "Personalizar" habilitado mesmo quando o contrato já tiver um plano de pagamento associado. Porém, quando já tiver sido gerado um lançamento para alguma parcela do contrato, o botão não ficará mais disponível. Ao personalizar um plano de pagamento para um contrato que já tem um plano associado, as parcelas do contrato serão regeradas de acordo com a nova personalização, portanto, qualquer alteração feita diretamente na parcela não será mantida. Otimizado também a opção de manter o  " botão "Personalizar" habilitado mesmo quando o contrato já tiver um plano de pagamento associado. Porém, quando já tiver sido gerado um lançamento para alguma parcela do contrato, o botão não ficará mais disponível. Ao personalizar um plano de pagamento para um contrato que já tem um plano associado, as parcelas do contrato serão regeradas de acordo com a nova personalização, portanto, qualquer alteração feita diretamente na parcela não será mantida. E otimizado no cadastro de plano de pagamento a opção de um anexo de Serviços para personalização. Neste anexo serão listados os serviços associados às parcelas do plano, para que o usuário possa configurar quais deles são obrigatórios na personalização. E onde também é possível incluir parcelas novas na personalização e sem a obrigatoriedade de informar a data de Vencimento para todos os serviços.
 
\*11.50.0 - Processo de inclusão de Bolsas\*
 
Otimizado no sistema , em processo de inclusão de bolsa a permissão de selecionar  múltiplas bolsas para serviços diferentes , não sendo mais preciso efetuar o processo toda vez que for efetuar a inclusão para um determinado serviço. Em um único processo agora é possível incluir uma bolsa para N Serviços do aluno

\*11.50.0 - Nota Fiscal Eletrônica\*
 
Implementado a geração de movimento por [competência|Edu.notaFiscalEletronica].
 
\*11.50.0 - Limite de crédito para verificar Inadimplência\*
 
Criado um parâmetro para informar o valor mínimo para considerar o aluno inadimplente. Se este parâmetro for preenchido, o bloqueio da matrícula será feito somente se o valor devido for maior que o mínimo informado.
