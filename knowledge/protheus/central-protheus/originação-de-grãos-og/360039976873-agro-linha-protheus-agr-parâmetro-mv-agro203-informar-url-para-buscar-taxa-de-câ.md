**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20493779734551)**Tempo aproximado para leitura: **00:00:35 min****Dúvida**Para que serve o parâmetro **MV\_AGRO203**?  
  
 **Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**O parâmetro **MV\_AGRO203** - **Informar URL para Buscar Taxa de Câmbio PTAX das moedas** é do tipo caractere e está localizado na rotina **OGX300** - **Integração com a M2M para atualização de Moeda e Índices de Mercado**.   
Ele é utilizado para atualizar as taxas de câmbio.
