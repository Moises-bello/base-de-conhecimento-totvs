![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: 00:01:00 min **Dúvida**Como executar um aplicativo no Android a partir do AdvPL?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Fiscal - Todas as versões  
  
**Solução**A linguagem AdvPL não é homologada para uso em Smartphones.  
  
Desenvolvimentos baseados em **Angular** e **TypeScript** utilize **PO-UI**.  
Portinari é um projeto open- source onde a Totvs é parceira, essas informações podem ser esclarecidas no <https://po-ui.io/>  
Para dúvidas referente a plataforma de Framework Portinari, favor consultar o Dev Fórum: [https://devforum.totvs.com.br](https://devforum.totvs.com.br/)
