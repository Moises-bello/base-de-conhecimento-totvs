# CADASTRO PROPOSTA DE PROJETO DE PESQUISA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Cadastro de proposta de projeto de pesquisa* |
| **Situação/Requisito:** | *O fluxo não permite o envio de uma solicitação de projeto de pesquisa em que as despesas sejam maiores que as receitas.*  *O fluxo não permite o envio de uma solicitação de projeto de pesquisa em que os valores das parcerias sejam maior que o valor capital, por projeto, cadastrado no edital.*  *As informações de resumo de valores de itens de planejamento devem estar vinculadas ao total de despesas e não ao total de receitas.* |
| **Solução/Implementação:** | *Alteração para exibição dos resumos de valores de itens de planejamento de almoxarifado na aba de despesas e não nas receitas, assim como a alteração de seus cálculos totais.*  *Remoção das validações que restringem as solicitações de projeto onde as despesas são maiores que as receitas.*  *Desvinculação dos valores de itens de parcerias do valor capital por projeto cadastrado no edital, assim como, sua restrição na solicitação de projetos de pesquisa.* |
