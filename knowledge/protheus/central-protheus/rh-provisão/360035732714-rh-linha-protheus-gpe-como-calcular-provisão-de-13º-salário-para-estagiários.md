**Dúvida**Como Calcular Provisão de 13º Salário para Estagiários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**

Criado o Mnemônico **P\_LPROVEST** para definir se o calculo de provisão de 13 salário será realizado para estagiários (Categoria E ou G). 

Para habilitar o Mnemônico, realize os seguintes passos:  
1. Acesse: Atualizações / Definições de Cálculo / Mnemônicos;  
2. Localize o mnemônico P\_LPROVEST e clique na opção Alterar;  
3. Altere o conteúdo do mnemônico para .T. conforme abaixo:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047529013)

4. Acesse: Miscelânea / Provisões de Férias/13º Salário / Outras Ações / Cálculo, Preencha os parâmetros e calcule as Provisões de Férias e 13º Salário para funcionários Estagiários.
