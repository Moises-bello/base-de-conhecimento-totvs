## **CONTEÚDO**

1. **Visão Geral**
2. **Passo a passo**

## **01. VISÃO GERAL**

       A opção "Salvar os parâmetros da geração" foi criada para que o usuário não tenha o retrabalho de informar os parâmetros de um layout toda vez em que for gerado, sendo válida para salvar para qualquer tipo de parâmetro (campos decimal, texto, data e etc).

## **02. PASSO A PASSO**

**01.**A opção "Salvar os parâmetros da geração" está localizada na tela de "Parâmetros" de um layout no momento de sua geração.

falseObservação:

A opção vem selecionada por default no sistema.

**02.**Ao gerar o layout com a opção marcada, o valor passado como parâmetro será salvo para as próximas gerações. Os dados do layout são salvos na tabela **GLAYOUTPARAMS**.

falseObservação:

 O sistema sempre salva o ultimo valor passado pelo usuário na geração.

**03.**Quando aberto novamente o layout para geração, o parâmetro já estará preenchido com o valor passado anteriormente pelo usuário.

false
