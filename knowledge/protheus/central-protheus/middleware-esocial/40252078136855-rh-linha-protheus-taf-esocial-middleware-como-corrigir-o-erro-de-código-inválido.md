**Ocorrência**  
Como corrigir o erro "Não foi possível obter a resposta do TSS. Detalhe: TOTVS Service SOA TSS: Evento: [1] com Código inválido" ao enviar os eventos de Processos Trabalhistas?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Rotinas Comuns - Todas as versões.  
  
**Causa**  
O TSS se encontra desatualizado  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

1. Execute as atualizações conforme a documentação:  
   [RH - Linha Protheus - TAF - ATUALIZAÇÕES - TAF e TSS para clientes MIDDLEWARE](https://centraldeatendimento.totvs.com/hc/pt-br/articles/34539886822295-RH-Linha-Protheus-TAF-ATUALIZA%C3%87%C3%95ES-TAF-e-TSS-para-clientes-MIDDLEWARE)
