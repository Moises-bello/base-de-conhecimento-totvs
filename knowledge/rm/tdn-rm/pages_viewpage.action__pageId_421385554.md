**Relatório de Clico de Transporte:**

O Relatório de Ciclos de Transporte possibilita a impressão de código de barras para os Ciclos de Transporte cadastrados para um projeto.

Este relatório pode ser acessado através do menu Indicadores | Mobilidade | Ciclo de Transporte. Este relatório possibilita ao encarregado fazer o apontamento de um Ciclo de Transporte através da leitura do código de barras com informação do Ciclo.

O usuário acessa o menu Indicadores | Mobilidade | Ciclo de Transporte.

O sistema exibe uma tela para o usuário informar os parâmetros para geração do relatório podendo ser  Smart View ou RM Reports e informar os códigos dos Ciclos para impressão dos códigos de barras.

O relatório é exibido com os códigos de barras correspondentes aos Ciclos selecionados e pode ser impresso.

Campos que serão exibidos neste relatório:

* Código do projeto (no cabeçalho);
* Descrição do ciclo;
* Tipo do Ciclo de Transporte;
* Distância em KM;
* Código e descrição do insumo;
* Código de barras.

O código de barras será formado pelo código do Projeto e o código do Ciclo.
