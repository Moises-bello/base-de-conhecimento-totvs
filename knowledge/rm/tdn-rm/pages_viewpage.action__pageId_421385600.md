**Cadastro de Variáveis**   
    
Nesta opção cadastra-se a tabela de variáveis.  
O cadastro de Variáveis consiste no cálculo da quantidade dos recursos associados a uma determinada composição.  
**Observações:**  
Após o cadastro das variáveis será necessário atribuir um valor as variáveis na janela de edição de composição, para que o cálculo da quantidade dos recursos da composição seja efetuado.  
As variáveis cadastradas ficam visíveis a todos os projetos.  
Pasta Identificação   
   
Código  
Informe um código para a variável. Este campo é alfanumérico.  
**Observações:**  
Uma vez incluída uma variável, não será possível alterar o seu código.  
Não é permitida a inclusão de códigos contendo apenas números, espaços ou caracteres especiais (\*, /, +, -, &, %, ^, ~, #, @, !, ?, etc.), exceto o caracter "\_" (underscore).  
Não é permitida a inclusão de códigos contendo espaços sejam eles no início, meio ou fim do código da variável.  
Não é permitida a inclusão de códigos repetidos, portanto, um código somente refere-se a uma determinada variável.
