# SUGESTÃO DE FÉRIAS (PORTAL)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias (Portal)* |
| **Situação/Requisito:** | Ao selecionar a data de início de férias no portal era permitido selecionar feriados e finais de semana. |
| **Solução/Implementação:** | Foi adicionada uma verificação ao selecionar a data de início das férias para validar se é final de semana ou feriado. Atenção: a validação só ocorre caso a data seja digitada. Devido à limitações técnicas, a validação não ocorre ao utilizar o componente do calendário. |
| **Chamados relacionados:** | TTO448 |
| **Versões/Release:** | *12.1.9* |
