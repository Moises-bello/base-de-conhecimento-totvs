**Dúvida**Existe uma rotina para se cancelar um Pedido de Compras ?

**Ambiente**Protheus – Compras – A partir da versão 12.1.23  
  
**Solução**No módulo de Compras, conforme o seu conceito, não existe uma rotina específica para se cancelar um Pedido de Compras.

Caso um pedido não for mais utilização, as opção existentes são:

* Realizar a exclusão do Pedido através da opção "Excluir" existente na rotina de Pedido de Compras (MATA121) / MATA120)

* Ou utilizar a rotina de Eliminação de Resíduos para que o Pedido não seja mais utilizado. Abaixo artigos sobre esta opção:

[MP - SIGACOM - Qual a Funcionalidade da Eliminação de Resíduo (MATA235)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024673534)

Obs.:

Ambas as opção relatadas não são possuem processo reversão no padrão do sistema caso realizadas.
