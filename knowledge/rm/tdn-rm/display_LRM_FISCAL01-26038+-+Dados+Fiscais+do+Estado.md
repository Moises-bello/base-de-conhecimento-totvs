## **02. SITUAÇÃO/REQUISITO**

Criar um novo anexo global denominado **"Dados Fiscais"**, vinculado ao cadastro de Estados (UF). Esse anexo deve conter um campo booleano (sim/não) com o rótulo:  
**"Gerar dados de diferimento do ICMS na NF-e?"**  
O campo será utilizado para indicar se os campos do grupo ICMS51 devem ser gerados no XML da NF-e, conforme a UF emitente.

## **03. SOLUÇÃO**

Criado anexo conforme requisito.
