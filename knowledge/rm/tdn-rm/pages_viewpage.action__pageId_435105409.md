**Situação da Venda e Motivo de Cancelamento**   
 Nesta opção de menu estão relacionados todos os Motivos de Cancelamento de Vendas ou Distratos disponíveis no sistema.  
    
 Esta tabela é fixa, ou seja, o usuário não tem permissão para cadastrar Motivos de Cancelamentos de Vendas, somente editá-las;  
    
 **Identificação - Situação da Venda e Motivo de Cancelamento**   
    
 Ao editar um Motivo de Cancelamento de Venda, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:  
    
 **Código:**  
 Código do Motivo de Cancelamento de Venda. Este campo é fixo do sistema e não poderá ser alterado;  
    
 **Descrição:**  
 Informe a descrição do motivo de cancelamento. Ex.: Distrato Bilateral;  
    
 **Observação**  
 Campo texto para informar alguma observação;  
    
 **Situação Sub-unidade após o cancelamento:**  
 Informe qual a situação da sub-unidade após o cancelamento da venda. Caso não seja informado, o sistema assume que será "Disponível para Venda";  
    
 **Cancelar Parcelas gerada a banco:**  
 Caso este parâmetro esteja desmarcado, os lançamentos em aberto que foram enviados a banco pela rotina de cobrança eletrônica do RM Fluxus, NÃO serão cancelados;  
    
 **Gerar parcelas de Devolução:**  
 Informe se para este motivo de cancelamento, o sistema irá gerar ou não devolução para o cliente. Devolução é um lançamento a pagar no RM Fluxus da empresa para o cliente;
