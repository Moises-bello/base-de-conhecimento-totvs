# FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Funcionários | Férias* |
| **Situação/Requisito:** | Ao filtrar todos os funcionários que possuem férias (Situação = F) e navegar entre os registros através da toolbar da tela de Férias (Anexos>Movimento>Férias ) mesmo sem alterar nenhum campo é exibido uma mensagem solicitando a confirmação da alteração |
| **Solução/Implementação:** | Ajustado a navegação entre registros de funcionários que estão com férias marcadas  \* Filtrar todos os Funcionários que estão com férias marcadas (Filtro Exemplo:Situação = F)  \* Abrir Anexos>Movimento>Férias  \* Navegar entre os funcionários filtrados através da toolbar |
