# 1992377 RMSAU-2174DT Valor do exame imagem está saindo errado ao lançar através da aba Guia/Autorização

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de contas |
| **Situação/Requisito:** | Cliente alega que ao adicionar uma guia/autorização (atendimento externo) de um procedimento com filme radiológico o valor do procedimento está ficando incorreto na conta do paciente |
| **Solução/Implementação:** | Quando marcado o parâmetro na condição contratual dos convênios (valor do filme destacado no lançamento de exames radiológicos) na conta do paciente deve aparecer o procedimento e abaixo o valor referente ao filme radiológico utilizado no mesmo.  Quando o parâmetro estiver desmarcado deve listar apenas o procedimento porém no valor do mesmo já deve estar somado o valor referente ao filme radiológico. |
| **Tickets relacionados:** | 1992377 |
| **Requisito:** | RMSAU-2174 |
