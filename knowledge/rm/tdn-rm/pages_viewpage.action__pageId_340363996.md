# Transferência de Grupos Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Transferência de Grupos Contábeis |
| **Situação/Requisito:** | Ao incluir ou alterar um molde, na estrutura de Transferência de Grupos Contábeis, é exibida uma mensagem indevida, mas que permite acessar a tela de cadastro. Nesta tela, ao tentar pesquisar as contas de origem (Grupo de Contas) nenhuma informação é retornada, não sendo possível salvar a estrutura e executá-la. |
| **Solução/Implementação:** | O cadastro "Estruturas de Transferência de Grupos Contábeis" foi alterado para permitir a inclusão de um ou mais moldes. Também houveram alterações para que a pesquisa de contas de origem (Grupo de Contas) retorne as informações necessárias. |
