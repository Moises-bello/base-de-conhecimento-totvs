![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21850934018199) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Existe ID especifico de triênio saldo de salário rescisão?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Não Existe ID especifico de triênio saldo de salário rescisão. O triênio saldo de salário se trata do adicional mês assim pelo padrão em rescisão será calculado no id 0003.
