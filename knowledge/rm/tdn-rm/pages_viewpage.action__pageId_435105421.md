Esse cadastro tem como objetivo criar descrições de tipos de imóveis. Os tipos de imóveis são usados para agrupar imóveis semelhantes e auxiliar em uma possível busca de imóveis.   
Possui os seguintes campos:

* **Código:** Campo numérico preenchido automaticamente pelo sistema. Utilizado como controle interno do sistema;
* **Descrição:** Campo de descrição livre, onde o usuário pode informar um tipo de imóvel desejado.
