# Cancelamento de transferência de controle

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Patrimonial |
| **Função:** | Cancelamento de transferência de controle |
| **Situação/Requisito:** | Ao executar o processo de cancelamento da transferência de controle o sistema está apagando a filial do patrimônio. |
| **Solução/Implementação:** | O processo de cancelamento da transferência de controle foi alterado para não apagar a filial do patrimônio. Essa situação estava ocorrendo somente com patrimônios que não possuíam um ou mais registros no histórico de filial. Vale ressaltar que o patrimônio deve possuir, no mínimo, um registro no histórico de filial. |
