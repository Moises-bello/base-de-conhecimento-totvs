**Estágio/ Emprego**   
Através deste menu, o aluno tem permissão para acompanhar toda gestão de vagas do Estágio/Emprego.   
   
No cadastro de solicitação de estágio, o aluno consegue cadastrar mais de um funcionário para a empresa mediante permissão.  O processo é permitido tanto para empresas já cadastradas quanto para as novas.   
   
Para os alunos egresso, o portal permite que os mesmos possam candidatar a vaga de emprego para o seu Curso/Habilitação. Para que a vaga fique ativa, é necessário que:

* O Status da no Curso/Habilitação do aluno esteja como Concluído;
* O Parâmetro na situação de matrícula "Indica conclusão de Curso" esteja habilitado;
* A vaga de Estágio/Emprego, deverá estar cadastrado como: Emprego.
