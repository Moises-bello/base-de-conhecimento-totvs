# Ajuste no Lançamento de Diagnose e Terapia

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Tesouraria |
| **Situação:** | Na tela de elaboração de contas, ao inserir um registro na aba Diagnose e Terapia, o sistema inseria automaticamente a data inicial da parcial como o horário do lançamento para todos os pacientes. |
| **Solução:** | Realizado ajuste no registro na aba Diagnose e Terapia, se o paciente for do tipo interno, será inserido o horário atual; senão, será inserido o horário inicial da parcial, no horário do lançamento. |
