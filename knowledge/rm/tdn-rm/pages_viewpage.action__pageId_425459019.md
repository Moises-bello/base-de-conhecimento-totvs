O processo Revisar Questões tem por finalidade facilitar a edição de questões sem impactar nas informações originais das provas que já foram realizadas. No entanto, o sistema atualizará as questões para as execuções futuras.

Na tela inicial, o sistema permitirá que se insira "notas de revisão". Este campo é destinado a qualquer nota descritiva que se deseje ser feita para esta revisão.  
 Ex: Revisão no Banco de questões devida a mudanças no Novo Acordo Ortográfico

**Criar versão para todas as questões:**Será possível também configurar que o processo "crie versão para todas as questões". Inicialmente esta opção estará desabilitada. Caso esta opção seja marcada, o processo gerará uma versão de questão (para fins de histórico) para todas as questões e suas respectivas versões em outros idiomas (se houver), independente de terem sido modificadas durante o processo.

**Revisão de questões:** Serão exibidas questão a questão, dentre as carregadas, a fim de que se realize as edições necessárias para as mesmas.

Estarão disponíveis para edição, os campos de questão: Enunciado da questão, Nível de dificuldade e Peso.

**Observações Importantes:**   
 Não será permitido alterar a parte estrutural da(s) questão(ões).   
 Ex: Não é possível incluir/excluir uma alternativa da questão que está sendo revisada.

**Questões exclusivas**  
  Não é permitido deixar:

* A questão sem nenhuma opção.
* O texto da opção em branco.
* Sem opção correta se o tipo de prova for de avaliação de conhecimento.
* Com opção correta se o tipo de prova for de pesquisa de opinião.
* Mais que uma opção correta.

**Questões múltiplas**

Não é permitido deixar:

* A questão sem nenhuma opção
* O texto da opção em branco.
* Sem opção correta se o tipo de prova for de avaliação de conhecimento.
* Com opção correta se o tipo de prova for de pesquisa de opinião.

Para questões de avaliação de conhecimento com compensação:

* O percentual de peso para opções corretas não pode superar 100%
* O percentual de peso para opções incorretas não pode superar 100%

Para questões de pesquisa de opinião:

* O percentual de peso para opções não pode superar 100%
