---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define o tipo de parâmetro da consulta SQL.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Expression | O parâmetro será recuperado da planilha através de uma expressão padrão no cadastro da consulta SQL. |
| Value | O parâmetro é o próprio valor informado. |
| CellReference | O parâmetro será recuperado de uma referência de célula no formato A1. |
