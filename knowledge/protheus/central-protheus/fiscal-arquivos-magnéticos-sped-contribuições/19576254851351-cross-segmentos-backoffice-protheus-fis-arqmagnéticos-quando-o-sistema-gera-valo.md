![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19576276973591) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Quando o sistema gera valor no campo **15 (VL\_ICMS)** do registro **C170** do EFD Contribuições?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Fiscal - Todas as versões

**Solução**

O sistema foi adequado para atender a **MP. 1.159 de 2023**, onde para operações de entrada ou devolução de entrada será levado o valor do ICMS não creditado do item para o **campo 15 VL\_ICMS** do registro **C170**:

Legislação;

<http://sped.rfb.gov.br/pagina/show/7202>

Documentação da adequação:   
<https://tdn.totvs.com/display/public/PROT/16873588+DSERFIS1-32846+DT+-+EFDCON+-+Campo+15+VL_ICMS+do+Registro+C170>

**OBS.** Para atender a regra acima na rotina, é preciso estar com as rotinas atualizadas conforme link abaixo:
