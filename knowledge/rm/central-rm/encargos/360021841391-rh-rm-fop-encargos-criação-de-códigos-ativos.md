**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura: **00:01:40 min****Dúvida**Para que o sistema realize a geração dos encargos, é necessário que seja relacionado o **Código Ativo** no encargo e também durante a geração de encargos na rotina. Mas como posso fazer para criar e relacionar os **Códigos Ativos** aos **Encargos**?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para cadastrar um novo código ativo para geração de encargos, siga os passos abaixo:  
  
1. Acesse a aba **Administração de Pessoal | Cadastros Globais | Tabelas dinâmicas**;  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8866632886039/mceclip0.png)  
  
2. Altere a opção **Sistema** para **Folha de pagamento;**  
3. Pesquise pela tabela com o código **PCODATIVO**:  
 **![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8866599015191/mceclip1.png)**4. Acesse a aba **Itens da tabela** e selecione o botão **Incluir;  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8866668614167/mceclip2.png)**

**![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8866640847767/mceclip3.png)**5. Será exibida a tela para cadastro do novo código ativo, que deverá ser preenchida seguindo a necessidade da empresa;  
6. Após conclusão do cadastro, o novo código ativo poderá ser utilizado na geração dos encargos;
