## **01. VISÃO GERAL**

Este processo tem a finalidade de transferir os itens selecionados para a aba de "Itens Grátis".

Somente os itens não estornados é que serão transferidos.

Caso a parcial já esteja com os status de Liberada ou Faturada, não será permitida a transferência.

Este processo existe nas seguintes abas: Honorários, diárias, Taxas e Serviços, Matmed, Diagnose e Terapia.

Para Matmed é possível informar a quantidade a ser transferida. Para realizar a transferência, não pode existir devolução pendente para o paciente.
