**Dúvida**Quais são os lançamentos padronizados referentes ao Documento de entrada no módulo de Compras?

**Ambiente**Microsiga Protheus – Compras – A partir da versão 11.80  
  
  
**Solução**Segue Lançamentos Padronizados (LP) disponíveis para o módulo de Compras:

640 - Entrada de NF Devolucao/Beneficiamento ( Cliente ) - Itens  
650 - Entrada de NF Normal ( Fornecedor ) - Itens  
660 - Entrada de NF Normal ( Fornecedor ) - Total  
642 - Entrada de NF Devol.Vendas - Total (SF1)  
655 - Exclusao de NF ( Fornecedor ) - Itens  
665 - Exclusao de NF ( Fornecedor ) - Total  
955 - Do SIGAEIC - Importacao  
950 - Do SIGAEIC - Importacao  
641 - Entrada de NF Devolucao/Beneficiamento ( Cliente ) - Itens do Rateio  
651 - Entrada de NF Normal ( Fornecedor ) - Itens do Rateio  
656 - Exclusao de NF ( Fornecedor ) - Itens do Rateio
