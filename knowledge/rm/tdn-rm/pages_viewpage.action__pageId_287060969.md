# Alocação manual de salas com horário em sub-turmas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Alocação manual de salas |
| **Situação/Requisito:** | Ao realizar a alocação manual de salas, os horários das subturmas somem e são transferidos para a turma. |
| **Solução/Implementação:** | Foi detectado que o horário perdia a marcação que indicava que o mesmo era da subturma. Dessa forma, o sistema entendia que esse horário era da turma/disciplina.  Foi realizado um acerto de forma que a marcação definida no horário continua e esse se mantêm na subturma recebendo apenas a associação da sala, realizada na alocação. |
