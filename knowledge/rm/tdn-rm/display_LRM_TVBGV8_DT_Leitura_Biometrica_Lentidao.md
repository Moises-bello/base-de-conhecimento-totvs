# LEITURA BIOMÉTRICA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Leitura biométrica* |
| **Situação/Requisito:** | **Foi identificado que a leitura biométrica na tela de movimentações está apresentando lentidão.** |
| **Solução/Implementação:** | *Foi analisado todo o processo da leitura biométrica e identificado que o sistema carrega todas as impressões digitais dos usuários do biblios, incluindo usuários cancelados, assim, fazendo com o o sistema faça uma busca em uma massa de dados muito grande, o que pode ocasionar lentidão, caso a base de usuários do sistema seja grande, sendo assim, para otimizar processamento e tempo, o sistema não irá mais carregar usuários com situação de "cancelado", assim reduzindo consideravelmente a quantidade de usuários e otimizando muito o processo de busca biométrica.* |
