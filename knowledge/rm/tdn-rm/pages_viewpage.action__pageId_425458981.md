Por este cadastro é possível definir áreas avaliadas, onde serão vinculadas as matérias e questões, para aplicação de provas e/ou pesquisas.

**Observação**

A partir do momento em se define um idioma para a área é possível cadastrar, para a mesma, versões dos textos em outros idiomas. Para áreas que já possuem matérias e questões e o idioma ainda não foi definido, caso seja informado será exibida uma mensagem para confirmação, pois todos os registros associados de áreas, matérias, questões e provas receberão o mesmo idioma.
