## **01. VISÃO GERAL**

O menu lateral do módulo de Odontologia é o principal ponto de navegação dentro do PEP

(Prontuário Eletrônico do Paciente), permitindo acesso rápido às funcionalidades específicas

da área odontológica. A sidebar permanece fixa à esquerda da tela, garantindo fácil localização

e acesso às opções disponíveis durante o atendimento.

Estrutura do Menu

## **02. ESTRUTURA DO MENU**

### 2.1 Cabeçalho

* **Mensagem de Bem Vindo**
* **Identificação do Profissional**
* **Campo de Pesquisa**

### 2.2 Opções de Navegação

Cada item do menu é exibido em formato de lista, acompanhado de ícone representativo e rótulo textual.

**Página Inicial:** Redireciona para a tela inicial do módulo odontológico.

**Identificação:** Permite visualizar os dados de identificação do paciente.

**Odontograma:** Redireciona para a tela de registro do odontograma do paciente.

**Orçamento:** Acessa o módulo de criação de orçamentos para procedimentos odontológicos.

### 2.3 Rodapé

* **Fechar Menu:** Botão “Fechar menu” para recolher a barra lateral e ampliar a área de trabalho.
Regras de Acesso

## **03. REGRAS**

## **Regras de Acesso**

* O item **Odontograma** somente é habilitado quando:

  + O usuário é o dentista responsável pelo atendimento.
  + Possui permissão específica no PEP para iniciar odontogramas e orçamentos.
* Demais itens seguem permissões gerais do perfil odontológico.
