# MUDANÇA DE TURMA - GRAVAÇÃO DE LOG Nº DO DIÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Mudança de Turma - Gravação de Log do Nº do Diário* |
| **Situação/Requisito:** | *Ao executar o processo de Mudança de Turma, sistema não informa o número do aluno no campo do Histórico de alteração de Matricula quando se retorna para a Turma inicial.* |
| **Solução/Implementação:** | *Ajuste no processo de mudança de turma para que seja gravado no histórico da matrícula do período letivo do aluno o número do diário quando se retorna para a turma inicial. Foi ajustado também no processo de numeração do ensino básico para a gravação do log do Nº do aluno no histórico de matrícula do período letivo.* |
