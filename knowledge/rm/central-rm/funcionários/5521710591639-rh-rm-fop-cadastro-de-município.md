**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura:**00:00:40 min****Dúvida**Como realizar o cadastro de município?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**No cadastro de funcionários existe o campo **Naturalidade**, onde é possível informar qual é o município da cidade natal do funcionário.   
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10760120367127)  
  
Para realizar o cadastro, realize os seguintes passos:  
  
1. Acesse o módulo **Folha de Pagamento | eSocial | Endereços | Municípios**  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10760179685911)  
  
2. Clique em **Incluir**:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10760223840535)  
  
3. Adicione o município desejado:  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10760277453975)
