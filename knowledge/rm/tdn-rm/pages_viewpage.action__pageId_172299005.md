# Objetivo:

---

     O objetivo do Preview Rápido é apenas exemplificar ao usuário, de forma rápida, os configuração para visualizar o Preview Rápido do relatório.

# Introdução:

---

     Para criar um Preview Rápido no Totvs Report, efetue o procedimento abaixo:

false

**Processo de Configuração:**

.1º Passo:

**Edite o relatório desejado.**

Selecione o relatório desejado e dê dois cliques ou acesse o menu *Processos | Editar Estrutura*.

2º Passo:

**Execute a pré visualização do relatório.**

Para executar pré visualização do relatório, ainda na visão de edição, clique na guia *Exibição | Pré-visualização*.

3º Passo:

**Salve o Preview.**

Para salvar o Preview, ainda na visão do Preview do relatório clique sobre a guia *Inicio | Salvar.*

     Depois de efetuado o procedimento descrito acima, atualize a visão do report. A partir de então, ao selecionar este relatório será exibido o seu Preview Rápido.

falseObservação:

* O Preview sempre exibirá o relatório salvo. Lembrando que a tela não fará atualização automática dos valores no relatório.
* Esta função pode deixar a seleção do relatório mais demorada, devido a exibição da imagem a todo o momento.
