# FÉRIAS NA SITUAÇÃO W COMPLEMENTO DA LICENÇA MATERNIDADE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Férias* |
| **Situação/Requisito:** | *Não está sendo permitido colocar o funcionário de férias quando a situação atual é igual a W - Licença Mater. Compl. 180 dias.*  *A situação W deve seguir o mesmo comportamento da situação E - Licença Maternidade. Se é permitido sair da situação E direto pra F - Férias, também deve liberar a transição da situação W direto pra F.* |
| **Solução/Implementação:** | *Ajuste no cadastro de férias para habilitar o botão de Lançar, quando o funcionário está na situação W - Licença Mater. Compl. 180 dias,* *a situação será alterada para 'F - Férias' direto.* |
