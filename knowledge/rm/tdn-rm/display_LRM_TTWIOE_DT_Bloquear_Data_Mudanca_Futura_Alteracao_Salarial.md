# BLOQUEAR DATA DE MUDANÇA EM COMPETÊNCIAS FUTURAS NA ALTERAÇÃO GLOBAL DE SALÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Alteração Global de Salários* |
| **Situação/Requisito:** | *Está sendo permitido efetuar alteração salarial com data de mudança em competetências futuras.*  *Entretanto os processos do sistema não estão preparados para considerar aumentos futuros, visto que o módulo de alteração global de salários altera o conteúdo do campo Salário do cadastro do funcionário.* |
| **Solução/Implementação:** | *Ajuste para não permitir informar Data de Mudança em competências futuras no módulo de Alteração Global de Salários.* |
| **Chamados   relacionados:** | *TTWIOE* |
| **Versões/Release:** | *11.82.43* |
