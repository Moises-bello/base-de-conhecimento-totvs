![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34808029362327) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que TRCT não apresenta nome atualizado mesmo tendo alteração no campo Nome cadastro funcionário (RA\_NOME)?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**O TRCT busca informação do campo nome completo (RA\_NOMECMP), assim, esse campo também deve ser atualizado para gerar o TRCT com nome atualizado.
