# Atualização das Parcelas do Contrato

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Processo de Atualização das Parcelas do Contrato |
| **Situação/Requisito:** | Na tela de parcela do plano de pagamento, existe a opção de desconto, sendo ele do tipo Percentual ou valor, ao marcar o campo como valor e informa o desconto 90,96 na parcela que desejo, vou no processo atualizar parcela do contrato e marco o campo valor do desconto, ao entrar na parcela do aluno que foi atualizada, onde constava a opção marcado de valor no Tipo de Desconto, automaticamente aparece marcado a opção de percentual, sendo que o correto seria a opção de valor. |
| **Solução/Implementação:** | Melhoria no processo de atualização das parcelas do contrato para que sempre que o usuário selecionar o campo “Valor do desconto” automaticamente o sistema selecionara o campo “Tipo de desconto” ou vice versa, garantindo assim que as duas informações fiquem atualizadas, pois uma impacta diretamente na outra’. |
