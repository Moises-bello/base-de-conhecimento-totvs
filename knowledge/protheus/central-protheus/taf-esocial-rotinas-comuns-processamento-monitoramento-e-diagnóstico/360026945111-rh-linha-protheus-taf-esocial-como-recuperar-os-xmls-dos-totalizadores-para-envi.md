**Dúvida**Como recuperar os recibos dos totalizadores para envio para receita quando necessário ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - totalizador - Todas as versões  
  
**Solução**

Será necessário acessar a rotina de cada totalizador separadamente.

![](https://totvssuporte.zendesk.com/attachments/token/nAd3ccjLNnUaFNplMYVnbCwKg/?name=inline1165973871.png)​

Dentro das rotinas existe o botão gerar XML em lote.

![](https://totvssuporte.zendesk.com/attachments/token/aUyFDHZb1mTKnIaeLtKCutBIQ/?name=inline-154516941.png)​

Utilize o filtro conforme a necessidade e gere os arquivos na pasta selecionada

![](https://totvssuporte.zendesk.com/attachments/token/WFBSOF9IMCm0aaoXMfU201ZzH/?name=inline1391073187.png)​

Escolha o diretório, onde deseja salvar os XML´s

![](https://totvssuporte.zendesk.com/attachments/token/XxPki04NIlNS8aIg4R5kqm1S6/?name=inline1387517601.png)​
