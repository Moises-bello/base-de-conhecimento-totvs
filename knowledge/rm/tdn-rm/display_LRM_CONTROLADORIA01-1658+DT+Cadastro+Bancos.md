# Cadastro de bancos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Cadastro de bancos |
| **Situação/Requisito:** | Não permitir a inclusão, edição e exclusão de bancos se a nova integração Eduacional x Backoffice Protheus (Id 1021) estiver ativa. |
| **Solução/Implementação:** | O cadastro de bancos foi alterado para que os botões de inclusão e exclusão não sejam exibidos quando a nova integração Eduacional x Backoffice Protheus (Id 1021) estiver ativa. Diante deste cenário apenas o campo Dígito poderá ser alterado pelo usuário. |
