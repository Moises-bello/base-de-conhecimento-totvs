**Dúvida**A função MATA011 foi descontinuada.   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Altere o seu arquivo de menu do **SIGAEIC**, onde estiver chamando a função **MATA011** altere para **MATA010**.  
Arquivo **SIGAEIC.XNU**, este esta na pasta System do Protheus.
