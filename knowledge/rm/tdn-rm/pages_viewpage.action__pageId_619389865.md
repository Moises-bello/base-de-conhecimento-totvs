Histórico de ApontamentosHistórico de Apontamentos

O menu Histórico de Apontamentos permite que o usuário consiga visualizar os apontamentos(sincronizados) realizados pelo coletor de acordo com a data informada.

O Histórico de Apontamentos ao ser aberto irá exibir por padrão a data corrente.

A data pode ser alterada para qualquer data válida e caso o coletor possua apontamentos para a data informada o histórico dos apontamentos será exibido. Para que os apontamentos sejam visualizados o usuário deve clicar no ícone .

Serão exibidos para o coletor os apontamentos de Avanço Físico, Mão de Obra, Ciclo de Transporte e Equipamento.

***Observação: Os apontamentos que serão exibidos no histórico respeitam as permissões do usuário.***

Exceções

* Caso a data informada pelo usuário não possuir apontamentos será exibida uma mensagem informando que não foram encontrados apontamentos.

* Caso o coletor não possua conexão com a internet ou houver algum problema de comunicação para o retorno das informações, será exibida a mensagem no coletor informando que não há conexão com a internet.
