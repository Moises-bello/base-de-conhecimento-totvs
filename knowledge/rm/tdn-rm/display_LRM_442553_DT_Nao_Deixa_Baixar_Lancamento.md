# BAIXA DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Baixa de lançamentos financeiros* |
| **Situação/Requisito:** | *Com o sistema parametrizado para não utilizar bolsas escalonáveis, ao baixar um lançamento que tenha bolsas escalonáveis e especiais, o sistema tenta validar se o valor baixado das bolsas escalonáveis condizem com o valor atual das bolsas, porém como não é possível determinar o valor das bolsas escalonáveis dentro do campo opcional utilizado para bolsas, o sistema acusa erro ao usuário.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de baixa de lançamentos financeiros, permitindo ao sistema, baixar um lançamento com bolsas escalonáveis e especiais quando o sistema não estiver parametrizado para utilizar escalonamento de bolsas.* |
