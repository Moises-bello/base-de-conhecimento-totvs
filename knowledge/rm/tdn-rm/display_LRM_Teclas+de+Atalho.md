O TOTVS Gestão de Estoque, Compras e Faturamento possui teclas de atalho, verifique as disponíveis abaixo para otimizar o trabalho do usuário:

| Acesso | Atalho |
| --- | --- |
| Recalcula o Movimento na Edição | F7 |
| Abre os Campos Complementares para edição na visão dos Movimentos | Ctrl + Shift + C |
| Abre o anexo Quadro Comparativo na visão das Cotações | Ctrl + Q |
| Consulta Movimentações do Produto | Ctrl + M |
| Consulta Saldos e Custos | Ctrl + T |

Veja abaixo as informações detalhadas sobre as partes que compõem a Visão Geral:

| Atalho | Visão Geral |
| --- | --- |
| Ctrl+Ins | Inclui um registro novo |
| Ctrl+Del | Exclui o registro corrente |
| Ctrl+Enter | Edita o registro corrente. |
| Ctrl+Home | Posiciona o ponteiro no primeiro registro. |
| Ctrl+End | Posiciona o ponteiro no último registro. |
| Up (seta para cima) | Posiciona o ponteiro no registro anterior. |
| Dn (seta para baixo) | Posiciona o ponteiro no próximo registro. |
| Left (seta a esquerda) | Desloca a tabela uma coluna a esquerda. |
| Right (seta a direita) | Desloca a tabela uma coluna a direita. |
| Ctrl+PgUp | Posiciona o ponteiro no primeiro registro visível da janela. |
| Ctrl+PgDn | Posiciona o ponteiro no último registro visível da janela. |
| F5 | Atualiza a visão. |
