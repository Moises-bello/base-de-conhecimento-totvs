Remoção da limitação de 1MB para envio e recebimento através de funções HTTP

|  |  |
| --- | --- |
| Situação | Remoção da limitação de 1MB para envio e recebimento através de funções HTTP |
| Ocorrência | Ao tentar enviar ou receber mais de 1MB através de funções HTTP ocorre erro |
| Melhoria | Deixando o limite de envio e recebimento o mesmo definido no MAXSTRINGSIZE |
| Informações adicionais | * Referente ao chamado: TSSE86 * Referente à ocorrência: TTEC-654 * Disponível em builds superiores a 7.00.131227A - 1.0.3 |
