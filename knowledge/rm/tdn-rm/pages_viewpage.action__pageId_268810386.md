# Digitação Frequência Diária

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Digitação de Frequência Diária |
| **Situação/Requisito:** | * A tacla “Enter” não estava funcionando nos componentes de pesquisa(lookups) da tela, ou seja, a pesquisa não era realizada ao ser acionado a tecla “Enter”. * Ao acionar a tecla "TAB" o sistema não estava posicionando o cursor no componente conforme a ordem de disposição do mesmo |
| **Solução/Implementação:** | Melhoria na tela de digitação de “Notas e faltas de etapa”, “Notas de avaliação” e “Frequência diária” para que ao acionar a tecla “TAB” o sistema respeite a ordem da disposição dos campos.  E também foi realizada melhoria para que a tecla “Enter” funcione corretamente nos componentes de pesquisa da tela (lookup). |
