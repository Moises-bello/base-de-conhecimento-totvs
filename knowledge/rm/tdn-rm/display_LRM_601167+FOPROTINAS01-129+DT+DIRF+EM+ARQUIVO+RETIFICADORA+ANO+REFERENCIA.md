# DIRF EM ARQUIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | Emissão dos campos. |
| **Situação/Requisito:** | Ao gerar a DIRF em arquivo conforme o manual do ano-calendário 2015 e ano referência 2016 ou superiores o sistema deve:     1. Para o registro DIRF campo de      ordem 4 "Indicador de retificadora" o valor "S" deve      ser informado quando o parâmetro "Situação do Estabelecimento"      tiver marcado a opção "Retificadora"; 2. Para o registro DIRF campo de      ordem 2 "Ano Referência" deve ser informado segundo os layouts      um ano a mais do ano-calendário se calendário igual a 2015, ano referência      deve ser 2016.. |
| **Solução/Implementação:** | A emissão da DIRF em arquivo conforme o manual do ano-calendário 2015 e ano referência 2016 ou superiores o sistema contempla os campos abaixo conforme o layout, a saber:     1. Para o registro DIRF campo de      ordem 4 "Indicador de retificadora" o valor "S" será      informado quando o parâmetro "Situação do Estabelecimento" tiver      marcado a opção "Retificadora"; 2. Para o registro DIRF campo de      ordem 2 "Ano Referência" será informado segundo os layouts com      um ano a mais do ano-calendário se calendário igual a 2015, ano referência      deve ser 2016. |
