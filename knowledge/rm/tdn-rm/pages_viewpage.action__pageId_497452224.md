# ALTERAÇÃO NO CADASTRO DE ALUNO COMO RESPONSÁVEL FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Cadastro de Aluno |
| **Situação/Requisito:** | Na alteração do cadastro do aluno quando o sistema tem a integração Protheus com o Educacional desativada, mas ativa para outro produto a alteração do cadastro do aluno não é finalizada. O sistema apresenta mensagem indevida referente ao commit da transação |
| **Solução/Implementação:** | Otimização no cadastro do aluno quando o sistema estiver configurado para cadastrar o aluno como responsável financeiro para exibir o motivo que tal cadastro não foi possível. |
| **Conversores e Parâmetros:** | Parâmetro "Cadastrar o aluno como responsável financeiro" marcado na alteração do cadastro de aluno |
