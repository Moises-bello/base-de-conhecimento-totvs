# INFORME DE RENDIMENTO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Informe de Rendimentos* |
| **Situação/Requisito:** | Verificamos que após inserir dados na tabela PFHSTRRA para que as informações fossem apresentadas para o Ano Calendário de 2015, ao gerar novamente o Informe de Rendimentos para disponibilizar no portal, os dados (Quadro 6) foram apresentados em todos os informes de rendimentos disponibilizados anteriormente no portal, ou seja, no ato da geração a data de pagamento não está sendo validada. |
| **Solução/Implementação:** | *Ajustado filtro do ano do informe de rendimentos ao buscar as informações dos Rendimentos Recebidos Acumuladamente (RRA).* |
| **Chamados relacionados:** | *TUVQVH* |
| **Versões/Release:** | 12.1.12 |
