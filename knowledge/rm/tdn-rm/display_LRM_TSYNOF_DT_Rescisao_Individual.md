# Rescisão individual

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Rescisão individual* |
| **Situação/Requisito:** | Entendemos que o cadastro da rescisão coletiva deve seguir as mesmas premissas que o cadastro da rescisão individual no que se refere obrigatoriedade de preenchimento de alguns campos.  No cálculo de rescisão individual o campo "Motivo de Demissão" não é obrigatório, permitindo que o cadastro seja feito sem apresentar nenhuma mensagem ao usuário.  Na rescisão coletiva o campo "Motivo de Demissão" é obrigatório.  Gentileza avaliar uma padronização para a situação, se nos dois recursos o motivo de demissão será obrigatório ou não. |
| **Solução/Implementação:** | Otimizada rescisão individual, regra para tratar o campo "Motivo de demissão" como obrigatório |
