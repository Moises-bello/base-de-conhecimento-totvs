# Cadastro de horário na turma/disciplina

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Horário da turma / disciplinas* |
| **Situação/Requisito:** | *No cadastro de horário da turma / disciplina, quando o sistema está parametrizado para permitir super alocação de professores é emitida uma mensagem informando os choques existentes e questiona o usuário se ele deseja dar prosseguimento a operação. Quando ocorre uma grande quantidade de choques existe a possibilidade que a mensagem sobrescreva as opções e o usuário não consiga dar finalizar o cadastro.* |
| **Solução/Implementação:** | *No cadastro de horário da turma / disciplina, quando o sistema está parametrizado para permitir super alocação de professores a mensagem informando os choques existentes é exibida em uma tela com barra de rolagem para permitir a correta visualização.* |
