A barra de navegação está presenta na tela "PAINEL DE INVENTÁRIOS" do app "Minha Contagem de Estoque", ao clicar no ícone é exibido uma lista de opções que permite navegar entre os seguintes recursos:

Menu na barra de navegação

# 

**Início**

Menu - Início

Navega de volta para a página "PAINEL DE INVENTÁRIOS".

**Sincronizar**

Menu - Sincronizar

Realiza o sincronismo das contagens realizadas no inventário se existirem, depois carrega dados relacionados ao inventário e os inventários, ao fim do processo retorna a tela inicial "PAINEL DE INVENTÁRIOS"

 

Informação

* Se o tipo de sincronismo configurado for manual, ao fim da contagem de estoque de todos os produtos vá no menu sincronismo para realizar o envio das informações para o ERP.
* Se o tipo de sincronismo for recorrente então os produtos vão ser sincronizados de tempo em tempo automaticamente.

Mais detalhes ver tópico Configurações

**Mensagens**

Menu - Mensagens

Exibe mensagens de alerta que possam ter ocorrido durante o sincronismo, por exemplo, um produto que em um contagem utilizou a unidade "KG" e em outra contagem "M3", isso vai gerar um alerta.

**Configurações**

Menu - Configurações

Ao acessar as configurações é possível definir o tipo de sincronização utilizado pelo app "Minha Contagem de Estoque", dentro dessa tela é possível as seguintes ações:

(1) Abre novamente o menu de navegação.

(2) Escolha entre os tipos de sincronização disponível:

* Manual
* Wi-Fi e Dados Móveis (essa opção abre uma configuração adicional, "Recorrência", essa configuração indica a cada quantos minutos o sincronismo deve ocorrer).
* Somente Wi-Fi (essa opção abre uma configuração adicional, "Recorrência", essa configuração indica a cada quantos minutos o sincronismo deve ocorrer).

(3) Salva a configuração escolhida, após salvar o usuário vai receber uma confirmação de que a configuração foi salva com sucesso, clique em continuar para voltar a tela inicial.

**Backup e Compartilhar**

Menu - Backup e Compartilhar

A opção "Backup e Compartilhar" permite compartilhar o banco de dados do app "Minha Contagem de Estoque" com os contatos registrados no aparelho, WhatsApp, eMail, entre outros.

O possível uso deste recurso é para quando o usuário deseja compartilhar com a TOTVS uma situação especifica que esteja ocorrendo com o app e assim seja possível a avaliação por parte da TOTVS.

**Ativar log/Desativar log**

Ativar log/Desativar Log

É possível solicitar ao app que registre códigos de barras de Produto que não foram encontrados durante o processo de Contagem.

Para isso é necessário marcar o campo 'Ativar/Desativar Log' no app:

Detalhes do funcionamento dessa opção estão descritos na seção **Registrar produtos não encontrados durante a contagem** do documento

**Enviar logs**

Enviar logs

Ao selecionar a opção "Enviar logs" o app envia os registros de códigos de barras de Produto que não foram encontrados durante o processo de Contagem, caso a opção "Ativar Log" esteja marcada.

Detalhes do funcionamento dessa opção estão descritos na seção **Registrar produtos não encontrados durante a contagem** do documento

**Sair**

Menu - Sair

Ao selecionar "Sair" o app "Minha Contagem de Estoque" desconecta do usuário e retorna para tela inicial solicitando usuário e senha.
