Em caso de salários compostos, selecione os eventos de salário composto que este evento utilizará como base para cálculo de seu valor.   
 **Exemplo:**  
 Evento Salário composto  
 Hora Extra de salário composto 01   
 Salário Composto 01  
 Para a hora extra de salário composto 01 que incide no salário composto 01, o usuário deverá, no evento de hora extra, no anexo Base de Salário Composto, incluir o evento de salário composto 01. Para a hora extra, será feito o cálculo utilizando o valor do Salário Composto 01.
