# LANÇAMENTO FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Lançamento Financeiro* |
| **Situação/Requisito:** | *A tag de controle de segurança que está sendo utilizada para acesso a tela de "Parâmetros Financeiros" é a mesma tag de controle que está sendo utilizada para acesso a tela "Lançamentos Financeiros".* |
| **Solução/Implementação:** | *Ajuste no controle de segurança para separar as tags de controle de acesso as telas "Parâmetros Financeiros" e "Lançamentos Financeiros". A tag correta para a tela de "Lançamentos Financeiros" é a tag que é utilizada no módulo Financeiro.* |
