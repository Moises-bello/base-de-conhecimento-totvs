**Dúvida**Em qual rotina é utilizado o parâmetro **MV\_QDIDTVG**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**O parâmetro **MV\_QDIDTVG - Define se deverá ser impresso a Data de Vigência no Relatório de Lista Mestra por documento** é utilizado apenas na listagem do relatório **QDOR042 - Lista Mestra de Documentos por Departamento**, onde se estiver parametrizado como **S**, irá listar a data de vigência com base no conteúdo do campo **QDH\_DTVIG - Dat Vigência**.
