# GERAÇÃO DE MOVIMENTO EM REGIME DE CAIXA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de movimento por boleto |
| **Situação/Requisito:** | Ao gerar movimento em regime de caixa para um determinado boleto que tenha seu lançamento baixado, quando os parâmetros do processo não permitem movimento com valor líquido igual a zero e quando o sistema está parametrizado para não gerar boleto após uma baixa parcial, ocorre erro devido o sistema não conseguir calcular o valor líquido do boleto. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimento por competência, de forma que o sistema consiga calcular o valor líquido do boleto para quando o sistema está parametrizado para não gerar boleto após uma baixa parcial. |
