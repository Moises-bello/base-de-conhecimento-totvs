**Dúvida**Como corrigir a mensagem "Um ou mais campos não foram preenchidos" Tipo de Frete ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Export  Control* – A partir da versão 11.80.

**Solução**Para que a mensagem não seja apresentada, realize o procedimento abaixo:  
1. Acesse o módulo SIGACFG em Base de Dados, selecione Dicionário / Base de dados.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360025329791/mceclip0.png)

2. Selecione Dicionário de Dados

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360025309112/mceclip2.png)

3. Selecione a lupa ![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360028632011/mceclip6.png)   
4. Selecione Procurar Por e informe a tabela SC5, após selecione Buscar.

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360028632612/mceclip8.png)  
5. Posicione no ![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360028632151/mceclip9.png) busque o campo C5\_FRETE.

![mceclip10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360028632872/mceclip10.png)

6. Na Aba Uso, desmarque a obrigatoriedade do campoe salvar a alteração.

![mceclip11.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360028632691/mceclip11.png)
