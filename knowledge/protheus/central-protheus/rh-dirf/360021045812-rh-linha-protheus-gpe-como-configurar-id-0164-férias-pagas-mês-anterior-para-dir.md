**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34325704583703)**Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como configurar para DIRF o ID 0164 Férias pagas mês anterior para a DIRF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**A verba com **ID 0164**, mesmo se tratando de uma verba de desconto deve ser configurada com incidência A para DIRF, assim como as verbas de provento de férias e férias mês seguinte, pois essas verbas tem incidência de IR na folha, e para a DIRF a verba de ID 0164 abate os valores de férias pagas mês anterior configuradas para a DIRF.  
  
Para ajuste, entre na rotina de **Verbas** pelo caminho **>Atualizações >Definições de cálculos >Verbas**, procure pela verba de ID 0164 e na aba **Anuais** deixe o campo DIRF com **A:**
