# Retorno Bancário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Retorno Bancário |
| **Situação/Requisito:** | Retorno bancário só grava em um campo complementar, configurado no layout bancário, quando o código do retorno é do tipo registrado ou recusado ou baixado |
| **Solução/Implementação:** | Retorno bancário passou permitir que um campo complementar, configurado no layout bancário, seja gravado para todos os lançamentos encontrados na base de dados durante o processo, independente do tipo de retorno enviado pelo banco |
