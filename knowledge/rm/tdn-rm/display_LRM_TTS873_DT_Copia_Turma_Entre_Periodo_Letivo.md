# Cópia de turmas entre períodos letivos

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Cópia de turma entre períodos letivos* |
| **Situação/Requisito:** | *Quando o processo de cópia de Turmas entre períodos letivos era executado sem selecionar as Disciplinas para cópia, uma mensagem de erro era exibida.* |
| **Solução/Implementação:** | *Ajuste no processo para que a cópia seja realizada, mesmo que o usuário não selecione a cópia das turmas/disciplinas. Neste cenário apenas a turma será copiada para o período letivo de destino.* |
