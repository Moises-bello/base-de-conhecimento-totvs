***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)*** Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Para que serve a rotina **Atraso de O.S - Ordem de Serviço - MNTA035**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Manutenção de Ativos (SIGAMNT) - Todas as versões  
  
**Solução**O cadastro de **Atraso de O.S.** vem para suprir a necessidade de adequar o Sistema para situações onde a execução de uma tarefa demanda mais tempo do que o esperado. Quando se planeja uma **O.S**, não podemos prever todos os fatores e, às vezes, a execução dessas **O.S's** foge do esperado, sendo necessário informar que ocorreu um atraso, para manter os dados condizentes com a realidade.
