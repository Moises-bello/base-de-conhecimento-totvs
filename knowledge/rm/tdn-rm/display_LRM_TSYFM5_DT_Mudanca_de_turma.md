# Mudança de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Mudança de turma* |
| **Situação/Requisito:** | *No contexto de ensino báisico, ao efetuar a mudança de turma de um aluno em que existisse uma disciplina optativa na matriz e em que ele não estivesse matriculado na turma origem, ocorria uma exceção não finalizando o processo.* |
| **Solução/Implementação:** | *No contexto de ensino básico, ao efetuar a mudança de turma de um aluno, caso exista uma disciplina optativa na matriz curricular e o aluno não estiver matriculado nessa disciplina na turma origem, ela é retirada da lista de disciplinas a serem matriculadas na turma de destino.* |
