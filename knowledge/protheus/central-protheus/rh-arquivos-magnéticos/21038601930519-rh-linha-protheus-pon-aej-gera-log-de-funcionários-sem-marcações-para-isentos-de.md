![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21038601907095) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Ao gerar o arquivo **AEJ**, é gerado log de **Funcionários sem Marcações** para pessoas isentas de registro de ponto.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21038588051223)  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Causa**A mensagem mostrada no log é apenas de **carater informativo** e para demonstrar funcionários que não possuem marcações de ponto no período de impressão do arquivo, mesmo quando na Regra de Apontamento o campo Isento de Marcações está como Sim.  
  
**Solução**O arquivo AEJ **não deixará de ser gerado** para outros funcionários que possuam marcações de ponto no período, portanto, não é necessário fazer nenhum tipo de filtro para que a impressão dos demais dados sejam geradas corretamente.
