# Compilador de Hemocultura

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Controle de Infecção Hospitalar (CIH) |
| **Função:** | Compilador de Hemocultura |
| **Situação/Requisito:** | O Compilador de Hemocultura e o cadastro de Cultura Final necessitavam de um aumento de inserção de Amostras de Resultados de Germes de 3 para 8 amostras. |
| **Solução/Implementação:** | 1. O processamento do Compilador de Hemocultura foi ajustado para processar até 8 amostras de resultados de germes (Antes era 3); 2. Na tela de Cultura Final a View de Germes foi ajustada de forma a apresentar as 8 amostras de resultados de germes, além disso as Views de Germes e Antibiograma foram dispostas uma debaixo da outra para fins de facilitar a leitura dos dados. 3. Após a execução do Compilador de Hemocultura o pedido de Cultura Final compilado terá os campos "Nº Amostras" e "Grupo mat" desabilitados para edição de forma a evitar inconsistência de dados. |
