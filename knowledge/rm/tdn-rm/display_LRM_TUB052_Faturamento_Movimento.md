# FATURAMENTO DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Gestão de Estoque, Compras e Faturamento* |
| **Função:** | *Faturar Movimento* |
| **Situação/Requisito:** | Criado um movimento com 2 itens, após criado uma cotação em um dos itens do movimento criado anteriormente. Após, ao faturar esse movimento ocorria erro:  "Movimento está participando de algum processo de cotação". |
| **Solução/Implementação:** | Melhoria no faturamento de movimento no qual um dos seus item participa de processo de cotação |
