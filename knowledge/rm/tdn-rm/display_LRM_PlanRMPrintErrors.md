---

# Descrição

---

Define se e como os erros das células serão impressos.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| AsDisplayed | Imprime os erros como são mostrados na tela. |
| AsBlank | Imprime os erros como um espaço em branco. |
| AsDash | Imprime os erros como traços ("---"). |
| AsNA | Imprime or erros como #N/A. |
