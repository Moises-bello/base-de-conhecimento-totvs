| **Sintoma** | **Como validar o acesso dos perfis do sistema?** |
| Solução | 1. Agora acesse o cadastro de perfis pelo menu: Cadastros -> Segurança -> Perfis ou Menu de seleção de aplicações -> Serviços Globais -> Segurança -> Perfis(.Net) 2. Clique duas vezes no perfil desejado e vá na aba Acesso a Menus 3. No quadro abaixo, serão exibidos todos os menus do sistema 4. Selecione o menu em questão e clique em "Permitir Acesso" caso queira liberar acesso ao menu ou "Proibir Acesso" caso queira que o Perfil não acesse o menu   IMPORTANTE:  Em .Net, toda vez que entrar no cadastro de Usuários e Perfis, verifique, logo acima do botao de Incluir se após "Sistema:" está descrito o sistema que deseja liberar / proibir acessos. |
