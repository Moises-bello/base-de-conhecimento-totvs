Esta tela é simplesmente para se cadastrar quais os tipos de participação existentes na instituição.

Por exemplo: Reitor, Vice Reitor, Primeiro secretário, Coordenador.  
    
 A necessidade desta tela se deu devido a possibilidade que cada IES pode ter nomes diferentes para uma mesma função.  
    
    
 É possível associar a um coordenador (anexo de Matriz Aplicada) vários tipos de participação. Visando facilitar este processo o sistema possui o filtro de tipo de participação na busca avançada na tela de emissão de certificados.  
    
 **Observação:** O usuário do sistema para emitir um certificado de participação a um coordenador é necessário ter pelo menos um tipo de participação selecionado. Um coordenador pode ter o mesmo certificado várias vezes, porém com o tipo de participação diferente.
