# VISUALIZAR RELATÓRIO DO RM REPORTS MARCANDO A OPÇÃO DE VISÍVEL PARA TODAS AS EMPRESAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Visualizar relatório do RM Reports marcando a opção de visível para todas as empresas* |
| **Situação/Requisito:** | Ao marcar a opção "Visivel a todas as coligadas" ao editar um relatório do RM Reports, e tentar gerar o mesmo pela tela de Relatórios do Funcionário ou Relatórios de Férias ou Relatórios de Rescisão o mesmo não é gerado. Ao desmarcar a opção "Visivel a todas as coligadas", o mesmo é gerado com sucesso. |
| **Solução/Implementação:** | Gerar os relatórios do RM Reports quando a opção "Visivel a todas as coligadas" estiver marcada, pela tela de Relatórios do Funcionário ou Relatórios de Férias ou Relatórios de Rescisão. |
| **Chamados relacionados:** | TUHHMM |
