Após utilizar o auto-complete do Dicionário de Dados não é possível compilar

|  |  |
| --- | --- |
| Situação | Após utilizar o auto-complete do Dicionário de Dados não é possível compilar |
| Ocorrência | O Rpo fica sendo utilizado pelo auto-complete e não é permitida a compilação |
| Correção | Quando a chave BuildKillUsers estiver ligada derrubar todas as conexões abertas inclusive as de auto-complete do Dicionário de dados |
| Informações adicionais | * Referente ao chamado: SSIM-1071 * Referente à ocorrência: não há ocorrência associada * Disponível em builds superiores a 7.00.131227A - 2.0.3 |
