A **Visão das Registradoras dos Contatos do Mutuário** está acessível a partir do menu de Anexos do cadastro de Cliente/Fornecedor, quando aberto a partir do contexto do TCGI:

Ao acessar essa visão os sistema apresenta os dados de contato deste cliente, que foram integrados com uma Registradora de Recebíveis, a partir da execução do Processo [Integrar Registradora](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora).

São exibidas as seguintes informações nesta grid: Tipo Registradora, CPF/CNPJ, Tipo de Contato, Data Registro, Cód. Integração, Usuários Criação, Data Criação, Usuário Alteração e Data Alteração, sendo que estas informações são somente informativas e não permitem nenhuma edição:

**Esta Melhoria está liberada a partir da versão 12.1.2302.**
