# Transferência de Grupos Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Transferência de Grupos Contábeis |
| **Situação/Requisito:** | Ao realizar o processo de transferência de grupos contábeis é apresenta a mensagem:  O sistema identificou que existem contas contábeis que não exigem rateio, mas, no entanto existem saldos gerenciais (rateios) correspondente ao saldo anterior (saldo gerado quando é realizado a Liberação de Período).  Sugerimos que seja executado o processo de “Zeramento do Saldo Anterior” selecionando a opção “Contas Gerenciais” e informando no filtro as contas listadas neste LOG.  1.4.0.01.0037.0023   ............................  Obs: o processo de “Zeramento do Saldo Anterior” foi descontinuado, sendo assim, o cliente não tem como realizar este procedimento. |
| **Solução/Implementação:** | Ajuste na mensagem da validação para que não seja referenciado o processo que foi descontinuado. |
