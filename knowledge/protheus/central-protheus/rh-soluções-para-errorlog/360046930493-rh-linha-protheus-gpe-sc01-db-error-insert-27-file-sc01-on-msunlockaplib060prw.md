**Ocorrência**Ao gerar evento periódico para todos os funcionários é gerado *error log:* "**\_SC01: DB *error (Insert):* -27 *File:* \_SC01 *-  on MSUNLOCK*(A*PLIB060.PRW)****".***Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões.  
  
**Causa**O erro ocorre quando existe um trabalhador **sem CPF** transferido entre empresas de **RAIZ CNPJ diferente**.  
  
**Solução**Para solucionar esse erro deve ser aplicado o pacote acumulado do RH de acordo com as instruções do artigo abaixo:  
Pacote de Expedição Contínua do RH:<https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057829854>
