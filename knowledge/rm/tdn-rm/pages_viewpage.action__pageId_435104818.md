Esta funcionalidade tem por objetivo permitir ao usuário realizar uma busca por  usando filtros.  
É possível realizar também uma busca avançada, aplicando filtros com mais informações que se agregam aos filtros da busca padrão para maior refinamento dos resultados.

Os imóveis com situação: Locado, Vendido, Inativo e Indisponível não serão retornados pela busca independente de qualquer filtro utilizado.  
   
**Filtros da Busca Padrão**

* **Tipo de Imóvel:**Permite informar vários tipos de imóvel para a busca;
* **Cidade:**Permite informar a cidade na qual queremos que o imóvel esteja para a busca;
* **Bairro:**Permite informar o bairro no qual queremos que o imóvel esteja para a busca;
* **Valor:**Permite informar uma faixa de valor para a busca;
* **Área:**Permite informar uma faixa de área para a busca;

**Filtros da Busca Avançada**

* **Coligada:**Permite informar várias coligadas dos imóveis para a busca;
* **Região:**Permite informar várias regiões na qual o imóvel se encontra para a busca;
* **Tipo de Locação:**Permite informar vários tipos de locação para a busca;
* **Data de Aquisição:**Permite informar um período de data de aquisição para a busca;
* **Características:**Permite informar diversas características que se deseja nos imóveis para a busca.

**Configuração dos critérios disponíveis para realizar a busca**  
Os disponibilidade dos critérios de busca acima listados é afetada pela configuração do  que está vinculado ao perfil do usuário.  
   
**Resultado da Busca**  
O resultado da busca se dá na forma de cards onde cada card representa um  disponível que atendeu aos critérios definidos na busca.  
Nestes cards são apresentados informações dos imóveis, como imagem, descrição, área, valor, endereço.  
É possível clicar no card para abrir a tela de cadastro do imóvel, bem como é possível clicar no endereço para que seja aberto o browser com a busca do endereço no Google Maps  
   
Observação:  
A tela de consulta de imóveis sempre será aberta com os parâmetros da ultima consulta realizada definidos.
