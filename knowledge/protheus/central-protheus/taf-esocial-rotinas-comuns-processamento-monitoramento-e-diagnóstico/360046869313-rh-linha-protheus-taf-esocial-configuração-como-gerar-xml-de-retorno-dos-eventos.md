**Dúvida**Como gerar o XML de retorno do e-Social, ou XML do TAF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF eSocial - Todas as versões

**Solução**

```
Obs.: O procedimento de geração do XML RET, não gera em Lote!
```

1 - Para gerar o XML do retorno do RET, ou o XML do TAF, deverá acessar a rotina desejada no menu do TAF (Seja Periódicos, Não Periódicos ou Tabelas):

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360067003353)

2 - Acessando o registro da rotina desejada, você vai no caminho:  
**"Outras Ações" -> "Gerar XML e-Social":  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360067003533)**

Outra opção abaixo: **![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360067003633)**

3 - Ao clicar em um dos botões para gerar o XML eSocial, será apresentada a tela abaixo:  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360065937394)  
As opções acima tem o XML gerado pelo TAF e o XML retornado pelo governo;

```
Obs.: Importante que o serviço do TSS esteja ativo!
```

4 - Salve o arquivo onde desejar e pronto. O XML do retorno do governo estará disponível.
