# Integração Totvs Gestão Patrimonial x Totvs Manutenção

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Patrimonial |
| **Função:** | Ocorrência de baixa total |
| **Situação/Requisito:** | O cliente deseja que os objetos de manutenção, integrados ao Totvs Gestão Patrimonial, sejam sucateados após a realização de uma baixa total. |
| **Solução/Implementação:** | Durante a realização de uma baixa total, se o patrimônio estiver integrado ao Totvs Manutenção, o objeto de manutenção será sucateado. Caso a baixa total seja excluída o sucateamento será cancelado. |
