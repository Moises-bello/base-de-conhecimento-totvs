# ALTERAR PARÂMETROS DE ETAPAS DE ÁREAS OFERTADAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Alterar parâmetros de etapas de áreas ofertadas* |
| **Situação/Requisito:** | *No processo de alteração de etapas, caso exista mais de uma área ofertada e as etapas tenham o mesmo nome, a alteração de uma etapa de somente uma área afeta todas que tiverem o mesmo nome, mesmo que não tenham sido alteradas.* |
| **Solução/Implementação:** | *Foi identificado que a o formato de busca das etapas alteradas utiliza somente o nome da etapa, ocasionando assim a alteração de todas as etapas de mesmo nome no processo seletivo. Foi inserido mais um critério de consistência que é o identificado da área de interesse, assim a alteração é feita somente para a respectiva área.* |
