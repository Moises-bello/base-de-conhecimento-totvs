# Regerar Contabilizações com mais de 250 lançamentos na tela.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Regerar Contabilização |
| **Situação/Requisito:** | Ao realizar o processo de Regerar Contabilização o sistema apresenta mensagem de erro relatando que não foi possível contabilizar por diferença de débito e crédito. |
| **Solução/Implementação:** | Ajustes no serviço  de alteração de lançamento. Ao regerar a contabilização de inclusão mais de 250 lançamentos ao mesmo tempo, todos as informações de cada  lançamento serão carregadas corretamente. |
