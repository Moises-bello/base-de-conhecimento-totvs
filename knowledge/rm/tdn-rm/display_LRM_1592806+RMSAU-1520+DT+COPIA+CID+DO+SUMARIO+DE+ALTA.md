# Copiar CID do Sumário de Alta

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de Classificação de Risco (finalizar atendimento) |
| **Situação/Requisito:** | Médico necessita que o campo CID – Classificação Internacional de Doenças, carregue o dado informado no prontuário eletrônico (sumário de alta), para evitar a digitação da informação em duplicidade, quando ele estiver finalizando o atendimento do paciente, no painel de classificação de riscos, alta do paciente. |
| **Solução/Implementação:** | Efetuado ajuste para efetuar a cópia do CID para a finalização do atendimento pelo Painel de Classificação de Risco quando o paciente estiver em uma Unidade de Atendimento previamente parametrizada para realizar esta cópia |
