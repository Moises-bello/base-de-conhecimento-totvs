![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24455747343767) Tempo aproximado para leitura: **00:05 min****Dúvida**Quais bancos estão homologados para registro de pagamento via API?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA717/FINA718  
  
**Solução**

Requisitos necessários para o registro de pagamentos via API do Banco do Brasil

No módulo financeiro, está disponível a rotina FINA717 para o pagamento dos boletos via API. Até o momento, o banco homologado é apenas o Banco do Brasil.

[Banco do Brasil - FINA717](https://tdn.totvs.com/pages/releaseview.action?pageId=734394173)

Com relação ao retorno dos pagamentos, dispomos da rotina FINA718. Até o momento, o banco homologado é apenas o banco do Brasil.

[Banco do Brasil - FINA718](https://tdn.totvs.com/display/public/PROT/Job+de+retorno+dos+pagamentos+-+FINA718)

Importante: **Diante da dependência de liberação de API compatível por parte dos bancos, não há previsão de liberação da funcionalidade para a implementação no protheus.**
