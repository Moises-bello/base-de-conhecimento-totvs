**Eventos**  
Através desde cadastro, é possível definir os eventos que serão utilizados relativos aos rendimentos e descontos dos autônomos do Fluxus e externos que devem ser informados ao Governo através do evento S-1200 para o eSocial.

**Provento utilizado na integração para autônomos de outros sistemas (S-1200)**

O sistema utiliza este evento para lançar o valor da remuneração do autônomo.

**Provento sem incidência em INSS/IRRF utilizado na integração para autônomos de outros sistemas (S-1200)**

O sistema utiliza este evento para lançar o valor da remuneração do autônomo que não é considerada no valor do serviço.

**Provento incidência exclusiva do empregador utilizado na integração para autônomos de outros sistemas (S-1200)**

O sistema utiliza este evento para lançar o valor da remuneração do autônomo quando o empregador é produtor rural pessoa fisíca e seu lançamento financeiro não possue desconto de INSS.

**Importante:** este evento só ficará disponivel caso a coligada seja pessoa fisíca e flag produtor rural marcada. Cadastrar um evento do tipo provento com incidência exclusiva do empregador.

****Desconto utilizado na integração para autônomos de outros sistemas (S-1200)****

O sistema utiliza este evento para lançar o valor de desconto de INSS.

******Desconto SEST utilizado na integração para autônomos de outros sistemas (S-1200)******

O sistema utiliza este evento para lançar o valor de desconto do SEST (desconto relativo a contribuições destinadas a outras entidades e fundos (Terceiros)).

********Desconto SENAT utilizado na integração para autônomos de outros sistemas (S-1200)********

O sistema utiliza este evento para lançar o valor de desconto do SENAT (desconto relativo a contribuições destinadas a outras entidades e fundos (Terceiros)).

**********Desconto ISS utilizado na integração para autônomos de outros sistemas (S-1200)**********

O sistema utiliza este evento para lançar o valor de desconto do ISS (imposto sobre serviço).
