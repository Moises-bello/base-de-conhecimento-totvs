**Dúvida**  
Como criar visões diferentes no Browse das rotinas no Protheus?  
  
**Ambiente**  
Cross Segmento - Backoffice (Linha Protheus) - SIGAEST - A partir da versão 12  
  
**Solução**  
Para criar uma visão nova no Protheus, realize os seguintes passos:  
1. Verifique se a rotina que esta acessando permite criar visões:

![Visao 01.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33339946619287)

2. Clicando em "Criar Visão", na primeira aba é possível definir o nome da visão e se ela será publica ou não:

![Visão 02.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33339946619799)

3. Na aba campos, definimos quais campos do Browse queremos que constem na visão criada, também podemos definir se os campos de legenda (caso a rotina possua) serão apresentados ou não:

![Visão 03.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33339946620567)

4. Na aba filtro é possível definir um filtro para exibição dos dados:

![Visão 04.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33339946620951)

Após as configurações, basta salvar a visão e ela ficará disponível para seleção:

![Visão 05.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33339946621591)
