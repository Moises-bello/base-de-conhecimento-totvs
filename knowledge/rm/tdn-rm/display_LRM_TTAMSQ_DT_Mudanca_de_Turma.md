# Mudança de turma

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Mudança de turma* |
| **Situação/Requisito:** | *Ao efetuar o processo de mudança de turma no contexto de ensino básico, caso a turma de destino possuir disciplinas diferentes da turma de origem é lançada uma exceção não tratada.* |
| **Solução/Implementação:** | *Ajustes para que, ao efetuar o processo de mudança de turma no contexto de ensino básico, caso a turma de destino possuir disciplinas diferentes da turma de origem será exibida uma mensagem informando dessa diferença, impedindo a mudança.* |
