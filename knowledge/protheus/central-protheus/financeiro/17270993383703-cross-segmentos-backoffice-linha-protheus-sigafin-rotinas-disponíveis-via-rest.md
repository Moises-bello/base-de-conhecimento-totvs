**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões  
  
**Solução**Todas as APIs padrões liberadas para serem utilizadas estão disponíveis no próprio link do webservice. Para consultá-las, basta configurar o servidor rest e acessar o endereço configurado.   
Exemplo:

```
http://{IP do servidor}:(port}/{path}
```
