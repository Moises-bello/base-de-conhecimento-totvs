![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32754112817175) Tempo aproximado para leitura: **00:01:48 min** **Dúvida**Como utilizar os relatórios **Smart View** no **SIGAOMS - Order Management System?****Ambiente**TOTVS Logistica - TOTVS OMS (Linha Protheus) - Gestão de Distribuição (SIGAOMS) - A partir da versão 12.1.2310  
**Solução**A integração com o **Smart View** tem como finalidade oferecer maior flexibilidade na visualização das informações, por meio de **Visões de Dados**, **Tabelas Dinâmicas** e **Relatórios**.  
  
O **Smart View** é a solução da **TOTVS** para extração, manipulação e visualização de dados transacionais.  
  
Para que a integração entre o **SIGAOMS** e o **SmartView** funcione corretamente, é essencial que o Sistema esteja devidamente configurado.  
  
Para isso, siga os tutoriais disponíveis:

1. [How To: Configuração do Smart View - Configuração do REST + Instalação](https://www.youtube.com/watch?v=YIwdqo1Ix9s)

3. [How To: Configuração do Smart View – Conectores + Token Protheus](https://www.youtube.com/watch?v=-Ui6W2gc3Pg)
