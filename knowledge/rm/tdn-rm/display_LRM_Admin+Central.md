Zonas suportadas: Tesp02, Tece01, Tesp03 (Novo Deploy)  
Zonas não suportadas: Máquinas da legada zona P1 e TESP1.

### Admin Central

Essa ação estará disponível no novo Deploy, tem como objetivo administrar usuários do Go-Global

### **Pré-requisitos****:**

Topologias devem estar no novo Deploy para que a ação seja disponibilizada.

### Utilização:

Acesse o Go-Global com usuário administrador para que as opções do Admin Central estejam disponíveis:

Após login, será exibido o ícone do Admin Central:

Na tela inicial do Admin Central, será exibido as informações de gerenciamento do Go-Global, como sessões ativas, processos em execução, usuários cadastrados etc...

Na aba "Usuários" possuímos as seguintes funcionalidades:

* Criar novos usuários
* Gerenciar múltiplos usuários
* Pesquisar usuário
* Editar usuário selecionado

Edição de apenas um usuário:

A opção APLICATIVOS é possível gerenciar qual usuário terá acesso a um determinado aplicativo:
