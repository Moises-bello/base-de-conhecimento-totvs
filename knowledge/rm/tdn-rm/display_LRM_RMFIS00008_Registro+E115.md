# Geração do registro E115 - SPED Fiscal

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Fiscal |
| **Versões:** | 12.1.5 |
| **Ocorrência:** | Geração do registro E115 - SPED Fiscal |
| **Ambiente:** |  |
| **Passo a passo:** | De acordo com o layout do SPED Fiscal o registro E115 refere-se a "Informações Adicionais da Apuração - Valores Declaratórios. Este registro tem o objetivo de informar os valores declaratórios relativos ao ICMS, conforme definição da legislação estadual pertinente. Esses valores são meramente declaratórios e não são computados na apuração do ICMS."     * **Geração do registro no sistema:**   Utilizaremos o FEEF para exemplificar a geração do E115. O FEEF trata-se do Fundo Estadual de Equilíbrio Fiscal, de caráter temporário instituído pela Lei 7428/16 com a finalidade de manutenção das finanças públicas e previdência do Estado do Rio de Janeiro.    Valores declaratórios como o FEEF serão informados no registro E115.    Esses valores serão incluídos na aba "Valores Adicionais Apuração" do período de apuração do ICMS.
