# Gerenciamento de Usuários, Perfis e Permissões

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 12.1.0 |
| **Ambiente:** | MDI | RM.exe | Portal RM |
| **Passo a passo:** | **Objetivo:**  O Objetivo deste documento é explicar como é realizado o gerenciamento de Usuários, Perfils e Permissões após o sincronismo ter sido executado.    **Introdução:**  Quando o RM estiver integrado e sincronizado com o IDENTITY o gerenciamento de Usuários, Perfils e Permissões devem ser realizados através do IDENTITY. Atenção Quando o RM estiver integrado o IDENTITY não será possível realizar operações de Inserção, Edição, Cópia e Exclusão de Usuários,Perfis e Permissões\* através do RM, estes recursos são bloqueados. |
