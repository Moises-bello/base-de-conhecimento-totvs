**Dúvida**  
Sistema apresenta mensagem " Status 0 - Não Processado"  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**  
Isso ocorre pois nunca foi realizada uma importação para aquele colaborador no qual as informações não existem na SRK, com isso o sistema sinaliza com o Status de Não Processado   
  
1. O colaborador de exemplo não possui o registro do empréstimo referente a competência de Outubro.   
Então na importação o sistema indica a Legenda Azul

![](https://centraldeatendimento.totvs.com/hc/article_attachments/36182667419287)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/36182667423511)  
  
2. Após gravar a importação o sistema vai atualizar a SRK - Lançamentos Futuros desse colaborador.
