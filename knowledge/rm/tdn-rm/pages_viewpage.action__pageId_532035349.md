# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Contábil |
| **Versões:** | 12.1.20 |
| **Ocorrência:** | Layout de importação Lançamentos Contábeis. |
| **Ambiente:** |  |
| **Passo a passo:** | O novo modelo de conceito utilizado na importação de lançamentos contábeis se aplica somente a versão 12. Outro detalhe é que mesmo no novo modelo de conceito não é possível fazer a importação de forma parcial, ou seja, caso algum erro ocorra será necessário corrigir e importar novamente pois nenhuma linha será gravada no caso de erro. Apesar de no novo modelo de conceito disponibilizar a opção de "Continuar a execução mesmo com erros (opção presente em todos os conceitos do novo modelo)" a mesma não é considerada para o conceito em questão por questões de limitação da arquitetura utilizada para gravação dos dados.  As informações do layout relatado abaixo deverão ser disponibilizadas em um único arquivo, ou seja, os dados referentes a Capa do lançamento, Partidas do lançamento, Distribuição gerencial (Rateio) e campo complementar,devem ser inseridas no mesmo arquivo, pois no momento da importação o sistema irá distinguir a informação através do identificador de Linha. Cada informação deve ser preenchida em linhas diferentes, pois para cada uma existe um identificador de linha que deve estar na primeira posição da linha.  **Observações**  A coluna "Obrigatório" consiste na obrigatoriedade ou não do preenchimento do campo. Quando informado com "X", o mesmo tem s do campo. Quando vazio, não é necessário o preenchimento do mesmo.  Para realizar a importação dos lançamentos contábeis, é necessário que o lote para onde os mesmos serão importados já existam no cadastro de lotes da contabilidade.
