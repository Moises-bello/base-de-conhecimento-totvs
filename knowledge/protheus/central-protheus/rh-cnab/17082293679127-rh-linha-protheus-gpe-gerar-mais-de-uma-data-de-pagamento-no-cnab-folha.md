![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17082266670615) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Gerar mais de uma data de pagamento no CNAB.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**

Não há uma opção de CNAB folha com múltiplas datas de pagamento devido ao próprio layout do arquivo da FEBRABRAN que determina uma data especifica para pagamento.  
  
![](https://totvssuporte.zendesk.com/attachments/token/fcboTxOgy3fV9xw7P7GW01YBL/?name=image.png)

Desta forma , o arquivo de configuração segue obrigatoriamente o layout padrão de comunicação bancária, chumbando uma data específica de crédito:

![](https://totvssuporte.zendesk.com/attachments/token/yXFId6mKB8oeWfjwszPvxhUyl/?name=image.png)

Sendo assim, uma vez que o layout da comunicação bancária não tem essa opção, será necessário gerar vários arquivos quando a data de pagamento for diferente entre eles.
