# GERAÇÃO DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de movimento em regime de caixa |
| **Situação/Requisito:** | Ao gerar movimento em regime de caixa para um boleto oriundo de uma parcela do tipo extra com o sistema parametrizado para gerar movimento em regime de competência, o sistema impede a geração de movimento, mesmo com o sistema também parametrizado para não gerar movimento por competência para parcelas do tipo extra |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimentação em regime de competência, permitindo ao sistema, gerar movimentação em regime de caixa para boletos oriundos de parcelas do tipo extra, mesmo quando o sistema estiver parametrizado para gerar movimento em regime de competência. |
