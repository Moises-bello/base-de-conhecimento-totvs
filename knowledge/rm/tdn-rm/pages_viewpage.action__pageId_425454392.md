# Diferença de Férias

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Diferença de Férias |
| **Situação/Requisito:** | Funcionária gozou férias do período 24/08/2018 à 12/09/2018, na competência outubro/2018 a mesma recebeu aumento retroativo competência agosto/2018, ao calcular diferença de férias por dissidio, o sistema retornou o valor do Dif.INSS Férias próximo mês com o valor indevido, ou seja, maior do que o valor que deveria ser descontado. |
| **Solução/Implementação:** | Ajuste no cálculo da diferença de INSS Férias para tratar casos de 2 períodos de férias no mesmo mês. |
