Nesta etapa é realizada as configurações referente a reserva de recurso e instalação

**Seleção de recurso durante reserva:**

Este parâmetro quando marcado, permite definir os recursos que compõe a reserva.

***Exemplo:***  
 O professor solicita a reserva de uma sala para aula de laboratório. Durante a execução do processo ele lista o nome dos alunos que iram assistir a aula. 

**Lista de Espera Recurso/Instalação**

**Utilizar lista de espera para recurso/instalação**

Este parâmetro quando marcado permite que uma solicitação de reserva de recurso e/ou instalação vá para a lista de espera quando o local ou recurso não estiver disponível na data e horários solicitados.

**Exemplo:**   
 Veja o cenário:

|  |  |  |  |
| --- | --- | --- | --- |
| **Professor** | **Data de solicitação** | **Instalação / Dia / hora** | **Recurso / Data / Hora** |
| João | 01/12/2014 | Sala 01 / 01/01/15 / 16:00hrs | Projetor 01 /01/01/15/16:00hrs |
| Carlos | 03/12/2014 | Sala 01 / 01/01/15 / 16:00hrs | Projetor 01 / 01/01/15 / 16:00hrs |

\*Observe que quando Carlos solicitou a reserva João já havia feito para a mesma data e horário. A solicitação de Carlos neste caso vai para a Lista de espera.

No dia 10/12/2014 João solicitou o cancelamento de sua reserva fazendo com que a reserva feita por Carlos fosse automaticamente confirmada.
