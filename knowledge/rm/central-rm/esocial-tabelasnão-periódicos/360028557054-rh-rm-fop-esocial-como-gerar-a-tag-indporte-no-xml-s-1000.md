**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24971809724567) Tempo aproximado para leitura: 00:02:00 min****Dúvida**Como gerar a tag **indPorte** no XML **S-1000**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - Todas as versões  
 **Solução**

Para o eSocial somente é enviado o S-1000 com a informação de Indicativo de microempresa - ME ou empresa de pequeno porte - EPP for sim = S.

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/24971809728279)**

Para preenchimento da tag acesse **eSocial |** **Informações do Empregador** a área **ME/EPP (Microempresa/Empresa de Pequeno Porte)** para ser preenchida como **Sim** ou **Não**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24971794754199)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24971794758935)

Marcando a opção **Sim** no campo supracitado, o XML do evento **S-1000** será gerado conforme abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24971794766999)
