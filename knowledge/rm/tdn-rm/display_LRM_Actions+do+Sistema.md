## **01. VISÃO GERAL**

Nessa tela é possível verificar todas as Actions que foram acessadas no aplicativo RM. É importante o conhecimento das propriedades das Actions para o uso de algumas funcionalidades do sistema. 

## **02. EXEMPLO DE UTILIZAÇÃO**

**acesse**: Serviços Globais | Serviços | Actions do Sistema

**• ID da Action**: É nome da funcionalidade no sistema. Este ID é única para cada funcionalidade no sistema.

**• Apelido:** É o nome alternativo dado àquela action.

**• Descrição**: Finalidade da action e o que ela representa.

**• Executar automaticamente após login:** Se marcada esta opção, o sistema programará a execução de actions automaticamente após o login. Se o usuário for supervisor, aparecerá um checkbox que dará a opção de executar a action para todos os usuários.
