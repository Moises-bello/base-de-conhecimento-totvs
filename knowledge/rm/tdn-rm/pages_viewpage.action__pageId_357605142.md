# Filtro de filial para mensagem pré-configurada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Processo "Agendamento/envio de mensagens" |
| **Situação/Requisito:** | Ao acessar o processo "Agendamento/envio de mensagens", e selecionar uma mensagem pré-configurada, o sistema não está filtrando pelas mensagens da filial corrente e exibindo as mensagens de todas filiais para seleção. |
| **Solução/Implementação:** | Foi realizado um ajuste no TOTVS Gestão Educacional no processo "Agendamento/envio de mensagens", de maneira que o sistema possa filtrar pelas mensagens cadastradas de acordo com o contexto corrente (Coligada, filial e nível de ensino). |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | N/A |
| **Requisito:** | N/A |

divs

Aperfeiçoado o envio de mensagens aos pais do aluno quando este estiver matriculado em dois ou mais cursos.
