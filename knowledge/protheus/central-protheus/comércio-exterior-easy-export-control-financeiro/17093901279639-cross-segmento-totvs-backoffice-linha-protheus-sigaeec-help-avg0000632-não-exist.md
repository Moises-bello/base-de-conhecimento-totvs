![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17093893861143) Tempo aproximado para leitura: **02:00 min** **Dúvida**Como corrigir o "**Help AVG0000632: Não existe registros para manutenção"?  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17094639953303)**  
 **Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) -*Easy Export Control*- A partir da versão 12.1.33

**Solução**A mensagem é apresenta pois não há parcelas de câmbio geradas. Para que as parcelas de câmbio sejam geradas, deve ser preenchida a Data de Embarque de Exportação, campo "**EEC\_DTEMBA"**.
