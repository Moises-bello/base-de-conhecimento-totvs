Nesta opção serão definidas as permissões de acesso a projetos, por projeto.   
 Os usuários terão acesso somente aos projetos para os quais foi concedido acesso e aos projetos que o próprio usuário criar.  
 A visão de usuários, utilizada para conceder permissão de acesso a projetos por usuário, irá listar somente os usuários que possuem acesso ao TOTVS Obras e Projetos;  
 Para fornecer permissão de acesso ao usuário efetue os seguintes procedimentos:

* Selecione os usuários cuja permissão de acesso a projetos você deseja alterar;
* Selecione em"Processos", a opção "Conceder Permissão de Acesso a Projetos";
* Marque para cada Projeto, os usuários que possuirão acesso ao mesmo, e conclua o processo.

Em "Segurança | Permissão de Acesso ao Projeto | Permissão de Acesso ao Projeto - Por Projeto | Anexos | Usuários que tem Acesso ao Projeto", exibirá todos os usuários que possuem acesso ao projeto selecionado na visão principal.
