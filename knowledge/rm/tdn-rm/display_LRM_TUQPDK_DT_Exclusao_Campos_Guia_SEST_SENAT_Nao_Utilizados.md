# EXCLUSÃO DE CAMPOS DA GUIA DE SEST SENAT NÃO MAIS UTILIZADOS NO SISTEMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Guia de INSS* |
| **Situação/Requisito:** | *Retirar os campos relacionados a Guia de INSS SEST/SENAT, que não são mais utilizados no sistema. São eles:*  *- "Recolhe INSE para SEST/SENAT e SESI/SENAI" no Parametrizador, pasta Folha Normal/Encargos Sociais. - "Atividade de Transporte" no cadastro de Funções. - "Contribui para Sesi/Senai" no cadastro de Seções. - "Contribui para Sesi/Senai" no cadastro de Centro de Custo.* |
| **Solução/Implementação:** | *A Guia de INSS SEST/SENAT é gerada automaticamente quando o funcionário está cadastrado com a categoria 15 - Transportador Autônomo.* |
