# IMPORTADOR - SCURSO E STURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Importador - SCURSO e STURMA* |
| **Situação/Requisito:** | *No Importador não existe o campo IDEIXOTECNOLOGICO para ser importado na tabela SCURSO e no layout de importação está com o campo CURPRESDIST da tabela SCURSO como obrigatório, porém o mesmo não existe no nível de ensino básico. Também não existe o campo TIPOMEDIACAO para ser importado na tabela STURMA.* |
| **Solução/Implementação:** | *- Adicionado o campo CODEIXOTECNOLOGICO para importação do IDEIXOTECNOLOGICO na tabela SCURSO;*  *- Alterado o layout de importação do campo CURPRESDIST da tabela SCURSO para que seja obrigatório apenas no nível de Ensino Superior;*  *- Adicionado o campo TIPOMEDIACAO para importação na tabela STURMA.* |
