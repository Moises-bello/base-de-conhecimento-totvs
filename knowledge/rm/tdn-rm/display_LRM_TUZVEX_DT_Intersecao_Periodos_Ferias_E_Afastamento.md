# ESTÁ SENDO PERMITIDO INTERSEÇÃO DE PERIODOS DE FÉRIAS E AFASTAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Afastamentos* |
| **Situação/Requisito:** | *Quando um funcionário está com férias marcadas, está sendo permitido cadastrar afastamento durante o periodo de férias.*  *E caso as férias estejam somente salvas, depois de afastar o funcionário está permitindo calcular as férias de um funcionário afastado.* |
| **Solução/Implementação:** | *Tratamento para consistir interseção entre afastamento e periodo de férias.*  *O ajuste deverá ser feito no cadastro do afastamento, e nos processos de cálculo e lançamento das férias.* |
| **Chamados   relacionados:** | *TUZVEX, TVAY69* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
