Dúvida**Como realizar alterações em um campo complementar de forma global?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**É possível realizar alterações nos campos complementares de forma global, ou seja, para vários funcionários de uma única vez utilizando uma fórmula.  
  
1. Para executar este processo acesse **Administração de pessoal | Alterações globais | Alteração campos do cadastro;**2. Após acessar a rotina e selecionar a opção **Campos complementares** no campo **Dados a serem alterados**, serão listados os campos complementares ativos para alteração no cadastro dos funcionários;  
3. Após selecionar o(s) item(s) a ser(em) alterado(s) será habilitado o campo para seleção da fórmula de alteração.  
4. Há duas formas para seleção da fórmula:  
- Digitar o código na primeira caixa e pressionar a tecla TAB. A descrição da fórmula aparecerá automaticamente;  
- Selecionar a fórmula usando o botão de seleção.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10961444750231)  
  
5. A criação da fórmula ficará a cargo do cliente, podendo ela ser uma fórmula simples apenas para o preenchimento geral ou então alguma fórmula que aplique alguma lógica condicional, aplicando dados diferentes para diferentes funcionários. Um exemplo de fórmula simples seria utilizar, em sua estrutura, apenas o dado a ser preenchido no campo complementar.
