# SOLICITAÇÃO E REQUERIMENTO NO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Solicitação (Requerimento) no Portal do Aluno. |
| **Situação/Requisito:** | Foi marcado o parâmetro para substituir todo o valor atual do serviço pelo valor do tipo de atendimento.  A questão é que o sistema está somando o total dos dois, a ideia deste parâmetro é desconsiderar o valor que está no serviço e levar em consideração o valor que está no Tipo de atendimento, mas ele está é somando os dois ao invés de substituir e com isso no portal fica exibindo o valor do serviço que no caso não deveria apresentar já que mandei desconsiderar o valor que está no serviço e o custo total fica com o valor errado e gerando o lançamento para a parcela com o valor indevido. |
| **Solução/Implementação:** | Ajustes ao abrir solicitação no portal do Aluno quando o parâmetro para substituir todo o valor atual do serviço pelo valor do tipo de atendimento está marcado. Quando o parâmetro estiver marcado o valor do preço do local de entrega do tipo de atendimento que será levado em consideração ao custo total. |
