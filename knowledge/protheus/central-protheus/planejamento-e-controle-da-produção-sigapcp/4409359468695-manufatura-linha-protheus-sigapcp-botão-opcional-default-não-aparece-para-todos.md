![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:25 min** **Dúvida**Por que no **MATA010 - Cadastro de Produtos**, o botão **Opcional Default** para seleção dos opcionais não é apresentado para todos os produtos?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Planejamento e Controle da Produção (SIGAPCP) - Versão 12  
  
**Solução**O botão **Opcional Default** é apresentado somente quando o produto selecionado no *browse* possui estrutura cadastrada no **MATA200 - Cadastro de Estruturas.**
