A partir da versão do **Application Server** **20.3.2.0**, a biblioteca **libctreecsv.so** do pacote foi atualizada para uma versão mais recente que contêm importantes correções que afetam o Ctree Client [mtclient.dll] e Ctreecsv com notificação em memória. Para o correto funcionamento desta biblioteca, o Sistema Operacional Linux requer a instalação da dependência **libncurses.so**.

Essa informação é válida somente para ambiente Linux.
