# Como alterar o leito de um paciente no sistema?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como alterar o leito de um paciente no sistema? |
| **Passo a passo:** | **Mudança de Leito**  Nesta função você poderá realizar a transferência de pacientes, de um leito que ele já ocupava para um novo leito. Como alterar Leito?  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Internação/ Mudança de Leito**. 2. Clique em **Inclui** e informe o nome do paciente e/ou clique em **Internados nesta data**. 3. Selecione o paciente desejado e clique em **OK.** 4. Informe também o Motivo da Transferência do paciente, a data e hora de transferência. 5. Selecione o novo leito no Mapa de Leitos. Clique na busca para realizar a pesquisa (raio). 6. Informe o responsável pela diferença de diária, caso necessário. 7. Informe se o sistema deverá desbloquear ou não o leito anterior. 8. Clique em **Grava** e o processo será executado. |
