Para alterar um Item de Pedido, basta selecionar o item no qual deseja-se alterar os dados.

O sistema irá abrir a tela permitindo a edição dos campos que estarão habilitados.

Caso o usuário tenha permissão de acesso para vincular Produto ao Insumo, o checkbox “Produto Vinculado Ao Insumo” estará habilitado e disponível para edição.

Com o checkbox habilitado, ao editar um produto, o usuário irá visualizar uma listagem com apenas o(s) produto(s) vinculados ao insumo.

Caso checkbox seja desmarcado, o usuário irá visualizar uma listagem com todos os produtos, podendo realizar a vinculação de produtos ao insumo atual.

**Observação:**  
Essas alterações só poderão ser realizadas antes do envio da requisição.
