**Dúvida**

Como atualizar os Códigos CNAE?  
  
**Ambiente**

Microsiga Protheus -  todas as versões.  
  
**Solução**

Para incluir um novo registro CNAE ou efetuar uma alteração, realize o procedimento abaixo :

No módulo Faturamento -> Menu Atualizações -> Cadastros -> CNAE (FATA500).

Clique em Incluir, ou alterar para ajustes dos registros.

**Observações:**

* Toda manutenção neste cadastro é de forma manual, não há  atualização de forma automática.
* Antes da inclusão de um novo registro, é importante sempre consultar no site oficial do IBGE e seguir o mesmo código CNAE (CC3\_COD).
