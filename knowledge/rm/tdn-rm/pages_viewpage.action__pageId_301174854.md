# PERMITIR ESCOLHER QUAIS RESPONSÁVEIS ENVIAR PARA A SAÍDA INTELIGENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Saída Inteligente |
| **Situação/Requisito:** | Ao encaminhar o aluno para o filho sem fila o sistema está mandando todas as entidades de responsável que o aluno tem cadastrado.  Se o aluno tiver cadastro de pai, mãe, responsável financeiro, responsável acadêmico e responsável do aluno ( Cadastro do ensino básico que permite cadastrar outros responsáveis para o aluno ), o sistema manda todas essas entidades para o filho sem fila, não é possível definir que quero encaminhar apenas o cadastro de pai e mãe.  O sistema precisa de um recurso onde o usuário possa definir qual entidade responsável será encaminhada. |
| **Solução/Implementação:** | - O sistema foi alterado para possibilitar a escolha de quais responsáveis do aluno devem ser enviados para a Saída Inteligente.  - As telas de Saída Inteligente (Exportar Aluno e Sincronizar Aluno) foram alteradas para sempre sugerir as mesmas configurações utilizadas na execução anterior. |
