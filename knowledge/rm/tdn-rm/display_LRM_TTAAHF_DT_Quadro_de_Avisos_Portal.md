# Quadro de avisos - Portal

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *TOTVS Gestão Educacional* |
| **Módulo:** | *Educacional* |
| **Função:** | *Quadro de avisos - Portal* |
| **Situação/Requisito:** | *Ao acessar o portal, caso o sistema esteja parametrizado para redirecionar o usuário para o quadro de avisos, e ele não possua permissão para acessar a funcionalidade, é lançada uma exceção.* |
| **Solução/Implementação:** | *Ajustes no redirecionamento ao quadro de avisos no portal. Caso o sistema esteja parametrizado para redirecionar o usuário para o quadro de avisos, e ele não possua permissão para acessar a funcionalidade, será emitida uma mensagem informando sobre a falta de permissão e o sistema se comportará como se não houvesse a parametrização de redirecionamento.* |
