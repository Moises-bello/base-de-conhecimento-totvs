![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30280354429335) Tempo aproximado para leitura: **00:05:00 min****Ocorrência****Ao tentar incluir, de forma paliativa, as informações de plano de saúde/odontológico no evento S-1210 (Pagamentos de Rendimentos do Trabalho) manualmente no TAF é apresentada a mensagem de erro abaixo:****Help:**VLDDATA\_POST  
**Problema:** Não é permitido informar dados sem referência superior. O formulário Info. Relac. Retenção Na Fonte (MODEL\_T8E) precisa ser preenchido.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30309946041751)  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF - Todas as versões.  
  
**Solução**Para corrigir o erro:  
  
**1.** Acesse a rotina Pgto. Rend. Trab. no TAF  
**Caminho: Atualizações > Eventos eSocial > Periódicos > Pgto. Rend. Trab.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30309946046231)  
  
2.** Selecione o registro e entre como **Alterar**:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30309944574487)  
  
**3.** Realize o preenchimento da aba **Informações IRRF > Plano de Saúde Coletivo**com as devidas informações:  
**![](https://centraldeatendimento.totvs.com/hc/article_attachments/30309946048663)  
  
4.** Após isso, entre para Editar o campo **Dt. Laudo** (o campo deve ficar em azul para preenchimento) e dê um ***Enter*** no campo:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30309944576407)  
  
**5.** Com os procedimentos acima realizados, tente salvar novamente o registro.  
 **Segue GIF com procedimento completo:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30321670676247)** **IMPORTANTE: O processo já está sendo analisado internamente para que não seja necessária tal ação no campo Dt. Laudo.
