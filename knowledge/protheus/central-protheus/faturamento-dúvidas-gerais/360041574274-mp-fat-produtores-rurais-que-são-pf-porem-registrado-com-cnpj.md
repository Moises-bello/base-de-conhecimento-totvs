**Dúvida**

Como deverá ser considerado um Produtor Rural pessoa física que no Estado de SP é obrigado a se inscrever no Cadastro Geral de Contribuintes

**Ambiente**  
Protheus – Faturamento – A partir da versão 12  
  
**Solução**

É possível no sistema Protheus cadastrar um cliente (Pessoa Física) com o numero de CNPJ.

Para este procedimento é necessário configurar, conforme as orientações abaixo:

![produtor_rural.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360056392013/produtor_rural.png)

- Campo: A1\_PESSOA = Física  
- Campo: A1\_TIPO = Produtor Rural

Para que o campo: A1\_CGC seja habilitado, é necessário que o A1\_EST seja para o estado de SP para que possa mencionar o CNPJ.

Obs: Este procedimento foi validado pela Consultoria Totvs.
