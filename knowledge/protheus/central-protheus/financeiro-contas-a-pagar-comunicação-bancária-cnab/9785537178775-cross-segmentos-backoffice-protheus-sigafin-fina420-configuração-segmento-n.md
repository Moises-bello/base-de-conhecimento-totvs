**Dúvida**As posições podem ser diferentes dentro do mesmo segmento N, depende do tipo do tributo, como realizar este tipo de configuração?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA420 - Todas as versões  
  
**Solução**Sugerimos ajustar o layout de CNAB modelo 2, como exemplo abaixo, de forma a criar uma linha de detalhes de acordo com o  modelo dentro do segmento, dessa forma poderá usar a posição dos campos conforme descrito no manual bancário**.  
  
![](https://totvssuporte.zendesk.com/attachments/token/uOoZVqQ2YKneSQe1npjpx9dsJ/?name=inline886632306.png)**

Sendo assim, ao utilizar o modelo correspondente na montagem do borderô, o arquivo será gerado corretamente conforme configuração.
