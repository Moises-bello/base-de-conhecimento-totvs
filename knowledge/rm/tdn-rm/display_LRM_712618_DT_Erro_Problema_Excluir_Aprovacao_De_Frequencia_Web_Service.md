# FREQUÊNCIA DIÁRIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Exclusão de frequência diária* |
| **Situação/Requisito:** | *Ao solicitar a exclusão de um registro de aprovação de frequência diária através do webservice wsDataServer, o sistema carrega a primeira tabela do dataset como a tabela padrão, porém devido essa tabela não representar a tabela física e principal, ela não possui chave primária, o que faz com que a chamada não exclua o registro.* |
| **Solução/Implementação:** | *Foi realizada otimização da funcionalidade de exclusão de registro de aprovação de frequência, através do webservice wsDataServer, de forma que o sistema consiga carregar o registro e excluí-lo com sucesso.* |
