# MATRÍCULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Validação de inadimplência* |
| **Situação/Requisito:** | *Ao realizar matrícula online, quando parametrizado, o sistema faz validação de inadimplência com base no status e na data de vencimento do lançamento financeiro e não com base nas informações do boleto. Assim, pode ocorrer de um lançamento ter sido baixado parcialmente e o outro boleto ainda estar a vencer e mesmo assim, o sistema impedir a matrícula do aluno.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de matrícula online, de forma que a inadimplência será verificada a partir da data de vencimento do boleto.* |
