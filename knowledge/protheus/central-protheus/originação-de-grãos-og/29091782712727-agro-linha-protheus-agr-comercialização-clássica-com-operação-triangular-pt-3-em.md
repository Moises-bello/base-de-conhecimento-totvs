![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29091823889687) Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Como é realizado um processo de **Comercialização Clássica com Operação Triangular PT 3 em Gestão Agroindústria - Manutenção**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução  
Dados Gerais:**

| Produto: | TOTVS Agro Beneficiamento |
| --- | --- |

| Linha de Produto: | Linha Protheus |
| Segmento: | Agroindústria |
| Módulo: | Gestão de Agronegócio |
| Função: | OGA250 - Romaneio com pesagem |
| Ticket: |  |
| Requisito/Story/Issue (informe o requisito relacionado) : | DAGROCCO-3902 |

**Requisito/Requisito:**Ao atualizar o romaneio criar o item na aba comercialização para a remessa da operação triangular, salvar o campo subtipo como **46 -  (S) Remessa por Venda a Ordem**.  
  
**Solução:**Realizado a implementação ao atualizar o romaneio, adicionando mais um item na aba comercialização para a remessa da operação triangular, gravando a entidade de entrega, a TES de estoque e o subtipo **46 -  (S) Remessa por Venda a Ordem**.
