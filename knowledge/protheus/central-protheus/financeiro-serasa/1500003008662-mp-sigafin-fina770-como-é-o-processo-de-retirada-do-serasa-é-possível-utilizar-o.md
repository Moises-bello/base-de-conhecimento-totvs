**Dúvida**  
Como é o processo de retirada do Serasa é possível utilizar o mesmo lote?  
  
**Ambiente**  
Microsiga Protheus - Financeiro - FINA770 - A partir da versão 12  
  
**Solução**  
Para enviar um arquivo de retirada ao Serasa deve ser gerado um novo lote, porém o que deve constar no mesmo é o ID do titulo o conteúdo do campo **FW9\_IDTITU** que já foi enviado.
