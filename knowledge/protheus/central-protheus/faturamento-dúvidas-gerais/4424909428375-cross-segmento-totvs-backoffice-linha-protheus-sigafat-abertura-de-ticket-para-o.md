![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como efetuar a abertura de um ticket de atendimento para o módulo faturamento?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT- Todas as versões  
  
**Solução**

1- Se o acesso for efetuado via portal do cliente, acesse o vídeo how to sobre a abertura: <https://www.youtube.com/watch?v=5OjB27iNbIo>

Documentação:

<https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500004556961-EC-Portal-Abrir-e-consultar-ticket-com-o-cat%C3%A1logo-de-servi%C3%A7os-TOTVS-Suporte-T%C3%A9cnico> ![portal.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4402266272919/portal.png)

![abertura_de_ticket.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4402262264087/abertura_de_ticket.png)

2- Se acesso for efetuado pela Carolina, você pode informar se é uma dúvida ou consulta, a dúvida e o módulo que deseja o atendimento. Após o atendimento, você pode continuar o atendimento ou falar como um analista, escolhendo a segunda opção, o sistema irá direcionar para o atendimento via chat.

![20220214_134314.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4424899324695/20220214_134314.gif)

Se precisar efetuar um contato com outro módulo basta digitar trocar módulo e fazer a pergunta:![20220214_134553.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4424915302167/20220214_134553.gif)

Observação: As opções de abertura de ticket são para todos os módulos do Protheus.
