**Dúvida**

Qual é o relacionamento de Campos Protheus X GFE (Cliente X Emitente) - SA1 X GW1 - Cliente Entrega?  
  
**Ambiente**

Microsiga Protheus – a partir da release 12.1.17.  
  
**Solução**Segue abaixo o relacionamento de campos:

1.Endereço Entrega   
**A1\_ENTEDENT - GW1\_ENTEND**

2.Bairro Entrega  
**A1\_BAIRROE - GW1\_ENTBAI**

3.CEP Entrega  
**A1\_CEPE - GW1\_ENTCEP**

4.Nr Cid Entrega  
**A1\_CODMUNE - GW1\_ENTNRC**

5.UF Entrega  
**A1\_ESTE - GW1\_ENTUF**
