| **Situação/Requisito:** | *Ao imprimir o relatório de contratos, quando é utilizado o gerador antigo, os relatórios são filtrados corretamente pelo tipo "tesouraria", porém se marcada a opção para utilizar o novo gerador, ao pesquisar o relatório, o sistema exibe todos os relatórios do educacional, de todos os tipos.* |
| **Solução/Implementação:** | *Foi feito o ajuste no filtro dos relatórios para que carregue sempre o tipo "tesouraria", independente se é o antigo ou novo gerador de relatórios.* |
