![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329822999) Tempo aproximado para leitura: **00:05:00 min****Dúvida**Como testar conexão dos ambientes existentes no DBACCESS.  
  
**Ambiente**RH - Linha Protheus - TAF - eSocial -  TOTVS Automação Fiscal - Todas as versões  
  
**Solução**

1. Acesse a pasta do DBACCESS e execute o arquivo DBMONITOR.EXE:  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329824535)
2. Certifique que a porta configura é a mesma no seu arquivo de configuração:  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329833239)![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329837719)
3. Clica na aba assistentes:  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329839255)
4. Selecione o banco de dados  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329841431)
5. Digite o nome da conexão com o seu banco de dados  
     
   Exemplo:  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679329845527)
6. Clique em Ok e verifique se está conectando no seu banco de dados:  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/25679774131735)  
     
   1. Caso dê algum problema, você pode clicar na aba mensagem para certificar o motivo da não conexão com o seu banco de dados.
