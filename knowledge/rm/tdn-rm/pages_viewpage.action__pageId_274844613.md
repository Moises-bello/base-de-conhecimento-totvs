# Ajuste no Arquivo de Envio de Autorização TISS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao solicitar autorização TISS, o sistema gerava o valor 99999 para o CBO 60087 (Cirurgião geral), no arquivo de envio. |
| **Solução:** | Sistema ajustado para gerar o código correto, ao solicitar autorização TISS, quando o CBO for 60087 (Cirurgião geral). |
