# CERTIFICADO DIGITAL

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Controladoria |
| **Função:** | Parametrização de certificado digital |
| **Situação/Requisito:** | Alterar uso do certificado digital na emissão de documentos eletrônicos para buscar os dados a partir do cadastro de certificado digital. |
| **Solução/Implementação:** | **Cadastrar certificado digital**  Acessar Totvs Gestão Fiscal no menu Cadastros (Globais) | Mais | Certificado Digital. Execute o Processo "Importar certificado digital" para importar certificado digital.      **Parametrização do certificado na filial**  Após efetuar cadastro, acessar Totvs Gestão de Estoque, Compras e Faturamento e parametrizar o certificado digital importado anteriormente. Para tanto acessar parametrizador em Ambiente/Parâmetros/Gestão de Estoque, Compras e Faturamento/Integrações/Fiscal/Dados Fiscais.      Selecione os parâmetros por filial e escolha a filial desejada para configurar certificado digital.      Acessar menu "Certificado digital 1/2" (para NF-e).      Acessar menu "Certificado digital 2/2" (para CT-e).      A partir desta parametrização sistema conseguirá buscar no servidor o certificado digital. |
