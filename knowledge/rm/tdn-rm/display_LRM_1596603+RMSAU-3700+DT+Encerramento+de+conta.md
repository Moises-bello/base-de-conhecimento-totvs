# Encerramento de conta

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Encerramento de conta |
| **Situação:** | Cliente informa que ao reprocessar uma conta que foi faturada tendo uma Taxa / Serviço com quantidade 0 devido à Auditoria Pré-Glosa, o sistema apresenta erro ao tentar encerrar a conta. |
| **Solução:** | Removida a validação que impedia o encerramento da conta quando a quantidade de Taxa / Serviço fosse zero para contas já faturadas. |
