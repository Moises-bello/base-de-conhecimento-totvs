Este cadastro tem como função registrar os ocupantes de cada subunidade (casa, apartamento ou galpão) e indicar qual será o **responsável financeiro** no qual será gerado o título de cobrança da quota do condomínio.   
Na tela de cadastro possui os seguintes campos:

Este cadastro só deve ser preenchido caso não haja integração com o módulo de aluguel no cadastro do empreendimento, pois se existir integração, o o sistema buscará o ocupante no contrato de locação.

* **Empreendimento:** Campo no qual será informado qual empreendimento que o Ocupante está associado;
* **Unidade:** Campo no qual será informado qual unidade que o Ocupante está associado;
* **Subunidade:** Campo no qual será informado qual subunidade que o Ocupante está associado;
* **Descrição**: Campo que mostra a descrição da subunidade;
* **Id Ocupante:** Id do Ocupante no qual é preenchido automaticamente.
* **Código Ocupante:** Informa qual Cliente/Fornecedor que o Ocupante está associado;
* **Data Inicial:** Data de inicio que o Ocupante está associado a subunidade informada anteriormente, campo obrigatório;
* **Data Final:** Data de saída do Ocupante da subunidade informada anteriormente;
* **Responsável Financeiro:** Ao marcar essa opção, é informado que o Ocupante é o Responsável Financeiro. As cobranças de Condomínio da subunidade serão gerado no nome do Ocupante que contém essa opção marcada.
