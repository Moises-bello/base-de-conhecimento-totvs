# ARREDONDAMENTO DE ENVELOPE DE FUNCIONÁRIO COM RESCISÃO CADASTRADA PARA O PRÓXIMO MÊS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Folha Mensal |
| **Situação/Requisito:** | Quando o funcionário possui uma rescisão cadastrada para o próximo mês, no cálculo do envelope da competência atual, se o líquido fica negativo não está sendo lançado o evento de arredondamento provento. |
| **Solução/Implementação:** | Ajuste no lançamento do evento de arredondamento provento para funcionários demitidos no próximo mês, para consistir somente se a rescisão já estiver calculada. |
