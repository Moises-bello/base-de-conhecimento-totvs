## **01. VISÃO GERAL**

Veja como configurar a permissão de acesso a campos sensíveis.

## **02. EXEMPLO DE UTILIZAÇÃO**

A segurança de permissão de acesso à campos sensíveis é configurada em cada perfil através do checkbox 'Permitir acesso à campos sensíveis' presente na aba Acesso a Campos.

Ao desmarcar o checkbox todos os usuários associados a este perfil não terão mais acesso de consulta nem de alteração aos campos que estiverem configurados como **sensíveis** no cadastro de .

O bloqueio de acesso a dados sensíveis segue o mesmo comportamento do controle de .

Importante

A funcionalidade de **Permitir acesso à campos sensíveis** é um facilitador para as configurações de segurança de dados no RM. O gerador de relatórios Delphi não trabalha em conjunto com essa funcionalidade. Para atingir um resultado similar devemos configurar as restrições de [acesso a campos](https://tdn.totvs.com/x/HJO2C). É importante salientar que as restrições de acesso a campos são válidas somente para os campos da base utilizados nos relatórios Delphi.
