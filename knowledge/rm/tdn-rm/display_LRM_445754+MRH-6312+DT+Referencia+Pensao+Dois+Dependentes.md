# REFERÊNCIA DO EVENTO DE PENSÃO COM MAIS DE UM DEPENDENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Pensão Alimentícia |
| **Situação/Requisito:** | Ao realizar o cálculo de pensão alimentícia para mais de um dependente, cada um com percentual diferente sobre o ordenado bruto, o valor da pensão é calculado corretamente, porém lança o evento para o envelope com a referência incorreta. |
| **Solução/Implementação:** | Ajuste na referência do evento de pensão alimentícia para informar o somatório do percentual de todos os dependentes de pensão. |
| **Tickets relacionados:** | MRH-6312 |
