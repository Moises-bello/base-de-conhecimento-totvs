# Exibição de Porcentagem de faltas na tela de Faltas do novo portal do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Porcentagem de faltas |
| **Situação/Requisito:** | Ao possuir na lista de faltas uma disciplina que possua a situação de matrícula que não esteja com o parâmetro "É uma disciplina em curso" marcado, a coluna "Percentual" não é calculada. |
| **Solução/Implementação:** | Foi realizado uma alteração para que seja calculado a Porcentagem de faltas de todas as disciplinas que estejam sendo listadas na tela de Faltas do novo portal do aluno. Independente da sua situação de matrícula. |
