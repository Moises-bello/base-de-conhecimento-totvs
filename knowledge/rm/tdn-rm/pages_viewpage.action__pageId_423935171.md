# VALOR DE BAIXA COM BOLSA CONDICIONAL E DESCONTO POR ANTECIPAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Baixa de lançamentos financeiros |
| **Situação/Requisito:** | Anteriormente, ao alterar o valor baixado para menor, como o sistema joga o valor de diferença para desconto, isso influencia no cálculo do valor de bolsa condicional pois a fórmula leva em consideração o valor de desconto do lançamento. Isso fazia com que o valor baixado fosse alterado novamente após o cálculo da fórmula da bolsa. |
| **Solução/Implementação:** | Ajuste para seleção do valor de desconto do lançamento ao invés do valor de desconto da baixa para que o valor calculado para a bolsa condicional permaneça o mesmo. |
