| **Função:** | Fluxo de Caixa |
| **Situação/Requisito:** | Após gerar uma fatura para um valor parcial em aberto no lançamento, somente o valor faturado é considerado no fluxo de caixa. O sistema deve considerar o valor baixado parcial e o valor do vencimento de fatura no Fluxo de Caixa. |
| **Solução/Implementação:** | Foi realizado um tratamento na geração do fluxo de caixa para que o sistema considere o valor parcialmente faturado e faturado. |
