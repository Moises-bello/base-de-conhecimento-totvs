![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26330940024855) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como configurar o Sistema para o calculo proporcional das contribuições sindicais?  
  
**Ambiente**TOTVS RH - TOTVS (RH Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Para o calculo proporcional das contribuições sindicais deve ser ajustado o mnemônico **P\_PROPCONT**.

Acesse no modulo de gestão de pessoal a rotina Mnemônicos em **Atualizações > Definições Cálculo > Mnemônicos (GPEA300)**, ajuste o conteúdo conforme abaixo:
