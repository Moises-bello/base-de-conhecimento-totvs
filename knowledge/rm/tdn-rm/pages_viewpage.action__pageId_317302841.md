# Exibição de Listagem de Disciplinas no processo de Rematrícula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Rematrícula - Listagem de Disciplinas |
| **Situação/Requisito:** | Listagem das disciplinas matriculadas no processo de Rematrícula |
| **Solução/Implementação:** | Descrição da história criada para solução  Como: Aluno ou Responsável pelo Aluno Eu preciso: Visualizar as disciplinas matriculadas Para conseguir: Ter a informação de quais disciplinas o aluno fará no próximo período letivo.  Critérios de aceitação: • No passo anterior à seleção da forma de pagamento e contrato, devem ser listadas as disciplinas que o aluno foi matriculado durante a rematrícula. • As disciplinas a serem listadas são aquelas vinculadas ao período letivo da matrícula. • Devem ser exibidas as informações de Código da disciplina, Nome da disciplina, Período (Ciclo/Ano), Situação de matrícula e turma. Atenção para a coluna de turma, pois essa deve ser exibida somente se o parâmetro para exibição estiver marcado nos parâmetros do Portal. |
