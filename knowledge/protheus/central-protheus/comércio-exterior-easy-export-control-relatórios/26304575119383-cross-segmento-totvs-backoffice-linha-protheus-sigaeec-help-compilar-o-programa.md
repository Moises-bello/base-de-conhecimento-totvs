![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26304594326295) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Ao tentar gerar o Relatório dentro do **SIGAEEC** o sistema está retornando a seguinte mensagem:  
**O documento/relatório não pode ser impresso pois o ambiente não está preparado para a geração. Para a geração, é necessário compilar o programa :EEC\*\*\*\*.****![](https://centraldeatendimento.totvs.com/hc/article_attachments/26305401313431)****Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - a partir da versão 12  
  
**Solução**Neste caso, para que a mensagem não seja apresentada, será necessário compilar o Rdmake em questão dentro do Ambiente.  
Os Rdmakes poderão ser obtidos dentro do Pacote Acumulado do Comex.
