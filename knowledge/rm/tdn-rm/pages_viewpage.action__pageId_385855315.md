# ANÁLISE CURRICULAR DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Análise curricular do aluno |
| **Situação/Requisito:** | Ao acessar a análise curricular de um aluno, pode ocorrer um erro não tratado caso o aluno esteja matriculado em uma disciplina equivalente a alguma das disciplinas optativas. |
| **Solução/Implementação:** | Foi realizada otimização da análise curricular, permitindo ao sistema, exibir disciplinas em curso que possuam equivalência para disciplinas optativas. |
