Permite criar versões de cadastro da questões em idiomas diferentes do cadastro original. Para isto é informado o texto do enunciado da questão e as opções de respostas para questões do tipo Exclusiva e múltipla no idioma selecionado ou o texto da resposta para questões abertas.

**Exemplo**  
*Versão da questão no idioma inglês*

Área: Sciences Nome da matéria: Biology Enunciado original: Áreas da Biologia: Novo enunciado:Areas of Biology: Idioma: Inglês

Opções de resposta

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| Cod. Opção | Correta | % Pontos | Novo texto | Texto original |
| A | T | 50 | Genetic | Genética |
| B | T | 50 | Ecology | Ecologia |
| C | F | 0 | Geography | Geografia |
| D | F | 0 | Radiology | Radiologia |

* Quando a questão for tipo aberta haverá o campo para informar a resposta no idioma selecionado

Observação

Para inclusão de uma versão da questão, deverá existir uma versão da área e matéria no mesmo idioma.
