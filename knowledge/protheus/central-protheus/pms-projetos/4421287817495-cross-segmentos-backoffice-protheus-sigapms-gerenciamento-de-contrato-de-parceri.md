Para inclusão, seguir o procedimento:

Clicado em "**Execução**", selecione a opção "**Gerenciamento Contrato de Parceria**". O sistema apresenta a tela para informação dos dados do contrato de parceria a ser atribuído à execução do projeto

Na parte superior desta tela, estão disponíveis as seguintes opções:

1. •  **Pesquisar**: Apresenta a ferramenta de pesquisa de projetos.  
   •  **Visualizar**: Quando selecionado o projeto, apresenta seus detalhes, conforme apresentado no Gerenciamento de Projetos  
   •  **Incluir**: Apresenta a tela de Cadastro de **Contrato de Parcerias** para informação dos dados.  
   •  **Alterar**: Apresenta a tela do contrato de parceria cadastrado para alteração.  
   •  **Excluir**: Apresenta a tela de contrato de parceria cadastrado para verificação dos dados e confirmação da exclusão.  
   •  **Sair**: Sai da tela de gerenciamento de contratos de parceria, retornando ao browser da rotina.
2. Informe os dados solicitados para cada uma das opções acima, conforme orientação dos help de campo.
3. Preenchidos ou visualizados os dados, confira-os e confirme.

OBS: Para utilizar um produto em um **Contrato de Parceria**preencha com **SIM**o campo **Contrato**do cadastro de produtos.
