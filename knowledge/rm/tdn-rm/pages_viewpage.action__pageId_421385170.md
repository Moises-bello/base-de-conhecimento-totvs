**Observação**

O acesso a parâmetros do projeto é permitido ou restringido através de permissão de acesso.

Para definir as permissões de acesso vá em Cadastros -> Segurança -> Perfis, abra o perfil que o usuário pertence, na aba Acesso a Menus acione Opções -> Parâmetros -> Totvs Obras e Projetos -> Projetos, selecione uma das opções e clique sobre "Permitir Acesso" ou "Proibir Acesso", as opções são as listadas abaixo:

Cálculo, Exibição, Cronograma, Campos Livres, Log, Pert/alocação de Recurso, Insumos, Contratos, Apropriação, Gestão de Risco, Integração, Planilha de Serviço, Planilha de Atividade, Projeto.

Isso possibilita que o acesso seja permitido ou negado para cada pasta disponível em Parâmetros do Projeto.

Para projetos globais, algumas opções ficam desativadas. As opções desativadas não alteram o funcionamento dos projetos globais.
