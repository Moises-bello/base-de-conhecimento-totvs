# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Gerar Contabilização por competência* |
| **Situação/Requisito:** | *Ao gerar contabilização utilizando o novo modelo de contabilização para quando o contrato possui mais de um serviço e existe aumento em um dos serviços, o evento contábil configurado para aplicar no contrato não calcula os valores corretamente.* |
| **Solução/Implementação:** | *Foi realizada otimização do novo modelo de contabilização para que os evento de contabilização para aumento e redução de contrato suportem alterações de valores em parte dos serviços associados ao contrato do aluno.* |
