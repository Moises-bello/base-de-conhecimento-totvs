**Dúvida** Como corrigir o Help AVG0000428 - ' Data do embarque deste item menor que a data de hoje' ?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4403370412951/mceclip0.png)  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.

**Solução**

A mensagem é apresentada quando a data do embarque é menor que a database da inclusão da PLI. Alltere a data da PLI ou a data do Embarque na Purchase Order.
