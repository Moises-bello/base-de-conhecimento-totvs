# PENSÃO ALIMENTÍCIA DE FÉRIAS NA RESCISÃO - CC 319

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Pensão Alimentícia* |
| **Situação/Requisito:** | *Valor da pensão sobre as férias na rescisão, CC 319, está ficando incorreto quando existem férias no envelope anterior, com data de pagamento no mês caixa anterior à competência atual.* |
| **Solução/Implementação:** | *Ajuste no cálculo do CC 319 - Pensão Alimentícia de Férias na Rescisão, para somente considerar base de IRRF Férias de outros periodos, se a data de pagamento for no mês caixa corrente.* |
| **Chamados   relacionados:** | *TUSBYA, TUYIPW* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
