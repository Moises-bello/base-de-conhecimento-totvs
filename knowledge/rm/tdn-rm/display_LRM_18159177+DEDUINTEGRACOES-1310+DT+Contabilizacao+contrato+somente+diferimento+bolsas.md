# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Geração de Contabilização de Contrato |
| **Situação/Requisito:** | Para tratar a questão de financiamentos a contabilização não deve realizar a apropriação da bolsa. Foram feitas alterações no processo que não permite a geração da contabilização do contrato caso não seja encontradas partidas contábeis do evento utilizado. |
| **Solução/Implementação:** | Ajustes para que na contabilização do contrato, quando houver aumento ou cancelamento de valor de contrato e não for encontrada partidas contábeis do evento utilizado, não seja barrada a contabilização e seja realizada somente o diferimento da bolsa. |
