**Dúvida**Como cadastrar um orçamento?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA020 - Todas as versões  
  
**Solução**A rotina **FINA020** Orçamentos permite um controle orçamentário previsto por período, possibilitando planejar financeiramente as operações através das naturezas cadastradas.

|  |  |
| --- | --- |
| Natureza | 201.102 - (Despesas com viagens para o projeto) |
| Ano | 2020 |
| Janeiro | 1.000 |
| Fevereiro | 1.300 |
| Março | 1.000 |
| Moeda | 1 |
| Centro de Custo | 000001 - Venda |

Os resultados são demostrados nos relatórios Mapa Comparativo - Valores Orçados X Reais (FINR720)/ Mapa Comparativo - Valores Orçados X Reais Ano (FINR730)

Para incluir um orçamento:  
1.Clicar em Incluir;

2. Preencher os campos de Ano, Natureza, mês (Janeiro à Dezembro), Moeda e Centro de Custo, conforme o exemplo acima;

3. Confirma a inclusão dos dados.
