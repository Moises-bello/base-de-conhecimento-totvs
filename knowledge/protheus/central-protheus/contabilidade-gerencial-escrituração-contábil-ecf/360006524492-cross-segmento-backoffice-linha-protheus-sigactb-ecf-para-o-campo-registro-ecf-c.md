**Dúvida**

Erro apresentado ao  realizar a integração com o TAF para gerar a ECF

O valor '**1**' informado na coluna 2 para o campo Registro ECF ( **CAT\_REGECF** ) somado ao valor '**16**' informado na coluna 3 para o campo Código Conta Referencial (**CAT\_CODCTA**) não existe na base de dados.   
   
 **Ambiente**  
Protheus – Contabilidade Gerencial  – A partir da versão 11.80
