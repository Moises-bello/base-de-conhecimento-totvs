**Dúvida**Como solucionar a 545 Rejeição: Falha no schema XML – versão informada na versaoDados do SOAPHeader diverge da versão da mensagem ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.

**Solução**A versão atual da NF-e é 4.0 para configurar a versão correta:

1. Acesse a rotina SPEDNFE ***através do menu Nf-e Sefaz Selecione em Transmissão ? 1- NFe***

![20220318_144039.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/32896644772247)

*4. Selecione Tipo de Nfe **1- Saída ou 2- Entrada, Filtra 2- Sem filtro***

![20220318_144702.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/32896644777495)

*5. Acesse o menu **Outras Ações -> Parâmetros -> Nfe -> versão de NF-e 4.0***

![20220318_145102.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/32896644780567)
