# Cadastro de Itens Terceirizados para .NET

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Itens Terceirizados | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER e ORACLE |
| **Tabelas Utilizadas:** | ``` SZITEMTERC, SZITEMTERCPRECO ``` |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Realizada a migração do Cadastro Itens Terceirizados para a tecnologia .NET.

## Procedimento para Utilização

1. Acesse **Cadastro/Faturamento/Itens Terceirizados**.
2. Filtre para visualizar os itens.
3. Cadastre, edite e exclua itens e tabelas de preço para itens terceirizados.
