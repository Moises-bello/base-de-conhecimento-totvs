MEU RH - Como realizar o bloqueio de inclusão manual da marcação do ponto?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - MEU RH - todas as versões  
  
**Solução**  
1. Para realizar o bloqueio de inclusão para marcação do ponto manual, deve ser realizado através da rotina **TCFA006**, rotina de permissões no módulo 18 (**SIGATCF**).   
  
Acesse o menu **>Atualizações > Configurações >Usuários >Permissões.**  
![b0UR3Xp3i9.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4422432649879)  
  
Caso não tenha a rotina configurada no menu, seguir o passo a passo do link abaixo para criação:  
[RH - Linha Protheus - MEU RH - Configuração de permissão de acesso as funcionalidades e menu do MEU RH](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360033892693-RH-Linha-Protheus-MEU-RH-Configura%C3%A7%C3%A3o-de-permiss%C3%A3o-de-acesso-as-funcionalidades-e-menu-do-MEU-RH?source=search)  
  
2. Ao acessar a rotina de permissões, selecione o usuário genérico e altere a permissão "**Inclusão batida informada**".  
  
**OBS:** Este usuário genérico é vinculado no cadastro do participante, ou seja, é importante verificar qual usuário esta sendo alterado para surtir efeito quando o trabalhador acessar o MEU RH.  
![bTCyHdVvXx.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4422424892311)  
  
3. Após configurado a permissão, quando o trabalhador acessar o espelho de ponto no MEU RH não irá existir a opção para incluir batidas manual.  
![mkXwtvsnCd.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4422440961943)
