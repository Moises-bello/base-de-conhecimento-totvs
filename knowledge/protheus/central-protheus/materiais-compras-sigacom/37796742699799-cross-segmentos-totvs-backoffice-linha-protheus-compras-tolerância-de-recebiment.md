**Dúvida**

Existe bloqueio de tolerância de Recebimento para documentos Originados do Sigaeic?

**Ambiente**

Documentos originados do Easy Import Control (SIGAEIC) não são submetidos ao processo de tolerância de recebimento, conforme regra de negócio definida para documentos integrados por este processo.

Observação: O campo D1\_TEC é preenchido nos documentos gerados pelo SIGAEIC.

Se houver o bloqueio, verifique o uso do campo D1\_TEC.
