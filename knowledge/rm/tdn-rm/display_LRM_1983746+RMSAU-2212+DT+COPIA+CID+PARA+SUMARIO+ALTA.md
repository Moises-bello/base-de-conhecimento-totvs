# Copia CID Provisório para o Sumário de Alta

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário Eletrônico |
| **Situação/Requisito:** | Os dados contidos no campo "CID" da aba Anamnese/Exame Físico sejam copiados para a aba "Sumário de Alta" do prontuário quando o atendimento for feito por uma unidade de atendimento de urgência. |
| **Solução/Implementação:** | Cid Provisário copiado automaticamente para o CID do Sumário de Alta no momento do seu lançamento. |
| **Parâmetros:** | SZUNIDATEND.COPIACIDSUMALTA |
