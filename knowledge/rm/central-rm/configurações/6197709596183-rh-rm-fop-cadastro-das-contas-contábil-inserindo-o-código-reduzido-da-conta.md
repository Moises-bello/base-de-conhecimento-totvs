![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como realizar o cadastro das contas contábeis, inserindo um código de conta reduzido?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar o cadastro das contas contábeis com código reduzido, é importante compreender que na folha o sistema respeita a máscara do centro de custo que foi parametrizada, mas no Gestão Contábil. Sendo assim deverá acessar a aba **Configurações |** **Parametrizador | Folha de Pagamento | Integrações | Plano de contas**:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10447312714007)  
  
Marcando a flag **Usa código reduzido**, o sistema acatará as necessidades  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10447355976599)  
  
**Exemplo**  
Código Centro de custo 023000  
Reduzido 230
