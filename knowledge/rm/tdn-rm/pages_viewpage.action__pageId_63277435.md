| **Introdução**  *Este documento tem como objetivo orientar o cadastramento de uma nova coligada e a inclusão de uma licença de uso para a mesma.* |
|  |
| **Desenvolvimento/Procedimento**  1. Incluir a Coligada  ***Acesse: Cadastro / Coligada***    2. Clicar em Novo  Preencher as informações corretamente.    **Obs.: Para versões iguais ou superiores à versão 11.52, não se faz necessário aplicar os procedimentos abaixo, pois a inclusão de licença de uso é automática.**    3. Incluir Nova Licença de Uso  · Na janela de coligadas marque a coligada desejada e acesse Processo / Incluir Nova Licença de Uso.    · Click em OK.    Após isto a licença será concedida a coligada selecionada.
