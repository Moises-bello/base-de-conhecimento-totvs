Este recurso é utilizado para atualizar um mesmo campo em diversos registros diferentes. Ele economiza tempo e evita o trabalho de digitar N vezes a mesma informação.  
Através deste Processo é possível atualizar um campo para vários cadastros simultaneamente.

**Campo:** Selecione o campo que sofrerá alteração.

Os campos  disponíveis para atualização irão respeitar as parametrizações existentes para o cadastro de Produto na coligada logada. Acesse o link  para visualizar as configurações possíveis no cadastro de Produto.

**Valor:** Selecione o valor para o campo que sofrerá alteração, exemplo:  
Gostaria de atualizar uma determinada tabela de classificação de 5 produtos ao mesmo tempo em seu cadastro.  
O campo "Tipo"(tabela de classificação 1 do produto) será atualizado com o valor "001" para os 5 registros ao mesmo tempo.  
Basta selecionar os 5 produtos pela visão ,  acessar o menu "Processos -> Atualizar Múltiplos Registros", selecionar o campo "Tipo", informar o valor desejado e executar o processo.
