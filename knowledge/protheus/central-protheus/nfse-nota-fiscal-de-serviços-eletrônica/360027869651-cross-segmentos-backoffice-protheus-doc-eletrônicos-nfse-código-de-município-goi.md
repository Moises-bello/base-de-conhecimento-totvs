**Dúvida**A prefeitura de Goiânia usa códigos de municípios diferenciados, onde preencher no Protheus para transmissão da NFSe?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.  
  
**Solução**Use o campo A1\_OUTRMUN para informar o código do município do cliente.  
  
Consulte o código do município no link abaixo:  
<http://www2.goiania.go.gov.br/sistemas/sress/Docs/Municipio.zip>
