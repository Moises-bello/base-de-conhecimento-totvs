# GERENCIAMENTO DE TURMA/DISCIPLINA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Turma/Disciplina* |
| **Situação/Requisito:** | Ao associar uma turma gerenciada à sua respectiva gerencial, o sistema estava permitindo incorretamente associar uma gerenciada que tinha dia da semana diferente da gerencial (o horário e datas estavam iguais). |
| **Solução/Implementação:** | Ao associar uma turma gerenciada à sua respectiva gerencial, o sistema deverá validar se o horário das mesmas são iguais (coligada, dia da semana, data inicial e final, hora inicial e final).  A mesma validação deve ser feita para relação entre filiais diferente. |
