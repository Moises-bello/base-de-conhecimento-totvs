# Alta administrativa no encerramento da parcial

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | Unidades de Diagnostico | Lançamento na Conta do Paciente | |
| **Banco(s) de Dados:** | Oracle®, SQL Server® |

## Descrição

Alta administrativa no encerramento da parcial.

## Procedimento para Implantação

O sistema é atualizado logo após a aplicação do pacote de atualizações da versão 12.1.16.029 da biblioteca do RM Saúde.

## Procedimento para Utilização

       1.            Crie um atendimento externo

       2.            Finalize o atendimento

       3.            Em Elaboração de Contas Insira uma nova Parcial

       4.            Encerre o atendimento.

       6. É possível verificar que o sistema informa da necessidade de preenchimento do motivo do encerramento.

7. É possível verificar que ao preencher os motivo a mensagem não será mais exibida.
