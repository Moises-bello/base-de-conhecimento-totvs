# Ajuste na visualização da senha no painel de atendimentos eletivos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de atendimentos eletivos |
| **Situação:** | O sistema não apresentava o prefixo da unidade de atendimento, quando era marcado o filtro "Exibir senha de todas unidades", na aba registro de atendimento do painel de atendimentos eletivos. |
| **Solução:** | Realizado ajusta para apresentar corretamente o prefixo da unidade de atendimentos, quando marcamos o filtro "Exibir senha de todas unidades", na aba registro de atendimento do painel de atendimentos eletivos. |
