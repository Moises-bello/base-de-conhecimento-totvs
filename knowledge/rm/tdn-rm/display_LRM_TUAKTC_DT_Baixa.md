# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Baixa de lançamentos |
| **Situação/Requisito:** | Ao utilizar duas formas de pagamento para fazer uma baixa no valor total do mesmo lançamento através do Web Service, o lançamento está  ficando como parcialmente aberto e com um saldo no valor da primeira forma de pagamento. |
| **Solução/Implementação:** | Implementado novo Web Service para que possa ser executada a baixa conforme as varias opções disponíveis de baixa que o sistema oferece através do formulário de processo de baixa. |
