**Dúvida**Como habilitar o Antidumping no regime de tributação do SIGAEIC?  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Para  que seja disponibilizada a aba do Antidumping dentro do Regime de Tributação do Desembaraço, o parâmetro "**MV\_ANDUBIC"** deve estar habilitado "**.T.**" dentro do Configurador.

1-) Acesse o configurador **"SIGACFG"** e dentro das configurações dos Parâmetros filtre o "**MV\_ANDUBIC**". Após tal ação, habilite o mesmo para "**.T.**"
