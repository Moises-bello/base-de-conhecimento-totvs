# AFASTAMENTO POR SERVIÇO MILITAR DEVE INTERROMPER CONTAGEM DO PERIODO PARA CONCESSÃO DE FÉRIAS EM DOBRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Férias* |
| **Situação/Requisito:** | *Solicitação para que, durante o afastamento por Serviço Militar, seja interrompida a contagem do periodo limite para concessão das férias em dobro.* |
| **Solução/Implementação:** | *Incluir a opção de afastamento do tipo M - Serviço Militar, no parâmetro "Interrompe contagem do período para pagto.de férias em dobro nos afastamentos I - L - M - P - T", do Parametrizador, pasta Férias/Férias em Dobro.*  *Caso o parâmetro seja confirmado, durante o afastamento por Serviço Militar será interrompida a contagem do periodo limite para concessão das férias em dobro.* |
| **Chamados   relacionados:** | *TUQCAE, TUWDYS* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
