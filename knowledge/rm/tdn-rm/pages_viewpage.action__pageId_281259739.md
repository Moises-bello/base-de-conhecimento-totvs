# Ajuste no Processo de Encerramento da Conta

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Lançamento na Conta de Paciente |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu **Unidades de Diagnóstico/Lançamento na Conta de Paciente**, abrir o formulário, e encerrar uma conta, era exibida a seguinte mensagem: Falha no processo de encerramento da conta: Insufficient memory for this operation. |
| **Solução:** | Ajuste realizado no formulário para que encerre a conta, dentro do processo esperado. |
