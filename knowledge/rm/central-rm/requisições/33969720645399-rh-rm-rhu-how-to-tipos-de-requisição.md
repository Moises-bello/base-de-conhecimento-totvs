**Dúvida**  
Quais são os Tipos de Requisição padrão existentes no sistema e como cada tipo pode ser utilizado?   
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - Todas as versões  
  
**Solução**  
  
Os Tipos de Requisição padrão do sistema são:   
   
Aumento de Quadro  
Alteração de Dados Funcionais  
Desligamento  
Transferência   
Transferência com Alteração de Dados Funcionais   
Substituição   
Treinamento  
Abertura de Turma   
Transferência em Lote   
  
Para criar os Tipos de Requisição padrão, acesse Configurações | Tipos de Requisição | Processos | Acerto nos Tipos de Requisição ou acesse o menu executar e pesquise pelo processo **Acerto nos tipos de requisições**.
