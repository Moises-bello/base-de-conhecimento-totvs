# ENVIO DE MENSAGENS - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Envio de mensagens pelo portal* |
| **Situação/Requisito:** | *Ao enviar mensagens pelo portal, o sistema permite a seleção de alunos que não tenham código de acesso ao portal, porém ao enviar a mensagem, o sistema retorna um erro não tratado e não conclui o envio. Foi identificado que o erro é gerado ao tentar enviar a mensagem para alunos que não tenham código de acesso ao portal,* |
| **Solução/Implementação:** | *Para solução, foi feito uma alteração na lista de seleção dos alunos, para que não seja possível selecionar alunos sem código de acesso, assim o campo de seleção fica desabilitado para o(s) aluno(s) sem código de acesso. Foi adicionado junto ao título da lista de alunos a mensagem informando que alunos sem código não poderão ser selecionados.* |
