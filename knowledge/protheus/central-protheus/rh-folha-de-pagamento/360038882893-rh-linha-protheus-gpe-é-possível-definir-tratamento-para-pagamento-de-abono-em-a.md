**Dúvida**O Módulo 07 **(SIGAGPE)**, possui tratamento para o abono definido para pagamento em algumas convenções coletivas?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoas - Todas as versões  
  
**Solução**O módulo 07 **(SIGAGPE)** Não possui tratativa para pagamento de abono definido em convenções coletivas. Há opção de ser lançada manualmente uma verba sem id para cálculo em um dos roteiros disponíveis para realização do pagamento.

Para que seja realizado de forma automática a partir de um determinado percentual ou valor, é necessário realizar customização no roteiro de cálculo que será utilizado.
