# PROPORCIONALIZAÇÃO DE MÉDIA DE FÉRIAS POR FÓRMULA NOS EVENTOS DO TRCT

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cálculo de Média* |
| **Situação/Requisito:** | *Quando o evento de média de férias na rescisão é calculado por fórmula, não está fazendo a proporcionalização correta nos eventos do TRCT, CC's 329, 330 e 331.* |
| **Solução/Implementação:** | *Ajuste no cálculo da média de férias na rescisão, para efetuar a proporcionalização do valor calculado por fórmula, de acordo com os avos apurados nos eventos a serem emitidos no TRCT, CC 329 - FÉRIAS INDENIZADAS SOBRE AVISO PRÉVIO,  CC 330 - FÉRIAS PROPORCIONAIS SEM AVISO PRÉVIO e CC 331 - FÉRIAS VENCIDAS SEM AVISO PRÉVIO.* |
| **Conversores e Parâmetros:** |  |
| **Chamados relacionados:** | *TTFJD0* |
| **Requisito (ISSUE):** |  |
| **Versões/Release:** | *11.82.41* |
