![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32892207007767) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como carregar processos do padrão para novas filiais no sistema?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Para carregar os processos padrões do sistema quando o cadastro de períodos é exclusivo (00001, 00002, 00003 e 00004) ao cadastrar uma nova filial, após o cadastro da nova filial via Configurador, entre no sistema pelo módulo 07 SIGAGPE logado na nova filial criada.

Acessar na rotina de **Processos** em **Atualizações> Definições Cálculos> Processos**, o sistema irá criar os processos 00001, 00002, 00003 e 00004 para a nova filial: **![](https://centraldeatendimento.totvs.com/hc/article_attachments/13112823451031)**
