![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22686209816727) Tempo aproximado para leitura: **00:00:30** min **Dúvida**O sistema gera Cnab para roteiro VRF?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para geração do arquivo CNAB é necessário existir uma verba de líquido no cálculo realizado, e este cálculo seja referente ao roteiro desejado (roteiro, data de pagamento, verba de líquido). Não há por padrão uma verba específica de líquido para este roteiro, de modo que na geração ocorra cálculo de VRF, com verba de líquido e contrapartida.

Como alternativa, por padrão , existe a possibilidade de efetuar pagamentos extras dentro do roteiro de cálculo VEX.
