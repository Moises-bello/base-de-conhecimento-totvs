# IMPORTAÇÃO DE INSCRIÇÕES ANÔNIMAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Processo Seletivo* |
| **Função:** | *Importação de Inscrições Anônimas* |
| **Situação/Requisito:** | *O processo de importação de inscrições anônimas quando utilizava o processo seletivo do novo portal, o usuário que fazia a importação era posteriormente associado como usuário do aluno no momento da matrícula.* |
| **Solução/Implementação:** | *Ajuste ao importar a inscrição anônima quando se utiliza o novo portal do processo seletivo, para que ao executar este processo não vincule o usuário da importação no usuário do processo seletivo.* |
