# EXTRATO FINANCEIRO DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Extrato financeiro no portal do aluno. |
| **Situação/Requisito:** | Mesmo o Educacional sendo parametrizado para não exibir boletos que não estivessem registrados, o aluno tinha acesso a emissão destes boletos via portal. |
| **Solução/Implementação:** | Caso o Educacional esteja parametrizado para não exibir boletos que não estejam registrados, o aluno não terá acesso a emissão do boleto ou ao IPTE de boletos que não estiverem registro. Vale ressaltar que, se o sistema permitir o registro online, os boletos serão visualizados normalmente. |
