**12.1.24 - Disponibilizado relatório para impressão de boletos do Banco do Brasil.**

O relatório está disponível na pasta Objetos Gerenciais: FINREL0042 - Boleto Banco do brasil.

**12.1.24 - Implementado controle de orçamento de receita.**

Para controle do orçamento de receita foi disponibilizado tipos de documentos e parametrização para esse controle.

**12.1.24 - Default de evento contábil para contabilização de crédito de adiantamento.**

Criada opção de para inclusão de evento contábil para contabilização de baixa de crédito de adiantamento.

**12.1.24 - Melhoria no cadastro de Cliente /Fornecedor**  
Disponibilizada opção MEI - Micro Empreendedor Individual para Cliente/Fornecedor Pessoa Física.
