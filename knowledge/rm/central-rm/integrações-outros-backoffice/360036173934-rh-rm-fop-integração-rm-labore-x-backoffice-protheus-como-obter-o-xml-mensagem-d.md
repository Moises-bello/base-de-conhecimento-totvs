**Dúvida**Quando é apresentado erros na integração RM x Protheus, é necessário avaliarmos os XML's de comunicação entre ambos ERP's, porém, como obter o XML mensagem de Resposta e Transformada no Protheus?  
   
 **Ambiente**Protheus - A partir da versão 12.1  
   
**Solução**Para obter a mensagem/XML de resposta e transformada no Protheus, realize os passos abaixo:  
  
**01.**Acesse o Protheus no Programa inicial SIGACFG.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047322834/mceclip0.png)  
  
**02.**No módulo SIGACFG acesse Ambiente | Schedule | Schedule | EAI.  
  
**03.**Na tela de EAI clique na lupa em Transações, segue:  
  
![Transa__es.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/360047323234/Transa__es.jpg)  
  
Salve as duas mensagens:  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360047323334/mceclip1.png)  
  
Para consulta do manual de integração RM Labore x Protheus [clique Aqui](https://tdn.totvs.com/display/public/INT/Manual_Doc_Integracao_RMLabore_BackOfficeProtheus).
