**Pasta Identificação - Requisição de Alteração de Dados Funcionais**

Na pasta Identificação os seguintes dados devem ser informados:

**Número -** Gerado automaticamente e com valor único.

**Status -** Será apresentado logo após a abertura da requisição como "Pendente". Este campo será alterado à medida que a requisição for avançando no fluxo de aprovações assumindo os valores parametrizados e definidos para cada etapa. Para verificar a parametrização acesse: Configurações | Tipos de Requisições.

Os status que poderão ser definidos pelo fluxo de aprovação são "Em Andamento", "Aprovado" e "Reprovado". Os status "Suspenso" e "Cancelado" serão definidos conforme a utilização do processo "Suspender requisição " e "Cancelar Requisição" respectivamente.

O status "Concluído" será determinado quando o processo "Concluir requisição" for realizado através do menu "Efetivar Alteração de Dados Funcionais".

**Os status das requisições são representados pelas cores:**

Aprovada – cor verde

Cancelada – cor preta

Concluída – cor roxa

Em Andamento – cor amarela

Pendente – cor laranja

Reprovada – cor vermelha

Suspensa – cor azul

**Nome do Aprovador Atual -**Este campo não é editável e apresentará o nome do aprovador atual da requisição, ou seja, o responsável atual pela requisição, conforme definição do fluxo de aprovações.

**Conclusão -** Irá apresentar a data que a requisição foi concluída, ou seja, a data que foi realizada a efetivação da alteração de dados funcionais.

**Requisitante -** Somente podem ser selecionados chefes da coligada na qual o usuário do Totvs Gestão de Pessoas esteja logado. Esta informação poderá ser modificada enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado. Caso a requisição seja aberta pelo "Totvs RM Portal" este campo exibirá o nome do usuário logado não podendo ser modificado.

**Requisição Vinculada (PAI) -** Este campo não é editável e apresentará o número e nome da requisição PAI que gerou/motivou a alteração de dados funcionais.

**Funcionário -** Para vinculação na requisição de alteração de dados funcionais serão exibidos os funcionários subordinados ao requisitante (exceto ex-funcionários). Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer tenha sido cadastrado.

**Previsão -** Deverá ser informada a data prevista para a alteração de dados funcionais, não podendo receber um valor inferior à data atual (data do dia). Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado. Por definição o sistema sugere a data atual.

**Justificativa -** Ao solicitar uma alteração de dados funcionais deverá ser informada uma justificativa para tal solicitação. Este campo poderá ser alterado enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado.

**Dados atuais do funcionário** **Função de Origem -** Este campo não é editável e apresentará a função atual do funcionário selecionado.

**Tabela Salarial -** Será apresentada a tabela salarial em que o funcionário está vinculado. Nível Salarial de Origem Este campo não é editável e apresentará o nível salarial atual do funcionário selecionado.

**Faixa Salarial de Origem -** Este campo não é editável e apresentará a faixa salarial atual do funcionário selecionado.

**Salário de origem -** Este campo não é editável e apresentará o salário atual do funcionário selecionado.

**Proposta de alteração** **Função -** Após o preenchimento do campo "Funcionário", este campo ficará habilitado permitindo que seja selecionada a função proposta para a alteração dos dados do funcionário selecionado. Neste campo, serão exibidas apenas as funções ativas vinculadas à seção de lotação atual do funcionário se o sistema estiver configurado para utilizar controle de lotação por quadro de lotação (vaga ou verba). Caso contrário, TODAS as funções ativas cadastradas no sistema devem ser exibidas. Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado. No Totvs RM Portal enquanto a requisição estiver em andamento.

**Tabela Salarial -** Caso o Totvs Gestão de Pessoas esteja configurado para utilizar tabelas salariais, o sistema deverá buscar o nome da tabela associada à função do funcionário selecionado, e exibi-lo como valor padrão. Este campo não é editável.

**Nível e Faixa Salarial -** Após o preenchimento do campo "Função" e se o parâmetro "Considerar os salários das tabelas salariais" estiver marcado, serão apresentados os níveis e as faixas da tabela vinculada à seção/função ou ao quadro de lotação. Estes campos poderão ser alterados enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado. No Totvs RM Portal enquanto a requisição estiver em andamento.

**Salário/ Percentual -** Se o parâmetro "Considerar os salários das tabelas salariais" estiver marcado, e for informado o nível e faixa salarial, o campo salário é preenchido automaticamente. Caso contrário, pode ser informado um percentual de aumento a ser considerado nesta alteração de dados funcionais ou informar diretamente o salário proposto do funcionário. Considerando se está desmarcado o parâmetro "Não permitir alterar diretamente o salário", este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado no Totvs RM Portal enquanto a requisição estiver em andamento.

**Motivo de mudança de função -** Se a função proposta para o funcionário for diferente da função atual, deverá ser informado o motivo de mudança de função. Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado. No Totvs RM Portal, enquanto a requisição estiver em andamento.

**Motivo de mudança salarial -** Se o salário proposto para o funcionário for diferente do salário atual, deverá ser informado o motivo de mudança salarial. Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado no Totvs RM Portal, enquanto a requisição estiver em andamento.

**Gerar substituição -** Esta opção deverá ser marcada se for necessário manter o número de vagas disponíveis ao concluir esta requisição, em função das configurações definidas no controle de lotação. Este campo poderá ser alterado enquanto a requisição estiver pendente e desde que nenhum parecer esteja cadastrado no Totvs RM Portal, enquanto a requisição estiver em andamento.
