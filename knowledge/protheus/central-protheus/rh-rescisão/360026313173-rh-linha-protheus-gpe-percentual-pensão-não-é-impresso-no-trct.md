**Dúvida**Ao calcular rescisão com desconto de pensão e imprimir o TRCT, no campo 28 -Pensão Alim. (%) TRCT não é impresso o percentual da pensão cadastrado na rotina Beneficiários.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**No cadastro do Beneficiário verifique se a coluna % Term.Resc esta preenchida com SIM, pois é por este campo que o percentual irá para o TRCT:
