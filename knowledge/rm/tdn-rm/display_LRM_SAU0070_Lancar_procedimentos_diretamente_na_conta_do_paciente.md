# Lançando procedimentos diretamente na conta do paciente.

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | Todas. |
| **Ocorrência:** | Ao realizar a parametrização abaixo, ao criar um agendamento, o procedimento parametrizado irá ser lançado diretamente na conta de um paciente. |
| **Passo a passo:** | **1º Passo)** Acessar o sistema TOTVS; **2º Passo)** Acessar o módulo Saúde e acessar a o menu Opções -> Parâmetros -> Parâmetros Gerais    **3º** **Passo**) Na aba “Registro e Controle IV”, marque o parâmetro para lançar o honorário associado à atividade da agenda ao registrar o atendimento    **4º Passo)** Acesse o menu Cadastros -> Uso Geral -> Agendamento -> Atividades    **5º Passo)** No Cadastro da atividade, na aba “Serviços e Taxas”, associe um procedimento a atividade e selecione um convênio |
