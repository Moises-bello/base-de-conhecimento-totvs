# Exames Incluídos pelo Prontuário não Geram Guias de Atendimento

|  |  |
| --- | --- |
| **Produto: RMSAUDE - GESTÃO HOSPITALAR** |  |
| **Versões: 11.82.40** |  |
| **Ocorrência: Ao inserir exames pelo prontuario eletrônico o sistema não gera guias de atendimento** |  |
| **Passo a passo:**  **Ir no Menu Cadastros / Unidades de Diagnósticos / Exames e Serviços**  **Escolher o exame  que deseja que a guia saia na conta;**      **Em anexos você seleciona a opção Item de Debito;**    **Identifica a opção o item de debito com os dados:**   * **Tipo de Codigo;** * **Unidade de Faturamento;** * **Convenio;** * **Descrição;**   **Após salvar o Item de Debito o mesmo aparecera assim;**    **Após fazer o cadastro do Item de Debito iremos fazer um teste incluindo um exame através do Prontuario Eletrônico;**      **Após lançar o exame vamos na conta do paciente em dados de atendimento na aba Guias de autorização e veremos que a guia foi lançada com sucesso;**    **Veja que o sistema já inclui uma guia de SP/SADT e uma Guia de Solicitação SP/SADT** |  |
