# Ajuste na tela de movimentação do estoque

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Estoques |
| **Situação:** | Na tela de movimentação do estoque, o sistema exibia movimentações pertencentes à unidades de atendimento, que não estavam associadas ao perfil do usuário logado. |
| **Solução:** | Realizado ajuste para não carregar movimentações do estoque que a unidade de atendimento não esteja vinculada ao perfil do usuário logado. |
