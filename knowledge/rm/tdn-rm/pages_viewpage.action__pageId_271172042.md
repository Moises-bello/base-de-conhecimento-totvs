# MATRICULAR ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Aluno |
| **Função:** | Processo Matricular Aluno |
| **Situação/Requisito:** | Ao executar o processo “Matricular Aluno”, após já ter preenchido a Turma, caso o usuário mude o Turno na tela do processo, o sistema não estava apagando a Turma escolhida anteriormente para que seja escolhida a nova turma para este novo turno. |
| **Solução/Implementação:** | Alterado o processo de “Matricular Aluno”, o campo Turma será limpo toda vez que o usuário alterar o Turno nesta tela de processo. Assim será possível escolher a Turma correspondente ao Turno. |
