# Linhas de pesquisas do professor

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *Linhas de pesquisas do professor.* |
| **Situação/Requisito:** | *Ao excluir uma linha de pesquisa do professor, caso ele seja orientador de algum TCC de mesma linha de pesquisa, o registro não é excluído, mesmo que a orientação seja realizada em um período letivo diferente do registro que está sendo excluído.* |
| **Solução/Implementação:** | *Ajustes para que a validação realizada ao excluir uma linha de pesquisa do professor considere o período letivo do registro que está sendo excluído.* |
