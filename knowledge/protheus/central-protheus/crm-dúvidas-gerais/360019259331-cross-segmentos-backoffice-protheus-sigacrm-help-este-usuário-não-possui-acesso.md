**Duvida**

Como resolver o Help de bloqueio de acesso à uma rotina/processo do sistema?  
  
**Ambiente**

Cross Segmentos - Backoffice Protheus - SIGACRM - a partir da Versão 12.  
  
**Solução**

Este Help é gerado pelas configurações de permissão de acesso aos registros, essas configurações podem ser realizadas pelas rotinas do **SIGACRM** ou pelas configurações de acesso do usuário no **SIGACFG**.

Na ocorrência do Help de bloqueio de acessos você deve validar:

* Configurações de Permissão no **SIGACRM**;
  + Estrutura de Negócios;
* Configurações de permissão no **SIGACFG**;
  + Restrições de Acesso;
* Privilégios;
* Papel de Trabalho.
