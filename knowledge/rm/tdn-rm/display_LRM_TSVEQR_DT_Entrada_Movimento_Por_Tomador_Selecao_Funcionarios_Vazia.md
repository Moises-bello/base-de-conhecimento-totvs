# ENTRADA DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Entrada de Movimento por Tomador de Serviços* |
| **Situação/Requisito:** | *Ao abrir o formulário de entrada de movimento por tomador de serviços com uma seleção de funcionários completamente vazia, o sistema está permitindo a entrada de dados, quando deveria exibir uma mensagem alertando que deve haver pelo menos um parâmetro para seleção dos funcionários.* |
| **Solução/Implementação:** | *Incluir a verificação dos parâmetros de seleção de funcionário no botão de "Entrada de dados".* |
| **Chamados relacionados:** | *TSVEQR* |
| **Versões/Release:** | *12.1.7* |
