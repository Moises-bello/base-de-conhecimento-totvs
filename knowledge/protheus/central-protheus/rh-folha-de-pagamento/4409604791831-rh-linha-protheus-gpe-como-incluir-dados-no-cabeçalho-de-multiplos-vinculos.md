**Dúvida**  
Como incluir dados no Cabeçalho de Múltiplos Vínculos?  
  
**Ambiente**  
TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17

**Solução**Foi implementado uma melhoria para que seja possível **incluir dados dos múltiplos vínculos** no cadastro de "**Lançamentos Fixos**", replicando todo o período criado na RG1 para as tabelas RAW e RAZ automaticamente, seja no momento de inclusão, alteração ou exclusão dos Lançamentos Fixos.   
  
Para solucionar essa dúvida, realize os seguintes passos:  
1. Acesse: atualizações / Lançamentos / Lançamentos Fixos (**GPEA550**), selecione o funcionário e clique em Incluir e informe as verbas de parte empresa e desconto do funcionário outra empresa.  
Ao clicar no botão “Salvar”, o sistema irá abrir uma nova tela para que seja informado os dados do outro Empregador:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4409611280151)  
  
2.Ao clicar no botão “Confirmar”, automaticamente será replicada para as tabelas RAW e RAZ o conteúdo para o período informado:
