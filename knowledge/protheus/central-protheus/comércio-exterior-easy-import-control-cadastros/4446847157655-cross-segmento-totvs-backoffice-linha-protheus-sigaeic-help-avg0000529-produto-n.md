![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como corrigir help AVG0000529: Produto não cadastrado para este Fabricante/Fornecedor.?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Verifique se já foi feita amarração do Produto X Fornecedor.

1 -Acessar SIGAEIC - Atualizações - Cadastros - Produtos X Fornecedor

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500002038082/mceclip0.png)

2 - Selecione incluir

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4411764655255/mceclip0.png)

3- Preencha o código do produto, fabricante, fornecedor e selecione confirmar.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360103101553/mceclip2.png)
