| **Solução/Implementação:** | *Foi identificado que no método responsável por salvar os dados no curso/habilitação do aluno, o campo de "data de registro" não é salvo, sendo assim, foi feito a alteração do método para incluir também este campo ao salvar os dados no curso/habilitação do aluno.* |
