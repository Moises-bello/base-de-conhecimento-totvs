# PARAMETRIZAÇÃO PARA A GERAÇÃO DE USUÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Parametrização para a geração de usuário* |
| **Situação/Requisito:** | *Ao entrar nos parâmetros do sistema Geração de usuário > Aluno os campos como Perfil do CRM e do Biblios não lista nada e os campos complementares também. Além disso, não estava sendo propagado o campo de acesso ao banco de dados tanto para a geração do usuário para aluno quanto para professor.* |
| **Solução/Implementação:** | *Ajuste nas parametrização de geração de usuário para aluno e professor para exibição dos dados do perfil CRM e Gestão Bibliotecária; e campo complementar para aluno, e dos dados do perfil CRM e campo complementar para professor. Além disso, foi ajustado que ocorra a propagação do campo acesso ao banco de dados ao gerar usuário automático tanto para aluno quanto professor.* |
