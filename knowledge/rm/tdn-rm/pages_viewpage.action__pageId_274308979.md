# Geração do Registro 0000 para ECD do tipo "ECD DA SCP"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Geração do Registro 0000 para ECD do tipo "ECD DA SCP" |
| **Situação/Requisito:** | Ao gerar o arquivo da SCP o sistema não esta preenchendo a posição 18 do registro 0000 com o CNPJ da SCP. |
| **Solução/Implementação:** | Adequação do layout 5.0 para atender a mudança na legislação e passar a preencher o campo 18 do registro 0000 com o CNPJ da SCP como determinado no manual da ECD. |
