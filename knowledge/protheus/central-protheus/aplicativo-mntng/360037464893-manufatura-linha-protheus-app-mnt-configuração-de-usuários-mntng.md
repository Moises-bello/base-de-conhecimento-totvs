**Dúvida**  
Como realizar as configurações de usuário do aplicativo **MNTNG?**  
  
**Ambiente**  
TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Aplicativo MNTNG - Versão 12  
  
**Solução**  
Para que seja possível logar no aplicativo **MNTNG**, é necessário possuir um **usuário** ativo no **Protheus** com **permissão** de acesso ao módulo **Manutenção de Ativos - SIGAMNT** e as **Filiais** por meio do **Configurador.**

* Para criar um novo usuário no **Protheus**, você deve acessar o módulo **SIGACFG** **- Configurador** e navegar pelos menus **Usuário / Senhas / Usuários**.

A partir do cadastro do usuário é possível também realizar o vínculo do usuário do **Protheus** com um [Funcionários da manutenção](https://tdn.totvs.com/pages/viewpage.action?pageId=506389105) caso o mesmo seja um manutentor. Para realizar o vínculo inclua / altere o **Cadastro do Funcionário** **- MNTA020** e informe os campos de **End. E-Mail - T1\_EMAIL** e **Cód. Usuário - T1\_CODUSU**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/33018260565399)**  
  
Além disso, é imprescindível que o usuário realize o *login* a partir do **End. E-Mail** previamente cadastrado, pois esse campo possui vínculo com o usuário **Protheus**.
