O emulador VTDEBUG ou Tera Term, utilizado no SIGAACD para geração de etiquetas, acessa o caminho "Relatórios - Código de Barras".

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37224081838615) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
Quais são as rotinas do emulador do SIGAACD como VTDEBUG ou Tera Term para geração de impressão de etiqueta?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**  
Ao acessar o emulador VTDEBUG ou Tera Term acessa o seguinte caminho, para geração das etiquetas:

Relatórios - Código de Barras

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37224066014871)

Todas essas rotinas são para geração de etiqueta no emulador.

**Observação**: Para consulta o nome de cada rotina no emulador seleciona o CTRL  + Z.
