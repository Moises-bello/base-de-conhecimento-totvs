**Dúvida**  
Como cadastrar filtros de usuário no Novo Fluxo de Compras - PGCA010.  
  
**Ambiente**  
Protheus – Compras – A partir da versão 12.1.2210  
  
**Solução**

O sistema permite a aplicação de filtros de usuário. Para isso, é necessário cadastrar o comprador na rotina Compradores (COMA087), no botão Botão Outras Ações > Filtro Necess. NFC, especificar o filtro desejado e ativar o parâmetro [MV\_FILTNFC](https://tdn.totvs.com/pages/viewpage.action?pageId=844976022). Para mais informações sobre como utilizar os filtros, consulte a documentação [PCOM09013 - Compradores (COMA087)](https://tdn.totvs.com.br/pages/viewpage.action?pageId=274632269), na sessão **Filtro Necessidade de Compra para o Novo Fluxo de Compras (NFC).**
