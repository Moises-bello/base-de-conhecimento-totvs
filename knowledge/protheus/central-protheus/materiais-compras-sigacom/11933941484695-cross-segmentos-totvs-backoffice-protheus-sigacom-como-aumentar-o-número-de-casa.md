![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00****min** **Dúvida**Como aumentar o número de casas decimais para o campo **SEV->EV\_PERC**, campo percentual de Múltíplas Naturezas para 5, por exemplo.

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Compras  - Todas as versões

**Solução**

Para aumentar o número de casas decimais para o campo **SEV->EV\_PERC = PERC DISTR** no documento de entrada nas informações de Múltiplas Naturezas.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11933667666583)

Acesse o configurador, selecione o parâmetro **MV\_MULTDEC** e informe o número de casas decimais que deseja, considerando limite máximo até **5.**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11933187491223)
