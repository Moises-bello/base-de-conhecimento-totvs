# Correção da descrição da hint de: "Registro com erro na Integração"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Integração TAF X RM |
| **Situação/Requisito:** | Ao realizar filtro na tela de integração de registros do RM x TAF, as mensagens apresentadas, estão divergentes com o Status de integração, referente ao retorno do TAF sobre a integração dos registros. O mesmo informa que os registro que foram integrados com sucesso e com erro, são retornados com a mesma mensagem "Registro Integrado Com sucesso", o qual não está correto. |
| **Solução/Implementação:** | Correção da descrição da hint de registros com erro para: "" "Registro com erro na Integração" |
