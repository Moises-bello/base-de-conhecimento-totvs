![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:40 min****Dúvida**Como criar e lançar um grupo de eventos para funcionários horistas?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para solucionar essa dúvida, verifique e realize o passo a passo orientado:  
  
1. Acesse: **Folha Mensal | Lançamentos | Grupo de eventos.** ![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9291228989847/mceclip0.png)  
  
2. Caso queira incluir um novo grupo de eventos clique para adicionar um novo registro, informe o código, descrição e faça a parametrização das demais ações que o lançamento irá realizar juntamente com o filtro de seleção de funcionário.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9291300256407/mceclip1.png)  
  
3. Marcando a flag **Lançar Eventos do Grupo** será habilitada uma aba onde deve ser informado os eventos que serão lançados pelo grupo de eventos.  
  
 ![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9291262521623/mceclip2.png)  
  
4. Na aba de **Eventos do Grupo**, deve-se informar os eventos de Provento e descontos que serão lançados para os funcionários horistas:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9291350152471/mceclip3.png)  
  
5. Após realizar parametrizações no grupo de eventos, o sistema solicitará que o grupo de eventos seja salvo. Clique em **Salvar** para usar o grupo de eventos futuramente.  
  
6. Após criação do grupo de eventos, clique em **Lançar** para que as parametrizações informadas no grupo de eventos sejam lançadas para os funcionários.

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9291325218071/mceclip4.png)
