# Ajuste no Arquivo de Exportação da DMED

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Utilitários |
| **Rotina:** | |  | | --- | | **Nome Técnico** | | Gerar DMED | |
| **País(es):** | Brasil |
| **Sistema(s) Operacional(is):** | Windows |
| **Versões/Release:** | 12.1.8 |

## Descrição

Ajuste no arquivo de exportação da DMED conforme o layout publicado na instrução Normativa RFB Nº1.596.

## Procedimento para Implantação

* O sistema é atualizado logo após a aplicação do pacote de atualizações 12.1.8.112 da biblioteca do RM.

## Procedimento para Utilização

1. Acesse o menu **Utilitários \ Rotinas \ Gerar DMED**.
2. Preencha os dados para geração do arquivo de exportação.
3. Após a geração do arquivo, verifique se o cabeçalho do arquivo está no padrão de geração do novo layout.
