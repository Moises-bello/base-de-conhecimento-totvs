# Gestão de mensagem individual

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Visão de mensagem individual do eduCONNECT para enquete |
| **Situação/Requisito:** | Ao acessar a Gestão de mensagens do TOTVS Educacional, no anexo mensagem individual o sistema não exibe a resposta de enquete por usuário. |
| **Solução/Implementação:** | Foi realizado um ajuste no TOTVS Gestão Educacional na visão de mensagem individual, de maneira que o sistema possa exibir uma nova coluna "Resposta (Apenas enquete)" para que o usuário possa obter a resposta de cada usuário na enquete.  Lembrando que essa coluna será preenchida com valor apenas se a mensagem for do tipo "Enquete" e o usuário já tenha respondido a enquete. |

| **Tickets relacionados:** | N/A |
| **Requisito:** | N/A |
