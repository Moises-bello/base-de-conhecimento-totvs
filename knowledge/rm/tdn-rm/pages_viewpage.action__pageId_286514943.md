# NÚMERO MÁXIMO DE ALUNOS NA TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Turma |
| **Situação/Requisito:** | Quando a turma possui mais alunos matriculados que o número máximo informado, ao salvar qualquer alteração feita na tela é exibida uma mensagem perguntando se o usuário deseja salvar as informações com alunos matriculados maior que a capacidade da turma. Mesmo clicando na opção SIM, o sistema não permite salvar a alteração. |
| **Solução/Implementação:** | O cadastro de turma foi corrigido para permitir alterar os dados quando existem mais alunos matriculados que o número máximo da turma. Após aparecer a mensagem perguntando se deseja salvar as informações com alunos matriculados maior que a capacidade da turma, o sistema irá permitir a alteração caso seja escolhida a opção SIM. |
