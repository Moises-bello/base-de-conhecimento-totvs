Nesta área é possível cadastrar o Tipo de Projeto para o empreendimento onde é feita integração das informações com o TCOP (Aluguel).

Para o cadastro, acessar o empreendimento cadastrado na venda conforme imagem abaixo:

Após acessar o empreendimento, no menu esquerdo em Integração, acessar a opção "Construção Obras e Projetos" conforme imagem abaixo:

No Lookup "Projeto" escolher o tipo do projeto para o empreendimento e Salvar (Criar o filtro todos para listagem dos tipos de projeto):

Importante!

O Lookup somente apresentará os Projetos da mesma Coligada do Contexto do Empreendimento.

Ou seja, não será possível se associar Projetos de uma Coligada diferente da Coligada do Empreendimento.
