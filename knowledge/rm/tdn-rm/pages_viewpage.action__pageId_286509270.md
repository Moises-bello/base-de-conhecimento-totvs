# Alocar Acomodação no Painel de Classificação de Risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de Classificação de Risco |
| **Situação:** | Ao acessar a tela de Alocação de Pacientes pela classificação de Risco, o campo Classe do leito não vinha preenchido e com isso, os leitos não eram carregados. |
| **Solução:** | Alterado o sistema para sempre exibir os leitos, e para mostrar a opção de TODOS no campo Classe dos leitos. |
