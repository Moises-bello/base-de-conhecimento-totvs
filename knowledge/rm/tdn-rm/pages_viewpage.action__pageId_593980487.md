**Backup/Restore de um projeto de Revisão Horizontal de Alteração de Escopo.**

Será permitido que o usuário faça Backup/Restore dentro de um projeto de Revisão Horizontal de [Alteração de Escopo](https://tdn.totvs.com/pages/viewpage.action?pageId=421385142).

**Envio de quantidade no processo de Liberação de Medição**

O sistema passa a realizar envio de quantidade de forma diferente para BackOffice RM  e BackOffice Protheus. **Saiba mais em:** [Gerar Integração Suprimento e Faturamento](https://tdn.totvs.com/pages/viewpage.action?pageId=421385502)

**Adiantamento de Contrato**

O sistema passa a verificar novas consistências e controles no Adiantamento. **Saiba mais em:** [Adiantamento de Contrato](https://tdn.totvs.com/display/LRM/Adiantamento+de+Contrato)

**Melhoria no processo de estorno de período liberado de medição de contrato**

Melhoria no estorno de períodos em que exista movimentação liberada pendente no BackOffice mas o período possui período posterior já liberado, ao realizar o cancelamento da primeira liberação e gerado o período de estorno automático. **Saiba mais em:**  [Cancelamento de Liberação](https://tdn.totvs.com/pages/viewpage.action?pageId=421385373)

**Valor Líquido da Medição nas Liberações de Período**

Este campo demonstrará o resultado do cálculo: Valor Reajustado da Medição - (Retenções + Deduções) **Saiba mais em:** [Valor Líquido da Medição](https://tdn.totvs.com/pages/viewpage.action?pageId=421385221)

**Permissão de Segurança para Detalhamento de Retenção**

Esta permissão de perfil de usuário foi desenvolvido para garantir segurança para liberações de contrato quando utilizado detalhamento de retenção.  **Saiba mais em:** [Detalhamento de Retenção](https://tdn.totvs.com/pages/viewpage.action?pageId=421385221)

**Permissão de Segurança para Detalhamento de Dedução**

Esta permissão de perfil de usuário foi desenvolvido para garantir segurança para liberações de contrato quando utilizado detalhamento de dedução.  **Saiba mais em:** [Detalhamento de Dedução](https://tdn.totvs.com/pages/viewpage.action?pageId=421385221)

**Cubo de Contrato com Insumos e Serviços Associados**

Esse recurso disponibiliza a opção de criação de cubos de decisão facilitando assim a visão das informações de contratos com insumos e serviços associados.

Os Cubos permitem que se aglutine em uma só tela, dados e recursos gerenciais disponíveis. **Saiba mais em:** [Cubos de Contrato](https://tdn.totvs.com/pages/viewpage.action?pageId=421385340)

**Novos Campos no Cadastro de Projeto para Atendimento da EFD Reinf**

Para atendimento à EFD Reinf, foram inseridos no cadastro do projeto os campos "Código Nacional de Obras (CNO)" e "Indicativo de Prestação de Serviços em Obra de Construção Civil" que são necessários para a geração dos Registros R-2010 e R-2020 da rotina. [Saiba Mais](https://tdn.totvs.com/pages/viewpage.action?pageId=421385284)

**Processo Copiar Folha Tarefa** 

Foi criado o processo de cópia de Folha Tarefa, que será permitido para folhas com status Cancelada ou Encerrada. [Saiba Mais](https://tdn.totvs.com/display/LRM/Copiar+Folha+Tarefa)

**Grupo de Custo na Alteração de Escopo** 

Os novos projetos de Alteração de Escopo criados a partir da versão 12.1.18 contemplarão os processos de Incluir/Alterar/Excluir Grupos de Custo. Assim, caso existam na base Projetos de Alteração de Escopo criados em versões anteriores, será necessário realizar o processo de Sincronismo para atualização dos Grupos de Custo nestes Projetos.  [Saiba Mais](https://tdn.totvs.com/pages/viewpage.action?pageId=421385142)

**Ações Permitidas no Projeto de Alteração de Escopo** 

No projeto de alteração de escopo será permitido executar os processos: Cópia de itens, Importação de Insumos Via Excel, Importação de Composições Via Excel e Importação de Tarefas Via Excel. [Saiba Mais](https://tdn.totvs.com/pages/viewpage.action?pageId=421385142)
