![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808222419223) Tempo aproximado para leitura: **00:02:30 min****Dúvida**Como realizar o envio de envelope de pagamento via e-mail para funcionários?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para efetuar envio do envelope de pagamento via e-mails para os funcionários cadastrados na base de dados, execute os passos abaixo:  
  
1. Acesse o módulo **Serviços Globais |** **Cadastro | Segurança | Usuário**; e verifique se em seu usuário existe e-mail cadastrado. Caso não tenha, cadastre um e-mail valido.  
  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808212308119)  
  
2. Preencha, no módulo Folha de Pagamento, dentro do cadastro do funcionário, o e-mail para recebimento:  
  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808222424343)  
  
3. Verifique se o cadastro de e-mail global no sistema está configurado, caso não esteja configurado, acesse **Ambiente | Parâmetros | Parâmetros Globais**.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808212313751)  
  
Os parâmetros da coligada atual serão utilizadas na coligada que o usuário está logado no momento e os parâmetros da coligada global serão usadas pela coligada global.  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808212318231)  
  
4. No menu Funcionários, selecione o funcionário desejado e acesse **Processos | Enviar e-mails para funcionários**:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808222439575)   
É possível também acessar o envio de e-mails em **Configurações | Enviar e-mails para Funcionários**, onde haverá uma tela para salvar de perfil de parâmetros e seleção de funcionários:  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808222446743)  
  
5. Após acessar o menu anterior, será direcionado a tela abaixo onde deverá ser preenchido os dados do remetente:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25808212336279)  
  
6. Caso deseja, temos um relatório padrão para envio de envelope de funcionário individual por funcionário que é **FOPREL 25.0025-2.004.01 Envelope de Pagamento - labo 05.0,** que deverá ser importando através do menu [TOTVS COMPARTILHAMENTO](https://centraldeatendimento.totvs.com/hc/pt-br/articles/7781155867543-RH-RM-FOP-Importa%C3%A7%C3%A3o-de-relat%C3%B3rios-e-layouts-atrav%C3%A9s-do-Totvs-Compartilhamento?source=search)

7. Ao realizar a importação do relatório marque a **Opção de Envio** marcada é Relatório do Sistema. Selecione a flag **Enviar relatório como Anexo** e selecione o relatório que será gerado. Preencha o assunto e o texto do e-mail. Avance e Execute o procedimento.
