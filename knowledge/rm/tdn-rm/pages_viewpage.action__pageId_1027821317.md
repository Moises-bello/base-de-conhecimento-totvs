# 1. Sobre

A **Nota Técnica SE\CGNFS-e nº 004** adapta o layout da **NFS-e Modelo Nacional** à Reforma Tributária do Consumo (RTC), incluindo novos agrupamentos e campos no XML para reportar os tributos **IBS e CBS.**

A NT também publica novos *schemas e* regras de validação.

# 2. Cronograma

Esta Nota Técnica entra em vigor a partir de:

* Produção Restrita (homologação/testes): **10/12/2025**
* Produção: **05/01/2026.**
