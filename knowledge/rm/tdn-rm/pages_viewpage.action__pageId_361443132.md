|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento de Convênios |
| **Situação/Requisito:** | Sistema não está respeitando a vigência para tabelas de Domínio onde o convênio tenha tabela de preço diferenciada |
| **Solução/Implementação:** | Ao gerar o xml do faturamento Tiss, o sistema verifica a condição contratual relativa à data de lançamento do item e também as tabelas de preços diferenciadas para esta data e não somente as tabelas básicas da condição contratual |
