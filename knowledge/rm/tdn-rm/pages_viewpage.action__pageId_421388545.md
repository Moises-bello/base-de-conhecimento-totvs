**12.1.21 - Disponibilizado layout de remessa de pagamento da Caixa Econômica Federal no padrão SIACC.**  
O layout está disponível na pasta de Objetos gerenciais, com o código "FINLAY0056"  
**12.1.21 - Disponibilizado relatório para impressão de boletos do banco Cecred. (**[**TDN**](http://tdn.totvs.com/pages/viewpage.action?pageId=379306394)**)**  
O relatório está disponível na pasta Objetos Gerenciais: FINREL0041 - Boleto Cecred.  
**12.1.21 - Implementado processo de geração de nosso número e Código de Barras para o banco Cecred. (**[**TDN**](http://tdn.totvs.com/pages/viewpage.action?pageId=379306394)**)**  
**12.1.21 - Implementado processo de geração de nosso número e Código de Barras para o banco Crefisa. (**[**TDN**](http://tdn.totvs.com/pages/viewpage.action?pageId=367238703)**)**  
**12.1.21 - Disponibilizado a partir da versão 12.1.20 o** [**Layout de Remessa de Cobrança**](http://tdn.totvs.com.br/display/LRM/Objetos+Gerenciais) **CNAB240 para o banco Crefisa.** ([**TDN**](http://tdn.totvs.com/pages/viewpage.action?pageId=378280251))  
**12.1.21 - Disponibilizado relatório para impressão boletos do banco Crefisa.**  
O relatório está disponível na pasta Objetos Gerenciais: FINREL0040 - Boleto Crefisa.  
**12.1.21 – Implementada** [**configuração do TEF por filial.**](http://tdn.totvs.com.br/pages/viewpage.action?pageId=421388560)  
Esta funcionalidade tem como objetivo permitir a parametrização da integração do TEF por Filial. ([TDN](http://tdn.totvs.com/pages/viewpage.action?pageId=361431990))  
**12.1.21 – Otimizado processo de transações com cartão crédito/débito via integração** [**Sitef**](http://tdn.totvs.com.br/pages/viewpage.action?pageId=421388560) **para salvar o Código de Identificação da Rede e o Código de Autorização para transações de crédito.** ([TDN](http://tdn.totvs.com/pages/viewpage.action?pageId=360448615))  
**12.1.21 – Melhoria no processo de agendamento de remessa bancária.**  
Implementada opção de "Permite agendamento da remessa bancária" na tela de execução do processo. ([TDN](http://tdn.totvs.com/pages/viewpage.action?pageId=358455115))   
   
**12.1.21 - Melhoria na parametrização do processo de Ajuste de Transações para pagamento/baixa com cartão por filial, do modelo buypage ou checkout. (**[TDN](http://tdn.totvs.com/pages/viewpage.action?pageId=356813265)**)**  
**12.1.21 - Melhoria na inclusão de lançamentos financeiros de** [**tributos**](http://tdn.totvs.com.br/pages/viewpage.action?pageId=421388704)**.**  
Caso os tributos (IRRF e CSRF - CSLL-RF, PIS-RF e COFINS-RF) possuam Natureza Orçamentária Financeira default em seu cadastro, o sistema irá utilizar esta natureza orçamentária para compor os rateios de centro de custo do lançamento gerado, caso existam.  
**12.1.21 - Melhoria na**[**Remessa Bancária**](http://tdn.totvs.com.br/pages/viewpage.action?pageId=421388744) **Cobrança e Débito automático.**  
O sistema permite que um boleto faturado com status 'Pendente Remessa' seja remetido ao banco para que se faça a operação de cancelamento do boleto junto ao sistema bancário.   
**12.1.21 - Melhoria no**[**Registro online de Boleto**](http://tdn.totvs.com.br/display/LRM/Registro+Online+de+Boletos) **para o Banco Banrisul. (**[**TDN**](http://tdn.totvs.com/pages/viewpage.action?pageId=351384062)**).**  
**12.1.21 - Foi disponibilizado o** [**Histórico de alterações**](http://tdn.totvs.com.br/pages/viewpage.action?pageId=421388636) **somente para lançamentos do TOTVS Incorporação em Utilitários | Habilita Controle somente para TOTVS Incorporação**.[(TDN)](http://tdn.totvs.com/pages/viewpage.action?pageId=351031553)
