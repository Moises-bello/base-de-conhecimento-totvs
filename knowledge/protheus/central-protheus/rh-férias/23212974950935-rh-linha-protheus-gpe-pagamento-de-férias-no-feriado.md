![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23212974929431) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível parametrizar o sistema para desconsiderar o feriado para o pagamento de férias?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**

O artigo 145 da CLT não detalha se a contagem é sobre dias úteis, então no padrão do sistema, a data de pagamento **será sempre dois dias antes** do início das férias, **desconsiderando apenas os finais de semana.**

É possível alterar a data do pagamento manualmente, conforme artigo:  
[RH - Linha Protheus - GPE - Como alterar a data de pagamento das férias](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360063518933-RH-Linha-Protheus-GPE-Como-alterar-a-data-de-pagamento-das-f%C3%A9rias)  
   
Para automatizar esse processo será preciso realizar customização. Outra alternativa é enviar uma sugestão na [Central Colaborativa TOTVS](https://centraldeatendimento.totvs.com/hc/pt-br/community/topics), informando esse cenário de melhoria.
