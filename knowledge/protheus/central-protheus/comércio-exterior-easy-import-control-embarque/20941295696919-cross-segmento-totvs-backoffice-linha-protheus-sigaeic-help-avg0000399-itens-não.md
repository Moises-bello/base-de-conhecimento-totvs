Como corrigir o Help "AVG0000399" "Itens não podem ser alterados, pois há Títulos Baixados"?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20941295673495)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão 12.1.33.

**Solução**Para que a mensagem não seja apresentada, é necessário primeiro estornar a liquidação do câmbio, após efetivada a operação, fazer o estorno do embarque.
