Através deste processo o usuário poderá inserir lançamento extemporâneo. Estes lançamentos são utilizados quando a nota foi registrada em período anterior de forma incorreta, sem o preenchimento do crédito/débito correspondente ou quando a nota deixou de ser registrada.

***Observações***: Este processo estará visível para as filiais dos Estados de Minas Gerais, São Paulo e Distrito Federal.  
Este processo não estará visível se o tipo de livro for igual a ISS  
O lançamento Extemporâneo terá o Status = 'X'  
Para esses lançamentos o campo data do documento ficará habilitado.  
Na inclusão de Lançamentos Fiscais extemporâneos, o campo data do documento deverá ser informado pelo usuário e deverá se encontrar dentro do período do lote corrente.  
Se o usuário não trabalha com lotes, deverá existir período aberto para a Data do documento informada. Neste tipo de Lançamento Fiscal, a Data Entrada/Saída deverá ser de período anterior à data do documento.
