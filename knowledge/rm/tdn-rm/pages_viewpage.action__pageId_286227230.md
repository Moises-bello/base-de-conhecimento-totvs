# Remuneração

|  |  |
| --- | --- |
| **Produto:** | RM Chronus |
| **Versões:** |  |
| **Ocorrência:** | **Artigo 58º-A § 3º**  As horas suplementares à duração do trabalho semanal normal serão pagas com o acréscimo de 50% (cinquenta por cento) sobre o salário-hora  normal. |
| **Ambiente:** | Remuneração, Jornada de Trabalho |
| **Passo a passo:** | Para atender o Artigo 58º A Paragrafo 3º, onde terá que realizar o calculo das horas suplementares a jornada do trabalho com acréscimo de 50%, foi realizado as seguintes parametrizações:    1º ) Acessar RM Chronus Configurações > Eventos>Ícone novo>Inserido o  evento de código de cálculo 0018        2º ) Acessar o cadastro Sindicato no Chronus e associar o evento 0018 criado, relacionando com o evento do Labore ( Evento relacionado ) em: Configurações>Parametrizador>Sindicato>Eventos>Associar o evento do RM Chronus com o evento do RM Labore          3º ) Após o recálculo do espelho de ponto, de acordo com as horas trabalhadas, será lançado para o movimento o evento criado:        4º ) Para lançar o evento criado (e outros )  para a folha de pagamento: Acessar> Movimento > Lançar para a folha de pagamento:            5º ) O evento será incluído no módulo Folha de pagamento, através do menu Folha mensal >  Consulta > Consulta Movimentação de integração        6º ) Acessar menu Folha Mensal > Lançamentos > Grupos de eventos> Enviar os eventos para o RM Labore. |
| **Observações:** |  |
