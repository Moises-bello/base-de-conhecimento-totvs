## Descrição

Foi implementada uma melhoria na Folha Analítica para permitir selecionar as Bases que serão impressas nos Totais do Funcionário, Totais da Seção e Total Geral de forma simples, não sendo mais necessário editar o layout do relatório.

## Procedimento para Configuração

É necessário atualizar o layout da Folha Analítica importando novamente o Relatório FOPREL09.0009 - 2.001.001 - Folha Analítica.TotvsReport.

## Procedimento para Utilização

Foi criada na etapa "Impressão" do wizard da Folha Analítica quatro colunas para seleção das bases: 

1)Para selecionar as bases a serem impressas utilize o botão esquerdo do mouse.

2) Para mover as bases para outra coluna utilize o botão direito do mouse. 

3) Para alterar a ordem de impressão, selecione a base e utilize as setas para cima () ou para baixo ().

4) Para restaurar as configurações padrão, clique no botão  localizado no canto superior direito.

5) Para selecionar todas as bases da coluna utilize o botão . Para desmarcar todas as bases da coluna utilize o botão .
