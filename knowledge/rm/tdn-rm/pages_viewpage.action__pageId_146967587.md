**Objetivo:**A finalidade da atividade "Sequência" é criar uma estrutura que permitirá a associação de **mais de uma atividade** em **atividades** que **permitem apenas uma atividade** associada à ela.

No exemplo vamos utilizar a atividade "**Para Cada Iteração**" pois a mesma permite apenas uma atividade associada.Primeiramente é necessário arrastar a atividade "**Para Cada Iteração**" para o "fluxo de trabalho" sequencial em sua fórmula visual.

|  |
| --- |

Agora vamos associar a atividade "**Sequencia**" à atividade "**Para Cada Iteração**".

|  |
| --- |

Para finalizar basta arrastar as atividades desejadas para à atividade "Sequência"

|  |
| --- |

**A atividade sequência não possuí nenhuma propriedade para ser preenchida.**
