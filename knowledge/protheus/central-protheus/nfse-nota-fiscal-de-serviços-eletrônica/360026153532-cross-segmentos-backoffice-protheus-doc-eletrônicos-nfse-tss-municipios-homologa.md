**Dúvida**Quais os municípios homologados no TSS para transmissão de NFTS?  
  
**Ambiente**Cross Segmentos - TOTVS Backoffice Protheus - TOTVS Doc. Eletrônicos - Todas as versões.  
  
**Solução**Segue abaixo a Relação de Municípios Homologados para NFTS no TSS:  
- <http://tdn.totvs.com/pages/releaseview.action?pageId=172300900>  
A coluna versão, informa a partir de qual versão do TSS o município está homologado.  
  
Já as colunas Cancelamento e Substituição, informam se estas respectivas Prefeituras possuem estes serviços via Web Service.
