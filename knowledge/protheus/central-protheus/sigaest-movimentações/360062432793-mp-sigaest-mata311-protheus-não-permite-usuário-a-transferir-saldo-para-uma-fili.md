**Dúvida**Após aplicar a última expedição contínua do Estoque o usuário não consegue fazer Transferência para nenhum outra filial, a não ser que eu dê acesso a ele nas filiais que quero transferir. Como permitir que o usuário possa transferir o saldo mesmo que ele não tenha acesso à filial destino?  
  
**Ambiente**Microsiga Protheus - Estoque - A partir da versão 12.1.17  
  
**Solução**Com as últimas atualizações , o usuário que não possui acesso à filial destino não irá conseguir visualizar para transferir.  
  
Para isso, temos o Ponto de Entrada **M310FILIAL** para que o usuário tenha acesso tanto a origem de destino como filial origem. Para maiores informações sobre este P.E, **[clique aqui.](https://tdn.totvs.com/pages/releaseview.action?pageId=6087581)**

Para obter a documentação da causa do ajuste desta validação, **[basta clicar aqui](https://tdn.totvs.com/pages/releaseview.action?pageId=527397681).**
