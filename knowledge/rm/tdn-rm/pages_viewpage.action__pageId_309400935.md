## Descrição

Permitir que usuário possa definir se será listadas as contas caixas inativas para seleção no Fluxo de Caixa

## Procedimento para Utilização

Dever ser marcado a opção "Listar Conta Caixa inativa" para que sejam exibidas as contas caixas inativas para seleção das mesmas.
