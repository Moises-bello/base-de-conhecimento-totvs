# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Alteração de Distribuição Gerencial |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**   A Distribuição gerencialé a divisão ou rateio que pode ser feito nos valores dos lançamentos contábeis para apropriação dos gastos/receitas das empresas em uma ou mais contas gerenciais.   A alteração de distribuição gerencial pode ser utilizada entre outros, para correção de rateios já efetuados ou mudança do cenário gerencial em determinado período.    **Regras Gerais:**  Este processo deve ser utilizado para alteração da distribuição gerencial, ou ainda inclusão de rateios em lançamentos em contas contábeis que não tinham distribuição gerencial e passou a ter.  Após a execução da alteração, não existe a opção de Desfazer ou Cancelar o processo, neste caso, deverá refazer o processo de Distribuição usando o Cenário Inicial.  Obs. O sistema não irá inserir dados gerenciais em partidas, onde as contas contábeis cuja opção de rateio esteja desmarcada no cadastro.    **Parametrização Necessária:**  1 - Para realizar o processo **Alteração de Distribuição Gerencial**, acesse o menu **Escrituração Contábil/Lotes**, selecione o(s) lote(s) desejado(s) e clique no menu **Processos/Alteração de Distribuição Gerencial**:      2 - Em seguida o sistema abrirá uma tela onde poderá acrescentar novos lotes a serem alterados, bem como filtros diversos, período em que a distribuição será alterada e um filtro genérico aumentando com isso, as possibilidades de seleção dos dados por parte do usuário:      3 - Ao avançar o usuário terá quatro opções para executar a alteração, todas contendo a explicação da ação que será feita pelo sistema. Vejamos abaixo:    Alteração de acordo com a informação cadastrada no plano de contas contábil:        Alteração para conta gerencial de acordo com a conta origem:        Redistribuição para outras contas gerenciais:        Informação da distribuição gerencial: |
