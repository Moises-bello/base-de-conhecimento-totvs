**Dúvida**  
Como consultar as APIs padrões disponíveis para uso?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**

Para verificar as **APIs padrões disponíveis para uso em integrações**, acesse o endereço: [**https://api.totvs.com.br/**](https://api.totvs.com.br/)

Essas APIs são disponibilizadas pela TOTVS como **padrão de integração**, porém **podem não atender completamente às necessidades específicas de cada cliente**.

Para consultar quais APIs disponíveis no Protheus para **Recursos Humanos**, selecione **Protheus > Recursos Humanos:**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/40637779912727)

**Importante:** Caso nenhuma das APIs padrão atenda ao requisito do projeto, será necessário **desenvolver uma integração própria** utilizando o **serviço*****REST*****do Protheus**.
