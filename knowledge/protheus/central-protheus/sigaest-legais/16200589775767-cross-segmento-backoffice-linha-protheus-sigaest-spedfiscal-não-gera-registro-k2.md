![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16200628139031) Tempo aproximado para leitura: **00:01:23min****Ocorrência**Na geração do arquivo SPEDFISCAL com Bloco K não está sendo apresentado os registros K200 relacionado ao período (Apenas para Banco de Dados POSTGRE).  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões  
  
**Causa**Este problema ocorre por conta da configuração do ODBC para uso do Banco de Dados POSTGRE.  
  
**Solução**

Para que o problema seja solucionado, deve reavaliar a configuração do ODBC de acordo com as documentações abaixo: 

   
ODBC para uso de [PostgreSQL+Windows](https://tdn.totvs.com/display/tec/DBAccess+-+Como+fazer+para+criar+uma+fonte+de+dados+para+uso+com+o+PostgreSQL+-+Windows)  
ODBC para uso de [PostgreSQL+Linux](https://tdn.totvs.com/display/tec/DBAccess+-+Como+fazer+para+criar+uma+fonte+de+dados+para+uso+com+o+PostgreSQL+-+Linux)
