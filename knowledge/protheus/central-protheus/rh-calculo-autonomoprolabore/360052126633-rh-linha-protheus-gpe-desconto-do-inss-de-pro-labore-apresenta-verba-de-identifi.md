**Dúvida**Desconto do INSS de Pro Labore apresenta verba de identificador de cálculo 0064 e não na verba de identificador de calculo 0222.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**A verba com identificador 0222 não é mais utilizada para o cálculo do INSS de Pró-Labore. Hoje é utilizado o mesmo identificador dos mensalistas, id 0064.   
  
O sistema não trata mais este identificador 0222, devido ao fato de antigamente existir escalas de 0 a 9 para contribuições de Autônomos e pró-labores. Como agora, é o mesmo desconto que um Funcionário Celetista, os campos para diferenciar o Salário de Contribuição e se o sistema irá recolher em cima disso, estão desativados, ou seja, estão somente para histórico e não funcionam mais.   
  
Caso a verba de identificador 0222 seja apresentada no cálculo, verificar se a verba foi calculada pelo próprio sistema ou se é proveniente de migração, cadastro particular no cadastro de funcionários ou lançamento de verba.
