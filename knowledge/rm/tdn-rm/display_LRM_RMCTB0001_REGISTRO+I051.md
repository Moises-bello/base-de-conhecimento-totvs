# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Contábil |
| **Versões:** | 12.1.XX |
| **Ocorrência:** | Erro no Registro I051 |
| **Ambiente:** |  |
| **Passo a passo:** | **Processo:**  Erro apresentado ao validar o arquivo da ECD no PGE (Programa Gerador de Escrituração):  **NÃO FOI INFORMADO NENHUM REGISTRO I051**    **Análise/Solução**  Caso deseje realizar o envio do Plano de Contas Referencial (Registro I051), deve-se realizar a vinculação das contas contábeis (empresa) com o plano de contas referencial/paralelo (Receita) através do menu ‘Cadastros’ / ‘Plano de Contas Paralelo’  Caso não tenha realizado o processo citado, o validador apresentará a mensagem em questão, porém a mesma é uma advertência e não impede o “envio” do SPED Contábil. |
| **Observações:** | O Plano de Contas Referencial é obrigatório para as empresas que entregam a ECF. |
