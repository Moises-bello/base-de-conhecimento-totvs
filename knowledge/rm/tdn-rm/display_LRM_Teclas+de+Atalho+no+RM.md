# OBJETIVO

O Objetivo deste documento é apresentar algumas opções de teclas de atalho para que seja possível agilizar a interação entre o Usuário e o Sistema.

As teclas de atalho apresentadas neste documento são para todos os módulos do RM. Podendo ser acessadas em quase todas as Actions do sistema.

Teclas de Atalho1Visões

|  |  |
| --- | --- |
| **ALT + E** | Define se o sistema vai abrir as Action em Abas ou Janelas. |
| **ALT + END** | Seleciona o o último registro da visão. |
| **ALT + ESPAÇO** | Opções da Janela para maximizar, minimizar, restaurar, etc. |
| **ALT + F3** | Abre janela de execuções do sistema. |
| **ALT + F4** | Fecha o sistema. |
| **ALT + HOME** | Seleciona o primeiro registro da visão. |
