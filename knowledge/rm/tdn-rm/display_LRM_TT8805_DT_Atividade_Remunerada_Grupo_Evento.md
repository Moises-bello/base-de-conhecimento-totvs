# GRUPO DE EVENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projeto* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Grupo de Eventos* |
| **Situação/Requisito:** | *Quando acessamos o cadastro do professor e vinculamos uma atividade remunerada (Atividade Extra),que não compõem salário, ao realizar o processo de reprogramação salarial no RM labore o mesmo fica vinculado na aba correta de Atividade Remunerada. Porém ao realizar o lançamento pelo grupo de eventos as atividades não são lançadas.* |
| **Solução/Implementação:** | *Ajustado o processo de lançamento de grupo de eventos para atender as atividades remuneradas.*  *Para que seja executado o usuário deve marcar o parâmetro Lançar Salário Composto, no Grupo de Eventos, e ter integração com Classis.Net.* |
| **Chamados relacionados:** | *TT8805* |
| **Versões/Release:** | *12.1.8* |
