# Ajuste na exibição da situação da disciplina

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educa Mobile |
| **Função:** | Situação de disciplina no TOTVS Educa Mobile |
| **Situação/Requisito:** | A situação da disciplina no TOTVS Educa Mobile está exibindo sempre a situação de matrícula da disciplina do aluno, mas quando existe uma situação de resultado final, o sistema deve exibir a situação de resultado final. |
| **Solução/Implementação:** | Foi realizado ajuste na situação da disciplina do TOTVS Educa Mobile, de maneira a exibir a situação de resultado final, quando esse estiver sido informado na matrícula na disciplina do aluno. |
