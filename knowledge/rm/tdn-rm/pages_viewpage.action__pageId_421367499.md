# Cadastro de Funcionário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Cadastro de Funcionário |
| **Situação/Requisito:** | Ao realizar a mudança de seção com a flag no parametrizador "Permitir alteração manual do salario" desmarcada, surge um aviso informando que há uma divergência no salario informado na tabela salarial, porem sendo verificado o salario esta igual ao o do nível e faixa informado na tabela vinculado a função/seção do funcionário. |
| **Solução/Implementação:** | Correção do aparecimento indevido da mensagem de salário divergente com o valor da tabela salarial mesmo quando ambos estão iguais. |
