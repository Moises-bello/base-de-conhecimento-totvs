# Geração de Certificados/Diplomas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Atividades Acadêmicas |
| **Função:** | Processo Gerar certificado/diploma |
| **Situação/Requisito:** | O processo de certificação não está preenchendo os campos da aba Diploma do cadastro de Cursos/Habilitações. |
| **Solução/Implementação:** | Alterado o processo de “Geração de Certificados/Diplomas” do menu: “Atividades Acadêmicas | Certificados/Diplomas” para preencher as informações do diploma na habilitação do aluno, quando escolhido a opção emitir “Diploma” ou “Certificado” (desde que seja a primeira via).  Obs.: Na tela do processo, a opção “Diplomação” permite executar o subprocesso “Gerar diploma/certificado”. |
