# Alteração da Grid de Pesquisa de Medicamentos na Prescrição Médica

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina(s) envolvida(s)** | | PEP | | Pesquisa de Medicamentos Prescrição | |
| **Ponto de Entrada:** | Prescrição Médica |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server®, Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Na Prescrição de Medicamentos do TOTVS Gestão Hospitalar, ao pesquisar um medicamento as colunas do resultado da pesquisa são apresentadas conforme o tamanho do nome do antibiótico, principio ativo e unidade.

## Procedimento para Utilização

**Exemplo:**

       1.            No TOTVS Gestão Hospitalar (RM Saúde), acesse PEP / Prescrição Médica.

                      O sistema apresentará a janela de prescrição.

       2.            Clique no botão Nova Prescrição e informe o nome de algum medicamento no campo de Pesquisa direta.

       3.            Na tela que será aberta, o sistema deve apresentar as colunas conforme o tamanho dos campos: nome do antibiótico, principio ativo e unidade.
