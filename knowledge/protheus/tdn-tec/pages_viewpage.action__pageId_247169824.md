O TDS 11.3 não reconhecia os projetos TOTVS do TDS 11.2, quando incorporados a área de trabalho via importação.

|  |  |
| --- | --- |
| Situação | Projetos TOTVS criados no TDS 11.2, não são reconhecidos no TDS 11.3, quando importados. |
| Ocorrência | Ao efetuar a importação de projetos TOTVS criados no TDS 11.2 para o TDS 11.3, estes não eram reconhcidos como tal. |
| Correção | Corrigido processo de importação, de forma que este reconheça projetos TOTVS criados no TDS 11.2, configurando-o corretamente no TDS 11.3. |
| Informações adicionais | * Referente ao chamado: TVRBGJ * Referente à ocorrência: [SSIM-1209](http://jira.totvs.com/browse/SSIM-1209) * Disponível em builds superiores a TDS 11.3, a partir de 30/09/16 |
