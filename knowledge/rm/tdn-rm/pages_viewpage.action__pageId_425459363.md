**Gerador de Saída**

---

O Gerador de Saídas é uma ferramenta criada para exportar dados de qualquer módulo do RM.  
    
 Quando se fala em layout refere-se a organização. Definir o layout de um escritório por exemplo é organizar as mesas e armários da melhor maneira possível para que se possa aproveitar o espaço da sala. No caso de rotinas legais, layout é um arquivo que define a organização das informações solicitadas: ordenação, hierarquia, formato de dados e formato de arquivo.  
    
 Sempre que se trabalha com exportação de informações deve-se definir um layout para auxiliar na leitura das mesmas por uma pessoa ou um outro sistema.  
    
 O gerador de saídas está disponível em: RM.exe | módulo Integração | aba Integração | opção Gerador de Saída  
    
 Estão disponíveis as opções:

* **Layouts**: nesta opção é possível acessar os layouts criados bem como incluir novos.

Quando se fala em layout refere-se a organização. Definir o layout de um escritório por exemplo é organizar as mesas e armários da melhor maneira possível para que se possa aproveitar o espaço da sala. No caso de rotinas legais, layout é um arquivo que define a organização das informações solicitadas: ordenação, hierarquia, formato de dados e formato do arquivo. Sempre que se trabalha com exportação de informações deve-se definir um layout para auxiliar na leitura das mesmas por uma pessoa ou um outro sistema.

* **Categoria**: permite criar e acessar as categorias disponíveis. A categoria é utilizada na classificação dos layouts. Na aba Perfis da Categoria do Gerador de Saídas, o preenchimento desta aba irá determinar quem terá acesso ao layout. Deve-se escolher os perfis para os quais deseja fornecer acesso clicando no botão incluir.
* **Tipo**: permite visualizar os tipos de layouts disponíveis.

***Nota:****O tipo de layout não é cadastrado pelo usuário. são tipos pré-definidos que são incluídos pelo analista responsável de cada produto. Os tipos são utilizados para separar os layouts por processos/aplicativos. Por exemplo: quando for criada uma chamada para layouts do financeiro não serão apresentados outros tipos de layout.*

* **Comparação**: permite selecionar dois layouts e realizar uma comparação entre os mesmos.
* **Executar**: permite executar um layout previamente criado.
