**Dúvida**Como gerar (exportar) ou comparar os arquivos XML do **SIGAGPE** (Gestão de Pessoal) e **SIGATAF** (Totvs Automação Fiscal) dentro do modulo **SIGATAF** para análise?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Com o objetivo de auxiliar em analises foi disponibilizado no sistema um botão que permite fazer a comparação entre o **XML** do evento gerado na integração do **SIGAGPE**  com **SIGATAF** , e o **XML** gerado pelo **SIGATAF** para transmissão ao **RET** (governo). Além da comparação é possível exportar o arquivo **XML** em um arquivo texto.  
  
Essa opção está disponível para os eventos **S-1200**, **S-1210, S-2299** e **S-2230**, acesse os artigos abaixo para saber como gerar.

* [S-1200 - Como gerar os arquivos XML do evento S-1200 (Folha de Pagamento) no modulo SIGATAF para análise](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500006729801);
* [S-1210 - Como gerar os arquivos XML do evento S-1210 (Pgto Rend Trab.) no modulo SIGATAF para análise](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500006741342);
* [S-2299 - Como gerar os arquivos XML do evento S-2299 (Desligamento) no modulo SIGATAF para análise](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500006744302);
* [S-2230 - Como gerar os arquivos XML do evento S-2230 (Afastamento Temporário) no modulo SIGATAF para análise](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500006730801).

**Observação**  
É possível executar o procedimento do artigo abaixo para gerar apenas o arquivo XML do **SIGAGPE**, para os casos que não trata-se das opções acima, ou ocorre um erro onde o evento não é gerado no **SIGATAF**.  
Artigo: **[Como exportar XML de eventos do esocial para analise do suporte técnico](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360006744012;)**
