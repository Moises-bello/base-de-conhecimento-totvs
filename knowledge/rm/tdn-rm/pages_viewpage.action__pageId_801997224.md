### **Venda**

* **Alteração Global do Cadastro da Condição de Venda:** Foi implementada a alteração do percentual do seguro via alteração global de regras para permitir zerar, caso o cliente deseje parar de cobrar o seguro ou mesmo alterar a taxa para um valor maior e menor. Para mais informações: [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=549501260)
* **Filtro para Integrar e Cancelar Parcelas da Comissão por Tipo de Comissão:** Agora é possível realizar a integração das parcelas de comissão, ou o cancelamento desta ação, através dos tipos de parcelas de comissão. Dessa forma, é possível tratar nestes processos apenas o tipo de parcela de comissão especificado, sem afetar os demais tipos. Para mais informações [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=773518793)
* **Parâmetro de Reajuste para "Salvar a memória de cálculo no log de database":** Para melhorar a performance do sistema e garantir a gestão de espaço do banco de dados, foi criado o parâmetro de reajuste para "Salvar a memória de cálculo no log de database". Para obter maiores detalhes [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=552575670)
* **Repositório de Arquivos para Banco de Terrenos:** Agora você pode anexar diversos tipos de formatos de arquivos ao *Banco de Terrenos*, com o uso do *FileRepo.* Para mais informações [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=841171931)
* **Exibição de Baixas Parciais de Parcelas de Financiamento e de Despesa no Cockpit 360:** Agora o Cockpit 360 exibe informações sobre as baixas parciais realizadas, tanto nas parcelas de financiamento, quanto nas parcelas de despesa. Para mais informações [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=715139212)
* **Exclusão de Cobrança:** Foi implementada no TCGI a opção de se excluir uma cobrança que tenha ocasionado um erro de lançamento. Por exemplo, pode ter ocorrido uma duplicação de cobrança devido a uma falha no sistema ou um erro humano durante o processo de entrada de dados. Corrigir esses erros é crucial para manter a precisão dos registros financeiros da incorporadora e garantir a transparência com os clientes. Além disso, manter registros precisos é essencial para evitar litígios futuros e manter a confiança dos clientes na empresa. Portanto, ao identificar um erro de cobrança, é importante agir prontamente para corrigi-lo e excluir a cobrança incorreta do sistema.  Esta opção foi liberada da versão 12.1.2306 em diante. [Clique Aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=780787693).

* **FileRepo nos documentos de aluguel:** Essa integração permite aos usuários anexar documentos de forma eficiente, utilizando a integração com o Google Drive fornecida pelo FileRepo. Disponível na tela de documentos, Contrato e imóvel. Para saber mais, [clique aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=834826635)
* **Anexo de evento financeiro do contrato:** Inclusão do anexo "Evento Financeiro", onde o usuário poderá visualizar todos os eventos avulsos pertinentes ao contrato de locação. Para saber mais, [clique aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=821578402)
* **Alteração de dia de vencimento no FPP:** A alteração de dia de vencimento permite maior flexibilidade no controle de lançamentos gerados para o fundos de promoção. Para saber mais, [clique aqui!](https://tdn.totvs.com/x/s1lzJw)
* **Geração de medição de faturamento após rescisão do contrato:** Nos casos de distrato ou rescisão, estamos ampliando a possibilidade de gerar medições para contratos nessa situação. Para saber mais, [clique aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=520659292)
* **Inclusão de parâmetro de data de emissão no fechamento de condomínio complementar:** O sistema passa a permitir alterar a data de emissão dos lançamentos financeiros ao integrar uma cobrança complementar. Para saber mais, [clique aqui!](https://tdn.totvs.com/x/cSF5Ig)
* **Valor Bruto na medição do aluguel complementar:** Disponibilizado o campo valor bruto no cadastro de medição. Para maiores detalhes, [clique aqui!](https://tdn.totvs.com/pages/viewpage.action?pageId=520659292)
