# GERAÇÃO DE USUÁRIO PARA PROFESSOR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de usuário para professor* |
| **Situação/Requisito:** | *Ao tentar executar o processo de geração de usuários para os professores foi verificado que o sistema não apresenta a opção de personalização de código de usuário, definição de senha, etc. Somente é mostrada a opção de segurança de senha e período de validade do usuário.* |
| **Solução/Implementação:** | *Ajuste no processo de geração de usuário para professor para a que seja exibido as opções de geração de usuário (personalização do código).* |
