![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16640539078551) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Sistema não apresenta Informações Exclusiva de Estágio no cadastro do Estagiário mesmo o campo Cat.Func. preenchido com "E".   
  
**Ambiente**

TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - Todas as versões  
  
**Solução**

Para o cadastro do estagiário, o sistema valida os campos Cat. Func (RA\_CATFUNC), Vin.Emp.RAIS (RA\_VIEMRAI) e Cat.Esocial (RA\_CATEFD).

Esse incidente ocorre, quando o preenchimento do campo **Categoria Esocial (RA\_CATEFD) está divergente de 901.**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31641640555287)

Após o preenchimento do campo Categoria Esocial incorreto, **não temos como ajustar via sistema**. Pois as categorias só poderão ser alterado dos tipos 102/103/105/106/111 para 101 conforme o novo Layout do Esocial.

Nesse caso será necessário **encerrar o vinculo empregatício e iniciar outro** com o preenchimento correto do campo Cat. Esocial (RA\_CATEFD).
