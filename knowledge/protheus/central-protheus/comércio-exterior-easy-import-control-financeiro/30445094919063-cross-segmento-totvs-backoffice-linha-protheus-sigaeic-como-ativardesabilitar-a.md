**Dúvida**Como ativar/desabilitar a contabilização online quando realizado a integração com módulo financeiro?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**

Para que a contabilização seja habilitada ou desativada é necessário acessar a rotina correspondente no módulo financeiro e alterar a perguntas nos parâmetros **F12**: "***contabiliza online? Sim ou não***", conforme o processo que está sendo efetuado: inclusão de títulos (**FINA050**), baixas a pagar (**FINA080**), compensação (**FINA350**).

![eee.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/30483092464279)

**Observação**:

```
O SIGAEIC não efetua contabilização ou possui Lançamento Padrão no SIGACTB.
```
