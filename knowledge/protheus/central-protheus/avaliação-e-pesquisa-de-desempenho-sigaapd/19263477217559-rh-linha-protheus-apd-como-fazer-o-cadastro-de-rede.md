![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19263461874455) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como fazer o cadastro de Rede?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Avaliação Pesquisa e Desempenho – Todas as versões  
  
**Solução**Neste cadastro são informadas as pessoas que participarão das avaliações e pesquisas de desempenho, chamadas de rede de relacionamentos, tais como: clientes internos, clientes externos, equipes, pares, outras áreas funcionais, superiores, gerência, parceiros, fornecedores, autoavaliação, etc.  
  
A rede de contatos inclui relacionamentos verticais, laterais e também com atores situados no ambiente externo da organização.

|  |
| --- |
| Help_buttonImportante:  A rede é um importante instrumento que facilita a seleção automática dos avaliadores de uma avaliação. |

  
A rede de relacionamento é vinculada ao tipo de avaliação que, por sua vez, é vinculado a cada avaliação de competência.  
  
No Portal de Relações Humanas, estas avaliações são apresentadas em divisão por seções que levam títulos padrão do Sistema.  
  
Exemplo:  
Visualização permitida ao Diretor:

|  |  |
| --- | --- |
| Seção | >> Minhas Avaliações |
| >> Minha Equipe |
| >> Pares |

  
Para permitir que esses títulos apresentem a descrição informada no cadastro de Redes, deve-se configurar o parâmetro [MV\_APDREDE](https://tdn.totvs.com/pages/releaseview.action?pageId=232819481), que habilitará a definição desses títulos.  
  
**Para cadastrar habilidades acesse o módulo 53 - SIGAAPD > Clique no menu Atualizações > Cadastros > Rede > Clique em Incluir e preencha os dados:**![Cadastro Rede SIGAAPD.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/19263508552215)
