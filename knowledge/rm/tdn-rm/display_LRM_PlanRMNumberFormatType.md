# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define o formato dos dados da célula.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| None | Define que não será aplicado um formato. |
| General | Define que será aplicado o formato geral. |
| Number | Define o formato numérico. |
| Currency | Define o formato de moeda. |
| Scientific | Define o formato científico. |
| Percent | Define o formato percentual. |
| Fraction | Define o formato de fração |
| Text | Define o formato texto. |
| Date | Define o formato de data. |
| Time | Define o formato de hora. |
| DateTime | Define o formato de data/hora. |
