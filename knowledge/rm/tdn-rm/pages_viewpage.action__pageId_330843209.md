# 1760795 RMSAU-2011DT Tela de aguarde ao alterar uma data de parcial na elaboração de contas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de contas |
| **Situação/Requisito:** | Cliente alega que ao alterar a data de uma parcial trava o sistema |
| **Solução/Implementação:** | Ao alterar a data inicial de uma parcial na elaboração de contas, deve mostrar mensagens com a passo a passo dos procedimentos para que o cliente possa acompanhar a execução das alterações referente as parciais da conta.  Desabilitar os controles da grid da elaboração para otimizar o processo de alteração da data da parcial. |
