# Novas dimensões Prótese e Equipe Cirúrgica no BI de Procedimento Cirúrgico

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Controle de Infecção Hospitalar (CIH) |
| **Função:** | BI de procedimento cirúrgico |
| **Situação/Requisito:** | Acrescentar no BI de procedimento cirúrgico as seguintes dimensões de análise:  1. Equipe Médica conforme parametrizado no Cadastro de Médicos.  Cadastros >> Médico >> Equipe Médica >> Anexos >> Médicos x Equipe  2. Dimensão de análise "Prótese", filtrando as cirurgias com prótese e sem prótese a partir da parametrização do Procedimento de Origem.  Cadastros >> Procedimento Cirúrgico >> Procedimento de Origem (Campo Prótese indicado) |
| **Solução/Implementação:** | As dimensões de BI solicitadas foram implementadas no BI de Procedimento Cirúrgico, para verificar as novas funcionalidades seguir os procedimentos indicados abaixo:  1º Dentro do RM CIH acessar as opções de menu:   Apoio Gerencial >> Componente Cirúrgico    2º Verificar as novas dimensões do BI criadas (Prótese e Equipe Cirúrgica):    3º Defina um período de data para busca de dados e clique no botão atualizar, após clique na dimensão Prótese e arraste para área de linha do BI:    4º Defina um período de data para busca de dados e clique no botão atualizar, após clique na dimensão Equipe Cirúrgica e arraste para área de linha do BI: |
