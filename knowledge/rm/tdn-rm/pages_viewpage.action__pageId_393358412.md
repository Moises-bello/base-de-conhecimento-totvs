# Campo de solução do requerimento sendo visualizado em todas as etapas.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | TOTVS Educacional. |
| **Módulo:** | Novo Portal do Aluno. |
| **Função:** | Requerimento. |
| **Situação/Requisito:** | O campo de solução de um requerimento não era visualizado mesmo quando estava concluído. Divergindo do CorporeRM que é possível visualizar. |
| **Solução/Implementação:** | Conforme verificamos com o time do Agilis e qualquer etapa de conclusão deve ser permitido que o campo de solução seja disponibilizado para consulta no nosso Portal. Verificamos com o suporte para saber se pode ocasionar algum problema de retirar essa validação implementada no nosso novo Portal e eles concordam que a solução deva ser exibida em qualquer uma das etapas de conclusão, assim como era no Portal antigo.. |
