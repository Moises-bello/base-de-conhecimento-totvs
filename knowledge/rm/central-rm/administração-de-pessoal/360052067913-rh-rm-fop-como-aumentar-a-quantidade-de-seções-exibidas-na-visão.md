Dúvida**  
Como aumentar a quantidade de seções exibidos na visão?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para aumentar a quantidade de eventos exibidos na visão, realize os seguintes passos:  
  
1. Acesse**Serviços Globais | Serviços | Servidores de Aplicação**;

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416879316375/mceclip0.png)

2. Ao abrir esta tela, caso exista cadastro do server **FopSecaoDataBR,**edite o cadastro.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416873749143/mceclip2.png)

3. Caso não exista, crie um novo cadastro informando no campo ID do Server o server **FopSecaoDataBR.**

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416857617303/mceclip1.png)

4. No campo **Número máximo de registro**, informe o máximo de eventos desejados para serem visualizados na visão ou informe 999999 e salve.

![](https://totvssuporte.zendesk.com/attachments/token/XbR41wQ6WzAbPyBv4Kbzdbx1U/?name=inline-1770618769.png)
