# PROCESSO SELETIVO RM - MATRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Relação de cadastro  Forma de inscrição x Tipo de ingresso.* |
| **Situação/Requisito:** | *Mesmo realizando a relação de cadastro entre Forma de Inscrição  e Tipo de Ingresso, ao executar o processo de matrícula do Processo Seletivo RM o  registro de Histórico de Ingresso é criado, porém não armazena a informação do Tipo de Ingresso.* |
| **Solução/Implementação:** | *Quando a relação de cadastro for realizada entre a Forma de Inscrição do aluno no processo seletivo e o Tipo de Ingresso no Educacional, ao executar o *processo de matrícula via Processo Seletivo RM,* o registro de Histórico de Ingresso será criado com o tipo de ingresso correto.* |
