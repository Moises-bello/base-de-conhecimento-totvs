# Pagamento Cartão de Crédito - (Cielo)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Pagamento Cartão de Crédito - (Cielo) |
| **Situação/Requisito:** | Necessidade de selecionar as transações de cartão para verificar o status na Cielo (Checkout Cielo) com o objetivo de verificar o chargeback e o cancelamento das transações. Se o status retornado pela Cielo indicar o cancelamento da transação, o cancelamento da baixa do boleto deverá ser efetuada. |
| **Solução/Implementação:** | Disponibilizado o processo de Cancelamento de Baixa para transações com Pagamento Cancelado e ChargeBack. Disponibilizado o processo na visão de Transações do Cartão de Crédito e Débito. Agora será possível executar o processo para um registro apenas. |
