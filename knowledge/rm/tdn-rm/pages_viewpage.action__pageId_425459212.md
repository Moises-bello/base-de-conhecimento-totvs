# Fazer inventário

---

Esta opção será utilizada para o usuário informar o número do exemplar a ser inventariado. O sistema irá gravar e verificar se exemplar existe, se existe mais de um exemplar com o mesmo numero de tombo e se exemplar já foi inventariado.

**Atenção:**  
Ao fazer o inventário de um exemplar, aparecerá um texto na tela informando se o inventário foi inventariado e, caso positivo, a data e hora do inventário.

# Limpar Inventário

---

Como a rotina de fazer inventário é realizada anualmente, usa-se limpar o inventário do ano anterior para a realização de uma nova rotina.  
Este processo limpa todo o inventário realizado na [unidade bibliotecária](https://tdn.totvs.com/pages/viewpage.action?pageId=425459667) corrente. Ele irá deletar os valores no campo "Inventário do Acervo" do exemplar na aba de identificação. Consiste em um Assistente em que é apenas necessário clicar em "Executar" para que o processo seja realizado.
