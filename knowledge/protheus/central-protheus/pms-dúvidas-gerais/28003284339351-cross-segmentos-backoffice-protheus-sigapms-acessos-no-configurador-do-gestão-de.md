![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28003240687639) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Quais são os acessos no configurador do módulo Gestão de Projetos?  
  
**Ambiente**Cross Segmentos - Backoffice Protheus - SIGAPMS - Todas as versões  
  
**Solução**Acessos de usuários (tópico 4: [Permissões, acessos e privilégios no Protheus](https://tdn.totvs.com/x/tEZpMg)) no configurador correspondentes ao módulo gestão de projetos (SIGAPMS):

|  |  |  |  |
| --- | --- | --- | --- |
| ACESSO | DESCRIÇÃO | EXPLICAÇÃO | ROTINAS |
| 3 | Excluir cadastros | Acesso que permite ou não o usuário excluir cadastros | Exceções Calendário - PMSA330 |
| 168 | Permite exportar planilha PMS para Excel | Permite ao usuário exportar planilhas para o Excel em determinadas rotinas do PMS | PMSXFUN |
| 170 | Exportar telas para Excel (Mod 1 e 3) | Permite ao usuário exportar planilhas para o excel em determinadas rotinas do PMS | PMSXFUNB |
