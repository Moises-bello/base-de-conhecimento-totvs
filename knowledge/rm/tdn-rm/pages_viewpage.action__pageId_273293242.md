# Alteração de Extrato de Caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão de Financeira |
| **Função:** | *Alteração de Extrato de Caixa* |
| **Situação/Requisito:** | Ao baixar um lançamento com meio de pagamento como cheque, o campo de Categoria do emitente que fica na aba dados adicionais do extrato não é preenchido, e com isso ao realizar uma alteração no extrato o sistema exibe o erro:  "Não foi possível validar CPF/CNPJ - Campo "Categoria" do Emitente deve ser preenchido." |
| **Solução/Implementação:** | Não apresentar erro "Não foi possível validar CPF/CNPJ - Campo "Categoria" do Emitente deve ser preenchido." ao tentar alterar um extrato proveniente de uma baixa com o meio de pagamento cheque |

| **Tickets relacionados:** | N/A |
| **Requisito:** | FIN000154 |
