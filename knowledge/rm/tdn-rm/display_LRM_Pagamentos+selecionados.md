Para os cenários onde é necessário selecionar títulos de múltiplos clientes/fornecedores para realização de um único recebimento, foi disponibilizado o recurso de seleção de pagamentos.

A partir desse recurso, é possível que a cada pesquisa o usuário inclua lançamentos a uma lista através do botão Adicionar, para após seleção de todos os títulos que deseja realizar a definição do pagamento.

Para usar o recurso, basta selecionar os títulos e clicar no botão Adicionar, ao incluir os títulos a lista fica disponível através de um ícone no canto inferior direito da tela, como demonstrado na imagem a seguir.

Os lançamentos podem ser incluídos e excluídos desta seleção até o momento anterior à inclusão do(s) meio(s) de pagamento. E além disso, o usuário pode fazer uma nova pesquisa que os pagamentos adicionados à lista permanecerão listados para definição de pagamento.

Após a seleção dos pagamentos, basta clicar em Definir Pagamento que o usuário será redirecionado para a tela de Meio de Pagamento. Ao adicionar um meio de pagamento, seja ele no valor total ou no valor parcial dos títulos selecionados, não e possível manipular os lançamentos selecionados, por isso, para excluir algum registro selecionado e necessário primeiro excluir o meio de pagamento informado para depois efetuar a exclusão de algum item da lista de pagamentos selecionados.

Quando o usuário volta para a tela de pesquisa, os títulos adicionados a lista permanecem lá, somente se a sessão for perdida ou fechada que os títulos precisam ser selecionados novamente.
