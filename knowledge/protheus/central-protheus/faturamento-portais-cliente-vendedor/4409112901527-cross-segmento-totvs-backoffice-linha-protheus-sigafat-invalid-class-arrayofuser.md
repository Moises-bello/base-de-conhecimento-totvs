Como tratar o erro do portal do vendedor: **invalid class \_ARRAYOFUSERFIELD on GRIDLINESEX(PWSXFUN.PRW)**  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Sigafat - Todas as versões  
  
**Solução**

Para solução basta alterar o parâmetro **MV\_WSUSRFI = .T.** no configurador.

**Para mais informações sobre portal do vendedor, acesse: [Portal do vendedor](https://tdn.totvs.com/x/eh59IQ)**
