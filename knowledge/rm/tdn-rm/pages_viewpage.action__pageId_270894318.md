# Pesquisa de Agendamento - Inclusão do Exame

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Atendimento / Agendamento / Agenda de Atendimentos / Pesquisar Atendimentos | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server® / Oracle® |
| **Tabelas Utilizadas:** | SZAGENDAMENTO |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

A melhoria consiste-se em permitir que o TOTVS Gestão Hospitalar possa apresentar os exames marcados ao pesquisar atendimentos na Agenda de Atendimentos.

## Procedimento para Utilização

1. Acesse o "**Atendimento / Agendamento / Agenda de Atendimentos**".
2. Clique no botão "Pesquisar" (Pesquisa Atendimentos).
3. Preencha pelo menos um das informações solicitadas (ex.: Pesquisar por:) / Clique em "Pesquisar" / O nome exame agendando será apresentado na coluna Exame.
