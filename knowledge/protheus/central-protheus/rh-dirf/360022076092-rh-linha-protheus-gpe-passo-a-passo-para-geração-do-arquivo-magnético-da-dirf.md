**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21369800205207)** Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como gerar o arquivo magnético da DIRF - GPEM590?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões.  
  
**Solução**1. Antes de gerar o arquivo Magnético, gere os dados conforme documento abaixo;  
[Gerar dados para DIRF](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020437012-MP-GPE-Passo-a-Passo-Gerar-Arquivo-DIRF-)  
  
2. Após gerar os dados e conferir os valores em Manutenção de Arquivo, acesse **Miscelânea >DIRF > Arquivo Magnético;**  
  
3. Preencha os parâmetros conforme necessidade;  
  
**Observação:** Para qualquer ano de entrega a pergunta "**Ano Calendário?"** serve para informar o ano efetivo de geração dos dados, por exemplo, se está gerando os dados do ano de 2024 para enviar em 2025, preencha a pergunta com 2024, já a pergunta "**Ano Referência?"  deve ser preenchida com**  o ano referência de envio dos dados, ou seja, o envio dos dados de 2024 será feito em 2025, assim, preencha a pergunta com 2025.  
As perguntas **"CPF Responsável?"** e "**CPF Resp. Pela Empresa?"** são obrigatórios no leiaute da DIRF, dessa maneira, preencha para que não gere erro no validador.
