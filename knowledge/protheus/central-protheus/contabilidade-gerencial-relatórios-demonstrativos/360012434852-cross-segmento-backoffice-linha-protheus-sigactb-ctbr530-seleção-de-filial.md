**Dúvida**

Ao emitir o relatório CTBR530 no formato "Não personalizável" o mesmo não esta respeitando o parâmetro "Seleciona Filial", no formato "Personalizável" após a confirmação é exibida a tela para seleção das filiais, o que não ocorre no modelo "não personalizável"

* Modo Personalizável (R4)
* Modo Não Personalizável (R3)

**Ambiente**Protheus – Contabilidade – A partir da versão 11.80  
  
  
**Solução**

 O tratamento do Pergunte "Seleciona Filiais" foi feito somente para o modelo de relatório R4. O modelo R3 não recebe certas implementações.

Segue o boletim técnico :[CTB\_BT\_Incl Perg Seleciona Filiais CTBR530](http://tdn.totvs.com/pages/releaseview.action?pageId=161351131)
