# PROVAS - GRUPOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Avaliação e Pesquisa* |
| **Função:** | *Provas com idiomas* |
| **Situação/Requisito:** | *Ao alterar o idioma de uma prova, o idioma dos grupos e dos períodos não estavam sendo alterados corretamente, causando impactos por exemplo na execução de avaliação institucional no educacional.* |
| **Solução/Implementação:** | *Foi identificado que se a prova possuir questões, a alteração eé feita corretamente, porém se a prova ainda não tiver questões, a alteração do idioma só era feita na prova. Foi feito o ajuste para que se o idioma for alterado o sistema altere também nos grupos e períodos, mesmo que a prova não possua questões.* |
