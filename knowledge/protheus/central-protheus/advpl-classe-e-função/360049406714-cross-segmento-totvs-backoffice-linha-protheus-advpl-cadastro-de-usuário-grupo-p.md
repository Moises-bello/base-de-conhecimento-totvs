![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como saber qual grupo é prioritário se nenhum está marcado como prioritário?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 12.1.17

**Solução**Neste caso terá que usar a função **FWSFUsrGrps(),** pois mesmo que não tenha nenhum grupo marcado como priorizado, o sistema irá considerar sem o primeiro grupo retornado pela função como prioritário.
