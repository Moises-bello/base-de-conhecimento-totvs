![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16207244373399) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Como configurar campo para que aceite apenas caracteres do tipo alfabético (apenas letras)?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12  
  
**Solução**No configurador, entre na rotina **Base de dados** pelo caminho **Base de dados > Dicionário > Base de dados**, pesquise pela tabela e clique em alterar:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/16206752188311)  
  
Selecione o campo que deseja alterar, no exemplo abaixo irei alterar o campo Nome e clique em Alterar  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/16206824592023)  
  
No campo Formato, preencha com A de acordo com o tamanho do campo, se o campo tiver tamanho 10, deve ser preenchido A para cada caractere do campo, conforme exemplo abaixo:  
AAAAAAAAAA ou @! AAAAAAAAAA para apenas maiúsculas:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/16207154568727)  
  
Salve a alteração e após isso, no ícone abaixo salve em modo exclusivo:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/16207132839319)
