# ALTERAR PARÂMETROS DE ETAPAS DE ÁREAS OFERTADAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Alterar parâmetros de etapas de áreas ofertadas* |
| **Situação/Requisito:** | *Quando o processo seletivo não possui período de seleção, ao executar o processo de alterar etapas, a data do período de seleção é exibida incorretamente. Situação ocorre também mesmo quando o processo seletivo possui período de seleção cadastrado corretamente.* |
| **Solução/Implementação:** | *Foi feito o ajuste para que se o processo seletivo não tiver período de seleção informado, os campos de data não serão exibidos e será exibido uma mensagem informando que o processo seletivo não possui período de seleção no calendário e para os processos seletivos que possuem cadastro de período, foi feito o ajuste para que estas datas sejam exibidas corretamente.* |

| **Chamados relacionados:** | *TUZBG1* |
| **Requisito (ISSUE):** | *N/A* |
