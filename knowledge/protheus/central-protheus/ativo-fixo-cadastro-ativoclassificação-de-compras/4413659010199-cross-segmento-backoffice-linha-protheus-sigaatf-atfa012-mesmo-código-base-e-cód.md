**Dúvida**

O sistema permite cadastrar mais de bem com o mesmo código base ?

Essa possibilidade atribui algum vinculo entre os bens cadastrados?

**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus) - Ativo Fixo  - Todas as versões  
  
**Solução**

**Mesmo código base e código de itens diferentes**

      No cadastro do ativo ou na sua classificação é possível informar o mesmo código base com itens diferentes.

      Este procedimento possibilita apenas a identificação  de vários itens relacionados ao mesmo bem, pois não haverá um vinculo obrigatório entre eles.
