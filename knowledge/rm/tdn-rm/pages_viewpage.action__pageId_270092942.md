# Relatório Listagem de Lançamentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Listagem de Lançamentos |
| **Situação/Requisito:** | Ao gerar o relatório Listagem de Lançamentos no módulo de Gestão Contábil, marcando a opção: "Listagem de lançamentos e rateios" o sistema apresenta a seguinte mensagem:  "All queries combined using a UNION, INTERSECT or EXCEPT operator must have an equal number of expressions in their target lists.” |
| **Solução/Implementação:** | Ajuste na consulta quando a opção "Listagem de lançamentos e rateios" esta marcada para que as colunas que contém o código reduzido faça parte da consulta para o rateio. |
