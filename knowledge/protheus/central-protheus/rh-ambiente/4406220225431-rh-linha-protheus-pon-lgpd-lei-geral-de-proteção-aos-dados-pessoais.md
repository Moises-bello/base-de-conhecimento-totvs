**Dúvida**Imformações sobre **LGPD (Lei Geral de Proteção aos Dados Pessoais)** no Protheus Recursos Humanos.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**O Protheus possui rotinas e recursos para que nossos clientes façam o **controle de dados protegidos** no sistema, normalmente é um dos itens previstos em **legislações de [controle de dados pessoais](https://tdn.totvs.com/display/public/PROT/Controle+de+dados+protegidos+-+Protheus+12)**, no Brasil é chamada de **LGPD(Lei Geral de Proteção de Dados)**.  
A [**Anonimização de Dados Protegidos**](https://tdn.totvs.com/pages/releaseview.action?pageId=532024154) é o último ato para eliminar definitivamente informações sensíveis ou pessoais vinculadas à uma determinada pessoa.  
  
Todos os dados contidos no **[*Cadastro de Dados Protegidos* enviados pela Totvs](https://tdn.totvs.com/pages/releaseview.action?pageId=532647279)** são apenas sugestões. O cliente sempre poderá conseguir incluir ou alterar dados  das  informações que serão utilizadas pelo sistema.
