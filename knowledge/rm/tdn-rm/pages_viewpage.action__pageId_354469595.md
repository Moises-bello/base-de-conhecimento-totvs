# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Classificação de Risco |
| **Situação/Requisito:** | Quando a gente evolui e um paciente está na observação e depois vai finalizar, o programa acaba perguntando se deseja finalizar outro paciente (o paciente que está na observação há mais tempo). Se não tivermos atenção a gente finaliza o paciente errado |
| **Solução/Implementação:** | Não atualizar a grid com a mudança do status para não provocar o erro. |
