![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29093110527767) Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Como é realizado um processo de **Comercialização Clássica com Operação Triangular PT 5 em Gestão Agroindústria - Manutenção**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução  
Dados Gerais:**

| Produto: | TOTVS Agro Beneficiamento |
| --- | --- |

| Linha de Produto: | Linha Protheus |
| Segmento: | Agroindústria |
| Módulo: | Gestão de Agronegócio |
| Função: | OGA250 - Romaneio com Pesagem |
| Ticket: | 9516363 |
| Requisito/Story/Issue (informe o requisito relacionado) : | DAGROCCO-3722 |

**Requisito/Requisito:**Disponibilizar e realizar os ajustes necessários para a comercialização clássica na opção do menu **"Informar Docto Referência"** para vincular as notas.  
  
**Solução:**Realizado os ajustes necessário no romaneio para a comercialização clássica para disponibilizar a opção do menu **"Informar Docto Referencia"**, que permite realizar o vinculo da **NF** de venda do cliente na **NF** de remessa da venda a ordem, este vinculo fica registrado na tabela **N8J**. Após realizar este vinculo poderá ser realizado o envio da **NF** de remessa da venda a ordem para o **SEFAZ**.

Abaixo segue os passos para gerar as **NF** de venda para contratos com operação triangular.
