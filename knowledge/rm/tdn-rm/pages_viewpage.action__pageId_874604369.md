O usuário poderá visualizar e cancelar a recorrência de contratos previamente habilitados para pagamento recorrente.

Para que essa opção fique disponível:   
No sistema habilitar para utilização do TPC, caso tenha dúvidas [clique aqui.](https://tdn.totvs.com/x/jAhOI)  
O usuário deverá marcar o parâmetro "15.02 - Tesouraria | Geral 3/4 | Permitir habilitar pagamento automático".

Caso o usuário cancele a recorrência, para habilitar novamente é realizado somente com um novo pagamento. Para mais informações, [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=874604387).

Visualizar Recorrência

Após clicar no menu de gestão da recorrência, o usuário tem opção de visualizar a recorrência juntamente com o cartão que será utilizado para pagamento automático.

Se o usuário selecionar um título que pertença a um contrato que está em recorrência, o campo para "Habilitar pagamento automático" na tela de carteira digital e na tela de dados de endereço do cartão será mostrado desabilitado.

Remover Recorrência

Ao excluir uma recorrência para um serviço/cartão e o usuário voltar para a tela de extrato financeiro, a tela de extrato carregará novamente os títulos exibidos.

## **TABELAS UTILIZADAS**

* FRECORRENCIACARTAO - Tabela principal de registro de pagamento automático
* SRECORRENCIACARTAO - Tabela que armazenará dados educacionais para pagamento automático
