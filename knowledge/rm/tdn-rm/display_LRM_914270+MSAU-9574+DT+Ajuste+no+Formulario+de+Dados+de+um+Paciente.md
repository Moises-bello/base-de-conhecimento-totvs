# Ajuste no Formulário de Dados de um Paciente

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Dados de um Paciente |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu: **Atendimento/Dados de um Paciente**, selecionar um paciente e clicar duas vezes, é possível verificar que ao preencher os campos complementares e salvar o registro, ele próprio não reproduzia os dados gravados anteriormente, quando realizado um novo acesso ao formulário. |
| **Solução:** | Foram realizados ajustes no formulário para que os dados sejam registrados adequadamente. |
