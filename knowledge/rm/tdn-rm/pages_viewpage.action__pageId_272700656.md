# Retirar Campos Obrigatórios da Classificação de Risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Classificação de Risco |
| **Situação:** | É necessário remover a obrigatoriedade de informar o nome da mãe e a data de nascimento na Classificação de Risco, pois as vezes essa informação não está disponível e é informado no Registro de Atendimento. |
| **Solução:** | Alterado para que não seja obrigatório a informação do Nome da Mãe e a data de nascimento da Classificação de Risco. |
