O Book de Relatórios do TOTVS Avaliação e Pesquisa tem o objetivo de otimizar o dia a dia dos usuários.

Os relatórios importados não poderão ser alterados mas temos a possibilidade de executar a "Cópia" do relatório para realizar a alteração conforme a sua necessidade.

Para a parametrização, o usuário deverá ter um conhecimento prévio da estrutura da base de dados, para que os filtros sejam aplicados de forma correta e retorne a informação desejada.  
  Segue a lista dos relatórios disponíveis:

|  |  |  |
| --- | --- | --- |
| **Código** | **Nome** | **Descrição** |
| TSTREL0001 | Provas Cadastradas | Este relatório apresenta todas as provas cadastradas em determinada filial |
| TSTREL0002 | Provas Realizadas e Número de Vezes | Este relatório lista as provas por tipo de prova e número de vezes que foram realizadas |
| TSTREL0003 | Ranking de Candidatos por Provas | Este relatório apresenta o ranking de candidatos por prova e o rendimento de cada candidato |
| TSTREL0004 | Quantidade de Questões por Nível de Dificuldade | Este relatório lista a quantidade de questões com separação por nível de dificuldade, área e matéria |
| TSTREL0005 | Quantidade de Acertos das Questões por Nível de Dificuldade | Este relatório lista a quantidade de acertos nas questões utilizando separação por nível de dificuldade |
| TSTREL0006 | Prova Corrigida | Este relatório exibe a prova realizada, a correção das questões e pontuação dos candidatos |
