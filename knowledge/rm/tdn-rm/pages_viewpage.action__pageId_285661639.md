# Relatório Razão Contábil Saldo Anterior

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Razão Contábil |
| **Situação/Requisito:** | Após utilizar parênteses como indicador de Saldo Credor, o valor de centavos está sendo cortado para o campo de saldo anterior em 1(um) dígito ao utilizar filtro de contas. Isso também acontece para o relatório de Retrospectiva. |
| **Solução/Implementação:** | O relatório Razão Contábil foi alterado para que o Saldo Anterior das contas seja exibido sem cortes quando é marcado nos parâmetros de sistema a opção (5) para imprimir saldo credor entre parênteses. |
