**Dúvida**  
Como imprimir o relatório para comparação do valor realizado X orçado?  
   
 **Ambiente**  
Protheus – Contabilidade Gerencial – A partir da versão 11.80  
   
**Solução**  
 Para solucionar essa dúvida, realize os seguintes passos:

|  |  |
| --- | --- |
| 1. | Para imprimir o relatório comparativo entre os saldos Orçado, Previsto e Realizado nos doze meses (períodos), a configuração das perguntas deve ser: |

Tipo de Saldo: 0 (Orçado)

Saldo a Comparar: 21 (Previsto e Realizado)

|  |  |
| --- | --- |
| 2. | Para imprimir o relatório comparativo entre os saldos Orçado e Realizado nos doze meses (períodos), a configuração das perguntas deve ser: |

Tipo de Saldo: 0 (Orçado)

Saldo a Comparar: 1 (Realizado)

|  |  |
| --- | --- |
| 3. | Para imprimir o relatório apenas do saldo Realizado nos doze meses (períodos), a configuração das perguntas deve ser: |

Tipo de Saldo: 1 (Realizado)

Saldo a Comparar: (em branco)

A apuração dos saldos ou movimentos será feita conforme a combinação de entidades selecionadas através das perguntas “Usa Conta”, “Usa Centro de Custo”, “Usa Item” e “Usa Classe de Valor”.
