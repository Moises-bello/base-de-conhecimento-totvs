*Atenção!*  
Esta funcionalidade só está disponível para as bases já migradas para o Novo Modelo do BackOffice.  
   
A execução deste processo removerá todos os vínculos do(s) Participante(s) selecionado(s) com os lançamentos contábeis.   
   
A remoção do vínculo consiste em limpar o campo *participante* de todos os lançamentos contábeis que estiver preenchido com o(s) participante(s) selecionado(s) para este processo.
