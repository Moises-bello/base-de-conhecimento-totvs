**Campos Complementares**   
 Por esta opção, você poderá cadastrar campos adicionais para armazenar dados no sistema.  
  
 Podemos cadastrar campos complementares para os seguintes cadastros:  
    
                 - Empreendimento  
                 - Unidade  
                 - Sub-unidade  
                 - Venda  
                 - Distrato  
                 - Compradores  
                 - Vendedores  
                 - Comissão  
    
 **Nome da Coluna:** Informe um nome para o campo complementar.  
  
 **Descrição:** Informe a descrição do campo complementar.  
  
 **Especificação – Tipo:** Escolha o tipo da coluna a ser inserida, podendo ser: Inteiro, Real, Data, Texto e Alfanumérico. Campos Alfanuméricos pode ser do tipo Email, URL e Skype.  
  
 **Tamanho:** Se o tipo for Alfanumérico, informe o tamanho do campo.  
  
 **Valor default:** Informe o valor default para o campo. Este valor tem duas funções:  
  
 • Informar qual o valor default que o sistema irá utilizar quando da inclusão de um novo registro.   
 • Alterar o respectivo campo complementar dos registros que estiverem com o referido campo vazio.  
    
 **Tabela Dinâmica:** Nesse campo pode ser informada uma tabela dinâmica. Essas tabelas são cadastradas no menu Cadastros, Tabelas Dinâmicas.  
 **Atenção:**  
 Ao clicar no botão "excluir", o campo complementar passará a ficar inativo, permanecendo na base de dados. Para ativá-lo novamente, clique no ícone "**Tornar o campo complementar ativo**".  
 O nome da coluna não poderá conter números, somente caracteres serão aceitos.
