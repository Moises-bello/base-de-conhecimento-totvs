Este processo é utilizado para gerar a carga inicial das informações para a serem enviadas ao parceiro.

**Integração:**onde deve ser selecionado qual a integração Ativa do  que será feita a carga inicial.

**Entidades:** será mostrada todas as entidades vinculadas a integração para serem selecionadas quais serão enviadas.

**Enviar Demitidos:**será marcado quando se quer buscar os dados dos demitidos.

**Observação: Somente serão gerados os registros de mensagens na Fila de Mensagens os dados não serão enviados automaticamente.**
