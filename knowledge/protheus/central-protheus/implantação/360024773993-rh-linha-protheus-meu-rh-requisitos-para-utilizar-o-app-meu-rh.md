**Dúvida**  
Quais os requisitos para  utilizar o APP Meu RH Linha  Protheus?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - MEU RH – Todas as versões  
  
**Solução**  
Para utilizar o aplicativo MEU RH é necessário possuir o mesmo padrão de licenciamento do Portal GCH - Gestão de Capital Humano ou as licenças **Corporativo, On** ***demand*****, Totvs I ou App Portal MEU RH**. Caso não tenha ou não saiba informar acionar seu **ESN - Executivo de Soluções de Negócios** para  orientação.  
Referente a licença, segue abaixo o documento onde detalha o consumo de licenças do MEU RH:  
  
[**Consumo de Licenças e Configuração Apropriada**](https://tdn.totvs.com/pages/viewpage.action?pageId=654098131)  
  
Ter acesso aos Módulos **07 (SIGAGPE), 16 (SIGAPON), 18 (SIGATCF) e 53 (SIGAAPD).**

* Possuir arquivos atualizados do portal **MEU RH**  
  [**Onde baixo a versão mais recente e como atualizar os arquivos do Portal Meu RH?**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360043729034)
* Para o correto funcionamento do MEU RH é necessário que a base esteja atualizada, com **LIB, Binários, DBAccess**, pois diversas funções da tecnologia e Framework Protheus são utilizadas.  
    
  Para acesso via aplicativo MEU RH
  + Android 7.0 ou superior   
    Alguns certificados não estão sendo aceitos nas versões do Android 8.0 e 9.0, nestes casos, devem ser utilizados o Android a partir da versão 10.0.
  + iOS 15.0 ou superior
  + Não ter ***root/jailbreak*** habilitado no dispositivo
  + Acesso à *internet*
  + Acesso externo ao servidor estar liberado (para acesso via **3G/4G**)
  + É altamente recomendado que seja implementado o **protocolo SSL (*****Secure Socket Layer*****)** para garantir que os dados dos colaboradores trafegados fiquem menos vulneráveis. Consulte a área de TI da sua empresa e/ou empresas certificadoras.
  + O SSL consegue fazer o uso de criptografia e garante o sigilo das informações que são depositadas pelo usuário dentro dos serviços oferecidos pela web. A consequência disso, é uma maior segurança durante a navegação.

Sem o uso do protocolo SSL algumas funcionalidades do aplicativo que utilizam geolocalização para funcionamento se tornam inoperantes.  
  
**Aviso Importante**:  
É altamente recomendado utilizar o protocolo **SSL** no aplicativo MEU RH devido as exigências da LGPD. Orientamos que se programem para a implantação do MEU RH considerando a utilização do protocolo **HTTPS/SSL.**
