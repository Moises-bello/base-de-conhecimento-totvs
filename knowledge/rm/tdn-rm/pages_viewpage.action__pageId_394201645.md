# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.20 |
| **Ocorrência:** | Reabrir Exercício Contábil |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do processo:**  Neste processo o usuário desfaz o último exercício fechado, voltando o Ano/Período anterior para atual, e com isso, atualizando as datas da contabilidade para as datas anteriores.  A execução deste processo move **”retorna”** os dados de contabilização das tabelas de histórico para as tabelas de contabilização atual.  **Exemplo:**  • Apaga os saldos das contas do exercício identificado para reabertura; • Modifica o exercício contábil em aberto, retornando com a data inicial 01/01/2010;  **Importante:**  • Caso o usuário precise reabrir um exercício mais antigo, ele deverá ir reabrindo um a um os exercícios até chegar ao exercício desejado.  Obs. Caso não tenha período para ser reaberto será apresentado a seguinte mensagem no processo:      Isso pode ocorrer quando a coligada nunca passou pelo processo de Fechamento de período ou foi realizado a Liberação de Período |
