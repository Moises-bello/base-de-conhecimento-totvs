![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26237307489175) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Por que cadastro de verbas apresenta mensagem: Valor Inválido (Id p/Calculo)?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26237307490839)  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**O sistema apresenta a mensagem pois foi selecionado id de cálculo para nova verba onde o mesmo já está sendo usado.

Em cadastro verbas só é permitido uma verba por código identificador de cálculo.

**Exemplo:**

Selecionado id 0891, onde o id de cálculo já está vinculado em outra verba.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26237346821271)
