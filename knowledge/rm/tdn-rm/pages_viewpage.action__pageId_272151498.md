# GERAÇÃO DE PLANO DE AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de Plano de Aula* |
| **Situação/Requisito:** | *Foi cadastrado no calendário um Feriado sem o checkbox "Feriado?" marcado do tipo Municipal. Ao tentar gerar plano de aula para uma turma/disciplina e marcar a opção para NÃO GERAR PLANO DE AULA PARA O TIPO DE FERIADO: Municipal e executar o processo o sistema apresenta uma mensagem de erro.* |
| **Solução/Implementação:** | *Ajuste na geração do plano de aula quando se considera para não gerar plano de aula para o tipo de feriado municipal, para o mesmo seja gerado de forma correta.* |
