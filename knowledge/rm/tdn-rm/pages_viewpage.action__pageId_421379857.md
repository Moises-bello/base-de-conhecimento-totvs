# DATA DE PREVISÃO DE ENTREGA NO ENVIO DE E-MAILS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Envio de e-mails |
| **Situação/Requisito:** | A rotina de envio de e-mails está gerando a data de devolução com a hora  Na tela de parâmetros do biblios, ao entrar nos parâmetros de envio de e-mails, a lista de exceções para envio vem vazia e só quando tento incluir outra exceção que aparecem os itens já cadastrados. |
| **Solução/Implementação:** | A rotina de envio de e-mails foi alterada para mostrar a data de devolução prevista sem a hora (somente para empréstimos com tipo de prazo por 'dia').  A tela de parâmetros do bliblios foi alterada para mostrar corretamente a lista de exceções para envio de e-mail ao entrar na tela. |
