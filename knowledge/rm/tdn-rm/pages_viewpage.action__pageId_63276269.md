**Introdução**

No ambiente do RM (nova MDI) é possível realizar a chamada de módulos do RM em Delphi para recursos ainda não migrados. Portanto, basta que os módulos estejam instalados que este recurso poderá ser usado.

Objetivo: Iniciar o executável do módulo selecionado no RM, para acessar os recursos ainda não migrados.

1. Faça login no RM.

     2. Selecione o módulo desejado. Neste caso usaremos como exemplo o Educacional. Educacional | Educacional.

    3. Serão carregadas mensagens padrões do sistema. Atente-se para a mensagem abaixo: Iniciar Executável do módulo. Clique nela.

    4. Outra forma de acionar esse recurso é através do botão Iniciar executável do módulo, conforme a imagem abaixo.

   5. O executável do módulo selecionado será carregado. Basta informar o usuário e senha e realizar login normalmente.

   6. Aplicativo RM Classis Net (Educacional) carregado.

    7. No aplicativo o caminho inverso também é possível. Para acessar o RM basta acessar Sistema | Abrir RM.Net.

    Obs: Essa ação somente surtirá efeito se o RM realmente não estiver aberto, pois somente uma instância do pode ser aberta por vez na mesma máquina.
