# Log Alteração Cadastro Leitos

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Cadastro de Leitos | | Controle de Ocupação de Leitos | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER® e ORACLE® |
| **Tabelas Utilizadas:** | SZLEITOLOG |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Melhoria possibilita que sejam logadas as alterações realizadas no Cadastro de Leitos e no Controle de Ocupação de Leitos, assim como o motivo da alteração, usuário e data de alteração.

## Procedimento para Utilização

       1.          Acesse**Cadastros/ Registro e Controle /Leitos**.

       2.          Acesse **Atendimento/Internação/Controle de Ocupação de Leitos**.

       3.           Para visualizar o log de alterações acesse **Cadastros/Registro e Controle/Leitos/****Anexo / Log de Leitos**.
