Este é um cadastro básico para Tipos de Áreas do Imóvel. Este cadastro está disponível no módulo de aluguéis do TIN. Para acessar este cadastro basta acessar Aluguel / Cadastros / Tipo de Área do Imóvel.  
 Os campos disponíveis neste cadastro são:

* **Código**
* **Descrição**

Os registros de Tipo de Área do Imóvel são usados no cadastro de Área do Imóvel.
