# Erro na Classificação de Risco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Realizar a Classificação de Risco do paciente |
| **Situação:** | Ao editar os dados de um atendimento realizado via classificação de risco, o mesmo estava desaparecendo da aba *Atendimento Médico*. |
| **Solução:** | Realizada a correção no *Registro de Atendimento Externo*, que estava alterando o médico do atendimento da *Classificação de Risco*, removendo ele do painel. |
