**Dúvida**A verba de falta id 0054 é considerada para proporcionalizar os lançamentos fixos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Por padrão do sistema as faltas **não** serão consideradas para proporcionalizar o cálculo quando o funcionário possui lançamentos fixos.

Para proporcionalizar o cálculo pelos dias trabalhados, o parâmetro abaixo deve estar com **"SIM".**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000766381)

O sistema irá proporcionalizar o cálculo em situações de Férias, Admissão ou Afastamento.
