Na tela do Processo é possível selecionar para quais coligadas o cadastro será copiado.

Para que o sistema realize a cópia, é necessário que os **[Parâmetros do Fabricante](https://tdn.totvs.com/x/GstEGQ) (Tabelas | Fabricantes)** e a **[Máscara das Tabelas de Classificação](https://tdn.totvs.com/x/GstEGQ) (Tabelas | Classificação)** sejam idênticos entre as coligadas.  
Quando essa condição é atendida, o sistema copia o fabricante juntamente com as respectivas tabelas de classificação.

***Observação**:* É possível selecionar se o registro irá substituir o existente na Coligada destino.
