Quais são as funcionalidades disponíveis dentro da rotina Gestão de Funcionários (GPEA011)?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução:**A rotina de Gestão de Funcionários (GPEA011) permite a administração completa dos dados dos Funcionários, incluindo cadastros, cálculos e gestão de eventos.  
  
**->** A rotina fica localizada no menu **Atualizações > Funcionários > Gestão de Funcionários,** e no botão **Funcionários,** temos acesso nas rotinas listadas abaixo:

|  |  |
| --- | --- |
| **Opção** | **Funcionalidades Disponíveis** |
| Funcionário | Visualizar, Incluir, Alterar, Excluir, Config. Cópia, Copiar, Período de Gestação |
| Dependentes | Visualizar, Incluir, Alterar, Excluir |
| Beneficiários | Visualizar, Incluir, Alterar, Excluir |
| Contr. Dias Direito | Visualizar, Manutenção, Excluir, Imprimir |
| Ausências | Visualizar, Manutenção, Excluir |
| Histórico Salarial | Visualizar, Atualizar |
| Transferência | Visualizar, Em lote |
| Período de Estabilidade | Visualizar, Incluir, Alterar, Excluir |
| Funcionário Temporário | Visualizar, Alterar, Excluir |

**->** Já no botão **Outras Ações**, estão disponíveis as seguintes funcionalidades:

|  |  |
| --- | --- |
| **Opção** | **Funcionalidades Disponíveis** |
| **Cálculos:** |  |
| - Férias | Incluir, Visualizar, Excluir |
| - Rescisão | Incluir, Visualizar, Excluir |
| **Lançamentos:** |  |
| - Lançamentos Mensais | Incluir, Alterar, Visualizar, Excluir, Lanc. Per. Vert, Lanc. Per. Hor |
| - Valores Futuros | Visualizar, Incluir, Alterar, Imprimir |
| - Valores Fixos | Visualizar, Incluir, Alterar, Excluir, Gerar Lanctos |
| - Acumulados | Visualizar |
| - Recibo Pagamento | Visualizar |
| - Tarefas | Visualizar, Incluir, Alterar, Excluir, Imprimir |
| **Legenda** | - |
| **Imprimir Browse** | - |
