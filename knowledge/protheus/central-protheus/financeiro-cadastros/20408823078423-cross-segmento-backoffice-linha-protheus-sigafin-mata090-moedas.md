**Dúvida**  
Como retirar a configuração de moedas toda vez que entrar em um módulo do Protheus?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Financeiro - Todas as versões  
  
**Solução**  
Para a mensagem não ser apresentada existe a seguinte opção:

A opção abaixo para não apresentar ao usuário a tela da moeda.

|  |  |  |  |
| --- | --- | --- | --- |
| **49** | **"Cadastra moeda na abertura"** | **Define se será apresentada a tela de moedas na abertura do sistema.** | **Abertura do sistema** |

É um acesso que deve ser definido no cadastro de usuário e grupos.  
Acesso 49
