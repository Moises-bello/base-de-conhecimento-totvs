![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16037063349783) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível realizar o empréstimo de EPI via Biometria?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Segurança e Saúde Ocupacional - **Todas as versões.**  
  
**Solução**Atualmente o sistema não possui a funcionalidade de empréstimo de EPI utilizando a biometria.

Contudo, a TOTVS possui uma nova ferramenta em parceria junto a NG >> [Quírons](https://quirons.com.br/), onde através deste o controle de empréstimos são realizados via biometria.
