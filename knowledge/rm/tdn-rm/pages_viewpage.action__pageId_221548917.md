# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento |
| **Função:** | Realocação Orçamentária |
| **Situação/Requisito:** | Na tela de transferência do orçamento, no grid de seleção dos orçamentos de destino hoje está apresentando uma listagem de todos os orçamentos do período. No cliente essa grid vai trazer muitas informações (mais de 1000 linhas), e da forma que está o cliente não terá como o cliente utilizar essa opção. A sugestão é trocar essa grid por um lookup multirecord que possa ser filtrado. |
| **Solução/Implementação:** | A partir de agora os orçamentos de destino não serão carregados automaticamente, mas sim através de um lookup multirecord onde o usuário selecionará os possiveis destinos e informará o valor para cada registro selecionado a partir de uma origem. |
