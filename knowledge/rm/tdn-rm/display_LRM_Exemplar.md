**Identificação**

Nesta tela o usuário pode realizar os cadastros gerais dos exemplares.

* Código  
   Identificador do exemplar no Banco de Dados. Este código é gerado automaticamente.
* Número do exemplar  
   O usuário pode definir um número para o exemplar.
* Edição  
   Nesta campo é possível informar a edição.
* Complemento da edição  
   Local onde é informado o completo da edição, caso exista.
* Número do tombo  
   Número identificador do exemplar nas estantes. Ele é gerado ao executar o botão "Número do tombo".
* Número de tombo (antigo)  
   Cadastros de antigos tombos, caso exista.
* Código auxiliar  
   Complemento que pode ser utilizado pela biblioteca.
* ISBN  
   Campo utilizado para cadastro do ISBN.
* Volume  
   São cadastrados os volumes do exemplar.
* Número do tomo  
   Pode ser considerado sinônimo de volume, quando a obra possui muitas divisões.
* Número de chamada (Localização)  
   Número que identifica o exemplar na estante
* Situação do exemplar  
   O usuário poderá cadastrar diferentes situações do exemplar.  
    
  **Observação**  
   Ao habilitar o parâmetro "Circulação: Bloquear este exemplar para empréstimo (Circulação Interna)" o exemplar será emprestado de acordo com os parâmetros adotados de exemplares de circulação interna.  
    
  **Dados de aquisição**
* Nesta tela o usuário pode cadastrar os dados de aquisição do exemplar.
* Moeda  
   O usuário pode informar a moeda utilizada.
* Valor da aquisição  
   No campo é possível informar o valor de aquisição.
* Tipo de aquisição  
   O usuário pode informar como foi realizada a aquisição. Exemplos: compra, doação, permuta, etc.
* Data do registro  
   É informado a data de registro do exemplar.
* Data de compra  
   É informado a data de compra do exemplar.
* Número da nota fiscal  
   É possível informar o número de controle da nota fiscal.
* Fornecedor  
   Através da Lookup o usuário pode escolher fornecedor entre os cadastrados.
* Informações complementares do tipo de aquisição  
   É possível informar dados adicionais.
* Dimensão  
   É possível informar as dimensões do exemplar como comprimento, altura, largura e peso.
* Dados de inclusão/alteração  
   Campos de preenchimento automático. A data de inclusão é quando o exemplar é criado e alteração é a data da última alteração.  
    
  **Dados da baixa**  
   O usuário pode informar a data de baixa do exemplar e data de retorno além da justificativa da baixa.  
    
  **Informações adicionais**  
   É possível informar dados adicionais do exemplar.  
    
  **Observações**  
   Caso o parâmetro "Exibir informações da situação do exemplar na devolução" estiver habilitado o texto inserido será apresentado no momento da devolução.  
    
  **Campos complementares**  
   O usuário pode informar formato da capa e tipo da capa.
