Este anexo possibilita o cadastro de endereços adicionais para um mesmo imóvel. Os campos a serem preenchidos para o este cadastro são:

* Tipo de Endereço;
* CEP;
* Tipo de logradouro;
* Logradouro;
* Número;
* Complemento;
* Barro;
* Município;
* Estado;
* País.

Alguns campos deste preenchimento são obrigatório.
