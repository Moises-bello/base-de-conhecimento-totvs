# TIPOS DE ANOTAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Parametrização de Tipo de Anotação no Portal* |
| **Situação/Requisito:** | *Ao marcar os tipos de anotações a serem exibidas no portal, o parâmetro utilizava a ordem dos itens na tela do parametrizador mas na leitura do parametro era utilizado o código do tipo de anotação.* |
| **Solução/Implementação:** | *Na tela do parametrizador foi alterado para utilizar também o código do Tipo de Anotação. Ao acessar a tela pela primeira vez, o sistema faz automaticamente a conversão do parâmetro de forma transparente para o usuário.* |
| **Chamados relacionados:** | TTBCAM |
| **Versões/Release:** | *12.1.7* |
