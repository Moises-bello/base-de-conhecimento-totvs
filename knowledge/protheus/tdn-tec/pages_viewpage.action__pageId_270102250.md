Correção - Impressão do caractere trademark (™) pelo agente TOTVS Printer.

|  |  |
| --- | --- |
| Situação | O caractere trademark (™) não é impresso pelo agente TOTVS Printer. |
| Ocorrência | O caractere trademark (™) não é impresso pelo agente TOTVS Printer. |
| Correção | Foi incluído um tratamento no agente TOTVS Printer para que o caractere Trademark seja impresso corretamente. |
| Informações adicionais | * Referente ao chamado: MTEC-32 * Referente ao ticket: 263531 * Disponível a partir da versão 1.6.6 da TOTVS Printer. |
