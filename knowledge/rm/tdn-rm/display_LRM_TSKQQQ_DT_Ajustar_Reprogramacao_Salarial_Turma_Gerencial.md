# REPROGRAMAÇÃO SALARIAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cálculo por Centro de Custo* |
| **Situação/Requisito:** | *Não está buscando nas turmas gerenciais a estrutura de verbas por centro de custo, fazendo com o lançamento do salário composto por centro de custo fique incorreto.* |
| **Solução/Implementação:** | *Alteração no serviço disponibilizado pelo Educacional, para que o retorno leve em consideração os alunos matriculados na turma/disciplina gerenciada, quando o professor estiver associado a uma turma/disciplina gerencial.*  *Ao carregar os dados do professor com as informações que serão utilizadas para cálculo do salário, a quantidade de alunos matriculados, agrupados por centro de custo, levarão em conta os alunos matriculados nas turmas/disciplinas gerenciadas, quando o professor estiver associado a uma turma/disciplina gerencial.* |
| **Chamados relacionados:** | *TSKQQQ* |
| **Versões/Release:** | *11.82.40* |
