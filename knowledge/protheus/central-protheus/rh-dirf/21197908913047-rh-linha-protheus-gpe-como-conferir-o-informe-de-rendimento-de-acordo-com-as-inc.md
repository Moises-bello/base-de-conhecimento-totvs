![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21197954005271) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como conferir o Informe de Rendimento de acordo com as incidências das verbas para a DIRF?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Abaixo segue como os valores são montados no Informe de Rendimento de acordo com as incidências para a DIRF:

**Quadro 3** - Rendimentos tributáveis, deduções e imposto:

Linha 01 => incidência A   
Linha 02 => incidência B  
Linha 03 => incidência M  
Linha 04 => incidência C  
Linha 05 => incidência D  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21197908787223)  
 **Quadro 4** – Rendimentos Isentos e Não Tributáveis:

Linha 01 => incidência F  
Linha 02 => incidência F1  
Linha 03 => incidência G  
Linha 04 => incidência H  
Linha 05 => incidência P  
Linha 06 => incidência U  
Linha 07 => incidência E  
Linha 08 => incidência O2  
Linha 09 => I + 0  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21197954008471)  
  
**Quadro 5** - Rendimentos sujeitos à tributação exclusiva:

Linha 01 => Valor líquido do 13º  
incidência J - incidência K - incidência 5 - incidência B1 - incidência T1 - incidência C1 - incidência M1 - incidência L - incidência 1 - incidência S1  
Linha 02 => incidência L   
Linha 03 => (incidência O - incidência Q ) + ( incidência O1 - incidência C3 - incidência Q1 )  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21197908794007)  
  
**Quadro 6** – Recebidos acumuladamente:

Linha 01 => incidência A1  
Linha 02 => incidência B3  
Linha 03 => incidência B2  
Linha 04 => incidência C2  
Linha 05 => incidência D2  
Linha 06 => incidência I1  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/21197954012951)  
  
**Quadro 7** - Informações complementares:

* Listados os beneficiários de Pensão Alimentícia, desde que estejam cadastrados na tabela **SRQ - Cadastro de Beneficiários**.
* Listados todos os Dependentes/Agregados que possuírem plano de Assistência Médica e/ou odontológica, bem como, a Razão Social e o CNPJ do fornecedor dos Planos de Saúde, os valores são obtidos da tabela de **Histórico de Plano de Saúde (RHS)** e da tabela de **Histórico de Coparticipação e Reembolso de Plano de Saúde (RHP)**.
* São listadas as verbas com incidências 2, 5, R, W e Z.
* Listado o valor bruto e o líquido recebido de Participação nos Lucros ou Resultados (PLR).
* Listadas neste quadro, detalhadamente, as informações referentes à Assistência Médica, Assistência Odontológica e Pensão Alimentícia, tais informações serão necessárias para que a pessoa física preencha sua declaração anual, tais como:
  + CPF beneficiário pensão.
  + CPF dos dependentes.
  + CNPJ fornecedor de Ass. Médica e Odontológica.
  + Razão social do fornecedor de Ass. Médica e Odontológica.
