O objetivo deste artigo é orientar sobre o cadastro das Naturezas Fiscais e suas características, um dos principais cadastros do sistema TOTVS Gestão Fiscal.

Para incluir um novo cadastro você deve acessar a nova MDI: **TOTVS LINHAS RM -> BACKOFFICE -> Gestão Fiscal -> Cadastros -> CFOP(Natureza de Operação)**. Para os contribuintes do ICMS e do IPI, devem ser cadastrados códigos de naturezas de operação que atendam as exigências do Regulamento do ICMS (RICMS). Como esta codificação pode sofrer alteração pelo Fisco, o sistema trabalha com o conceito de vigência para o cadastro de naturezas. Esta vigência é controlada pelo cadastro de Exercícios Fiscais**(Cadastros | Tabelas Auxiliares -> Exercícios.**

Para cada [Exercício Fiscal](http://tdn.totvs.com/pages/releaseview.action?pageId=108659194) deve ser definida uma máscara para o cadastro de naturezas de operação. Antes de se iniciar o uso desse cadastro, é necessário que as parametrizações relacionadas já tenham sido feitas pelo menu **Opções | Parâmetros | Gerais/Tabelas | Apuração de Tributos | ICMS | Natureza de Operação.**
