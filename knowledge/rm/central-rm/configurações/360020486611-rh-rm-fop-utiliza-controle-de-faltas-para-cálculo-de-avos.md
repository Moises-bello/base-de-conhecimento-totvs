Dúvida**Qual a funcionalidade do parâmetro **Utiliza controle de faltas para cálculo de avos**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para verificar a funcionalidade do parâmetro, veja os pontos abaixo:  
  
**Utiliza controle de faltas para cálculo de avos**Este parâmetro é utilizado para que o Código de Cálculo 8 seja desconsiderado a partir do período cadastrado no campo de **Competência a considerar para controle de faltas.** Ou seja, com o parâmetro marcado o sistema não considera os eventos com código de cálculo 8 que tenham sido lançados no período informado no campo **Competência a considerar para controle de faltas**.  
  
Para ativar o parâmetro, acesse **Configurações | Parametrizador | Folha Normal | Controle de faltas para Cálculo de Avos**.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/26844464745367)  
  
Após marcar este parâmetro será disponibilizado um histórico de controle de faltas, disponível no cadastro do funcionário, em **Anexos | Movimento | Controle de faltas para cálculo de avos.** Neste caso o controle de faltas deverá ser alimentar através de importação se for utilizado outro sistema de ponto ou através de inclusão manual.  
  
**Observação**Para mais informações sobre o controle de faltas, [clique aqui](https://tdn.totvs.com/display/LRM/Controle+de+Faltas).
