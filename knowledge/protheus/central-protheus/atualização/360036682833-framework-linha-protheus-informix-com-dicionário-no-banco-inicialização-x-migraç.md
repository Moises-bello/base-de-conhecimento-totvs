**Dúvida**Como utilizar Informix com Dicionário no Banco de Dados?  
   
 **Ambiente**Protheus - Servidor de Aplicação - Versão 12  
  
**Solução**Caso opte por usar base com **Dicionário de Dados** no **Banco de Dados**, observe as seguintes informações:  
- O Banco de Dados Informix **está** homologado para o procedimento de **migração**, conforme documentação:  <https://tdn.totvs.com/display/tec/DBAccess+-+Banco+de+dados>  
- O Banco de Dados Informix **não está** homologado para o procedimento de **inicialização**, pois não possui **APIs** para tal procedimento, conforme destacado na documentação: <https://tdn.totvs.com/pages/viewpage.action?pageId=364926893>
