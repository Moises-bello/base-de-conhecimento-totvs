# CERTIFICADO / DIPLOMA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Certificado / Diploma |
| **Situação/Requisito:** | O cadastro manual de certificados e diplomas não permite a inserção manual dos dados do registro no livro. |
| **Solução/Implementação:** | Foram alterados os campos do registro do livro para permitir a inclusão manual com a geração do número do registro e folha automáticos, foram feitos também ajustes na tela para obrigar o preenchimento dos dados do livro somente se o campo livro for preenchido, ou seja, os demais campos só serão habilitados e obrigatórios se o livro for preenchido. |
