# DATA DE DEVOLUÇÃO DE EMPRÉSTIMO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Empréstimo / Renovação pelo portal |
| **Situação/Requisito:** | Quando o sistema está parametrizado para realizar empréstimo por dia, no portal da biblioteca estava sendo exibido na data de devolução o horário, o que dava a entender que deveria ser devolvido naquela data e naquele horário. |
| **Solução/Implementação:** | Ajuste para verificar se o empréstimo foi realizado por dia ou por hora, caso seja por dia, ao acessar o portal da biblioteca a hora de devolução será exibida zerada. |
