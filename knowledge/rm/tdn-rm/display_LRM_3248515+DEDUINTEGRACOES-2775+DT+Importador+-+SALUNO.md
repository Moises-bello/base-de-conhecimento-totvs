# IMPORTADOR - SALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Importador - SALUNO* |
| **Situação/Requisito:** | Ao importar alunos através do conversor (SALUNO) é realizada uma validação para encontrar a pessoa. No log não é informado qual aluno gerou o erro causando problema para identificar o registro no arquivo que deve ser ajustado. |
| **Solução/Implementação:** | Ajustes no importador para que no log seja informado qual aluno está com problema. Será informado o nome, cpf e data de nascimento para localização do registro com problemas no arquivo. |
