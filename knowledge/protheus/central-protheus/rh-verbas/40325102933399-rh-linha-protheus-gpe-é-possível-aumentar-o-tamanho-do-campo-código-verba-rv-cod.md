**Dúvida**  
É possível aumentar o tamanho do campo Código Verba (RV\_COD)?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/40325102923287)  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**  
No padrão do sistema, não é possível aumentar o tamanho do campo RV\_COD. A indicação é utilizar códigos Alfanuméricos como: A001, AAA, AA1...
