Para atender ao layout do eSocial, foi criado o tipo de demissão "G-Força Maior".

Para utiliza-lo, siga o passo a passo abaixo:

* Para a criação do novo tipo de demissão será necessário executar o script através do sistema RM.Script.Executor.exe.

* Acesse RH / Folha de Pagamento / Administração de Pessoal / Funcionários, selecione o funcionário e clique em Rescisão

* Cadastre a demissão com o novo tipo de demissão "G-Força Maior"

* Acesse RH / Folha de Pagamento / eSocial / Fila de Eventos e gere o XML do evento S-2299. Abaixo segue um exemplo do XML gerado através do sistema.
