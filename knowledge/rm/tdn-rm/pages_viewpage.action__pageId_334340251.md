# Rotina Federal DIRF - registro BRPDE, campo 09 "Relação fonte pagadora pessoa jurídica e beneficiário pessoa jurídica"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Geração de Arquivo para rotina Federal DIRF |
| **Situação/Requisito:** | Ao gerar DIRF O Campo 09 "Relação fonte pagadora pessoa jurídica e beneficiário pessoa jurídica"  do Registro BRPDE não estava sendo gerado para cli/for cujo fim de relacionamento não estava preenchido (ou seja ativo). |
| **Solução/Implementação:** | Efetuada adequação na geração da DIRF, registro BRPDE, para que o campo 09  "Relação fonte pagadora pessoa jurídica e beneficiário pessoa jurídica" seja gerado para todos cli/for que tenham relacionamento ativo. |
| **Conversores e Parâmetros:** | Não se Aplica |
| **Tickets relacionados:** | Não se Aplica |
| **Requisito:** | FIS000307 |
