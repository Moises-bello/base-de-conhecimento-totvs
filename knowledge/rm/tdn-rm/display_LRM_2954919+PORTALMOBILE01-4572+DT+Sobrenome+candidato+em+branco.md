# Sobrenome candidato em branco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Inscrição no novo portal e dados pessoais |
| **Situação/Requisito:** | Uma vez o processo seletivo esteja parametrizado para exigir sobrenome, ao alterar os dados do candidato não era possível pois o campo sobrenome ficava em branco e bloqueado a edição. |
| **Solução/Implementação:** | O comportamento do novo portal do candidato relacionado ao parâmetro "Exige preenchimento sobrenome" passou a ser o mesmo do portal antigo, o candidato informa o nome completo apenas, caso esteja marcado este parâmetro, o sistema bloqueia se houver apenas o primeiro nome. |
