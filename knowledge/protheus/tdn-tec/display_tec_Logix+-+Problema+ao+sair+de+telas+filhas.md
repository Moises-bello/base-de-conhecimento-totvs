<Resumo do que foi contemplado na alteração associada a essa nota de release> 

|  |  |
| --- | --- |
| Situação | Ao sair de telas filhas, a tela principal é apresentada vazia e com os botões desabilitados |
| Ocorrência | Utilizando o programa SUP3760, após realizar uma pesquisa e selecionar uma das opções do menu lateral, como por exemplo a opção “Q-Impostos”, abrirá a tela de consulta/manutenção dos impostos e ao tentar sair dessa tela (botão sair), o sistema não volta para a tela anterior, as informações simplesmente somem da tela, deixando-a vazia e os botões desabilitados. |
| Correção | Corrigido para que a tela anterior seja apresentada. |
| Informações adicionais | * Referente ao chamado: não há chamado associado * Referente à ocorrência: SCHTML-295 * Disponível a partir da builds 7.00.131227A - 3.0.11 |
