# Consulta de férias (Portal)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Totvs Folha de Pagamento* |
| **Função:** | *Consulta de Férias* |
| **Situação/Requisito:** | Após mudar as tabelas e estruturas de dados relacionados às férias, a página de Consulta de Férias do portal continuou usando a antiga visão, limitando a visualização das informações. |
| **Solução/Implementação:** | *Foi atualizada a página para usuários que utilizem o Cálculo .Net visualizem os dados de acordo com a nova estrutura e permitindo também, que sejam visualizadas a partir do ajuste as férias com status de "Finalizadas no Próximo Mês", "Lançadas" ou "Pagas".* |
