**Dúvida**MV\_CNMDEAT - Como realizar o Encerramento Automático de Uma Medição na Liberação de Alçadas ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões  
  
**Solução**Hoje no Padrão do módulo de Gestão de Contratos, a possibilidade existente do encerramento automático de uma medição, é quando esta medição possui aprovação por alçadas, através da utilização do parâmetro **MV\_CNMDEAT**.

|  |  |
| --- | --- |
| MV\_CNMDEAT | Habilita encerramento automático de uma medição de contrato após ser liberada pelo grupo de aprovadores. |

Por padrão este parâmetro tem seu conteúdo igual a .F. (desabilitado).

***Obs:***

A utilização do parâmentro **MV\_CNMDEAT** é válida para uso tanto para Contratos de Compra como também para de Venda.
