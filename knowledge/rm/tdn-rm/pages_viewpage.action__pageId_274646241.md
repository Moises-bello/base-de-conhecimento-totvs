# Lançamento - Alteração

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento - Alteração |
| **Situação/Requisito:** | Ao executar o processo de Distrato no TIN em casos onde o cliente/fornecedor possui lançamentos vinculados o sistema exibe a seguinte mensagem: "Campos 'ValorOriginal' do lançamento @-XXXXXX não pode ser alterado em: Lançamentos com Vínculos (Devolução, Nota de Crédito e/ou Adiantamento)". |
| **Solução/Implementação:** | Otimização no processo de alteração de lançamento. Agora o sistema irá permitir a alteração do lançamento do SGI quando o mesmo estiver vinculado e for executado pelo processo de Distrato pelo TIN. |
