# PROCESSO SELETIVO TERCEIRIZADO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Matrícula via Processo Seletivo Terceirizado.* |
| **Situação/Requisito:** | *Ao informar uma turma na execução da matrícula via processo seletivo terceirizado, o processo não priorizava a matrícula nesta turma. Desta forma o aluno não era matriculado nas turmas/disciplinas da turma informada no processo. Esta informação ficava disponível apenas no registro de matrícula no período letivo.* |
| **Solução/Implementação:** | *Quando o usuário informar uma turma uma turma no processo, durante a execução do processo as turmas/disciplinas desta turma serão priorizadas na matrícula. O processo vai inserir a matrícula nestas disciplinas e se não for possível(por um motivo qualquer) matricular em todas as disciplinas do período na mesma turma, o processo vai buscar a disciplina em outras turmas.* |
