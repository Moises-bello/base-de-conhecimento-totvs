**Dúvida**Ao transmitir um RPS para o município de Goiânia-GO ocorre o erro L999.  
  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.

**Solução**

A prefeitura Municipal de Goiânia trabalha com códigos próprios para os municípios.

O campo A1\_OUTRMUN deve ser preenchido com o código de Goiânia.

Consulte o código do município no link abaixo:

http://www2.goiania.go.gov.br/sistemas/sress/Docs/Municipio.zip
