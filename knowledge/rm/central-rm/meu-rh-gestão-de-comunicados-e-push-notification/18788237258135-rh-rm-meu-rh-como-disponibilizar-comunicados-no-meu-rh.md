**Dúvida**  
Como disponibilizar comunicados no Meu RH através da Gestão de Comunicados?  
  
**Ambiente**

TOTVS RH - TOTVS RH (Linha RM) - Meu RH - A partir da versão 12.1.2310.123

**Solução**  
Por meio da funcionalidade de **Gestão de Comunicados**, a empresa poderá criar e enviar comunicados internos para seus colaboradores visualizarem através do aplicativo **Meu RH**.  
  
Para utilizar a funcionalidade, realize os seguintes passos:  
  
1. Acesse **Folha de Pagamento> Configurações> Parametrizador> Push Notification** e marque o parâmetro "Utiliza push Notification".

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/18788237244951)**

2. Libere as permissões destacadas no perfil do usuário em **Serviços Globais > Segurança > Perfis > Sistema: Folha de Pagamento.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23442251900823)

3. Para disponibilizar ou visualizar os comunicados já cadastrados pelo usuário logado no RM, acesse o módulo **Folha de Pagamento** > **Configurações** > **Gestão de Comunicados**.

![image-2023-10-24_8-25-23.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_8-25-23.png?version=1&modificationDate=1698146754860&api=v2)

**Importante:** Para acessar esta funcionalidade, é obrigatório que o usuário logado no RM esteja vinculado em um cadastro de funcionário interno ou externo. Caso o usuário não esteja vinculado, será apresentado o seguinte erro:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23442237210135)

Caso não existam registros cadastrados por aquele usuário, será apresentado a mensagem **"Sem resultados!"**. Para disponibilizar, clique na opção **"Novo Comunicado"**.

![image-2023-10-24_8-30-4.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_8-30-4.png?version=1&modificationDate=1698147035613&api=v2)

4. Informe um título e um texto para o comunicado, pode selecionar caso deseje uma imagem, podendo escolher entre os formatos vertical ou horizontal. Será aceito apenas formatos **.png, .jpg, .gif.**

![image-2023-10-24_10-3-52.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_10-3-52.png?version=1&modificationDate=1698152663880&api=v2)

5. Clique em **'Elaborar Push'** para prosseguir com o processo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18788250677143)

6. Descreva qual será o título e subtítulo da sua Push Notification sobre esse comunicado:

![image-2023-10-24_9-3-48.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_9-3-48.png?version=1&modificationDate=1698149060390&api=v2)

**Importante:** Para o funcionamento do Push Notification, é necessário realizar as parametrizações da seguinte documentação: [RH - RM - Meu RH - Como parametrizar o Push Notification no Meu RH](https://centraldeatendimento.totvs.com/hc/pt-br/articles/18701717777175-RH-RM-Meu-RH-Como-parametrizar-o-Push-Notification-Beta-no-Meu-RH)

7. Clique em '**Escolher Destinatários**' para selecionar os filtros de envio. Será obrigatório selecionar ao menos a coligada para envio, apenas a coligada do contexto do usuário que está realizando o cadastro será exibida para a seleção. Ao selecionar a coligada, os campos de **'Função'** e **'Filial'** serão habilitados para seleção, porém não são obrigatórios.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/23442251941527)

Não serão criados comunicados e/ou notificações para funcionários que se enquadrarem nessas situações:

* Demitidos;
* Com admissão para o próximo mês;
* Com data de demissão ou externos com data fim preenchida;
* Com data de admissão ou externos com data de inicio maior que a data atual.

8. Para finalizar, clique em **'Criar Comunicado'** e confirmar em **'Sim, estou ciente'.**

![image-2023-10-24_10-11-18.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_10-11-18.png?version=1&modificationDate=1698153109327&api=v2)

O comunicado será salvo com o status **'Aguardando'**, após o envio da notificação o status será alterado para **'Enviado'**.

![image-2023-10-24_10-24-45.png](https://tdn.totvs.com/download/attachments/799247950/image-2023-10-24_10-24-45.png?version=1&modificationDate=1698153916783&api=v2)

Após alteração do status para Enviado, o usuário receberá uma notificação no Meu RH e poderá consultar os comunicados através do menu "**Comunica RH**":

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18788669088791)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18788669095831)
