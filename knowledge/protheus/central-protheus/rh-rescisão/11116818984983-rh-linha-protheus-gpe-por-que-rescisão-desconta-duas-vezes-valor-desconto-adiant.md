![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34809950712343) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que rescisão desconta duas vezes valor desconto adiantamento 13 salário calculado em roteiro 132?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**O incidente ocorre pois o valor é apresentado no Id 1661-Base dedutora INSS 13º, sendo que este Id se trata de uma verba tipo **base desconto** e não tipo desconto. Para corrigir o incidente o cadastro Id 1661 deve ser atualizado como tipo base desconto.
