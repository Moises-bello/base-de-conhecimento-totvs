|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Fluxo de Caixa |
| **Situação/Requisito:** | Ao emitir o relatório Fluxo de caixa utilizando o Excel (pacote Microsoft Office 2007), ao clicar em "Carregar Coligadas", o sistema não lista as coligadas, e consequentemente os centros de custos e as contas caixas para seleção. Ao utilizar "Planilha RM" as coligadas são listadas corretamente. |
| **Solução/Implementação:** | Otimização no processo de emissão do relatório de Fluxo de Caixa. Agora o sistema carrega as coligadas corretamente. |
