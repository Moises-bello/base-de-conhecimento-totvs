Esta janela permite associar os professores que irão ministrar aulas para as turmas da instituição.

A associação do professor à disciplina pode ocorrer de duas formas:  
Existe na parte de parametrizações do sistema (Opções / Parâmetros) um check-box para "Considerar somente disciplinas autorizadas para os professores", quando este estiver ativo, ao criar uma turma/disciplina e associar um professor para ela, só serão listados professores autorizados para tal disciplina.  
Quando este check- box estiver desmarcado, aparecerão TODOS os professores cadastrados no sistema.  
Neste cadastro, existe as seguintes opções para o tipo do professor:

* Adjunto [J]
* Assistente [I]
* Auxiliar [X]
* Coordenador [D]
* Colaborador [C]
* Conteudista [P] - **a partir das versões 12.1.2502.221, 12.1.2506.168, 12.1.2510.101 e 12.1.2602**
* Diretor de Turma [E]
* Mediador pedagógico [Q] - **a partir das versões 12.1.2502.221, 12.1.2506.168, 12.1.2510.101 e 12.1.2602**
* Monitor [M]
* Não docente [N]
* Orientador [R]
* Outros [O]
* Substituto [S]
* Titular [T]
* Tutor [U]

Pagamento Independente do Ponto - Selecionando esta opção o sistema irá realizar o pagamento das aulas do professor independente do seu ponto na instituição.

Campo de preenchimento não obrigatório.

O campo faturamento é apenas um campo informativo, é usado apenas para relatórios, este campo é usado para mostrar quanto (de %) o professor ganha referente a turma/disciplina.

## Professor responsável por assinar o diário de classe

Para que o professor possa assinar os documentos, será necessário marcar a opção 'Responsável por assinar o diário de classe', no cadastro do professor à turma/disciplina.

Importante

As funcionalidades relacionadas ao professor  assinar o diário de classe estão disponíveis a partir da versão 12.1.2310.
