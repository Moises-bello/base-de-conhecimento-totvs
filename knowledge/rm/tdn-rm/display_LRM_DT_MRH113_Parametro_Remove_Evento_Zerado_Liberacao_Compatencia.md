# LIBERAÇÃO DE COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos.* |
| **Módulo:** | *Folha de pagamento.* |
| **Função:** | *Remove eventos zerados na liberação de competência.* |
| **Situação/Requisito:** | *Ao realizar a liberação de competência, mesmo desmarcando o parâmetro na tela para remover eventos zerados, o sistema não respeitava o parâmetro e removia os eventos zerados, fazendo com que a liberação de competência demorasse muito a ser realizada.* |
| **Solução/Implementação:** | *Foi ajustado o sistema para respeitar o parâmetro da tela da liberação de competência, desta forma, caso o parâmetro esteja desmarcado na tela, os eventos zerados não serão removidos fazendo com que a liberação de competência seja realizada de forma mais rápida.* |
| **Chamados relacionados:** | MRH-113 |
