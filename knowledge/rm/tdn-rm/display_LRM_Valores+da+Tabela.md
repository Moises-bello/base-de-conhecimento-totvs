Nesta janela são visualizados os valores que compõem a tabela selecionada (aquela em que estiver posicionado o cursor na visão do Cadastro de Tabelas de Cálculo). No caso de tabela que estiver sendo incluída, seus valores serão visualizados após terem sido incluídos na Janela de Edição de Valores da Tabela (pasta Identificação).

**Atenção:**

As tabelas de INSS e IRFF devem ser cadastradas obrigatoriamente. Para saber como incluir ou editar valores da tabela, clique no tópico Ícones, na parte superior desta janela.  
    
 **Identificação**

Nesta pasta são realizados os processos de inclusão, edição e consulta de valores de tabela de cálculo. A acessá-la, os campos Código e Início de Vigência estarão desabilitados para edição: eles se referem à tabela de cálculo que estiver selecionada (a que houver sido imediatamente incluída ou aquela em que estiver posicionado cursor na janela de Cadastro de Tabelas de Cálculo ("visão"). Para identificar cada tabela de valores de cada, preencha os seguintes campos:

**Número Faixa**

Informe um número para identificar a faixa que está sendo cadastrada (Ex. 1 para faixa 1, 2 para faixa 2 e assim por diante).

**Limite Superior**

Informe o limite superior dessa faixa.

**Percentual**

Informe o percentual de multiplicação para a faixa, caso exista. Para a Tabela de Cálculo com finalidade "INSS" informe neste campo a percentual de alíquota reduzida conforme limite da faixa.

**Percentual 2**

Informe neste campo outro percentual a ser considerado além do valor informado no campo "Percentual".

**Valor a Acrescentar**

Informe o valor a acrescentar para essa faixa, caso exista.

**Valor a Deduzir**

Informe o valor a deduzir para essa faixa, caso exista.
