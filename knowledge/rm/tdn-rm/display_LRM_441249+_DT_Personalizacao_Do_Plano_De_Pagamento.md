# PERSONALIZAÇÃO DO PLANO DE PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Personalização do plano de pagamento* |
| **Situação/Requisito:** | *Ao incluir parcelas pelo processo de personalização do plano de pagamento, quando definida uma data de vencimento para a parcela inicial para o último dia do mês, o sistema limita o dia com base no mês anterior e o toma como base para as demais parcelas.* |
| **Solução/Implementação:** | Foi realizada otimização do processo de personalização do plano de pagamento, permitindo ao sistema, utilizar o dia de vencimento da parcela inicial como base, quando o dia de vencimento da parcela inicial não existir no mês de referência*.* |
