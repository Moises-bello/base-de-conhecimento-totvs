# Pagamento Cartão Crédito e Débito Cielo Checkout

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Pagamento Cartão de Crédito e Débito Cielo Checkout* |
| **Situação/Requisito:** | *Sistema não permite que o pagamento com cartão de crédito via checkout Cielo seja efetuado quando o responsável financeiro não possui e-mail cadastrado.* |
| **Solução/Implementação:** | *Permitir que seja efetuado pagamento com cartão de crédito via checkout Cielo quando o responsável financeiro não possui e-mail cadastrado. O e-mail é utilizado apenas para preencher na pagina da Cielo no momento que efetua o pagamento, caso o responsável não tenha e-mail cadastrado, poderá no momento do pagamento informar um e-mail.* |
| **Conversores e Parâmetros:** | *N/A* |
| **Chamados relacionados:** | TWAKBQ |
| **Requisito (ISSUE):** | PCREQ-8625 |
