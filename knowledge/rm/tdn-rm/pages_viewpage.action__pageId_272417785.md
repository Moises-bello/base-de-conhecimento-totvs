# Portal Aluno - Pagamento Cartão de Crédito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Pagamento Cartão de Crédito Portal do Aluno |
| **Situação/Requisito:** | Quando responsável do aluno é um estrangeiro, que não possui CPF, ao tentar pagar uma mensalidade via cartão de crédito pelo portal do aluno, sistema esta emitindo mensagem que CPF obrigatório |
| **Solução/Implementação:** | Permitir que um responsável financeiro de um aluno, que não possui CPF, consiga efetuar um pagamento de mensalidade através do portal do aluno utilizando a modalidade de cartão de crédito |
