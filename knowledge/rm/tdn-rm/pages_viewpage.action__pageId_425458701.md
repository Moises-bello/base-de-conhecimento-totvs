Esta janela permite cadastrar os horários das aulas nas disciplinas cadastradas.

Otimizado no sistema o processo, que é possível montar o horário de uma turma de forma gráfica. Na tela principal deste processo, é  apresentado todas as disciplinas de uma turma bem como os horários do turno da turma. O usuário vai poder arrastar as disciplinas para os horários do turno e o sistema vai cadastrar os horários e associar os professores da disciplina aos horários cadastrados.

O Sistema também está preparado para  não permitir cadastrar o mesmo horário mais de uma vez para a turma/disciplina. Se informar um horário sem data inicial e final, o sistema não permitirá cadastrar o mesmo horário novamente para a turma/disciplina. Se tiver datas informadas (horário modular), somente permitirá informar o mesmo horário em períodos diferentes.

No cadastro do horários da turma/disciplina pode informar o link para [aula online](https://tdn.totvs.com/display/LRM/Aula+Online?moved=true) pelo campo "Aula Online". O link ficará disponível nos portais Educacionais para o aluno e para o professor. O professor poderá atualizar ou informar um novo link da aula online pelo portal do Professor.
