O Grupo de Faturamento é uma classificação a ser informada no cadastro dos produtos para que, durante o faturamento do movimento, se o tipo de movimento de origem estiver habilitado para filtrar por grupo de faturamento, será exibida uma janela para informar o código do grupo que se deseja faturar. Somente os produtos que tenham o mesmo grupo de faturamento serão copiados do movimento de origem para o destino, os demais permanecerão com faturamento pendente.  
***Observação*:**Para utilizar este recurso, após de cadastrar os Grupos de Faturamentos, esses deverão ser associados ao cadastro do [Produto](http://tdn.totvs.com/pages/viewpage.action?pageId=423938817) através da Pasta Detalhes|Outros Dados.    
 Nos parâmetros do tipo de movimento, etapa Compras/Vendas - Outros, o campo "Utiliza filtro por grupo de Faturamento" deverá estar habilitado.
