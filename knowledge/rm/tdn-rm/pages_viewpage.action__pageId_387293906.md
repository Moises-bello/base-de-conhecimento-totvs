# Validar status importação da cultura parcial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Controle de Infecção Hospitalar |
| **Função:** | Utilitários > Agreagação / Validação > Cultura Parcial |
| **Requisito:** | Ao validar o status da importação da Cultura Final o sistema não altera também o status do pedido de cultura parcial vinculada a este pedido de cultura final |
| **Implementação:** | Ao validar o status da importação da Cultura Final o sistema altera também o status do pedido de cultura parcial vinculada a este pedido de cultura final, e com isto esta cultura parcial não aparecerá mais na visão |
