# SUGESTÃO DE DISCIPLINAS - NÚMERO DE VAGAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Sugestão de Disciplinas - Número de Vagas* |
| **Situação/Requisito:** | *Mesmo o controle de vagas na matriz curricular estar "Por turma" e existirem vagas disponíveis para a turma em questão, no momento de realizar o processo de "Sugestão de disciplinas" as disciplinas da turma ficam indisponíveis para a matrícula do aluno, acusando que o número de vagas é 0. Caso seja preenchido na turma/disciplina o número máximo de alunos maior que zero, a disciplina fica disponível.* |
| **Solução/Implementação:** | *Ajuste na busca de vagas na SDD, para que seja buscado o número de vagas na turma quando o controle de vagas é por turma e feito a busca na turma/disciplina quando o controle de vagas for por turma/disciplina.* |
