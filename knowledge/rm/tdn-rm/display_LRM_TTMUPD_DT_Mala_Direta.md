# MALA DIRETA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Envio Mala Direta* |
| **Situação/Requisito:** | *Em instituições que utilizam servidores SMTP com SSL, o usuário remetente não pode ser alterado, desta forma o e-mail recebido pelo aluno vem como remetente o endereço utilizado para login no servidor.* |
| **Solução/Implementação:** | *Como não é possível alterar o remetente do e-mail, ajustamos o processo para que o e-mail de resposta seja personalizado pelo cliente. No processo de mala direta, quando o usuário selecionar um remetente diferente, o e-mail será enviado para o aluno com o endereço de login no servidor, porém quando o aluno clicar em "Responder e-mail", o endereço de destino será alterado e informado o endereço selecionado como remetente durante o envio.* |
