![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26561399230999) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Quando calculada rescisão para funcionário que possui desconto de pensão alimentícia, Sistema não leva verba informada no cadastro do beneficiário para rescisão.  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.1.17  
  
**Causa**Quando informado o mesmo código de verba para todos os tipos de cálculo, o Sistema se perde e não demonstra nenhum valor de pensão alimentícia no cálculo da rescisão.

**Solução**Para que sejam apresentadas verbas de pensão alimentícia no cálculo de rescisão é necessário que sejam informados códigos de verba diferentes para cada tipo de cálculo, conforme exemplo abaixo:
