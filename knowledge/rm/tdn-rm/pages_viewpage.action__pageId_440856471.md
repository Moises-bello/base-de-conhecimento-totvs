# CADASTRO DE INVENTÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento |
| **Função:** | Cadastro de Inventário; Cadastro de Item de Inventário |
| **Situação/Requisito:** | O sistema permite que o inventário do tipo \*Lote\* seja incluído sem que o lote do produto seja informado, porém ao editar o inventário posteriormente, o campo de lote é bloqueado para edição. |
| **Solução/Implementação:** | O campo de lote de item de inventário estará habilitado para edição quando o inventário for por lote e o produto associado ao item de inventário permitir controle por lote. |
