# AVISO AUTOMÁTICO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Aviso Automático* |
| **Situação/Requisito:** | *Avisos automáticos com relatório .net não estavam sendo tratados corretamente e consequentemente não estavam sendo gerados com os parâmetros corretos.* |
| **Solução/Implementação:** | *O relatório .Net deve ser montado utilizando consultas SQL que podem receber parâmetros do aviso automático (1).*    *Os parâmetros devem possuir os mesmos nomes dos parâmetros disponibilizados (2). Em seguida o parâmetro do relatório (1) deve ser associado ao parâmetro do Aviso Automático (clicando no botão em (3)).* |
| **Tickets relacionados:** | MRH-3323 |
