Para que o Processo [Integrar com Registradora](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora) seja executado com sucesso quando a Registradora de Recebíveis for a CERC, o TCGI deverá integrar também os **Contratos** das vendas que estão associadas ao Empreendimento, através do [Cadastro de Vendas](https://tdn.totvs.com/pages/viewpage.action?pageId=435105210).

| **CAMPO  CERC-IM003A - CONTRATO** | **CAMPO API - CONTRATO** | **CAMPO RM** | **DESCRIÇÃO** |
| Tipo de Operação | tipoOperacao | Ação | O Tipo de Operação a ser realizado na integração dos dados coma  CERC é definido pelo campo de **Ação** da tela do Processo [Integrar com Registradora](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora) |
| Referência Externa - Projeto | referenciaExternaProjeto | Código da Coligada + Empreendimento | É formado com a junção dos campos **[Código da Coligada](https://tdn.totvs.com/display/LRM/Coligada)** (acrescido de zeros à esquerda, para ocupar 4 posições) + **[Empreendimento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105154)** que é o identificador desta entidade (que é preenchido automaticamente pelo TCGI). |
| Referência Externa - Contrato | referenciaExternaContrato | Código da Coligada + Venda/Aluguel | É formado com a junção dos campos **[Código da Coligada](https://tdn.totvs.com/display/LRM/Coligada)**  + **Venda/Aluguel** da aba [Identificação](https://tdn.totvs.com/pages/viewpage.action?pageId=435105242) do Cadastro de Venda. |
| Quadra/Torre | quadraTorre | Identificador da Unidade | É o campo **Identificador da Unidade** cadastrado na aba [Integração Registradora Recebíveis](https://tdn.totvs.com/pages/viewpage.action?pageId=737563311) da Unidade. |
| Unidade | unidade | Subunidade | É o campo **Subunidade/Lote/Apto,** da aba de Identificação, do cadastro de [Subunidade](https://tdn.totvs.com/display/LRM/Unidade+-+Anexos+-+Subunidade). |
| % Mora ao mês | porcentagemMoraMes | Taxa (%) | É o campo **Taxa (%)** do agrupador Tipo Juros ao Dia, dos Componentes geradores de parcela ([entrada](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Entrada), [principal](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Principal), etc.) das [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta Venda, convertido para um valor mensal.  O sistema utiliza o primeiro valor encontrado nas Condições de Financiamento desta venda.  Caso não esteja preenchido ou esteja parametrizado para utilizar um valor, o sistema informará 0% à CERC. |
| % Multa | porcentagemMulta | Multa ao dia | É o campo **Multa ao Dia** dos Componentes geradores de parcela ([entrada](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Entrada), [principal](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Principal), etc.) das [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta Venda, convertido para um valor mensal.  O sistema utiliza o primeiro valor encontrado nas Condições de Financiamento desta venda.  Caso não esteja preenchido ou esteja parametrizado para utilizar um valor, o sistema informará 0% à CERC. |
| Data Assinatura | dataAssinatura | Data de Assinatura ou Data da Venda/Aluguel | É o campo **Data de Assinatura** da aba [Identificação](https://tdn.totvs.com/pages/viewpage.action?pageId=435105242) do Cadastro de Venda.  Caso este campo não esteja preenchido, o sistema considerará o campo **Data Venda/Aluguel** desta mesma aba. |
| Contrato Tipo | tipoContrato | (valor fixo) | Atualmente é considerado apenas o valor fixo **001** - Promessa de Compra e Venda. |
| Valor | valor | Valor Venda/Aluguel | É o campo **Valor Venda/Aluguel** da aba [Identificação](https://tdn.totvs.com/pages/viewpage.action?pageId=435105242) do Cadastro de Venda. |
| Metod. Amortização | metodoAmortizacao | Modelo de Cálculo | É realizada uma busca no campo **Modelo de Cálculo**, dos grupos das [Condições de Financiamento da Venda](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209), para verificar se é Price, Sacre, Sac, etc. |
| Índice de Preços – Pré Obra | indicePrecoPreObra | Moeda/Índice | É realizada uma busca no campo **Moeda/Índice**, dos componentes de atualização monetária antes da data de entrega das [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta venda. |
| Índice de Preços - Pós Obra | indicePrecoPosObra | Moeda/Índice | É realizada uma busca no campo **Moeda/Índice**, dos componentes de atualização monetária após da data de entrega das [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta venda. |
| Juros (a.a) | jurosAA | Taxa de Juros % | É o campo **Taxa de Juros %**, do componente do tipo [juros](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Juros), caso ele exista nas [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta venda convertido para juros ao ano, |
| Aplicação do Juros | aplicacaoJuros | (calculado em relação à data base do componente do tipo [juros](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Juros)) | É realizada a verificação através do campo Data Base do componente do tipo [juros](https://tdn.totvs.com/display/LRM/Tipos+de+Componentes+-+Juros), caso ele exista nas [Condições de Financiamento](https://tdn.totvs.com/pages/viewpage.action?pageId=435105209) desta venda, para verificar se ele foi aplicado antes ou após a data da entrega da subunidade vendida. |

Para a CERC, esta informação é obrigatório, quando “tipo de operação” = AC (Atualização por Cessão) |
| Data do Distrato | dataDistrato | Data Base do Distrato | É o campo **Data Base do Distrato**, da aba [Identificação](https://tdn.totvs.com/display/LRM/Contratos+de+Venda+-+Distrato+-+Distrato) do Distrato.  Obrigatório, quando “tipo de operação” = AD (Atualização por Distrato).  Verifique as [Premissas](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora) desta entidade para este processo. |
| Valores a Devolver | valorDevolver | Valor do Distrato | É o campo **Valor do Distrato**, da aba [Identificação](https://tdn.totvs.com/display/LRM/Contratos+de+Venda+-+Distrato+-+Distrato) do Distrato.  Obrigatório, quando “tipo de operação” = AD (Atualização por Distrato) |
| Status do Contrato | statusContrato | Situação | É o campo **Situação** da aba [Identificação](https://tdn.totvs.com/pages/viewpage.action?pageId=435105242) do Cadastro de Venda. |
| Já foi renegociado? | jaRenegociado | Venda/Aluguel | Identifica se o contrato já teve renegociação através de uma consulta ao número da venda, da Tabela de Aditivos de Renegociação (XADITRENEGOCIACAO) com uma data anterior à da *Data de Integração* definida na execução do processo [Integrar  com Registradora](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora).  Verifique as [Premissas](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora) desta entidade para este processo. |

Após a execução com sucesso do Processo [Integrar com Registradora](https://tdn.totvs.com/display/LRM/Empreendimentos+-+Processos+-+Integrar+com+Registradora) o sistema vai abastecer a aba [Visão das Registradoras](https://tdn.totvs.com/pages/viewpage.action?pageId=741311157), do Cadastro de Venda, com as informações relativas à esta integração.
