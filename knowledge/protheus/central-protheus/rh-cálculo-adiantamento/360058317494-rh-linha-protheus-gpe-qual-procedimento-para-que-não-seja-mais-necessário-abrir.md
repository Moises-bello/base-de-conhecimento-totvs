**Dúvida**Qual procedimento para que não seja mais necessário abrir e fechar o roteiro ADI a cada período, uma vez que não é utilizado mais?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Uma vez que foi criado o **roteiro ADI**, não é possível cancelar esta operação, pois o sistema **sempre** irá validar a criação deste roteiro de um período para o outro.  
Se trata de um roteiro **obrigatório,** sendo necessário mantê-lo cadastrado em **todos** os períodos.  
Caso não utilize o roteiro ADI, não inclua na rotina cadastro de período, acesse/ atualizações/ definições de cálculo/ períodos (GPEA400).
