O Histograma Discriminado é uma visão anexa à funcionalidade "Geração de Pedidos em Suprimento/Faturamento" onde é possível visualizar todos os itens do pedido selecionado.   
 Para cada item são apresentadas duas linhas distintas na listagem da funcionalidade: acatado e sugerido. A linha "Acatado" do item, mostrada em cor vermelha, traz os valores conforme foram pedidos. A linha "Sugerido", mostrada em cor verde, traz os valores da sugestão automática do sistema de como o pedido deveria ser feito, tomando por base os dados do planejamento de execução do projeto feito no cronograma.  
 A opção "Histograma Discriminado" não permite qualquer edição nos dados do pedido. Ela é utilizada para simples visualização das informações.
