# RESERVA DE RECURSOS E RESERVA DE INSTALAÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Anexos de arquivos nas reservas de instalação e nas reservas de recursos |
| **Situação/Requisito:** | Ao acessar o anexo de arquivos da reserva de instalação ou o anexo de de arquivos da reserva de recursos, não existem permissões específicas para a manipulação desses arquivos. Assim pessoas que não deveriam possuir acesso aos arquivos conseguem manipulá-los. |
| **Solução/Implementação:** | Foi realizada otimização dos processos de reserva de recursos e de reserva de instalações, permitindo ao sistema, maior flexibilização, com relação ao permissionamento dos arquivos anexados. |
