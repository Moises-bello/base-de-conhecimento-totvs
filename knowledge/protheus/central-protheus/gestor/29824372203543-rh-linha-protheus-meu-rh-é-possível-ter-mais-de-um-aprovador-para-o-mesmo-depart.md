**Dúvida**  
É possível ter mais de um aprovador para o mesmo Departamento na hierarquia?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
  
**Solução**  
Essa relação é 1 para 1, ou seja, para cada departamento **teremos somente 1 único aprovador.**  
  
É possível ter uma hierarquia com mais de um Gestor para aprovação, em diferentes níveis hierárquicos, porém **não é possíveis dois Gestores aprovarem num mesmo nível**, ou aprovarem requisições de tipos diferentes.  
  
Exemplo:  
SUPORTE > LIDERANÇA > COORDENAÇÃO  
Quando o funcionário do Suporte realizar uma solicitação, o responsável pelo departamento **LIDERANÇA** aprovando, sobe para o responsável da **COORDENAÇÃO** aprovar, ele aprovando, vai para o RH atender via **TCFA040**.  
  
**Ou seja, cada departamento terá apenas 1 responsável, ou seja, 1 aprovador.**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29824360428567)  
  
Levando em consideração o exemplo acima, o responsável pelo departamento COORDENAÇÃO não consegue visualizar ou aprovar as pendências, sem antes o responsável pelo departamento LIDERANÇA realizar as aprovações.  
  
Para saber mais sobre a hierarquia de aprovação por Departamentos, acesse o artigo abaixo. <https://centraldeatendimento.totvs.com/hc/pt-br/articles/7917580297623?source=search>
