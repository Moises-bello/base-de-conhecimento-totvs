**Dúvida**Como parametrizar o sistema para que os **eventos adicionais componham** a base para calculo **1ª Parcela** do **13º Salário**?  
  
**Ambiente**RM - Totvs Folha de Pagamento - Todas as versões  
  
**Solução**Para que o sistema **considere** os eventos adicionais no pagamento da **1ª Parcela** do **13º Salário**, é necessário acessar **Configurações | Parametrizador | 13º Salário | Calculo** e marcar o parâmetro **Paga eventos adicionais na 1ª parcela do 13º salário.** **![](https://centraldeatendimento.totvs.com/hc/article_attachments/30602044553879)  
  
  
Observação**Caso seja necessário que o sistema desconsidere os eventos adicionais na 1ª Parcela do 13º Salário, basta desmarcar o mesmo parâmetro.
