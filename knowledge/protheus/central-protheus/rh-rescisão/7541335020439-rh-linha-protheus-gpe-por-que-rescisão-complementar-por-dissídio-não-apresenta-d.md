![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **HH:MM:SS min** **Dúvida**Por que rescisão complementar por dissídio não apresenta diferença de INSS 13º salário no ID 0070?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para rescisão complementar por dissídio, a diferença de INSS 13º salário é calculada no ID 0401, para isso, deve existir uma verba relacionada ao ID 0401.  
O ID 0070 tem que ser configurado na aba dissídio vinculado ao ID 0401.
