![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18506754712727) Tempo aproximado para leitura: **00:02:00 min****Dúvida**É possível a alteração de títulos Provisório (PR) gerados no Contas a Pagar a partir do módulo SIGAEIC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**A alteração de títulos gerados a partir do SIGAEIC, poderá ser feita somente via Ponto de Entrada.
