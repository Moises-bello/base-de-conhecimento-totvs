# Navegabilidade entre menus do novo portal do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Menu do novo portal do aluno |
| **Situação/Requisito:** | Para que seja acionado o item de menu desejado, é necessário clicar em cima da palavra, e não exatamente na área destinada aquele item de menu. |
| **Solução/Implementação:** | Foi alterado o menu, possibilitando o usuário clicar apenas na área destinada ao item de menu, não sendo necessário clicar apenas em cima do texto para que o item de menu seja acionado. |
