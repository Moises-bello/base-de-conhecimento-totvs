# Erro ao ligar a propriedade Municipio ao DataSource

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Flexibilização da Geração de Guias |
| **Situação/Requisito:** | Ao selecionar o período de apuração ISS (01/11/2017), processos > flexibilização de Guias > selecionar >  gerar as guias nota a nota > avançar > sistema apresenta a seguinte mensagem de erro:  "Não é possível ligar à propriedade ou à coluna MunicipioServico em DataSource. Nome do parâmetro: dataMember" |
| **Solução/Implementação:** | Criado a lookup de UF de Prestação do Serviço no processo de Flexibilização da Geração de Guias. |
