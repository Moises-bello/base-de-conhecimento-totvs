# TCC - Envio de arquivo final

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *TCC - Envio de arquivo final* |
| **Situação/Requisito:** | *Ao realizar o envio do arquivo final do TCC é informado a descrição do arquivo. O arquivo anexado ao e-mail enviado está assumindo como nome essa descrição, ocasionando erro quando o arquivo é aberto.* |
| **Solução/Implementação:** | *Ao realizar o envio do arquivo final do TCC, o arquivo será anexado ao e-mail com o seu nome físico, evitando problemas ao abrir o arquivo.* |
