# Como importar Guias de Atendimento

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.8x e 12.1x |
| **Ocorrência:** | Como importar guias de atendimento? |
| **Passo a passo:** | Abra o RM Saúde (TOTVS GESTÃO HOSPITALAR)  Acesse o menu Relatórios / Gerador.net    Clique na aba "Processos" / "Importar estrutura de Relatório"      Selecione a Guia Desejada    Marque o Checkbox - SOBRESCREVER EXISTENTE    Em cada uma das linhas de Consulta SQL, marque a opção: Importar sentença e substitui se existir    Clique em executar.  Sua guia está Importada. |
| **Observações:** | Existem diferenças entre guias SQL e guias em ORACLE, antes de importar, verifique em qual versão está esta Guia. |
