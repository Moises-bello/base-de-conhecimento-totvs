![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22683929680919) Tempo aproximado para leitura: **00:01:30 min****Ocorrência**Ao calcular a folha de pagamento para um estagiário horista, Sistema não traz verba de DSR  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - todas as versões  
  
**Causa**Como não há **previsão** de pagamento de DSR para estagiários, no Protheus **não** há um id de cálculo específico para cálculo **automático** de DSR.  
  
**Solução**Caso o empregador entenda que deve ser feito pagamento de DSR para estagiários, o sistema permite configurar uma verba diferente para gerar DSR e sem ID de cálculo.  
  
Na documentação abaixo está descrito o procedimento para utilizar outra verba para calculo de DSR.

Link: [Cálculo DSR – Descanso Semanal Remunerado de outras Verbas](http://tdn.totvs.com/pages/releaseview.action?pageId=234455345)  
  
A verba criada deve ser **informada** no campo **Verba DSR**.
