Código de Cálculo provento do tipo valor.  
O código de cálculo 341 - Arredondamento de Insuficiência de Líquido foi criado para ser lançado a insuficiência de saldo do envelope de pagamento do funcionário separado do código de cálculo 20.  
   
**Observação**  
Para que o sistema lance o evento com o código de cálculo 341, é necessário que o parâmetro 'Lança Líquido insuficiente separado do arredondamento' esteja marcado em Configurações | Parâmetros | Parametrizador na pasta Folha de Pagamento | Folha Normal | Geral.  
   
Caso o parâmetro esteja desmarcado, mesmo cadastrado o evento com o código de cálculo 341, o sistema irá lançar o evento com código de cálculo 20 para insuficiência de saldo.

Atenção:

Para atender ao eSocial foi criado o código de cálculo  .
