# RESERVA CONFIRMADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Reserva confirmada - Envio e-mail* |
| **Situação/Requisito:** | **Quando é feita uma devolução de um exemplar que possui reserva, o sistema envia o e-mail de confirmação de reserva para o e-mail da biblioteca e não para o usuário da reserva, no processo de reservas vencidas o sistema envia corretamente para o usuário da biblioteca. .** |
| **Solução/Implementação:** | *Foi feito o ajuste para que o sistema envie o e-mail para o usuário da reserva, somente se o usuário não tiver e-mail cadastrado que o e-mail será enviado para o da biblioteca* |
