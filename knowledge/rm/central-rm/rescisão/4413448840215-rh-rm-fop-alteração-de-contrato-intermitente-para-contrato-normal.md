**Dúvida**Posso utilizar o cadastro de funcionário com o contrato intermitente para torná-lo um funcionário normal?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**O contrato intermitente não pode ser reutilizado para transforma-lo num contrato normal. Por se tratar de contratos diferentes, não se pode utilizar a mesma chapa. Será necessário demitir o funcionário com contrato intermitente e admiti-lo novamente para o contrato normal.   
Segue abaixo orientação para realizar a demissão do contrato intermitente:  
  
O tipo de demissão a ser utilizado é o tipo ‘**V – Comum Acordo**’. Ao selecionar este tipo de rescisão, o eSocial fará um De/Para levando para o xml o tipo de rescisão correspondente ao layout do governo.   
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4413443937303/mceclip0.png)  
  
O RM Folha de Pagamento para o intermitente já calcula automaticamente a multa sobre o saldo de FGTS para fins rescisórios pela metade e os demais cálculos mediante lançamento dos eventos adicionais informado no parâmetro de rescisão.
