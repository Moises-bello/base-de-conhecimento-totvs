Nesta página, o professor pode **cadastrar, editar e liberar** os complementos das disciplinas para visualização dos alunos.

### O que são Complementos?

São informações detalhadas que caracterizam a disciplina, tais como:

* Ementas e Bibliografias;
* Planos de Ensino e Portarias;
* Formas de Avaliação, entre outros.

### Como realizar o cadastro

O processo é simples e flexível. Ao criar um registro, o usuário deve informar:

1. **Tipo de Complemento:** Nomenclatura definida pela instituição (ex: Ementa, Bibliografia), garantindo que o sistema se adapte à realidade de cada faculdade.
2. **Data:** Referência temporal do registro.
3. **Descrição:** O conteúdo textual do complemento.

> **Observação:** Não há limite de registros; podem ser cadastrados quantos complementos forem necessários para cada disciplina.

### Liberação para os Alunos

Para que os alunos visualizem as informações no portal, o professor deve selecionar o item desejado e clicar no botão **"Liberar para visualização"**. Uma vez liberado, o complemento ficará disponível para consulta pública no portal.

Portal

Para exibição no portal, o professor deve estar cadastrado como 'Professor responsável' na tela da disciplina.
