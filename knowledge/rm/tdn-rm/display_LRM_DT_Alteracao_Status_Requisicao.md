# ALTERAÇÃO DO STATUS DO REQUISITO

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Construção e Projetos** |

| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | **Processo Alterar Status para 'Em Andamento'** | *Alteração de status do requisito* | |
| **Versões/Release:** | *12.1.9* |

## Descrição

Processo que permite que as requisições tenham seu status alterado para **Em Andamento** quando o Status da requisição for **Aprovada**, **Reprovada** ou **Cancelada**

## Procedimento para Utilização

Este processo só irá mudar o status de requisições Aprovadas, Reprovadas ou Canceladas. Este processo deverá reabrir o atendimento no Agilis e o atendente deve ser o ultimo atendente antes da execução do processo. O processo também irá incluir um parecer com informações sobre a mudança de status da requisição, informando que a mesma teve seu status alterado para em andamento. O processo também exibi uma mensagem de confirmação para usuário alertando sob a execução da operação, após o usuário confirmar, o processo será executado diretamente.

Para realização de tais processos vamos em **Requisições / Processos / Alterar Status para 'Em Andamento'.**
