**Dúvida** O que ocorre quando o usuário preenche a data de encerramento do processo de desembaraço?  
  
**Ambiente** Protheus – Easy Import Control – Todas Versões.  
  
**Solução**

O campo W6\_DT\_ENCE (Encerramento) deve ser preenchido quando se termina todo o processo, exceto câmbio. Quando o usuário preenche este campo, ocorre o seguinte:

(1) Todos os títulos provisórios (PRE) são baixados (cancelados)  
(2) O sistema impede qualquer alteração em dados que afetem diretamente o processo (exceto em campos de observação).

Este campo deve ser preenchido após o usuário ter liquidado todas as despesas e ter pagado todos os impostos. Portanto, deve-se preencher com a data a partir da qual o processo fica arquivado.
