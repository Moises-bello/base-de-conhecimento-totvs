| **Passo a passo:** | Descrição A publicação do edital de pesquisa ou do edital de extensão acontece através do FLUIG. O edital só estará disponível para publicação se estiver devidamente cadastrado no TOTVS Educacional e marcado como "Edital liberado".  Somente pessoas associadas ao papel de "Reitoria" poderão realizar a publicação do edital.  Ao publicar o edital, será enviado um e-mail para todos os pesquisadores cadastrados, que estejam ativos, informando dessa publicação. É importante que o pesquisador tenha um e-mail válido cadastrado no TOTVS Educacional.  Pré-requisitos para utilizar a funcionalidade de publicação do edital   * Ter o FLUIG devidamente instalado e configurado conforme documentação:   + Instalação: <http://tdn.totvs.com/pages/viewpage.action?pageId=144409653>   + Configuração: <http://tdn.totvs.com/pages/viewpage.action?pageId=144409655> * Ter o TOTVS Developer Studio (TDS) devidamente instalado e configurado.   + Instalação: <http://tdn.totvs.com/display/fluig/Como+Instalar+-+TOTVS+%7C+Developer+Studio>   + Configuração: <http://tdn.totvs.com/pages/viewpage.action?pageId=73078179> * Criar no FLUIG os papéis necessários para a execução do fluxo de publicação do edital. É importante criar da mesma forma descrita abaixo pois o fluxo utiliza essa definição para referenciar os papéis).   + Código = **reitoria**| Descrição = **Reitoria** * Associar adequadamente os usuários do FLUIG aos papéis criados anteriormente. * Verificar se todos os pesquisadores cadastrados no TOTVS Educacional possuem endereço de e-mail válido. * Configurar corretamente o TOTVS Educacional para permitir o envio de e-mail através dos parâmetros globais do sistema.   + Configuração: <http://tdn.totvs.com/display/public/rm/Envio+de+email+-+LINHA+RM> * Importar o fluxo de publicação de edital para a ferramenta TOTVS Developer Studio (TDS). Caso não tenha alterado a instalação padrão dos produtos TOTVS, os arquivos zipados, contendo o(s) fluxo(s), estarão disponíveis em **c:\totvs\CorporeRM\ObjetosGerenciais\Fluig**   + Configuração: [http://tdn.totvs.com/download/attachments/172300565/RM\_BT\_Montagem\_Ambiente\_Workflows\_Fluig.pdf](http://tdn.totvs.com/download/attachments/172300565/RM_BT_Montagem_Ambiente_Workflows_Fluig.pdf?version=1&modificationDate=1432910252000&api=v2) * Exportar para o servidor do FLUIG os datasets, diagrama, formulário e eventos da publicação de edital.    + Configuração: <http://tdn.totvs.com/pages/viewpage.action?pageId=189313846>   Publicando o edital  Após realizar a exportação do fluxo de publicação do edital para o servidor do FLUIG o usuário deve iniciar uma nova solicitação escolhendo a opção "Educacional | Inovação, Pesquisa e Extensão | Publicação de Edital | Publicação de Edital".  Será apresentado um formulário onde o usuário deverá selecionar o edital e indicar se o mesmo será "Publicado" ou "Não publicado".  Ao salvar/enviar, caso a indicação seja para "Publicado", um e-mail será enviado (conforme parametrização) para todos os pesquisadores cadastrados, que estejam ativos, informando dessa publicação. Será realizada alteração no edital cadastrado no TOTVS Educacional para marcá-lo como publicado e informações como o número do processo do FLUIG e usuário que fez a publicação também serão gravadas.  Caso a indicação seja para "Não publicado", o usuário deverá informar uma justificativa na aba "Observações" e nenhuma alteração será realizada no edital cadastrado no TOTVS Educacional.  Após essas etapas o fluxo é encerrado.
