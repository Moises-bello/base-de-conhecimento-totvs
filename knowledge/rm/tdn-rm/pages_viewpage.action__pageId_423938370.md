Este processo permite que a contabilização, integrada ou não ao lote zero do Totvs Gestão Contábil seja excluída. De forma que o processo de Contabilização de Depreciação/Correção Monetária seja executado novamente.   
Deve-se selecionar qual o cenário de cálculo para qual a exclusão será realizada.  
Os lançamentos contábeis já enviados para o sistema contábil, armazenados no lote "N" definido no processo de integração contábil deve ser executado o processo Desfazer Contabilização, no Assistente de Exclusão da Contabilidade da Depreciação/Correção deve ser marcado a opção "Excluir".  
Caso os lançamentos já tenham sido integrados ao lote zero da contabilidade Deve ser executado o processo Desfazer Contabilização, no Assistente de Exclusão da Contabilidade da Depreciação/Correção deve ser marcado a opção Excluir via Tarefa. Essa opção cria uma Tarefa que deve ser executada pelo usuário do TOTVS Gestão Contábil.  
No TOTVS Gestão Contábil deve acessar Utilitários /Gerenciador de Tarefas selecione a tarefa e execute o processo Executar Tarefa para excluir a Contabilização de Depreciação/Correção Monetária.
