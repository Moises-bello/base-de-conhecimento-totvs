**Dúvida**Como corrigir o error log: Data width error - Field: F1\_PBRUTO?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**  
Neste caso, trata-se do tamanho do campo F1\_PBRUTO.   
O tamanho dos campos do SIGAEIC devem corresponder ao mesmo tamanho do SIGACOM.   
Sendo assim o boletim técnico que contempla os campos do SIGAEIC referente ao Peso bruto, peso liquido , quantidade e valor: [MTRADE-1656 DT Bloqueio do update U\_UTTESWHG nas versões P12](https://tdn.totvs.com/pages/releaseview.action?pageId=311631781)  
  
\*Observação: O documento esta separado por módulo SIGAEEC e SIGAEIC.
