# Envio de NFS-e

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Envio de Nota Fiscal Eletrônica de Serviço |
| **Situação/Requisito:** | Ao tentar transmitir a NFS-e ocorre a mensagem abaixo:  Não foi possível enviar a nota. Não foi possivel enviar o(s) movimento(s) da Coligada 1, Filial 1, Tipo Movimento 2.1.02. startIndex não pode ser maior que o comprimento da cadeia de caracteres. Nome do parâmetro: startIndex |
| **Solução/Implementação:** | O processo de envio da NFS-e passou a informar com uma mensagem clara se o campo Município do cadastro da Filial emitente está preenchido. |
