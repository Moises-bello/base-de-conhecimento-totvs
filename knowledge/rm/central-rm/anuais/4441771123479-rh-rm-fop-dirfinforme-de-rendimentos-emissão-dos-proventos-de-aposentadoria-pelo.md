Como parametrizo o sistema para informar a remuneração do código da receita 3533?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Como o processo referente a parametrização para emissão com o código de receita 3533 é demasiado extenso, foi disponibilizado um manual completo no TDN para servir de base de consulta e para tirar as dúvidas em relação a parametrização geral. **Acesse o link:** [Código de Receita 3533](https://tdn.totvs.com/pages/releaseview.action?pageId=209453637)
