**Dúvida**

Qual a configuração correta para o parâmetro **MV\_PMSCCT**?  
   
 **Ambiente**

Microsiga Protheus - até a release 11.80.  
  
**Solução**

O parâmetro é para indicar se há uso o Template de Terraplanagem e Construção Civil  (CCT), por padrão ele vem em branco, caso seja utilizado o Template deverá deixar como 1 , caso não utilize, deixe como 2.

|  |  |
| --- | --- |
| **MV\_PMSCCT** | Indica se utiliza o template de construção civil e terraplanagem. 1=Sim; 2=Não. |

**Obs..Todavia, o template CCT encontra-se descontinuado a partir da versão 12 , não houve evolução do produto.**
