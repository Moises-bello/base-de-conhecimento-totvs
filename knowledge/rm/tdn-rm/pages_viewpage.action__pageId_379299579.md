# EXCLUSÃO DE LANÇAMENTO QUANDO EXISTE BOLSA DE CRÉDITO - INTEGRAÇÃO PROTHEUS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Remoção de lançamento financeiro. |
| **Situação/Requisito:** | Ao excluir um lançamento financeiro via integração Protheus quando existe vinculo com lançamento de bolsa de crédito a integração apresenta mensagem indevida para o usuário. |
| **Solução/Implementação:** | Otimização na integração Protheus para remover o lançamento de bolsa de crédito juntamente com a remoção do lançamento do aluno. Se o usuário excluir o lançamento de bolsa de crédito, a integração continuará a solicitar que deve ser removido o lançamento do aluno. |
