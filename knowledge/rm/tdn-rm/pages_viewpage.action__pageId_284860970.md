# Ajuste na Elaboração de BPA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de BPA |
| **Situação:** | Ao abrir o BPA pela tela de atendimento externo e em seguida criar um novo BPA, o sistema não mantinha as informações do atendimento selecionado. |
| **Solução:** | Realizado ajuste para manter os dados do atendimento, quando criado um novo BPA pela tela de registro de atendimento externo. |
