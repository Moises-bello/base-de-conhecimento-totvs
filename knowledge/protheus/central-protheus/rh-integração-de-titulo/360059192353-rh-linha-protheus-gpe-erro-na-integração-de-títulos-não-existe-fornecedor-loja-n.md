**Ocorrência**Na integração de títulos: Não existe fornecedor / Loja no Cadastro de fornecedores.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.  
  
**Causa**Esse incidente ocorre, pois no cadastro de **Fornecedores - MATA020**, o campo de **Loja** (**A2\_LOJA**), está em em branco.   
  
**Solução**Erro apresentado: 12\_1\_23

**![erro_loja_fornecedor.JPG](https://centraldeatendimento.totvs.com/hc/article_attachments/360099514213)**  
Para solucionar essa ocorrência:   
  
**Acessar:** Modulo 02 - SIGACOM Compras ->Cadastros ->Fornecedores / Aba Cadastrais no campo A2\_LOJA informar um valor numérico para o mesmo.
