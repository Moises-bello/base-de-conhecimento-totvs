Defina os Eventos que o sistema irá considerar para fazer os cálculos, também é possível inserir Eventos Calculados por Fórmula ou Eventos Calculados por tipo de Ocorrência.

**Observação** Os códigos de cálculo: 0038 – Horas Dia em Dobro; 0041 – 1ª Faixa de Extra Noturna; 0042 – 2ª Faixa de Extra Noturna. São utilizados em um plugin de customização. Para quem não possui o plugin deve utilizar os códigos de cálculo: 0010 – Adicional Noturno 1ª Faixa Extra; 0011 – Adicional Noturno 2ª Faixa Extra.

**Código de cálculo** Será exibida uma lista de eventos cadastrados e calculados internamente pelo sistema.  
É possível selecionar o evento de código 0040 (Evento calculado por fórmula) para calcular um evento usando as fórmulas dos sistema, uma vez selecionado o código de cálculo 0040 o campo Código da Fórmula ficará disponível para associar uma a fórmula ao evento.  
   
O evento de código 0043 (Tipo Ocorrência) serve para associar tipos de ocorrências como atrasos, faltas etc... ao evento, mais detalhes na Informações Complementares.

**P****rioridade** Digite a prioridade de cálculo do evento. O sistema irá calcular primeiramente os eventos com menor prioridade. A prioridade é importante, pelo fato de eventos dependerem dos valores de outros eventos para serem calculados.

**Observação** No cadastro de parâmetros do sindicato deverão ser selecionados quais eventos do ponto irão ser considerados na movimentação dos funcionários.
