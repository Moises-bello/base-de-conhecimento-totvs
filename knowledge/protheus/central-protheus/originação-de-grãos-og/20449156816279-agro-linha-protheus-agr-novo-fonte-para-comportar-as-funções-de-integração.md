![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20449149460119) Tempo aproximado para leitura: **00:00:40 min****Ocorrência**  
No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para tratar o **envio** e **recebimento** de **tags XML** no **SIGAAGR** é apresentada a ocorrência **Novo fonte para comportar as funções de integração**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é necessário realizar o processo para tratar o **envio** e **recebimento** de **tags XML** no **SIGAAGR** no Sistema.  
  
**Solução**O fonte **AGRPMT010INTEG**contém as funções necessárias para tratar o **envio** e **recebimento** das **tags XML - eXtensible Markup Language** referente ao produto de agronegócio na **integração** do cadastro de **produto**.
