![relogio_tempo_leitura_2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26306737399831) Tempo aproximado para leitura: **00:03:00 min****Dúvida**Qual metodo contabilizar no estoque? por ambas/padrão ou por consumo e produção? como contabilizar corretamente?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.

**Solução**Existem 2 métodos de contabilização disponiveis, onde apenas 1 método deve ser utilizado.

**Método 1: Consumo e Produção**

A contabilização nesse etapa é dividida, primeiro calcula o **consumo**, onde normalmente após etapa, os cliente validam a area contabil, se os custos gerados por consumo seguem conforme esperado, para então ser feita a etapa posterior de **produção**.

**Método 1: Ambas/Padrão**

A contabilização de **consumo** e **produção** ocorre simultaneamente, descarregando os valores de uma só vez para ambos os tipos de movimento.

**Qual devo usar?**

A escolha entre utilizar o método de **Consumo/Produção** ou o método **ambas/padrão** deve ser feita conforme a necessidade específica do cenário e dos processos envolvidos.

**Eu posso usar os dois de forma conjunta?**

**Não pode**, os metodos tem conceitos de contabilizações diferentes, portanto **apenas 1 método deve ser utilizado**, afim de evitar duplicidades, uma vez que sempre que inicia a contabilização, o sistema apaga os lançamentos para gerar novamente.

**Exemplo:** Se voce usou **Consumo**, terminou e vai processar selecionando **ambas/padrão**, tudo oque voce fez por consumo vai ser perdido, porque ele sera refeito novamente, e agora aglutinado os dois metodos de uma só vez.
