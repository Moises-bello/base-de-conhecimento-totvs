**Dúvida**Como utilizar o Monitor Electron com o **License Server Virtual**?  
  
**Ambiente**Protheus – Servidor de Licenças - Todas as versões  
  
**Solução**Realize os seguintes passos:

**Download***:*

1. Portal do Cliente: <http://suporte.totvs.com>;
2. Menu Downloads e Atualizações;
3. Linha Protheus;
4. TOTVSTEC-FRAMEWORK;
5. Categoria: Monitor;
6. Baixe os arquivos conforme seu Sistema Operacional

**Instalação*:***

- Após Download, descompacte o arquivo e execute o instalador como Administrador;

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918441218839)

- Escolha um diretório de Destino e pressione o botão “Instalar”;

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918441225879)

- Após instalação pressione o botão “Concluir”;

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918435224087)

**Configuração:**

- Após abertura do Monitor, clique em “Novo Servidor”;

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918441237271)

- Preencha as configurações para conexão via TCP;

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918441238679)

- Clique no Servidor criado e preencha a informação com o nome do ambiente configurado no appserver.ini do License Server;

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918441244951)

- Efetue a autenticação do Usuário e Senha do License Server, lembrando que no padrão o usuário é Admin e a senha em branco;

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918435251863)  
  
- Configuração finalizada.  
![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17918435260823)
