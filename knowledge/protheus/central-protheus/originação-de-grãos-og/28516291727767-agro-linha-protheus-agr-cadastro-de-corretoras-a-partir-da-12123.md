Como realizar um **Cadastro de Corretoras a partir da 12.1.23**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

**1.** Acesse **Gestão de Agronegócio > Atualização >> Cadastros Gerais >>> Fornecedores**, selecionando a opção **Incluir** para adicionar um novo fornecedor. O novo registro deve ter os dados da sua corretora. Após finalizar o cadastro, acesse **Outras Ações → Relacionadas → Contatos**Informe os contatos que serão vinculados ao **Fornecedor**. Esse contato indica os dados do corretor. Para incluir um novo contato, utilize a opção de **Consulta Padrão** **F3** do campo **Código**. A tela apresentará os contatos existentes no Sistema. Utilize a opção;

**2.** Acesse **Gestão de Agronegócio > Atualização >> Comercialização >>> Negociações >>>> Contrato de Compras >>>>> Contrato de Compras**, selecionando a opção **Incluir** ou **Alterar** para um contrato de compra existente. Na pasta **Corretoras**, informe o código do **Fornecedor** que identifica a sua corretora no campo **Cod. Crtra**. No campo **Cod.Corretor** informe o **Contato** que foi vinculado no cadastro de **Fornecedor**.
