# Visão de Férias no Ícone "Marcação de Férias"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Folha de Pagamento |
| **Módulo:** | Férias |
| **Solução/Implementação:** | Criar uma visão para o menu de Marcação de Férias, onde será mostrado chapa, nome, inicio do período aquisitivo aberto, final do período aquisitivo aberto, saldo de férias e a data limite de gozo das férias. |
| **Requisito:** | [FOPCALCULO01-1738](http://jiraproducao.totvs.com.br/browse/FOPCALCULO01-1738) |

Foi implementado uma visão para mostrar ao usuário os dados de férias dos funcionários. Incluída no ícone "Marcação de Férias", antes não utilizado.

Para acessar siga os passos:

**Acesse Folha de Pagamento | Férias | Marcação de Férias;**

Foi criado uma nova permissão de segurança para ela, então deverá ativar no perfil previamente.
