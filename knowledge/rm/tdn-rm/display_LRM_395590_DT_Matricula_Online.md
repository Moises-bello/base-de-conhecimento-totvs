# MATRÍCULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matrícula online |
| **Situação/Requisito:** | Quando o aluno está matriculado em duas disciplinas que possuem co-requisito e ele troca a turma de uma delas via matricula online, o sistema bloqueia a matricula informando que o aluno não selecionou o co-requisito. |
| **Solução/Implementação:** | Melhoria na validação de co-requisito da matricula online, validando se o aluno está realizando troca de turma da disciplina de co-requisito. |
