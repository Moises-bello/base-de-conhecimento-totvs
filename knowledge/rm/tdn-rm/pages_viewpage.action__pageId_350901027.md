# CADASTRO DE APLICAÇÃO FINANCEIRA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Cadastro de Aplicação Financeira |
| **Situação/Requisito:** | Cliente relata que um usuário supervisor definiu os campos FTIPOAPLFIN.CODNATFINANCEIRAPAG e FTIPOAPLFIN.CODNATFINANCEIRAREC como obrigatórios em uma aplicação financeira. No entanto, ao incluir uma nova aplicação os campos não estão como obrigatórios e usuário consegue salvar esta nova aplicação sem preencher as informações. |
| **Solução/Implementação:** | Otimizado o cadastro de aplicação financeira para validar a obrigatoriedade de campos definidas pelo usuário supervisor. |
