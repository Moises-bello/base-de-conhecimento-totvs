![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16608580981399)Tempo aproximado para leitura: **02:00 min** **Dúvida**Como corrigir o aviso 'Não há registros válidos para seleção'?  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/16608614609815)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir de Versão 12.1.33

**Solução**Para que seja possível prosseguir com a geração da *Purchase Order '*P.O.'*,* deve ser verificado o tipo de agrupamento na Solicitação de Importação e os parâmetros informados. Em "**Concorrência**" selecione "**Outras Ações**" e "**Geração Automática da P.O.**"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16608445633303)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/16608409020439)

Após selecionar o Tipo de Agrupamento desejado, deve ser verificado os parâmetros para integração dos pedidos.
