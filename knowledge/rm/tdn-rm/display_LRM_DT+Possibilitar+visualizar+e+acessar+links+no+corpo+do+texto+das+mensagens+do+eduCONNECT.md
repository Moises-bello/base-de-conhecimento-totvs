# Links no corpo das mensagens do eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | eduCONNECT |
| **Função:** | Links no corpo das mensagens do eduCONNECT |
| **Situação/Requisito:** | Possibilitar visualizar e acessar links no corpo do texto das mensagens do eduCONNECT |
| **Solução/Implementação:** | Agora os textos das templates de mensagens da central de comunicação contam com a possibilidade de inserção de algumas tags HTML, as quais possibilitam uma melhor experiência do usuário do eduCONNECT. Os textos também contam com a possibilidade de inserção de links, os quais direcionam o usuário a outra página navegável no browser do smartphone. A saber alguns exemplos:    <font color="red">Muda a cor do texto para vermelho </font>    <b> Texto em negrito </b>  <i> Texto em itálico </i>  <u> Texto sublinhado </u>  <sup> Texto sobrescrito </sup> superscript <br/> Quebra de linha    Atenção! - Não é necessário tags para links - Não é permitido alterar o tamanho da fonte |
