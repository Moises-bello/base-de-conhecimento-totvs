# GERAÇÃO DOS ENCARGOS PARA PROVISÃO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Geração dos Encargos* |
| **Situação/Requisito:** | Gerar o encargo Provisão de Encargos de Férias por exemplo, no log do encargo o sistema informa o %seção.. Mas este % Seção na verdade se refere ao percentual de Aposentadoria Especial localizado no cadastro da seção. |
| **Solução/Implementação:** | Gerar o Log do encargo apresentando a informação 'Aposentadoria Especial' quando for gerado o encargos de provisão de férias. |
| **Chamados relacionados:** | TVRHFG |
