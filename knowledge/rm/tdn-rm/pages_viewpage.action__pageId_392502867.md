# Ajustes na criação de parâmetros para tipos de atendimento.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Novo Portal do Aluno |
| **Função:** | Requerimentos |
| **Situação/Requisito:** | Ao utilizar uma sentença SQL para preencher o valor de um parâmetro do tipo de atendimento, a lista de opções, referente a esse parâmetro, não era exibida corretamente na tela de requerimento do novo portal do aluno. |
| **Solução/Implementação:** | Foi realizado ajuste para exibir corretamente o valor retornado pela sentença SQL, no parâmetro do tipo de atendimento, quando essa sentença retorna apenas um valor. Mas o ideal, é que a sentença SQL retorne pelo menos dois valores para serem utilizados na criação da lista do novo portal do aluno. Ex: Código do período letivo e Descrição do período letivo. |
