# BANCA DO TCC NO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Banca no TCC no Portal* |
| **Situação/Requisito:** | *Quando existe dois professores com o mesmo código, porém em Coligadas distintas e se inclui um destes professores na banca de TCC, no portal está sendo exibido os dois professores, mesmo que seja inserido apenas um.* |
| **Solução/Implementação:** | *Ajuste no filtro para trazer apenas o professor que foi inserido na banca do TCC no portal, quando o mesmo possuir o mesmo código porém em outra coligada.*  *Além disso, foi feito o ajuste para que seja exibido no lookup de seleção do professor no RM apenas professores ainda não inseridos na banca.* |
