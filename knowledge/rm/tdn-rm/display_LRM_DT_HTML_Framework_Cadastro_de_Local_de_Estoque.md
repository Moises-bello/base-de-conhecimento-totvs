## Procedimento para Utilização

Para acessar a página de Cadastro de Local de Estoque em HTML, é preciso entrar no Fluig ou diretamente no endereço do servidor na qual as páginas estão hospedadas.

Existe o menu:

Gestão de Estoque, Compras e Faturamento | Local de Estoque

Este menu leva para a página de listagem com informações dos locais de estoque. 

Nos itens listados, estão disponíveis as opções Editar e Excluir.

A página de inclusão de registro possui os campos para inserir ou editar um Local de Estoque.
