![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28869826980119) Tempo aproximado para leitura: **00:05 min****Ocorrência**Help: FANODATA ao tentar incluir um registro com data de vencimento menor que data de emissão  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Financeiro - Todas as versões  
  
**Causa**Não é possível incluir um registro no contas a pagar com a data de vencimento menor que a data de emissão  
  
**Solução**

Exemplo:

Incluir um título com data de 30/12/2024 e adicionar o vencimento para o dia 27/12/2024. O Help exibido será: **FANODATA**.

**![Gravar_2024_12_30_16_51_22_568.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/28872138224151)**

A data de vencimento deve ser igual ou maior à data de emissão, ou seja, a partir de 30/12/2024.
