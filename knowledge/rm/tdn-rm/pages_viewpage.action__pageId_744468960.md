O processo de "Gerar Atendimento" no sistema RM permite que os usuários criem pedidos de assistência usando a interface do TCGI para seus contratos de aluguel. Isso facilita o registro e o acompanhamento de todas as interações relacionadas ao atendimento desses contratos, oferecendo uma forma integrada e eficiente de lidar com questões ligadas à locação. Além disso, os usuários podem aproveitar recursos como o histórico completo de atendimentos para ter uma visão completa do relacionamento com os clientes e a gestão dos contratos de aluguel. Essa abordagem centralizada ajuda a tornar a administração de contratos e atendimentos mais organizada, proporcionando uma experiência mais satisfatória para o cliente e otimizando os processos internos.

Para geração do atendimento, realize acesso a visão de contratos de locação \ Processos \ Gerar Atendimento.

Observações:

***A partir da versão 12.1.2306 é possível realizar a geração de atendimentos para contratos de locação com status rescindido.
