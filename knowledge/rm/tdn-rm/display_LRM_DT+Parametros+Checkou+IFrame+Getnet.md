## Descrição

Criado parâmetros para integração de pagamentos com cartão da solução Checkout IFrame da Getnet.

  

* **Código de acesso** - chave de identificação no e-commerce (seller\_id)
* **Ambiente** - ambiente do e-commerce ativo.
* **URL de checkout** - url de checkout onde será realizada as transações do e-commerce.
* **URL de autenticação** - url do serviço de autenticação do e-commerce.
* **URL de cancelamento** - url do serviço de cancelamento do e-commerce.
* **Client ID** - código de identificação para o serviço de autenticação.
* **Client Secret** - chave de acesso para o serviço de autenticação.
* **Número máximo de Parcelas** - quantidade de parcelas para o pagamento.
