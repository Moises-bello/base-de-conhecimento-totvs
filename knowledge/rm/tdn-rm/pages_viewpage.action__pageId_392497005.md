# MARCAÇÃO DE FÉRIAS PARA UM SUBORDINADO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Gestão de Férias. |
| **Situação/Requisito:** | Ao acessar o Portal com um chefe externo, e tentar marcar férias para um subordinado, passo a ocorrer o erro: "Funcionário -1 não tem grupo de acesso ao RM Portal associado". |
| **Solução/Implementação:** | Utilização e validação de dados do funcionário subordinado; como início, fim, dias de férias, dentre outros; no(a) agendamento/programação de férias pelo chefe. |
| **Tickets relacionados:** | 3608026 |
