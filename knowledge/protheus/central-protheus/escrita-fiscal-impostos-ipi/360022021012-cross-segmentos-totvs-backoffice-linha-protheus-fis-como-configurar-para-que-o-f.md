**Dúvida**

Como configurar para que o frete some na base do IPI?

**Ambiente**

Protheus - a partir da versão 11.80  
  
**Solução**

Para que o valor do frete some na base do IPI configure o campo abaixo no TES:

Calc.Ipi.Frete (F4\_IPIFRET) = Sim
