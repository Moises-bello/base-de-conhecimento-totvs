No tipo de movimento há o parâmetro Horário de Emissão que quando habilitado passa a exibir no movimento automaticamente, como informativo, Dados da Inclusão sendo esses dados a Data de Criação, Usuário de Criação e Horário de Emissão do movimento.   
Esse parâmetro possui três opções para determinar seu comportamento, que tem influência da Data de Emissão:

1. **Não utiliza**: Não exibe os Dados de Inclusão.
2. **Data e Hora de criação do movimento**: Exibe os Dados de Inclusão de acordo com a criação do movimento. Mesmo que a Data de Emissão seja editada e salva, o sistema sempre manterá os Dados da Inclusão de quando foi criado.
3. **Data e Hora de emissão do movimento**: Exibe os Dados de Inclusão de acordo com a criação do movimento. Quando a Data de Emissão for editada e salva, se os Dados da Inclusão forem diferentes de quando o movimento foi criado, o sistema automaticamente irá atualizar os Dados da Inclusão de quando foi alterada a data de emissão.
