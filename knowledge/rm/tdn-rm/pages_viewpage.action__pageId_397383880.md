# Desabilitar menu "Portal(antigo)" no novo portal do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Novo Portal do Aluno |
| **Função:** | Acesso ao menu |
| **Situação/Requisito:** | Cliente informa que ao tirar todas as permissões de acesso para as funcionalidades do portal do Aluno Corpore.Net, o menu de acesso ao portal antigo continua aparecendo no novo portal do aluno. |
| **Solução/Implementação:** | Foi realizado ajuste para retirar o menu de acesso ao portal antigo caso o usuário não possua permissões de acesso à essas funcionalidades do portal antigo Corpore.Net |
