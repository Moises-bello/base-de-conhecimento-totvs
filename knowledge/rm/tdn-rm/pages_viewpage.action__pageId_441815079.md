# EXCLUIR MATRÍCULA EM PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Educacional |
| **Função:** | Matrícula em período letivo - Excluir |
| **Situação/Requisito:** | Ao excluir um registro da matrícula no período letivo, caso tenha preenchido o campo “Data de encerramento da matrícula”, o sistema emitia incorretamente a mensagem “There is no Current data to access”. |
| **Solução/Implementação:** | Alteração para permitir excluir matrícula em período letivo, quando está preenchido o campo “Data de encerramento da matrícula”. |
