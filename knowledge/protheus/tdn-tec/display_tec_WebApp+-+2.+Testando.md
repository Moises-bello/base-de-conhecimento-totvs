Se o certificado for emitido para um domínio de sites (\*.mycompany.com), voce pode alterar o arquivo de hosts (C:\Windows\System32\drivers\etc\hosts) para um teste em um domínio válido. Para isso, adicione uma linha no arquivo que mapeia o localhost para um endereço do domínio. Ex:

text

Depois acesse, pelo navegador, usando o endereço mapeado e utilizando o protocolo **https://**. Caso tenha configurado para porta 443, não é necessário incluí-la após o endereço.

Ex: https://smartclient.mycompany.com

Verifique se aparece o cadeado ao lado do endereço e veja as informações de segurança do site.

Atenção

Certifique-se que a configuração foi efetivada, observando o cabeçalho do browser utilizado; caso a mensagem de "Não seguro" ou um cadeado com uma tarja vermelha seja apresentado, realize novamente as configurações.
