Para agilizar e facilitar o cadastro, uma Dimensão Contábil já cadastrada em uma Coligada poderá ser copiada para outras Coligadas. Para isso, selecione as Dimensões Contábeis que deseja copiar e execute o processo, marcando para quais Coligadas deseja efetuar a cópia.

**Observações**

* A Coligada de Origem considerada é sempre a de contexto.
* Não é possível copiar Entidades Globais.
* Para Entidades do tipo Tabela Dinâmica (GDINAM), serão copiadas apenas as Visíveis para todas as Coligadas.
