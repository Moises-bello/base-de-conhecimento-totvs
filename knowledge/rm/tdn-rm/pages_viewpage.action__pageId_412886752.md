# ENTURMAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Educacional |
| **Função:** | Enturmação |
| **Situação/Requisito:** | Ao realizar o processo de Enturmação, para o aluno inadimplente, no contexto de ensino básico, o sistema preenche o código da turma na Matricula no Período Letivo, porém não inclui nenhuma disciplina para o aluno. |
| **Solução/Implementação:** | Criado novo parâmetro "Bloquear enturmação para inadimplentes", na Parametrização do Educacional → Matrícula → Movimento 1/3, para que o usuário escolha se a enturmação deverá ou não ser bloqueada para alunos com pendências financeiras. |
