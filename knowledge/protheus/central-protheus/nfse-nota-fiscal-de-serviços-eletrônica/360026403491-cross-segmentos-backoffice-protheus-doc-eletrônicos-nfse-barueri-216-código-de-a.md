**Dúvida**  
Como solucionar a rejeição abaixo para o município de Barueri?  
216 - Código de Atividade não encontrada na base da PMB Informar Código de Atividade Válido.  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Documentos Eletrônicos - Todas as versões.  
  
**Solução**  
Para a prefeitura de Barueri, existe uma particularidade onde o código do serviço deve ser preenchido no campo **B1\_CNAE ou BZ\_CNAE** (caso use a rotina de indicador de produtos**.**  
  
Caso tenha **dúvidas a respeito do Código do Serviço/Atividade** usado para essa prestação de serviço e/ou a **rejeição ainda ocorra** mesmo com a informação já estando correta, **deverá acionar a prefeitura para esclarecimentos.**
