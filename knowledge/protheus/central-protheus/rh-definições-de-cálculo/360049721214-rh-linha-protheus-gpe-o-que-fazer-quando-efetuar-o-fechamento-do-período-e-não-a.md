**Dúvida**  
O que fazer quando efetuar o fechamento do período, mas o status não altera para fechado?  
  
 **Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17

**Solução**Verifique se as informações de calculo foram levadas corretamente para a tabela SRD e efetue a manutenção manual diretamente nas tabelas de período, pois como é uma rotina que atualiza com o fechamento será necessário altera-la manual para ficar correta.  
  
Caso as informações não tenham sido levadas corretamente para a SRD será necessário reabrir o período. Para saber como reabrir o período clique [aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360017683991-MP-GPE-Orienta%C3%A7%C3%A3o-sobre-Reabertura-de-Folha-de-Pagamento?source=search)   
  
Lembrando que o atendimento não dá suporte para reabertura de roteiros, indicamos que tenha um TI que entenda do processo ou um analista in loco para auxiliá-lo no processo.

Para que o problema não volte a ocorrer é necessário certificar-se que esta com último acumulado do RH.
