# Assunto

|  |  |
| --- | --- |
| **Produto:** | **TOTVS Educacional** |
| **Versões:** | *11.80* |
| **Ocorrência:** | *Parametrização de Upload de Materiais* |
| **Ambiente:** |  |
| **Passo a passo:** | **Upload/ Download de Materiais** |
| **Observações:** | É importante analisar as configurações de segurança de cada servidor, para que algumas restrições não interfiram no Upload e Download dos materiais. Por exemplo sistemas de firewall, antivírus, web-filter, etc. |

|  |
| --- |
| No Processo de Upload de Materiais, devem ser cumpridas as seguintes etapas:  Parametrização do Educacional: Informa-se quais são as especificações do repositório de armazenamento de arquivos.  Configuração de Perfis: É necessário liberar determinados acessos aos vários perfis para utilização da ferramenta no portal. |

|  |
| --- |
| **1 – Parâmetros do Educacional** |

*****1.1-*****Acesse o módulo Educacional

**1.2** - Vá aos parâmetros do Educacional → Ambiente/Parâmetros/Educacional

***1.3* -** Selecione a área de atuação:   
**15.04.01 – RM Portal - Gerais**

***1.4-*** Selecione a Etapa 4: **Portal – Geral 4/5**.

No campo “Diretório de armazenamento”, deve-se preencher com o endereço do local onde serão salvos os arquivos disponibilizados. No campo “Tamanho máximo de armazenamento”, deve-se preencher com o limite máximo estabelecido para cada arquivo que o Professor irá disponibilizar. No campo “Tamanho máximo do arquivo da entrega”, deve-se preencher com o limite máximo estabelecido para cada arquivo que o Aluno irá postar.

Após preencher todos os campos necessários, clique em “Avançar”.

***1.5-*** O sistema exibirá um resumo das alterações feitas. Clique em “Avançar”.

***1.6-*** Clique no botão concluir. O Sistema exibirá uma mensagem informando que, após a conclusão, todas as parametrizações serão efetivadas. Confirme a operação.

**2- Configuração dos Perfis**

***2.1*-** Selecione o módulo de Serviços Globais.

***2.2-*** Na aba Segurança, selecione os Perfis.

***2.3-*** Selecione o sistema Educacional, clique no perfil desejado e depois clique no botão editar.

***2.4-  Configuração para Perfil de Professor***

*2.4.1-* Para o perfil de Professor, selecione:

**Outras Permissões>RM Portal>Professor> Upload de Material**.

Permita os acessos para este perfil, de acordo com a necessidade da instituição.

***2.5- Configuração para Perfil do Aluno***

*2.5.1 -*  Para o perfil de Aluno, selecione:

**Outras Permissões>RM Portal>Materiais.**

Permita os acessos para este perfil, de acordo com a necessidade da instituição.

***2.6- Configuração para Perfil de Funcionários Administrativos da Instituição***

*2.6.1 -*  Para o perfil de Funcionário administrativo da instituição, selecione:

**Outras Permissões>RM Portal>Administração> Upload de Material**.

Permita os acessos para este perfil, de acordo com a necessidade da instituição.

**3- Visualização no Portal**

**3.1-** Acesse o módulo Educacional no portal.

***3.2-*** Para o perfil de **Professor**, na parte esquerda da tela a opção de Upload de Materiais ficará disponível no menu.

***3.3-*** Para o perfil de **Aluno**, na parte esquerda da tela o menu de Materiais ficara disponível.

***3.4 -*** Para o perfil de **Funcionário Administrativo** da instituição, na parte esquerda da tela o menu de Administração ficará disponível.

**4– Observações**

***4.1*** – É importante analisar as configurações de segurança de cada servidor, para que algumas restrições não interfiram no Upload e Download dos materiais. Por exemplo sistemas de firewall, antivírus, web-filter, etc.
