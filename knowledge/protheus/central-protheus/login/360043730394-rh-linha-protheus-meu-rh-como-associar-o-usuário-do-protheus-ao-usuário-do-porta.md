**Dúvida**  
MEU RH - Como associar o Usuário do Protheus ao Usuário do Portal para acesso ao MEU RH?  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - Meu RH – Todas às versões  
  
**Solução**  
Para associar o **Usuário do Protheus** ao cadastro do **Usuário do Portal** acesse no Protheus o módulo "**18 - SIGATCF - Terminal de Consulta do funcionário**":  
  
No Menu acesse as opções: > **Atualizações - Configurações  - Usuários - Genéricos:**  
  
![xh7g14LKN0.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4407521963287)  
  
Na rotina crie ou edite um **Usuário do Portal** e no campo "**Usuário Int**." informe o **Usuário do Protheus**, aquele que foi criado via Configurador (**SIGACFG**):  
  
![mR0wp4hz14.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4407522050071)  
  
[**RH - Linha Protheus - MEU RH - Como cadastrar um Usuário do Protheus via Configurador para acesso ao MEU RH?**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360043729194)  
  
**IMPORTANTE:** Para o MEU RH você pode ter um Usuário do Portal único/genérico, ou seja, não é necessário cadastrar um para cada Trabalhador, isso facilita a manutenção e evita que forneça permissões indevidas para determinados Trabalhadores.   
  
As permissões de acessos as informações do MEURH são concedidas para o Usuário do Portal, caso seja necessário definir diferentes visualizações, crie diferentes **Usuários do Portal** e vincule corretamente aos Participantes que terão acesso as determinadas informações.
