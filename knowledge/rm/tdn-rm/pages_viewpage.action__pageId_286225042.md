# Denifição de CBO ao gerar XML de integração

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Autorização de Procedimentos |
| **Situação:** | Ao realizar a solicitação de procedimentos pela Agenda de Atendimentos, o sistema gerava no XML de geração o dado do CBO, que não corresponde a especialidade da agenda informada. |
| **Solução:** | Alterado o sistema para carregar a informação de CBO corretamente, ao gerar a solicitação de procedimentos pela agenda de atendimentos. |
