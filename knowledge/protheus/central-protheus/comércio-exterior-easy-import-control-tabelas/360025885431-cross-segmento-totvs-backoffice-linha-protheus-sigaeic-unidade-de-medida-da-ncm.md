**Dúvida**Como deve ser preenchido o conteúdo do campo Unidade (YD\_UNID),  numérico (ex: 11) ou carácter (ex: UN) no cadastro de NCM?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
  
**Solução**O campo Unidade (YD\_UNID) é de carga padrão sendo gravado com o conteúdo numérico para a  integração com o Siscomex, devido a tabela da NCM (SYD) ter a finalidade para as integração dos processos de importação com o Siscomex.

Para os cliente que não utilizam o módulo SIGAEIC, este conteúdo pode ser alterado.
