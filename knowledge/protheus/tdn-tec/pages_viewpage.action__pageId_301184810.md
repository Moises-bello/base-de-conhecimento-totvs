<Resumo do que foi contemplado na alteração associada a essa nota de release> 

|  |  |
| --- | --- |
| Ocorrência | No componente TGrid, quando **não** é utilizado uma imagem no cabeçalho da coluna (método SetHeaderImage), o título da coluna não é apresentado.  Acontece apenas no browser Internet Explorer. |
| Correção | Corrigido o componente TGrid para sempre apresentar o título da coluna. |
| Informações adicionais | * Referente ao chamado: 1398015 * Referente à ocorrência: MTEC-704 * Disponível a partir da build 7.00.131227A - 3.4.5 |
