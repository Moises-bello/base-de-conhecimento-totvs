Na customização avançada, poderemos customizar os arquivos de Javascript do projeto. Para isso, é necessário se ter conhecimento em Javascript e AngularJs.

Será possível a customização dos seguintes componentes:

* **Controller**: responsáveis pelo controle da aplicação. É nele que ocorre o gerenciamento do fluxo de dados apresentados nas views.
* **Factory**: responsável por retornar um objeto de dados, reusável.

  Nos exemplos referente a customização, iremos customizar a tela de Ocorrências.
