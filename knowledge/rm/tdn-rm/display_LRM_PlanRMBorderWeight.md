# Descrição

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Hairline | Define uma borda muito fina (geralmente 0,25 pontos quando possível). |
| Thin | Define uma borda que tem normalmente 1 ponto (1 pixel da tela). |
| Medium | Define uma borda que tem normalmente 2 pontos (2 pixels da tela). |
| Thick | Define uma borda que tem normalmente 3 pontos (3 pixels da tela). |
