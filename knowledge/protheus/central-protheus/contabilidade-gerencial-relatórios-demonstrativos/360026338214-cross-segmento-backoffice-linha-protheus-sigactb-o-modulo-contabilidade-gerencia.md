**Dúvida** O modulo Contabilidade Gerencial possui um relatório que gere as informações contábeis atendendo as necessidades do IBGE para importação no programa PIA (Pesquisa de Industria Anual)?

**Ambiente**Microsiga Protheus  – Contabilidade Gerencial  – A partir da versão 11.80]

**Solução :**  
O Modulo Contabilidade Gerencial não possui um relatório específico para esta finalidade.  
  
A maioria dos relatórios no modulo possuem a funcionalidade para extração em Excel. Também é possível utilizar a rotina Consultas Genéricas para extrair os dados em Excel.   
  
Neste caso, sugerimos a alocação de um analista de TI especialista contábil para extrair as informações necessárias do Protheus para manipulação dos dados de acordo com a necessidade e importar no sistema do IBGE.
