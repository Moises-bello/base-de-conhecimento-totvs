![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31134701281431) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como realizar a alteração de atitude das ocorrências de forma global?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 11.80  
  
**Solução**  
Para realizar o processo de alteração de atitude das ocorrências de forma global, realize os seguintes passos:

1. No módulo de **Automação de Ponto** selecione a guia **Movimento** e o menu **Coletadas**:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31134709306775)

2. Realize um filtro para selecionar as ocorrências que deseja alterar e selecione o menu **Processos** e depois **Alterar Atitude**.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31134709307031)

3. Selecione as ocorrências antes de alterar a atitude, apenas as ocorrências selecionadas serão alteradas. Caso não selecione nenhum registro, o sistema irá exibir o alerta abaixo, aguardando a confirmação para executar o processo para todas as ocorrências da visão, selecione as ocorrências desejadas para que o processo seja executado conforme desejado.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/31134709307671)  
  
4. Após realizar a alteração da atitude das ocorrências desejadas, realize o processo de recálculo do espelho do cartão. Caso opte pelo recálculo selecionando parâmetros, sempre desmarque a opção Atualiza informações das ocorrências (Atitudes, Justificativas), para que a alteração seja mantida.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31134701286295)

**Importante**

Apenas paras os funcionários que usam o banco de horas do tipo diário por ocorrência podem ter as atitudes alteradas.  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31134701286935)
