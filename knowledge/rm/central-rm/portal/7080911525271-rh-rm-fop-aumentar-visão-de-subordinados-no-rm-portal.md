![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:31 min****Dúvida**Como aumentar a visão de subordinados no RM portal?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para realizar esse processo é necessário acessar o sistema nesse caminho descrito a baixo:  
**Serviços Globais | Serviços | Servidores de Aplicação | Novo**  
Deve possuir um cadastro com o ID do Server FopSubordinadosData, e no campo Número máximo de registros, deve informar a quantidade de registros que deseja visualizar. Segue print das telas onde deve realizar a alteração:  
   
1 - No módulo Serviços Globais,:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9250311918871/mceclip0.png)  
  
2 - Após clicar para incluir um novo registro, e alterar para a quantidade de registros que se deseja ser visualizada:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9250343401495/mceclip1.png)

Realizando o processo descrito acima a visão irá aumentar proporcionalmente ao número cadastrado.
