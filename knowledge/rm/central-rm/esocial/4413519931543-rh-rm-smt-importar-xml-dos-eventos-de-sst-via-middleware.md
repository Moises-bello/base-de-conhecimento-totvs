![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16035766195735) **Tempo aproximado para leitura: 00:01:30 min** **Dúvida**É possível importar o XML dos eventos de SST diretamente via Middleware ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Segurança e Saúde Ocupacional - A partir da versão 12.1.28 e superiores.  
  
**Solução**

Uma das premissas para usar o Middleware é a não consolidação de dados, inclusive SST. O cliente que utiliza o SST de outro software (terceiros) e utilizar o middleware deverão importar os XML's do SST diretamente do outro software ao governo ou não poderá utilizar o middleware, ou seja, deverá permanecer no TAF Full devido essa consolidação.

Atualmente o Middleware foi desenvolvido para tratar as informações geradas pelos produtos TOTVS RH- Linha RM, portanto os clientes que utilizam o sistema de Medicina e Segurança de terceiros devem gerenciar o envio e retorno ao governo através dos sistemas de terceiros ou devem utilizar o TAF.

Além disto, temos o nosso time de fábrica de software que pode lhe auxiliar em uma entrega customizada, aderente à necessidade e com a qualidade esperada.

Desta forma recomendo que os eventos de SST sejam importados diretamente no TAF.
