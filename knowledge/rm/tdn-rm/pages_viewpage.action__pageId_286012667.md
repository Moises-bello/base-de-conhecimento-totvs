# Réplica na Diária Especial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Elaboração de Contas |
| **Situação:** | O sistema apresentava validação de campos na réplica da diária especial, onde este tipo de rotina não requer tal validação. |
| **Solução:** | Foi adicionado uma condição para que a gravação da diária especial seja feita sem a validação dos campos previstos para os outros tipos de diárias. |
