# TCC em grupo

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão**Educacional* |
| **Função:** | *TCC* |
| **Situação/Requisito:** | *A disciplina de TCC está cadastrada como 'Não permite a realização em grupo'. Mesmo com essa configuração o portal permite iniciar o cadastro e ao final é informado um log que não é possível associar novas matrículas ao TCC.* |
| **Solução/Implementação:** | *Ajustes para que, caso uma disciplina de TCC não permita a realização em grupo, a seleção de novas matrículas e a inserção delas no TCC sejam desabilitadas no portal.* |
| **Conversores e Parâmetros:** | *N/A.* |
| **Chamados relacionados:** | *TSUEUC* |
| **Requisito (ISSUE):** | *N/A* |
| **Versões/Release:** | *12.1.8* |
