![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que rescisão complementar por dissídio não apresenta diferença de bases INSS IDs 0013 e 0014?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para rescisão complementar por dissídio, a diferença de bases INSS são calculadas no ID 0338, para isso, deve existir uma verba relacionada ao ID 0338.  
Os IDs 0013 e 0014 devem ser configurados na aba dissídio vinculado ao ID 0338.
