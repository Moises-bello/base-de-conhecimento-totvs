# Renovação de empréstimo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Movimentações - Renovação |
| **Situação/Requisito:** | O sistema não permitia renovar um empréstimo para aluno sem matrícula, mesmo quando desmarcado o parâmetro "Bloquear Empréstimo / Reserva para alunos sem disciplinas em curso”. |
| **Solução/Implementação:** | Alterado a descrição do parâmetro de “Biblioteca | Integração | Educacional” para “Bloquear Empréstimo / Reserva / Renovação para alunos sem disciplinas em curso”, que passa a observar esta regra também para Renovação de Empréstimos. |
