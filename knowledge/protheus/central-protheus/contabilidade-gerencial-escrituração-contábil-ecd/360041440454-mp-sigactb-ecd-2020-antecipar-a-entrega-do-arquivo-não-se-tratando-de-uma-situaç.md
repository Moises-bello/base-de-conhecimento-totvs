**Dúvida**

Caso tenha necessidade  enviar o arquivo antes do último dia útil do mês de maio, não se tratando de uma situação especial

Ex.:

* Licitação
* Auditoria

**Ambiente**

Microsiga Protheus – Contabilidade – A partir da versão 12.1.17  
  
**Solução**

O layout da ECD, até o momento, não foi disponibilizado pelo Protheus.  A liberação do pacote ECD está  prevista para 31/03/2020.  
Diante disso poderá como paliativo, gerar o arquivo no layout 7 e realizar a adequação das informações no .txt para o layout 8, manualmente.
