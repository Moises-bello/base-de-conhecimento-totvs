| **Sintoma** | **Como funciona o parâmetro “Utiliza Controle de Faltas para o cálculo de avos”** |
| Solução | Esse parâmetro é utilizado para que o Código de Cálculo 8 seja desconsiderado a partir do período cadastrado no campo de “Competência a considerar para controle de faltas”, ou seja, com o parâmetro marcado o sistema não considera os eventos com código de cálculo 8 que tenham sido lançados no período informado no campo “Competência a considerar para controle de faltas”.  Exemplo: O funcionário tem 5 faltas no período 7 do mês de competência 7. Marcando o parâmetro e cadastrando a competência do mês 7 no campo de competências a considerar para o controle de faltas o sistema vai desconsiderar as 5 faltas cadastradas no mês para o funcionário. |
