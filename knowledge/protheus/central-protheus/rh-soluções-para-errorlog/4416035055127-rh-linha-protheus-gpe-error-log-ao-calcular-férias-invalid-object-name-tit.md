![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34873838343447) Tempo aproximado para leitura: **00:02:00 min****Ocorrência**Ao tentar realizar o **Cálculo de Férias**, através da rotina **GPEM030**, é gerado ***error log***: "***Invalid object name*** **'TIT'**".  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões.  
  
**Causa**Este erro ocorre devido à tabela **TIT** não existir na Base de Dados.  
  
**Solução  
1.** Acessar o Módulo de Gestão de Pessoal, na rotina de Atualizações/Controle Disciplinar/Gestão Disciplinar:  
![](https://totvssuporte.zendesk.com/attachments/token/97BK01Eo7aGzdg3bDbwBp5NjC/?name=inline-321424956.png)  
  
**2.** Clicar sobre incluir, apenas para criar a tabela (não é necessário incluir nenhum registro);  
**3.** Realizar o Cálculo de Férias novamente.
