## Instalação do Produto RM Versão 12.1

|  |  |  |
| --- | --- | --- |
| **Produto** | **:** | Framework                         **Versão:**12.1 |
| **Processo** | **:** | Instalador dos Produtos RM |
| **Subprocesso** | **:** | Instalação do Produto RM Versão 12.1. |
| **Data da publicação** | **:** | 27/10/2014 |

 

**Introdução**  
 *Este documento tem por objetivo auxiliar a Instalação do Produto RM na Versão 12.1 na ORDEM correta. **O mesmo poderá ser aplicado para ambientes 32 ou 64 bits.***  
  

***Observação:*** *Todos os itens instalados na versão 12.1, já contemplam os instaladores dos Módulos já convertidos todos para Plataforma .Net, você os encontrará todos já instalados na pasta no caminho C:\totvs\CorporeRM\RM.Net. Além da própria versão .Net (Nova MDI).*  
    
   
  

 

**1º PASSO**  
 Para realizar a instalação em ambientes WIN32 ou 64bits deve-se realizar o seguinte procedimento:  
 Realizar a desinstalação completa dos produtos anteriores através do painel de controle, caso já estejam instalados.  
 **(Abaixo segue processo para desinstalação e reinstalação).**  
 1) Remover através do painel de controle os aplicativos TOTVS **seguindo a ordem**:  
 a) Aplicativos (RMFluxus\_GoBack, RMLabore, RMVitae...etc.);   
 b) BibliotecaRM; c) Excluir a pasta TOTVS que encontra-se no diretório c:\TOTVS;d) Pesquisar se existe algum arquivo RM ainda existente no Windows;f) Reiniciar a máquina.   
   
   
**2° PASSO**  
 Faça o Download no Portal do Cliente <https://suporte.totvs.com/download> da versão **BIBLIOTECA RM 12.1.MSI,** após o Download inicie a instalação.   
   
 Nesta primeira tela clique em Avançar.

clique no link para expandir a imagem.

Aceite os termos de Contrato de licença.  
  
  
 Selecione Nome de Usuário e Organização caso necessite (Conforme tela abaixo).

Caso necessite escolher outra pasta, clique em alterar, ou mantenha o mesmo caminho:  
   
   
 Logo em seguida, clique em Instalar.  
   
   
 O Processo de Instalação dará ínicio: Aguarde até aparecer a tela do ambiente que deseja realizar as suas configurações.   
   
   
 Nesta tela você terá a opção de selecionar se o seu ambiente será LOCAL ou 3 CAMADAS.  
 (Client ou Server)

O Processo de configuração continuará a seguir:  
   
   
 Nesta Tela a instalação solicita o seu Idioma:

Logo em seguida o processo continuará:  
   
   
   
Nesta tela, você irá selecionar a versão do seu Banco de Dados que utiliza, o Nome do Servidor de Banco de Dados, e o Nome da sua base no Banco de Dados.  
   
   
 Após estes processos a instalação se encerrará, basta clicar em concluir e a sua versão 12.1 estará concluída.
