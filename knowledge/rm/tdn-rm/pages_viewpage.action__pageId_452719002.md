Este recurso deve ser utilizado para determinar uma data específica para o funcionário utilizar um horário alternativo.

**Data de mudança**  
Informar o data de mudança do horário para utilização do horário programado.

**Código do horário**  
Informar o código do horário que será cadastrado como programado.

**Índice do horário**  
Informar o índice do horário

**Aprovado**  
Sinalização de aprovação para utilização do horário.

**Exemplo:**  
Horário do funcionário: 08:00 12:00 14:00 18:00  
No horário alternativo tem os seguintes horários cadastrados:  
01 – 10:00 às 16:00  
02 – 13:00 às 19:00  
No dia 14/11/2006 o funcionário efetuou as seguintes batidas:  
12:30E 19:00  
O sistema considera que o funcionário deveria utilizar o horário alternativo 02. Com o horário programado podemos determinar um outro horário para o sistema considerar no dia 14/11/2006.  
Caso cadastre o horário programado 01 para o dia 14/11/2006. O sistema respeitará para o cálculo o horário 01 e não o horário alternativo.

**Observação:**  
O horário programado deve ser um horário alternativo.
