**Dúvida**Ao acessar a rotina **(GPEA940)** - Gerenciamento do Termo de Consentimento apresenta a mensagem: **"Tabelas não definidas RI2/RI3 - Versionamento  e Aceites do Consentimento."**   
O que deve ser realizado para correção da mensagem?  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360097969953/mceclip0.png)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Portal do Candidato – Todas as versões  
  
**Solução**Para o release **12.1.23** deverá aplicar o pacote pontual para adequação da base pacote disponível no link abaixo.  
[Pacote de atualização de dicionários do controle de dados protegidos para release 12.1.23](https://suporte.totvs.com/portal/p/10098/download?e=994842)   
  
Para o release **12.1.25** deverá aplicar o pacote pontual para adequação da base pacote disponível no link abaixo.  
[Pacote de atualização de dicionários do controle de dados protegidos para releases 12.1.25](https://suporte.totvs.com/portal/p/10098/download?e=994841)  
  
A partir do release **12.1.27** será necessário aplicar o **Dicionário Diferencial,** para que as tabelas relacionadas ao processo possam ser criadas.  
  
Para fazer o **download do pacote de Dicionário Diferencial Brasil** acesse o link abaixo:

Download Release [12.1.27](https://suporte.totvs.com/portal/p/10098/download?e=946797)  
Download Release [12.1.33](https://suporte.totvs.com/portal/p/10098/download?e=1031456)  
  
Caso opte por realizar o Download diretamente no portal segue Filtro a ser utilizado. Adeque o filtro ao seu release.
