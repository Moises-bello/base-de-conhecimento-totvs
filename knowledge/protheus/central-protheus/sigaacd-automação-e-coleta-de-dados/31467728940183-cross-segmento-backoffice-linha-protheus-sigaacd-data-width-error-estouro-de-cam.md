![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31467752941463) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Ao realizar o processo de inventário no aplicativo Meu Coletor de Dados, apresenta o error.log

Data width error - Field: CBC\_QUANT Value: 999999998000000008192.000000 on GRVINV(ACDM010.PRW) 28/01/2025 21:16:04

O que fazer para resolver?  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**

Para correção desse error.log é necessário verificar no seu cadastro do produto, na aba

**MRP / Suprimentos,** se o campo **Qtd.Embalag (B1\_QE)** consta com preenchimento. Caso estiver preenchido ira apresenta o error.log do estouro de campo Data Width Error.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/31467752943639)

Para o error.log não ocorrer no aplicativo Meu Coletor de Dados deixar o campo em branco, para ler a leitura do inventário ou outros processos realizados no aplicativo.
