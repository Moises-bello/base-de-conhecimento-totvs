**Dúvida**

No Dashboard Backoffice é possível incluir um novo Card?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FATA900 -  Todas as versões  
  
**Solução**  
No **Dashboard Backoffice** estão disponíveis as inclusões de novos CARDS.

Para **Incluir** um **Card**:

1) Clicar no menu **Gerenciar Cards**;

2) Clicar no botão **Incluir**;

3) Informar os campos conforme sequência:

a) **Tipo de Card**: Selecionar no combo o tipo de Card desejado;

b) **Status**: Indica se o Card está desabilitado ou habilitado para visualização;

c) **Título**: Informar um título para o Card;

d) **Mostrar Filtros**:  Indica se o Card está com o botão de filtro do usuário habilitado ou desabilitado.

e) **Primeira Informação até Quarta Informação**: Selecionar os itens que deseja exibir, como por exemplo: Pedido, Produto ou Quantidade;

f) **Filtros**: É possível filtrar as informações do Card, como por exemplo por um único Pedido ou Produto específico. A configuração de **Filtro** está explanada em detalhes no ponto [**Filtros do Card**](https://tdn.engpro.totvs.com.br/display/public/PROT/Gerenciar+Cards#GerenciarCards-Filtros) deste documento.

g) **Help do Card**: Essa funcionalidade permite informar uma descrição de **help** para o Card, que será exibida ao clicar no**Título do Card**;

h) Clicar no botão **Salvar** para concluir a operação:
