# Ajuste no Formulário Registro de Atendimento Externo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | **Saúde** |
| **Módulo:** | TOTVS Gestão de Saúde. |
| **Função:** | Registro de Atendimento Externo. |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu Unidade de Diagnóstico/Registro de Atendimento Externo, preencher o atendimento, preencher a aba Exames Solicitados, acessar a Elaboração de Contas através do botão Lançamento em Conta, acessar a aba Diagnóstico e Terapia, é possível verificar que o lançamento era exibido com duplicidade de registros. |
| **Solução:** | Foram realizados ajustes no formulário para que ao registrar os Exames Solicitados, estes não sejam exibidos em duplicidade em Elaboração de Contas.. |
