| **Versões:** | 12.1.17 |
| **Ocorrência:** | Transferência de Controle |
| **Ambiente:** |  |
| **Passo a passo:** | **Introdução**  Este processo é responsável por transferir o(s) patrimônio(s) entre [filiais](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Filial.aspx), [departamentos](http://wikihelp.totvs.com.br/WikiHelp/FIS/FIS.Departamentos.aspx), [centros de custo](http://wikihelp.totvs.com.br/WikiHelp/CTB/CTB.cadastroCentroCustos.aspx), [localizações](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Localidade.aspx) e [responsáveis](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Responsavel.aspx).A transferência poderá ser realizada utilizando um ou mais [patrimônios](http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.Patrimonio.aspx), sendo que para a segunda opção deve-se atentar a questões como a data de aquisição e se estão todos ativos.  **Procedimento (Transferência de Controle)**   Acessar o patrimônio pelo menu Cadastro / Patrimônios, editar os respectivos patrimônios, Processos > Transferência de Controle.    Altere os campos e aplique os valores que desejarem.    Informe a Data da Transferência, lembre-se que esta data deve compreender o Mês da competência em aberto.  Caso deseje contabilizar a mudança marque o flag.  Caso este Patrimônio possua outros Patrimônios agregados, o usuário poderá optar se Transfere os mesmos ou não.    Avance e execute o Processo. Ao término será apresentado o Log informando se a alteração foi realizada.    Assim os dados do Patrimônio serão alterados.      **Procedimento (Cancelar Transferência de Controle)**  Se por algum motivo deseja cancelar a Transferência de Controle poderá ser feito:  **Acessar a Transferência de Controle pelo menu Cadastro / Transferência de Controle, editar as respectivas Transferências, Processos > Cancelamento de Transferência de Controle.**    E o Patrimônio voltará com dados iniciais.            **Observações:**  **A transferência de controle não será realizada nas seguintes situações:**   * Em patrimônio(s) considerado(s) Título(s); * Em patrimônio(s) inativo(s) e baixado(s) totalmente. Para isto a baixa total deverá ser realizada com o parâmetro "Desativar Patrimônio após sofrer baixa total" marcado; * Em patrimônio(s) inativo(s); * Em data anterior a da última transferência realizada para o(s) mesmo(s) patrimônio(s), ou seja, deve-se conferir se o patrimônio já possui uma transferência e se a data é posterior a informada no processo a ser realizado; * Os dados de destino (filial, departamento, centro de custo, localização e responsável) devem estar ativos. * Os dados de destino devem ser diferentes dos dados de origem, ou seja, os dados (filial, departamento, centro de custo, localização e responsável) atuais do patrimônio devem ser diferentes dos informados durante a transferência de controle.   **Transferências de controle realizadas**  Após realizar a transferência de controle com sucesso pode-se conferir seu resultado por destino a partir da tela de cadastro de patrimônio. Para isto é necessário editar o patrimônio transferido e acessar a aba de históricos de controle. Esta aba apresentará o histórico por Filial, Centro de custo, Departamento, Responsável e Localização.  Entre as informações que serão exibidas nesta tela podem-se citar os usuários de criação e alteração, as datas de criação e alteração, a data de entrega do patrimônio naquela opção (exemplo: entrada na filial) e a data de saída do patrimônio naquela opção (exemplo: saída da filial). Outro caminho existente na visão de cadastro de patrimônios para acessar as informações das transferências realizadas é em Anexos, históricos de Filial, Centro de custo, Departamento, Responsável ou Localização.  **Serviço referente ao envio de e-mail**  A cada transferência de controle realizada pode-se enviar um e-mail para o responsável atual e o novo responsável do patrimônio.  Caso queira utilizar esta funcionalidade deve-se marcar a opção "Enviar e-mail de patrimônios sob responsabilidade" nos parâmetros do sistema. Observação: Este recurso é válido somente quando o responsável está definido como um funcionário do RM Labore. Para isto o parâmetro "Usar funcionários do RM Labore como responsáveis" deve estar marcado e o campo que armazena o e-mail do funcionário devidamente preenchido.    Observação :  Caso seja necessário realizar a transferencia de controle para um periodo posterior a data do periodo de calculo atual, será necessário marca o parametro abaixo.  Menu > ambinete > parametro > gestão patrimonial > avança > selecione Transferencia de controle .  Ao marca o parametro, não será necessário permitido realizar o processo alterando a filial, conforme mensagem abaixo. |
