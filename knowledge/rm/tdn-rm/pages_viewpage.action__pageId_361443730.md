# ASSOCIAÇÃO DE MATRIZ APLICADA À CAMPUS/POLO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Associação de matriz aplicada à campus/polo |
| **Situação/Requisito:** | No processo de “Assistente para Associação de matriz aplicada à campus/polo”, emitia mensagem de erro ao utilizar filtro para a matriz aplicada. |
| **Solução/Implementação:** | Alterado processo de “Assistente para Associação de matriz aplicada à campus/polo” para permitir utilizar  filtros nas colunas “Matriz Aplicada” e “Campus/Polo” da tela do processo.  No filtro para "Campus/Polo", aparecia incorretamente a descrição "\_CAMPUSMEC\_ e foi alterado para "Código do Campus/Polo no MEC". Obs.: este campo somente existirá na versão 12.1.19 mediante execução de script. |
