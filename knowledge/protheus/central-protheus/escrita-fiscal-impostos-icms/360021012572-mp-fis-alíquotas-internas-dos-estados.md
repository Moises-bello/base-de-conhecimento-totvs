**Dúvida**Como configurar no sistema as Alíquotas internas para os Estados Destinos?  
   
 **Ambiente**Protheus - A partir da versão 11.80]  
  
   
**Solução**As alíquotas internas para  os Estados Destinos servem para o cálculo do Difal, cálculo do ICMS-ST, Cálculo do Diferencial de Alíquota-ST

Para configurar as alíquotas alterar o Parâmetro: MV\_ESTICM

Exemplo de Preenchimento: MV\_ESTICM = SP18
