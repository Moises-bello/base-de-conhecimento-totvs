**Dúvida**Como solucionar a mensagem de erro WSCERRINT / Cannot find function Objself in appmap   
  
**Ambiente**

Cross Segmentos - Backoffice Protheus - Doc. Eletrônicos - NFe - a partir da versão 12.1.25

Cross Segmentos - TSS - a partir da versão 12

**Solução**

* Caso gere o ***erro conforme abaixo:***

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414382394263/mceclip0.png)

1. Aplique a ***Patch no Protheus:***

**12.1.25:** [Clique Aqui](https://suporte.totvs.com/portal/p/10098/download#detail/785367)

**12.1.27:** [Clique Aqui](https://suporte.totvs.com/portal/p/10098/download#detail/956647)

**12.1.33 :** [Clique Aqui](https://suporte.totvs.com/portal/p/10098/download#detail/1040489)

2. Caso o ***TSS esteja na Release inferior 12.1.27:***

1. Caso aplicar no TSS ocorrerá o ***erro dessa documentação abaixo:***  
[MP - TSS - Server returned: Duplicated function](https://centraldeatendimento.totvs.com/hc/pt-br/articles/1500008076022-MP-TSS-Server-returned-Duplicated-function?source=search)  
  
  
2. Para migrar o ***TSS realizar o procedimento, abaixo:***  
[MP - TSS - Migração para TSS 12.1.27 ou 12.1.33?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360038065954-MP-TSS-Migra%C3%A7%C3%A3o-para-TSS-12-1-27-ou-12-1-33-?source=search)
