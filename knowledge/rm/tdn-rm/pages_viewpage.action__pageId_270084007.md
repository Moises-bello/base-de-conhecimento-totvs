# Controle Débito x Crédito Tela de Partidas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Controle Débito x Crédito Tela de Partidas |
| **Situação/Requisito:** | Cliente possui um lançamento com várias partidas a Débitos e uma Parida a Crédito. Ao realizar a inclusão de uma partida a Débito salvar a mesma, editar a partida a Crédito e realizar o ajuste do valor para que não haja a diferença, salvar, na tela da capa do lançamento ao clicar em salvar é apresentado a mensagem: "O LANÇAMENTO NÃO PODE SER SALVO POIS A SOMA DAS PARTIDAS A DÉBITO É DIFERENTE DA SOMAS DAS PARTIDAS A CRÉDITO". Porém não há diferenças no lançamento. |
| **Solução/Implementação:** | Ajuste na tela de partidas para que ao se alterar o valor de uma partida clicar em Ok e alterar o valor voltando ao que era novamente calcule a diferença entre débitos e créditos corretamente. |
