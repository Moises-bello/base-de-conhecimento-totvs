## O que são?

Este relatório apresenta o status da última execução dos Projetos de Testes, fornecendo uma visão geral do status e resultados mais recentes de cada Projeto. Ele é uma ferramenta essencial para monitorar o progresso e identificar possíveis problemas em execuções dos testes automatizados.

## Para que servem?

O relatório serve para acompanhar de forma rápida e eficiente o desempenho das execuções de teste mais recentes, ajudando a garantir que os Projetos estão sendo executados conforme esperado. Além disso, ele permite identificar falhas e tomar medidas corretivas, como editar os Projetos diretamente a partir do relatório e visualizar o Log.

# Exemplo de Uso

Como FiltrarComo filtrar 1. Navegação para Filtrar

1. Navegue no menu TOTVS Automação de Testes e clique em **Relatórios**→ **Status de Execução → Detalhes.**

2. Visualização do Relatório

Este relatório apresenta a execução mais recente dos Projetos de Teste, fornecendo uma análise detalhada dos resultados obtidos, identificando possíveis falhas, e destacando áreas de melhoria e oportunidades para otimização do processo de teste.

Os filtros disponíveis incluem:

**Versão**: Permite filtrar os Projetos de Teste com base na versão específica da atividade.

**Grupos**: Este filtro permite selecionar Projetos de Teste com base nos Grupos aos quais pertencem. [(Saiba mais sobre os Grupos clicando aqui)](https://tdn.totvs.com/display/public/LRM/6+-+Grupos#Cria%C3%A7%C3%A3odeumgrupo--1840173891).

**Status**: Filtra os projetos de teste de acordo com o seu estado atual, como sucesso, falha ou não executado.

**Nome do projeto de teste**: Permite a pesquisa e filtragem de Projetos com base no nome específico do Projeto de Teste. Esse filtro facilita a localização de Projetos específicos rapidamente, especialmente quando há uma grande quantidade de testes a serem geridos.

Na tabela, é possível visualizar e identificar a quantidade de projetos de teste em cada status, permitindo uma análise clara do progresso e dos resultados de cada item.

Após a aplicação do filtro, os seguintes dados são apresentados:

* Nome do Projeto de Teste
* Status
* Data de Finalização da última execução do Projeto
* Ações

No campo "Ações", é possível:

**Editar projeto de teste:** A edição permite ajustes e melhorias contínuas no processo de testes, sendo essencial para corrigir parâmetros incorretos. Isso garante que o projeto de teste permaneça sempre alinhado com os objetivos atuais e as necessidades do sistema.

**Visualizar log:** Com esse recurso, é possível visualizar os logs detalhados das atividades do projeto de teste por meio da ferramenta Histórico de Execuções, oferecendo uma visão completa do desempenho e das ações realizadas durante o processo.

[(Para obter  informações sobre a ferramenta "Histórico de Execuções", clique aqui).](https://tdn.totvs.com.br/pages/viewpage.action?pageId=754947778)

3. Exportação dos Logs

É possível também exportar os dados de execuções de projetos no formato **PDF**.

Para a exportação de logs é necessário preencher apenas o filtro de versão e grupos:

**Versão**: Permite filtrar os Projetos de Teste com base na versão específica da atividade.

**Grupos**: Este filtro permite selecionar Projetos de Teste com base nos Grupos aos quais pertencem. [(Saiba mais sobre os Grupos clicando aqui)](https://tdn.totvs.com/display/public/LRM/6+-+Grupos#Cria%C3%A7%C3%A3odeumgrupo--1840173891).

Após configurar os filtros e realizar a pesquisa, será exibido um botão de exportação:

Ao clicar no botão, um modal será aberto para que você informe um ou mais e-mails que receberão o relatório. Após confirmar a exportação, o documento será enviado aos destinatários em poucos minutos.

---

# Saiba mais

Para a exportação, serão incluídas todas as execuções filtradas pelos critérios de versão e grupos, não apenas as encontradas na primeira página da pesquisa.

A exportação dos dados de execuções de projetos no formato PDF é rápida, levando apenas alguns segundos ou minutos. No entanto, o tempo de geração pode se estender caso sua instalação possua um grande número de Projetos de Teste.

Mesmo em caso de erro durante a geração, os destinatários receberão um e-mail informando o ocorrido.

O relatório facilita a análise dos resultados de forma eficiente, permitindo identificar rapidamente áreas problemáticas e oportunidades de melhoria, além de ajudar a priorizar testes críticos e refinar Casos de Testes.

Se um Projeto de Teste apresenta falhas recorrentes, é possível utilizar os relatórios para identificar padrões nas execuções. A partir disso, o usuário pode ajustar o projeto de teste, corrigir erros no sistema ou modificar os parâmetros de teste para resolver o problema de forma definitiva.

# FAQ

**P: Como os relatórios auxiliam na priorização de correções?**  
R: Os relatórios de execução destacam claramente os testes que falharam, permitindo que as equipas priorizem as correções com base na gravidade e frequência das falhas. Essa priorização ajuda a focar em problemas críticos que podem impactar diretamente o funcionamento do teste.

**P: Por que o acompanhamento de execuções de teste é importante?**  
R: O acompanhamento permite detectar problemas em tempo real, garantindo que as falhas sejam corrigidas rapidamente, mantendo a qualidade do software. Além disso, ele proporciona uma visão clara sobre o desempenho contínuo dos Projetos de Testes.P:
