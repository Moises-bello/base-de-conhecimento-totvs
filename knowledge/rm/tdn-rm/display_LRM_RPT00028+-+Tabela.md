*A pesquisa por uma fonte de dados é feita através do menu “Inicio | Dados | Adicionar Fonte de Dados”.*

2ª - Cabeçalho

       Para imprimir o cabeçalho de coluna na parte superior das informações do documento, adicione uma faixa de cabeçalho de página ao relatório. Para fazer isso, clique com o botão direito do mouse na superfície do relatório e selecione Inserir Seção | Cabeçalho do Detalhe, no menu de contexto que é chamado.

       Selecionando a Caixa de Ferramentas, inclua controles do tipo Texto e atribua a nomenclatura desejada para as colunas da tabela.

3ª - Incluindo a Tabela

       Para incluir o controle Tabela acesse a aba de Caixa de Ferramentas | Controles Avançados, selecione e arraste para o corpo do relatório.

       Para fornecer conteúdo dinâmico às colunas da tabela, alterne para a Lista de campos. Selecione o campo, arraste-o e solte-o na célula desejada.

*Também é possível associar uma fonte de dados à célula utilizando a seguinte forma: Clicando no ícone Smart Tag da célula, em “ligação de dados” selecione a coluna desejada.*
