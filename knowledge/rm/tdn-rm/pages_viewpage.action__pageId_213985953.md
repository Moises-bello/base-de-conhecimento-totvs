| **Passo a passo:** | **Nota Técnica 2015.003 – Nota Fiscal Eletrônica**  Realize o download do pacote **SCRIPT\_NT2015002\_NT2015003\_11\_82.ZIP para a versão 11.82** ou **SCRIPT\_NT2015002\_NT2015003\_12\_1\_8.ZIP para a versão 12.1.8** na central de downloads do cliente e o execute no RM.Script. Para confirmar a criação dos campos **PERICMSESTDESTINO** e **PERICMSFCP** na tabela **DREGRAICMS** pelo script da NT2015.003 sobre Grupo de Tributação do ICMS para UF de Destino, favor executar o seguinte select no Banco de dados Corpore:  SELECT PERICMSESTDESTINO,PERICMSFCP,\* FROM DREGRAICMS    Para confirmar a criação do campo **CODIGOCEST** na tabela **TPRDFISCAL** pelo script da NT2015.003 sobre Código Especificador da Situação Tributária, favor executar o seguinte select no Banco de dados Corpore:  SELECT CODIGOCEST,\* FROM TPRDFISCAL        **Natureza de operação (CFOP)**  O grupo de partilha de ICMS ( ICMSUFDest ), conforme próprio nome ( Informação do ICMS Interestadual ) , somente será gerado quando utilizado natureza de operação interestadual (**natureza iniciada por 6**). PS: Desta forma, será criado no relatório DANFE um único registro contendo o somatório dos valores de todos os itens da NF-e.    **Formula para os itens de movimento:**  Utilizando esta formula, os valores serão gerados por item, ou seja, será apresentado uma linha por item no DANFE;  SE TABMOVFISCAL('OPERACAOCONSUMIDORFINAL','I') =1 ENTAO "vFCPUFDest = " + VALTOSTR(VFCPUFDEST('ICMS')) +  " vICMSUFDest = " + VALTOSTR(VICMSUFDEST('ICMS')) +  " vICMSUFRemet = " + VALTOSTR(VICMSUFREMET('ICMS')) SENAO "" FIMSE    Acesse os parâmetros do tipo de movimento | edite o tipo de movimento | Etapa Item - Campos livres 2/2, no campo Formula Preenchimento Histórico selecione a formula criada.  PS: Desta forma, será criado no relatório DANFE uma linha para cada item da NF-e.    **Movimento**  Segundo a NT 2015.003 a legislação só deve ser aplicada quando se tratar de venda para consumidor final.
