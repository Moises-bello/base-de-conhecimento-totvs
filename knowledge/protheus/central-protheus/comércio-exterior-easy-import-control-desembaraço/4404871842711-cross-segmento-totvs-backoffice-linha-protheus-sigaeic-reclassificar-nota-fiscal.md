**Dúvida**É possível Reclassificar Nota fiscal?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**Não existe esta opção no **SIGAEIC**, a nota deve ser estornada no **SIGAEIC** e gerada novamente, para então ser classificada no **SIGACOM**.
