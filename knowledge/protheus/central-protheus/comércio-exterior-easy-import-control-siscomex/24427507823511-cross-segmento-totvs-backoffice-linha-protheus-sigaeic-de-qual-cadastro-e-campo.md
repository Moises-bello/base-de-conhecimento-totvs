![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24427522725271)Tempo aproximado para leitura:**00:02:00 min** **Dúvida**De qual cadastro e campo vem a informação para o preenchimento do campo **"Descri. Comp"?** (EK9\_DSCCOM)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24427507797271)

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão12.1.33.  
  
**Solução** A informação vem da rotina **MATA010** do Cadastro de produtos, aba outros, campo **'Desc. LI.'** (B1\_VM\_GI)
