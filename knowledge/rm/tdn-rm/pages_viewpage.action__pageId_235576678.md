# INCLUSÃO DE BOLSAS NO CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Inclusão de bolsas* |
| **Situação/Requisito:** | *Ao incluir uma bolsa em um contrato que possua a mesma bolsa inativa e aplicada ao mesmo escopo de parcelas, o sistema entende que o contrato já possui aquela bolsa e não permite a inclusão.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de inclusão de bolsas de forma que o sistema permita a inclusão de uma mesma bolsa para as mesmas parcelas, caso a bolsa existente esteja inativa.* |
