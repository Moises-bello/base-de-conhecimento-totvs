# NOTAS/FALTAS DE ETAPA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Visão de Notas/Faltas de Etapas disponível no portal do aluno. |
| **Situação/Requisito:** | Quando as turmas/disciplinas matriculadas pelo aluno tem etapas de notas/faltas diferentes, ao visualizar esta informação no portal, o aluno sente dificuldade em identificar quais etapas são das turma/disciplinas exibidas. Como a etapa é exibida como uma coluna no grid, esta exibição sugere ao aluno que a etapa está disponível em todas disciplinas matriculadas, porém nestes casos o aluno nunca terá uma nota exibida nessa coluna, pois a etapa não pertence a turma/disciplina. |
| **Solução/Implementação:** | Adicionado um filtro na visão com as turmas/disciplinas matriculadas pelo aluno, permitindo que o usuário consiga filtrar o grid com as notas/faltas da etapa. Quando o aluno selecionar uma turma/disciplina, só serão exibidas as etapas disponíveis para a disciplina selecionada, evitando que o aluno tenha dificuldade no entendimento de qual etapa pertence a determinada turma/disciplina. |
