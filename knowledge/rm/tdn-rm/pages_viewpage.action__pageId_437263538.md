# NUMERAÇÃO DE TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Numeração de turma |
| **Situação/Requisito:** | No Portal do Professor, o diário de classe não estava listando os alunos ordenados quando utilizava-se turma gerencial.  A numeração estava sendo realizada em todas as turma/disciplinas gerenciais de uma determinada turma e o correto seria numerar cada turma gerencial separadamente. |
| **Solução/Implementação:** | Otimização no processo de numeração de turma, quando marcado para numerar pela turma Gerencial, ou seja quando marcado a opção “Gerar a numeração pela turma Gerencial”.  O campo “Disciplina Gerencial” deverá ser preenchido com a Turma/Disciplina Gerencial, assim o sistema irá numerar as suas respectivas gerenciadas. |
