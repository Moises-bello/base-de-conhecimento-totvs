Este código de cálculo se refere ao desconto do tipo valor. O INSS referente às férias será lançado neste código de cálculo. Ao fazer o lançamento das férias no mês, o código de cálculo 082 será lançado no mês com o mesmo valor do desconto no recibo de férias. Caso as férias sejam calculadas com a tabela de INSS de um mês e a Folha com outra tabela, o evento de código de cálculo 082 não será alterado: a diferença de INSS será calculada no evento de código de cálculo 03.

**Atenção**

O código de cálculo 082 somente será utilizado quando o usuário calcular as férias automaticamente pelo sistema. Este código de cálculo não deverá ser utilizado no lançamento manual das férias.
