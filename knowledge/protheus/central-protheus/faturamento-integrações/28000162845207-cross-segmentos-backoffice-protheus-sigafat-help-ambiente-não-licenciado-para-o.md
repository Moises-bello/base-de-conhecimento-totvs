![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28000145889943) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como arrumar a mensagem "ambiente não licenciado para o modelo TOTVS Colaboração"?  
  
**Ambiente**Cross Segmentos - Backoffice Protheus - SIGAFAT - Todas as versões  
  
**Solução**

1 - Adquirir a licença para uso:

* Contate seu ESN para verificação da licença para o uso dessa funcionalidade/integração.

2 - Desativar a integração com TOTVS Colaboração (Neogrid), caso não use:

* Basta deixar o parâmetro MV\_TCNEW em branco.
