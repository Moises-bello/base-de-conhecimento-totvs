 **Dúvida**Como gerar uma programação de vacinação?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Esta rotina permite gerar a programação de vacinas para todos os funcionários da empresa, facilitando o controle de agendamento das aplicações de vacinas que são muito importantes para a prevenção de doenças no homem.   
  
Para realizar sua geração a empresa já deverá ter definidos os cadastros básicos conforme artigos abaixo.  
  
[MP - MDT - Como cadastrar vacinas](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360052189973/)  
[MP - MDT - Como cadastrar um calendário de Vacinação](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360052191913)

Para incluir a Programação de Vacinas, acesse o módulo 35 Medicina e Segurança do Trabalho (SIGAMDT), no seguinte caminho: Atualizações > Medicamentos > Programação de vacinação.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360081996013)  
  
Incluir e definir os dados para geração.  
  
![](https://totvssuporte.zendesk.com/attachments/token/KwDttfmxWQrXpmsLi5Tc4re9y/?name=inline306111520.png)  
  
Conforme o registro criado.  
  
![](https://totvssuporte.zendesk.com/attachments/token/8aALy5qHMmCXFL6gd2D63ZoJE/?name=inline-616100645.png)  
  
Para conferir as Vacinas que foram geradas para os funcionários. Acesse o seguinte caminho:  Atualizações > Medicamento > vacinas do Funcionário.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360081996173)  
  
Com base nos cadastro anteriores foram gerados as vacinas a serem aplicadas.  
  
![](https://totvssuporte.zendesk.com/attachments/token/e37TT8dVABlJ6zX0JRuHvHgi4/?name=inline-1215251874.png)
