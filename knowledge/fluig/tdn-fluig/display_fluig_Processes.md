# Descrição

Com ele, o desenvolvedor poderá iniciar solicitações de um processo a partir de um dataset, uma solicitação, formulário ou mesmo em evento global do fluig.

**processes** é um objeto disponibilizado pela plataforma Fluig em todas os pontos de personalização e permite iniciar solicitações de um determinado processo.

# Sintaxe

js

## Parâmetros

### processId

Uma string  com o código do processo que irá ser manipulado

# Métodos da instância

Inicia uma solicitação do processo *processId*, conforme os *properties* enviados*.*

# Compatibilidade

Este objeto só está disponível a partir da versão 1.8.2.
