Consiste em visualizar os registros fiscais de Períodos Fechados apenas para consulta. O objetivo é disponibilizar consultas às notas fiscais das Tabelas Históricas, uma vez que todos os registros do período fechado estarão nessas tabelas.  
Para visualização das notas fiscais de períodos fechados, serão criados dois anexos para visualização dos dados após o fechamento de tal período:

1. Lançamentos Fiscais de Saída (Histórico);
2. Lançamentos Fiscais de Entrada (Histórico);

Essa documentação fiscal ficará disponível apenas para consulta, não sendo permitido quaisquer alterações.

***Observações:***O Sistema não permitirá modificar Lançamentos de Outros Débitos/Créditos que estejam vinculados a um Período Fiscal Fechado.  
O Sistema não disponibilizará registro de Período Fiscal Fechado para vinculação à Carta de Correção.  
Informações de Ativos que estejam vinculados a Lançamentos Fiscais de Período Fechado não poderão ser manipulados, uma vez que o registro já foi transferido para as Tabelas Históricas.  
Não será permitido voltar uma Escrituração Fiscal de Período Fechado.  
Não será possível reimportar Lançamentos Fiscais cuja suas Referências ou Referencias dos Itens a Lançamentos Fiscais que já estão em Períodos Fiscais Fechados.   
Exportar Lançamentos Fiscais de Período Fiscal Fechado não serão permitidas, uma vez que o sistema não encontrará registro nas Tabelas Originais.
