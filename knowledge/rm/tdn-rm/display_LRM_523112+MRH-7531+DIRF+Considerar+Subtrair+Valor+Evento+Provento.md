# DIRF/INFORME DE RENDIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | DIRF/Informe de Rendimentos |
| **Situação/Requisito:** | Ao gerar o informe de rendimentos (seja o normal ou detalhado) com eventos informados no campo 7 - Informações Complementares, o sistema não está obedecendo o parâmetro "Subtrair Valor" para abater valores informados nestes campos. |
| **Solução/Implementação:** | Alterado na geração da DIRF para considerar a opção Subtrair valores mesmo se o evento for do tipo provento. |
