Disponibilizado o módulo de  importação/integração com os softwares de frente de loja migrado para a plataforma .NET. Os Cadastros migrados para integração são os seguintes:

- Cadastro de [Ponto de Venda](http://tdn.totvs.com/display/LRM/Ponto+de+Venda)   
- Cadastro de [Cupom Fiscal](http://tdn.totvs.com/display/LRM/Cupom+Fiscal)   
- Cadastro de [Tributação Cupom Fiscal](http://tdn.totvs.com/pages/viewpage.action?pageId=423938773)   
- Cadastro de [Redução Z](http://tdn.totvs.com/pages/viewpage.action?pageId=423938855)

Disponibilizado o módulo de envio automático de NFS-e.Este processo permite ao usuário o envio automático das [Notas Fiscais de Serviço Eletrônica (NFS-e)](http://tdn.totvs.com/pages/viewpage.action?pageId=422546027) ao um incluir movimento, além de realizar [cópia de movimento a partir de outro movimento](http://tdn.totvs.com/pages/viewpage.action?pageId=423938213) e faturar movimentos manualmente e/ou automaticamente.

Disponibilizado o módulo de envio de NFS-e. Este processo permite o envio automático das [Notas Fiscais Eletrônicas de Serviço (NFS-e)](http://tdn.totvs.com/pages/viewpage.action?pageId=422546027) a partir da visão de Movimentos. Para que este recurso esteja disponível o tipo de movimento deve estar parametrizado para Enviar NFS-e Manualmente.

Disponibilizado diagramas de tipo de movimento. Para acessar o [Diagrama Tipos de Movimentos](http://tdn.totvs.com/display/LRM/Diagramas+Tipos+de+Movimentos) é necessário seguir o seguinte caminho: Gestão de Estoque, Compras e Faturamento | Utilitários | Diagramas Tipos de Movimentos.

Disponibilizado o módulo prorrogação de remessas. O recurso de [Prorrogação de Remessa](http://tdn.totvs.com/pages/viewpage.action?pageId=423938860) altera a data de retorno dos movimentos de remessa. Para isso o sistema deve respeitar prazo de retorno e o número de prorrogações informados na natureza fiscal do movimento.
