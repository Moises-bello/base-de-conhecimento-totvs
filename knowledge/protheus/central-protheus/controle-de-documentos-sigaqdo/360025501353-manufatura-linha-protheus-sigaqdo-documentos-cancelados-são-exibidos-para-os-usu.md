**Dúvida**Por que documentos que foram **cancelados** continuam aparecendo para os usuários na rotina de **Documentos - QDOA050**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**  
Esta situação ocorre apenas quando é utilizado os pontos de entrada **[QD050FIL](https://tdn.totvs.com/pages/releaseview.action?pageId=6801967)** ou **[QDOFILBR](https://tdn.totvs.com/pages/releaseview.action?pageId=6801945)**. No **Protheus** padrão, os documentos cancelados deixam de ser exibidos para os usuários.
