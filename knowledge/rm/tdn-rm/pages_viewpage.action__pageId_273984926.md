# GERAÇÃO DE PLANO DE AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de Plano de Aula* |
| **Situação/Requisito:** | *Ao gerar plano de aula para a turma/disciplina mesmo não marcando a opção de "Não gerar plano de aula para os feriados" não está gerando aula no feriado.* |
| **Solução/Implementação:** | *Ajuste na geração do plano de aula para que quando não marcar a opção de "Não gerar plano de aula para os feriados" seja gerado aula para todos os dias, independente se é feriado ou não.*  *Observação: o calendário considerado na geração do plano de aula é o da parametrização por curso, entretanto se ele não estiver preenchido é feito a busca do mesmo no cadastro do período letivo.* |
