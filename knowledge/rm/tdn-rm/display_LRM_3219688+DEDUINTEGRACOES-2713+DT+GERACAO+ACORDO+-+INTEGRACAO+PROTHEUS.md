# GERAÇÃO DE ACORDO - INTEGRAÇÃO PROTHEUS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | *****Totvs Educacional***** |
| **Função:** | Geração de acordo - Integração Protheus |
| **Situação/Requisito:** | Ao gerar um acordo com mais de um lançamento, o prefixo parametrizado no serviço não é informado corretamente na integração. |
| **Solução/Implementação:** | Na geração de acordo, quanto existe a integração com o Protheus, o valor do prefixo estava sendo informado apenas para o primeiro lançamento a ser gerado no acordo.  Ajustes para o prefixo seja informado para todos os lançamentos a serem gerados através do acordo. |
