# Validação bolsa exclusiva por serviço na concessão de bolsas futuras

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Concessão de bolsas futuras |
| **Situação/Requisito:** | Sistema não validava as concessões de bolsas exclusivas por período de concessões. Isso fazia com que uma concessão de bolsa exclusiva fosse única mesmo com outras concessões em períodos diferentes. |
| **Solução/Implementação:** | Sistema passou a verificar os períodos de concessões de bolsas na validação de bolsas exclusivas além de levar em consideração os serviços associados à concessão. |
