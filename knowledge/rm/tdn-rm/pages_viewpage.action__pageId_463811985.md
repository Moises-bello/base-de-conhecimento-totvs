**Este Menu está disponível apenas para o contexto ENSINO SUPERIOR.**

Este step tem como objetivo realizar a conferência dos dados aluno e caso necessite, efetuar a atualização dos dados.

Para que a tela de confirmação de dados seja visível na matrícula do Ensino superior, deve ser habilitado o parâmetro "Permitir alteração de dados cadastrais durante a matrícula".

 **Educacional| Configurações| Parâmetros| RM Portal| Matrícula| Geral 1/5**

Dica

Existe a possibilidade de parametrizar como o aluno/responsável irá realizar a alteração dos dados:

* **Solicitar alteração para Filial do aluno**

com esta opção marcada o aluno e o responsável acadêmico poderão fazer alterações, porém quando ele salva ainda ficará as informações antigas e ele será informado a solicitação foi enviada. As alterações são enviadas para o e-mail cadastrado na filial do aluno e o responsável por receber estes e-mails na instituição deverá acessar o cadastro do aluno e alterar manualmente os dados solicitados para alteração. A partir daí ficará disponível para o aluno os dados alterados.  
**Para cadastrar o e-mail na Filial do aluno basta acessar MDI/Fiscal/Filial/Anexos/Dados Educacionais.**

* **Solicitar alteração para o Nível de Ensino do aluno**

com esta opção marcada o aluno e o responsável acadêmico poderão fazer alterações, porém quando ele salva ainda ficará as informações antigas e ele será informado a solicitação foi enviada. As alterações são enviadas para o e-mail cadastrado no nível de ensino do aluno e o responsável por receber estes e-mails na instituição deverá acessar o cadastro do aluno e alterar manualmente os dados solicitados para alteração. A partir daí ficará disponível para o aluno os dados alterados.

**Para cadastrar o e-mail do Nível de ensino do aluno basta acessar MDI/ Configurações/ Nível de Ensino.**

* **Permitir alteração;**

A alteração será realizada diretamente na base de dados pelo aluno/responsável, ou seja, as alterações já ficarão disponíveis após salvar as alterações.

 **Educacional| Configurações| Parâmetros| RM Portal| Gerais| Geral 1/11**

**Atenção!!!**

A fim de adequar ao eSocial (Legislação do Governo Federal), os dados relativos aos funcionários devem ser gerenciados pelo RH.  Portando não é permitido realizar alteração dos dados cadastrais do Aluno e do responsável  acadêmico pelo portal do aluno, quando forem respectivamente funcionários da instituição. Este tipo de alteração deve ser realizada pelo departamento da instituição de ensino responsável pela gestão dessas informações.
