![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:05:00 min****Dúvida**Como gerar a Shipping Instructions?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – A partir da versão 11.80.  
  
**Solução**Esta rotina permite a impressão das Instruções de Embarque (Shipping Instructions) por PO em formulário padrão:  
1. Acesse o módulo SIGAEIC em Atualizações \ Embarque \ Ship. Instructions (EICPO552);  
2.  Informe o Número do PO, selecione o idioma (Inglês ou Português) e clique no botão "Ok" para prosseguir. Se o Número do PO não for informado, o sistema mostrará todos os PO's com saldo a embarcar.  
3. Selecione os itens marcando-os com um duplo clique ou através do botão "Todos".  
4. Utilize o botão "Mensagens" para alterar a ordem e o conteúdo de cada observação.  
5. Para alterar as Datas de Embarque e Entrega, utilize o botão "Alterar Datas".  
6. Clique no botão "Imprimir", siga as orientação de impressão e confira os dados apresentados no documento.
