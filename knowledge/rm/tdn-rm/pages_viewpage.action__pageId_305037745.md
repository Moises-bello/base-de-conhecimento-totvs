# Transferência de Grupos Contábeis

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Transferência de Grupos Contábeis |
| **Situação/Requisito:** | Ao realizar o processo de transferência de grupos contábeis o sistema apresenta a seguinte mensagem: "A partida 2-0 não deve possuir Centro de Custo pois a Contabilidade está parametrizada para não usar Centro de Custo." |
| **Solução/Implementação:** | Melhoria no processo de Transferência de Grupos Contábeis para que seja possível realizar o processo em cenário onde existe saldo por centro de custo tanto no Período Contábil em aberto quanto no Saldo Anterior, porém o sistema está parametrizado para não usar centro de custo. |
