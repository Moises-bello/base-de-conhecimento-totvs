![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min****Dúvida**O que fazer quando a mensagem "*Internal Server Error*" é apresentada?  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9708408224663)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - MEU RH - Todas as versões  
  
**Solução**A apresentação da mensagem "***Internal Server Error***" indica a presença de um error log ocorrido na camada de aplicação do serviço, ou seja, uma operação solicitada pelo aplicativo Meu RH causou um erro no código fonte da funcionalidade.  
  
Um "**Erro Interno do Servidor**" (em tradução livre) **pode ocorrer** à **qualquer momento** e em qualquer tela da aplicação, por **motivos diversos**, desde problemas no Dicionário de Dados, Registros preenchidos incorretamente ou até mesmo erro no próprio programa.  
  
Para análise deste tipo de ocorrência, é necessário:  
**1.** Garantir a atualização do ambiente com o pacote de Expedição Contínua do RH mais recente, conforme disponível aqui: **[Expedição Contínua Gestão de Pessoal](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057829854)**  
**2.** Acessar a funcionalidade que apresenta o erro;  
**3.** Avaliar (ou enviar para a equipe de suporte) o arquivo de console.log, que deverá conter um *thread error*com o erro completo gerado.  
  
Caso o ambiente se encontre nos serviços **Cloud TOTVS**, é possível solicitar a atualização com o pacote de Expedição Contínua do RH, verificar se o erro permanece e, caso positivo, realizar a abertura de um chamado para a área de Protheus Meu RH.
