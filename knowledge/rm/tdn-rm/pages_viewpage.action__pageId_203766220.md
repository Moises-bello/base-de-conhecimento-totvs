# Como visualizar o resumo da ocupação e controle dos leitos?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como visualizar o resumo da ocupação e controle dos leitos? |
| **Passo a passo:** | **Ocupação de Leitos**  Nessa opção é visualizado o resumo da ocupação e o controle dos leitos da instituição. Como acessar o Resumo de Ocupação de Leitos? No **TOTVS Gestão Hospitalar** acesse **Atendimento/Internação/Controle de Ocupação de Leitos**.  Será exibida a tela de resumo de leito (gráfico).  Utilize a opção **Setor** selecionado para verificar especificamente a ocupação de um determinado setor. Como acessar o Controle de Ocupação de Leitos?  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Internação/Controle de Ocupação de Leitos**. 2. Será exibida a tela de resumo de leito. 3. Clique na guia **Leitos**. 4. É possível realizar filtros para facilitar a visualização dos leitos da instituição, realize sua busca utilizando a Situação do leito, o Setor, a Classe (enfermaria, apartamento, etc.), o Gênero (masculino, feminino ou sem diferenciação), a Ala. 5. Marque a caixa **Leitos em processo de alta** para que sejam exibidos apenas leitos correspondentes. 6. Clique em **Atualizar** para que as informações sejam atualizadas. 7. Selecione o leito e clique em **Controle** para realizar as seguintes ações:  * Reservar Leito. * Cancelar Reserva. * Isolar Leito. * Cancelar Isolamento de Leito. |
| **Observações:** | Para verificar a legenda posicione o mouse sobre o botão **Situação dos Leitos**. |
