# Gestão de mensagens eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Atividades acadêmicas| Central de Comunicação | eduConnect | Gestão de mensagens |
| **Situação/Requisito:** | Por existir uma limitação no consumo dos dados na nuvem (local onde fica armazenado as mensagens enviadas ao eduConnect), o sistema não exibia mais de 50 mensagens na funcionalidade Gestão de mensagens, mesmo informando um período que compreendia mais mensagens. |
| **Solução/Implementação:** | Foi realizado uma otimização no consumo das mensagens armazenadas na nuvem, de maneira que o sistema possa retornar todas mensagens de acordo com o filtro (data inicial e final) informado pelo usuário sem restrição na quantidade de mensagens retornadas. |
