O sistema exibirá uma lista com os valores comparados entre o XML e o tipo de movimento parametrizado como "[Tipo de movimento - Comparar com XML](http://tdn.totvs.com/pages/viewpage.action?pageId=423937940)", onde o usuário poderá verificar quais os valores de cada imposto foram selecionados para a alíquota, base de cálculo e o valor.   
Caso os valores esteja iguais ou não existam em ambos ou até não esteja parametrizado no tipo de movimento, o sistema não irá gerar um log de comparação, pois esses valores não existem ou não diferem.
