![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:06 min****Dúvida**Como realizar a rescisão no sistema quando há falecimento durante o período de gozo das férias?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
  
Primeiramente, será necessário alterar o período de gozo do funcionário para um dia antes do falecimento, finalizar as férias e realizar a rescisão normalmente. Ainda que as férias tenham sido pagas, o período de gozo deve estar até um dia antes do falecimento para que ele retorne para ativo e possa ter as férias finalizadas.  
  
Com as férias finalizadas, você terá o recibo de férias e ela não aparecerá na rescisão.  
  
Para melhor entendimento, segue abaixo instruções para realizar o processo de Rescisão por falecimento do funcionário durante as Férias:  
  
1. Abra o período aquisitivo, acesse as férias do funcionário e altere a situação das férias para **Marcadas**, para que seja possível a alteração da data fim.  
  
![](https://totvssuporte.zendesk.com/attachments/token/657lqOfemXr9orfvFlAuGdXNw/?name=inline-1061735066.png)  
  
2. Ao alterar para marcadas, será possível realizar a alteração da data fim. Neste campo, preencha com a data de um dia antes do falecimento do funcionário.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/5326649720471/mceclip0.png)  
  
3. Após o preenchimento, retorne a Situação das Férias para **Pagas** e clique em salvar. Perceba que a data ficará correta.  
  
4. Após isso, realize o processo de finalizar férias. Para lhe auxiliar no processo de finalização das férias, segue documentação orientando o processo: [RH - RM - FOP - Férias: Finalizar.](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360012328752-RH-RM-FOP-F%C3%A9rias-Finalizar-)  
  
5. Feito isso, realize a demissão do funcionário.
