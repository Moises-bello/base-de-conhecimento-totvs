**Dúvida**  
Como definir uma **Q****uantidade Mínima** para **venda** de um determinado produto?

**Ambiente**  
Protheus – Estoque – A partir da versão 11.80

**Solução**

Para solucionar essa dúvida, realize os seguintes passos:

1. Dentro do cadastro do respectivo produto na aba outros;  
2. Localizar o campo **QTDE. VENDA** ( **B1\_LOTVEN**);

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000580042/mceclip0.png)

3. Informar a quantidade mínima para venda, assim ao fazer uma **pedido de venda** e informar uma quantidade menor que a informada no cadastro o sistema irá apresentar um Help da necessidade de colocar a quantidade mínima estipulada no campo citado.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000580382/mceclip1.png)
