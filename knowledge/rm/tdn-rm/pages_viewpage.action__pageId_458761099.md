# Desabilitar opção "Ambos" no Cli/For quando a integração Educacional x Protheus Financeiro está ativa

|  |  |
| --- | --- |

| **Segmento:** | BackOffice. |

| **Função:** | Cadastro de Clientes/Fornecedores. |
