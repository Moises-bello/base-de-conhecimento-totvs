**Dúvida**Como utilizar a funcionalidade de Facilitador no Cadastro de Clientes (**MATA030**)?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Faturamento (SIGAFAT) - Todas as versões.  
  
**Solução**A rotina de Cadastro de Clientes (**MATA030**) possui um facilitador para alteração do cadastro, essa funcionalidade é utilizada quando é necessário atualizar o conteúdo de diversos campos ao mesmo tempo, sem que seja necessário acessar o formulário de cadastro e alterar campo a campo.

O sistema apresentará uma tela informando que o Facilitador foi iniciado e iniciará as etapas:

* Etapa 1/5 - **[Campos a serem alterados](https://tdn.totvs.com/download/attachments/625949058/02.png?version=1&modificationDate=1624541270903&api=v2)**

Nesta etapa é possível selecionar os campos que deseja alterar na etapas posteriores, nela é possível buscar o campo pelo nome através da pesquisa.

* Etapa 2/5 - **[Filtro](https://tdn.totvs.com/download/attachments/625949058/04.png?version=1&modificationDate=1624541270830&api=v2)**

É possível realizar um filtro de quais registros deseja alterar, se, por exemplo, for selecionado um filtro onde "Vendedor" é igual a ' ' por exemplo, o sistema irá realizar a alteração de todos os cadastros de cliente que possuem o campo "Vendedor" (A1\_VEND) vazio.

* Etapa 3/5 - **[Grupo](https://tdn.totvs.com/download/attachments/625949058/05.png?version=1&modificationDate=1624541270793&api=v2)**

Nesta etapa é formado um grupo dos campos que serão apresentados para alteração na próxima etapa

* Etapa 4/5 - **[Edição](https://tdn.totvs.com/download/attachments/625949058/06.png?version=1&modificationDate=1624541270763&api=v2)**

O sistema apresenta os campos selecionados na etapa anterior, indicando qual era o conteúdo antigo deles e permitindo inserir a informação nos campos de conteúdo novo.

* Etapa 5/5 - **[Resumo](https://tdn.totvs.com/download/attachments/625949058/07.png?version=1&modificationDate=1624541270733&api=v2)**

Nesta etapa o sistema demonstra tudo que será realizado, podendo verificar os campos, os filtros e os grupos que serão editados após a confirmação.
