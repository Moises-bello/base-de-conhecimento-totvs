# Cadastro de evento contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro de evento contábil |
| **Situação/Requisito:** | O cliente informa que ao acessar o cadastro de evento contábil, alterar alguma informação no item do evento e avançar para o próximo item (através da seta direcional), o sistema não salva as alterações e nem emite avisos pertinentes para que as modificações sejam gravadas. |
| **Solução/Implementação:** | O cadastro de evento contábil foi modificado para que ao alterar alguma informação no item do evento e avançar para o próximo item (através da seta direcional), o sistema envie avisos pertinentes para que as alterações possam ser salvas ou canceladas. |
