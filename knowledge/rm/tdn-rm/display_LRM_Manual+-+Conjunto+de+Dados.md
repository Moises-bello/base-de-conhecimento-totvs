O contexto de conjunto de dados permite utilização de dados de um dos bancos de dados suportados pelo gerador de saídas. É possível criar uma ou mais tabelas no contexto e as tabelas podem ter relacionamentos entre si. Para adicionar uma tabela ou relacionamento, clique com o botão direito na área do diagrama e escolha uma das opções do menu.

Antes de adicionar uma tabela ou consulta SQL é necessário definir os dados da conexão do Layout, esta conexão será utilizada para que o gerador faça a leitura dos meta-dados da base para exibir as tabelas da base dados com seus respectivos campos.

![](/download/attachments/319787290/conjunto_de_dados.png?version=1&modificationDate=1512921890000&api=v2)

1Tabela

Representa uma tabela ou consulta SQL do conjunto de dados com os seus campos e relacionamento. Clique duas vezes na tabela para alterar as suas propriedades. Para mais informações consulte [Propriedades da Tabela](/display/LRM/Manual+-+Propriedades+da+Tabela) e [Propriedades da Consulta SQL](/display/LRM/Manual+-+Propriedades+da+Consulta+SQL).

2Relacionamento

Representa os relacionamentos entre as tabelas do conjunto de dados. Quando um relacionamento é criado, a tabela será exibida como uma lista filha da tabela principal na árvore do contexto. Para criar um relacionamento, clique com o botão direito e selecione a opção para adicionar relacionamento no menu. Para alterar as propriedades de um relacionamento, clique duas vezes no nome do relacionamento dentro da tabela pai. Para mais informações consulte [Propriedades do Relacionamento](/display/LRM/Manual+-+Propriedades+do+Relacionamento).

3Parâmetros

Quando uma tabela do contexto possuir um parâmetro de filtro, o mesmo será exibido na guia parâmetros para que seja definido o seu valor. Para mais informações consulte [Parâmetros do Contexto](/pages/viewpage.action?pageId=319787287).
