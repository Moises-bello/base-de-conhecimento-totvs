# ACORDO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Acordo* |
| **Situação/Requisito:** | Definido um template de acordo que só efetiva o acordo após o pagamento da primeira parcela. Ao efetivar o acordo, o sistema está gerando outro contrato para demais parcelas, ou seja, um contrato contendo a primeira parcela do acordo e outro contrato contendo as demais parcelas do acordo.Entendemos que todas as parcelas deveriam estar no mesmo contrato no educacional, pois, desta maneira, o entendimento do acordo fica confuso. |
| **Solução/Implementação:** | Otimizado processo de geração de acordo para que ao efetivar o acordo, o sistema gere o contrato das demais parcelas com o mesmo contrato da primeira parcela no educacional. |
