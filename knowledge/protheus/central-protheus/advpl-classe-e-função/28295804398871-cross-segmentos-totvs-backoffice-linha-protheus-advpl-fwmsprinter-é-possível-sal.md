![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28295787098903) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível salvar o arquivo com letras maiúsculas utilizando a classe FWMsPrinter?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**Não é possível salvar o arquivo com letras maiúsculas, mesmo utilizando funções como Upper por exemplo.  
Isso ocorre porque todo o binário do Protheus é salvo por padrão em Lower Case.
