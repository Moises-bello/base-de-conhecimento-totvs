# Envio NF-e e Emissão da DANFE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Envio de NF-e e Emissão de DANFE |
| **Situação/Requisito:** | Ao emitir uma NF-e de Transferência - Quando o destinatário é a filial o  RM não está gerando o CEP (GFILIAL.CEP) no xml, consequentemente o CEP não é gerado no Danfe. |
| **Solução/Implementação:** | Implementada melhoria na geração da NF-e para imprimir o CEP do destinatário corretamente quando movimento for uma transferência entre filiais. |
