Dúvida**Como enviar o peso bruto para a Pré-Nota?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 11.80  
  
**Solução**Habilitar o parâmetro **MV\_EIC0014** para envio do peso Bruto Unitário.
