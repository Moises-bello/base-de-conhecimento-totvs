Insumo  
 Informe o código do insumo que está sendo apropriado. Caso o projeto esteja integrado com o RM Labore e o insumo associado possuir pelo menos, uma função será habilitado campos para seleção de funcionário. Caso o projeto esteja integrado com o RM Bonum e o insumo associado possuir pelo menos, um grupo de bem, será aberta uma janela para seleção do bem.

**Observação**  
    
 Ao selecionar o código do insumo, a descrição e a unidade do mesmo será preenchida automaticamente. Se a descrição for selecionada, o código e a unidade serão preenchidos automaticamente.  
 Data Movimento: Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
    
 Data Apropriação:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.

Não é permitido criar ou alterar apropriações onde a data apropriação é inferior a data limite para apropriação definida nos parâmetros do projeto, através do menu Opções | Parâmetros | Totvs Obras e Projetos | Projetos, pasta Apropriação, campo Data Limite para Apropriação.  
 Moeda:  
 O valor default deste campo será de acordo com os parâmetros do projeto. Parâmetros do projeto – Leis/ Outros – Moeda do projeto. Como se trata de um campo editável, pode-se alterar a moeda.  
 Uma apropriação pode ser efetuada em outra moeda.  
 Cód. Tarefa:  
 Selecione o código da tarefa ao qual o insumo será apropriado. Esse código pode ser um serviço, etapa ou obra.  
    
 Nome Tarefa:  
 O nome da tarefa ao qual o insumo será apropriado será exibido neste campo.  
 Unidade:  
 A Unidade da tarefa que está sendo apropriada será exibida neste campo.  
 Data de Apropriação:   
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
 Quantidade:  
 Informe a quantidade do insumo que está sendo apropriado. Esta é uma informação obrigatória.  
 Preço Unitário:  
 Ao informar o insumo o sistema busca o preço do insumo.  
 Se no momento do cadastro do insumo, não foi informado o preço, na apropriação pode-se informar o preço do insumo.  
 Data Movimento:  
 Este campo será preenchido automaticamente com a data atual. Porém é um campo editável, desta forma a data poderá ser alterada.  
 Moeda:  
 O valor default deste campo será de acordo com os parâmetros do projeto. Parâmetros do projeto – Leis/ Outros – Moeda do projeto. Como se trata de um campo editável, pode-se alterar a moeda.  
 Uma apropriação pode ser efetuada em outra moeda.  
Informe uma observação referente à apropriação.  
Todas as observações detalhadas para Apropriação de Serviço/Insumo feitas item a item são validas para Apropriação Múltipla de Insumo.
