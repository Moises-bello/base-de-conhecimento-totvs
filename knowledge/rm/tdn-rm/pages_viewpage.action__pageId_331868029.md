# Lançamento Fiscal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Lançamento Fiscal |
| **Situação/Requisito:** | Alteração do Sped Fiscal para 2018  Acrescentar as opções "Declaração Única de Exportação Direta" e "Declaração Única de Exportação Indireta".  Acrescentar a opção "5 – Exportação" no campo Motivo de Ressarcimento. |
| **Solução/Implementação:** | Foram incluídos os campos no Lançamento Fiscal.  Lançamento Fiscal / Pasta Exportação Foram acrescentadas a as opções "Declaração Única de Exportação Direta" e "Declaração Única de Exportação Indireta" no campo Natureza Exportação.  Lançamento Fiscal / Item / Pasta Referências Foi acrescentada a opção "5 – Exportação" no campo Motivo de Ressarcimento. |
