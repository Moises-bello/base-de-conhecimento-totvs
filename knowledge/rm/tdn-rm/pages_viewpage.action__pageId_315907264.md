# FICHA MÉDICA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Ficha médica do aluno. |
| **Situação/Requisito:** | Disponibilizar no portal do aluno a possibilidade de informar a ficha médica do aluno no ensino básico. |
| **Solução/Implementação:** | O acesso e alteração da ficha médica do aluno deve ser habilitada no perfil do usuário.  No processo de matrícula online do contexto do ensino básico, foi criado um parâmetro para permitir que a ficha médica seja uma etapa da matrícula. Neste cenário o aluno poderá realizar as alterações necessárias, após a edição dos dados cadastrais.  Importante: No portal do aluno, a visão de ficha médica está disponível como uma aba na visão de dados pessoais do aluno. Na matrícula esta aba não será visualizada como uma aba dos dados pessoais e sim com uma etapa no processo. Desta forma, o aluno obrigatoriamente terá que passar pela validação dos dados da ficha médica.  Vale ressaltar que a visualização da etapa de ficha médica na matrícula seguirá a parametrização realizada no sistema. |
| **Conversores e Parâmetros:** | RM Portal >> RM Portal - Matrícula >> Permitir alteração de dados da ficha médica do aluno durante a matrícula. |
