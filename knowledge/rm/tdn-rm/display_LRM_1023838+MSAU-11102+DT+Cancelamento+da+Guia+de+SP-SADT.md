# Cancelamento da guia de SP-SADT campo numeroguiaprestador vazio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cancelamento de Guia TISS |
| **Situação:** | Ao tentar realizar o cancelamento de uma guia de SP-SADT, o sistema não preenchia o campo numeroGuiaPrestador no XML de envio. |
| **Solução:** | Ajuste realizado para que o sistema faça o preenchimento do campo numeroGuiaPrestador corretamente, no XML de envio para cancelamento de guia. |
