## **01. VISÃO GERAL**

Tela para cadastrar e manter as situações de agendamento para padronizar o controle e permitir a correta classificação dos agendamentos conforme o contexto operacional.

**Código da Situação:** Código único de identificação.

**Descrição:** Descrição que permite identificação clara no processo de agendamento.

**Indicação de Uso:**A situação permite indicar sua aplicabilidade conforme o contexto: Agenda, Autorização ou Ambos.

**Ativo:**O campo Status permite os valores: Ativo ou Inativo. Situações com status **Inativo** não são disponibilizadas para uso em novos registros, mas permanecem visíveis para consulta.

## **02. EXEMPLO DE UTILIZAÇÃO**

É permitido incluir novos registros ou editá-los, caso queira inativar, alterar uma indicação de uso ou descrição.
