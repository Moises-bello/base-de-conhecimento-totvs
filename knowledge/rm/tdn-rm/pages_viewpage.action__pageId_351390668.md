# Integração Bancária - Retorno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Financeira |
| **Função:** | Integração Bancária - Retorno |
| **Situação/Requisito:** | Ao importar retorno de cobrança registrada, o sistema ignora os arquivos do retorno que devem ser processados, e exibe no log apenas o erro referente as linhas que estão sem chave do lançamento. |
| **Solução/Implementação:** | Ajustes no log de retorno bancário.  Ajustes no tratamento do código de cancelamento do layout bancário.  Ajustado validação de caracteres alfa numéricos na chave do lançamento do arquivo de retorno. |
