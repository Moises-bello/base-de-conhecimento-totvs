**Alterações Globais de Terminais de Acesso**

Utilize este menu para informar o(s) terminal(is) que os funcionários podem utilizar, e informar também se as batidas coletadas pelo terminal serão consideradas ou não no cálculo da movimentação do funcionário. Nesta alteração o sistema respeita o filtro de perfil de usuário para acesso a funcionários cadastrado em "Cadastros | Segurança | Perfis | Pasta de Acesso a Funcionários". Para proceder à alteração global de terminais de acesso, deverão ser preenchidos corretamente os seguintes campos:

Para o grupo de funcionários

**Código de quebra:** Informe o código de quebra da seção a qual pertencem os funcionários que terão os dados alterados.

**Seleção de Funcionários:** Clique no botão "Seleção de Funcionários" para acessar a janela que irá selecioná-los por situação, tipo, código de recebimento ou Chapa

**Visitante** Este campo serve para selecionar apenas um visitante por chapa ou pelo nome para fazer o lançamento de terminal de acesso. Para fazer o lançamento a todos os visitantes o campo chapa deve estar nulo.

**Opção de Lançamento:** **Insere os Terminais de Acesso Marcados para funcionários** Se selecionada, esta opção permite que os terminais de coleta sejam inseridos no cadastro dos funcionários.

**Retira os Terminais de Acesso Marcados para funcionários** Se selecionada, esta opção permite que os terminais de coleta sejam retirados do cadastro dos funcionários.

**Insere os Terminais de Acesso Marcados para visitantes** Se selecionada, esta opção permite que os terminais de coleta sejam inseridos no cadastro dos visitantes.

**Retira os Terminais de Acesso Marcados para visitantes** Se selecionada, esta opção permite que os terminais de coleta sejam retirados do cadastro dos visitantes.

**Opções para Terminais de Acesso Inseridos:** **As batidas importadas serão consideradas no cálculo** Selecione este parâmetro para que as batidas importadas sejam consideradas para cálculo (de horas extras, normais, etc).

**As batidas importadas não serão consideradas no cálculo** Selecione este parâmetro para que as batidas importadas assumam o status "T" (batidas em trânsito), ou seja, para que estas batidas sejam apenas informativas, não sendo consideradas para cálculo (de horas extras, normais, etc).

**Terminais de Acesso** Escolha quais os terminais de acesso serão inseridos ou retirados para os funcionários ou visitantes selecionados. Para selecionar todos os terminais use o botão selecionar todos.

**Perfil de Parâmetros** Este campo permite guardar a configuração dos parâmetros habilitados do lançamento. Ao acessar novamente este lançamento, basta selecionar o perfil criado para o sistema trazer os parâmetros salvos.

**Salvar perfil ao concluir** Este parâmetro é utilizado para incluir um novo perfil de parâmetros. Informe um nome de um novo perfil, marque o parâmetro "salvar perfil ao concluir" e ao clicar no botão "OK" para efetuar o lançamento o sistema gravará o novo perfil de parâmetros.
