Esta opção permite a geração de um movimento através de assistente do Módulo Educacional tendo como referência os boletos gerados para os alunos, caracterizando emissão de NF-e por regime de caixa. Para a geração do movimento pelo regime de caixa, o usuário deverá seguir os passos abaixo:

Marque a opção desejada:

* **Tipo de movimento:** Escolha o tipo de movimento correspondente a emissão de NF-e.
* **Data de emissão do movimento:** escolha qual será a data de emissão do movimento. As opções são:
  + Data de emissão do lançamento
  + Data de vencimento do lançamento
  + Data de baixa do lançamento (somente para lançamentos baixados)
  + Data de competência do lançamento
  + Data atual do sistema
* **Dia fixo relacionado ao mês/ano da data de emissão do movimento:** Informe um dia fixo para a data de emissão do movimento.
* **Permitir regeração de movimentos:** marque esta opção para que seja possível a regeração do movimento posteriormente.
* **Gerar movimentos para boletos de valor líquido igual a zero:** marque esta opção para que seja possível gerar movimentos referentes a lançamentos com valor liquido igual a zero.
* **Desconsiderar bolsas de crédito para valores de desconto:** marque esta opção para que a bolsa de crédito referente ao boleto não seja considerada como desconto.

Informe os dados para seleção dos boletos que deverão ter a NF-e gerada.

* **Data de emissão**: informe a data de emissão inicial e final para seleção dos boletos.
* **Data de vencimento**: informe a data de vencimento inicial e final para seleção dos boletos.
* **Filtro por boleto**: caso seja necessário, os boletos poderão ser selecionados através de filtro específico.
* **Status do lançamento**: escolha o status do lançamento para seleção dos boletos.
