# TRCT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | TRCT |
| **Situação/Requisito:** | Ao realizar a rescisão e posteriormente gerar o TRCT, o campo 65 (Férias Proporcionais) está levando a quantidade de avos e também de dias o que por padrão é incorreto, não sendo possível realizar a homologação junto as entidades. |
| **Solução/Implementação:** | Criado o campo 'Considerar número de dias Campo 65' no processo de geração do relatório do TRCT. Marcando este parâmetro será informando no relatório a quantidade de dias de férias proporcionais devido. Com o parâmetro desmarcado é informado somente a quantidade de avos de férias proporcionais devido. |
