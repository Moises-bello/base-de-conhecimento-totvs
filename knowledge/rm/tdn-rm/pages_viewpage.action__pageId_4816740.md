Execução de Actions

FAQ: **Execução de Actions**

|  |  |
| --- | --- |
| Produto: | Unspecified |
| Ambiente: | Unspecified |
| Versão: | 10.70 |

Solução

A partir da versão 10.70, será possível executar actions a partir de registros gerados em resultados de consultas SQL cadastradas no sistema. Este recurso vale também para as Consultas SQL executadas dentro de cenários de análise ou como anexo.
