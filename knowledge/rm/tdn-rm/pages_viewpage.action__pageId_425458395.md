Este processo permite alocar salas para mais de uma turma/disciplina de uma única vez não sendo necessário apontar as salas para alocação, ou seja a alocação é feita de acordo com a prioridade de alocação e disponibilidade das salas.

Informe o período letivo em seguida filtre as turmas/disciplina as quais deseja alocar sala. Obs.: para seleção da turma/disciplina é necessário configurar o item 'Prioridade de alocação de habilitações'. Vide em 'Como Fazer' Prioridades. Em seguida tem-se a opção de fazer a alocação manual. Caso clique em 'Alocação Manual' o sistema direciona para tela de alocação manual. O procedimento é o mesmo para o processo 'Alocação Manual' documentado anteriormente.

Em seguida clique em 'Executar'.
