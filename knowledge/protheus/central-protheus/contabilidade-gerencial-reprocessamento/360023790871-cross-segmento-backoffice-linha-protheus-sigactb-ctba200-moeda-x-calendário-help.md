**Dúvida**

Ao reprocessar os saldos (CTBA190) é gerado a mensagem: HELP: CTGDTOUT. Verifique se existe calendário para essa data. Solução: Verifique se existem moedas x calendários cadastrados para a data informada.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360021298312/mceclip0.png)  
  
**Ambiente**Protheus – Contabilidade Gerencial – A partir da versão 11.80  
  
  
**Solução**Na rotina Moeda x Calendário (CTBA200)

Verifique se existe relacionamento entre MOEDA X CALENDÁRIO para a filial e período ao qual será gerado o reprocessamento.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360021298612/mceclip1.png)
