# PORTAL - MATRICULA ON LINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Portal - Matrícula online* |
| **Situação/Requisito:** | *No Portal, ao fazer matricula em 2 disciplinas, cuja uma delas possua CoRequisito, o sistema apresentava mensagem “Alerta: referência de objeto não definida para uma instância de um objeto”. Somente quando marcado o parâmetro “Bloquear matrícula em lista de espera para disciplinas com corequisitos”.* |
| **Solução/Implementação:** | *No Portal, ao fazer matricula disciplina que tenha CoRequisito e esteja marcado o parâmetro “Bloquear matrícula em lista de espera para disciplinas com corequisitos”, o sistema irá mostrar mensagem clara na tela informando sobre a disciplina estar sem vagas disponíveis e possuir corequisito.* |
