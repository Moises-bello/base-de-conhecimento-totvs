**Itens de Classificação**   
O itens de classificação servem para identificar a qual grupo as classificações serão associadas. O cadastro é fechado e a única operação permitida é a alteração. O itens se limitam para o cadastro de provas e de questões.  
Cada item possui um campo de máscara que será usada no cadastro de classificações. Podemos ter um tipo de máscara para cada item. As máscaras servem para definir a forma como serão gerados os códigos de classificação.
