**Vendedor Pessoa Física**   
Através deste menu poderemos cadastrar, editar e excluir os Corretores ou Vendedores Pessoa Física a serem informados no momento da venda.  
Na edição de Vendedores Pessoa Física, o Sistema permite ao Usuário cadastrar as seguintes informações:  
   
**Aba Identificação:**  
   
**Código:** Informa o código do Vendedor Pessoa Física. Este campo será gerado automaticamente pelo sistema;  
**CNPJ/CPF:** Informe o CNPJ ou CPF do vendedor;  
**Nome:** Informe o nome completo do vendedor;  
**Cliente / Fornecedor:** Informe o Cliente / Fornecedor referente a este vendedor. Ao realizar as comissões para o Vendedor, irá gerar lançamentos para o Cliente / Fornecedor que está relacionado neste campo.  
**Observação:** Caso necessite, utilize este campo para alguma informação complementar do vendedor;  
   
**Aba Dados Pessoas Física:**  
   
**Empresa:** Informe qual empresa o vendedor pertence, o sistema apresentará na lista de opções as empresas já cadastradas através do Menu Cadastro | Tabelas | Vendedor | Pessoa Jurídica;  
**Profissão:** Informe qual a profissão do vendedor, o sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Profissões;  
**Sexo:** Informe o sexo do vendedor;  
**Estado Civil:** Informe qual o estado civil do vendedor, o sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Estado Civil;  
**Naturalidade:** Informe qual a naturalidade do vendedor, o sistema apresentará na lista de opções os tipos já cadastrados no sistema;  
**Data Nascimento:** Informe a data de nascimento do vendedor;  
**CI:** Informe o número de identidade do vendedor;  
**Órgão Emissor:** Informe o órgão emissor da CI;  
**Nome Mãe:** Informe o nome da mãe do vendedor;  
**Nome Pai:** Informe o nome do pai do vendedor;  
   
**Aba Informações**  
   
**Tipo Vendedor:** Informe o tipo de vendedor. O sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Tipo de Vendedor. Ex.: Vendedor Interno, Vendedor Externo, etc.  
**Número:** Informe o número do vendedor na empresa;  
**Salário:** Informe o salário do vendedor;  
**% Comissão:** É informado o % de comissão para este vendedor;  
**Tipo Comissão:** É informado o Tipo de Comissão deste vendedor;  
**CRECI Nº:** Informe o número do vendedor no CRECI (Conselho Regional de Corretores de Imóveis);  
**Nível Vendedor:** Informe se o vendedor é gerente ou simplesmente corretor;  
**Gerente:** Caso o nível do vendedor seja "corretor", informe o seu gerente. Aparecerá na lista de opções todos os vendedores cujo o nível seja "gerente";  
**Situação:** Marque se o vendedor está ativo ou inativo. Se o inativo estiver marcado, este vendedor não poderá ser usado na venda;  
**Funcionário:** Informe o funcionário;  
   
**Aba de Endereços.**  
   
**Logradouro:** Informe o nome da rua, Av, praça, etc;  
**Número:** Informe o número do endereço;  
**Tipo de Endereço:** O sistema apresentará na lista de opções os tipos já cadastrados através do Menu Cadastro | Tabelas Adicionais | Tipo Endereço;  
**Complemento:** Informe o complemento do endereço;  
**Bairro:** Informe o bairro do vendedor;  
**CEP:** Informe o CEP do vendedor;  
**Cidade:** Informe a cidade do vendedor;  
**Estado:** Informe o estado do vendedor. O sistema apresentará na lista de opções todos os Estados já cadastrados. Campo obrigatório;  
**Telefone:** Informe o telefone do vendedor;  
**Ramal:** Informe o ramal do vendedor;  
**Celular:** Informe o celular do vendedor.  
**Fax:** Informe o fax do vendedor;
