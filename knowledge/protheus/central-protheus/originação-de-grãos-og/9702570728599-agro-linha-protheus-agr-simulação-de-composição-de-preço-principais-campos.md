Dúvida**Como encontrar os **Principais Campos** em uma **Simulação de Composição de Preço**? **Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12 **Solução**Principais Campos:

| Campo | Descrição |
| --- | --- |
| Descrição | Uma breve descrição da simulação. |
| Cód. Produto | Código do produto que será utilizado para simulação. |
| Unid. Medida | Código de unidade de medida. |
| Unid. Medida Preço | Código da unidade de medida de preço que será utilizada na simulação. |
| Quantidade | Volume do produto a ser utilizado na simulação. |
| Entrega Inicial | Data da previsão de entrega inicial. |
| Entrega Fim | Data da previsão de entrega final. |
| Moeda | Código da moeda. |
| Tipo Sim. | Indica o tipo de simulação. Os valores aceitos são:   * 1 - Compra; * 2 - Venda. |
| Vlr.Uni.Prod | Valor unitário na unidade de medida do produto para ser informado manualmente. |
| Vlr.Uni.Preço | Valor unitário na unidade de medida de preço para ser informado manualmente. |
| Tot. UM.Prod. | Valor total na unidade de medida do produto para ser informado manualmente. |
| Tot. UM.Preço | Valor total na unidade de medida de preço para ser informado manualmente. |
| Un. Calc.Um1 | Valor unitário na unidade de medida do produto calculado automaticamente conforme o preço proposto informado. |
| Un. Calc.UMP | Valor unitário na unidade de medida de preço calculado automaticamente conforme o preço proposto informado. |
| Tot.Cal.UM1 | Valor total na unidade de medida do produto calculado automaticamente conforme o preço proposto informado. |
| Un.Prop.UM1 | Valor unitário proposto na unidade de medida do produto. |
| Un.Prop.UMP | Valor unitário proposto na unidade de medida de preço. |
| Tot.Prop.UM1 | Valor total proposto na unidade de medida do produto. |
| Preço Proposto | Indica o valor proposto final. Ao informar um valor os campos calculados são atualizados. |
