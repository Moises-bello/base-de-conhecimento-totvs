# LISTAGEM DE PEDIDO DE MATERIAL EXTRA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Obras e Projetos. |
| **Função:** | Portal TOTVS Obras e Projetos - Pedido de Material Extra |
| **Situação/Requisito:** | Necessidade de migrar funcionalidade para web, dando mobilidade para geração de pedido extra pelos usuários. |
| **Solução/Implementação:** | Foi desenvolvido a listagem de pedido de material extra de forma responsiva para os dispositivos: mobile, tablet e desktop.  A listagem possui filtros por intervalo de data e status do pedido de material extra.  As seguintes funções estarão disponíveis para pedido de material extra:   * Criação de novo pedido Extra * Edição de pedido Extra * Envio de movimento * Processo para Retornar para status de criação * Processo para enviar para aprovação * Processo para aprovar pedido * Processo para reprovar pedido   Não houve alteração no comportamento dos processos |
