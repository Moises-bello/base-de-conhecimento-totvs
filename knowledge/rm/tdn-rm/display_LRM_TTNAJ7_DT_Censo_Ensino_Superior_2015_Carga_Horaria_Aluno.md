# CENSO DO ENSINO SUPERIOR 2015

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *RM CLASSIS ES - Atividades Acadêmicas* |
| **Função:** | *Censo do Ensino Superior* |
| **Situação/Requisito:** | *Circular nr° 100 divulgada pelo INEP informa que a partir do Censo de 2015 serão exigidas novas informações: Carga Horária prevista e já cumprida do curso do aluno; modificações na lista de tipos de remuneração para os professores visitantes..* |
| **Solução/Implementação:** | *O Assistente de preparação de dados sofreu as seguintes modificações: 1 -* *passou a verificar se os dados referentes à carga horária das Disciplinas cursadas pelos alunos recenseados foi informada, relacionando os registros que omitem este dado e impedindo o avanço do processo. 2 - passou a registrar a carga horária já cumprida pelo aluno até a data de referência do Censo na tabela auxiliar *(UALUNOCURSOMEC)*  que é utilizada na geração do arquivo de exportação.*  *É importante salientar que as IE que utilizam o módulo de exportação de dados para o Censo do Ensino Superior, mesmo que controlem o cumprimento da grade acadêmica por outros critérios que não a Carga Horária, como Créditos ou Número de Disciplinas, devem registrar a Carga Horária das Disciplinas.* |
