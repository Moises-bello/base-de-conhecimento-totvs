**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19431369869335) Tempo aproximado para leitura: 00:02:00 min** **Dúvida**Para que serve e como realizar cadastro de grupos no modulo Arquitetura Organizacional  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Arquitetura Organizacional – Todas as versões  
  
**Solução**Neste cadastro são informados **os grupos funcionais de uma empresa,** que podem ser utilizados nos seguintes controles:  
1- **Na montagem da estrutura de cargos** para definir o grupo a que pertence cada cargo;  
2- **N****a definição de competências para o grupo funcional** (recurso disponível nos ambientes de Treinamento e Cargos e Salários);  
3- **Na definição dos fatores de avaliação de grupos**, permitindo, com base na pontuação mínima/máxima de cada grupo, calcular os pontos de cada fator.  
  
A partir da informação dos campos **"Pontos Mínimos" e "Pontos Máximos"** pode ser utilizada uma pontuação para os grupos, indicando a faixa de pontos que os cargos de cada grupo podem obter. Ou seja, **pontos mínimos/máximos de cada um, dentro de um grupo funcional.**  
  
Esta informação será utilizada para **definir a pontuação dos fatores do grupo** que posteriormente irão definir os pontos dos cargos.  
  
Este conceito é utilizado em empresas que consideram, no plano de Cargos e Salários, **uma pontuação para seus grupos funcionais.**
