**Dúvida**Por que cálculo de rescisão complementar emite alerta: Atenção Data de Aviso não foi preenchida?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4402316698391)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**A mensagem é gerada pois em rescisão original, o campo Data Aviso não foi preenchido.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4402309691287)

**IMPORTANTE:** Mesmo se o tipo de rescisão for configurado com aviso N (em tabela S043), o campo Data Aviso no cabeçalho da rescisão original deve ser preenchido, pois através do campo Data Aviso é preenchido automaticamente o campo Dt. Demissão para qualquer tipo de rescisão.
