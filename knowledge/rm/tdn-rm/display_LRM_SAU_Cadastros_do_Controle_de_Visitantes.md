# Quais são os cadastros da funcionalidade Controle de Visitantes?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Menu:** | Cadastros |
| **Assunto:** | 1. Como cadastrar Cartão de Visitante?  2. Como cadastrar Tipo de Visitante?  3. Como cadastrar Visitante? |

**1. Como cadastrar Cartão de Visitante?**

Nessa opção é realizado o cadastro de Cartões de Visitante, é nessa etapa que você define quantos visitantes poderão entrar ao mesmo instante em um determinado leito. A quantidade de cartões cadastrados para o leito que define esse limite.

1. No **TOTVS Gestão Hospitalar** acesse **Registro e Controle/Visitante/Cartão de Visitante**.
2. Informe o Número do Cartão de Visitante (com no máximo 12 dígitos).
3. Clique em **Calcular Dígito Verificador** para que o 13º dígito verificador do código de barras seja calculado automaticamente.
4. Informe o Número do Leito ou clique em '' **...**'' para realizar a pesquisa.
5. Selecione o leito que será relacionado ao cartão.
6. Clique em **OK**.

### 2. Como cadastrar Tipo de Visitante?

Nessa opção é realizado o cadastro de Tipo de Visitante, como por exemplo, visitantes para paciente, fornecedores, terceiros etc.

1. No **TOTVS Gestão Hospitalar** acesse **Registro e Controle/Visitante/Tipo de Visitante**.
2. Clique em **Incluir** (página em branco).
3. Informe a Descrição do tipo de visitante.
4. Clique em **OK**.

### 3. Como cadastrar Visitante?

1. No **TOTVS Gestão Hospitalar** acesse **Registro e Controle/Visitante/Visitante**.
2. Preencha o Nome do visitante.
3. Preencha as informações de CPF e RG (não obrigatório).
4. Se desejar, inclua uma foto do visitante.
5. Clique em **OK**.
