# Permissão para processamento de requisições

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | Todas. |
| **Ocorrência:** | Realizando estes procedimentos, será possível adicionar um local de estoque onde o usuário terá acesso. |
| **Passo a passo:** | **1º Passo)** Acessar o sistema TOTVS GESTÃO HOSPITALAR; **2º Passo)** Acessar o menu Opções -> Parâmetros -> Parâmetros Gerais    **3º** **Passo**) Clique na aba “Estoques”    **4º Passo)** Conforme a imagem, clique em “+”, escolhe o local de estoque onde o usuário irá possuirá acesso.    **5º Passo)** A permissão para processamento dá-se pelo parâmetro “Usuário Confirma Requisição” |
