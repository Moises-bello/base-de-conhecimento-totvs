**Dúvida**Ao visualizar os dados na Dashboard de Controladoria no Gooddata do Projeto Smart Analytics, os dados não estão aparecendo ou não estão batendo, como devo proceder?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus – Smart Analytics – A partir da versão 3.0  
  
**Solução**Inicialmente precisa validar se a extração ocorreu tudo certo com as tabelas referente a controladoria.  
[Área Controladoria - BI - P12](http://tdn.totvs.com/pages/releaseview.action?pageId=240976379)  
  
Posterior precisa validar se foram configuradas as variáveis de Controladoria no Gooddata.  
[Variáveis Smart Analytics](http://tdn.totvs.com/pages/releaseview.action?pageId=235307362)  
  
Se após isso não ver que os dados estão condizentes ainda, favor validar os dados atráves do Relatório Modelo 1.
