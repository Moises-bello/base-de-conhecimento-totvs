## Descrição

        Foi disponibilizado um mecanismo para que telas feitas no modelo do frame html sejam utilizadas dentro do portal RM.

## Procedimento para Configuração

*(Estes procedimentos devem ser feitos quando for necessário configurar parâmetros e/ou  rotinas no menu).*

**CONFIGURAÇÃO DE PARÂMETROS**

1. Em parâmetros globais define a url onde o frame html está instalado.

**Exemplo:**

       1.            Basta acessar o portal normalmente, as telas que estão escritas em html e disponibilizada pelo produto para ser utilizadas dentro do portal RM, será apresentada como qualquer menu.
