![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida** O módulo de Importação *Easy Import Control* **(SIGAEIC)**,  faz a integração com o Sistema RM?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**  
O módulo 17 *Easy Import Control* '**SIGAEIC**', possui integração apenas com o sistema Logix, não há no padrão integração com o sistema RM.
