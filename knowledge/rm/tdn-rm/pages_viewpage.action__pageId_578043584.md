## **01. VISÃO GERAL**

Esta funcionalidade tem por objetivo realizar o processo de geração de exceção

Tela Resultados Laboratoriais

## **02. TELA RESULTADOS LABORATORIAIS**

Unidade de Diagnóstico > Resultados Laboratoriais 

Ao selecionar um exame e clicar no botão "Geração de Exceção" o sistema permite a criação de uma exceção a determinado exame.

O sistema não permite gerar exceções para exames com status liberado ou posterior.

Tela Geração de Exceção

## **03. TELA GERAÇÃO DE EXCEÇÃO**

Na tela de geração de exceção podemos cadastrar uma exceção para o exame que impedirá que o exame seja liberado.

Ela pode ser impeditiva ou restritiva.

Caso a exceção seja impeditiva, não poderá evoluir o exame.

Se for restritiva, só libera após exibir uma mensagem informando que existe aquela exceção.
