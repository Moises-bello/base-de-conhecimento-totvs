![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24999990812055) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Como realizar a Migração de Software Terceiros?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - Todas as Versões.  
  
**Solução**Este artigo tem como objetivo prover informações para clientes que estejam iniciando a utilização da Folha de Pagamento RM, e que já tenham enviado informações para o ambiente do eSocial utilizando softwares de folha de pagamento de terceiros, para que possam continuar a enviar os dados para o eSocial através da fila de eventos do RM.

Abaixo as documentação com orientações para cada tipo de usuário:

* Usuário Middleware:  [Migração Software Terceiros para RM Middleware](https://tdn.totvs.com/pages/releaseview.action?pageId=552096198)
* Usuário TAF: [Migração Software Terceiros para RM e TAF](https://tdn.totvs.com/pages/releaseview.action?pageId=450147203)
