Através do Processo de Download que se encontra em Processos do Modelo de Projeto, é possível Exportar um arquivo do sistema para uma pasta específica do seu Computador. Veja o exemplo abaixo:

**Passo a passo:**

1. Selecione o Arquivo IFC que deseja exportar;
2. Selecione o Processo de Download de Arquivo IFC;
3. Informe um caminho físico da máquina para onde deseja salvar o arquivo exportado;
4. Execute o Processo;

Após a execução do mesmo, o sistema exporta toda estrutura do arquivo IFC para o caminho indicado.
