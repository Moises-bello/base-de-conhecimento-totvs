# APROVEITAMENTO DE CRÉDITO DA CONTA CORRENTE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de lançamento a pagar do aproveitamento de conta corrente do aluno* |
| **Situação/Requisito:** | *Ao aproveitar um crédito da conta corrente do aluno, o sistema, por utilizar o campo opcional de desconto, parametrizado na integração financeira, preenche o campo opcional do lançamento gerado com o valor a ser aproveitado da conta corrente do aluno. Porém, para que o aluno possa receber o valor líquido igual ao valor aproveitado na conta corrente, o sistema preenche o valor original do lançamento financeiro com o dobro do valor aproveitado da conta corrente.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de aproveitamento de crédito da conta corrente do aluno, de forma que o lançamento a pagar gerado pelo sistema, não utilize o campo de valor opcional de desconto parametrizado na integração financeira e consequentemente não dobre o valor original do lançamento.* |
