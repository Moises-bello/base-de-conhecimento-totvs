Este documento do TOTVS TDN oferece melhores práticas para otimizar a rotina de Recalculo do Custo Médio no Protheus, incluindo ações, correções e coleta de dados de performance para análise técnica. **Dúvida**  
Como melhorar a performance da rotina de Recalculo do Custo Médio ?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Apartir da release 12.

**Solução**

A presente documentação centraliza, em nosso **TDN**, todos os pontos abordados e as melhores práticas para aprimoramento do desempenho durante o processamento do Custo Médio.

Este documento deve ser consultado como referência inicial para a aplicação de *patchs* e configurações recomendadas.

**Documentação destinada a area tecnica do cliente (Infraestrutura/T.I/DBA).**

* **Melhorias e Otimizações:** Lista das principais ações e correções destinadas a otimizar o processamento da rotina de Custo Médio.
* **Insuficiência de Melhoria:** Caso as implementações não resultem na melhoria esperada, o documento provê as diretrizes e instruções detalhadas para a **coleta de dados de performance** (Logs, *Trace* de Banco de Dados, etc.).
* **Avaliação do Suporte:** As informações coletadas conforme as orientações serão essenciais para que o Suporte Técnico possa realizar uma avaliação aprofundada da performance em seu ambiente.
