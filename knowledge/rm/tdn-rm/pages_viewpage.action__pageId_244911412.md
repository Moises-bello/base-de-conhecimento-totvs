# Bolsa por Período Letivo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Cadastro Bolsa por Período Letivo |
| **Situação/Requisito:** | O sistema estava permitindo salvar um Bolsa por Período Letivo em que o nível do ensino fosse diferente do nível de ensino da Bolsa.  Isto ocorre quando o usuário abre o cadastro de Bolsa em um determinado nível de ensino e sem fechar o cadastro muda o contexto para outro nível de ensino. |
| **Solução/Implementação:** | Melhoria no cadastro de Bolsas por período letivo para que seja validado se o nível de ensino da bolsa está conforme o nível de ensino do período letivo. |
