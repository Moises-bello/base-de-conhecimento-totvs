![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26681384023831) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como calcular verbas indenizatórias em rescisão considerando salário base mais gratificação (verba sem ID)?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para calculo de verbas indenizatórias considerando salário base mais gratificação, a verba de gratificação deve estar com Sim para Incorpora Salário e a verba indenizatória como campo Base Cálculo com Salário Incorporado. Deste modo o sistema considera como base para cálculo da verba indenizatória a soma do salário base mais gratificação.
