# SPED Contábil (ECD) Layout 6.0

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Geração do SPED Contábil (ECD) |
| **Situação/Requisito:** | O SPED Contábil (ECD) deve ser evoluído para contemplar as evoluções referentes ao layout 6.0 divulgado pela Receita Federal |
| **Solução/Implementação:** | Com objetivo de atender aos clientes que querem entregar o SPED Contábil (ECD) foram feitas as seguintes evoluções:   * Inclusão do campo Notas Explicativas (NOTAS\_EXP\_REF) nos registros J100, J150 e J210. Obs.: (Contempla as versões 12.1.17 e superiores). * Inclusão do cadastro de Notas Explicativas para as Demonstrações Contábeis. Obs.: (Contempla apenas a versão 12.1.20 e superiores). * O cadastro de Notas Explicativas será feita por Fato Contábil sendo recuperada fato a fato no registro J100 e J150. Já o registro J210 que se refere a demonstração e não apenas um fato contábil terá a informação recuperada a partir do Primeiro Fato Contábil cadastrado na demonstração. |
