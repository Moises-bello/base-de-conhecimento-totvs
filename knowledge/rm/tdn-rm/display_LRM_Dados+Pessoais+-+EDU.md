**Dados Pessoais**   
Nesta página é possível enxergar todos os dados do aluno. A instituição tem como opção permitir ou não que o aluno atualize seus dados no portal.   
Criado no sistema campo nome social no cadastro de alunos conforme estabelecido pela Portaria n. 1612/2011 do Ministério de Educação. Entende-se por nome social aquele pelo qual as pessoas se identificam e são identificadas pela sociedade.  
Caso a instituição permita o aluno deve manter os dados sempre atualizados. Após preencher todos os campos salve os registros!  
A tela de cadastro vem divida em três blocos:

* Dados pessoais
* Filiação
* Endereço
