## **01. VISÃO GERAL**

Para atender a [Lei Nº 13.709/18](http://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/L13709.htm) foi criado o processo "Anonimização" dentro do cadastro de prestador, este processo irá alterar os campos permitidos e definidos para um valor fictício (ex: 000). 

Campos passíveis de anonimizar:

| Coluna | Descrição |
| --- | --- |
| SEXO | Vida Sexual |
| ASSINATURA (IDIMAGEM) | Identificadores de Via Eletrônica (e-mail, etc.) |
| BIP | Telefone |
