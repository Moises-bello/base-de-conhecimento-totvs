# Captura de Título de Cobrança (DDA)

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | Captura de título de cobrança - DDA |
| **Situação/Requisito:** | No cadastro de DDA (Débito Direto Autorizado), ao efetuar uma captura de título de cobrança, no qual o layout utiliza o segmento opcional, sistema não estava gravando a inscrição do cedente registrada no segmento opcional. |
| **Solução/Implementação:** | Ao efetuar uma captura de título de cobrança, no qual o arquivo possui o segmento opcional, gravar a inscrição do cedente registrada na linha do segmento opcional. |

| **Chamados relacionados:** | *N/A* |
