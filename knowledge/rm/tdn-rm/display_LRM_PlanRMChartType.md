# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Define o tipo de gráfico para todas as séries dele ou para cada uma individualmente.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Area | Gráfico de área. |
| AreaStacked | Gráfico de áreas empilhadas. |
| AreaStacked100 | Gráfico de áreas 100% empilhadas. |
| BarClustered | Gráfico de barras. |
| BarStacked | Gráfico de barras empilhadas. |
| BarStacked100 | Gráfica de barras 100% empilhadas. |
| ColumnClustered | Gráfico de colunas. |
| ColumnStacked | Gráfico de colunas empilhadas. |
| ColumnStacked100 | Gráfico de colunas 100% empilhadas. |
| Line | Gráfico de linhas. |
| LineStacked | Gráfico de linhas empilhadas. |
| LineStacked100 | Gráfico de linhas 100% empilhadas. |
| Pie | Gráfico do tipo pizza. |
| PieExploded | Gráfico do tipo pizza (fatias separadas). |
