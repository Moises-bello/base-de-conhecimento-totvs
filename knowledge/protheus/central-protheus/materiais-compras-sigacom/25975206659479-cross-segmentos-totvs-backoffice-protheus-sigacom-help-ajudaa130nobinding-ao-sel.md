**Dúvida**  
Ocorre o HELP: AJUDA:A130NOBINDING, ao selecionar o fornecedor no Novo Fluxo de Compras - NFC (PGCA010)

![Artigo.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25978064172183)

**Ambiente**  
Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Gestão de Compras - Protheus Release 12.1.2210.

**Solução**

Esse HELP ocorre quando o produto não possui amarração no cadastro de Produto x Fornecedor (MATA061), nesse caso é necessário realizar a amarração para seguir com a cotação.

Ou caso deseje que o sistema não valide o cadastro de Produto x Fornecedor basta acessar o configurador e alterar o parâmetro MV\_SELFOR para S, desse modo o sistema permitirá seguir com a cotação mesmo que o produto não possua amarração

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25975180610967)

**Obs.** Por padrão, Novo Fluxo de Compras não valida a amarração Grupo de Produto x Fornecedor. Somente a amarração Produto x Fornecedor é validada.
