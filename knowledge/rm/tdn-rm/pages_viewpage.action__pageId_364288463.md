# TRATAMENTO DO PARÂMETRO "TIPO VISITANTE DEFAULT", QUANDO EXISTIR ITEM VAZIO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Visitantes |
| **Situação/Requisito:** | Ao clicar no botão que abre a janela de Controle de Visitantes, o sistema exibia um erro com a seguinte mensagem: "A cadeia de caracteres de entrada não estava em um formato correto." |
| **Solução/Implementação:** | Inclusão de tratamento quando o parâmetro "Tipo Visitante Default", na aba Registro e Controle III dos Parâmetros Gerais, conter algum item vazio. |
