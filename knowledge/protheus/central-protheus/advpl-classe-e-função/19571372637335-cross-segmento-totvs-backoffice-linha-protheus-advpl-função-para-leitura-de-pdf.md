Dúvida**Existe função para leitura de um arquivo PDF?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – Todas as Versões  
  
**Solução**Não existe uma função para leitura de arquivos PDF. Entretanto, existem funções para que seja aberto o arquivo PDF:

* Abertura sendo feita pelo Protheus, existe a função *TWebEngine.*
* Abertura acionando um programa do seu sistema operacional, existe a função *ShellExecute.*

**Saiba mais**[ShellExecute](https://tdn.totvs.com/display/tec/ShellExecute)
