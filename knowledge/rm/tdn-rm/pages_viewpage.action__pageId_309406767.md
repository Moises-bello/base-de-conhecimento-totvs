# Cadastro de mensagens da Central de Notificação

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *TAGs para montagem da mensagem na central de notificação* |
| **Situação/Requisito:** | **Cadastro de mensagens da Central de Notificação, quando selecionamos o objetivo "Enviar mensagens eventuais para via e-mail, Fluig ou eduConnect" e marcamos mais de um público-alvo, o sistema esta exibindo TAGs que não são pertinentes ao público alvo.** |
| **Solução/Implementação:** | *Realizado ajuste no cadastro de mensagens/processo com o objetivo "Enviar mensagens eventuais para via e-mail, Fluig ou eduConnect" para exibir apenas TAGs coerentes ao público-alvo selecionado. Caso seja marcado mais de um público-alvo, será disponibilizado apenas a tag [NOME](Nome do destinatário).* |
