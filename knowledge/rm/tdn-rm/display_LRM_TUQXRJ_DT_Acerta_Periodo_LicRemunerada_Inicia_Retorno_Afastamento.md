# ACERTO DO PERIODO COM LICENÇA REMUNERADA INICIA NOVO PERIODO NO RETORNO DO AFASTAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Acerto do Período Aquisitivo* |
| **Situação/Requisito:** | *Quando ocorre mais de 30 dias de afastamento por Licença Remunerada (tipo R) dentro do periodo aquisitivo, este periodo deve ser interrompido e perdido.*  *Neste caso, o novo período aquisitivo deve ser iniciado quando o funcionário retornar ao serviço, ou seja, no dia seguinte à data final do afastamento.* |
| **Solução/Implementação:** | *Ajuste no módulo de Acertar Periodo Aquisitivo para que no caso da ocorrência de mais de 30 dias de Licença Remunerada, o período seja interrompido e perdido, e um novo seja iniciado no dia seguinte à data final do afastamento.* |
| **Chamados   relacionados:** | *TUQXRJ* |
| **Versões/Release:** | *11.82.43* |
