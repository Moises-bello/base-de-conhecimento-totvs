Primeiramente um template seria como um modelo, ou um default. Este cadastro permite parametrizar o sistema para que os usuários possam fazer consultas de imóveis disponíveis para locação através de alguns campos. Para cada um dos tipos de usuários, com funções diferentes, a consulta deve possuir campos específicos.

**Campos disponíveis:**

* **Cód. Template:** Este campo mostra o código do template criado no sistema.
* **Descrição:** Este campo permite inserir uma descrição sobre o template que está sendo cadastrado. Exemplo de descrição: Template para buscas por coligada.
* **Quadro de Disponibilidade de campos para consulta:** Neste quadro o usuário poderá selecionar um ou mais campos para serem utilizados em suas consultas. Os campos disponíveis são:
  + Coligada
  + Endereço (cidade, bairro, estado)
  + Região
  + Tipo de imóvel
  + Tipo de locação
  + Valor de locação
  + Área
  + Data de aquisição
  + Características
* **Associação de Perfil:** Nesta área é possível inserir um ou mais perfis de usuários que terão acesso ao Template que está sendo criado ou editado.
  + **Observação:** Um mesmo perfil de usuário não pode ser associado a mais de um Template.
