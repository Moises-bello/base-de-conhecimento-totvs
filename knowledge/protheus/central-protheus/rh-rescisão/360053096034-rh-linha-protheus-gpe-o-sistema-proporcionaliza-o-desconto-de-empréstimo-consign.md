Dúvida**O sistema proporcionaliza o desconto de empréstimo consignado em rescisão quando o funcionário tem dois empréstimos ou mais?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Por padrão, o sistema não irá proporcionalizar esse desconto em rescisão, calculando 15% de desconto para cada banco.  
A legislação diz que o empréstimo consignado só pode ser descontado até 35% das verbas rescisórias, então o sistema calcula o primeiro empréstimo, se esse primeiro alcançar os 35% o sistema não irá calcular o outro empréstimo.
