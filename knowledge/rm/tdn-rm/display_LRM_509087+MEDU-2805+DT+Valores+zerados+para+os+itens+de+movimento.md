# VALORES ZERADOS PARA OS ITENS DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Geração de movimentos por competência* |
| **Situação/Requisito:** | *Sistema estava gerando itens de movimento com valores zerados quando se tinha a soma de percentuais de bolsas e desconto maiores ou iguais a cem porcento (100%) mesmo com o tipo de aplicação de bolsas sendo em Cascata.* |
| **Solução/Implementação:** | *Acréscimo do campo TIPOBOLSA na seleção de contratos a fim de que o sistema aplique as bolsas de acordo com o valor setado no cadastro de contratos.* |
