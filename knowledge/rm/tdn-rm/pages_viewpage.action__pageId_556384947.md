## **02. SITUAÇÃO/REQUISITO**

Ao realizar a digitação de notas/faltas, avaliação e frequência diária para uma etapa com fórmula vinculada, o sistema estava exibindo dados financeiros do aluno para o professor.

## **03. SOLUÇÃO**

Otimizado o processo para que, não seja exibido dados financeiros do aluno para o professor ao realizar o processo de digitação no sistema.
