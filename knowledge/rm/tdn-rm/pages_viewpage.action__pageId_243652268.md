# Migração Cadastro de Recém Nascidos para tecnologia .NET

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Cadastro de Recém Nascidos | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER® e ORACLE® |
| **Tabelas Utilizadas:** | ``` SZRNACOMPANHANTE ``` |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Realizada migração da tela de cadastro de recém-nascido para tecnologia .NET.

## Procedimento para Utilização

1. Selecione uma paciente internada de ginecologia e obstetrícia.
2. Cadastre um novo recém-nascido para a paciente.
3. Informe todos os dados necessários e clique em **Salvar**.
