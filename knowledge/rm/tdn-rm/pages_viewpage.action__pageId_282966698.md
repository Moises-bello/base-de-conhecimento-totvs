# Lançamento de Honorários Anestésicos com Fator de Acomodação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Honorários |
| **Situação:** | Ao lançar itens nos honorários da Elaboração de Contas e informar um fator de acomodação, o sistema não levava em consideração as informações referente ao porte anestésico, removendo o valor do item correto e inserindo o valor total moeda do procedimento. |
| **Solução:** | Alterado o sistema para efetuar o cálculo correto do valor do item buscando pela tabela do porte quando existir. |
