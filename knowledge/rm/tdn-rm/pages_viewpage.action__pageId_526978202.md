## **ÍNDICE**

1. **Visão Geral**
2. **Exemplo de utilização**

**01. VISÃO GERAL**

      O Parâmetro "Assistente de Processos" tem por função, filtrar a busca do contexto por "Tela de Cadastro" ou "Assistente de Processos"

**02. EXEMPLO DE UTILIZAÇÃO**

**Filtro : Tela de Cadastro**

      Verifique nas imagens abaixo, que ao utilizar o filtro "Tela de Cadastro" é filtrado somente as telas de cadastro do RM, não é possível realizar a busca de um processo por esse filtro.

| * Ao realizar uma pesquisa (ex: GlbUsuarioAction) pelo filtro "Tela de Cadastro", a busca será realizada com sucesso! |
| --- |
| * **Quando alterado o filtro para "Assistente de Processos", veja que não é mais possível realizar a buscar da tela de usuário!** |

**Filtro : Assistente de Processos**

      O mesmo acontece quando selecionado o filtro "Assistente de Processo" é filtrado somente os processos do RM, não é possível realizar a busca de uma tela do sistema por esse filtro. Exemplo abaixo:

| * Ao realizar uma pesquisa (ex: GlbActionProcCopyPerfil) pelo filtro "Assistente de Processos", a busca será realizada com sucesso! |
| --- |
| * **Quando alterado o filtro para "Tela de Cadastro", veja que não é mais possível realizar a buscar de um processo!** |
