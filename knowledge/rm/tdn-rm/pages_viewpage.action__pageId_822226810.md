Atenção

Para uma melhor experiência, é recomendado configurar primeiramente os campos obrigatorios, fechar e reabrir o formulario, antes de realizar qualquer salvamento de dados no formulário.

Para configurar um campo como obrigatório em formulários que possuem este recurso, é necessário seguir este processo abaixo:

* Ao abrir o formulário desejado e ao clical com o botão direito do mouse sobre o campo a ser configurado, neste exemplo usaremos o campo "**Nome Social**", será exibido este controle:

* Após aplicar a obrigatoriedade no campo desejado, o controle fica com a função "**Preenchimento Obrigatório**" selecionada, caso seja necessário remover a obrigatoriedade.

* Após a configuração dos campos, é necessário fechar o e abrir novamente o formulário para que o controle dos campos seja atualizado e assim iniciar a alteração de dados do registro. Os campos com obrigatoriedade aplicada irão aparecer em negrito.
