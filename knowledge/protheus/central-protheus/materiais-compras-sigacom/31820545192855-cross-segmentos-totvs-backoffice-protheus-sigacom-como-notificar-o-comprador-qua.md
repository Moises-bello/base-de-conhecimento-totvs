**Dúvida:**Como notificar o comprador quando o pedido de compras for gerado através do Novo Fluxo de Compras?

**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Gestão de Compras - Protheus Release 12.1.2210.

**Solução:**Para que o Comprador receba o e-mail notificando quando a SC virar um Pedido de Compra, deve seguir as etapas abaixo:

* **Atenção:** Para que o Comprador seja devidamente comunicado via e-mail, seu e-mail deve estar cadastrado no perfil de usuário no Protheus, pois caso contrário, não receberá as notificação via e-mail.

![](https://tdn.totvs.com.br/download/attachments/680260500/WF_MATA110.gif?version=1&modificationDate=1742393836443&api=v2)

Ao final do proceso de cotação será disparado o email conforme consta na imagem abaixo, informando o comprador que o pedido foi gerado:

![image-2025-4-11_9-1-10.png](https://tdn.totvs.com.br/download/attachments/680260500/image-2025-4-11_9-1-10.png?version=1&modificationDate=1744372871007&api=v2)

**Observação:**Para que o email seja devidamente enviado é necessário possui uma conta de email cadastrada no Protheus, conforme documentação abaixo:

[Cross Segmento - TOTVS Backoffice Linha Protheus - BI - Configuração Básica de conta para envio de WorkFlow pelo Gmail](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360037067513-Cross-Segmento-TOTVS-Backoffice-Linha-Protheus-BI-Configura%C3%A7%C3%A3o-B%C3%A1sica-de-conta-para-envio-de-WorkFlow-pelo-Gmail)
