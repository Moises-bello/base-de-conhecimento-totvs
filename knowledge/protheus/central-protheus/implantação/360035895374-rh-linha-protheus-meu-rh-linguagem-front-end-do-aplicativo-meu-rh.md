**Dúvida**  
Qual a linguagem front-end utilizada para desenvolver o aplicativo Meu RH?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Meu RH – Todas as versões  
  
**Solução**  
O front-end é feito em **Angular** (atualmente versão 14), juntamente com **THF** (TOTVS HTML Framework) que atualmente foi transformado para o projeto **Portinari** ([https://po-ui.io](https://www.google.com/url?q=https://portinari.io&sa=D&source=hangouts&ust=1569520475503000&usg=AFQjCNF9gQqXOD5rs52_ZLxzSHTaFb_PcQ)).
