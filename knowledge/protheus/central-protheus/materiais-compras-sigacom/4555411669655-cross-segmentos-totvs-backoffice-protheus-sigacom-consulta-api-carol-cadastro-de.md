![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:04:00 min****Ocorrência**Consulta Api Carol Cadastro de Fornecedor - O que fazer quando os campos de Razão Social (A2\_NOME) / Nome Fantasia (A2\_NREDUZ) / Bairro (A2\_BAIRRO) / Município (A2\_MUN) / Endereço (A2\_END) não forem carregados ao ao informar o CNPJ?  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Compras - Todas as versões  
  
**Causa**Esse incidente ocorre, pois o tamanho dos campos do protheus é menor do que a informação carregada no Api carol.

**Solução**

Verifique no dicionário de dados o tamanho dos campos correspondentes e aumente caso haja necessidade.
