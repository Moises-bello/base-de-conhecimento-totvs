| **Sintoma** | **Precisamos gerar duas guias de INSS quando temos dissídio no mês?** |
| **Solução** | Sim, o código da GPS para dissídio coletivo é diferente (2909), por este motivo a empresa precisa gerar duas guias.  Hoje, o sistema RM Labore não está preparado para isto, o cliente deverá gerar a guia pelo SEFIP. Quando o cliente for gerar os arquivos referente ao depósito do FGTS, o cliente vai precisar gerar dois arquivos, um com o código de recolhimento 115 ou 155 e outro com o código de recolhimento 650 (para dissídio coletivo ou reclamatória trabalhista). Neste momento poderá emitir as guias separadas.   Entretanto em relação a GPS, ainda não existe a possibilidade de gerar a GPS específica para o dissídio, portanto o cliente deverá gerar esta guia através do SEFIP |
