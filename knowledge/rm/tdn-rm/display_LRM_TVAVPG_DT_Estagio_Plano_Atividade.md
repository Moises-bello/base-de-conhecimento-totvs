# ESTÁGIO - PLANO DE ATIVIDADE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Estágio - Plano de Atividade* |
| **Situação/Requisito:** | *O campo Código do contrato, no Termo de compromisso de estágio (Gestão Educacional | Atividade acadêmicas | Estágio | Termo de compromisso) não é de preenchimento obrigatório, mas ao gerar o Plano de atividade do estágio o campo é obrigatório.* |
| **Solução/Implementação:** | *Ajuste na tela termo de compromisso para que seja exibido o campo termo de compromisso e que o mesmo fique somente leitura. Além disso, foi alterado o plano de atividade para que seja exibido este mesmo campo termo de compromisso ao invés do código do contrato e que o mesmo seja somente leitura e já venha preenchido caso seja acessado pelo anexo do termo de compromisso. Caso for acesso pelo menu o mesmo será possível selecionar. Com isso, resolve o problema de campo obrigatório do código de contrato na tela de plano de atividade.* |
