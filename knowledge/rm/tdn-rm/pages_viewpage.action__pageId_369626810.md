# DIGITAÇÃO DE NOTAS E FALTAS DA ETAPA DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Digitação de Notas e Faltas da Etapa do Aluno |
| **Situação/Requisito:** | Foi identificado que na digitação de notas quando utilizado fórmula o sistema não está validando corretamente o número de casas decimais configurado na disciplina. |
| **Solução/Implementação:** | Foi identificado que a situação ocorre quando a fórmula utiliza a função "GravaCampoEtapa", assim, foi inserido uma validação do número de casas decimais e o ajuste do número para que fique com as cadas decimais definido na disciplina. |
