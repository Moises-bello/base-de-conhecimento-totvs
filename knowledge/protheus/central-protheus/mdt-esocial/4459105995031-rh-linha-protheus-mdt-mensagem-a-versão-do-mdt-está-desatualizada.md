![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17371955207575) Tempo aproximado para leitura: **00:04:00 min** **Dúvida**Ao acessar rotinas do módulo SIGAMDT ocorre mensagem "A versão do MDT está desatualizada":  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4459017985175)  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho -  Todas as versões  
  
**Solução**É necessário verificar se o ambiente esta atualizado com os Acumulados do eSocial e MDT, ambos pacotes devem ser executado Dicionário de Dados:  
  
[1. Pacote de Expedição Continua Medicina e Segurança do Trabalho (SIGAMDT)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057956773-RH-Linha-Protheus-MDT-Como-fazer-o-download-do-pacote-de-expedi%C3%A7%C3%A3o-continua-acumulado-para-atualizar-o-modulo-medicina-e-seguran%C3%A7a-do-trabalho)  
  
Entre no módulo Configurador, no menu Base de Dados > Dicionário > Base de Dados, filtre a tabela TNE e consulte se existe o índice de ordem 2, conforme exemplo. Se necessário, efetue a inclusão do índice.
