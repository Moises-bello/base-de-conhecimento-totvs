# Reserva de Instalações (Portal - Professor)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Reserva de instalações |
| **Situação/Requisito:** | Foi identificado que quando um usuário (professor) executa a função de salvar os dados de uma nova reserva de instalação, o sistema não completa a operação como também não fornece um feedback sobre a existência de erro ou inconsistência.  Contudo este problema ocorria apenas quando o perfil do usuário não possuía permissão de inclusão de anexos para as reservas de instalação. |
| **Solução/Implementação:** | Ajuste realizado para que a falta de permissão de usuário(professor) para inserir anexos nas reservas de instalação, não o impeça de incluir/editar novas reservas. |
