# Fechamento de Período

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Fechamento de Período |
| **Situação/Requisito:** | O fechamento de período foi executado com sucesso para os anos de 2014 e 2015, porém não foi possível fechar o ano de 2016. No log de execução são exibidos os motivos que impediram a execução do processo para o ano de 2016. |
| **Solução/Implementação:** | Para possibilitar o fechamento de período, do ano de 2016, foi necessário realizar algumas modificações no processo. O saldo anterior dos débitos e créditos sem rateio estava sendo agrupado por coligadas diferentes, porém eles pertenciam a mesma coligada. Após ajustar esse agrupamento foi possível fechar o período com sucesso. |
