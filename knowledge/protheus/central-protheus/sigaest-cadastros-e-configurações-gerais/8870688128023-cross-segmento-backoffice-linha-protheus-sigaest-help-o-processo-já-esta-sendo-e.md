**Ocorrência**Help - **O processo já esta sendo executado**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8870551211927/mceclip0.png)

Ao tentar abrir duas telas no Protheus da mesma rotina.  
  
**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.

**Causa**

Este help acontece quando o usuário não tem o acesso necessário para verificar a mesma rotina em 2 telas.

**Solução**Na configuração do usuário, no SIGACFG é possível configurar se o usuário terá este acesso ou não: Acesso 124

|  |  |  |  |
| --- | --- | --- | --- |
| 124 | "Processos idênticos na MDI" | Define se o usuário tem permissão para utilizar processos idênticos no ambiente MDI. Por exemplo: utilizar dois cadastros de produtos simultaneamente. | Acesso genérico do sistema |
