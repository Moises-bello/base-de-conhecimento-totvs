|  |  |

| **Linha de Produto:** | *RM* |

| **Módulo:** | *Totvs Processo Seletivo* |
| **Função:** | *Alterar data de vencimento de lançamentos* |
| **Situação/Requisito:** | *O sistema estava permitindo alterar a data de vencimento de um lançamento para uma data maior que a data limite para vencimento da forma de inscrição que o candidato está inscrito.* |
| **Solução/Implementação:** | *Foi feito um ajuste no processo para verificar a data limite para vencimento da forma de inscrição em que o candidato está inscrito, sendo assim, se a data for maior o sistema irá alertar no final do processo que não é possível alterar a data de vencimento. Os candidatos que estão inscritos em formas de inscrição com prazo de vencimento válidos, poderão alterar a data de vencimento sem erros.* |
