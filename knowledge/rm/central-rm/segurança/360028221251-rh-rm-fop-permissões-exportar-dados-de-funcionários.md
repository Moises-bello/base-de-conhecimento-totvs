**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)**Tempo aproximado para leitura:**00:00:40 min****Dúvida**Como liberar a permissão de acesso para que o usuário do sistema realize a exportação de dados da visão dos funcionários?  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12272764645911)  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para liberar o menu será necessário conceder permissão, conforme abaixo:  
  
1. Acesse **Serviços globais | Segurança | Usuários** e altere o sistema para Folha de Pagamento;  
2. Edite o usuário utilizado e verifique qual perfil está vinculado a ele, conforme abaixo:  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12272806033431)  
  
3. Após verificar o perfil utilizado, acesse **Serviços globais | Segurança | Perfis**e altere o sistema para Folha de Pagamento;  
  
4. Edite o perfil verificado no passo dois e libere a permissão **Funcionários: Listar/imprimir  
  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/12272816137111)**
