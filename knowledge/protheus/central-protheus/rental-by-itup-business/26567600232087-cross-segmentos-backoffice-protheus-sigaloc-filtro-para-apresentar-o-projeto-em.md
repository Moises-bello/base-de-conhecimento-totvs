**Dúvida**  
Filtro para apresentar o Projeto em LOTE para apontamento AS  
  
**Ambiente**  
Cross Segmentos - Backoffice Protheus - SIGALOC - Todas as versões  
  
**Solução**  
Ao acessar a rotina "Apontador AS LOCA059", o sistema exibe uma caixa de diálogo solicitando que você defina o filtro de período para a busca desejada.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26567600197399)

Nesse momento, o sistema valida os campos do projeto "Dt Início" (**FPA\_DTINI**) e "Dt Fim Loc" (**FPA\_DTENRE**) para exibir os projetos que devem ser apontados nas AS.

Ao acessar **OUTRAS AÇÕES** >> **LOTE**, será apresentada uma nova caixa de perguntas. Nesse caso, é importante inserir as mesmas datas para "Dt Início" (**FPA\_DTINI**) e "Dt Fim Loc" (**FPA\_DTENRE**). Se as datas forem diferentes das informadas no **PROJETO**, as Ações Selecionáveis em Lote não serão exibidas.
