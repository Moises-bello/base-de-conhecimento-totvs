# SINDICATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sindicato* |
| **Situação/Requisito:** | Inconsistência no cadastro do sindicato.   Na Aba Férias não está aparecendo a Sub-aba Eventos para pagamento de média de na rescisão   Na Aba 13º Salário não está aparecendo a Sub-aba Eventos para pagamento de média de 13º na rescisão |
| **Solução/Implementação:** | Ajustado a exibição das abas 'Evento p/ Pag. de Média de 13º na Rescisão' e 'Evento p/ Pag. de Média de Férias na Rescisão'.   Sistema estava verificando o parâmetro Tipo de Cálculo dos parâmetros específicos de rescisão, sendo que esta aba está desabilitada. |
| **Chamados relacionados:** | *TVQEJ0* |
