# Cópia por Referencia - Venda para Entrega Futura

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Gestão de Estoque, Compras e Faturamento. |
| **Função:** | Informe a função. |
| **Situação/Requisito:** | Ao realizar o processo "venda para entrega futura" utilizando assistente de cópia por referência com o motivo de referência 2 - Simples Remessa. Para itens controlados por lote o sistema emite um aviso de que o lote do movimento de destino deve ser o mesmo do movimento de origem impedindo que o processo se conclua. Porém o movimento de origem não afeta estoque, portanto não se faz necessário informar o lote do produto.  Mensagem apresentada: "O número do lote do movimento de destino deve ser o mesmo do movimento de origem." |
| **Solução/Implementação:** | Criado o motivo de copia por referencia "33 - Venda para Entrega Futura", que não consiste Lote e Serie. |
| **Conversores e Parâmetros:** | Desnecessário. |
