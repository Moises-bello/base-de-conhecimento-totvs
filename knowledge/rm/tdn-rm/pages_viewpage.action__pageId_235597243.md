Lançamento - Exclusão

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financiera |
| **Função:** | Lançamento - Exclusão |
| **Situação/Requisito:** | Ao tentar excluir um lançamento financeiro, através da edição de um lançamento, o sistema exibia a seguinte mensagem de erro: "Object reference not set to an instance of an object." A mensagem é exibida, porém, o lançamento é excluído. |
| **Solução/Implementação:** | Otimização no processo de exclusão de lançamento. Agora o sistema consegue realizar a exclusão do lançamento corretamente. |
