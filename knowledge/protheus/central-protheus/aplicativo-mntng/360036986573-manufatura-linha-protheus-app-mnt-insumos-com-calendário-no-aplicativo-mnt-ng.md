***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16831244235159)***Tempo aproximado para leitura: **00:01:00 min****Dúvida**Porque os insumos com calendário não são sincronizados no aplicativo **MNT NG**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Aplicativo MNT NG - A partir da versão v3.3.0 - 02/08/2023  
  
**Solução**Atualmente o aplicativo não suporta insumos com calendário das versões anteriores a **versão Mnt - v3.3.0**, desta forma as **OS - Ordens de Serviço** somente serão sincronizadas caso não possua insumos que utilizem calendário, campo **Usa Calendário - TL\_USACALE** igual a **N**.Porém os processos de insumos com calendario podem ser utilizados no Aplicativo **MNT NG** a partir da **versão 1.12.2**e versões posteriores.  
Para que o campo **TL\_USACALE** fique disponível no aplicativo, é necessário atualizar para a **versão 1.12.2**, já disponível na **Play Store**.
