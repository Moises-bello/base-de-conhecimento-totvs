Neste menu será possível visualizar todos os abonos lançados para o funcionário independente do período. Serão visualizados todos os abonos lançados para o funcionário. É possível criar filtros para que sejam visualizados somente os registros do período ou conforme a conveniência do usuário. Caso necessite visualizar somente os abonos do período poderá acessar o espelho do funcionário em Anexos do período.  
   
 A tela contém filtros para melhor configuração de visualização sendo que alguns desses filtros são nativos do sistema. São eles:  
**Todos:** Selecionando este filtro, serão demonstrados em tela todos os abonos que existem para o funcionário independente do período ativo.  
**Fora período ativo:** Serão exibidos todos os abonos existentes com exceção dos abonos com data dentro do período ativo.  
**Dentro período ativo:** Serão exibidos somente os abonos existentes com data dentro do período ativo.  
Além dos filtros predefinidos, é possível criar novos filtros de acordo com a necessidade do usuário.   
**Observação**: Abonos que não estão no período ativo não podem ser editados, dessa forma a visualização é feita somente através da visão de Abono funcionário.  
**Parâmetros:**  
Data de início: Data em que inicia o abono Dia da Semana: Dia da semana em que inicia o abono Código de abono: Código de identificação do abono selecionado conforme cadastro de abonos em Automação de Ponto| Cadastro| Cálculo| Abono. Abono: Descrição do abono selecionado conforme cadastro de abonos em Automação de Ponto| Cadastro| Cálculo| Abono. Hora início: Hora em que inicia o abono Hora Fim: Hora em que finaliza o abono Data Término: Data em que finaliza o abono
