# ENVIO DE EMAIL PARA FUNCIONÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção & Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Envio de E-mail para Funcionários* |
| **Situação/Requisito:** | A equipe de Framework criou uma nova exceção para envio de e-mails e solicitou uma adaptação na função de envio de e-mail para funcionários do Labore, para que sejam listados os e-mails que não foram enviados. |
| **Solução/Implementação:** | No envio de e-mail de mensagem livre para funcionários, caso ocorra erro ao tentar enviar o e-mail para um ou mais destinatários, eles serão listados no log do processo. |
| **Chamados relacionados:** | TTXQIE, TTXSAY |
| **Versões/Release:** | *11.82.43* |
