# Objetivo:

---

       O objetivo deste documento é trazer uma visão de como funciona tela de Cadastro de Relatório.

# Como criar:

---

    Para criar um novo Relatório, basta clicar em "+ Novo" e informar os campos abaixo:

***Código:***Informe o código do Relatório, deve ser um código único e será por ele que o Relatório será identificado.

***Descrição:*** Informe uma descrição.

***Observação:*** Campo opcional caso o usuário deseje escrever uma observação.

***Grupo de Relatórios:*** Informe em qual [Grupo de Relatório](http://tdn.totvs.com/x/nyGTEg) o relatório fará parte.

***Exemplo prático abaixo:***

O usuário logado terá acesso aos relatórios do grupo em que ao menos um de seus perfis esteja associado. Caso nenhum dos perfis desse usuário pertença ao grupo, os relatórios desse grupo **não serão exibidos**.

# Funcionalidades:

---

    Após clicar em salvar, clique em "Estrutura" para acessar as funcionalidades do relatório, que serão detalhadas na página [Estrutura](http://tdn.totvs.com/x/qyGTEg).

Para mais detalhes sobre a geração de relatórios, acesse a página [Assistente de geração de relatório](http://tdn.totvs.com/x/XQn9FQ).
