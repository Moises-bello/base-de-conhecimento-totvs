**Dúvida**  
O que deve ser enviado ao suporte para avaliar quando a solicitação de abono não é salva  
  
**Ambiente**  
TOTVS RH (Linha Protheus) - MEU RH - Todas as versões  
  
**Solução**  
Pelo App Meu RH, é possível solicitar **uma requisição de abono para justificar um evento apontado pelo Ponto Eletrônico**, tendo também a possibilidade de **anexar um comprovante para comprovação**.  
  
Por vezes, ao salvar a requisição de abono, **o Meu RH não processa**, impedindo a criação do registro.  
Quando temos esse cenário, é importante **a abertura de um ticket ao Suporte**, com as seguintes **evidências para uma análise mais assertiva:**  
- vídeo ou *prints* do processo realizado até o final;  
- *console.log* gerado na pasta do *appserver*, para saber como coletar, [**clique aqui**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4416746889751)**;**  
- console de depuração do Navegador, para saber como gerar, [**clique aqui**](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4461070844567)**;**  
- compartilhamento das tabelas ACB e AC9, sendo possível verificar no **Configurador**, via rotina **Base de Dados > Dicionário > Base de Dados;**  
- controle de numeração da tabela ACB, sendo possível verificar no **Configurador**, via r**otina Ambiente > Cadastros > Controle de Numeração;**  
- demais evidências para auxílio do Suporte.  
- console.log de todos os serviços do ambiente
