**Dúvida**Ao enviar uma ordem de separação para gerar a nota fiscal de saída via coletor é apresentado a mensagem "Problema Numeração NF "  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - A partir da versão 12.1.25  
  
**Solução**

Para solucionar o problema apresentado é necessário validar o parâmetro **MV\_ACDSERI.**

Para maiores informações consultar o link da documentação abaixo:
