# Relatório Retrospectiva Gerencial Contábil

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório Retrospectiva |
| **Situação/Requisito:** | O relatório Retrospectiva Gerencial Contábil foi parametrizado para exibir a totalização do movimento. Ele está apresentando informações de contas gerenciais, porém ao gerar o relatório Razão não é encontrada nenhuma movimentação para as contas contábeis associadas a elas. |
| **Solução/Implementação:** | O relatório Retrospectiva Gerencial Contábil foi alterado para que, ao selecionar Movimento na opção Totalização, sejam exibidas apenas contas gerenciais associadas as contas contábeis que possuem movimentação. |
