# CANDIDATO - INCLUIR NO PROCESSO DE ADMISSÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | Incluir no Processo de Admissão (Candidato) |
| **Situação/Requisito:** | Foi criado um aviso automático do tipo “Admissão de Candidatos” porém ao efetuar a admissão de um candidato através do RM Gestão de Pessoas, ao executar o aviso automático o e-mail é enviado com uma mensagem inconsistente onde não retorna o nome do candidato e sim do próprio funcionário cadastrado no vitae para receber os e-mails. |
| **Solução/Implementação:** | Implementado uma forma para que seja enviado um aviso quando um candidato for incluido no processo de admissão. |
| **Requisito:** | 115010 |
