**Ocorrência**Error log: InterFunctionCall: cannot find function AVDTFINVAL in AppMap on FI400TITULO(EICFI400.PRW)  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Causa**Incidente ocorre devido não ter a função AVDTFINVAL  
  
**Solução**  
Para solucionar essa ocorrência, realize a aplicação dos pacotes, fonte AVFLUXO.prw com data igual ou superior a 20/04/2018:  
**AVFLUXO**: <https://suporte.totvs.com/portal/p/10098/download?e=727952>
