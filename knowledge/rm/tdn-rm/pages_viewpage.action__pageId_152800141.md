# Objetivo

O objetivo deste documento é ensinar como baixar o Token de aplicações no Fluig.

Primeiramente é necessário acessar o fluig e procurar a aplicação desejada.

|  |
| --- |

Após selecionar a aplicação é necessário clicar na guia configurações.

|  |
| --- |

Na guia configurações clique na opção "Mostrar Token de Configuração". Será exibida uma nova opção "Token de Configuração" informando o token da aplicação.

|  |
| --- |
