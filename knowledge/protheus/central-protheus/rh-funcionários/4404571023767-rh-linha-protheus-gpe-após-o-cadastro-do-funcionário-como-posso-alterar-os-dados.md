**Dúvida**Após o cadastro do funcionário, como posso alterar os dados de Centro de Custo, Departamento e Função?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões.  
  
**Solução**Para alterar o Centro de Custo e o Departamento, será necessário **realizar a transferência do funcionários.** Ambos os campos ficam bloqueados via cadastro de funcionários (SRA), sendo permitida alteração via rotina de transferência para que o sistema alimente todas as tabelas envolvidas.  
Verifique no link a seguir como realizar a transferência de funcionários: [RH - Linha Protheus - GPE - Procedimento para transferências de funcionários](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360017732931-MP-GPE-Procedimento-para-transfer%C3%AAncias-de-funcion%C3%A1rios)

Na **alteração da função** podemos realizar também através do **cadastro de funcionários** ou no menu **histórico salarial**. Ambos menus irão alimentar a tabela SR7 contendo a alteração.  
No processo de alteração de função via **transferência**, será preciso incluir o **campo de função**. Verifique a documentação com passo a passo: [RH - Linha Protheus - GPE - Como alterar a Função durante uma transferência](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360058248473-RH-Linha-Protheus-GPE-Como-alterar-a-Fun%C3%A7%C3%A3o-durante-uma-transfer%C3%AAncia)
