![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22593243972759) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Qual o campo que guarda a informação do Peso Líquido Total na seleção dos itens do Desembaraço?  
  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control –  A partir da versão 12.1.33.  
  
**Solução**

O peso líquido total na seleção dos itens do Desembaraço é gravado no campo "**W6\_PESOTOT**".

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/22593252227223)**

**Importante**:  
Caso precise aumentar o tamanho do campo deve ser feito pelo administrador do sistema via configurador.
