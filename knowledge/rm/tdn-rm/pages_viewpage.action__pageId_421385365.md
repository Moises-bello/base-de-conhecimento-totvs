Esta opção possibilita a cópia de Curvas de Distribuição do projeto escolhido para o projeto aberto, podendo copiar do próprio projeto aberto.

Dados do Projeto de Origem:

**Coligada:** Coligada de origem do projeto a ser copiado.

**Projeto:** Projeto de origem a ser copiado.

**Curvas de Distribuição:** Escolha uma ou mais Curvas de Distribuição que deseja copiar.  
    
 **Observações:**  
 Para que as Curvas de Distribuição fiquem disponíveis para cópia, é preciso ter o item habilitado pelo Usuário Supervisor no menu Cadastros | Segurança | Perfis.

Os filtros criados na visão de Curvas de Distribuição não serão visualizados na cópia de itens.

A cópia de itens deve copiar todas as curvas de distribuição locais de um projeto para outro.
