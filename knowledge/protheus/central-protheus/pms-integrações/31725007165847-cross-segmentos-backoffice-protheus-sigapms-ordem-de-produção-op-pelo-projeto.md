![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31725007157015) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Como gerar ordem de produção (OP) pelo projeto  
  
**Ambiente**Cross Segmentos - Backoffice Protheus - SIGAPMS - Todas as versões  
  
**Solução**Passo a passo: [PMS0013 Gerar ordem de produção através do projeto](https://tdn.totvs.com/x/bYVUE)

Por padrão do sistema é considerado a "Data de necessidade (AFA\_DATPRF)" tanto para geração da OP quanto para a solicitação de compras quando gerado pelo gerenciamento de execução, que gerencia quando o registro deve ser executado ou não.

O conceito é que não há como ter uma ordem de produção antes da necessidade prevista no projeto.
