![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20324298440087) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Como incluir uma faixa intermediaria no **SIGAAGR**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**Foi alterado o programa de cadastro de tabela de classificação para permitir cadastrar uma **faixa intermediária de desconto**. No entanto, foi preservada a validação para não permitir incluir uma faixa que possa ficar no intervalo de outra faixa.
