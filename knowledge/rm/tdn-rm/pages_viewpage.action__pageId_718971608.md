Quaisquer alteração de situação de matrícula na **disciplina** é gerado o log sendo ela pela portal quanto pelo RM.exe. A tabela que armazena este log existe um campo que grava o IP de quem efetua a alteração. Entretanto este campo somente é povoado no **ensino superior**e pelo **portal**. No **ensino básico** ele **não** é preenchido mesmo se a operação de alteração for feita pelo **portal**, para o ensino básico o IP é gravado apenas na tabela de log da matrícula do período letivo.

Será possível observar os números de créditos de cobrança alterados no log nas versões 12.1.2302 e superiores.
