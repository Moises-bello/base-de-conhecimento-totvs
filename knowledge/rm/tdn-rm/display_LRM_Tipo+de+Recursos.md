Aqui são cadastrados todos os tipos de recursos usados para reservas de recursos.  
 Pode-se cadastrar via inserção de no sistema itens como mesas, projetores, dentre outros, para que possa ser utilizado dentro de um período de reserva.  
 Existe a possibilidade de determinar qual item será passível ou não de reserva, sendo que para isso seleciona-se o checkbox "Permite Reserva".
