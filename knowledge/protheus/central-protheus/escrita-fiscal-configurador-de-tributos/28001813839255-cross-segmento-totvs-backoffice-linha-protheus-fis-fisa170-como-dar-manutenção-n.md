![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28001813823767) Tempo aproximado para leitura: 03:00**min** **Dúvida**Como dar manutenção no cadastro de Perfil de produtos de forma automática?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Fiscal - MP12  
  
**Solução**Para dar manutenção de forma automática usar a rotina **FISA166 como ExecAuto (execução automática)**

é uma rotina disponível pelo **Configurador de Tributos (FISA170)** para agrupar todos os produtos que compartilham de características semelhantes a serem enquadradas nas operações fiscais.

Através do sistema o usuário tem a possibilidade de ao cadastrar um novo produto utilizar do **facilitador fiscal** **(MV\_FACAUTO)** para adicionar um novo produto a um **Perfil de Produto** já existente na base quando o parâmetro **MV\_FACAUTO** está ativado.
