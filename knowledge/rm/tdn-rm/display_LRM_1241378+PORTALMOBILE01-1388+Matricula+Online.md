# MATRICULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matricula online no portal do aluno. |
| **Situação/Requisito:** | Quando estava parametrizado para gerar lançamento ao finalizar a matrícula online do aluno, se a parcela já possuísse lançamento gerado e Baixado ou Baixado Parcialmente ou com Boleto registrado, o sistema não permitia que o aluno finalizasse a matrícula pelo portal. |
| **Solução/Implementação:** | Melhoria no processo de matrícula online, criado parâmetros para definir se a matrícula onlise será finalizada mesmo que no momento de regerar a parcela definida nos parâmetros a parcela estiver: Baixada Baixada parcialmente Com boleto registrado |
