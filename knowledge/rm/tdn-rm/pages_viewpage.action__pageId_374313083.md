# Restrição de acesso para o usuário que gravou a Anamnese Especial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário Eletrônico / Anamnese Especial |
| **Situação/Requisito:** | Usuário que registrou a Anamnese Especial não possui permissão para acessar esse mesmo registro caso informe um ou mais usuários que terão acesso ao registro e não inclua o seu próprio usuário. |
| **Solução/Implementação:** | Permitir que o usuário que gravou a Anamnese Especial não tenha restrições de acesso no registro que gravou. |
| **Documento de Referência:** | Ticket #468193 |
