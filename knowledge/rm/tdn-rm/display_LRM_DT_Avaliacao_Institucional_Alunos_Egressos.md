# Avaliação Institucional

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Totvs Educacional |
| **Módulo:** | Educacional |

## Descrição

O processo de associar aluno a uma avaliação institucional (Totvs Educacional | Atividades Acadêmicas | Acadêmico | Avaliação Institucional), permite agora associar um aluno egresso. Na primeira etapa do processo, foi disponibilizada a opção "Egresso", que em seguida listará somente os alunos egressos para serem associados ao objeto avaliado.

Através do portal no menu Avaliação Institucional, os alunos egressos irão visualizar e executar as avaliações associadas.
