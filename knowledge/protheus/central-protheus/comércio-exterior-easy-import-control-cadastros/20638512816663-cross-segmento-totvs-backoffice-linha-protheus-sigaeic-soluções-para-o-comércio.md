**Dúvida**

Quais são as soluções para o Comércio Exterior no Protheus?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) Easy Import Control - A partir da versão 12.1.33  
  
**Solução**

As soluções de Comércio Exterior no Protheus são compostas pelos módulos:

SIGAEIC - Easy Import Control  
SIGAEEC - Easy Export Control  
SIGAEFF - Easy Financing Control  
SIGAEDC - Easy Drawback Control  
SIGAESS - Easy Siscoserv
