| **Dúvida:** | Qual a URL do TSS para envio dos Não-Periódicos? |
| **Resposta:** | A URL para envio da 2ª fase do eSocial (Eventos Não-Periódicos) está disponível para Download no Portal do Cliente conforme link abaixo:  <https://suporte.totvs.com/portal/p/10098/download?e=662882>    A URL deve ser inserida na pasta System e posteriormente deve-se reiniciar o serviço do TSS.  Após este processo, a URL pode ser retirada da pasta System. |
