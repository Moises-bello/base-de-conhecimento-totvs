![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como alterar códigos fixos de forma global?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Acessar **Administração de pessoal | Cadastros globais|  Alteração de códigos fixos**:

Poderá criar perfil de parâmetro:

![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10717134736535)  
  
Selecionar a chapa ou fazer o filtro que melhor atenda a necessidade da empresa:  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10716671505047)

As ações:

* Inclusão: Irá incluir o evento informado na aba de código fixo do cadastro do funcionário

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10716756522647)

* Soma é para utilizar um evento que já exista dentro do código fixo e deseje aumentar:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10716851908119)

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10716942239639)

* Substituição irá substituir o valor que existe dentro do cadastro para o informado no processo:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10716976812055)

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10717020867735)

E a exclusão irá retirar o evento informado do cadastro:

![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10717073803159)

* **Nº de Vezes de Lancto:** Deverá colocar o número de vezes que ele será lançado;
* **Tipo de Lançamento:**Esse campo é o que o sistema valida para realizar o lançamento do código fixo. Selecione se você deseja que este código fixo seja lançado na Folha, Rescisão, 13º Salário ou nas Férias.
