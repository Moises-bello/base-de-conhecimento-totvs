**Dúvida**Como corrigir a ocorrência da **SEFIP 100175** código de pagamento GPS incompatível com as informações indicadas.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Nesse caso deve ser verificado junto a **SEFIP** qual o código de pagamento da GPS deve ser utilizado para empresa de acordo com o manual de preenchimento divulgado pelo INSS.  
Segue abaixo posicionamento do manual da **SEFIP.**

|  |  |  |  |
| --- | --- | --- | --- |
| 100175 | Código de Pagamento GPS incompatível com informações indicadas. | Preencher o campo com código GPS válido  Seguir as regras de determinação de código de pagamento GPS, conforme Manual de Preenchimento divulgado pelo INSS. | Registro 10  Posição: 226 a 229 |
