# Logo da TOTVS aparece momentaneamente após o login.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Novo portal do aluno |
| **Função:** | Logo cabeçalho |
| **Situação/Requisito:** | Após o usuário realizar login, enquanto o portal carregava as informações, a imagem definida como padrão na pasta da FrameHTML era exibida no local da logo da instituição, mesmo existindo uma logo parametrizado no TOTVS Educacional. |
| **Solução/Implementação:** | Foi realizado um ajuste para que a imagem padrão da pasta FrameHTML não apareça no local da logo da instituição, enquanto o portal é carregado. |
