# Rateio de Tomadores

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Rateio de tomadores* |
| **Situação/Requisito:** | O sistema não bloqueia corretamente a inclusão do registro quando o usuário cancela o processo, onde seria informado um total de dias a ser rateado para o tomador, que ultrapassa o total de dias a ratear. |
| **Solução/Implementação:** | Otimizada tela de rateio de tomadores, acerto no cancelamento de registro com informações de valor acima do permitido para os dias a serem rateados |
