# CADASTRO DE MATÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Avaliação e Pesquisa* |
| **Função:** | *Cadastro de matérias* |
| **Situação/Requisito:** | *Foi identificado que o sistema está apresentando erro (travando) na Lookup da Área do cadastro de Matéria ao tentarmos inserir o código de área diferente da forma em que o mesmo foi gravado (maiúsculo/minúsculo).* |
| **Solução/Implementação:** | *Foi identificado que o erro era causado no evento pós lookup da área, no método que gerado código da matéria, foi feito o ajuste no método que gera o próximo código da matéria e após os ajuste o sistema não apresentou mais erro.* |
