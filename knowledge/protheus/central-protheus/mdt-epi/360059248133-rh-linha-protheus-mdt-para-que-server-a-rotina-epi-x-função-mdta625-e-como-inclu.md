**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25627858125079)**Tempo aproximado para leitura: **00:02:00 min****Dúvida**Para que server a rotina **EPI x Função** (MDTA625) e como incluir?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**Essa rotina é responsável por relacionar os **EPI's** (equipamento de proteção individual) necessários a **função**. Para saber como cadastrar um EPI consulte: **[MP - MDT - Como cadastrar um Equipamento de Proteção Individual (EPI)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360048704353-MP-MDT-Como-cadastrar-um-Equipamento-de-Prote%C3%A7%C3%A3o-Individual-EPI-?source=search)**.  
  
Para cadastrar acesse no modulo **SIGAMDT (35)** o caminho: atualizações > PPRA > **EPI x Função** (MDTA625). Escolha a função que vai ser relacionado os EPI necessários e clique em **EPI's**.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360099585953)  
  
Na próxima tela é possível escolher os EPI's que serão necessários para a função, informar se a tipo do EPI é **obrigatório** ou **alternativo**.
