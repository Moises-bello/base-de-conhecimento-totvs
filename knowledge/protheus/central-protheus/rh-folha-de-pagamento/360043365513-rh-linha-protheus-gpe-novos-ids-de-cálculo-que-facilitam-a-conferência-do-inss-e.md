**Dúvida**Novos Ids de Cálculo que Facilitam a Conferência do INSS - **Emenda Constitucional Nº103**  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17

**Solução**Foram incluídos 12 novos identificadores de cálculo, que **não serão obrigatórios**, e que, caso sejam utilizados na criação de verbas, irá gerar o **valor do INSS de cada faixa**, facilitando a conferência. Os novos identificadores são os seguintes:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360058577953)  
  
Após a criação das verbas, **elas serão geradas nos cálculos**, como no exemplo abaixo, no cálculo de férias:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360100494954)  
  
O Sistema vai gerar as verbas com o valor do INSS para cada Faixa, **apenas para demonstração**, o Desconto do INSS continuará sendo apresentado nas verbas com Ids **0064 - Inss Folha, 0065 - Inss Férias, 0232 - Inss Férias Mês Seguinte e 0070 - Inss 13º Salário.**

**Importante: Cadastre as verbas sem nenhuma incidência**, **inclusive para o eSocial.**  
  
Abaixo outros **exemplos**, com a fórmula de cálculo de cada faixa. 

1. Calculo de folha Salario **acima do teto**;

Salario do funcionário: **R$ 6.500,00**

Base INSS => **6.433,57 - Teto**

1º Faixa = 1.100,00 \* 0,075 = Valor do INSS = **R$82,50**  
2º Faixa = 2.203,48 – 1.100,00 => 1.103,48 \* 0,09 = Valor do INSS = **R$99,31**  
3º Faixa = 3.305,22 – 2.203,48 => 1.101,74 \* 0,12 = Valor do INSS = **R$132,20**  
4º Faixa = 6.433,57 – 3.305,22 => 3.128,35 \* 0,14 = Valor do INSS = **R$437,96****Soma de todas as faixas calculadas: R$751,97 - INSS que será descontado**

2. Calculo de folha Salario **dentro do teto**;

Salario do funcionário: **R$ 4.060,00**

Base INSS => **R$ 4.060,00**

1º Faixa = 1.100,00 \* 0,075 = Valor do INSS = **R$82,50**  
2º Faixa = 2.203,48 – 1.100,00 => 1.103,48 \* 0,09 = Valor do INSS = **R$99,31**  
3º Faixa = 3.305,22 – 2.203,48 => 1.101,74 \* 0,12 = Valor do INSS = **R$132,20**  
4º Faixa = 4.060,00 – 3.305,22 => 754,78 \* 0,14 = Valor do INSS = **R$105,66****Soma de todas as faixas calculadas: R$419,67 - INSS que será descontado**
