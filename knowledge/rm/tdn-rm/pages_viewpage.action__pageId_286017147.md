# RETORNO BANCÁRIO COM NOSSO NÚMERO REPETIDO EM DIFERENTES CONVÊNIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeiro. |
| **Função:** | Retorno bancário. |
| **Situação/Requisito:** | Em retorno bancário de cobrança não registrada ou CNAB240 no qual alguma das linhas possui o campo nosso número com um valor existente em mais de um boleto de diferentes filiais. Sistema emitia mensagem de validação indicando que o nosso número está repetido. |
| **Solução/Implementação:** | Caso a filial esteja informada na tela de configuração de execução do processo de retorno, na pesquisa pelo nosso número, será buscado o boleto dessa filial. |
