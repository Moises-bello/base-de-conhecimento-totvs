**1 -** Criando um relatório para utilização no Tipo de Atendimento.

Neste exemplo será construído um relatório simples com a utilização de consulta SQL.

**1.1** - Na aba gestão Visão de Dados - Criar uma Consulta SQL

* A consulta deve possuir as colunas CODCOLIGADA, CODLOCAL, CODATENDIMENTO, para que o processo possa aplicar o filtro no relatório no momento de criação do atendimento.

2 - Criando Relatório

2.1 - Criando o Relatório.  
       **Dica:** Após salvar o registro. Dois cliques no registro para que abra a edição de estrutura do relatório.

2.1 - Incluindo fonte de dados (Outras fontes de dados podem ser utilizadas esta foi escolhida como exemplo)

2.2 - Incluindo campos no Relatório.

3 - Ao editar ou incluir um tipo de atendimento na Aba Relatório de Abertura informar o código do relatório
