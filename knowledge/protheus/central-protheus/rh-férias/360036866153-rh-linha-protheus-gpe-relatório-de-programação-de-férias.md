**Dúvida**Como emitir o relatório de programação de férias?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para executar a impressão do relatório de férias, siga os passos abaixo:

1. Entre em **Relatórios > Férias > Programação de Férias**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10633408275735)  
  
2. Entre em **Outras Ações >Parâmetros**![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10631051549719)  
  
3. Preencha os parâmetros com as informações solicitadas conforme a necessidade.  
  
**Filial**:  Informe intervalo de filiais que deseja considerar para impressão do relatório;

**Centro de Custo:** Informe intervalo de Centros de Custo que deseja considerar para impressão do relatório;

**Matricula:** Informe intervalo de matrículas que deseja considerar para impressão do relatório;

**Nome:**  Informe intervalo de nomes de funcionários que deseja considerar para impressão do relatório;

**Situações**: Informe ou Selecione as situações dos funcionários para filtro dos dados;

**Categorias**: Informe ou selecione uma categoria para funcionários para o filtro dos dados;

**C.C em outra pagina:**  Informe se deseja que o relatório seja impresso com quebra de página por centro de custo;

**Tipo de Férias:** Informe o Tipo de Férias que deseja imprimir, sendo programadas, não programadas ou ambas;

**Programadas DE / ATE:** caso queira a impressão para as férias que estão programadas em controle dias de direito, informe a partir de qual data deseja listar o início do período de férias programadas;

**Imprime períodos:** Informe quantos períodos de férias deseja demonstrar para o período aquisitivo (Conforme reforma trabalhista, é possível dividir as férias em até 3 períodos)

**Seleção de processos:**  Selecione a lista de processos que deseja executar;

**Tipo de Relatório:** Informe o relatório a ser impresso: 1- Relação de Programação de Férias : 2- Relação de Programação de Recesso;

**Data Limite Máximo e Ideal:** Informe a quantidade de dias para o limite máximo do vencimento das férias, este valor será considerado para o calculo da data no campo Dt. Limite Máxima do relatório, caso este pergunte esteja vazio, serão considerados 45 dias;

**Filtrar período:** Informe se deseja exibir apenas o 1º período aquisitivo em aberto;

**Filtrar Data :**  Informe se deseja exibir apenas as programações iniciadas dentro das datas parametrizadas nos parâmetros;

**Data Referencia:**  Informe a data a ser usada para calcular a projeção de dias de férias vencidos e proporcionais;

**Turno:** Informe o turno de trabalho;

**Obs:** caso coloque a data que não seja dentro do período atual, o sistema já projeta os avos que o funcionário terá direito até o período mencionado.
