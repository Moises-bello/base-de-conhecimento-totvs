# REMUNERAÇÃO BASE DE PROFESSOR CONSIDERA ATESTADO MÉDICO NA PROPORCIONALIZAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Remuneração Base de Professor |
| **Situação/Requisito:** | No cálculo da Remuneração Base de Professor, quando está marcada a opção "No caso de valor proporcionalizado, efetuar engenharia reversa para obter valor integral" no Sindicato, a proporcionalização dos valores está considerando na divisão os 15 dias de atestado médico, onde deveria ser utilizado somente os dias efetivamente trabalhados pelo funcionário. |
| **Solução/Implementação:** | Ajuste na proporcionalização da engenharia reversa nos meses de afastamento, para considerar na divisão somente os dias efetivamente trabalhados pelo funcionário. |
| **Tickets relacionados:** | MRH-8623 |
