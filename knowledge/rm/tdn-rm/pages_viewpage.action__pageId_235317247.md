# GERAR LANÇAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Gerar lançamento* |
| **Situação/Requisito:** | *Na geração de lançamento, quando o sistema está parametrizado para buscar a conta caixa do responsável financeiro e a parcela possui bolsa de crédito com outro sacado, o lançamento do outro sacado trazia a conta caixa do cliente/fornecedor do aluno e o correto seria trazer a conta caixa do outro sacado.* |
| **Solução/Implementação:** | Alterado a geração de lançamento, quando o sistema está parametrizado para buscar a conta caixa do responsável financeiro e a parcela possui bolsa de crédito com outro sacado, o lançamento do outro sacado terá a conta caixa cadastrada no cliente/fornecedor correspondente à bolsa de crédito. |
