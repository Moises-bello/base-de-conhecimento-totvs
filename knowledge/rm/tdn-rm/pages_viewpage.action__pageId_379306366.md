# Código de retorno do banco

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Cadastro de lançamentos |
| **Situação/Requisito:** | Na versão 12.1.13 existia o campo de Cód. Retorno Bancário, no qual era preenchido no momento da importação de arquivo de retorno com seus devidos códigos. Nas versões atuais (12.1.17 e 12.1.18) tal campo não existe nem no lançamento financeiro, nem no boleto. O cliente trabalhava com este controle e deseja que o campo retorne. |
| **Solução/Implementação:** | O campo "Cód. Retorno do Banco" está dispnível na aba Integração Bancária, existente no cadastro de lançamentos. Vale ressaltar que ele será exibido para lançamentos a pagar e a receber. |
