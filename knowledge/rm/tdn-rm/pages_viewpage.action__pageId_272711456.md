# TRANSFERÊNCIA DE FUNCIONÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Transferência de Funcionários |
| **Situação/Requisito:** | Ao transferir um funcionário, a chapa antiga fica como demitida e permanece no último contexto do portal. Assim quando o funcionário faz o acesso online recebe a mensagem de que está demitido e tem que efetuar a troca manual no contexto para a nova chapa. |
| **Solução/Implementação:** | Alterar o processo de transferência para atualizar o último contexto do portal com a nova chapa do funcionário |
