**Pasta Identificação** **- Efetivar Transferência com Alteração de Dados Funcionais**

Na pasta Identificação poderão ser visualizados/alterados os seguintes campos:

**Dados atuais do funcionário** **Filial de origem -**Este campo não é editável e apresentará a função atual do funcionário selecionado na requisição.

**Seção de origem -** Este campo não é editável e apresentará a seção atual do funcionário selecionado na requisição.

**Função de origem -** Este campo não é editável e apresentará a função atual do funcionário selecionado na requisição.

**Nível Salarial de Origem -** Este campo não é editável e apresentará o nível salarial atual do funcionário selecionado na requisição.

**Faixa Salarial de Origem -** Este campo não é editável e apresentará a faixa salarial atual do funcionário selecionado na requisição.

**Salário de origem -** Este campo não é editável e apresentará o salário atual do funcionário selecionado na requisição.

**Dados Propostos** **Filial -** Este campo apresentará a filial proposta para alteração dos dados do funcionário selecionado na requisição. Este campo não poderá ser alterado.

**Seção -** Este campo apresentará a seção proposta para alteração dos dados do funcionário selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado, esse campo poderá ser alterado.

**Função -** Este campo apresentará a função proposta para alteração dos dados do funcionário selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado, esse campo poderá ser alterado.

**Nível e Faixa Salarial -** Se o parâmetro "Considerar os salários das tabelas salariais" estiver marcado serão apresentados nesses campos o nível e a faixa salarial proposta para alteração dos dados do funcionário selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado esse campo poderá ser alterado. Para saber como funciona a vinculação de tabelas acesse: Gerência de RH | Cargos e Salários | Tabelas Salariais | Vinculação.

**Salário/ Percentual** Serão apresentados nesses campos o salário e o percentual de alteração salarial proposto para o funcionário selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado e o parâmetro "Não permitir alterar diretamente o salário" estiver desmarcado esse campo poderá ser alterado.

**Motivo da mudança de seção -** Este campo apresentará o motivo da mudança de seção selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado e a seção proposta for diferente da seção atual do funcionário, esse campo poderá ser alterado.

**Motivo de mudança de função -** Este campo apresentará o motivo da mudança de função selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado e a função proposta for diferente da função atual do funcionário, esse campo poderá ser alterado.

**Motivo de mudança salarial -** Este campo apresentará o motivo da mudança salarial selecionado na requisição. Se o parâmetro "Permitir alterar dados da requisição vinculada" estiver marcado e o salário proposto for diferente do salário atual do funcionário, esse campo poderá ser alterado.

**Observação**

Se os dados provenientes da requisição forem alterados, o usuário deverá fornecer uma justificativa e o sistema irá gerar um novo parecer para a requisição, no qual constará o registro do usuário logado, a justificativa fornecida e as alterações realizadas. Além disso, será enviado e-mail para o requisitante, o Gestor do RH e todos os participantes do fluxo comunicando a situação da requisição.
