# Geração de Lançamento Financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Geração de Lançamento Financeiro |
| **Situação/Requisito:** | Ao gerar lançamentos dos alunos em lote, através da função "Financeiro" no menu "Financeiro/Contábil". Ao executar o procedimento com mais de 1000 alunos exibe a mensagem de não conformidade "ORA -01795" |
| **Solução/Implementação:** | Melhoria no processo de geração de lançamento financeiro para que não seja apresentada nenhuma não conformidade quando é selecionado uma grande quantidade de alunos que podem ultrapassar mais de 1000 parcelas. |
