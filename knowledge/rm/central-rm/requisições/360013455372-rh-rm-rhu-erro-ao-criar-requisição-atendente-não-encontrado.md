**Dúvida**  
Ao salvar uma requisição no portal aparece a mensagem de erro *"Erro na integração com o RM Agilis: Atendente não encontrado. Coligada X - Usuario XXXXXXXXXXXXXXXX at RM.Rhu.Facade.RhuAtendenteAgilis.GetDadosAtendente(Int32 codColigada, StringcodUsuario)".*

O que fazer?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - A partir da versão 11.82  
  
**Solução**

Para criar o atendente no Agilis, acesse o menu Configurações > Criar Atendente no RM Agilis.
