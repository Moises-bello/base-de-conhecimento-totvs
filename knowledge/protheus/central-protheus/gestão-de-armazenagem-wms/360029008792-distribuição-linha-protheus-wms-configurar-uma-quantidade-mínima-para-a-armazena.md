***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34835331563671)***Tempo aproximado para leitura: **00:00:42 min****Dúvida**É possível configurar uma quantidade mínima para a armazenagem de um produto?  
  
**Ambiente****TOTVS Distribuição** - **TOTVS WMS** (Linha Protheus) - Gestão de Armazenagem (**WMS**) - Todas as versões  
  
**Solução**Sim, é possível configurar uma quantidade mínima para armazenagem de um determinado produto nas estruturas do armazém.  
  
Para isto, é necessário configurar para o produto o campo **End. Mínimo** - **DC3\_ENDMIN**, do cadastro **Sequência Abastecimento - WMSA030**.   
O Endereçamento Mínimo funciona de forma semelhante à funcionalidade já existente no processo de saída, que é a separação mínima, sendo possível configurá-lo a nível de estrutura física.
