**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34626521905559) Tempo aproximado para leitura: 00:01:30 min****Dúvida**Por que o cálculo de rescisão apresenta o ID 1693-Insalubridade Férias Proporcionais?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.25.  
  
**Solução**

O ID 1693-Insalubridade férias proporcionais se trata da insalubridade referente a verba indenizatória férias proporcionais, sendo que a partir da versão 12.1.25, foram criados novos identificadores quanto a cálculo de adicionais em rescisão (todos adicionais são referentes as indenizações em rescisão).

**Cadastro ID 1693.**
