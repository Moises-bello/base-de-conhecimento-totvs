# COLUNAS PI + R NA VISÃO DE PERÍODOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Períodos do Contrato |
| **Situação/Requisito:** | Colunas com informação do valor medido a preço inicial e valor medido de reajuste. |
| **Solução/Implementação:** | Adicionada as colunas de valor medido a preço inicial e valor medido de reajuste na visão de períodos de contratos. Estas colunas são exibidas quando o parâmetro de projeto "Utilizar Valor do Reajuste na Medição (PI + R)" estiver marcado.  Adicionado dois layouts de preferências na visão de períodos de contrato. Sendo um para ser utilizados em projetos que usa PI + R e outro em projeto que não usa:   * Layout "Com PI + R"; * Layout "Sem PI + R".   A partir da escolha de um dos layouts em um projeto, o sistema passa a alternar automaticamente entre um e outro de acordo com o parâmetro mencionado acima. Isto não impede o usuário de utilizar um layout customizado. |
