# Filtro de BPA por Unidade de Atendimento

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Lançamentos de Procedimentos BPA | |
| **Chamados Relacionados** | TTOSQ2 |
| **Requisito (ISSUE):** | PCREQ-10854 |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | MSSQL®, Oracle® |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

 Esta melhoria possibilita a criação de filtros no BPA por **id** ou **descrição** da unidade de atendimento.

## Procedimento para Utilização

1. Acesse o menu **Faturamento/Faturamento SUS/Lançamento de Procedimentos BPA**.
2. Clique em **Novo**.
3. Realize o filtro por Unidade de Atendimento.
4. Ou realize o filtro por Código da Unidade de Atendimento.
5. Clique em **OK**.
