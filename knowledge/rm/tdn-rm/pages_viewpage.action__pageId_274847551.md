# Integrar Aquisições de Compras

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Totvs Gestão Patrimonial. |
| **Função:** | Integrar Aquisições de Compras. |
| **Situação/Requisito:** | Ao realizar o processo de integração de aquisição com compras, onde, um movimento possui dois itens, um item está sem o grupo de contas informado na aba integração, e o outro está correto, ao marca a opção ( Considera a falta do Grupo de patrimônios como erro) sistema integra o item correto, e deixa o incorreto. |
| **Solução/Implementação:** | Implementar a validação do parâmetro de tela "Considera a falta do Grupo de patrimônios como erro", para que nenhum item do movimento seja integrado quando algum não tem o grupo de patrimônio cadastrado, conforme documentação em: <http://wikihelp.totvs.com.br/WikiHelp/PAT/PAT.integraAquisicaoCompra.aspx> . |
| **Conversores e Parâmetros:** | parâmetro de tela "Considera a falta do Grupo de patrimônios como erro". |
