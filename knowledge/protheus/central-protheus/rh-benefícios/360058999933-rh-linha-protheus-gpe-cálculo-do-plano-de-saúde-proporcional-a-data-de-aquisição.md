**Dúvida**É possível fazer o cálculo do Plano de Saúde de forma proporcional a data de aquisição?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.1.2210  
  
**Solução**Foram criados os campos "Data Inicio Cálculo" para o titular, dependente e agregados, que poderão ser preenchidos com datas distintas e, caso esteja preenchido com o mesmo mês/ano do cálculo, **este será feito de forma proporcional, independente do tipo de plano utilizado.** Para que o cálculo seja feito de forma integral, basta que os campos continuem vazios.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/21022926685719)

Exemplo de cálculo para o plano iniciado em 20/06/2023 (conforme imagem acima)

Tabela S008:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/21022858165527)

**Titular:** R$ 130,00 [Valor titular] / 30 [Dias mês] = R$ 4,33 [Valor dia] x 11 [Dias proporcionais] = R$ 47,67 x 10% [% Desconto titular] = **R$ 4,77**

**Dependente:** R$ 100,00 [Valor dependente] / 30 [Dias mês] = R$ 3,33 [Valor dia] x 11 [Dias proporcionais] = R$ 36,67 x 10% [% Desconto dependente] = **R$ 3,67**

**Agregado:** R$ 100,00 [Valor agregado] / 30 [Dias mês] = R$ 3,33 [Valor dia] x 11 [Dias proporcionais] = R$ 36,67 x 10% [% Desconto agregado] = **R$ 3,67**
