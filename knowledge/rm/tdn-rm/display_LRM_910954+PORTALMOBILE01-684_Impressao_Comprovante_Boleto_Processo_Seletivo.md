# PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Processo Seletivo |
| **Função:** | Portal > Nova Inscrição > Imprimir comprovante de inscrição |
| **Situação/Requisito:** | Foi identificado que após realizar a inscrição do candidato em umprocesso seletivo, os dados de comprovante do mesmo estava considerando apenas o "Número da Inscrição" para recuperar o relatório de comprovante, desta forma exibindo as informações incorretamente. |
| **Solução/Implementação:** | Realizado ajuste na tela de impressão de relatório e comprovante/boleto para considerar além do número da inscrição o código da coligada e o id do processo seletivo. |
