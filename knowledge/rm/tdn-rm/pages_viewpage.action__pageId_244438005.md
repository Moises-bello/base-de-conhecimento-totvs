# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de lançamentos* |
| **Situação/Requisito:** | *Ao gerar lançamentos de bolsa de crédito, a construção da referência entre o lançamento do aluno e o lançamento de bolsa ocorre somente após a inclusão dos lançamentos. Assim, caso os lançamentos sejam do tipo contábil e o evento utilize de fórmula para um tratamento diferente para o lançamento de bolsa o sistema não será capaz de identificar o lançamento de bolsa no momento da contabilização de inclusão.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de lançamentos financeiros, permitindo ao sistema, realizar a contabilização de inclusão de um lançamento de bolsa de crédito caso se utilize fórmula que precise da referência entre o lançamento do aluno e o lançamento de bolsa.* |
