Para visualizar o processo de Rateio de Produtos acesse:  Totvs Obras e Projetos/Planejamento/Geração de Pedidos.

Selecione o pedido no qual deseja realizar o rateio e acesse: Processos/Rateio de Produtos.

**Filtro:**  
Para realizar o filtro para rateio executar os seguintes passos:  
Selecionar um insumo que está contido na requisição;   
Em seguida, selecionar as tarefas que o sistema irá listar para seleção, as quais contém o insumo selecionado anteriormente;  
Selecionar os períodos e avançar.

**Rateio de Um Item:**  
Com a tela para rateio aberta executar os seguintes passos:  
Selecionar o Item desejado;   
Informar o produto para rateio, na lista de Produtos para o Insumo;   
Informar a quantidade/Percentual, em seguida acionar o botão ">" para ratear um produto com a quantidade/Percentual informado e o botão ">>" para rateio de todos os produtos selecionados com a mesma quantidade/Percentual.  
Para aplicação do Rateio, acionar o botão "Aplicar" para efetuar o mesmo.

**Rateio de Vários Itens:**  
Com a tela para rateio aberta executar os seguintes passos:  
Selecionar os Itens desejados;   
Informar os produtos para rateio, na lista de Produtos para o Insumo;  
Informar o percentual desejado da necessidade do insumo para cada produto selecionado na lista de produtos do insumo, em seguida acionar o botão ">" para ratear os produtos selecionados com o percentual informado, ou acionar o botão ">>" para enviar todos os produtos da lista de produtos do insumo com o mesmo percentual, acionar o botão "Aplicar" para efetuar o Rateio.

**Exemplo:**  
Para o período 1 e Tarefa 1 tenho um planejamento de 50 litros de tinta.  
Suponha que essa tinha esteja vinculada aos seguintes produtos:  
Tinta acrílica azul   
Tinta acrílica verde  
Tinta acrílica vermelha  
Posso realizar o rateio entre esses produtos vinculados, pedido uma quantidade de cada opção de produto vinculado, desde que essa quantidade não ultrapasse a necessidade.  
Tinta acrílica azul = 10 litros  
Tinta acrílica verde = 20 litros  
Tinta acrílica vermelha = 20 litros  
Total = 50 litros

**Observação:**  
Caso o usuário tenha permissão de Associar Produto ao Insumo, será exibido um ícone onde o usuário poderá realizar a vinculação de produtos ao insumo atual, os quais serão exibidos na lista de Produtos do Insumo para que assim possam ser rateados.
