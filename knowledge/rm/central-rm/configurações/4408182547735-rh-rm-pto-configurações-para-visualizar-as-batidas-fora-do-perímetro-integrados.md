![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19409011321367) Tempo aproximado para leitura: **00:00:12 min****Dúvida**Como parametrizar o sistema para trabalhar com recurso de batidas fora do perímetro?  
  
**Ambiente**RH - RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 12.1.31  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos contidos no link [batidas fora do perímetro](https://tdn.totvs.com/pages/viewpage.action?pageId=563951308).  
  
**Importante**  
Este recurso é para permitir a visualização das batidas fora do perímetro realizadas dentro do período atual e também a alteração da situação das mesmas. Funcionalidade disponível apenas na integração Automação de Ponto x Carol.
