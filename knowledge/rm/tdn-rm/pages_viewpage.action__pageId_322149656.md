# FOLHA ANALITICA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | Calculo das bases de FGTS SEFIP folha normal e 13º Salário. |
| **Situação/Requisito:** | Ao gerar folha analítica para funcionários que tiveram rescisão calculada pelo tipo “V” Comum Acordo, o sistema não deve informar valores para base de FGTS SEFIP, e Base FGTS SEFIP 13º. Visto que os mesmos foram recolhidos na guia GRRF. |
| **Solução/Implementação:** | Foi otimizado o calculo para Base de FGTS SEFIP e Base FGTS SEFIP 13º para não calcular valores na Folha Analítica quando Rescisão de comum acordo. Assim como já era o calculo para rescisões: Por iniciativa do Empregador sem justa causa, Termino de contrato de trabalho e por Culpa reciproca. |
