Possibilitar ao usuário visualizar um resumo/detalhamento dos lançamentos do(s) título(s) selecionado(s).

Esta tela será comum após selecionar quaisquer tipos de pagamentos disponíveis.

   

Após o usuário selecionar o tipo de pagamento a ser realizado, a tela de resumo dos lançamentos será exibida para o usuário conforme o boleto selecionado no extrato financeiro.

Se o usuário for o responsável pelos alunos, ele terá permissão para visualização dos dados dos alunos.

Caso o acesso esteja sendo feito por um aluno, ele somente visualizará os seus dados.

| Acesso com responsável financeiro | Acesso com aluno |
| --- | --- |
|  |  |

Boletos Agrupados

A partir dos patches **12.1.2310.176 e 12.1.2402.114 ou superiores**  na visualização do resumo de pagamento de boleto agrupado, o aluno irá visualizar somente os valores correspondentes aos valores que compõem o boleto relacionado à ele. Desta forma, os valores que compõem o boleto pertencentes de outro aluno serão exibidos com a informação “**OUTROS ALUNOS**”. 

Vale ressaltar que, o responsável financeiro continuará visualizar todos os detalhamentos dos valores que compõem o boleto agrupado.  

## **TABELAS UTILIZADAS**

* FBOLETO - Tabela de boletos
* FLANBOLETO - Tabela de lançamentos de boletos
