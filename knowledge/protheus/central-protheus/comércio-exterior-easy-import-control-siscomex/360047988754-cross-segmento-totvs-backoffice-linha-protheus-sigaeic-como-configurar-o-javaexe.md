**Dúvida**Como configurar o JAVA.EXE na Integração Siscomex?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**1. Acessar o módulo SIGAEIC em Atualizações \ Tabelas Siscomex \ Integ Siscomex Web (EICDI100).  
2. Posicione em Gerados da Decl.de Importação e selecione a ações Configurações:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360071912693/mceclip0.png)

3. É necessário no campo "Diretório local onde encontra-se o executável 'Java.exe'. " a pasta onde encontra-se o arquivo java.exe:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360071915173/mceclip1.png)
