**Dúvida**  
Como realizar compensação de títulos com data de emissão futura?  
  
**Ambiente**  
Cross Segmento - BackOffice Linha Protheus – Financeiro – FINA460 – A partir da versão 12.1.17.  
  
**Solução**  
A opção **"Títulos com Emissão Futura"** na rotina **FINA450** serve para a seguinte situação:  
1) Título a receber gerado com data de emissão dia 01/02/2021.  
2) Título a pagar gerado com data de emissão dia 23/02/2021.  
3) Realizar compensação entre carteiras com data menor que 23/02/2021.

Para essa situação, será necessário marcar a opção **"Títulos com Emissão Futura",** para o sistema trazer os títulos com data maior que a data logada do sistema.
