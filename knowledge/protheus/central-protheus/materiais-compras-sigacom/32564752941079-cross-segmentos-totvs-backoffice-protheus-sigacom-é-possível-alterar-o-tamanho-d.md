![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32564738550807) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**É possível alterar o tamanho do campo F1\_MENNOTA?

**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus compras - Todas as versões

**Solução**Sim é permitido a alteração do campo **F1\_MENNOTA** no Configurador do sistema, com tamanho máximo de até **254 caracteres.**

Para realizar o ajuste do tamanho do campo siga os passos abaixo:

1. Acesse o configurador do sistema **>**Base de Dados**>**Dicionário**>**Base de Dados.

2. Localize a Tabela SF1 e clique em Editar conforme print abaixo: ![](https://centraldeatendimento.totvs.com/hc/article_attachments/32564752920983)

3. Na próxima tela ,pesquise na Lupa pelo campo F1\_MENNOTA e clique em Editar.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/32564752921495)

4. Ajuste o Tamanho do Campo , o sistema permite o aumento do Tamanho do campo para até 254 Caracteres.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/32564738554263)

5. Salve o Ajuste realizado.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/32564752923159)
