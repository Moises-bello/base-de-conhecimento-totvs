**Plano de Aula**

---

   
O professor consegue através desta página acessar os planos de aula cadastrados para suas turmas. O primeiro passo é selecionar a turma/disciplina, a etapa, as datas de inicio e fim e os planos de aula serão exibidos.   
Opções disponíveis para o professor executar referente as aulas de cada plano de aula disponível:

* Copiar conteúdo previsto para realizado
* Copiar conteúdo para outra turma/disciplina
* Copiar conteúdo realizado para a próxima aula
* Associar arquivo às aulas
* Desassociar arquivos das aulas
