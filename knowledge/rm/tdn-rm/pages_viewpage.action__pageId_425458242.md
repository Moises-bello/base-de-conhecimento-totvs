Por este  menu é possível visualizar cada uma das questões respondidas na prova executada pelo candidato.

**Atenção**

O sistema permite que uma ou mais questões apresentadas no histórico possam ser excluídas. Porém, pelo menos uma questão deverá ser mantida no histórico de execução.

Para que o usuário não tenha acesso à exclusão do histórico, é necessário que se retire a permissão de exclusão de Ranking, dentro da aba Acesso a Menus, da tela de cadastro do perfil do usuário.
