# 3353063 - DSAUGHASSIST-1314 - Problema no Status de senha na aba triagem painel de eletivos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Totvs Gestão Hospitalar |
| **Função:** | Triagem através do painel de eletivos |
| **Situação/Requisito:** | Ao iniciar e cancelar uma triagem para um atendimento já cadastrado, não altera o status do atendimento para triagem iniciada |
| **Solução/Implementação:** | Independente do momento, quando inicia uma triagem grava o log de triagem iniciada e altera o status do atendimento |

| **Requisito:** | DSAUGHASSIST-1314 |
