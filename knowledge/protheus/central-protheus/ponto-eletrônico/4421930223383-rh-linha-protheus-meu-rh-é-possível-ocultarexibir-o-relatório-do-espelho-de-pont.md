**Dúvida**MEU RH - É possível ocultar/exibir o relatório do espelho de ponto conforme o perfil do usuário? **Ambiente**TOTVS RH (Linha Protheus) - Meu RH – todas as versões  
 **Solução**De acordo com o perfil do usuário é possível ocultar ou exibir o relatório do espelho de pontoForam Implementadas duas novas permissões para que seja possível definir:

1 - Se o funcionário poderá realizar o download/compartilhamento do seu próprio espelho de ponto

![](https://tdn.totvs.com/download/attachments/656340356/image2021-12-20_18-54-41.png?version=1&modificationDate=1640037650807&api=v2)

2 - Se o gestor poderá realizar o download/compartilhamento do espelho de ponto do seu subordinado.

![](https://tdn.totvs.com/download/attachments/656340356/image2021-12-20_18-54-21.png?version=1&modificationDate=1640037650863&api=v2)  
  
**Importante:**

Para que as permissões sejam criadas, é necessário acessar a rotina de permissões do Meu RH.

Após o acesso, as permissões serão criadas automaticamente com o conteúdo habilitado (SIM)  
  
Segue abaixo exemplo de como será apresentado na rotina **"Permissões MEU RH"** e de como será apresentado no **MEU RH** caso esteja **habilitado como "Sim":**  
**Módulo 18- Terminal de consulta do funcionário - Atualizações - Configurações - Usuários - Permissões MEU RH**Acessando as permissões do usuário do portal criado para um usuário comum e um usuário do portal para o usuário gestor  
  
![Permiss_es_MEU_RH.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4421908394647)  
  
Acessando o MEU RH com um usuário comum:  
  
![Usu_rio_comum.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4421929193751)  
  
Acessando o MEU RH com um usuário gestor:  
  
![usu_rio_gestor.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4421909568791)  
  
Caso a permissão **não** esteja habilitada, o botão **"Download"** no espelho de ponto não será apresentado:  
  
![permiss_o_desabilitada.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/4421918598807)  
  
Para o correto funcionamento desta melhoria, é necessário atualizar os arquivos do Portal MEU RH, disponíveis através deste link: [**Atualizando os arquivos**](https://tdn.totvs.com/display/NPR/Passo+1%3A+Atualizando+os+arquivos)
