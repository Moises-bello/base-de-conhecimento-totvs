No aplicativo Meu Coletor de Dados versão 3.1.10, ao criar um Mestre de Inventário por Endereço, o campo de bipagem do endereço não é habilitado; o endereço é preenchido automaticamente para o produto. Já no Mestre por Produto, a bipagem do endereço funciona normalmente.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37072428589719) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
Quando cria um mestre de inventário por endereço, não está habilitando a bipagem do campo de endereço, como corrigir?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.

**Solução**

O aplicativo Meu Coletor de Dados com a nova versão 3.1.10. Quando se faz um Mestre de Inventário por Endereço, não está habilitando o campo de bipagem no campo de endereço.

Com nova versão do aplicativo  não será habilitado a bipagem do campo endereço, o mesmo será   apresentado automaticamente o endereço no campo daquele determinado produto.
