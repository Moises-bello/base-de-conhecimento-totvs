# GERAÇÃO SEFIP

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Geração de Sefip* |
| **Situação/Requisito:** | *Cadastro uma rescisão tipo 5 para outra base de dados e o funcionário não é levado para a Sefip do mês.*  *Ao gerar a Sefip deverá ser criada uma linha de registro para essa funcionária com a informação de N2, porém percebemos que para uma base específica o sefip não gera para funcionários transferidos para outra base de dados. (N2)* |
| **Solução/Implementação:** | *Inclusão dos funcionários transferidos (tipo 5) para o tipo recolhimento 155.* |
