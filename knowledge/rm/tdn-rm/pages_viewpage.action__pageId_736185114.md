Na **Etapa 1 - Registradora Recebíveis**, é possível de se habilitar o Parâmetro de **Integração** com a **Registradora de Recebíveis:**

Após habilitar este parâmetro informe as seguintes opções:

**API da Registradora de Recebíveis (Ex.: [https://imobiliario-homolog.cerc.inf.br/](https://imobiliario-homolog.cerc.inf.br/ "Follow link")):** Informe a *URL* da *API* que a Registradora de Recebíveis disponibiliza, para de que o sistema possa realizar a integração dos dados;

**API Token da Registradora de Recebíveis: (EX.: <http://ap-homolog.cerc.inf.br/oauth/token):>** Informe a *URL* da *API de Token* que a Registradora de Recebíveis disponibiliza, para validar a conexão com a Registradora;

**ClienteId API:** Informe o *Usuário* que será utilizado pelo sistema para realizar a integração dos dados com a Registradora de Recebíveis; e

**ClienteSecret API:** Informe a *Senha* do Usuário acima, para que o sistema para realizar a integração dos dados com a Registradora de Recebíveis.
