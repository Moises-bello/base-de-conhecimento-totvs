![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24726351825943) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**É possível importar arquivos do sistema SOC (conexão por API, importação de arquivos) para o Medicina e Segurança do Trabalho?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões}  
  
**Solução**O módulo Medicina e Segurança do Trabalho não tem a funcionalidade de importar arquivos, é necessário consultar analista in loco para orientações.   
  
O que se refere aos eventos SST para o eSocial, se o software disponibilizar o arquivo XML é possível efetuar a importação através do módulo TAF, consulte a documentação:  
[Como importar arquivos XML no TAF](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360027012291-Automa%C3%A7%C3%A3o-Fiscal-INTEGRA%C3%87%C3%83O-Como-importar-arquivos-XML-no-TAF?source=search)
