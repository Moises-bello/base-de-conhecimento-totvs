# Dados opcionais na baixa de lançamento financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Dados Opcionais na Baixa de Lançamento Financeiro |
| **Situação/Requisito:** | Os campos datas opcionais, campos alfas opcionais, filial, departamento e centro de custo na aba de dados opcionais não ficam visíveis na tela da baixa de lançamento financeiro |
| **Solução/Implementação:** | Liberação dos campos abaixo na aba de dados opcionais na tela de baixa de lançamento financeiro:   * Datas Opcionais; * Campos Alfas Opcionais; * Filial; * Departamento; * Centro de Custo   Os campos também serão liberados no histórico de alteração de lançamentos |

| **Chamados relacionados:** | N/A |
