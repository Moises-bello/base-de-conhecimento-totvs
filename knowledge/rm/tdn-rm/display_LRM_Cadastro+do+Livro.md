O cadastro do Livro é um recurso que estará disponibilizado apenas para o nível de ensino Superior.  
O menu fica localizado em: Atividades acadêmicas > Certificados / Diplomas / Solenidade > Livro

Todo Diploma é registrado em um livro físico que fica de posse da [IES](http://pt.wikipedia.org/wiki/IES). Este é um documento formal que é regulamentado pelo MEC. No TOTVS Educacional, faz-se um cadastro deste livro para auxiliar o preenchimento e também o armazenamento do mesmo. Nele será definida a regra de numeração do registro do livro e de detalhes do mesmo.

Informações disponíveis:   
   
O cadastro baseia-se nas informações do livro físico de forma a simplesmente passar para o sistema um reflexo deste. A partir daí, os dois vão caminhando de forma sincronizada, permitindo assim que quando um determinado registro tiver que ser encontrado no Livro físico, possa ser agilizado o processo de busca, uma vez que no sistema estão as informações de todos os Diplomas/Certificados que estão registrados no livro, bastando apenas o usuário efetuar a busca pelo sistema.  
**Observação:**   
Para o "Reinício do registro" utilizando o tipo "Contínuo" o sistema irá permitir somente um livro com situação "aberto" por coligada, para que o sistema considere o contexto é recomendável utilizar o tipo "Contínuo por nível de ensino", assim o sistema irá permitir um livro com situação "aberto" por contexto (coligada, filial e nível de ensino).

**Atenção:**Ao informar no reinício do livro a opção "Contínuo por livro" e informar o livro anterior, o sistema desabilita o primeiro registro. Para habilitar a caixa de seleção é necessário ser um livro do tipo contínuo por livro, que não tenha livro anterior e que o primeiro registro seja diferente de 1.

**Modelo de participantes**   
Ao registrar um Certificado/Diploma no Livro, tal registro deve conter a assinatura dos responsáveis pelo Curso e/ou Instituição. Para agilizar este processo, existe a possibilidade de já se cadastrar os participantes que assinarão o registro.  
   
Entretanto, não significa que apenas os participantes aqui cadastrados poderão assinar. Exemplo prático: Imaginemos que no livro os participantes cadastrados são O reitor e o vice-reitor neste caso estarão o nome dos dois cadastrados neste modelo de participantes. Porém o Vice reitor está sendo substituído na ocasião pelo coordenador do curso. Neste caso, no momento em que for gerar o Diploma/Certificado, o usuário pode substituir o nome do vice-reitor pelo coordenador.
