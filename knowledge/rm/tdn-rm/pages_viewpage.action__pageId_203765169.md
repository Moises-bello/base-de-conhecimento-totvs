# Como realizar a Recepção de um paciente no sistema?

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Hospitalar |
| **Versões:** | Todas |
| **Ocorrência:** | Como realizar a Recepção de um paciente no sistema? |
| **Passo a passo:** | Na recepção é realizado o registro da entrada do paciente na instituição de saúde. Trata-se de um cadastro essencial para as demais funcionalidades dentro do processo de atendimento ao paciente internado. Registrando Paciente  1. No **TOTVS Gestão Hospitalar** acesse **Atendimento/Recepção/Dados de um Paciente**. 2. Será exibida tela inicial de cadastro de pacientes. 3. Clique em **Incluir** (página em branco). 4. Na tela de registro de paciente informe o Nome do Paciente (obrigatório). 5. Informe o Nome da Mãe do paciente (obrigatório). 6. Preencha as demais informações do paciente (não obrigatório). 7. Na guia **Campos Compl. Paciente** podem ser incluídas observações financeiras do paciente. 8. Clique em **OK**. 9. Em seguida é exibida novamente a tela inicial de cadastro de pacientes, com o registro incluído. 10. Para alterar informações de algum registro, basta selecionar o registro e clicar em **Editar**. |
| **Observações:** | Os dados do paciente também podem ser incluídos/alterados na tela de Registro de Internações. |
