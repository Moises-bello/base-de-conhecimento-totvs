A aba **Integração Registradora Recebíveis**, está disponível na de cadastro de Unidades.

Ao acessar esta aba, o sistema apresenta os seguintes campos:

**Tipo Registradora:** Esta informação é utilizada para indicar se este Empreendimento está integrado com a [CERC](https://www.cerc.inf.br/) (Central de Recebíveis) ou não. Este campo tem as seguintes opções:

* Nenhuma: Não está integrado à CERC; e
* CERC: Integrado à CERC (Central de Recebíveis).

**Identificador da Unidade:** Informe o código de identificação desta Unidade junto ao CERC;

**Tipo de Uso:** É utilizado para informar o Tipo de Uso destinado à Unidade. Para este fim, estão disponíveis as seguintes opções:

* Não Residencial;
* Residencial; ou

**Número de Pavimentos:** Informe a quantidade de Pavimentos que esta Unidade tem.

Nenhum dos campos acima tem preenchimento obrigatório e todos eles estão disponíveis na Tabela de ***Log da Unidade***, para fins de histórico de alterações.
