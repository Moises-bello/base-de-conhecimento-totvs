**Dúvida**  
Quais campos são preenchidos automaticamente com a API Carol no Cadastro de Clientes?  
  
**Ambiente**  
Cross Segmentos - Backoffice Protheus - SIGAFAT - Todas as versões  
  
**Solução**  
A execução da API **preenche automaticamente** os seguintes campos:

| Campo | Título |
| --- | --- |
| **A1\_NOME** | **Nome** |
| **A1\_NREDUZ** | **N Fantasia** |
| **A1\_PESSOA** | **Física/Juríd.** |
| **A1\_END** | **Endereço** |
| **A1\_MUN** | **Município** |
| **A1\_BAIRRO** | **Bairro** |
| **A1\_EST** | **Estado** |
| **A1\_CEP** | **CEP** |
| **A1\_DDD** | **DDD** |
| **A1\_TEL** | **Telefone** |
| **A1\_CNAE** | **Cód. CNAE** |

Os demais campos **continuam com a necessidade**do seu **preenchimento manual.**
