**Dúvida**Sistema não está calculando salário Família.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**

Verifique no cadastro das verbas em Atualizações > Definições de Cálculos > Verbas (GPEA040 na aba Incidências, se as verbas de salário e atestado (**ID 0031, ID 0032 , ID 0033, 0041 e 0042)** então com SIM para Salário Familia. Considerando que tais verbas **não devem ter incidência de Salário Família.** O sistema considera o salário base do funcionário para fazer base do salário família automaticamente, desta forma, se essas verbas estiverem com SIM para Salário Família, elas serão consideradas duas vezes na base de cálculo.
