|  |  |
| --- | --- |
| **Linha de Produto:** | RM |

| **Módulo:** | TOTVS Gestão Hospitalar |

| **Situação:** | Ao tentar abrir a elaboração de contas de um registro vindo da agenda o sistema trava. |
