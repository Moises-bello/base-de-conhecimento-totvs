![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18984321655319) Tempo aproximado para leitura: **00:02:30 min****Dúvida**Como exportar XML em lote pelo RM?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Folha de Pagamento - eSocial - A partir da versão 12.1.33  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
1. Acesse menu **eSocial |****Outros Processos | Exportar** **XML**;

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11250774752535)

2. Selecione os eventos desejados, o tipo de Status dos eventos que deseja salvar o XML e selecione a pasta onde irá salvar os eventos;

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11251981850391)

2.1. No passo a passo acima, há como selecionar **Eventos de tabelas**, **Eventos Não periódicos** e **Eventos periódicos**. Ao selecionar algum Evento periódico, a opção **Selecione a competência**, será habilitada;

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11252114017687)

4. Para os usuários que possuem o **Middleware** ativo é possível realizar a exportação, também, do XML de retorno do governo (S-5001, S-5002 e S-5003). Para isto, é necessário marcar a opção **Exportar XML de Retorno.**

**Importante**Somente é considerado o período de apuração para os **Eventos periódicos**. Para os demais eventos não é possível realizar a seleção por data de envio;

Apenas serão exportados os XMLs de retorno do período que foi utilizado o Middleware para o envio dos eventos originais, sendo que o governo só retorna os XML de retorno para aqueles eventos que possuem verbas (S-1200, S-2299, S-2399) e para o evento de fechamento (S-1299). Porém, a exportação em lote só servirá para os eventos periódicos S-1200 e S-1210 e não periódicos S-2299 e S-2399.
