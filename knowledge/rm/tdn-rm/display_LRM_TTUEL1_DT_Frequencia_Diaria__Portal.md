# FREQUÊNCIA DIÁRIA - PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *TOTVS Gestão Educacional* |
| **Módulo:** | *Educacional* |
| **Função:** | *Frequência diária - Portal* |
| **Situação/Requisito:** | *Ao acessar a tela de digitação de frequência diária através do portal e efetuar um filtro, onde é retornado uma quantidade maior do que mil registros, é exibida uma mensagem orientando o usuário a proceder com a alteração de limite máximo no cadastro global de serviços. Mesmo após alterar esse limite, a mensagem continua a ser exibida.* |
| **Solução/Implementação:** | *Ajustes para que a leitura dos registros na tela de digitação de frequência diária, através do portal, respeite o limite máximo cadastrado no cadastro global de serviços.* |
