![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**É possível a Data de Digitação do Documento de Entrada ser levada para o Titulo a Pagar gerado ?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Compras - Todas as versões  
  
**Solução**Por padrão, dentro da tabela SE2, temos somente a data de emissão do título que, quando é gerado através de uma nota de entrada, a informação desse campo é preenchida com a mesma informação da Data de Emissão informada na da nota.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4407418503831/mceclip0.png)

Este é o funcionamento padrão do módulo, não havendo parametrização para fazer de forma diferente. Porém, caso no processo da empresa se tenha um campo customazado destinado a essa necessidade dentro da tabela SE2 (contas a pagar), existe um ponto de entrada que pode auxiliar no preenchimento do campo customizado.
