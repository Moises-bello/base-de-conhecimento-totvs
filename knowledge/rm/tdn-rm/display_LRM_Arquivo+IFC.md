O IFC (Industry Foundatiom Classes) é um modelo de dados aberto, idealizado para favorecer a interoperabilidade entre os envolvidos de um processo. Tem como objetivo a troca de um modelo informativo sem perda de dados ou referências.

O Totvs Construção Obras e Projetos permite o upload de Arquivo IFC para manipulação e visualização dos dados do Projeto;

Versões suportadas para upload no sistema:

* 2X3;
* 4;
* 4X1;
