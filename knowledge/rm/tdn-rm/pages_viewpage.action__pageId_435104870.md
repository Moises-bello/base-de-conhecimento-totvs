**Cadastrar Relatório RM Reports**

---

**Passo 1-** Acesse: RM/ Globais/ Gestão/ RM Reports. (A Aba Gestão é exibida em todos os módulos. **Passo 2–** Foi exibida uma lista com todos os módulos do sistema. Clique em Incluir **Passo 3-** Preencha os campos

* Código
* Descrição
* Visível a todas as coligadas
* Grupo
* Data de Criação
* Tipo
* Nível de Acesso
* Modificado por: usuário que efetuou a modificação
* Em: Data de modificação
* Aplicação: Sistema em que será utilizado
* Disponível no Menu
* Versão
* Fonte de Dados: Conexão a Banco de dados Externo cadastrada Anteriormente
