# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | Ao realizar uma baixa de um lançamento utilizando o meio de pagamento igual a cheque buscando dados default do emitente (Coligada) o sistema não carrega automaticamente o tipo de inscrição ch CPF/CNPJ. |
| **Solução/Implementação:** | Otimização no processo de baixa de um lançamento utilizando o meio de pagamento igual a cheque buscando dados default do emitente (Coligada). Agora o sistema carrega corretamente a opção tipo de inscrição ch da forma que o campo CPF/CNPJ estiver preenchida. |
