**Dúvida**  
Como habilitar o campo: Cheque (FO2\_NUMCH), na opção: Títulos Gerados?

**Ambiente**  
Protheus – Financeiro – Versão 12

**Solução**  
Para habilitar/deixar editável o campo respectivo, necessário: 

Acesse: SIGACFG > base de dados > dicionário > base de dados > parâmetros > pesquise o parâmetro respectivo.

MV\_GRSEFLQ = T

Para maiores informações, acesse: http://tdn.totvs.com/pages/viewpage.action?pageId=340363674
