# Baixa com extrato mútuo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | Ao efetuar a baixa de lançamentos financeiros onde o extrato de caixa será gerado em outra coligada, devido a contabilização de "Mutuo", o sistema está apresentando a seguinte mensagem de erro:  "Violação de chave estrangeira Possíveis causas:   * exclusão de registro que possui outros registros associados * inclusão de registro detalhe sem um registro mestre associado" |
| **Solução/Implementação:** | Otimização no processo de baixa de lançamentos  ao gerar extrato para outra coligada (mútuo). |

| **Tickets relacionados:** | N/A |
