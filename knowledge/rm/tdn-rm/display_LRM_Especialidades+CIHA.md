**Especialidade**

---

Esta funcionalidade tem como objetivo cadastrar as especialidades atuantes no Hospital.  
Este cadastro esta associado ao cadastro de médico.  
Permite você incluir, editar e excluir.   
Para as especialidades já cadastradas na base o código da especialidade será replicado no campo código cliente podendo ser editado caso não corresponda ao código da especialidade da base a ser importada.  
Ao incluir uma nova especialidade não será replicado o código, neste caso devera informar o código correspondente a esta especialidade da base a ser importada.
