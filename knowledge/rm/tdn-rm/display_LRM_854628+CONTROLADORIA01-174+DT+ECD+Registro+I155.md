# ECD Registro I155

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | SPED Contábil |
| **Situação/Requisito:** | Ao gerar a ECD, no registro I155: DETALHE DOS SALDOS PERIÓDICOS, uma conta credora que teve o saldo final igual a zero está saindo com o indicador da situação do saldo final (campo 9) como devedor em vez de credor. |
| **Solução/Implementação:** | Ao gerar o ECD, no registro I155, a conta que tiver saldo final igual a zero irá sair com o indicador da situação do saldo final (campo 9) igual a sua natureza. |
