# Vagas de emprego

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Totvs Educacional |
| **Módulo:** | Educacional |

## Descrição

Foi disponibilizado através do menu do portal educacional Estágio/Emprego | Acompanhamento | Vagas, a possibilidade dos alunos egressos consultarem as vagas cadastradas/disponibilizadas por empresas parceiras ou pela instituição. São exibidas as vagas do tipo emprego que ainda estão com status "Em aberto", e que a data limite ainda esteja vigente, ou seja, data limite divulgação seja menor que a data atual do sistema.

As vagas de emprego para os alunos egressos só poderão ser consultadas, não permitindo se candidatar.
