# CADASTRO DE FUNCIONÁRIO PERDE A INFORMAÇÃO DA CONTA CORRENTE NA NAVEGAÇÃO DE REGISTROS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Funcionários* |
| **Situação/Requisito:** | *Na edição do cadastro de funcionários acessando a aba de Banco Pgto / Financeiro, o campo "Nro. Conta Corrente" perde a informação quando são utilizados os botões de navegação de registros.*  *O problema acontece quando os "Bancos de Pagamento" dos funcionários possuem máscaras diferentes de conta corrente.*  *Ao alterar a máscara da caixa de edição, perde o conteúdo do campo.* |
| **Solução/Implementação:** | *Ajuste no cadastro de funcionários para que ao atualizar a máscara de edição do "Nro. Conta Corrente", não cause a perda da informação contida no campo.* |
| **Chamados   relacionados:** | *TUTRZ0, TUXSJI* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
