# Relatório Contabilização por Filial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Totvs Gestão Patrimonial. |
| **Função:** | Relatório Contabilização por Filial. |
| **Situação/Requisito:** | Ao realizar a emissão do relatório Contábil seleciona o relatório Contábil por Filial, a emissão é realizada com sucesso realizando as quebras por Filiais, porém ao selecionar a estrutura do relatório e selecionar a opção ‘Visível para todas as Coligadas’, o processo de emissão é realizado sem realizar as quebras das contabilizações por filiais. |
| **Solução/Implementação:** | Implementar a query que traz o dataschema do relatório para procurar pela coligada do relatório e não da coligada corrente. |
