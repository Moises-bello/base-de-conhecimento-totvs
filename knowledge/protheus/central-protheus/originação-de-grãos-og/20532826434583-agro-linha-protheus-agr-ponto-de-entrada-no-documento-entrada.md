![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20532826412695) Tempo aproximado para leitura: **00:00:50 min****Ocorrência**  
No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para fazer o ponto de entrada para manipular os dados nos documentos de geração é apresentada a ocorrência **Ponto de entrada no documento entrada**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é necessário realizar o processo para fazer o ponto de entrada para manipular os dados nos documentos de geração.  
  
**Solução**  
Para solucionar essa ocorrência, o **Ponto de Entrada** é o **OGX009NF - Permite Manipular dados na geração do Documento de Entrada**, ele é chamado ao confirmar o romaneio **OGX009 - Geração do Documento de Entrada**.
