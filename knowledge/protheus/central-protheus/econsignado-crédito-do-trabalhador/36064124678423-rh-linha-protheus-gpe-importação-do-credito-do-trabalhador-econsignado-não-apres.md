**Ocorrência**  
Importação do Credito do Trabalhador eConsignado não apresenta pasta local para seleção do arquivo  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.2310  
  
**Causa**  
Este problema acontece quando o Agente Local não está habilitado.  
  
**Solução**  
Para que o Sistema apresente a pasta local para selecionar o arquivo a ser importado na rotina do Credito do Trabalhador eConsignado, siga os passos abaixo:

1. Faça *logoff* ou feche o Protheus
2. Selecione o botão de **Configuração** (ícone de engrenagem) na tele de login inicial do Sistema:  
   1. ![](https://centraldeatendimento.totvs.com/hc/article_attachments/36064116349847)
3. Clique na caixa de seleção Habilita/ Desabilita o Agente Local para habilitar:
   1. ![](https://centraldeatendimento.totvs.com/hc/article_attachments/36064116351511)
4. Clique em fechar no canto superior direito  
   1. ![](https://centraldeatendimento.totvs.com/hc/article_attachments/36064116353047)
5. Acesse o Protheus com usuário e senha

Desta forma o Sistema apresentará as pastas locais que o usuário tiver acesso.
