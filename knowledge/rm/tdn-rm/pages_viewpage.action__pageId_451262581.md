# Rotina Municipal DES-BH

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Rotina Municipal DES BH |
| **Situação/Requisito:** | Cliente solicita geração que o campo 08 - Motivo de não Retenção do registro Tipo "R" - Serviços Tomados da DES BH seja gerado com o código 9 - Profissional Autônomo inscrito na PBH. |
| **Solução/Implementação:** | No cadastro de Cliente\Fornecedor \ Integrações \ Tributos \ Campo Regime de ISS, foi implementado a opção Profissional Autônomo;  Na rotina DES-BH no registro tipo "R", foi implementado a geração do campo "08-Motivo de não Retenção" com a informação de "09-Profissional Autônomo com registro na PBH". |
