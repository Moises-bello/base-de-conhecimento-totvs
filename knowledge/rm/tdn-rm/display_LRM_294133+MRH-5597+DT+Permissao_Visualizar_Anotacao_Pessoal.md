# VISUALIZAR ANOTAÇÃO PESSOAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Visualizar anotação pessoal* |
| **Situação/Requisito:** | O anexo de anotação pessoal não estava sendo apresentado no cadastro do funcionário, pois foi criada uma nova tag de segurança que permitia a visualização das anotações pessoais, porém esta tag não havia sido incluída para liberação no sistema, fazendo com que o usuário não conseguisse liberar permissão na mesma. |
| **Solução/Implementação:** | Foi ajustado o sistema para que fosse apresentada a tag de visualização de anotações pessoais para que o usuário conseguisse liberar as permissões no anexo e o mesmo fosse apresentado. |
