![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como realizar a devolução de uma mercadoria no SIGAEIC?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - Todas as versões  
  
**Solução**O SIGAEIC não possui tratamento de devolução, destruição e transferência.  
Pois esta operação seria uma saída e o SIGAEIC apenas trata a entrada de mercadoria importada e transferência de posse no caso de importações por conta e ordem.   
Neste caso, para realizar a devolução verifique o procedimento com a equipe do módulo SIGAFAT ou SIGAFIS.
