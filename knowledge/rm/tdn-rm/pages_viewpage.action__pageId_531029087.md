## **01. VISÃO GERAL**

Nesta funcionalidade devem ser cadastrados todos os tipos de Unidades de Medida utilizadas para informar os resultados encontrados no processamento dos Exames de Laboratório.

## **02. EXEMPLO DE UTILIZAÇÃO**

Para realizar o cadastro dos tipos de unidade de medida para exames basta seguir o passo a passo abaixo:

Telas Utilizadas

## **03.TELAS UTILIZADAS**

* No TOTVS Gestão Hospitalar acesse o menu**Cadastros> Unidades Diagnóstico> Padrão de Medida para Exame.**

* Clique em **Incluir**.

* Preencha o Código, o Padrão de medida e Descrição.

  **Clique em Salvar> OK.**

* Cadastro realizado com sucesso.
