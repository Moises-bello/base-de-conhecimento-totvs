**Ocorrência**Ao confirmar uma rescisão é apresentado Help: Para incluir uma rescisão ela deve ser calculada.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - Todas as versões.  
  
**Causa**O sistema apresenta a mensagem pois antes de confirmar, a rescisão deve ser calculada.   
  
**Solução**  
Antes de confirmar a rescisão, o cálculo deve ser efetuado, o cálculo é efetuado pela tecla F6 ou pelo comando >Outras ações >Calcular rescisão (F6).
