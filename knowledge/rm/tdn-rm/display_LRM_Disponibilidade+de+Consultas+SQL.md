# Objetivo:

---

       No formulário de cadastro de consultas SQL há configurações para restringir a disponibilidade da consulta em funções do sistema. Nesta página falaremos sobre estas opções.

# Introdução:

---

       Quando uma nova consulta SQL é criada algumas opções já vem selecionadas por default. São elas:

       Em seguida, será explicado a utilidade de cada uma das opções acima.

# Funcionalidades:

---

**Funcionalidade de cada opção:**

false.Execução de Visões

Quando marcada essa opção a consulta SQL fica disponível para ser adicionada à Planilhas RM, Excel, Anexos, Cubos, Gráficos, entre outros.

Atenção

Caso a opção seja desmarcada, não será possível utilizar a consulta SQL em nenhuma das opções citadas acima.

Filtros

Quando marcada essa opção é possível adicionar uma consulta SQL à uma condição de filtro. Caso a opção esteja desmarcada, não seria possível vincular a consulta.

Ex: Quero que apareçam somente os funcionários cuja situação é igual a 'A'

Atenção

É importante que a consulta SQL seja criada na aplicação em que se deseja executar o filtro, conforme evidenciado na imagem acima.

Relatórios

Quando marcada essa opção é possível adicionar a consulta à um relatório no RM Reports, através de "Adicionar Fonte de Dados | Sentença SQL". Caso a opção esteja desmarcada, não seria possível localizá-la.

Menu

Quando marcada essa opção a consulta SQL fica disponível quando clicado em 'Visões de Dados', conforme imagem abaixo:

RM Portal

Quando marcada essa opção a consulta SQL fica disponível para ser acessada através do Menu Portal. Caso a opção esteja desmarcada, a consulta não ficará visível.
