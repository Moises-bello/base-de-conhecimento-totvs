**Dúvida**Como configurar a moeda para não apresentar a mensagem: Não foi possível gerar o título!A moeda: XXX não está configurada no Financeiro! ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**1. Acesse o módulo SIGAEIC em Atualizações \ Cadastros \ Moedas (EICA150).  
2. Posicione na moeda e selecione Alterar:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079273714/mceclip0.png)  
3. No campo Moeda ERP (YF\_MOEFAT), informe a moeda utilizada no SIGAFIN:   
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079274034/mceclip1.png)  
  
4. Selecione Salvar para gravação da alteração.  
5. Acesse a rotina Cotacao das moedas (EICA140), selecione Incluir  
6. Informe para a moeda a taxa e selecione Salvar  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079274334/mceclip2.png)
