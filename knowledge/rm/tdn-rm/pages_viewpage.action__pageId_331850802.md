# Campo indicação clínica apresenta mensagem ao abrir tela do cabeçalho da guia

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Guia / Autorização |
| **Situação/Requisito:** | Ao abrir o cabeçalho de uma guia de solicitação de internação, era apresentado uma mensagem informando que o campo indicação clínica era obrigatório. |
| **Solução/Implementação:** | Foi alterado a mensagem para ser exibida somente após o usuário salvar o registro. |
