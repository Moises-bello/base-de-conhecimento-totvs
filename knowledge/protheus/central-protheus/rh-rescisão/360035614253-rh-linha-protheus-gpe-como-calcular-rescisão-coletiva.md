**Tempo aproximado para leitura: 00:01:30 min**

**Dúvida**Como calcular rescisão coletiva?   
  
**Ambiente**

TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:

1. Miscelânea > Cálculos > Rescisão > Rescisão Coletiva;  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360097773614)  
  
2. Preencha os parâmetros para efetuar o cálculo da rescisão coletiva;  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360100047153)  
  
3. Caso necessite de uma parametrização diferente, altere pelo Filtro Rápido;  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360045660114)   
  
4. Preencha os dado conforme necessário e Confirme.
