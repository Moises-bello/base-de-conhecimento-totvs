# GERAÇÃO DE USUÁRIO COM A REMOÇÃO DE CARACTERES ESPECIAIS PARAMETRIZADA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Geração de usuários |
| **Situação/Requisito:** | Ao executar o processo de geração de usuário o processo está removendo caracteres especiais como traços. |
| **Solução/Implementação:** | Como uma solução, foi disponibilizado um parâmetro para que houvesse uma flexibilização no processo de geração de usuários.  Dessa forma, ao executar o processo, será possível a definição da remoção ou não de caracteres especiais.  Essa parametrização poderá ser realizada no processo de geração de usuários ou na parametrização para execução automática.  O parâmetro será disponibilizado para a geração dos código de usuários: Aluno, Professor, Pesquisador e Funcionários. |
