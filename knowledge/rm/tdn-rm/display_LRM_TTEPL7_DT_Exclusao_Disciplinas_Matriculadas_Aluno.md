# Exclusão de disciplinas matriculadas do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Excluir disciplina matriculada do aluno* |
| **Situação/Requisito:** | **Ao tentar excluir uma disciplina na qual o aluno esteja matriculado, caso o sistema esteja parametrizado para considerar a matriz do aluno para validação de requisitos da disciplina, e a disciplina não seja, ou não tenha, corequisito, é lançada uma exceção impedindo a exclusão.** |
| **Solução/Implementação:** | *Ajustes para que a*o excluir uma disciplina na qual o aluno esteja matriculado, caso o sistema esteja parametrizado para considerar a matriz do aluno para validação de requisitos da disciplina, e a disciplina não seja, ou não tenha, corequisito, a ação seja finalizada corretamente.** |
