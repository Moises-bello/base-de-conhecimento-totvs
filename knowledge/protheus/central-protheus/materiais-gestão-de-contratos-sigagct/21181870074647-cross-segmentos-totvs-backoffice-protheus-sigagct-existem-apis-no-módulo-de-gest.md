![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/21181870072983) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Existem API's no Módulo de Gestão de Contratos para automatização ou Integrações com outros Sistemas ?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões

**Solução**

Atualmente no módulo de Gestão de Contratos não há disponíveis API's para uso em automatizações ou integração com outros sistemas.

As API's, as disponíveis para utilização por clientes de demais processos estão documentadas no link <https://api.totvs.com.br/>.

No Gestão de Contratos não há pontos de entrada especificos para automatização, e no caso o que pode ser verificado seria o desenvolvimento de Execautos existentes tanto para Contratos como para Medições.

Abaixo artigos disponiveis com exemplos de Execautos:
