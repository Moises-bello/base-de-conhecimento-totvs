**Dúvida**Quais as funções disponíveis para adquirir informação sobre usuários no Arquivo de senhas?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Para obter informações do arquivo de senhas pode utilizar as seguintes  funções:

[FWSFallGrps](http://tdn.totvs.com/display/PROT/FWSFallGrps)Esta função carrega todos os registros do cadastro de grupos do arquivo de senhas

[FWSFALLUSERS](http://tdn.totvs.com/pages/viewpage.action?pageId=54429690)Esta função carrega todos os registros do cadastro de usuário no arquivo de senhas (SUPERFILE)
