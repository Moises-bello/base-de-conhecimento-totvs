# MATRÍCULA - PROCESSO SELETIVO RM

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Matrícula via Processo Seletivo RM* |
| **Situação/Requisito:** | *No cadastro do aluno como cliente/fornecedor, durante a execução do processo de matrícula via Processo Seletivo RM, caso o supervisor tenha informado campos obrigatórios no cadastro de cliente/fornecedor o candidato não era matriculado. Este bloqueio ocorria porque os campos informados como obrigatório não podiam ser informados durante a matrícula ou no registro do candidato.* |
| **Solução/Implementação:** | *Quando houver campos obrigatórios informados no cliente/fornecedor, eles serão desconsiderados quando a matrícula for realizada via Processo Seletivo RM. Vale ressaltar que os campos continuarão sendo obrigatórios para no cadastro e edição do cliente/fornecedor.* |
