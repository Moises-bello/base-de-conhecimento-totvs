# SPED FISCAL Bloco B

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | SPED FISCAL |
| **Situação/Requisito:** | * Criar na tela de geração do Sped Fiscal um checkbox para que o usuário informe se deseja gerar o **Bloco B** ou não. * Tratar na classe de parâmetros |
| **Solução/Implementação:** | * Foi criado CheckBox **"Gerar Bloco B"** na aba "Personalização" da tela de geração do SPED FISCAL.  * Tratado na Classe de Parâmetros para que possa ser usado quando o Bloco B for implementado.  ATENÇÃO O CheckBox só estará visível nas versões 12.1.21 e 12.1.22 após a implementação do Bloco B. Até a presente data 22/11/2018 o Bloco B ainda não é gerado. |
