**Dúvida**Para que server o parâmetro **MV\_AGRO024**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - A partir da versão 12  
  
**Solução**O parâmetro **Uso do Portal Agro Comercial - MV\_AGRO024** é do tipo **lógico**. Indica se as funcionalidades do **Portal Agro Comercial** devem estar disponíveis via **Representational State Transfer - REST** para integração com Sistemas externos.
