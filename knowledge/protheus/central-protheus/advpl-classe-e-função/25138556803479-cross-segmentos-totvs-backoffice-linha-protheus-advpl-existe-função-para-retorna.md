![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25138550481431) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Existe função para retornar as funções contidas no repositório?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**

Nesse caso pode ser usado a função *GetFuncArray* no qual retorna um ou mais arrays contendo os dados das funções contidas no RPO - Repositório Portável de Objetos, a partir de uma máscara.
