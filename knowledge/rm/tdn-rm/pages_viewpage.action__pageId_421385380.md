Para que o no cadastro de insumos o código fique automático, o parâmetro do projeto deverá estar marcado e definida a máscara de acordo com o que o usuário preferir (com letras e/ou números).    
    
 >> Máscaras  
    
 Após definir a máscara e selecionar o auto-incremento, o usuário deverá fazer o cadastro de no mínimo um insumo, para que o auto-incremento dê a devida sequencia nos próximos. Por Exemplo caso o usuário defina a máscara com letras e números 'DD001', o próximo insumo o sistema já sugere  o 'DD002' e assim por diante. Mesma lógica se aplica só com números.   
    
 Ao selecionar a opção (auto- incremento) no parâmetro e selecionar um valor inicial, o insumo desabilitará o campo de Código, e começar a partir do número indicado no valor inicial.
