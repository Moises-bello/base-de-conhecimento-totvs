![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:03:00 min** **Dúvida**Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Como configurar para que outros usuários sem ser o Usuario Administrador possa visualizar o Campo Bloqueado AL\_MSBLQL no Grupo de Aprovação?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Compras - Todas as versões  
  
**Solução**-Por padrão o nível do campo AL\_MSBLQL é 9.![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9349867095703)

-Caso o Nível do campo do usuário for menor conforme exemplo abaixo, o usuário não conseguirá visualizar o campo.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9350027067927)

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9350017036439)

-Recomendamos dessa forma ou ajustar os níveis do usuário para o mesmo nível do campo ou alterar o nível do campo no configurador para 1, alterando para 1 todos usuários terão acesso a visualização do campo.

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9350114651031)
