# Rais

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Rais* |
| **Situação/Requisito:** | O funcionário foi transferido entre coligadas, na coligada anterior houve o desconto de contribuição sindical.  Ao gerar a RAIS para a coligada atual é levado o CNPJ da coligada anterior na contribuição sindical. |
| **Solução/Implementação:** | Otimizada geração da RAIS, de forma que, nas gerações dentro do ano base (RAIS não genérica), as contribuições sindicais anteriores à data de transferência do funcionário não sejam levadas em consideração para indicar quais as contribuições sindicais do funcionário |
