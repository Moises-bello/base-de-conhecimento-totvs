# REGISTRO DE PRESENÇA DE CANDIDATOS E PROFISSIONAIS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Processo Seletivo* |
| **Função:** | *Registro de presença de candidatos e profissionais* |
| **Situação/Requisito:** | *Ao efetuar um duplo clique no checkbox de presença o sistema está invertendo o ícone do status da presença, somente se for um duplo clique.* |
| **Solução/Implementação:** | *Foi feito o ajuste na lista de presença para ignorar o duplo clique, se o usuário executar um duplo clique na lista o sistema irá se comportar como se fossem dois cliques únicos, assim evitando a falha na definição do status da presença.* |
