# Ajuste nas mensagens de responsável eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT / TOTVS Educa Mobile |
| **Função:** | Mensagens de notificação (Timeline) do eduCONNECT para responsável que possui mais de um dependente. |
| **Situação/Requisito:** | Quando um usuário do eduCONNECT responsável por mais de um dependente acessa o aplicativo, e possui dependentes que não estão ativos, as mensagens da Timeline não estavam sendo carregadas. |
| **Solução/Implementação:** | Foi realizado ajuste no TOTVS Educa Mobile e eduCONNECT, de maneira que ao realizar login no aplicativo, os dependentes retornados sejam apenas os alunos ativos, tendo o mesmo comportamento dos alunos carregados ao realizar o acesso diretamente no TOTVS Educa Mobile (fora do aplicativo.) |
