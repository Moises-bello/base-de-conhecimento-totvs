****Configurador do TOTVS Business Connect****

---

O configurador é uma funcionalidade que gera a integração, cria o mapeamento das entidades, a transformação das mensagens únicas e está incluído no instalador do ERP RM.

O Assistente de Configuração tem o objetivo de criar a conexão que integrará os módulos TOTVS Gestão de Pessoas x Fluig LMS - Elearning

Durante o processo, são inseridas as credenciais para conexão ao banco de dados em que as informações do TOTVS Gestão de Pessoas estão gravadas e selecionadas a integração responsável por conectar os dois sistemas.

**1**. Para executar o configurador acesse: RM / Integração / Ferramenta / Configurar

**2**. Clique em avançar, insira um Usuário e Senha com permissão de acesso ao banco de dados utilizado ao conectar ao sistema RM.

**3**. Após o preenchimento dos dados de conexão, clicar em Testar para validar a conexão com o banco. Em seguida clique no botão Avançar.

**4**. Selecionar a integração TOTVS Gestão de Pessoas x Fluig LMS - Elearning. Após clique em Avançar, e em Executar.

**Configurando o Web Service da Mensagem Única**

Para que a integração conecte os sistemas é necessário que seja informado o endereço de Webservice do TOTVS LMS e as suas credenciais de autenticação

**1**. Para isso acesse: RM / Integração / Integração / Mensagem Padrão / Integrações.

**2**. Selecione a integração TOTVS Gestão de Pessoas x Fluig LMS - Elearning e edite o registro.

**3**. Preencha os campos:

* + **Url Web Service:** Endereço que identifica o local onde o Webservice está instalado.
  + **Usuário Autenticação**: usuário com permissão de acesso ao Webservice.
  + **Senha Autenticação**: Senha de acesso ao Webservice

**4**. Selecionar o check Box Ativo

**5**. Salve as modificações realizadas.
