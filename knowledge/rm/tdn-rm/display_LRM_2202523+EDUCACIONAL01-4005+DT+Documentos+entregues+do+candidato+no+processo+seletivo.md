# DOCUMENTOS ENTREGUES DO CANDIDATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Processo Seletivo* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Documentação do candidato* |
| **Situação/Requisito:** | No processo seletivo, o campo “Documento Entregue” do candidato não estava habilitando mesmo quando o usuário logado tinha permissão de acesso ao item “Inscrição | Documentação do candidato”. |
| **Solução/Implementação:** | No processo seletivo, o campo “Documento Entregue” do candidato será habilitado quando o perfil do usuário logado tenha permissão de acesso ao item “Inscrição | Documentação do candidato”. |
