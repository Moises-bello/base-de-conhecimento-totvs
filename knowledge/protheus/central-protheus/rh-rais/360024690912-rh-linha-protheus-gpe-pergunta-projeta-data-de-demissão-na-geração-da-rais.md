Dúvida**Qual o comportamento do sistema quando preenchida a pergunta Projeta Data de Demissão na geração da RAIS?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal –  Todas as versões  
  
**Solução**

1. Cabeçalho da rescisão do funcionário que utilizaremos como exemplo:

```
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023351792)
```

2. Opções de preenchimento da pergunta Projeta Data de Demissão:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023391031)

2.1 Selecionando a opção Verbas rescisão:

O sistema apresenta as verbas rescisórias no mês correspondente a demissão do funcionário (Campo Data de Demissão) e as verbas indenizatórias no mês que termina a projeção do aviso prévio (Campo Data Projetada). Nesta opção a data de demissão demonstrada no cabeçalho da RAIS corresponderá a data final da projeção.

```
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023391451)
```

2.2 Selecionando a opção Todas as Verbas:

O sistema apresenta todas as verbas da rescisão no mês que a projeção do aviso prévio termina (Campo Data Projetada). Nesta opção a data de demissão demonstrada no cabeçalho da RAIS corresponderá a data final da projeção.

```
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023393191)
```

2.3 Selecionando a opção Não Projeta:

O sistema apresenta todas as verbas da rescisão no mês que corresponde a demissão do funcionário (Campo Data de Demissão). Nesta opção a data de demissão demonstrada no cabeçalho da RAIS corresponderá a data de demissão do funcionário.

```
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023355312)
```

2.4 Selecionando a opção Verbas Resc. +13º:

O sistema apresenta as verbas rescisórias no mês correspondente a demissão do funcionário (Campo Data de Demissão) e as verbas indenizatórias + 13º salário no mês que termina a projeção do aviso prévio (Campo Data Projetada). Nesta opção a data de demissão demonstrada no cabeçalho da RAIS corresponderá a data final da projeção.

```
![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023355552)
```
