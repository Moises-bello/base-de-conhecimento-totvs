## **02. SITUAÇÃO/REQUISITO**

Era necessário criar uma API para permitir que o usuário logado no eduConnect visualizasse o recibo de pagamento por cartão de crédito, ao clicar em algum título pago, da aba "Financeiro".

## **03. SOLUÇÃO**

Foi realizada implementação para criar a API que será consumida pelo eduConnect. Essa API retornará informações de pagamento a partir do par de informações COLIGADA|IDBOLETO passada pelo usuário.
