**Dúvida**É possível parametrizar o Sistema para que determinadas verbas o cálculo seja sempre sobre 30 dias, e para outras verbas o cálculo seja sobre os dias do mês (28, 29, 30 ou 31), no mesmo período e para o mesmo funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoas - Todas as versões  
  
**Solução**Não é possível parametrizar o sistema para que considere diferentes dias como base de cálculo no mesmo período e para o mesmo funcionário, o sistema sempre irá considerar para todas as verbas da folha de pagamento o Cadastro de Períodos, onde buscará na coluna Dias Cálculo a quantidade de dias a ser considerada no cálculo:
