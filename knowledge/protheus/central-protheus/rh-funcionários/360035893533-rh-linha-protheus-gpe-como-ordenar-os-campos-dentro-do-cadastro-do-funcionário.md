**Dúvida**Como ordenar os campos dentro do cadastro do funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para ordenar os campos do cadastro de funcionário, siga os seguintes passos:

1. Acessar o programa **SIGACFG - Configurador**;  
2. Acessar **Base de Dados - Dicionários - Arquivos,** localize a tabela **SRA**e selecione **Editar**;  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046105194)  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31870159086999)  
  
3. Abrir os campos para visualização;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31870115097367)  
  
4. Modificar a ordem dos campos que podem sofrer essa alteração, marcados pela legenda ![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046105494), usando a **seta para cima ou para baixo**, clicando **duas vezes** sobre a mesma;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31870059523479)  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31870015689623)  
  
5. Clicar **Confirmar,** através do ícone**![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046105614) ;**6. Clicar em **Atualizar base de Dados** através do ícone ![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360046105634) e avance para que a mudança seja efetivada;  
7. Após isso, ao acessar o Cadastro do Funcionário, os campos alterados estarão reordenados.
