# PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Área de interesse ofertada do processo seletivo. |
| **Situação/Requisito:** | Ao alterar o número de vagas na área de interesse ofertada do processo seletivo, emitia mensagem: A área de interesse não possui instituição ou a instituição informada é diferente da instituição do processo seletivo. |
| **Solução/Implementação:** | Alterado a validação da instituição do processo seletivo com a instituição da área de interesse ofertada. Caso a área de interesse ofertada esteja preenchido o código da Instituição e o processo seletivo também tenha instituição preenchida, ambos devem utilizar o mesmo código. |
