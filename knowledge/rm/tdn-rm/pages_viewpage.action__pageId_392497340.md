# Período de Apuração - Eventos Especiais para - SCP

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Período de Apuração - Cadastro/Encerramento |
| **Situação/Requisito:** | 1 - Na apuração do IRPJ/CSLL já estamos tratando ocorrências especiais, no entanto,  como não tem filial no registro, estamos aplicando a situação especial  para a matriz e para as filiais SCP. Logo, no encerramento do período,  ao verificar se houve ocorrência especial no período, teremos que verificar  se houve ocorrência para a filial do período que está sendo encerrado.  2 - Verificar consistência na criação do Período de Apuração. |
| **Solução/Implementação:** | Ajustados os serviços onde se busca ocorrências especiais (Cisão) para passar a consistir a Filial. |
