# Transferência de Funcionários

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Transferência de Funcionários |
| **Situação/Requisito:** | O cliente precisará encerrar uma empresa e por este motivo todos os funcionários serão transferidos para outra coligada, porém existem funcionários afastados e de férias. Atualmente o Labore não permite efetuar uma transferência com funcionário afastado/férias, no entanto o cliente salienta que devido ao eSocial essa realidade precisa ser ajustada. |
| **Solução/Implementação:** | Criado o parâmetro 'Permite transferência tipo 5 de funcionários afastados ou de férias' em configurações | Parâmetrizador | 06.01 - Folha de Pagamento | 06.01.06 - Rescisão | Transferência, que, quando marcado, permite fazer a transferência de funcionários em situação de Férias ou Afastamento. |
