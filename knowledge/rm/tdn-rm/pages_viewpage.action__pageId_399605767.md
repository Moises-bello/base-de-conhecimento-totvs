# Alteração de Salário Composto

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Alteração de Salário Composto |
| **Situação/Requisito:** | Ao processar a alteração salarial retroativa onde teve um evento que compõe salário composto inserido mês após a data da efetiva alteração, o salário inserido após a data da mudança não está sofrendo o ajuste. |
| **Solução/Implementação:** | Ajuste na alteração global de salários para considerar eventos de salário composto incluídos e excluídos em meses posteriores a mudança. |
