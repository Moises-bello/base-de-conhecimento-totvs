|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Chefe/Supervisor* |
| **Situação/Requisito:** | *No cadastro de chefe supervisor o Sistema permite que seja cadastrado um chefe com data anterior a sua admissão. Ao gerar o PPP para um funcionário que foi cadastrado como chefe com uma data anterior a sua admissão as informações do campo 13 Lotação e Atribuição não estão sendo preenchidos corretamente.* |
| **Solução/Implementação:** | Adicionado validação para não permitir cadastrar chefe/supervisor com data anterior a data de admissão. |
