![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02****:00 min** **Dúvida**Como configurar despesa base de imposto para a nota de importação?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) -*Easy Import Control* - Todas as versões  
  
**Solução**São as despesas que compõem a base de cálculo do imposto de importação (I.I.).  
Elas são configuradas no cadastro de despesas em Atualizações -> Financeiro -> Cadastro Despesas.  
![cadastro_despesa.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/5369591749911/cadastro_despesa.gif)  
  
A configuração delas é feita da seguinte forma:

* Base de imposto = SIM
* Base de custo = NÃO
* Base de ICMS = NÃO
