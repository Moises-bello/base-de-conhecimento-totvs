# Incluir extrato correspondente com defaults da conta/caixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Reconciliação Bancária - Incluir extrato correspondente |
| **Situação/Requisito:** | Ao realizar o processo de incluir extrato correspondente marcando a opção "Um Extrato para cada registro de reconciliação, informando os dados somente uma vez" o sistema não carrega os defaults da conta/caixa do registro. |
| **Solução/Implementação:** | Agora o sistema irá carregar os defaults da conta/caixa caso todas as linhas selecionadas possuam a mesma conta/caixa. |
| **Tickets relacionados:** | 2311157 |
| **Requisito:** | FIN000181 |
| **Documento de Referência:** | <http://wikihelp.totvs.com.br/WikiHelp/FIN/FIN.incluirExtratoCorrespondente.aspx> |
