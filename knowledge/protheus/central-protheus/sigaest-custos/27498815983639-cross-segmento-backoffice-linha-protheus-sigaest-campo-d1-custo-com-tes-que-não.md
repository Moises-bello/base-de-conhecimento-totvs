**Dúvida**

Qual a Configuração para que o campo **D1\_CUSTO** seja populado mesmo para a TES que não **Atualiza Estoque (F4\_ESTOQUE=N)**?

![F4_ESTOQUE.png](https://centraldeatendimento.totvs.com/hc/article_attachments/27499022722583)

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões

**Solução**

Para esse caso existe no Cadastro da TES (MATA080) o campo **Agrega Valor (F4\_AGREG)** quando Configurado **igual a Sim**, mesmo para  TES que Não Atualiza Estoque popula o campo D1\_CUSTO.

![F4_AGREG.png](https://centraldeatendimento.totvs.com/hc/article_attachments/27499502362775)
