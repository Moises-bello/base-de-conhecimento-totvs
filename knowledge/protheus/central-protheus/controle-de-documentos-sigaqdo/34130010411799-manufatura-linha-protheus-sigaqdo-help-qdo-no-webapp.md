**Ocorrência**  
Na rotina **QDOA050** **- Cadastro de Documentos**, ao visualizar um documento é apresentada a mensagem: **QDO-NO-WEBAPP - Execução via WebApp sem WebAgent**.  
  
**Ambiente**  
TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Causa**  
O help **QDO-NO-WEBAPP - Execução via WebApp sem WebAgent** ocorre quando o *WebAgent* não está habilitado ou quando a opção **Agente Local** não está habilitada.  
  
**Solução**  
Para solucionar essa ocorrência, realize os seguintes passos:  
1. Verificar se o *WebApp* está habilitado;  
2. Verificar se o *WebAgent* está habilitado;  
3. Estando o *WebAgent* habilitado, verifique se o **Agente Local** está habilitado, conforme exemplo:
