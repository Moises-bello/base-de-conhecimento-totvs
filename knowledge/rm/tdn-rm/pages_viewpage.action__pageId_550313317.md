# Geração do SCAE

Para gerar o Layout do SCAE é necessário executar os procedimentos abaixo:

Acessar a módulo integração.

Acessar os layouts para importação

 Acessar o layout e gerando o Layout

 Selecionando o Layout para geração

 \* Por padrão o diretório padrão onde o arquivo é salvo é \TOTVS\CorporeRM\RM.Net\Saidas se quiser alterar o local basta clicar no ícone e alterar o local.   
  
 Informar os parâmetros de geração na tela abaixo.

 Executar a geração do arquivo.

Geração executada com sucesso

# Localizando e visualizando o arquivo gerado

Para visualizar o arquivo gerado, basta acessar o diretório onde o arquivo foi salvo e abrir o arquivo, no nosso  
exemplo C:\TOTVS\CorporeRM\RM.Net\Saidas

O Gerador de saída gera o arquivo em **TXT.**

Clique em Arquivo e Salvar Como, altere o tipo para “**Todos os Arquivos**”,e salve o arquivo com a extensão \***.xml**, por exemplo SCAE\_FEV2023.xml
