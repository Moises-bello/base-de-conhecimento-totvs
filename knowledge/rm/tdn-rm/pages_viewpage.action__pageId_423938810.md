Pela tela de permissões por Tipo de Movimento é possível permitir/proibir acessos aos Tipo de Movimento para cada usuário.

**Definindo permissões de Tipo de Movimento para um usuário**

As Permissões por Tipo de Movimento são acessadas pelo menu Serviços Globais | Segurança | Usuários.  
Após escolher o Sistema: Gestão de Estoque, Compras e Faturamento, selecionar o usuário para qual deseja-se definir as permissões, deve ser acessado o menu Anexos | Permissões por Tipo de Movimento.  
Na janela de Permissões por Tipo de Movimento é apresentada a Grid com todos os tipos de movimentos cadastrados juntamente com as permissões de cada movimento.   
Para alterar as permissões de um tipo de movimento deve-se selecionar o mesmo na Grid e marcar/desmarcar as permissões desejadas. (Marcado = Acesso Permitido/Desmarcado = Acesso Proibido).  
Para encontrar tipos de movimento rapidamente é possível utilizar a busca por Código e Nome do Tipo de Movimento. O campo de busca é habilitado ao clicar no botão "Procurar" apresentado acima da Grid de Tipos de Movimento.  
Ao habilitar o campo de busca, basta digitar a informação do campo escolhido (Código ou Nome do Tipo de Movimento) que a seleção será feita automaticamente, após o movimento estar selecionado devem ser definidas as permissões, e concluir o processo salvando as alterações.
