TLinearLayout:nDirection

Indica a direção linear na qual os componentes serão dispostos no layout. Consulte a área de observações para conhecer as opções disponíveis.

| Tipo | Valor Padrão | Somente Leitura |
| --- | --- | --- |
| numérico | 0 | N |

## Observações

### Valores disponíveis para a propriedade:

| Valor | Descrição |
| --- | --- |
| 0 | Direção horizontal da esquerda para a direita |
| 1 | Direção horizontal da direita para a esquerda |
| 2 | Direção vertical do topo para a base |
| 3 | Direção vertical da base para o topo |
