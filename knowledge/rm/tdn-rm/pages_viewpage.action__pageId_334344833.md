# Gráfico - Gestão de mensagens eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Atividades acadêmicas| Central de Comunicação | eduConnect | Gestão de mensagens | Anexo Gráfico |
| **Situação/Requisito:** | Por existir uma limitação no consumo dos dados na nuvem (local onde fica armazenado as mensagens enviadas ao eduCONNECT), o sistema não exibia o gráfico de uma mensagem do tipo enquete, quando essa mensagem fosse enviada para mais de 30 usuários. |
| **Solução/Implementação:** | Foi realizado uma otimização no consumo das mensagens armazenadas na nuvem do tipo enquete, de maneira que o sistema possa retornar todas informações da mensagens de acordo com a quantidade de mensagens individuais e permitindo a geração/exibição do gráfico corretamente. |
