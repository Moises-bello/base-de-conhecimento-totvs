**Dúvida**Como realizar inclusão/exclusão global de Horários Alternativos no sistema?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 12.1.20  
  
**Solução**Para realizar o processo de alteração de forma global, realize os passos:

1. Acessar  o menu **Processos / Inclusão | Exclusão Horários Alternativos,** ao abrir o assistente clique em avançar.
2. Na primeira etapa, escolha um grupo de funcionários. Se não selecionar nenhum, a alteração será aplicada a todos.  
   Atenção: Para proceder com a alteração global, é necessário selecionar pelo menos a situação dos funcionários.   
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29786973715479)
3. Na terceira etapa, escolha se irá incluir ou excluir um horário alternativo.   
   - Preencha os campos: Código do Horário, Data de Referência e Índice da Data de Referência.  
   - Você pode visualizar uma prévia das alterações antes de executar o processo, ao clicar no botão Visualizar horário.  
   - Após preencher todos os campos, clique no botão "Adicionar Horário".  
   Observação: O campo Índice da Data Base é preenchido automaticamente quando a Data de Referência e o Índice são preenchidos, através de um cálculo interno do sistema.  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29786975226647)
4. Avance para etapa 4, e execute o processo.  
   ![horario_alter.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29786973721751)
