*![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25306012053527)* Tempo aproximado para leitura: **00:02:00 min****Dúvida**Criei uma exclusão (S-3000) para um evento, mas não quero que seja enviada para o Governo. Como faço para desfazer essa exclusão?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - eSocial - TAF - Todas as versões  
  
**Solução**  
O evento de exclusão (S-3000) só poderá ser desfeito antes do envio para o Governo. **Se o evento de exclusão já foi enviado, este procedimento não será válido**.  
  
Quando for gerada uma exclusão indevidamente para algum evento que não deseja excluir, siga os procedimentos abaixo para que essa exclusão seja desfeita:

**1.** Entre na rotina do evento que excluiu indevidamente;

**2.** Encontre o registro que excluiu indevidamente, estará com a legenda de cor laranja:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360045733073)  
  
**3.** Com o registro selecionado, vá em **Outras Ações > Desfazer Exclusão** para os eventos Periódicos ou **Outras Ações > Excluir > Desfazer Exclusão** para os eventos Não Periódicos:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360044870794)  
  
**4.** Após selecionar a opção **Desfazer Exclusão**, será aberta uma nova tela para demonstrar o evento S-3000 que será desfeito:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360045733453)  
  
**5.** Confirme a ação. O evento S-3000 será excluído e a versão anterior do registro original será restaurada:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360045733813)
