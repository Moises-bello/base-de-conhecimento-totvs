# DISCIPLINAS DE TCC NA ANÁLISE CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Análise Curricular |
| **Situação/Requisito:** | A análise curricular está exibindo equivocadamente uma disciplina de TCC, aprovada por equivalência, na lista de disciplinas da matriz curricular e não apenas no espaço reservado para as disciplinas de TCC. |
| **Solução/Implementação:** | Alteração na tela de Análise Curricular para:  - retirar do grid de Matriz Curricular os TCCs que estão concluídos ou em andamento e possuem equivalência.  - incluir a informação de disciplina da grade no grid de TCC quando a disciplina for cursada por equivalência. |
