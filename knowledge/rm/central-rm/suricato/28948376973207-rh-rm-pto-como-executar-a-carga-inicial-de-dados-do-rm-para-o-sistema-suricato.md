![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/28948424827415) Tempo aproximado para leitura: **00:05:00 min****Dúvida**Como executar a carga inicial de dados do RM para o sistema Suricato  
  
**Ambiente**TOTVS RH - TOTVS RH(Linha RM) - Automação de Ponto - A partir da versão 12.1  
  
**Solução**

1.  Realize a configuração do RM para integração com o Suricato conforme documentação a seguir:

[RH - RM - PTO - Configuração do RM para integrar com o sistema Suricato](https://centraldeatendimento.totvs.com/hc/pt-br/articles/27719956683927)

2.  Acesse o cadastro de Seção no módulo Folha de Pagamento, guia Administração de Pessoal

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948424828311)

3.  Clique em Processos / Fórmula Visual / Gerenciar

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948376956439)

4. Na janela que será aberta (Gerenciamento de Fórmula Visual), clique em Processos de Fórmula Visual / Adicionar Fórmula Visual

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948456531991)

5.  Mantenha o filtro por Nome, digite um percentual (%) na caixa de entrada e clique no botão de filtrar. Selecione a Fórmula Visual Carga Inicial – TSA e confirme no botão OK

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948470786967)

6.  Na tela de Gerenciamento de Fórmula Visual com a fórmula da carga inicial adicionada, clique em OK para fechar

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948456539799)

7.  De volta ao cadastro de Seções do módulo Folha de Pagamento, selecione as seções que deseja integrar com o Suricato e clique em Processos / Fórmula Visual / Carga Inicial – TSA para iniciar o envio inicial de dados para o Suricato.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/28948456545687)
