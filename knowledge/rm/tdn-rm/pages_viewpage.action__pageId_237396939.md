# Data da baixa menor que a data de emissão na baixa com cheque

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa com cheque |
| **Situação/Requisito:** | No processo da baixa com cheque o parâmetro "Permite data de baixa menor que data de emissão" não verificado |
| **Solução/Implementação:** | Na baixa de lançamento com cheque emitido verificar se a data da baixa é menor que a data de emissão do lançamento conforme configuração do parâmetro "Permite data de baixa menor que data de emissão" |
| **Conversores e Parâmetros:** | Contas a Pagar ou Contas a Receber -> Baixa -> Manutenção de Baixas -> Baixa 1/5 -> Permite data de baixa menor que data de emissão |
