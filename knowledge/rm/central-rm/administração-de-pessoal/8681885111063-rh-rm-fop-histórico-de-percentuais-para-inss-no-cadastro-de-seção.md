**Dúvida**Como parametrizar o sistema para que o histórico de percentuais para INSS seja preenchido no cadastro da seção?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Como o processo referente a parametrização do Histórico de Percentuais para INSS no cadastro de Seção é demasiado extenso, foi disponibilizado um manual completo no TDN para servir de base de consulta e para tirar as dúvidas em relação a parametrização geral.

Saiba mais:  **[Histórico de Percentuais para INSS no anexo do cadastro de seção](https://tdn.totvs.com/pages/releaseview.action?pageId=493623930)
