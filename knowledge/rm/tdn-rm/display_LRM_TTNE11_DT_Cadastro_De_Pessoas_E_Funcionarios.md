# CADASTRO DE PESSOAS E FUNCIONÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Gestão de Pessoas* |
| **Função:** | *Cadastro de Pessoas e Funcionários* |
| **Situação/Requisito:** | *Ao realizar a admissão de um funcionário, digitar os dados da unicidade (CPF ou os campos básicos), se existir uma pessoa com estes dados de unicidade, o sistema sugere a seleção desta pessoa, porém ao realizar esta operação é apresentado o erro "Referência de objeto não definida para uma instância de um objeto".* |
| **Solução/Implementação:** | *Ajuste em processo de admissão, cadastro de novas pessoas e candidatos afim de que não gere erro ao selecionar um pessoa já existente na base de dados.* |
