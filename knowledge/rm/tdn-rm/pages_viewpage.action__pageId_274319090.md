# Imprimir Evolução Automaticamente ao Salvar

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prontuário Eletrônico do Paciente |
| **Situação:** | Ao adicionar a evolução do paciente e clicar em salvar, o sistema deveria automaticamente imprimir a evolução do paciente. |
| **Solução:** | Se o parâmetro (Imprime Automaticamente Evolução Médica ao Salvar) estiver marcado e o usuário salvar uma nova evolução, o sistema automaticamente irá imprimir a evolução do paciente. |
