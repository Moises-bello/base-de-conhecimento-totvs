# Relatórios - Extrato de Cliente/Fornecedor

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Relatórios - Extrato de Cliente/Fornecedor |
| **Situação/Requisito:** | Ao gerar relatório de Extrato de Cliente/Fornecedor, são apresentados valores incorretos para o Saldo Anterior/Inicial. O valor do tributo está sempre somando no Saldo Anterior/Inicial. |
| **Solução/Implementação:** | Otimização no processo de Extrato de Cliente/Fornecedor. Agora o sistema respeita o parâmetro "Subtrair impostos e tributos do valor do lançamento" para o Saldo Anterior/Inicial, subtraindo o valor dos tributos no saldo Anterior/Inicial caso marcado. |
