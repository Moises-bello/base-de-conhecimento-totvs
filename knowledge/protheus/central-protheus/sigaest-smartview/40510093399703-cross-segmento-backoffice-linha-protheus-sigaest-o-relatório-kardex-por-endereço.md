O relatório SmartView apresentava dados incorretos, exibindo informações de outro armazém indevidamente. A solução foi ajustar o layout do relatório para corrigir o agrupamento das informações.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40510093388567) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
O relatório gerado pelo smartview apresenta informações incorretas, exibindo dados de outro armazém indevidamente, além de não mostrar os dados corretos que deveriam aparecer. Como corrigir?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.

**Solução**  
Ajustado o layout de relatório do smartview considerando um agrupamento de informações para impressão.
