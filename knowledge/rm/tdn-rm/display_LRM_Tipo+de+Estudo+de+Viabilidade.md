O tipo de é o cérebro da análise de viabilidade e por isso é obrigatório seu cadastro/ importação. A TOTVS disponibiliza um tipo de estudo padrão que atende a análise de viabilidade para empreendimentos imobiliários. O diferencial do produto é que se trata de um recurso com seu código aberto, permitindo alteração ou adequação da regra ali estabelecida. Entende-se como regra os métodos de calculo, fórmulas, defaults e até mesmo a forma que o resultado será gerado, como por exemplo, o fluxo de caixa. Uma vez alterada o tipo de estudo pelo cliente, a TOTVS não se responsabiliza pelos dados obtidos a partir desta alteração.

Para criar um novo Tipo de Estudo, temos que primeiramente criar um Tipo de Estudo clicando no botão "Novo" e informar o Campo "Nome" e o campo "Tipo de Código".

**Nome:** indentificará através de uma descrição, o novo tipo de estudo que está sendo criado.

**Tipo de Código:** irá indentificar em qual linguagem de programação o novo Tipo de Estudo será desenvolvido. Estará disponivel a linguagem C# e Visual Basic (VB).

Logo em seguida, Clicar na Aba "Configuração".

Por padrão, todo Tipo de estudo tem 3 tipos de Informações básicas, que são:

**Parâmetros:** é a entrada de dados do Estudo; o que ele vai ser informado ao Estudo para que possa ser gerado os resultados através do processamento do Parâmetros;

**Lançamentos:** são informações que serão exibidas no fluxo de caixa;

**Indicadores:** são os resultados finais obtidos através do processamento dos Parâmetros;

Para cada tipo de Informação anterior podemos desenvolver/criar.
