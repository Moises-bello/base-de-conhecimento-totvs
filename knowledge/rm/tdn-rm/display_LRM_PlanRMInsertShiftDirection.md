---

2
complete

# Descrição

---

Define se deve deslocar as células para a direita ou para baixo após células serem inseridas.

# Membros da classe

---

## Métodos

|  |  |
| --- | --- |
| Right | Define que as células devem ser deslocadas para a direita quando células forem inseridas |
| Down | Define que as células devem ser deslocadas para a baixo quando células forem inseridas |
