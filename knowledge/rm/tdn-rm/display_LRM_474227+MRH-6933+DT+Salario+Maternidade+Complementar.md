# SALÁRIO MATERNIDADE COMPLEMENTAR NO MÊS DE FEVEREIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Salário Maternidade |
| **Situação/Requisito:** | No cálculo da Licença Maternidade Complementar (CC 352) no mês de fevereiro não está considerando 30 dias para funcionário mensalista.  O evento está sendo lançado totalizando apenas 28 dias no mês. |
| **Solução/Implementação:** | Ajuste no cálculo do CC 352 (Licença Maternidade Complementar) no mês de fevereiro para funcionários mensalistas. |
| **Tickets relacionados:** | MRH-6933 |
