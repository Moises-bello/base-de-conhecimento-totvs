![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15620008307607) Tempo aproximado para leitura: **00:01:04 min****Dúvida**Como criar novos tipos de lançamentos para os eventos programados do funcionário?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/15619694667031)

**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**O campo **Tipo de Lançamento**, é alimentado pela tabela dinâmica **TPEVTPROG**, novos itens devem ser adicionados na respectiva tabela.

1. Acesse: **Administração de Pessoal | Cadastros Globais | Tabelas Dinâmicas**;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/15619888154263)

2. Selecione o sistema **RH | Folha de Pagamento**;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/15619858185111)

3. Localize a tabela dinâmica **TPEVTPROG** e inclua os itens conforme a necessidade;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/15619855405463)
