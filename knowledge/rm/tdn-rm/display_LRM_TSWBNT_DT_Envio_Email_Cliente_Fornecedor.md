# Envio de E-mail para Cliente/Fornecedor

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Estoque, Compras e Faturamento.* |
| **Função:** | *Envio de E-mail para Cliente/Fornecedor* |
| **Situação/Requisito:** | Ao enviar um relatório por e-mail, através do Processo "Enviar E-mail para Cliente/Fornecedor", o relatório foi enviado corrompido, apresentado a seguinte mensagem no momento de abrir o arquivo:  "O Adobe Reader não pôde abrir 'Ordem%20de%20Compra.PDF' porque não há suporte a esse tipo de arquivo ou ele foi danificado (por exemplo, foi enviado como anexo de e-mail e não foi decodificado corretamente)." |
| **Solução/Implementação:** | Ajuste realizado no processo responsável por enviar e-mail para o cliente/fornecedor. Ajustado o tipo de geração do arquivo para garantir que o mesmo não chegue corrompido ao destinatário. |
