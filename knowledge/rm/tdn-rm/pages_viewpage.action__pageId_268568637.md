# Lançamento - Boleto

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento - Boleto |
| **Situação/Requisito:** | Ao acessar a visão de Boletos, selecionar um registro, ir em Processos > Relatórios > Impressão de Boletos a  mensagem abaixo é exibida: "Boleto Ref. 81710 - Somente é possível imprimir boleto registrado.". Alguns  clientes não concordam com esta validação já que a obrigatoriedade da FEBRABAN passa a valer apenas em 2017. |
| **Solução/Implementação:** | Otimização na impressão de boleto. Agora ao executar o processo, o sistema exibe o alerta "Atenção! Existem  boletos não registrados a serem impressos!" e deixa a escolha do cliente continuar a execução do processo. |
