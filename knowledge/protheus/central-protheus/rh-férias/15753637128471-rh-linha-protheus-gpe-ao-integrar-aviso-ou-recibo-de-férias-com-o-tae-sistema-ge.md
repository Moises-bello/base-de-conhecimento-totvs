![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34703712486935) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Ao integrar aviso ou recibo de férias com o TAE, sistema gera log de Recibo ou aviso não enviados.  
Login realizado com sucesso!  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/15753515899415)  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Causa**Diretório para impressão inválido.  
  
**Solução**Após configuração do TAE para integração de recibos e avisos de férias, na rotina de férias, pelo caminho **>Miscelânea >Cálculos >Férias >Outras Ações >Assinatura Eletrônica**, no campo de diretório no bloco de Tipo de impressão, informe um caminho válido de uma pasta na máquina que esta sendo realizada a integração:  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/15753603615511)
