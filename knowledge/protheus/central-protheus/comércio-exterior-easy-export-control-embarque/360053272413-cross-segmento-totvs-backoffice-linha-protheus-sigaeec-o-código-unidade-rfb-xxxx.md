![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:02:00 min****Dúvida**Ao enviar o registro da DUE apresenta a mensagem: O código UNIDADE RFB: XXXXXX não é válido. Recurso não encontrado [SUCE] , como corrigir?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Export Control* – A partir da versão 12.   
  
**Solução**A mensagem é apresentada quando o URF informando não esta cadastrado no Siscomex, sendo necessário alterar no Embarque (EECAE100), o conteúdo informado:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360085283174/mceclip0.png)

É possível verificar os URF válidos através do Siscomex link: <https://www35.receita.fazenda.gov.br/tabaduaneiras-web/public/pages/security/login_publico.jsf>
