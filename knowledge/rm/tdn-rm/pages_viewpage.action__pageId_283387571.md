# Integração Bancária - Retorno de Cobrança

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Retorno de Cobrança |
| **Situação/Requisito:** | Ao importar arquivo de retorno o sistema apresenta uma mensagem de erro informando diferença nos valores do lançamento para com o arquivo, mas o sistema não está respeitando o parâmetro ‘No retorno bancário utilizar os valores(juros, multa e desconto) do arquivo, sobrepondo os do lançamento’. |
| **Solução/Implementação:** | Efetuar o retorno de cobrança respeitando o parâmetro ‘No retorno bancário utilizar os valores(juros, multa e desconto) do arquivo, sobrepondo os do lançamento’ |
