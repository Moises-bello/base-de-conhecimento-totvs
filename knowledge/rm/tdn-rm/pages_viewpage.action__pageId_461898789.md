# GERAÇÃO DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de movimentos em regime de caixa |
| **Situação/Requisito:** | Ao gerar movimento utilizando rateio por centro de custo, o sistema não carrega as informações de centro de custo para os movimentos, gerando erro quando a informação for obrigatória. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimento em regime de caixa, de forma que o sistema, ao gerar movimento para um lançamento que tenha rateio por centro de custo, as informações do rateio sejam enviadas para o movimento. |
