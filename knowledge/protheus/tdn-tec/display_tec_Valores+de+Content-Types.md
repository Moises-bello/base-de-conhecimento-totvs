Valores de Content-Types

Para algumas funções Http pode ser necessário especificar o tipo de conteúdo que está sendo enviados na requisição. A lista abaixo contempla todos os Content-Types possível suportados pelo protocolo Http.

## Application

| Nome |
| --- |
| ``` application/EDI-X12 ``` |
| ``` application/EDIFACT ``` |
| ``` application/javascript ``` |
| ``` application/octet-stream ``` |
| ``` application/ogg ``` |
| ``` application/pdf ``` |
| ``` application/xhtml+xml ``` |
| ``` application/x-shockwave-flash ``` |
| ``` application/json ``` |
| ``` application/ld+json ``` |
| ``` application/xml ``` |
| ``` application/zip ``` |
| ``` application/x-www-form-urlencoded ``` |
| `application/graphql` |
