A proposta do relatório consolidado de medição de contrato é apresentar todos os valores do contrato, incluindo o valor unitário inicial, valor atual, valor medido e, caso aplicável, valor reajustado. Além disso, o relatório também exibe informações sobre a quantidade contratada até a quantidade acumulada, com o intuito de ter uma visão geral de cada contrato do seu projeto.

Importante:

Será necessário realizar o processo de associação de itens/objetos ao contrato para o mesmo aparecer no cubo.

Este cubo contém apenas um campo para inserir a parametrização, que é o código da coligada. Dessa forma, à esquerda, ele exibe todos os projetos cadastrados para essa coligada específica no sistema. A hierarquia deste cubo segue a seguinte estrutura: Nome do projeto → nome fantasia/social do cliente/fornecedor do contrato → finalidade do contrato → campos básicos.
