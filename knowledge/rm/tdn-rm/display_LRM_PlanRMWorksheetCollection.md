# Descrição

---

Essa classe representa as planilhas existentes em um livro (arquivo). Métodos para adição e remoção de planilhas, bem como métodos para listagem se encontram nessa classe.

# Membros da classe

---

## Propriedades

|  |  |
| --- | --- |
| Count | Retorna a quantidade de planilhas do livro. |
| First | Retorna a primeira planilha do livro. |
| Item | Retorna uma planilha buscando pelo seu nome ou pelo seu índice. |
| Last | Retorna a última planilha do livro. |
| Workbook | Retorna o livro proprietário dessa coleção de planilhas. |

## Métodos

|  |  |
| --- | --- |
| Add | Adiciona uma planilha ao livro. |
| AddAfter | Adiciona uma planilha ao livros depois da planilha passada como parâmetro. |
| AddBefore | Adiciona uma planilha ao livros antes da planilha passada como parâmetro. |
| Contains | Verifica se a coleção contém a planilha especificada. |
| CopyAfter | Copia uma planilha e a insere depois da planilha passada como parâmetro. |
| CopyBefore | Copia uma planilha e a insere antes da planilha passada como parâmetro. |
| Delete | Remove a planilha passada como parâmetro. |
| GetEnumerator | Retorna o enumerador das planilhas. |
| SheetIndex | Busca pelo índice da planilha a partir do nome. |
