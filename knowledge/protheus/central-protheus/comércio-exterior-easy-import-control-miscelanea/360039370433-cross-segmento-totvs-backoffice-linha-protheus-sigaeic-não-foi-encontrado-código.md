**Dúvida**Não foi encontrado código do despachante?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões

**Solução**O incidente ocorre pois o TXT não obedece o layout de integração, exemplo o TXT de integração de despesas não possui código de despachante informado e este é obrigatório, o processo de desembaraço não possui referencia cadastrada; **![](https://totvssuporte.zendesk.com/attachments/token/Uw8XoXafE4Dh94qQNHDxlgGv6/?name=inline709994457.png)**
