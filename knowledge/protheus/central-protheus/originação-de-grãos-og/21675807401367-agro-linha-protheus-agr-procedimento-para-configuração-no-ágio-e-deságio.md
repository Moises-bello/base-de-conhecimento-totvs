Como realizar um **Procedimento para Configuração no Ágio e Deságio**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12.1.23  
  
**Solução**  
Para solucionar essa dúvida, realize os seguinte passo:

**1.** Verifique no **Configurador - SIGACFG**, em **Acessos > Cadastros > Parâmetros - CFGX017**. Realize a **Configuração dos Parâmetros**.

| --- | --- |
| Itens/Massas | Descrição |
| **Nome:** | MV\_AGRO005 |
| **Tipo:** | *Lógico* |
| **Cont. Por.:** | *.T.* |
| **Descrição:** | Permite indicar se as funcionalidades de Ágio e Deságio devem estar disponíveis no cadastro de Contratos de Venda (OGA290). |
