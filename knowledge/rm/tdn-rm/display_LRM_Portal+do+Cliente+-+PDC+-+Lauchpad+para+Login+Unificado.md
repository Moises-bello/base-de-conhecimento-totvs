A partir do Release 12.1.2502, ao logar nos portais do TCGI, caso o usuário tenha mais de um contexto de acesso (Contrato de Venda, Contrato de Locação, Contrato de Shopping, Administrador de Shopping) o sistema apresentará a ele uma tela com as opções para ele escolher qual contexto ele deseja acessar, conforme exemplo abaixo:

O usuário cockpit realiza login no portal:

Como este usuário possui contratos de vendas, de locação de imóveis e de shopping, o sistema apresenta a tela abaixo com os seguintes contextos para a continuidade do acesso:

*Selecione um dos Portais:*

* + [Portal do Cliente - Incorporação](https://tdn.totvs.com/pages/viewpage.action?pageId=435105150);
  + Portal do Cliente - Locação;
  + Portal do Cliente - Lojista

Ao selecionar o contexto desejado, o mesmo será direcionado para o seu respectivo portal.

Para voltar a esta opção de seleção do contexto, o usuário deverá fazer o logout no portal do contexto atual e logar novamente.

Importante!

Caso o usuário tenha acesso a somente um dos módulos dos contextos acima, esta tela de seleção não será apresentado e o cliente será direcionado diretamente para o portal que ele tenha contratos.
