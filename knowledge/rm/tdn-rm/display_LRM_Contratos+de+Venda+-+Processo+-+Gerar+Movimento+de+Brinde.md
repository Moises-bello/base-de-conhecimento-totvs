Alguns clientes utilizam a rotina de repasse de brinde aos seus clientes que negociam imóveis com as imobiliárias. O gerenciamento dos brindes é feito através da geração de Movimentos.  
  
 Nesta tela, o usuário deve preencher estas informações para realizar a geração de um movimento de Brinde. O movimento será enviado para o **TOTVS Gestão de Estoque, Compras e Orçamentos**.

* **Parâmetros default Movimento:** Um parâmetro traz algumas definições para geração do movimento.
* **Data Emissão:** Data de emissão do movimento.
* **Data de Entrega:** Data de entrega do brinde. Por default o sistema irá trazer a Data de Entrega da Chaves preenchida na Venda, e na ausência desta data irá trazer a Data de Entrega do Empreendimento vinculado na venda.
* **Código do Movimento:** Tipo de movimento que será usado para a geração do movimento de brinde.
* **Filial:** Filial que será gerado o movimento.
* **Centro de Custo:** Centro de custo que será gerado o movimento.
* **Histórico Movimento:** Histórico do movimento é preenchido com os mnemônicos usado no Parâmetros do Movimento
* **Produto / Serviço:** Local onde o usuário define a quantidade do produto a ser repassado como brinde.

Todos os campos acima, são definidos no Parâmetros default do movimento.

Para realizar a geração, o usuário deve clicar no **botão Executar**. Com isso, o movimento será gerado **TOTVS Gestão de Estoque, Compras e Orçamentos.**   
 Para visualizar o movimento criado, acesse o Anexo de Vendas/Aluguel chamado .
