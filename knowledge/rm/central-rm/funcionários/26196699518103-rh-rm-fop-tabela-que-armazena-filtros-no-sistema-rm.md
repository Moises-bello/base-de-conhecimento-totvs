![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26196757284247) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**No módulo Folha de Pagamento, qual tabela que armazena os filtros gerados na tela de funcionários no Sistema RM?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Os filtros criados na tela de funcionários são armazenados na tabela **Gfiltros**. Esta tabela é responsável por guardar as configurações e os critérios de filtragem que você define para personalizar suas consultas e relatórios no sistema.
