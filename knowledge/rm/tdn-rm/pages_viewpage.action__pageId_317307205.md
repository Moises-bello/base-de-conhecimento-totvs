# Processo Seletivo Terceirizado

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Processo seletivo terceirizado* |
| **Situação/Requisito:** | *Quando o candidato já é nosso aluno ou quando um pai ou mãe já é responsável financeiro de outro aluno (o irmão por exemplo), o Processo Seletivo Terceirizado não permite matricular (levar para o Educacional), informando que CPF já está em uso.* |
| **Solução/Implementação:** | *Correção do processo de matricula pelo processo seletivo terceirizado, o sistema agora verifica se existe uma pessoa cadastrada no Gestão de Pessoas, de acordo com a regra de unicidade informada nos parâmetros de validação do Gestão Pessoa. Caso exista o sistema vincula essa pessoa a pessoa a ser cadastrada pelo processo seletivo terceirizado.* |
