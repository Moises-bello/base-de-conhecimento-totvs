Ocorrência**Função HttpsGet retorna vazio após aplicação de ultimo release.  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) - ADVPL -A partir da versão 12.1.17  
  
**Causa**Após aplicação de ultimo release  
  
**Solução**Com a atualização do Application Server para a data de 27/07/2018 e com a adição da letra "S" no protocolo HTTP para HTTPS do link enviado, o erro não foi mais reproduzido, assim sendo, segue abaixo o link para download do mesmo:

**[18-07-27-P12\_APPSERVER\_WINDOWS.ZIP](https://suporte.totvs.com/portal/p/10098/download#detail/657319)**

[**18-07-30-P11\_APPSERVER\_WINDOWS\_X64.ZIP**](https://suporte.totvs.com/portal/p/10098/download#detail/655910)
