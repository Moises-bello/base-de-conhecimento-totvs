# HISTÓRICO SALARIAL NA RESCISÃO POR TRANSFERÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão por Transferência* |
| **Situação/Requisito:** | *Na rescisão por transferência está criando um novo histórico salarial para o funcionário, mesmo sendo transferido com o mesmo salário.* |
| **Solução/Implementação:** | *Tratar no processo de rescisão por transferência para só criar um novo histórico salarial quando houver alteração de salário, ou quando estiver marcado para não transferir históricos.*  *O ajuste será para transferência na mesma coligada ou para outra coligada.* |
