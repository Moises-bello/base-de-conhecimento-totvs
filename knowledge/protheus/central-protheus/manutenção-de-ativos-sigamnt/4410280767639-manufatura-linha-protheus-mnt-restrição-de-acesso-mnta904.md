**Dúvida**  
Para que serve a rotina **Restrição de Acesso - MNTA904**?  
  
**Ambiente**  
TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Manutenção de Ativos (SIGAMNT) - Todas as versões  
  
**Solução**  
Essa rotina permite efetuar o cadastramento de**Restrições de Acesso - MNTA904**, estas que podem ser referentes a um usuário ou grupo de usuários do **Microsiga Protheus**. Estas restrições são consideradas apenas para as rotinas visuais do módulo **Manutenção de Ativos - SIGAMNT**, ou seja, as rotinas em que as restrições e controle de acesso realizado pelo **Configurador - SIGACFG** não tem **Suporte**.  
São afetadas pelo processo de restrição de acesso as rotinas:

* **Árvore Lógica - MNTA902**
* **Planta Gráfica - MNTA907**
* **Solicitação de Serviço - MNTA280**
* **Distribuição de Solicitação de Serviço MNTA296**
* **Portal de S.S. - MNTI005**
* **Atendimento - MNTA901**
