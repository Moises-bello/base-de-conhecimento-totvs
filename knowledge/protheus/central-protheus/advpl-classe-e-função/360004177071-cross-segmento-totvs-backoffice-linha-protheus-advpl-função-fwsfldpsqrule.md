**Dúvida**Tem alguma função, que atrele os privilégios ao usuário?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL – Todas versões  
  
**Solução**Função FWSFLdPsqRule - Esta função retorna a lista de usuários que possui uma regra atrelada a seu código:

```
@param cSeek Id do privilégio  
@return aUser Array com o usuários
```
