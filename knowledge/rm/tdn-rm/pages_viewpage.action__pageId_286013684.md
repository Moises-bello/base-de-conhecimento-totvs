# Ajuste no Lançamento de Honorário na Conta do Paciente

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao realizar uma solicitação de procedimento com coparticipação maior que o valor do procedimento, o sistema lançava valores negativos na conta do paciente. |
| **Solução:** | Realizado ajuste para não lançar valor negativo na conta do paciente quando o valor da coparticipação for maior que o valor do procedimento. |
