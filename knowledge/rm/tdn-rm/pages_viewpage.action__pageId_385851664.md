# 3029482 DSAUGHFATF-831 Sistema não está lançando a consulta como FORA DA CONTA em atendimento de RETORNO.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Totvs Gestão Hospitalar |
| **Função:** | Lançamento de consulta em retorno por regra de especialidade |
| **Situação/Requisito:** | Ao lançar uma consulta no atendimento em retorno (usando como regra de retorno a especialidade) o item não está caindo fora da conta |
| **Solução/Implementação:** | Ao lançar uma consulta no atendimento em retorno (usando como regra de retorno a especialidade) o item irá cair fora da conta |
| **Tickets relacionados:** | 3029482 |
| **Requisito:** | DSAUGHFATF-831 |
