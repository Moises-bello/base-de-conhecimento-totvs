Os campos complementares podem ser usados para acrescentar mais informações em alguns cadastros, tais como:

* Extrato de Caixa
* Clientes/Fornecedores
* Lançamentos
* Contatos do Cli/For
* Itens de Baixa

Para incluir um campo complementar, na pasta identificação clique no botão "Novo", e informe:

Nome da Coluna

Informe um nome para o campo complementar. Este campo não poderá conter números, somente caracteres serão aceitos.

Descrição

Informe a descrição do campo complementar.

Especificação

Tipo: Escolha o tipo da coluna a ser inserida, podendo ser, alfanumérico, data, inteiro ou real.

Tamanho

Se o tipo for Alfanumérico, informe o tamanho do campo.

Valor default

Informe o valor default para o campo. Este valor tem duas funções:

* Informar qual o valor default que o sistema irá utilizar quando da inclusão de um novo registro.
* Alterar o respectivo campo complementar dos registros que estiverem com o referido campo vazio.

Tabela Dinâmica

Nesse campo pode ser informada uma tabela dinâmica.  
Essas tabelas são cadastradas no menu Cadastros | Tabelas Dinâmicas.

Pesquisa Tabela Dinâmica por

Através deste campo você pode escolher como será a pesquisa de uma opção da tabela dinâmica no campo complementar, você pode pesquisar esta opção pelo Código ou pela Descrição.

**Observações**:

Os Campos Complementares que forem incluídos estarão disponíveis na aba “Campos Complementares” de cada cadastro definido na sua inclusão.

Ao clicar no botão "Excluir", o campo complementar passará a ficar inativo, permanecendo na base de dados. Para ativá-lo novamente, clique no ícone "Ativar" que fica no canto inferior direito da tela do cadastro.
