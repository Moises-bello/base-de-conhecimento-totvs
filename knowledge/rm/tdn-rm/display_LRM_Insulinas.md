## **01. VISÃO GERAL**

Possibilidade de prescrever insulina fixa e controle de glicemia capilar para o paciente através da prescrição médica.

Exemplo de utilização

## **02. EXEMPLO DE UTILIZAÇÃO**

No submenu de insulinas ao marcar a opção de inserir o usuário terá a opção de prescrever insulina fixa e/ou controle de glicemia capilar.

Insulina fixa

## **03.****INSULINA FIXA**

Escolhendo a opção insulina fixa, será aberto uma tela onde será possível a prescrição da mesma. No campo de busca o usuário terá acesso a todos os itens da lista ou poderá buscar por um item especifico. Poderá ser adicionado um ou mais itens por vez.

Ao selecionar os itens, será criada uma lista na parte inferior para as definições dos campos via, dose, quantidade, complemento, início, insulina continua e observação.

A partir da versão 2209 é possível indicar via parâmetro da unidade para não obrigar o preenchimento do campo complemento:

O default é vir marcado esse campo.

O usuário poderá adicionar mais de um o mesmo procedimento, basta clicar no botão de adicionar.

Para adicionar uma observação, basta selecionar o checkbox correspondente.

Ao selecionar o checkbox de Insulina contínua serão exibidos campos para informação de diluição.

Caso seja selecionado a opção "Bomba de infusão" o campo tempo de infusão será habilitado.

Após o preenchimento de todos os campos obrigatórios, poderá ser possível adicionar os itens clicando no botão de incluir.

Ao incluir, os itens deverão ser carregados para dentro do menu de Insulinas que deverá ficar descrito o tipo do item juntamente com algumas informações básicas.

Controle de glicemia capilar

## **04.****CONTROLE DE GLICEMIA CAPILAR**

Escolhendo a opção controle de glicemia capilar, será aberto uma tela onde será possível a prescrição da mesma.

Inicialmente serão visíveis somente os campos relacionados a hipoglicemia mas caso seja selecionado a opção Insulina variável, os campos relacionados a hiperglicemia serão exibidos.

Após o preenchimento do valor de hipoglicemia o campo "Medicamento" e a opção "Se  outro tratamento" serão habilitados.

Se algum medicamento for selecionado, os campos relacionados a ele também serão disponibilizados.

Entretanto caso a opção "Se outro tratamento" for escolhida os campos de medicamento serão limpos, bloqueados e o campo "Outro tratamento" liberado.

No grupo de hiperglicemia, caso o campo "Insulina" seja preenchido os campos relacionados a ele serão disponibilizados.

Inicialmente virão 6 intervalos como padrão, mas é possível inserir ou remover intervalos de acordo com o que o usuário necessite. Para realizar a exclusão de intervalo é necessário escolher o intervalo e selecionar a opção de exclusão. É obrigatório preenchimento de ao menos um intervalo para a inserção de hiperglicemia.

Após o preenchimento dos campos obrigatórios (frequência, insulina, dados intervalo) a opção de incluir será habilitada

Ao incluir, os itens deverão ser carregados para dentro do menu de Insulinas que deverá ficar descrito o tipo do item juntamente com algumas informações básicas.
