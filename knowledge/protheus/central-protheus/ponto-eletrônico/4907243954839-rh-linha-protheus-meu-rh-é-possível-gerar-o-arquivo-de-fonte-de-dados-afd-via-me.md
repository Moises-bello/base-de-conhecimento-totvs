**Dúvida**  
MEU RH - É possível gerar o Arquivo de Fonte de Dados (AFD) via Meu RH?  
  
**Ambiente**  
TOTVS RH - (Linha Protheus) - MEU RH - Todas as versões  
  
**Solução**  
O App Meu RH não emite o **AFD**, ele somente é o registrador das marcações para inserção no sistema Protheus. O Protheus, que recebe os dados é responsável pela geração do **AFD**. Sendo assim, caso seja utilizado o SIGATCF (Terminal de Consulta de Funcionários), é possível obter o arquivo por ele.  
  
Lembrando que, o App Meu RH é considerado um REP A, **onde pela Portaria 671**, não é necessário gerar **nenhum tipo de comprovante para as marcações**., que por sua vez, sendo o App Meu RH integrado com o SIGAPON, é possível visualizar de forma instantânea a marcação de ponto no espelho ou em relatórios.   
  
**Obs**: Essa funcionalidade é **exclusiva para o protheus, ou seja gerar o AFD do MEU RH e fazer a leitura do mesmo pela rotina PONM010 - Leiura e Apontamento das marcações, caso precise. Não recomendamos o uso para validação de terceiros.**  
   
Será possível, **pelo Protheus, a geração de um AFD com as marcações**, inclusive as de **geolocalização**, conforme informações do Desenvolvimento do Meu RH.
