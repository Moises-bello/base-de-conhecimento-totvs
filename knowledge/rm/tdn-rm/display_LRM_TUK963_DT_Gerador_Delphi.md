# CAMPO TOTALIZADOR FGTS PROVISÃO 13° RELATÓRIO GERADOR DELPHI

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Relatório - Totalizador FGTS, provisão 13° no gerador delphi* |
| **Situação/Requisito:** | Ao gerar o relatório 03.018-Provisão de Férias e 13º por Seção - MSSQL.RRM para os funcionários é apresentado o valor referente a cada funcionário nas colunas e os totais de cada seção. Porém na última coluna referente a provisão 13º o valor referente a FGTS está somando o valor de total da seção na seção seguinte. |
| **Solução/Implementação:** | Gerar o relatório "03.018-Provisão de Férias e 13º por Seção - MSSQL", sendo que na coluna do totalizador FGTS referente a  provisão de 13°, o totalizador deve ser zerado a cada seção. |
