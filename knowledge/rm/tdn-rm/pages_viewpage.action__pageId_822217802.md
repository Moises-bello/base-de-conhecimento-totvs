## **VISÃO GERAL**

A página "Agendar" possui um completo e intuitivo processo baseado em etapas que irá guiar o paciente no agendamento de uma consulta e/ou exame, tendo como principais características:

* Agendar consultas, sejam estas presenciais ou online (teleconsultas);
* Agendar exames ;
* Permitir o agendamento de pacientes logados no Portal (possuem uma conta válida e ativa no Portal do Paciente), assim como para outra pessoa (dependente);
* Permitir o cadastro de um ou mais convênios de saúde;
* Selecionar a especialidade da consulta, exame e/ou procedimento disponível;
* Selecionar a melhor data/horário para o agendamento de acordo a disponibilidade das agendas;
* Receber notificação via e-mail e/ou SMS com a confirmação do agendamento, juntamente com todos os dados necessários referente ao agendamento.

## **EXEMPLO DE UTILIZAÇÃO**

Após efetuar o login no Portal do Paciente, o usuário será direcionado para a página "Home", onde poderá realizar uma agendamento clicando nos links disponíveis:

* Menu lateral > link "Agendar";
* Dashboard principal > link "Agendar consulta ou exame".

Entrando na página de "Agendamento", o usuário deverá seguir o processo (etapas), a fim de poder cadastrar todas as informações necessárias para o agendamento.

**Importante:**

* A etapa seguinte somente será liberada após o usuário informar todos os dados corretamente (cada etapa terá uma validação específica);
* Após avançar etapas, será possível navegar entre estas (anterior / próximo), a fim de confirmar e/ou ajustar alguma informação;
* Se o usuário sair do processo de agendamento antes de confirmar o mesmo, este será notificado e, caso confirme o cancelamento, todas as informações serão descartadas.
Agendar

## **AGENDAR**

01. Após efetuar o login no Portal do Paciente, clicar no link "Agendar" localizado na barra de menu lateral ou no link "Agendar consulta ou exame" localizado no dashboard principal.

02. Tela principal do processo de agendamento.

03. Caso alguma etapa tenha sido completada e o usuário estiver na primeira etapa (Dados do paciente) e clicar no botão "Voltar", o sistema irá notificar o usuário perguntando se o mesmo deseja realmente sair e cancelar o processo de agendamento.

04. Se o usuário clicar em "Sim", o sistema irá limpar todos os dados informados até o momento e o usuário será redirecionado para a página "Home". Se o usuário clicar em "Não", então o sistema permanecerá no processo de agendamento.
