# ANÁLISE CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Análise Curricular* |
| **Situação/Requisito:** | *Mudança no comportamento do cálculo da carga horária dos componentes curriculares na análise curricular/histórico (portal, mobile, relatório), sendo considerado os mínimos exigidos de cada componente.* |
| **Solução/Implementação:** | *Ajuste no cálculo das atividades curriculares na análise curricular/histórico (portal, mobile, relatório) para que seja feito o cálculo da forma anterior que continha na versão 12.1.7 e 12.1.8, que consiste em não considerar os mínimos de cada componente curricular cadastrado na matriz aplicada e sim carga horária total cumprida pelo aluno. Os relatório alterados foram o EDUREL0018 - Análise Curricular e EDUREL0028 - Histórico do Ensino Superior.* |
