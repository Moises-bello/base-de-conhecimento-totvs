Qual Data o sistema verifica para gravação do campo E1\_EMISSAO do título a pagar gerado pelo Documento de entrada?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Compras - Todas as versões

**Solução**O sistema busca a informação do campo F1\_EMISSÃO para gravação do campo E1\_EMISSÃO do título a pagar.
