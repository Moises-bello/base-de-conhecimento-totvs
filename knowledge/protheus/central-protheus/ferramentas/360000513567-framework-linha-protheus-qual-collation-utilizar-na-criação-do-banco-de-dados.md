**Dúvida**Qual *Collation* utilizar na criação do Banco de Dados?  
  
**Ambiente**Protheus - DBAccess - Todas as versões  
  
**Solução**Segue abaixo o *Collation* utilizado pelos bancos de dados homologados pela Totvs.

| **Banco de Dados** | **Collation** |
| --- | --- |
| IBM DB2 | IBM-1252 |
| IBM Informix | EN\_US\_CP1252 |
| Microsoft SQL | Latin1\_General\_BIN |
| ORACLE | WE8MSWIN1252 |
| PostgreSQL | C |
|  |  |

**Importante**Para informações sobre como configurar a ***Collation*** do banco de dados, entre em contato com seu **analista** **DBA** ou a equipe **TIS** (TOTVS Infra Services).
