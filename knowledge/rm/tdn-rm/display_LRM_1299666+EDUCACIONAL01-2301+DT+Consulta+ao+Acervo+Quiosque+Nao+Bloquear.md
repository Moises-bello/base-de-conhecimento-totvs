# CONSULTA AO ACERVO - QUIOSQUE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Bibliotecária |
| **Função:** | Consulta ao acervo - Quiosque |
| **Situação/Requisito:** | Foi identificado que a tela de consulta ao acervo do tipo QUIOSQUE está permitindo bloqueio automático e desconexão quando configurado nos parâmetros globais do RM, sendo que esta tela quando aberta trava as demais funções do sistema, sendo que só é possível fechar utilizando o login e senha do RM, sendo assim essa tela não pode ser bloqueada nem encerrada automática de forma alguma. |
| **Solução/Implementação:** | Foi feita uma implementação na framework e no gestão de biblioteca que impede o bloqueio e desconexão quando a tela do quiosque estiver aberta. |
