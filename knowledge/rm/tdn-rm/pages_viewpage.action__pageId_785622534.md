**03. SITUAÇÃO/REQUISITO**

Tratativa para integrar os dados do Funcionário com Feedz.

**04. SOLUÇÃO**

Disponibilizamos no produto de Folha de Pagamento o processo "Multi-Coligadas" para executar a integração.

Os dados integrados consistem em:

* Registros Auxiliares: Departamento, Cargo e Unidade
* Pessoas: Gestor direto e Colaborador

  + Nome
  + Nome Social
  + E-mail
  + Data de admissão
  + Nascimento
  + Data de demissão
  + Tipo/Motivo de demissão
