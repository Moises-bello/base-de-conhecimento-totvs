![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Ao alterar o campo "Adiantamento E4\_CTRADT" na Condição de Pagamento, apresenta o **"Help:** NOALTERA **Problema:** Não é permitido alterar pedidos c/ itens já faturados. SE4 - Adiantamento**".**

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415356085399/mceclip0.png)

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Faturamento(SIGAFAT) - A partir da versão 12.  
  
**Solução**

O Help apresentado, esta informando que para está condição de pagamento, já existem itens faturados com adiantamento, sendo assim não é possível realizar a alteração da condição de pagamento, sendo necessário realizar a inclusão de uma nova condição de pagamento.
