## **06. EXEMPLO DE UTILIZAÇÃO**

11Visualização via Smart View Agent

1. Acessar o **Smart View**.

2. Clicar em **Relatórios**.

3. Clicar em **Visualizar** no relatório desejado.

4. Informar os parâmetros **Data Início**, **Data Fim** e **Seção**, os parâmetros são obrigatórios.   
 **Importante:**

* Para conseguir preencher o campo de Seção é necessário clicar em Seção >
* Para filtrar todas as seções é necessário informar o valor -1
* Para filtrar mais de uma seção é necessário adicionar mais campos, fazemos isso clicando no botão  mais vezes

5. Clicar em **Enviar**.

6. O Relatório será exibido.

2Visualização via RM

1. Acessar o menu **Gestão**.

2. Clicar em **SV**.

3. Selecionar o recurso desejado.

4. Clicar com o **botão direito > Selecionar Outras Informações > Clicar em Execução de Recurso do Smart View**.

5. Informar os parâmetros **Data Início**, **Data Fim** e **Seção**, os parâmetros são obrigatórios.  
 **Importante:**

* Para conseguir preencher o campo de Seção é necessário clicar em Seção >
* Para filtrar todas as seções é necessário informar o valor -1
* Para filtrar mais de uma seção é necessário adicionar mais campos, fazemos isso clicando no botão  mais vezes

6. Clicar em **Enviar**.

7. O Relatório será exibido.
