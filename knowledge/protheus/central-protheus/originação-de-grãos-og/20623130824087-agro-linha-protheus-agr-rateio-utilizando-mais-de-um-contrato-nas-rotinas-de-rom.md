No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para efetuar um rateio usando mais de um contrato nas rotinas é apresentada a mensagem de aviso **Procedimento para uso de adição e supressão de contratos**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**  
Esse incidente ocorre, pois é preciso realizar o processo para efetuar um rateio usando mais de um contrato das rotinas no Sistema.  
  
**Solução**  
Para solucionar essa ocorrência, é  preciso efetuar o rateio por meio da aba **Comercialização**. Para isso é necessário inserir outra linha e preencher com as informações dos contratos. Conforme as linhas são inseridas com os contratos correspondentes são geradas as notas fiscais para cada contrato.
