Base de cálculo do tipo valor. Este evento deverá estar em chave desativada. Ao cadastrar uma rescisão, o usuário deverá informar o código de cálculo 033, para que o sistema efetue corretamente os cálculos de FGTS na rescisão.

**Observação**

Você não precisará informar o valor do evento na rescisão, pois o sistema buscará o valor do campo Saldo (Cadastros | Funcionários | Registro | pasta FGTS/SEFIP/INSS).
