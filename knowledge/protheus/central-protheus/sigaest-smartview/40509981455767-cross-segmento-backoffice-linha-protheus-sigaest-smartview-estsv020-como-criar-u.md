O artigo explica como criar e aplicar um filtro específico por Armazém no relatório de Posição de Estoque no TOTVS Smart View. O processo envolve acessar o relatório, adicionar uma condição de filtro pelo campo Armazém com o código desejado, salvar e aplicar o filtro para visualizar os dados restritos ao armazém selecionado.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40509946270743) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
Como criar e aplicar um filtro específico por Armazém no relatório de Posição de Estoque utilizando o TOTVS Smart View?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - A partir da versão 12.1.2310  
  
**Solução**  
Para aplicar um filtro de armazém no relatório de Posição de Estoque no Smart View, é necessário criar uma nova condição de filtragem nas configurações do relatório. Siga os passos descritos abaixo:

1. Acesse o relatório de Posição de Estoque no Smart View.
2. No painel lateral de Filtros, insira uma descrição no campo Nome de exibição (exemplo: Filtro Armazém 01).
3. Na seção Condições, clique no ícone de Adicionar (+) e selecione a opção Condições.
4. Na lista de Propriedades apresentada, selecione o campo Armazém.
5. No operador lógico, selecione a opção Igual a.
6. No campo de Valor, digite o código correspondente ao armazém desejado (exemplo: 01) e clique em Adicionar.
7. Clique no botão Salvar, localizado no canto inferior direito, para gravar o filtro.
8. Retornando à tela de parâmetros, certifique-se de que o filtro recém-criado está devidamente selecionado no campo superior.
9. Clique no botão Enviar para reprocessar a consulta e visualizar o relatório restrito aos dados do armazém selecionado.
