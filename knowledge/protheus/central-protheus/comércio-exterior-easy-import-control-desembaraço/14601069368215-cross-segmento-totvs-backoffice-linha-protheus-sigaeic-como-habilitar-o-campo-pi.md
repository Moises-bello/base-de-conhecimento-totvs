![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida** Como ativar no módulo de Importação *Easy Import Control* **(SIGAEIC)**,   o campo PIS/Cofins ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - A partir do release 12.1.33  
  
**Solução**  
Para habilitar o campo **"Reg trib. P/C"(EIJ\_REG\_PC)** verifique o valor do parâmetro **"MV\_AUTPCDI"**, o mesmo deve estar habilitado, com o valor **".T."** sem aspas.
