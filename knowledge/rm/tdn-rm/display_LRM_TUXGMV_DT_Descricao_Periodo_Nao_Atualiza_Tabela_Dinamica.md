# DESCRIÇÃO DO PERIODO NO PARAMETRIZADOR NÃO ATUALIZA TABELA DINAMICA PDESCPER

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Parametrizador* |
| **Situação/Requisito:** | *Ao criar um novo período e informar a descrição do mesmo em Configurações | Parametrizador | Configurações de Competência, o período criado não aparece na tabela dinâmica PDESCPER.*  *Com isto, a descrição do periodo não é atualizada no rodapé do sistema.* |
| **Solução/Implementação:** | *Ajuste para atualizar a tabela dinâmica PDESCPER sempre que for alterada a descrição do periodo mensal no Parametrizador.* |
| **Chamados   relacionados:** | *TUXGMV, TURDAB* |
| **Versões/Release:** | *11.82.44* |
