**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus compras - Todas as versões  
  
**Solução**

Caso necessite incluir um novo processo de integração no módulo PCO x Compras/Contratos ao qual não exista no padrão, deverá utilizar-se da numeração á partir do Código 90001, as numerações anteriores são reservados para processos padrões da TOTVS.

Para criação de novos processos é indispensável que sejam tratados á partir das variáveis :

PCOINILAN.

PCODETLAN.

PCOVLDLAN

PCOFILAN
