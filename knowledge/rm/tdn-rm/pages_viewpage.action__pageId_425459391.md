**Parâmetros  da integração Backoffice TOTVS Protheus x TOTVS Incorporação**

---

Os parâmetros da integração Backoffice TOTVS Protheus x TOTVS Incorporação  são responsáveis por definir o auto incremento de  alguns cadastros integrados, o meio de pagamento  e os percentuais de multa e juros.  
    
 **Pré-Condições:**

1- Ter executado o configurador da Integração Backoffice TOTVS Protheus x TOTVS Incorporação

**1-** Selecione o cadastro da integração e acesse: Anexos/ Parâmetros de Integração

**Os parâmetros são:**

|  |  |  |  |
| --- | --- | --- | --- |
| **Coligada** | **Nome do Parâmetro** | **Tipo** | **Valor** |
| 0 | CENTROCUSTOAUTOINC | Lógico | Selecione o CheckBox |
| 0 | CLIFORAUTOINC | Lógico | Selecione o CheckBox |
| 0 | CODMEIOPAGAMENTO | Número Inteiro | valor referenciando o código   do meio de pagamento |
| 0 | CONTACAIXAAUTOINC | Lógico | Selecione o CheckBox |
| 0 | GERARTITULONF | Lógico | Selecione o CheckBox |
| 0 | NATUREZAFISCALAUTOINC | Lógico | Selecione o CheckBox |
| 0 | PERCENTJUROSFIXO | Número Decimal | Informe o valor desejado |
| 0 | PERCENTMULTAFIXO | Número Decimal | Informe o valor desejado |
