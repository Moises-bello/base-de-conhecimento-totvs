# DIRF/Informe de Rendimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *DIRF em Arquivo* |
| **Situação/Requisito:** | *A DIRF.NET obriga o usuário ter uma seção centralizadora no cadastro de funcionário, sendo que isso não ocorria na DIRF antiga.* |
| **Solução/Implementação:** | *Criado o parâmetro para informar a seção centralizadora manualmente. Caso o cliente marque esse parâmetro o sistema vai considerar essa seção como a centralizadora na geração da DIRF e Informe de Rendimentos.* |
