# GERAÇÃO DE MOVIMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de movimento em regime de caixa |
| **Situação/Requisito:** | Utilizando geração de um movimento para cada lançamento, ao regerar os movimentos de um mesmo boleto, casa um deles esteja cancelado, os sistema acusa erro, pois um dos movimentos não possui referência válida. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de movimentos, permitindo ao sistema, gerar/regerar os movimentos de um mesmo boleto, mesmo que existam movimentos cancelados entre os movimentos do boleto. |
