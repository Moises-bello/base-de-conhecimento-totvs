A geração do QR code foi criada com o objetivo de facilitar o sincronismo entre o TOTVS Obras e Projetos e o TOP Mobile.

O processo foi inserido na visão dos usuários da mobilidade em "Controle |  Mobilidade | Usuários de Coletores Móveis".

Através dessa opção será permitido gerar o QR Code para o usuário informado, copiar o QR Code para a área de transferência e também será permitido enviá-lo via e-mail.

Para gerar o QR Code todos os campos devem estar informados e deve ser selecionada a opção "Gerar QR Code".

**URL do WebService:** URL para trafegar os dados do sincronismo.

**Usuário de acesso:** usuário do RM para acessar o TOP Mobile.

**Senha:** senha do usuário RM.

O envio de e-mail é realizado ao avançar para a segunda página do processo. Serão exibidos os usuários e os respectivos e-mails cadastrados para envio.

**Observação:**

Para realizar o envio do e-mail corretamente, deve estar preenchida a configuração de envio de e-mail em "Projetos | Parâmetros globais | Envio de E-Mails".  
 Para utilizar o QR Code, ao  abrir o TOP Mobile, selecione a opção de configuração para que a câmera seja habilitada para leitura, direcione o foco da câmera para o QR Code gerado e aguarde o processamento do sincronismo.  
 Após o sincronismo ser processado com sucesso via QR Code, os dados do projeto utilizado serão sincronizados.
