![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Por que rescisão complementar por dissídio não apresenta diferença de INSS saldo de salário no ID 0064?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para rescisão complementar por dissídio, a diferença de INSS saldo de salário é calculada no ID 0340, para isso, deve ser cadastrada uma verba relacionada ao ID 0340.  
O ID 0064 tem que ser configurado na aba dissídio vinculado ao ID 0340.
