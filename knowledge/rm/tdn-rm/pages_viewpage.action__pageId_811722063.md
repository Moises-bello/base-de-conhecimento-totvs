Enviar documento da matrícula no período letivo para assinatura com o **TOTVS Assinatura Eletrônica**.

false

Essa funcionalidade está disponível a partir do patch: 12.1.2402.

Para acessar o processo de integração é necessário que **RM** esteja devidamente parametrizado. **Para saber mais acesse** [Integração com TOTVS Assinatura Eletrônica](https://tdn.totvs.com/x/yCOOIQ).

Para conhecer o **TOTVS Assinatura Eletrônica** [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=605018639).

### 4.0 - Processo de envio de documento para assinatura

Ao executar este processo, o documento selecionado, será enviado para **TOTVS Assinatura Eletrônica** com o(s) destinatário(s) de assinatura previamente definido(s) no cadastro do documento.

Filtros enviados para o relatório

Cada relatório deve possuir os campos obrigatórios para correta emissão do relatório, os filtros são passados automaticamente pelo sistema. 

**Parâmetros obrigatórios**: CODCOLIGADA, RA, IDPERLET, IDHABILITACAOFILIAL

### 5.0 - Asssinatura do documento

Os destinatários devem acessar o seu e-mail e fazer uso do token e link para realizar a assinatura, conforme a orientação enviada no email. **Para saber mais acesse** [TOTVS Assinatura Eletrônica](https://tdn.totvs.com/x/fvccJ) na opção de **Funcionalidades | Fluxo do usuário | Assinando um documento |  Eletronicamente (Com com autenticação por envio de código por e-mail)**
