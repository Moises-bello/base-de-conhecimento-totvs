É possível registrar as várias rodadas de negociação com os fornecedores. Esse processo segue a ideia de Revisões de Projeto e o usuário deve selecionar a Rodada de Negociação desejada na visão de Projetos. O sistema considera a última Rodada de Negociação no processo de Equalização. Esse novo recurso pode ser usado para Licitações, usando somente tarefas ou com Licitações usando os Recursos (Insumo e Composição).  
 O sistema cria um novo projeto copiando todos os dados do projeto atual, para o projeto novo. Nesse instante, o projeto atual não será mais considerado no módulo de Equalização. Caso esse projeto atual esteja em NEGOCIAÇÃO, ele passa para o status de PARALIZADO.  Pois, o novo projeto criado será considerado como o projeto em NEGOCIAÇÃO.  
 Pode-se criar as Rodadas de Negociação em qualquer um dos projetos correspondentes às planilhas importadas, e criar Rodadas "em cima" da última rodada de Negociação já existente.  
 **Observação:** É aconselhável que recalcule o projeto se alguma alteração foi feita. Isso é necessário para garantir que o módulo de Equalização exiba os dados atualizados.
