# COPIAR AVALIAÇÕES ENTRE TURMAS DISCIPLINAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Copiar avaliações entre turmas disciplinas* |
| **Situação/Requisito:** | *Foi identificado uma inconsistência no processo de copia de avaliações entre turmar/disciplinas, quando a avaliação possui campos complementares, os valores não são copiados no processo de cópia, somente se os campos complementares possuírem valor default.* |
| **Solução/Implementação:** | **Foi identificado que só era considerado na cópia o valor default dos campos caso existissem, sendo assim, foi feito um ajuste para que copie também os valores definidos dos campos, para as novas avaliações geradas no processo de cópia.** |
