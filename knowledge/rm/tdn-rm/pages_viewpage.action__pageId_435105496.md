**Reajustar Tabela de Preço**    
   
Este processo permite que o usuário faça reajuste no preço das Sub Unidades que estão vinculadas no Empreendimento da Tabela de Preço a ser reajustada.  
   
A situação da Tabela de Preço deve ser Vigente.  
   
Ao iniciar o este processo o usuário deve selecionar a(s) Unidade(s) que terão o preço alterado.  
   
Avançando no Processo o usuário deverá escolher entre as opções:  
   
Percentual: Escolhendo esta opção o usuário deverá informar um percentual para acréscimo ou decréscimo no valor da sub-unidades a reajustar.  
   
Moeda: Possibilita selecionar uma moeda em um intervalo de tempo para corrigir o preço das sub-unidades pela variação da moeda neste intervalo de tempo. Onde a variação poderá ter valor inflacionário ou deflacionário.  
   
Valor: Nesta opção o usuário deverá informar um valor fixo para acrescentar ou decrementar (se negativo) do valor das sub-unidades a reajustar.  
   
Ao selecionar uma das opções acima o usuário deverá então informar o registro para a respectiva opção selecionada.  
   
Para Percentual será habilitado o campo Percentual Fixo.  
   
Para Moeda serão habilitados os campos Moeda, Data Inicial e Data Final.  
   
Para Valor será habilitado o campo Valor Fixo.  
   
Após a utilização deste processo a tabela de preço selecionada passará para a situação "Revogada", com isso o sistema criará uma nova tabela de preço criada terá a situação "Vigente".
