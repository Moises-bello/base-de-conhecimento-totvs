# ALERTA DE PERIODO DE FÉRIAS COLETIVAS NA RESCISÃO DURANTE LICENÇA REMUNERADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Rescisão* |
| **Situação/Requisito:** | *Quando ocorre a rescisão de um funcionário com menos de 1 ano de casa, que está em periodo de férias coletivas com dias de licença remunerada, não está emitindo o aviso de alerta sobre a situação de férias.*  *Deveria avisar o usuário que o funcionário está de férias, e perguntar se deseja finalizar estas férias automaticamente.* |
| **Solução/Implementação:** | *Ajuste na tela de cadastro de rescisão para considerar também funcionários com menos de 1 ano de casa, em periodo de licença remunerada devido a férias coletivas, ao emitir aviso de alerta sobre férias pendentes de finalização.* |
