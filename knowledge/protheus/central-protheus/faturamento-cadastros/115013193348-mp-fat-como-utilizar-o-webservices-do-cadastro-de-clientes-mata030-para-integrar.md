**Dúvida**

Como utilizar o Webservices do cadastro de clientes (MATA030) para integrar com softwares terceiros e/ou customizações?  
  
  
**Ambiente**

Microsiga Protheus - a partir da versão 12  
  
**Solução**  
  
A rotina de Cadastro de Clientes (MATA030) foi reescrita no modelo MVC, onde já possui um WebServices nativo para utilização. Abaixo segue o link para consultar nossa apostila de ADVPL que contem detalhes de como utilizar nossos webservices.  
<http://tdn.totvs.com/display/public/mp/AdvPl+utilizando+MVC> - Consultar as páginas 104 a 116 que contem o capitulo sobre WebServices  
  
Maiores detalhes, acesse a FAQ no tdn: <http://tdn.totvs.com/pages/viewpage.action?pageId=301178247>
