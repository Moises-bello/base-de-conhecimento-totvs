Através deste módulo é possível importar um arquivo texto contendo o movimento de ensino de outro sistema acadêmico.

A importação dos dados de ensino permite que outro sistema acadêmico integre com o RM Labore para o cálculo da folha de pagamento do professor (código de recebimento P-Professor (Horista)), devendo ser gerado um arquivo texto conforme layout disponível abaixo.

**Sobrescrever importação apenas para chapas que existem no arquivo**

Selecione este parâmetro para que o sistema sobreponha apenas o movimento das chapas contidas no arquivo de importação, ao invés de limpar todo o movimento para o período letivo informado.

Com o parâmetro desmarcado, ao importar um arquivo com o mesmo ‘Período Letivo’ de um arquivo já importado, o sistema irá deletar os dados importados anteriormente e em seguida importará os dados do arquivo atual.
