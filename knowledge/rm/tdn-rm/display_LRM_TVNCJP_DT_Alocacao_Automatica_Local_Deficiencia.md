# INSCRIÇÃO DE CANDIDATO - ALOCAÇÃO AUTOMÁTICA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Inscrição de candidato - alocação automática* |
| **Situação/Requisito:** | *Ao sistema está alocando candidatos sem nenhum tipo de deficiência em locais que dão suporte a deficiente, situação que ocorre somente quando o processo seletivo utiliza alocação automática após a inscrição.* |
| **Solução/Implementação:** | *Foi identificado que o sistema valida corretamente somente quando o candidato possui alguma *deficiência* , não quando o candidato não possui e o local dá suporte. Foi feito o ajuste no processo de alocação automática após a inscrição para que valide também quando o candidato não possui nenhuma *deficiência* em local com suporte a deficiente, alocando somente no local correto conforme o processo de Alocação de candidatos.* |
