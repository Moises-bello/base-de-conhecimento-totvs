# Popup de "usuário existente" permite acesso a tela anterior sem clicar no botão "Fechar"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Portal Processo Seletivo |
| **Função:** | Recuperação dos dados de usuário existente |
| **Situação/Requisito:** | Quando um candidato já possuí cadastro na base e o mesmo vai realizar uma nova inscrição o sistema joga uma mensagem informando que foi encontrado o mesmo cadastro na base, porém o sistema está permitindo que o candidato clique na parte inferior da mensagem e continue para realizar um novo cadastro ao invés de clicar em fechar na mensagem para aproveitar o cadastro existente. O portal deveria travar a parte de baixo da mensagem para que o candidato volte para aproveitar os dados existente na base. |
| **Solução/Implementação:** | Foi realizado ajuste para impedir que o usuário clique na parte inferior da mensagem. Será necessário sempre clicar no botão fechar para dar sequência na inscrição, aproveitando os dados de usuário existente. |
