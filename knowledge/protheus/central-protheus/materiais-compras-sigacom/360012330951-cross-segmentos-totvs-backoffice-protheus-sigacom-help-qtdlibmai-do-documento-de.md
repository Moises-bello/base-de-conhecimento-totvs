**Dúvida**Em que momento sistema apresentará Help **QTDLIBMAI** na rotina de Documento de Entrada?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4410621630359)

**Ambiente**Protheus – Compras – A partir da versão 11.80  
  
**Solução**

Possibilidades para que o sistema apresente o help **QTDLIBMAI**, são:

* Se a quantidade do Pedido subtraída ( - ) da Quantidade já atendida não for maior que zero
* Se o Pedido foi eliminado por resíduo - **C7\_RESIDUO ( S )**
* Se o Pedido estiver encerrado - **C7\_ENCER - ( E )**
