**Documentos**   
Este cadastro objetiva registrar todos os documentos envolvidos no processo jurídico agrupados por classificações a fim de facilitar o levantamento destes para os compromissos.

**Código do Documento:** Identificador do Documento.

**Nome do arquivo:** Nome do arquivo salvo.

**Procurar:** Botão utilizado para buscar o arquivo para ser salvo. Extensões aceitas: xml, txt, ppt, pptx, pdf, doc, docx, xls, xlsx, jpg, png e outros tipos comuns de arquivos.

**Classificação:** Classificação interna para facilitar a busca.

**Data:** Data do Documento.

**Descrição:** Descrição breve do Documento.

**Abrir Arquivo:**Abre o arquivo salvo para visualização.
