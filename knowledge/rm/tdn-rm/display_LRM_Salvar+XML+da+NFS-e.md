Através deste processo é possível salvar (exportar) o XML da NFS-e para um arquivo e armazená-lo em disco. Este processo só é executado para notas cujo status seja Autorizada e pode ser disparado para um ou mais registros de uma só vez.  
Para executar este processo crie um filtro para selecionar as notas das quais deseje salvar o XML. Selecione os registros e nos Processos escolha a opção Salvar XML. Na tela que será aberta informe o diretório onde serão gravados os arquivos gerados e clique no botão executar.  
Os arquivos serão gerados com a seguinte nomenclatura: **nfse\_XXXXXX.xml**

Onde:  
**nfse**: Designa arquivo de xml de NFS-e;  
**XXXXXX**: O número da NFS-e constante no xml;  
**xml**: Extensão do arquivo.
