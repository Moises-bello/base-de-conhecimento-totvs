Feita a correção para que os campos no Linux voltem a aceitar caracteres acentuados.

|  |  |
| --- | --- |
| Situação | Ao digitar acentos em campos no Linux eles não aparecem. |
| Ocorrência | A partir da versão 20.3.0.1 os acentos passaram a não aparecer mais. |
| Correção | O comportamento foi corrigido e os acentos aparecem normalmente. |
| Informações adicionais | * Referente à ocorrência: DTCLIENT01-3253 * Disponível em builds superiores a 20.3.0.3 |
