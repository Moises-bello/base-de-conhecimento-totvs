![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/5319745239831)  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução** Somente será enviada a tag  **EXTIPI**, quando preenchido via Regime de Tributação, caso contrário não será enviada esta informação de nenhum outro cadastro para o arquivo **XML**.
