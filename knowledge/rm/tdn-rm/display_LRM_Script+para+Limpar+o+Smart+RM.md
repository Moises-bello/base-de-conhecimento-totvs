Para solicitar a limpeza do ambiente Smart RM é necessario seguir os passos abaixo:

* Abrir issue com o tipo Apoio - Cliente.
* Anotar na issue o tipo do banco de dados (Oracle ou SQL).
* Anotar o CNPJ da coligada 1 da base em que será executado o script.

**Observação:** Caso a limpeza não seja para todas as coligadas da base deverá ser especificado no chamado.
