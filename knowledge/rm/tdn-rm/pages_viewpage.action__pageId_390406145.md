# SUBSTITUIR RESPONSÁVEL FINANCEIRO NA MATRÍCULA DO PROCESSO SELETIVO RM

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Informe a função. |
| **Situação/Requisito:** | Ao fazer a matrícula de um candidato no processo seletivo RM, marcando a opção para gerar novo RA para candidatos que já são alunos e também a opção para utilizar o candidato como responsável financeiro, o responsável financeiro do aluno não é alterado, permanecendo o pai do aluno, como estava antes. |
| **Solução/Implementação:** | A matrícula do processo seletivo RM foi alterada para substituir o responsável financeiro quando for escolhido a opção de utilizar o aluno como responsável ou utilizar o responsável financeiro cadastrado no processo seletivo e for utilizada a opção de gerar um novo RA quando já existir o aluno cadastrado. |
