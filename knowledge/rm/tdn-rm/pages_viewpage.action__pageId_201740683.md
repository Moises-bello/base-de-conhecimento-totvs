# Como utilizar a funcionalidade "Orçamento para Clientes"

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.8x e 12.1.x |
| **Ocorrência:** | Como utilizar a funcionalidade "Orçamento para Clientes" |
| **Passo a passo:** | A funcionalidade "Orçamento para clientes", serve para gerar um orçamento prévio para clientes que desejam realizar procedimentos em seu hospital / clínica, sejam eles procedimentos complexos e/ou procedimentos simples. Assim, antes do seu paciente dar sua entrada no hospital para realizar o procedimento em questão, ele já pode estar ciente do valor a ser gasto, sendo este valor negociável com o mesmo.  Para acessar esta funcionalidade, acessar o menu  faturamento / particular e convênios / Orçamento para clientes.    Inclua um "Novo"    **N**a aba identificação, preencher os dados necessários do paciente para que possa identificá-lo.    Após realizar a identificação do paciente, você pode ir para aba "Itens do Orçamento", para simular os procedimentos pedidos pelo paciente.  Vá na aba “itens do orçamento”  e clique em "Incluir".  Nota: Nesta aba, você pode preenchê-la com Matmeds, procedimentos, serviços e/ou taxas para seu paciente.      Após finalizado os itens do orçamento, você pode imprimir um relatório para ser apresentado para seu cliente, lembrando que este relatório é desenvolvido e personalizado pelos hospitais. |
| **Observações:** | No campo "Observação", você pode colocar observações como "Valores de desconto a vista", condições de pagamentos e outras informações necesárias. |
