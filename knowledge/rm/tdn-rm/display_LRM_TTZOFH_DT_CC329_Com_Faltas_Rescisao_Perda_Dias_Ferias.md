# CC 329 COM FALTAS NO ENVELOPE DE RESCISÃO QUE RESULTAM EM PERDA DE DIAS DE DIREITO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão* |
| **Situação/Requisito:** | *Ao calcular rescisão para funcionário que teve evento de faltas lançado em seu envelope de rescisão, a soma dos eventos com código de cálculo 329 e 330 não está compatível com o valor do evento com código de cálculo 24.* |
| **Solução/Implementação:** | *Ajuste no cálculo do evento de CC 329 - FÉRIAS INDENIZADAS SOBRE AVISO PRÉVIO, para tratar faltas lançadas no envelope de rescisão, que resultam em perda de dias de direito de férias.* |
| **Chamados   relacionados:** | *TTZOFH* |
| **Versões/Release:** | *11.82.43, 12.1.10* |
