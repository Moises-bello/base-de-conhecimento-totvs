Como gerar Orçamento?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAPMS - Toda as Versões

**Solução**

O Orçamento é o processo inicial do gerenciamento de projetos e se caracteriza por possuir a estrutura completa do projeto, porém não possui o controle de datas. O seu principal objetivo é levantar todos os custos envolvidos para permitir uma análise mais detalhada dos custos e os quantitativos dos recursos utilizados.

Através desta rotina é possível realizar a manutenção dos orçamentos cadastrados e incluir novos orçamentos.

Um projeto não precisa necessariamente iniciar a partir de um orçamento. Este, apenas serve como base de custos para a geração do Projeto. Sendo assim, o fluxo operacional para o cadastramento de um Projeto pode iniciar pelo **Gerenciamento de Orçamentos** ou pelo **Gerenciamento de Projetos** (onde teremos o projeto por completo com datas, alocação de recursos, relacionamentos etc).

**Para cadastrar um Orçamento:**

**1.** **Manutenção de Orçamentos**, selecione a opção **Incluir**, disponível no menu. Será apresentada a tela de inclusão de orçamentos dividida em pastas que facilitam o gerenciamento das informações, sendo:

Pasta do Orçamento -> Pasta Custo do Projeto -> Pasta Código Estruturado.

->Em cada pasta, preencha os campos conforme orientação do help de campo e confirme. O sistema apresenta a tela de gerenciamento de orçamentos, conforme parametrização [F12]:

-> Clicando sobre o orçamento, o Sistema apresenta automaticamente seus dados cadastrais, ao lado esquerdo da janela, quando a parametrização [F12] estiver configurada como **Árvore.**O mesmo ocorre para as **EDTs, Tarefas**, além dos **Produtos, Despesas** e **Relacionamentos**.
