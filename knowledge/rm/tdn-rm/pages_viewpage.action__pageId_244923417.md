# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO PATRIMONIAL |
| **Versões:** | 12.1.17 ou superior |
| **Ocorrência:** | Cálculos |
| **Ambiente:** |  |
| **Passo a passo:** | Disponível através do **menu Cadastros | Cálculos.** Neste cadastro deve ser parametrizado o Cálculo a ser utilizado pelo sistema. O sistema permite que sejam usadas mais de uma forma de cálculo, utilizando para isto, as informações abaixo:        **Descrição** (campo livre).  **Tipo de cálculo:** Depreciação Linear.  **Cota proporcional**: Permite que os cálculos do sistema sejam realizados proporcionalmente a partir da data de aquisição, ou seja, ao cadastrar um patrimônio no sistema com a Data de Aquisição 15/03/2015, o sistema irá calcular a depreciação por apenas 15 dias.  **Cota proporcional** **(Desmarcada):** Deixando esta opção desmarcada, o sistema irá reconhecer que a cota de cálculo será integral, ou seja, irá calcular a depreciação de forma integral, ao cadastrar um patrimônio no sistema com a data de 15/03/2015 (por exemplo), o sistema irá calcular a depreciação por 30 dias (integralmente).  **Periodicidade:** Anual.  **Início periodicidade:** Permite que seja definido o mês inicial a ser aplicado o cálculo.    **Observação:** O período contábil utilizado pelo sistema é de 30 dias, independentemente da quantidade de dias do mês.    O processo de Cálculo de Depreciação poderá ser executado a partir da tela de Cálculos. Para isto deve-se selecionar o Cálculo desejado e através da opção Processos selecionar a opção Cálculo do Patrimônio. |
| **Observações:** | Os cálculos cadastrados deverão ser vinculados a um ou mais [Cenários](https://tdn.totvs.com/pages/viewpage.action?pageId=423938337) que posteriormente, serão utilizados no [Cadastro do Patrimônio](https://tdn.totvs.com/pages/viewpage.action?pageId=423938026). |
