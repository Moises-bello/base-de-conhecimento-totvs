# Quantidade incorreta na movimentação de estoque quando utilizado o painel de Soros e Componentes

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Prescrição de Soros e Componentes |
| **Situação/Requisito:** | Ao prescrever um soro com um componente no painel de Soros e Componentes no PEP, o sistema está criando uma movimentação de estoque com a quantidade errada do componente |
| **Solução/Implementação:** | Realizado o ajuste no tratamento do item componente, para realização do cálculo da quantidade corretamente |
