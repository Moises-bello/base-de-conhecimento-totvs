![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34314526387479) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como calcular dissídio com percentuais mensais?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para calcular dissídio com percentuais diferentes a cada mês, nos parâmetros de cálculo do dissídio a pergunta ÍNDICE ? deve ficar com Mensal:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416008241175)

Na tela de percentual do dissídio, o sistema irá apresentar um campo para cada mês de dissídio, para que seja informado o percentual por mês:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416008285335)  
  
Ao confirmar o cálculo, sistema calculará o percentual informado para cada mês:  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416008326807)  
  
Na geração do dissídio para a folha, no Histórico Salarial o sistema irá demonstrar o histórico com os dois percentuais:  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4416017159063)
