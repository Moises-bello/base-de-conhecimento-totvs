![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida** Como gerar o Follow-Up do pedido de exportação?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Export Control - Todas as versões  
  
**Solução**Para identificar os processos que necessitam de solicitação de crédito, está disponível a rotina Follow-up, que relaciona todos os processo de exportação com data de solicitação de crédito não preenchida, permitindo inclusive a sua impressão.

É possível efetuar follow-up sobre os processos que estão aguardando aprovação de crédito e que possuem crédito aprovado no período selecionado pelo usuário.

Procedimentos

Para imprimir o follow-up em fase de processo:  
1. Ao ser selecionada a opção Follow-up, será apresentada a janela para parametrização.  
2. Preencha os dados conforme orientação do help.  
3. Clique no botão "Ok" para confirmar.  
4. Para imprimir o documento, siga os procedimentos descritos no tópico [Relatórios](https://interno.totvs.com/mktfiles/tdiportais/helponlineprotheus/p12/portuguese/aa100rel.htm).
