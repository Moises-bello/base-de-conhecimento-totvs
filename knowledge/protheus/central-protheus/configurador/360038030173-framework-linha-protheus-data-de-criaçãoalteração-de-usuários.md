**DÚVIDA**É possível saber a data de criação e de última alteração de um usuário em específico?  
   
 **AMBIENTE**Protheus - Configurador - A partir da versão 12.1.17  
  
**SOLUÇÃO**Sim, é possível, porém torna-se necessário habilitar os campos abaixo em Política:  
1. No Configurador, acesse o menu Usuário > Senhas > Política > Aba Outros > **Regras de Auditoria**  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360049234234)  
  
2. Para visualizar as datas, acesse o relatório de Situação de Usuários, entrando no menu Base de Dados > Auditoria > **Situação de Usuários**  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360050122133)
