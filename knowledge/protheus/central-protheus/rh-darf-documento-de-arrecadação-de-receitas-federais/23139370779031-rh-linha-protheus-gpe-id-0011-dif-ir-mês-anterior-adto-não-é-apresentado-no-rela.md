![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23139415831575) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**ID 0011 - Dif. IR Mês Anterior Adto não é apresentado no Relatório Dirf Mensal (GPER050)   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.

**Solução**O sistema só considerará o ID 0011 - Diferença de IR Mês Anterior Adto - no relatório Dirf Mensal (GPER050) quando o cálculo for efetuado automaticamente pelo sistema.

Para os casos em que o ID 0011 é lançado manualmente, não será considerado para o relatório Dirf Mensal, pois o sistema efetua uma validação na SRD (Acumulados) de bases para compor este relatório.
