## **VISÃO GERAL**

A página de "Login" permite que um usuário acesse o Portal do Paciente.

Exemplo de Utilização

## **EXEMPLO DE UTILIZAÇÃO**

Para que seja possível efetuar o login no Portal, o usuário deve informar os dados de acesso (CPF e Senha). Feito isto, o sistema irá validar os dados informados e poderá seguir com o processo de login para o Portal ou interromper a ação e notificar o usuário.

Caso seja de interesse do usuário, este poderá marcar a opção "Lembrar usuário", desta forma, ao acessar futuramente o Portal do Paciente, o sistema irá carregar automaticamente o CPF do mesmo.

**Importante:**

Por critérios de segurança, os dados de acesso somente estarão disponíveis enquanto a sessão atual do usuário estiver ativa, ou seja, todos os dados serão redefinidos nos seguintes casos:

* Fechar a tab atual no navegador;
* Abrir uma nova tab no navegador;
* Fechar por completo a janela do navegador.
Login

## **LOGIN**

01. Acessar o Portal do Paciente, preencher os dados CPF e Senha e clicar no botão Cadastrar no "Entrar".

02. Se os dados informados não corresponderem com o registro do usuário no Portal do Paciente, o processo será interrompido.

**OBS :**Caso o usuário veja a executar 3 tentativas incorretas, o sistema notificará o usuário de que precisa aguardar o tempo de 15 minutos para uma nova tentativa.  Após o tempo terá mais 3 tentativas e/ou recorrer a opção "Esqueçeu sua senha".

02. Se os dados informados estiverem corretos, o sistema irá efetuar o login no Portal e o usuário será redirecionado para a página "Home".

Logout

## **LOGOUT**

01. Clicar no botão "Minhas Configurações" localizado no canto superior direito da página e clicar no botão "Sair".

02. O usuário será questionado se realmente deseja sair do Portal.

03. Se clicar no botão "Não", o usuário permanecerá no Portal. Se clicar no botão "Sim", a sessão do usuário será fechada e o mesmo será redirecionado para a página de "Login".
