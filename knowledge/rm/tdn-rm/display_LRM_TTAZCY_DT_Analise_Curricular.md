# Análise curricular

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Análise curricular.* |
| **Situação/Requisito:** | *O sistema permite a parametrização para que o aluno possa ser matriculado em uma disciplina já aprovada e que a nota a ser exibida no histórico possa ser a mais recente. Caso o aluno esteja matriculado em uma disciplina e seja feita a troca de turma, a matricula na nova disciplina terá a mesma data de matrícula, podendo ocasionar a exibição errada da nota na análise curricular, caso o sistema esteja parametrizado para a exibição da nota mais recente.* |
| **Solução/Implementação:** | *Ajustes para exibir a nota correspondente a disciplina exibida na análise curricular, caso o sistema esteja parametrizado para permitir a matricula em uma disciplina já aprovada e a nota a ser exibida seja a mais recente.* |
