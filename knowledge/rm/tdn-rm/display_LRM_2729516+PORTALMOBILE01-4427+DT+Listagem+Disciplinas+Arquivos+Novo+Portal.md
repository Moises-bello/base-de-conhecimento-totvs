|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Listagem de disciplinas na tela de arquivos do novo portal do aluno |
| **Situação/Requisito:** | O portal não exibia as disciplinas que não estivessem em curso mesmo que a parametrização do sistema definia que era para exibir. |
| **Solução/Implementação:** | Alteração na diretiva que lista as disciplinas que o aluno está matrículado para receber um parâmetro que define se será ignorado a situação de matricula "Disciplina em curso". |
