**Dúvida**  
Quais são Relatórios Smartview padrões do Compras

**Ambiente**  
Cross Segmentos - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Compras - Todas as versões

**Solução**  
Para verificação dos Relatórios Smartview padrões disponíveis do módulo de Compras, acessar o link abaixo da funcionalidade no módulo:

[Smart View - Compras](https://tdn.totvs.com/x/x_b0L)

**Obs:**

No configurador do sistema em **Ambientes -> Smartview -> Integração Smartview** tem a opção de menu "Personalização de Campos", que permite adicionar novos campos em um objeto de negócio.

**Atenção:**

* Não é possível adicionar campos MEMO ou virtual.
* Para que o campo apareça na listagem o mesmo precisa estar configurado como "Usado" no SX3

Veja mais detalhes nas documentações: [Amarração Protheus x Smart View](https://tdn.totvs.com/pages/releaseview.action?pageId=708098869)
