![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:03:00 min****Dúvida**Como configurar para uso o *Workflow* via novo método de autenticação do Gmail ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – BI – Workflow - Todas as releases.  
  
**Solução**  
Para correto funcionamento do *Workflow* em conta Gmail, seguir os passos abaixo:

Visando melhorar a segurança de seus serviços, o **Google**, por motivo de segurança, irá descontinuar a configuração de aplicativos menos seguros em 30/05/2022. Para continuar usando a conta GMail com o TOTVS | Application Server após essa data, é necessário configurar as **Senhas de App**. 

Com exceção do passo a passo documentado para geração do novo método, não há nenhuma mudança quanto a está configuração no serviço Workflow bastando apenas a substituição de sua senha Gmail que já está configurada no Workflow (via Configurador > Ambientes >  Workflow > Contas de e-mail ) pela senha gerada no processo Google.
