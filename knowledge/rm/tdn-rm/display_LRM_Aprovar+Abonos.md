**Aprovar Abonos**

Utilize este menu para aprovar os abonos solicitados pelos subordinados via RM Portal e ainda não foram aprovados pelos chefes ou supervisores.

**Observação**

Os filtros criados aqui também ficarão disponíveis na página 'Aprovar Abonos' do RM Portal.

Pelo menu "Aprovar Abonos" é possível controlar:

Para abrir a janela de "Identificação" é necessário editar um abono não aprovado apresentado na visão de "Aprovar Abonos".

Na pasta de identificação é possível alterar:

**Código do Abono Lançado -**Para alterar o código do abono basta informar um novo código ou clicar no ícone de pesquisa para localizar um novo abono.

**Término -** Informe neste campo a hora de término do intervalo de horas a ser abonado.
