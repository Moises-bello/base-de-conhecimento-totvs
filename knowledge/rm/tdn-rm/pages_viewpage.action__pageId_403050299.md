# Envio da NFS-e

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | NFS-e |
| **Situação/Requisito:** | O valor liquido do item "1" não corresponde com o cálculo de quantidade \* valor unitário - desconto. |
| **Solução/Implementação:** | Caso na nota de serviço haja mais de um item com o mesmo serviço, e seus valores unitários forem diferentes,  o sistema agrupará os mesmos e gerará o XML com quantidade 1 e valor unitário igual ao valor total. |
