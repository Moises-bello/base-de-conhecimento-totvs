## **01. VISÃO GERAL**

Esta funcionalidade permite o cadastro de especialidades Médicas atuantes no Hospital. As especialidades já cadastradas na base, ficarão com o código replicado no campo **código cliente,** esse campo é passível de edição caso não corresponda ao código da especialidade da base a ser importada. Ao incluir uma nova especialidade não será replicado o código, neste caso deve ser informado o código correspondente a esta especialidade na base que será importada.

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Selecione o filtro desejado com um duplo clique ou clique em fechar para prosseguir. 2. Será exibida a tela com todas as Unidades Clínicas já cadastradas. 3. Clique em **Incluir** (Ctrl + Insert). 4. Será exibida a tela Cadastro de Especialidade. 5. Estarão disponíveis para preenchimento os campos:  * + Código: Código de identificação da especialidade cadastrada.   + Nome: Nome da especialidade que será cadastrada.   + Código do Cliente: O campo código do cliente é usado para viabilizar a importação de dados de outros sistemas.   + Caso a especialidade seja cirúrgica, selecione a *flag* (Caixa de Seleção)**Cirúrgica,** no canto esquerdo inferior da tela.         7. Clique em **Salvar**.        8. Clique em **OK**, para concluir o processo e voltar para a tela onde são exibidas as especialidades já cadastradas. |
