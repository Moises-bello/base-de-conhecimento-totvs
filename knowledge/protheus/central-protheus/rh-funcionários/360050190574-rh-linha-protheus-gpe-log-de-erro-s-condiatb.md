**Dúvida**O que fazer quando gera o log de erro S\_CONDIATB  
  
 **Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**O erro S\_CONDIATB é gerado quando existe funcionário afastado com inconsistência nos campos da ausência.  
  
Verifique no cadastro de ausência (atualizações/lançamentos/ausências) da matricula como está o cadastro dos campos abaixo:  
**Num de Dias** / **Dias empresa**/**Dias a pagar**   
**Saldos de Dias:**é quantidade de dias que falta para completar para o funcionário voltar ao trabalho.   
**Dias pagos:**é a quantidade de dias que já foram pagos.  
  
Se for necessário ajuste nos campos mencionados, em seguida a folha deve ser recalculada.  
Lembrando que para o erro não voltar ocorrer é necessário que aplique o último acumulado do RH.   
  
Após todo processo o problema será corrigido.
