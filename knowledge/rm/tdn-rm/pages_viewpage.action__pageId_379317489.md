# Criar campo "Regime Especial de Tributação" para emissão de NFS-e (TSS)

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Dados Fiscais da Filial |
| **Situação/Requisito:** | Criar o campo "Regime Especial de Tributação - NFS-e/TSS" |
| **Solução/Implementação:** | Criação do campo "Regime Especial de Tributação - NFS-e/TSS" no Anexo Dados Fiscais do  Cadastro da Filial (pasta Tipo de Estabelecimento).  Esse campo será utilizando para emissão de NFS-e através do modelo único do  TSS (regimeesptrib) e deve conter a seguinte lista:  0 – Tributação Normal 1 – Microempresa Municipal (ME); 2 – Estimativa; 3 – Sociedade de Profissionais; 4 – Cooperativa; 5 – Microempresário Individual (MEI); 6 – Microempresário e Empresa de Pequeno Porte (ME EPP). 7 - Movimento Mensal/ISS/Fixo Autônomo; 8 - Sociedade Limitada/Média Empresa; 9 - Sociedade Anônima/Grande Empresa; 11 - Empresa Individual; 10 - Empresa Individual de Responsabilidade Limitada (EIRELI); 12 - Empresa de Pequeno Porte (EPP); 13 - Microempresário; 14 - Outros/Sem Vínculos; 50 - Nenhum; 51 - Nota Avulsa. |
| **Conversores e Parâmetros:** | Script para criação do campo na base LI.2018.07\_01 |
| **Tickets relacionados:** | 986362 |
| **Requisito:** | Não se Aplica |
