# PLANO DE AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Processo de cópia de conteúdo realizado para próxima aula.* |
| **Situação/Requisito:** | *Quando o processo era executado no portal do professor, a data efetiva no plano de aula de destino ficava em branco no banco de dados.* |
| **Solução/Implementação:** | *Ao executar o processo "Copiar conteúdo realizado para próxima aula", disponível no portal do professor, a data efetiva do plano de aula de destino será preenchida com a mesma data efetiva do plano de aula de origem. Quando esta informação estiver nula no plano de aula de origem, o processo vai informar a própria data do plano de aula como data efetiva.* |
