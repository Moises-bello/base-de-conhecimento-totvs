# PARÂMETROS ESPECÍFICOS DE MÉDIA DE COMISSÃO NO CADASTRO DE SINDICATO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cálculo de Média* |
| **Situação/Requisito:** | *Quando está marcada a opção "Utiliza parâmetros específicos para média de comissão", no cadastro do Sindicato, o recurso de considerar o mês atual na média não existe na pasta "Comissão".*  *Com isto, o mês atual nunca é considerado na média de comissionistas.* |
| **Solução/Implementação:** | *No caso de ser utilizado parâmetros específicos para média de comissão, a opção de considerar ou não o mês atual na média do salário comissão será verificada nos parâmetros de média do processo.*  *Ou seja, nas pastas de Férias, 13o., ou Aviso Prévio.* |
| **Chamados   relacionados:** | *TTVH68* |
| **Versões/Release:** | *11.82.43* |
