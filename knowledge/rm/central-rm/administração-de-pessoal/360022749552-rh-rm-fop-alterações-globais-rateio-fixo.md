Dúvida**Como realizar a alteração do rateio fixo por centro de custos de forma global, ou seja, com a possibilidade de lançamento para todos os funcionários da coligada?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Veja as informações abaixo para realizar a alteração global de Rateio Fixo:  
  
1. Acesse **Administração de pessoal | Alterações globais | Alteração rateio fixo**;  
  
2. Caso já exista rateio fixo no cadastro dos funcionários é possível remover o registro para cadastro de novo rateio. Para tanto, habilite o parâmetro **Limpar rateio dos funcionários**. Para executar o processo para limpar o cadastro do funcionário é recomendado não informar nenhumcentro de custo;  
  
3. Com o cadastro dos funcionários limpo, será possível parametrizar os centros de custos que serão utilizados. Veja a tela abaixo onde é mostrado a seleção onde são exibidos os centros de custos para seleção;  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10591323567383)  
  
4. Após informar os centros de custos, será necessário parametrizar a porcentagem do rateio a ser utilizada para cada um deles, sendo que a soma total dos percentuais deverá ser **100%**;  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10591368423575)  
  
5. Após informar os Centro de Custo e a Seleção de funcionários, execute o processo. Os centros de custos serão adicionados ao rateio fixo dos funcionários.  
 **Importante**  
A opção de alteração global de Rateio Fixo somente será exibida se o parâmetro **Utiliza cálculo por centro de custo** estiver habilitado. Para verificar o parâmetro, acesse **Configurações | Parametrizador | Folha normal | Cálculo 2/2.**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10591268702231)
