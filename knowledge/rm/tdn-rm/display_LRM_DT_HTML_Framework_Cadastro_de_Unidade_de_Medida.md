## Procedimento para Utilização

Para acessar a página de Cadastro de Unidade de Medida em HTML, é preciso entrar no Fluig ou diretamente no endereço do servidor na qual as páginas estão hospedadas.

Existe o menu:

Gestão de Estoque, Compras e Faturamento | Unidade de Medida

Este menu leva para a página de listagem com informações das unidades de medida. 

Nos itens listados, estão disponíveis as opções Editar e Excluir.

A página de inclusão de registro possui os campos para inserir ou editar uma Unidade de Medida.
