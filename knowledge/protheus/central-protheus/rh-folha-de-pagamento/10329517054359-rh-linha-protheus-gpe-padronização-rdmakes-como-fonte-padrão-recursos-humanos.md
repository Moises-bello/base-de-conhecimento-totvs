![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26319461207447) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Conversão de rdmakes para fonte padrão do módulo.  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.33.  
  
**Causa**Padronização rdmakes GPE como fonte padrão.  
  
**Solução**Alguns relatórios do Sistema estavam sendo utilizados como funções de usuário e para compatibilização com o release 12.1.33, é necessário alterar a chamada dessas funções no Menu, substituindo por função padrão do Protheus através do Configurador:  
  
SIGACSA  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10328933976983)  
  
SIGATRM  
**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10328969606935)**SIGAGPE

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10329346982551)
