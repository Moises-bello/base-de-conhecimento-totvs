![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18529408310167) Tempo aproximado para leitura: **00:06:00 min** **Dúvida**Como são preenchidos os campos EA\_TRANSF e EA\_SUBCTA?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro -  Todas as versões  
  
**Solução**Os campos **EA\_TRANSF** e **EA\_SUBCTA** são preenchidos após transmissões de titulo via API ou na geração do arquivo de remessa via CNAB

**EA\_TRANSF** = "S" = Titulo OK   
**EA\_TRANSF** = "F" = Titulo Falhou

**EA\_SUBCTA** = Preenche o número da subconta utilizada para geração do CNAB ou Titulo via API
