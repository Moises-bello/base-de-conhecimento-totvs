**Externo**   
   
O cadastro de Externos surgiu para proporcionar com que pessoas vinculadas a fornecedores (pessoas jurídicas) pudessem ter acesso ao RM Portal e realizar procedimentos relativos aos papéis de chefes ou supervisores. Para que isso seja possível os Externos devem ser associados ao cadastro de Chefes/Supervisores.

**Observação**

 - Cada externo sempre estará associado a uma única pessoa do cadastro de pessoas.

- A exclusão de um externo não excluirá os dados cadastrais da pessoa associada.

Por este cadastro é possível controlar:

**Pasta Identificação – Externos**

Pelo menu Identificação podem-se definir os dados relativos aos Externos, tais como Nome, Apelido, Data de nascimento, Sexo, Naturalidade, Estado Natal, Estado civil, Tipo sanguíneo, Nacionalidade, Cor/raça, Grau de instrução, Email e Código do Usuário.

**Pasta Dados Externo**

Pelo menu Dados Externo é possível definir Código Externo, Situação, Seção, Função, Período de atuação e Código do Cliente/Fornecedor que o Externo vai estar associado.

**Pasta Informações Adicionais – Externos**

Pelo menu Informações Adicionais pode-se definir se é portador de algum tipo de necessidade especial ou se precisa de algum recurso específico para ter acesso à empresa contratante.

**Pasta Endereço Principal – Externos**

Pelo menu Endereço Principal é preenchido o endereço do externo e este pode ser preenchido utilizando o recurso de preenchimento automático do CEP, buscando dados importados da base dos Correios realizados pelo menu Utilitários| Importação de CEPs.

**Pasta Documentos Básicos**

Pelo menu Doc. Básicos pode-se preencher dados de documentos dos externos, tais como: CPF, Carteira de Identidade, Título de Eleitor, Carteira de Trabalho e Carteira de Motorista.

**Pasta Documentos Estrangeiros – Externos**

Pelo menu Doc. Estrangeiros pode-se preencher dados de documentos dos externos, tais como: Passaporte e outros dados gerais de pessoa estrangeira.

**Pasta Campos Complementares – Externos**

Pelo menu Campos Complementares pode-se preencher os campos complementares que foram anteriormente cadastrados através do menu Cadastros| Campos Complementares| Pessoa.
