![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: 00:01:00 min **Dúvida**A classe TMobile utilizando o método Barcode não funciona para a leitura de código de barras, como corrigir?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**O TMobile é uma classe utilitária que agrupa métodos focados na plataforma móvel TOTVS | FatClient Embarcado e promove as integrações com aplicativos ou com o hardware do dispositivo móvel, foi descontinuado porque essa plataforma  não é mais distribuída.  
  
A única forma hoje de fazer isso, seria utilizando o TWebEngine, criando uma página HTML e utilizando javascript para acessar a câmera do celular.
