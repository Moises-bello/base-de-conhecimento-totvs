# FLUIG - CONSULTA RÁPIDA - ENVELOPE DE PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Fluig - Consulta Rápida - Envelope de Pagamento* |
| **Situação/Requisito:** | *Ao inserir um consulta rápida no fluig de envelope de pagamento, quando o mês/ano tem mais de um período, os valores dos períodos são somados e não é possível realizar o filtro de Nro. Período.* |
| **Solução/Implementação:** | *Ao acessar o Fluig, na consulta rápida do Envelope de Pagamento, é possível realizar o filtro por Nro.Período e quando o filtro estiver vazio, é apresentado todos os envelopes por mês/ano e nro.período.* |
| **Chamados relacionados:** | TWBWMI |
