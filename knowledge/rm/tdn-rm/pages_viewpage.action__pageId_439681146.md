# Envio de Evento de NF-e

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Envio de NF-e |
| **Situação/Requisito:** | NF-e - Não foi possível enviar o(s) evento(s):Enviar Evento: Erro ao enviar o evento. Log: INTERNAL SERVER ERROR |
| **Solução/Implementação:** | Na tela de envio de Eventos da NF-e estavam sendo apresentadas duas opções (Prestação em Desacordo e Registro Multimodal) que pertenciam ao processo do CT-e.  Estas duas opções foram retiradas da lista para evitar erro em possíveis tentativas de envio destes eventos no processo da NF-e. |
