| --- | --- |

| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Utilização do DataServer de aprovação de frequência via web service. |
| **Situação/Requisito:** | O DataServer obrigava que fosse passado registro de frequência mesmo quando nenhum aluno tivesse faltado na turma/disciplina. |
| **Solução/Implementação:** | Ajuste no DataServer EduAprovacaoFrequenciaDiariaData, possibilitando que se execute o SaveRecord sem informar registro de frequência. |
