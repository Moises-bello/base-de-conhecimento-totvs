![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)Tempo aproximado para leitura: **00:03:00 min****Dúvida**Foi configurado um Apple para acesso ao Protheus, porém quando utiliza funções para o Excel ele não mostra as planilhas, poderia me ajudar e orientar o que devo fazer, pois para o Windows não há problemas.  
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Não temos integração com a planilha utilizando o Sistema Operacional APPLE, por exemplo em relatório a planilha é gerada em arquivo na pasta protheus\_data.  
Sem essa integração não é possível acesso as funções.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023829431/mceclip0.png)

Veja no exemplo no Sistema Operacional Windows na planilha aparece a opção Suplementos que valida a integração.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360023829671/mceclip2.png)
