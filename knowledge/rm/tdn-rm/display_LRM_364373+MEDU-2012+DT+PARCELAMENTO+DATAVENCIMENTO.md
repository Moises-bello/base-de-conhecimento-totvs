# Data de Vencimento no Parcelamento

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | *Parcelamento* |
| **Situação/Requisito:** | *Ao realizar o parcelamento dos lançamentos o sistema não calcula as datas de vencimento fazendo uma para cada mês.* |
| **Solução/Implementação:** | Adicionado a Flag "Manter data de Vencimento" na tela de Processo do Parcelamento.  Desta forma o padrão do sistema se torna gerar as parcela com um para cada mês.  Caso o usuário queira manter as datas será necessário marcar a nova flag. |
