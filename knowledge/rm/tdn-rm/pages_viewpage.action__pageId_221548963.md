# QUEBRA CHAPA COM MAIS DE 8 CARACTERES NO RELATÓRIO DO BOOK FOPREL00031 - Escala Anual de Férias

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Gerar relatório do book sem quebra da chapa.* |
| **Situação/Requisito:** | Ao gerar o relatório FOPREL00031 - Escala Anual de Férias.TotvsReport quando a chapa do funcionário possui mais de 9 caracteres o sistema quebra a chapa do funcionário enviando para a linha de baixo deixando a chapa desalinhada. |
| **Solução/Implementação:** | Realizado alteração no tamanho do campo Chapa do relatório FOPREL00031 - Escala Anual de Férias, para que seja permitido apresentar sem quebra o campo Chapa. Para isso foi realizado a alteração do nome do campo DATA VENCIMENTO para DT VENCTO. |
| **Chamados relacionados:** | TTKH25 |
| **Versões/Release:** | *12.1.9* |
