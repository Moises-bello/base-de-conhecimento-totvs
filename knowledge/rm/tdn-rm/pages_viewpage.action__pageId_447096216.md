# Cadastro de patrimônio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Patrimonial |
| **Função:** | Cadastro de patrimônio |
| **Situação/Requisito:** | Dentro do cadastro do bem, na aba "Identificação", existe o campo "Patrimônio agregado a".  Seu nome gera confusão no entendimento, pois desta maneira os clientes podem pensar que o bem informado neste campo é o bem "filho", quando na verdade o bem informado neste campo é o bem "pai ou principal". |
| **Solução/Implementação:** | O campo "Patrimônio agregado a", existente no cadastro de patrimônio, teve sua descrição alterada para "Agregado ao patrimônio principal". |
