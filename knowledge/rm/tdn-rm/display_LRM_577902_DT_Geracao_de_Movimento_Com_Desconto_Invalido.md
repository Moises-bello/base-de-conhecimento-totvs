# GERAÇÃO DE MOVIMENTO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Geração de movimento por competência* |
| **Situação/Requisito:** | *Ao gerar movimento por competência para contratos que não possuam bolsa e que possuam desconto concedido na parcela, o sistema não calcula o valor total de descontos atual do contrato.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de geração de movimento por competência, permitindo ao sistema, calcular o valor de descontos para contratos que possuam apenas descontos concedidos nas suas parcelas e não possuam bolsas.* |
