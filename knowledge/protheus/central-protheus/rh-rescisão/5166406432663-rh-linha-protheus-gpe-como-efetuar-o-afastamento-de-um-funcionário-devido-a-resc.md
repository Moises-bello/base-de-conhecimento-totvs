![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26670463224727) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Como efetuar o afastamento de um funcionário devido a rescisão indireta, quando não há previsão de data desligamento?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.

**Solução**Em tipo de ausências o sistema possui o tipo Licença sem Vencimentos, deste modo é possível lançar para  este de tipo de ausência o afastamento com a data do abandono\comunicação do funcionário.  Assim o funcionário se mantém afastado (sem cálculo de saldo de salário) e quando houver a decisão judicial, a rescisão será calculada.
