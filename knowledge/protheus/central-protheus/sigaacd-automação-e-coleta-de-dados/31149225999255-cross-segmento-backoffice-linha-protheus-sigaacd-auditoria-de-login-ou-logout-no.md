![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/31149225983639) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Existe algum recurso de auditoria de login e/ou logout para o coletor de dados do módulo SIGAACD?   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.

**Solução**Por questões estruturais de Framework, a geração do rastro de login de usuários está atrelada ao login no Protheus, e atualmente não existe nenhuma forma de gerar os logs de auditoria de login no coletor de dados, visto que o método de autenticação usado não é o mesmo usado no login dos módulos.
