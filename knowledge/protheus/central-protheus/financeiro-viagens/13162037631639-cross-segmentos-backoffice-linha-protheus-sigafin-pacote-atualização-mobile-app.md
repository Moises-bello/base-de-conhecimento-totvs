# **Pacotes de Atualização - Mobile**

Por meio deste canal, disponibilizamos os principais pacotes de atualização e correção dos serviços **Protheus Mobile,**para serem baixados via download.

* Este trabalho é realizado **especificamente** para casos críticos que envolvam alto volume de atendimento**.** Todos estes pacotes são oficiais e homologados pelo time TOTVS, como normalmente disponibilizado por meio da **Central de Downloads** (**Portal do Cliente**).
* Os pacotes contidos nesta página ficarão disponíveis até a próxima liberação do repositório de dados no portal do cliente. Após esta liberação os pacotes de atualização serão removidos da página.

Link - [Pacotes de Atualização - Mobile - P12](https://tdn.totvs.com/pages/releaseview.action?pageId=527830949)

**Obs**: O pacote da Expedição Contínua conterá o patch acumulado dos fontes dos serviços Protheus Mobile com todas as alterações publicadas até a data de geração do pacote da Expedição Contínua conforme tabela acima.
