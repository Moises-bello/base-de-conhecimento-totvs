![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29623257996567) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Ao acessar o aplicativo meu coletor de dados ocorre o erro "Error 1 in Server Handshake".   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**A mensagem  é apresentada quando tenta utilizar o protocolo HTTP sendo que esta como HTTPS, não seria um erro e sim um informativo que a conexão está sendo efetuada de forma errônea.
