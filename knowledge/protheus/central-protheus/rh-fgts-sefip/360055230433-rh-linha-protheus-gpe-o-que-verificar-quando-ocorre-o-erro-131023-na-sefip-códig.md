**Ocorrência**Ao gerar a SEFIP ocorre o seguinte erro 131023-Código de identificação do trabalhador na caixa inválido.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Causa**Esse erro está ocorrendo pois no cadastro do funcionário existem campos preenchidos errados.  
  
**Solução**Para solucionar essa ocorrência, realize os seguintes passos:  
1. Acesse o cadastro do funcionário que está com o erro aba funcionais;  
  
2. Verifique os seguintes campos:  
"Cta. Dep FGTS"  
"Bco Ag FGTS"

![](https://totvssuporte.zendesk.com/attachments/token/o8NSSCvwHjdGNIW6CTO5X5R29/?name=inline342768401.png)

![](https://totvssuporte.zendesk.com/attachments/token/CCYr77ugiQXoozwXIh8nsAGWJ/?name=inline973578807.png)

Deixe em branco e/o com zeros ou informe os dados corretamente  
  
3. Caso as informações estejam corretas, será necessário entrar em contato com o suporte da CEF e verificar o procedimento a ser executado, pois conforme o layout do SEFIP, uma vez cadastrado os dados no sistema, essa informação será carregada para o arquivo TXT.
