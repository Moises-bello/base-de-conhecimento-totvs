# CLASSIFICAÇÃO DE CANDIDATOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Classificação de Candidatos |
| **Situação/Requisito:** | Ao realizar o processo de classificação de candidatos de um processo seletivo em que existam duas áreas de interesse ofertadas com a mesma prova e pesos diferentes, o sistema está utilizando apenas o peso da 1a área de interesse para calcular a pontuação das duas áreas de interesse, . |
| **Solução/Implementação:** | Alteração no processo de classificação de candidatos para utilizar o peso de cada área de interesse no cálculo da pontuação quando o candidato possuir mais de uma área de interesse. Antes estava buscando apenas o peso da 1a área de interesse. |
