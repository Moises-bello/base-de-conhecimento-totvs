O cadastro de Modalidade de seguro foi desenvolvido para o usuário poder associar esta informação no cadastro de seguro do módulo Gestão de Controle de Seguro do **Totvs Incorporação**. O intuito desta funcionalidade é facilitar a localização e visualização dos registros de seguro, agrupando os mesmo por sua modalidade.  
São os seguintes dados que constam este cadastro:

* **Código:** Identificador único gerado automaticamente pelo sistema para controle interno;
* **Descrição:** Campo de texto livre para o usuário informar uma breve informação referente a modalidade de seguro;
