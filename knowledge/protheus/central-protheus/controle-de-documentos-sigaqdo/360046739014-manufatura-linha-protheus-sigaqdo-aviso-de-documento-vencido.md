**Dúvida**Quando é gerado o **aviso de documento vencido**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**O **aviso de vencimento do documento** é gerado para todos os usuários que estejam parametrizados no documento, para gerar revisão, independente do nível de responsabilidade. E se o parâmetro **MV\_QDOREVD - Define se o digitador pode gerar revisão (1-SIM / 2-NÃO)** estiver como **1**, será gerado o **aviso de vencimento** também para o digitador do documento.
