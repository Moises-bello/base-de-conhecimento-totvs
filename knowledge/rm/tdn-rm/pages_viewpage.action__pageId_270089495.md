# Assunto

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 11.82.XX e 12.01.XX |
| **Ocorrência:** | Erro License Server |
| **Ambiente:** | Hard Lock e License Server 2014(Cloud) |
| **Passo a passo:** | O objetivo deste documento é resolver o problema ocorrido no License Server quando o horário das maquinas clientes estão diferentes do Servidor de License Server e do Banco de Dados.    Ocorrência: Caso se depararem com este erro ao acessar o RM (Erro-9), basta ajustar o horário das maquinas clientes com os Servidores para que o erro seja corrigido.    Obs.: A configuração de ajuste de horário vai variar da versão do Windows. |
| **Observações:** | Vale ressaltar que o License Server, deverá estar sempre atualizado com a última versão disponível, tanto para o Hard Lock quanto para o License Server 2014(Cloud). |
