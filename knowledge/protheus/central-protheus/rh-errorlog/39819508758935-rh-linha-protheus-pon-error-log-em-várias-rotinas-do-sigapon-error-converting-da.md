**Dúvida**  
Error log em várias rotinas do SIGAPON: Error converting data type varchar to float   
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**  
Para correção do errro é necessário efetuar atualização do fonte PONXFUN, com data a partir de do ambiente com o pacote abaixo:  
12.1.2310:<https://r.totvs.io/p/1246847> ;   
12.1.2410:<https://r.totvs.io/p/1246845> ;   
12.1.2510:<https://r.totvs.io/p/1246846> ;
