# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Essa classe representa as informações da janela específica da planilha.

# Membros da classe

---

## Propriedades

|  |  |
| --- | --- |
| BlackAndWhite | Define se a impressão será em preto e branco. |
| BottomMargin | Define o tamanho para impressão da margem inferior (em pontos). |
|  | Define o que será impresso no centro do rodapé da página. |
|  | Define o que será impresso no centro do cabeçalho da página. |
| CenterHorizontally | Define se as páginas impressas devem ser centralizadas horizontalmente. |
| CenterVertically | Define se as páginas impressas devem ser centralizadas verticalmente. |
| Draft | Define se a impressão terá qualidade de rascunho. |
| FirstPageNumber | Define o número da primeira página. |
| FitToPages | Define se a escala de impressão será alterada de acordo com o número de páginas definidos nas propriedades FitToPagesTall e FitToPagesWide. |
| FitToPagesTall | Define o número de páginas na vertical para ajustar a impressão. |
| FitToPagesWide | Define o número de páginas na horizontal para ajustar a impressão. |
| FooterMargin | Define o tamanho para impressão do rodapé (em pontos). |
| HeaderMargin | Define o tamanho para impressão do cabeçalho (em pontos). |
|  | Define o que será impresso no lado esquerdo do rodapé da página. |
|  | Define o que será impresso no lado esquerdo do cabeçalho da página. |
| LeftMargin | Define o tamanho para impressão da margem esquerda (em pontos). |
|  | Define a ordem de impressão. |
|  | Define a orientação utilizada na impressão. |
| PaperSize | Define o tamanho do papel a ser utilizado na impressão. |
| PrintArea | Define a área da planilha (worksheet) a ser impressa. |
| PrintComments | Define a forma como os comentários serão impressos. |
|  | Define a forma como os erros das células serão impressos. |
| PrintGridlines | Define se as linhas de grade serão impressas. |
| PrintHeadings | Define se o cabeçalho das colunas e linhas serão impressos. |
| PrintQuality | Define a qualidade de impressão (em dpi). |
| PrintTitleColumns | Define as colunas que serão repetidas em cada página impressa. |
| PrintTitleRows | Define as linhas que serão repetidas em cada página impressa. |
|  | Define o que será impresso no lado direito do rodapé da página. |
|  | Define o que será impresso no lado direito do cabeçalho da página. |
| RightMargin | Define o tamanho para impressão da margem direita (em pontos). |
| TopMargin | Define o tamanho para impressão da margem superior (em pontos). |
| Zoom | Define o fator de escala da impressão. |
