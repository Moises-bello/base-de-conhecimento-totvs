Este processo efetiva as alterações informadas no aditivo, podendo ser informações de valores, imóveis, áreas, o que estiver informado será alterado. As informações anteriores, serão salvas, caso o usuário necessite retornar com estas informações basta utilizar o Processo de .

**Campos da Tela:**

* **Data efetivação aditivo:** Esta será a data de efetivação do aditivo, sendo que esta data não pode ser menor que a data de criação do aditivo.
* **Gerar lançamentos anteriores à data do aditivo:** Caso não exista lançamentos gerados para a data anterior à data do aditivo, estes lançamentos serão gerados.
* **Regerar lançamentos após a data do aditivo:** Com essa opção marcada, os lançamento financeiros serão regerados.
* **Observação aditivo:** Este é um campo texto, para que o usuário coloque informações referentes ao aditivo que está sendo realizado.
* **Observação:**  (restrição para quando se usa o módulo de condomínio): - Para os imóveis associados à Subunidades, não será permitido Efetivar o Aditivo, caso haja fechamento de calculado ou integrado ao financeiro, que utilize o Imóvel em questão, dentro do período de Efetivação do Aditivo.
