**Correspondência - Criptografia MD5**

---

O MD5 (Message-Digest algorithm 5) é um algoritmo de hash de 128 bits unidirecional. Por ser um algoritmo unidirecional, uma hash MD5 não pode ser transformada novamente no dado que lhe deu origem. O método de verificação é, então, feito pela comparação das duas hash (uma da mensagem original confiável e outra da mensagem recebida).   
    
 A operação Criptografia MD5 recebe a entrada, criptografa os dados e os envia para o campo destino.  
 Os parâmetros para configurar esta operação são:  
 *Alimentação*

* **Entrada:** Ponto de entrada da operação ou campo.

*Identificação*

* **Nome:** Campo somente leitura, tem como valor o tipo da operação.
* **Nome:** Nome da operação.
