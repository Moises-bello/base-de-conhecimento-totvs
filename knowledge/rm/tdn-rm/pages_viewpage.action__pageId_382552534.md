# BAIXA DE LANÇAMENTOS FINANCEIROS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Visão de lançamentos da parcela do TOTVS Educacional |
| **Situação/Requisito:** | Ao exibir os lançamentos de uma parcela, através do Educacional, sempre é exibido o valor original com 4 casas decimais, independente da forma como o sistema financeiro está parametrizado. |
| **Solução/Implementação:** | Foi realizada otimização da visão de lançamentos da parcela, de forma que o sistema exiba o valor original do lançamento conforme o número de casas decimais parametrizado no sistema financeiro. |
