# Introdução

---

O objetivo deste documento é utilizar a desinstalação completa e correta do License Server Virtual.

Acesse a tela do Painel de Controle para realizar a desinstalação;

# Procedimentos de desinstalação

---

* Pelo menu Iniciar > Painel de Controle > Programas e Recursos;
* Ao abrir o Painel de Controle do Windows, procure pelo programa TOTVS| License Server Virtual (x64) ou x(86);
* Selecione a opção Desinstalar/Alterar;
* Nesta etapa o programa somente sai da lista, mas não remove da maquina.

* Caso ele só apague da lista de programas acesse o caminho C:\totvs\TOTVSLicenseVirtual\uninstall;
* A pasta uninstall está oculta;

* Acesse opções de pastas do Windows e desmarque a opção não mostrar arquivos, pastas ou unidades ocultas

* Execute o arquivo **uninstaller.jar**

* MARQUE a flag Forçar a remoção de C:\totvs\TOTVSLicenseVirtual > clique em Desinstalar.

|  |  |  |
| --- | --- | --- |

* Em uma ação normal o License Server Virtual é desinstalado com está ação.

ATENÇÃO***\* Caso ocorra algum erro basta executar a instalação do LSVirtual toda padrão sem preocupar com parâmetros, pois quando chegar na informação do diretório a ser instalado,*** 

***mostrará que já existe tal caminho, confirme que será no mesmo local informado clicando em SIM.(isto atualizará a referencia para desinstalar) \*\****

  

* Veja no link , como realizar a instalação completa do License Server Virtual.
