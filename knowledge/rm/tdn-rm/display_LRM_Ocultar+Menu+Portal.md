# Ocultar Menu Portal

|  |  |
| --- | --- |
| **Produto:** | RM |
| **Versões:** | 12.1.16 ou Superiores |
| **Ocorrência:** | Ocultar Menu Portal |
| **Ambiente:** | RM Portal |
| **Passo a passo:** | Introdução Neste módulo iremos mostrar procedimento para ocultar menu    **1 -** Ocultar Menu   **1.1 -** Através da MDI acessar o contesto “Gestão de Conteúdo”    **1.2 -**  Acessar o menu “Menu Portal"    **1.3 -** Através do menu aberto adicionar um novo registro      Através da tela é possível ocultar um modulo por completou ou apenas um menu especifico do módulo.    **2** - No Exemplo abaixo iremos realizar bloqueio do módulo completo “Educacional”.    **2.1 -** Bloqueio módulo “Educacional”  **2.1.1** – Adicionar novo registro na opção “Identificador do Menu Pai”  Através da opção é possível selecionar o módulo completo.    Iremos selecionar o módulo completo. As informações referentes a Menu serão preenchidas automaticamente    Após preenchimento desabilitar o parâmetro “Habilitado”.    **2.1.2 –** Salvar registro    **2.1.3 –** Aplicação no portal  Com registro salvo basta atualizar a página do portal para que menu fique oculto.  Antes do registro salvo    Depois do registro salvo.      **2.2 -** Bloqueio menu especifico  **2.2.1 –** Adicionar novo registro na opção “Identificador do Menu”  Através da opção é possível selecionar menu especifico de todos os módulos    Iremos selecionar o menu “Identificação”. Selecionado os campos “Identificador do Controller | Identificador | Identificador Pai” serão preenchidos automaticamente.    Após preenchimento desabilitar o parâmetro “Habilitado”.    **2.2.2 –** Salvar registro    2.2.3 – Aplicação no portal  Com registro salvo basta atualizar a página do portal para que menu fique oculto.  Antes do registro salvo    Depois do Registro Salvo |
