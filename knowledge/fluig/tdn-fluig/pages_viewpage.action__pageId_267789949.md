# Ocorrência

Temos vários processos na empresa 1 e agora criamos a empresa 2. Como migrar os processos de uma empresa para a outra?

# Solução

Para que os processos da empresa 1 também estejam na empresa 2, é necessário importá-los para o  e então exportá-los para a empresa 2.

Atenção!

Importante mencionar que a transferência de processos somente pode ser feita através do fluig Studio seguindo os passos abaixo.

Veja o passo a passo de como exportar os processos para sua segunda empresa:

0.5falsesamplesfadetrue1Passo 1

* Faça a importação do processo para o fluig Studio conforme a documentação .

2Passo 2

* Caso possua formulário em seu processo, é preciso fazer a definição dele. Deve colocar a definição como Local, para depois poder exportar.

3Passo 3

* Agora deve exportar para empresa 2. Para realizar a exportação veja a documentação .

Observação

Para fazer a exportação para empresa 2, você deve criar um servidor no fluig Studio para empresa 2. Verifique na documentação , no tópico Cadastrando o servidor fluig, onde o usuário e senha informados devem ser da empresa 2.
