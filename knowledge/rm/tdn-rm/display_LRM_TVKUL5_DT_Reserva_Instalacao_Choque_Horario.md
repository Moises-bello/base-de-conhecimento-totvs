# RESERVA DE INSTALAÇÕES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Reserva de instalação* |
| **Situação/Requisito:** | Identificamos que o sistema estava validando o choque de horário, na reserva de instalações, para um período mesmo informando um único dia. |
| **Solução/Implementação:** | Foi realizado um ajuste no processo de reserva de instalações para que não valide o período quando possuir data de inicio e de fim iguais. Com isso, não ocorrerá o choque de horário de forma indevida quando for efetuada uma reserva de uma instalação num horário disponível. |
