# Conceção de Bolsa Futura

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Concessão de Bolsa Futura |
| **Situação/Requisito:** | Deparamo-nos com a seguinte situação: Após cadastrar a concessão de bolsa futura para um aluno, acessar o anexo habilitações da concessão de bolsas futuras e selecionar o botão [...](ou digitar o código do curso) para escolher o curso do aluno, o aplicativo está demorando cerca de 11 segundos para listar o curso. Este tempo está muito elevado, para listar apenas o curso do aluno, tornando o processo de cadastro de bolsas futuras muito lento. |
| **Solução/Implementação:** | Melhoria no tempo de consulta da matriz aplicada do cadastro de Habilitação da concessão de bolsas futuras.  Para complementar esta melhoria é necessário executar um script de criação de um indice no banco de dados.  Para isto recomendamos entrar em contato com o suporte e solicitar a antecipação. |
