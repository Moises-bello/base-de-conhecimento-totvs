**Dúvida**

Onde estão os Arquivos Modelos - Plano Referencial / Visões Gerenciais

**Ambiente**  
  
Microsiga Protheus – Ativo fixo – A partir da versão 11.80

**Solução**

Disponibilizado nos arquivos abaixo os arquivos modelos de Plano de Contas Referencial e Visão Gerencial para importação no sistema Protheus.

Para efetuar o download, acessar: <http://tdn.totvs.com/pages/releaseview.action?pageId=189314312>

As visões gerenciais contidas no pacote do ECF, são referente aos blocos L para lucro real, P para presumido, U para Imunes e Isentas, V para o DEREX, X para informações econômicas e Y informações gerais.

Para saber qual utilizar verifique quais registros se enquadram ao perfil da empresa, link referente aos blocos: <http://tdn.totvs.com/pages/releaseview.action?pageId=192094180>
