# Ficha Financeira

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | TOTVS Folha de Pagamento. |
| **Função:** | Remoção de Eventos Zerados na Ficha Finaceria para Demitidos. |
| **Situação/Requisito:** | O sistema deve passar a excluir os eventos zerados da ficha financeira incluindo os funcionários demitidos.. |
| **Solução/Implementação:** | O sistema passa a **excluir** os eventos zerados da ficha financeira incluindo os funcionários demitidos. Na opção **"** **Folha Mensal / Ficha Financeira / Remover Eventos Zerados de Competências Anteriores**" .****  Este processo é habilitado através do parâmetro **"** **Folha Normal/ Ficha Financeira / Remover Eventos Zerados na Liberação de Competências".** E executado ao efetuar a liberação de competência ou manualmente pela opção **" **Folha Mensal / Ficha Financeira / Remover Eventos Zerados de Competências Anteriores** ".** Ao executar este processo é excluído todos os eventos zerados da ficha financeira para todos os funcionários. |
