# Pagamento por cartão de crédito de título baixado no portal acadêmico

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Extrato financeiro |
| **Situação/Requisito:** | No portal do aluno, a opção de pagamento por cartão de crédito está disponível para boletos já liquidados. |
| **Solução/Implementação:** | Ajustado o controle de visibilidade da opção de pagamento com cartão de crédito.  A opção estará disponível somente se:  o título estiver aberto;  ou se estiver parametrizado para permitir boletos baixados parcialmente e o boleto estiver baixado parcialmente;  estiver parametrizado a integração do cartão de crédito e a matriz aplicada estiver disponível para pagamento por cartão de crédito;  e por fim o lançamento não pode estar integrado com o Protheus. |
