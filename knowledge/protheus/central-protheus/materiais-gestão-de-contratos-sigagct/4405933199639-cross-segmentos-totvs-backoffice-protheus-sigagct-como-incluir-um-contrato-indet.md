![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Como Incluir um Contrato Indeterminado ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões  
  
**Solução**Para a inclusão de um Contrato Indeterminado, deve-se informar na inclusão do contrato o campo *"Un. Vigência = 4-Indeterminado"* ( ***CN9\_UNVIGE*** ) conforme a imagem abaixo:

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405933216535/mceclip0.png)

Esta configuração tem a característica de deixar o contrato cadastrado uma data final de Vigência indeterminada:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4405933244055/mceclip1.png)

Uma observação importante é que, esta característica é válida apenas para a data de vigência do contrato, sendo que caso seja cadastrado um contrato com "Medição Eventual = Não", ou seja, com Cronograma Financeiro, as parcelas de pagamento do contrato seguirão suas datas conforme o que foi configurado no cronograma cadastrado no Contrato.
