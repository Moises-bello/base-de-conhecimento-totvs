# Registro de atendimento não salva quando realizado pela agenda

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Registro de Atendimento externo |
| **Situação:** | Sistema não permitia gravar o atendimento externo quando vem de um agendamento. |
| **Solução:** | Ajuste realizado para que o sistema faça a gravação do atendimento, mesmo quando é realizado realizado através da agenda. |
