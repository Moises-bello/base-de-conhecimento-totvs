**Dúvida**Para que server o parâmetro **MV\_OGDECPS?**  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - A partir da versão 12  
  
**Solução**O parâmetro **MV\_OGDECPS - Define a quantidade de decimais para campos de peso no romaneio**. Caso não tenha conteúdo, ou não exista o parâmetro, será considerado como 0 (Zero) decimais.
