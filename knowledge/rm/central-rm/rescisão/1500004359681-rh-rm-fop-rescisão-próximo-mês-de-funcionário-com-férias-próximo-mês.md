Dúvida**Como realizar rescisão próximo mês de funcionário que tem férias partidas, ou seja, férias finalizando na próxima competência?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, realize o passo a passo abaixo:   
  
Normalmente, para funcionário com férias próximo mês, a finalização das férias é realizada após virar a competência, onde o funcionário terá a situação alterada de **F- Férias** para **A- Ativo**.   
  
1. Como a empresa decidiu demiti-lo após o retorno das férias e ambas as situações são para o próximo mês, neste primeiro passo, verifique se as férias estão cadastradas para finalizar no próximo mês e em situação **P- Pagas**.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500005496662)  
  
2. Logo, deverá realizar a finalização das férias pela rotina: **Férias | Finalizar**, informando os dados necessários. É importante, finalizar as férias com os dados do próximo mês. Atente-se ao período da folha que deseja lançar os eventos das férias.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29426753091095)  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29426753093911)  
  
3. Com as férias finalizadas próximo mês, irá verificar que o campo **Situação das Férias** será mudado para **Finalizadas para o próximo mês**.  
  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500005498122)  
  
4. A situação e histórico de situação do funcionário deverão conter as informações ativo para que consiga realizar a rescisão, pois na situação **F- Férias** o sistema não permite.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/29426753096343)  
  
É válido ressaltar que, a situação não altera automaticamente. Portanto, deverá realizar de forma manual para **A-** **Ativo** no cadastro do funcionário.   
  
5. Após finalizar as férias, poderá realizar a rescisão normalmente, programando-a para o próximo mês.  
  
![mceclip8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500005501602)  
  
6. No envelope, o sistema emitirá o aviso sobre a rescisão próximo mês.
