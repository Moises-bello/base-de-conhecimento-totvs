# EMISSÃO DE RECIBOS DE MOVIMENTAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Bibliotecária* |
| **Função:** | *Emissão de recibos de movimentação - impressão direta* |
| **Situação/Requisito:** | *Quando os parâmetros de emissão de recibos de movimentação estão configurados para imprimir relatórios de movimentações sem visualização, ou seja, impressão direta, o sistema mostra sempre a caixa de dialogo de seleção da impressora.* |
| **Solução/Implementação:** | *Foi identificado que realmente na versão 11.82 a impressão é feita diretamente, sem seleção da impressora, ou seja, carregando a impressora padrão configurada no computador. Sendo assim, foi feito o ajuste para o sistema identifique a impressora padrão e envie a impressão diretamente para a impressora, sem a exibição da caixa de dialogo para seleção da impressora.* |
