![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30615060309655) Tempo aproximado para leitura: **00:01:30 min****Dúvida**Como realizar envio e-mail para os funcionários de maneira global?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para efetuar envio de e-mails para os funcionários cadastrados na base de dados, execute os passos abaixo:

1. Acesse **Configurações | Enviar e-mails para funcionários**;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30615060310551)   
2. Selecione os filtros de acordo com os funcionários que receberão os e-mails.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4413021214615)

3. Após acessar o menu anterior, será direcionado a tela abaixo onde deverá ser preenchido os dados do remetente

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30615065988247)

4. Selecione a flag “Enviar relatório como Anexo”. Selecione o relatório que será gerado. Preencha o assunto e o texto do e-mail. Avance e Execute o procedimento

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30615065988887)
