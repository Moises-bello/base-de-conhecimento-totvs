## Descrição

Melhoria consiste na possibilidade de inserir registros de Procedimentos para Agenda de Cirurgia, onde o nome de apresentação possa ter até 100 caracteres.

## Procedimento para Utilização

**Cadastrar Procedimentos para Agenda de Cirurgia**

1. Acesse o Menu **Cadastros** **/** **Cuidados com o Paciente / Cirurgias / Procedimentos para Agenda de** **Cirurgias**.
2. Edite e/ou inclua um registro.
3. Preencha os campos obrigatórios da aba **Identificação**.

   1. Código
   2. Decrição
   3. Execução
   4. Limpeza
   5. Ativo
4. Preencha a **Descrição** com até **100 caracteres**.
5. Salve o registro para visualizar na Listagem.
