# Inclusão de Cubos no BI de Procedimento Cirúrgico

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Controle de Infecção Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | BI de Procedimento Cirúrgico | |
| **Cadastros Iniciais:** | Procedimento de Origem, Agrupamento de Procedimento de Origem |
| **Banco(s) de Dados:** | SQL Server® /Oracle® |
| **Tabelas Utilizadas:** | SZJCORRESPPROCEDIMENTO, SZJAGRUPAPROCORIGEM |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Foi verificado a necessidade de implementação dos cubos de "Procedimento de Origem" e "Agrupamento de Procedimento de Origem", no "BI de Procedimento Cirúrgico".

## Procedimento para Utilização

       1.            No "TOTVS Controle de Infecção Hospitalar"(RM Janus), acesse "Apoio Gerencial / Procedimento Cirúrgico".

O sistema apresenta o "BI de Cirurgias".

       2.            Informe uma data de inicio e fim, e clique em "Atualizar".

       3.            Posicione os cubos de "Procedimento de Origem" e "Agrupamento de Procedimento de Origem", sobre o "BI".
