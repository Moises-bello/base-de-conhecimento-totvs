# Opção de perfil e valor default para contabilizar posteriormente na baixa e retorno bancário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Opção de perfil e valor default para contabilizar posteriormente na baixa e retorno bancário. |
| **Situação/Requisito:** | Controlar a permissão, por perfil, na opção "Contabilizar Posteriormente" na tela do processo de baixa. Usuários não vinculados a perfil com essa permissão não poderão alterar o valor da mesma. Também será definido no parametrizador um valor padrão para a opção contabilizar posteriormente. |
| **Solução/Implementação:** | 1 - Definir a opção de perfil para contabilizar posteriormente.    2 - Definir o default para o parâmetro contabilizar posteriormente na tela de baixa manual e retorno de cobrança e pagamento |
