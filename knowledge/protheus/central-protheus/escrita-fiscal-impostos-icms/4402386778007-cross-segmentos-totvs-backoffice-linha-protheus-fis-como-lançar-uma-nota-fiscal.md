**Dúvida**TOTVS Backoffice Linha Protheus - FIS- Como lançar uma nota fiscal com redução de base de cálculo?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão Fiscal - Todas as versões  
  
**Solução**

Lançamento de uma nota fiscal com redução de base de calculo para industrialização / comercio

Redução de 51,11

Configuração da TES

Calcula icms = sim

l fiscal icms = isento / outros

% red icm = 48,89

Mat consumo = não

CST = 20

Dessa forma a parte que tem redução de base de calculo será lançado na coluna isento /outros do ICMS

Exemplo

1000,00

Redução 51,11

Base de calculo = 488,90 \* 18% = 88,00
