**Copiar parâmetros do funcionário**   
   
Este assistente irá auxiliá-lo na cópia dos parâmetros de um funcionário para outro dentro da mesma coligada  
Para utilizar o assistente clique no botão Avançar.  
   
**Seleção de processos** Na janela de seleção de Funcionário, selecione o processo funcionário e clique em avançar. Na janela seguinte o sistema lista todos os funcionários disponíveis na base de dados para se fazer à cópia dos parâmetros. Selecione o funcionário que deseja fazer a cópia e clique no botão Avançar.  
**Observação** O funcionário não ficará disponível caso o mesmo não utilize cartão de ponto.  
**Processos Copiar parâmetros do funcionário**  
Informar a chapa para a qual deseja copiar os parâmetros   
   
**Concluindo o Assistente de Cópia de Registros entre Coligadas** Para concluir a cópia dos parâmetros do funcionário clique no botão 'executar'.
