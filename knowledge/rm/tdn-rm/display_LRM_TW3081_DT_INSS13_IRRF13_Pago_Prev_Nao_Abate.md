# EVENTO DE INSS13 E IRRF13 PAGO PELA PREVIDENCIA NÃO ABATE NOS EVENTOS DESCONTADOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *13o. Salário* |
| **Situação/Requisito:** | Quando o funcionário tem salário maternidade pago pela previdência e são lançados os eventos de código de cálculo 171 e 172, os mesmos não são deduzidos e/ou estornados das bases e valores de desconto de INSS e IR, CC's 103 e 49. |
| **Solução/Implementação:** | Ajuste no cálculo dos eventos de CC's 103 e 49 para abater o valor lançado nos CC's 171 e 172, respectivamente. |
