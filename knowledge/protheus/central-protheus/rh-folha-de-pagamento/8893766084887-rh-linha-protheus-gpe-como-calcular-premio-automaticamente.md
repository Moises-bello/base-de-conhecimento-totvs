![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18330113632791) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**O sistema calcula valor de premio automaticamente?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da Versão 12.  
  
**Solução**Pelo sistema padrão não há ID de cálculo para valor premio, assim o valor não é calculado automaticamente. Para pagamento é necessário lançar o valor em uma verba de provento sem ID de cálculo ou customizar a rotina.
