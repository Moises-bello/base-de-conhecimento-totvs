# Notificações recebidas pelo eduCONNECT quando está fechado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Recebimento de notificações push no eduCONNECT. |
| **Situação/Requisito:** | Foi informado que o eduCONNECT quando está aberto ou em segundo plano recebe corretamente a notificação de push, mas não ocorre quando o aplicativo está completamente fechado. |
| **Solução/Implementação:** | Aperfeiçoado o recebimento de notificações push quando o eduCONNECT está completamente fechado, ou seja, nem aberto ou executando em segundo plano. |
