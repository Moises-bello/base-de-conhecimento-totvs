**Histórico de Importação**

Visualize as informações sobre os arquivos importados. Cada importação de batidas realizada registrará os dados necessários para identificação do usuário responsável pela importação, data e hora da realização e o layout utilizado. Ao utilizar o layout AFD conforme PORTARIA 1510/2009 será registrado o 'número do REP' que coletou as batidas, essa informação deverá estar disponível no arquivo de importação conforme 'Fonte dos dados'.

**Observação**

Caso esteja utilizando a importação automática, informe o caminho de rede do arquivo, no qual deverá estar compartilhado. Exemplo \\servidor\batidas.txt   
Todas as batidas registradas nessa importação poderão ser visualizadas através do anexo 'Arquivo Fonte de Dados Tratado'.
