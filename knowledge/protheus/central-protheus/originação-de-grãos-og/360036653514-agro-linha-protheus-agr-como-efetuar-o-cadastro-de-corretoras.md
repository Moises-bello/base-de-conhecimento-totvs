**Dúvida**Como efetuar o cadastro de Corretoras?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**Para cadastrar corretoras no Sistema, siga os passos:

**1.** Acessar o módulo **67** **-** **Gestão de Agronegócio >** **Atualização >** **Cadastros** **Gerais >** **Fornecedores - MATA020** e clique na opção **Incluir** para adicionar um novo **fornecedor**. O novo registro deve ter os dados da sua corretora.  
Após finalizar o cadastro, acesse **Outras Ações**, **Relacionadas**, **Contatos**.

![CORR.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/7941617837335)

Informe os contatos que serão vinculados ao **Fornecedor**. Esse contato indica os dados do corretor. Para incluir um novo contato, utilize a opção de **Consulta Padrão F3** do campo **Contato**.

![CORR1.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/7941619255447)

A tela apresentará os contatos existentes no Sistema. Utilize a opção **Incluir** da tela de **Consulta Padrão** para adicionar novos contatos;  
  
**2.** Acessar **Gestão de Agronegócio** **>** **Atualização >** **Comercialização >** **Negociações >** **Contrato de Compras >** **OGA280** - **Contrato de Compras**, acesse a opção **Incluir** ou **Alterar** para um contrato de compra existente.  
Na pasta **Corretoras**, informe o **código** do **Fornecedor** que identifica a sua corretora no campo **Cod. Crtra.** No campo **Cod.Corretor** informe o contato que foi vinculado no cadastro de **Fornecedor**. Utilize a **Consulta Padrão - F3** para filtrar apenas os contatos da corretora informada.

![CORR2.PNG](https://centraldeatendimento.totvs.com/hc/article_attachments/7941628174999)

**Importante**  
O exemplo apresentado é para o **Contrato de Compra** - **OGA280**, mas o mesmo pode ser utilizado para o **Contrato de Venda** - **OGA290**.   
Somente com a **Nova Comercialização ativa -** **MV\_AGRO002** é possível usar a pasta de corretagem com os cálculos das comissões, com a versão clássica os dados são apenas informativos.
