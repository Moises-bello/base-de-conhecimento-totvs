![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22810352310423) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Existe ID especifico de IRRF saldo de salário rescisão?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Não existe ID especifico de IRRF saldo de salário rescisão. O IRRF saldo de salário se trata do desconto IRRF mês e assim pelo padrão em rescisão será calculado no ID 0066.
