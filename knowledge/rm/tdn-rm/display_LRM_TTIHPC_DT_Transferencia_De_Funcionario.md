# TRANSFERÊNCIA DE FUNCIONÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção & Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Transferência de Funcionário* |
| **Situação/Requisito:** | *A transferência de funcionários pode demorar horas em alguns casos, mesmo apenas para um funcionário.* |
| **Solução/Implementação:** | *A demora se devia à quantidade de informações do Chronus que precisavam ser copiadas e recalculadas para garantir a integridade da informação. Em casos de funcionários com um grande volume de batidas, o processo era muito demorado.*  *O processo foi então alterado para copiar apenas as informações da competência atual, mantendo o histórico antigo associado à chapa antiga do funcionário. Salvo algumas exceções que ainda são necessárias de serem copiadas em sua totalidade, como o Saldo de Banco de Horas.* |
| **Chamados relacionados:** | TTIHPC |
| **Versões/Release:** | *12.1.8* |
