## **02. SITUAÇÃO/REQUISITO**

Cadastrar perímetros para os funcionários, que possam ser utilizados em integração com a Carol Clock-in para validação das batidas (dentro ou fora do perímetro).

## **03. SOLUÇÃO**

Foi implementado um cadastro para localizações, de forma que o usuário consiga gerenciar endereços de cada funcionário, para que então, uma posterior integração com a Carol Clock-in consiga validar batidas dentro e fora do perímetro.

Permissões, Telaspasso1,passo2yespasso1

Foram criadas algumas permissões que controlam as funcionalidades de cadastro da tela de localizações.

Para acesso a estas permissões, é necessário abrir o módulo de **Serviços Globais** e conceder as permissões para o menu de **Localizações**, conforme imagens abaixo.

nopasso2

Para acesso a tela de Localizações, é necessário selecionar os anexos da tela de **Funcionários**, conforme imagens abaixo.
