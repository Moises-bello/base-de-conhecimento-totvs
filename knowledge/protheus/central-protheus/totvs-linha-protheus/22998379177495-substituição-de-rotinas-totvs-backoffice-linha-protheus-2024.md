Os produtos TOTVS estão em constante evolução para acompanhar cada etapa da jornada digital da sua empresa.

Diante disso, comunicamos que algumas **rotinas do TOTVS Backoffice Linha Protheus** serão descontinuadas em **31/10/2024**.

Conheça abaixo as rotinas que serão descontinuadas e suas substitutas:

|  |  |  |  |
| --- | --- | --- | --- |
| **Módulo** | **Rotina** | **Descrição da rotina** | **Rotina Substituta** |
| Entradas | MATA045 | [M-Messenger](https://tdn.totvs.com/pages/viewpage.action?pageId=821188056) | Event Viewer |
| Faturamento | Portal do Cliente | [Portal do Cliente](https://tdn.totvs.com/pages/viewpage.action?pageId=821568502) | Novo Portal do cliente |
| Financeiro | FINA380 | [Conciliação bancária manual](https://tdn.totvs.com/pages/viewpage.action?pageId=820552747) | Novo conciliador Backoffice |
| Financeiro | FINA473 | [Conciliação bancária automática](https://tdn.totvs.com/pages/viewpage.action?pageId=820552747) | Novo conciliador Backoffice |
| Controladoria | CTBR355 | [Conferência de Lançamentos](https://tdn.totvs.com/x/VR74M) | Conciliador Backoffice |
| Controladoria | CTBR357 | [Log de Lançamento](https://tdn.totvs.com/x/VR74M) | Conciliador Backoffice |
| Controladoria | CTBA101 | [Lançamentos contábeis manuais](https://tdn.totvs.com/x/VR74M) | Lanc. Contábeis autom. |

A todos os clientes que ainda utilizam as rotinas que serão descontinuadas, sugerimos que adotem as rotinas substitutas. Conheça os benefícios das **rotinas substitutas:**

**Event Viewer:** oferece a possibilidade de registrar os eventos ocorridos dentro do ambiente TOTVS Backoffice - Linha Protheus e disponibilizá-los para visualização dos usuários.

**Novo Conciliador Bancário:** o novo processo de conciliação de movimentos bancários permite que a conciliação manual e automática sejam executadas na mesma interface, além de automatizar uma série de processos que trarão mais agilidade à operação dos clientes.

**Portal do Cliente:** o Portal do Cliente - Backoffice Linha Protheus, proporciona aos clientes dos nossos clientes, uma experiência de auto atendimento. Por meio dele, é possível acompanhar informações financeiras, gerar boletos, visualizar as notas fiscais eletrônicas emitidas, extrair relatórios entre outras funcionalidades.

**Conciliador Backoffice:** oferece funcionalidades avançadas para conciliação, tais como: conciliação automática de contas, detecção de divergências, controle de acesso às informações contábeis e muitas outras funcionalidades. Também oferece a possibilidade de uso de inteligência artificial para auxiliar o cliente na conciliação de movimentos divergentes. 

**Lançamentos Contábeis Automáticos:** Interface única para lançamentos contábeis manuais e automáticos, proporcionando uma melhor experiência e mais produtividade aos nossos clientes. 

A seguir, esclarecemos as possíveis dúvidas sobre a transição para as **rotinas substitutas**. 

**Como posso utilizar as rotinas substitutas?**

Cada rotina possui um procedimento distinto para acesso, confira cada um deles:

**Event Viewer:** Acesse o módulo Configurador, opção Ambientes / Cadastros / Inscr. Event Viewer. Nos demais módulos, a rotina está disponível em Miscelâneas / Inscr. Event Viewer.

**Novo Conciliador bancário:** o novo processo de conciliação de movimentos bancários deve ser configurado via Configurador para execuções automáticas e a interface de usuário é carregada por meio da rotina Conciliador Contábil (CTBA940),  onde é possível fazer as conciliações manuais.

**Portal Cliente:** para acessar este Portal, você deve estar no release 12.1.33 ou superior, possuir um Alias no Mingle com um IP público, e seguir as demais orientações detalhadas em nossa [documentação](https://tdn.totvs.com/display/public/PROT/Portal+do+Cliente).

**Conciliador Backoffice:** a interface de usuário é carregada por meio da rotina Conciliador Contábil (CTBA940) disponível nativamente no produto TOTVS Backoffice - Linha Protheus (Contabilidade Gerencial módulo 34), no  release 12.1.33 ou superiores.

**Lançamentos Contábeis Automáticos:** a interface de usuário é carregada por meio da rotina Conciliador Contábil (CTBA102),  disponível nativamente no produto TOTVS Backoffice - Linha Protheus (Contabilidade Gerencial módulo 34).

 

***Importante:*** todos os clientes que utilizam as rotinas que serão descontinuadas atualmente, não terão custos para migrar para as rotinas substitutas.

 

**O que vai acontecer com os meus dados?**

Seus dados permanecerão disponíveis no banco de Dados já utilizado. 

Lembrando que a TOTVS sempre atuará observando toda e qualquer legislação aplicável e eventuais deveres de confidencialidade existentes.

 

**O que vai acontecer se eu não migrar para as rotinas substitutas até a data da descontinuação?**

Se você não realizar a migração para as **rotinas** **substitutas** até a data da descontinuação, você não contará mais com os serviços de suporte técnico e/ou correções e a partir de 31/12/24, você perderá o acesso às rotinas descontinuadas, pois elas serão removidas do menu do produto. 

Recomendamos migrar para as rotinas substitutas até a data da descontinuação, para evitar eventuais impactos em sua operação e garantir suporte técnico.

 

**O que vai acontecer após a data da descontinuação?**

Conforme nossa Política de Ciclo de Vida de Software, a partir da data de descontinuação, a TOTVS não irá evoluir, prestar suporte ou dar manutenção para as rotinas descontinuadas.

**Preciso fazer a validação das rotinas substitutas no meu ambiente?**

Recomendamos que, para assegurar o sucesso na adoção das rotinas substitutas, seja realizada a validação da aderência e definição de configurações específicas e novas parametrizações, seguidas de rodadas de testes. Em alguns casos, a implantação das rotinas substitutas pode gerar a necessidade de treinamentos e capacitações a serem fornecidos sob demanda.

Estamos à disposição para esclarecer qualquer dúvida. Basta entrar em contato com o seu ESN (Executivo de Soluções e Negócios)!
