* Data de corte: Data definida para início para operações de integração com o TOTVS Antecipa/Painel Financeiro.
* Base de Dados de Produção: Como o TOTVS Antecipa não possui um ambiente de testes, é necessário informar a base de dados oficial de produção onde será rodado o processo de leitura de transações no TOTVS Antecipa, evitando assim que seja processado em uma base de dados de testes.
