Foi criado o processo de **Efetivar Seguro** na tela de **Seguros** do **TOTVS Incorporação**.   
 Para usar este recurso basta acessar a tela de **Seguro | Processo Efetivar Seguro**.

Observações

* É possível selecionar mais de um seguro para a Efetivação.
* Após a efetivação do seguro, não será possível alterar os dados do(s) mesmo(s).
* Apenas será possível desfazer a efetivação, ou seja, voltar a situação do seguro para "Em preparação", casa não haja lançamentos gerados para o seguro.
