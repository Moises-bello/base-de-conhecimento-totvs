![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18552858691479) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Com lentidão nas rotinas, como gerar logprofiler das rotinas do SIGAMDT para análise de lentidão e problemas de performance ?  
  
**Ambiente**TOTVS RH (Linha Protheus) - Medicina e Segurança do Trabalho - Todas as versões  
  
**Solução**

Para análise de lentidão e/ou problemas de performance no sistema é necessário gerar um arquivo log específico para que seja analisado o tempo de execução de cada rotina no sistema. Para isto deve-se seguir a documentação para geração do arquivo corretamente:
