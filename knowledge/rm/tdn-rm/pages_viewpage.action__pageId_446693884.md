# Chave Duplicada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Lançamento Fiscal |
| **Situação/Requisito:** | Ao tentar incluir a Referência para o segundo item de um mesmo lançamento de origem e destino, foi apresentado erro de Chave Duplicada. |
| **Solução/Implementação:** | Ajuste técnico no cadastro de associação de itens, nos itens do lançamento fiscal para que seja possível referenciar manualmente itens diferentes da mesma nota origem para a mesma nota destino. |
