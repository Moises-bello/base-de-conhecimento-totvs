**Dúvida**Quais campos são verificados para o Registro 1100?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**Para o registro 1100, deve ser preenchido os seguintes os seguintes campos no Embarque utilizando a DUE: EEC\_NRODUE , EEC\_DTDUE ,EEC\_DUEAVR  
Segue link que contempla tal informação:  [Declaração Única de Exportação (DUE) no SIGAEEC](https://tdn.totvs.com/pages/releaseview.action?pageId=455802907)
