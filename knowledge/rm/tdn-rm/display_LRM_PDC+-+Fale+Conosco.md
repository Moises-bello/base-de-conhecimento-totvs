Ao acessar o menu **Fale Conosco**, no *PDC*, o sistema apresenta um filtro por Empreendimento e por Contrato, possibilitando a comunicação entre o comprador e a incorporadora.

São exibidas os seguintes campos com preenchimento obrigatório:

* **Selecione o Assunto:** Selecione o assunto do contato, entre as opções cadastradas pelo gestor do PDC. Este campo tem o preenchimento obrigatório;
* **Selecione o Imóvel**: Selecione o Imóvel para o qual esta solicitação será aberta. Este campo é preenchido automaticamente pelo sistema, de acordo com o contrato selecionado.

Caso o usuário deseje abrir a solicitação para outro imóvel, basta selecioná-lo entre as opções apresentadas;

* **Descrição:** Insira um texto, link ou imagem que descreva a solicitação que será enviada para a incorporadora.

Esta tela apresenta ainda, a opção **Envio Arquivo**, onde podem ser anexados arquivos em um tamanho máximo definido pelo Parâmetro [Geral](https://tdn.totvs.com/pages/viewpage.action?pageId=731881683), do TOTV Gestão e Construção de Imóveis e com os formatos abaixo:

* Imagem: jpg, jpeg, png;
* Vídeo: flv, mov;
* Documento: pdf

Ao enviar o e-mail, o Comprador verá a mensagem de que o e-mail foi enviado com sucesso, porém sugerimos que a incorporadora crie um e-mail de resposta automático para estas interações, de forma que o usuário tenha um retorno sobre o recebimento dela.

Para determinadas demandas, o comprador pode usar a opção de *[Atendimento](https://tdn.totvs.com/display/LRM/PDC+-+Atendimento)* do próprio PDC.
