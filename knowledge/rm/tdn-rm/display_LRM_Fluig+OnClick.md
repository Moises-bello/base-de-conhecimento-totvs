# Fluig OnClick

|  |  |
| --- | --- |
| **Produto:** | Framework |
| **Versões:** | 12.1.8 |
| **Ambiente:** | RM.exe |
| **Passo a passo:** | **Objetivo:**  O objetivo deste documento é ensinar como configurar o a integração RM X IDENTITY utilizando a funcionalidade "Fluig OnClick"  **Introdução:**  Para configurar a integração é necessário pegar o Token dos aplicativos RM no Identity. Para pegar o Token acesse o link [Token da Aplicação](http://tdn.totvs.com/x/Xb5bDQ).  Após pegar o Token acesse o menu "Fluig OnClick", que pode ser encontrado na guia "Ambiente" de qualquer módulo.    Será exibida a seguinte tela:   | Na opção 1 deve ser inserida a URL do Fluig Identity. Ex: [https://totvs.fluigidentity.com](https://totvs.fluigidentity.com/)  Na opção 2 deve ser inserido o Token da aplicação **RM** criada no Fluig  Na opção 3 deve ser inserido o Token da aplicação **RM Portal** criada no Fluig  A Opção 4 é a barra de progresso da execução do sincronismo do RM de cada aplicativo do Identity. Observação O Token da aplicação **RM Portal** não é obrigatório caso não possua o produto. | | --- |     Após preencher os campos o item "**Situação atual do Fluig Identity**" será atualizado, exibindo o status da conexão com o IDENTITY.  Caso o IDENTITY esteja funcionando o botão **c****onfigura****r** ficará habilitado, onde necessário clicar no mesmo para ativar a integração.   |  |  | | --- | --- |  Observação O Fluig OnClick configura a integração sempre como **opcional**.   Para mais informações sobre tipo de integração acesso o link [Tipos de Integração](http://tdn.totvs.com/x/AMlbDQ). |
