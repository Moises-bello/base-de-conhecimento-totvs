# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1.17 |
| **Ocorrência:** | Classificação do Evento Contábil |
| **Ambiente:** |  |
| **Passo a passo:** | A tabela de Classificação de Evento Contábil é livre e pode ser usada de acordo com as necessidades de cada empresa. Esta funcionalidade permite que o usuário classifique o Evento Contábil da maneira que desejar facilitando o gerenciamento das contabilizações.  Ao solicitar inclusão o sistema apresentará para preenchimento o campo ‘Classificação Contábil’, estando o usuário responsável por informar se este é de Aquisição, Baixa, Acréscimo, entre outros. Posteriormente deve selecionar o evento que se relaciona a Classificação Contábil.  Acesse o **Menu Contabilização | Classificação do Evento Contábil** | Incluir | Preencha o campo ‘Classificação Contábil’ | Preencha o campo ‘Evento Contábil’ que corresponde a classificação | Salvar.  **Exemplo:**            **Observação:** O [Evento Contábil](https://tdn.totvs.com/pages/viewpage.action?pageId=423938693) deve ser previamente criado no menu Contabilização | Evento Contábil. |
| **Observações:** | A execução deste processo é necessária quando o usuário precisa vincular Eventos Contábeis no cadastro de Grupo de Patrimônios, pois o processo irá apresentar para seleção somente os eventos classificados. |
