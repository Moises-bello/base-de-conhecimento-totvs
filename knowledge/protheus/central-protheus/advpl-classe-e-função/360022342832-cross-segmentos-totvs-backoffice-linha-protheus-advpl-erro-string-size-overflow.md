***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png)*** Tempo aproximado para leitura: **00:00:20 min****Ocorrência**

Erro String size overflow!

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360019644912/mceclip0.png)

**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) - Customizações - A partir da versão 11.80.  
  
**Causa**Esta ocorrência é reproduzida quando atingimos o limite do tamanho de uma **string** em **advpl** [String size overflow](http://tdn.totvs.com/display/tec/String+size+overflow)  
  
**Solução**É possível alterar esse comportamento.usando a chave [MaxStringSize](http://tdn.totvs.com/pages/viewpage.action?pageId=161349793)
