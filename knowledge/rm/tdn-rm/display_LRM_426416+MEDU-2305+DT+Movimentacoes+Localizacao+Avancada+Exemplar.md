# MOVIMENTAÇÕES - LOCALIZAÇÃO AVANÇADA - EXEMPLAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Bibliotecária* |
| **Função:** | *Movimentações - localização avançada - exemplar* |
| **Situação/Requisito:** | *Foi identificado que na tela de movimentações na tela de 'Localização avançada', ao selecionar a opção de busca por exemplar e digitar o nome da publicação e pressionar 'enter' para a busca rápida, o sistema retorna a lista de exemplares da publicação porém somente o título da publicação, não retorna mais nenhum dado, o que dificulta a identificação do exemplar da publicação.* |
| **Solução/Implementação:** | *Foi feito um ajuste na opção de busca por exemplar para que ao informar o nome da publicação e pressionar enter para a busca rápida o sistema retorne além do título da publicação, traga também o subtítulo, código da publicação, código do exemplar e o número do tombo do exemplar, assim possibilitando uma melhor identificação do exemplar desejado.* |
