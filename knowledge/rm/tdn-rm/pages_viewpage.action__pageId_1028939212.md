Para enviar os dados fiscais da nova reforma tributária deverá configurar a Reforma Tributária do TCGI e Fiscal definindo os impostos de IBS e CBS. Os valores serão calculados como base, sem efeito financeiro, nesse primeiro momento da reforma. Os valores bases serão armazenados na tabela de parcelas “xvendaparcela” como base do IVA e base redutor do IVA. O valor base é a soma de todos os componentes que não tenha marcado desconsiderar base do IVA. O valor base redutor é o valor de desconto cedido para abater o cálculo de imposto, podendo cadastrar outros redutores de incentivos locais.

A memória de cálculo dessas bases é guardada na memoria de cálculo do reajuste. Para o cálculo correto dos valores dos impostos, o cliente deverá utilizar a nova máquina de cálculo do reajuste e também o reajuste on-line, não será permitido o uso da nova regra tributaria sem essas premissas. Agora, todos os componentes serão reajustados os valores tributários, conforme legislação vigente, como os componentes de entrada, principal e MCMV.  Os valores serão gerados apenas para unidades residenciais e não optante do RET.
