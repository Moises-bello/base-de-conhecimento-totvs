Fonte Padrão é sobrescrito mesmo sem código de autorização

|  |  |
| --- | --- |
| Situação | Fonte Padrão é sobrescrito mesmo sem código de autorização |
| Ocorrência | Ao tentar compilar um fonte com o mesmo nome de um outro fonte que já estava no RPO o fonte era sobrescrito sem nenhuma checagem do tipo de Licença de compilação |
| Correção | Criação de mecanismo para impedir a compilação de um fonte com o mesmo nome de um inserido no RPO com Licença Full por alguém que tenha apenas licença de usuário. |
| Informações adicionais | * Referente ao chamado: SSIM-269 * Referente à ocorrência: TTEC-727 * Disponível a partir da build a 7.00.131227A - 2.0.3 |
