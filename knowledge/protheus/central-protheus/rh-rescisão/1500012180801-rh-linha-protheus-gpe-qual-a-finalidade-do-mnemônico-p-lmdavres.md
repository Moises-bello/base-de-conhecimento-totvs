**Dúvida**Qual a finalidade do mnemônico P\_LMDAVRES?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O mnemônico P\_LMDAVRES foi criado para indicar se as verbas lançadas na rescisão devem ser consideradas para o cálculo da média de aviso prévio. Este mnemônico terá a mesma funcionalidade que o P\_LMDAVMES especificamente para funcionários que não são comissionados ou tarefeiros.

O mnemônico por padrão esta desativado, e para que as verbas sejam consideradas deverá ser alterado para true (.T.)

**Mnmemônico P\_LMDAVRES.**
