Dúvida**Como é preenchido o campo WD\_DTENVF para despesas de Importação?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 11.80  
  
**Solução**O campo WD\_DTENVF somente é preenchido para as despesas incluídas via solicitação de numerário e posterior prestação de contas e para as despesas incluídas diretamente no processo, os títulos  o Frete/ Seguro e Cambio da Invoice a data não são preenchidas na tabela SWD.
