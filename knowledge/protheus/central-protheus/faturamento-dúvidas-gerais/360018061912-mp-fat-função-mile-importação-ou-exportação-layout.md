**Dúvida**

Como importar/exportar tabelas no sistema?

**Ambiente**

Microsiga Protheus - a partir da versão 11.80  
  
**Solução**

Você pode realizar esse processo através da função Mile.

O intuito desta ferramenta é facilitar a importação/exportação de dados para o sistema através do uso de rotinas automáticas **MSExecAuto**. Pra isso você ira precisar de um Layout.

Para validação de layout acessar a documentação.
