# Objetivo:

---

     O objetivo deste documento é demonstrar como habilitar/desabilitar funcionalidades do sistema.

false

# Introdução:

---

     Algumas opções do sistema ficam desabilitados mesmo que o usuário tenha permissão de acesso. Por proporcionarem perca no desempenho estas opções veem por default desabilitadas. Abaixo demostraremos como habilitar/desabilitar estas opções.

false

     As configurações para ativação e desativação estão localizadas nos **Parâmetros Globais**. Acesse o menu "*Ambiente | Configuração | Parâmetros | Parâmetros Globais*". No formulário que irá carregar selecione a guia "**Performance**"

Obs.: *De qualquer módulo é possível acessar os Parâmetros Globais.*

---
