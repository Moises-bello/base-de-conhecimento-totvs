# PERÍODO DA FICHA FINANCEIRA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Período da Ficha Financeira* |
| **Situação/Requisito:** | Ao realizar a alteração do campo "Período" na tela de "Parâmetros Locais" informando um valor acima de dois dígitos, ao tentar informar o mesmo valor no campo "Período" na tela de "Período da Ficha Financeira" não é possível, pois o campo aceita somente 2 dígitos. |
| **Solução/Implementação:** | Ajustado o campo "Período" na tela de "Período da Ficha Financeira"  para aceitar o mesmo número de dígitos que é informado no campo "Período" na tela de "Parâmetros Locais" |
| **Chamados relacionados:** | TTR938 |
| **Versões/Release:** | *12\_1\_9* |
