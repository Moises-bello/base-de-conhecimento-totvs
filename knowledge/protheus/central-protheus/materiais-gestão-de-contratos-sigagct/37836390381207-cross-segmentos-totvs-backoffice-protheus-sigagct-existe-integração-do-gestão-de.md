O módulo Gestão de Contratos do TOTVS Protheus não possui integração nativa com o módulo Estoque/Custos (SIGAEST) para checagem de saldos na inclusão de contratos. É possível avaliar customizações conforme a necessidade, utilizando pontos de entrada disponíveis na rotina de manutenção de contratos. Links para documentação e guias relacionados são fornecidos para suporte.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/37836381296791) Tempo aproximado para leitura: **00:10:00 min**

**Dúvida**

No Gestão de Contratos, existe algum tipo de integração com o módulo Estoque/Custos (SIGAEST) para checagem de saldos em estoque dos produtos na inclusão de um contrato?

**Ambiente**

Cross Segmentos - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões

**Solução**

No padrão do Gestão de Contatos, ele não possui uma funcionalidade ou parametrização para realização deste processo de integração na inclusão de contratos com módulo do SIGAEIC do Protheus para checagem de saldos de produtos e nem checagem de saldo sem outros pontos do modulo, não possuindo nenhum tipo de integração com este módulo.  
 

Caso deseje pode-se avaliar a possibilidade através de uma customização conforme a necessidade.  
Abaixo segue artigos com os pontos de entrada disponíveis da rotina para que se possa avaliar algum que possa atender de alguma forma conforme a necessidade.
