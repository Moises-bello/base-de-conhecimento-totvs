Estou realizando a atualização/migração, utilizando o ATUALIZADOR, e durante o processo é apresentado o erro abaixo:

**OCORREU UM ERRO NÃO TRATADO! :Object reference not set to an instance of an object**

**OCORREU UM ERRO NÃO TRATADO! :Referência de objeto não definida para uma instância de um objeto**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30830558851351)

**Ambiente**TOTVS RH - TOTVS RH - eSocial  - TAF eSocial - Atualização - ATUALIZADOR - Todas as versões  
  
**Solução**

Caso esteja atualizando o TAF, migrando de versão, e seja apresentado o erro:  
*OCORREU UM ERRO NÃO TRATADO! :Object reference not set to an instance of an object,* Orientamos a leitura da documentação abaixo:  
<https://tdn.totvs.com/pages/releaseview.action?pageId=546248653>  
  
\*\*Inicie a leitura á partir do item:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30830558852503)

**ATENÇÂO:** Reforçamos que, após terminar com sucesso a atualização, o sistema não estará com a última expedição contínua.   
Após rodar o ATUALIZADOR, é necessário aplicar a última Expedição Contínua do TAF:  
[RH - Linha Protheus - TAF - ATUALIZAÇÃO - Como atualizar o TAF E-social (Expedição Contínua)?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/18972648169239)
