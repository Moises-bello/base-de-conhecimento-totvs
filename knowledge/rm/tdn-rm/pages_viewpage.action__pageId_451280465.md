# TAG do contrato de matricula não esta calculando parcelas por créditos e valor fixo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Matrícula |
| **Função:** | Contrato Financeiro |
| **Situação/Requisito:** | Cliente informa que, ao utilizar os valores por crédito, o sistema está realizando o cálculo considerando somente o valor fixo dividindo pelo número de parcelas e não está considerando os créditos das disciplinas selecionadas no momento da rematrícula. |
| **Solução/Implementação:** | Foi realizado ajuste para tratar corretamente o cálculo dos valores a serem substituídos pelas TAGS, considerando os créditos das disciplinas selecionadas no momento da rematrícula. Assim os valores serão exibidos corretamente no contrato financeiro do aluno. |
