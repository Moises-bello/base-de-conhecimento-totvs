**Introdução**

---

Em sistemas cujo o Portal de Imóveis já foi migrado para a base RM, a visão de comissão 2.0 consulta diretamente todas as comissões criadas a partir desta migração, possibilitando uma visão abrangente que pode compreender períodos distintos além de situações diferentes.

Esta visão mostrará apenas as comissões do corretor logado. Porém, caso o usuário seja um supervisor, ou administrador dentro do sistema, a visão irá carregar uma quantidade maior de registros.

Essa é uma tela que, dependendo da operação do portal, pode carregar bastante registros, dependendo do usuário que a acessa.

Há paginação dos campos, selecionando o botão "*Carregar mais...*" Mas, dado ao volume de dados, recomendamos que seja utilizado um período pequeno para a consulta gerencial das comissões.

**Pré-Requisitos**

---

* Portal de Imóveis Migrado: Esta visão só está disponível para o Portal de Imóveis migrado para a base RM. Para O portal de Imóveis não migrado, favor consultar a documentação no link (clique aqui)
* Comissão configurada e migrada: Para entender mais sobre a comissão 2.0 acesse os links no help abaixo:  

  + Neste link, constam todos os procedimentos de configuração, manipulação, permissões e associação dos novos modelos de comissão aos Empreendimentos disponíveis no Portal de Imóveis.

**Procedimentos para utilização**

---

Para acessar a visão de comissão, o usuário deve ir no menu *Corretores / Comissão 2.0*

Nesta visão, serão apresentadas todas as comissões do corretor que realiza a consulta. Ou todas as comissões dos subordinados quando um usuário é supervisor. Ou todas as comissões do sistema quando o usuário é administrador.

**Período**: Defina um período para realizar a pesquisa das comissões. Recomendamos sempre utilização deste filtro quando o usuário é administrador / supervisor, para não impactar a performance da tela.

**Ordenar por data:** Ordenação de exibição das comissões lançadas, que pode ser crescente ou decrescente.

Além do período, as comissões podem ser filtradas pelas seguintes situações:

* Preparação;
* Calculada;
* Integrada;
* Concluída.

A possibilidade de aplicar o filtro de situação ou de ordenação, só ficarão disponíveis após a primeira pesquisa.
