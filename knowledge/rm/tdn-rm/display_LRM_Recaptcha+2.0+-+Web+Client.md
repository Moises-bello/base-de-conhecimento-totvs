# Objetivo:

---

       Informar sobre a nova extensão criada (TOTVS Mashups Extension) para a correta execução do Web Client do Mashups (reCaptcha 2.0) .

# Introdução:

---

       Para utilizar os serviços do Mashups que possuem o reCaptcha, é necessário baixar e instalar a extensão "TOTVS Mashups Extension". Instalador disponível no site do [Mashups](http://mashups.totvs.com.br/).

       Segue abaixo passo a passo para instalação da extensão:

falseInstalação em N camadas (JobServer)1º Passo:

Acesse o site do [Mashups](http://mashups.totvs.com.br/) e clique em "Extensão do Chrome" para baixar o instalador.

falseObservação:

Quando instalada novamente, é necessário acessar no Chorme, as opções "Mais Ferramentas | Extensões" e ativar novamente a extensão do TOTVS Mashups Extension, para utilizar normalmente os serviços.
