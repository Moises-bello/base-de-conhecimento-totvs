# NOME DO REQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Gestão de Estoque, Compras e Faturamento* |
| **Função:** | *Faturamento de cliente bloqueado e Gerar Financeiro* |
| **Situação/Requisito:** | *Ao Faturar ou Gerar financeiro, a liberação do usuário supervisor deve respeitar sua permissão relacionada a cliente bloqueado, conforme “[02.01.01.10] – Incluir Lançamentos para cli/for bloqueado”. A permissão do supervisor está ignorando essa parametrização e permitindo o lançamento de cliente bloqueado mesmo quando não tem a permissão.* |
| **Solução/Implementação:** | **Ao Faturar ou Gerar financeiro, a liberação do usuário supervisor respeita sua *permissão relacionada a cliente bloqueado, conforme “[02.01.01.10] – Incluir Lançamentos para cli/for bloqueado”, e não consegue gerar lançamento para um cliente bloqueado se não tiver permissão.*** |
