# Impressão de Relatório

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Impressão de relatório no contrato do aluno |
| **Situação/Requisito:** | Durante o processo de "IMPRIMIR RELATÓRIO" no anexo de contrato da matricula no período letivo, ou na tela de contratos, o sistema está apresentando o assistente de geração de relatório para definições de filtros/fórmulas. Isto tem um grande impacto caso o usuário selecione, equivocadamente, filtros indevidos para geração do relatório. O sistema deve respeitar o Contrato selecionado como filtro. |
| **Solução/Implementação:** | Melhoria na emissão de relatório do anexo de contrato da matricula no período letivo para que ao gerar os relatórios do RM Reports não seja apresentado a tela do Wizard e com isso o relatório é gerado de  forma mais dinâmica e simples sem apresentar os filtros. |
