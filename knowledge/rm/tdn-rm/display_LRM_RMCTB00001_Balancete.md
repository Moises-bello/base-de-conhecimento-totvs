| **Passo a passo:** | **Definição do processo:**  O Balancete é um relatório contábil oficial exigido pela Legislação. Ele reflete a contabilidade de uma empresa ou organização num determinado período.  Sendo um demonstrativo auxiliar que relaciona os saldos das contas remanescentes no diário. Imprescindível para verificar se o método de partidas dobradas está sendo observado pela escrituração da empresa.  Geralmente o balancete é disponibilizado mensalmente, servindo assim como suporte aos gestores para visualizar a situação da empresa diante dos saldos mensurados, sendo um demonstrativo de fácil entendimento e de grande relevância e utilidade prática. É também utilizado como auxiliar na análise dos tributos gerados e para fins de planejamento fiscal.    **Regras Gerais:**  Para emissão do relatório no Gestão Contábil, podemos citar a configuração para a impressora padrão que possibilita sua correta geração. Para maiores informações a respeito [clique aqui](http://wikihelp.totvs.com.br/WikiHelp/CTB/CTB.requisitosrelatorios.aspx).    **Parametrização Necessária:**  **1** - **Balancete Contábil** -> como é o tipo de demonstrativo mais usado, sua configuração terá um maior detalhamento, sendo que várias opções mostradas aqui podem ser replicadas para as outras opções do relatório.    Acesse o caminho Relatórios/Balancete, conforme abaixo:        Na figura abaixo mostramos algumas configurações básicas da aba Dados      Destacamos a seguir a seleção de filial/departamento, bem como a opção de buscar os dados do histórico contábil        Podem ser informadas várias preferências de configuração para agilizar o acesso às informações desejadas, sendo que após serem salvas, a funcionalidade permite a exportação e posterior importação dos dados para os demais usuários        Na aba filtros temos várias funcionalidades para extração das informações, vejamos abaixo        Para filtrar centros de custo usamos os mesmos critérios da figura anterior        O filtro de históricos é muito utilizado para se exibir o balancete com as contas resultado antes da transferência de grupos contábeis, ou seja, as contas são exibidas com seus respectivos saldos        A aba layout possui várias opções de configuração em sua maioria autoexplicativas, abaixo destacamos algumas que auxiliam na padronização de apresentação do relatório        Na aba campos temos opções para exibir ou não os campos, informar o tamanho desejado, alterar o nome do campo, bem como observar se o relatório está dentro da delimitação necessária para correta apresentação do mesmo        **2 - Balancete Gerencial** -> extrai os valores lançados nas contas gerenciais.    Em destaque na figura abaixo, os campos básicos para extração dos dados        **3 - Balancete Contábil/Gerencial** -> lista os valores das contas gerenciais informadas como rateio nas contas contábeis.    Na figura abaixo, destacamos o campo contas com movimentação e sem rateio que quando está marcado, busca as contas contábeis sem rateio gerencial, mas que devem fazer parte do relatório, se for o caso        **4 - Balancete Gerencial/Contábil** -> lista os valores das contas contábeis agrupados pelas contas gerenciais.    Na figura abaixo, o destaque é para os campos contas contábeis sintéticas e apenas contas gerenciais analíticas que, dependendo da seleção feita, alteram consideravelmente a apresentação do relatório        **5 - Balancete Centro de Custo/Contábil -**> lista os valores das contas contábeis agrupados pelos centros de custo informados nos lançamentos.  Vale destacar as opções de totalização desta configuração as quais mudam sobre a maneira da apresentação das informações        **6 - Balancete Contábil/Centro de Custo** -> lista os valores das dos centros de custo informados nos lançamentos, agrupados pelas contas contábeis, bem como os valores da conta contábil que não possuem centros de custo informados        **7 - Balancete Orçamentário** -> este relatório lista informações baseadas no cadastro de orçamento do sistema.
