Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como preencher a Matrícula eSocial?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - eSocial - Todas as versões  
  
**Solução**Para preenchimento da Matrícula eSocial, realize os passos a seguir:  
1. Verifique se a [Máscara para Matricula](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360013053051-RM-eSocial-Par%C3%A2metro-M%C3%A1scara-para-Matr%C3%ADcula-do-Trabalhador) foi preenchida em **Configurações | Parametrizador | eSocial | Configurações Gerais 2/7;**

![8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24315547160727)

2. Acesse o menu **eSocial | Saneamento de Dados | Preencher Matricula eSocial;**

![oioiio.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24315547169047)

3. Selecione a coligada desejada, preencha o campo com a data de admissão caso esteja no Leiaute S-1.0, e preencha o filtro para seleção do funcionário;

![matricula.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24315547172247)

4. Após a conclusão do processo, o campo **Matricula eSocial** no cadastro do funcionário será atualizado com a nova matricula informada no processo anterior.

![10.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24315547178135)

**Importante**O campo **Gerar matricula para funcionário sem vinculo com admissão a partir de** será apresentado a partir do leiaute S-1.0  e a data preenchida padrão será a data de alteração para o leiaute S-1.0 na coligada. Poderá ser preenchida com uma data igual ou superior a data padrão. Para funcionários sem vinculo que foram transferidos será considerado a data de transferência.
