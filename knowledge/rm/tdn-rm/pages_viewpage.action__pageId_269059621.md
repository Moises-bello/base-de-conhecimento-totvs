# Cálculo do Valor Liquído

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | *Calculo do valor liquido na tela de lançamento* |
| **Situação/Requisito:** | Ao incluir um lançamento cuja a moeda é um índice esta ocorrendo mensagem "Não foi encontrado cotação para a moeda XXXX na data XX/XX/XXXX", mesmo a moeda tendo a cotação na data atual. |
| **Solução/Implementação:** | Não apresentar mensagem "Não foi encontrado cotação para a moeda XXXX na data XX/XX/XXXX" ao incluir um lançamento que tem como moeda um índice e que tenha cotação cadastrada na data atual. |
