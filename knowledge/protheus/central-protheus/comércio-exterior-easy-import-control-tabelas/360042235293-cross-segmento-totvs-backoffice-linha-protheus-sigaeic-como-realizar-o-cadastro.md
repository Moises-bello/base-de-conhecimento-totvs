**Dúvida**Como realizar o cadastro de navio (EE6)?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**

1.    No módulo Easy Import Control (SIGAEIC), acesse as opções “Atualizações\ Tabelas\ Nomeação de Navio” (EECAC170A). Clique em Incluir.

2.    Preencha os campos obrigatórios.

3.    Na pasta “Trânsito”, clique na consulta do campo Cod. Agente (EE6\_AGENTE).

4.    Selecione um agente embarcador e clique em OK.

5.    O nome do Agente (EE6\_ DSCAGE) será preenchido automaticamente, clique em OK para salvar.

6.    Será possível visualizar o cadastro.
