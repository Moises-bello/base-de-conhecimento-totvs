# Inscrição no Portal do Processo Seletivo "Responsável pela inscrição"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Gestão Educacional |
| **Módulo:** | Educacional |
| **Função:** | Inscrição no processo seletivo |
| **Situação/Requisito:** | Quando o processo seletivo do ensino básico não utiliza o parâmetro "Utilizar responsável por candidato na inscrição", não deve ser necessário informar se o usuário será o candidato ou não. |
| **Solução/Implementação:** | Quando o processo seletivo do ensino básico não utiliza o parâmetro "Utilizar responsável por candidato na inscrição", durante a inscrição, não será exibido o campo onde o usuário informa se será o candidato ou não. Quando não se utiliza o parâmetro todo usuário será o próprio candidato. |
