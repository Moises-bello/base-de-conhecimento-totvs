**Objetivos**

---

O sistema deve permitir que o usuário realize as operações de cadastro nos objetivos do projeto. Entende-se como objetivo do projeto uma forma de categorização de onde o risco irá impactar. Ex: Custo, Tempo, Qualidade, Escopo.  
Com o intuito de facilitar a identificação de quais objetivos o usuário irá utilizar em um projeto. Esse poderá criar grupos de objetivos, associando os objetivos a um determinado grupo e posteriormente informar com qual grupo irá trabalhar em um projeto.  
  
 O objetivo pode estar ativo, disponível para utilização, ou não disponível para utilização. Somente serão exibidos para seleção objetivos ativos.   
 O tipo de grandeza pode ser definido como "Quantitativa" ou "Qualitativa".  
 Se o objetivo do projeto for definido como "Quantitativa" o campo Atributos Quantitativos ficará habilitado para se informar a unidade de medida  
  
**Observação:**

* As unidades de medidas deverão ser cadastradas previamente no cadastro de unidades (Cadastros->Unidades).

Se o objetivo do projeto for definido como "Qualitativa" o campo Atributos Qualitativos ficará habilitado para se cadastrar os atributos qualitativos.  
  
**Observações:**

* Um objetivo será qualitativo ou quantitativo, nunca os dois ao mesmo tempo;
* O cadastro de objetivos é visível a todos os projetos e coligadas. Qualquer alteração realizada em um objeto irá  impactar em todos os projetos que utilizam este objetivo.
