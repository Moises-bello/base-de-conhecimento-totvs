Este é o processo utilizado para realizar a exportação de um ou mais XML para um diretório especificado pelo usuário.

O usuário poderá salvar todos os xml de conhecimentos Pendentes, Autorizados, rejeitados e inconsistentes. Para a exportação de XML de CT-e cancelado, serão gerados os arquivos de autorização e do cancelamento.

Para realizar o processo, basta selecionar os registros dos conhecimentos de transporte desejados e acessar o menu Processos > Salvar XML e informar o diretório no qual o RM deverá gravar os XML's.

***Nota:*** O usuário deve ter acesso no diretório (local/rede) de leitura e escrita para realizar esse processo.
