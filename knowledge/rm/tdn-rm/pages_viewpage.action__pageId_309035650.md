# CONTROLE DE SEGURANÇA ESTENDIDA NA CARGA DE DADOS DO RETORNO BANCÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Retorno bancário. |
| **Situação/Requisito:** | Sistema aplicava segurança estendida por filial/centro de custo em carga de dados de lançamento no retorno bancário. |
| **Solução/Implementação:** | Nas cargas internas de dados do lançamento realizadas no processo de retorno bancário não deve ser aplicada a segurança estendida já que o resultado da consulta não é exibido para o usuário. |
