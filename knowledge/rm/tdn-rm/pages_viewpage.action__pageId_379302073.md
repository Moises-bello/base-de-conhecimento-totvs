# Alteração na validação de CNES na elaboração de AIH

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Gestão Hospitalar |
| **Função:** | Elaboração de AIH |
| **Situação/Requisito:** | Sistema está exibindo uma mensagem de obrigatoriedade de CNES indevidamente,  pois quando o procedimento é lançado no SISAIH01 a mensagem não é exibida. |
| **Solução/Implementação:** | Ajuste na validação da AIH para desconsiderar a mensagem de CNES obrigatório deste procedimento. |
| **Tickets relacionados:** | <https://totvssuporte.zendesk.com/agent/tickets/3107549> |
