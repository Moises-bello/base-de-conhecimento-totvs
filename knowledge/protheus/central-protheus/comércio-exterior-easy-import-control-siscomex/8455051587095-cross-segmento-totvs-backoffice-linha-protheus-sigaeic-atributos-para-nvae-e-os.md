![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Onde onde atualizamos os atributos para NVAE e os Metodos da Valoração no módulo **SIGAEIC**?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**As informações referentes os atributos são inseridas nas rotinas **EICSJK.PRW** e **EICSJL.PRW.** Acessar o modulo do **SIGAEIC** através das opções no menu:

1. Atualizações -> Tabelas Siscomex - Atributo Para N.V.E
2. Atualizações -> Tabelas Siscomex - Especificação Para N.V.E
