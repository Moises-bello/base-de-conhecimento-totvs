# Guia de INSS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *C&P.* |
| **Módulo:** | *Folha de pagamento.* |
| **Função:** | *Guia de Inss* |
| **Situação/Requisito:** | Ao realizar um lançamento financeiro para um autônomo no RMFluxus e gerar a guia de INSS no RMLabore marcando o parâmetro de importar autônomos do RMFluxus, os valores da guia de INSS saem corretos porém o sistema não considera o valor dos autônomos no lançamento financeiro  *.* |
| **Solução/Implementação:** | Otimizado geração dos lançamentos financeiros na guia de INSS de maneira que os autônomos sejam considerados. |
