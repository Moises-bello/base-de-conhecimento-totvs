**Dúvida**Como efetuar cálculo de pensão vitalícia para ex-funcionário?

**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.

**Solução**Não existe uma forma de efetuar o calculo da pensão vitalícia no sistema **automaticamente** para ex-funcionários. É necessário efetuar rescisão complementar mensalmente para o cálculo da pensão vitalícia para o ex-funcionário que tenha direito a este benefício.
