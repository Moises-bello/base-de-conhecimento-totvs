**Dúvida**Como realizar o cadastro de Agentes Transp. ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**1. No módulo SIGAEIC acesse em Atualizações \ Tabelas \ Agentes Transp.(EICA040).  
2. Selecione Incluir;  
3. É necessário informar o campo Fornecedor (Y4\_FORN) e loja (Y4\_LOJA):  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360071986234/mceclip0.png)

**Observação:** O fornecedor informado deve ter o campo Identificac. (A2\_ID\_FBFN) como 3 - Todos:  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360071986394/mceclip1.png)
