# Botão "Ver faltas" no grid de visão de faltas por etapas

|  |  |
| --- | --- |
| **Linha de Produto:** | TOTVS Educacional |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Educacional |
| **Função:** | Faltas por aula |
| **Situação/Requisito:** | O botão "Ver faltas" no grid de visão de faltas por etapas não realiza nenhuma ação quando o perfil do usuário não possui permissão para a tela de Faltas por aula. |
| **Solução/Implementação:** | Quando o usuário não possui permissão para a tela de "Faltas por aula" (no grid de funcionalidades do perfil de usuário possui o nome de "Frequência Diária"), não será mais exibido o botão "Ver faltas". Este botão aparecerá apenas para os usuários que possuírem permissão para esta tela. |
