|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | *****Educacional***** |
| **Módulo:** | T*****otvs Educacional***** |
| **Função:** | Alterar situação de matrícula |
| **Situação/Requisito:** | Ao alterar a situação de matricula para vários alunos ao mesmo tempo, o sistema não estava observando corretamente os documentos obrigatórios do tipo Ingresso. |
| **Solução/Implementação:** | No processo de alteração da situação de matricula (em Lote), o sistema deverá validar se foi entregue os documentos obrigatórios do tipo Ingresso, caso esteja marcado o parâmetro Educacional | Matricula | Movimento | Considerar documentos do tipo ingresso mesmo que não seja a primeira matricula. |
