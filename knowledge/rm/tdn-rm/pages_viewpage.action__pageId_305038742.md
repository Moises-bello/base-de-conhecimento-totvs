# QRCode de configuração do eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração do QRCode dos parâmetros de integração com eduCONNECT no TOTVS Educacional |
| **Situação/Requisito:** | O QRCode de configuração do eduCONNECT está disponibilizado apenas no portal do aluno ou professor, mas no sistema TOTVS Educacional não possui a opção para geração de QRCode. |
| **Solução/Implementação:** | Foi implementado a funcionalidade para geração do QRCode de configuração do eduCONNECT no TOTVS Educacional nas seguintes funcionalidades:  * Mala direta * Agendamento/envio de mensagens (Texto livre) * Parâmetros do sistema na aba do eduCONNECT   Assim, os clientes do TOTVS Educacional que possuem a integração com o eduCONNECT ativada, podem realizar o envio de mala direta, mensagens e imprimir o QRCode de configuração com instruções para configuração do aplicativo da instituição. |
