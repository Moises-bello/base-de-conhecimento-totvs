# NÃO ESTÁ PERMITINDO TRANSFERÊNCIA DE ESTAGIÁRIO SEM FICHA DE REGISTRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão por Transferência* |
| **Situação/Requisito:** | *Ao tentar realizar a Transferência de um funcionário com o Tipo Estagiário, pela Rescisão Individual, não está sendo permitido concluir o processo sem* *informar o número da ficha de registro, mesmo após marcar o parâmetro "Não cadastrar número de Ficha de Registro para Estagiários e Autônomos" no* *Parametrizador, pasta "Funcionários/Configuração de Registro".* |
| **Solução/Implementação:** | *Ajuste nos parâmetros de Transferência na tela da Rescisão Individual, para verificar o parâmetro "Não cadastrar número de Ficha de Registro para* *Estagiários e Autônomos" no Parametrizador, ao consistir o campo para um funcionário do Tipo Estagiário.* |
| **Chamados   relacionados:** | *TVBPOV, TVBZSS* |
| **Versões/Release:** | *11.82.44, 12.1.12* |
