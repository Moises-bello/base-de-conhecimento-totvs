**Dúvida**  
Como atualizar um menu que está no banco de dados?  
  
**Ambiente**  
Protheus - Configurador - A partir da versão 12.1.23  
  
**Solução**  
Quando a base do Protheus está com Dicionário de Dados no Banco de Dados, existe um procedimento específico para atualizar os menus. Por exemplo, se existe alguma nova liberação de menu pelo módulo. Neste caso, deve-se baixar o novo arquivo de menu, salvar na pasta System, e então atualizar conforme procedimento abaixo:  
  
1. Acesse o Configurador > Ambiente > Cadastros > **Menus**  
  
2. No lado direito da rotina, clique no botão **Atualizar**  
![2019-04-05_995.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360025658292)  
  
3. Serão listados os arquivos de menus que estiverem na pasta System. Clique em **Atualizar**  
![2019-04-05_996.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360025658272)  
  
4. Ao término do processo, será exibida uma mensagem de **Sucesso**  
![2019-04-05_997.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360025658312)
