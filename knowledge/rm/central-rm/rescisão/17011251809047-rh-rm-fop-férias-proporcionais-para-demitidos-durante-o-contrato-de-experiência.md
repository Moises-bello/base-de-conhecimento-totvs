![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17011283550359) Tempo aproximado para leitura: **00:01:45 min****Dúvida**Como efetuar o pagamento de férias proporcionais para funcionários que foram demitidos durante o contrato de experiência?  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, verifique e parametrize conforme orientações abaixo:

1. Primeiramente, é necessário parametrizar o sistema para pagar férias proporcionais para demitido como menos de 1 ano, para isso  acesse:**Administração de Pessoal | Sindicatos | edite o sindicato desejado | aba Férias** e marque o parâmetro **Paga férias proporcionais demitidos menos de um ano**;  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17010911358103)

2. Após marcar o parâmetro acima, é necessário informar o número de mínimo de meses para pagamento de férias proporcionais, no caso de contrato de experiência é preciso informar 0 no campo abaixo:  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/17011088638487)

3. Dessa forma, as férias proporcionais serão pagas para o ex-funcionário.
