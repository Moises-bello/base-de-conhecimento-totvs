**Cópia entre coligadas**

Este assistente irá auxiliá-lo na cópia de registro(s) entre as coligada(s) do sistema.

**Parâmetros da cópia -** Na janela de "Parâmetros da cópia" o sistema lista todas as coligadas disponíveis na base de dados para se fazer à cópia de registro. Selecione a coligada ou as coligadas que deseja fazer a cópia.

**Observação**

A coligada não ficará disponível caso o usuário não tenha permissão para acessá-la.

**Substitui registros no destino se eles já existirem -** Marque esta opção quando já existir o registro na coligada de destino e deseja alterar seus dados pelos dados do registro da coligada de origem. Caso contrário o sistema manterá os dados do registro na coligada de destino.

**Concluindo o Assistente de Cópia de Registros entre Coligadas -** Para fazer a cópia de registro entre as coligadas clique no botão 'Concluir'.

**Observações**

- Este processo tem como objetivo Copiar entre coligadas os Itens de Informação Clínica, juntamente com as Faixas e Opções relacionadas.

- Se a Faixa tiver uma consulta SQL associada, a faixa só será copiada se na coligada destino já possuir a consulta SQL.
