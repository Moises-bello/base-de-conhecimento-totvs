# DADOS PESSOAIS DO ALUNO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Matrícula online no ensino básico. |
| **Situação/Requisito:** | Permitir a visualização e edição dos dados pessoais do aluno, durante a execução do processo de matrícula online no contexto de Ensino Básico. |
| **Solução/Implementação:** | A visualização e edição dos dados está condicionada a parametrização do sistema. A parametrização define se a etapa será visualizada no processo e o modo de alteração dos dados pessoais. Sendo que será possível selecionar se a alteração do dado será enviada para a instituição de ensino para avaliação, antes da atualização dos dados ou permitir a alteração diretamente na base de dados. |
| **Conversores e Parâmetros:** | Habilitar a visão de dados cadastrais na matrícula online: RM Portal >> RM Portal - Matrícula >> Permitir alteração de dados cadastrais durante a matrícula.  Configurar modo de alteração dos dados pessoais: RM Portal >> RM Portal - Gerais >> Alteração de dados cadastrais/profissionais do aluno. |
