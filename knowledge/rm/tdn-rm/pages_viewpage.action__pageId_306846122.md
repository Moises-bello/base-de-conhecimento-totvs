# Incluir um boleto de filial diferente do default de dados pagamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Inclusão de lançamento. |
| **Situação/Requisito:** | Ao realizar a inclusão de um boleto na filial 1 que o responsável financeiro (Cliente/Fornecedor) possui default bancário na filial 2, o sistema carrega o default débito automático incorretamente. |
| **Solução/Implementação:** | Agora o sistema valida corretamente a filial que está cadastrada o default de dados bancários do cliente/fornecedor. |
| **Requisito:** | FIN000268 |
