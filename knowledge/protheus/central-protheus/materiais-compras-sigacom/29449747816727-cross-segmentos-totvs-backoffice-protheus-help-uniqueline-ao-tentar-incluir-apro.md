Help UNIQUELINE ao tentar incluir aprovador no Grupo de aprovação.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29449763645079)

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus compras - Todas as versões  
  
**Causa**  
Esse incidente ocorre, pois , está tentando incluir um código de aprovador que já existe no Grupo de Aprovação.

Conforme exemplo print abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29449763646487)  
  
**Solução**  
Para solucionar essa ocorrência:

-Acesse a rotina de Cadastro de aprovadores (MATA095) e inclua o aprovador com outro código, segue exemplo abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29449747789847)

-Dessa forma será permitido incluir o mesmo usuário (com novo código de aprovador) no Grupo de aprovação conforme print abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29449747792407)
