**Processos - Cadastro de Abono**   
Através dos processos do Cadastro de Abono é possível controlar:

**Cópia de abono entre coligadas**  
Este assistente irá auxiliá-lo na cópia de registro(s) entre as coligadas do sistema. Para utilizar o assistente clique no botão Avançar.  
Parâmetros da cópia Na janela de Parâmetros da cópia o sistema lista todas as coligadas disponíveis na base de dados para se fazer à cópia de registro. Selecione a coligada ou as coligadas que deseja fazer a cópia e clique no botão Avançar.  
Observação Caso o abono a ser copiado tenha evento relacionado, a coligada destino deve ter este evento cadastrado no cadastro de evento. Caso não tenha o abono não será copiado.  
Substitui registros no destino se eles já existirem Marque esta opção quando já existir o abono na coligada de destino e deseja alterar seus dados pelos dados do abono da coligada de origem. Caso contrário o sistema manterá os dados do abono na coligada de destino.  
Concluindo o Assistente de Cópia de Registros entre Coligadas Para fazer a cópia de abono entre as coligadas clique no botão 'Concluir'.
