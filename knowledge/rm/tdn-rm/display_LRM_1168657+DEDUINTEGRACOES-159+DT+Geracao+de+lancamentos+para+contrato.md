# GERAÇÃO DE LANÇAMENTOS PARA O CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Geração de lançamentos para o contrato |
| **Situação/Requisito:** | No processo de geração de lançamentos (Finaceiro/Contábil | Financeiro) quando algum dos alunos selecionados no processo possui uma contrato cancelado, o processo finaliza com o status de erro informando que os lançamentos para esse contrato não foram gerados porque ele estava cancelado. |
| **Solução/Implementação:** | O processo de geração de lançamentos considerará apenas os contratos não cancelados na execução. |
