# COMPARATIVO SEFIP X FOLHA ANALÍTICA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Comparativo Sefip X Folha Analítica |
| **Situação/Requisito:** | Ao gerar o comparativo Sefip X Folha Analítica é apresentado diferença de valores, quando o SEFIP é gerado com a opção "Sefip para 13° salario" marcada. |
| **Solução/Implementação:** | Criado o parâmetro "Folha Analítica para 13° salario" no processe de geração da Folha Analítica. Dessa forma ao gerar o comparativo Sefip X Folha Analítica os valores devem estar corretos quando o SEFIP for gerado com a opção "Sefip para 13° salario" marcada e a opção "Folha Analítica para 13° salario" marcada na Folha Analítica. |
