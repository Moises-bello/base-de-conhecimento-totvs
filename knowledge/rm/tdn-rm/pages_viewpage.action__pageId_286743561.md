# Introdução:

---

A propriedade Ligação de Dados define de onde virão os dados que serão impressos no Texto Rico.

# Passo a passo:

---

A propriedade possui 4 opções de ligação e que devem ser utilizadas somente uma de cada vez. Se utilizarmos html e texto, por exemplo, a de texto irá sobrepor a de html.

**HTML:** Recebe como entrada um campo que contenha tags HTML.

**Identificação:**

**RTF:** Texto no modo RTF.

**Texto:** Texto simples.

# Observações:

---

Após selecionar um campo para ser a ligação de dados, é necessário informar entre colchetes o nome do campo que precisa ser mostrado no componente Texto Rico.
