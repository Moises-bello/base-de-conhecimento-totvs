Nesta opção o sistema permite parametrizar as seguintes opções:

* **Utiliza módulo de venda:** Marque esta opção caso queira utilizar o módulos de vendas de imóveis do TCGI. Desmarque esta opção caso queira-se utilizar o TCGI apenas para gerir os alugueis
* **Venda sequencial:** Se ativado, o sistema irá gerar o número da venda sequencialmente, caso contrário, o usuário deverá informar um número de venda manualmente.
* **Usar data do sistema para a data da venda:** Se marcado, ao criar uma venda, a sua data será preenchida automaticamente pela data do sistema, podendo ser alterada no momento deste cadastro.
