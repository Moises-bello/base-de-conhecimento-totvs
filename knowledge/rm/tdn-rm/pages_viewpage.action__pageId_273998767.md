# ANÁLISE CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Análise Curricular |
| **Situação/Requisito:** | Na análise curricular do aluno, o sistema não estava mostrando corretamente nas informações de TCC uma disciplina por equivalência recíproca em que foi reprovada no período letivo anterior, mas cujo status atual é aprovada. |
| **Solução/Implementação:** | Otimização da análise curricular do aluno, para permitir demonstrar nas informações de TCC disciplinas concluídas por equivalência recíproca. Por exemplo, a disciplina “A” é equivalente recíproca à disciplina “B”, onde “A” foi reprovada no período letivo anterior, mas a disciplina “B” foi aprovada no período letivo atual. |
