# Delete

Remove um registro no dataserver. Esse método pode ser acionado através de uma requisição do tipo DELETE.. Após a alteração o método retornará uma mensagem confirmando a operação ou mostrando os erros ocorridos.

## Exemplo de utilização

Método: DELETE

URL: <http://localhost:8051/rmsrestdataserver/rest/GlbDeptoData/1$_$1$_$99>
