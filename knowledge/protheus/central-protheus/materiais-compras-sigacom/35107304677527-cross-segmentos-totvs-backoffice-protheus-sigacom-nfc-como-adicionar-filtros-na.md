**Dúvida**

Como adicionar filtros na tela do Novo Fluxo de Compras?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS COMPRAS - Versão 12

**Solução**

Não há funcionalidade padrão para salvar filtro na abertura da tela na rotina, para adicionar novos filtros utilize os pontos de entradas:

**Ponto de entrada**: NFCFILTSC

**Objetivo**: Este ponto de entrada é utilizado na necessidade de compra para filtrar SCs de acordo com os filtros estabelecidos.

**Documentação**: [Clique Aqui - Documentação NFCFILTSC](https://tdn.totvs.com.br/pages/viewpage.action?pageId=951342471)

**Ponto de entrada**: NFCFILFOR

**Objetivo**: Este ponto de entrada é utilizado para escolher fornecedores conforme os   
filtros previamente definidos. Os fornecedores filtrados serão exibidos na aba **“Meus Fornecedores”**.

**Documentação**: [Clique Aqui - Documentação NFCFILFOR](https://tdn.totvs.com.br/display/PROT/NFCFILFOR+-+Filtrar+meus+fornecedores+NFC)
