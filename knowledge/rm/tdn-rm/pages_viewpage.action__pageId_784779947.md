Nesta seção serão apresentadas todas os empréstimos processadas para usuário.

### Renovação de empréstimos

Na visão de movimentações, os exemplares que estão com status "Emprestado" poderão ser renovados respeitando as regras de renovação da publicação e tipo de usuário.

|  |  |
| --- | --- |
|  | Indica que o empréstimo corrente pode ser renovado. Caso este item não seja exibido pode ser necessário conceder permissão ao perfil do usuário.  [Perfil da biblioteca → 13 Gestão Bibliotecária (Portal) → 13.02 Biblioteca (Novo Portal do Aluno) → 13.02.02 Movimentações → 13.02.02.02 Empréstimos → 13.02.02.02.01 Renovar Empréstimo] |
|  | Este ícone será exibido caso o empréstimo esteja em atraso, indicando que não é possível renovar empréstimos em atraso. |

### Pesquisar empréstimos

Na tela de empréstimos será possível filtrar os empréstimos de acordo com os campos disponíveis.

Observação: o campo "**Informe o texto a ser pesquisado**" é utilizado pelo campo "**Pesquisa por**", as opções disponíveis deste campo são as mesmas da pesquisa ao acervo que podem ser verificados no link .
