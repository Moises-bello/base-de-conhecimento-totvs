## **01. VISÃO GERAL**

Essa funcionalidade tem a finalidade de cadastrar as unidades de internação existentes no hospital. É possível incluir, editar ou excluir o cadastro. Os códigos das unidades clínicas não são editáveis, são gerados automaticamente ao incluir uma nova unidade clínica.

## **03. TELA INICIAL**

**Outras Ações / Ações relacionadas**

| Ação | Descrição |
| --- | --- |
| Procedimento para inclusão | 1. Selecione o filtro desejado ou clique em fechar para prosseguir. 2. Será exibida a tela com todas as Unidades Clínicas já cadastradas. 3. Clique em **Incluir** (Ctrl + Insert). 4. Será exibida a tela Cadastro de Unidade Clínica. 5. Estarão disponíveis para preenchimento os campos:  * + Unidade Clínica: Preencher o **Nome** da unidade.   + Taxa Geral: Essa propriedade só possui dois valores possíveis, sendo um deles a letra "C" e o valor nulo. A única Unidade que possui a Taxa Geral com a letra C é o Berçário.   + A: Unidades clínicas de internação nível I (unidades não críticas).   + B: Unidades de terapia intensiva (áreas críticas).   + C: Unidades externas e berçário de nível I, unidades de hemodiálise, hemodinâmica etc.   + Nº de leitos: Nesse campo é informado o número de leitos total da unidade.   + No quadro **Código do Cliente**: O campo código do cliente é usado para viabilizar a importação de dados de outros sistemas.   + No quadro **Código do Leito**, preencha com a numeração dada a cada leito, e informe se esse será virtual clicando na *flag*, na coluna virtual.         7. Clique em **Salvar**       8. Clique em **OK**, para retornar para tela anterior. |
