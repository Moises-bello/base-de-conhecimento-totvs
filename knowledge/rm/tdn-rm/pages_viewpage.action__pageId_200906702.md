# GERADOR DE RELATÓRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Relatórios* |
| **Função:** | *Gerador de Relatórios* |
| **Situação/Requisito:** | *Ao gerar usuário para Professor, Aluno e Coordenador não é possível vincular perfil do módulo Serviços Globais. Tanto professor, aluno e coordenador precisa ter acesso a algumas*  *permissões do módulo Serviços Globais e no antigo RM Portal (Delphi) para que possam emitir relatórios pelo Portal Educacional.* |
| **Solução/Implementação:** | *Criado menu de permissões Gerador de Relatórios dentro do módulo Educacional para configuração de permissão para visualização de relatórios pelo Portal.*          *Para gerar e visualizar relatórios do gerador antigo o usuário precisa ter permissão nos itens: Gerador de Relatórios, Emitir relatórios e Visualizar relatório (Gerador Antigo);*    *Para gerar e visualizar relatórios do RM Reports o usuário precisa ter permissão nos itens: Gerador de Relatórios e Emitir relatórios.* |
