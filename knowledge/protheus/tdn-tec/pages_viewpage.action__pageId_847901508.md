O motor de processamento de chamadas para impressão foi mudado no MacOS para garantir um bom funcionamento.

|  |  |
| --- | --- |
| Situação | Impressões em MacOS demoram para retornar o funcionamento do sistema ou falham de forma inesperada. |
| Ocorrência | O motor para chamada de processos do sistema operacional está tendo um funcionamento errático. |
| Correção | Mudado o motor de chamada de processos do sistema operacional, garantindo um funcionamento correto. |
| Informações adicionais | * Referente à ocorrência: DTCLIENT01-4459 * Disponível em builds superiores a 20.3.2.8 |
