# ESTÁGIO - PORTAL - RELATÓRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Estágio - Portal - Relatórios* |
| **Situação/Requisito:** | *Pelo portal do aluno, na tela de Estágio, é possível que o aluno realize a impressão do termo de compromisso. Para isso, o relatório de termo de compromisso deve estar associado no menu de parâmetros dentro do RM. Caso não esteja associado, o aluno não deverá conseguir emitir nenhum relatório. O sistema está retornando indevidamente um relatório padrão de contrato (parece interno do sistema).* |
| **Solução/Implementação:** | *Ajuste na geração de relatórios (termo de encaminhamento e termo de compromisso) para que caso não seja parametrizado não exiba nenhum relatório.* |
