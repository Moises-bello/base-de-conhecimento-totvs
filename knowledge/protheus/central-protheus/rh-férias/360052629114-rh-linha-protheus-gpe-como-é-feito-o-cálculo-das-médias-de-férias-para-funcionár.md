**Dúvida**Como é feito o cálculo das Médias de Férias para funcionário que possui Programação de Rateio?

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões

**Solução**  
A Programação de Rateio **não interfere** no cálculo das médias de férias.

O Sistema busca no **Acumulado do Funcionário (SRD)** as verbas que constam com **incidência** para cálculo de **Médias** (campo **Referência** **a Férias** na aba **Médias** da verba como **S** ou **SP),** trazendo todos os valores para cálculo independente de ter sido rateada ou não.
