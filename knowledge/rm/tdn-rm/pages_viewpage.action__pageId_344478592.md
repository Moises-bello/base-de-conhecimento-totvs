# Relatório Diário

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Relatório |
| **Situação/Requisito:** | O relatório Diário deve exibir o total de débitos e créditos a transportar e transportados, para o dia e mês, conforme ocorria na plataforma Delphi. |
| **Solução/Implementação:** | O Diário foi alterado para que, ao gerar o relatório em mais de um arquivo ou imprimir em formato livro, a totalização diária ou mensal seja transportada.  Ex1: Se o relatório for gerado em dois arquivos a última página do primeiro arquivo irá exibir o saldo a transportar e a primeira página do segundo arquivo exibirá o saldo transportado.  Ex2: Se o relatório for impresso em livro a última página do primeiro livro irá exibir o saldo a transportar e a primeira página do segundo livro exibirá o saldo transportado. |
