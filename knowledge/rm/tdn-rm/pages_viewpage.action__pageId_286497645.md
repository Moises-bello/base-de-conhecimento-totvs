# Ajuste no Formulário de Regra de Plantão

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Saúde. |
| **Módulo:** | TOTVS Gestão de Saúde. |
| **Função:** | Regra de Plantão |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar no menu Cadastro/Faturamento/Regra de Plantão, não havia validação do campo Período Inicio e Fim, períodos de relação restrita com o horário, o que acarretava em mensagem de exceção no formulário Faturamento/Repasses/Apuração de Plantões Realizados em processos Apuração de Plantão Realizado. |
| **Solução:** | Foram realizados ajustes no formulário para que identifique formatos de horário não suportados pelo sistema. |
