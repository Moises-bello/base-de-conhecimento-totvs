# GERAÇÃO DE LANÇAMENTOS FINANCEIROS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Geração de lançamentos financeiros |
| **Situação/Requisito:** | Ao gerar lançamentos financeiros para contratos que não possuem curso, como ocorre quando o aluno está matriculado em disciplinas isoladas, quando o sistema está parametrizado para buscar a conta caixa das parametrizações por curso, o sistema não consegue gerar os lançamentos, pois o sistema não consegue atribuir uma conta caixa válida. |
| **Solução/Implementação:** | Foi realizada otimização do processo de geração de lançamentos financeiros, permitindo ao sistema, utilizar a conta caixa default para as parcelas de contrato que não tem curso, como ocorre no caso de matrículas em disciplina isoladas, quando o sistema estiver parametrizado para buscar a conta caixa das parametrizações do curso. |
