Esta janela permite ao usuário associar uma pessoa à atividade ofertada.

É possível inscrever na atividade ofertada qualquer pessoa cadastrada na base de dados mesmo não sendo aluno ou professor.

**Associar Pessoa:**  
 O usuário deve localizar e selecionar uma pessoas cadastrada na base de dados

Ainda na tela de associar pessoa o usuário pode determinar se a pessoa associada esta com a inscrição confirmada e se cumpriu a atividade ofertada.
