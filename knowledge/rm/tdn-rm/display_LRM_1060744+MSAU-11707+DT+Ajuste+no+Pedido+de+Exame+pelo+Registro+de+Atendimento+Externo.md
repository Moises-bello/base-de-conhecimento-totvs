# Ajuste no Pedido de Exame pelo Registro de Atendimento Externo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao realizar uma solicitação de exame com valor de filme pelo registro de atendimento externo, o sistema não somava o valor do filme ao valor do exame, na elaboração de contas. |
| **Solução:** | Realizado ajuste para que o sistema some o valor do filme ao valor do exame na elaboração de contas, ao solicitar um exame pelo registro de atendimento externo. |
