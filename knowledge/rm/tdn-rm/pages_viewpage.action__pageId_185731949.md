| **Subprocesso:** *Transferir dados para tabela de   produção* |

A Transferência de dados para tabela de produção tem como finalidade disponibilizar os dados referente ao tratamento de ponto de períodos anteriores para consulta, alteração  e geração de relatórios de acordo com a necessidade do usuário nas tabelas oficiais.

## Executando o processo

1. Para executar o processo acesse **RH | Totvs Automação de ponto|Configurações| Períodos.**
2. Selecionar o período desejado (obrigatório estar em arquivo morto)  e acessar o **menu Processos | Transferir dados para tabela de produção.**
3. Será exibido um assistente para realizar o processo. Nesta tela está disponível a opção de seleção de funcionários possibilitando **realizar o processo parcialmente** visando otimizar o tempo de execução do processo.

* **Transferir registros para a tabela de produção de todos os funcionários:** Caso desejar transferir todos os dados para a tabela de produção para as tabelas oficiais basta marcar o este parâmetro.

**Observação:** Caso o parâmetro “**Transferir registros para tabela de produção de todos os funcionários**” seja selecionado, o filtro realizado na **seleção de funcionário** será desprezado, e o processo irá realizar a transferência de todos registros referente ao período selecionado para a tabela de produção sem restrição de funcionários.

* **Grupo de funcionários:** Dentro deste grupo de opções é possível realizar a seleção de código de quebra e também seleção de funcionários e assim realizar uma transferência parcial.
* **Perfil de Parâmetros:** É possível gravar perfis de parâmetros na tela para facilitar as próximas transferências.

      4.  Após parametrizar a tela conforme os critérios desejados basta clicar em **Executar.**

## Visualizando o período do funcionário

1. É possível conferir os funcionários que foram transferidos para tabela de produção . Para isso acesse **RH | Totvs Automação de ponto|Configurações| Períodos.** Selecione o período que deseja verificar e acesse **Anexos| Período do funcionário.**
