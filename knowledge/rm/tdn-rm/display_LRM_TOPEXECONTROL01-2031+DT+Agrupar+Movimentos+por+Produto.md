# AGRUPAR MOVIMENTOS POR PRODUTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Enviar pedido para suprimentos / faturamento |
| **Situação/Requisito:** | O parâmetro de agrupar movimentos não fica visível em tela, o que dificulta a identificação pelo suporte. |
| **Solução/Implementação:** | No processo de enviar pedido para suprimentos / faturamento o sistema passa a exibir as informações dos parâmetros usados para agrupar produtos. Sendo exibidos somente quando desmarcados.  Parâmetro "Agrupar itens de movimento por produto":    Parâmetros de aglutinação (Somente Backoffice PROTHEUS): |
| **Conversores e Parâmetros:** | Agrupar itens de movimento por produto: MPARAMETRO.AGRUPARITENSMOVIMENTOPORPRODUTO.  Gerar solicitação de armazém aglutinada: HCPARAMETROS.PRJ\_AGLUTINAITENSSA.  Gerar solicitação de compras aglutinada: HCPARAMETROS.PRJ\_AGLUTINAITENSSC. |
