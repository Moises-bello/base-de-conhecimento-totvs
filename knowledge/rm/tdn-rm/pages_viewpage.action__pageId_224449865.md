# Egressos poderem fazer inscrição em vagas de emprego

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *TOTVS Educacional* |
| **Módulo:** | **Estágio/Emprego*.* |
| **Rotina:** | |  |  | | --- | --- | | **Rotina(s) envolvida(s)** | **Nome Técnico** | | Acompanhamento Estágio/Emprego (Portal) | Acompanhamento Estágio/Emprego (Portal) | |
| **Requisito (ISSUE):** | *PCREQ-9513* |
| **País(es):** | *Brasil* |

## Descrição

O objetivo dessa implementação é permitir que alunos egressos possam fazer inscrição em vagas de emprego disponíveis para seu curso/habilitação concluído, através do módulo de emprego/estágio do RM Portal.

## Procedimento para Utilização

**Para ser considerado egresso o aluno precisa ter a opção "Indica conclusão do curso" marcada, na aba "Status no curso" da "Situação de matrícula" do seu curso/habilitação.**

Foi feito ajuste para permitir que o aluno egresso consiga realizar inscrição em vagas de emprego que tenham seu "curso/habilitação" como público alvo dessa vaga.

O botão de "Inscrever" passa a aparecer ao lado das vagas de emprego listadas para que o aluno egresso possa efetuar sua inscrição.
