**Dúvida**Como incluir uma carta de crédito no Importação?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – Easy Import Control – Todas as versões.  
  
**Solução**Esta rotina permite cadastrar as **Cartas de Créditos** emitidas para o Fornecedor em garantia do pagamento do Importador.  
Esta transação armazena os dados da **Carta de Crédito** que deve ser vinculada ao processo de embarque. Este tratamento permite o controle de saldos à medida que estas cartas de crédito são associadas aos pedidos de importação.  
  
**Pré-Requisitos:**

• Possuir um *Purchase Order* cadastrado.  
  
**Exemplo** - Como cadastrar uma Carta de Crédito  
1. No *Easy Import Control* (SIGAEIC), acesse Atualizações\ Financeiro\ **Carta de Credito**.  
2. Clique na opção Incluir e informe os seguintes dados:  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360056360594)

3. Em Outras Ações clique em Incluir.  
4. Selecione o PO desejado e clique em Confirmar.  
5. Clique em Confirmar para salvar a **Carta de Crédito**.

**Importante:** Os saldos disponíveis podem ser consultados através do campo Saldo Carta, disponíveis na carta de crédito. O Saldo Carta é abatido toda vez que um Purchase Order é vinculado a L/C.
