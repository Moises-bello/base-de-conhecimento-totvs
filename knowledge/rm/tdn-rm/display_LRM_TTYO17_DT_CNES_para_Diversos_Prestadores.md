## Descrição

Ajuste realizado para permitir o cadastro de vários prestadores com o mesmo código do estabelecimento (CNES).

## Procedimento para Utilização

1. Acesse **Cadastros / Uso Geral / Prestador**.
2. Selecione um prestador.
3. Informe um **CNES** já existente e salve.
4. O sistema permitirá que esta alteração seja gravada.
