![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/25186502328727) Tempo aproximado para leitura: **00:01:30 min** **Dúvida**Como conferir valor FGTS mês rescisão ID 0119 em rescisão tipo aviso indenizado?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.2210  
  
**Solução**Devido ajuste junto ao e-social, em cálculo de rescisão no ID 0293 (Base FGTS mês rescisão) só serão considerados os valores de  salário salário e adicionais (hora extra por exemplo) e no ID 1887 (Base FGTS Aviso), os valores de aviso prévio indenizado. Porém para o calculo de FGTS 8% mês rescisão ID 0119 o calculo será pelo valor base FGTS ID 0293 mais valores aviso prévio indenizado (menos os valores de 13 por aviso que são considerados no cálculo FGTS 13 ID 0214).

**Exemplo:**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25186486585111)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25186502329751)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/25186502330135)

**Saldo salário: 1.500,00 Base FGTS ID 0293 verba 888**

**Aviso prévio indenizado 3.000.00 Base FGTS Aviso ID 1887 verba YO2**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/25186502331031)**

**1.500,00 + 3.000.00 = 4.500,00 \* 8% = 360,00 ID 0119 verba 726**
