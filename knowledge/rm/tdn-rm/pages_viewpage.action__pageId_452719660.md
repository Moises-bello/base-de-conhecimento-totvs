**Pasta Identificação - Requisição de Treinamento**

Na pasta Identificação os seguintes dados devem ser informados:

**Número -** Gerado automaticamente e com valor único.

**Status -** Será apresentado logo após a abertura da requisição como "Pendente". Este campo será alterado à medida que a requisição for avançando no fluxo de aprovações assumindo os valores parametrizados e definidos para cada etapa.

Para verificar a parametrização acesse: Configurações | Tipos de Requisições. Os status que poderão ser definidos pelo fluxo de aprovação são "Em Andamento", "Aprovado" e "Reprovado". Os status "Suspenso" e "Cancelado" serão definidos conforme a utilização do processo "Suspender requisição " e "Cancelar Requisição" respectivamente.

O status "Concluído" será determinado quando o usuário acessar Processos | Concluir Requisição.

**Os status das requisições são representados pelas cores:**

Aprovada – cor verde

Cancelada – cor preta

Concluída – cor roxa

Em Andamento – cor amarela

Pendente – cor laranja

Reprovada – cor vermelha

Suspensa – cor azul

**Aprovador Atual -** Este campo não é editável e apresentará o nome do aprovador atual da requisição, ou seja, o responsável atual pela requisição, conforme definição do fluxo de aprovações.

**Data de conclusão -** Irá apresentar a data em que a requisição foi concluída.

**Requisitante -** O Gestor de RH pode definir como requisitante qualquer funcionário de qualquer coligada. Caso a requisição seja aberta pelo Totvs RM Portal o requisitante será o usuário logado.

**Justificativa -** Ao solicitar um treinamento deverá ser informada uma justificativa para tal solicitação. Este campo poderá ser alterado enquanto a requisição estiver pendente ou se nenhum parecer tiver sido cadastrado.

**Curso -** Deverá ser informado o Curso do qual será realizado o treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Entidade -** Deverá ser informada a Entidade que ministrará o Curso escolhido para o treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Previsão -** Deverá ser informada a data prevista para início do treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Data prevista final -** Deverá ser informada a data prevista para final do treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Hora início -** Deverá ser informada a hora prevista para o início do treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Hora fim -** Deverá ser informada a hora prevista para o fim do treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.

**Carga horária -** Deverá ser informada a carga horária prevista para o treinamento. Este campo poderá ser alterado enquanto a requisição estiver pendente ou em andamento, e caso a requisição esteja pendente, apenas se nenhum parecer tiver sido cadastrado.
