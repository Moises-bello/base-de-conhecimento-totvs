**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19409332677527) Tempo aproximado para leitura: 00:01:00 min** **Dúvida**Para que serve e como realizar cadastro de funções no modulo arquitetura organizacional  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Arquitetura Organizacional – Todas as versões  
  
**Solução**Função é usualmente conceituada como um conjunto de **ações ou tarefas de natureza e níveis semelhantes**, executadas por uma ou mais pessoas qualificadas ou com formação específica para tal.   
  
A função está diretamente ligada à natureza do trabalho e ao processo exigido para a produção de um bem ou de um serviço.  
  
Esta rotina permite efetuar o **cadastro/manutenção de todas as funções exercidas pelos colaboradores de uma empresa**. O sistema possibilita ainda que sejam **relacionados os cursos necessários para cada função**.   
  
Desta forma, ao gerar uma Necessidade de Treinamento, o sistema **verifica os cursos necessários tanto para o cargo quanto para a função de um colaborador.**

Para realizar um cadastro de funções é necessário seguir os seguintes passos:  
1-Acessar o modulo 70- Arquitetura organizacional  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19409338016663)  
  
2-Acessar o seguinte caminho **Atualizações > Cadastro > Funções**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19409305679767)  
  
3- Realizar a inclusão de uma função   
![](https://centraldeatendimento.totvs.com/hc/article_attachments/19409349392407)  
  
4- Preencher de acordo com a sua necessidade
