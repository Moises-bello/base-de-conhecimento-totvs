# 1. Sobre

Esta documentação explica o comportamento do TOTVS Inteligência Tributária na aplicação de filtros.

# 2. Comportamento e utilização dos filtros

Por padrão, o painel será aberto filtrando as operações da Coligada do contexto, selecionando todas as suas filiais e o período de 13 meses.

Para alterar o filtro, utilize as opções:

| Ação | Descrição |
| --- | --- |
| 1 - Coligada | O campo permite que o usuário filtre as informações que serão apresentadas em cada uma das tabs pelas coligadas, sendo este um campo de multiseleção. |
| 2 - Filial | O campo permite que o usuário filtre as informações que serão apresentadas em cada uma das tabs pelas coligadas, sendo este um campo de multiseleção. |
| 3 - Período | O campo permite que o usuário filtre as informações que serão apresentadas em cada uma das tabs dentro de um período, sendo este dois campos de data. O primeiro representando a data inicial e o segundo a data final. |
| 4 - Aplicar Filtro | O botão aplica os filtros selecionados nas tabs, sendo que só é possível filtrar as informações quando todos os campos estiverem preenchidos. |
| 5 - Limpar Filtro | O botão limpa os campos dos filtros preenchidos possibilitando o usuário refazer a sua seleção. |

Após filtrar os dados será exibido na marcação de filtros ativos com o total de **coligadas**, **filiais** e o **período** selecionado.

Caso quando os dados filtrados seja de um período cujo processamentos dos dados identificou períodos inconsistentes e/ou abertos será exibido um alerta ao lado do informativo do período, como mostra na imagem abaixo:
