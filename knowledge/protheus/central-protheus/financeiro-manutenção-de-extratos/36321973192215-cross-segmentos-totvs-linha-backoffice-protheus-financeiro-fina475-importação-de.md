**Ocorrência**  
Com a descontinuação da API do Protheus para a Totvs Techfin, poderia confirmar se a importação de extrato via API para conciliação automática será feita pela Totvs Techfin ou continuará da mesma forma?  
  
**Ambiente**  
Cross Segmentos - TOTVS Linha Backoffice Protheus - Financeiro - A partir da release 12.1.2310

**Causa**  
Com a descontinuação da comunicação bancária online via API do módulo Contas a Receber no Protheus prevista para 31/03/2026, o processo de importação de extratos bancários continuará disponível.

**Importante**

A descontinuidade deste processo **não afeta a importação feita pela rotina FINA475** — o extrato via API seguirá disponível.  
A descontinuação vale apenas para a API de cobranças, que será transferida para a plataforma TECHFIN.
