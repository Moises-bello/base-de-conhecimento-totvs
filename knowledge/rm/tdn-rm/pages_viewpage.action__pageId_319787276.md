Utilize esta opção para que o gerador faça a ordenação dos dados do registro em memória, antes da geração do arquivo final.

![](/download/attachments/319787276/ordenacao.png?version=1&modificationDate=1512921849000&api=v2)

1Campo

Selecione os campos para fazer a ordenação do registro.

2Ordenação

Selecione a forma com que os valores do campo serão ordenados que pode ser Crescente ou Decrescente.

3Remover

Clique para remover o campo da lista de ordenação.

Atenção

Somente utilize esta opção caso não seja possível definir a ordenação diretamente no contexto, pois desta forma todos os registros precisam ser carregados na memória para fazer a ordenação o que pode ocasionar problemas caso a quantidade de dados do arquivo seja muito grande.
