# VISUALIZAR NOME DE CAMPOS NO CADASTRO DE PERIODO AQUISITIVO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Férias* |
| **Situação/Requisito:** | *Quando é acionado o recurso para visualizar o nome dos campos no cadastro de periodo aquisitivo de férias, no campo "Saldo do período(vencido)" aparece a descrição "PFUFERIAS.SALDOPERIODO".*  *Este campo não existe na base, é criado durante a execução, portanto deveria aparecer a informação de "Campo calculado pelo sistema".* |
| **Solução/Implementação:** | *Ajuste no cadastro de periodo aquisitivo de férias, quando é acionado o recurso para visualizar o nome dos campos, para informar "Campo calculado pelo sistema" no campo "Saldo do período(vencido)".* |
