![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/32754988310167) Tempo aproximado para leitura: **00:04:00 min** **Dúvida**Existe algum processo de alçada de Aprovação de Pedido de compras via Workflow?

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Protheus Compras - Todas as versões

**Solução**

As opções dispnivel de aprovação de açada de pedido de forma remota (não diretamente pelo Protheus) são as que seguem abaixo:

**Opção 1 - App Meu Protheus**

Temos hoje disponível para uso no sistema , o processo de aprovação de pedidos com interação de usuário que é por meio do aplicativo **Meu Protheus**. Após a aprovação realizada no app, o sistema Protheus será automaticamente atualizado com a aprovação.

Caso tenha interesse em utilizar o **Meu Protheus**, disponibilizamos o link para a documentação com mais detalhes: [Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Guia de Uso App Meu Protheus](https://centraldeatendimento.totvs.com/hc/pt-br/articles/7404666750359-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Guia-de-Uso-App-Meu-Protheus)

**Opção 2 - Customização de Workflow**

A equipe Protheus ADVPL disponibiliza uma documentação para uso de Workflow (Workflow Protheus BI), que pode ser consultada para verificar se atende às suas necessidades, segue links abaixo:

[MP - BI - Como configurar um Workflow via Link](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020999472-MP-BI-Como-configurar-um-Workflow-via-Link)

[Cross Segmento - TOTVS Backoffice Linha Protheus - BI - Como configurar para uso o Workflow via Configurador](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4446748107159-Cross-Segmento-TOTVS-Backoffice-Linha-Protheus-BI-Como-configurar-para-uso-o-Workflow-via-Configurador)

Nesse Workflow o padrão do workflow envia um emial para o aprovador, com link para uma tela HTML para aprovação que processa e executa o retorno das informações.

Caso ocorra algum erro no disparo, retorno ou se o link não abrir, o problema pode estar relacionado ao caminho configurado ou à parametrização do processo conforme orientações nos artigos acima.

**Ob1:**

Caso tenha dúvidas ou ocorrência no processo acima de Workflow (Protheus BI), pode ser verificado junto ao suporte "Protheus ADVPL".

**Ob2:**

Havia anteriormente um processo em uso de Workflow compras x Fluig , porém ele foi descontinuado. Para mais informações, consulte a documentação:  
[Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Como utilizar os Workflows Fluig x Protheus que foram descontinuados](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4411812507671-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGACOM-Como-utilizar-os-Workflows-Fluig-x-Protheus-que-foram-descontinuados)

Caso tenha alguma dúvida entre em contato com um de nosso Canais de atendimento para abertura de um ticket.
