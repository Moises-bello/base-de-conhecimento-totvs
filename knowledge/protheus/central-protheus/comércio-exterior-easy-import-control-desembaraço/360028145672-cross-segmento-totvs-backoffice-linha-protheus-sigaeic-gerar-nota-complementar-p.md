Dúvida**É possível gerar Nota Complementar para processo com nota única?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão 11.80  
  
**Solução**Sim, para gerar nota complementar para processos com nota única gerada, o parâmetro MV\_AVG0160 deve estar desligado (MV\_AVG0160 = .F.).
