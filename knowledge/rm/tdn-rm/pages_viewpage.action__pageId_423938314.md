Nesse processo definem-se algumas informações de estoque dos produtos selecionados para as filiais cadastradas: Estocável, Consignado, Prioridade Próprio, Prioridade de Terceiros.

Através desse Processo é feito a inclusão ou atualização das informações de filiais para os produtos selecionados.

As informações que podem ser alteradas são:

**Estocável:** Define se produto é estocável ou não.

**Consignado:** Quando a empresa deixa o produto com um vendedor para que ele seja comercializado.

**Prioridade Próprio:** Caso produto esteja marcado como consignado, é possível define que produto pertence a empresa.

**Prioridade de Terceiros:** Caso produto esteja marcado como consignado, é possível define que produto é terceirizado.

Caso a filial ainda não exista no produto, este serviço incluir a nova filial.
