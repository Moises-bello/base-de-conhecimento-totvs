# Ajuste no Formulário Controle de Pedido de Exames

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Pedido de Exames |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu: **Unidades de Diagnóstico/Controle de Pedido de Exames**, selecionar um pedido e clicar duas vezes sobre ele, abrir o formulário "Preenchimento de Resultados", ir aba Laudo, alterar os dados registrados e salvar as alterações, era exibida uma mensagem de exceção de acesso ao banco e dados. |
| **Solução:** | Foram realizados ajustes no formulário para que os dados sejam registrados adequadamente. |
