# Exceção ao Processar uma requisição em Movimentação de Estoque

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Movimentação de estoque |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu **Estoque/Movimentação de estoque**, abrir o formulário, criar uma nova movimentação, preencher os dados e clicar no botão "Processa", era exibida a seguinte mensagem: Uma exceção foi acionada pelo destino da chamada. |
| **Solução:** | Ajuste realizado no formulário para que ao processar uma movimentação não seja exibida nenhuma exceção. |
