***![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20477689271575)*** Tempo aproximado para leitura: **00:00:30 min****Dúvida**Para que serve o parâmetro **MV\_AGRO010**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - A partir da versão 12  
  
**Solução**O parâmetro **Tipo de movimentação Venda Futura - MV\_AGRO010** é do tipo *caractere* e é utilizado para que seja gerada uma **Movimentação para o Romaneio Global de Venda Futura**. É necessário cadastrar o **Tipo de Movimentação - OGA441** informado no parâmetro, conforme a informação cadastrada no campo **Tipo Movimento - NKL\_TIPOMV**. No caso de não possuir informação cadastrada no parâmetro será considerado **.F. = Falso.**
