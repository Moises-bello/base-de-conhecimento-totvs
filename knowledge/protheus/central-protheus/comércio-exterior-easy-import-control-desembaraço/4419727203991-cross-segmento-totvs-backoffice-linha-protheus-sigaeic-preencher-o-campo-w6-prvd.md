**Dúvida**Como configurar o sistema para preencher o campo W6\_PRVDESE manualmente?  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões.  
  
**Solução**

Para que o campo W6\_PRVDESE não seja preenchido automaticamente.  
1. Acesse o módulo SIGACFG em Base de Dados, selecione Dicionário / Base de dados.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360025329791/mceclip0.png)

2. Selecione Dicionário de Dados

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360025309112/mceclip2.png)

3. Selecione a lupa

![](https://centraldeatendimento.totvs.com/hc/article_attachments/360025330191/mceclip3.png)

4. Selecione Procurar Por e informe a tabela SW6, após selecione Buscar. 

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4419718946839/mceclip0.png)

5. Posicione no campo W6\_CALCAUT e selecione a folha com o lápis.

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4419718983831/mceclip1.png)

6. Na aba Opções altere o Inic. Padrão para "2" e Salvar.

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4419711832343/mceclip2.png)
