![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/29553859989399) Tempo aproximado para leitura: **00****:03:00 min** **Dúvida**Qual permissão liberar para exportar relatório em Excel?  
  
**Ambiente**Cross Segmentos - Backoffice Linha Protheus - SIGAFIN - Todas as versões  
  
**Solução**Quando ocorrer a mensagem do print a seguir:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/29553859990039)

Neste caso, o usuário não possui permissão para realizar a impressão em planilha. Recomenda-se a liberação de alguns acessos no usuário que apresenta essa mensagem, a fim de permitir que a ação seja concluída com sucesso.

Para solucionar essa ocorrência, realize os seguintes passos:

1. Acesse via Configurador Usuário -> Senhas -> Grupos -> Alterar. Em restrições de acesso / Acessos selecionar os "acessos"  -> 110, 111, 112 e 160.
