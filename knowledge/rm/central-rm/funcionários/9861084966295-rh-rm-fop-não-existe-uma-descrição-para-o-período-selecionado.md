![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min****Dúvida**O que fazer para que o aviso **Não existe uma descrição para o período selecionado!** não seja apresentado ao acessar o envelope de pagamento ? 

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9860767358871)  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

1. Acesse **Administração de Pessoal | Cadastros Globais | Tabelas dinâmicas:**  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9860806410903)  
  
2. Selecione em sistemas: **Folha de Pagamento** e em código digite PDESCPER:  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9860877570967)  
  
3. Acesse a tabela e na aba **Item de** **tabela Dinâmica**, insira a descrição do período:  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9860926168215)  
  
4. Caso deseje não cadastrar, ou que o sistema não mostre a descrição acesse, **Configurações | Parametrizador | Configuração de Competência**, e desmarque a opção **Exibir descrição de períodos**.  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9861027950615)
