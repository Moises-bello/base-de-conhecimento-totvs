![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15869290020631) Tempo aproximado para leitura: **00:00:45 min** **Dúvida**Como realizar o reajuste de tabela salarial?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - Todas as versões  
  
**Solução**O processo **Reajustar Tabela Salarial** é utilizado para reajustar os valores das tabelas salariais selecionadas de acordo com o percentual informado e com o intervalo de valores que se deseja alterar, dando a opção de arredondamento, podendo escolher qual expoente será arredondado e os modos de arredondamento. 

Para realizar o processo, acesse o menu **Valorização** | **Tabelas Salariais** e selecione a tabela desejada e acesse a opção **Processos** | **Reajustar tabela Salarial:**

**![](https://centraldeatendimento.totvs.com/hc/article_attachments/27005479771287)**Ao abrir o assistente clique em avançar e na tela de reajuste, defina os parâmetros desejados:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27005449184279)  
  
Abaixo há o detalhamento de como utilizar o recurso Arredondamento.  
  
**Descrição dos campos**  
**· *Percentual:***  
Neste campo é informado o percentual de reajuste para os valores dos níveis das tabelas selecionadas. É permitido o preenchimento apenas de números positivos.  
  
**· I*ntervalo – Valor Inicial e Valor Final:***  
 Os campos *Valor Inicial* e *Valor Final* definem o intervalo de valores que receberão o reajuste. Atente-se de que os valores do campo estão inclusos no reajuste e de que o campo *Valor* *Inicial* deve ser maior que o Valor Final.  
  
**· *Arredondamento – Menor Expoente e Modo***  
 O campo *Menor* *Expoente* é utilizado para definir qual casa decimal será arredondada. Os valores permitidos são aqueles a partir de **-2**.  
O campo *Modo* é para definir como será o arredondamento, se o mesmo será para o Próximo Valor, Valor Anterio*r*, ou se *Padrão*, que é quando se a casa decimal for igual ou maior à metade da potência de 10, será arredondado para o próximo valor, senão, para o anterior.  
  
 **Importante**  
 - Para apenas arredondar a tabela salarial, deixe o campo *Percentual* com 0.  
 - Para apenas reajustar sem arredondar, deixe o campo *Menor* *Expoente* com -2.
