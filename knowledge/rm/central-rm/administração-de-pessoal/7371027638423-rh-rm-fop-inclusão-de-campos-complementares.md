![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:55 min****Dúvida**Como incluir Campos Complementares ?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as Versões  
  
**Solução**É possível acrescentar novos campos para as abas **Campos Complementares** nos cadastros de Funcionários, Dependentes, Cliente/Fornecedor e Seções, para complemento do cadastro com os dados que desejar  
  
1. Acesse **Administração de Pessoal | Campos Complementares | Escolha o cadastro onde deseja incluir novos campos.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9524979338903)**

2.  Clique em **Incluir**, apresentará a seguinte tela:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9525022589079)

**Nome da Coluna e Descrição**: São informações obrigatórias que identificarão o campo;

**Tipo do Campo**: Define o formato do campo de acordo com com a informação que deseja que seja adicionada, cada tipo de campo fornece também um subtipo de campo. Exemplo: Campo para informação de data, ao selecionar este campo apresentará o formato da data e a máscara utilizada para a apresentação;

**Configurações Gerais do Campo**: Possibilita incluir limites de caracteres, valor default, ordem de apresentação e se poderá ter quebra de linhas;

**Configurações do Campo Utilizando Fórmula**: Campo utilizado para validação dos dados inseridos, retornará valores de 1 para positivo e 0 para negativo;

**Configurações do Campo Utilizando Tabelas Dinâmicas**: Utilizado em casos onde a informação que será inserida já é definida e apresenta um lista com opções. Exemplo: Tipo sanguíneo (apresentado como na imagem abaixo no cadastro de funcionários). 

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/9525122221335)
