**Dúvida**É possível utilizar a classe TFtpClient em host compartilhado?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Não, pois o host que classe aguarda é o endereço do servidor FTP que receberá a conexão, após esse acesso é direcionado para diretório remoto de destino através dos métodos.
