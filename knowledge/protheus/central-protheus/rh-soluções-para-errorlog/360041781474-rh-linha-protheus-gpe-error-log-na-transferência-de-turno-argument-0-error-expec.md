**Ocorrência**Ao realizar uma **Transferência de Turno**, através da rotina **PONA160**, é gerado *error log*: "***argument*** **#0 *error, expected* N->C*, function dbgoto on* GDPUTINFODATA(RHLIBGD.PRX)**"**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Causa**Este erro ocorre ao uso do fonte **PONA160** anterior à **18/12/2019**  
  
**Solução** **1.** Para solucionar essa ocorrência, necessário aplicação do pacote de expedição contínua de RH, conforme abaixo:  
Pacote de Expedição Contínua do Gestão de Pessoal: <https://centraldeatendimento.totvs.com/hc/pt-br/articles/360057829854>
