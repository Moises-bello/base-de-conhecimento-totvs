# Ocorrência

Precisamos realizar a migração do servidor de licenças (License Server), mas ao criamos a nova máquina de licença, o programa de licenças requisitou uma nova instalação.

# Solução

É necessário uma nova instalação do  para que seja gerado um novo TOTVS ID (identificação única dos ambientes instalados).

Você consegue realizar a gestão das licenças através do monitor e transferir para outro ambiente, para realizar essa configuração acesse o [Guia Gestão de Licenças](http://tdn.totvs.com/pages/viewpage.action?pageId=184779108).

Qualquer dúvida relacionada a licenças ou valores, ligue: (11) 4003 0015 - Opção 4.
