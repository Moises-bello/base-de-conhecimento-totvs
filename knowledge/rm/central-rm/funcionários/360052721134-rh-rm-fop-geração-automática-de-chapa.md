**Dúvida**  
Como parametrizar para que o sistema gere uma chapa para um novo registro de funcionário de forma automática?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**  
Para solucionar este caso, execute os passos abaixo:  
  
1. Acesse **Configurações | Parametrizador | Funcionário**;  
  
2. Na Etapa 1 - Configurações da chapa, marque a flag **Cadastro automático de chapas sequenciais**
