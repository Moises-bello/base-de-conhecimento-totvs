A aba **Movimentação de Estoque** é composta pelos campos abaixo:

**Movimentação de Estoque:**

Este campo quando habilitado utiliza movimentação de estoque.

**Tipo de movimento de transferência:**

Define tipo de movimento que será utilizado para transferência.

**Locais de estoque disponíveis:**

Locais disponíveis para serem utilizados.

**Locais de estoque selecionados:**

Locais selecionados para armazenamento.
