Para agilizar e facilitar o cadastro, um centro de custo já cadastrado em uma coligada poderá ser copiado para outra coligada. Selecione os centros de custos desejados e execute o processo, marcando para quais coligadas deseja efetuar a cópia.

**Observações**

* As máscaras entre as coligadas de origem e de destino devem, obrigatoriamente, ser iguais para que a cópia seja efetuada.
* No processo de cópia, o sistema consistirá se na coligada destino já existe algum centro de custo com mesmo código do que está sendo copiado. Se já existir, a cópia não será efetuada. Se desejar, marque a opção '*Substituir registros no destino se eles já existirem*' para que o sistema substitua os dados do centro de custo de origem no destino.
