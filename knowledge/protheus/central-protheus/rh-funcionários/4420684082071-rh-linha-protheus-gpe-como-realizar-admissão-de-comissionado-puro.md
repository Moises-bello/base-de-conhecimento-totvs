**Dúvida**Como realizar admissão de comissionado puro?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Acesse o caminho **Atualizações > Funcionários >** **Funcionário**.

Principais Campos:

* Matricula (**RA\_MAT**): código da matrícula
* Nome (**RA\_NOME**): informe o nome completo do funcionário.
* Data Nasc. (**RA\_NASC**): informe a data de nascimento. Este campo é importante para vários controles do sistema como convênio médico, férias, aposentadoria, etc.
* Centro de Custos (**RA\_CC**) - Como o próprio nome indica, o Centro de Custo possibilita a apuração de custos. Esta informação no Cadastro de Funcionários permite uma série de controles que serão efetuados em outras rotinas, entre eles:
* Sindicato (**RA\_SINDICA**): O cadastro do **sindicato** é onde contém o valor da **garantia de comissão**
* Data Admis. (**RA\_ADMISSA**) – Informe a data de admissão do funcionário, esta data será considerada para criação do período aquisitivo, cálculo de férias, 13º. Salário, rescisão contratual, etc.
* Cód.Função (**RA\_CODFUN**) - Selecione o código da função, o sistema preenche automaticamente o salário e o **CBO**, além de buscar o cargo do funcionário em algumas rotinas.
* Salário (**RA\_SALARIO**) – Para **comissionado puro, o campo deve ficar zerado**.
* Categoria (**RA\_CATFUNC**): Informe a categoria **C (comissionado)**
