**Dúvida**  
Como consulto as APIs padrões disponíveis para uso.  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Contabilidade Gerencial - Todas as versões

**Solução**

##### **Consulta às APIs Padrões da TOTVS:**

Para verificar as **APIs padrões disponíveis para uso em integrações**, acesse o endereço:

[**https://api.totvs.com.br/**](https://api.totvs.com.br/)

Essas APIs são disponibilizadas pela TOTVS como **padrão de integração**, porém **podem não atender completamente às necessidades específicas de cada cliente**.

Caso nenhuma das APIs padrão atenda ao requisito do projeto, será necessário **desenvolver uma integração própria** utilizando o **serviço** ***REST*** **do Protheus**.

##### **Requisitos para Desenvolvimento**

Para construir integrações personalizadas no Protheus, é necessário:

* Conhecimento em **AdvPL**
* Capacidade de trabalhar com ***Web Services REST*** **no Protheus**
