# Pré-requisitos

---

2
complete
Linha RM versão 12.1.5 e posteriores

# Descrição

---

Essa classe representa as informações da janela específica da planilha.

# Membros da classe

---

## Propriedades

|  |  |
| --- | --- |
| DisplayGridlines | Define se as linhas de grade serão exibidas. |
| DisplayHeadings | Define se os cabeçalhos das linhas e colunas serão exibidos. |
| FreezePanes | Define se os painéis da janela serão congelados. |
| SplitColumns | Define o número de colunas que serão exibidas à esquerda da divisão. |
| SplitRows | Define o número de linhas que serão exibidas à acima da divisão. |

## Métodos

|  |  |
| --- | --- |
|  | Converte a posição de uma coluna (decimal iniciado em zero) para pontos (1/72 de polegada). |
|  | Converte a posição de uma linha (decimal iniciado em zero) para pontos (1/72 de polegada). |
