# Permissões por perfil de usuário no contrato

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *BackOffice* |
| **Módulo:** | *Totvs Gestão de Estoques, Compras e Faturamento* |
| **Rotina:** | CtrCntAction |
| **Tickets relacionados** | -- |
| **País(es):** | *BRA* |
| **Banco(s) de Dados:** | *SQL SERVER e ORACLE* |
| **Tabelas Utilizadas:** |  |
| **Sistema(s) Operacional(is):** | *Windows* |

## Descrição

Foram disponibilizadas permissões por perfil de usuário para processos de contrato.

## Procedimento para Implantação

Acesse o cadastro de perfis de usuários no módulo de serviços globais, edite o perfil desejado e identifique o cadastro de contratos na aba "Acesso a Menus". Note que agora é possível definir o acesso ao menu dos seguintes processos:

* Inclusão de Contabilidade
* Reclassificação Contábil
* Exclusão de Contabilidade
* Estorno de Contabilidade
* Solicitação de Exclusão de Toda Operação Contábil
* Liberar Contabilidade do Item de Contrato
* Reajuste de Preços
* Desfazer Reajuste de Preços

## Procedimento para Utilização

Os processos estarão disponíveis no cadastro de contratos de acordo com as permissões configuradas previamente.
