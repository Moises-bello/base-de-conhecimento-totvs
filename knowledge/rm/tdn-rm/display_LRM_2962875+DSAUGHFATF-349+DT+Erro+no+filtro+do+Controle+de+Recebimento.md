# Erro no filtro do Controle de Recebimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Recebimento |
| **Situação/Requisito:** | O Controle de Recebimento não estava considerando a unidade de faturamento da remessa (quando havia mais de uma remessa para o mesmo convênio e com a mesma numeração porém para unidades de faturamento diferentes, os valores eram agrupados). |
| **Solução/Implementação:** | Ajustado para distinguir as remessas também pela unidade de faturamento. |
| **Documento de Referência:** | Ticket #2962875 |
