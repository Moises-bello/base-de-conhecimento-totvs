**Dúvida**Como enviar boleto via e-mail?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - FINA150- Todas as versões  
  
**Solução**Tratamento para envio de boleto via email para o sacado, no Cnab modelo 1 (Detalhe tipo 5)

Para tal tratamento deve ser criado o campo A1\_BLEMAIL (Char/1) que definirá:

"1" - Envia Boleto Via Email ao Sacado  
"2" - Não envia Boleto Via Email ao Sacado

Deve ser feita a configuração do "Detalhe Tp 5" no configurador.

Obs- No cadastro do cliente deve haver o e-mail cadastrado.
