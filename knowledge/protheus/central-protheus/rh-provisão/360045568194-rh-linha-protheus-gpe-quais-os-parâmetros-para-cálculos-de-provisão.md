**Dúvida**Quais são parâmetros que impactam nos cálculos de Provisão?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.  
  
**Solução**

**MV\_MEDDIRE** - Parâmetro que determina a regra de divisão das Médias.

Para mais informações [Clique aqui](https://tdn.totvs.com/pages/releaseview.action?pageId=224112471)

**MV\_TPBXFER** - Indica se a baixa das Férias será Total ou Parcial.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024752653-RH-Linha-Protheus-GPE-Ferias-partidas-na-provis%C3%A3o-par%C3%A2metro-MV-TPBXFER)

**MV\_CSALINC** - Diminuir o tempo de processamento do cálculo e permitir cálculo retroativo de provisão com base no salário da época.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/11899851782423-RH-Linha-Protheus-GPE-Conceito-do-Par%C3%A2metro-MV-CSALINC)

**MV\_MAPREND** - Configuração para Cálculos de Jovem Aprendiz Horista.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360034214354-RH-Linha-Protheus-GPE-Como-configura%C3%A7%C3%A3o-calculo-Menor-Aprendiz-Horista)

**MV\_GRID -** Configuração de GRID (Performance).

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4402890654999-RH-Linha-Protheus-GPE-Como-configurar-o-GRID-para-c%C3%A1lculos-do-GPE)

**MV\_GPEGRID** - Parâmetro que possibilita habilitar a execução GRID para uma ou mais rotinas.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360028757611-RH-Linha-Protheus-GPE-Par%C3%A2metro-MV-GPEGRID)

**MV\_DF13NEG** - Define se calcula diferença negativa de 13º salário no complemento.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360019474072-RH-Linha-Protheus-GPE-Ao-calcular-a-folha-de-pagamento-de-dezembro-Sistema-gera-diferen%C3%A7a-negativa-13%C2%BA-par%C3%A2metro-MV-DF13NEG)

**MV\_ITMCLVL** - Parâmetro para habilitar os campos Item Contábil e Classe de Valores no cadastro de Funcionários.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360020271991-RH-Linha-Protheus-GPE-Par%C3%A2metro-MV-ITMCLVL-para-configura%C3%A7%C3%A3o-de-Item-e-Classe-de-Valor)

**MV\_PROVRES** - Possibilita ao usuário a opção de escolha entre apurar ou não o provisionamento de Férias e Décimo Terceiro Salário no mês de demissão do funcionário.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360007260472-RH-Linha-Protheus-GPE-C%C3%A1lculo-de-Provis%C3%A3o-no-m%C3%AAs-de-Desligamento#:~:text=O%20par%C3%A2metro%20MV_PROVRES%20possibilita%20ao,m%C3%AAs%20de%20demiss%C3%A3o%20do%20empregado.&text=Como%20n%C3%A3o%20est%C3%A1%20sendo%20provisionado,valor%20provisionado%20no%20m%C3%AAs%20anterior.)

**MV\_PERCFGC** - Percentual do FGTS Referente a Contribuição Social nas Provisões.

Para mais informações [Clique aqui](https://tdn.totvs.com/pages/releaseview.action?pageId=6082468)

**MV\_TRFAMES** - Indica como serão demonstradas as transferências na provisão.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360025027553-RH-Linha-Protheus-GPE-Como-Conferir-os-Relat%C3%B3rios-de-Provis%C3%A3o-com-Transfer%C3%AAncia)

**MV\_RATPROV** - Parâmetro para Cálculos de Provisões com Rateio.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360018658931-RH-Linha-Protheus-GPE-Como-realizar-a-programa%C3%A7%C3%A3o-de-rateio)

**MV\_DESFOL**- Parâmetro impacta nos cálculos de provisão e rescisão, deve ser preenchido com o primeiro mês referente ao cálculo da desoneração.

Para mais informações [Clique aqui](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360053888253-RH-Linha-Protheus-GPE-Como-parametrizar-a-desonera%C3%A7%C3%A3o-pura)
