## **Conceito**

10%90%

O **Prazo de Entrega do Desenvolvimento** consiste no acordo realizado entre a área de Desenvolvimento e o Cliente, comunicando-o sobre a data de entrega da sua solicitação.

## **Detalhamento**

A área de Desenvolvimento deve planejar a **Data Acordo de Entrega** de todos os itens (obrigatório: manutenção, legislação, rejeição - manutenção, ponto de entrada e participativo; opcional: *Story*) que entrarem no próximo *Sprint* de Desenvolvimento.A **Data Acordo de Entrega** deve ser preenchida antes de iniciar o desenvolvimento do item.

O Cliente pode solicitar a **priorização** de algum item pendente, caso este ainda não tenha sido planejado.

A área de Desenvolvimento deve informar a **Data Acordo de Entrega** para o Cliente conforme planejamento da sua expedição, caso seja realizada uma Liberação Emergencial, a Data Acordo de Entrega deve ser preenchida com essa informação. Caso a entrega seja planejada para o próximo release, a Data Acordo de Entrega deve ser preenchida de acordo com o **[Calendário Corporativo](http://tdn.totvs.com/pages/viewpage.action?pageId=270897139)**.

O **Cliente** receberá uma mensagem com a **data de solução,** informado por meio do *ticket*.

Caso a área de Desenvolvimento necessite **replanejar o item**, poderá alterar a Data Acordo de Entrega e o Cliente será comunicado com o novo prazo. Atentar-se a este item, quando houver mudança na data de expedição do pacote (**[Calendário Corporativo](http://tdn.totvs.com/pages/viewpage.action?pageId=270897139)**), onde haverá necessidade de informá-lo da nova data.

**Importante**

* O cálculo do SLA será mantido na ferramenta Zendesk e encaminhado para a ferramenta JIRA para que as Equipes consultem essa informação no planejamento. Não há necessidade de definir a Data Acordo de Entrega dentro do prazo do SLA do *Ticket*.
* A informação do SLA não será mais encaminhada para o Cliente, somente a informação preenchida na Data Acordo de Entrega.
* Caso a área de Desenvolvimento não concorde com a solicitação de priorização do Cliente, deverá entrar em contato com a área de Atendimento para que realize este alinhamento.
