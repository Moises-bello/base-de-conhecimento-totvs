Como solucionar o erro "Help: AVG0000813", Nota Fiscal não pode ser gerada. Processo não possui Invoices?

![](https://centraldeatendimento.totvs.com/hc/article_attachments/21971703757335)  
  
**Ambiente** Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - A partir da versão P12.1.33.

**Solução**

A mensagem “**Help: AVG0000813**” é exibida quando não é possível localizar a fatura (**Invoice**) no processo. Certifique-se de que a fatura tenha sido incluída corretamente no processo de desembaraço.
