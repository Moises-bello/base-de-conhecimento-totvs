**Ocorrência**No módulo **Gestão de Pessoal**, ao tentar realizar o cálculo do **vale transporte** é apresentado o *error log*, ***argument #0 error, expected N->U, function SPACE on FCARMVTO*****Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de pessoal – A partir da versão 12.1.17  
  
**Causa**   
Erro ocorre devido a variável estar esperando um valor numérico e estar recebendo um valor nulo.  
  
**Solução**  
Para solucionar a ocorrência, realizar atualização com pacote do link abaixo:  
Pacote acumulado RH: <https://suporte.totvs.com/portal/p/10098/download#000006>
