# Copia de Patrimônio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Totvs Gestão Patrimonial |
| **Função:** | Cadastro de Patrimônio |
| **Situação/Requisito:** | Cliente entrou em contato informando que editou um patrimônio oriundo de integração com o Nucleus, clicou com o botão direito, selecionou a opção Copiar, selecionou todos os campos, solicitou a inclusão de um novo patrimônio, colou todos os campos e salvou o cadastro. Ao tentar realizar a exclusão do novo patrimônio é enviada uma mensagem informando que os patrimônios vinculados na mesma nota serão excluídos. Ao verificar a visão de patrimônios o patrimônio copiado estava com um ícone de ocorrência, que veio do patrimônio de origem, mas o novo patrimônio não possui ocorrências. |
| **Solução/Implementação:** | Os campos Tipo Ocorrência e Identificador da Nota não serão copiados através da opção copiar, que é apresentada quando o usuário clica com o botão direito em cima do patrimônio desejado. |
