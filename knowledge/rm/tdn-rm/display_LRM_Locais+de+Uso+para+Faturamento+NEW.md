## **01. VISÃO GERAL**

No cadastro de locais de uso, será necessária a definição dos Centros de Custo default para lançamento para cada um dos locais de uso cadastrados. Dessa forma, teremos de alterar os parâmetros gerais de forma a eliminar o Grupo de parâmetros marcados logo abaixo e que define os centros de custo default apenas para os locais Centro Cirúrgico / UTI.
