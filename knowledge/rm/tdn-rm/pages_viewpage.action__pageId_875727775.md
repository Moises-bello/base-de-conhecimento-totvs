# **01.****Visão Geral**

O processo de Cópia de Escrituração Contábil é uma funcionalidade projetada para simplificar o registro de novas escriturações. O objetivo é permitir que o usuário copie informações de uma escrituração existente, alterando apenas os dados necessários, economizando tempo e esforço.

# **02.****Execução do Processo**

**2.1. Seleção de Escriturações**

O usuário pode selecionar uma ou várias Escriturações Contábeis na tela de Cadastro. A quantidade selecionada determinará quantas novas Escriturações serão criadas.

**2.2. Abertura do Processo**

Após a seleção, o usuário inicia o processo de Cópia de Escrituração Contábil, que exibirá uma tela com três campos obrigatórios para preenchimento:

* Data Inicial: Data de início do período a ser copiado.
* Data Final: Data de término do período a ser copiado.
* Data de Arquivamento Constitutivo: Data correspondente ao arquivamento dos atos constitutivos.

Essas datas serão comuns a todas as novas escriturações contábeis geradas a partir do processo.

**2.3 Geração Automática de Número de Documento**

O sistema possui uma funcionalidade inteligente que, ao identificar o Código da Coligada e o Tipo de Escrituração selecionado, busca automaticamente o último Número de Documento registrado e incrementa esse valor. Essa lógica garante que o número do documento seja sequencial, facilitando o envio da ECD. O usuário terá a opção de alterar esse número após a conclusão do processo, se desejado.

Observação

Se as datas inicial e final forem diferentes do período de escrituração, das escriturações selecionadas, todas as informações da Demonstração Contábil serão apagadas. Neste caso, após a execução do processo, o usuário deverá acessar as Escriturações e informar as demonstrações desejadas.
