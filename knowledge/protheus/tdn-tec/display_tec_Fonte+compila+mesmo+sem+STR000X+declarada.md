Fonte compila mesmo sem STR declarada

|  |  |
| --- | --- |
| Situação | Fonte compila mesmo sem STR000X declarada |
| Ocorrência | A compilação era feita com sucesso mesmo que haja a utilização de uma STR000X que não tivesse sido declarada |
| Correção | Acusa erro de compilação devido a STR000X não estar declarada |
| Informações adicionais | * Referente ao chamado: SSIM-1084 * Referente à ocorrência: não há ocorrência associada * Disponível em builds superiores a 7.00.131227A - 2.0.3 |
