**Para se encerrar um contrato de aluguel, antes é preciso realizar o preenchimento de uma lista de verificação.**

Os itens que compõe a lista são:

* Chaves foram entregues;
* Quantas chaves foram entregues;
* Controles remotos foram entregues;
* Quantos controles remotos foram entregues;
* Não possui conta de água em aberto;
* Registro de água foi desligado / cortado;
* Não possui conta de luz em aberto;
* Não possui condomínio em aberto;
* Foi realizada a vistoria;
* Campos para observação em geral.

**Observação**: Após o preenchimento das informações será necessário marcar uma flag informando que a lista de verificação está concluída. Uma vez este campo marcado o processo de encerramento do contrato passa a ser permitido para execução.
