# **Coluna/Linha Total Geral**

|  |  |
| --- | --- |
| **Produto:** | RM Reports |
| **Versão:** | 12.1.X |
| **Ocorrência:** | Componente Matrix no RM Reports |
| **Ambiente:** | Biblioteca RM |
| **Passo a Passo:** | Objetivo  ---   Esse documento ilustra a visualização da coluna ou linha Total Geral no componente matriz. Comportamento  ---   Quando trabalhamos com matrizes, é possível visualizar colunas ou linhas de total geral dependendo de como os campos estão disponíveis na matriz.  Foi verificado que em algumas das configurações de campos essa coluna/linha Total Geral sempre fica visível impossibilitando a sua remoção.  Um exemplo simples é quando todos os campos estão disponíveis como linhas é criada uma coluna Total Geral    Outro exemplo é quando todos os campos estão como coluna é criado uma linha Total Geral.    Por se tratar de uma ferramenta de terceiros notificamos esse comportamento através do link <https://www.devexpress.com/Support/Center/Question/Details/T684643/how-to-hide-grand-total-column-or-row>, porém trata-se do comportamento normal do componente. Portanto, sugerimos alterar a disposição dos campos dentro da matriz para trazer a melhor visualização possível dos dados. |
