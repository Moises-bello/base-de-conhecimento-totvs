Nesta tela são mostrada as mensagens que já foram lidas e/ou não lidas.

Ao acessar as mensagens o usuário tem a opção de ler e, se necessário, marcá-la como não lida para que um futuro usuário possa visualizar esta mensagem.  
A configuração da mensagem pode ser customizada pelo cliente e neste mesmo sentido é possível estruturá-la com modificações no título e texto que compõem o corpo da mensagem. Neste texto, podemos inserir os parâmetros pré-estabelecidos para identificação do paciente e do atendimento relacionado; estes dados são recuperados do banco de dados no processo de envio.
