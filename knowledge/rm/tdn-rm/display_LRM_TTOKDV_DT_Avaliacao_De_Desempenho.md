# AVALIAÇÃO DE DESEMPENHO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão de Pessoas* |
| **Função:** | *Avaliação de Desempenho* |
| **Situação/Requisito:** | *Na versão atual o sistema está impedindo que se informe data de abertura da avaliação de desempenho maior que a data atual. Esta funcionalidade permitia liberar a avaliação em uma data futura impedindo que funcionários pudessem acessá-la antes que estivesse completamente parametrizada.* |
| **Solução/Implementação:** | *Ajuste no cadastro de Avaliações de Desempenho. O cadastro e a configuração permitem que a AD seja cadastrada com data de abertura posterior à data atual, mas as ADs só serão exibidas no portal a partir do dia de abertura.* |
