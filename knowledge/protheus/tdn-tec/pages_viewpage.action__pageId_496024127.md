Correção - TGrid causa encerramento do SmartClient na navegação entre linhas

|  |  |
| --- | --- |
| Situação | Durante a navegação entre as linhas utilizando o teclado com tecla CTRL pressionada em um componente TGrid populado, o SmartClient é encerrado repentinamente. |
| Ocorrência | Ocorre quando são utilizadas as teclas CTRL + Home/End/PageUp/PageDown/ArrowUp/ArrowDown para navegação dos registros. |
| Correção | Foi aplicada uma correção no componente TGrid. |
| Informações adicionais | * Referente ao chamado: PP-682 * Referente à ocorrência: ITEC-422 * Disponível em builds iguais ou superiores a 7.00.170117A - 17.3.0.8 |
