# CADASTRO LOTAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Lotação* |
| **Situação/Requisito:** | *Sistema não está permitindo a exclusão de uma nova Lotação cadastrada em Orçamento ao tentar excluir o sistema apresenta seguinte mensagem: Não é possível excluir a lotação pois existem funcionários associados a mesma!, ao excluir os funcionários o sistema apresenta mesma mensagem e não salva as alterações.* |
| **Solução/Implementação:** | *Efetuada a adequação para exclusão de lotação sem orçamento e funcionários vinculados. Processo a ser realizado para efetuar a exclusão corretamente:*   * *Efetuar a exclusão de todos os filtros vinculados a Lotação.* * *Efetuar a exclusão da Lotação*   *No caso de não existir orçamento vinculado a Lotação a exclusão será autorizada.* |
| **Chamados relacionados:** | *TVXLDV* |
