# Geração de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Geração de Lançamento |
| **Situação/Requisito:** | Ao executar o processo de geração de lançamento em lote (vários lançamentos simultâneos), o cálculo por crédito de um determinado lançamento estava apresentando uma não conformidade, e se executasse a geração de lançamento individualmente o cálculo ficava correto. |
| **Solução/Implementação:** | Identificamos que o cenário ocorria somente para alunos que estavam matriculados em disciplinas equivalentes a disciplinas da grade, que esta mesma disciplina tinha valores diferente entre as matrizes aplicadas. |
