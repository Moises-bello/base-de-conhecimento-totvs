# EMISSÃO DE CHEQUES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | *Emissão de Cheque* |
| **Situação/Requisito:** | Durante a emissão de cheque para mais de um lançamento é selecionado a opção 'Um cheque para cada Lançamento' e 'Informar dados somente uma vez'. Na próxima etapa é informado o número do cheque acrescentando um 0 a esquerda, por exemplo 041574, porém o sistema respeita essa definição somente para o primeiro lançamento, de modo que o número do cheque dos demais lançamentos não possuem 0 a esquerda, exemplo: 41575. |
| **Solução/Implementação:** | Otimizado preenchimento do campo número do cheque no processo de emissão de cheque. |

| **Chamados relacionados:** | *N/A* |
