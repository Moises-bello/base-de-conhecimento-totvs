**Dúvida**Como criar novos códigos Homolognet para impressão no TRCT?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Ponto Eletrônico - Todas as versões  
  
**Solução**1. Entre como Alterar na Tabela S020 na rotina Manutenção Tabelas >Atualizações >Definições de Cálculo >Manutenção Tabelas;  
  
2. Posicione na ultima linha para incluir o novo código, conforme exemplo abaixo, mas de acordo com a sua necessidade:
