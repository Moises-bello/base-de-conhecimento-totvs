# Escrituração - NF-e Complementar não leva a NF-e referenciada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Totvs Gestão Fiscal |
| **Função:** | Escrituração |
| **Situação/Requisito:** | Ao escriturar movimento de complemento de ICMS criado utilizando cópia por referência, o lançamento referenciado não foi escriturado para o RM Liber. |
| **Solução/Implementação:** | Ajuste para que o sistema possa escriturar os documentos referenciados quando se tratar de uma NF-e complementar. |
