# MATRIZ CURRICULAR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Controle de Vagas na Matriz Curricular* |
| **Situação/Requisito:** | *O campo "controle de vagas" passou a ser obrigatório, podem ainda podem existir registros que não tem esta informação(Registros criados antes da obrigatoriedade).  Neste registro, caso a matriz se a "Atual", ao alterar e gravar o registro uma série de validações são realizadas e uma destas validações estava gerando uma mensagem de erro informando que o campo não pode ser nulo.* |
| **Solução/Implementação:** | *Ajuste na validação das matrizes curriculares atuais para que seja permitido alterar o Controle de Vagas de matrizes criadas antes da implementação da obrigatoriedade do campo.* |
