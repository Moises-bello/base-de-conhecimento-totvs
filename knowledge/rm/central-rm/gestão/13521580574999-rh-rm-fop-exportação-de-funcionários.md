![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:20 min****Dúvida**Como exportar os dados cadastrais de um funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para exportar os dados cadastrais de um funcionário do RM, é necessário a utilização do layout **FOPLAY0039 - Exportação de Funcionários** no processo **Gerador de Saídas** presente no menu **Gestão.**

Para importar o layout para o RM, utilize a ferramenta TOTVS Compartilhamento, que permite o download de estruturas padronizadas para uso no RM, o processo está descrito na documentação abaixo:

**[RH - RM - FOP- Como importar relatórios através do totvs compartilhamento](https://centraldeatendimento.totvs.com/hc/pt-br/articles/7781155867543)**Caso não encontrar o layout desejado, poderá solicitar para o time de suporte e então importa-lo utilizando o processo **Importação de Layouts** no **Gerador de Saídas**., o processo está descrito na documentação abaixo:

**[RH - RM - FOP - Gerador de Saídas: exportação de layout](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4416255197591)**Após importar a estrutura do layout para o RM, selecione-o e em seguida execute o processo **Geração de Saídas**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/13521545407511)

Em seguida será apresentada uma tela para inserir um filtro, onde poderá selecionar uma ou mais chapas de acordo com o filtro aplicado, no exemplo abaixo foi utilizado um filtro para apenas uma chapa.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/13519854690967)

O layout será gerado na pasta Saídas no diretório de instalação do RM **(C:\totvs\CorporeRM\RM.Net\Saidas).**
