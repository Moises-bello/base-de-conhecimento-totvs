# MATRÍCULA EM LISTA DE ESPERA COM CORREQUISITO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matrícula em Lista de Espera com Correquisito* |
| **Situação/Requisito:** | *Não está sendo validado o parâmetro de "Bloquear matrícula em lista de espera para disciplinas com correquisito", pois ao matricular o aluno em uma turma/disciplina que possui correquisito e a mesma não possui vagas, o aluno está sendo matriculado na lista de espera.* |
| **Solução/Implementação:** | *Ajuste na matrícula para que seja validado de forma correta o parâmetro "Bloquear matrícula em lista de espera para disciplinas com correquisito", ou seja, quando estiver matriculando um aluno em uma turma/disciplina que possui correquisito e não possuir vagas a mesma não poderá ser inserida na lista de espera. Além disso, o parâmetro "Bloquear matrícula em lista de espera para disciplinas com correquisito" foi alterado o seu nome para "Bloquear matrícula em lista de espera para disciplinas com correquisito não concluído".* |
