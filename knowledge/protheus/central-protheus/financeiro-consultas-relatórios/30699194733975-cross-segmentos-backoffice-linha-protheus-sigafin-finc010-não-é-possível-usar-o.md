![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/30699194722967) Tempo aproximado para leitura: **00****:02:00 min** **Dúvida**Ao tentar gerar Excel na rotina FINC010 é apresentada a mensagem **Não é possível usar o envio para Excel quando é usada a aplicação desse smartclient HTML**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/30699864768023)  
  
**Ambiente**Cross Segmentos - Backoffice Linha Protheus - SIGAFIN - A partir da release 12.1.2310  
  
  
**Solução**

Para que não ocorra a mensagem em questão, deve ser configurado na engrenagem no inicio do acesso ao sistema o agente local.

Após habilita-lo conforme a seguir a geração do Excel ocorrera sem interrupções.
