# PLANO DE AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Plano de Aula da turma/disciplina* |
| **Situação/Requisito:** | *Ao selecionar mais de uma Turma/Disciplina para gerar Plano de aula, o processo gera plano de aula somente para uma das Turmas/Disciplinas e ignorando todas as demais selecionadas.* |
| **Solução/Implementação:** | *Correção no processo de geração de plano de aula. Após alteração, os planos de aulas serão gerados para todas as turmas/disciplinas selecionadas. As informações sobre a geração e o motivo da não geração do plano de aula será listado no log do processo.* |
