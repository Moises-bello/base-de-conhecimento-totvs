# FREQUÊNCIA DIÁRIA - SUBTURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Frequência Diária* |
| **Situação/Requisito:** | *Considerando o cenário onde são criadas duas subturmas dentro de uma turma disciplina, em cada uma são vinculados seus respectivo horários. Após matricular os alunos nas respectivas suturas, ao tentar lançar frequência pela tela de frequência diária as aulas aparecem invertidas. As aulas da subturmaA aparecem na subturmaB e as aulas da *subturmaB* na *subturmaA*. Os alunos matriculados são exibidos corretamente apenas as aulas que estão invertidas. O parâmetro para utilizar horários independentes esta desmarcado.* |
| **Solução/Implementação:** | *Ajuste na seleção de alunos matriculados na subturma na visão de frequência diária, trazendo apenas os alunos e horários da subturma selecionada..* |
