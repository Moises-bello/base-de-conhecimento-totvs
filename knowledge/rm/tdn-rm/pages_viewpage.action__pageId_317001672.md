# AJUSTES INCIDENTES IOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Funcionalidades iOS |
| **Situação/Requisito:** | Precisamos verificar se os incidentes abaixo estão realmente ocorrendo:   * Quando aparece o push da notificação abrir a mensagem diretamente * Erro ao clicar no sobre o banner (onde consta um link), o APP fecha (bug) * A clicar no QRCode e depois em cancelar, é apresentada a mensagem: Ocorreu um erro ao alterar o contexto, tente novamente. (retirar) * Quando clicamos em "conectar" sem inserir usuário ou senha, o aplicativo apresenta a mensagem: Nenhuma condição de login satisfatória para os parâmetros. * Notificação chegando desformatada. * expandir enquete no IOS. |
| **Solução/Implementação:** | * Ao receber o push de notificação abre a mensagem diretamente * Clique do banner corrigido * Mensagem do QRCode retirada * Permite logar somente quando os dados são preenchidos. * Corrigido formatação da notificação * Corrigido formatação na enquete no IOS. |
