Ao marcar este parâmetro, o sistema irá gravar horários onde ocorrer choque de horário para sala informada com outra turma/disciplina.   
 Este virá habilitado na tela somente se no perfil do usuário, na guia geral, o parâmetro "Permitir superalocação de salas" estiver marcado. Esta parametrização é feita em: Módulo Serviços Gerais > menu Segurança > Perfis > Selecione o sistema o qual quer conceder tal permissão > Selecione o perfil > Anexo Parâmetros Educacionais.
