# CALCULAR PENSÃO COM PERCENTUAL TOTAL DE TODOS OS DEPENDENTES

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Pensão Alimentícia* |
| **Situação/Requisito:** | *O cálculo da Pensão Alimentícia é executado separadamente, pra cada dependente de pensão.*  *Cliente solicita que este cálculo, quando exitir mais de um dependente, seja executado de uma única vez, considerando o percentual total de todos os pensionistas.* |
| **Solução/Implementação:** | *Foi criado um parâmetro no Parametrizador, pasta Folha Normal/Pensão Alimentícia,, para dar a opção de efetuar o cálculo da Pensão Alimentícia de uma única vez, considerando o percentual total de todos os dependentes de pensão.* |
| **Chamados   relacionados:** | *TTSVXM* |
| **Versões/Release:** | *12.1.9* |
