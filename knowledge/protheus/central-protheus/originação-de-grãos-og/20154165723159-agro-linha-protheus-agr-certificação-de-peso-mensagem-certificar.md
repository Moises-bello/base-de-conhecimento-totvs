No módulo **Comercialização (Linha Protheus) - Originação de Grãos (OG)**, ao realizar o processo para fazer a certificação de peso é apresentada a mensagem de **Certificação de Peso - CERTIFICAR**.  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Causa**Esse incidente ocorre, pois é preciso realizar o o processo para cadastrar corretamente o cadastro **IE** no Sistema.  
  
**Solução**  
Para solucionar essa ocorrência, verifique após a **Estufagem**, permite informar o peso do *container*. Para isso, na tela de relacionamento**Instrução de Embarque IE x container**, acessar a **ação relacionada certificar**.

![CERTIFICAR.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20154153756567)  
![CERTIFICAR2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20154153757079)

Somente é permitido certificar se o *container* estiver com **status estufado**. Após a certificação, o *status* do *container* será **certificado** e será registrada a **data da certificação** como sendo a data atual do Sistema. Também é efetuada a atualização do peso de cada fardo vinculado ao *container*.  
  
Será gravado a quantidade de **fardos de containers certificados.**
