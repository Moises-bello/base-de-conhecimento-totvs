Utilize esse anexo para verificar o horário, suas batidas e tipos de jornada no período atual ou no período que desejar. Cada cor representa um comportamento no dia conforme legenda pode ser verificado através da legenda.  
Habilitando o parâmetro 'Jornada por dia' o horário pode ser visualizado da forma antiga. Exemplo:

* Nova forma de visualizar o horário.

  |  |  |  |  |  |  |  |  |  |
  | --- | --- | --- | --- | --- | --- | --- | --- | --- |
  | Data | Índice | Letra | ID | Dia | Entrada1 | Saída1 | Entrada2 | Saída2 |
  | 13/10/2010 | 6 | D | 1 | QUA | 23:50 | +02:00 | +06:30 | +08:10 |
* Forma antiga.

  |  |  |  |  |  |  |  |  |  |
  | --- | --- | --- | --- | --- | --- | --- | --- | --- |
  | Data | Índice | Letra | ID | Dia | Entrada1 | Saída1 | Entrada2 | Saída2 |
  | 13/10/2010 | 6 | D | 1 | QUA | 23:50 |  |  |  |
  | 14/10/2010 | 7 | D | 1 | QUI |  | 02:00 | 06:30 | 08:10 |
