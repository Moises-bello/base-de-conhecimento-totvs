**Dúvida**Porque quando existe mais de uma convocação, sistema duplica verbas?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O sistema calcula a folha do funcionário intermitente de acordo com cada convocação e demonstra separadamente na folha para facilitar a conferência de cada convocação.

**Ex.:** Verifique que no cálculo é apresentado 2 verbas de calculo para cada provento e desconto, pois é gerado calculo para cada convocação lançada.
