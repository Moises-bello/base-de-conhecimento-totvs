# Chefe/Supervisor pode enviar direto para o cadastro de subordinados

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Plataforma RH |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Criação de parâmetro 'Chefe/Supervisor pode enviar direto para o cadastro de subordinados' |
| **Situação/Requisito:** | A parametrização para permitir o envio de férias direto para o cadastro do funcionário funcionava antes quando o grupo de acesso ao portal do subordinado possuía o parâmetro 'Enviar direto para o cadastro de funcionários' marcado, porém chefes/gestores desejavam em alguns casos marcar diretamente as férias dos funcionários, mas isso não era possível. Com o novo parâmetro 'Chefe/Supervisor pode enviar direto para o cadastro de subordinados' gestores poderão marcar as férias para os funcionários. |
| **Solução/Implementação:** | Foi criado em Parametrizador | RM Portal | Grupo de Acesso | Férias, o parâmetro 'Chefe/Supervisor pode enviar direto para o cadastro de subordinados'. Com este novo parâmetro chefes/supervisores poderão enviar as férias diretamente para o cadastro de seus subordinados. |
