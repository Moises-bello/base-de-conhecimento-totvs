**Dúvida**  
Como realizar o cadastro de Perfis no Configurador de Tributos (FISA170)?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAEIC - a partir da versão 12.1.2210.  
  
**Solução**  
  
A configuração do Configurador de Tributos para importação tem como objetivo **receber** os valores de impostos já calculados pelo SIGAEIC. O sistema **não** deve recalcular os tributos, mas sim utilizar os **Operandos de Integração** para capturar os valores pronto.

Passos de Configuração do Perfil de Fornecedor/Cliente.

* **Perfil de  Participante:**
  + Acesse: Perfis → Perfil Participante.
  + Na aba **Participantes**, utilize o **Tipo** `1 - Fornecedor / Cliente` e inclua os fornecedores de importação.
  + ![6a20e6b4-1016-4fc4-beef-daf79fa3f64f.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/37706550094231)

| **Nota - Pode ser cadastrado apenas 1 Fornecedor/Cliente , ou utilizar o facilitador e integrar diversos Fornecedores e Clientes.** |
