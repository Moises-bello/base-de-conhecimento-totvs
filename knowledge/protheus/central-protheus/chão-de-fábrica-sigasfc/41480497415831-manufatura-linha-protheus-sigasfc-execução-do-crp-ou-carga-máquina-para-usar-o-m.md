**Dúvida**  
É necessário executar o **PCPA152** ou o **MATA690** para poder fazer uso do módulo **SIGASFC**?  
  
**Ambiente**  
TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Chão de Fábrica (SIGASFC) - Versão 12  
  
**Solução**  
Não, não há obrigatoriedade de execução do **PCPA152** ou do **MATA690** para utilizar o módulo **SIGASFC**.  
  
**Saiba Mais**  
Para saber mais sobre o que é necessário para fazer uso do módulo de **SIGASFC** acesse o link [Ativar o SFC](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360036166253-Manufatura-Linha-Protheus-SIGASFC-Ativar-o-SFC)  
Já para informações sobre o que ocorre no **SIGASFC** quando o carga máquina é executado, acesse o link [Alocação do carga máquina no modulo SIGASFC](https://centraldeatendimento.totvs.com/hc/pt-br/articles/4402769354519-Manufatura-Linha-Protheus-SIGASFC-Aloca%C3%A7%C3%B5es-do-carga-m%C3%A1quina-no-m%C3%B3dulo-SIGASFC)  
  
**Glossário**  
**PCPA152** - Programação dos recursos da fábrica  
**MATA690 -** Carga máquina  
**SIGASFC** - Chão de Fábrica
