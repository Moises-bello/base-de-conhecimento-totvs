# Validação para não permitir transformar atendimento interno em externo com período maior de 24hs

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Transferência de atendimento interno em externo. |
| **Situação/Requisito:** | O sistema não estava fazendo as consistências de período máximo (24hs) para fazer a transferência de interno para externo. |
| **Solução/Implementação:** | Criada a regra para bloquear a transferência quando período máximo de atendimento externo (24hs) for atingido |
| **Documento de Referência:** | Ticket #386217 |
