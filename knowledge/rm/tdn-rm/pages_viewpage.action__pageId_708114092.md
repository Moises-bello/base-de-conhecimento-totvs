* **Registro 0220:**  
  O registro 0220 não será gerado para produtos onde a situação da mercadoria seja "Material de Uso e Consumo" a partir de 2023. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546008#BLOCO0-0220).

* **Registro 0221:**  
  Inclusão do Novo Registro 0221 (Correlação Entre Códigos De Itens Comercializados) - o mesmo só será gerado a partir de 2023. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546008#BLOCO0-0221).

Informações

A implementação do Registro 0221 está disponível a partir da versão 12.1.2205.

1Bloco C

* **Registro C100:**   
  A partir de 2023, o código de situação de documento 04 (NF-e denegada) e 05 (NF-e Numeração inutilizada) não será mais gerado. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C100).
* **Registro C185:**   
  Se o terceiro caractere do código preenchido no campo “COD\_MOT\_REST\_COMPL” for igual a 0, os campos 12, 13 e 14 devem ser preenchidos e os campos 10, 11 e 15 a 18 não devem ser preenchidos. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C185).
* **Registro C800:**   
  A partir de 2023, o campo 09 (CNPJ\_CPF) do Registro C800 não será mais gerado. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C800).
* **Registro C850 e C890:**   
  A partir de 2023, o campo 08 (COD\_OBS) Será gerado com a Observação do Lançamento Fiscal quando preenchida.

* **Registro C855:**  
  Geração do registro C855 - Observações do Lançamento Fiscal (Código 59) Perfil A. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C855).
* **Registro C857:**  
  Geração do registro C857 - Outras obrigações tributárias, ajustes e informações de valores provenientes de Documento Fiscal. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C857).
* **Registro C895:**  
  Geração do registro C895 - Observações do Lançamento Fiscal (Código 59) Perfil B. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C895).
* **Registro C897:**  
  Geração do registro C897 - Outras obrigações tributárias, ajustes e informações de valores provenientes de  
  documento fiscal.  (Código 59) Perfil B. Para mais detalhes clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=422546009#BLOCOC-C897).
