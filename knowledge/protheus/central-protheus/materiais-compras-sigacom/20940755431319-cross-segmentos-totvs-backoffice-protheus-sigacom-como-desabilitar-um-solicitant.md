**Dúvida**Como desabilitar um Solicitante?  
  
**Ambiente**Protheus – Compras – A partir da versão 12.1.17  
  
**Solução**

Para desabilitar um cadastro de um Solicitante, temos a opção de ativar o campo AI\_MSBLQL (Bloqueado?) para efetuar o bloqueio.

Segue telas demonstrativas:

Tela 1 - Abaixo mostra o acesso pelo configurador, na tabela SAI clicar no ícone "Campos reservados"

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940733171479)

Tela 2 - Ticar a opção "Bloqueio Automático", clique no botão finalizar e salve no Disquete do configurador

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940733172887)

Tela 3 - Tela com o campo já configurado após o processo anterior

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940755410583)

Tela 4 - Abaixo o Grupo de Aprovadores com o campo em funcionamento

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940733174295)

***Importante:***

Caso o campo não apareça na rotina verifique se o nível de campo é o mesmo do usuário logado:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940733175575)

Ou Ajuste o nível do campo no configurador para Nível 1 assim todos usuários terão acesso a visualização do campo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/20940733176983)

***Obs:*** Essa nova configuração do grupo será aplicada para novos registros criados.
