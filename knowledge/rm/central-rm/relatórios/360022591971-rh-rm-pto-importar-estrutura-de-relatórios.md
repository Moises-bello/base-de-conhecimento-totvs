Dúvida**  
Como importar estrutura de relatórios?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto  
  
**Solução**Para realizar a importação de estruturas do relatório, siga os passos abaixo:

1. Acesse o módulo de **Automação de Ponto**, e clique no menu **Gestão |** **RM Reports**.
2. Insira um filtro para o sistema de **Automação de Ponto** ou para o sistema desejado.  
   ![1DiCmqrT7a.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29831875159959)
3. Acesse a opção **Processos** e clique na opção **Importar estrutura de relatório**.
4. A tela de importação realizará a abertura de uma tela de seleção do Windows, para selecionar a estrutura desejada. Selecione a estrutura, caso deseje no campo 'Código do relatório' o renomeie o relatorio e clique em **Executar**.  
   ![RM_eWLxjgZdPF.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/29831921331095)
5. Ao gerar o relatorio, basta selecionar o relatorio importado.   
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/29831921332759)
