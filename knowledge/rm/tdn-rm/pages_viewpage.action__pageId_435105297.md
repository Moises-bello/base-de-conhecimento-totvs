**Reserva de Áreas Comuns**    
Este cadastro é um anexo de Áreas Comuns e é usado para cadastrar reservas para as áreas existentes no condomínio.  
  
**Figura 1 - Tela de cadastro da reserva**  
**Cód. Reserva:** Código identificador da reserva.  
**Situação:** Situação da Reserva cadastrada pode se apresentar das seguintes formas:

* + Em preparação:\* Quando o fechamento foi criado, porém ainda não foi calculado. **- Calculado:** Quando a apuração foi realizada, porém os lançamentos financeiros ainda não foram gerados. **- Integrado:** Quando a apuração foi realizada, e os lançamentos financeiros gerados para o TOTVS Gestão Financeira.  
    **Observação:** O único status que permite alterações nas Reservas é o Status de **Em Preparação**.  
    **Empreendimento:** Empreendimento para onde a reserva foi destinada.  
    **Unidade:** Unidade para onde a reserva foi destinada.  
    **Subunidade:** Subunidade no qual solicitou a reserva. Através desse campo será buscado o ocupante, locador ou locatário responsável pelo pagamento da taxa de reserva. Esse campo permite somente as subunidades relacionadas ao campos Empreendimento ou Empreendimento/Unidade. Campo obrigatório.   
    **Área Comum:** Área Comum para onde a reserva foi destinada.  
    **Início Reserva:** Data e hora ao qual se inicia a reserva.  
    **Fim Reserva:** Data e hora ao qual se finaliza a reserva.  
    **Obs.:** Os campos de data e hora acima são similares ao período da reserva.  
    **Fechamento do Condomínio:** Esse campo exibe o Fechamento no qual a reserva está associada. Esse campo somente é preenchido quando o Fechamento é Calculado envolvendo a reserva.   
    **Id Ocupante:** Ocupante do condomínio que fez a solicitação da reserva. Este campo usa a informação do cadastro de Clientes/Fornecedores existente no sistema. Esse campo é opcional, pois o sistema busca automaticamente o responsável financeiro pela subunidade informada. Ao alterar a informação do campo Subunidade, o sistema limpa o conteúdo desse campo.   
    **Descrição:** Este campo pode ser usado para uma breve descrição da reserva.  
    **Utilização:** Este campo pode ser usado para uma descrição mais detalhada.  
    **Cód. Item Cobrança:** Código do Item de Cobrança envolvido na reserva. Este campo não é obrigatório, caso o usuário não registre nenhuma informação aqui, o sistema irá utilizar o Item de Cobrança informado no cadastro de **Áreas Comuns**.  
    **Taxa de Reserva:** Campo usado para informar qual será a taxa ou valor da reserva. Exemplo: 100,00.  
    Este cadastro está disponível também como anexo para os cadastros de Empreendimento e Unidade/Subunidade no módulo de Condomínio.
