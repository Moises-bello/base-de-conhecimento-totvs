**Dúvida**Como liquidar várias invoices de um único contrato de câmbio? Como aglutinar os pagamentos?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**Sequência – Manutenção FFC:  
1. No Easy Import Control (SIGAEIC) acesse Atualizações/ Financeiro/ Manutenção FFC (EICLO100).  
2. Informe os dados necessários e clique no botão OK.  
Note que o campo Cod. Forn (WB\_FORN) apresenta o campo Loja For (WB\_FORLOJ).  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360050885294/mceclip0.png)  
3. Marque ou desmarque as invoices, conforme o agrupamento a ser fechado no contrato de câmbio.  
Note que o campo Cod. Forn (WB\_FORN) apresenta o campo Loja For (WB\_FORLOJ).  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051797473/mceclip1.png)  
4. Selecione outras ações\Gera FFC´s.  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051797513/mceclip2.png)  
5. Selecione o botão Confirmar para gravar. E confirme a gravação.  
6. Para liquidar e estornar a FFC, na tela Manutenção de Lote, selecione a FFC desejada e selecione o botão Confirmar.  
![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051797633/mceclip3.png)  
7. Na tela seguinte, selecione outras ações\Fechamento. Informe os dados para a baixa do FFC.  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360050885414/mceclip4.png)  
8. Clique no botão Confirmar. Será exibida a tela para confirmar a baixa da FFC.   
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360051797773/mceclip5.png)  
9. Para estornar a liquidação, basta informar o número da FFC na tela de Manutenção de lote e utilizar o  
botão Estorno.
