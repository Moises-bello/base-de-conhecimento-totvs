# Criação do campo Sublimite Excedido no anexo dados fiscais da Filial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Anexos dados Fiscais do cadastro da Filial |
| **Situação/Requisito:** | No Anexo Dados Fiscais da Filial, na pasta Tipo Estabelecimento, criar um campo "Sublimite excedido" (abaixo do campo "Optante Regime Simplificado") que será habilitado somente se este último estiver marcado, ou seja, se a Filial for optante do Simples. |
| **Solução/Implementação:** | Foi criado o campo "Sublimite excedido" no anexo Dados Fiscais do cadastro da Filial pasta Tipo de Estabelecimento  O campo Sublimite Excedido será habilitado somente se o campo Optante Regime Simplificado estiver marcado |
