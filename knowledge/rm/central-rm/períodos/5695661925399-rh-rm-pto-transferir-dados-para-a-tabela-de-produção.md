**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16034235867799) Tempo aproximado para leitura: 00:00:45 min** **Dúvida**Como transferir dados para a tabela de produção?   
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Totvs Automação de Ponto - Todas as versões   
  
**Solução**Para transferir os dados para a tabela de produção, siga os passos abaixo:

* No módulo de **Automação de Ponto**, acesse o menu **Configurações** | **Períodos**.  
  Selecione o período anterior que está no qual deseja gerar o relatório.  
  Obs.: Confira a coluna Arquivo Morto e caso a caixa de seleção da coluna estiver marcada, indica que os registros estão em arquivo morto.   
  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151993051671)
* Acesse a opção **Processos**| **Transferir dados para as tabelas de produção.**Vai ser aberta a janela de execução.  
  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151993058455)
* Nesta tela está disponível a opção de seleção de funcionários possibilitando realizar o processo parcialmente visando otimizar o tempo de execução do processo. Ao realizar o registro somente para um funcionário ou grupo de funcionários. A caixa de seleção da coluna arquivo morto irá ficar com um quadradinho indicado que há registros movimentados parcialmente:  
  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151976606743)
* Para conferir os funcionários que os registros foram levados para tabela de produção, selecione o período desejado e acesse a opção **Anexos** | **Período do Funcionário:**![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151976607511)
* Caso o parâmetro **“Transferir registros para tabela de produção de todos os funcionários”** seja marcado, o filtro realizado na seleção de funcionário será desprezado, e o processo irá realizar a transferência de todos os registros referente ao período selecionado para a tabela de produção sem restrição de funcionários.  
  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151993065623)  
    
  Obs.: A caixa de seleção da coluna arquivo morto irá ficar vazia indicado que há registros  movimentados parcialmente:![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151976611863)
* Para retornar com os dados para as tabelas de **arquivo morto**, selecione o período e vá em **Processos** | **Transferir dados para as tabelas de arquivo morto**.  
  ![](https://centraldeatendimento.totvs.com/hc/article_attachments/30151993075223)
