Dúvida**Como criar novo código para integração contábil?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para cadastrar uma nova conta para integração contábil, acesse **Administração de pessoal | Cadastros globais | Tabelas dinâmicas** e selecione o sistema **Folha de Pagamento.** Depois procure a tabela **CODINTCONT** e crie um novo campo na tabela com o código e descrição desejado.
