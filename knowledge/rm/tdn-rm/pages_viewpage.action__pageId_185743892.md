# Pré-requisitos

---

2
complete
Linha RM atualizada até a versão 12.1.5

1
complete
Ter uma conta de comunicação para o Twitter cadastrada como Remetente

# Objetivos

---

Cadastrar uma Conta de Comunicação utilizando o Twitter.

# Criando a conta

---

1. Acesse o cadastro de Contas de Comunicação e selecione a Fonte de Comunicação Twitter:
2. Para criar uma conta de Destinatário:

   1. Selecione "Obter código de identificação".
   2. Será exibida a seguinte pergunta:
   3. Respondendo "não", você será orientado a seguir os passos para .
   4. Respondendo "sim", você deverá informar qual de qual conta o sistema irá buscar a lista de conexões.
   5. Selecione o contato desejado e clique em "Selecionar usuário".
3. Clique em "Salvar".
