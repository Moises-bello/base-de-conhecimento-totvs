# Inclusão de reunião de TCC

|  |  |
| --- | --- |
| **Linha de Produto** | RM |
| **Segmento:** | TOTVS Gestão Educacional |
| **Módulo:** | Educacional |
| **Função:** | Reunião de TCC |
| **Situação/Requisito:** | Ao cadastrar uma nova reunião/acompanhamento de TCC, é exibido apenas os TCCs do período letivo definido como Período Letivo atual, nos parâmetros do sistema. |
| **Solução/Implementação:** | Foi realizado um ajuste para exibir todos os TCCs, independente do período letivo definido nos parâmetros do sistema, mas que não estejam definidos como status de "Status final". Ou seja, todos os TCCs que estão em andamento, serão exibidos no momento de um cadastro de uma nova reunião/acompanhamento. |
