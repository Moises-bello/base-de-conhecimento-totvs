# ALTERAR SITUAÇÃO DE MATRÍCULA NA DISCIPLINA COM TURMA MISTA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Alterar Situação de Matrícula na Disciplina com Turma Mista* |
| **Situação/Requisito:** | *O aluno está matriculado em turma mista com a situação de matrícula para bloquear alteração, mas ao alterar a situação de matrícula na turma (origem), sistema está alterando  a situação de matrícula na turma mista.* |
| **Solução/Implementação:** | *Ajuste no processo de alteração de situação de matrícula na disciplina (origem), para quando possuir matrícula em turma mista, a situação da turma mista somente poderá ser alterada pela turma origem se a situação não tiver marcada para bloquear a alteração.* |
