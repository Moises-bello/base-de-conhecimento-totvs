# ASSISTENTE DE INCLUSÃO DE BOLSAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Validação de inclusão de bolsas* |
| **Situação/Requisito:** | *Ao validar a inclusão de bolsa, utilizando escopo por parcela, o sistema está permitindo a inclusão da mesma bolsa para um mesmo serviço em sobrepondo parcelas quando o escopo da bolsa que está sendo adicionada abrange mais parcelas que bolsa existente.* |
| **Solução/Implementação:** | *Foi realizada otimização do assistente de inclusão de bolsas, de forma que o sistema seja capaz de perceber sobreposição de uma mesma bolsa para o mesmo serviço, quando a bolsa que estiver sendo inserida englobar a bolsa existente.* |
