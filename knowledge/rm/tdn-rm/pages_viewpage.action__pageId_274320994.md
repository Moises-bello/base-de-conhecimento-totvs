# MUDANÇA DE TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | Mudança de turma / Enturmação |
| **Situação/Requisito:** | Ao mudar o aluno de turma o sistema exibe uma informação de erro “Preencha o campo 'Aulas Dadas'  sendo que na parametrização ele não marca a flag do campo “copiar os registros de presença diária para a turma destino”. |
| **Solução/Implementação:** | O erro ocorria porque o sistema considerava a atualização de notas e faltas ao marcar o flag para copiar notas.  Foi feito um ajuste para que a cópia de faltas seja considerada ao marcar a opção "Copiar registros de presença diária para a turma de destino". |
