A Equivalência por aluno só está disponível para o contexto de Ensino Superior.

Equivalência é a forma de definir que disciplinas de nomes diferentes podem ter o mesmo conteúdo, ou seja, conteúdos equivalentes.  
   
É comum disciplinas terem nomes diferenciados, tanto em Instituições de Ensino diferentes quanto em uma mesma instituição, como por exemplo, cada curso utilizar uma nomenclatura diferente. Daí a necessidade de ter este conceito de "Equivalência de Disciplinas."  
   
A equivalência de disciplinas se dá através do Conceito de Grupo, isto para que haja uma flexibilidade de equivaler mais de uma disciplina ao mesmo tempo. exemplo:

|  |  |
| --- | --- |
| **Grupo 1** | **Grupo 2 (equivalente)** |
|  | Comunicação e Expressão |
| Português | Literatura |
|  | Redação |

No caso acima, não basta o aluno cursar a disciplina de Comunicação e Expressão para que tenha cumprido Português, ele TEM obrigatoriamente que cursar todas as disciplinas do Grupo 2.  
   
Também existe o caso básico de equivalência, onde o grupo pode ter só uma disciplina fazendo a equivalência mais conhecida que é a que uma disciplina equivale a outra simplesmente.

|  |  |
| --- | --- |
| **Grupo 1** | **Grupo 2 (equivalente)** |
| Algorítimos | Técnicas de Programação Inicial |

A equivalência de disciplinas poderá (ou não) ser recíproca, ou seja Grupo 1 equivale a Grupo 2 e vice-versa. Esta definição é feita no momento do cadastro das equivalências, através de opção na tela.  
Existem três formas de se cadastrar equivalências:

* **Por Disciplina:** Neste formato, quando se informar que disciplina A equivale à disciplina B, qualquer aluno poderá cursar qualquer uma delas em substituição à outra.
* **Por aluno:** Existe a possibilidade de se cadastrar uma equivalência de forma individual, ou seja onde Disciplina A equivale a Disciplina B, Somente para um determinado aluno (ou para um grupo de alunos). Esta opção está disponível como anexo do  do aluno, no anexo [Disciplinas Equivalentes](http://tdn.totvs.com/x/QfxbGQ). Neste local, são exibidas todas as equivalências de disciplinas que o aluno possui. Para cadastrar uma equivalência para um grupo determinado de alunos, existe um assistente, , para facilitar o cadastro.
* **Por Matriz:** No cadastro de disciplinas da matriz curricular também é possível cadastrar grupos de equivalências. As disciplinas que serão utilizadas neste cadastro são do cadastro geral de disciplinas, não de outra matriz curricular. **Disciplinas de um mesmo período não poderão ser equivalentes entre si, o mesmo vale para as disciplinas optativas/eletivas.**  
  **Ordem de verificação da equivalência**  
  Caso existam as três equivalências cadastradas (Por Disciplina, Por Aluno e Por Matriz) e o aluno tenha sido aprovado em todas elas, o sistema irá verificar nesta ordem:

1. Equivalência por aluno
2. Equivalência por matriz
3. Equivalência por disciplina

|  |  |  |
| --- | --- | --- |
| **Tipo de Equivalência** | **Disciplina** | **Equivalente** |
| Por Aluno | DS-INGI | A129-1 |
| Por Matriz | DS-INGI | C003-1 |
| Por Disciplina | DS-INGI | A127-1 |

A disciplina DS-INGI possui 3 grupos de equivalência  
O aluno foi aprovado nas três disciplinas equivalentes a DS-INGI. Na Análise Curricular a disciplina DS-INGI é apresentada como APROVADA e, logo abaixo dela, A129-1 como equivalente cursada.

* **Exclusivo para esta habilitação:** O aproveitamento de estudos será válido somente para a habilitação na qual o aluno está matriculado.

Exemplo: Suponha que o aluno esteja matriculado na Matriz A e dispensado na disciplina V. Caso o aluno seja matriculado na Matriz B e, exista na Matriz B uma disciplina X equivalente à disciplina A, ao abrir a Análise Curricular do aluno na Matriz B, a disciplina V estará "concluída" por equivalência.

|  |  |
| --- | --- |
| **Matriz A** | **Matriz B** |
| Disciplina A | Disciplina V |

|  |
| --- |
| **Equivalência** |
| Disciplina A = Disciplina V |

É possível informar qualquer disciplina no aproveitamento de estudos, portanto qualquer disciplina do nível de ensino do contexto poderá ser informada.  
**Obs.**: O sistema não permite matricular o aluno em disciplinas aprovadas no aproveitamento de estudos. Após incluir um registro de aproveitamento de estudos, todos os campos podem ser alterados, exceto **CODDISC** e **IDPERLET**.
