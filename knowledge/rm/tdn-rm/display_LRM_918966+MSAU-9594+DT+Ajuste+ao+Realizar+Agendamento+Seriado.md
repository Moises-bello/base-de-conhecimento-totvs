# Ajuste ao Realizar Agendamento Seriado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao realizar um agendamento seriado, a data de chegada e o atendimento do paciente, eram copiados do atendimento de origem. |
| **Solução:** | Realizado ajuste para não copiar a data de chegada e o atendimento do paciente do atendimento de origem, ao realizar um agendamento seriado. |
