# Atributo de Segurança nos DataServers

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS EDUCACIONAL* |
| **Função:** | *Segurança* |
| **Situação/Requisito:** | *Segurança de acesso aos DataServers através do WebService (TBC)* |
| **Solução/Implementação:** | *A partir da versão 12.1.8 foi realizado pela Framework da linha RM a verificação de atributos de segurança existentes nos DataServers para validar a permissão do usuário através do acesso pelo TBC.*  *Na versão 12.1.8 alguns dataServers ainda não possuem a tag de segurança, causando a seguinte mensagem de erro para o usuário:*  Ocorreu um erro ao efetuar a leitura do registro:  Não foi encontrado o atributo de segurança no NomeDataServer.  **A partir da versão 12.1.9, todos os dataservers possuem os atributos de segurança definidos.** **Já na versão 12.1.8, foi realizado apenas para os principais DataServers.**  *Foram incluídos as Tags de segurança em todos os dataservers do Educacional na versão 12.1.8.* |
