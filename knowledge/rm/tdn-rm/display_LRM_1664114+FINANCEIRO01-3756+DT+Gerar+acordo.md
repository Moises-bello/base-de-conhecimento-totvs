|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Gerar acordo |
| **Situação/Requisito:** | Após desabilitar a tabela opcional 1, ao gerar acordo para lançamentos que tinham a tabela opcional preenchida, o sistema está apresentando o erro abaixo: "Preparando inclusão de lançamentos gerados pelo serviço de Acordo Tabela Opcional 1 não está sendo utilizada. Verifique os parâmetros do Financeiro. |
| **Solução/Implementação:** | Ajuste no processo de acordo para não carregar a tabela opcional para os lançamentos gerados por acordo caso a tabela não esteja mais sendo utilizada. |
