# Exibição da filiação do aluno nos dados pessoais do novo portal do aluno

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Filiação do aluno. |
| **Situação/Requisito:** | Ao acessar a tela de Dados Pessoais do aluno, no novo portal do aluno, era exibido apenas uma pessoa da filiação do aluno, mesmo quando o aluno possuía mais de uma pessoa cadastrada. |
| **Solução/Implementação:** | Foi alterado o campo que exibe a Filiação, para uma tabela onde é exibido todas as pessoas cadastradas como Filiação do aluno. |
