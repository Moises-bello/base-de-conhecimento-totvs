# Gerar aprazamento na Prescrição Médica

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.82.42.x 12.1.8.x e Superiores |
| **Ocorrência:** | O sistema não está gerando aprazamento na Prescrição Médica |
| **Passo a passo:** | Acessar o menu Opções -> Parâmetros -> Parâmetros Gerais    Na aba "Prontuário Eletrônico" dentro da Subaba "Prescrição"  Marque o parâmetro indicado na imagem.  Com o parâmetro DESMARCADO, o sistema não irá gerar aprazamento na Prescrição e sim na Movimentação de Estoque.  Com ele Marcado, ele passa a gerar o aprazamento na Prescrição Médica. |
