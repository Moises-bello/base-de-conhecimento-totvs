# Agendamento Consulta de Campo Número Carteira

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Agenda de Atendimentos | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server®/ Oracle® |
| **Tabelas Utilizadas:** | SZAGENDAMENTO |
| **Sistema(s) Operacional(is):** | Windows® |

## Descrição

Melhoria consiste na inclusão da coluna **Carteira do Convênio** na lista de **Agenda de Atendimentos**.

## Procedimento para Utilização

### Agenda de Atendimentos

1. Acesse o menu **Atendimento** / **Agendamento** / **Agenda** **de** **Atendimentos**.
2. Selecione uma **Unidade de Atendimento**.
3. Selecione a **Agenda de um Médico** e visualize o campo **Carteira do Convênio**.   
   Observação

   Para visualizar o campo preenchido é necessário selecionar uma **Faixa de Horário** para **Incluir** e/ou **Editar** um registro.
