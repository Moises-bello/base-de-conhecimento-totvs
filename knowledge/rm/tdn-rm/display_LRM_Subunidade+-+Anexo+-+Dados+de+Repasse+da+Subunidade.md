Nesta opção de menu serão inseridos os Dados de Repasse da Subunidade que serão usados para efetuar o Repasse no módulo Gestão Financeira;

Ao cadastrar ou editar um Dados de Repasse da Subunidade, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* **Código Empreendimento**: Neste campo estará o código do Empreendimento que receberá os Dados de Repasse. Este campo está desabilitado para edição;
* **Código Unidade**: Neste campo estará o código da unidade que receberá os Dados de Repasse. Este campo está desabilitado para edição;
* **Código Subunidade:** Neste campo estará o código da subunidade que receberá os Dados de Repasse. Este campo está desabilitado para edição;
* **Percentual**: Informe qual será o percentual de rapasse para o Cliente;
* **Comprador**: Informe o cliente que receberá o repasse.

**Fideicomiso**  
Para atender ao mercado internacional foi criado o tipo de participação (Repasse)  que podem ser por Lançamentos financeiros ou por Fideicomiso. O FIDEICOMISO é um arranjo legal que permite a participação de mais de uma empresa  nos ganhos financeiros. Diferente do Repasse atual, este gera um movimento ao invés do lançamento financeiro.

* **Tipo Participação**: Informe se o repasse será gerado através de um lançamento financeiro ou pelo Fideicomiso.

Caso o Fideicomiso for selecionado serão habilitados outros campos na tela:

* **Valor de Participação:** Informe o valor fixo da participação do parceiro no empreendimento.
* **Parâmetros de movimento:** Informe um conjunto de configurações default que trazem os dados para a geração do movimento.

Com o parâmetro de Fideicomiso selecionado, é possível escolher apenas participação por percentual, ou por valor, nunca os dois ao mesmo tempo.
