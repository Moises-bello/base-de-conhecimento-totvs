Neste processo é possível verificar entre as comunidades ativas ou inativas de cada entidade que tenham comunidades cadastradas, quais deseja que voltem a estar ativas no sistema ou quais deseja desativar no sistema.  
   
É necessário informar para quais entidades deseja realizar este processo.  
   
Caso opte por ativar comunidades, serão listadas somente as comunidades das entidades inativas no sistema.  
   
Caso opte por desativar comunidades, serão listadas somente as comunidades das entidades ativas no sistema.  
   
Para maiores informações, acesse: **Academia Social**
