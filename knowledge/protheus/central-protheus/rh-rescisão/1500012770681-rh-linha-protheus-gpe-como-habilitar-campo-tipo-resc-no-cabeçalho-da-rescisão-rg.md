**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34327586674071)Tempo aproximado para leitura: 01:30 min****Dúvida**Como habilitar campo Tipo Resc no cabeçalho da rescisão (RG\_TIPORES)?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**

1. Pelo Configurador, entre na rotina Base de Dados (caminho >Base de Dados >Dicionário >Base de Dados):  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019711482)

2. Selecione a opção Dicionário de Dados:

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019711542)

3. Pesquise pela tabela SRG:

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019711582)

4. Clique em EDITAR:

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019982401)

5. Clique em Campos e para o campo RG\_TIPORES clique em EDITAR:

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019982461)

6. Configure as abas CAMPO e USO conforme abaixo:

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019711742)  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/14693698272791)

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019712062)

7. Clique no campo selecionado abaixo para confirmar a alteração: 

![mceclip7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019712082)

8. Clique no Disquete selecionado abaixo para salvar a alteração no Dicionário, isso deve ser feito em modo exclusivo, caso contrário dicionário não será modificado:

![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500019982741)

9. Acessar o modo SIGAGPE rotina rescisão (miscelanea\cálculos\rescisão), pesquisar funcionário, clicar em incluir e selecionar o tipo de rescisão.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18879371723799)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/18879350771991)
