Este menu foi criado para facilitar o rastreamento das transações de pagamento realizadas no sistema via cartão de Crédito e Débito.  
É exibido na visão a informação do pagamento com cartão, podendo ser identificada pelo modelo de transação, sendo por pagamento via portal Educacional nos modelos BuyPage Cielo, Checkout Cielo, IFrame Getnet, CyberSource, Adyen ou pagamento pela Sessão de Caixa utilizando o SiTef.

Em Anexos | Histórico de Transações é exibido para cada registro um histórico do processo de pagamento, facilitando o acompanhamento de mudança dos status do pagamento. É exibido também no campo dados da transação as informações do retorno pela adquirente.

**Observação:**

O menu de "Histórico de Transações" está disponível também para integração com TOTVS Educacional x BackOffice Protheus e EAI 2.0, quando ativa. Disponível a partir da versão 12.1.31.

**Ajustar transações**

Esta opção possibilita selecionar as transações de cartão para consultar o status na adquirente, com o objetivo de ajustar o status das transações e/ou o status do boleto/lançamento no TOTVS Gestão Financeira. Pode ser executado em Processos | [Ajustar transação](https://tdn.totvs.com/pages/viewpage.action?pageId=421388533).
