Neste cadastro poderão ser incluídos campos para gravar informações nos [Lançamentos Fiscais](http://tdn.totvs.com/pages/viewpage.action?pageId=422546023) de Entrada ou Saída que não existem na base de dados do sistema.

Estas informações poderão ser utilizadas para a geração de relatórios. Eventualmente serão criados campos complementares que serão utilizados para a geração de rotinas legais. Neste caso as especificações do campo devem ser extraídas do help da rotina relacionada.

Para otimizar o uso dos Campos Complementares pode-se associar a eles tabela dinâmicas. Desta forma serão limitados os dados que poderão ser gravados neste campo minimizando os erros de digitação.

Campos Complementares não podem ser excluídos. Quando houver esta necessidade os mesmos serão desativados.
