![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23703355326359) Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Quais são os **Principais Campos de Moedas Protheus x Externo**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**Os **Principais Campos** estão descritos na rotina abaixo:

| Campo | Descrição |
| --- | --- |
| Cod Protheus | Código da Moeda padrão do Protheus. |
| Descrição | Descrição da moeda. |
| Cod Atual | Código da moeda no sistema externo usado na integração para atualizar a cotação atual da moeda. |
| Cod Futuro | Código da moeda no sistema externo usado na integração para atualizar as cotações futuras da moeda. |
| Índice | Índice de mercado. |
