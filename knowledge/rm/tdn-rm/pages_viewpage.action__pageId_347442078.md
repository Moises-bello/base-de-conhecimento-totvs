# Pesquisa de item com bloqueio na movimentação de estoque

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Estoque / Movimentação de Estoque |
| **Situação:** | Cliente informa que o filtro dos produtos na busca a partir da tela de Movimentação de Estoque não estão correspondendo às regras do Bloqueio por Centro de Custo. |
| **Solução:** | Realizada a correção das regras dos filtros e implementada validação que impede a troca do Centro de Custo quando a há itens na Movimentação. |
