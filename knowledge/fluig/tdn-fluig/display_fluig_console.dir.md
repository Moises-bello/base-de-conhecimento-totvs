O método dir do  registra em formato json os dados de um objeto umano nível INFO. É o método comumente usado para ter uma visão clara do conteúdo de um objeto complexo de forma expandida. Múltiplos argumentos são concatenados com um espaço. Este é o mesmo método que log.dir.
