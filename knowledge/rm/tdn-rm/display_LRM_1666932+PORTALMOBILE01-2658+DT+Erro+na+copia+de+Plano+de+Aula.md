# Erro na copia de Plano de Aula

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Portal do Professor |
| **Função:** | Cópia de conteúdo previsto/realizado entre turma/disciplinas |
| **Situação/Requisito:** | Ao selecionar todos os planos de aula de uma determinada turma disciplina e utilizar o processo de "Copiar conteudo para outra Turmar / Disciplina" o sistema retorna a mensagem de erro:  Erro HTTP 404.15 - Not Found O módulo de filtragem de solicitação está configurado para negar uma solicitação quando a cadeia de caracteres de consulta for muito longa. |
| **Solução/Implementação:** | Realizado ajuste para limitar o número de aulas selecionadas ao executar o processo de cópia de conteúdo previsto/realizado entre turma/disciplinas, para evitar o erro de HTTP 404.15 |
