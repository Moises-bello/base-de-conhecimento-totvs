# MATRÍCULA ISOLADA EM TURMA ASSOCIADA A UMA MATRIZ COM CONTROLE DE VAGAS POR TURMA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matrícula isolada* |
| **Situação/Requisito:** | *Ao matrícula um aluno em uma turma associada a uma matriz que possui controle de vagas por turma, o sistema apresenta uma mensagem informando que não há vagas.* |
| **Solução/Implementação:** | *Foi realizado um ajuste para que o sistema, quando a matrícula for realizada em uma turma com matriz, obtenha a configuração de controle de vagas da mesma, senão será aplicado o controle de vagas por turma/disciplina.* |
