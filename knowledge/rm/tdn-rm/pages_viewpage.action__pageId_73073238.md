**Introdução**   
  
Para garantir a integridade dos lançamentos contábeis oriundos do RM Liber, durante a conversão da Base de Dados para versão 11.8x, é necessário realizar a Consistência de Lançamentos.

**Desenvolvimento/Procedimento**

Acesse o menu 'RELATÓRIOS' / 'CONSISTÊNCIA P/ CONVERSÃO GESTÃO FISCAL', conforme imagem abaixo:

Depois marque o parâmetro “Preparar a base para Conversão Novo Modelo BackOffice versão 11.80”

Na próxima tela, selecione todas as coligadas e clique em avançar

 

Caso o Processo não encontre inconsistências, sistema vai apresentar a seguinte mensagem:

Caso o sistema encontre alguma inconsistência a seguinte tela vai ser apresentada:

Sendo assim Clique em Bloco de Notas e acerte as inconsistências apresentadas, caso tenha dúvidas para solucionar alguma consistência, anexe o log gerado ao chamado para que possamos avaliar.
