#### Honorário de repasse não é apresentado na folha de pagamento de prestadores

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde. |
| **Módulo:** | TOTVS Gestão Hospitalar. |
| **Função:** | Cadastros > Faturamento > Critério de Geral de Repasse |
| **Situação/Requisito:** | Na tela de Pesquis de Itens (Procedimentos) ao consultar via descrição o sistema retornava somente a tabela base cadastrada, mesmo coma configuração do convênio estando com tabela específica configurada |
| **Solução/Implementação:** | Inicialização de atributos Convênio, Unidade, Data de Vigência e UsaTabBasica |
