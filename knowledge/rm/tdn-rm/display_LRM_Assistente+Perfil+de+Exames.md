**Assistente Perfil de Exames**

A partir deste assistente é possível associar perfis de exames a funcionários para a geração automática de exames pendentes. O assistente possibilita vincular um perfil de exames a uma função, seção, lotação ou a uma consulta SQL. O vinculo é feito automaticamente, após escolhido uma das opções e os perfis de exames. Para auxiliar na utilização do Assistente, o RM Vitae disponibiliza explicações dentro de cada janela, como um passo-a-passo, assim a associação é realizada com facilidade, seguindo as instruções do sistema. O Assistente possui as seguintes opções de associações:

* Função
* - Seção
* - Lotação (Função)
* - Lotação (Seção)
* - Consulta SQL

Conforme a opção selecionada o assistente exibe os registros selecionados para serem associados aos perfis de exames. Os exames dos perfis serão consistidos na pasta de Exames Pendentes do funcionário, possibilitando visualizar assim os exames que ainda são necessários para o funcionário.

O assistente contém os seguintes passos:

1) Selecionar Tipo de Associação (Função, Seção, Lotação (Função), Lotação (Seção) ou Consulta SQL;

2) Selecionar os registros para associação: seleciona os registros aos quais os perfis de exame serão associados;

3) Associação de perfis de exame: Nesta tela são listados os registros solicitados nos passos anteriores para manipular a associação de perfis de exame a eles; 4) Concluir a associação de perfis.

**Observação**

- A qualquer momento é possível voltar ou avançar e fazer a correção do vínculo;

- Será apresentado antes da conclusão do lançamento, um resumo das associações efetuadas, caso você observe algum dado incorreto, clique no botão <Voltar> e faça a correção do vínculo;

- Quando for utilizada a opção Consulta SQL a mesma deverá retornar os campos codcoligada e chapa do funcionário.

**Atenção**

Para qualquer ícone desabilitado, verifique com o Supervisor as permissões do usuário em questão em Cadastros | Segurança | Perfis | pasta Acesso a Menus.
