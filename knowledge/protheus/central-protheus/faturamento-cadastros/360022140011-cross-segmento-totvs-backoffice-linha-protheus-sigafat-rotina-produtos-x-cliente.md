**Dúvida**Explicativo de funcionamento da Rotina **MATA370** e Relatório Lista de Preços por Clientes **MATR785**.

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.

**Solução**Rotina **Produtos X Clientes** - **MATA370**Esta rotina permite que seja cadastrado um vínculo entre produtos e clientes, demonstrando os últimos preços aplicados no processo de faturamento.

Por meio dela é possível verificar os últimos preços aplicados nas operações de venda para o Produto e para o Cliente selecionado na Rotina, além de alimentar os dados para geração do relatório Produtos X Clientes **MATR370**.

Relatório **Lista de Preços por Clientes - MATR785**  
Este relatório permite a emissão da lista de preços dos produtos cadastrados, fazendo uma relação entre os clientes, conforme parametrização do usuário.  
Tem como base os dados registrados nas Tabelas **SA7** , **SA1** e **SB1**.

Veja no link disponível mais detalhes sobre a rotina MATA370.
