# Lançamento - Exclusão

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Lançamento - Exclusão |
| **Situação/Requisito:** | Ao excluir um lançamento financeiro gerado pelo movimento (seja excluindo o movimento, reabrindo o financeiro ou alterando dados do movimento para regerar o lançamento), o sistema apresenta o seguinte erro: "Excluindo: Coligada = 1; Identificador = 6551. Violação de chave estrangeira". |
| **Solução/Implementação:** | Otimização no processo de cancelamento do controle orçamentário. Agora o sistema cancela corretamente o controle orçamentário originado pelo Nucleos e seus lançamentos financeiros. |
