**![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19461401961879) Tempo aproximado para leitura: 00:02:00 min** **Dúvida**Para que serve e como realizar cadastro de Categorias de Cursos, no modulo Treinamento  
 **Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Treinamento – Todas as versões  
  
**Solução**Esta rotina permite o cadastramento de todas as **entidades** que podem **ministrar cursos para os treinamentos oferecidos** pela empresa.  
  
A partir do **cadastro de entidades** é possível efetuar os seguintes controles:   
• Planejar treinamentos para os funcionários;   
• Montar um calendário de treinamentos para a empresa;  
• Controlar os custos de treinamento por funcionário e custos anuais para a empresa;   
• Efetuar cotação dos cursos oferecidos pela entidade.  
  
No **planejamento de treinamentos**, existe a opção de **orçar treinamentos e cursos**, através da integração entre os ambientes de **Treinamento e Compras.**   
  
Mas, para que esse controle seja possível, é necessário que:   
• Todo treinamento seja cadastrado como um **produto**, onde seu código será relacionado posteriormente no Cadastro de Cursos (Internos ou Externos);   
• Toda entidade deve ser cadastrada como **fornecedor**, relacionando seu código neste Cadastro de Entidades;   
• Uma vez cadastrados como **produto** e **fornecedor**, em **Calendário de Treinamento**, o sistema atualiza o calendário com as informações do planejamento, onde, caso haja pedido de compra gerado, são apresentados os dados referentes ao fornecedor e custo do treinamento**.**
