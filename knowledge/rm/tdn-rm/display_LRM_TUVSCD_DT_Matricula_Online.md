|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Matrícula Online.* |
| **Situação/Requisito:** | *O portal online permitia o aluno excluir uma disciplina matriculada mesmo que a situação de matrícula no período letivo estivesse parametrizado para bloquear a exclusão.* |
| **Solução/Implementação:** | *Impedir a exclusão de matrícula quando a situação de matrícula estiver parametrizada para bloquear a exclusão. Vale ressaltar que o aluno poderá alterar a turma da disciplina matriculada, porém não será permitido deixar de selecionar pelo menos uma turma da disciplina matriculada.* |
