# CADASTRAR/ALTERAR FUNCIONÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastrar ou alterar um funcionário* |
| **Situação/Requisito:** | Quando um campo obrigatório não está preenchido, ao clicar no botão "OK", o sistema emite a mensagem, porém fecha a tela do sistema. |
| **Solução/Implementação:** | Ao tentar inserir ou alterar um cadastro de funcionário, caso tenha algum campo que seja obrigatório, ao clicar no botão "OK", deve ser apresentado a mensagem e a tela de cadastro não deve fechar. Somente irá fechar se salvar com sucesso. |
| **Chamados relacionados:** | TTZAP5 |
