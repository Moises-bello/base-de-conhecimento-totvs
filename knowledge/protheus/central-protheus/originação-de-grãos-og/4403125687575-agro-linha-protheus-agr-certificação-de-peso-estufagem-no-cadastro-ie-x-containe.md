**Dúvida**Como efetuar a estufagem corretamente no cadastro  **IE x Container**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**Após ser feita a vinculação dos **Containers da Instrução de Embarque**, será possível fazer a **Estufagem**.  
Para produto **Algodão**, na tela de **relacionamento IE x Container - OGA730**, acessar a **ação relacionada estufagem**.

![ESTUF1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048154815127)

**Somente é****permitido estufar** se o container estiver com status **disponível ou em estufagem**.  
  
Será aberta uma nova tela onde a esquerda ficará os fardos que pertencem a **Instrução de embarque - IE** posicionada e que estão presentes em um **romaneio e que o mesmo está com status de confirmado.**

**![ESTUF2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048186629911)**

Ao mover os fardos da tela da esquerda para a tela da direita, caso o peso dos fardos for maior que o peso máximo permitido para o container definido na instrução de embarque, o Sistema apresenta uma mensagem de alerta informando **a quantidade que ultrapassou**, possibilitando a correção se necessário.  
  
Após **salvar** e confirmar a tela será gravado as alterações no banco.

![ESTUF3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048192003095)  
![ESTUF4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048224070679)

Para produto grãos na aba de certificação será habilitado o campo **N7Q\_QTDCER - Qtd. Certificada**, ao informar o valor, este valor será gatilhado para os campos **N7Q\_QTDREM - Qtd Remetida** e **N7Q\_QTDREC -** **Qtd Recebida**.  
Caso esteja sendo feita uma estufagem para uma **IE** que já teve faturamento status faturamento faturada, o Sistema retorna o status faturamento para parcial.  
  
Outra forma de acessar a tela e efetuar essa operação é via menu **atualizações originação comercialização IE x container**Após clicar a tela será aberta, com a opção de **incluir** um novo container ou editar algum container existe.

![ESTUF5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048226061207)

Desta forma será aberta a mesma tela que anteriormente com a possibilidade de filtrar e preencher os campos de acordo com a **Instrução de Embarque** necessária.

![ESTUF6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048198244375)

Em **Outras ações** é possível efetuar a mesma interação.

![ESTUF7.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048231158295)

Após a chamada pelo clique em estufagem será aberta a tela de vínculo com a opção de **vincular** e **desvincular** um fardo ao container, em efetuando o **salvar** e confirmando a tela todos os dados serão gravados no banco.

![ESTUF8.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048283398935)

Desta forma o registro estará em tela ao retornar para a tela principal.

![ESTUF9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/8048285641111)  
![mceclip9.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4403119539607)
