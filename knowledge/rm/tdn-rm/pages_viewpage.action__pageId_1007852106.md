### Escolha dos Parâmetros

Esta tela apresenta a **lista de Parâmetros** **opcionais** à serem selecionadas para seguir com o preenchimento.

**Cada parâmetro selecionado nesta etapa, adicionará uma nova etapa de preenchimento ao avançar para a próxima tela, conforme exemplo acima.**

|  |  |
| --- | --- |
| **Relatórios** | Permite o acesso a **relatórios gerenciais ou adicionais** dentro do **PDC/APP**. |
| **Situação financeira / Emissão de novos boletos** | Essa etapa funciona como Parametrização da situação financeira do cliente e a funcionalidade de **emissão de segundas vias de boletos ou novos boletos**. |
| **Atendimentos** | Objetivo dessa etapa é para selecionar os **tipos de atendimentos** para visualizar no **PDC/APP**. |
| **Criação de Usuários** | Permite que **usuários administradores** ou com **permissão específica criem novas contas** de acesso ao portal. |
| **Termo de Aceite** | Permite a seleção de um relatório **padronizado para o termo de aceite** que será apresentado ao cliente. |
| **Renegociação de Contratos** | A parametrização é fundamental para definir as condições sob as quais um cliente pode **renegociar suas dívidas ou faturas em atraso.** |
| **App Meu Imóvel** | Nesta etapa, vinculada ao aplicativo móvel **“Meu Imóvel”**, o usuário poderá definir quais funcionalidades estarão ativas ou inativas, conforme as necessidades da operação. |
