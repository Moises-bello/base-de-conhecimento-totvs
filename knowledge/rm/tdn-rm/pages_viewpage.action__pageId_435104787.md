Este cadastro tem como função possibilitar o anexo de Imagens relacionadas ao Imóvel. De forma a facilitar a integração das Imagens de um Imóvel ao portal próprio da Administradora.   
 Ao realizar o cadastro de uma imagem, são exibidos os seguintes campos:

* **Campo Imagem:** Através desse campo é possível selecionar uma imagem desejada para o cadastro. Além disso, é possível Excluir uma imagem já cadastrada, assim como o seu download para o computador e tirar uma foto para ser utilizada no cadastro;
  + **Observação:** Nesse campo só poderá ser inserido arquivos do tipo Imagem (arquivos com as seguintes extensões .jpg, .gif, .bmp e etc ) e que possua um tamanho de até 5 MB;
* **Código**: Campo que mostra o código da imagem cadastrada. Não é possível editar este campo, a informação é inserida pelo sistema;
* **Descrição**: Campo utilizado para inserir um texto descritivo da Imagem cadastrada;
* **Exibir na Web:** Campo utilizado para definir se a Imagem pode ser exibida na WEB. Podendo ser utilizado como parâmetro em um Portal próprio da Administradora;
* **Definir Imagem Principal:** Nesse parâmetro é possível definir qual é a Imagem Principal do Imóvel. Podendo ser utilizado como parâmetro em um Portal próprio da Administradora;
  + **Observação:** É permitido somente uma imagem principal por Imóvel. Dessa forma, caso deseje cadastrar uma nova imagem principal em um Imóvel que já a possui, será exibida a seguinte mensagem: "O Imóvel já possui a imagem "Código da Imagem Principal já cadastrada" definida como principal. Deseja alterar a imagem principal para a imagem atual?" Caso escolha a opção "Sim", o sistema irá \*desmarcar\* o parâmetro da imagem principal já cadastrada e irá salvar a imagem que está sendo cadastrada como principal. Caso escolha a opção "Não", o sistema irá \*manter\* o parâmetro da imagem principal já cadastrada e irá salvar a Imagem que está sendo cadastrada desmarcando o parâmetro "Definir Imagem Principal";
* **Ordem:** Nesse campo é possível definir a ordem de exibição das Imagens, em um portal próprio da Administradora dos Imóveis, através de valores numéricos.

A edição das informações da imagem pode ser feita na visão de Imagens do Imóvel diretamente no grid sem a necessidade de entrar em imagem por imagem.
