# Assunto

|  |  |
| --- | --- |
| **Produto:** | Totvs Gestão Patrimonial |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Responsável |
| **Ambiente:** |  |
| **Passo a passo:** | Nesta funcionalidade você poderá visualizar, cadastrar, excluir e alterar dados dos Responsáveis pelos [patrimônios](https://tdn.totvs.com/pages/viewpage.action?pageId=423938026) na empresa.        Para cadastrar um Responsável diretamente no RM Bonum, o parâmetro “Usar funcionários do RM Labore como responsáveis” deve estar desmarcado;  Ou se preferir, ao invés de cadastrar os Responsáveis aqui, você poderá usar os funcionários do RM Labore. Para isso, no parâmetro, basta ativar a opção "Usar funcionários do RM Labore como responsáveis".  Parâmetro disponível no menu Ambiente | Parâmetros | Gestão de Patrimônio | Cadastro de Bens | Responsáveis.        **Atenção:** Ao optar por usar funcionários do RM Labore como responsáveis, a janela passará a ter uma única função que é a de visualizar os registros, não permitindo qualquer alteração de dados ou inclusão manual de cadastros. Após vincular algum Responsável (funcionário) em um cadastro de patrimônio, a flag ficará desabilitada para desmarcar. Ao cadastrar um Responsável diretamente pelo RM Bonum, a flag ficará desabilitada para marcar.    **Importante:** Você também poderá copiar os funcionários do RM Labore para o cadastro de Responsáveis, utilizando o processo "[Copiar Funcionários Folha](https://tdn.totvs.com/pages/viewpage.action?pageId=444616209)" no menu Utilitários.    **Essa operação só poderá ser realizada se atendidas as seguintes condições:**   * Que o Totvs Folha de Pagamento esteja acessível; * Que a Tabela de Responsáveis do Totvs Gestão Patrimonial esteja sem nenhum registro. Ou seja, sem nenhum dado cadastrado.   Verifique se os módulos estão integrados, acesse o menu Ambiente | Parâmetros | Integrações de Sistemas | RM BONUM e RM LABORE | Integrado.    Diferentemente do parâmetro "Usar funcionários do RM Labore como responsáveis", que usa a tabela diretamente do Totvs Folha de Pagamento, esse assistente fará uma cópia dos dados.  Lembrando que o parâmetro "Usar funcionários do RM Labore como responsáveis" deve estar desmarcado para que seja habilitada essa opção. |
| **Observações:** | Orientamos que na implantação seja decidido se será usado o cadastro de Responsáveis (Bonum) ou de Funcionários (Labore). |
