**Lançamentos Globais - Atitude**

Em atitude é possível selecionar Pagar/Descontar ou Compensar.

**Pagar/Descontar**

Ao marcar esta opção em atitude o sistema enviará as horas que estão no banco de horas para o movimento do funcionário no período informado em dados do lançamento.Em Ocorrências será possível selecionar o tipo da ocorrência que será lançada para o movimento. São elas Extras Normais, Extras Descanso, Extras Feriado, Extras Compensado, Atrasos, Faltas.

**Compensar**

Ao marcar esta opção em atitude o sistema enviará as horas que estão no banco de horas para o movimento do funcionário no período informado em dados do lançamento. Com a atitude compensar é possível enviar parte das horas da ocorrência que estão no banco de horas para o movimento do funcionário.

Com a opção de atitude compensar marcado o sistema habilita as seguintes opções:

**Percentual de horas a ser lançado**

Este campo será utilizado pelos funcionários com horário do tipo rígido que utilizam banco de horas diário por ocorrência. Informe neste campo o percentual de horas diárias que serão lançadas para o movimento do funcionário.

**Observações:**

1) Este procedimento será realizado apenas para os funcionários que possuem banco de horas diário por ocorrência.

2) A alteração será efetuada apenas para atitude compensar.

**Número de Horas**

Informe neste campo o número de horas do dia de extras, atrasos ou faltas que estão com a atitude "Compensar" no banco de horas que serão enviadas para o movimento do funcionário.

**Observações:**

1) Este procedimento será realizado apenas para os funcionários que possuem banco de horas diário por ocorrência.

2) A alteração será efetuada apenas para atitude compensar.

**Limite de Horas**

Informe neste campo o limite de horas que permanecerão no banco de horas do funcionário. As horas que ultrapassarem este limite serão encaminhadas para o movimento do funcionário.

**Observação:**

1) Este procedimento será realizado apenas para os funcionários que possuem banco de horas diário por ocorrência.

2) A alteração será efetuada apenas para atitude compensar.

**Lançamento de Horas**

As opções de lançamento de horas só serão habilitadas se a opção de atitude compensar estiver marcada.

**Lança total de horas quando ultrapassar limite de horas**

Para fazer este lançamento é preciso informar o "Limite de Horas" e o(s) tipo(s) de ocorrência(s) que fará(ão) parte do lançamento. O sistema verifica dia a dia se o funcionário ultrapassou o limite de horas informado, caso ultrapassar, as horas da(s) ocorrência(s) serão lançadas para a movimentação do funcionário. Caso contrário serão mantidas no banco de horas.

**Lança horas até o número de horas**

Para fazer este lançamento é preciso informar o "Número de horas" e o(s) tipo(s) de ocorrência(s) que fará(ão) parte do lançamento.O sistema lançará dia a dia horas do banco para o movimento até o número de horas informado.
