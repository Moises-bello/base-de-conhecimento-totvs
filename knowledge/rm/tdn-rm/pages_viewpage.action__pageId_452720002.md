Para conferir maior segurança nos processos de cálculo de ponto, o sistema disponibiliza as configurações de recálculo. É possível travar e destravar o recálculo das movimentações de ponto de forma global evitando assim recálculos acidentais. Normalmente, quando é realizada alguma alteração nos dados do funcionário, o sistema automaticamente solicita o recálculo da movimentação, deixando ao cargo do usuário confirmar ou não a operação. Esta opção foi criada para que haja a possibilidade de solicitar o recálculo ao sistema quando o usuário assim o desejar (por exemplo: quando houver atualização de versão).  
Para utilizar basta clicar sobre o botão disponível no menu Configurações. Na barra de processamento será exibida a tarefa que poderá ser travar recálculo ou destravar recálculo. Em seguida, caso tenha escolhido a ação destravar recálculo, poderá ser executado o recálculo normalmente.
