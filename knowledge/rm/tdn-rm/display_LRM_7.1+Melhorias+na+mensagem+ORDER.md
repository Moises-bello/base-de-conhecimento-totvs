| **Descrição** | Novidades na mensagem ORDER |
| **Observações** | No Template CNI trabalhamos apenas com Pedido de Vendas. |

**Objetivo**

Para fornecermos uma melhor experiência nas integrações do EAI disponibilizamos as melhorias abaixo:

* Evolução do adapter da mensagem ORDER (Pedido de Compras/Vendas) para trafegar  
  o campo histórico do movimento e do item;

* Evolução do adapter da mensagem ORDER (Pedido de Compras/Vendas) para trafegar  
   campo Desconto do movimento e do Item;

* Evolução no adapter da mensagem ORDER (Pedido de Compras/Vendas) para enviar  
  para TES Inteligente no Protheus.
* Reenvio da mensagem de Pedido de Vendas
