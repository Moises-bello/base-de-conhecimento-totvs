# Cadastro de BPA pela agenda de atendimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Agenda de atendimentos |
| **Situação:** | O sistema não permitia Deletar/Editar um lançamento de BPA cadastrado pela agenda de atendimentos. |
| **Solução:** | Alterada a chamada da tela de BPA para chamar a tela antiga do lançamento de BPA somente quando o atendimento for realizado pela agenda de atendimento. |
