# SUGESTÃO DE FÉRIAS PELO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Sugestão de Férias.* |
| **Situação/Requisito:** | *Quando um funcionário já possuía férias cadastradas pelo portal com situação G - Aguardando aprovação do Gestor, e o funcionário tentava mudar a data de inicio das férias, o sistema apresentava erro pois não estava considerando a data fim*  *que foi calculada na tela para a alteração do registro.* |
| **Solução/Implementação:** | *Foi ajustado o sistema para que quando já existir férias cadastradas e o usuário for realizar alteração desta data, o sistema consiga buscar a data fim que está sendo apresentada na tela de sugestão de férias e não cause mais o erro.* |
