O contexto de Consulta SQL (RM) permite ao gerador utilizar dados a partir de visões de dados (Consultas SQL) do RM. Esta opção só está disponível no Gerador RM.

![](/download/attachments/319787304/consulta_sql_rm.png?version=1&modificationDate=1512921924000&api=v2)

1Consulta SQL

Selecione a Consulta SQL do RM que será executada para leitura dos dados do contexto. Os parâmetros da Consulta SQL deverão ser informados na aba Parâmetros. Para mais informações consulte [Parâmetros do Contexto](/pages/viewpage.action?pageId=319787287).
