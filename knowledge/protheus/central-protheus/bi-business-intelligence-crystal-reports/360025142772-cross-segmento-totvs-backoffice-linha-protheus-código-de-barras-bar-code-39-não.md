**![](https://jiratdncdncontent.blob.core.windows.net/tdn/icons/time.png)**Tempo aproximado para leitura: **2 minuto****Dúvida**Após a integração do Crystal com o Protheus, o código de Barras BAR CODE 39 não é impresso corretamente. Na realidade o sistema traz um \* no local do código. Já as outras informações e dados são apresentados corretamente  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus – Crystal Reports – A partir da versão 12  
  
**Solução**Por ser uma ferramenta de terceiros, o suporte TOTVS tratará apenas a integração do Crystal com o Protheus. Customizações ou desenvolvimentos via API ou outras ferramentas ficam a cargo do cliente ou sua consultoria
