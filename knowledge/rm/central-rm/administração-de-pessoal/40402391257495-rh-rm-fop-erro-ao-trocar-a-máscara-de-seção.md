**Dúvida**  
Como corrigir o erro de troca de máscara de seção?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de pagamento - Todas as versões  
  
**Solução**  
Ao tentar trocar a Máscara de seção, é possível se deparar com o seguinte erro:  
  
![2026-05-04_14h50_21.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40402391250327)

Com o Log apresentando a seguinte mensagem de sucesso na alteração:

![2026-05-04_14h50_35.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40402419076247)  
  
Este erro pode ser encontrado pelo usuário caso ele tente realizar o processo com integrações ativas. Para corrigir a situação, o usuário deve seguir os passos:

**1-** Acessar o módulo de Integração e validar se existe integração ativas, caso sim desative as integrações e faça novamente a troca do código de seção, caso tiver mais de uma integração marque o parâmetro não em todas.  
![image (5).png](https://centraldeatendimento.totvs.com/hc/article_attachments/40402419076759)

**Observação**  
É recomendado que realize o processo primeiramente em base teste.
