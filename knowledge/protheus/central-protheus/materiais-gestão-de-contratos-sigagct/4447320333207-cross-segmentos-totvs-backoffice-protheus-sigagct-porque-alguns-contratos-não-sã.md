![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/17987889501079) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**Porque alguns contratos não são listados no Dashboard de Contratos ?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos  - Todas as versões

**Solução**Sobre os contratos listados no DashBoard de Contratos, para que o contrato seja listado para o usuário que está acessando o Dashboard, este usuário necessita ser o usuário que cadastrou o contrato ou possuir acesso ao contrato, conforme a configuração de "Acesso ao Contrato do Gestão de Contratos" do artigo abaixo, que podem ser concedidas pelo usuário criador do contrato:

[Cross Segmentos - Totvs Backoffice Protheus - SIGAGCT - Controle de Acesso ao contrato no Gestão de Contratos](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360016499391-Cross-Segmentos-Totvs-Backoffice-Protheus-SIGAGCT-Controle-de-Acesso-ao-contrato-no-Gest%C3%A3o-de-Contratos?source=search)

E também são listados apenas os contratos cuja configuração de Tipo Planilha utilizado (tabela CNL) são suportadas, conforme abaixo:

​![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4447347171735)
