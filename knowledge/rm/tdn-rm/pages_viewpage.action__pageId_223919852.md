# INCLUSÃO DE BOLSA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Inclusão de bolsa* |
| **Situação/Requisito:** | Ao incluir uma bolsa por valor e por número de parcelas para um contrato que já possua a mesma bolsa aplicada às mesmas parcelas e serviço, o sistema não consegue validar a sobreposição de bolsa, caso o vencimento da última parcela seja menor que o vencimento da primeira parcela. |
| **Solução/Implementação:** | *Foi realizada otimização do processo de inclusão de bolsas, de forma que a validação de sobreposição de bolsas tenha o mesmo comportamento tanto para a inclusão de bolsas por valor como por percentual.* |
