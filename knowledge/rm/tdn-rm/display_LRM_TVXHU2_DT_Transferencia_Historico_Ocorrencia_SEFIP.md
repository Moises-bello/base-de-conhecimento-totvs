# HISTÓRICO DE OCORRÊNCIA DO SEFIP

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construções e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de funcionário* |
| **Situação/Requisito:** | *Ao realizar o processo de transferência de um funcionário, o sistema estava levando todo o histórico de ocorrência do SEFIP da chapa antiga para a nova chapa, desta forma levando informações incorretas para o PPP do vitae.* |
| **Solução/Implementação:** | *Foi ajustado o sistema para transferir para a nova chapa somente o ultimo histórico do funcionário com data da mudança igual a data da transferência.* |
| **Chamados relacionados:** | TVXHU2 |
