**Dúvida**  
Como realizar o cadastro de Perfis  no Configurador de Tributos (FISA170)?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAEIC - a partir da versão 12.1.2210.  
  
  
**Solução**  
A configuração do Configurador de Tributos para importação tem como objetivo **receber** os valores de impostos já calculados pelo SIGAEIC. O sistema **não** deve recalcular os tributos, mas sim utilizar os **Operandos de Integração** para capturar os valores pronto.

Passos de Configuração do Perfil de Produto

* **Perfil de Operação:**
  + Acesse: Perfis → Perfil de Operação.
  + Cadastro preenchido automaticamente. Verifique qual tipo de operação será utilizado em seu processo.
  + ![4225baf2-97f7-471e-bd4c-080fdb2746f0.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/37705821652887)
