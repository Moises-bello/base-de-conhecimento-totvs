| **Sintoma** | **Como validar o perfil associado ao meu usuário?** |
| Solução | O usuário está associado a um determinado perfil, portanto é preciso saber qual o perfil do usuário:   1. Acesse o menu: Cadastros -> Segurança -> Usuários(Delphi) ou Menu de seleção de aplicações -> Serviços Globais -> Segurança -> Usuários(.Net) 2. Clique duas vezes no usuário em questão e vá até a aba Segurança 3. No quadro a direita, serão exibidos os perfis que possui cadastrado, o perfil do usuário estará marcado   Obs. O indicado é que o usuário esteja associado em um perfil apenas  Caso queira validar o acesso do perfil, acesse o link:  IMPORTANTE:  Toda vez que entrar no cadastro de Usuários e Perfis, verifique, logo acima do botao de Incluir se após "Sistema:" está descrito o sistema que deseja liberar / proibir acessos. |
