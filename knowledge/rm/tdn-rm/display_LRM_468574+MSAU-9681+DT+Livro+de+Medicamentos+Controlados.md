# Livro de Medicamentos Controlados

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Estoques |
| **Situação:** | Ao gerar o relatório do controle de medicamentos controlados, o sistema apresentava diferença entre o saldo final de um mês e o saldo inicial do próximo mês, quando o medicamento possuía mais de um lote cadastrado. |
| **Solução:** | Realizado ajuste no relatório de medicamentos controlados, para exibir corretamente o saldo, se um medicamento possui mais de um lote cadastrado. |
