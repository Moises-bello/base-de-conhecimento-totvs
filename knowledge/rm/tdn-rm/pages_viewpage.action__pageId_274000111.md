# Geração do Registro J150 Contas Analíticas

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Geração do Registro J150 Contas Analíticas na ECD |
| **Situação/Requisito:** | Ao gerar o Sped Contábil Layout 5.0, mesmo marcando a opção:  Não mostrar as contas analíticas na demonstração de resultado do exercício (Registro J150), que fica na etapa: Parametrização da DRE / Balanço Patrimonial.  O arquivo txt é gerado com algumas contas analíticas. |
| **Solução/Implementação:** | Ajuste na geração do registro para que contas analíticas não sejam geradas no registro J150 quando o parâmetro "Não mostrar as contas analíticas na demonstração de resultado do exercício (Registro J150)." for marcado. |
