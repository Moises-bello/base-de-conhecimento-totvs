**Dúvida**  
Como habilitar e realizar as requisições de transferência no Meu RH?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha RM) – Meu RH – A partir do release 12.1.2205 Patch 102  
  
**Solução**  
Primeiramente, o usuário que vai iniciar a requisição, precisa de estar cadastrando no RM como um Chefe ou Supervisor, ou papel de liderança na Hierarquia por Posição, após, conferir:

1. Liberar a permissão  **Requisições** > **Transferência** / **Alteração de dados Funcionais** no Perfil associado ao Chefe ou Supervisor:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/37503238042903)

 Acesso no Meu RH através do menu Gestor → Requisições → Transferência.

Para a linha RM existe a opção de 'Próxima etapa' onde irá apresentar as opções de etapas para o usuário selecionar, para as demais linhas será apresentado os botões de 'aprovar/reprovar'.

É importante lembrar que somente será possível avançar a etapa, quando a requisição for pendente e o gestor logado for responsável por ela.

**4. Movimentação das requisições de transferência:**

* É possível realizar a aprovação ou reprovação das requisições, esta opção poderá ser utilizada apenas para as requisições pendentes (em andamento) e que estejam na responsabilidade do gestor logado.
* Para a linha RM não será apresentada a opção de 'aprovar/reprovar' no lugar será disponibilizado a opção de 'Próxima etapa' onde irá apresentar as opções de etapas para o usuário selecionar (aprovar/reprovar/passar para o próximo chefe/ etc).
* É importante lembrar que somente será possível avançar a etapa, quando a requisição for pendente e o gestor logado for responsável por ela.
* Esta opções estão disponíveis tanto na tela principal quanto na tela de detalhes.

**7. Orientações específicas para a linha rm:**

* O menu só ficará visível para Gestores
* A visão de transferências no Meu RH irá englobar os dois tipos de requisições do ERP, são elas:

           - Transferência simples

           - Transferência com alteração de dados funcionais

* Para ter a permissão para visualizar a tela de requisições basta ir no ERP Serviços Globais → Perfis → Gestão de Pessoas.
* Neste Perfil as seguintes permissões devem ser habilitadas:

**12.01.02.01.01.05 Transferência:**deve ser habilitada para visualizar o card de transferência e as requisições simples que sejam pertinentes aquele usuário;

**12.01.02.01.01.05.01 Incluir:**deve ser habilitada para permitir incluir uma requisição simples;

**12.01.02.01.01.06 Incluir :**deve ser habilitada para permitir visualizar as requisições com alteração de dados funcionais que sejam pertinentes aquele usuário;

**12.01.02.01.01.06.01 Incluir :** deve ser habilitada para permitir incluir uma requisição com alteração de função;

* A solicitação de uma nova requisição de transferência terá uma flag chamada 'Alterar função' esta flag somente será visualizada pelos usuários que tiverem permissão de incluir uma requisição com alteração de dados funcionais;
* Link com mais informações sobre as requisições no ERP: [Requisição de transferência](https://tdn.engpro.totvs.com.br/pages/releaseview.action?pageId=452719426) - [Requisição de transferência com alteração de dados funcionais](https://tdn.engpro.totvs.com.br/pages/releaseview.action?pageId=452719580).

**Observação:**Os campos complementares para requisição de transferência, foram implementados a partir da versão **12.1.2510.138**. Para habilitar, é necessário apenas atualizar para esta versão ou superior que os campos serão apresentados na requisição.
