# Calcular dígito verificador de débito automático do Cliente/Fornecedor

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *TOTVS Gestão Financeira* |
| **Função:** | *Calcular dígito verificador de débito automático do Cliente/Fornecedor**.* |
| **Situação/Requisito:** | *Não se aplica.* |
| **Requisito (**ISSUE**):** | *FINANCEIRO01-1210* |

## Descrição

Inclusão do processo do cálculo do dígito verificador de débito automático do Cliente/Fornecedor no sistema.

## Procedimento para Utilização

O processo de cálculo do dígito verificador de débito automático do Cliente/Fornecedor, que era obrigatoriamente executado pelo Atualizador de Base de Dados, a partir da versão 12.1.18 passará a ser opcional podendo ser executado posteriormente no sistema, acessando o TOTVS Gestão Financeira o menu *Utilitários | Ajustes na Base | Calcular dígito verificador de débito automático do Cliente/Fornecedor.*
