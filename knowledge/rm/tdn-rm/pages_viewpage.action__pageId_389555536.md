# Alteração de Férias via Portal

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção & Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Gestão de Férias |
| **Situação/Requisito:** | É emitido uma mensagem de erro para qualquer alteração em dados relativo a férias; mesmo tais dados corretos. |
| **Solução/Implementação:** | Os dias de férias são a soma do saldo restante e o abono. Caso contrário, mostra-se uma mensagem de erro quando a esta condição não atendida. |
