![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24831111408279) Tempo aproximado para leitura: **00:10:00 min****Ocorrência**No módulo Financeiro, ao tentar realizar a geração do arquivo de remessa via CNAB FINA420, ocorre o **HELP BORNOXADO**  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/24831111409047)  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - a partir do release 12.1.2210  
  
**Causa**Este erro ocorre, pois o Borderô gerado, foi criado para uso do API FINA717

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24831111410199)  
  
**Solução**

Cancelar o Borderô e recriá-lo, evitando as opções acima, o título será enviado através do **FINA420 - Arquivo de pagamento.**
