# Senha no Toten de Pronto Atendimento em base Oracle

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Toten de Pronto Atendimento |
| **Situação:** | Ao realizar a chamada de senhas no toten de pronto atendimento em base Oracle®, o sistema emitia uma mensagem informando que a tabela ou a view não existe. |
| **Solução:** | Alterado o sistema em base Oracle®, para não apresentar a mensagem ao solicitar uma nova senha no toten de pronto atendimento. |
