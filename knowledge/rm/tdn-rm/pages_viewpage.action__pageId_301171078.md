# Ajuste no Formulário Atualização de Valores

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atualização de Valores |
| **Situação:** | Em Atualização de Valores, ao selecionar para atualizar os valores a partir de uma remessa, o sistema pedia que fosse preenchido as datas, que não estavam disponíveis no filtro de remessa. |
| **Solução:** | Realizada alteração no formulário de Atualização de Valores para que analise da forma correta a necessidade de preenchimento dos períodos. |
