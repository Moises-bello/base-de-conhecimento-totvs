# Descrição do processo

Possibilita que algumas informações do cadastro de Certificado/Diploma seja alterada simultaneamente para mais de um registro.

## Aba - Identificação

* Data do certificado.
* Carga horária.

## Aba - Registro no livro

* Data de conclusão.
* Data conferência.
* Data de emissão.
* Data de registro.

O campo **data de registro** ficará disponível para alteração somente se no perfil do usuário em Anexos/Parâmetros Educacionais a opção "Permitir alterar o campo Data de Registro do Registro no Livro do Certificado" estiver marcada. 

# Mudanças a partir da versão 12.1.32

A partir da versão 12.1.32 este processo passa a chamar **Atualização de dados do Certificado** e terá os mesmos campos para atualização porém em apenas uma aba conforme é exibido abaixo.

Nenhuma regra dos campos exibidos foi alterada.
