**Dúvida**Descontinuidade nos relatórios em formato Release 3 (não personalizável)?

**Ambiente**Protheus – Financeiro – A partir da versão 12

**Solução**A geração dos relatórios passa a ocorrer somente no formato personalizável **(Release 4)**, conforme comunicado expedido no link: http://tdn.totvs.com/pages/releaseview.action?pageId=309035095

Segue lista dos relatórios em que o formato *Release* 3 foi descontinuado:

**FINR130** - Títulos a receber - Data de homologação: 30/10/17;

**FINR133** - Razonete de cliente (Aging) - Data de homologação: 27/10/17;

**FINR350** - Posição dos Fornecedores - Data de homologação: 24/11/2017 ;

**FINR170** - Emissão de Borderô - Data de homologação: 27/11/2017;

**FINR190** - Relação de Baixas - Data de homologação: 23/11/17;

**FINR850** - Retorno SISPAG - Data de homologação: 29/11/2017;

**FINR830** - Histórico aplicação - Data de homologação: 04/12/17;

**FINR470** - Extrato bancário - Data de homologação: 08/12/17;

**FINR550** - Razonete de contas correntes de Cliente/Fornecedor - Data de homologação: 08/12/17;

**FINR530** - Movimentos Financeiros Diário - Data de homologação: 13/12/17;

**FINR720** - Orçado x Realizado - Data de homologação: 12/12/17;

 Observações: O parâmetro **MV\_TREPORT**não terá mais efeito para os relatórios acima. Independentemente de seu conteúdo, o sistema exibirá sempre a tela de impressão do relatório personalizável.
