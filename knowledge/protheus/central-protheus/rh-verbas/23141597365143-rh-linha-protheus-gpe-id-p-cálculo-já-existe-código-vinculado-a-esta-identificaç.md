![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/23141549791255) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Ao tentar cadastrar uma verba é apresentada a mensagem: ID p/ Cálculo - Já existe código vinculado a esta identificação de cálculo  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/23141549792407)

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Causa**Já existe uma outra verba com o ID de cálculo atrelado.  
  
**Solução**O sistema não permite que o **mesmo ID de calculo** seja vinculado em mais de uma verba, nesse caso o ideal é verificar se o ID já não está atrelado a uma verba com uma das opções abaixo:

1- Buscar o código do id na barra de pesquisa  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/32740911932567)

No exemplo, foi realizado a busca do id 0088, que **já existe no cadastro de verbas**  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/32740895377687)  
  
  
2- Extraindo o relatório com o cadastro de todas verbas
