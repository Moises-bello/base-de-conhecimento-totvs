# Objetivo:

---

       Este documento tem como objetivo demonstrar o uso do controle Caixa de Imagem.

# Introdução:

---

       Arraste o item Caixa de Imagem da Barra de Controles para o seu relatório para adicionar o controle.

       O controle pode ser usado para incorporar imagens *estáticas* (armazenadas com a definição de relatório) ou *dinâmicas* (obtidas de uma fonte de dados) em um relatório. As imagens podem ter um dos seguintes formatos: BMP, JPG, JPEG, GIF, TIF, TIFF, PNG, ICO, DIB, RLE, JPE, JFIF, EMF, WMF, SVG.

# Propriedades:

---

1Fonte da Imagem

Na primeira propriedade de Fonte da Imagem, clique nas reticências para abrir a tela de seleção de imagem do computador.

Na segunda propriedade exibida, clique nas reticências para que seja aberto o Editor de Expressão, onde é possível obter uma imagem de uma fonte de dados. Use este editor para construir uma expressão de ligação que possa incluir dois ou mais campos de dados.

2URL de Imagem

Na primeira propriedade URL de Imagem, especifique o caminho completo para a imagem, que será imediatamente exibida no controle.

Use a segunda propriedade exibida para abrir o Editor de Expressão e construir uma expressão de ligação que possa incluir dois ou mais campos de dados.

3Ajuste de Tamanho

Clique na caixa para exibir as opções para o ajuste de tamanho. Defina a propriedade como um dos modos disponíveis para especificar como posicionar uma imagem dentro do controle.

**Normal:** A imagem é exibida com suas dimensões originais.

**Extender Imagem:** A imagem é esticada para preencher a largura e a altura do controle.

**Tamanho Automático:** As dimensões do controle são ajustadas automaticamente para o tamanho da imagem.

**Centralizar Imagem:**A imagem será exibida no meio do controle.

**Aumentar Imagem:** A imagem é redimensionada proporcionalmente, para que ela se ajuste ao controle.

**Comprimir:** Se as dimensões do controle excederem o tamanho da imagem, a imagem será centralizada e mostrada em tamanho real. Caso contrário, a imagem é redimensionada para caber nas dimensões do controle.  
**Telha:** A imagem original é replicada no controle, começando no canto superior esquerdo. A imagem replicada é cortada se não couber no controle de imagem que a contem.
