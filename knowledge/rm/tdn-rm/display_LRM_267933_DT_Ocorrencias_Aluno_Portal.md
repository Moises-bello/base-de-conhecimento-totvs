# OCORRÊNCIAS PARA ALUNOS NO PORTAL

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Ocorrências para alunos no portal* |
| **Situação/Requisito:** | *Quando o professor que está realizando o registro de ocorrência no portal e o mesmo possui a situação Demitido, porém ele ainda está dentro do prazo de acesso ao portal na parametrização do sistema, ao salvar a ocorrência é ocorre erro de chave ou é feito o registro como se fosse outro professor.* |
| **Solução/Implementação:** | *Ajuste no portal para que ao salvar uma ocorrência no portal com o professor demitido e dentro prazo de acesso ao portal após demissão, para que seja feito o registro da mesma de forma correta.* |
