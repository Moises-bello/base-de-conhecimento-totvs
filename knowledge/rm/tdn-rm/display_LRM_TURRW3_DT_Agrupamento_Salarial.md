# Agrupamento Salarial

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Agrupamento Salarial* |
| **Situação/Requisito:** | Ao acessar no Labore Folha Educacional>Agrupamento Salarial>Classis Net com o parâmetro do Período Letivo do Classis Período Letivo Encerrado marcado, nenhum agrupamento salarial é demonstrado.  Porém, ao desmarcar o parâmetro Período Letivo Encerrado do Classis, o agrupamento salarial é corretamente demonstrado no Labore.  Entendemos que o parâmetro Período Letivo Encerrado encerra o Período, mas não as movimentações de Folha para o Professor. |
| **Solução/Implementação:** | Otimizado filtro para tela de agrupamento salarial, de forma que o Labore passe a considerar apenas o parâmetro  de Período letivo Encerrado para pagamento presente no produto classis |
