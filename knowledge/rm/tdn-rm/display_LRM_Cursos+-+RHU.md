**Cursos**

Este cadastro guarda informações relativas a cursos ministrados por entidades, como dados sobre carga horária e conteúdo programático, para que o usuário possa gerenciar a aplicação de treinamentos. O cadastro de cursos é fundamental, ao cadastrar uma turma será necessário associá-la a um curso.

Flag ' curso eSocial ' - marcando este flag as turmas que possuírem o curso, terão as informações levadas para o eSocial conforme parametrização do RM Labore.

**Atenção**

Para qualquer ícone desabilitado, verifique com o Supervisor as permissões do usuário em questão em Cadastros | Segurança | Perfis | pasta Acesso a Menus.
