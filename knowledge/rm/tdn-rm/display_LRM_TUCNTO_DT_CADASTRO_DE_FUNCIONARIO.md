# CADASTRO DE FUNCIONÁRIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cadastro de Funcionário* |
| **Situação/Requisito:** | Definindo um valor default para o campo de seção, ao abrir a tela de funcionários para inserção de um novo o campo seção é preenchido mas o campo de filial não é, forçando o usuário a selecionar a seção novamente. |
| **Solução/Implementação:** | *Ao abrir a tela de cadastro de funcionários é verificada a existência de um valor default para o código de seção e é preenchido o campo da Filial* |
| **Chamados relacionados:** | TUCNTO, TUDJ65 |
