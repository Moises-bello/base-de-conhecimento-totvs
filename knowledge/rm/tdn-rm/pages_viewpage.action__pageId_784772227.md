Para que seja possível [enviar documentação na matrícula](https://tdn.totvs.com/x/EREMKg), a instituição deve marcar o parâmetro "Permite o envio de documentos na matrícula" nas parametrizações da área de interesse ofertada:

* **TOTVS Educacional Processo Seletivo| Cadastros| Área de interesse Ofertada| Aba Matrícula**

Em seguida efetuar o cadastro dos documentos que serão exigidos na etapa de Envio de arquivos da matrícula do candidato.

 Caminho de acesso para efetuar a parametrização dos Documentos exigidos:

* **TOTVS Educacional | Currículo e Oferta | Oferta | Parametrização por curso**

Através da Flag **"Indica se o Documento é obrigatório"** podemos determinar a obrigatoriedade do documento. É importante lembrar que ao usar este parâmetro só será permitido prosseguir com o processo de matrícula, se o mesmo estiver devidamente anexado.

**Enviando os documentos**

Neste passo devemos anexar os arquivos solicitados

Importante

O tamanho máximo permitido para o nome do arquivo é de 100 caracteres.

Após clicar no botão **Selecionar arquivo** escolha o arquivo que será anexado.

Os arquivos que possuem o asteriscos em vermelho são os documentos que obrigatoriamente deveram ser anexados.

 Após clicar em **Próximo** ou **Salvar e continuar depois**o sistema irá gravar os arquivos que foram anexados nos arquivos do candidato, para que, caso o candidato não finalize a matrícula naquele momento e voltar um outro dia, os documentos já enviados, serão exibidos para o mesmo, não necessitando um segundo envio. Ao prosseguir com a matrícula os mesmos estarão disponibilizados para download se for necessário.

Para que os arquivos sejam salvos com sucesso nesse primeiro momento, deve ser configurado nos parâmetros do processo seletivo aba "Arquivos".

o botão **Limpar arquivo** permite apagar o arquivo anexado.

Após anexar os arquivos corretamente clique no botão **Próximo** para dar continuidade na matrícula.

Para que os documentos sejam salvos corretamente no cadastro do aluno, deve ser parametrizado o armazenamento de arquivos nos parâmetros educacionais.

* **TOTVS Educacional | Configurações| Parâmetros| Secretaria| Geral 6/7**

Filtro de documentos por sexo

A partir das versões 12.1.33.114 e superiores, foi disponibilizado uma evolução na entrega de documentos na matrícula via central do candidato, de maneira a [filtrar os documentos por sexo (Todos, Feminino ou Masculino).](https://tdn.totvs.com/display/LRM/Documentos+Exigidos+do+Aluno)

Na parametrização dos documentos exigidos, o sistema permite definir se o documento é exigido para o **sexo "Masculino", "Feminino" ou "Todos"** que faz com que o documento seja exigido independente do sexo do candidato.

 Caminho de acesso para efetuar a parametrização dos Documentos exigidos:

* **TOTVS Educacional | Currículo e Oferta | Oferta | Parametrização por curso**

* **FILTRO POR SEXO MASCULINO**

Desta forma, caso o candidato ao realizar o processo de Matrícula via Central do Candidato informar o campo "Sexo" como Masculino na aba "Dados cadastrais".

Ao avançar na matrícula, o sistema exibirá para ser enviado apenas os documentos parametrizados como  "Todos" e de sexo "Masculino".

* **FILTRO POR SEXO FEMININO**

De maneira semelhante, caso o candidato ao realizar o processo de Matrícula via Central do Candidato informar o campo "Sexo" como "Feminino" na aba "Dados cadastrais".

Ao avançar na matrícula, o sistema exibirá para ser enviado apenas os documentos parametrizados como  "Todos" e de sexo "Feminino".
