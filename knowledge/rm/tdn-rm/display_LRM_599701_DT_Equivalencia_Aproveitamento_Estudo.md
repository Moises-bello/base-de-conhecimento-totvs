# EQUIVALÊNCIA DE DISCIPLINA APROVADA PELO APROVEITAMENTO DE ESTUDOS.

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Análise curricular |
| **Situação/Requisito:** | Quando no curso do aluno uma disciplina X era equivalente a duas disciplinas da grade (A e B), se o aluno tiver sido dispensado da disciplina A via aproveitamento de estudos e se matriculasse na disciplina X uma vez que ela é equivalente a B, o sistema mudava a situação das disciplinas A e B para em curso por equivalência da disciplina X. |
| **Solução/Implementação:** | Ajustar para que quando a disciplina estiver concluída via aproveitamento de estudos e o aluno se matricular em uma disciplina equivalente o sistema mantenha a situação de matricula aprovada via aproveitamento de estudos. |
