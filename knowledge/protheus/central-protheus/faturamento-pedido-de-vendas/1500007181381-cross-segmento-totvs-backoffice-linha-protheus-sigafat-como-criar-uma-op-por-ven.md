**Dúvida**Como criar uma OP por Venda  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - A partir da versão 12.1.25  
  
**Solução**  
Abaixo um passo a passo prático para a operação1) Criar um Produto PA e outro MP;  
2) Criar estrutura (**MATA200**);  
3) Incluir um Pedido de Vendas com o PA;  
4) Incluir uma OP por Vendas , mais detalhes, segue a documentação abaixo:  
**[MP - SIGAEST - Como incluir uma Ordem de Produção para uma venda?](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024912671-MP-SIGAEST-Como-incluir-uma-Ordem-de-Produ%C3%A7%C3%A3o-para-uma-venda-?source=search)**  
  
Neste momento avalie o campo C6\_NUMOP. Ele estará com o número da OP gravada
