# INSCRIÇÃO DO CANDIDATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Processo Seletivo |
| **Função:** | Inscrição do candidato |
| **Situação/Requisito:** | No cadastro de inscrição do candidato, os campos complementares ficam desabilitados após o término do período de inscrição. |
| **Solução/Implementação:** | Foi implementada no processo seletivo a disponibilização dos campos complementares da inscrição independentemente de sua etapa ou datas do calendário de inscrição. Foi ajustado, também, a disponibilidade dos campos de deficiência do candidato, para alteração, independentemente de sua situação de classificação e do encerramento das inscrições no processo seletivo. |
