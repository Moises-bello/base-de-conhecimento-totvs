# UTILIZAR O NOME SOCIAL EM TODAS AS OPÇÕES DE NUMERAÇÃO DOS ALUNOS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Numeração |
| **Situação/Requisito:** | Existe apenas uma opção de numeração por nome social. Deve ser possível utilizar o nome social em todas as opções de numeração. |
| **Solução/Implementação:** | A rotina de numeração foi alterada para permitir a utilização do nome social em todas as opções disponíveis.  Foi incluído o parâmetro "Utilizar nome social no lugar do nome civil" e ao marcá-lo a opção de numeração escolhida utilizará o nome social no lugar do nome civil. |
