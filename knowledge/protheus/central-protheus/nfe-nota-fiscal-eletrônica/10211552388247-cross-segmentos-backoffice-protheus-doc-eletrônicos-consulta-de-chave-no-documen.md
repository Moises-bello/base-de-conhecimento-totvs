Acesse o TSSINTERFACE pelo smartcllient do TSS:

Caso tenha dúvidas de como acessar as interfaces gráficas do TSS:

[MP - TSS - Como acessar as interfaces gráficas do TSS](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360049308093-MP-TSS-Como-acessar-as-interfaces-gr%C3%A1ficas-do-TSS)

**Importante**: É necessario criar um usuario para utilização e vincular ao CNPJ da filial, o usuario ADMIN não possui acesso as rotinas.  
  
[Como criar um usuario para o TSSInterface](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360052410314-Cross-Segmentos-TSS-Transmiss%C3%A3o-de-Documentos-Eletr%C3%B4nicos-Como-criar-um-usu%C3%A1rio-para-acesso-no-TSSMONITOR)

**![](https://tdn.totvs.com/download/attachments/697696968/image2022-7-7_11-11-37.png?version=1&modificationDate=1657203103130&api=v2)**

Acesse Configurações>Entidades>Outras Ações> Configurar

**![](https://tdn.totvs.com/download/attachments/697696968/image2022-7-7_9-44-13.png?version=1&modificationDate=1657198356073&api=v2)**

**Acesse a aba Fiscal>NF3-e**

**![](https://tdn.totvs.com/download/attachments/697696968/image2022-7-7_9-45-33.png?version=1&modificationDate=1657198355880&api=v2)**

Selecione os valores de acordo com o seu ambiente e clique em *"Confirmar"* para salvar as alterações efetuadas.

**Obs: Para consultar um chave que foi autorizada em produção o campo "ambiente " deve estar como Produção.**
