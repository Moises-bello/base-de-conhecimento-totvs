**Esquema de Repasse**   
Nesta janela você define o esquema de repasse de atendimento para o grupo de atendente.   
   
A grade permite visualizar os seguintes dados:  
Tipo de atendente  
Selecione o tipo de atendente selecionado na tela de edição.   
 Tipo de Repasse  
Exibe o tipo de repasse selecionado na tela de edição.   
Os tipos de repasse são:  
Para um atendente fixo do grupo  
Por um rodízio entre os atendentes do grupo  
Para o atendente do grupo com o menor número de atendimentos  
Ao selecionar o tipo de repasse Para um atendente fixo do grupo, será necessário informar o Atendente que receberá as ocorrências.
