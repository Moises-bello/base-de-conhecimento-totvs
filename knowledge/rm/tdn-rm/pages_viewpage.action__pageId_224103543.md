# Diária do Classe do Professor no Portal Educacional

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *TOTVS EDUCACIONAL* |
| **Módulo:** | *Educacional* |
| **Função:** | **Diário de Classe** |
| **Situação/Requisito:** | *Permissão dos itens relacionados ao Diário de Classe do Portal Educacional.* |
| **Solução/Implementação:** | *Foi alterado a nomenclatura do item de permissão "Minhas Turmas" existente nas permissões de um Perfil do RM, localizado em "Educacional > Outras Permissões > RM Portal > Professor" para "Aluno", conforme o nome da funcionalidade que é exibido dentro menu Diário de Classe no grupo Professor, do Portal Educacional.*  *Com o intuito de tornar coerente a organização da exibição da lista de itens para permissões, na edição do Perfil do RM foi criado uma nova árvore para o item Diário de Classe, e colocado todos os outros itens relacionados abaixo desta permissão, sendo que somente será possível acessar as demais funcionalidades caso o professor já possua permissão em Diário de Classe.*  *Os itens de permissão incluídos abaixo do item de Diário de Classe foram:*   * *Cadastro de Avaliações* * *Alunos (anteriormente Minhas Turmas)* * *Frequência Diária* * *Notas de avaliações* * *Notas de etapa* * *Cadastro de Ocorrências* * *Plano de Aula*     *Todos estes itens estão disponíveis no Portal Educacional do Professor dentro do menu Diário de Classe, conforme imagem abaixo:*    *Somente foi alterado a localização e organização da listagem de itens para permissão. Não afetando as permissões já definidas anteriormente.* |
