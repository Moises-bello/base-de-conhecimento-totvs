| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Totvs Gestão Fiscal |
| **Função:** | Envio de NF-e |
| **Situação/Requisito:** | * A tag vTroco deverá ser gerada somente quando o parâmetro "Edita troco" estiver habilitado no Tipo de Movimento. * No layout Sefaz, quando são informados mais de um meio de pagamento, o sistema está gerando o grupo <pag> mais de uma vez ocasionando erro de validação do schema. |
| **Solução/Implementação:** | Realizado os ajustes no grupo de pagamento conforme solicitado. |
