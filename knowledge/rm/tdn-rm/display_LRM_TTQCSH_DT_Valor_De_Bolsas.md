# BOLSA RETROATIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Incluir Bolsa Retroativa* |
| **Situação/Requisito:** | *Ao inserir bolsas classificadas como somar bolsas, sem definir a ordem da aplicação da bolsa, tanto para o contrato quando para a classificação, ocorre comportamentos distintos, se a bolsa for incluída de forma convencional ou se for incluída através do processo de bolsa retroativa. O processo de bolsa retroativa atribui ordem zero caso não seja informada ordem e por isso, pode ocorrer diferenças no cálculo para essa situação específica.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de bolsa retroativa, para que o sistema não tenha uma ordem padrão de aplicação de bolsa, evitando assim, um comportamento distinto da aplicação convencional de bolsas no contrato dos alunos.* |
