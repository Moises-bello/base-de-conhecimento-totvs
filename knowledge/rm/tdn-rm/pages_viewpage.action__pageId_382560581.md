# Importação de Antibiótico

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Controle de Infecção Hospitalar |
| **Função:** | Importação de Antibiótico |
| **Situação:** | Quando a View de integração trouxer o antibiótico já classificado como 'Terapêutico' (caso do print em anexo) o importador não deve pré-classificar estes antibióticos como profiláticos. |
| **Solução:** | Ao importar o antibiótico do tipo terapêutico não realiza sua classificação como profilático |
