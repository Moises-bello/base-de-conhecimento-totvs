# Erro ao vincular recurso ao procedimento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro> Cirurgias> Procedimentos para Agenda de Cirurgias |
| **Situação:** | Sistema estava duplicando os recursos adicionados no cadastro dos procedimentos utilizados na agenda cirúrgica. |
| **Solução:** | Problema estava ocorrendo porque o sistema não estava respeitando a coligada que estava logada, foi adicionado um novo filtro. |
