# Data limite para digitação de Frequência Diária

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Frequência Diária |
| **Situação/Requisito:** | Ao selecionar uma Etapa para a digitação de Frequência Diária por um professor, no Corpore.NET, o calendário para a seleção da data inicial e final não eram atualizados conforme o período da etapa selecionada. |
| **Solução/Implementação:** | Foi ajustado a atualização do período de datas habilitados para a seleção, de acordo com a etapa selecionada pelo professor. |
