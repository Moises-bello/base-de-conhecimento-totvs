Dúvida**Como alterar uma data de aumento salarial que foi cadastrada de forma errada?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Se foi inserida uma data de aumento de forma incorreta no Cadastro de Funcionário, é possível a alteração da mesma utilizando a rotina **Atualizações -> Funcionários -> Histórico Salarial** (GPEA250).  
  
Exemplo:   
  
Foi cadastrado um dissídio para o funcionário no dia 01/11/2020, mas de forma incorreta, pois a data correta seria 01/12/2020.  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000143521)  
  
Com isso, os registros são gravados com a data de 01/11 nas tabelas SR3 e SR7. No entanto, é possível alterar essa data diretamente na rotina, no quadro superior.

**1.** Para isso, clique no campo 'Data' e edite conforme necessário.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360101238593)  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360101238613)  
  
Note que a data também foi atualizada no quadro inferior.

**2.** Agora, basta salvar para que a alteração seja efetivada
