# EDUCACENSO NO NÍVEL DE ENSINO SUPERIOR

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | ************Educacional************ |
| **Módulo:** | ***********Totvs Gestão Educacional*********** |
| **Função:** | *Censo da Educação Básica - Educacenso* |
| **Situação/Requisito:** | ***A tela de Dados do Censo do Curso/Habilitação* está mostrando os campos referentes ao Censo da Educação Superior, mesmo quando o nível de ensino é Superior e a opção "Usa Educacenso" está marcada.** |
| **Solução/Implementação:** | **A tela de Dados do Censo do Curso/Habilitação* foi alterada para não mostrar os campos referentes ao Censo da Educação Superior, quando o nível de ensino for Superior e a opção "Usa Educacenso" estiver marcada.* |
