# AGENDAMENTO / ENVIO DE MENSAGENS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Central de Notificações |
| **Função:** | Agendamento/envio de Mensagens |
| **Situação/Requisito:** | Ao enviar uma mensagem para o aluno, a mensagem é exibida com o nome  do RESPONSAVEL DO ALUNO e não o do próprio aluno como descreve a TAG utilizada. |
| **Solução/Implementação:** | Aperfeiçoada a resolução da tag "NOMEALUNO" para o envio das mensagens do eduCONNECT,  onde antes enviava o nome dos respectivos pais e responsáveis acadêmico e financeiro, quando  o público-alvo fosse parametrizado para estes. Neste caso, apenas o aluno deverá receber a  mensagem, ou seja, a tag resolve apenas o nome do aluno. |
