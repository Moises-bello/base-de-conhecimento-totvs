**Dúvida**Como exportar arquivo XML do funcionário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da versão 11.80  
  
**Solução**Para exportar o arquivo XML e enviar ao suporte, siga os passos abaixo:

1. Antes de exportar o arquivo XML avalie se o período que está definido como ativo, é o mesmo que compreenda o dia (data) em que a inconsistência ocorre. Para avaliar acesse o modulo **Automação de Ponto** o menu, **Configurações |** **Períodos**.  **![](https://centraldeatendimento.totvs.com/hc/article_attachments/13846584468887)**Caso não seja, é necessário definir o período em que a inconsistência ocorre, como ativo. Conforme as orientaçoes do link abaixo:  
     
   [RH - RM - PTO - Como definir período anterior como ativo (Trocar de Período)](https://centraldeatendimento.totvs.com/hc/pt-br/articles/360024507332-TOTVS-RH-Linha-RM-PTO-Como-definir-per%C3%ADodo-anterior-como-ativo-Trocar-de-Per%C3%ADodo-)
2. Acesse o menu **Processos** | **Importação e Exportação de Dados em XML**.   
     
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/13846685685911)
3. Selecione a opção **Exportar** e insira a chapa desejada. Execute o processo e salve o arquivo em alguma pasta de seu sistema.  
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/13846756822807)
4. Após isso, será aberta a janela para salvar o arquivo. A salve em lugar de fácil acesse o nos envie através do ticket.    
   ![](https://centraldeatendimento.totvs.com/hc/article_attachments/13846801554071)
