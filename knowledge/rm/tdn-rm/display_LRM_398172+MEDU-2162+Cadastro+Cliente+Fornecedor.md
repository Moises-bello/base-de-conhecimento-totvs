# Cadastro Cliente Fornecedor

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | Gestão Financeira. |
| **Função:** | Cliente Fornecedor |
| **Situação/Requisito:** | O perfil associado ao usuário está sem acesso a todos os campos referente ao endereço de pagamento do Cliente/Fornecedor. Todos os campos estão com a opção 'Pode Alterar' desmarcada. No cadastro de cliente/fornecedor, tais campos realmente estão desabilitados para alteração quando o usuário acessa a aba Endereço > Pagamento. Porém, se alterar a informação no endereço principal e clicar na opção ‘Realiza a cópia do Endereço Principal para o Endereço de Pagamento’ a alteração é feita nos dados do endereço de pagamento. |
| **Solução/Implementação:** | Melhoria no cadastro de cliente fornecedor, ao realizar a cópia do endereço principal para o endereço de entrega ou de pagamento, somente os campos que o usuário tem permissão de alteração serão copiados. |
