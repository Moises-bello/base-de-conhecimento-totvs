# Importação de Verbas Geradas por Diferença

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Importação de Dados do RM Labore |
| **Situação/Requisito:** | Alguns clientes vindos de outros sistemas ou por algum motivo específico acabam importando a movimentação do funcionário, sendo preenchido neste caso apenas a Ficha Financeira pois atualmente não existe a possibilidade de importação das 'Verbas geradas por diferença'. Contudo, o eSocial utiliza as informações da tabela correspondente as verbas de diferença (PFVERBASDIS) para preenchimento de determinadas TAGS, como é o caso da InfoPerAnt, responsável por informar os dados de diferença salarial.  A sugestão então é que o sistema permita a importação das 'verbas geradas por diferença'. |
| **Solução/Implementação:** | Criada a nova funcionalidade: Importação de Verbas de Dissídio em Configurações | Importações | Importações de Dados do RM Labore, aba Funcionários II |
