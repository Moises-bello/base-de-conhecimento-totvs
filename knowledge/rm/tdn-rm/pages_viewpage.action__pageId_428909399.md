# MELHORIA MENSAGEM VALIDAÇÃO CRIAÇÃO RESPONSÁVEL FINANCEIRO - MATRÍCULA PROCESSO SELETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Matrícula - Processo Seletivo* |
| **Situação/Requisito:** | Ao matricular um candidato aprovado em um processo seletivo e selecionar para aproveitar o responsável financeiro do candidato, o sistema apresenta uma mensagem informando que o CPF já está cadastrado. |
| **Solução/Implementação:** | Foi realizado um ajuste na mensagem de validação para que facilite a identificação do problema. O problema em questão ocorreu devido a um problema no cadastro, mas a mensagem não deixava claro em qual cadastro se poderia realizar o acerto. |
