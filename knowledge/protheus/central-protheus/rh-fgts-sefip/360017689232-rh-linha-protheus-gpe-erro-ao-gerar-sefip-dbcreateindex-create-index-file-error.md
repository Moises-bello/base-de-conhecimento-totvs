Dúvida**Como corrigir o erro "Erro ao Gerar SEFIP - *DBCreateIndex* - *Create index file error* - sfp1.idx  *on GERAINS*" gerado na SEFIP?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Dentro da pasta ***System*** do Protheus, localizar o arquivo SFP1.IDX e renomea-lo para SFP1.OLD  
2.  Limpar os arquivos temporários do *Windows*. Para isso, digite **%*temp*%** na pesquisa do *Windows*. Faça uma cópia desta pasta e exclua os arquivos contidos nela.
