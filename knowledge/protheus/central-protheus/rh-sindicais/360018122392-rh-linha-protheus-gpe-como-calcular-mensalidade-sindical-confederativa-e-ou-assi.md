**Dúvida**Como parametrizar o cálculo de mensalidade sindical, Confederativa e/ou Assistencial?

**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal -  A partir da versão 11.80  
  
**Solução**Para calcular a Mensalidade Sindical, Confederativa e/ou Assistencial, faça a manutenção no cadastro de sindicatos conforme passos abaixo:

* Acesse em **Atualizações > Cadastros > Sindicatos (GPEA340)**
* Verifique as abas correspondentes a contribuição sindical desejada (Assistencial, Confederativa e Mensalidade Sindical) para preenchimento conforme necessidade:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824744389527)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707662231)

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707666455)

Verifique se no cadastro do funcionário, consta a informação indicando o sindicato devidamente parametrizado;

* Acesse **Atualizações > Funcionários > Funcionários (GPEA010)**;
* Verifique a Aba Funcionais, informe o sindicato desejado e informe SIM para Mensalidade Sindical, Confederativa e/ou Assistencial (de acordo com a contribuição a ser calculada):

![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707668247)

Verifique se a verbas Mensalidade Sindical, Confederativa e Assistencial possuem ID de cálculo informados corretamente:

* **Atualizações >Cadastros >Verbas (GPEA040)**;
* Verifique se consta para Mensalidade Sindical o id 0720;![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707671831)
* Verifique se consta para Confederativa o id 0175;![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707677719)
* Verifique se consta para Assistencial o id 0069;![](https://centraldeatendimento.totvs.com/hc/article_attachments/24824707680535)
