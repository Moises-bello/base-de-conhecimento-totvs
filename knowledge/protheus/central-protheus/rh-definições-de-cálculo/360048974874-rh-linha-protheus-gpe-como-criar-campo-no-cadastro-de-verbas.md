**Dúvida**  
Como criar campo no cadastro de verbas?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - A partir da versão 12.1.17  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:  
  
1. Acesse o **Configurador**com senha de Administrador em modo exclusivo (sem usuários utilizando o ambiente) através do menu **Base de Dados > Dicionário > Base de Dados**.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614845749399)

2. Clique na **Empresa** para **expandir** as opções. Selecione **Dicionário de Dados** e clique na lupa para busca da tabela;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614852754071)

3. Busque pela tabela **SRV,** selecione a opção e clique em editar;

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614852757655)  
  
  
4. Clique em **Verbas** para expandir as opções, selecione a opção **Campos** e clique no ícone de folha com + para incluri um novo campo.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614852766743)

5. Configure o campo conforme desejado e clique em **salvar.**

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614845774999)

6. Clique no ícone do disquete para que o sistema atualize o dicionário de dados com o novo campo criado.

![](https://centraldeatendimento.totvs.com/hc/article_attachments/26614845781655)
