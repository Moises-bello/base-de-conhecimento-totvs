O acesso ao App Meu Coletor de Dados via navegador não está disponível para clientes, sendo obrigatório o uso em dispositivos físicos compatíveis. A simulação no browser é restrita ao time técnico da TOTVS para validação e desenvolvimento, não fazendo parte do escopo funcional do produto nem tendo suporte oficial. Recomenda-se usar o app em dispositivos homologados para uma experiência completa.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33291603611543) Tempo aproximado para leitura: **00:02:00 min**

**Dúvida**  
É possível acessar o App Meu Coletor de Dados via browser do computador, para teste interno com a validação do app, sem possuir o coletor de dados com o app instalado?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.   
  
**Solução**  
Atualmente, **o acesso ao App Meu Coletor de Dados via navegador de internet (browser)** não está disponível como funcionalidade para o cliente.

**EXEMPLO:**

![dadada.png](https://centraldeatendimento.totvs.com/hc/article_attachments/33291890155159)  
  
A execução e o uso do aplicativo requerem, obrigatoriamente, a instalação em um dispositivo físico compatível (como coletor de dados ou smartphone Android), em conformidade com os critérios de licenciamento e funcionamento previstos para o produto.   
  
Em algumas situações específicas, **vídeos internos de testes, treinamentos técnicos e webinars da TOTVS** podem demonstrar o uso do aplicativo em ambiente de browser. No entanto, é importante esclarecer que esse recurso **é restrito ao time técnico da TOTVS**, utilizado exclusivamente para fins de validação, homologação e desenvolvimento de melhorias no processo de automação.   
  
Reforçamos que **essa simulação via browser não faz parte do escopo funcional do produto disponibilizado aos clientes**, sendo assim, não é prevista documentação oficial ou suporte para esse tipo de utilização por meio de browser.  
  
Para uma experiência completa e homologada, recomenda-se sempre o uso do app em dispositivos homologados e dentro dos padrões definidos pela TOTVS para automação com o Meu Coletor de Dados.
