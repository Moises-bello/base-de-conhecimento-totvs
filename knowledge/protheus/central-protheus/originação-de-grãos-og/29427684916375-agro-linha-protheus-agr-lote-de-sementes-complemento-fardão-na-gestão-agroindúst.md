Como funciona uma estrutura **Lote de Sementes - Complemento Fardão na Gestão Agroindústria - Manutenção**?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**  
Para solucionar essa dúvida, realize os seguintes passos:

**1.** Veja na tabela os **Dados Gerais**;

| Produto: | Totvs Agro Beneficiamento |
| --- | --- |

| Linha de Produto: | Microsiga Protheus |
| Segmento: | Agroindústria |
| Módulo: | SIGAAGR |
| Função: | AGRA610-Complemento de Fardão  AGRA840-Lote de Sementes |
| Ticket: |  |
| Requisito/Story/Issue (informe o requisito relacionado) : | DAGROINDUSTRIA-7916 |

  

**2.** **S****ituação/Requisito**;  
Na rotina **Lote de Sementes**, quando a estrutura do produto é diferente de **1** a sugestão da quantidade do grid **Lotes X Saldo** não está correta.   
Na rotina **Complemento de Fardão**, ao realizar o complemento físico selecionando complementos negativos e positivos;

**3.** **Solução**.  
Realizado ajuste na rotina **Lote de Sementes** para sugerir a quantidade dos lotes corretamente. **Realizado** ajuste na rotina **Complemento de Fardão** para permitir o complemento físico de fardões negativos quando o **"Total Compl Fis."** for positivo.
