![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18495684469783) Tempo aproximado para leitura: **02:00 min****Dúvida**O SIGAEIC possui campo para informar o código da retenção para gerar a DIRF?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  –*Easy Import Control*– A partir da versão 12.1.33.  
  
**Solução**Não há um campo próprio no **SIGAEIC**, o código da retenção deve ser informado manualmente no momento que é aberta a tela do contas a pagar, ao fazer a prestação de contas, ou tratar via Ponto de Entrada.
