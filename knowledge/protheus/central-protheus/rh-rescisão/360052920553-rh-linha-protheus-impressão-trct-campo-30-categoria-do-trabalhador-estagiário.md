**Tempo aproximado para leitura: 00:01:30 min**

**Dúvida**É possível imprimir no campo 30-Categoria do Trabalhador no TRCT a categoria Estagiário?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - Todas as versões.  
  
**Solução**O Ministério do Trabalho não prevê uma categoria para o estagiário, apenas as categorias abaixo estão previstas no layout disponibilizado pelo Ministério do Trabalho para impressão no campo 30 do TRCT:  
  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360085093793)  
  
O sistema busca essa informação do cadastro de funcionários, se for da necessidade de alterar o TRCT, seguem instruções:  
  
Atualizações>Funcionários>Funcionários>Aba Funcionais>Cat.SEFIP>Cat.Esocial  
No campo Cat e-social defina a descrição a ser utilizada e preenche o campo Cat SEFIP de acordo.  
Exemplo. Categoria E-Social = Domestico /  Categoria SEFIP = 06
