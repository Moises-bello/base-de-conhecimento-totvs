| **Função:** | Efetivar Alteração de Dados Funcionais |
| **Situação/Requisito:** | Ao executar  o processo Efetivar Alteração de Dados Funcionais para um grande número de registros, o processo esta criando requisições do tipo  Substituição indevidamente para requisições que não estão com o flag Gerar Substituição. |
| **Solução/Implementação:** | Realizado ajuste no processo "Efetivar Alteração de Dados Funcionais" de forma que as Requisições de Alteração de Dados Funcionais gerem requisições de Substituição apenas se a flag Gerar Substituição estiver marcada. |
