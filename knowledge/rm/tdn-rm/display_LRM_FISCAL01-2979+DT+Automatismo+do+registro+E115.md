# Automatismo do registro E115

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Geração do Sped Fiscal |
| **Situação/Requisito:** | Automatismo do registro E115 |
| **Solução/Implementação:** | Implementada a geração do Registro E115 conforme Lançamentos Fiscais (Ajuste Sped)  A Geração do Arquivo manterá a forma antiga de geração do Registros E115 (Período de Apuração)  agregando também os Códigos de Ajuste incluídos via Lançamento Fiscal.  Obs.: Para os Códigos Informados via Lançamento Fiscal o sistema somará os Itens  que tiverem o mesmo Código de Ajuste Sped, inclusive se este código estiver sido Lançado  no Período de Apuração de forma Manual o mesmo será somado e a descrição será a informada no período. |
