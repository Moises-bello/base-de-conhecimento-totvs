**Acesse** **o seu** **banco** **de** **dados.** **Expanda** **a** **raiz** **escolhendo** **o diretório "Security | Logins". Selecione o usuário "rm" com o botão direito do mouse e escolha a opção "Propriedades".**

**Na** **tela** **de** **propriedades** **da** **estância** **você** **irá** **definir** **a linguagem "English" para os usuários utilizados pelo banco que acessam o sistema.**
