# **Sobre a Instalação do Visual Studio**

* Instalar o visual studio ( Abrir chamado no TI para instalação )
* Adicionar o pacote do .NET framework 4.8
* Adicionar o endereço do TFS [http://tfs2015.totvs.com.br](http://tfs2015.totvs.com.br/) - mapear o diretório:  $/RM para C:\RM
* Incluir as dlls DevX localizadas no TFS ( $/RM/Terceiros/DevX/19.2/19.2.7/Bin.Design ) no diretório de instalação do visual Studio C:\Program Files (x86)\Microsoft Visual Studio\2019\Enterprise\Common7\IDE

**Treinamento de LIB RM .NET Framework**

Caminho no TFS para treinamento LIB RM: $/RM/Treinamentos/Framework RM/Documentos
