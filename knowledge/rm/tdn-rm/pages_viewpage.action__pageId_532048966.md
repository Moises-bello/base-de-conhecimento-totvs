## **02. SITUAÇÃO/REQUISITO**

No acesso do aluno ao Educamobile/Educonnect, ao clicar em alguns tipos de solicitações, está sendo exibida a seguinte mensagem de erro:  
"Ocorreu um erro durante a requisição. Object reference not set to an instance of an object"

## **03. SOLUÇÃO**

Otimizado o processo para que as Solicitações que possuem campos personalizados com consulta SQL sejam exibidos no TOTVS Educa Mobile.
