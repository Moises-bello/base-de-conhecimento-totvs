![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/26079898568855) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Qual é a rotina para Lançamentos de Verbas (Hora Extra, Faltas, atrasos, etc) para o cálculo da folha de pagamento?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.  
  
**Solução**Para o lançamento de uma verba que não seja calculada automaticamente pelo sistema, dependendo da necessidade do cliente ela pode ser incluída através das rotinas abaixo:

**1º**  - Lançamentos por funcionários pelo caminho >**Atualizações** >**Lançamentos** >**Por Funcionários**;  
- Selecione o funcionário;  
- Se o funcionário já tiver lançamentos na rotina, clique em **Alterar**, se não tiver, clique em **Incluir**:
