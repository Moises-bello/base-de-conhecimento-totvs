# Ajuste para Exibir o Menu Faturamento do Médico para o Convênio

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Faturamento |
| **Situação:** | O menu Faturamento do Médico para o Convênio, não estava disponível na versão 12 do sistema. |
| **Solução:** | Realizado ajuste para exibir o menu Faturamento do Médico para o Convênio, se o parâmetro Habilitar Menu Faturamento do Médico para o Convênio, estiver selecionado nos parâmetros gerais, aba Faturamento II. |
