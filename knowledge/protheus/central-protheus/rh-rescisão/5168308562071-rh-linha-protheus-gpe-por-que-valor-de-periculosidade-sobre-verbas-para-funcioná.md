![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Por que valor de periculosidade sobre verbas para funcionário mensalista é calculado por base do salário em dobro?  
  
**Ambiente**TOTVS RH - TOTVS RH ( Linha Protheus ) GPE Gestão de Pessoal - A partir da versão 12.1.17.  
  
**Solução**O valor de periculosidade é calculado por base salário em dobro devido o id 0031 (salário mensalista) possuir incidência Sim para periculosidade.

Como a periculosidade é sobre salário mais verbas, somente as verbas de adicionais (exemplo hora extra), devem possuir a incidência Sim para periculosidade.
