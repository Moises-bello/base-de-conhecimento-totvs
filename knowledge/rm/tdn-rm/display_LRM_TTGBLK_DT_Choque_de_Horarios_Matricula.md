# CHOQUE DE HORÁRIOS - MATRÍCULA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Choque de horários - Matrícula em disciplinas* |
| **Situação/Requisito:** | *Choque de horário não valida quando aluno já está matriculado em 1 disciplina de outra filial e continua o processo de matrícula na sua filial de origem.*  *A inconsistência ocorre tanto para disciplinas da grade do aluno quanto de outra grade.* |
| **Solução/Implementação:** | **Validar o choque de horários entre filiais quando o Sistema/Portal permitir a matrícula em turma/disciplina de outra filial. Além disso, validar o choque de horário entre níveis de ensino diferentes, caso esteja parametrizado tal funcionalidade nas configurações do Educacional.** |
