As informações de incidências de dependentes são para definir as incidências de cálculos para cada dependente.   
   
**Atenção:**  
Na tabela dinâmica INT37 poderá ser cadastrado o nome de outras incidências diferentes das incidências fixas. Estas incidências serão utilizadas para cálculos por fórmulas na função INCDEP.  
   
**Observações:**

1. Para que os dados da pensão alimentícia possam ser cadastrados a incidência  de pensão deve ser marcada.
2. Se o parâmetro "Forçar incidência de Salário Família" estiver marcado, o dependente incide Salário Família independente de atender ou não aos requisitos legais (universitário, cartão vacina, etc). Se estiver desmarcado, continuará valendo os requisitos legais.
3. Para atender ao leiaute do eSocial S-2205 -Alteração de Dados Cadastrais do Trabalhador,
4. Caso o dependente tenha plano privado de Saúde deverá ser confirmado o parâmetro "Assistência Médica ".

Veja também o TDN [Fórmulas / Funções – S - SALVAVALDEP](https://tdn.totvs.com.br/pages/viewpage.action?pageId=452719340) caso utilize parâmetro Assistência Médica e a fórmula que referencia essa função de fórmula.
