![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:05:00 min** **Dúvida**No Dashboard Compras, como liberar acesso para os usuários gerenciarem Cards, Gráficos e Visões?  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Compras - Todas as versões  
  
**Solução**O usuário possui acesso apenas as visões que foram previamente cadastradas para seu perfil, onde as opções de Gerenciar Cards, Gerenciar Gráficos e Gerenciar Visões, são de uso exclusivo do administrador do sistema.

Para maiores informações sobre controle de usuários no Dashboard [clique aqui.](https://tdn.totvs.com/pages/releaseview.action?pageId=568924290)
