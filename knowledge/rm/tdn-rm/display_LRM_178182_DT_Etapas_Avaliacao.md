# ETAPAS - AVALIAÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Etapas - Avaliação* |
| **Situação/Requisito:** | *Ao marcar o campo "Disponível para os alunos" no cadastro da etapa, o sistema replica a informação para o cadastro das avaliações, porém, ao desmarcar a flag na etapa, o sistema não desmarca a flag nas avaliações, deixando as mesmas visíveis para os alunos no portal.* |
| **Solução/Implementação:** | *Ajuste no cadastro da etapa para que ao desmarcar o item "Disponível para os alunos" seja também desmarcado o mesmo item nas avaliações.* |
