# LANÇAMENTO FINANCEIRO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Lançamento financeiro* |
| **Situação/Requisito:** | Otimizado lançamento financeiro de líquido salarial, verificando a situação do funcionário na época que o lançamento se refere e se o lançamento é retroativo. |
| **Solução/Implementação:** | Ao gerar o lançamento financeiro de liquido salarial retroativo, para um funcionário demitido o sistema apresenta a seguinte mensagem: Não existe lançamentos a serem gerados. O lançamento se trata de um mês que o funcionário estava ativo, devido a isso o sistema deveria validar o histórico do funcionário de acordo com a parametrização e gerar o lançamento retroativo |
