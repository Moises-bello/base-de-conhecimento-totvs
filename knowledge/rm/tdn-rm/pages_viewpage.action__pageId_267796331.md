# Geração de Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educação |
| **Função:** | Geração de Lançamento |
| **Situação/Requisito:** | Quando o educacional esta parametrizado para identificar os opcionais através do responsável financeiro, o sistema não está respeitando a parametrização default de  opcionais para o cliente/fornecedor referente ao lançamento da bolsa de credito. |
| **Solução/Implementação:** | Melhoria na geração de lançamento de bolsa de crédito para que as informações da tabela opcional do default de cliente fornecedor seja conforme o default do cliente fornecedor da bolsa de crédito, esta regra se aplica quando o educacional estiver parametrizado para que a tabela opcional seja originada do responsável financeiro. |
