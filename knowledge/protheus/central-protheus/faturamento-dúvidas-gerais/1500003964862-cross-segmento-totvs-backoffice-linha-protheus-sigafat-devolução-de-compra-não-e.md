**Dúvida**Ao realizar a devolução de compra, apresenta a mensagem:  
Help: F4NAONOTA - não há notas fiscais de origem referente este cliente/fornecedor e produto  
para serem devolvidas.

**Ambiente**

Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAFAT - Todas as versões.

**Solução**O campo F1\_ORIGLAN=NF, a nota de origem foi incluída pelo modulo livros fiscais, por esse motivo não é possível realizar a devolução pelo faturamento.  
A devolução deve ser realizada pelo modulo livros fiscais.
