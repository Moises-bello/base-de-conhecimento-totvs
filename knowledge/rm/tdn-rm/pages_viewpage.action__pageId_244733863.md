# Parcela - Identificação do Responsável

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Cadastro Parcela / Responsável |
| **Situação/Requisito:** | Ao editar uma parcela e excluir o ressonável e logo em seguida adicionar um novo responsável o sistema esta apresentando a seguinte mensagem ao salvar a parcela:  *Não é possível salvar a parcela sem que o percentual dos responsáveis seja igual a 100.* |
| **Solução/Implementação:** | Realizado um ajuste na identificação do responsável ao salvar a parcela de forma que o cadastro identifique o procedimento que o usuário esta executando conforme o relatado na situação acima. |
