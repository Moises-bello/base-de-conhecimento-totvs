**Dúvida**  
Element '{http://www.prefeitura.sp.gov.br/nfe}CodigoServico': '' is not a valid value of the atomic type '{http://www.prefeitura.sp.gov.br/nfe}tpCodigoServico'.

**Ambiente**  
Cross Segmentos - TOTVS Backoffice Protheus - TOTVS Doc. Eletrônicos - Todas as versões.  
  
**Solução**  
Para corrigir o erro acima, relacionado a nota de serviços de São Paulo, informe o código do serviço nos campos B1\_CODISS e B1\_TRIBMUN, **com tamanho máximo de 5 dígitos.**

Lembrando que o código de serviço deve ser válido conforme legislação municipal.
