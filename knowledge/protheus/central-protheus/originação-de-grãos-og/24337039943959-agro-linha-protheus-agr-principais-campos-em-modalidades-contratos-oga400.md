![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/24337007876247) Tempo aproximado para leitura: **00:01:00 min****Dúvida**Quais são os principais campos em registrar as negociações?  
  
**Ambiente**TOTVS Agro - TOTVS Agro - Comercialização (Linha Protheus) - Originação de Grãos (OG) - Versão 12  
  
**Solução**

**Veja, os principais campos da rotina estão descritos abaixo:**

| Campo | Descrição |
| --- | --- |
| Código | Código identificador da modalidade do contrato. |
| Modalidade | Descrição da modalidade. |
| Tipo Preço | Indica o tipo de preço da negociação. Informação utilizada para validação do registro de negócio na nova comercialização. Os valores aceitos são:   * 1 - Fixo; * 2 - A fixar; * 3 - Ambos. |
| Tipo Mercado | Indica o tipo de mercado da negociação. Informação utilizada para validação do registro de negócio na nova comercialização. Os valores aceitos são:   * 1 - Interno; * 2- Externo; * 3 - Ambos. |
| Finalidade | Indica o código da finalidade previamente cadastrado. Informação utilizada para carregar automaticamente o campo de finalidade no contrato da nova comercialização. |
