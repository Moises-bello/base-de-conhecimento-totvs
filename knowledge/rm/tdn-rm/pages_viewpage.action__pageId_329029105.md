# Permissão de Acesso para Realocação Orçamentaria de Extrato/Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Permissão de Acesso para Realocação Orçamentaria de Extrato/Lançamento |
| **Situação/Requisito:** | Necessidade do controle de permissão por perfil dos seguintes processos do Totvs Gestão Financeira:   * Controle gerencial > Realocação orçamentaria de lançamentos -> Liberar lançamento bloqueado por orçamento * Controle gerencial > Realocação orçamentaria de lançamentos -> Reprocessar lançamento bloqueado por orçamento * Controle gerencial > Realocação orçamentaria de lançamentos-> Realocação Orçamentária  * Controle gerencial > Realocação orçamentaria de Extratos de Caixa -> Liberar extrato bloqueado por orçamento * Controle gerencial > Realocação orçamentaria de Extratos de Caixa -> Reprocessar extrato bloqueado por orçamento * Controle gerencial > Realocação orçamentaria de Extratos de Caixa-> Realocação Orçamentária. |
| **Solução/Implementação:** | Melhoria no processo de Realocação orçamentaria de lançamentos e Realocação orçamentaria de extratos. Agora o sistema irá também tratar seus processos na permissão de perfil. |
