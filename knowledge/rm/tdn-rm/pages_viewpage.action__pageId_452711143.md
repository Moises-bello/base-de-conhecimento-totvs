Disponibilizada a importação/exportação de dados do TOTVS Gestão de Estoque, Compras e Faturamento via [Conceito](http://tdn.totvs.com/pages/viewpage.action?pageId=423938143)e [Gerador de Saídas](http://tdn.totvs.com/pages/viewpage.action?pageId=425459363), estão disponíveis para importação e/ou exportação os seguintes processos:

* [Importação de Lista de Preços de Produtos por Cli/For](http://tdn.totvs.com/pages/viewpage.action?pageId=423938007)
* [Importação Layout ANFAVEA](http://tdn.totvs.com/pages/viewpage.action?pageId=423938013)
* [Importação/Exportação Lista de Preços de Produtos](http://tdn.totvs.com/pages/viewpage.action?pageId=423938144)
* [Importação/Exportação Número(s) de Série de Produto(s)](http://tdn.totvs.com/pages/viewpage.action?pageId=423938144)

Disponibilizado o cadastro de esquema de exportação. O cadastro de [Esquema de Exportação](http://tdn.totvs.com/pages/viewpage.action?pageId=423938099) permite agrupar as informações contidas no layout de relatório do parceiro (Elbrus ou SpressCom), para que posteriormente estes dados sejam exportados.
