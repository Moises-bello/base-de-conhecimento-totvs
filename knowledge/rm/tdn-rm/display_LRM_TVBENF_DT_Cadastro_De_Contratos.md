# CADASTRO DE CONTRATOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Cadastro de contratos* |
| **Situação/Requisito:** | *O sistema possui um tratamento com o intuito de alertar o usuário com relação ao preenchimento do período contábil quando se utilizar a contabilização por competência e o contrato estiver datado. Porém se o período contábil não estiver definido, o sistema gera um erro e não permite que o contrato seja criado ou editado.* |
| **Solução/Implementação:** | *Foi realizada otimização da visão de contratos de forma que o sistema não impeça a criação ou edição de um contrato caso o período contábil não esteja preenchido e o sistema esteja parametrizado para utilizar contabilização por competência.* |
