# EDUCAMOBILE - PROFESSOR - ETAPA NOTAS E FALTAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Digitação de etapas de notas e faltas e avaliações via EducaMobile.* |
| **Situação/Requisito:** | *Uma mensagem de período de digitação expirado era exibida quando o professor acessava a visão de digitação de etapas de notas e faltas ou avaliações no EducaMobile, quando o o acesso era realizado no último dia de digitação.* |
| **Solução/Implementação:** | *O EducaMobile só emitirá uma mensagem de período de digitação expirado nas visões de digitação de notas e faltas de etapas e digitação avaliações, quando a data de digitação for posterior a data do limite de digitação na Etapa.* |
