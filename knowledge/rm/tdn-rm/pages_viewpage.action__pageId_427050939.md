# ASSOCIACAO DE MATRICULA ISOLADA AO TCC

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Associação de matrícula ao TCC* |
| **Situação/Requisito:** | Após associação de uma matrícula isolada a um TCC, a mesma não é exibida na visão. Quando se tenta cadastrar a mesma, novamente, ocorre uma mensagem de validação. |
| **Solução/Implementação:** | Foi detectado que a visão exibia, somente, matrículas que tinham matriz aplicada. Dessa forma, foi realizado um ajuste para que todas as matrículas fossem exibidas. |
