# RESCISÃO ESTÁ PERMITINDO LANÇAMENTO DE MEDIA COM VALOR NEGATIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Rescisão* |
| **Situação/Requisito:** | *No cálculo da rescisão está sendo lançado valor de média negativo.*  *Situação ocorre quando valor de desconto que incide na média é maior que o valor de provento.* |
| **Solução/Implementação:** | *Ajuste no cálculo da rescisão para não lançar o evento de média quando o valor calculado for negativo.* |
| **Chamados   relacionados:** | *TUJDXU, TUKJED* |
| **Versões/Release:** | *11.82.43, 12.1.11* |
