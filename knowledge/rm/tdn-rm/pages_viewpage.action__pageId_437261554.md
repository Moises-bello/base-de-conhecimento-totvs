# MOEDA NA LIBERAÇÃO DE ADIANTAMENTOS DE CONTRATOS A PAGAR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Liberar Adiantamento |
| **Situação/Requisito:** | Moeda do adiantamento contratual, não é igual moeda do projeto ao realizar o processo de "Liberar Adiantamento" em contratos. |
| **Solução/Implementação:** | Ajuste no configurador 1.0 para marcar o parâmetro "Usa moeda do movimento", na página "FIN - Faturamento 1/6" no movimento 1.2.05 (Adiantamento de contrato a pagar). Este parâmetro poderá ser marcado acessando os parâmetros de movimento do Gestão de Estoque, Compras e Faturamento. |
| **Conversores e Parâmetros:** | Não se aplica. |
| **Tickets relacionados:** | Não se aplica. |
