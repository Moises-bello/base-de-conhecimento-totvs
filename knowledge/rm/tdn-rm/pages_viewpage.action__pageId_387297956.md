# Exibir lançamento/boletos independente da matriz aplicada

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Portal do Aluno |
| **Função:** | Extrato Financeiro |
| **Situação/Requisito:** | O valor bruto de boletos agrupados por Registro Acadêmico de contratos de matrizes aplicadas diferentes não eram listados corretamente. |
| **Solução/Implementação:** | Foi criado o parâmetro "Educacional > RM Portal > Gerais > Portal - Geral 7 /11 > Exibir lançamentos / boletos independente da matriz aplicada" que altera o comportamento do extrato financeiro do Portal Corpore e Novo Portal do aluno.  Uma vez marcado o parâmetro supracitado o sistema deixa de filtrar os boletos. Este comportamento atende a necessidade de clientes que utilizam o agrupamento de lançamentos por Registro Acadêmico ou por Responsável. |
