![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/19278340605847) Tempo aproximado para leitura: **00:02:00 min****Dúvida**Como realizar o cadastro de Projetos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Avaliação Pesquisa e Desempenho – Todas as versões  
  
**Solução**A rotina APDA130 é utilizada para **cadastrar os projetos que a empresa está conduzindo para a criação de um produto ou serviço.**   
São informados os dados relacionados à **descrição do projeto,** **período de vigência e seu detalhamento.** Desta forma, será possível efetuar **avaliações de desempenho dos participantes envolvidos no projeto.**  
  
Exemplos:

|  |  |
| --- | --- |
| • | Projeto de novos produtos e processos de produção. |

|  |  |
| --- | --- |
| • | Projetos para o busca da excelência da qualidade. |

|  |  |
| --- | --- |
| • | Implantação do produto de software (Sistema ERP). |

**Para cadastrar habilidades acesse o módulo 53 - SIGAAPD > Clique no menu Atualizações > Cadastros > Projetos > Clique em Incluir e preencha os dados:**![Cadastro de Projetos.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/19278312572695)
