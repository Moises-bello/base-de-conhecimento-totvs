|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Geração de Arquivo para rotina Federal DIRF |
| **Situação/Requisito:** | Incluir na carga de lançamentos da DIRF os que contenham CFOP de entrada de Energia Elétrica |
| **Solução/Implementação:** | Acrescentadas as natureza de compra de energia elétrica na carga dos lançamentos para a geração do arquivo da DIRF.
