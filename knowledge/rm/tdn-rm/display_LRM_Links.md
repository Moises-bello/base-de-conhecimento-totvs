# **Visão Geral**

---

O menu de links consiste em um dropdown de opções em que, ao selecionar uma das opções, é aberto uma aba na MDI direcionando para o respectivo website.

As opções de link estão listadas abaixo; este menu **não é customizável**, ou seja, não é possível inserir, editar ou remover opções.

## **TOTVS**

---

A opção **TOTVS** direciona para o website oficial da TOTVS: <https://www.totvs.com/>.

## **TOTVS Mashups**

---

A opção **TOTVS Mashups** direciona para o a página de instruções sobre o TOTVS Mashups: <http://mashup.totvs.com.br/>.

## **Google Docs**

---

A opção **Google Docs** direciona para o website <http://docs.google.com>.

É importante ressaltar que, quando uma conta for logada no Google Docs pela MDI, ela permanecerá logada para todos os usuários do RM que logarem na mesma máquina.
