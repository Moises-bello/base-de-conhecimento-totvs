Dúvida**API com comunicação via XML-RPC, existe alguma função ou classe para consumo desse serviço?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**Atualmente o ERP  não esta preparado para a comunicação via XML-RPC, pois os protocolos disponíveis são Soap e Rest.
