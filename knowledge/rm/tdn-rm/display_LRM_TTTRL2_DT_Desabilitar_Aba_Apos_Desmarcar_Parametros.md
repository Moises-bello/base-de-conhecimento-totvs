# DESABILITAR ABA DE "EVENTOS P/ PAG. DE MÉDIA NA RESCISÃO" AO DESMARCAR O PARÂMETRO "UTILIZA PARÂMETROS ESPECÍFICOS PARA MÉDIA DE FÉRIAS NA RESCISÃO"

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Desabilitar aba "Eventos p/Pag. de Média na Rescisão" ao desmarcar o parâmetro "Utiliza parâmetros específicos para média de férias na rescisão" na aba de "Média de Férias".* |
| **Situação/Requisito:** | Ao acessar o cadastro do Sindicato, foi identificado que na aba "Média de Férias", ao marcar o parâmetro "Utiliza parâmetros específicos para média de férias na rescisão", é habilitado uma nova aba "Média de Férias na Rescisão". Nessa aba existe o campo Tipo de Cálculo, que se for igual a "Sem média", não é habilitado nenhuma outra aba, porém ao selecionar o tipo de cálculo como "Média po Valor" ou "Média por Hora" é habilitado uma nova aba "Eventos p/Pag. de Média na Rescisão". Com isso na aba "Média de Férias" ao desmarcar a opção "Utiliza parâmetros específicos para média de férias na rescisão" a aba "Média de Férias na Rescisão" não é apresentada, porém a aba "Eventos p/Pag. de Média na Rescisão" continua habilitada. |
| **Solução/Implementação:** | *Ao desmarcar o parâmetro "Utiliza parâmetros específicos para média de férias na rescisão" na aba de "Média de Férias" a aba "Eventos p/Pag. de Média na Rescisão" deve ser desabilitada.* |
| **Chamados relacionados:** | TTTRL2 |
| **Versões/Release:** | 12.1.10 |
