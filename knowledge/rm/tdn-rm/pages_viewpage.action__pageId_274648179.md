# SOLICITAÇÃO DE ESTÁGIO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Solicitação de Estágio* |
| **Situação/Requisito:** | *No momento em que o aluno está realizando o cadastro da solicitação de estágio pelo portal ele deverá associar uma empresa ou realizar o cadastro de uma nova empresa. No campo Empresa irá aparecer todas as empresas inseridas por todos os campi para realizarem qualquer tipo de ação de extensão, porém o número de empresas cadastradas será muito expressivo, dificultando a seleção da empresa, pois não existe nenhum tipo de filtro.* |
| **Solução/Implementação:** | *Ajuste no componente de seleção da empresa para que seja possível filtrar pelo nome da empresa ao digitar no campo. O filtro funcionará do tipo que contém, ou seja, se digitar a Totvs, irá aparecer todas empresas que contém a palavra Totvs. O mesmo foi efetuado para o campo de funcionário ao se cadastrar/editar o mesmo.* |
