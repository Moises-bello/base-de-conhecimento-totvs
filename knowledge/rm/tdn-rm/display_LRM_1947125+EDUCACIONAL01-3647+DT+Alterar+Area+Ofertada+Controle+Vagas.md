# ÁREA DE INTERESSE OFERTADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Processo Seletivo* |
| **Função:** | *Área de interesse ofertada* |
| **Situação/Requisito:** | *Ao realizar qualquer alteração em uma área ofertada o sistema retorna que não é possível alterar pois o número de vagas é menor que o número de inscritos.* |
| **Solução/Implementação:** | **F*oi identificado que erro foi causado por uma inconsistência na alteração de candidatos excedentes e inscritos já ajustado, porém foi feito um ajuste na alteração da área ofertada para validar o número de vagas somente se ocorreu alteração neste campo, ao alterar os demais campos o sistema não irá validar o número de vagas pelo número de inscritos caso o processo seletivo utilize controle de vagas.*** |
