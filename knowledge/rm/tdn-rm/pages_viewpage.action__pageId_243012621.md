# GERAÇÃO DE LANÇAMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Simulação de parcelas financeiras* |
| **Situação/Requisito:** | *Ao simular uma parcela financeira calculada por crédito e gerada, com o sistema parametrizado para impedir a regeração de lançamentos utilizando créditos financeiros, o sistema recalcula o valor da parcela como se o valor da parcela pudesse ser alterado.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de simulação de parcelas financeiras, de forma a impedir que o sistema recalcule o valor de uma  parcela gerada por crédito, caso o sistema não permita que parcelas geradas por crédito sejam regeradas.* |
