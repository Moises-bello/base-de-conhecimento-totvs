# Criar a opção de "Última Mudança de Função" em "Datas a Considerar"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | RH |
| **Módulo:** | Segurança e Saúde Ocupacional |
| **Função:** | Assistente Posto de Trabalho |
| **Situação/Requisito:** | Criar a opção de "Última Mudança de Função" em "Datas a Considerar" disponível no Assistente de Associação de Posto de Trabalho, assim como existe para a seção, onde deverá verificar a maior data do histórico de função para essa associação. |
| **Solução/Implementação:** | Criada nova opção de  "Última Mudança de Função" em "Datas a Considerar" no Assistente de Associação de Posto de Trabalho, que considera a ultima mudança de função do funcionário ao criar o "Histórico de Postos de Trabalho". |
