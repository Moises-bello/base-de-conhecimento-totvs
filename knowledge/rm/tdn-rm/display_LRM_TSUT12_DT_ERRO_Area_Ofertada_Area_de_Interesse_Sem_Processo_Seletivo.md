# ÁREA OFERTADA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Processo Seletivo* |
| **Função:** | *Área Ofertada* |
| **Situação/Requisito:** | *Ao cadastrar uma nova área ofertada é possível selecionar a área disponível antes de selecionar o PS, pois está sendo possível cadastrar uma área que não é de cliente em um PS que é terceirizado.* |
| **Solução/Implementação:** | *O cadastro de área ofertada permite que seja selecionado uma área de interesse antes de selecionar um processo seletivo, desta forma, pode ocorrer a situação de ter uma área ofertada que não pertence ao processo seletivo selecionado. Este checkin visa bloquear a seleção da área informada até que seja selecionado um processo seletivo.* |
