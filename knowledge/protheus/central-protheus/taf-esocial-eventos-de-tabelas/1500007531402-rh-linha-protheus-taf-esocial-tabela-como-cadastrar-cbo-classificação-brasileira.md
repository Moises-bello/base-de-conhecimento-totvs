**Dúvida**Não consigo encontrar o código CBO necessário nas opções disponíveis no TAF. É possível cadastrar manualmente?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS Automação Fiscal - Todas as versões.  
  
**Solução**

Para cadastrar um novo código CBO (Classificação Brasileira de Ocupação) no TAF, siga as etapas abaixo:

1. Acesse a lista de tabelas dinâmicas no TAF pelo menu Consultas > Tabelas Dinâmicas:  
   ![Acessar_Tabela_Din_mica.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010801981)
2. Altere o modo de pesquisa para "código":

   **![Altera_modo_de_pesquisa.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010802521)**
3. Pesquise o código "C8Z" para acessar a tabela dinâmica com os cadastros CBO.

   ![Buscar_C8Zgif.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010526542)
4. Uma vez no código C8Z, selecione o botão "Abrir Browser":![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010527502)
5. Na nova janela que abrir, clique no botão "+ Incluir";
6. Preencha o campo "Cód Ocupação" com o código desejado, forneça uma descrição para esse código e uma data de início de vigência:  
   ![Incluindo_um_c_digo.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010529982)
7. Após configurar o novo código CBO, clique no botão "Confirmar". O código estará disponível no TAF para seleção:  
   ![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/1500010530382)
8. 1. Após o cadastro, integre novamente o evento no TAF e efetue a transmissão.
