![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:00:40 min** **Dúvida**Por que ao alterar uma solicitação na rotina **QDOA052 - Cadastro de Solicitações** é exibida a mensagem **Usuário sem permissão para modificar Solicitação**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Controle de Documentos (SIGAQDO) - Todas as versões  
  
**Solução**Esta mensagem é exibida quando o usuário que está tentando modificar a solicitação, não foi o usuário que incluiu esta solicitação.  
Para identificar o usuário que incluiu a solicitação, verifique qual é o usuário do campo **Solicitante**.  
  
**Importante**  
Somente o usuário que incluiu a solicitação é que poderá realizar a alteração.  
Os demais usuários poderão apenas visualizar a solicitação.
