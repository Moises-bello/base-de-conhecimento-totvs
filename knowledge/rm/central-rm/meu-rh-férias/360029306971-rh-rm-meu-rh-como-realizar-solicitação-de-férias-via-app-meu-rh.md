**Dúvida**Como realizar solicitação de férias via *app* **Meu RH**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Meu RH - A partir do release 12.1.17  
  
**Solução**Para solicitar férias pelo *app* **Meu RH**,  é necessário executar uma sequência de passos informando os dados necessários:  
  
**1.** Acesse o menu **Férias > Solicitar Férias,** defina a data desejada e clique em **Confirmar;**

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415932952471/mceclip3.png)

**2.** Selecione a quantidade de dias de férias e conforme sua escolha, será perguntado se deseja vender outros 10 dias. (Caso essa permissão esteja habilitada no parametrizador);

![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415911858967/mceclip4.png)

**3.** Em seguida, será perguntado se deseja receber o adiantamento do seu 13º e após a sua escolha, será apresentado a tela de finalização da solicitação;

![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415926924183/mceclip5.png)

**4.** Após finalizar a solicitação, será apresentado uma mensagem de confirmação.

![mceclip6.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4415912344599/mceclip6.png)

|  |  |
| --- | --- |
| **Data de início** | Data na qual as férias serão iniciadas.   * A data informada não pode ser igual ou inferior a data atual, e não pode ser superior a data limite para solicitação (data final do período aquisitivo subtraído pelo saldo disponível) |
| **Dias de férias** | Quantidade de dias que deseja solicitar de férias a partir da data de início.   * Caso informado um valor acima do saldo disponível o campo será limpo para ser informado um novo valor válido. * Se o valor informado representar o saldo total disponível, os passos referentes a venda de férias serão pulados. |
| **Vender férias** | Selecionar a opção sim ou não para informar se deseja vender dias de férias. |
| **Dias à vender** | Quantidade de dias que deseja vender. |
| **Receber adiantamento** | Selecionar opção sim ou não para informar se deseja receber adiantamento do 13º. |

**Importante**Os parâmetros **vender férias**, **dias à vender** e **receber adiantamento** devem ser configurados acessando o modulo **Folha de pagamento** / **Parametrizador** / **RM Portal /** **Edite o quiosque** / **Férias II**
