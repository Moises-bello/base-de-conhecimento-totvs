**Dúvida**

Caso tenha necessidade  enviar o arquivo antes de 15/03 não se tratando de uma situação especial

Ex.:

* Licitação
* Auditoria

**Ambiente**  
Microsiga Protheus – Contabilidade – A partir da versão 11.80  
  
   
**Solução**

A previsão do Protheus para entrega do layout 7 do ECD é de até 15/03/2019 (ISSUE DSERCTR1-1635).

A empresa que não conseguiu entregar até o prazo de 10 de janeiro, poderá como paliativo, gerar o arquivo no layout 6 e realizar a adequação das informações no .txt para o layout 7, manualmente

O time de produto para apoio no parecer oficial,  disponibilizou a  documentação abaixo TOTVS News com as mudanças que o manual sofreu para facilitar os ajustes na ECD layout 6, manualmente. (ISSUE DSERCTR1-18415)

[ECD\_SPED\_CONTABIL\_Alteracoes\_para\_Leiaute\_7\_00](http://tdn.totvs.com/display/public/PROT/ECD_SPED_CONTABIL_Alteracoes_para_Leiaute_7_00)
