Aqui serão listadas as breaking changes de Grupo de Relatórios conhecidas entre versões TReports.

# Versão 12.1.28:

---

* [Configuração de perfis com permissão de acesso a grupo](https://tdn.totvs.com/x/nyGTEg) de relatórios não é realizado automaticamente ao se atualizar de uma versão anterior.

O TReports inicialmente somente aplicará o usuário 'Admin' a todos grupos já existentes,  desta forma usuários que não têm o perfil 'Admin' configurado no RAC irão perder acesso aos relatórios.

É necessário acessar o cadastro dos grupos e adicionar os perfis desejados.
