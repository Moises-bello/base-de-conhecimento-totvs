# CONTABILIZAÇÃO DE EXTRATO COM OPÇÃO DE INVERTER DEFAULT CONTÁBIL DE MÚTUO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Construção e Projetos. |
| **Módulo:** | Totvs Gestão Financeira. |
| **Função:** | Contabilização de extrato com mútuo. |
| **Situação/Requisito:** | Quando parâmetro "Inverter o default contábil de mútuo para extrato de saque" marcado o sistema invertia corretamente as contas de débito e crédito, mas o rateio gerencial carregado pelo default contábil não. |
| **Solução/Implementação:** | Ajustada a rotina para também inverter o rateio gerencial para que tenha o mesmo comportamento das contas de débito e crédito. |
| **Conversores e Parâmetros:** | N/A. |
| **Tickets relacionados:** | N/A. |
| **Requisito:** | FINANCEIRO01-179. |
