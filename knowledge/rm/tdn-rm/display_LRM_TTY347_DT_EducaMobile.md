# SELEÇÃO DE CONTEXTO NO EDUCA MOBILE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Gestão Educacional* |
| **Função:** | *Seleção de contexto no Educa Mobile.* |
| **Situação/Requisito:** | *Quando o portal do Educa Mobile é instalado em uma porta diferente da padrão, ao selecionar um contexto o sistema redirecionava o usuário para um endereço diferente utilizando a porta padrão.* |
| **Solução/Implementação:** | *Nos cenários que o portal for instalado em uma porta diferente, ao selecionar o contexto e endereço levará em consideração a porta selecionada na instalação. Desta forma o usuário será redirecionado corretamente.* |
