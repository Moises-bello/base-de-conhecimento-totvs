# PARÂMETROS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Educacional.* |
| **Função:** | *Parâmetro de seleção dos relatórios que ficarão disponíveis no portal.* |
| **Situação/Requisito:** | *O controle de seleção dos relatório estava com um comportamento diferente do padrão e estava marcando alguns itens que não foram selecionados pelo usuário. Além disso, quando o usuário selecionava muitos relatórios, o sistema bloqueava um limite de 250 caracteres, sendo que esta quantidade é calculada de acordo com o código do relatório selecionado.* |
| **Solução/Implementação:** | *Ajuste no controle de seleção dos relatórios para que só fiquem marcados aqueles relatório que o usuário desejou. Além disso, aumentamos o tamanho do campo que armazena a informação dos relatórios que serão disponibilizados no portal Educacional.* |
