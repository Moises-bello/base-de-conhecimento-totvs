# Pré-requisitos

---

2
complete
Linha RM atualizada até a versão 12.1.5

# Objetivos

---

Cadastrar uma Conta de Comunicação para uma Página do Facebook.

# Criando a conta

---

1. Acesse visão de Contas de Comunicação
2. Selecione uma conta de comunicação do Facebook já cadastrada.
3. Acesse o menu de processos, opção "Importação de Páginas como Contas de Comunicação"

   Atenção

   Devido a restrições de segurança do Facebook, somente usuários administradores do aplicativo tem plenos acessos fazer publicações e gerenciar páginas. Portanto, o usuário utilizado neste passo deve atender a estas restrições.
4. Clicar em Executar:
5. Verifique que as páginas que são administradas pelo usuário selecionado no início do processo foram importadas como contas de comunicação.
