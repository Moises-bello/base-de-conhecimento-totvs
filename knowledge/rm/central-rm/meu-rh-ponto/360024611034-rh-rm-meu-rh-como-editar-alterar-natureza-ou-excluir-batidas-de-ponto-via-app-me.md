**Dúvida**Como editar, alterar natureza ou excluir batidas de ponto via app **Meu RH**?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - Meu RH - A partir da versão 12.1.17  
  
**Solução**Esta função permite editar, excluir ou adicionar manualmente as batidas/marcações de ponto do funcionário. O acesso é via menu **Ponto | Espelho de Ponto | Ver | Editar Batidas.**

Para liberação ou restrição de acesso a esta função, é necessário que o usuário possua permissão de acesso ao Espelho de Ponto:

* **RM:** acesso à função Ponto ([Segurança / Perfis](http://tdn.totvs.com/pages/viewpage.action?pageId=285656979)).

**Tela Editar Batidas  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414063883799/mceclip2.png)  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4414079683991/mceclip1.png)**

**Importante**

* Só é possível excluir uma batida que foi inserida manualmente e que ainda não foi aprovada pelo gestor.
* Após aprovação da batida, só é possível alterar a natureza para "Entrada" ou "Saída".
