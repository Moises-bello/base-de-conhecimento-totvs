![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20062950999063) Tempo aproximado para leitura: **00:02min****Dúvida**O que fazer quando o conteúdo do campo CKO\_FLAG está = "2"?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - TOTVS COMPRAS - A partir da Versão 12

**Solução**

Para solucionar essa dúvida, siga os seguintes passos:

1. Acesse a rotina de REPROCESSAR no Monitor.
2. Localize o documento e verifique qual é o código de erro associado a ele.
3. Em seguida, faça os ajustes necessários para que a nota seja exibida corretamente no Monitor.

![gif - MONITOR.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/24154440581271)

***Atenção:***

Todo esse procedimento deve ser realizado na Empresa/Filial correspondente ao documento.
