# Ajuste no Formulário Faturamento Para Convênios

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | Faturamento |
| **Função:** | Faturamento para Convênios |
| **Situação:** | Ao acessar o sistema TOTVS Gestão Hospitalar, ir ao menu "Faturamento"/"Faturamento para Convênios" (Nova MDI), pesquisar uma remessa já faturada e gerar um refaturamento, o sistema retornava a mensagem "ORA - 00936". |
| **Solução:** | Foram realizados ajustes no formulário para que o sistema finalize o processo de refaturamento sem nenhuma exceção. |
