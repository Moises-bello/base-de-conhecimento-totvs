**Dúvida**  
No Dashboard Backoffice é possível incluir um novo Gráfico?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro - Todas as versões  
  
**Solução**  
No **Dashboard Backoffice** estão disponíveis as inclusões de novos Gráficos.

Para incluir um novo Gráfico:

1) Clicar no menu Gerenciar Gráficos;

2) Clicar no botão Incluir;

3) Informar os campos conforme sequência:

a) Modelo de Gráfico: Selecionar no combo o tipo de Gráfico desejado;

b) Status: Indica se o gráfico está desabilitado ou habilitado para visualização;

c) Título: Informar um título para o Gráfico;

d) Help do Gráfico: Esta funcionalidade permite informar uma descrição de help para o Gráfico;

e) Dados Gerais: Selecionar o tipo de gráfico, as opções são: Linha, Barra e Radar;

f) Clicar no botão Salvar para concluir a operação:
