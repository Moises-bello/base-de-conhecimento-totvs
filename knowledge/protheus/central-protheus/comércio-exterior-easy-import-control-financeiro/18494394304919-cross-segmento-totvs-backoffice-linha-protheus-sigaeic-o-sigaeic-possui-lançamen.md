![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/18494422046743) Tempo aproximado para leitura:**00:02:00 min** **Dúvida**O **SIGAEIC** possui Lançamentos Padrões "**LP's"**?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) –*Easy Import Control*– Todas versões.  
  
**Solução**

O **SIGAEIC** não possui lançamentos padrões próprios (**LP's**),   
Os processos do **SIGAEIC** podem ser contabilizados utilizando os **"LP's**" existentes para outros módulos, como o **SIGACOM** e **SIGAFIN** que possui integrações de Notas Fiscais e Títulos respectivamente.  
**Exemplo**: Os títulos incluídos no contas a pagar a partir do **SIGAEIC,** podem ser contabilizados utilizando **LP's** como do contar a pagar, como o **LP 510, 515,** entre outros.  
  
**Observação:**

```
O Suporte Técnico não realiza validações ou configurações de lançamentos padrões, pois essas demandas requerem informações detalhadas sobre o negócio e os processos a serem contabilizados.  
Se houver dúvidas sobre a configuração, sugerimos testar utilizando um campo fixo no LP (exemplo: SE5->E5_VALOR), removendo eventuais validações.  
Caso você não tenha familiaridade com o cadastro de LP, recomendamos entrar em contato com o seu agente de relacionamento TOTVS para agendar uma visita de um analista, que poderá avaliar seu ambiente de forma mais detalhada.
```
