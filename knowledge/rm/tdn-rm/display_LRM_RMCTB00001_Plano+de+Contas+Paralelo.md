# Assunto

|  |  |
| --- | --- |
| **Produto:** | TOTVS - Gestão Contábil |
| **Versões:** | 12.1.18 |
| **Ocorrência:** | Cadastro de Contas Paralelas |
| **Ambiente:** | Novo Modelo BackOffice |
| **Passo a passo:** | **Definição do Processo**  As contas paralelas são muito usadas nas obrigações acessórias ECD e ECF para que a Receita Federal consiga analisar os dados de forma padronizada. Porém, seu principal objetivo é consolidar as contas contábeis para avaliação de novos cenários ou adequação dos fatos contábeis à legislação estrangeira.  **Regras Gerais**  O usuário só tem acesso ao plano paralelo por meio de relatórios, visto que os lançamentos são sempre feitos nas contas contábeis.  O sistema não permite mais de um relacionamento de uma conta contábil com uma paralela.  **Parametrização Necessária**  1 - Acesse Cadastros/Paralelo para inserir um novo Plano Paralelo:        2 - Ao clicar em incluir, o sistema abrirá a tela com os dados básicos do cadastro:                                  **Importante** Se o plano paralelo for digitado pelo usuário a máscara deve ser informada, por outro lado, se for um cadastro para importação de um dos planos da Receita Federal o campo deve ser preenchido com apenas uma "#", pois no momento da importação o plano irá seguir a hierarquia informada no arquivo texto.  A instituição responsável também merece atenção, visto que irá influenciar na geração das obrigações acessórias bem como na tela de visão das contas paralelas.  3 - Após o cadastro dos dados básicos, clique em Anexos/Contas Paralelas para inserir as contas:                              4 - Em seguida ao aplicar o filtro o sistema abre a tela de visão do plano, clicando em Incluir a tela com os dados de cadastro é apresentada. Vejamos nas figuras:                              Ao informar uma conta analítica o sistema abre os cadastros de associação:                                      5 - Acesse as abas de associação e informe as contas contábeis e gerenciais/centros de custo relativos à conta paralela.  Selecione as contas contábeis e clique na seta para a direita:                                      Após a seleção das contas contábeis, informe qual conta gerencial/centro de custo está relacionado às contas contábeis selecionadas no item anterior: |
| **Observações:** | * A associação de contas gerenciais/centros de custo pode ser feita de forma automática, acesse [Associação Dinâmica de Centro de Custo/Conta Gerencial ao Plano Paralelo](http://tdn.totvs.com/pages/viewpage.action?pageId=286722599). * Para importação do plano de contas referencial, acesse [Importação do Plano de Contas Referencial](http://tdn.totvs.com/pages/viewpage.action?pageId=235332636). |
