# Ajuste para Instrumentadores no Registro de Informações de Cirurgias

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cuidados com o Paciente |
| **Situação:** | Quando o percentual do instrumentador nos padrões de faturamento e codificação estava zerado, o sistema lançava o valor cheio nos honorários da conta do paciente, ao enviar os dados para faturamento no registro de informações de cirurgias. |
| **Solução:** | Realizado ajuste para não calcular o valor do instrumentador, ao enviar os dados para faturamento no registro de informações de cirurgias. |
