**Dúvida**

É possível compartilhar o saldo de um contrato com os vários clientes incluído neste contrato, sendo este um saldo geral, em que todos os clientes possam consumir desse saldo.

**Ambiente**

Cross Segmentos - TOTVS Backoffice (Linha Protheus) - TOTVS Gestão de Contratos - Todas as versões

**Solução**

Hoje no padrão do Gestão de Contratos ele não possui uma funcionalidade ou parametrização para realização deste processo de no cadastro e uso de contratos cadastrados, o saldo total do contrato ser um saldo geral, podendo ser compartilhado entre os vários clientes do contrato.

No padrão, cada planilha possui seu cliente e seu saldo respectivo, sendo no caso o saldo do contrato apenas o montante total dos saldos das planilhas, e cada cliente consegue utilizar apenas o saldo de sua respectiva planilha.  
   
Este se trata de fato da forma como o sistema/rotina padrão hoje trabalha.  
   
   
Verificamos que hoje não há uma forma de se customizar este conceito do módulo.  
   
   
Sobre este padrão do sistema, caso deseje, para uma forma diferente de seu funcionamento, o que podemos orientar é a abertura de uma sugestão de melhoria através da Central Colaborativa diretamente no Portal do Cliente.  
Este é o contato direto do cliente com a Equipe responsável pelo Produto.
