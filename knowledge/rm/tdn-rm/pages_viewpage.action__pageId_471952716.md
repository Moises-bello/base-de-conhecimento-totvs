**Este Menu está disponível apenas para o contexto ENSINO SUPERIOR.**

Ao acessar pela primeira vez a tela de seleção de disciplinas na matrícula do ensino superior, será exibido um pequeno tutorial interativo, mostrando para o aluno as principais funcionalidades da seleção de disciplinas.

Para ver novamente o tour, basta clicar no botão de help, posicionado no canto direito superior.
