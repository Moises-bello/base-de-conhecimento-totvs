## **01. VISÃO GERAL**

Nas visões você pode incluir Layouts que salvam uma determinada distribuição de campos. Para salvar estes Layouts, configure as colunas à sua maneira. Você poderá alternar seus Layouts quando quiser.

## **02. EXEMPLO DE UTILIZAÇÃO**

Veja todos os componentes do Layout:

**LAYOUT**

* Seleciona os layouts que estão salvos ou retorna para o padrão.

* Salva o layout que está sendo usado no momento.

* Exclui o layout que está sendo usado no momento.

* Restaura o layout padrão do sistema.

* Exporta o layout usado no momento.

* Importa um layout já existe para o sistema.

**RECURSOS**

* Formata a visão de acordo com uma condição que você dá ao sistema, dentre as formatações temos: Cor do fundo, fonte, tamanho, dentre outras.

* Cria uma nova coluna de acordo com uma especificação definida.

* Define uma action que esteja associada a visão.

* Adiciona a visão um gráfico.

**CÓPIA DE LAYOUT ENTRE USUÁRIOS**

O aplicativo RM permite realizar cópia de Layouts de um usuário com permissão de Supervisor para outros usuários, admitindo assim que as configurações de Layout de um usuário sejam utilizadas por outros.

Para realizar a cópia de um Layout, um usuário com permissão Supervisor precisa selecionar uma Action que tenha a funcionalidade Layout disponível. Após definir a estrutura do Layout que será copiado, acione o botão ‘Layout – Salvar Layout Como’.

Selecione agora a Action Processos e a opção Cópia de Configuração da Visão. Uma janela será exibida para informar os Parâmetros de configuração. No campo Layouts a serem copiados, selecione o Layout que foi salvo e será copiado.

No campo Perfil selecione o perfil que o usuário de destino está vinculado, porém este filtro é opcional. Selecione também o Usuário para qual o Layout será copiado. Avance o processo e ao final, com a conclusão ocorrendo com sucesso, realize o Logout/Login para sair do sistema.

Acesse o sistema utilizando o Usuário para qual foi copiado o layout. Tento então acesso ao sistema, selecione a Action para qual foi destinado o Layout copiado. Acesse a opção Layout e verifique que o layout copiado está presente na listagem de opções.

Selecione então o layout que foi copiado e o sistema exibirá a estrutura que foi migrada do usuário com perfil Supervisor.
