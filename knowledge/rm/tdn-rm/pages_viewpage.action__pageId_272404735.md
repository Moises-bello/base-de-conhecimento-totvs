# Código Estruturado/Reduzido de Centro de Custo

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Código Estruturado/Reduzido de Centro de Custo |
| **Situação/Requisito:** | A partir do release 12.1.14, o sistema Educacional passou a obedecer os parâmetros global contábeis nas telas onde mostram código do centro de custo e para o caso do código reduzido do centro de custo o cliente não quer que essa funcionalidade seja obedecida.  ( Vide documentação em   ). |
| **Solução/Implementação:** | Melhoria na parametrização contábil para que o código reduzido de centro de custo seja aplicado por módulo evitando assim recorrência de problema com outros clientes que usam o reduzido de forma global no ERP. |
