Quando a integração com o Fluig não estiver habilitada ao acessar os parâmetros de projetos em: Projetos | Construção e Projetos | Projetos (F6) é exibida uma mensagem informando que os parâmetros gerais não foram configurados neste caso deverá acessar os parâmetros gerais em : Projetos | Construção e Projetos | Gerais | Fluig e definir os mesmos .

**Integração Fluig:** Habilitada quando integrado com o Fluig.

|  |  |
| --- | --- |
| ***Workflow*** | Define quais workflows serão utilizados na integração |
| **Liberação de Período** | **Contratos a Pagar**  **Contratos a Receber** |
| **Contratos -Workflow de aprovação** | **Contrato a Pagar**  **Contrato a Receber** |
| **Projetos** | **Aprovação de Projetos**  **Utilizar workflow para revisão simples** |
| **Fases do Projeto** | Define a fase que será considerada :  **Sem Controle**  **Orçamento**  **Venda**  **Planejamento**  **Execução** |
| **Pedido de Material Extra** | **Utilizar workflow de Pedido de Material Extra** |
| **Pedido de Faturamento Direto** | **Utilizar workflow de Faturamento Direto** |
