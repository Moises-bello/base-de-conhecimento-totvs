O projeto pode ser criado na ferramenta JIRA a cada novo ciclo de *Roadmap* e agrupado por **Produto / Projeto / SQUAD**. É importante destacar que devido ao modelo de release incremental utilizado na TOTVS, não é obrigatório a criação de um novo projeto a cada ciclo de *Roadmap*, isto deve-se também a forma que a ferramenta JIRA é parametrizada, sendo o projeto um agrupador de *EPICs* e *Stories*. Fica a critério de cada Segmento / *SQUAD* a gestão e o controle dos projetos na ferramenta JIRA.

Para criar um novo projeto no JIRA deve-se acessar as opções:

1. Projects > Create Project From Template > “Projeto de Desenvolvimento” > Create Project.
2. Ao criar um projeto será solicitado a seleção de um projeto *template*:

   1. Selecione a opção "Projeto de Desenvolvimento";
3. Preencha os campos:

   1. Project Name: deverá ser preenchido com o nome do Projeto. **Exemplo:** Desenvolvimento Serviços Faturamento
   2. Project Key: deverá ser preenchido com a [nomenclatura padrão](http://tdn.totvs.com/x/2JklE) de Projeto de Desenvolvimento. **Exemplo:** DSERFAT
   3. Project Owner: deverá ser escolhido o usuário que terá perfil de Administrador do Projeto.

Após a criação do projeto será apresentada a tela abaixo com as opções:

* ***Browse***: ir para o painel de Navegação do Projeto.
* ***Administer***: ir para o painel de Administração do Projeto.
