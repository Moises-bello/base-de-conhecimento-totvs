![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Preciso alterar o fabricante de um item do Purchase Order, porém o campo fabricante está desabilitado.   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões]  
  
**Solução**O sistema não permite alterar o fabricante de um item no *Purchase Order* quando o item já está inserido em um embarque. Nesse caso,  para alterar o fabricante do item no Purchase Order, é necessário retirar o item do  embarque.
