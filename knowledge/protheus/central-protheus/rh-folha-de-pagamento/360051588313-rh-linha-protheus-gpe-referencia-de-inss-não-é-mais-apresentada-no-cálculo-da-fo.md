**Ocorrência**  
Referencia de INSS não é mais apresentada no cálculo da folha.  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - GPE Gestão de Pessoal - A partir da versão 12.  
  
**Causa**  
Novo cálculo de INSS pela tabela progressiva.  
  
**Solução**Neste novo método de INSS Progressivo, o cálculo do INSS passa pelas Faixas até chegar na base de salário da matricula.  
Desta forma, como não é mais aplicado um percentual direto, não haverá mais referencia no desconto de INSS.  
![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360078684214)

Exemplo de conferência:  
**Base de INSS 2.863,09**

faixa 1 = 1.045,00 X 7,5 % = 78,37  
faixa 2 = 2089,60 - 1.045,00 = 1.044,60 X 9% = 94,01  
faixa 3 = 2.863,09 - 2.089,60 = 773,49 X 12% = 92,81

Assim é possível somar o resultado de todas as faixas pra descontar o INSS do funcionário que é 78,37 + 94,01 + 92,81 = 265,19.
