# CADASTRO DE OCORRÊNCIAS - PORTAL PROFESSOR

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacinoal. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Cadastro de ocorrências para alunos no portal do professor. |
| **Situação/Requisito:** | Na visão de cadastro de ocorrências ao clicar para realizar o download do arquivo associado, o sistema tentava abrir o arquivo em uma janela modal. Apesar do tamanho mínimo que impedia a leitura, a visualização de aquivos em pdf ocorria sem problemas. Porém quando um arquivo em outro formato era exibido uma mensagem de erro era exibida para o usuário. |
| **Solução/Implementação:** | A visão foi alterada para que ao clicar no botão de download uma visão seja exibida e o usuário só tenha a opção para baixar o arquivo. Os arquivos não serão exibidos no navegador, eles apenas serão baixados para a máquina do usuário. |
