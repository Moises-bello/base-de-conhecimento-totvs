Dúvida**Como calcular rescisão com data retroativa no módulo Folha de Pagamento?

**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Através do módulo de Folha de Pagamento, não é possível realizar o cálculo da rescisão com data retroativa através do módulo de Folha de Pagamento. O sistema não efetua o cálculo de valores de rescisão quando a data cadastrada é retroativa à competência atual. No entanto, é permitido cadastrar a rescisão com data retroativa, independentemente do tipo, mas o cálculo retroativo não é viável.  
  
Existem duas alternativas para inserir a movimentação: é possível inserir os valores por meio da ficha financeira ou por importação de dados.

* **1****ª Opção:** Cadastrar a movimentação manualmente via ficha financeira.
* **2ª Opção:** Através do processo de importação de dados.
