**Linha** **RM x Protheus SigaMNT - U\_UPDPMS**

---

O U\_UPDPMS é um aplicativo integrado ao Protheus smartClient que efetua a parametrização dos dados que trafegarão entre as integrações. Essa é uma parametrização necessária para o correto funcionamento da integração.  
    
 **Para executar o U\_UPDPMS acesse :**

1. Protheus Smart Client.  
 2. Preencher os campos :   
 o **Starting Program**: infromar U\_UPDPMS .   
 o **Connection**: Tipo de conexão  
 o **Server Enviroment** : Base de dados que utilizará.  
 3. Clique em Ok para se conectar.  
 4. Clique em sim para confirmar a mensagem.  
 5. Após a finalização do processamento verificar se a data gerada é superior a 19/09/2012.
