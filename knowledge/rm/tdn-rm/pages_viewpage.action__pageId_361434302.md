# Retrospectiva de Saldos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Relatório Retrospectiva de Saldos |
| **Situação/Requisito:** | O relatório Retrospectiva Gerencial/Contábil foi parametrizado para exibir contas gerencias grau 1, porém os valores das contas contábeis não estão sendo consolidados, ou seja, as contas se repetem desrespeitando o grau gerencial. |
| **Solução/Implementação:** | O relatório Retrospectiva Gerencial/Contábil foi alterado para consolidar os valores das contas contábeis, respeitando o grau da conta gerencial. O mesmo comportamento será adotado por outros relatórios como o Retrospectiva Contábil/Gerencial, por exemplo. |
