**Dúvida**No momento de gerar a nota Filha na rotina do Recebimento de importação é possível digitar as quantidades?  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - Easy Import Control - Todas as versões  
  
**Solução**O campo percentual é um facilitador onde é possível calcular o percentual das quantidades do processo, mas é possível informar as quantidades dos itens na coluna *Quantidade a Utilizar* manualmente. Com isso é possível informar a quantidade desejada para cada produto informado no processo como é mostrado na imagem abaixo.
