Este assistente possibilita ao usuário do TOTVS Educacional ofertar uma matriz aplicada de uma forma mais ágil. Uma Matriz Aplicada é uma matriz curricular vinculada a uma filial, um nível de ensino e um turno.   
E esta matriz aplicada deverá estar ativa para que o processo funcione corretamente.

O usuário deverá ter permissão para executar este processo.

O processo também possibilita a associação de descontos por antecipação as matrizes aplicadas que serão ofertadas (Para o usuário vincular descontos por antecipação a matriz aplicada ele precisa ter permissões na funcionalidade de desconto por antecipação no módulo financeiro).

O assistente de " Ofertar matriz curricular" está disponível em Cadastros |Acadêmicos| Matriz curricular| Matrizes curriculares. Estará acessível como item de "Processos" na tela de visão dos registros de matrizes curriculares.

A partir da versão **12.1.2406**, foi incluído o parâmetro oferta ativa na [matriz aplicada](https://tdn.totvs.com/pages/editpage.action?pageId=425458548) que permite habilitar ou desabilitar a matriz aplicada para a vinculação da oferta. Ao realizar o processo o sistema gera as matrizes aplicadas com este parâmetro habilitado, quando o status [matriz curricular](https://tdn.totvs.com/display/LRM/Matriz+Curricular) estiver Ativa ou Atual.  Para a matriz curricular inativa ao finalizar o processo o sistema gera as matrizes aplicadas com o parâmetro desabilitado.  

Outra mudança foi com relação ao nome do parâmetro Oferta ativa para oferta ativa para a matrícula.
