# CAMPOS COMPLEMENTARES PESSOA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Gestão de Pessoas* |
| **Função:** | *Campos complementares de Pessoas* |
| **Situação/Requisito:** | *Ao preenchermos os campos complementares de uma pessoa o sistema apaga os dados da visão e também não leva as informações para o banco de dados.* |
| **Solução/Implementação:** | *Ao editar um registro de pessoa que não possui campos complementares são inseridos os defaults. Desse modo, durante a edição a inserção de campos complementares foi normalizada.* |
