# PORTAL - ALUNO - MATRÍCULA ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM.* |
| **Segmento:** | *Educacional.* |
| **Módulo:** | *TOTVS Gestão Educacional.* |
| **Função:** | *Simulação de pagamento durante matrícula online.* |
| **Situação/Requisito:** | *A simulação de valores das parcelas durante a matrícula online não levava em consideração alguns cenários, como seleção de disciplinas equivalentes e situações de matrícula que não estivessem parametrizadas para contar como créditos financeiros.* |
| **Solução/Implementação:** | *Alteração na simulação de parcelas na matrícula online para que valide os seguintes cenários: -Só serão levadas em consideração disciplinas matriculadas com situação de matrícula parametrizada como "Contar como créditos financeiros". -Ao selecionar disciplinas equivalentes, a simulação levará em consideração o parâmetro "Usar valor do crédito financeiro da matriz do aluno".* |
