# ASSOCIAÇÃO DE AVALIAÇÃO DESCRITIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Avaliação descritiva |
| **Situação/Requisito:** | Ao realizar uma associação de uma avaliação de descritiva, onde uma avaliação não possui nota lançada, o sistema apresenta uma mensagem de validação que impede a execução do processo. |
| **Solução/Implementação:** | Foi detectado que o sistema estava exigindo o preenchimento desse campo para a execução do processo. Considerando que o campo não é obrigatório quando a nota é conceitual, retiramos a obrigatoriedade, na execução do processo, do valor da nota. |
