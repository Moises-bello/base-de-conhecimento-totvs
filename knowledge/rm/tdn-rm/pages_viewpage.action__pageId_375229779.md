# EXCLUSÃO DE MATRÍCULA NO PERÍODO LETIVO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Matrícula no Período Letivo |
| **Situação/Requisito:** | Ao excluir uma matrícula no período letivo estão sendo excluídos todos os documentos exigidos, de todos os cursos. |
| **Solução/Implementação:** | Alteração na rotina de exclusão da matricula no período letivo, para que sejam excluídos apenas os documentos solicitados que não estejam vinculados a outro curso. |
