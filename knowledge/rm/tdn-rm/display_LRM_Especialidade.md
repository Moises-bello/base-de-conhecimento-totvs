## **01. VISÃO GERAL**

Nesta tela serão cadastradas as Especialidades dos Prestadores de acordo com os Convênios.

O sistema só permite exclusões da especialidade, caso não possua nenhum lançamento já realizado para aquele prestador com a especialidade informada para o convênio

**Principais Campos**

| Campo | Descrição |
| --- | --- |
| **Convênio** | Convênio a ser escolhido para vincular à Especialidade. Neste campo, pode-se escolher o Item "Todos os Convênios" para que o Sistema relacione a Especialidade escolhida a todos os convênios. |
| **Médico Autorizador** | Só se aplica quando o convênio SUS. Indica se naquela especialidade o Prestador pode atuar como autorizador da tela **Autorizador das Especialidades.**  Caso só existe um autorizador para a especialidade selecionada o campo "Autorizador" será preenchido automaticamente, caso contrário o usuário deverá escolher. |
