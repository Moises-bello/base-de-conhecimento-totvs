No Protheus, é possível realizar a leitura de código de barras na conferência física na rotina Produto x Fornecedor usando o parâmetro MV\_CBSA5.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/39165922520855) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
É possível realizar a leitura de código de barras na conferência física, pelo emulador na rotina de produto x fornecedor?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Automação e Coleta de Dados - Todas as versões.  
  
**Solução**  
Na nativo do Protheus, é possível sim realizar a leitura do código de barras, na rotina Produto x Fornecedor, utilizando a rotina de conferência, através do parâmetro **MV\_CBSA5.**  
   
Segue um boletim dos parâmetros do SIGAACD, demostrando a descrição do parâmetro citado acima.
