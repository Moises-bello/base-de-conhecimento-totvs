# Falha ao carregar alíquota para os tributos INSS, FUNRURAL na inclusão de movimentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | Serviço de Tributação |
| **Situação/Requisito:** | Ao incluir movimentos que possuem os tributos INSS ou FUNRURAL é carregada a alíquota do INSS ou FUNRURAL para os tributos INSS15, INSS20, INSS25, SEST E SENAR. |
| **Solução/Implementação:** | Ajuste no serviço de tributação para recuperar as aliquotas adicionais do INSS e FUNRURAL. |
