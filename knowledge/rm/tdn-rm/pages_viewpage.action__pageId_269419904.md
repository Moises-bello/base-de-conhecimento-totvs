# Lançamento

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Lançamento |
| **Situação/Requisito:** | Quando o parâmetro "Calcular valor líquido automaticamente na visão” está marcado, o campo do valor liquido não é preenchido automaticamente quando é encontrado algum inconsistência no calculo do valor liquido desses lançamentos. |
| **Solução/Implementação:** | Otimização no processo de calcular valor líquido automaticamente na visão de lançamentos. Agora o sistema carrega todos os lançamentos com o campo do valor liquido preenchido mesmo quando é encontrado alguma inconsistência no calculo do valor liquido dos lançamentos. |
