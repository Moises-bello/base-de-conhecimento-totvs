# REMOVER ALTERAÇÃO DE DADOS FUNCIONAIS PROGRESSIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão de Pessoas |
| **Função:** | Remover Alteração de Dados Funcionais Progressiva |
| **Situação/Requisito:** | Em 'Alteração de Dados Funcionais', ao tentar excluir uma progressão existente no anexo 'Alteração de Dados Funcionais Progressiva' através do processo 'Remover Alteração de Dados Funcionais  Progressiva', ocorre o seguinte erro: "Informações sobre a linha excluída não podem ser acessadas através da linha." |
| **Solução/Implementação:** | Realizado ajuste para que não ocorra erros ao excluir uma progressão através do processo "Remover Alteração de Dados Funcionais Progressiva". |
