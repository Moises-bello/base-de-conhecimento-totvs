# Publicações - assinaturas de periódicos

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Bibliotecária* |
| **Função:** | *Cadastro de assinatura de periódicos na publicação* |
| **Situação/Requisito:** | *O número de exemplares previstos para serem recebidos estavam sendo atualizados pela exclusão de um registro na lista de periódicos, além do fato que o sistema estava incorretamente apresentando a mensagem de regeração dos periódicos.* |
| **Solução/Implementação:** | *Ajuste na função para atualizar o número de exemplares apenas quando os campos periodicidade, data prevista para primeira entrega ou data final forem alteradas e ajuste na emissão da mensagem de regeração para que a mensagem seja apresentada apenas nos momentos adequados.* |
