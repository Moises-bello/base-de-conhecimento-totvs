# Teclado do EducaMobile pelo eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Teclado do EducaMobile pelo eduCONNECT |
| **Situação/Requisito:** | Quando clicamos em um campo de busca, texto no EducaMobile pelo eduCONNECT a barra inferior, referente às mensagens da timeline, era exibida a ponto de atrapalhar a navegação no EducaMobile. |
| **Solução/Implementação:** | Aperfeiçoamento na exibição do teclado no eduCONNECT em dispositivos Android para impedir que a barra inferior, referente à navegação para a timeline, seja redimensionada ao ponto de atrapalhar a exibição do EducaMobile no webview. Essa situação ocorria quando clicávamos em um campo texto, e o teclado era expandido. Consequentemente, a barra inferior de mensagens também era redimensionada. |
