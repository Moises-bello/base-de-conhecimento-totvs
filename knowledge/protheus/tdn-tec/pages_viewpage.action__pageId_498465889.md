Correção - SmartClient para Mac OS apresenta algumas janelas sem foco para mouse

|  |  |
| --- | --- |
| Situação | Utilizando o SmartClient em um Sistema Operacional Mac, algumas telas do Protheus abrem com o foco do teclado mas não com o foco do mouse, sendo necessário fazer um primeiro clique sobre a janela para então poder fazer clique sobre algum componente da tela. |
| Ocorrência | Ocorre, por exemplo, ao abrir telas de cadastro/edição/visualização e também ao retornar delas para uma tela com a listagem (browse). |
| Correção | O SmartClient para Mac OS recebeu uma correção para aplicar corretamente o foco do mouse. |
| Informações adicionais | * Referente ao chamado: 5625424 * Referente à ocorrência: MTEC-2563 * Disponível em builds iguais ou superiores a 13.2.3.41 |
