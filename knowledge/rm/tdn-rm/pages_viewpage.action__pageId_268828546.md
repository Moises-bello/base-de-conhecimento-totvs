# Enturmação em Turma Mista

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Enturmação em Turma Mista |
| **Situação/Requisito:** | Ao realizar uma enturmação de um novo aluno em uma turma mista que já teve enturmação, e após aciona o botão “Numeração automática” o novo aluno fica com o número no diário em branco.  Isto ocorre somente se a enturmação estiver ocorrendo em uma data superior à da data limite para numeração automática definida na parametrização por curso, e com isso não é possível mais definir um número para o aluno. |
| **Solução/Implementação:** | Melhoria no processo de enturmação em turma mista para que ao acionar o botão “Numeração automática” seja possível o usuário definir o comportamento da numeração que será aplicado.  1º Enumerar turma mista respeitando a data limite para numeração automática definida na parametrização por curso.  2º Enumerar toda turma mista ignorando a data limite para numeração automática definida na parametrização por curso.  3º Numerar turma mista atribuindo último número do diário ao novo aluno |
