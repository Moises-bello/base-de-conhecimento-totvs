Nesta opção de menu estão relacionados todos os Tipos de Receita disponíveis no sistema.  
 Esta tabela é fixa, ou seja, o usuário não tem permissão para cadastrar tipos de receitas.

Caso o parâmetro "Tipo de Receita" em Parâmetros Gerais | Opcionais, esteja marcado, será necessário informar para cada tipo de receita quais os registros correspondentes no RM Fluxus.

Através do cadastro é possível controlar:

**Identificação**

Ao editar um Tipo de Receita, abrirá a janela de edição, na pasta Identificação, onde iremos cadastrar os seguintes campos:

* Código: Código do Tipo de Receita. Este campo é fixo do sistema e não poderá ser alterado;
* Nome Interno: Nome do Tipo de Receita. Este campo é fixo do sistema e não poderá ser alterado;
* Nome Externo: Informe o nome externo para este Tipo de Receita.

Exemplo: Um exemplo de funcionalidade deste cadastro é definir o Tipo de Receita de alguma parcela do plano de financiamento de uma venda.
