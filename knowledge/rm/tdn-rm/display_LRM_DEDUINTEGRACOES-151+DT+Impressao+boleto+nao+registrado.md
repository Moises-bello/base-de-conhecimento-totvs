# IMPRESSÃO DE BOLETO NÃO REGISTRADO

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Educacional* |
| **Rotina:** | Impressão de boletos |

## Descrição

Permitir a parametrização do sistema para que seja possível imprimir apenas os boletos já registrados para convênios de cobrança registrada.

**Configuração no Totvs Gestão Educacional**

O parâmetro está disponível em: **Totvs Gestão Educacional | Configurações | Parâmetros | Tesouraria | Relatórios**

**Parâmetros**

* **Permite a impressão de boletos não registrados**  
  Caso esteja selecionado irá permitir que os boletos provenientes de convênios com cobrança registrada sejam impressos, mesmo que os boletos não tenham sido registrados. Nessa situação, caso o boleto não tenha sido registrado, na solicitação de impressão será exibida uma mensagem informando da situação, mas o relatório será exibido normalmente:  
    
    
    
    
    
  Caso **não** esteja selecionado, ao solicitar a impressão de um boleto que não tenha sido registrado será exibida uma mensagem informando a situação do boleto e o relatório não será impresso:
