**Dúvida**O que é código ISPB e onde posso configurar para envio da remessa de PIX ?  
  
**Ambiente**Cross Segmento - Backoffice Linha Protheus - Financeiro - A partir da versão 12.1.23  
  
**Solução**No cadastro de **Bancos** (**MATA070 - Atualizações -> Cadastros -> Bancos**) há um novo campo com nome de **Código ISPB**, que é o Identificador do Sistema de Pagamentos Brasileiro, necessário para envio no **CNAB Receber**. É um número único por banco e poderá ser solicitado na agência. No link abaixo também há uma relação, disponibilizada pelo banco Central:

<https://www.bcb.gov.br/pom/spb/estatistica/port/ASTR003.pdf>
