# GERAÇÃO DE ARQUIVO DE CONCLUINTES DO ENADE

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Educacional |
| **Função:** | Geração de arquivo ENADE |
| **Situação/Requisito:** | Para alguns alunos, é exibida a mensagem "Matriz curricular deve conter as informações dos campos "Total de créditos", Carga Horária" e "Máx. créditos" cadastradas.". Porém todos os dados estão preenchidos e o erro persiste. |
| **Solução/Implementação:** | A rotina de  cálculo do ano/período de conclusão do ENADE foi alterada para que a mensagem "Matriz curricular deve conter as informações dos campos 'Total de créditos', 'Carga Horária' e 'Máx. créditos' cadastradas." não seja exibida quando a carga horária cursada pelo aluno for superior à carga horária do curso. |
