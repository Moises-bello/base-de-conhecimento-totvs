# Campos de valor opcional disponibilizado para TOTVS Smart Analytics

|  |  |
| --- | --- |
| **Produto:** | TOTVS Gestão Financeira |
| **Versões:** | 12.1.19 e 12.1.18.107 ou superiores. |
| **Ocorrência:** | Necessidade de utilizar os valores opcionais do lançamento como valores de análise no GoodData. |
| **Ambiente:** | RM, GoodData, Totvs Smart Analytics |
| **Passo a passo:** | Acessar o cadastro dos conceitos relacionados às Fatos e realizar a ligação dos campos de valores opcionais com os campos Livres disponíveis. |
| **Observações:** | Implementação para disponibilizar os campos de Valor Opcional dos Lançamentos Financeiros para serem utilizados no GoodData |
