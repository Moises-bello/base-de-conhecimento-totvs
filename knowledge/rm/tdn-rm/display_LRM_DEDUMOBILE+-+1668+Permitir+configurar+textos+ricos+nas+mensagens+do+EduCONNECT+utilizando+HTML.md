## Descrição

Para a parametrização da mensagem em HTML, o usuário contará com a formatação de *Tags* existentes em cada categoria da mensagem, links, alinhamento, listas, parágrafo, cores. Não será possível alterar o tipo de fonte, onde por default, a fonte padrão para utilizada para o texto será Nunito Sans, a mesma fonte utilizada no *App* eduCONNECT.

As mensagens parametrizadas seguem o limite máximo de caracteres no texto formatado (já com as TAG's HTML) será de 4000 caracteres. Será apresentado uma mensagem para o usuário, caso extrapole a quantidade máxima tanto na parametrização do texto ou no processo de envio de mensagens.

Para os textos no formato HTML, não será possível anexar nenhum  arquivo (imagem, pdf, entre outros) no corpo do texto.
