# ALTERAÇÃO GLOBAL DE SALÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |

| **Função:** | *Alteração Global de Salários* |
| **Situação/Requisito:** | Ao realizar a rotina de alteração salarial retroativa a data de transferência do funcionário o sistema seta a data de mudança no histórico salarial com a data de transferência. |
| **Solução/Implementação:** | Alterado a regra para considerar apenas a transferência com ônus para cedente ao buscar a data de admissão para funcionário transferido na alteração global de salário. |
