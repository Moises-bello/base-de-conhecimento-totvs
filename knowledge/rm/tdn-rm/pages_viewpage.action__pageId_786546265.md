Para agilizar e facilitar a Associação dos Itens de Evento Contábil à Dimensão, foi disponibilizado um processo. Para isso, **selecione uma única Dimensão Contábil** para que seja efetuada a Associação, em seguida selecione os Itens de Evento Contábil desejados e execute o processo.

**Observações**

* É permitida a seleção de uma única Dimensão Contábil para executar o processo.
* Para gravar os Itens de Evento, é obrigatória seleção de um ou mais Itens.
