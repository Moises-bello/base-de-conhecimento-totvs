![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/16980146960279) Tempo aproximado para leitura: **00:00:30 min** **Dúvida**Como gerar o relatório Arquivo Controle de Jornada para Efeitos Fiscais (ACJEF) da Portaria 1510?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Automação de Ponto - A partir da 11.80  
  
**Solução**Para gerar o relatório Arquivo Controle de Jornada para Efeitos Fiscais (ACJEF) da Portaria 1510, basta acessar no módulo Automação de Ponto o menu **Relatórios | ACJEF**: **![](https://centraldeatendimento.totvs.com/hc/article_attachments/30152644303639)**

Ao abrir a tela de geração do relatório e valide os campos;

**1-Período**: Selecione o período desejado

**2-Seleção de Funcionários:** Faça o filtro desejado.

**3-Nome do Arquivo:** Informe o nome do arquivo.

**4-Salvar o(s) arquivo(s) na pasta:** Informe o caminho onde o arquivo vai ser salvo.     
**5-** Clique no botão executar o processo.

**![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/34664155908503)**

Ao aparecer a mensagem abaixo, clique em ok:*Atenção! Devido a validação da integridade das informações na base de dados para a emissão dos registros da Portaria 1.510, esse processo pode levar alguns minutos.*

*![](https://centraldeatendimento.totvs.com/hc/article_attachments/30152644305815)*No final da execução clique no botão Exibir Arquivo, ou acesse o caminho selecionado onde o arquivo foi salvo para visualizá-lo.   
  
Observações:

- O arquivo é gerado em .txt(bloco de notas) seguindo a regra da portaria 1.150.

- O relatório é gerado individualmente por cada período.  
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/30152644306967) **Importante**  
Para realizar o processo de gerar relatórios não é necessário que o período a ser gerado esteja definido como ativo, mas os dados do mesmo devem estar nas tabelas de produção. Para conferir se os registros estão em tabela de produção acesse o link abaixo:   
[Como transferir dados para a tabela de produção](https://centraldeatendimento.totvs.com/hc/pt-br/articles/5695661925399-TOTVS-RH-Linha-RM-PTO-Como-transferir-dados-para-a-tabela-de-produ%C3%A7%C3%A3o)
