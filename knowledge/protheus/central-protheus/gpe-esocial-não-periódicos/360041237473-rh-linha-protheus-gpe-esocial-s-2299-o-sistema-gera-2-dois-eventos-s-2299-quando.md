**Dúvida**  
O sistema gera 2 (dois) eventos S-2299 quando realizado o desligamento de 2 trabalhadores múltiplos vínculos no mesmo mês?  
  
**Ambiente**  
TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – Todas as versões  
  
**Solução**  
Sim. Mesmo que a Raiz de CNPJ seja igual (8 primeiros dígitos) o sistema vai gerar 2 eventos S-2299 para os trabalhadores desligados. Esse processo é diferente de quando existe folha para múltiplos vínculos onde só é gerado 1 eventos S-1200 para os vínculos caso a Raiz de CNPJ seja a mesma.
