**Dúvida**Função para retirar zeros a esquerda de uma variável numérica?   
  
**Ambiente**Cross Segmentos - Backoffice (Linha Protheus) – ADVPL – A partir da versão 11.80  
  
**Solução**

Não temos uma função padrão, porem é possível criar um validação customizada no qual irá retirar os zeros à esquerda de uma string. Conforme exemplo abaixo.

![gif6.gif](https://centraldeatendimento.totvs.com/hc/article_attachments/20950240468247)

Ainda é possível utilizar funções como SUBSTR() / STRTRAN() para criar validações diferentes da proposta no exemplo para retirar os zeros à esquerda de uma string.
