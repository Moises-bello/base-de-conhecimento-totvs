## **01. VISÃO GERAL**

As permissões de acesso do PEP RM são configuradas da mesma forma que as permissões das aplicações RM Desktop. Para mais informações sobre a configuração de permissões na plataforma RM clique [aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=146182940).

Exemplo de utilização

## **02. EXEMPLO DE UTILIZAÇÃO**

Acesse **Serviços Globais → Segurança → Perfis**e selecione o perfil dos usuários que deseja configurar as permissões.

Telas de passo a passo

## **03. TELAS DE PASSO A PASSO**

* No cabeçalho da lista, selecione o sistema **Gestão Hospitalar**.

* Clique na aba **Acesso a Menus**e selecione o item **Prontuário Eletrônico**. As permissões devem ser exibidas conforme abaixo:

* Configure as permissões conforme desejar para o perfil selecionado, utilizando os botões **Permitir Acesso**e **Proibir Acesso**.

IMPORTANTE

**Ordem dos menus**

O item **Telas iniciais** contém os menus exibidos após o login: agenda, [painel de eletivos](https://tdn.totvs.com/display/SaudePiloto/Painel+de+Eletivos) e [lista de pacientes](https://tdn.totvs.com/display/SaudePiloto/Listagem+de+Pacientes). Já o item **Prontuário paciente** contém os menus internos do paciente. A remoção de uma permissão de menu implica na ausência do menu na seleção do usuário.
