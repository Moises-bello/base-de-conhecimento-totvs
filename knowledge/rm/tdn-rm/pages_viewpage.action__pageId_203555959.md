# BOLSA RETROATIVA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Gestão Educacional* |
| **Função:** | *Exclusão de bolsa de crédito de forma retroativa* |
| **Situação/Requisito:** | *Ao remover uma bolsa de crédito de forma retroativa para uma parcela que possui mais de uma bolsa de crédito associada, o sistema cancela todos os lançamentos de bolsa créditos.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de exclusão de bolsa retroativa, de forma a garantir que, ao remover uma bolsa de crédito, o sistema cancele apenas o lançamento referente a bolsa que está sendo excluída.* |
