**Dúvida**TDS não faz a conexão com servidor.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice Linha Protheus - ADVPL - a partir da versão 12.1.25

**Solução**

O **TDS 11.3.12** é compatível apenas com AppServer release 17.x.x.

Para o uso com AppServer release 19.x.x é preciso utilizar o **TDS 11.3.15**, que passa a ser um **plug-in do [VSCode](https://code.visualstudio.com/).**

O suporte versões **TDS 11.3.12** e**11.3.15** se **encerra em 31/12/2020**

A partir de **Janeiro/2021** nossa extensão para o editor **[VSCode](https://code.visualstudio.com/)** passa a ser a **única IDE suportada**, fornecendo um ambiente simples e performático para desenvolvimento AdvPL, sendo compatível com todos os ApServers 13.x.x ou superior.
