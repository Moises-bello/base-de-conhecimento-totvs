Para que o processo "Captura Títulos em Cobrança" seja realizado corretamente é necessário o preenchimento do Layout de DDA.  
Através destas informações o sistema consegue encontrar no arquivo bancário as informações necessárias para realizar a Conciliação dos Títulos em Cobrança com os lançamentos existentes na base de dados.  
Para o correto preenchimento do layout consulte o layout fornecido pelo banco.
