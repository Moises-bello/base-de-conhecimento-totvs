# RM Reports

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *RM Reports, relatório da visão do funcionário com a opção de visível para todas as coligadas.* |
| **Situação/Requisito:** | Não conformidade ao utilizar um relatório VISÍVEL A TODAS AS COLIGADAS na visão de funcionários, em que o o relatório é gerado em branco. |
| **Solução/Implementação:** | Gerar os relatórios do RM Reports com as devidas informações quando o mesmo tiver a opção de "Visível a todas as coligadas" marcada e o relatório seja do tipo de visão do funcionário. |
