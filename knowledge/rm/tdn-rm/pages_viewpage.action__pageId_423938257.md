Ao criar Períodos de Orçamentos com periodicidades coincidentes, será criada uma tabela de 'Classificação de Período' que permitirá salvar o mesmos com classificação diferenciada, exemplo:

| 1º Trimestre | |
| --- | --- |
| Jan | R$2.000,00 |
| Fev | R$4.000,00 |
| Fev | R$6.000,00 |

Classificação do Período: **001**

| 1º Trimestre | |
| --- | --- |
| Jan | R$3.000,00 |
| Fev | R$7.000,00 |
| Fev | R$10.000,00 |

Classificação do Período: **002**

***Observação**:*Os períodos serão classificados de acordo com esta nova tabela. Os Orçamentos originados do RM Solum terão Períodos e Classificação de Períodos distintos.  
 Para não permitir que um Centro de Custo faça parte de mais de um Orçamento ativo, será criado um 'Vinculo entre Centro de Custo e Classificação de Período'.
