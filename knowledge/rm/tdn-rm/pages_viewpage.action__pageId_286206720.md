# Geração do Registro I157 via importação da ECD (ano anterior).

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Contábil |
| **Função:** | Geração do Registro I157 via importação da ECD (ano anterior). |
| **Situação/Requisito:** | Ao realizar a importação do arquivo anterior da ECD para auto preenchimento das contas anteriores do registro I157 (Controle de plano de contas anterior) e caso alguma conta não seja apresentada no ultimo mês do arquivo (Registro I150), a mesma não é levada para o sistema. |
| **Solução/Implementação:** | Melhoria no processo de importação do arquivo da ECD (ano anterior) "Identificar Contas do Plano de Contas Anteriores Automaticamente" para geração do registro I157 de forma que a importação não valide somente as contas que não existem no plano de contas atual e no último período de saldo permitindo que contas que tiveram uma linha do registro I155 (Saldo Periódico) em um período qualquer sejam importadas também. |
