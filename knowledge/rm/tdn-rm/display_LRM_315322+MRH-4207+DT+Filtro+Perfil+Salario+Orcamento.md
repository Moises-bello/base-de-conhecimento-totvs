# FILTRO POR PERFIL NO CAMPO DE SALÁRIO DO ORÇAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projeto |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Orçamento |
| **Situação/Requisito:** | O sistema não está respeitando as permissões de campo que foram informadas no perfil do usuário, quando o mesmo acessa qualquer tela do orçamento.  Pois mesmo bloqueando o campo para não permitir visualização o sistema não oculta o campo como é feito em todas outras telas do sistema. |
| **Solução/Implementação:** | Foi ajustado o sistema para respeitar as permissões de campos para que o campo não seja exibido caso exista alguma restrição para o mesmo. |
