No cadastro de ativo fixo do TOTVS Protheus (rotina ATFA012), é possível visualizar o código do produto na aba "Dados Complementares", no campo Cod. Produto (N1\_PRODUTO). Para isso, acesse a rotina, localize o bem desejado e verifique esse campo.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/40043845283991) Tempo aproximado para leitura: 00:03 min  
  
**Dúvida**  
Existe algum campo no cadastro de ativo que demonstre o código do produto?

**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - SIGAATF - A partir da Versão 12  
  
  
**Solução**  
Épossível localizar o código do produto acessando a aba "Dados Complementares" dentro da rotina de cadastro do ativo fixo, no campo Cod. Produto (N1\_PRODUTO).  
  
**Passos**

1. Acesse a rotina de cadastro de ativo (ATFA012).
2. Localize o bem que deseja verificar o código de produto.
3. Verifique na aba "Dados Complementares" o campo Cod. Produto (N1\_PRODUTO).
