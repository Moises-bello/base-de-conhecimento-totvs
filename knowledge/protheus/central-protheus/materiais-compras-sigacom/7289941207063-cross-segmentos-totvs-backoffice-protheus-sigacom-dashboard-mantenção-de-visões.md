Como criar visão para usuário ?   
  
**Ambiente**  
Cross Segmentos - Totvs Backoffice Protheus - SIGACOM - Dashboard - Mantenção de visões  
  
**Solução**

O administrador possui a permissão de criar uma visão para um usuário.

Para incluir uma nova Visão para o usuário:

1) Clicar no menu Gerenciar Visões;

2) Clicar no botão Incluir;

3) Informar os campos conforme sequência:

a) Título: Informar um título para a visão;

b) Descrição: Informar uma descrição para a visão;

c) Status: Define se a visão está habilitada ou desabilitada para visualização;

d) Cards: Informar os cards que serão apresentados na visão;

e) Gráficos: Informar os gráficos que serão apresentados na visão;

f) Usuários: Informar os usuários que terão acesso a visão;

g) Clicar no botão Salvar para concluir a operação:
