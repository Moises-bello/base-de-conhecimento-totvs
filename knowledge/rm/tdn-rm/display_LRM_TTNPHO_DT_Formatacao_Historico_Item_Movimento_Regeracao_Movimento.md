# HISTÓRICO DO ITEM DE MOVIMENTO NÃO ESTÁ SENDO FORMATADO NA REGERAÇÃO DE MOVIMENTOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Regeração de Movimentos* |
| **Situação/Requisito:** | Item de movimento não está sendo formatado no processo de regeração de movimentos |
| **Solução/Implementação:** | Ajuste na regeração de movimentos passando o item de contrato considerado na preparação do item de movimento. Sem informar o item de contrato, o sistema não conseguia saber que a geração de movimentos era por competência e, por consequência, não formatava o histórico do movimento na regeração. |
