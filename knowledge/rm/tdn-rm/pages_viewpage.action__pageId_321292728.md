# REMATRÍCULA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Comprovante de matrícula no processo de rematrícula. |
| **Situação/Requisito:** | Visualização do comprovante de matrícula. |
| **Solução/Implementação:** | • Ao final do processo de matrícula será exibida uma mensagem de confirmação conforme o parâmetro "Mensagem de confirmação de matrícula" localizado em Parâmetros -> Portal -> Matrícula.  • Além da mensagem de confirmação, serão apresentadas as opções para impressão de boleto (se a matrícula estiver configurada para gerar lançamentos através do parâmetro "Gerar lançamentos"), opção de pagamento com cartão (se a instituição utilizar o pagamento de boletos com cartão de crédito) e a opção de impressão do comprovante de matrícula conforme regras abaixo.  • Se o parâmetro de "disponível para impressão" do comprovante de matrícula estiver marcado (Parâmetros -> Portal -> Matrícula), será exibida a opção de impressão para o aluno/responsável.  • O texto do comprovante será exibido conforme o parâmetro "Texto do comprovante de matrícula" (Parâmetros -> Portal -> Matrícula) e as tags utilizadas serão substituídas de acordo com a informação solicitada. |
