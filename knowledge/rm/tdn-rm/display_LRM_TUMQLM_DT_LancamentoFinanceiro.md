# Lançamento Financeiro

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *Lançamento financeiro* |
| **Situação/Requisito:** | Ao realizar o lançamento financeiro da guia de INSS o sistema não está preenchendo na Capa do lançamento o centro de custo que está informado dentro da seção na aba dados contábeis.  Verificamos que o erro acontece somente quando o parâmetro utiliza calculo por centro de custo se encontra desmarcado |
| **Solução/Implementação:** | Otimizado lançamento financeiro, de forma que o centro de custo da seção seja preenchido pelo sistema na capa do lançamento financeiro, mesmo se o cliente não utilizar cálculo por centro de custo |
