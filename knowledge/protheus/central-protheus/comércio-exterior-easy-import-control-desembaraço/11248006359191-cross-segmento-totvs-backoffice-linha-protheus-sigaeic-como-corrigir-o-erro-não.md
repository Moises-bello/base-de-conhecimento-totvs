![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/22367675268887) Tempo aproximado para leitura: **05:00 min** **Dúvida**Como corrigir o erro "Não foi possível encontrar o ISAM instalável", ao exportar dados para a planilha na rotina de Desembaraço?

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/11247345250839)  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – A partir da versão P12.1.27  
  
**Solução**Neste caso, será necessário instalar o *Microsoft Access Database Engine 2010 Redistributable* na máquina local.
