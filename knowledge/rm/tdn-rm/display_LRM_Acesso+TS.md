É possível utilizar um parâmetro global para identificar o uso ou não do Acesso TS. A identificação será feita através do IP exibido no consumo de licenças do Licence Server.

Para utilizar esse processo, basta acessar Serviços Globais:

Em Ambiente, selecionar Parâmetros Globais:

Navegar até a aba Acesso TS.

Com Utilizar cliente TS marcado

            A licença será consumida pela máquina do usuário

Com Utilizar cliente TS desmarcado

            A licença será consumida pelo servidor de TS.
