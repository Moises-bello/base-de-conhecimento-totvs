# Monitor Clínico

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Monitor Clínico / Monitorização | | Cuidados com o Paciente / Centro Cirúrgico / Registro de Informação de Cirurgia | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL Server® / Oracle® |
| **Tabelas Utilizadas:** | \*MCT002\_PARAMETER, MCT004\_SCENARIOALERT, MCT014\_SCENARIOALERT\_ACTIONS |
| **Sistema(s) Operacional(is):** | Windows® 8.1 |

\*Base de dados própria do Monitor Clínico

## Descrição

A partir dessa implementação será possível emitir o relatório da ficha anestésica do Monitor Clínico integrado ao produto TOTVS Gestão Hospitalar.

## Procedimento para Utilização

### **Monitorização**

1. Acesse o Monitor Clínico / Faça o seu Login / Login.
2. Preencha os campos Usuário e Senha.
3. Acesse a localização de paciente.
4. Digite o código do prontuário do paciente a ser monitorado.
5. Inicie o processo de monitorização.
6. Encerre o processo de monitorização quando desejar.

### Relatório da ficha anestésica

1. Acesse Cuidados com o Paciente / Centro Cirúrgico / Registro de Informações Cirúrgicas
2. Marque um registro / Anexos / Relatórios / Monitor Clinico
3. O sistema apresentará o relatório\*.
