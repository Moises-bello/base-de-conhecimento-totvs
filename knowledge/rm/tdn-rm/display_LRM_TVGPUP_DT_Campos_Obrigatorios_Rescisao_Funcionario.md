# CAMPOS OBRIGATÓRIOS NO CADASTRO DA RESCISÃO E FUNCIONÁRIOS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Campos obrigatórios* |
| **Situação/Requisito:** | Ao deixar algum campo do Cadastro da Rescisão como obrigatório, Motivo da Demissão por exemplo, ao editar o Cadastro de qualquer funcionário e efetuar alguma alteração, o sistema retorna o erro: Campo Motivo de Demissão obrigatório, mesmo o funcionário não tendo Rescisão. |
| **Solução/Implementação:** | Permitir cadastrar/alterar o funcionário, não obrigando o preenchimento dos campos obrigatórios que existe na tela de rescisão. |
| **Chamados relacionados:** | TVGPUP |
