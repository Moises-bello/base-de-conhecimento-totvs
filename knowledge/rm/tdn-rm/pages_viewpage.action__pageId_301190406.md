# REGERAR CONTABILIZAÇÃO DE BAIXA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Regerar contabilização de baixa |
| **Situação/Requisito:** | Os eventos contábeis de baixa que possuem a flag “Não validar valor contabilizado zero” marcada em seu cadastro não são apresentados no processo de Regerar Contabilização de Baixa |
| **Solução/Implementação:** | Ajuste na tela de regerar contabilização de baixa para exibir eventos contábeis com o parâmetro "Não validar valor contabilizado zero" marcado. |
