A entrada dos percentuais de completude (apontamentos de Avanço Físico) das tarefas de uma Folha deve ser realizada de forma ágil e dinâmica então sua interface deve fornecer recursos para tal.

O acesso a interface para a leitura de código de barras da folha tarefa fica restrita de acordo com o perfil do usuário.

Além de poder realizar os apontamentos das tarefas via Coletores Móveis, o usuário poderá registrá-los manualmente através do próprio TOTVS Obras e Projetos.

Para isso, existe o anexo "Interface de Coleta via Leitura de Código de Barras" disponível no menu Cadastros | Mobilidade | Folha Tarefa, que contém controles e tratamentos específicos para se efetuar a leitura dos códigos de barras e atualização do sistema a partir dos dados informados nesta área.

Para execução do processo é necessário existir Folhas Tarefas cadastradas com status Pronta para Impressão.

O processo consiste em acessar o anexo Interface de Coleta via Leitura de Códigos de Barras da Folha Tarefa, marcar (ou desmarcar) o indicador de 100%, efetuar a leitura do código de barras (ou digitar), selecionar o percentual de completude da tarefa (somente se o indicador de 100% estiver desmarcado) e salvar.

O sistema interpreta o código de barras identificando a tarefa e atualiza o seu apontamento de acordo com o valor selecionado.

**Atenção:**  
Todos os apontamentos efetuados com o indicador de 100% (checkbox) marcado serão  considerados apontamentos 100% concluídos.
