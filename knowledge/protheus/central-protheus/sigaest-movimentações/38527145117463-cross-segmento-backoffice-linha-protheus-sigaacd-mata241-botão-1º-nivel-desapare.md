O artigo explica que, no TOTVS Backoffice (Linha Protheus) - Estoque/Custos, o botão "1º Nível" desaparecia após ser utilizado uma vez. A correção foi feita por meio de um tratamento no array dos botões. Links para correções em várias versões estão disponíveis.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/38527134219287) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
O botão de nível desaparece na rotina MATA241  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**  
Botão 1º Nível desaparece após utilizar uma vez, para correção foi realizado um Tratamento do Array dos botões.
