![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/20892662846615) Tempo aproximado para leitura: **00:01:00 min****Ocorrência**Qual a diferença entre uma consulta padrão e consulta específica?  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - ADVPL - Todas as versões  
  
**Solução**A ​consulta específica é um programa customizado, criado via User Function, para trazer determinada informação para a consulta.

Já a consulta padrão fornece ao usuário uma maneira simples para exibir e procurar valores nas tabelas do Protheus sem necessidade de uma função customizada.
