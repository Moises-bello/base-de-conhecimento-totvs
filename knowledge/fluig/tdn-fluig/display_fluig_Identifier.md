Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**.

A finalidade desse componente é realizar o roteamento de mensagens recebidas pelo Fluig ESB. Para definir as possibilidades de fluxo baseado no valor que será retornado pelo objeto, pode-se tratar as possibilidades conectando ao Identifier um objeto .

Nos casos em que não for encontrado nenhum valor do objeto When, pode ser conectado ao Identifier um objeto , que desvia o fluxo para uma situação de erro podendo realizar algum tratamento específico.

| Campo | Descrição |
| --- | --- |
| Name | Inserir uma identificação para a configuração do componente. |
| XPath | Inserir expressão XPath responsável por efetuar validações no XML e mapeamento de informações. |
