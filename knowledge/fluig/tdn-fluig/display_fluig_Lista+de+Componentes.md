Fique atento!

O TOTVS ESB não é mais ofertado por se tratar de uma solução legada. A nova solução para realizar integrações é o TOTVS iPaaS. Saiba mais detalhes **[aqui](https://www.totvs.com/totvs-ipaas/)**. 

A tabela abaixo demonstra um resumo de cada componente disponível para construir os diagramas dentro do TOTVS ESB Editor. A seguir, será discriminado o uso de cada componente.
