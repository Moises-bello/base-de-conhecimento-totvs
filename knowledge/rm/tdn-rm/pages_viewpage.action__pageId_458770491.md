# VALOR INVÁLIDO PARA O CAMPO "APLICAR DESCONTO POR ANTECIPAÇÃO"

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Bolsas de contratos |
| **Situação/Requisito:** | Ao inserir a bolsa no contrato em bases que utilizam "classificação de bolsa", o sistema emitia a mensagem de erro: "Valor inválido para o campo Aplicar desconto Antecipação" |
| **Solução/Implementação:** | Ajuste para que o campo de aplicação de desconto por antecipação não tenha um valor inválido quando o parâmetro de aplicação de bolsas está por "Classificação de Bolsa" |
