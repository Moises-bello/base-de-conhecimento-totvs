# Baixa

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Gestão Financeira |
| **Função:** | Baixa |
| **Situação/Requisito:** | Ao trabalhar com o parâmetro 'Permitir Alterar Valores da baixa' desmarcado está sendo possível alterar o valor liquido da baixa alterando os valores dos campos que estão bloqueados. |
| **Solução/Implementação:** | Otimização no processo de baixa trabalhando com o parâmetro 'Permitir Alterar Valores de Baixa' desmarcado. Agora o sistema bloqueia o campo do valor liquido da baixa para que não seja possível o cliente alterar o valor liquido da baixa e consequentemente alterando os valores dos campos que estão bloqueados. |
