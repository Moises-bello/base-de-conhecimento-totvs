# CONTABILIZAÇÃO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Educacional. |
| **Função:** | Novo modelo de contabilização por competência |
| **Situação/Requisito:** | Ao cancelar um contrato contabilizado, o sistema tenta contabilizar a diferença entre o apropriado e o diferido, porém, como o evento possui fórmula que consulta o valor da contabilização e o sistema ainda não gravou as informações no banco de dados, um erro é apresentado na tela do usuário. |
| **Solução/Implementação:** | Foi realizada otimização do processo de contabilização por competência, permitindo ao sistema, a execução de fórmulas durante a apropriação do cancelamento de contrato. |
