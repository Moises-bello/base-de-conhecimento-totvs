# Registro Online

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Registro Online na Emissão de Boleto no portal do aluno |
| **Situação/Requisito:** | No portal do aluno, quando usuário tentar imprimir um boleto no qual o convênio utiliza registro online, estava ocorrendo mensagem erro "Lançamentos que pertencem a boletos em abertos não podem ser incluídos em outros boletos" devido ao processo tentar gerar um novo boleto para o lançamento. |
| **Solução/Implementação:** | Permitir usuário imprimir boleto através do portal do aluno no qual o convênio utiliza registro online. |
| **Conversores e Parâmetros:** | N/A |
| **Tickets relacionados:** | N/A |
