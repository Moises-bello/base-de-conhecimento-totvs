Na navegação do browser na interface do smartclient ocorre o erro.

|  |  |
| --- | --- |
| Situação | Na navegação do browser na interface do smartclient ocorre o erro Invalid row (1) on SelectedRow. |
| Ocorrência | Dependendo da resolução da tela da tela, durante a navegação do browser na interface do smartclient apresentava erro de invalid row. |
| Correção | Correção no tratamento de linhas do browser. |
| Informações adicionais | * Disponível em builds superiores a 7.00.131227A - 1.0.8 |
