# Lançamento Inclusão / Alteração

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | Lançamento - Inclusão / Alteração |
| **Situação/Requisito:** | Ao criar um lançamento para uma determinada filial, ao selecionar a conta caixa o sistema exibe todas as contas caixas cadastradas (de todas as filiais).  Caso o usuário selecione uma filial diferente da informada no lançamento, ao salvar o lançamento o sistema mostra um erro falando que a filial da conta caixa deve ser igual a filial do lançamento. |
| **Solução/Implementação:** | Otimização de consulta de conta caixa na tela de lançamentos financeiros. Incluído filtro por filial selecionada. |
