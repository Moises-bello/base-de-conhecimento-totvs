# CANCELAMENTO DE FÉRIAS

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e Projetos* |
| **Módulo:** | *Folha de Pagamento* |
| **Função:** | *Cancelamento de Férias* |
| **Situação/Requisito:** | No wizard de Aprovação de Dados Cadastrais, o processo de cancelar férias não alterava os campos necessários na tabela dos funcionários, fazendo com que os mesmos fossem apresentados incorretamente em alguns relatórios de férias. |
| **Solução/Implementação:** | *Foi tratado o processo de cancelamento de férias através da tela especificada para apagar os campos apropriados* |
| **Chamados relacionados:** | TTHUXK |
| **Versões/Release:** | *12.1.8* |
