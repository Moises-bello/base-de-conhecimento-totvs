## ****01. DADOS GERAIS****

## **02. SITUAÇÃO/REQUISITO**

Foi detectada a necessidade da exportação do PERT poder ser enviada diretamente para o cronograma Base.

## **03. SOLUÇÃO**

No processo de Exportação do PERT para o Cronograma foi adicionada a opção do cronograma Base como destino.

Este cronograma não possui bloqueio de períodos. O processo também não irá considerar os parâmetros da Cópia da Linha Base. marcados abaixo.

Desta forma o processo sempre irá considerar todos os períodos como abertos para a exportação.
