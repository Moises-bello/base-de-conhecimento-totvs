# Copiar endereço da empresa para endereço do funcionário

## Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *TOTVS Educacional* |
| **Rotina:** | |  |  | | --- | --- | | **Rotina** | **Nome Técnico** | | *Cadastro de Funcionários da Empresa (Central de Estágios) - Sistema* |  | | Cadastro de Funcionários da Empresa (Central de Estágios) - Fluig |  | |
| **Requisito (ISSUE):** | PCREQ-8817 |
| **País(es):** | *Brasil* |
| **Versões/Release:** | *12.1.10* |

## Descrição

No momento em que o usuário estiver cadastrando um funcionário para uma empresa na central de estágios, esse usuário deverá ter a opção de atribuir ao endereço do funcionário que está sendo cadastrado o mesmo endereço da empresa à qual ele pertence. Essa regra vale tanto para a tela de cadastro de funcionário da empresa no Sistema quanto para a tela Web disponível no Fluig.

## Procedimento para Utilização

* *Acessar a tela de cadastro de funcionários da empresa a central de estágios;*
* *No momento do cadastro do funcionário, clicar sobre o botão "Utilizar mesmo endereço da empresa".*
* *Ao clicar nesse botão, caso haja um endereço cadastrado para a empresa, esse endereço será copiado para os campos de endereço do funcionário.*
