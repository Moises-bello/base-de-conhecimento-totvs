# Cheques

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Gestão Financeira |
| **Função:** | Cheques |
| **Situação/Requisito:** | Informação do campo Histórico não é exibida na tela do cheque ao baixar, emitir ou receber para somente um lançamento. |
| **Solução/Implementação:** | Otimização no campo Histórico de cheque. Agora o sistema informa corretamente a informação dos mnemônicos formatados no campo Histórico utilizando o parâmetro "Histórico default cheque a pagar / a receber" durante a baixa, a emissão ou recebimento de cheque para somente um lançamento. |
