# SEFIP

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Construção e projetos* |
| **Módulo:** | *Folha de pagamento* |
| **Função:** | *SEFIP* |
| **Situação/Requisito:** | Ao gerar o lançamento financeiro do tipo 15 - FGTS conforme Sefip para várias filiais durante a processo de emissão da SEFIP, os valores dos lançamentos financeiros são apresentados com diferença (centavos) ao serem comparados com os valores apresentados em relatório emitido pelo aplicativo SEFIP (exemplo: relatório Analítico GRF). Porém ao gerar o lançamento financeiro durante o processo da SEFIP para uma filial apenas, o valor do lançamento financeiro corresponde ao valor apresentado nos relatórios emitidos pelo aplicativo SEFIP. |
| **Solução/Implementação:** | Otimizado correção de valores de centavos no SEFIP, agrupando por filial |
