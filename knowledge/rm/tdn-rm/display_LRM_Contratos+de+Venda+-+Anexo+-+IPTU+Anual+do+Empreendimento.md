Neste anexo é possível visualizar, incluir, editar e excluir o valor do IPTU Anual do Empreendimento no qual pertence o Contrato selecionado.   
 Ao incluir um novo registro, é exibida uma tela com os seguintes campos:

* **Empreendimento:** Exibe o Código do Empreendimento a qual o Contrato está vinculado, este campo é preenchido automaticamente.
* **Ano IPTU:** Permite definir o Ano do IPTU que será cadastrado.
* **Valor:** Permite definir o Valor do IPTU que será cadastrado.
* **Qtde. de parcelas:** Permite definir o número de parcelas que o IPTU será divido.
* **Vencimento Inicial:** Permite definir qual será a data do primeiro vencimento do IPTU.
