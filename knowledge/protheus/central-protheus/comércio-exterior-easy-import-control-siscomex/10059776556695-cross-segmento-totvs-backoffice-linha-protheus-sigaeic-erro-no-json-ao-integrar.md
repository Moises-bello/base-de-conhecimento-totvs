![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min****Ocorrência**1. Dá erro na geração do json quando faço a integração do catálogo de produtos sem a informação do produto no grid "Relação de Produtos".  
2. Quando informo um produto com o ncm diferente do ncm da capa do processo dá uma tela de erro sem informação.  
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) - *Easy Import Control* - A partir da versão 12.1.27  
  
**Causa**1. Corrigido o sistema para gerar o json corretamente com ou sem a informação no grid "Relação de Produtos".  
2. Corrigido o sistema para informar corretamente o problema e a solução.  
  
**Solução**  
Para solucionar essa ocorrência, aplique o pacote de correção:   
12.1.27:<https://suporte.totvs.com/portal/p/10098/download?e=1072810>;  
12.1.33:<https://suporte.totvs.com/portal/p/10098/download?e=1072811>;
