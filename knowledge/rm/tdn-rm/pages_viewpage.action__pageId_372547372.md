# Validação de Requisito na Matrícula Online

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | TOTVS Educacional |
| **Módulo:** | Educacional |
| **Função:** | Matrícula Online |
| **Situação/Requisito:** | Ao realizar a matrícula online, o portal não verificava requisitos de uma disciplina que já estavam concluídas. Notificando o aluno que as disciplinas estavam pendentes. |
| **Solução/Implementação:** | A verificação de requisitos não conseguia identificar a conclusão das disciplinas já aprovadas devido a falta do carregamento de uma informação da disciplina no qual não era identificada como uma disciplina concluída. Deixando os requisitos de uma disciplina como pendente.  Foi realizado o ajuste para o correto carregamento da informação e identificação da situação das disciplinas da grade. |
