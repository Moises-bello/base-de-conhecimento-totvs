**Dúvida**Como efetuar o cadastro de Ausência de funcionário comissionista misto para que as médias não componham o cálculo de afastamento?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal - Todas as versões  
  
**Solução**Para que as médias do funcionário comissionado misto, não componham o cálculo do afastamento, no cadastro do **Tipo de Ausência**, o campo **N. Mes. C. Med.** deve​ estar **preenchido com 0 (zero)**, dessa forma o sistema não utilizará as médias para a composição do cálculo do afastamento, efetuando o cálculo somente sobre o salário do funcionário.

Se este campo estiver preenchido, o sistema validará as verbas de comissão que estão configuradas com SIM para média para a composição do cálculo de afastamento.  
**OBS:** Essa configuração é valida para todos os Tipos de Ausência.
