# Plataforma

# Ocorrência

Em Editar Perfil → Preferências de Usuário é preciso bloquear a edição do campo E-mail.

# Solução

Há duas formas de fazer este bloqueio:   
1) Utilizando o TOTVS Identity;   
2) Através de eventos de usuário: [beforeUpdateUser](http://tdn.totvs.com/display/public/fluig/Desenvolvimento+de+Eventos#DesenvolvimentodeEventos-beforeUpdateUser)
