# IMPORTAÇÃO DO MOVIMENTO DE ENSINO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *C&P* |
| **Módulo:** | *TOTVS Folha de Pagamento* |
| **Função:** | *Importação do movimento de ensino* |
| **Situação/Requisito:** | Ao realizar a importação do movimento do ensino da folha educacional é apresentado mensagem de advertência pois não é encontrado o registro da turma para filial informada no arquivo de importação. |
| **Solução/Implementação:** | Criado um check box na tela de importação onde é possivel escolhar se será utilizado o codigo da filial informada no arquivo ou o codigo da filial 1. |
| **Versões/Release:** | *12.1.8* |
