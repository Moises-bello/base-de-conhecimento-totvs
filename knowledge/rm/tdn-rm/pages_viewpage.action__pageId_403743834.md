# Não permitir cadastrar item de débito do exame com quantidade zero

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Cadastro / Unidades de Diagnóstico / Exames e Serviços / Item de Débito |
| **Situação/Requisito:** | O sistema permitia gravar item de débito do exame com quantidade zero. |
| **Solução/Implementação:** | Ajuste para não permitir cadastrar item de débito com quantidade menor que 1. |
| **Documento de Referência:** | <https://totvssuporte.zendesk.com/agent/tickets/3791256> |
