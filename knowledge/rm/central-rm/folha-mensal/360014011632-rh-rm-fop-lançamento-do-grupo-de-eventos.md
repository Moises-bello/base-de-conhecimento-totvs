Dúvida**Como criar e lançar um grupo de eventos?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Folha de Pagamento - Todas as versões  
  
**Solução**Para solucionar essa dúvida, verifique e realize o passo a passo orientado:  
  
1. Acesse: **Folha Mensal | Lançamentos | Grupo de eventos.**![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10547737837207)  
  
2. Caso queira incluir um novo grupo de eventos clique para adicionar um novo registro, informe o código, descrição e faça a parametrização das demais ações que o lançamento irá realizar juntamente com o filtro de seleção de funcionário.  
  
![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10547740584087)  
  
3. Marcando a flag **Lançar Eventos do Grupo** será habilitada uma aba onde deve ser informado os eventos que serão lançados pelo grupo de eventos.  
  
![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10547775063191)  
  
4. Após realizar parametrizações no grupo de eventos, o sistema solicitará que o grupo de eventos seja salvo. Clique em **Salvar** para usar o grupo de eventos futuramente.  
  
![mceclip4.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10547802084631)  
  
5. Após criação do grupo de eventos, clique em **Lançar** para que as parametrizações informadas no grupo de eventos sejam lançadas para os funcionários.  
  
![mceclip5.png](https://centraldeatendimento.totvs.com/hc/article_attachments/10547836905367)
