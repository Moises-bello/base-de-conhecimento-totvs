**Quadro de Horários**

---

   
Através desta funcionalidade o professor consegue visualizar as turmas as quais esta alocado e o horário de cada uma delas.

* Selecione o período letivo que deseja visualizar
* O quadro de horários será exibido com as informações referentes a disciplina, turma, prédio, sala e tipo de aula (presencial ou a distancia). Veja um exemplo:

  |  |  |  |  |  |  |
  | --- | --- | --- | --- | --- | --- |
  | **Horário** | **Segunda-Feira** | **Terça-Feira** | **Quarta-Feira** | **Quinta-Feira** | **Sexta-Feira** |
  | 19:00 - 19:50 | Matemática   **Turma:** 3-A   **Prédio:** C   **Sala:** 12   **Tipo:** Presencial |  | Matemática   **Turma:** 3-A   **Prédio:** C   **Sala:** 12   **Tipo:** Presencial |  | Matemática   **Turma:** 3-A   **Prédio:** C   **Sala:** 12   **Tipo:** Presencial |
  | 19:50 - 20:40 |  | Cálculo   **Turma:** 2-A   **Prédio:** D   **Sala:** 8   **Tipo:** Presencial |  | Cálculo   **Turma:** 2-A   **Prédio:** D   **Sala:** 8   **Tipo:** Presencial |  |
  | 21:00 - 21:50 |  |  | Matemática   **Turma:** 3-A   **Prédio:** C   **Sala:** 12   **Tipo:** Presencial |  |  |
  | 21:50 - 22:40 | Matemática   **Turma:** 1-B   **Prédio:** E   **Sala:** 32   **Tipo:** Presencial |  |  |  | Matemática   **Turma:** 1-B   **Prédio:** E   **Sala:** 32   **Tipo:** Presencial |
* Ao clicar nas disciplinas abre um balão com informações acerca do curso e da habilitação aos quais a disciplina pertence.
* Abaixo do quadro de horário e possível também visualizar o resumo do total de horas que o professor esta alocado por filial.
