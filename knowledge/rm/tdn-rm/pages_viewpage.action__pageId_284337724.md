# Ordenar os Itens da Requisição de Estoque por Nome

# Características do Requisito

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Rotina:** | |  | | --- | | **Rotina** | | Movimentação de Estoque | |
| **País(es):** | Brasil |
| **Banco(s) de Dados:** | SQL SERVER® e ORACLE® |
| **Tabelas Utilizadas:** | SZMOVIESTOQUEITEM |
| **Sistema(s) Operacional(is):** | Windows ® |

## Descrição

Ao utilizar a Movimentação de Estoque, na aba Itens da Prescrição, permitir que os itens da Grid possam ser ordenados pelas colunas "Código" e "Nome".

## Procedimento para Utilização

* Acesse o opção de Menu Estoques / Movimentação de Estoques
* Selecione um Registro e vá até a aba Itens da Prescrição
  + Ordene por Nome
  + Ordene por Código
