**Dúvida**  
Ao tentar realizar a transferência de um título que possui portador para outro banco, é apresentado o help 'FA060PORT'. Como proceder nesse caso?  
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Financeiro – Todas as versões  
  
**Solução**  
Para que o sistema permita a transferência de um banco para outro, sem a necessidade de alterar previamente a situação para A fim de viabilizar a transferência de um banco para outro sem a necessidade de alterar previamente a situação para a carteira '0', é imprescindível que o parâmetro MV\_TRFBCO esteja configurado com o valor '1'. Isso permitirá que a mudança para o novo banco ocorra de forma direta.
