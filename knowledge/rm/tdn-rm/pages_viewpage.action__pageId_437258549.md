# Objetivo:

---

          Este tutorial tem por objetivo esclarecer como configurar seu relatório.net para que seja impresso conforme papel personalizado.

# Como configurar:

---

falseConfigurações de Impressão11ª - Propriedades

          Na área de edição do relatório tecle F4 para acessar a Grade de Propriedades. Selecione a opção “*RptReport Relatório*” para habilitar as configurações “*Definições de Página | Impressora*”.

          Nas definições de página, na propriedade “*Impressora*” selecione a impressora onde o papel personalizado foi criado.

false

Obs.: As configurações de impressão serão da máquina local. Caso o cliente utilize o sistema em N Camadas, serão mostradas as configurações da máquina cliente.

22ª - Selecionando Impressora

          Na sequência das configurações selecione a impressora onde foi definido o papel personalizado. Para esta definição selecione em “*Definições de Página | Tipo de Papel*” a opção “*Personalizado*”.

          Em seguida, na propriedade “*Definições de Página | Nome do Papel*” selecione o papel criado com as definições particulares.
