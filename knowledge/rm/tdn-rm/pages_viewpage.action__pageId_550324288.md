**Atenção:** Não se aplica a integração com Protheus

Para transferir os lançamentos contábeis para o Lote 0 acesse: *BackOffice | Gestão Contábil | Escrituração Contábil | Lotes*

Selecione os lotes a serem transferidos, acesse *Processos | Integrar Lote (s)/Lançamento (s) ao Lote Oficial,* clique em “Avançar”

É possível escolher os lançamentos dentro do Lote que serão transferidos para o Lote 0, caso não queira transferir todos os lançamentos de uma só vez.

Após a transferência para o Lote 0, os lançamentos contábeis podem ser visualizados em: Escrituração Contábil | Lançamentos

Antes de gerar o arquivo do Zeus Contábil é necessário fazer a transferência para o Lote Oficial da Contabilidade (Lote 0).
