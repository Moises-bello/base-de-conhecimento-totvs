# FOLHA ANALÍTICA POR CENTRO DE CUSTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Folha Analítica |
| **Situação/Requisito:** | Ao gerar a folha analítica imprimindo por centro de custo usando o filtro 'Usar filtro'  na página total geral os campos referentes a:   * FGTS Dep. * FGTS Dep. (SEFIP) * Base FGTS * Base FGTS (SEFIP) * Base FGTS   Os valores estão incorretos. |
| **Solução/Implementação:** | Gerar a folha analítica por centro de custo onde os totais dos funcionários, totais da seção/ centro de custo e total geral seja o mesmo valor. |
