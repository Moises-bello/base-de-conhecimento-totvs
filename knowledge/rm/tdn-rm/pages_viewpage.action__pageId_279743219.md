# Ajuste na Geração do Arquivo de Autorização da TISS

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Atendimento |
| **Situação:** | Ao solicitar autorização da TISS, o sistema gerava o valor 99999 para os CBOs 60153, 60228 e 60248. |
| **Solução:** | Sistema ajustado para gerar o código correto, ao solicitar autorização da TISS quando o CBO do prestador for 60153, 60228 ou 60248. |
