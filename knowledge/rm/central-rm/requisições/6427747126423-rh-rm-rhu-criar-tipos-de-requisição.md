![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/15869349691543) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Ao acessar o menu de Tipos de Requisição não são listados os tipos padrões. Como crias os tipos de requisição?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha RM) - TOTVS Gestão de Pessoas - Todas as versões  
  
**Solução**Para criar os tipos requisição, acesse o menu **executar** no RM a pesquise pelo processo "Acerto nos tipos de requisições".   

 

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27005670360087)  
  
Ao clicar na opção **'Acerto nos tipos de requisição'** será aberto uma janela de execução do processo e ao finalizar no menu **Configurações** | **Tipos de requisição,** os tipos deverão ser listados.

A opção 'Acerto nos tipos de requisição' também foi criada no menu 'Processos' na guia **Configurações** | **Tipos de Requisição**.   
  
![](https://centraldeatendimento.totvs.com/hc/article_attachments/31710412253207)

**Importante**

- Caso seja apresentada alguma mensagem referente a não possuir acesso a funcionalidade para executar, gentileza validar as permissões de acesso do perfil vinculado ao usuário de acesso ao RM.

É necessário que o perfil tenha acesso ao menu [06.01.03.01] Acerto nos Tipos de Requisição, conforme exemplo abaixo:

![](https://centraldeatendimento.totvs.com/hc/article_attachments/27005670361623)
