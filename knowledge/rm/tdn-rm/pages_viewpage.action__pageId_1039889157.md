# 1. Sobre

Esta atualização permiti emitir NFS-e Nacional sem informar o **Tomador**, que é permitido conforme regras do documento fiscal e pela Prefeitura.

# 2. Versões para atualização

A solução está disponível a partir dos patches:

Data: 

Biblioteca RM

* 12.1.2502.277
* 12.1.2506.242
* 12.1.2510.166

# 3. Detalhe da Alteração

A Tag <toma> deixa de sair no Xml quando informado um **Tomador** fictício com dados mínimos preenchidos [conforme documentação](https://tdn.totvs.com/pages/viewpage.action?pageId=439355177).
