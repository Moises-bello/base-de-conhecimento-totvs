# Envio de e-mail para envolvidos na reprovação e aprovação de atestado

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | RH |
| **Módulo:** | Segurança e Saúde Ocupacional |
| **Função:** | Pré-Atestado |
| **Situação/Requisito:** | Quando atestado for aprovado ou não  pelo RH o funcionário e o gestor devem ser comunicados com um e-mail informando o motivo da recusa do atestado. |
| **Solução/Implementação:** | Foram criados quatro parâmetros na aba validação, para validar para quem deve ser enviado os e-mails. Eles estão divididos em dois grupos o de aprovação e o de reprovação e o usuário tem a opção de escolher enviar e-mail somente para o funcionário ou para o gestor ou para ambos. |
| **Conversores e Parâmetros:** | É necessário execução de script para liberar a funcionalidade. |
