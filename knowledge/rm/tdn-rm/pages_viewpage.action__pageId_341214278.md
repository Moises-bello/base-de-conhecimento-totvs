# Cadastro de Tributos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | Gestão Fiscal |
| **Função:** | Cadastro de Tributos. |
| **Situação/Requisito:** | Criar no Cadastro do Tributo um campo para informação do Default de Natureza Orçamentária. Esse campo só deve ser habilitado para os tributos gerados pelo Financeiro (IRRF e CSRF - CSLL-RF, PIS-RF, COFINS-RF). |
| **Solução/Implementação:** | Foi feita a criação do campo "Natureza Orçamentária Financeira" no cadastro de Tributos, pasta "Outros dados".  O campo vai ficar disponível para os tributos (IRRF e CSRF - CSLL-RF, PIS-RF, COFINS-RF).  Disponível a partir da versão 12.1.20. |
