# Alteração da distribuição gerencial

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | Totvs Gestão Contábil |
| **Função:** | Alteração da Distribuição Gerencial |
| **Situação/Requisito:** | Deve ser realizada uma validação para não permitir que o rateio gerencial seja excluído, quando tiver sendo usado pelo TIN. |
| **Solução/Implementação:** | Foram realizadas as seguintes alterações:  1 - O processo “Alteração do campo Tem Distribuição Gerencial”, disponível no cadastro de contas contábeis, foi alterado para não permitir que o rateio gerencial seja excluído quando a conta gerencial estiver sendo utilizada pelo Totvs Incorporação.  2 - O processo responsável por alterar a distribuição gerencial, existente na aba Gerencial do módulo contábil, foi alterado para não permitir que o rateio gerencial, das contas contábeis utilizadas pelo Totvs Incorporação, seja modificado. |
