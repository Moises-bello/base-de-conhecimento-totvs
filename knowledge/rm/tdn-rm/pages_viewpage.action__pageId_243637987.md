# MOVIMENTO POR COMPETÊNCIA

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Regeração de movimento por competência* |
| **Situação/Requisito:** | *O sistema possuía uma regra de negócio que tratava a data de competência, ao utilizar o período de competência do período letivo, como a primeiro dia do mês informado no processo, porém registrava o movimento na base de dados como o último dia do mês. Assim, ao regerar o movimento, o sistema não encontrava o movimento para removê-lo da lista de lançamentos processados.* |
| **Solução/Implementação:** | *Foi realizada otimização do processo de regeração de movimentos, de forma que o sistema possa distribuir corretamente os valores, em caso de alteração no valor do contrato, com a utilização do período de competência do período letivo.* |
