![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:01:00 min** **Dúvida**Ao gerar a Primeira Nota, as despesas configuradas como base de custo = SIM, base ICMS = Não e base de imposto = Não, não estão sendo exibidas no campo "Outras Despesas".   
  
**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus) – *Easy Import Control* – Todas versões  
  
**Solução**Na Primeira Nota só serão consideradas as despesas  configuradas como base de imposto = SIM ou base ICMS = SIM. Já para a Nota Fiscal Única, as  despesas configuradas como base de custo = SIM, base ICMS = Não e base de imposto = Não, serão consideradas e exibidas no campo Outras Despesas.
