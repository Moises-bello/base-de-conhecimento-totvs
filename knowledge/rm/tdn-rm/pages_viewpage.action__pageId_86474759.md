| **Produto:  TOTVS Automação de Ponto**                                            **Versão:** *11.80* |
| **Processo: Integração Ponto x Educacional** |
| **Subprocesso:** *Horário dos professores* |
|  |
| Essa integração consiste em gerenciar o ponto eletrônico dos professores cadastrados no TOTVS Educacional por meio da solução TOTVS Automação de Ponto. Para analisar as ocorrências de ponto do professor serão confrontadas as batidas desse conforme seus horários de aula. |
| **1º) Turno/Horário**  No TOTVS Educacional cadastre os turnos e respectivos horários dos professores. Para isso, acesse:  Guia Currículo e Oferta / Grupo Acdêmico / Turnos e Horários.  Inclua, primeiramente o turno, em seguida, acesso o anexo "Horários" e inclua os horários.  ***Exemplo:***  Turno: Manhã  Horário:   |  |  |  | | --- | --- | --- | | **Início** | **Fim** | **Dia da semana** | | 07:00 | 07:50 | Segunda | | 07:50 | 08:40 | Terça | | 13:00 | 13:50 | Terça | | 09:50 | 10:40 | Quarta | | 10:40 | 11:30 | Sexta |     **2º) Turma/Disciplina**  Após cadastrar os turnos e seus respectivos horários, devemos vinculá-los ao cadastro de turmas/disciplinas. Além disso, mencionar o período letivo vigente. Para isso, acesse:  Guia Currículo e Oferta / Grupo Oferta / Turmas|Disciplinas.  Edite o registro de turma|disciplina desejado e informe o turno e o período letivo.  **Obs.:** Caso não exista o registro de turmas, acesse o cadastro de turmas e faça a devida inclusão. O mesmo serve o cadastro de turmas/disciplinas. No cadastro do período letivo é possível visualizar sua vigência.  Para vincular o professor a turma/disciplina em questão, acesse o anexo "Professores". Faça a inclusão do funcionário que tenha a função relacionada ao professor. Nessa vinculação é de suma importância os campos de data início e término, pois é com base neles que o sistema fará a consideração dos horários na Automação de Ponto.  **Obs.:** Para saber quais são estas funções ou incluir novas, acesse a guia Currículo e Oferta / Grupo Aluno e Professor / Professores / Função de professor.  Agora precisamos relacionar o horário criado ao registro de turma/disciplina em questão, para que em seguida, façamos a vinculação do professor. Para incluir um registro de horário à turma/disciplina em questão, acesse o anexo "Horários". Após salvar o registro do horário, acesse seu anexo "Professor do Horário" e vincule o registro do professor que irá ministrar a disciplina no horário e turma em questão.  Nos processos de Turma / Disciplina, execute "Gerar Plano de Aula". Nesse momento, o horário é criado para que em seguida, seja importado para a Automação de Ponto.    **3º) Importação do horário**  Os horários devem ser importados através do TOTVS Automação de Ponto, para isso, acesse:  Guia Processos / Grupo Utilitários / Importação Horário Professor.  Ao executar a importação de horários dos professores, será considerado o período vigente para o usuário que está realizando a importação, assim como, a seleção de funcionários realizada por esse. Após importar os horários do TOTVS Educacional, o TOTVS Automação de ponto irá considerar os horários importados como horários planejados para os funcionários, desta forma, o usuário poderá proceder com a apuração da movimentação de ponto.  Após importar os horários do TOTVS Educacional, o TOTVS Automação de Ponto irá considerar esses horários como Horário Planejado para o professor dentro do período considerado na importação.  **Exemplo:**  Horário planejado para o professor: segunda-feira, de 08:00 às 12:00.  Período de disponibilidade da atividade: 01/05/2011 até 31/05/2011.  Nesse caso, serão gerados 5 horários para o plano de aula, pois existem 5 segundas-feiras entre 01/05/2011 e 31/05/2011. Ao importar esses horários, serão considerados como horário planejado para o professor no espelho de ponto:  02/05/2011, segunda-feira, Entrada 08:00, Saída 12:00.  09/05/2011, segunda-feira, Entrada 08:00, Saída 12:00.  16/05/2011, segunda-feira, Entrada 08:00, Saída 12:00.  23/05/2011, segunda-feira, Entrada 08:00, Saída 12:00.  30/05/2011, segunda-feira, Entrada 08:00, Saída 12:00.  **Atenção!** Para considerar o horário importado do TOTVS Educacional com o horário planejado para o professor, o parâmetro “Considera horário planejado do Chronus para o professor” deverá estar desmarcado, para isso, acesse o cadastro do funcionário com a função professor e execute o processo “Parametrizar funcionário”, na configuração da etapa “Horário” basta desmarcar o parâmetro aqui mencionado. Não deixe de avançar as etapas até concluir o processo. |
|  |
| **Informações Adicionais**  Para os horários que a instituição de ensino deseja considerar que o professor não precisa bater ponto, ou seja, em casos nos quais o professor está fora da instituição, porém, executando alguma tarefa designada por essa, poderá utilizar do parâmetro “Desconsidera ponto”.  **Exemplo:**  O professor José da Silva, leciona a disciplina Matemática no horário de 19:00 às 19:50, todas as segundas-feiras, em um prédio fora da instituição, neste caso, não precisará bater ponto referente a essas batidas, pois no prédio não existe um relógio de ponto pertencente à instituição de ensino.  **Atenção!** O parâmetro “Desconsidera ponto” encontra-se disponível tanto no anexo “Professores” do cadastro de Turmas/Disciplinas, quanto no anexo “Professor do Horário” disponível através do anexo “Horários” também disponível no cadastro de Turmas/Disciplinas. Sendo que, quando o parâmetro estiver marcado para o professor da turma/disciplina, o comportamento do sistema será adotar esse parâmetro para todos os horários associadas à turma/disciplina. Quando marcado para o professor do horário, será adotado apenas para o professor associado ao horário em questão. |
