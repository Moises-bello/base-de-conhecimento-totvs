Segue a lista das URL's externas de terceiros que são utilizadas no Portal do Aluno.  Para o correto funcionamento do portal, será necessário que o servidores web onde estão instalado o portal precise ter acesso liberado ao links relacionados.

Alguns do links externos de terceiros utilizados no Portal do Aluno, são configurados pelo próprio cliente, através de parâmetros no RM.exe

## **01. Google Analytics**

O Google Analytics é o serviço oficial e gratuito de monitoramento de Marketing Digital do Google. Sua principal função é coletar dados de acesso, comportamento e navegação**.** Para mais informações acesse

A URL utilizada para esta funcionalidade é <https://www.googletagmanager.com/gtag/js>

## **02. Google Fonts Nonito**

O Google Fonts Nonito é um conjunto de estilo de fonte utilizada pelo portal para definir um padrão de fonte dos textos**.**

A URL utilizada para esta funcionalidade é <https://fonts.googleapis.com/css?family=Nunito>

## **03. Plataforma de pagamento digital Adyen**

A adyen é uma plataforma de pagamentos digitais. Para mais informações acesse

As URL's utilizadas para esta funcionalidade são

<https://checkoutshopper-test.adyen.com/checkoutshopper/sdk/3.9.4/adyen.css>

<https://checkoutshopper-test.adyen.com/checkoutshopper/sdk/3.9.4/adyen.js>

## **04. Plataforma de pagamento digital CyberSource**

A cybersource é uma plataforma de pagamentos digitais. Para mais informações acesse

A URL utilizada para esta funcionalidade é <https://songbirdstag.cardinalcommerce.com/cardinalcruise/v1/songbird.js>

## **05. Login via Facebook**

Realizar acesso único utilizando a conta do Facebook no login do portal. Para mais informações acesse

A URL utilizada para esta funcionalidade é <https://connect.facebook.net/pt_BR/sdk.js>

## **06.** **Recaptcha** **do Google para consulta pública de diplomas**

O Recaptcha do google para consulta pública de diplomas. Para mais informações acesse

A URL utilizada para esta funcionalidade é [https://www.google.com/recaptcha/api.js?onload=vcRecaptchaApiLoaded&amp;render=explicit](https://www.google.com/recaptcha/api.js?onload=vcRecaptchaApiLoaded&render=explicit)

## **07. Aceleradora de carreiras**

A integração com com a Aceleradora de carreiras. Para mais informações acesse

A URL utilizada para esta funcionalidade é informada nas parametrizações conforme o documento acima.
