Os produtos TOTVS estão em constante evolução para acompanhar cada etapa da jornada digital da sua empresa.

Diante disso, comunicamos que algumas funcionalidades do TOTVS Agro Multicultivo serão descontinuadas em **27 de junho de 2025.**

Confira abaixo as funcionalidades que serão descontinuadas e suas substitutas:

|  |  |
| --- | --- |
| **Funcionalidade a ser descontinuada** | **Funcionalidade substituta** |
| AERM0002 - Aplicação de Insumos | AERM0019 - Apontamento Agrícola |
| AERM0003-Atividade Mecanizada | AERM0019 - Apontamento Agrícola - |
| AERM0004-Atividade Manual | AERM0019 - Apontamento Agrícola |
| AERM0005-Atividade de Produção | AERM0019 - Apontamento Agrícola |
| PLAM0002-Plantio | AERM0019 - Apontamento Agrícola |
| App Meus Multicultivos (\*) | App Minhas Atividades Agrícolas - Apontamento Agrícola |

(\*) Insumos, Mecanizada, Manual, Produção, Plantio, Tratamento de Sementes e Justificativa de Estouro de Dosagem. 

A todos os clientes que ainda utilizam estas funcionalidades a serem descontinuadas, sugerimos que adotem as funcionalidades substitutas, que oferecem os seguintes benefícios: possibilidade de uso em dispositivos tablet e celular, nova e moderna solução Mobile para Apontamentos Agrícolas, Tipo de Apontamento Agrícola para utilização com o TOTVS Agro Conecta Dados para integração com máquinas e equipamentos, por exemplo, Solinftec, John Deere e plataforma Jacto Multimarcas, além de permitir a criação de diferentes Tipos de Apontamento Agrícola de acordo com as características do negócio de cada cliente. 

E para cada Tipo de Apontamento Agrícola é possível:

* Definir num único apontamento um ou mais tipos, entre eles, Mecanizada, Manual, Insumos, Produção e Plantio;
* Definir para cada Tipo de Apontamento se Permite Local de Produção diferente da Ordem de Serviço;
* De acordo com as características de cada campo, definir se o mesmo é utilizado, se é obrigatório e se estará habilitado;
* Definir quais as Unidades Administrativas possuem direito de acesso ao Tipo de Apontamento Agrícola;
* Definir Usuários, Grupos de Usuários e tratamentos de exceções de acesso por Tipo de Apontamento Agrícola;
* Definir Usuários Mobile por Tipo de Apontamento Agrícola;

A seguir, esclarecemos as possíveis dúvidas sobre a transição para as funcionalidades substitutas: 

**Como posso utilizar as funcionalidades substitutas?**

As funcionalidades substitutas já estão disponíveis com os demais aplicativos do TOTVS Agro Multicultivo em nossa [Central de Downloads](https://suporte.totvs.com/portal/p/10098/download#company/),  a partir do release 12.1.15.

Ao instalar os releases vigentes, que podem ser identificados no [Calendário de Releases](https://suporte.totvs.com/portal/p/10098/ciclodevidacalendarios),  em seu ambiente,  as funcionalidades estarão disponíveis no menu: **Apontamentos > Atividades e Recursos > Apontamento Agrícola**.

***Importante:*** todos os clientes que utilizam as funcionalidades que serão descontinuadas atualmente, não terão custos para migrar para as funcionalidades substitutas..

**O que vai acontecer com os meus dados?**

Para garantir uma transição fácil, seus dados estarão disponíveis no banco de dados já utilizado.

Lembrando que a TOTVS sempre atuará observando toda e qualquer legislação aplicável e eventuais deveres de confidencialidade existentes.

**O que vai acontecer se eu não migrar para as funcionalidades substitutas até a data da descontinuação?**

Se você não realizar a migração para as funcionalidades substitutas até a data da descontinuação, elas serão removidas do menu do cliente a partir do release 12.1.2506. Já o App Mobile poderá ser mantido  no seu ambiente, mas não contará mais com Suporte Técnico e Manutenções.

***Importante:*** as novas regras de negócio e validações serão implementadas apenas nas funcionalidades de Apontamento Agrícola substitutas.

Recomendamos migrar para as funcionalidades substitutas até a data da descontinuação para evitar eventuais impactos em sua operação e garantir suporte técnico.

**O que vai acontecer após a data da descontinuação?**

Conforme nossa Política de Ciclo de Vida de Software, a partir da data de descontinuação, a TOTVS não irá evoluir, prestar suporte ou dar manutenção para as funcionalidades descontinuadas.

**Preciso fazer a validação do produto substituto no meu ambiente?**

Recomendamos que, para assegurar o sucesso na adoção das funcionalidades substitutas, seja realizada a validação da aderência e definição de configurações específicas e novas parametrizações, seguidas de rodadas de testes. Em alguns casos, a implantação das funcionalidades substitutas pode gerar a necessidade de treinamentos e capacitações a serem fornecidos sob demanda.
