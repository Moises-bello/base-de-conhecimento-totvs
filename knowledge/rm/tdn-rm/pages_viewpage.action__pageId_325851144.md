# Objetivo

---

Disponibilizar a funcionalidade "Aplicar tema default para todos usuários".

# Configuração

---

**1º)**Acesse a guia/menus  "**Ambiente******|****Configuração**| **Parâmetros | Globais".****

**2º)**Depois de carregado, selecione a guia Performance.

**3º)**Para que a funcionalidade de "**Aplicar tema default para todos os usuários**" funcione é necessário que os **temas da MDI estejam habilitados**.

**4º)**Selecione a funcionalidade que deseja habilitar. Neste exemplo, habilitaremos a opção:**"**Aplicar tema default para todos os usuários**"**.

**5º)**Após habilitar esta funcionalidade, **todos os usuários** do sistema utilizarão a skin **'Sample'** (que possui o Icone da empresa ou o logo cadastrado).

**6º)**Para realizar configuração do Logo basta acessar Menu Serviços Globais | Administração | Configurações.

      Para mais informações de como configurar o logo basta acessar o link [Inserindo Logomarca ou Imagem no Sistema RM](http://tdn.totvs.com/display/LRM/Inserindo+Logomarca+ou+Imagem+no+Sistema+RM)

Para maiores informações:

Consulte o [WikiHelp TOTVS](http://wikihelp.totvs.com.br/WikiHelp/GLB/GLB.Perfis.aspx)
