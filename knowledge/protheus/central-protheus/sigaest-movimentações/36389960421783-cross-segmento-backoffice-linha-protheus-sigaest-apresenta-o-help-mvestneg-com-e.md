Ao executar a rotina automática MATA241 no TOTVS Protheus, pode ocorrer o erro Help MVESTNEG. Para corrigir, atualize o ambiente com os pacotes das versões 12.1.2210, 12.1.2310 ou 12.1.2410, testando antes em base de homologação. A atualização inclui tratamento para identificar o processamento via rotina automática.

![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/36389949374615) Tempo aproximado para leitura: **00:01:00 min**  
  
**Dúvida**  
Como corrigir o Help MVESTNEG com ExecAuto do MATA241?   
  
**Ambiente**  
Cross Segmento - TOTVS Backoffice (Linha Protheus) - Estoque/Custos - Todas as versões.  
  
**Solução**  
Ao executar a rotina automática MATA241, o processamento é interrompido e é exibido o Help: MVESTNEG.

Efetuado tratamento para rotina identificar se o processamento é via rotina automática.

Atualizar  o ambiente com o pacote abaixo, avaliar primeiramente em base de homologação:

**12.1.2210**:<https://suporte.totvs.com/portal/p/10098/download?e=1190445> ; **12.1.2310**:<https://suporte.totvs.com/portal/p/10098/download?e=1190444> ; **12.1.2410**:<https://suporte.totvs.com/portal/p/10098/download?e=1190443> ;
