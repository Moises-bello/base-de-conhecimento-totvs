**Dúvida**É possível determinar no cadastro de produtos se ao calcular a necessidade de aquisição do item deve ser gerada uma **SC - Solicitação de Compra** ou **OP - Ordem de Produção**?  
  
**Ambiente**TOTVS Manufatura - TOTVS Manufatura (Linha Protheus) - Planejamento e Controle da Produção (SIGAPCP) - Versão 12  
  
**Solução**Ao identificar a necessidade de aquisição de um determinado item o Sistema irá gerar uma **OP** se encontrar estrutura para o item, caso contrário irá gerar uma **SC**. Não há uma configuração no cadastro de produtos para essa identificação.
