**Bloqueio/Desbloqueio de Recálculo**

Este módulo é utilizado para realizar o bloqueio e/ou desbloqueio do recálculo de toda a movimentação já processada no período para os funcionários, para uma seção, unidade ou ainda, para um funcionário.

Para bloqueio e/ou desbloqueio o sistema respeita o filtro de perfil de usuário para acesso a funcionários cadastrado em "Cadastros | Segurança | Perfis | Pasta de Acesso a Funcionários".

Para proceder à alteração, deverão ser preenchidos corretamente os seguintes campos:

**Para o grupo de funcionários**

**Código de quebra -** Informe o código de quebra da seção a qual pertencem os funcionários que terão os dados alterados.

**Seleção de Funcionários -** Clique no botão "Seleção de Funcionários" para acessar a janela que irá selecioná-los por situação, tipo, código de recebimento, chapa ou mesmo criar filtros para seleção.

**Observação**

Após montar a seleção, visualize os funcionários para ter certeza que o bloqueio ou desbloqueio será feito corretamente.

**Bloquear/Desbloquear Recálculo** **Visualizar -** Clique aqui para visualizar a chapa, o nome, o código da seção e o status do recálculo dos funcionários, ou seja, se o recálculo está bloqueado ou desbloqueado. Para isso será disposto imagens intuitivas. A tela que abrirá disponibilizará os processos de bloquear e desbloquear o recálculo, disponibilizando também outros recursos de posicionamento e procura de registros, configuração de colunas e exportação dos registros da visão para arquivo do tipo CSV e criação de filtros.

**Atenção -** A visualização respeitará a seleção de funcionários.

**Bloquear -** Este botão será utilizado para bloquear o recálculo conforme seleção.

**Desbloquear -** Este botão será utilizado para desbloquear o recálculo conforme seleção.

**Perfil de Parâmetros -**Este campo permite guardar a configuração dos parâmetros habilitados do lançamento. Ao acessar novamente este lançamento, basta selecionar o perfil criado para o sistema trazer os parâmetros salvos.

**Salvar perfil ao concluir -** Este parâmetro é utilizado para incluir um novo perfil de parâmetros. Informe o nome de um novo perfil, marque o parâmetro "salvar perfil ao concluir" e ao executar as opções "Bloquear" ou "Desbloquear" o sistema gravará o novo perfil de parâmetros.
