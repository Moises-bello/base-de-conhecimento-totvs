# Marcação de Agendamento Desabilitada

|  |  |
| --- | --- |
| **Produto:** | TOTVS GESTÃO HOSPITALAR |
| **Versões:** | 11.8X - 12.1.X |
| **Ocorrência:** | Quando a marcação de agendamento está desabilitada. |
| **Passo a passo:** | É necessário configurar os Perfis de acesso para realizar agendamento:  1º Passo: Acessar CADASTRO > USO GERAL > AGENDAMENTO > AGENDAS;    2º Passo: Selecione a agenda > ANEXO > USUÁRIO QUE ALTERAM A AGENDA;    3º Passo: Adicione o usuário que necessita visualizar a agenda;    4º CADASTRO > SEGURANÇA > PERFIL;    5º Passo: SELECIONE O PERFIL > ABA ACESSO A MENUS > + ATENDIMENTO + AGENDAMENTO + AGENDA DE ATENDIMENTOS > Desmarque a opção "VISUALIZA TODAS AGENDAS". |
