![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura:**00:02:00 min** **Dúvida**

Quando é adquirido o serviço do Totvs Comex Conteúdo (**EICDI100**) no módulo **SIGAEIC** , a liberação é feita para a família de cnpj do cliente ou específico para uma filial?

**Ambiente**Cross Segmento - TOTVS Backoffice (Linha Protheus)  – *Easy Import Control* – Todas versões  
  
**Solução**Quando é liberado o serviço do Totvs Comex Conteúdo é feita pela raiz do CNPJ. Então todas as filiais com a mesma raiz podem utilizar a rotina.
