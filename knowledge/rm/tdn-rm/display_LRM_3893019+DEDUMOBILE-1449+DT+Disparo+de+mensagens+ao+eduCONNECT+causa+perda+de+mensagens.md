# Mensagens ao eduCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS eduCONNECT |
| **Função:** | Processo de envio de mensagens eventuais |
| **Situação/Requisito:** | As mensagens do eduCONNECT demoravam muito para ser disparadas, e em alguns casos, as mensagens sequer eram enviadas, causando término abrupto do processo. Em alguns casos não era sequer possível saber o porquê de não ter enviado. |
| **Solução/Implementação:** | Aperfeiçoado o envio das mensagens do eduCONNECT para todos os usuários destinados, bem como a otimização do rastreamento de possíveis problemas relacionados ao envio, que serão devidamente registrados em log.. |
