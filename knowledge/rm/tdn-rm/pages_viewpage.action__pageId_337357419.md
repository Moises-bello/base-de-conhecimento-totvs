# SISTEMA NÃO ALTERA PARCIAL DA REQUISIÇÃO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Alteração de parcial |
| **Situação/Requisito:** | Ao alterar a data de uma parcial o sistema não está alterando a parcial da requisição associada ao atendimento, gerando assim uma inconsistência ao processar a requisição. |
| **Solução/Implementação:** | Ao alterar a data da parcial, o sistema está alterando a parcial das requisições que estão no período das parciais alteradas |
