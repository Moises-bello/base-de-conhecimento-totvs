# HISTÓRICO DE OCORRÊNCIA SEFIP

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | TOTVS Folha de Pagamento |
| **Função:** | Histórico de Ocorrência SEFIP |
| **Situação/Requisito:** | Ao realizar a transferência de um funcionário para outra seção (mesma coligada), o histórico de ocorrência do SEFIP, permanece com a data original, não sendo alterado para a data de transferência, dessa forma, ao gerar o relatório PPP o sistema não carrega os dados do histórico. |
| **Solução/Implementação:** | Implementação de uma condição, onde a data de transferência será considerada para o histórico de ocorrência do SEFIP. |
| **Chamados relacionados:** | TUVMJ1; TVDOKR |
