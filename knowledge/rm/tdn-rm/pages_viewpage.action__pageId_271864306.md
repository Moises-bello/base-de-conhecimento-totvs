# ENVELOPE DE PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Folha de Pagamento |
| **Função:** | Envelope de Pagamento |
| **Situação/Requisito:** | Ao mudar a competência na tela de envelope de pagamento, o sistema valida se é possível alterar o envelope daquela competência. Em caso negativo, a checkbox de "Forçar valores no envelope" continua habilitada, permitindo habilitar o botão de salvar e exibindo uma mensagem de erro caso o usuário tente salvar as alterações. |
| **Solução/Implementação:** | Adicionar o controle da checkbox na validação de edição do envelope |
