# Baixa de lançamentos com geração automática de Retenções federais CSRF

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Gestão Financeira* |
| **Função:** | Baixa de lançamentos com geração de retenções federais CSRF |
| **Situação/Requisito:** | Ao realizar a baixa de lançamentos com geração automática de retenções federais CSRF. O número de documento gerado, para os lançamentos, não estão respeitando a parametrização para a retenções.  Parâmetro: *“Gerar número de documento de acordo com os parâmetros dos lançamentos*” disponível na Etapa  60-Geração de Retenções na baixa dos lançamentos a Pagar. |
| **Solução/Implementação:** | Otimizado o processo de baixa de lançamentos com geração automática de retenções federias CSRF para checar o parâmetro (*Gerar número de documento de acordo com os parâmetros dos lançamentos)* na geração do numero de documento. Parâmetro disponível na Etapa  60-Geração de Retenções na baixa dos lançamentos a Pagar. |
