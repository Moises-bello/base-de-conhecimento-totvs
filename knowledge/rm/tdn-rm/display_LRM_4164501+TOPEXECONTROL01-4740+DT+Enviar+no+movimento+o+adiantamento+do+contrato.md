# ENVIAR NO MOVIMENTO O ADIANTAMENTO DO CONTRATO

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Construção e Projetos |
| **Módulo:** | Gestão de Obras e Projetos |
| **Função:** | Gerar Integração com Suprimentos / Faturamento |
| **Situação/Requisito:** | Valor de dedução de adiantamento não é enviado para o item do movimento do modulo de **Gestão de Estoque, Compras e Faturamento**. |
| **Solução/Implementação:** | Quando o TOP esta utilizando o back-office do RM, o valor de adiantamentos é enviado como desconto do movimento ao  **Gestão de Estoque, Compras e Faturamento**. |
