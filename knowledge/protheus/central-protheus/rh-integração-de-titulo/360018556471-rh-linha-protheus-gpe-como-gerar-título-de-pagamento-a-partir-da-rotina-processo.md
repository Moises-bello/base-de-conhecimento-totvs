**Dúvida**Como gerar título de pagamento a partir da rotina Processos - APTA100?  
  
**Ambiente**TOTVS RH - TOTVS RH (Linha Protheus) - Gestão de Pessoal – A partir da versão 12.  
  
**Solução**1 - Acesse o menu: **Atualizações** ->**Processos Trabalhistas** ->**Processos** ->**Processos**: insira as informações de Sentença/Recursos que sejam necessárias.  
2 - Cadastre os títulos desejados na pasta: **Despesas/Pagamentos.**  
![PROCESSOS.JPG](https://centraldeatendimento.totvs.com/hc/article_attachments/1500000035122)​​  
  
3 - Para visualizar os títulos criados.  
Acesse o menu: **Miscelânea** -> **Títulos** -> **Manutenção**: valide se os itens foram cadastrados corretamente.  
![MOVIMENTO_TITULO.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/360101124193)​  
  
4 - Execute o procedimento para integração do título para a rotina **Contas a Pagar - FINA050** do módulo **Financeiro**.  
Acesse o menu: **Miscelânea** -> **Títulos** -> **Integração**: defina os parâmetros para a integração:  
![INTEGRACAO.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/360101124373)  
  
5 - Caso o processo anterior tenha sido executado com sucesso, o título poderá ser consultado no módulo Financeiro  
Efetue a troca de módulo para **06 - SIGAFIN** no menu acesse: **Atualizações** -> **Contas a Pagar** -> **Contas a Pagar**  
![contas_a_pagar.jpg](https://centraldeatendimento.totvs.com/hc/article_attachments/360101124533)​
