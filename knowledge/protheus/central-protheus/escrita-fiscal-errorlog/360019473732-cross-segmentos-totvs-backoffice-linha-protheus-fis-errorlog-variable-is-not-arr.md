**Ocorrência** Ao gerar apuração ISS ocorre error.log variable is not array - Type [U] on A954PROCESSA(MATA954.PRX) line : 435  
  
**Ambiente**Protheus – Livro fiscal – A partir da versão 12.1.17  
  
**Solução**Para corrigir o error.log verifique se os parâmetros MV\_FXFAT estão preenchidos com as faixas de receitas brutas.
