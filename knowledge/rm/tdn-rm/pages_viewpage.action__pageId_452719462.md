**Pasta Pareceres - Requisição de Alteração de Dados Funcionais**

Os pareceres tem como objetivo registrar as alterações realizadas na requisição de alteração de dados funcionais. Cada parecer estará sempre vinculado a uma única requisição, porém, uma requisição poderá ter diversos pareceres.

Para acessar o parecer de uma requisição de Alteração de Dados Funcionais o usuário deverá acessar a requisição desejada, Anexos | Parecer de Alteração de Dados Funcionais.

**Pasta Identificação do Parecer de Alteração de Dados Funcionais**

Na pasta Identificação os seguinte dados devem ser informados:

**Emitido em -** Este campo exibirá a data e hora da emissão do parecer e não poderá ser alterado.

**Status -** Exibirá o status que a requisição assumiu conforme definição do fluxo de aprovação, porém, se a requisição não tiver sido incluída no fluxo, ou seja, quando o controle estiver sendo feito manualmente, este campo poderá ser alterado. Esta alteração será possível apenas no Totvs Gestão de Pessoas.

**Parecer emitido -** Deve conter o texto do parecer emitido pelo usuário.

**Responsável -** Somente podem ser selecionados chefes da coligada na qual o usuário do Totvs Gestão de Pessoas esteja logado. Para informações relacionadas aos chefes das seções verifique o cadastro de chefes e supervisores.

**Filial/Função e E-mail -** Após preenchimento do campo "Responsável", os dados relacionados a estes campos serão exibidos automaticamente. O campo "Filial/Função" deve exibir o nome da filial seguido do nome da função de lotação do funcionário selecionado no campo "Responsável". A informação do campo "E-mail" deverá ser automaticamente atualizada com o e-mail que constar no cadastro do responsável indicado.

Para confirmar esta informação acesse Acompanhamento | Pessoas | Pasta Identificação.

**Pasta Dados da Requisição de Alteração de Dados Funcionais** **Funcionário**

Este campo apresentará o nome do funcionário selecionado na requisição e não poderá ser alterado.

**Previsão -** Exibirá a mesma data prevista da requisição. Este campo poderá ser alterado ao criar um novo parecer para a requisição.

**Dados atuais do funcionário:**

**Função de origem -** Este campo não é editável e apresentará a função onde o funcionário selecionado está lotado.

**Nível Salarial de Origem -** Este campo não é editável e apresentará o nível salarial atual do funcionário selecionado.

**Faixa Salarial de Origem -** Este campo não é editável e apresentará a faixa salarial atual do funcionário selecionado.

**Salário de origem -**Este campo não é editável e apresentará o salário atual do funcionário selecionado.

**Proposta de alteração****:**

**Função -** Este campo apresentará a função proposta para alteração dos dados do funcionário selecionado e poderá ser alterado ao criar um novo parecer para a requisição.

**Tabela Salarial -** Caso o Totvs Gestão de Pessoas esteja configurado para utilizar tabelas salariais, o sistema exibirá a tabela salarial vinculada à função do funcionário selecionado. Este campo não é editável.

**Nível e Faixa Salarial -** Após o preenchimento do campo "Função" e se o parâmetro "Considerar os salários das tabelas salariais" estiver marcado, serão apresentados os níveis e as faixas da tabela vinculada à seção/função ou ao quadro de lotação. Estes campos poderão ser alterados ao criar um parecer para a requisição.

**Salário/ Percentual -** Se o parâmetro "Considerar os salários das tabelas salariais" estiver marcado, e for informado o nível e faixa salarial, o campo salário é preenchido automaticamente. Caso contrário, pode ser informado um percentual de aumento a ser considerado nesta alteração de dados funcionais ou informar diretamente o salário proposto do funcionário, considerando se está desmarcado o parâmetro "Não permitir alterar diretamente o salário".

Este campo poderá ser alterado ao criar um parecer para a requisição.

**Motivo de mudança de função -** Se a função proposta para o funcionário for diferente da função atual, deverá ser informado o motivo de mudança de função. Este campo poderá ser alterado ao criar um parecer para a requisição.

**Motivo de mudança salarial -** Se o salário proposto para o funcionário for diferente do salário atual, deverá ser informado o motivo de mudança salarial. Este campo poderá ser alterado ao criar um parecer para a requisição.

**Gerar substituição -** Esta opção deverá ser marcada se for necessário manter o número de vagas disponíveis ao concluir esta requisição, em função das configurações definidas no controle de lotação. Este campo poderá ser alterado ao criar um parecer para a requisição.
