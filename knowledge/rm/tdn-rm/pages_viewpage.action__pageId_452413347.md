# VALIDAÇÃO DE INADIMPLÊNCIA - PROCESSO DE CONFIRMAÇÃO DE MATRÍCULA POR PAGAMENTO

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | *Educacional* |
| **Módulo:** | *Totvs Educacional* |
| **Função:** | *Processo de confirmação de matrícula por pagamento* |
| **Situação/Requisito:** | *Ao executar o processo de confirmação de matrícula por pagamento, o sistema está bloqueando devido à inadimplência do aluno, mesmo com o parâmetro para validação desmarcado. Apenas a validação para enturmação está marcada.* |
| **Solução/Implementação:** | *Foi realizado um ajuste no sistema para que a validação de inadimplência da enturmação seja realizada na matrícula apenas quando o processo de enturmação for realizado.* |
