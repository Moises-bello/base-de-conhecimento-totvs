# Campo Parcial (SEQPARCIAL) na tela de Controle de Documentos

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Controle de Documentos |
| **Situação/Requisito:** | Cliente solicita a vinculação do campo PARCIAL (SEQPARCIAL) pois considera que a conta deve ser formada pelo CODPACIENTE+CODATENDIMENTO+SEQPARCIAL. Também solicita que a pesquisa de pacientes seja melhorada, pois está demorando muito para carregar a tela de pesquisa. |
| **Solução/Implementação:** | Colocado na tela o campo Parcial (SEQPARCIAL), e para a pesquisa de paciente, foram adicionadas algumas melhorias na query responsável por carregar a pesquisa, inclusive a limitação de carregar apenas 1000 registros. |
