Neste tutorial vamos explicar como disponibilizar sua base de dados com o programa de FTP chamado Classic FTP. Para instalar este programa, faça o download em <http://www.nchsoftware.com/classic/cftpsetup.exe>

Após instalar o programa, abra-o e siga os passos abaixo para configurá-lo:

**1. Clique no Botão Sites:**

**2. Clique no Botão Add Site:**

**3. Preencher as informações para acesso ao diretório, como descrito abaixo:**

*a)       Label: FTP RM*  
*b)       FTP Server: ftp.rm.com.br*  
*c)       User Name: clienteonline*  
*d)       Password: ftponline02*  
*e)       Marque a opção “Use this directory always”*  
*f)        Remote directory path: /clientes/xxxxxxxxxxxxxx (xxxxxxxx = codigo CFO + CNPJ)*  
*g)       Clique em OK.*

**4. Selecione o item criado e clique em Connect:**

**5. Para realizar o Upload da base de dados, navegue pelos diretórios do lado esquerdo do programa. Selecione o backup da base de dados e clique do botão de Upload:**

**6. Aguarde a conclusão do Upload.**
