# EFD Contribuições

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Serviços |
| **Módulo:** | TOTVS Gestão Fiscal |
| **Função:** | EFD Contribuições |
| **Situação/Requisito:** | Os Documentos Fiscais que não possuem os tributos PIS e COFINS no primeiro item não estão sendo considerados na geração da EFD Contribuições. |
| **Solução/Implementação:** | Efetuado tratamento para correta geração dos documentos na rotina fiscal independente da ordem dos itens que possuem o PIS e a COFINS |
