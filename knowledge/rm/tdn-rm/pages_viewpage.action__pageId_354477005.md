# PLANO DE AULA

|  |  |
| --- | --- |
| **Linha de Produto:** | RM. |
| **Segmento:** | Educacional. |
| **Módulo:** | TOTVS Gestão Educacional. |
| **Função:** | Edição do plano de aula da turma/disciplina |
| **Situação/Requisito:** | Ao editar o plano de aula, o sistema permitia incorretamente alteração no plano de aula, mesmo configurado para bloquear alterações em período letivo encerrado. |
| **Solução/Implementação:** | Otimização no plano de aula para obedecer as configurações do Parâmetros Educacional | Secretaria | Período Letivo – Bloqueia alteração em período letivo encerrado”.  Nos parâmetros do perfil de usuário também está bloqueado desmarcando o campo “Alterar dados em período letivo encerrado”.  Na situação citada acima, não será permitido alterar informações no plano de aula e nem gerar plano de aula. |
