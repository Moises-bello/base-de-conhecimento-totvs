# FUNCIONALIDADE "VER TODOS" NO EDUCONNECT

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Educacional |
| **Módulo:** | TOTVS Gestão Educacional |
| **Função:** | Funcionalidade "Ver todos" no eduCONNECT |
| **Situação/Requisito:** | A funcionalidade "Ver todos", apresentada na barra de pesquisa, era exibida sempre, independente se o texto da barra de pesquisa estivesse preenchido ou não no eduCONNECT. |
| **Solução/Implementação:** | Aperfeiçoada a exibição da funcionalidade "Ver todos" para que seja apresentada apenas caso haja algum texto preenchido na barra de pesquisa do eduCONNECT. |
