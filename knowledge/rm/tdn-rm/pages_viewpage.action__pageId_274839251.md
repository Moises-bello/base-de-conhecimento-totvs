# Envio de Paciente para Observação

|  |  |
| --- | --- |
| **Linha de Produto:** | RM |
| **Segmento:** | Saúde |
| **Módulo:** | TOTVS Gestão Hospitalar |
| **Função:** | Painel de Classificação de Risco |
| **Situação:** | Necessário a realização de uma implementação, quando o médico efetuar a chamada de um paciente na classificação de risco e abrir o PEP, ao fechar o PEP e abrir a tela de finalização do atendimento, deve possuir uma opção para enviar o paciente para observação também. |
| **Solução:** | Criado uma opção que permite enviar o paciente para observação quando este ainda não estiver, direto na tela de finalizar o atendimento, que é aberta ao fechar o PEP na chamada na classificação de risco. |
