| **Ambiente:** |  |
| **Passo a passo:** | * No módulo Integração vá no menu: Integração/ Gerador de Saída/ Categoria.      * Clique em Incuir e informe o nome da nova categoria.        * Na aba Perfis da Categoria, vincule os perfis dos usuários que terão permissão para importar o layout. Observe o código do perfil e sistema correspondentes para a importação do layout no Módulo em questão.         Obs.: Se a categoria já estiver cadastrada, basta apenas vincular o perfil do usuário para ter acesso a importação do layout. |
