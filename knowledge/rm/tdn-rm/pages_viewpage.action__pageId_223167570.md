# NEGOCIAÇÃO ONLINE

|  |  |
| --- | --- |
| **Linha de Produto:** | *RM* |
| **Segmento:** | **Educacional** |
| **Módulo:** | **Totvs Gestão Educacional** |
| **Função:** | *Negociação Online* |
| **Situação/Requisito:** | *Ao acessar a negociação, através do portal, lançamentos de bolsa de crédito, estão sendo exibidos, mesmo com o sistema parametrizado para não exibir boletos de bolsa de crédito na tela de histórico financeiro do aluno. O sistema está correto, porém como não há parametrização similar para a tela de negociação, esse comportamento gera questionamentos.* |
| **Solução/Implementação:** | *Foi feita otimização do sistema afim de tornar mais abrangente o parâmetro para exibir boletos de bolsa de crédito na tela do histórico financeiro do aluno. Assim, o parâmetro passa a ter a função de exibir lançamentos financeiros de bolsa de crédito no portal. Dessa forma foi otimizada a tela de negociação para que respeite a parametrização.* |
