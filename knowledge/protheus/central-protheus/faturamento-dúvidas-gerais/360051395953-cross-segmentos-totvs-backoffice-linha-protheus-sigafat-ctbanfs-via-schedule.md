**Dúvida**

Como rodar a contabilização off line (**CTBANFS)** via **Schedule**?

**Ambiente**

Cross Segmentos -TOTVS Backoffice (Linha Protheus)-SIGAFAT - todas as versões.

**Solução**  
Para rodar o contabilização off line (**CTBANFS)** via **Schedule** é necessário :

1) Acessar o Modulo Configurador - Ambiente - **Schedule;**

2) Verificar se o Status está como Iniciado;

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079038753/mceclip0.png)

3) Incluir o Cadastro da rotina " **CTBANFS** " e verificar os parâmetros :

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079038833/mceclip1.png)

4) Incluir a recorrência;

![mceclip2.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360077898314/mceclip2.png)  
  
\* Caso não seja incluída a recorrência o Status ficará como Finalizado ao invés de Habilitado/Desabilitado

![mceclip3.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360079039053/mceclip3.png)
