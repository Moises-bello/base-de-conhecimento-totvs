![time.png](https://centraldeatendimento.totvs.com/hc/article_attachments/360023589592/time.png) Tempo aproximado para leitura: **00:02:00 min** **Dúvida**Ao alterar um Lançamento Padronizado é emitido o Help CTBA080POS

**Ambiente**Cross Segmentos - TOTVS Backoffice (Linha Protheus) - Faturamento (SIGAFAT) - todas as versões  
  
**Solução**Por padrão, o sistema possibilita a configuração de mais de uma sequencia para o mesmo lançamento padrão.  
  
Porém, como a regra de negócio permite que apenas UMA UNICA CONTA seja levada para o campo FT\_CONTA,  não é permitido indicar mais de uma sequência de lançamento como receita/despesa

![mceclip1.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4417412644247/mceclip1.png)

Caso contrário a rotina emitirá uma mensagem impedindo a conclusão do processo.

![mceclip0.png](https://centraldeatendimento.totvs.com/hc/article_attachments/4417419547927/mceclip0.png)
